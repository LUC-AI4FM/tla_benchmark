You are a TLA+ specification engineer. You will receive a natural language description of a system. Produce a complete, syntactically correct TLA+ specification that faithfully captures the described behavior. The output must be a valid TLA+ module that passes the SANY parser. Include the MODULE declaration, EXTENDS, CONSTANTS, VARIABLES, Init, Next and Spec. Include all safety invariants and liveness properties described, and any fairness conditions mentioned. Output only the TLA+ specification.

System description: The XPlusCal module is a formal specification, written by Leslie Lamport in 2005, of the translation from a +CAL algorithm's abstract syntax tree (AST) to its corresponding TLA+ description. It is a utility or translator-specification module rather than a model of a concurrent system.

The module defines the grammar of +CAL ASTs using record-valued sets and mutually recursive predicates. The main syntactic categories covered include Algorithm (uniprocess and multiprocess), Procedure, Process, VarDecl, PVarDecl, LabeledStmt, While, LabelSeq, LabelIf, LabelEither, FinalStmt, Assign, CallOrReturn, Goto, and SimpleStmt. TLA+ expressions are represented throughout as sequences of string lexemes.

The core operator is `Translation(alg, fairnessOption)`, which takes a valid algorithm AST and a fairness option ("", "wf", "wfNext", or "sf") and produces a sequence of lexemes constituting the full TLA+ specification of that algorithm. Internally, `Translation` proceeds by: exploding labeled statements into simple labeled statements via `Explode` and `FullyExplodeSeq`; translating calls, returns, and gotos into explicit assignments to the `pc` and `stack` variables via `XlateCall`, `XlateReturn`, `XlateCallReturn`, and `XlateGoto`; adding process-local variable subscripts via `AddSubscript` and `ProcessVars`; and assembling the Init predicate, Next-state action, per-procedure and per-process action definitions, the Spec formula, and a Termination liveness property. The fairness conditions are added as conjuncts to Spec based on the chosen option. The module concludes with an ASSUME clause that, when model-checked, computes and prints `Translation(ast, fairness)` for an externally supplied AST constant.
