```tla
-------------------------------- MODULE AsyncHandshake --------------------------------
EXTENDS Naturals

CONSTANT Data

VARIABLES val, rdy, ack

vars == <<val, rdy, ack>>

TypeInvariant == 
    /\ val \in Data
    /\ rdy \in {0, 1}
    /\ ack \in {0, 1}

Init == 
    /\ val \in Data
    /\ rdy \in {0, 1}
    /\ ack = rdy

Send == 
    /\ rdy = ack
    /\ val' \in Data
    /\ rdy' = 1 - rdy
    /\ ack' = ack

Rcv == 
    /\ rdy # ack
    /\ ack' = rdy
    /\ val' = val
    /\ rdy' = rdy

Next == Send \/ Rcv

Spec == Init /\ [][Next]_vars

THEOREM Spec => []TypeInvariant

=============================================================================
```
