```tla
---------------------------- MODULE Barrier ----------------------------
EXTENDS Integers, FiniteSets

CONSTANT N

ASSUME N \in Nat /\ N > 0

VARIABLES pc

Procs == 1..N

Init == pc = [p \in Procs |-> "b0"]

Enter(p) == /\ pc[p] = "b0"
            /\ pc' = [pc EXCEPT ![p] = "b1"]

Reset == /\ \A p \in Procs : pc[p] = "b1"
         /\ pc' = [p \in Procs |-> "b0"]

Next == \/ \E p \in Procs : Enter(p)
        \/ Reset

Spec == Init /\ [][Next]_pc

TypeOK == pc \in [Procs -> {"b0", "b1"}]

BarrierProperty == \A p \in Procs : \A q \in Procs :
                      (pc[p] = "b0" /\ pc[q] = "b1") => (pc'[q] = "b1" \/ pc'[p] = "b0")

=========================================================================
```
