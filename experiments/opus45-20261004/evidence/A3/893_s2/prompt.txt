System description: This specification models a simple one-place communication channel with handshake between a sender and a receiver. The channel is represented as a record with fields for the value being sent (val), a ready bit (rdy), and an acknowledge bit (ack), with both rdy and ack taking values 0 or 1. The sender can send a value when rdy equals ack, flipping rdy and updating val; the receiver can receive when rdy and ack differ, flipping ack. The temporal property Spec asserts that the system starts in a state where the channel is initialized and then always evolves according to the Next action, which allows either sending or receiving. The main property proved is that the type invariant on the channel is always preserved.
