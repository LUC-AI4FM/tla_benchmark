---------------------------- MODULE SmallStateMachine ----------------------------
EXTENDS Integers

VARIABLES x, y

Foo(f, idx) ==
    IF idx = 1
    THEN [f EXCEPT ![idx] = 42]
    ELSE f

Init ==
    /\ x \in 1..5
    /\ y = [i \in {1,2,3,4,5} |-> 0]

Next ==
    /\ y' = Foo(y, x)
    /\ x' = x

Spec == Init /\ [][Next]_<<x, y>>

=============================================================================
