---------------------------- MODULE CountToFive ----------------------------
EXTENDS Naturals

VARIABLES x

Init == x = 1

Next == 
    IF x < 5 
    THEN x' = x + 1
    ELSE x' = x

Spec == Init /\ [][Next]_x /\ WF_x(Next)

TypeInvariant == x \in 1..5

SafetyInvariant == x >= 1 /\ x <= 5

Liveness == (x = 1) ~> [](x = 5)

=============================================================================
