```tla
---------------------------- MODULE SmallStateMachine ----------------------------
EXTENDS Integers, TLC

VARIABLES x

\* Helper predicates
IsOne == x = 1
AllDone == x = 2
WrapAround == x = 2 /\ x' = 0

\* Initial state
Init == x = 0

\* Next state relation - advances modulo 3
Next == x' = (x + 1) % 3

\* Temporal specification with stuttering
Spec == Init /\ [][Next]_x

\* Safety invariant - x is always in {0, 1, 2}
TypeInvariant == x \in {0, 1, 2}

\* TLC-specific check for named-state coverage
\* This checks that each of the three predicates (IsOne, AllDone, WrapAround equivalent states) are visited
TLCCoverageCheck ==
    LET isOneCoverage == TLCGet("stats").coverage["IsOne"]
        allDoneCoverage == TLCGet("stats").coverage["AllDone"]
        wrapAroundCoverage == TLCGet("stats").coverage["WrapAround"]
    IN isOneCoverage = 1 /\ allDoneCoverage = 1 /\ wrapAroundCoverage = 1

===============================================================================
```
