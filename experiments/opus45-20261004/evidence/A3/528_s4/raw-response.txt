```tla
----------------------------- MODULE SmallPlusCal -----------------------------
EXTENDS Sequences, TLC

CONSTANTS a, b, c

VARIABLES x, y, pc

vars == <<x, y, pc>>

Init ==
    /\ x = {a, b}
    /\ y = <<1, 2, 3>>
    /\ pc = "start"

MainStep ==
    /\ pc = "start"
    /\ x' = x \cup {c}
    /\ y' = <<y[1], 4, y[3]>>
    /\ PrintT(x')
    /\ PrintT(y')
    /\ pc' = "Done"

Terminating ==
    /\ pc = "Done"
    /\ UNCHANGED vars

Next ==
    \/ MainStep
    \/ Terminating

Spec == Init /\ [][Next]_vars

Termination == <>(pc = "Done")

TypeInvariant ==
    /\ x \subseteq {a, b, c}
    /\ y \in Seq(Int)
    /\ Len(y) = 3
    /\ pc \in {"start", "Done"}

=============================================================================
```
