```tla
---------------------------- MODULE SmallStateMachine ----------------------------
EXTENDS Naturals

CONSTANTS MyNat

VARIABLES x

TypeOK == x \in MyNat

Init == x = 0

A == x' = (x + 1) % 31

BandC == 
    /\ x < 30
    /\ x' = x + 1

DandE ==
    /\ x > 0
    /\ x' = x - 1

Next == A \/ BandC \/ DandE

Inv == x \in MyNat

Spec == Init /\ [][Next]_x

=============================================================================
```
