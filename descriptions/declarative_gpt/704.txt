This module defines a representation of undirected graphs in TLA+ where each edge is modeled as an unordered pair {a,b} of nodes, which enforces symmetry directly in the data representation. It provides predicates for checking whether a structure is an undirected graph or a loop-free undirected graph, defines subgraphs, paths, simple paths, and computes connected components by iteratively merging node sets connected by edges. The module is purely structural and state-free: it has no VARIABLES, no actions, and no temporal correctness properties; instead it focuses on graph-theoretic definitions using sets, sequences, choice, and folds.
