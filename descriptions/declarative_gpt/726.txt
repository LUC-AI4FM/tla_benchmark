This module is a test specification for a collection of sequence-related operators provided by extended library modules such as SequencesExt and related utility modules. It does not model a transition system with variables or temporal behavior; instead, it uses many ASSUME assertions to check the expected behavior of operators over sequences, strings, sets, bags, folds, prefixes, suffixes, subsequences, interleavings, zips, replacements, and permutation-generating utilities. The file also defines several pure reference operators, often local helper definitions, to compare library implementations against mathematically specified alternatives, and it includes error-message assertions for invalid argument cases.
