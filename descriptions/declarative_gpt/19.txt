This specification models a simple message-set system with two message channels stored in a record variable: one for integer-tagged messages and one for string-tagged messages. The system can add integer messages, remove and inspect integer messages, add string messages, and remove and inspect string messages; inspection updates boolean flags when the removed message carries the distinguished payload 3 or "c" respectively. The spec defines initial state, individual actions, a Next-state relation as the disjunction of those actions, and a type-correctness predicate, but it does not include a temporal specification such as Spec, fairness assumptions, or liveness properties.
