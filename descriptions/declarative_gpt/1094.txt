This specification models a simplified PCR process with explicit thermal stages and molecular counts. The state tracks temperature, remaining primers, double-stranded DNA, single-stranded template, template-primer hybrids, a stage/history variable, and a cycle counter. The design constrains the order of actions through the stage variable so that heating, cooling, annealing, and extension occur in a sensible sequence, and the temporal specification requires weak fairness for each step while checking a type invariant and importing properties from an instantiated clean module.
