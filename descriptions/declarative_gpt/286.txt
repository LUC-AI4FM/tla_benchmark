This module specifies a small test about function comparison, specifically comparing a function whose domain is empty against another function value. The comments indicate it is intended as a regression test for an Apalache issue involving function comparison with an empty-domain function. The specification defines an initial state in which result is constrained both to belong to a singleton set containing one function and to equal an empty-domain function, while found is an unconstrained Boolean value; it also defines a stuttering next-state relation and a simple state predicate NotFound.
