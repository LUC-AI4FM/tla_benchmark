This module specifies the Car Talk balance-scale puzzle about breaking an N-pound stone into P integer-weight pieces so that any integral weight from 1 through N can be weighed using a balance. It models candidate breaks as nondecreasing functions from 1..P to 1..N, defines when a target weight is representable by placing some pieces on each side of the scale, and characterizes solutions as breaks that represent every weight in 1..N. The spec is not a transition system with variables or temporal behavior; instead it is a mathematical specification intended for TLC evaluation of the set of all solutions, with an auxiliary operator that expands each solution into explicit weighing instructions.
