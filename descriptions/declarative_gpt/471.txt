This TLA+ specification models Dijkstra's distributed termination detection algorithm on a ring network, as described in EWD 840. The system consists of N nodes arranged in a ring, each of which can be active or passive and colored white or black. A token circulates among the nodes, carrying a color, and the protocol uses the token and node colors to detect global termination. The model includes actions for initiating a probe, passing the token, sending messages (which may activate other nodes and stain the sender black if the activation goes against the token direction), and deactivating nodes. The specification verifies type correctness, models the next-state relation as a disjunction of system and environment actions, and asserts a temporal property requiring weak fairness for the system actions. The fault model is benign (no faults), and the design is focused on correctness of the termination detection protocol.
