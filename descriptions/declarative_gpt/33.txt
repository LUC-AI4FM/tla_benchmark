This module defines an option-type utility library in TLA+ using Apalache variants. It models the common algebraic datatype with two alternatives, `Some(x)` for present values and `None` for absence, and provides eliminators and combinators such as case analysis, map, flatMap, default extraction, conversion to sequences and sets, nondeterministic guessing from a set, lifted function application, and conversion of a total function into an option-valued partial-style function. The module is purely definitional: it declares no state variables, no transition actions, and no temporal properties, and it relies on the imported `Apalache` and `Variants` modules for variant construction and access.
