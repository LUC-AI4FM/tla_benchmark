This file contains two TLA+ modules. The first module, Github790, specifies a trivial one-variable system in which the variable a is initialized to 0 and every next-state step leaves a unchanged, so the behavior is entirely stuttering after initialization. It defines a temporal specification Spec as Init /\ [][Next]_a and also defines a temporal formula AlwaysTrue asserting <>TRUE => <>[]TRUE. The second module, Github790_proof, extends the first and TLAPS and proves the theorem AlwaysTrue using the PTL backend; there is no fault model and no PlusCal algorithm.
