This module specifies the N-queens problem and an iterative algorithm for computing all solutions. A queen placement is represented as a function from rows to columns, concretely as a sequence, and partial placements are represented as shorter sequences. The algorithm maintains a set of partial solutions in todo and a set of complete solutions in sols, repeatedly extending one partial solution by placing the next queen in every non-attacking column. The specification includes an initial condition, a next-state action with weak fairness, a type invariant, a correctness invariant relating sols and the mathematical set of all solutions, and a termination property asserting that eventually todo becomes empty.
