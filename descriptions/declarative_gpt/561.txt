This module is a small model-checking companion module for the transaction commit specification defined in TCommit. It adds two top-level state predicates over the variable rmState: a type-correctness condition requiring each resource manager to be in one of the four named status strings, and a consistency condition stating that no two resource managers can simultaneously be in aborted and committed states respectively. The module itself does not define actions, temporal behavior, fairness, or proofs; it only introduces these state-level predicates while extending another module.
