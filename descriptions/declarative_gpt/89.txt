This specification models a simple one-place communication channel with a data value and a two-bit ready/ack handshake. The state variable chan is a record with fields val, rdy, and ack; sending is enabled when rdy equals ack and flips rdy while storing a data value, while receiving is enabled when rdy differs from ack and flips ack. The specification defines an initial condition requiring the channel to satisfy its type invariant and start with ack equal to rdy, then constrains behavior with the temporal formula Init /\ [][Next]_chan. It proves that the type invariant is always preserved.
