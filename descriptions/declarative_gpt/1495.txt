This specification models a simple state machine over a single variable x together with side effects through TLCSet and TLCGet. The initial state sets x to 0, and the main step Next requires x = 0 and then performs a sequential action composition of three actions A applied to the sets {1,2}, {3,4}, and {5}, respectively. The temporal property Spec is a standard safety-style specification Init /\ [][Next]_x, and the file also defines a PostCondition that checks TLC-side generated values, but it does not include fairness or liveness requirements.
