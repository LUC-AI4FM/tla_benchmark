This specification models an inner sequential memory/request handling component with per-process register files, a per-process queue of issued operations, and a memory array. Processes can issue requests into free registers, receive responses for reads and writes, and internally remove completed operations from the head of their queue, updating memory for writes and checking consistency for reads. The spec asserts a data invariant over the register file, operation queues, and memory structure, and defines a temporal specification with weak fairness for response actions and queue removal so that enabled operations are not postponed forever.
