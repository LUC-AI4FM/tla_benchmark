This module is a model-checking harness around an alternating-bit protocol specification imported from another module. It adds queue-length constraints, states liveness and temporal properties about sent data eventually being received and about possible permanent disagreement of protocol bits, and records a concrete postcondition/counterexample structure using TLC-style trace data. The file also introduces a derived action-temporal formula and a simple stability property over sent data, while composing a combined specification from the imported protocol specification and an added temporal condition.
