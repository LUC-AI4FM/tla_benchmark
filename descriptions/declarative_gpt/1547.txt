This specification models a buffered random-access file implementation corresponding to BufferedRandomAccessFile.java, including the key in-memory fields, the underlying file state, and the operations seek, read, write, flush, and setLength. It defines internal invariants Inv1 through Inv5 about the relationship between the in-memory buffer, the logical file contents, and the on-disk file, and it checks both those invariants and refinement against an abstract RandomAccessFile specification. The module also states action-by-action refinement properties for the concrete operations, includes temporal safety properties over the next-state relation, and adds a liveness property that dirty data eventually leads to a clean state.
