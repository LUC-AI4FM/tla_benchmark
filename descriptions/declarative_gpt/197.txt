This module specifies a simple state machine over a single variable S, where S is a finite subset of the integers 1..10 initially constrained to have cardinality at least 5. Each next-state step nondeterministically chooses an element of S: if the chosen element is even, it is replaced by its doubled value; if it is odd, it is removed from the set. The specification also defines a state predicate Inv asserting that some element of S is positive; the module contains only initialization, next-state relation, and invariant-style state predicates, with no temporal specification, fairness conditions, proofs, or fault model.
