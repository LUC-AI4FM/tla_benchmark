This module, named Utils, provides utility operators for working with cycles in graphs represented as functions. The IsSimpleCycle operator checks whether a given function r over a finite set S forms a simple cycle, using a constructive approach to build the cycle sequence. The SimpleCycle operator is a recursive variant that constructs a cycle from a sequence, leveraging the SequencesExt module for set-to-sequence conversion. The comments note that IsSimpleCycle is compatible with PlusPy, while SimpleCycle is more efficient for TLC but not supported by PlusPy. No temporal properties or fault models are specified; the module is intended as a reusable library for cycle-related predicates.
