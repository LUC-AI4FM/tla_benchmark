This specification models Safra's distributed termination detection algorithm on a ring, as described in EWD 998. Nodes maintain activity status, colors, local message counters, pending in-flight messages, and a circulating token whose position, accumulated counter, and color are used to detect global termination. The spec includes safety properties relating token-based detection to actual system termination, an inductive invariant for the algorithm, a liveness property stating that termination is eventually detected, and TLC-specific state and action constraints to bound checking and collect runtime statistics.
