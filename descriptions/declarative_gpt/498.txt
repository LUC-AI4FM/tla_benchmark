This module specifies a multi-slot consensus model in which values can first be proposed and then chosen independently for each slot. The file contains a PlusCal algorithm and its generated TLA+ translation: one action adds a previously unproposed value to the set of proposed values, and another action picks a proposed value for an empty slot by storing it as a singleton chosen set for that slot. The specification proves safety properties including type correctness, nontriviality, stability, and per-slot consistency, and it also states a liveness result under weak fairness of Next that eventually every slot becomes nonempty. The fault model is essentially none: this is an abstract nondeterministic consensus model without crashes or Byzantine behavior.
