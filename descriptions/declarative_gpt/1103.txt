This module specifies the non-blocking atomic commitment (NBAC) algorithm with crash failures, based on Raynal 1997, using a TLA+ encoding. The system models processes that vote YES or NO, exchange messages, may crash, and observe a local failure detector that can nondeterministically report whether some process has crashed. The specification defines initialization, per-process steps combining message receipt, failure detector updates, and local transitions, and verifies structural properties such as type correctness and a validity condition relating unanimous YES votes to possible commit outcomes.
