This module specifies an algorithm for enumerating all k-element subsets of the range 0..(n-1) in a specific total order, representing subsets as increasing sequences rather than unordered sets. The file contains a commented PlusCal algorithm sketch, helper operators for converting a sequence of sequences into a set of sets, and an invariant asserting that upon termination the generated collection matches the expected k-subsets and is sorted according to the defined order.
