This specification models a spanning tree construction algorithm over arbitrary undirected graphs. Unlike the original SpanTree module, here the set of edges (Edges) is a variable, not a constant, and is initialized to any possible set of edges between nodes in Nodes, allowing the algorithm to be tested on all possible graphs with a given number of nodes. The algorithm maintains, for each node, a parent (mom) and a distance (dist) from the root, and updates these values to construct a spanning tree rooted at Root. The specification checks both safety (that when no further steps are enabled, the postcondition holds) and liveness (that the postcondition is eventually reached), and includes a property that all distances become 1. The model is parameterized by the set of nodes, the root, and the maximum allowed distance, and uses finite sets and integer arithmetic.
