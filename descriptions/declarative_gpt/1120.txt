This module defines an SVG-based animation and visualization layer for a Tower of Hanoi specification. It renders the current state of the Hanoi towers into graphical elements, including tower poles, disks, a title, a step counter, and a success banner when all disks have been moved to the final tower. The module does not define the transition system itself; instead, it depends on state and constants imported from the Hanoi module and provides derived view operators for TLC frame generation and interactive SVG debugging.
