This specification models a one-variable transition system in which the state variable x starts at 0 and then can nondeterministically change to either a natural number in the range 1..100, the Boolean value FALSE, or the string value "abc". The spec is intentionally mixing incompatible value types in the same state variable, likely to exercise tool behavior around state representation and liveness checking rather than to model a typed algorithm. It defines a standard temporal specification Spec using Init and the boxed next-state relation, and a liveness-style property Prop asserting that eventually TRUE holds forever, which is trivially satisfied because TRUE is always true.
