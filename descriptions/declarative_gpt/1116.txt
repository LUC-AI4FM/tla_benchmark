This module models an abstract two-peer TCP finite state machine based on RFC 9293, focusing on connection-state transitions rather than low-level protocol details such as sequence numbers. It represents per-peer TCP control block existence, per-peer connection state, and in-flight network messages as sequences, and models user-triggered actions, protocol-driven state transitions, and reset behavior. The specification checks a state invariant about agreement on the ESTABLISHED state when no messages are in flight, and a liveness property that a peer in SYN-SENT eventually reaches ESTABLISHED, LISTEN, or CLOSED. The design explicitly includes RFC note-inspired transitions such as the FIN-WAIT-1 to TIME-WAIT shortcut and a reset action applicable broadly across states, and it adds weak fairness both for system steps and for a specific user close action to avoid getting stuck in SYN-SENT.
