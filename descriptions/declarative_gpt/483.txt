This module specifies a small Paxos-style consensus protocol without explicit leaders or learners, using message passing and a global set of sent messages. It models phase 1a, phase 1b, phase 2a, and phase 2b messages, tracks acceptor promise and vote state, and defines a refinement-oriented view of votes from sent phase 2b messages. The specification focuses primarily on safety rather than realistic message transport, explicitly noting that message loss and duplication are not modeled because safety depends only on which messages may be received; it also includes an inductive invariant and helper definitions copied from a Voting specification to express safe value selection.
