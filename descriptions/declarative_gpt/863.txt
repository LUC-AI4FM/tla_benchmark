This specification models an improved Software Defined Perimeter (SDP) architecture with a legitimate client, an SDP controller, a firewall, a target server, and an attacker operating under a Dolev-Yao-style attacker model for message interception, replay, spoofing, and probing. The design ties SPA authentication sessions to concrete data-plane TCP connection attempts using encrypted client/server tuple information, and the firewall is configured with exact 4-tuple ACL rules after successful authentication. The spec verifies both safety and liveness-style temporal properties about SPA authentication, anti-replay and anti-spoof behavior, legitimate user access availability, server hiddenness against attackers, firewall rule consistency, and firewall correctness under retransmission scenarios.
