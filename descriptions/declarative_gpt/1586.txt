This module specifies a small PlusCal algorithm named Either that manipulates variables x, y, and z, and includes a procedure Foo(a). The main control flow executes an either-or choice: it can assign x := 1 and y := 0, or assign y := 1, or call Foo(1), after which an assertion checks x = 1; finally it asserts that x + y = 1. The translated TLA+ model includes program-counter control, a call stack for the procedure return, an assertion mechanism via Assert, and a temporal specification requiring the translated Next action to evolve under weak fairness, with an eventual termination property stating that pc reaches "Done".
