This specification models a nondeterministic algorithm that computes the maximum element of an input tuple of integers. The input tuple is chosen from a constant set Tuples, every element of every tuple is assumed to be greater than minValue, and the algorithm iteratively removes an index from the remaining index set I while updating max when a larger tuple element is found. The translated TLA+ spec defines initialization, the main control-location action, a terminating stuttering action, the overall temporal specification, and an eventual termination property; it also includes an assertion that checks the returned max is minValue for the empty tuple and otherwise is both an element of the tuple and an upper bound of all tuple elements.
