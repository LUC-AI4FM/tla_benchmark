This specification models a single natural-valued state variable x that starts at 0 and can increment by 1 while x < 3. The main behavior specification says the system begins in Init and then evolves according to the stuttering-closed action [][Step]_x; a stronger specification FairSpec additionally imposes weak fairness on Step. The file also defines simple temporal properties about eventually reaching 3, about never seeing 3 after x becomes 1, and a trivial leads-to tautology, with no fault model or distributed components present.
