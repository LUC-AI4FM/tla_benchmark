This module is a thin wrapper around another specification, Channel, and adds Apalache-specific type annotations while keeping the original Channel specification unchanged. It declares a constant Data as a set of data values and a variable chan with a record-shaped type annotation containing fields val, rdy, and ack. The module itself contains only one concrete top-level definition, DataVal, and does not define actions, temporal properties, fairness conditions, or proofs; the actual channel behavior is inherited through INSTANCE Channel and must not be extracted here.
