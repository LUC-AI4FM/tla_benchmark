This module specifies a simple memory interface vocabulary rather than a full transition system. It defines the shape of memory requests as either read requests with an address or write requests with an address and value, and it defines a distinguished value NoVal chosen to lie outside the set Val. The file declares an interface variable and several constants for send/reply relations, initialization, and basic domains, but it does not define an Init, Next, Spec, or temporal correctness property. A commented-out assumption indicates the intended typing of Send and Reply as boolean-valued operators over process, data, and old/new memory-interface states, but because it is commented out it is not part of the active syntax.
