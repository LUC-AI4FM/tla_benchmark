This module contains TLAPS proofs for a TCP finite-state-machine specification imported from the module tcp, but it only extracts and proves facts stated explicitly in this proof module. It proves safety properties of the imported spec, in particular type correctness (Spec => []TypeOK) and an agreement invariant Inv stating that when both peer-to-peer message queues are empty, the two peers agree on whether they are in the ESTABLISHED state. To carry out the safety proof, it introduces a stronger inductive invariant IndInv with several auxiliary clauses about singleton messages, evidence for ESTABLISHED, and the last message in a queue, and it reasons under the intended two-peer model using choice functions A and B together with finiteness/cardinality assumptions about Peers.
