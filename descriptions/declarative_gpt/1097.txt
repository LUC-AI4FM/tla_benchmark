This specification models Lamport's distributed mutual-exclusion algorithm from the 1978 paper "Time, Clocks and the Ordering of Events in a Distributed System". It represents a set of processes that communicate by pairwise FIFO message queues, using logical clocks, request messages, acknowledgements, and release notifications to coordinate entry into a critical section. The specification defines the initial state, the process actions for sending and receiving protocol messages, a next-state relation, and a temporal specification `Spec == Init /\\ [][Next]_vars`; it also states safety-oriented predicates such as type correctness, a bounded-network property for model checking, a clock bound state constraint helper, and the mutual exclusion invariant `Mutex`.
