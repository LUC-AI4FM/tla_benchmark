This module specifies a small test of recursive operator unfolding for a factorial-like function. It defines a recursive operator Fact(n) over integers, initializes the single variable f to Fact(4), and has a next-state action that sets f' to Fact(7). The specification also includes an invariant asserting that f is at least 1, and it uses the Integers module because the recursive definition and unrolling defaults use integer expressions including -1.
