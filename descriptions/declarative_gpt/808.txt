This module specifies a simple PlusCal algorithm that sums the elements of a sequence of integers. The algorithm keeps the input sequence unchanged, iterates through it with an index variable n, accumulates the running total in sum, and terminates when all elements have been processed; the translated TLA+ spec includes a fair action and an explicit terminating stuttering action. The module also defines a mathematical operator SeqSum for the sum of a sequence, states both safety and liveness properties, and contains a substantial TLAPS proof showing that the algorithm is safe by proving an inductive invariant and also proving auxiliary lemmas about sequences and SeqSum.
