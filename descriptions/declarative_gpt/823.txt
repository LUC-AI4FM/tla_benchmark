This module contains TLAPS proofs of partial correctness for the algorithm specified in module Reachable. It proves invariant properties about the reachable-node marking algorithm using previously established graph-theoretic lemmas from ReachabilityProofs, and shows that when the control variable pc reaches "Done", the variable marked equals Reachable. The proof structure relies on invariants Inv1, Inv2, and Inv3 from the imported module, uses standard inductive invariance arguments over Spec and [Next]_vars, and makes notable use of decomposition into CASE, PICK, and SUFFICES/ASSUME/PROVE proof steps rather than introducing any new algorithmic behavior here.
