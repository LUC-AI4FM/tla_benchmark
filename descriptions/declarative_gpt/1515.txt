This specification models a very small one-variable state machine over the variable x. The initial condition allows x to start in the range 0..1, and each Next step requires the current value to satisfy x < 10 while the next-state value x' is chosen from the range 1..9. The temporal specification asserts that the system starts in Init and then always evolves according to [][Next]_x, which permits either a Next step or stuttering on x. There is no fault model, no fairness condition, and no proof content in this file.
