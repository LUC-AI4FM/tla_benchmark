This module specifies a very small state machine with a single integer variable x, initialized to 0 and never changed thereafter. The main purpose of the file is not to model a distributed protocol, but to check the correctness of an SMT encoding for folding over a set into a sequence using Apalache's ApaFoldSet operator together with the Sequences operator Append. The invariant-like operator Inv intentionally asserts the negation of the expected result set, so the intended verification outcome is that the model should be UNSAT if the encoding is properly constrained.
