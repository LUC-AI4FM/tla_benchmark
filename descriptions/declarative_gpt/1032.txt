This module defines a directed graph abstraction represented as a pair consisting of a set of vertices and a set of edges. It provides operators to project the vertex and edge components, check whether a value is a well-formed digraph, compute the children of a vertex, compute the descendants reachable from a set of vertices using a recursive definition, and construct the reachable subgraph induced by a starting set of vertices. The module contains no variables, actions, temporal specification, fairness conditions, PlusCal algorithm, or proofs; it is a purely structural and recursive helper module for reasoning about directed graphs.
