This specification models a tiny state machine over two variables, x and y, with set-valued constraints on the initial state and next-state relation. The key design point is that the next-state action leaves y unchanged while constraining the next value of x to be a subset of y', and the spec also defines predicates checking whether x is the full set {1, 2, 3} and whether element 3 is gained in a transition. It additionally uses the TLC module to inspect named-state exploration metadata through TLCGet and asserts expected counts for the named predicates FullSet and GainThree; there is no fault model, no full temporal Spec operator, and no fairness condition.
