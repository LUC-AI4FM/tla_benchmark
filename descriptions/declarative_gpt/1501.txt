This specification defines a very small state machine with a single variable x over the natural numbers. It introduces a recursive factorial operator fact and uses it in two actions, A and B, which assign x' to fact(3) or fact(9), respectively; the next-state relation is their disjunction. The temporal specification requires the initial state x = 0 and then always permits only Next steps or stuttering via the standard box-action formula on <<x>>; there is no fault model, fairness condition, PlusCal algorithm, or proof content.
