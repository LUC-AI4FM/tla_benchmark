This specification models MultiPaxos for state machine replication on a single key, with both write commands and read commands. The network is modeled as a monotonic set of sent messages in a non-Byzantine asynchronous setting where messages may be delayed, duplicated, or lost, and the algorithm uses prepare, accept, and commit-notice phases to replicate a log across replicas. The spec checks safety-oriented behavior through client-observed request and acknowledgement events and includes a temporal termination property stating that all replica processes eventually reach the "Done" control state; deadlock avoidance after termination is handled by an explicit stuttering action.
