This module is a regression-style test specification for operators provided by an extended functions library, especially predicates and transformers over functions such as RestrictDomain, RestrictValues, IsInjective, FoldFunction, FoldFunctionOnSet, AntiFunction, Pointwise, and IsRestriction. It uses a large collection of ASSUME statements to check expected values, error behavior, and equivalence to pure logical definitions written directly in TLA+, including tests over records, sequences, ordinary functions, and finite function encodings built with :> and @@. The spec does not model a transition system or fault-tolerant protocol; instead it validates functional behavior and side-effect freedom of library operators, including CHOOSE-based inverse constructions and recursively defined function values.
