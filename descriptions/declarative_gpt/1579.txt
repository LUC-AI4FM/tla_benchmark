This specification models Dijkstra's first self-stabilizing token ring algorithm for a ring of N processes with local values in 0..(K-1), under the assumption K > N and N > 0. Process 0 increments its value modulo K when its value matches the last process, while every other process copies its predecessor when their values differ; this creates and propagates a logical token around the ring. The translated PlusCal algorithm is given together with a temporal specification using weak fairness, and the module states and proves that some process always holds a token and that eventually exactly one token holder remains, expressing convergence to a legitimate single-token state.
