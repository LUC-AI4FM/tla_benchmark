This specification models a particular configuration of the Sailfish protocol with four nodes, one of which is Byzantine. The comments state that any set of three nodes is treated as a quorum and any set of two nodes is treated as a blocking set, and the module defines node sets, a round range, quorum and blocking predicates, a fixed leader schedule, and a GST value. It declares protocol state variables and then defines a state constraint, a termination predicate, a terminating action that leaves the state unchanged, and a temporal specification that allows either normal protocol steps through Next or stuttering termination steps.
