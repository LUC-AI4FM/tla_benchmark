This module specifies an inner FIFO buffer connected between an input channel and an output channel. It instantiates a separate Channel module twice, once for the input channel and once for the output channel, and models an internal queue q that stores messages received from the input until they are forwarded on the output in first-in first-out order. The specification defines initialization, message sending into the input channel, buffering of received input messages, forwarding from the buffer to the output, receipt from the output channel, a next-state relation over these actions, and a temporal specification asserting that all behaviors start in Init and evolve by Next with stuttering allowed. It also states a theorem that Spec implies the invariant that both channel instances satisfy their type invariants and that q is a sequence of Message values.
