This specification models a tiny two-variable state machine with integer variable x and string variable y. The initial state sets x to 0 and y to "a". The next-state relation allows x' to be either 0 or 1 and y' to be either "a" or "b" independently. The temporal specification combines Init with [][Next]_x and weak fairness WF_x(Next). The module also defines two leads-to properties, one of which contains a nested always formula.
