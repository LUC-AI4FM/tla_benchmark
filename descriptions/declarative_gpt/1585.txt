This specification models a PlusCal algorithm with two identical processes in the set {1, 2}, each executing an either-or branch followed by a second either-or branch with guards. In the first branch, a process either sets x to 1 and then increments it, sets y to 1 and then increments it, or sets z to 100; in the second branch, it updates z depending on whether x is 0 or 2, and then checks two assertions. The translated TLA+ spec defines the initial state, per-label actions, the next-state relation, a stuttering termination action, a full temporal specification with weak fairness for each process action, and a termination property asserting that eventually all processes reach "Done".
