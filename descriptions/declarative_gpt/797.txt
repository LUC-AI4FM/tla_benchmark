This module specifies a very simple system in which a single variable x starts at 0 and is repeatedly incremented by 2 forever. The file includes a PlusCal algorithm and its generated TLA+ translation, with the temporal specification given by Init /\ [][Next]_vars. It proves a type invariant that x always remains a natural number and also proves that x is always even, using TLAPS proof steps and the auxiliary divisibility operator a|b.
