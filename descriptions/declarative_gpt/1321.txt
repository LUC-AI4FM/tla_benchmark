This module specifies a very small state-based system with two variables, a and b. The initial condition requires a to be a function from the range 1..2 to the range 1..3, and b to be TRUE. The temporal specification allows only stuttering steps by stating that every step leaves vars unchanged, and it includes a simple invariant assertion Inv == a >= 0 together with a comment noting that this property is violated by all initial states because a is a function rather than a numeric value.
