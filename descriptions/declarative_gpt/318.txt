This specification models a simple factorization search for the fixed integer 999999. The initial state sets integer variables m and n to 0 and a Boolean answer flag to FALSE, and the single next-state action nondeterministically chooses factors i and j from 2..1000000 whose product is 999999, then stores them in m and n and sets answer to TRUE. The file also defines an invariant asserting that answer remains FALSE, which is notable because it is contradicted by the Next action whenever a factorization step occurs.
