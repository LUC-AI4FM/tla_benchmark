This module provides Apalache-specific type annotations and concrete constant-value helper definitions for an underlying single-lane bridge specification. It declares the constant sets for cars approaching from the right and left, the bridge positions, and the overall positions domain, and it declares state variables for car locations and the queue of cars waiting before the bridge. The module instances the separate SingleLaneBridge specification module, but this file itself only contains the declarations, the instance statement, and concrete value definitions; it does not define the transition relation, temporal specification, or fault model directly.
