This specification models the Echo algorithm for constructing a spanning tree in an undirected graph, starting from a single initiator node. The system is described as a PlusCal algorithm and then translated into TLA+ with explicit state variables and actions. The model assumes a set of nodes, a single initiator, and an undirected, irreflexive, and connected neighborhood relation. The algorithm ensures that every node is included in a single spanning tree rooted at the initiator, and verifies properties such as correct parent-child relationships, acyclicity, and eventual termination. The specification includes both safety (TypeOK, ParentChild, etc.) and liveness (Termination) properties, and models message passing and process state transitions explicitly.
