This module specifies a nondeterministic algorithm for computing the maximum element of an input integer sequence drawn from a constant set Tuples, with the special case that the maximum of the empty sequence is minValue. The PlusCal algorithm repeatedly chooses an index from the remaining index set I, updates max when inp[i] > max, and removes that index from I until all positions have been examined; the translated TLA+ model includes a terminating stuttering action after pc = "Done". The specification assumes every tuple element is greater than minValue, uses weak fairness on Next, and asserts both termination and the correctness condition that the final max is either minValue for the empty tuple or else equals some input element and is at least every input element.
