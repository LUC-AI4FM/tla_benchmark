This module specifies a small Fibonacci computation test intended to exercise handling of recursive functions in TLA+. It compares an iterative state-based computation of Fibonacci numbers, using variables n, fibComp, and fibCompPrev, with a recursively defined function Fib over the finite domain 0..15, and stores the specification-side value in fibSpec. The file defines initialization, a next-state action that advances the iterative computation by one step, and an invariant asserting that the recursively computed value and iterative value agree.
