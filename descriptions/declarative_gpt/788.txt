This module specifies a simple key-value store that supports transactions with snapshot isolation. Each transaction takes a snapshot of the store, chooses nonempty read and write key sets, reads from its snapshot, applies its writes locally, and then commits only if its write set does not conflict with keys missed due to concurrent committed transactions. The specification includes a PlusCal algorithm translated to TLA+, a temporal specification with weak fairness for each transaction process, a termination property, type correctness conditions, and client-centric isolation checks for snapshot isolation and serializability through an instantiated module.
