This module is a model-checking wrapper around an instantiated binary search specification, fixing the integer width to 8 bits while leaving the input sequence and search key unconstrained except for initialization through generated values. It introduces the state variables used by the binary search instance and defines a single top-level operator, ConstInit, that constrains the constants INPUT_KEY and INPUT_SEQ using Apalache's Gen operator. The file does not define the search algorithm itself, no temporal specification or fairness condition is present here, and the main design choice is to reason about arbitrary inputs rather than one concrete sequence.
