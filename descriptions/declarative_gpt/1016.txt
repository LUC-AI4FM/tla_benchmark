This module specifies a voucher redemption protocol between voucher holders and voucher collectors coordinated by a voucher transaction provider using a simplified Two-Phase Commit style protocol. The model tracks voucher state, voucher life-cycle state, participant states, a set of received Prepared acknowledgments, and a global set of messages that only grows; messages are never removed, so reception is modeled by message presence. The specification proves that the protocol preserves type correctness and consistency, meaning holders and collectors do not reach conflicting redeemed versus aborted outcomes, and it also proves that the protocol implements an imported voucher life-cycle specification.
