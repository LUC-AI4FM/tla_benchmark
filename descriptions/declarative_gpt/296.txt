This module specifies Lamport's bakery mutual exclusion algorithm for N processes, using the PlusCal translation that introduces control-state variable pc and per-process state variables num, flag, unchecked, max, and nxt. The spec models the algorithm as a concurrent transition system with weak fairness for each process when it is outside the noncritical-state guard, and it states both safety and liveness properties including mutual exclusion, deadlock freedom, and starvation freedom. The file also defines a strong inductive invariant capturing type correctness and ordering relationships used in the bakery argument, while explicitly omitting the original TLAPS proof from the source specification.
