This module specifies a very small abstract model for checking that a hash function over a fixed finite set of allowed strings is injective. It defines a bit-string codomain as functions from 1..6 to {0,1}, constrains the constant hash to map AllowedStrings to BitString, and requires IsInjective(hash) in ConstInit. The behavior itself is trivial, with Init and Next both equal to TRUE, and the main property of interest is the invariant Inv stating that distinct allowed strings map to distinct hash values.
