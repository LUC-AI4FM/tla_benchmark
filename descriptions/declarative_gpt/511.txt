This specification is a model-checking wrapper module for a system defined in the extended module Session10set. It defines a termination condition stating that all message queues are empty, a type correctness invariant for the imported state variables depth, parent, and msgs, and recursive operators that characterize parent paths and graph distance from a root. It also states a correctness property that if the system has terminated, then the computed parent-path depth of every node matches its distance from the root.
