This module specifies the worker-side behavior of a task orchestration system, modeling how nodes are seen by SwarmKit as either up or down and how tasks assigned to nodes progress through lifecycle states. It defines actions for normal task progress, shutdown completion, task rejection, container exit reporting, node disconnection and reconnection, and orphaning runnable tasks on nodes that remain down. The module is focused on state-transition behavior and action decomposition, and it does not itself define a temporal specification or verification theorem in this file.
