This module specifies a graph problem on a set of Nodes with undirected Edges, together with a distributed PlusCal algorithm that computes paths to a distinguished root. It defines graph-neighborhood and reachability operators, proves that an executable recursive reachability procedure RF is equivalent to the simpler declarative ReachableFrom definition, and then models message-passing processes that propagate depth information toward a spanning tree rooted at root. The assumptions require that every edge connects exactly two nodes, root is a node, MaxNodes bounds the number of nodes, and every node is reachable from root; the temporal specification uses weak fairness for each node process.
