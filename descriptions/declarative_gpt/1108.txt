This module is a TLAPS proof layer for a spanning-tree protocol specification imported from the module spanning. It proves the safety property `Spec => []SntMsg`, where `SntMsg` states that a non-root process whose parent is not yet set has sent no messages. The proof strengthens the invariant with `SentMeansCanSend` and `PrntDomain`, then shows the combined invariant is inductive over `[Next]_vars`; comments also note a design issue in the imported spec's `TypeOK` regarding non-symmetric neighbor relations, so this proof avoids relying on that invariant.
