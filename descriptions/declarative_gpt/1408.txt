This specification models a single-variable system with one state variable x. The initial condition sets x to FALSE, and the next-state relation allows x to take any value in BOOLEAN in the next state. The temporal specification combines Init, the standard stuttering-closure formula [][Next]_x, and a doubly universally quantified strong fairness condition SF_x(Next); it also states a temporal property Prop asserting that eventually x is always in BOOLEAN.
