This specification models a single-variable state machine over a function variable `myfun` from integers to integers. The initial state sets `myfun` to the identity function on the domain `1..3`, and the next-state action updates it by right-biased function override using `@@` with a function that maps `2..4` to `42`. The specification also defines an invariant asserting that entries 2 and 3 of `myfun` retain their initial values, which is a property that is not preserved by the update step because the override changes those arguments.
