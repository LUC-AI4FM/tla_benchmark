This module is an aggregate test wrapper that brings together a collection of separate test modules via EXTENDS. Its comments state that new tests using ASSUME statements should be added to the comma-separated EXTENDS list, so the file serves as a central harness or umbrella module rather than specifying an independent algorithm. The module itself introduces no constants, variables, operators, actions, temporal properties, fairness assumptions, proofs, or PlusCal processes; all such content, if any, belongs to the extended modules and must not be extracted here.
