This module is a small test specification that checks proper evaluation of primed variables inside an action. It models a single-variable state machine where the initial state sets x to 2, and the only step Next constrains the next-state value x' to 2 while also asserting several expressions over x' involving arithmetic, ranges, set comprehension, filtered set comprehension, and existential quantification. The specification uses TLC's Print operator to mark progress through these checks, and it defines a trivial invariant Inv == TRUE rather than a full temporal Spec.
