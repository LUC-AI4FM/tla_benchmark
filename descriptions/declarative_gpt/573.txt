This module specifies the CCF variant of the Raft consensus algorithm over an asynchronous message-passing network with explicit in-flight messages, per-server logs, terms, elections, reconfiguration, and retirement of nodes. It models CCF-specific features such as signatures that make prefixes committable, pre-vote behavior, configuration changes, retirement phases, and explicit successor nomination via propose-vote messages. The specification defines an initial single-node start configuration, a detailed next-state relation with message send/receive handlers, fairness assumptions over both node and network actions, and verifies a collection of safety and temporal properties including log consistency, append-only committed logs, refinement to an abstract spec, and several CCF-specific invariants about signatures, configurations, and retirement.
