This module is a small regression-style TLA+ test specification for set operators, specifically \cup, \cap, \subseteq, set difference \, and Cartesian product \X. It models a trivial one-variable system where x is a Boolean state variable that never changes, and uses the operator Inv to evaluate a conjunction of assertion-style checks over sets, sequences, function-set membership, subset relations, and Cartesian products using Integers, TLC, and Sequences.
