This specification models a very small one-variable state machine over the variable s, together with a collection of temporal properties and wrapper operators designed to exercise parameterized operator passing through an INSTANCE of an abstract module. In the concrete module, Init sets s to 0 and Next increments s while s < 8, otherwise resetting s to 0; the main temporal behavior is given by SPEC == Init /\ [][Next]_s. The file also defines several properties by routing concrete operators, recursive operators, and constant operators through operators in an abstract module, and it includes a trivial leads-to tautology.
