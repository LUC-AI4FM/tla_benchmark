This module is a parser and instantiation test for TLA+ named definitions, labels, and theorem references imported from an instantiated module rather than a behavioral system specification. It exercises many forms of INSTANCE usage, including parameterized instances, local instances, and explicit WITH substitutions, and then asserts numerous assumptions about instantiated theorem labels, operators, tuple components, and nested label selection syntax. The file contains no variables, no transition actions, no temporal specification, and no proofs; its purpose is to validate name resolution and instantiation behavior for imported labeled expressions and theorem references.
