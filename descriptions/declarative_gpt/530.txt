This specification models a PlusCal algorithm named TupleMax that scans an input integer sequence and computes its maximum value. The input is constrained by assumptions: it comes from a set of integer sequences Tuples, every element is at least minValue, and the algorithm additionally asserts that every element of the chosen input is strictly greater than minValue before the loop begins. The translated TLA+ spec defines initialization, two control-location actions, a terminating stuttering action, the standard safety-style temporal specification Spec == Init /\ [][Next]_vars, and a liveness property asserting eventual termination with pc = "Done".
