This specification models a single-variable transition system over an integer variable x. The initial state sets x to 0, and there are two actions enabled only when x is even: action A increments x by 1 and leads to a deadlock state, while action B increments x by 2 and preserves evenness so it can continue forever. The comments explain that this file is a regression or test case demonstrating that Apalache 0.15.1 can miss a deadlock, because although A leads to deadlock, an infinite execution using only B (and thus Next) is also possible from the initial state.
