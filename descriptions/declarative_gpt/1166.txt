This module specifies a task lifecycle system in which a variable `tasks` stores the currently allocated tasks, and tasks progress through a fixed transition table managed by different components such as the orchestrator, allocator, scheduler, agent, and reaper. The specification defines typing constraints for `tasks`, a state update action-like operator `UpdateTasks` that replaces existing tasks according to a function while preserving task identity, and a constructor `NewTask` for creating new task records from service, slot, id, and desired state information. It also defines a transition table and asserts a consistency property `TransitionTableOK` requiring monotonic state progression and non-overlapping ownership of source states across components, with limited exceptions for reaper cleanup; the file contains an ASSUME that asks TLC to check this property.
