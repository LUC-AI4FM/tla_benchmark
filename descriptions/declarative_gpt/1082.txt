This TLA+ specification models Safra's algorithm for distributed termination detection on a ring, as described in EWD 998. The system consists of N nodes arranged in a ring, each of which can be active or inactive, and communicates asynchronously by sending messages. The algorithm uses a circulating token with a color and a counter to detect global termination, ensuring that when the token returns to node 0 in a specific state (white, zero counter, no in-flight messages), all nodes are inactive and no messages are in transit. The model includes both safety (termination detection is sound) and liveness (termination is eventually detected) properties, as well as an inductive invariant capturing the correctness of the token and message accounting. The state space is bounded for model checking, and the module instantiates a generic termination detection specification for comparison.
