This specification models a very simple state machine over a single variable `set`. The variable ranges over subsets of the constant set `Humans`, starts as the empty set, and each next-state step nondeterministically chooses a human and adds that human to the set. The module also defines a symmetry expression using permutations of `Humans` and `Others`, but it does not define a temporal specification such as `Spec`, nor any fault model, fairness condition, or theorem to verify.
