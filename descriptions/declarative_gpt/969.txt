This module defines a collection of directed state graphs together with associated violation sets and example counterexample paths, intended for testing model-checker specifications such as TLCMC and MCReachability. Each graph is represented as a record with fields for the set of states, the set of initial states, and a sequence of successor-state sets indexed by state number; separate operators define the corresponding violating states and witness traces. The module contains no variables, actions, temporal specification, fairness, or proofs; instead it serves as a static data library that selects one named test case based on the IO environment variable GRAPH, defaulting to graph 7 when that setting is absent.
