This module is a small test specification for the standard Naturals module, using TLC helper operators to report success or failure of arithmetic checks. It models a trivial one-variable system in which x is initialized to 0 and never changes, while the main invariant Inv consists of a conjunction of arithmetic and comparison tests over exponentiation, subtraction, multiplication, division, modulo, ordering, set membership in Nat, and range expressions. The design intentionally puts all substantive behavior in a state predicate rather than in actions or temporal properties, and it uses Print and Assert from TLC to validate expected results.
