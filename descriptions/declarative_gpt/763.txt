This module is an Apalache-oriented wrapper around another specification, intended to provide type annotations for the Dining Philosophers model while keeping the original specification free of tool-specific details. It declares the constants and variables that are typed here, and then instantiates the underlying DiningPhilosophers module. The file itself does not define any top-level operators, actions, assumptions, or temporal properties; it only supplies annotations and an INSTANCE of the underlying DiningPhilosophers module.
