This module specifies a small symbolic transition system used to test slicing of transitions. It models three state variables, state, n, and k, with actions Init, Start, A, B, and a combined Next action; the behavior includes existential quantification, LET-bound set expressions, and a cardinality check over finite sets. The file defines a simple invariant asserting that state is not equal to "B", but it does not include a complete temporal specification such as Spec, fairness assumptions, or proofs.
