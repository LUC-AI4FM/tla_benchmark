This specification is a small test module about subtle INSTANCE semantics in TLA+. It declares a single variable x, defines an initial condition where x is one of the values in 1..3, and a next-state action that updates x to 9-x. The module instantiates another module test57a with both formal parameters u and v substituted by x, then defines several invariant-style properties and a temporal property to exercise how instantiated operators and ENABLED expressions behave under substitution.
