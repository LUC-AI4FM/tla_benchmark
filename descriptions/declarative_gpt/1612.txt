This specification models a PlusCal algorithm that tests multi-assignment semantics over arrays for three concurrent processes. Each process starts with its own array-valued local state and a scalar value, performs one atomic step that simultaneously updates two array positions and a scalar, then checks via assertions that the swap-like multi-assignment produced the expected result. The translated TLA+ spec defines the initial state, per-process actions, a terminating stuttering action to avoid deadlock after all processes finish, a standard temporal specification with weak fairness for each process action, and an eventual termination property asserting that all processes eventually reach "Done".
