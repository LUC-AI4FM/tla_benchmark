This module models a simple set-growing system together with a recursively defined cardinality function over finite subsets of integers. The key design idea is to encode recursion without a top-level RECURSIVE definition, by using a bounded CHOOSE over functions from SUBSET S to Int and constraining that function to satisfy the recursive cardinality equations. The specification initializes an empty integer set with size 0, then repeatedly adds a fresh integer from 1..10 while incrementing the tracked size, and states an invariant asserting that the tracked size equals the recursively defined cardinality of the current set.
