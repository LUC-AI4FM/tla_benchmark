This specification models a simple state machine that incrementally builds a set of integers drawn from a fixed finite range and tracks its size in a separate variable. It defines a recursive operator Card over subsets of NUMS to compute set cardinality by repeatedly choosing an element from a nonempty set and recursing on the set with that element removed. The system starts from the empty set with size 0, allows steps that add an element from NUMS to the set while updating size to Card[set'], and states an invariant that the tracked size equals the standard FiniteSets cardinality of the current set.
