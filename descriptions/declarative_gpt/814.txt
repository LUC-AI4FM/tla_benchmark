This module is a thin wrapper around another specification, Reachable, used to attach Apalache type annotations while keeping the original module free of tool-specific annotations. It declares constants for a graph-like structure consisting of a set of nodes, a successor function from nodes to sets of nodes, and a distinguished root node, and it declares variables marked, vroot, and pc with annotated types. The module does not define its own transition system, temporal specification, or correctness properties; instead, it instantiates Reachable with direct substitutions for the three constants and additionally defines concrete constant values NodesVal, SuccVal, and RootVal for use by configuration.
