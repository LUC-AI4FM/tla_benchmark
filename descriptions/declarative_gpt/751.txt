This specification models the classic cigarette smokers synchronization problem. A dealer repeatedly offers a set of ingredients that is missing exactly one ingredient, and the smoker who has the missing ingredient can smoke; afterward the system returns to a state where the dealer may offer again. The spec uses a simple state-machine model with variables for the smokers' smoking flags and the dealer's current offer, assumes structural constraints on the set of possible offers, defines a basic temporal specification with `Init /\ [][Next]_vars`, adds weak fairness for `Next` in `FairSpec`, and includes an invariant `AtMostOne` asserting that no more than one smoker is smoking at any time.
