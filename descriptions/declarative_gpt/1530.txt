This module, MCWriteThroughCache, is designed for use with TLC to check the specification of a write-through cache system. It adapts the WriteThroughCache specification for TLC by avoiding instantiation (which TLC v1 cannot handle) and instead manually instantiates the InternalMemory specification with appropriate substitutions for memory, control, and buffer variables. The module checks that the implementation satisfies both a type invariant and a coherence invariant, and that it refines the InternalMemory specification under a specific refinement mapping. Notably, the module includes a hand-inlined version of the InternalMemory specification (with operator names prefixed by LM_Inner_) and verifies that the implementation maintains type correctness and liveness properties.
