This module gives a high-level TLA+ model of a Tendermint-style blockchain intended specifically for reasoning about a light client. It models nodes, validator sets, commits, block headers, a global reference clock, and a monotonically growing blockchain up to a bounded ultimate height. The fault model assumes a set of faulty validators drawn from AllNodes, with the set of faulty nodes represented explicitly and intended to be non-decreasing; the initialization constrains each block's validator set so faulty validators remain below a specified threshold ratio, and the spec includes helper predicates for two-thirds commits, trusting-period checks, and whether a light block could be justified by digital signatures.
