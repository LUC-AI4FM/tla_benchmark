This module defines standard operators for finite sequences in TLA+, representing a sequence of length n as a function with domain 1..n. It provides constructors and selectors such as Seq, Len, concatenation, Append, Head, Tail, SubSeq, and SelectSeq, with comments explaining their intended meaning and the representation of tuples as sequences. The module is a library-style definitions module rather than a transition-system specification: it declares no variables, no actions, and no temporal properties, and it notes that TLC overrides these operators with Java implementations.
