This module specifies the Echo algorithm for constructing a spanning tree in an undirected connected graph starting from a single initiator. The graph is modeled by a set of nodes and a Boolean neighborhood relation R, with assumptions that R is irreflexive, symmetric, and connected; communication is modeled by per-node inbox sets containing message records. The PlusCal algorithm is included together with its TLA+ translation, and the specification verifies safety-style properties such as type correctness, absence of a parent for the initiator, parent-neighbor consistency, parent-child consistency, and ancestor properties at termination, as well as a termination temporal property stating that all processes eventually reach Done.
