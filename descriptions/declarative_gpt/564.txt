This specification models the Two-Phase Commit protocol, a classic distributed transaction commit protocol involving a transaction manager (TM) and a set of resource managers (RM). The model tracks the states of the resource managers and the transaction manager, as well as the set of messages exchanged between them. The protocol proceeds in two phases: first, RMs prepare and notify the TM, and then the TM decides to commit or abort, informing the RMs. The specification defines the possible actions for both TM and RMs, including preparation, commit, abort, and the receipt of messages. The temporal property TPSpec asserts that the system starts in the initial state and all steps are valid transitions according to TPNext. The model is parameterized by the constant RM, representing the set of resource managers, and does not explicitly model faults or failures.
