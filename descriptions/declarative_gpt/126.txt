This module specifies a very small TLA+ model used to check the behavior of folding over a finite set into a sequence using the Apalache operator ApaFoldSet. The state consists of a single integer variable x, initialized to 0 and then left unchanged forever, so the dynamic behavior is trivial and the interesting property is a state invariant about the value produced by ApaFoldSet. The helper operator A appends an integer q to a sequence p, and the invariant asserts that folding the set {1,2,3} starting from the empty sequence yields one of the six possible permutations of those three elements.
