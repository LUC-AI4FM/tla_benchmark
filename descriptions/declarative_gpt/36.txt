This module is an internal support module for Apalache rather than a user-level algorithm or distributed protocol specification. It defines two helper operators with dummy TLA+ bodies that Apalache rewires internally: one returns a sequence capacity bound, and the other denotes an operator that should cause the model checker to stop with a message if evaluated. The module contains no state variables, no actions, no temporal behavior, and no correctness properties; its purpose is purely to expose internal operators with well-typed placeholder definitions.
