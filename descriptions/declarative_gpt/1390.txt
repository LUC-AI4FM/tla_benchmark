This specification models a bounded FIFO communication channel indexed by endpoints. The top-level module defines a single variable channel mapping each endpoint to a sequence, initially the empty sequence, and allows either reading the head element from a nonempty endpoint queue or writing a message to an endpoint queue provided its length is not MaxSize. It verifies the temporal behavior of this channel with Spec == Init /\ [][Next]_channel and also states a refinement property asserting that for every endpoint, the per-endpoint queue refines the behavior of an instantiated FIFO module. The file also contains the FIFO module itself, which specifies an unbounded queue with Put and Get actions, plus a TLC configuration selecting Spec as the behavior specification and Refinement as a property.
