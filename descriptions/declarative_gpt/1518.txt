This specification models a simple counter-like state machine with one state variable i and one constant j. The initial state sets i to 0, and the next-state relation increments i by 1 while i < j, otherwise it stutters by leaving i unchanged. It defines an invariant Inv through the helper operator op(k), which universally quantifies over l in the range 0 .. (j - k) and asserts that i is a natural number; the file also includes an assumption that j is a natural number and a TLC configuration section setting j = 10 and checking Inv.
