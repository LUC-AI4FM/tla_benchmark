This specification models a tiny one-variable state machine over the variable x. The initial state sets x to 0, and the next-state relation allows either a branch that contains an existentially quantified local value t drawn from {0} together with FALSE and assignments to x', or a stuttering step that leaves x unchanged. The spec does not define a full temporal Spec operator or any explicit safety or liveness property; it is a minimal action-level example illustrating the structure of Init and Next with quantification, boolean constants, and UNCHANGED.
