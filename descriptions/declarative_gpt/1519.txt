This specification models a PlusCal translation of a Dekker-style mutual exclusion protocol for a set of threads. Each thread raises a flag, waits while another competing thread's flag is set, uses a shared next_thread variable as a turn mechanism, enters a critical section, then selects another thread as the next turn and repeats. The spec checks a safety property asserting that at most one thread is in the critical section at a time, and a liveness-style property asserting that every thread eventually reaches the critical section; the temporal specification uses weak fairness for each thread action, and the file also includes a separate leads-to tautology property and a termination property over a synthetic Done control state.
