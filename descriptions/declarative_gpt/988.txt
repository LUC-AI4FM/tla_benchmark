This module is a TLC-oriented wrapper around an atomic commit protocol specification, extending ACP_NB and adding a few top-level properties and a concrete postcondition witness. It defines a symmetry-related permutation operator, a reformulated temporal property AC4_alt about decision stability for participants, an eventual-commit property AllMustCommit, and a large PostCondition value that encodes a specific counterexample trace and visited states. The file does not define the underlying transition system itself; instead, it refers to state imported from the extended module and packages TLC data structures for checking or replaying a counterexample scenario involving two participants p0 and p1, coordinator failure, and participant crashes.
