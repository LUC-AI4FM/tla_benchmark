This specification models a simple recursive cardinality computation over a set of integers together with a state machine that grows the set and a matching size counter. The recursive operator Card removes an arbitrary chosen element from a nonempty set and returns 1 plus the cardinality of the remainder, with the base case Card({}) = 0; comments note that CHOOSE is fixed through LET binding to avoid nondeterministic issues in Apalache-style unfolding. The transition system starts from an empty set and size 0, then repeatedly increments size and inserts the old size into the set, while the invariant Inv asserts that the counter always equals the recursively computed cardinality of set.
