This module specifies an ERC20-style token contract together with a simple model of Ethereum transaction submission and later commitment, in order to analyze behaviors around approve, transfer, and transferFrom. It models account balances, allowances, a set of pending transactions with unique identifiers, and the last executed transaction, and it focuses in particular on the classic approve/transferFrom race-style attack where a transferFrom may occur while a smaller approval is still pending. The file contains initial-state and next-state action definitions, several state invariants intended both for debugging and for checking expected safety conditions, and one trace-oriented property over sequences of states used with Apalache. The model deliberately ignores 256-bit overflow behavior and is written for model checking rather than for temporal-proof-oriented fairness reasoning.
