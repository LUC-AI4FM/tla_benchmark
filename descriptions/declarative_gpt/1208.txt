This specification models a reconfigurable Paxos-style consensus algorithm with acceptors, ballots, instances, and configurations. It represents acceptor votes in a three-level function `avote` and the set of learned commands in `learned`, including special reconfiguration commands that install new configurations. The file proves safety properties, especially uniqueness of the learned command per instance, by defining a strong inductive invariant, auxiliary configuration-ordering functions, stability lemmas, and a substantial TLAPS proof; there are no liveness or fairness assumptions beyond the standard safety specification `Spec == Init /\ [][Next]_<<avote, learned>>`.
