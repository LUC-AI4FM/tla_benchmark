This specification models a simple bounded FIFO queue of messages. The system starts with an empty sequence, allows sending a message from a fixed message range when the queue length is below a fixed size bound, and allows receiving by removing the head element when the queue is non-empty. The file is designed to stress TLC under anomalous conditions by generating a large state space, and it also states and checks a safety property that every element currently stored in the queue belongs to the allowed Messages set.
