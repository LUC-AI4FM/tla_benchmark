This module specifies a distributed spanning-tree construction over a graph of processes, where processes communicate by recording sent messages in a shared set and adopt a parent when they receive a message. Initially every process has no parent, no process has reported, and no messages have been sent; a process may send to a neighbor if it is the root or it already has a parent, and an unparented non-root process may adopt as parent a sender from which it has received a message. The specification includes a weak fairness condition for the main step relation, a type correctness invariant, a termination property asserting eventual parent assignment for all non-root processes, and a safety-style property stating that once a parent is assigned it never changes.
