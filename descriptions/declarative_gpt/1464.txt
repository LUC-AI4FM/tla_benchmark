This specification models a single variable mvs that is initialized to a set of three TLC model values constructed from the strings "T_MV1", "T_MV2", and "T_MV3". The behavior specification keeps the state unchanged forever after initialization, and the invariant checks that the set has cardinality 3 and contains exactly those three named model values. The file also includes several assumptions testing TLCExt-specific behavior for model values, string conversion via ToString, equality and inequality on same-typed model values, and an asserted error for equality on differently-typed model values.
