This module is a test specification for sequence-related operators provided by SequencesExt and related libraries. It models a trivial state machine with Init == TRUE and Next == TRUE, and expresses correctness entirely as state predicates that act as tests for conversions between sets and sequences, sorting, containment, reversal, removal, replacement, prefix and suffix relations, folding, flattening, zipping, subsequences, and subsequence replacement. The file does not specify a fault model, does not define a temporal specification such as Spec, and does not include proofs; instead it aggregates many operator-level test predicates into a single conjunction AllTests.
