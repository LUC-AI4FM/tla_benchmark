This file contains a small two-module TLA+ example centered on instantiation and enabledness. The top-level module Github725c declares a single variable a, instantiates Inner725c with the substitution x <- a, defines an initial condition Init requiring a = 0, defines Next as a stuttering action UNCHANGED a, and defines Inv as the enabledness of the instantiated expression I!F \in {0, 1, 2}. The inner module Inner725c declares a variable x and defines F == x', so the top-level specification is primarily illustrating how a primed variable expression from an instantiated module is referenced from the outer module rather than specifying a full temporal system with a Spec formula or fairness conditions.
