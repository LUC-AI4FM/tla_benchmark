This module is a model-checking wrapper for a Tendermint accountability specification. It declares a proposer constant, imports an external Tendermint debugging/accountability module by instantiation with concrete sets of correct and faulty processes, concrete valid and invalid values, and a maximum round, and constrains the proposer mapping in a constant-initialization predicate. The file itself contains no transition relation, temporal specification, or proofs; instead, it provides concrete parameters and shared variables intended to match the instantiated Tendermint model, with a single constant-initialization predicate.
