This module specifies an internal memory system that implements the MemoryInterface. The system models a set of processes interacting with a shared memory, where each process can issue memory requests, perform operations, and receive responses. The state is tracked by variables for memory contents (mem), control state per process (ctl), and per-process buffers (buf). The algorithm models request, operation, and response phases for each process, with explicit state transitions and primed variables. The main temporal property ISpec asserts that starting from IInit, the system repeatedly executes INext steps, and a theorem proves that the type invariant is always maintained. The design uses explicit state transitions and does not include a fault model.
