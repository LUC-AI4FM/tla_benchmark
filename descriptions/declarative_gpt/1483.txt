This specification models a tiny state machine with a single variable x. The initial state sets x to FALSE via the operator Get, and the next-state action sets x to TRUE via the operator Get2. The temporal specification requires Init and then always Next over x, and it states a liveness-style property asserting that eventually it becomes permanently true that Print(x, x = TRUE) holds and the TLC runtime value TLCGet("diameter") is greater than 0; there is no fault model, PlusCal algorithm, or proof content.
