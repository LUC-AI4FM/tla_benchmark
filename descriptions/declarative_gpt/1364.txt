This module models a small TLC evaluation scenario involving nested function values, EXCEPT updates, and fingerprint comparison. It defines a non-reducible function domain so that the outer function remains a lazy function lambda value, initializes x and y through successive EXCEPT updates, and compares y against a separately recomputed correct value. The specification uses a trivial stuttering next-state relation and verifies an invariant asserting that TLCFP(y) equals TLCFP(correct), thereby checking that constructing the value incrementally does not corrupt the resulting fingerprinted value.
