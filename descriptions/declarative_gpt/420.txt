This module is a small test specification for TLA+ operator arguments. It checks that user-defined operators and built-in infix operators can be passed as arguments to higher-order operators, using helper definitions like FooBar and Foo and validating the results through TLC's Print and Assert operators. The state space itself is trivial, with a single variable x, an initialization x = 1, a stuttering Next action x' = x, and a state predicate Inv that contains several IF-THEN-ELSE checks for expected arithmetic results.
