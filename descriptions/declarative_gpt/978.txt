This module specifies a simple alternating system with two state variables, v and x. The variable v acts as a control bit that alternates between 0 and 1, and each transition corresponds to one of two abstract actions: an A_0 action when v changes from 0 to 1, and an A_1 action when v changes from 1 to 0. The details of x's initial value and transition behavior are abstracted by the operator-valued constants XInit and XAct, and the temporal property Spec requires the system to start in Init and then always take Next steps.
