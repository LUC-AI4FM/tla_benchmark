This specification is a small TLC-oriented test module for fingerprinting and state representation of nested function, set, and record values. It models two variables, x and y, whose values range over functions from a singleton set to functions returning subsets; y in particular ranges over subsets of records with fields a and b. The spec defines an initial predicate, an invariant that checks equality of two structurally equivalent type expressions and triggers an assertion failure if they differ, and a Next action consisting of stuttering plus several updates to x or y, including EXCEPT-based updates to nested function entries.
