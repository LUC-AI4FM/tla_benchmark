This module is a regression test for a TLC evaluation bug involving the interaction of function application, EXCEPT, and sequence conversion. It defines a helper operator F that extracts a one-element subsequence, initializes x from a function built over 1..4 and updated with EXCEPT, and checks an invariant intended to fail when the bug is fixed. The specification is a simple safety-only model with one variable, no fairness, and no PlusCal; its purpose is to expose whether TLC correctly evaluates the EXCEPT-modified function as a sequence.
