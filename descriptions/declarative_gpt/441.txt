This module specifies a simple two-variable state machine over natural-number variables x and y. The initial state sets both variables to 0, and the next-state action toggles x between 0 and 1 using the assignment x' = 1 - x while leaving y unchanged. The specification defines two ENABLED predicates over explicit actions, a safety-style temporal specification using Init /\ [][Next]_<<x,y>>, and a liveness-style specification that strengthens the safety specification with the weak fairness condition WF_<<x,y>>(Next).
