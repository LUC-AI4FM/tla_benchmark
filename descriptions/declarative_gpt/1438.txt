This module specifies a simple state machine over a single variable t, which is initialized to a function from the range 1..10 to itself and whose next-state relation leaves t unchanged. It defines three invariant-style predicates that check duplicate-related properties on the array/function t, two of which are hard-coded to FALSE and one of which computes a filtered subsequence of non--1 elements and requires that no two retained elements have the same absolute value. The specification is purely state-based except for the trivial stuttering action Next, has no fault model, and does not include temporal liveness properties, fairness, or proofs.
