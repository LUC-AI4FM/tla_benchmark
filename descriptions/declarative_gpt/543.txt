This module is a small model-checking companion module for a specification extended from Session7fg. It defines a concrete constant value, a type correctness invariant over the state variables x, pc, and t, and an additional correctness condition stating that if all processes are in the "Done" control state then x equals N. It also defines the set of distinct process pairs and a mutual exclusion style invariant asserting that no two different processes can simultaneously be in control states "p1" or "p2", which appear to represent a critical-section region.
