This specification models a distributed spanning tree construction algorithm over a fixed graph. The system consists of a set of processes (Proc), each of which can send messages to its neighbors (nbrs) to establish parent-child relationships and build a spanning tree rooted at a distinguished process (root). The variables track each process's parent (prnt), whether it has reported (rpt), and the set of messages in transit (msg). The algorithm ensures that each process (except the root) eventually selects a parent, and that the parent relationship forms a tree structure. The specification includes type correctness, termination, and safety properties, and models weak fairness for the main step. The design uses explicit state transitions and message passing, and does not assume any faults.
