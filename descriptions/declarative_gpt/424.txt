This specification models a simple request-issuing system in which processors maintain per-processor request queues and a global partial order over request identifiers. The model defines typed request and free-register values, initializes all processor queues to the empty sequence, and allows a processor to issue a request by appending a register record to its queue while extending the global request order monotonically. It checks structural properties such as a type invariant, a well-formed request ordering relation with transitivity, irreflexivity, and per-processor index order, and also includes a queue-length constraint limiting each processor queue to fewer than two elements.
