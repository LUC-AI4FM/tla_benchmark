This module defines basic relational properties and operations for relations represented as binary Boolean functions over a set S. It provides predicates to check if a relation is reflexive, irreflexive, symmetric, asymmetric, transitive, and connected over a set. The module also defines operators to compute the transitive closure and reflexive transitive closure of a relation, using recursive LET-bound operators and function constructors. The design is purely functional and state-free, focusing on mathematical properties of relations rather than modeling a dynamic system or algorithm.
