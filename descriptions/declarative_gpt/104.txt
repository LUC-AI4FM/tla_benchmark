This specification models Dijkstra's EWD 840 token-based termination detection algorithm on a ring of N nodes. Each node has an active/passive status and a white/black color, while a circulating token has a position and color; the environment can send messages that activate nodes and may color senders black, and the protocol passes the token around the ring to detect global termination. The spec defines safety and liveness properties about detecting termination, includes alternative liveness formulations and stronger fairness variants for experimentation with TLC, and also states Dijkstra's inductive invariant together with a derived specification for checking inductiveness.
