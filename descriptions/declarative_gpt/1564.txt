This module, named MC, serves as a model-checking harness for the MultiUser module and its parameterized instantiations. It defines a constant range for user IDs and several properties that reference the specifications of various SingleUser and SingleUserP instances, both for specific parameters and universally quantified over small sets. The module is intended to check correctness properties of the SingleUser and SingleUserP systems for particular parameter values, but does not itself define any new algorithms or state transitions. No temporal properties or fairness conditions are introduced directly in this file; all such logic is inherited from the referenced modules.
