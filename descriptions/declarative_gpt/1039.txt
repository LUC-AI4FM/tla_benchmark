This module specifies an environment controller for an eventually perfect failure detector in a partially synchronous distributed system with crash faults. It composes process behavior and communication behavior via two instantiated modules, models message transit with ages, tracks local process clocks and pauses, and constrains executions using partial synchrony assumptions on message delay and relative process speeds. The specification verifies type correctness and temporal properties corresponding to Strong Completeness and Eventually Strong Accuracy, and includes a TLC state constraint used for bounded model exploration.
