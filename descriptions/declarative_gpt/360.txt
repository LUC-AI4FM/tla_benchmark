This module is a small test specification for TLC fingerprinting and state comparison behavior. It initializes several variables with records, sequences, sets, functions, and function overrides, then defines a Next action that can stutter or update one variable at a time to structurally equivalent values expressed in different syntactic forms. The specification is intended to exercise TLC's treatment of equality among sequences and functions, set normalization, DOMAIN, Cartesian products, concatenation, and EXCEPT updates; it includes a Print-based check in Init and a trivial invariant.
