This specification models a very small state machine with two state variables, x and y. The initial state sets both variables to 1, and the Next action always increments x while either nondeterministically assigning y' from the set {1,2} when x = 1 or leaving y unchanged otherwise. The file defines two state invariants, one constraining y to remain below 2 and another constraining x to remain below 30, and combines them into a state constraint named Constraint; there are no temporal properties, fairness conditions, proofs, or PlusCal constructs.
