This module specifies the Paxos consensus algorithm using message-passing between leaders and acceptors, and includes a TLAPS-checked proof of safety. The model tracks the set of sent messages and, for each acceptor, the highest ballot it has participated in and the highest ballot/value it has voted for. It assumes quorums are subsets of acceptors with pairwise nonempty intersection, proves an inductive invariant, proves consistency of chosen values, and finally proves refinement to an abstract consensus specification imported from the Consensus module.
