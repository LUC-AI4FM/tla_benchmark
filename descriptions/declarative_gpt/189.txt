This specification defines a very small TLA+ module centered around a helper operator F(x,y) that uses a LET-bound singleton set {x} and an IF test to return x when y is a member of that set, and otherwise return y. The system behavior itself is trivial: both Init and Next are defined as TRUE, so the module does not model a substantive transition system or fault model. The property captured is a simple invariant-style state predicate Inv asserting that F(1,1) = 1, and the file also includes Apalache type annotations in comments to describe the intended polymorphic type of F and the local set A.
