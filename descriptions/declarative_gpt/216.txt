This module defines a collection of invariant-style checks over the operator Repeat imported from the Apalache module. It tests Repeat with several kinds of operators: a constant increment operator, an accumulating operator that adds the iteration index, a cyclical operator modulo 3, an idempotent set-flattening operator using UNION, and a nilpotent operator that repeatedly removes maximal elements from a set. The specification itself is trivial at the temporal level with Init == TRUE and Next == TRUE, while the main asserted content is the conjunction Inv of the five properties describing expected behavior of Repeat under these different algebraic patterns.
