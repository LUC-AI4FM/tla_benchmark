This module defines helper notions on directed acyclic graphs for DAG-based consensus protocols, focusing on vertices that are pairs of a network node and a round. It defines leader vertices, a deterministic-but-arbitrary ordering of set elements, a way to find the previous leader in a DAG, and a recursive linearization procedure that turns a DAG into a sequence. The specification is not itself a full transition-system protocol model with variables and actions; instead it provides structural functions and predicates intended to support safety and liveness reasoning about DAG-based consensus, assuming a genesis vertex and that DAG paths terminate at genesis.
