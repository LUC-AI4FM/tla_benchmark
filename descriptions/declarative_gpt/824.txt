This module specifies Jayadev Misra's algorithm for computing the set of graph nodes reachable from a distinguished node Root in a directed graph. The graph structure itself is taken from the imported Reachability module via the constants Nodes and Succ, and the algorithm maintains two sets, marked and vroot, plus a control variable pc generated by the PlusCal translation. The specification defines the translated PlusCal algorithm, its temporal specification with weak fairness of Next, several state invariants used for partial correctness, a theorem asserting that termination implies the computed set equals the mathematical reachable set, and a liveness theorem asserting eventual termination when the reachable set is finite.
