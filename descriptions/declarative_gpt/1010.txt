This specification models a B-tree-based key-value store supporting get, insert, and update requests over a bounded set of keys, values, and nodes. The state explicitly represents tree structure using node-local key sets, child pointers, last-child pointers, leaf flags, stored values, and a small request/response control interface with operational states for searching, adding, and splitting nodes. It includes a refinement mapping to an abstract kvstore specification, a type invariant and several structural invariants, and a temporal specification with weak fairness for get requests; there is no fault model, and comments note that deletes are not implemented.
