This specification models a very small two-variable state machine over integers. The initial state sets x to 0 and y to 1, and the only transition swaps the values of x and y on each step by assigning x' = y and y' = x. It asserts two temporal properties: one liveness property stating that it is always the case that eventually the state x = 1 /\ y = 0 recurs, and another false liveness property stating that it is always the case that eventually x = 0 /\ y = 0, which is not reachable under the defined swap behavior.
