This module defines a very small parameterization for a concurrent percolator specification by fixing the key space to two keys and the client set to two concurrent clients. It models two clients, c1 and c2, whose primary keys are 1 and 2 respectively, and is intended for TLC model checking as stated in the comments. The file itself contains only constants and simple value definitions; it does not define variables, actions, temporal properties, fairness, or proofs, and it relies on an extended module for the actual system behavior.
