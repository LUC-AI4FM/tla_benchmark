This module specifies Conway's Game of Life over an N by N finite grid using a typed TLA+ style. The single state variable is a function mapping each position in the set of board coordinates to a Boolean cell state, and the next-state relation updates all cells simultaneously according to the usual survival and birth rules based on the usual survival and birth rules based on the number of live neighbors. The specification includes a recursive summation helper, a boundary-aware scoring function that treats out-of-bounds or dead cells as contributing 0, an initial typing condition, and a temporal specification asserting that all behaviors start in an initialized state and thereafter evolve by repeated Next steps.
