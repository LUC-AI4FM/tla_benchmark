This specification models a simple iterative exponentiation algorithm that computes m ^ n by repeated multiplication. The original algorithm is written in PlusCal and translated into TLA+, with state variables m, n, res, i, and pc representing the current inputs, accumulator, loop index, and control location. The spec assumes m is drawn from a set of integers and n from a set of naturals, initializes res to 1, repeatedly multiplies res by m while i =< n, and asserts at the end that the result equals m ^ n. It verifies a basic temporal specification consisting of initialization and the standard next-state relation, plus an eventual termination property asserting that control eventually reaches the Done state. A notable design choice is the explicit Terminating action that allows infinite stuttering after termination to avoid deadlock.
