This module provides Apalache-oriented type annotations and concrete constant values for an existing single-producer, multiple-consumer Disruptor specification by instantiating `Disruptor_SPMC`. It declares the constants and variables expected by that underlying model, adds a typed monomorphic helper operator `Range(f) == { f[x] : x \in DOMAIN(f) }`, and supplies concrete writer and reader sets for configuration. The file itself does not define the transition system, actions, or temporal properties; those are inherited from the instantiated module and therefore are not extracted here. A notable design choice documented in comments is that the local `Range` definition intentionally shadows another helper with an identical body so that the original spec remains free of tool-specific annotations.
