This specification models a very small state machine over a single variable s. The initial state assigns s to the subset of the enumerated set {1,3,5,2} containing exactly the element 2, and the only next-state action leaves s unchanged forever. The spec defines an invariant asserting that s = {}, which is intended as a state predicate to be checked against the initialized behavior; because Init makes s equal to {2}, the invariant does not hold initially.
