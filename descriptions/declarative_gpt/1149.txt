This specification models Dijkstra's token-based distributed termination detection algorithm (EWD840). The system consists of N nodes arranged in a ring, each of which can be active or passive and colored white or black. A token circulates among the nodes, carrying a color (white or black) and a position. The algorithm ensures that global termination is detected when all nodes are passive and the token returns to node 0 as white. The model includes actions for initiating a probe, passing the token, sending messages (which can activate other nodes and stain the sender black), and deactivating nodes. The specification verifies type correctness, safety (termination detection), and liveness (eventual detection of termination), and explores the effect of different fairness conditions. Notable design decisions include the use of a weakened fairness condition (WF_vars(System)) to avoid undesired liveness properties, and the explicit modeling of node and token colors to capture the algorithm's correctness arguments.
