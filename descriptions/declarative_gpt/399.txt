This module is a small test specification for TLC fingerprinting of structured values, especially elements of function spaces of the form [S -> [B -> C]]. It initializes four variables with nested functions, records, tuples, and sequences, then allows either stuttering or a single transition that rewrites those variables into extensionally equivalent or structurally transformed values using function constructors, tuples, IF expressions, and EXCEPT updates. The spec does not model a fault-tolerant distributed algorithm; instead it is a state-space test focused on data representation and state equality, with a comment indicating TLC should find only one state.
