This module defines a small library of TLA+ operators for representing BNF-style grammars as languages over sequences of strings. It includes constructors for singleton-sequence languages, concatenation, union, one-or-more repetition, zero-or-more repetition, a grammar type as a function from strings to sets of string sequences, and a least-grammar operator defined with CHOOSE. The module has no constants, variables, actions, temporal formulas, assumptions, or PlusCal code.
