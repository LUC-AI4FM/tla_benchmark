This specification models a simple key-value store with four operations: get, insert, update, and delete. The store maps keys to either a value in Vals or the distinguished marker MISSING, and requests/responses are modeled with explicit state variables for the current operation, arguments, return value, and whether the system is ready or working. The spec defines type correctness, initialization, request and response actions for each operation, and a temporal specification requiring initialization, all steps to satisfy Next up to stuttering, and weak fairness for delete requests over op.
