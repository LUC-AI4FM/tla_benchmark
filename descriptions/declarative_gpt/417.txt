This module is a small test specification for TLA+ function application and related value expressions. It checks, through the invariant Inv, that function constructors and record-style application behave as expected, using TLC operators Assert and Print to report success or failure of individual tests. The active part of the file models a trivial one-variable system where x is fixed at 1, with Type constraining the state, Init initializing x, and Next stuttering; many additional test cases are present but commented out and therefore not extracted as active syntax.
