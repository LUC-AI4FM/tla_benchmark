This module specifies a tutorial version of binary search over an input sequence `INPUT_SEQ` with a search key `INPUT_KEY`, using bounded machine-integer-style constants derived from `INT_WIDTH`. The state tracks the current search interval with `low` and `high`, whether the search has terminated, the returned result, and a step counter `nSteps`. The specification defines initialization, a single-step transition relation for the search loop, a sortedness predicate over the input, a correctness condition for the returned value, and state/action properties related to postcondition, termination, and progress; it does not define a full temporal `Spec` formula.
