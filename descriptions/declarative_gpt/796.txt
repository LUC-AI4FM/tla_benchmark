This module defines a simulation wrapper around a Knuth-Yao coin-flipping specification, using TLC generation mode to collect statistical data about the outcomes of the algorithm. It models both a stateless crooked coin and a stateful crooked coin, initializes a simulation state, advances the system by taking transitions according to the current flip, and records completed samples into a CSV file while maintaining TLC counters. The specification also includes assumptions about the TLC runtime configuration, a statistics constraint for side effects during generation, and a postcondition that checks the number of generated samples and applies a chi-square test to the observed terminal-state distribution.
