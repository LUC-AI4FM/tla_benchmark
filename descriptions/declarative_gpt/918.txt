This module provides Apalache-oriented type annotations and helper definitions for an inner FIFO channel specification. It declares the message domain, queue bound, and channel state variables `in`, `out`, and `q`, then instantiates `MCInnerFIFO` as an external module without extracting any inherited operators from it. The module adds a concrete finite message set `MessageVal` and defines `ChannelTypeInvariants` to check the input and output channel type invariants together with a bounded-queue condition `Len(q) <= qLen`, specifically to avoid using a non-enumerable `Seq(Message)` type expression in Apalache.
