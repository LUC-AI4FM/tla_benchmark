This module provides alternative, Apalache-compatible definitions for standard sequence operators from the Sequences module. The comments explain that the module must be named Sequences so that SANY accepts it, and that the definitions are rewired by the Apalache importer rather than intended as full semantic implementations here. It defines basic sequence operators such as Seq, Len, concatenation, Append, Head, SubSeq, Tail, and SelectSeq, mostly as dummy bodies, with SelectSeq expressed via a local fold-based helper and a conditional append.
