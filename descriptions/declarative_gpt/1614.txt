This specification is the PlusCal translation of a small multiprocess program with one shared variable n and a per-process local variable i. Three processes in the set {1, 2, 3} each execute a single control location named main, assign their local i to the expression nplus2 derived from n, assert that the resulting value is 2, and then terminate by moving their program counter to "Done". The generated TLA+ spec defines the initial state, the process action, a terminating stuttering action to avoid deadlock after all processes finish, the overall safety-style temporal specification Spec as Init /\ [][Next]_vars, and a liveness property asserting eventual termination of all processes.
