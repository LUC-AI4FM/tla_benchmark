This module is a model-checking wrapper around another specification, intended to instantiate a binary-search model with fixed parameter choices for 8-bit integers. It fixes the integer width by defining INT_WIDTH == 8, leaves the input sequence and search key unconstrained except for initialization through generated values, and declares the state variables used by the underlying BinSearch7 specification. The module does not define the search algorithm itself locally; instead, it introduces constants, variables, an INSTANCE of BinSearch7, and a ConstInit predicate that assigns arbitrary generated values of appropriate sizes to the input key and input sequence.
