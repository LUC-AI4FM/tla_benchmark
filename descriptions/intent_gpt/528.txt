Specify a simple state-transition system that models a program which initializes a finite set of symbols and a fixed-length sequence of integers, then performs a single update step that (1) adds one new symbol to the set and (2) changes one element of the sequence to a new integer value, then terminates. The specification should capture initial states, the single composite update step, and allow the system to remain in the final state forever (stuttering) so termination is not considered a deadlock.

Requirements:
- Initial state: the set contains two distinct symbols and the sequence has three integer entries with specified initial values.
- Single update step: the set must become the union of its initial value with an additional specific symbol; simultaneously, the second element of the sequence must be overwritten with a specified new integer. No other components may change during this step.
- Termination: after the update step the system reaches a final state and may stutter indefinitely without further changes.
- Observability: the updated values of both the set and the sequence should be observable immediately after the update.
- Safety property: the set must always be a set of symbols (no duplicates) and the sequence must always remain a sequence of length three of integers; the only allowed state transition that alters values is the single composite update described.
- Liveness property: eventually the system must perform the update and reach the final state.
