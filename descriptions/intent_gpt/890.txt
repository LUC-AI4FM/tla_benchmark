Specify a TLA+ model of an asynchronous single-message handshake interface between a sender and a receiver that communicate via a single shared data channel and explicit ready/acknowledge signals. The system should capture the asynchronous exchange of a value where the sender may present a value and raise a ready signal, the receiver may sample the value when ready and raise an acknowledge signal, and both sides may reset their signals to allow subsequent transfers. The model must allow the sender and receiver to act independently (i.e., not atomically synchronized) and to progress in any interleaving subject to the handshake protocol.

Require that the model enforce the protocol invariants: values transmitted are drawn from the declared value domain; ready and acknowledge signals are booleans; when the receiver accepts a value it reads the value currently presented by the sender only when the ready signal is set; the acknowledge is raised only in response to a valid ready and clears in a way that allows another transfer; the sender does not overwrite the presented value while an outstanding ready/acknowledge exchange is in progress except according to protocol rules. Specify liveness properties ensuring eventual completion of a handshake under fair scheduling assumptions: if the sender repeatedly offers a value, the receiver eventually accepts it, and vice versa under similar fairness. State a safety property that the type and handshake invariants hold in every reachable state. Do not constrain implementation details such as using specific variables or atomic steps.
