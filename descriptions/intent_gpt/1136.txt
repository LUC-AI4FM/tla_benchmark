Model a nondeterministic generator and evaluator of short expressions over a fixed small domain. The system should repeatedly construct expressions up to a bounded syntactic depth and then evaluate them to produce values in a known finite set. Requirements:

- The expression language: allow a finite set of atomic values and a set of compositional operators that produce new expressions; the maximal expression size is a given constant bound. The generative process must be able to produce any syntactically valid expression up to that bound.

- The evaluation semantics: provide a deterministic evaluation mapping from expressions to values in the finite domain. Evaluation must be total for all generated expressions (no runtime errors or undefined results).

- The control behavior: repeatedly choose an expression to evaluate; choices may be nondeterministic but must respect the size bound. The system may log or report each expression together with its evaluated value.

- Correctness properties to verify:
  - Coverage: every syntactically valid expression of size ≤ bound is reachable by some execution.
  - Type/Domain safety: every evaluation result belongs to the specified finite set of values.
  - Determinism of evaluation: evaluating the same expression always yields the same value.
  - Termination of each evaluation step: evaluation of any expression completes in finitely many steps.

- Parameters: the finite domain of values and the size bound should be model parameters so different instances can be checked.
