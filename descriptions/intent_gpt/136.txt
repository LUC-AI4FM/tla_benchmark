Specify a formal model of Conway’s Game of Life on an N×N finite square board. The model should describe the grid as a configuration of Boolean cell states (alive or dead) and allow any initial configuration. Time should progress in discrete synchronous steps in which every cell updates simultaneously according to the standard Life rules: a live cell survives only if it has 2 or 3 live neighbors; a dead cell becomes live only if it has exactly 3 live neighbors; otherwise the cell is dead. Neighboring positions are the eight orthogonal and diagonal adjacent cells; cells at the board boundary have fewer neighbors (no wraparound).

Require the model to ensure basic type and domain invariants: the grid is always an N×N mapping of coordinates to Booleans, and coordinates used in neighbor calculations must be restricted to the board. The model should permit checking reachability and temporal properties over execution traces.

Key correctness properties to be expressible and checkable:
- Safety: every step conforms to the Life update rule for every cell.
- Invariance: type and domain invariants (grid shape and Boolean values) hold in all states.
- Liveness and behavior analyses: ability to state and verify properties such as eventual quiescence (reach a state that repeats or is fixed), detection of oscillators, and preservation of conserved counts (e.g., total number of live cells is an integer-valued function that evolves according to rules).
- Boundedness: all neighbor-count computations access only positions inside the N×N board.

Do not prescribe any particular implementation technique; focus on the abstract state, transition relation, and the desiderata above so that model checking and temporal reasoning can be applied.
