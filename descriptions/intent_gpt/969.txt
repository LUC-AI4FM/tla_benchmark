Specify a model of directed finite-state graphs used to represent transition systems, and a tool that analyzes reachability and counterexample extraction. The model should allow an arbitrary directed graph with a finite set of nodes, a distinguished set of initial nodes, and a collection of labeled transitions where each transition from a node can nondeterministically lead to one of several successor nodes (including none). The system to specify must support the following analyses and guarantees:

- Reachability: determine which nodes are reachable from the initial set via zero or more transitions.
- Violation detection: given a set of designated "bad" nodes, determine whether any bad node is reachable.
- Counterexample generation: when a bad node is reachable, provide at least one finite path (sequence of nodes starting in an initial node) that leads to a bad node.
- Support for multiple independent test graphs: the specification must be parametric so different graphs, initial sets, transition collections, and bad-node sets can be plugged in.
- Correctness properties: (1) any returned counterexample is a valid path consistent with the graph’s transitions and starts at an initial node and ends at a bad node; (2) if no counterexample is returned the model must guarantee that no bad node is reachable; (3) reachability computation must be sound and complete relative to finite path semantics.
- Edge cases: handle empty graphs, nodes with no outgoing transitions, multi-sink structures, and graphs with strongly connected components.

Do not prescribe any particular algorithmic implementation; state only the required semantics, outputs, and correctness obligations.
