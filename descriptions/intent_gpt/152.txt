Specify a state-transition system that models a simple counter variable observed with a fixed-length history of past values. The system should non-deterministically update the current counter at each step to any value inside a given bounded range, while the stored history shifts: the most-recent historical slot receives the previous current value, and older slots receive the value that was previously in the more-recent slot. The initial state must allow arbitrary initial current values within the range while the history slots begin with distinguished sentinel values outside the valid range.

Require expressing both safety and liveness properties. Safety requirements: every step must keep the current value within the bounded range; history slots must always equal values that have previously been held by the current variable (except for initial sentinel values). Liveness requirements: whenever the current counter ever becomes zero, it must be guaranteed that, eventually, the oldest history slot will hold zero (i.e., zero propagates through the history eventually). Also allow specifying an alternative liveness requirement that cannot be satisfied (for use in testing counterexample generation): whenever the current counter is zero, eventually the oldest history slot equals some other fixed value that is not reachable.

Ensure the specification supports model checking of temporal properties so that counterexamples with nonempty non-looping prefixes can be produced and examined. Provide plainly stated invariants and temporal goals (the realizable liveness and the intentionally false liveness) for verification.
