Specify a simple discrete-state system in which a single integer-valued state component evolves nondeterministically but is always constrained to lie within a fixed finite range. The model should allow any initial state in that range or a single chosen initial value, and every step may change the state to any value within the allowed range (including leaving it unchanged). The specification must express both the initial condition and the allowed transitions, and use a liveness fairness condition that requires enabled transitions to eventually occur (weak fairness for the state variable).

State clearly the properties to be verified, expressed as temporal logic assertions about all behaviors of the system. Required correctness properties include:
- Basic trivial tautologies: eventual truth, invariant truth, and eventual invariance, to exercise model-checking and proof tooling.
- Implications and refinement-style temporal properties combining classical logical connectives with temporal operators (leads-to, always implies eventually, and eventually always).
- State-level formulas asserting that the state can eventually equal itself and that it may eventually differ from itself, and corresponding invariance and recurrence variants.
- Properties that combine unconditional truths with conditional temporal obligations (e.g., from true or false antecedents to eventual or invariant statements about the state).
- At least one property that is vacuously satisfied because its antecedent is always false, to test handling of vacuous implication.

Do not prescribe an algorithmic implementation—only the abstract state space, transition relation, fairness requirement, and the set of temporal properties to be checked or proved.
