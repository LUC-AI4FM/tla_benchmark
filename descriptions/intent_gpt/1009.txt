Specify a model of a single-threaded buffered random-access file abstraction that sits on top of an underlying file image. The model should expose the externally observable operations: seek, setLength, read (single-byte and multi-byte), write (single-byte and multi-byte), and an explicit flush of the in-memory buffer to the underlying file. The buffered implementation must support a fixed-size in-memory window (buffer) that caches a contiguous region of the file; reads and writes that fall inside the cached window should be served/recorded from/to the buffer without immediately touching the underlying file, while operations that move outside the window must cause the buffer to be refilled (possibly after flushing dirty contents). Flushing must copy buffered bytes to the underlying file and clear the dirty flag. setLength must correctly truncate or extend the logical file and adjust the apparent file length and pointer according to the RandomAccessFile contract. The model must maintain invariants tying the buffer contents, buffer window bounds, and logical file contents (so that the logical file equals the underlying file updated by any buffered modifications where relevant), and must ensure a relationship between the internal file pointer and the underlying file pointer after flush/seek operations. Correctness properties required: (1) internal invariants always hold; (2) the buffered behavior refines an abstract RandomAccessFile specification (i.e., every buffered operation corresponds to a valid abstract operation on the logical file and pointer); and (3) each concrete operation refines its abstract counterpart (reads return the expected bytes, writes/flush update logical contents as if writing to the abstract file, seeks and setLength behave as specified). Also require liveness-style guarantees that a dirty buffer can be flushed when needed so that buffer-restoring sequences (flush then refill or seek) can always restore buffer invariants.
