Specify a system in which a single shared value is passed between two components by instantiating and reusing a separate module that defines a sender/receiver protocol. Model one component as providing the value and the other as consuming it; the system must treat the shared datum as an external parameter handed into the reused module instance. The model should capture initialization, the evolution of the shared value, and the interaction such that the reused module operates with that external parameter bound to the system’s current shared value.

The specification must ensure that when the shared value changes, the instantiated protocol observes the updated value consistently and that no illegal bindings or redefinitions of the external parameter occur. Safety properties required: the consumer never reads a value that has not been provided by the producer, and the protocol prevents simultaneous conflicting updates. Liveness properties required: every value provided by the producer is eventually observed and consumed by the receiver, and the system does not deadlock waiting for a binding change. Also require that the reuse of the external module preserves its correctness invariants when its parameter is mapped to the system’s shared value.
