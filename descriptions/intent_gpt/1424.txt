Model a simple state machine that explores a single mutable storage cell which may take values from multiple distinct types (e.g., integers, booleans, and strings). The model should capture an initial state where the cell contains a specific integer and allow transitions that assign the cell either a range of integer values, a boolean value, or a string value. The purpose is to exercise how a state-space exploration and state-set representation behave when values of incompatible types coexist in the same variable.

Specify the system's behavior and the following correctness requirements:

- Safety: Every reachable state must have the cell equal to some permitted value (either within the given integer range, the boolean constant, or the specific string), i.e., no undefined values may be produced.
- Liveness: From the initial state, it must be possible to continue taking steps forever (no deadlock unless explicitly prohibited by allowed transitions).
- Type-mixing observation: The model should make explicit that distinct concrete type values can appear in the state-space and allow checking for collisions or equivalence in state representation across types (for example, that a boolean value is not considered equal to any integer or string value).
- Boundedness: If a finite integer range is used, ensure the specification makes it possible to enumerate the integer alternatives so the state-space can be inspected for interactions among types.

Do not prescribe an implementation strategy; focus on the allowed values, the transition relation that can assign any one of them in a single step, and the above correctness properties to be checked.
