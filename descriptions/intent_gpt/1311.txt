Specify a model of a sequential algorithm that computes the greatest common divisor (GCD) of two positive integers using the subtraction-based Euclid method and then terminates. The model should represent an initial state in which the first input is a fixed positive integer and the second input is an arbitrary positive integer drawn from a finite range. The algorithm repeatedly transforms the pair of numbers so that their unordered multiset stays the same while reducing the larger by the smaller until one of them becomes zero; at that point the other value equals the GCD and the algorithm stops.

Requirements:
- Model the control flow of the loop and the conditional swap that ensures the larger value is reduced by the smaller.
- Capture the nondeterminism of the second input within a specified finite domain and allow the first input to be an arbitrary fixed constant.
- Ensure eventual termination: for every allowed initial second input, the algorithm must reach a terminal state in a finite number of steps.
- Preserve invariants: at every step the GCD of the two numbers remains equal to the GCD of the initial pair; both numbers remain nonnegative integers; when the loop exits, the nonzero component equals the GCD.
- Provide a safety property that the algorithm never produces negative values and that the pair of numbers remains within a bounded range determined by the initial values.
- Provide a liveness property that termination is always reached (no infinite looping).
