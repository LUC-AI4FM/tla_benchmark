Specify a model of an algorithm that finds all placements of N queens on an N×N chessboard so that no two queens attack each other (no two in the same row, column, or diagonal). The model should treat a full placement as an ordered list of N column positions, one per row, and allow partial placements of length ≤ N representing queens placed in the first k rows. The system should explore the space of partial solutions by repeatedly selecting some partial placement, computing every nonattacking way to place a queen in the next row, and replacing the selected partial placement with those extensions (or recording extensions as complete solutions when they reach length N). The model must permit nondeterministic choice of which pending partial placement to expand next and of which legal column positions to extend with, so the search order is unspecified.

The specification must guarantee:
- Safety: every recorded full placement is a valid nonattacking solution, and every pending partial placement contains no pair of attacking queens.
- Progress: when pending partial placements remain, the algorithm can make progress (i.e., it can always perform an expansion step); termination is reached precisely when no pending partial placements remain and all solutions have been discovered.
- Completeness: once the search finishes, the set of recorded full placements equals the set of all valid N-queen solutions.
- Type invariants: pending and solution collections only contain sequences of appropriate lengths and values in 1..N.

Also state liveness properties ensuring the search does not starve expansions (e.g., a weak/strong fairness requirement on the expansion action). Do not prescribe a particular internal representation or operational scheduling beyond the nondeterministic selection of a pending partial placement and its legal extensions.
