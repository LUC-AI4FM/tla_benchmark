Specify a small collection of deterministic function-evaluation properties for a specification language that models applying built-in binary operators and predicates as first-class arguments. The model should describe a system that can apply an arbitrary binary operator or predicate to two concrete operands and return the correct result, treating built-in operators (numeric addition, set union, membership predicate, Boolean constants, etc.) as values that can be passed to and invoked by higher-order function-like constructs.

Require the model to include at least these behaviors:
- Applying the numeric binary addition operator to two integer literals yields their arithmetic sum.
- Applying the binary set-union operator to two concrete finite sets yields their union.
- Applying a membership predicate operator to an element and a concrete set correctly reports whether the element belongs to the set, including treating Boolean constants as elements of a Boolean domain.

The specification must assert these properties as invariants or assertions that hold in every reachable state. The model need not describe concurrency, state-changing actions, or a particular implementation strategy; it only needs to capture evaluation correctness for these examples and ensure that passing built-in operators as arguments produces the same result as invoking them directly. Include straightforward finite domains for integers and booleans sufficient to check the examples.
