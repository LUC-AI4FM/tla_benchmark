Specify a parameterized model of a simple coherent shared-memory cache system with N processors, a finite set of memory addresses, and a finite data domain. The model should describe the global memory (a mapping from addresses to values) and, for each processor, a local cache state that may either hold the current memory value for each address or be in an unknown/not-present state. Each processor also has an input queue of operations and an output queue of responses. Operations may be ordinary read/write address-data pairs or special tagged operations; responses are address-data pairs.

The system must allow (at any step) an arbitrary memory update at any address, arbitrary processor-local cache updates that may set a cache entry to a concrete value or to unknown, enqueueing operations into a processor’s input queue (up to a fixed maximum length), dequeueing operations, enqueueing responses into a processor’s output queue (up to a fixed maximum length), and dequeueing responses. Queues must be bounded by specified maximum lengths.

Require invariants that the global memory and all caches and queues always have values drawn from the declared finite domains (including an explicit “unknown” symbol for caches). Guarantee that the system’s state space is finite. Specify safety properties: no variable ever takes a value outside its declared domain; lengths of per-processor queues never exceed their maxima; and caches always map addresses to either the current memory value or the unknown symbol. Also require liveness/progress statements allowing processors’ input and output queues to make progress (i.e., enqueues can eventually be dequeued). The model should be parameterized by the number of processors, address set, data set, initial memory contents, and maximum queue lengths.
