Specify an abstract model of undirected, loop-free graphs and their connectivity properties. The model should represent a finite set of nodes and a set of edges, where each edge is an unordered pair of two distinct nodes. Provide operations for taking arbitrary subgraphs and for expressing finite simple paths (nonempty sequences of distinct nodes where each adjacent pair is connected by an edge). Define the concept of connected components as the partition of nodes into maximal sets such that each pair of nodes in the same set is joined by a path. The model must also provide a predicate to test whether two given nodes belong to the same connected component, and a predicate asserting that the graph is connected (exactly one connected component).

Formally require that:
- Edges contain only existing nodes and never contain the same node twice.
- Simple paths use each node at most once and follow existing edges.
- Connected components form a cover of the node set, are disjoint, and are maximal with respect to path connectivity.
- The two-node connectivity predicate is equivalent to existence of a path between them.
- The connectedness predicate is equivalent to having a single connected component equal to the set of all nodes.

Do not prescribe a particular algorithm for computing components; allow any correct definition or construction that satisfies these properties.
