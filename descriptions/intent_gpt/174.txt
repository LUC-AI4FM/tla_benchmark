Specify a concurrent/state-transition system that manipulates two nonnegative integer counters bounded by a finite range (e.g., 0..50). The system must always start in a state where both counters lie within the allowed range and their values are not equal. At each transition both counters are updated simultaneously according to a deterministic rule that computes each new value as a simple function of the other counter’s previous value (for example, incrementing the other’s value by a fixed constant). The model should permit only transitions that keep the counters within the integer domain (no requirement to encode arithmetic overflow handling beyond ordinary integers).

State the following correctness properties to be checked:

- Safety: the two counters are never equal in any reachable state (invariant).
- Boundedness: both counters remain within the initial allowed finite range for all reachable states (or clearly indicate if and when a counter can escape that range).
- Progress/liveness: if a counter ever exceeds the high end of the initial range, the other counter eventually and thereafter permanently exceeds that high end (formulate as a temporal implication of eventual and then always).
- Demonstrate a nontrivial liveness implication that can deliberately fail (for testing purposes): an implication whose antecedent can become true but whose consequent is not guaranteed, so model checking can produce a counterexample.

Do not prescribe how the update function is written; only require it to be deterministic, symmetric in structure (each counter’s new value depends only on the other’s old value), and suitable to produce both provable invariants and interesting liveness behavior for model checking.
