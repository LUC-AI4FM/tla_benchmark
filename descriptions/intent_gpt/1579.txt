Specify a TLA+ model of a distributed token circulation algorithm on a unidirectional ring of N processes (N > 0) with K distinct integer states (K > N). Each process maintains a local counter drawn from 0..K-1. The system should implement a single logical token that moves around the ring by comparisons and updates of neighboring counters: a process is considered to "hold the token" when its counter differs from its predecessor’s (for process 0, the predecessor is process N-1, and process 0 holds the token when its counter equals the last process’s counter). The protocol must guarantee that at any reachable state at least one process holds the token (token existence) and that, starting from any initial configuration, the system eventually reaches and remains in states where exactly one process holds the token (liveness and convergence to a single token). Model asynchronous interleaving of processes, where each process can perform local steps comparing its counter to its neighbor and either incrementing its own counter (for the designated initiator) or copying the predecessor’s counter (for others) according to the token semantics. Specify safety properties: the set of token holders is always non-empty; and liveness properties: the token circulates (individual token-passing steps occur) and the system converges to a stable single-token regime (eventually always exactly one holder). Include assumptions K > N and that counters range over 0..K-1.
