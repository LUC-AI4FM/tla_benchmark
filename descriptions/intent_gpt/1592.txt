Specify a model of a recursive factorial computation implemented by two mutually calling procedures that share a single global accumulator. The model should represent a procedural execution with an explicit call stack, procedure-local parameters, and local temporaries, but need not prescribe how the stack is implemented. The system must accept an initial request to compute n! for a given nonnegative integer n and then execute calls between the two procedures until all calls return and the computation terminates.

Requirements:
- The model must allow arbitrary nonnegative integer inputs n (including 0) and must initialize the global accumulator to 1 before the call.
- Each procedure call may either return immediately when its argument is zero or multiply the global accumulator by its argument and then call the other procedure with the argument decremented by one.
- Calls must properly save and restore local state and return control to the caller when finished; the call/return discipline must be modeled explicitly so nested mutual recursion behaves like real procedure calls.
- The model should allow observing termination (completion of the original call) and the final value of the accumulator.

Correctness properties to verify:
- Safety: the accumulator always holds a natural number (no negative or non-integer values) and when termination occurs the accumulator equals n! for the initial input n.
- Liveness: the computation eventually terminates for every finite n (no infinite mutual recursion or livelock).
- Stack discipline: calls and returns preserve caller-local data and control flow; no return should occur to an incorrect continuation.

Do not constrain how procedures are named or implemented internally; only require that the observable behavior (final accumulator and termination) matches the specification above.
