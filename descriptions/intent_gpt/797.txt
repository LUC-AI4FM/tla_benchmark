Specify a simple infinite-state sequential system that models a single numeric counter repeatedly incremented by two. The model should treat the counter as a natural number initialized to zero and allow an unbounded, nonterminating sequence of steps each of which increases the counter value by exactly 2.

The specification must state the legal initial states and step relation without prescribing an implementation technique. It must permit only those transitions that add two to the current value; no other transitions (including stuttering or arbitrary jumps) are allowed except as required to express temporal properties.

Require and verify these correctness properties:

- Type safety: the counter value remains a natural number in every reachable state.
- Evenness invariant: the counter value is always an even integer (divisible by two) in every reachable state.
- Liveness: the system must always be able to perform another increment (i.e., there are infinitely many steps — no deadlock).

Express the specification using temporal logic so that invariants are provable as safety properties (always holds) and the liveness requirement is stated as a fairness or progress obligation ensuring the repeated increment action can always occur. Avoid encoding internal implementation details; describe only states, transitions, and the properties to be ensured.
