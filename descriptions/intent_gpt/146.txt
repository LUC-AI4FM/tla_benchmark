Specify a simple two-variable state machine that swaps values between two integer registers on each step and reason about its safety and liveness properties. The model should represent two integer-valued locations initialized to distinct values and define a deterministic transition that assigns each register the previous value of the other. The specification must allow infinite behaviors produced by repeatedly applying this swap.

Require the following correctness properties be specified and checked:

- Safety: an invariant stating the possible pairs of register values at any time (for example, that both registers always hold integer values and that their values remain within some explicitly stated domain or relation derived from the initial state).

- Liveness: liveness assertions expressing eventualities about arithmetic relations of the registers. Include at least two liveness goals: one that requires that a particular arithmetic equality (constructed from the registers using local arithmetic helper expressions) holds infinitely often, and another that requires that some arithmetic equality eventually becomes permanently true. The liveness properties must be expressible using local/let-style helper definitions inside the temporal formulas.

Also require that the spec be precise about which expressions are allowed inside temporal constructs, and that it distinguishes fairness-type liveness obligations from safety invariants. Do not prescribe any particular implementation language or proof method; state only the behavioral model and the properties to verify.
