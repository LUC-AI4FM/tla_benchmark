Specify a model of nondeterministic finite directed graphs and a simple concurrent pair of processes that each repeatedly pick and hold an edge of a given graph, subject to the following. The system should allow a parameterized finite set of nodes and represent a directed graph as an arbitrary subset of node pairs. The model must support a designated constant graph instance that is treated as fixed for a run, and it must also allow a separate randomized or externally chosen auxiliary graph used only to assert cross-constraints in invariants (so that the auxiliary graph can differ from the fixed graph).

Model two concurrent agents that independently and indefinitely choose an edge from the fixed graph at each step; each agent’s local variable is always one concrete edge of that fixed graph. The system should permit arbitrary nondeterministic re-selection at each step (no communication or ordering constraints between agents is required).

State and prove the following correctness properties as invariants:
- Safety: at every reachable state, each agent’s chosen edge is a member of the fixed graph’s edge set.
- Cross-graph consistency: at every reachable state, each agent’s chosen edge is also an edge of the auxiliary graph produced by an external random selection (i.e., a relationship between the fixed and auxiliary graph edges must hold).
- Deterministic numeric assertion: a particular computed integer expression derived from bounded sequences over small finite sets must equal a specified constant in all reachable states (this checks evaluator/stability aspects rather than system behavior).

Do not specify algorithmic implementation details for graph selection, randomization, or step sequencing—only the abstract state space, transitions that reassign each agent to any edge of the fixed graph, and the invariants to be checked.
