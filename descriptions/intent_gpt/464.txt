Specify a simple, deterministic system that models an immutable numeric state and validates arithmetic and set-interval properties of the underlying logic. The system should have an initial state containing a single integer value and no state transitions that change that value; its purpose is to assert a collection of arithmetic truths and interval/set identities rather than to evolve behaviorally.

The model must check basic integer arithmetic facts (equality, inequality, ordering, division and remainder identities, and modulo properties) and simple set/interval expressions, and it must treat any violation of these facts as a safety error. The required arithmetic checks include: integer addition and multiplication identities, comparisons (<, >, ≤, ≥), divisibility and the relationship between division and remainder (a = b*(a div b) + (a mod b) for positive integers and specified edge cases), identities for division or modulus by 1 and 0 as appropriate, and specific examples that demonstrate nontrivial quotient/remainder calculations. The set checks include that empty intervals are empty and that bounded integer intervals enumerate the expected elements.

Specify these checks as invariants that must hold in every reachable state; the system should report an assertion failure if any invariant is false.
