Specify a simple stateful system that maintains a finite mapping from integer keys to integer values and supports atomic updates that override the mapping for a specified range of keys. The model must initialize the mapping so that a contiguous set of integer keys has identity values (each key maps to itself). It must include an atomic transition that replaces the values for another contiguous range of keys with a constant value while leaving other keys unchanged.

Describe the expected safety properties: after initialization, particular keys within the initial range must have their identity values; after any sequence of transitions, keys outside the replaced range must retain their previously established values; keys that were explicitly overwritten must hold the new constant value. Specify invariants that assert specific keys maintain expected values across all reachable states (both inside and outside the overwritten region as appropriate).

Also require that the update operation is deterministic and total on the specified domain ranges, and that no transition changes the domain of the mapping (only values are modified). The specification should support model checking of the invariants and of absence of unintended value changes.
