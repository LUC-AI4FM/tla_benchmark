Model a pure functional operator that folds over a finite set to produce a finite map from elements of that set to integer values, where the fold uses a deterministic combining function that may extend the map with default integer values for previously unseen keys. The specification should treat the set as an unordered collection and the fold as iterating over all elements in some nondeterministic order, but the final result must be independent of the iteration order. Capture initial conditions, the type constraints (finite sets, finite maps, integers), and the folding semantics: given an initial finite map and a combining function that, for any key, may set or update the map entry for that key (with integer values and explicit defaults), the fold returns a finite map whose domain is the union of the initial domain and the input set. Require that entries for keys not in the union are absent, and keys from the union have integer values. Specify properties that must hold after the fold completes:

- Domain preservation: the result domain equals the initial domain union the input set.
- Determinism: for fixed initial map, input set, and combining function, the result is unique (order-independence).
- Default behavior: if the combining function never writes a value for a key, that key maps to a specified default integer.
- Idempotence/consistency: repeated folding with the same inputs yields the same map.
- Type safety: result is a mapping from the set of allowable keys to integers.

Also include invariants that assert the map never contains keys outside the intended universe and that integer values remain within specified bounds if bounds are required.
