Model a distributed stabilizing token-ring algorithm for N asynchronous processes arranged in a unidirectional ring. Each process holds an integer counter drawn from a finite domain of size M. The system should allow a distinguished source process to inject a token value by incrementing its counter modulo M, and all other processes to copy the counter value of their immediate predecessor when they detect a change. The model must capture arbitrary interleavings of these local actions and permit repeated injections and passes under fairness assumptions that ensure enabled actions eventually occur.

Specify the initial state where every process counter is an arbitrary value in the allowed domain. Require that the design parameters satisfy natural bounds relating N and M so stabilization is possible.

Formalize correctness as two key properties:
- Safety: At every reachable state, all counters remain within the finite domain; no illegal counter values occur.
- Self-stabilization (liveness): From every initial configuration, the system eventually reaches and thereafter maintains a canonical “unique token” configuration in which there is a single boundary in the ring separating two contiguous segments of identical counter values — one segment holding a value v and the other holding (v-1) mod M — so that exactly one logical token is present and it circulates according to the protocol.

Also require that the specification uses weak/strong fairness constraints as needed so that the token creation and passing actions cannot be indefinitely postponed.
