Specify a formal TLA+ model of the Quicksort algorithm as a high-level sorting procedure over a fixed-length array of integers. The model should treat the array abstractly as a sequence of comparable values drawn from a finite domain and must capture the algorithm’s essential behavior without prescribing a particular implementation of partitioning. The system to model must:

- Initialize with an arbitrary permutation of values in an array of given length.
- Repeatedly apply partitioning and recursive subproblem handling until the entire array is sorted in nondecreasing order.
- Model partitioning as an atomic step that chooses a pivot index within the current subarray and produces a rearrangement of the elements inside that subarray that (1) preserves all elements outside the subarray, (2) leaves the pivot element in some chosen position, and (3) ensures every element on the pivot’s left is ≤ every element on its right. The partition step may nondeterministically choose any valid pivot and any valid rearrangement satisfying these conditions.
- Model recursion or its equivalent control flow to process left and right subranges until no subrange requires sorting.

Require the model to guarantee the following correctness properties:

- Safety: the final array is a permutation of the initial array (no elements lost or created) and is sorted in nondecreasing order.
- Liveness/termination: every execution eventually reaches a state where no further sorting steps are needed (quicksort terminates).
- No unexpected interference: partitioning or recursive calls must not modify elements outside the current subarray.

State invariants that capture permutation preservation and the partial ordering established by completed partitions, and specify fairness or well-foundedness conditions sufficient to prove termination.
