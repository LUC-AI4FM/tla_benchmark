Specify a concurrent system that maintains two independent maps from a fixed finite domain of integer keys to sets of integers. The system starts with both maps assigning the empty set to every key in the domain. At each step, a single operation may nondeterministically choose one key and one of the maps and add a specified element to the set stored at that key in that map (adding is idempotent). The operation must model the update as an atomic modification of a single map at a single key; other keys and the other map remain unchanged by that step.

Require that the domain of keys and the element to add are parameters of the model so different finite domains and elements can be explored. The specification must allow arbitrary interleavings of updates to the two maps.

State the following correctness properties to be checked:
- Safety: the two maps maintain only sets of integers at each key and never map keys outside the domain.
- Invariant: initially the two maps are equal, and the model should support checking whether they remain equal under all possible execution sequences.
- Liveness: if an update to a particular map and key is continuously enabled, then it eventually occurs (a weak fairness condition for enabled updates).

Also specify useful assertions for model checking: reachable states, counterexamples when the invariant is violated, and traces illustrating fairness violations if the liveness condition fails.
