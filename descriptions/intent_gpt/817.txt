Specify a model of a finite directed graph network together with a nondeterministic assignment of each node’s outgoing neighbors, and characterize reachability properties of nodes under that assignment. The system should allow any finite set of nodes and permit each node to have exactly two distinct outgoing neighbors chosen from the node set. Also allow exploration of all possible choices where some nodes may have no edges (i.e., consider sequences of nodes of length up to the number of nodes as possible paths). The model must express reachability: given the chosen outgoing-neighbor relation, a node u is reachable from node v if there exists a finite path following outgoing edges from v to u. Specify operations that nondeterministically pick a valid outgoing-neighbor relation and then evaluate which nodes are mutually reachable, which nodes are reachable from a given source set, and which nodes are reachable from some but not all starting nodes. Guarantee that the specification can check the existence of configurations meeting predicates such as “every node has exactly two successors,” “some node is reachable from every other node,” and “a node is reachable from some but not all other nodes.” Include invariants and temporal properties to assert correctness of reachability computations.
