Specify a model of a single-threaded program execution with explicit procedure calls, returns, local variables, and arguments, including nested calls and parameter passing. The model should represent an initial main invocation that calls a first procedure, which in turn may call a second procedure twice with computed arguments; the second procedure checks its local state and forwarded argument and then calls a third procedure with a computed value; the third procedure validates its received argument and returns. The system must capture the call-stack behavior: pushing a frame on a call, preserving caller locals and return point, and restoring them on return. Parameter evaluation must use the callee’s expected parameter values determined at call-time (including expressions based on caller locals), and local variables must be initialized as specified on entry. Assertions scattered through the code must always hold during execution; if an assertion would fail the run is considered invalid. The model should allow termination when the initial call sequence completes and must ensure absence of assertion violations on every reachable terminating or nonterminating execution. Key properties to check: (1) safety — every assertion in any procedure always holds; (2) proper call/return control-flow — every return restores the caller’s control point and local environment; (3) correct parameter passing — argument values observed by callees match the intended evaluated expressions at call time; and (4) termination — the program eventually returns to the top level (optional liveness property to verify termination).
