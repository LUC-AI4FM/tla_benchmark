Specify a simple synchronous-state transition system with two integer state components whose initial values are fixed. The system repeatedly takes discrete steps that update one component by incrementing it and either leave the other component unchanged or keep both unchanged. Some steps are conditional: when the first component currently equals a particular value, the step increments it and records a successful branch; otherwise the step increments it and records a different branch outcome. The model should allow non-deterministic choice between the update branches and a stuttering (unchanged) step.

Require the specification to express assertions about which conditional branches are taken and to enable checking of whether certain predicates about the state before and after a step can be evaluated or lead to contradictions. The properties to guarantee are:
- Safety: the state variables always remain integers and follow only the allowed transitions.
- Deterministic update semantics per chosen branch: if a branch requiring a given precondition is taken, the postcondition must hold.
- Liveness of progress: from any state where the increment-branch is enabled, it must be possible to eventually take a non-stuttering update.
Also include invariants that can be trivially true so the model checker can validate that assertions embedded in conditional step choices behave consistently (i.e., never produce a failed assertion) and that evaluation of pre- and post-step predicates respects primed/unprimed semantics.
