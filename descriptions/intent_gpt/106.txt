Specify a state-based model of a small mutable data store that holds three different typed tables and supports atomic updates to individual entries or nested fields. The model should represent: (1) a finite indexed array mapping integers to records with two named fields; (2) a finite mapping from strings to strings; and (3) a single record containing an integer and a fixed-length tuple of a string and an integer. The system must initialize these three data structures to particular values and then allow nondeterministic single-step updates that atomically change one or more components per step.

Model the update operations so they can (a) change a single numeric field inside a record stored at a particular index, (b) change multiple fields in one step (including replacing an entire element at an index with a new record), (c) update a mapping entry keyed by a string, and (d) update an element inside the tuple stored inside the record. Updates must be applied atomically and preserve the overall types: indices remain in the valid index set, keys remain in the key set, and records/tuples keep their expected field shapes.

Specify invariants to guarantee type safety (fields have the expected types and required keys), that only allowed indices/keys are modified, and that steps perform precisely the permitted atomic modifications. Also state that no other state components change during an allowed update.
