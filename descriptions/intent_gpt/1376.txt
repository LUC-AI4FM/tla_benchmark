Specify a system that models a growing repository of distinct data items that can be added over time. The system should begin empty and support nondeterministic additions of any item from a fixed finite set of possible items. Once an item has been added, it remains present permanently (no removals or modifications). The model must allow arbitrary interleavings of addition events and must not require that all items be added immediately—some may never be added. Correctness properties to guarantee include: safety (the set of items is always a subset of the allowed universe and never contains duplicates beyond set semantics), monotonicity (the set of items never shrinks), and eventual consistency variants as desired (for example, optionally assert that each permitted item may eventually appear, or that some items remain absent). Also specify invariants ensuring the initial state is empty and that every state is reachable only by successive additions of single allowed items. Include the ability to check liveness statements (e.g., fairness or eventual add of a specific item) and permit model checking of both safety and liveness properties.
