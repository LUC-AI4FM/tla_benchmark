Model the N-queens solver that incrementally constructs all valid placements of N queens on an N×N chessboard so that no two queens share a row, column, or diagonal. The model should represent partial placements that place exactly one queen in each of the first k rows for some k ≤ N and full placements when k = N. The system repeatedly chooses a partial placement, computes all column positions in the next row that do not conflict with already placed queens, and replaces the chosen partial placement by all resulting one-row-extended partial placements; if the extension reaches N rows it is recorded as a full solution instead of being requeued. Specify the initial condition, the progress steps that add and remove partial placements and accumulate full solutions, and fairness so that the iterative extension step cannot be permanently disabled.

Require the following correctness properties:
- Safety: every recorded full placement is a valid N-queens solution (no two queens attack each other).
- Sound coverage: when no partial placements remain, the set of recorded full placements equals the complete set of all N-queens solutions.
- Type invariants: partial placements have length < N, full placements have length = N, and placements use only column indices in 1..N.
- Termination liveness: eventually there are no remaining partial placements (the algorithm completes).
Also request that the specification be abstract (describe states as sets of partial and full placements) and avoid committing to a particular exploration order.
