Specify a concurrent state machine that models two integer-valued components that repeatedly update each other based on simple conditional rules. The system has two state variables taking integer values and starts from a fixed initial state. In each step both components simultaneously compute new values: each component either adopts a fixed large value when the other component exceeds a given threshold, or otherwise increments to a value derived from the other component. The model should allow infinite executions.

Require that the specification capture both safety and liveness properties. Safety requirements:
- Values remain integers and updates follow the conditional update rule described above at every step.
- No illegal state transitions occur (every transition must satisfy the simultaneous-update rule).

Liveness requirements (properties to verify):
- Eventually and thereafter a stabilization property holds for one component (there exists a time after which that component permanently equals the designated large value).
- As a contrasting property, express a candidate liveness assertion that should fail: it should be possible that the same component never stabilizes above a small bound (i.e., that "eventually always" being below a threshold is not guaranteed).

Include the ability to check which liveness assertions are true or false under the model semantics and to explore counterexamples for failing liveness claims.
