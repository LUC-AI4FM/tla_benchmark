Specify a concurrent system that models a pair of state-holding components where one component increments a numeric counter and the other component’s value is unaffected by that increment. The system should allow explicit actions to be enabled or disabled and should be able to evaluate the enabledness of actions as first-class predicates. Capture behavior in discrete, synchronous steps: at a step where the increment action occurs, the counter must increase by one and the other component must remain unchanged. Provide an operator for testing whether an arbitrary action is enabled in the current state, and allow that test to be applied both to a concrete increment action and to a general parameter representing an action. Ensure that the enabledness-test operator returns true exactly when there exists a valid successor state reachable by executing the tested action. Specify initial conditions that permit at least one execution of the increment action. The correctness properties required are: (1) safety — the non-counter component never changes value during the increment action; (2) liveness — the increment action can eventually occur repeatedly if continually enabled; and (3) logical consistency — testing enabledness against a parameterized action and testing enabledness against the concrete increment action must behave consistently when the parameter denotes that concrete action.
