Specify a model of a simple reactive system that repeatedly evaluates a fixed pure function over a constant finite set and exposes the function’s boolean output as the system state. The system has one state element that always reflects the most recent evaluation result. On every step the system computes the function applied to a particular constant subset of a predetermined domain and updates the state to the Boolean value whether that function’s result equals a specific target singleton set. The function itself is an external (opaque) mapping from finite subsets of the domain to finite subsets of the codomain; it does not change during execution. Model the domain and codomain as finite sets and allow the external function to be provided as a parameter. Require that the initial state is true and that every transition sets the state equal to the predicate “function(constantSubset) = targetSingleton”. 

Specify properties to check:
- Safety: the state is always a Boolean and equals the evaluation predicate at every step.
- Liveness: if the external function ever becomes (conceptually) such that the predicate holds, the system will reflect that in the state on the next step.
- Determinism of transitions given the fixed external function and constant subset.

Also allow model-checking scenarios that instantiate different external functions to validate these properties.
