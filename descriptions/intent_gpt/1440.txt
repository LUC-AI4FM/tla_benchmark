Specify a simple reactive system with a single boolean state that starts false and can change nondeterministically, and require several variants of the system with different liveness guarantees. The model should capture an initial condition (state is false) and a transition relation that allows the state to become true. Provide three system specifications: (1) a safety-only variant that enforces only the initial condition and transitions (no fairness or liveness guarantees); (2) a weak-fairness variant that, in addition to the initial and transition constraints, ensures weak fairness of the transition with respect to the state so that continuously-enabled progress cannot be ignored; and (3) a custom-liveness variant that requires the state eventually becomes true at some time. Specify the following correctness properties to be checked against each variant: safety properties preventing illegal sequences (for example, forbidding a pattern where once true leads to an impossible return to false under a given safety condition), basic liveness that the state eventually becomes true, leads-to relations showing that from false the system must reach true, and stronger liveness properties including infinitely-often true and eventually-always true. Also include a proof or refinement target showing how a looser abstract specification with full nondeterminism over booleans refines each concrete variant under the corresponding fairness or liveness assumptions. State clearly which properties are expected to hold under which variant (e.g., eventual truth may not hold in the safety-only variant but should hold under the custom-liveness or weak-fairness variants), and identify any properties that are vacuously true or require additional assumptions.
