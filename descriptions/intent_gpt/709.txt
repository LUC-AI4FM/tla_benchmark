Specify a formal model of integer bitwise operations on nonnegative machine-word values (up to a configurable maximum width) and prove their standard algebraic and semantic properties. The model should treat bitwise AND, OR, XOR, NOT, and right-shift as operations on finite-width binary encodings of natural numbers, where widths are a parameter limiting the number of considered bit positions.

Requirements:
- Represent each operation purely in terms of the bits of its operands (no hidden arithmetic tricks) so that bitwise semantics correspond to per-bit Boolean functions applied across the defined width.
- Ensure identity and boundary behavior: operations with zero, one, and identical operands must behave as expected (e.g., x & 0 = 0, x | 0 = x, x ^ 0 = x, x ^ x = 0).
- Ensure commutativity and associativity where applicable (AND, OR, XOR), and self-inverse and distributive properties as appropriate for XOR and NOT.
- Define NOT as bitwise complement within the given width (i.e., flipping each bit); ensure that repeated complement yields original value when width is fixed.
- Define right-shift as logical shift filling with zeros and prove that shifting by one equals integer division by 2 under the semantics used.
- Provide explicit equivalence proofs (or assertions) that the bitwise definitions agree with corresponding arithmetic/aggregate definitions for values within the representable range, and validate small-case examples (diagonal relationships and specific small integers) to exercise edge behavior.

The model should be suitable for mechanized checking of these properties and for varying the bit-width parameter to test generality.
