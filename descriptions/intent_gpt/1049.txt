Specify a formal TLA+ model of a distributed Echo (wave) algorithm that constructs a spanning tree in a connected undirected network starting from a single designated initiator. Model each node as an independent process that communicates by asynchronous point-to-point messages with its neighbors. The model must allow arbitrary message delivery order and interleaving, but messages are neither duplicated nor spontaneously created. The initiator must start the wave by sending a probe to all its neighbors. A non‑initiator, on receiving its first probe, must record the sender as its parent and forward the probe to all its other neighbors; subsequent probes are treated as replies or ignored for further forwarding. After a node has exchanged messages with all its neighbors (i.e., received exactly one message from each neighbor), a non‑initiator must send an acknowledgment to its parent. The initiator completes when it has received acknowledgments from all neighbors.

Require the model to guarantee the following correctness properties:
- Safety: no node ever chooses a parent that is not one of its neighbors; the initiator never chooses a parent.
- Parent–child consistency: if a node records another node as parent then the parent eventually records it as a child (and eventually every recorded parent–child relation corresponds to the child having informed that parent).
- Termination: every node eventually completes the protocol (terminates).
- Spanning tree: when all nodes have terminated, the parent relations form a rooted, acyclic spanning tree that includes every node with the initiator as the unique root and an ancestor relation that is irreflexive.
Also specify basic type invariants (message formats, mailbox contents, neighbor sets) and permit checking of the above properties under arbitrary connected undirected topologies and a single designated initiator.
