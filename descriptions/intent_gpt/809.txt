Specify a formal model of an algorithm that, given a finite sequence of values drawn from a fixed finite domain, selects a candidate for a majority value and computes its count. The system must accept any input sequence of values and produce two outputs: a single candidate value from the domain and an integer count equal to the number of occurrences of that candidate in the input sequence.

The model should capture the progression of a sequential procedure that inspects elements of the sequence in order, maintains a current candidate and an integer counter, and updates them based only on the current element and the current candidate and count. The model must allow the algorithm to terminate after exactly one pass over the sequence and yield the final candidate and count.

Specify invariants and correctness properties that must hold for every execution:
- The candidate at all times is a value from the given finite domain; the count is a non‑negative integer.
- After termination, the reported count equals the actual number of occurrences of the reported candidate in the original sequence.
- If some value appears strictly more than half of the sequence positions, then after termination the reported candidate must be that majority value.
- The model should rule out illegal states such as reading beyond the bounds of the sequence or using counts that exceed the sequence length.

Do not constrain the algorithm to a specific implementation; allow any stepwise, deterministic or nondeterministic, sequential update strategy that performs a single linear scan and satisfies the properties above.
