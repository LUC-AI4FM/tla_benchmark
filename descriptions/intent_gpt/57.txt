Specify a simple static model of a system that defines and reasons about finite functions and sets of functions, ensuring membership relationships between a concrete function and a set-of-functions. The model should include a domain of small integers and construct a function that maps a specific integer to a value. It should also construct a set whose single element is a function (a mapping from a small finite set of integers to a small finite set of integers). The specification must state and check the invariant that the constructed concrete function is an element of the constructed set of functions.

The model should treat these objects as immutable values (no state changes required), but express them in the language of the specification so properties can be proven. Include explicit definitions of the function value and of the set containing a function value, and specify the invariant asserting membership. The correctness property to guarantee is that the invariant holds in the initial state and is preserved (trivially, since no transitions occur). The specification should be minimal, focusing on types and membership, so that a model checker or theorem prover can verify the membership claim about finite functions and sets of functions unambiguously.
