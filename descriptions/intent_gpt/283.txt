Specify a simple state machine that models a fixed-size array of integers and an index into that array, where neither the array nor the index may change over time. The system has a global constant that determines the array size, and the initial state must set the array to a concrete mapping of each valid position to an integer value and set the index to a particular valid position. The transition relation must allow no state changes: every step must preserve the array, the index, any individual array-element value at the current index, and the size constant. Model the system so it can take arbitrary stuttering steps but cannot alter any of these values; in particular the array’s contents, the index, and the constant that fixes the array length remain invariant. Specify as safety properties that the array remains equal to its initial mapping at all times, the index remains equal to its initial value at all times, and the element located at the index never changes. Also assert that the constant defining the array size is invariant. Include an explicit initial condition that assigns the array a concrete numeric mapping for all valid positions and assigns the index a concrete valid integer.
