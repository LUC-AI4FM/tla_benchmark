Specify a system that models a two-stage message transfer process between two buffers over a fixed number of rounds. The system maintains a multiset-like collection of distinct messages initially all placed in the first buffer and an empty second buffer. Repeatedly, individual messages may be moved atomically from the first buffer to the second buffer until the first buffer is empty; when the first buffer becomes empty, the contents of the second buffer are swapped to become the new first buffer and the second buffer is reset to empty, and a round counter increments. The system runs for a predetermined number of rounds and then stops making progress.

Formalize the state as the two buffers and a round counter plus a global message-transfer counter. Require that only messages from the initial finite set may ever appear in either buffer and that no message is duplicated or lost: at every state the union of the two buffers equals the original set of messages. Ensure individual moves transfer exactly one message from the first buffer to the second and increment the transfer counter; ensure the swapping transition occurs only when the first buffer is empty and increments the round counter. Specify safety properties (invariant that the multiset of messages is preserved, and that no duplicates are introduced) and liveness properties (eventual completion of each round and termination after the given number of rounds). Allow reasoning about symmetry under permutations of message identifiers.
