Specify a concurrent algorithm that computes the square of a nonnegative integer n by coordinating two cooperating tasks that update a shared variable x while a control index i progresses from 0 to n. The model should allow n to be any chosen natural number (including zero) and must capture only the abstract behavior and correctness goals, not any particular coding style.

Model two conceptual phases of progress: one phase where a task establishes that the current shared value equals i^2 for the current index i, and another phase where an action advances the index i by one while updating the shared value to match the new index. The system should start from a state representing i = 0 and x = 0, and it should permit interleavings of the tasks' steps. It must guarantee termination in a distinguished finished state in which i = n and x = n^2.

Require and verify the following safety properties: types and bounds of all variables are preserved; whenever the control is in the phase that asserts the current square, x equals i^2; whenever the control is in the advancing phase, x equals (i−1)^2 and i > 0; and upon reaching the finished state x equals n^2. Require and verify liveness: from any reachable state there is a possible sequence of steps that reaches the finished state (eventual termination). The specification should be suitable for model checking for small n and for reasoning about invariants and termination in TLA+.
