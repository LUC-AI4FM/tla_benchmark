Model Conway's Game of Life on a finite N×N toroidal board and specify its safety and liveness requirements.

The model should represent a square grid of N by N cells, each cell either alive or dead. Time advances in discrete synchronous steps where, at each step, the state of every cell is updated simultaneously according to the standard Life rules: a live cell survives only if it has 2 or 3 live neighbors; a dead cell becomes alive only if it has exactly 3 live neighbors. Neighbor counting wraps around the edges (toroidal topology) or alternatively provide an option to model non-wrapping boundaries that treat out-of-range neighbors as always dead.

Specify the initial state as an arbitrary assignment of alive/dead to all cells. Require the model to allow nondeterministic initial configurations and to evolve according to the deterministic update rule.

State and verify these correctness properties:
- Type correctness: the grid always maps each grid position to a boolean value.
- Update determinism: given a state, the next state is uniquely determined by the neighbor counts and the Life rules.
- Invariance: the set of live/dead labels remains within the boolean domain throughout execution.
- Conservation/monotonicity properties for given patterns: ability to assert and check that recognized still lifes remain unchanged, oscillators return to their initial configuration with a fixed period, and glider patterns translate with the expected period and velocity on the chosen topology.
- Progress property: for any finite configuration eventually reaching a previously seen state implies a fairness assertion for periodic behavior (formulate as liveness: there exist repeated states or cycles reachable from some initial configurations).

Allow the option to check bounded model properties (for given N and bounded time horizon) and to state invariants for proving absence of illegal transitions or miscounted neighbors.
