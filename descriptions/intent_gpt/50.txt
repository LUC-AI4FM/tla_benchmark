Specify a simple state machine that models a single integer-valued storage cell which can be initialized and updated. The system must allow the cell to hold any integer value initially and must permit transitions that change the stored integer to any other integer value. The specification should capture an initial condition that does not constrain the initial value beyond being an integer, and a transition relation that nondeterministically updates the cell to any integer at each step. Require that the model expresses safety and liveness properties for this simple storage: safety should assert that a chosen Boolean invariant predicate over the cell always holds (allowing the invariant to be instantiated later to either true or a specific property), and liveness should assert that from any reachable state the system can continue to make transitions (no deadlock). Also require the ability to express and check a trivial failing invariant to exercise the model checker’s counterexample reporting. Do not prescribe implementation details such as variable names or the specific syntactic form of transitions; focus on the semantic behavior and the correctness properties to be verified.
