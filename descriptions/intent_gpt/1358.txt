Specify a formal model of a tiny messaging setup between a fixed set of peers that can be used to reason about message creation and state evolution. The system has two distinct participants and models directed channels between every ordered pair of participants. Each channel holds an ordered sequence of messages. The only state is the mapping from each channel to its current sequence of messages.

Model a step in which any single channel may be atomically assigned a new sequence that contains exactly one newly created message; the message is a record identifying its kind (for example, a “hello” message). No other channel contents change in that step. The initial state maps every channel to the empty sequence.

Specify the safety properties that must hold at all times: channels are always sequences (never undefined), and each channel’s content equals exactly the sequence last assigned to it. Specify liveness properties to check that the system can always perform a step (i.e., it is never stuck) and that progress can be made repeatedly (infinite steps are possible). Also require that all state transitions are deterministic with respect to the effect on the chosen channel (a step fully overwrites that channel’s sequence with the single-message sequence). Do not prescribe any particular implementation or algorithm beyond allowing arbitrary choices of which channel is updated each step.
