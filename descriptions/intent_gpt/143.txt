Specify a simple state system that initializes a single integer-valued state variable to a fixed constant and then remains stable forever. The specification should model an initialization step that sets the variable to a particular constant value and a transition relation that allows no further changes to that variable. The model must treat the constant as an abstract, immutable value that can be defined once and used in the initialization action; it should be possible to substitute or rename that constant without changing behavior. The correctness properties to guarantee are: (1) safety — at every reachable state the variable equals the initial constant; and (2) stuttering invariance — all transitions are either stuttering steps or maintain the same value, so liveness properties that require eventual change must fail. Also assert that the state variable ranges over integers and that the constant is an integer so type-correctness can be checked. Include an explicit initial condition and transition relation, and state the invariants and properties to be model-checked, but do not prescribe how the model enforces immutability beyond the required semantics.
