Specify a simple state machine that models a system with a single integer-valued state and no meaningful state transitions (the state remains constant). The model should capture initialization and the absence of state change, and it should allow the use of generic binary operations as first-class parameters to be applied to integers.

Require the following behavior and correctness properties:

- Initialization: the state is set to a specific integer value (choose a concrete constant).
- Next-state relation: the state does not change in any step (the next-state value equals the current value).
- Operation application: provide a mechanism to apply an arbitrary binary integer operator to two integer arguments; the specification must be able to accept both named operator definitions and built-in arithmetic operators as arguments and produce the expected integer result.
- Assertions and checks: include properties that evaluate several example applications of the operation-application mechanism (for example, applying addition, a custom addition-like operator, and a custom subtraction-like operator) and assert that their results equal the expected integers. Each check should report success or fail clearly.
- Safety invariants: include an invariant asserting that the state remains equal to its initial value in all reachable states.
- The model should be purely declarative about what must hold; do not describe algorithmic steps of how operators are passed or invoked.
