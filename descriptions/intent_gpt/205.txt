Specify a formal model of a computation that produces successive Fibonacci numbers and a second, declarative definition of the same sequence, and require that the two agree at every step.

Model a discrete-step system that maintains a nonnegative integer index that advances by one on each step. The system must compute the Fibonacci sequence in two different ways concurrently: (1) an iterative process that updates a pair of integer accumulators to produce the next Fibonacci value, and (2) a reference definition of Fibonacci given declaratively by recursion (or an equivalent mathematical definition), defined for a fixed finite range of indices large enough to cover all steps the system may take. The system must initialize the index and both computations consistently with the usual Fibonacci base cases.

Specify the state space, initialization, and a single-step transition that increments the index and updates the iterative accumulators to the next Fibonacci number while also advancing the reference definition to index+1. Assert an invariant that the value produced by the iterative computation always equals the value given by the declarative definition for the current index. Also require that all numeric quantities remain integers and nonnegative, and that the reference definition is total over the permitted index range. Optionally include a bounded fairness condition ensuring the index continues to progress.
