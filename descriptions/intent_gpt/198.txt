Specify a simple state machine that models a single integer-valued state initialized to a fixed constant and then remains unchanged forever. The system must expose a constant parameter that determines the initial value; that constant should be constrained to a specific legal range. The model should capture an initialization step that sets the state equal to that constant, and a transition relation that does not modify the state thereafter. In addition, require an invariant property about the existence of some integer within a specified closed interval relative to the constant: the invariant should assert that there exists an integer in the interval from (constant + 1) to an upper bound such that that integer equals a particular target value. The specification must check that the initialization and transition rules always preserve this invariant for all behaviors, given the constraint on the constant. Also include a predicate that constrains the constant to a concrete numeric value so that model checking can be exercised. The goal is to verify that with the chosen constant and ranges the invariant holds initially and is preserved by the no-op transitions.
