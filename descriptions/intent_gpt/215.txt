Specify a system that models a higher-order repetition operator which applies a given unary operation repeatedly a fixed number of times. The model should treat the operation as an abstract function from integers to integers and the repetition count as a nonnegative integer literal constant. The system must accept any integer-returning operation and any concrete, finite repetition count, and it must compute the result of composing the operation with itself that many times, starting from a given integer initial value.

The specification must allow reasoning about the correctness of the repeated application: for any chosen operation f, any nonnegative integer n (a literal constant), and any initial value v, the repeated application should produce f^n(v) (the n-fold composition of f applied to v). It must ensure that when n = 0 the result equals the initial value, and when n > 0 the result equals f applied to the result of repeating f n-1 times. The model must admit concrete examples to validate this behavior and support proving that for a particular operation and literal count, the computed result equals an expected integer value. Specify invariants and properties that capture these identities and that rule out misinterpretations where the repetition count is not enforced as a literal constant.
