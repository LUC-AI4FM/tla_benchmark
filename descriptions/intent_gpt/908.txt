Specify a formal model of an unreliable asynchronous single-slot message channel that implements a simple two-way handshake for one-way data transfer. The system has a sender and a receiver that communicate through a single shared message cell holding one data value and two one-bit control signals. The sender should place a data value into the cell and toggle its send signal only when the channel is ready (i.e., when the send and acknowledge signals match). The receiver should observe a mismatch between the two control bits to detect a new message, read the data without modifying it, and toggle the acknowledge bit to indicate receipt. The channel must preserve the data value until the receiver has acknowledged it; the sender must not overwrite an unacknowledged message. The model should allow arbitrary interleaving of sender and receiver steps and nondeterministic selection of data values from a fixed data domain. Specify the initial condition that control bits are synchronized (no outstanding message) and the safety properties: control bits remain booleans, the sender only writes when allowed, the receiver only acknowledges on a detected message, and data is not lost or corrupted between write and acknowledgement. Also specify liveness properties ensuring that if the sender continuously attempts to send a fixed value, eventually the receiver will acknowledge it, and that the receiver does not starve indefinitely when messages are pending.
