Specify a formal model of binary relations on a finite set and the common algebraic properties used to classify them. The model should treat a relation as an arbitrary subset of the Cartesian product of a finite universe with itself and support predicates that determine whether a relation satisfies: reflexivity, irreflexivity, symmetry, antisymmetry, asymmetry, transitivity, partial order, strict partial order, total (linear) order, and strict total order. The model must allow querying each predicate for any given finite universe and arbitrary relation instance. It should also capture logical relationships among those predicates (for example, what combinations imply others, and which are mutually exclusive) so that consequences such as "a relation that is asymmetric is irreflexive and antisymmetric" and "a strict total order is asymmetric, transitive, and total" can be checked. Include the ability to construct example relations that either satisfy or violate particular properties so the predicates can be tested. The specification must state precise correctness properties: each predicate must return true exactly when the mathematical definition holds for the given universe and relation; implication facts among predicates must be provable within the model; and counterexamples should exist for non-implications. The model should be executable on small finite universes to validate the predicates and implications.
