Specify a simple cyclic counter system with one integer-valued state variable that evolves in discrete steps modulo a fixed positive modulus. The model should initialize the counter to zero and allow a single kind of step: increment the counter by one, then reduce it modulo the modulus so the value always stays within 0..modulus-1. The system must permit infinite execution where the step can be repeatedly taken forever.

Formally state the state space, initial predicate, and next-state relation without prescribing an implementation language. Parameterize the model by the modulus (a positive integer greater than zero) so different numeric moduli can be studied. Ensure the model captures stuttering (steps that leave the variable unchanged should be clearly excluded unless they are explicitly allowed by the chosen next-state relation). Specify the safety property that the counter value is always an integer within the range 0..modulus-1, and the liveness property that from any reachable state it is possible to eventually visit every value in 0..modulus-1 (i.e., the counter cycles through all residues). Also specify that all behaviors start from the given initialization and follow the increment-modulo transition relation for every step.
