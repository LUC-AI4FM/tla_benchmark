Specify a model of an algorithm that enumerates all k-element subsets (combinations) of the set {0, 1, ..., n-1} exactly once, producing them in a deterministic, lexicographic-like order. The model should treat each k-subset as a sequence of k strictly increasing integers drawn from 0..n-1 so that order is meaningful for representation and comparison, but correctness should be stated in terms of the underlying sets when appropriate.

The system must repeatedly produce the next k-subset until all k-subsets have been emitted, then terminate. It must never produce duplicates, must produce every k-subset exactly once, and must maintain that each produced sequence is strictly increasing and consists of k distinct elements in 0..n-1. The sequence order produced must be a total order consistent with the natural lexicographic order on increasing sequences: for any two consecutive produced sequences, the earlier one must be less than the later one by the standard prefix/first-difference comparison.

Inputs are parameters n and k with 0 ≤ k ≤ n and n, k are fixed for a run. The specification should include a precise definition of the expected set of all k-element subsets, a termination condition indicating when enumeration is complete, and invariants that assert no repetition, completeness (all expected subsets have been produced upon termination), and the maintained ordering relation between adjacent produced sequences.
