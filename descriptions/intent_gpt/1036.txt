Specify a small utility library for manipulating finite nonempty sets of integers that will be used by other TLA+ specifications. The model should define the abstract operations of computing the maximum and minimum element of a nonempty finite integer set, and must state their expected behavior and properties without prescribing a particular implementation technique.

The specification must require that the max operation always returns an element of the input set and that every other element of the set is less than or equal to the returned element. Symmetrically, the min operation must always return an element of the input set and every other element must be greater than or equal to the returned element. Both operations must be total on the domain of finite nonempty integer sets and must be undefined (or explicitly disallowed) on empty sets.

Include simple algebraic properties necessary for compositional reasoning: idempotence when applied twice yields the same element, invariance under singleton sets, and monotonicity under subset relationships where the subset remains nonempty (for example, the max of a subset is less than or equal to the max of its superset). State that these operators commute with integer translation (adding a constant to every element shifts the result by that constant) and respect negation symmetry between max and min. Also assert basic correctness lemmas useful for proofs that use these utilities.
