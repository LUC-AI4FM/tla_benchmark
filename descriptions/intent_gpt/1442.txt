Specify a simple finite-state counter system that repeatedly cycles through three states labeled 0, 1, and 2. The system starts in state 0 and at each step deterministically advances to the next numeric state modulo 3 (0 → 1 → 2 → 0 → ...). The model should expose predicates that identify when the system is in state 1 and when it has reached state 2, and should also allow defining predicates that are syntactically valid but semantically unreachable (for example, a predicate asserting the system is in an impossible state). The specification must support two modes: a normal liveness/step mode in which the transition relation is active, and a special “only-initial” mode in which no transitions are allowed so that only the initial states exist.

The correctness properties to verify are:
- Safety: the system never attains any state outside the set {0,1,2}.
- Progress (liveness): from any state there is a successor and the system infinitely often visits each of the three states (i.e., it cycles).
- Reachability assertions: state 1 and state 2 must be reachable as expected; an explicitly declared unreachable predicate must indeed never hold.
- In the “only-initial” mode, the model checker should treat action-level predicates as irrelevant to reachability but still report violations when expected (e.g., when an assertion about transitions would fail because there are no transitions).

Do not prescribe internal variable names or implementation structure; only describe behavior, initial conditions, allowed transitions, and the properties to be proved.
