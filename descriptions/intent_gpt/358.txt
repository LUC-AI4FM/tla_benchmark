Model a simple invariant-checking system that reasons about sets whose elements are 1‑tuples (singletons), and that verifies membership, existential properties, and projection-based equality tests over those tuples. The model should represent a state that does not change except for initial setup; it must initialize a boolean flag and a fixed finite set of one‑tuples containing the integers 1..4. The specification should assert the following correctness requirements:

- The set of one‑tuples must contain the one‑tuple whose single component equals 1.
- There must exist an element of the set whose first (and only) component equals 2.
- The invariant checks must be evaluated in a stable, non‑evolving system: once initialized, the state remains unchanged and the invariant conditions must hold for all reachable states.

Capture the semantics of one‑tuples and projection (accessing the sole component) as part of the model so that membership and existential queries over tuple components are expressed naturally. The specification should expose the invariants as properties to be checked by a model checker, and should produce clear success/failure signals for each invariant without prescribing any particular internal implementation of tuples or state transitions.
