Model a trace-to-vector-clock translation service that reconstructs per-process logical clocks from an execution trace of a concurrent system and emits them in a format suitable for visualization. The model should accept as input an ordered sequence of global states, where each state records each process's program counter (or other local progress indicator). From this trace, compute a vector clock for every prefix (state) such that:
- In the initial state all process clock components are zero.
- When the event at a state is a local action by a particular process, that process's clock component increases by one relative to the previous state while all other components remain unchanged.
- The vector clock for a state equals the pointwise sum of the initial clock and all per-state increments up to that state (i.e., clocks accumulate monotonically and reflect local events).
- The mapping identifies, for each transition between consecutive states, which process performed the event that caused the state change (or a special marker for the initial state).
Ensure the model preserves determinism of the reconstructed host-of-event choice given the two consecutive program-counter snapshots (it must choose a process whose local indicator differs between those states). Specify invariants that every computed clock is a mapping from processes to nonnegative integers, that clocks never decrease, and that the chosen host for each transition actually accounts for the single differing local indicator. Provide output conversion to a key-value object representation suitable for downstream visualization consumers.
