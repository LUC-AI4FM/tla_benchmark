Specify a state-machine model of a single integer-valued state variable that ranges over a finite natural-number domain, with an initial condition and a nondeterministic transition relation. The model should capture these requirements:

- The state variable must always remain within a prescribed finite set of natural numbers (a bounded numeric type).
- The system starts in a unique initial state with the variable set to that initial value.
- Transitions are nondeterministic but constrained by a small set of allowed kinds of updates. Each transition must map the current value to one of several explicitly permitted next values or ranges of next values, depending on the current value or independent of it. Some transitions should be unconditional assignments to a fixed value, some should permit the next value to lie in a contiguous subrange, and some should be guarded by specific current-state values (i.e., particular current values enable particular next values).
- The transition relation must permit choices that are sometimes contradictory with the bounded type (so the specification should ensure such choices are disallowed by the type invariant).

State the safety properties to verify:
- Type safety: the state variable never leaves the prescribed finite domain.
- Invariance of the initial value: the initial value remains part of a global invariant that must hold at all reachable states (i.e., the system should be checked against preserving a conjunction asserting type-correctness and that the variable equals the initial value).

Do not specify any particular implementation structure; express only the state space, initial condition, allowed next-state relations, and the invariants to be checked.
