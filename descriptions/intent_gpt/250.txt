Specify a formal model of a multiset (bag) abstraction and its basic operations over integers. The model should treat a bag as a finite collection of integer elements where elements can appear multiple times. It must include operations to add a single element to a bag, remove a single occurrence of an element, remove all occurrences of an element, compute the sum of all elements accounting for multiplicity, and compute the product of all elements accounting for multiplicity. The specification should state the intended semantics of these operations (add increases multiplicity by one, remove decreases multiplicity by one or has no effect if element absent, remove-all sets multiplicity to zero). For aggregate operations, define how empty bags are handled (sum of an empty bag is zero; product of an empty bag should follow a chosen convention and be clearly specified). Specify invariants and correctness properties: that add followed by sum/product reflects the added value, that remove preserves multiplicities for other elements, that remove-all eliminates the target element entirely, and that operations commute with standard multiset union or difference where applicable. Also require that all operations are total and deterministic on the chosen representation, and include representative test scenarios that validate behavior for present and absent elements, negative integers, and empty bags.
