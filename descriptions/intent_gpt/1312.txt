Specify a formal model of the classic "Die Hard" water jug puzzle parameterized by two jugs of fixed integer capacities and an unbounded water source. The model should describe a system state that records the current amount of water in each jug and an action indicator that selects the next operation. The allowed operations are: fill either jug from the source (to capacity), empty either jug to the drain (to zero), and pour from one jug to the other until the source jug is empty or the destination jug is full. Include an operation that models doing nothing or taking a structural/idle step if needed.

The specification must allow any nondeterministic sequence of operations starting from an initial state where both jugs are empty (or a specified initial fill). It must permit specifying an integer target volume and check whether the system can ever reach a state in which either jug contains exactly that target volume.

Key correctness properties to guarantee and check:
- Safety: Jug volumes never exceed their capacities and never become negative.
- Invariance: All state transitions preserve that jug volumes are integers within [0,capacity].
- Liveness/Reachability: If the target volume is reachable, there exists a finite sequence of allowed operations leading to a state with the target in one jug.
- Minimality/Termination (optional): Provide a way to reason about existence of a shortest sequence to reach the target (or show that no sequence exists).

Allow parameterization of jug capacities and the target, and support model checking of reachability and invariants.
