Specify a finite-state system that demonstrates and enforces a simple set-theoretic invariant about the number of distinct elements in a specific finite collection. The model should include a finite universe of values and a designated collection whose elements are sets drawn from that universe. The system should allow arbitrary state transitions provided they preserve finiteness, but the design must guarantee that the cardinality of the designated collection always equals a particular constant value (for example, 1). The specification should state the initial condition that establishes the invariant, describe what transitions are permitted in an abstract way (not by implementation), and require that every reachable state satisfies the invariant about cardinality.

Formally state the safety property that the size of the collection remains equal to the constant at all times, and include a liveness property that the system does not deadlock (i.e., some transition is always possible) unless the model intentionally models termination. Ensure the model is finite-state so that model checking is feasible. Provide assumptions needed about the universe (finite, nonempty) and about allowed operations on the collection (adding, removing, replacing elements only in ways that preserve finiteness), but do not prescribe a particular algorithm for maintaining the invariant.
