Specify a simple cyclic hour clock that models a 12-hour analog clock that advances one hour at each tick. The model should represent the clock’s observable state as a single hour value drawn from the set {1,2,...,12}. The allowed transitions must be that at each discrete time step the hour either increments by one if it is not 12, or wraps to 1 when it is 12. The system must start in a valid hour state and every reachable state must satisfy the invariant that the hour is always in the set {1..12}.

Formalize the notion of time steps (ticks) as an unbounded sequence of discrete transitions; no additional environment or nondeterministic actions are required beyond the tick that advances the hour. Specify initial conditions, the transition relation, and the usual temporal semantics (safety and liveness as appropriate). State and prove the following correctness properties: (1) Safety: the hour value is always within 1..12 (type/invariant preservation). (2) Progress/liveness: from any reachable state, the system will continue to make ticks forever (no deadlock of ticks); optionally assert that every hour value recurs infinitely often. Do not constrain internal representation choices beyond these requirements.
