Specify a simple state machine that models a single component whose state can be one of three distinct labels: A, B, or C. The system should start with the component in any of these three labels. At each step the component may nondeterministically transition to any one of the three labels (including remaining in the same label). Additionally, incorporate a debugging or testing mode that can abruptly disable all transitions when a global debugging level reaches a high threshold; when that threshold is reached, the system must perform no further state changes. The model should expose the initial condition, the allowed transitions, and the global interrupt condition as independent elements so properties can be checked under both normal and disabled modes.

Specify the following correctness properties to be verified:
- Safety: the component's state is always one of the three labels (never any other value).
- Liveness (under normal, non-disabled operation): from any reachable state, it must always be possible to eventually reach every label (A, B, and C) again (i.e., the system is strongly connected when not disabled).
- Disabled-mode quiescence: once the debugging threshold condition becomes true, the state must remain unchanged thereafter.
- Transition disabling monotonicity: once the system is disabled, it cannot re-enable itself without an explicit change in the global debug level.

Do not commit to a particular encoding of the debug-level check; treat it as an external boolean condition that can be toggled for verification scenarios.
