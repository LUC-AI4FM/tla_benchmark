Specify a simple 12-hour clock counter that models the behavior of an hours display which cycles through values 1..12. The model should represent the clock's state as the currently displayed hour and allow a single step action that advances the display by one hour. When advancing, the clock must increment the hour modulo 12 so that after 12 the next displayed value is 1. The model must allow any initial displayed hour to be any integer in the allowed range 1..12.

State the safety and liveness properties the system must guarantee:
- Safety: the displayed hour is always an integer in the range 1..12; no step can produce a value outside that range.
- Determinism of the step action: from any state there is exactly one enabled step that computes the next hour.
- Correct wraparound: taking one step from hour 12 yields 1, and for any hour h in 1..11 a step yields h+1.

Specify an invariant capturing the legal range and a step relation capturing the modulo-12 increment semantics. Also state a simple liveness property that every hour value will be reached infinitely often under repeated stepping (fairness / eventual reachability of each of the twelve hours).
