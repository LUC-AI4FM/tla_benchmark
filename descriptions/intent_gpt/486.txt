Specify a concurrent state machine with two integer-valued registers that evolve nondeterministically each step. The system should start with both registers initialized to zero. At each transition, either the two registers are simultaneously swapped, or a special update sets the first register to 1 while requiring that the second register takes the value 2. The model must allow both kinds of transitions to occur repeatedly and in any order, including back-to-back occurrences of the same kind.

Formalize the reachable-state space and prove key safety and liveness properties. Safety requirements: (1) both registers are always integers; (2) whenever the first register equals 1, the second register must equal 2 in the same state (i.e., the special update cannot leave the pair inconsistent); and (3) swapping preserves the multiset of register values. Liveness requirements: (4) from any reachable state, it must be possible to eventually perform either a swap or the special update (no deadlock); and (5) if the special update is continually enabled, it can occur infinitely often (fairness for that kind of step). Also state and check invariants characterizing all reachable pairs of values and show that repeated application of swaps and special updates cannot produce undefined or out-of-range values.
