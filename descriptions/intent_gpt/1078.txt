Specify a formal model of Dijkstra’s EWD998 distributed termination-detection protocol for a unidirectional ring of asynchronous processes. Model processes that asynchronously send and receive indistinct "work" messages and a circulating token used to detect global quiescence. The model must capture: process local state (active vs. inactive), a per-process taint flag that marks whether the process has become "black" (tainted) since last pass of the token, per-process counters that track messages sent minus messages received, and asynchronous FIFO channels between neighbors that can hold messages in flight. The token must carry a color (white/black) and an integer accumulator representing the sum of counters or queue contributions observed while the token traverses the ring. Processes may become active by performing local work that sends messages to other processes; they become inactive when they have no local work to perform. Message delivery is asynchronous and may be delayed arbitrarily but preserved (no loss or duplication). The token circulates sequentially around the ring; each process, when receiving the token, updates the token color/accumulator based on its taint and counters and may reset its taint and counters per the algorithm’s rules.

State the correctness properties to verify:
- Safety: Termination detection is only declared when all processes are inactive, all channels are empty, and the accumulators indicate no outstanding messages (i.e., global quiescence).
- Liveness: If the system actually reaches global quiescence (all processes idle and no messages in channels), then the token eventually completes a circulation that causes the algorithm to detect termination.
- No false positives: The algorithm must never declare termination while any message is still in flight or any process is active.
- Preservation: Message counts and channel contents evolve consistently with sends and receives (conservation of messages).

Include parameters for ring size and unbounded but finite channel capacities, and allow nondeterministic scheduling of process actions and message delivery. The specification should not assume synchronous steps or global clocks.
