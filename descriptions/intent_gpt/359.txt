Specify a simple two-variable state machine that evolves in discrete steps. The system has two integer-valued state components and starts with both initialized to 1. In each step, the state may either perform a specific increment transition for the first component or do nothing. The intended increment transition deterministically sets the first component to 2 (representing a single-step progression) and may also update the second component to 1; other transitions must be possible in which the second component remains unchanged. The model should allow stuttering steps that leave both components unchanged.

Formalize the allowed behaviors and require the following correctness properties:
- Safety: The first component is always a natural number, and every reachable state satisfies the invariant that the first component is at least 1.
- Reachability: From the initial state, a state with the first component equal to 2 and the second equal to 1 is reachable.
- Nontriviality: There exist at least two distinct reachable states (i.e., the system is not stuck in a single-state loop).
- Deterministic effect on first component: Whenever the transition that changes the first component executes, its new value must equal 2 (no other value is produced by that transition).
- Conditional consistency: Whenever the first component becomes 2 in a step, the second component must either be left unchanged or be set to 1 (both behaviors are allowed but the model must enforce one of these two outcomes when the first component changes).

Also include assertions or checks to detect violations of these properties during model checking, and permit printing/logging messages at key points for diagnostics.
