Specify a formal model of a simple two-variable state machine that repeatedly grows two set-valued state components and supports checks about operator application and action implication. The model should describe an initial state where each of the two state components is a specific singleton set. The transition relation must non-decreasingly update the first component by union with a fixed element and update the second component by union with a possibly different fixed element on every step. The specification should allow standard temporal reasoning (safety and liveness framing) using an Init and a Next relation and the usual always/next modalities.

Require the following correctness properties be expressible and verifiable:
- An invariant asserting that a particular high-level action predicate (representing “some action is enabled”) always holds in all reachable states.
- A safety property asserting that, at every step, a conjunction of two facts holds: one stating that a given state component remains unchanged by the action, and another stating that the primed value of a state expression equals the unprimed one (i.e., a specific equality relating next-state and current-state expressions). This safety property must be preserved by the transition relation.
- The model must permit abstraction of set and domain operators as first-class parameters to functions used in assertions, so that correctness can be checked with a variety of operator arguments (including standard set operators and user-defined prefix or postfix operator-like constructs).
- Provide ability to print or emit diagnostic messages at model setup time.

Do not commit to a particular encoding; focus on the system behavior, allowed operator argument abstraction, and the invariants and temporal properties to be proved.
