Specify a simple deterministic two-argument function on an abstract value domain and a tiny system that evaluates it. The function takes two inputs and returns one of them according to a membership test: if the second argument equals the singleton containing the first argument, the function returns the first argument; otherwise it returns the second argument. Model the domain as an uninterpreted set of values that supports equality. The system should allow arbitrary calls of the function with any pair of values from that domain.

Require a safety property stating that when the function is called with the concrete value 1 for both arguments it returns 1. Require that this property be invariant across any number of calls: every evaluation with those concrete inputs must yield the specified result. Also require that the function is deterministic: given the same pair of inputs it always produces the same output. Finally, specify no liveness constraints beyond termination of each individual function call; the model may nondeterministically choose inputs for each call but each call must complete and produce a result. Include types or simple domain constraints so analysis tools can check the invariant.
