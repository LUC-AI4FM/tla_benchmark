Model a reliable asynchronous FIFO buffer that connects a producer and a consumer through two unidirectional channels. The system must allow a producer to asynchronously send arbitrary messages into an input channel, the buffer to accept messages from that input channel and enqueue them at the tail, and a dispatcher to dequeue messages from the head and send them on an output channel for the consumer to receive. Channels should behave as abstract asynchronous message queues: sends append a message to a channel and receives remove a message from a channel; the buffer must interact only via these channel interfaces. The buffer itself must maintain an internal finite sequence representing queued messages and must not invent or lose messages: every message accepted from the input channel eventually appears on the output channel in the same relative order (FIFO). The system must permit interleaving of producer sends, buffer receives/sends, and consumer receives, and must be safe under nondeterministic scheduling.

Specify the initial condition, valid steps, and a temporal specification that enforces the buffer’s liveness: any message placed by the producer into the input channel is eventually accepted and delivered to the consumer, provided the consumer continues to receive. State invariants ensuring type-correctness of channels and that the internal queue always contains only messages of the allowed message type, and prove that these invariants are preserved.
