Specify a formal model of a deterministic sequence-filtering operator that takes a finite sequence of integers and a predicate over integers and returns the subsequence of elements that satisfy the predicate, preserving their original order. The model should treat the sequence and predicate as inputs and allow arbitrary finite sequences (including empty) and arbitrary decidable predicates on integers.

Require that the operator:
- Returns a sequence that contains only elements from the input sequence that satisfy the predicate.
- Preserves the relative order of selected elements as in the input.
- Produces an empty sequence when no input elements satisfy the predicate.
- Produces the original sequence when every element satisfies the predicate.
- Is deterministic: the same input sequence and predicate always produce the same output.

Specify additional sanity properties to check:
- Length monotonicity: the output length is at most the input length.
- Element correspondence: every element of the output appears at some index in the input and satisfies the predicate; conversely, every input element that satisfies the predicate appears in the output.
- Idempotence: applying the operator twice with the same predicate yields the same result as applying it once.

Model initial states and transitions only as needed to exercise and verify these properties; avoid committing to a particular implementation strategy.
