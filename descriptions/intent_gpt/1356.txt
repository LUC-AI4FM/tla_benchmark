Specify a model of a simple discrete-state counter system that repeatedly cycles through a fixed finite range of integer states. The system must initialize the state to the lowest value and then, on each step, either advance the state deterministically by incrementing until a maximum is reached and then wrap back to the minimum, or allow nondeterministic assignment of the next state within the allowed range (two alternative transition semantics should be expressible). The specification must permit plugging in parameterized predicate operators that take either a state value or another operator as an argument and evaluate safety properties over all reachable states. Support the ability to pass recursive boolean predicates as parameters (including ones that always hold and ones that fail for some inputs) and to pass externally supplied constant operators. Required correctness properties to check include:
- Invariant: the state always remains within the predefined finite range.
- Liveness: the system continues to make transitions indefinitely (no deadlock).
- Parameterized safety: for any supplied unary predicate operator, it is always true when applied to the current state (so the framework can assert and verify such predicates).
- Composition: nested parameterized operators must preserve the intended invariants when composed.
Also allow expressing trivial tautologies for sanity checks. The model should be amenable to model checking of the above properties.
