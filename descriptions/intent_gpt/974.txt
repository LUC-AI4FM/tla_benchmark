Model a concurrent system of N processes communicating through single-writer shared registers that are regular (not atomic). Each process repeatedly executes a simple three-step protocol: first it begins writing a value A to its own shared register, then completes the write so that the register eventually contains A, and finally it reads the register of its left neighbor and stores the observed value in its local state. The regular-register semantics must allow a read that overlaps one or more writes to nondeterministically return either the value that the register had before those writes began or one of the values being written by an overlapping write. Initialize every shared register to 0 and every local storage to 0. The model must allow arbitrary interleavings and overlapping of read and write operations consistent with regular registers.

Specify the safety property that if all processes reach termination (complete their read and transition to a terminated state), then at least one process must have read the value 1. Specify a progress/termination property asserting that it is possible for all processes to eventually terminate. Provide type invariants expressing that shared registers always hold a nonempty subset of {0,1} representing possible concurrent values, local storages hold 0 or 1, and process program counters are within the defined control states. The specification should be suitable for invariant and temporal-property proofs.
