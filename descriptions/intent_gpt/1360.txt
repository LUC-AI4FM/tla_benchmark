Specify a simple concurrent system that maintains a single shared boolean flag which may be nondeterministically set to either true or false at each step. The model should allow the flag to start in any boolean value and permit any sequence of subsequent boolean values, so long as each new value is a well-formed boolean. Do not constrain how or why the flag changes; the system should represent arbitrary interleavings or external inputs that may flip or hold the flag at each transition.

State the liveness and safety goals the specification must guarantee: safety — every state of the system must have the flag equal to either true or false (i.e., the flag's domain is always Boolean); liveness — from any reachable state, it must always be possible for the flag to assume either boolean value in some future step (the system does not get stuck with an inability to produce either value). Additionally, require that all behaviors are infinite sequences of states (no deadlock termination), and that step transitions only change the flag to a value that is itself a Boolean. Provide these requirements abstractly so they can be checked with temporal logic properties.
