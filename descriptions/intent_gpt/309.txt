Model a binary search procedure that searches for a target integer in a finite sequence of integers. The model should treat the input sequence and the search key as arbitrary but fixed values for each execution, and reason about all possible such inputs. The system must capture the usual binary-search control structure that maintains a low index and a high index and repeatedly narrows the search interval until it concludes whether the key exists in the sequence. It must allow for the sequence to be of any nonnegative length and for indices and arithmetic to be bounded by a fixed machine integer width.

Specify the algorithm’s required behavior, not any particular implementation: when the algorithm terminates it must indicate termination and produce a return value that is either a valid index where the sequence element equals the key or a distinguished value indicating “not found.” If the sequence contains the key at multiple positions, returning any one such index is acceptable. The specification must guarantee safety invariants: indices remain within legal bounds, the search interval always contains any index at which the key could still be located, and no out-of-range memory accesses occur. It must guarantee progress: unless already determined, the algorithm eventually terminates. Include a correctness property that if the algorithm reports an index, that index indeed points to an element equal to the key; and if it reports “not found,” then the key does not occur anywhere in the input sequence.
