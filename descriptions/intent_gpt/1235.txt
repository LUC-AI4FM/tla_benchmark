Specify a system that models a simple verifier that must produce two distinct diagnostic messages during system initialization: one message that is conditionally emitted when a given assertion holds, and another message that is always emitted regardless of conditions. The model should represent system startup and the emission of diagnostic output, but need not model actual I/O devices. It must capture whether each diagnostic message has been produced and allow checking of both messages' occurrence.

The specification must include states for "not-yet-emitted" and "emitted" for each message, and a startup transition that can optionally check a boolean condition before emitting the first message, while the second message is emitted unconditionally. The model must permit nondeterministic timing of emissions during initialization but ensure that, when the conditional assertion is true, the first message will be emitted at least once during startup. If the assertion is false, emission of the first message may be suppressed. The model should also allow observers to assert that the unconditional message is always produced.

Key correctness properties to specify: (1) Liveness: eventually the unconditional message is emitted in every execution; (2) Conditional liveness: if the assertion condition holds initially, then eventually the conditional message is emitted; (3) Safety: no spurious additional messages appear beyond those two; and (4) termination: startup completes after emitting the applicable messages.
