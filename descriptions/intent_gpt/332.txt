Model a simple validation and classification service that determines whether a person is legally licensed given only their two-digit birth year and a minimum licensing age threshold. The system takes as inputs an encoded birth year represented as an integer in the range 0..99 (representing years modulo 100) and a licensing-age threshold represented as an integer in a sensible range (for example 10..99). The model must compute whether the person has reached the required age in the current calendar year, where the current year is also represented in two-digit form and comparisons wrap at century boundaries. Specify how to interpret the two-digit birth year relative to the current two-digit year using a clear rule for mapping to an unambiguous age (for example, choosing the nearest past year consistent with expected lifespans, or using an explicit century pivot). The specification must state allowed input domains and produce a Boolean outcome "licensed" and, optionally, the computed numeric age. Key correctness properties: the computed age must be nonnegative and within plausible human limits; the licensed result must be true exactly when computed age >= licensing-age threshold; handling of century wrap must be consistent and deterministic; and for any valid inputs the model must not deadlock and must always produce an outcome. Include invariants expressing these properties and assertions that guard against undefined or out-of-range ages.
