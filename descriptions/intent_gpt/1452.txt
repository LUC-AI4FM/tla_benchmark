Specify a formal model of a system that assigns subsets of a fixed source set to a collection of targets, subject to a size constraint on each assigned subset, and that ensures controlled diversity of the assigned values across targets.

Model the following:

- There is a finite source set S and a finite collection T of targets. Each target must be associated with a subset of S whose cardinality is exactly a given parameter p (0 ≤ p ≤ |S|). Assignments are total functions from targets to p-sized subsets of S.

- The system must support enumerating or reasoning about the set of all such assignments and computing the set of distinct subsets actually used by an assignment (the image or range of the assignment).

- The model must capture and allow checking the property that the number of distinct subsets used by an assignment equals the minimum of |T| and the number of possible p-sized subsets of S. In other words, assignments should be able to achieve maximal diversity up to the combinatorial limit: either every target can receive a different p-subset, or diversity is capped by the number of distinct p-subsets available.

- Include constraints and invariants to ensure p-sized subsets are chosen from the power set of S and that the computed range and cardinalities are consistent with standard set semantics.

Specify these concerns abstractly so correctness properties (totality, subset-size constraint, and maximal achievable distinctiveness) can be mechanically checked.
