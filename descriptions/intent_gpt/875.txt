Specify a distributed algorithm that builds a shortest-path spanning tree rooted at a designated node in an undirected connected graph. The model should treat the graph as a fixed set of nodes and an arbitrary set of undirected edges; the graph may be nondeterministically chosen but thereafter static. Each node runs the same simple local protocol and maintains two local variables: a parent pointer that must always reference one of the node’s neighbors (or itself to indicate no parent), and a distance value that is intended to equal the number of hops to the root (or a special “infinite” value if the node is unreachable). Initially every node considers itself its own parent and has distance 0 if it is the root, otherwise the infinite distance. In each step, any node may adopt one of its neighbors as its parent if that neighbor currently advertises a strictly smaller distance, and it may decrease its distance to one more than the chosen neighbor’s distance (but not increase it). The algorithm should proceed asynchronously, with any enabled local update allowed to occur.

Require the model to guarantee these correctness properties:
- Safety: at all times, parent pointers point to nodes that are neighbors (or self), distance values are natural numbers, and for any node with finite distance > 0, its distance equals one plus the distance of its parent; the root’s distance is 0 and its parent is itself; unreachable nodes retain infinite distance and self-parent until a neighbor with finite distance appears.
- Convergence (liveness): from every initial state, the system eventually reaches a stable global state satisfying the postcondition that every node either is the root, is unreached (infinite distance and self-parent with all neighbors also infinite), or has a finite distance equal to parent-distance+1 and the parent is a neighbor. Ensure the model checks fairness so enabled updates are not permanently starved.
