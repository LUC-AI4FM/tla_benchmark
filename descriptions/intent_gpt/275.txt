Specify a simple concurrent system that models progression of time or steps where the system is always allowed to take a transition. The model should permit an infinite sequence of steps (liveness: there is always some action enabled), yet require an invariant that is impossible to satisfy. The specification should capture the notion that the system itself imposes no constraint on state evolution, while an external correctness requirement asserts a property that must hold at every reachable state but deliberately cannot hold.

Describe the state space broadly (it may be unconstrained or contain any values), allow a transition relation that always enables a next step from every state, and assert an invariant predicate that evaluates to false for all states. The model must include checks that exercise both safety and liveness reasoning: show that the invariant is required to hold at all times (safety requirement) and that the system nevertheless allows infinite progress (liveness requirement). The key correctness properties to state are (1) the invariant holds in the initial state and is preserved by every transition, and (2) the system is non-blocking (there is always a next transition). The specification should make explicit that property (1) is unsatisfiable so that model checking will report an invariant violation despite the system being live.
