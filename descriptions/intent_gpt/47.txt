Specify a model of a simple shared array object accessed by procedures and by direct reads, suitable for formal verification. The model should represent an array of fixed finite length containing integer values. It must allow initialization to a known concrete content and permit non‑destructive steps that leave the array unchanged. The system should include abstract procedure calls that accept a function as an argument and invoke it at a particular index to compute a result; these procedure calls are pure (no side effects) and must operate only by reading the array at the indicated index. Also include direct expressions that read a specific array slot.

The specification must state the intended behaviors (initialization and allowed transitions) and the interaction pattern between reading procedures and direct reads without committing to a particular implementation style. Key correctness properties to prove:

- The array’s contents remain within the initialized bounds and never change across any transition (invariance).
- Procedure calls that read a given index always return the value currently stored at that index (read consistency).
- Any expression that directly reads a slot yields the same value as a procedure that reads the same slot (observational equivalence).

Specify the state space, the initialization condition, the allowed transitions, and the temporal properties (safety invariants and observational equality) to verify these requirements.
