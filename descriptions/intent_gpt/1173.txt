Specify a simple labeling mechanism for associating an immutable constant with arbitrary payloads. Model a system that maintains an abstract label constructor which, given a fixed global constant and an input value, produces a label object that pairs the global constant with that input. The label constructor must always produce a deterministic, total function: for any allowed input value it yields a label consisting exactly of the current global constant and that input. The global constant is immutable for the entire run. The model must treat labels as abstract pairs and allow equality comparison: two labels are equal iff both their constant components and payload components are equal. Guarantee that labels preserve the constant component across all constructions and that the label construction is side-effect free and does not alter any other part of the state. Specify properties asserting determinism (same input always yields the same label), constancy (the constant component never changes), and compositionality (labels can be compared elementwise). Also include well-formedness constraints: the label constructor accepts only valid payloads from a specified domain and always returns a value in the label domain.
