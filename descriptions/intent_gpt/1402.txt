Specify a formal model of a two-component system where one component is a simple immutable state holder initialized to a concrete value, and the other component observes that state through a single-step temporal relation. The model should capture that the first component's state does not change after initialization, while the second component exposes a relation that looks at the next-state value of the observed variable. Require that the combined system must be expressible compositionally: the observer component is instantiated with the state holder as its parameter. The specification should assert and verify a safety property requiring that the observer's relation, when evaluated within the composition, can only produce a small fixed set of values (specifically 0, 1, or 2). Also ensure the model checks that this safety property is well-formed and enabled in the initial and all reachable states. Finally, include a liveness-friendly structure that leaves the state holder unchanged forever (no transitions that modify it), so that the verification focuses on the interplay between a constant state and an observer that refers to the state's next value.
