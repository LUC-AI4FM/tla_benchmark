Specify a model of an iterative computation that computes the factorial of a positive integer by repeatedly incrementing a counter and accumulating a product. The model should represent a bounded domain of inputs (a finite set of positive integers) and permit stepping the counter from an initial value up to a chosen maximum. It must maintain two independent representations of the factorial value: (1) a reference specification that defines factorial as a mathematical function (recursive or functional) on the finite domain, and (2) a computed accumulator that is updated iteratively as the counter advances. The system must initialize the counter and both representations consistently for the base case, then allow a transition that increments the counter by one and updates the accumulator accordingly.

Require the specification to guarantee that, for every reachable state with the counter in the allowed domain, the accumulator equals the reference factorial value for that counter (a safety invariant). Also require termination or bounded-progress reasoning: the counter should not exceed the specified maximum and it should be possible to reach the maximum in a finite number of steps. Finally, require that the reference factorial is only defined on the finite domain and that the model detects any attempt to step outside that domain as an error.
