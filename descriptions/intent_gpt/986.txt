Specify a TLA+ model of a distributed leader election algorithm that runs on an undirected, connected graph of uniquely identified nodes and guarantees eventual election of a single leader with termination detection. Model nodes that communicate only with neighbors by asynchronous message passing in rounds that alternate a "down" phase and an "up" phase. The protocol must propagate candidate identifiers outward during the down phase and aggregate responses during the up phase so that smaller identifiers win ties. To ensure progress and termination, include pruning rules in the up phase that (a) allow a sink node with only one incoming neighbor to become inactive and be removed, and (b) allow a node that received the same value from multiple incoming neighbors to non-deterministically keep exactly one incoming link for each distinct value while removing the other equivalent incoming links. Pruning actions must be signaled in messages so receivers can update local neighbor sets consistently even with in-flight messages.

Require invariants that maintain that every message references currently adjacent nodes except as allowed for in-flight reversals or pruning, that node kinds (source/ internal/ sink/ leader) are determined by incoming/outgoing neighbor sets, and that no mailbox contains more than one message per (phase, sender) pair. Specify correctness properties: eventual termination in a state where exactly one node (the minimum id) is isolated and declared leader, all other nodes are inactive, and all mailboxes are empty; safety properties preventing multiple leaders; and a formulation relating enabled transitions to termination (deadlock iff termination). Include liveness that the system eventually reaches the termination state.
