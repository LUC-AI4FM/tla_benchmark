Specify a model of the two-jug "water jug" (Die Hard) puzzle as an abstract state machine. The system has two containers with fixed integer capacities: a smaller jug and a larger jug. The state is the pair of current integer volumes in the two jugs. The model must include the following nondeterministic state transitions that any step may perform: fill either jug to its capacity, empty either jug completely, or pour from one jug to the other until either the source is empty or the destination is full. All operations are instantaneous, atomic, and deterministic in their effect given the current state. The initial state has both jugs empty.

Specify the goal predicate(s) that express reaching particular target volumes in either jug or a combination (for example, one jug containing exactly a given amount). Allow the target(s) to be parameters of the specification.

State the essential correctness properties to verify:
- Safety: jug volumes never exceed their capacities and are never negative.
- Invariance: every reachable state respects capacity constraints.
- Liveness: if a target volume is reachable under the allowed operations, then there exists a finite sequence of operations that reaches a state satisfying the target (i.e., reachability/existence of a plan).
- Termination/Progress: when a target is reached, the model records success and does not require further changes to satisfy the goal.

Do not hard-code any particular capacities or targets; make capacities and targets parameters so the model can be checked for arbitrary integer capacities.
