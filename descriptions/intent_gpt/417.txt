Specify a simple, single-variable system that initializes a state to a fixed value and then stays constant forever. The model should capture an initial condition that assigns the one state variable a known integer value and a transition relation that performs no updates (i.e., leaves the state unchanged). The specification must allow checking that the variable's value belongs to the intended type set (for example, a singleton set containing that integer) and that the only reachable state is the initial state.

Additionally, require a set of lightweight, deterministic assertions that exercise function/map selection and value lookup semantics: evaluate constant maps and indexed function values, including lookups by numeric keys, tuple keys, and map entries; verify that modifications to maps via single-point updates yield expected lookup results; and ensure nested-map and tuple-indexing behave as specified. These checks should not alter the system state but must be expressible as Boolean invariants that must hold in every reachable state. Specify overall correctness properties: type safety (the variable always has the declared value), invariance of the state (no transition changes it), and validity of all lookup/assertion checks. Make the model small and deterministic so a model checker can exhaustively verify the invariants.
