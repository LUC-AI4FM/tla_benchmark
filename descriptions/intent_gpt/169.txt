Specify a simple integer counter system that starts at a fixed initial numeric value and, on each step, deterministically decrements by one. The model should allow the counter to take any integer values but should also express an expected safety property that the counter stays nonnegative at all reachable states. The specification must capture the initial condition, the transition relation that decreases the counter by exactly one each step, and the invariant condition asserting the counter is greater than or equal to zero.

Additionally, include liveness-like reasoning to clarify expectations about eventual behavior: either state that the system may continuously decrement forever (allowing eventual negative values unless prevented by the invariant), or strengthen the model so that execution stops when the counter would become negative. The specification should make explicit which interpretation is required.

Formulate correctness properties to check: the safety invariant (counter never negative), consistency of the initial value with the invariant, and that every step respects the single-decrement rule. Also request model checking with sufficient bounds to explore runs that would violate the invariant under the infinite-decrement interpretation, and include an option to assert termination when the counter hits zero.
