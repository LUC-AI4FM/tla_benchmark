Model a simple discrete-state control system with three independent components that evolve in lockstep steps. The system initially sets one component to a specific initial value while others may start arbitrarily. On each step, exactly one designated component may change, and its allowed next values are constrained to a single specific value. Additionally, disallow transitions where another particular component would simultaneously move into one forbidden value while it currently holds a particular disallowed value. The model must treat the other components as unconstrained except for the above restrictions.

Specify the behavior as an infinite-state transition system with an initial condition and a Next-state relation that enforces the single-component update and the forbidden simultaneous-update pattern. Require temporal fairness to ensure the system proceeds with steps indefinitely (i.e., use the usual weak fairness on the Next relation) and that invariants can be checked over all reachable states.

Key correctness properties to guarantee:
- Safety: the designated component only ever takes the one allowed next value and its initial value is the specified start.
- Safety: the disallowed simultaneous transition never occurs.
- Liveness: the system does not deadlock — from any reachable state there is some allowed Next transition.
- Optional property: reachability or eventuality assertions about specific target states of the components.
