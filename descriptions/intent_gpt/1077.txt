Specify a formal model of a distributed termination-detection protocol for N processes arranged in a unidirectional ring, implementing Safra’s token-based algorithm. The model should capture asynchronous message passing (payload messages and a circulating special token), local process states (active/inactive), local counters that track outstanding sends, and a two-valued local “color” marker used to record whether a process has sent work since last seeing the token. The system must allow arbitrary sending and receiving of payload messages between any processes and must allow processes to become inactive. Exactly one special token circulates around the ring, carried in messages; a process may hold and forward the token only when it is inactive. When the token makes a full round under certain conditions it should indicate global termination.

Specify the safety property that the protocol never declares termination while some process is active or there are undelivered payload messages. Specify the eventual-detection liveness property: if the system truly reaches quiescence (no in-transit payload messages and all processes inactive), then the token circulation will eventually lead to a global termination declaration. Include invariants needed to reason about correctness: conservation/consistency between local counters and the number of outstanding payload messages, monotonicity constraints on token metadata accumulation, and that at most one token exists. The model should be parameterized by N (N ≥ 1) and allow proofs (or checks) of the stated safety and liveness properties.
