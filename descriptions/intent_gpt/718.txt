Specify a formal TLA+ model of finite directed graphs and a library of common graph queries and predicates. The model should treat a graph as a finite set of nodes together with a finite set of directed edges (ordered pairs of nodes). It must provide deterministic, purely functional operators (no hidden state) that compute: neighbors reachable by a single outgoing or incoming edge; the union of two graphs; all nodes reachable from a given set via repeated outgoing edges; all nodes that can reach a given set via repeated incoming edges; ancestors and descendants of a node (transitive closure in incoming and outgoing directions); roots (nodes with no incoming edges) and leaves (nodes with no outgoing edges); whether two nodes are connected (there exists a directed path); simple paths and the set of all simple paths in a graph; and whether a graph is a directed acyclic graph (DAG) and whether it is bipartite with respect to two given partitions. Require these operators to be total on the domain of finite graphs and to return values of sensible types (sets of nodes, booleans, sets of tuples). Specify correctness properties and unit-test style assertions: specific small-example graphs should yield the expected results for each operator (including empty graphs, single-node loops, cycles, and simple chains). Ensure definitions are consistent (e.g., the connectivity predicate equals membership in the computed connections matrix).
