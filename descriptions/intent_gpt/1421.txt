Specify a concurrent state machine that models a simple shared-variable system with one integer-valued state variable that can take a small finite set of distinct values. The system must describe an initialization choice that may start the variable in one of two distinct initial states. After initialization, the system should allow only a limited set of state transitions: one set of transitions that moves the variable nondeterministically between two specified values, and an extended set that additionally permits a third distinct value. The specification must capture both safety and liveness constraints:

- Safety: it must be impossible to violate invariants that express that once the system reaches certain designated states, certain other states are thereafter forbidden or permanently stabilized. Express safety properties that prevent undesired oscillations between specific pairs of values and that establish eventual permanence of particular values when entered under specified conditions.

- Liveness: it must express weak fairness for the basic transition relation so enabled transitions cannot be continuously ignored, and include at least one reachability (leads-to) requirement asserting that starting from a particular initial value the system must eventually enforce a persistent condition about another value (for example, once that value is reached it remains true indefinitely).

Model the state space explicitly, allow nondeterministic choices for transitions, and require checking of both invariants (safety) and liveness (weak fairness and leads-to) properties. Do not prescribe an implementation strategy or control flow; state only what behaviors are allowed and what correctness properties must hold.
