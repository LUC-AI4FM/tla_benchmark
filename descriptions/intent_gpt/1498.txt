Specify a simple two-action toggle system with a single boolean state that can be switched repeatedly. The model should represent a system whose state is a single boolean value that initially equals FALSE. At each step the system nondeterministically performs one of two equivalent toggle operations that flip the boolean value. The specification should express the initial condition, the allowed state transitions (either toggle action may be chosen at any step), and that time is unbounded so the toggling can continue indefinitely.

Capture the liveness requirement that the system never gets stuck: from any reachable state there is always a next action available. Capture safety properties that must always hold: the state is always a boolean and each transition indeed flips the value. Also require fairness that prevents one of the two actions from being permanently ignored (e.g., both actions should be weakly fair or at least the set of actions should be treated fairly so that neither is starved).

Finally, state correctness properties to check: reachable states alternate between FALSE and TRUE, and every reachable state is either FALSE or TRUE (no other values), and that the system does not converge to a fixed point where toggling stops changing the value.
