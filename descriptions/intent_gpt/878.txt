Specify a distributed algorithm that computes a rooted spanning tree of an undirected graph. The system inputs are a finite set of nodes, a set of undirected edges (no self‑loops, at most one edge between two nodes), a distinguished root node, and a numeric bound at least as large as the number of nodes. The algorithm must produce, for every node reachable from the root, a parent pointer pointing to one neighbor such that following parent pointers from any reachable node reaches the root; unreachable nodes must point to themselves. Each node must also maintain a finite numeric distance value equal to its hop distance from the root (or equal to the given bound for unreachable nodes). The distributed solution should operate by asynchronous message passing: nodes learn neighbors’ distance values only via messages. The root initially announces its distance zero to neighbors; thereafter a node that changes its distance must send its new distance to all neighbors. The algorithm must guarantee safety: whenever no more local steps are enabled (the system has quiesced), every node’s parent and distance satisfy the spanning‑tree and distance conditions above. It should also guarantee termination (or progress) under fair scheduling: if repeated local steps are enabled, the system eventually quiesces, and upon quiescence the postcondition holds. Do not describe internal implementation details; instead specify the required state, messaging behavior, and the correctness properties (safety and liveness) the model must satisfy.
