Specify a concurrent/state-transition system that models a small, deterministic state space manipulated by atomic steps, and state the expectations about which expressions must remain unchanged across steps. The system has a fixed finite collection of indexed data elements and at least one scalar counter. Initial state: each indexed element is initialized to a distinct known value and the counter to a known value. Transitions either leave the whole state unchanged (stuttering steps) or increment the counter while keeping every indexed data element unchanged.

Require the specification to expose and allow checking of the semantics of "unchanged" for a variety of expressions derived from the indexed data: individual indexed elements, records constructed from those elements, existential and universal predicates over indices, choice expressions that pick an index satisfying a predicate, sets formed by comprehension of element values, set comprehensions using quantified predicates, and the domain of the indexed collection. The model must permit assertions or checks that each of these expressions is indeed unchanged whenever the underlying indexed elements are unchanged, and must allow distinguishing cases where an expression is syntactically different but semantically constant.

State correctness properties: invariants asserting initial values and that any step that modifies the counter does not change any indexed element; properties asserting that all listed derived expressions evaluate to the same value before and after any transition that leaves the indexed elements unchanged; and safety conditions that flag if any derived expression ever changes while the indexed elements do not. Include liveness trivially (e.g., transitions are always enabled) only if needed for model checking.
