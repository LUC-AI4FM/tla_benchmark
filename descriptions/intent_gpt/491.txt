Specify a concurrent-state system with two integer-typed state components that evolve in discrete steps. The model should start from a single initial global state where both components equal zero. At each step, one of two kinds of updates may occur: either the two components swap their values simultaneously, or the second component is reset nondeterministically to one of a fixed finite set of small integers while the first component is set to a fixed constant value. The choice between these alternatives is nondeterministic and must be allowed whenever enabled.

Require the specification to expose the state-transition relation and the temporal behavior so safety and liveness properties can be stated. Guarantee invariants that characterize reachable values: for example, the components should always remain integers and, when the second component is set from the small fixed set, the first component must equal the fixed constant after that step. Assert that the initial state satisfies the given initial values and that every transition preserves the allowed update patterns. Provide checks for two key correctness properties: (1) a safety invariant forbidding illegal values or illegal combinations not obtainable by the allowed transitions, and (2) a reachability/liveness property ensuring that from the initial state it is possible to perform the swap action and to perform the reset action (i.e., both action types are eventually reachable in some execution).
