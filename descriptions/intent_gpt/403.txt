Model a simple state-transition system with a single integer state representing a counter. The system must start in a fixed initial state with the counter equal to a particular positive integer. At every step the system nondeterministically performs a transition that results in the counter taking a new value that must satisfy several arithmetic and set-theoretic relations relative to that new value (not the old one). The specification must require that the new counter value equals the fixed initial integer and is strictly greater than 1. It must also require that the inclusive range from 1 to the new value corresponds exactly to the two-element set {1,2}, that adding 1 to each element of the singleton set containing the new value yields the singleton {3}, and that filtering the singleton containing the new value for equality with 2 yields the singleton {2}. The specification must assert the existence of an element equal to 2 inside the singleton set containing the new value, and must assert the existence of an element in the range 1..newValue that is strictly less than the new value. Finally, include a trivial invariant that always holds (true) so the model checker can exercise invariants without imposing additional constraints. Specify the desired temporal behavior and safety properties so that every reachable state satisfies the listed relations about the new counter value.
