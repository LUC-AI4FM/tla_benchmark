Specify a simple discrete-state system that maintains a finite partial function mapping a fixed small integer domain to integer values and repeatedly either leaves the mapping unchanged or updates each mapped value by adding its key. The model should initialize the mapping to the identity on the domain {1,2}. The system should permit two kinds of steps: a stuttering step that does not change the mapping, and an update step that simultaneously replaces every value in the domain by its current value plus the corresponding key. The specification must expose the mapping as an observable state for model inspection.

Formally state the safety property that the value associated with key 1 is never equal to 2 in any reachable state. Also specify invariance checking of this property; the model checker should be able to verify whether the property holds from the given initial state under all allowed transitions. Additionally, allow the model to be checked under full state exploration (no fairness constraints are required). Ensure the model is abstract and independent of any particular implementation detail, focusing only on the mapping, its initialization, the two transition kinds, observability of the mapping, and the stated invariant.
