Specify a model of a system that maintains a single total function from the (mathematical) integers to integers. The system initializes that function so that every integer maps to 0 except one distinguished key, which must map to 42. After initialization the function does not change. The model should allow reasoning about functions with infinite (countably infinite) domain, treating the mapping as a total function on integers, not as a partial map or a finite table.

The specification must state the initial condition that enforces the described infinite default mapping with the single exception value and must include a next-state relation that leaves the function unchanged thereafter. The key correctness property to verify is an invariant asserting that the distinguished integer indeed maps to 42 in all reachable states. The model should also enable checking that the function is total over integers and that the default value for all other integers remains 0. The specification must avoid relying on any finite enumeration of domain elements and should be suitable for model checking or theorem proving tools that can handle operations on infinite domains.
