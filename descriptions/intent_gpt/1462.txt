Model a simple counter system that maintains a nonnegative integer counter and a boolean flag. The system must start with the counter at zero and the flag set to false. At each step, the system nondeterministically performs either an increment or a decrement operation: an increment increases the counter by one; a decrement decreases the counter by one but is allowed only when the counter is strictly positive. Each operation flips the boolean flag. The counter must always remain a natural number (no negative values).

Specify the following correctness requirements. Safety: the counter must never reach or exceed a given fixed upper bound. Liveness: it must always be possible for the counter to eventually reach that upper bound (i.e., from every reachable state there exists a future execution where the counter attains the bound). Fairness: ensure that the increment operation is treated fairly so that it cannot be indefinitely disabled by the scheduler; this fairness should be strong enough to guarantee the liveness requirement where applicable. Additional invariants: the boolean flag should always be a well-defined boolean and should flip on every state transition. The specification should allow reasoning about reachable states, preserve stuttering equivalence for steps that do not change the observable variables, and enable checking both safety and liveness properties separately and together.
