Specify a concurrent bounded open-addressing hash table with fingerprint entries and an external overflow log, used by multiple concurrent insertors and readers. The model should capture the abstract behaviour (not a particular implementation) of: (1) concurrent insertion attempts that probe up to L alternate positions for a fingerprint before giving up; (2) a single eviction procedure that compacts and sorts the in-memory table and moves selected fingerprints to an external, ordered storage when the table is "full"; (3) readers that check for a fingerprint by probing the same sequence of positions and consult the external storage if probing stops at an empty or marked slot. Probing is deterministic and bounded; the external store is append-only and maintains an ordering invariant relative to what is evicted.

The specification must ensure the following correctness properties:
- Safety: Every fingerprint that a reader reports as present (found in table or external) must have previously been successfully inserted (no false positives from non-inserted elements). Every inserted fingerprint eventually becomes visible to readers (either in table or external).
- Linearizability of insertion with respect to a single atomic compare-and-swap primitive on table slots (model CAS as atomic per-slot): each successful insert must have a single linearization point consistent with CAS success; failed insert attempts do not produce spurious history entries.
- Mutual exclusion for eviction: at most one eviction runs at a time; while eviction is in progress, writers and readers coordinate so that they either wait or observe consistent intermediate states (no lost or duplicated fingerprints).
- Preservation of ordering invariants: the in-memory compaction/sort must preserve a well-defined relative order so that items moved to external appear in nondecreasing order and readers can rely on that ordering for correctness.
- Liveness: assuming a fair scheduler and that CAS can eventually succeed, every insertion will either complete by placing the fingerprint in the table or complete by causing/observing an eviction that moves it to external; readers eventually terminate on each lookup attempt.

State the abstract data domains (finite table of K slots, fingerprint universe, special empty/marked values), the allowed atomic operations (per-slot CAS, atomic set of an eviction flag), and the allowed interference patterns (concurrent writers and a reader with the single evictor). Specify invariants to enforce the safety and ordering requirements and the linearization points for operations, without prescribing the concrete sorting or loop structure used to achieve them.
