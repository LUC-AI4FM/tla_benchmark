Model a fault-tolerant consensus protocol among N processes that uses a two-phase broadcast to try to agree on a value equal to the maximum of proposed inputs when a particular condition holds. The model should capture asynchronous message sending and reception, crash faults (up to F faulty processes), and the following high-level behavior: in phase one, each noncrashed process broadcasts its input; after receiving sufficiently many phase‑one messages, it computes a local estimate based on the maximal value seen; in phase two, processes broadcast their estimates along with the value they expect others to have; upon collecting sufficiently many phase‑two messages, a process either decides a value that is supported by a large quorum or, if it has heard from every process, deterministically chooses a value from its view. The specification must permit processes to crash at any time, limited by the bound F, and must model unreliable delivery only insofar as messages can be delayed but not forged.

Require the following correctness properties to be specified and checked:
- Validity: any decided value must equal some process’s original input.
- Agreement: no two noncrashed processes decide different values.
- Termination: under the protocol’s condition that more than F processes propose the global maximum input, every noncrashed process eventually decides.
Also specify safety/typing invariants for message and state formats and ensure liveness assumptions that allow processes to eventually receive the needed quorums of messages unless crashed.
