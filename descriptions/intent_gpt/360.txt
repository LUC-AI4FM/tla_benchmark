Specify a stateful system that manipulates values of several data-typed components — a record/dictionary with two named fields, a finite sequence of two integers, a finite set of small integers, a finite function/mapping defined over a small integer domain, and a nested mapping built from pairs. The system should begin in a single concrete initial state in which each component has a given literal value, including one component built by a comprehension and another constructed by an exception-like update of a nested mapping. The model must treat comparisons between sequences and functions/records in a way that reveals equality or inequality as appropriate (i.e., sequence values should compare equal to explicitly built sequences even if obtained from a comprehension).

Allow nondeterministic transitions that either leave the global state unchanged or update exactly one component at a time. Valid updates must include: reassigning the record/dictionary to an equivalent literal representation; replacing the sequence with various equivalent sequence constructions (concatenation of one-element sequences, indexed function-to-sequence constructions, and exception-like updates), including constructions that are syntactically different but semantically equal; setting the set component to several equivalent set expressions (explicit listing, interval/range expression, set-comprehension with arithmetic, and domain-of-sequence expressions); replacing the function component by another function with equivalent mapping; and updating the nested mapping by incrementing an inner element via an exception-style update. The specification should assert an invariant that always holds and make explicit that the state space contains exactly one canonical initial state. Key correctness properties: only the allowed single-component updates occur; semantically equivalent expressions are treated as equal states; no other state mutations are reachable; and the invariant holds in all reachable states.
