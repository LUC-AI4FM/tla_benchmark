Specify a model of finite, statically constructed functions as first-class values, where functions may have non-primitive domains and codomains (including sets and other functions). The model should allow constructing functions from explicit finite sets of argument–result pairs and treating those functions as values that can be used as arguments, keys, or results of other functions. It must support checking domains, applying functions to valid arguments, and comparing functions for equality based on their graph of pairs.

Requirements:
- Provide a way to represent a finite function by an explicit finite set of (argument, value) pairs.
- Ensure function application is defined exactly for arguments in the function’s domain and returns the associated value.
- Support domains that are heterogeneous structures, including sets, tuples, strings, integers, and other finite functions.
- Support functions whose codomain elements may themselves be functions, enabling higher-order use and using functions as keys in other functions.
- Guarantee that domain membership and function equality are determined by the set of pairs (i.e., extensional equality).
- Include a simple initial configuration with several distinct finite functions (including a function from strings to integers, a function from sets to integers, and a function that maps function-values to strings) and invariants asserting their domains and per-argument values.
- Assert invariants that rule out unintended modifications (i.e., functions remain constant across steps) and validate correct behavior of domain, application, and equality properties.
