Model a simple state system that maintains a single Boolean state which is initialized to true and never changes. The goal is not to exercise concurrency or complex state transitions but to verify correct reasoning about one-element tuples (1‑tuples) and operations over small finite sets of such tuples. Specify a finite set consisting of one‑tuples containing integer elements drawn from a known small domain. Provide expressions and queries that must be provably equivalent to expected values: membership of a particular one‑tuple in the set; existence of a one‑tuple with a given element value; extraction of the element from a one‑tuple; comprehension that filters the set by element value; concatenation of two one‑tuples into a two‑tuple; and construction of a function over the one‑tuple set that maps each one‑tuple to its element plus one, with correct lookup behavior for a specific key. The specification should assert these properties as invariants of the system so that model checking will report any mismatches. Include informative failures/messages for each property so that a counterexample clearly indicates which one‑tuple operation failed. Do not prescribe a particular encoding; instead require the model to support standard tuple membership, indexing, concatenation, set comprehension over tuples, existential quantification, and function application semantics.
