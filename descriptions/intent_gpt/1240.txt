Specify a formal specification of the classic Euclidean algorithm for computing the greatest common divisor (GCD) of two positive integers. Model a single-process, terminating algorithm that starts from two input integers chosen nondeterministically from 1..MaxNum and repeatedly reduces them by replacing the larger by its difference with the smaller until one becomes zero. The specification should:

- Represent initial inputs as arbitrary values in the given input range and record them as immutable input parameters.
- Evolve a pair of nonnegative integers that at every step preserve the invariant that the GCD of the current pair equals the GCD of the initial inputs.
- Allow only the standard reduction step that subtracts the smaller from the larger and an eventual termination when one component becomes zero; when one component is zero, the other must equal the GCD of the original inputs.
- Ensure termination: from every reachable state the system must eventually reach a state where one value is zero (no infinite subtraction loops).
- Include an assertion or property that at termination the remaining nonzero value equals GCD(initial1, initial2).
- Specify safety properties: values remain within the natural-number domain and the GCD invariant holds in all states.
- Specify liveness: the algorithm makes progress toward termination (e.g., a well-founded measure decreases) and eventually terminates for all allowed initial inputs.
