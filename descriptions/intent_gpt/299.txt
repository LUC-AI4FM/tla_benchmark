Specify a formal TLA+ model of an in-place binary search procedure over a fixed-size, indexed array of integers with machine-word arithmetic bounds. The model must treat the array and the search key as inputs and must account for wraparound and bounded integer arithmetic determined by a given bit width. Model the algorithm’s iterative search over a closed interval [low, high] that is initialized to cover the whole array and that repeatedly inspects a middle element and narrows the interval until the key is found or the interval is empty.

The specification must capture all legal executions (including stuttering once the algorithm has terminated) and must ensure array accesses never occur out of bounds for any reachable mid calculation under the bounded arithmetic semantics. It must express the expected outcome: when the procedure terminates, it must report a nonnegative index exactly when the key exists in the input array (and that index must refer to an occurrence), and must report a negative value when the key is absent. Also capture a weaker postcondition that allows the implementation to return a correct result whenever the input array is sorted, while still permitting arbitrary behavior on unsorted inputs.

Additionally, include progress and termination requirements: show that the search reduces the search interval on each nonterminating step and that termination occurs within a bound derived from the integer bit width. State safety properties (bounds checking, preservation of unchanged variables across steps that do not modify them) and liveness properties (eventual termination under the contracted-interval assumption). Do not prescribe a particular control structure—only the state space, transitions, and required invariants and properties.
