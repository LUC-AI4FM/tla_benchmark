Specify a stateless test harness that models and checks the semantics and typing of nested record and function constructions, membership, and element updates. The model should describe a simple universe of integers and booleans and define a collection of constant record and function values built from literals, comprehension-based functions, nested records, and records whose fields are themselves functions or records. It must express queries that test field selection by name and by string key, nested field access, and function application using tuple indices. It must express non-destructive updates that yield new records (functional update expressions) and verify that unchanged fields remain the same while updated fields take the new values. It must define set and dependent-record types (records whose fields range over specified sets) and verify membership and subset relationships between records and those types, including counting cardinalities of product-like record spaces. It must assert properties such as specific numeric field values, containment or non-containment of particular records in specified sets, universal properties over sets of records, and that cardinalities of particular sets equal expected counts. The specification should expose any violation as an explicit assertion failure and otherwise indicate success for each test. The model should not encode an algorithmic transition system beyond a trivial single-state initialization.
