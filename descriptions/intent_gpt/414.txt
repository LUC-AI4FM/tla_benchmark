Specify a simple state machine that models a system with an initial condition imported from another module and a single state variable whose only allowed transition is to take a fixed constant value. The model should capture: an initial predicate that may be defined externally (treated as part of the specification); a deterministic step that assigns the designated constant to the state variable and no other state changes; and an invariant that checks whether the state variable equals that constant in every reachable state, producing an explicit success/failure indication when evaluated. The specification must ensure liveness is trivial (every step leads to the constant) and safety requires the variable never takes any value other than the constant after the first transition. Include the ability to treat the constant as a parameter of the model. The correctness properties to verify are: (1) from any initial state allowed by the external initialization, all reachable states satisfy the invariant that the variable equals the constant; (2) the next-state relation deterministically establishes the constant; and (3) no other transitions are possible. The model should be suitable for model checking these safety and determinism properties.
