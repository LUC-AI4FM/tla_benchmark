Specify a model of a simple state machine that manipulates three kinds of abstract resources: a token drawn from an abstract set of user-type values, an item drawn from an abstract set of pair-type values, and a textual label describing the current phase. The system starts in an initial configuration with: no user-type tokens held, the pair-type item set containing a single designated item, and the label set to an initial state string. It must offer a single transition that atomically swaps those holdings: after the transition the user-type token set contains a single designated user value, the pair-type item set becomes empty, and the label is updated to a next-state string.

Model the domain constants abstractly so their concrete identities and types are not assumed; treat them only as distinct abstract values belonging to appropriate domains. Specify that the only allowed behaviors are repetitions of the initial choice followed by zero or more applications of the single transition.

Formally state and check an invariant that asserts the designated user-type constant and the designated pair-type constant are equal. The specification should allow verification that this invariant does not hold (i.e., should enable detection of a type/value incompatibility or invariant violation). Include safety properties: the label must always be either the initial or the next-state string, and at every step exactly one of the two resource-sets is a singleton and the other is empty.
