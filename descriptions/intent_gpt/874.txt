Specify a distributed algorithm that constructs and maintains a spanning tree over a fixed undirected connected graph of nodes. The model should treat the graph as input (a finite set of nodes and a finite set of undirected edges) and a designated root node. Nodes execute local actions and exchange only minimal information with neighbors; the specification should be independent of any particular message-passing encoding, focusing on the abstract state each node maintains and the allowed state transitions.

The system must converge from arbitrary initial local states to a consistent spanning tree rooted at the designated root. Convergence requires every non-root node to eventually select exactly one parent that is a neighbor, such that following parent pointers from any node reaches the root in a finite number of steps. The chosen parent relation must form a tree spanning all nodes (no cycles and connected). The model should also support non-decreasing integer distance labels from the root: each node maintains a distance estimate that is consistent with its parent (distance = parent's distance + 1 for stable nodes) and never exceeds a specified maximum. Specify fairness assumptions sufficient for convergence under weakly fair execution of node actions.

Key correctness properties: safety (every node’s parent is always a neighbor; parent pointers never form cycles), progress (eventual stabilization to a spanning tree with correct distances), and termination bounds relative to the diameter or the given maximum distance. Also state invariants ensuring the root has no parent and distance zero.
