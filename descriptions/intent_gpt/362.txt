Specify a formal model of a simple set-manipulation and membership-testing library and a one-state verification harness that checks basic set-theoretic equalities and relationships. The model should represent finite sets of integers and symbols, multi-set inputs that are interpreted as sets (duplicates ignored), set comprehensions, ranges, unions, intersections, subset and set-difference operations, powerset and union-over-powerset, and domains of finite functions. Provide a small, fixed initial state and a trivial transition relation so the system is effectively a static verification of expressions. The specification must enumerate a suite of boolean properties that assert equivalence between various different syntactic constructions that are intended to denote the same mathematical set (for example: explicit listing vs. comprehension vs. range; union of singletons vs. explicit set; intersection of two sets vs. comprehension; domain of a mapping given in different forms, etc.). For each assertion, the model must check the property and report failure if any equality, subset relation, or membership expectation does not hold. Guarantee that all tests are deterministic, exhaustively evaluated, and that the verifier will signal success only if every specified identity and containment property is true.
