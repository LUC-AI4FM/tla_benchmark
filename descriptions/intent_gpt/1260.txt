Model a bookkeeping mechanism that tracks which external agents have recently claimed or used a particular resource name, and that enforces that no two agents concurrently hold the same name. The model should represent an unbounded (but finitely represented) set of agents that may announce interest in names over time, and a multiset-like summary of how many active claims exist for each name. The system must provide operations for an agent to declare interest in a name, to withdraw interest, and for the global state to be queried for counts per name. The invariant to guarantee is that any name considered "available" is not currently claimed by any active agent (count zero), and that the recorded counts accurately reflect all declared interests despite concurrent or interleaved actions. The model must capture potential races and delayed updates from independent agents: two agents may simultaneously attempt to claim the same name, and the specification must show whether and how conflicts are detected or prevented. Define reachability and liveness goals that include (1) safety: no two agents are simultaneously considered the winner of the same name; (2) consistency: the global per-name counts always equal the sum of all individual agents' current claims; and (3) progress: an agent that withdraws its claim eventually causes the count for that name to decrease. The model should be parameterized by the set of names and the set of agents, and expose operations for inspection and debugging of per-name counts.
