Specify a formal model of a simple recursive factorial computation and the relationships between mutually recursive definitions. The model should describe a pure mathematical function that computes factorial for natural numbers, including base case and recursive case, and it should allow identical behavior when the function is referred to by different names or via an indirection. Requirements:

- Define a total function from the natural numbers to the naturals that satisfies factorial(0)=1 and, for all n>0, factorial(n) = n * factorial(n-1).
- Allow at least one alternate name or alias for the factorial function and require that the alias yields identical results for all arguments; the model must capture the equivalence between the primary function and its alias.
- Support a mutually recursive pair of definitions that reference each other but nonetheless compute factorial; require that these mutually recursive definitions are consistent with the primary factorial function for a specified range of inputs.
- Include assertions or invariants that demonstrate correctness for specific sample inputs (e.g., values 0, 3, 4) and that the recurrence holds across a small finite range (e.g., 0..5).
- Ensure the specification is purely functional (no state variables tracking execution), focuses on mathematical properties, and is suitable for formal checking of the stated equalities and recursion properties.
