Specify a formal model of a pure functional left-fold operation applied to sequences of integers. The model should represent a binary combining function that appends a single integer to the end of a sequence, a left-fold operator that iteratively applies this combining function over the elements of a source sequence starting from an initial accumulator sequence, and the evaluation of a concrete folding scenario: folding an initial empty sequence with the source sequence [1,2,3] using the append function. The model must capture the sequencing of fold steps and the final result, ensuring that the fold semantics correspond to left-associative application (i.e., each element of the source is combined into the accumulator in order). Specify the expected final accumulator value for the concrete scenario and the invariant that the fold produces that exact sequence. The specification should be entirely declarative about the algorithm’s intended behavior and correctness properties: totality of the fold on finite sequences, preservation of order of elements in the result, and determinism (given the same combining function, initial accumulator, and source sequence, the fold yields a unique result). The model should not prescribe an implementation strategy or operational scheduling.
