Model a system that manipulates immutable record values built from a fixed record schema and values constructed at runtime. The model should allow creation of record instances that must exactly contain the set of required fields prescribed by the schema; fields may not be added or removed after construction. Each field has an associated value type (for example, integers or strings) and newly created records must assign a value of an appropriate type to every required field. The model must permit creating multiple records and comparing them for equality, and it must ensure that operations over records cannot access a field that is not present in the record schema.

Specify operations that construct records, test equality and inequality of records, and attempt invalid constructions that omit or add fields; such invalid constructions must be forbidden by the specification (i.e., they are not reachable states). Express the typing requirement so that a record value is considered well-formed only if its domain exactly matches the schema and each component has the declared type. The key correctness properties to guarantee are: (1) record domains are fixed by the schema and cannot be expanded or shrunk, (2) field accesses are only performed on fields that exist in the schema, and (3) constructed records that satisfy the schema can be used and compared, while ill-formed records are impossible in any reachable state.
