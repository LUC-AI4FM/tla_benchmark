Specify a formal TLA+ model of a system that evaluates and tracks the validity of a constant expression against a known specification predicate. The model should represent a set of constant expressions (including complex structured expressions), a designated target predicate that determines whether a candidate expression satisfies the intended specification, and a verification check that asserts membership of each candidate in the set of expressions that meet the predicate.

The system must accept a finite collection of constant expressions as inputs, compute which of them satisfy the target predicate, and produce a report that pairs each expression with a boolean result indicating success or failure of the predicate check. The model must allow the target predicate itself to be an abstract, configurable condition so that different specifications can be substituted without changing the rest of the model.

Require invariants expressing that (1) every reported success corresponds to an expression that truly satisfies the predicate, (2) no expression that satisfies the predicate is reported as failure, and (3) the reporting function is total over the input collection (i.e., every input expression gets a result). Additionally, require a safety property forbidding any false positives and a liveness property ensuring that every input eventually receives a result. Include the ability to assume or print a combined diagnostic value containing a fixed string and the boolean verification outcome for model-checking and debugging.
