Specify a formal model of operations and properties of total functions between finite sets. The model should treat a function as a mapping from a finite domain set to values and support the following abstract operations and queries:

- Restrict a function to an explicitly given subset of its domain, to the domain elements satisfying a predicate, and to those domain elements whose images satisfy a predicate. The result should itself be a function with domain equal to the chosen subset.

- Compute the image (range) of a function and compute the inverse-image relation for a specified set of targets. Also support computing an inverse function when the mapping is one-to-one on a specified source and target set.

- Test whether one function is a restriction of another (domain containment and agreement of values on the smaller domain).

- Apply a binary operator pointwise to two functions defined on compatible domains, producing a new function on the common domain.

- Fold (aggregate) the values of a function over an arbitrary subset of its domain using an associative, commutative binary operator and a specified base value; provide a convenience for folding over the whole domain and for summation.

- Define and characterize injective, surjective, and bijective mappings between two sets, and predicates that state existence of such mappings.

State precise invariants and correctness properties: restricted functions must have the expected domains and preserve values; range and inverse operations must be mutually consistent; the inverse of a bijection must be its two-sided inverse; pointwise application should preserve domain compatibility; fold-based aggregates must be insensitive to ordering and equal to the intended algebraic reduction for associative/commutative ops; tests for injection/surjection/bijection must coincide with the usual mathematical definitions. Ensure all definitions work for empty and nonempty finite domains.
