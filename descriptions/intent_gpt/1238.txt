Specify a formal model of basic set and sequence theory operations and their expected behaviors when used to build and query collections of integers and finite sequences. The model should expose primitive domains (integers, naturals, finite sets, Cartesian products, function spaces, and finite sequences) and allow constructing unions, intersections, set difference, membership tests, subset relations, Cartesian products, and function/sequence ranges. It must describe expected equality and containment relations between concrete examples of sets and between sets defined by comprehensions or type constraints, and how these operations interact with empty sets. It must also represent sequences as values drawn from sequence spaces and function spaces (finite tuples as total functions from an index range to a value domain), and specify membership tests for sequences in sequence and function spaces and in unions/intersections of such spaces.

The correctness properties to verify include:
- Union and intersection yield the mathematically correct sets for given concrete operands and comprehensions.
- Set difference yields the correct remaining elements and handles empty operands.
- Membership tests correctly distinguish elements that belong or not to unions, intersections, complements, and function/sequence spaces.
- Subset relations are true exactly when every element of the left set lies in the right set.
- Cartesian products and unions with explicit tuples correctly include or exclude particular ordered pairs/sequences.
- Behavior with built-in domains (Int, Nat) is consistent (e.g., negative integers are members of Int but not Nat).

The model should be amenable to model checking: provide initial states and transitions that leave the collections unchanged, and assert the above properties as invariants to be checked.
