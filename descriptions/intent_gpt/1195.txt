Specify a formal TLA+ model of a language-level set and function equality test suite. The model should represent a deterministic procedure that takes no external input and evaluates a fixed collection of set and function expressions, verifying that various differently written expressions denote the same mathematical sets or maps. For each test case, the model must check equality (or subset relation where appropriate) between two expressions (examples include explicit enumerations, set comprehensions, images of expressions, unions of subsets, intersections, set difference, integer ranges, and domains of sequence or function constructors). The system must assert failure when a declared equivalence does not hold, and otherwise record success for that test. The overall behavior should be a single-step deterministic evaluation that produces a report indicating which tests passed or which assertion failed. Key correctness properties: (1) every comparison must be evaluated according to standard set-theoretic and function semantics; (2) any mismatch must lead to a reachable state labeled as an assertion failure; (3) if all comparisons are correct, the model must reach a terminal state recording completion without failures. The specification should not prescribe how evaluation is implemented, only the required comparisons and the pass/fail outcomes that must be observable.
