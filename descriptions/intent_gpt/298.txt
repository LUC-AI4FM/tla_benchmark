Specify a formal TLA+ model of the classic binary search algorithm that finds whether a target value exists in a sorted array of distinct integers. The model should treat the array as a finite, indexed sequence and provide an operation that accepts a target value and returns whether the target is present. The algorithm must repeatedly narrow a search interval by comparing the target with the middle element and updating the interval endpoints until the target is found or the interval becomes empty.

The specification must express the initial conditions, the allowed state transitions of the search, and termination. It must allow non-deterministic scheduling of steps to model any interleaving of internal decisions but should not model concurrency beyond the sequential search itself. Key correctness properties to assert: (1) Safety — whenever the algorithm reports “found” it must report an index whose element equals the target; when it reports “not found” the target must not occur anywhere in the array; (2) Invariant — every active state must maintain that the target, if it occurs in the array, lies within the current search interval; (3) Termination — the algorithm must always terminate in a finite number of steps for any finite array; (4) Progress — the search interval strictly decreases on steps that do not report “found.” Include specifications of array bounds, ordering of array elements, and a clear notion of the final result.
