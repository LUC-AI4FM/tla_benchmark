Model a simple configurable-state system that initializes a small collection of typed parameters and maintains them unchanged. The system should accept a set of externally supplied constant configuration values (an integer, a string, two distinct symbolic model values, and a set of integers) and expose corresponding runtime state variables that are initialized from those constants at system start. The system must perform no state transitions that change these values after initialization.

Specify the initial-state requirements so that each runtime parameter equals the matching provided configuration constant. Specify an invariant that expresses the desired stable configuration properties: the integer parameter has a particular required numeric value, the string parameter has a particular required text value, a symbolic parameter equals a designated model value and is distinct from an alternate model value, and the set parameter equals a fixed finite set of integers. Require that the invariant holds in the initial state and is preserved by all steps (which must be identity steps over the parameters). Also demand that the model treats the provided constants as assumptions (parameters) rather than as computed values, and ensure types for all parameters are explicit (integer, string, symbolic model values, and set of integers).
