Specify a simple nondeterministic state machine that models a single integer-valued state variable whose value may be set at each step to any one of a fixed finite set of integer constants (for example, 0..19). The model should start in an initial state with a specified value (for example, 0). At every transition, the machine may nondeterministically choose any one of the allowed constants and update the state to that constant.

Describe the system at the abstract level: the set of allowed values, the initial value, and the transition relation that permits assigning any allowed value on each step. Do not commit to any particular encoding of actions or helper operators; only require that the transitions are total over the allowed choices (i.e., at least one choice is always available).

Specify the following correctness properties to be checked:
- Safety: The state variable always stays within the allowed finite set (invariant).
- Liveness: From any reachable state, it is always possible eventually to reach any specific allowed value (strong fairness / eventual reachability of each constant).
- Absence of deadlock: There is always a valid next transition (no terminal states).
Optionally state that the system should be amenable to model checking for the above properties.
