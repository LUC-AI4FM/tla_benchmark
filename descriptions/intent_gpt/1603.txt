Specify a model of a simple program that initializes a numeric state and then performs a single computation by calling a reusable component to obtain a value. The system should represent two distinct phases: initialization and a single computation step that uses the component's result to update the program state, after which the program terminates (but the model should allow stuttering after termination to avoid deadlock). The reusable component should be treated as an external module instance that supplies a deterministic numeric result computed from parameters or constants supplied at instantiation time; the main program must invoke that component and incorporate its result into its state update.

Requirements:
- The model must initialize the program state to a known integer value and start in a state ready to perform the computation step.
- During the single computation step, the program must obtain the component's numeric output and assign that value to the program state, then transition to a terminated control state.
- After termination, the system may stutter indefinitely without changing state.
- The component's output must be parameterizable by fixed constants provided at instantiation, and the overall system must allow reasoning about the final possible values of the state given those parameters.

Correctness properties to verify:
- Safety: the program's state after the computation is one of the expected numeric values determined by the component and its parameters.
- Liveness: the program eventually reaches the terminated control state (the computation step occurs).
- No unexpected state changes occur after termination (stuttering only).

Model the system abstractly without prescribing an implementation of the component beyond its deterministic numeric result and its instantiation parameters.
