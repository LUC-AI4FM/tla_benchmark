Specify a simple two-variable state machine that repeatedly swaps the values of two integer registers on each step, starting from a given initial assignment. Model the state space, the initial condition, and a deterministic transition that exchanges the contents of the two registers every step. Include the liveness and safety requirements to be checked over all infinite executions.

The model should guarantee these properties:
- Safety: the allowed transitions preserve that both registers always hold integer values and adhere to the swapping behavior (no other updates allowed).
- Liveness (reachability): it must be always the case that eventually the registers reach a specified target configuration (for example, one register equals 1 and the other equals 0) infinitely often — i.e., the target configuration recurs infinitely often along any infinite execution.
- Liveness (unreachability): specify another target configuration (for example, both registers equal 0) that should never be forced to occur infinitely often; the model should allow verifying whether this second configuration is not guaranteed to recur.

Also require that the specification separates safety from liveness so model checking can validate invariant-style properties (always statements) and fairness/recurrence properties (eventually and infinitely often) independently.
