Specify a model of a simple lossy message-delivery system with three components: a sender that initially holds a finite set of messages to transmit, a transmission medium that can carry zero or more messages (and may drop some), and a receiver that accumulates messages it observes. The system should allow the following behaviors: the sender may pick a message it still holds and place a copy into the medium (removing it from the sender’s local set); the medium may nondeterministically drop any message it currently carries; and the receiver may nondeterministically observe (receive) any message present in the medium, adding it to its local set without removing the message from the medium (i.e., reception does not consume the medium’s copy). The model should assume a finite, nonempty universe of possible message values.

Specify as correctness requirements that (1) the system never reaches a state in which all three components are simultaneously empty (i.e., at least one of sender, medium, or receiver always contains some message), and (2) the model explores the possibility that not all messages must be lost — there should exist executions where at least one original message is eventually present at the receiver. Also require that the model supports nondeterminism in action ordering and allows multiple copies of the same value in transit conceptually through the medium’s set semantics. Finally, state liveness and safety properties to check: safety — the triple-empty state is unreachable; liveness — there exists an execution in which the receiver eventually contains some message originally held by the sender.
