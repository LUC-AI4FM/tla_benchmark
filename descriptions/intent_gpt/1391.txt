Specify a parameterized circular counter system of configurable size. The system maintains a single position on a ring of N labeled slots (N > 1). In each atomic step the position may move one slot clockwise or one slot counterclockwise, with wraparound at the ends (so stepping clockwise from slot N-1 goes to 0, and stepping counterclockwise from 0 goes to N-1). The parameter N must be a parameter of the model so the same specification can be instantiated for different ring sizes.

Require that every execution starts with the position initialized to some valid ring slot. The model should allow nondeterministic choices between the two step directions on each transition.

State the key correctness properties to verify:
- Safety: the position is always a valid slot index in 0..N-1.
- Liveness: from any state, it is always possible to eventually reach every ring slot (the system is strongly connected under the allowed moves).
- Progress fairness variants: support checks that under weak fairness of the whole transition relation every enabled move will not be permanently ignored, and that under strong fairness of the clockwise move, if clockwise is enabled infinitely often then it occurs infinitely often.
- A temporal property ensuring cycles wrap correctly: whenever the position is at N-1 and a clockwise step occurs, the next position equals 0; conversely, ensure no transition falsely steps from N-1 to a nonwrap value unless explicitly allowed.

Allow instantiation-dependent sanity checks (expressions using modular arithmetic with the instance parameter) so that client specifications can assert arithmetic relationships about concrete instances.
