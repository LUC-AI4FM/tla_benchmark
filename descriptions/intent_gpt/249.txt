Specify a TLA+ model of a simple multiset counter system over a fixed finite universe of elements. The system maintains a multiset whose element types come from a known finite base set. Initially the multiset is empty. At each step the multiset may either increment or decrement the multiplicity of exactly one element from the base set. Incrementing increases the count of that element by one; decrementing decreases the count by one but must not cause negative multiplicities. The choice of which element to change may be nondeterministic at each transition.

The specification must capture all reachable multisets and all possible interleavings of increments and decrements. Required correctness properties to assert:

- Safety: multiplicities are always nonnegative and always finite; the multiset contains only elements from the given base set.
- Invariance: the empty multiset is a valid initial state and subsequent states are reachable only via the allowed single-element increment/decrement transitions.
- Liveness: from any reachable state, it must be possible to eventually reach a state with at least one increment of some base element (i.e., the system cannot be stuck without enabling an increment unless the base is empty).
- Optional property to check: reachability of all multisets with element counts bounded by some user-chosen limit (if a bound is imposed).

Specify the model so proofs or model checking can verify these properties and explore the state space of possible multisets.
