Specify a system that models a finite-state configuration of nested finite mappings and sequences and permits only deterministic, local, or no-change transitions over those data structures. The model should represent several distinct finite collections: (1) a fixed ordered collection of small integer-indexed sequences whose elements are computed by simple arithmetic expressions, (2) a small finite map from symbolic keys to short sequences of strings, (3) a map from a finite set of external indices to small maps whose keys are drawn from a tiny fixed domain and whose values are integers derived from simple arithmetic, and (4) a map from the same external index set to maps keyed by another small external domain with all entries initialized to a single constant value.

The system must permit an initial state that assigns concrete values to each of those collections. Transitions must either leave the entire state unchanged or apply a bounded, syntactic update to one or more nested entries: replacing an entire sequence-within-a-sequence, replacing the value associated with a symbol by a new short sequence with a specified element change, and performing single-location updates inside nested maps that may be written in two successive update steps (one that changes a nested element to a new value and another that restores or reassigns it). Updates must be expressed as atomic assignments to the resulting collections (not via auxiliary loops).

Specify invariants asserting that the domains of each top-level map remain fixed, that sequence lengths and key sets of inner mappings do not change, and that all values always belong to their expected types (integers or strings) and specified small ranges. Also specify a liveness/diagnostic assertion that only a single reachable state exists in a particular test scenario.
