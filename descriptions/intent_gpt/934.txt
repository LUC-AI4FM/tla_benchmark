Specify a model of a simple 12-hour clock that advances the hour by one on each tick and wraps from 12 back to 1. The model should represent the hour as an integer in the range 1..12 and include an initial condition that the hour is always within this range. The only state change allowed is a tick that increments the hour by one unless it is currently 12, in which case it becomes 1. The specification must capture infinite execution of ticks (i.e., the tick step can occur repeatedly).

Require the following correctness properties:
- Invariance: at all times the hour value must remain within 1..12.
- Determinism of the tick step: for any state, the next hour value is uniquely determined by the current hour (no nondeterministic choices).
- Liveness/Progress: from any state, it must be possible to perform another tick (no deadlock).
- Cycle completeness: starting from any valid hour and after some number of ticks, every hour in 1..12 is reachable (the model should demonstrate that the ticking produces the full 12-state cycle).

Express these properties as temporal formulas suitable for model checking.
