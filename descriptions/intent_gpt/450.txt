Specify a formal model of a language runtime's handling of immutable sequences of characters (strings) and their basic operations. The model should treat strings as sequences of character values and must capture concatenation and length computation as primitive operations. It should support representing characters that include ordinary letters, backslashes, double quotes, and escape sequences such as newline; the model must reflect that escaping and literal composition are represented as sequences of single-character elements so that concatenating substrings with escape characters yields the expected overall sequence.

Require the model to express and verify equalities that arise from concatenation: concatenating two literal substrings must produce the combined literal string, and concatenating a prefix containing an escape character with a suffix should equal the full literal containing that escape interpreted as a single character in the sequence. Require the model also to relate lengths: the length operator applied to any literal string must equal the number of characters in its sequence representation, counting escape sequences as single characters when they represent one character value (for example, newline counts as one).

State properties to check: concatenation is associative and preserves character order; length is additive across concatenation; escape-containing literals are decomposable consistently into prefix and suffix whose concatenation equals the original literal and whose lengths sum to the original length. The specification should be suitable for model checking these equalities and arithmetic facts about lengths.
