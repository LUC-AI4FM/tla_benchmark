Specify a formal model of single-decree Paxos (Basic Paxos) with a stable leader (no leader election). The model should capture proposers, a single distinguished leader that issues numbered ballots, a set of acceptors, message-passing among them, and a finite set of possible values to be chosen. Do not commit to any particular implementation or code structure — describe the system behaviorally.

The model must allow the leader to start a ballot by sending prepare requests to acceptors, acceptors to respond with promises including any previously accepted highest-numbered proposal and its value, the leader to form a proposal value consistent with received promises (choosing the value from the highest-numbered accepted proposal if any, otherwise any allowed value), and the leader to send accept requests for that value. Acceptors must accept an accept request only if they have not promised to a higher ballot, updating their accepted proposal and promise accordingly; all communication is via asynchronous messages that may be delayed or reordered but not corrupted.

Specify safety properties: (1) Agreement — once any value is chosen (i.e., a quorum of acceptors have accepted the same proposal number and value), no other different value can ever become chosen. (2) Integrity — only values from the allowed value set can be chosen and a chosen value must have been proposed. (3) Non-contradiction of promises — acceptors never accept two different values for the same ballot. Optionally state liveness assumptions separately (e.g., eventual reliable delivery and a stable leader) but do not bake liveness into safety requirements.
