Specify a formal TLA+ model of the Boyer–Moore majority vote problem: given a finite sequence of values drawn from a fixed nonempty domain, produce an element after a single left-to-right pass that is guaranteed to be the only possible majority element of the whole sequence. The model should describe a single-pass streaming procedure that maintains only constant additional state (independent of sequence length) and may inspect each input element once in order. It must accept any fixed input sequence of arbitrary but finite length and nonempty value domain.

The specification must state the expected observable output at termination and the correctness requirements: if any value occurs strictly more than half of the positions in the input, then the reported element must equal that majority value; conversely, if no value has such a strict majority, no particular output is required (the procedure may return an arbitrary candidate). The model should record and reason about counts needed to support proofs but should not assume extra storage proportional to sequence length.

Include invariants that make it possible to prove the main safety property (uniqueness of a possible majority equal to the final candidate when one exists) and state liveness so that the procedure completes after processing all input elements. Ensure the model supports checking the safety property for all sequences up to a bounded length.
