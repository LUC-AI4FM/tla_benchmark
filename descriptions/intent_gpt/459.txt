Specify a simple constant propagation and aliasing model: model a system that declares a fixed constant value and allows one or more names to refer to that constant. The model should express that the constant itself is immutable and that each name is an alias that always denotes the same immutable value. It must permit introducing additional alias names that are defined to be equal to other names (transitive aliasing), and ensure that all aliases remain consistent with the original constant regardless of the aliasing chain.

Require invariants that capture equality relationships: the original constant equals every direct alias, and any alias equals any other alias that is transitively linked to the constant. The model must forbid redefinition or mutation of the constant and disallow an alias from being assigned a different value. The specification should allow checking that expressions using aliases evaluate to the same value as expressions using the original constant. Also include checks that adding redundant alias declarations does not change the system’s meanings. The goal is to verify that aliasing preserves referential transparency and equality under transitive aliasing for the immutable constant.
