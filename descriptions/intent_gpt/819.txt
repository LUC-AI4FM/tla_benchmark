Specify a concurrent graph reachability algorithm executed by a fixed finite set of worker processes that collectively determine the set of nodes reachable from a designated root in a finite directed graph. The specification should describe the abstract system, not an implementation: workers repeatedly pick unexplored nodes from a shared work pool, mark a picked node as visited, and add its successors to the shared pool (possibly one successor at a time). The system must satisfy:

- Safety: At all times, every node recorded as visited must indeed be a node of the graph; every node added to the shared pool must be a graph node; and the union of visited nodes and nodes in the pool must always be a subset of nodes reachable from the root.
- Partial correctness: If the algorithm terminates with no workers able to proceed, then the set of visited nodes equals exactly the set of nodes reachable from the root.
- Termination/Progress: The system should terminate (all workers become quiescent) if and only if the reachable set is finite; if the reachable set is finite, then under weak fairness of worker actions the algorithm must eventually reach a quiescent state.
- Refinement relation (informal): The concurrent behavior should be allowed to take extra internal steps (e.g., adding successors one at a time) but must implement an abstract sequential reachability algorithm that adds a node and all its successors atomically.

Also require simple typing/invariant properties for worker-local state to enable proofs of the safety and refinement claims.
