Model a simple two-variable state machine representing an assignment mechanism that repeatedly updates two variables concurrently. The system starts with both variables equal to a known initial value. In each step, either (A) each variable is assigned the other's new value simultaneously (a swap of their new values), or (B) the pair is deterministically set to a specific constant pair of values. Specify the state space, initial condition, and transition relation abstractly so the model allows both kinds of steps nondeterministically at each transition.

Require that the model capture liveness and safety aspects: safety must assert that every reachable state is one of the intended shapes (either a pair where both components are in the set of values produced by the mutual-assignment option, or the fixed constant pair), and it must forbid any state with values outside those allowed by the two update options. Liveness properties should express that from the initial state the system can always eventually reach the constant pair option, and that executions are closed under repeated application of the transition relation (no stuck states). Also require invariants asserting that values remain within a small finite domain and a property characterizing whether and when the swap-like action can repeat forever versus when the system stabilizes into the constant pair.
