Specify a simple counter system that starts at zero and repeatedly increments by one until reaching a bound. Model the states as natural-number values of a single counter. The system must initialize the counter to 0 and allow only transitions that increase the counter by exactly 1, up to a maximum value of 5; once the counter reaches 5, no further increments are permitted.

Describe the possible behaviors as infinite sequences of states (or finite if the system can stutter or terminate after reaching the bound), and make explicit which steps are considered state changes and which are allowed stuttering steps that leave the counter unchanged.

Require and verify the following correctness properties:
- Safety (invariant): the counter is always a natural number between 0 and 5 inclusive.
- Progress (liveness): whenever the counter is less than 5, the system eventually performs an increment to a strictly larger counter value.
- Fairness/Nonstarvation: the specification should permit no infinite execution in which a transition that would increment the counter is continuously enabled but never taken.
- Transition characterization: clearly distinguish and specify both the strict incrementing steps and the allowed stuttering (no-op) steps so that temporal assertions referring to "next-step increment" versus "unchanged step" are well-defined.

Do not prescribe an implementation language; instead produce a formal model suitable for temporal reasoning that separates state predicates from action-level transition properties.
