Model a deterministic procedure that transforms all elements of a finite input set into an ordered sequence by repeatedly removing one element from the remaining set and appending it to the output sequence, until the remaining set is empty. The model should treat the input as an arbitrary finite set of distinguishable elements and should allow any nondeterministic choice of which element to take next, but the procedure itself must always terminate when no elements remain.

Specify the system's state as consisting of (1) a multiset or set of elements that remain to be processed and (2) a sequence representing the output order constructed so far. The initial state must have the remaining set equal to the given input set and the output sequence empty. A step of the system must choose an element currently in the remaining set, remove it from that set, and append it to the end of the output sequence; if the remaining set is empty, no changes occur.

Require the following correctness properties:
- Safety: at all times, every element is either still in the remaining set or already appears exactly once in the output sequence, and no element is lost or duplicated.
- Progress/termination: the process eventually reaches a state where the remaining set is empty (i.e., the algorithm terminates) for any finite input set.
- Final output: when terminated, the output sequence is a permutation of the input set (contains every input element exactly once) and its length equals the input set's cardinality.

Also specify invariants needed to express the safety property and a proof obligation or liveness condition to establish termination for finite inputs.
