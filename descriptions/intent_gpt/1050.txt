Model a message-passing echo (flooding) algorithm that elects an initiator and causes every node in a connected undirected network to learn that node’s identity by flooding messages. The model should treat the network as a fixed, finite set of distinct nodes connected by undirected, irreflexive edges (any connected topology may be used). The algorithm must allow any node to be the initiator and must not depend on unique port numbers or synchronous rounds.

Specify the state of each node with local knowledge about who it believes is the initiator, a mailbox of incoming messages, and whether it has already forwarded the initiator’s identity. Nodes communicate only by sending messages along edges; messages may be delivered reliably but with arbitrary delays and in arbitrary order. The system must model nondeterministic scheduling of message deliveries and node actions.

The required correctness properties:
- Safety: eventually no node believes an identity other than the actual initiator; once a node adopts the initiator identity it never changes it to a different identity.
- Liveness (termination of flooding): for every fair execution in which messages are eventually delivered, every node eventually adopts the initiator identity and no messages remain in transit.
- No duplication/monotonicity invariant: once a node has forwarded the initiator identity it will not forward a different identity, and repeated forwarding of the same identity does not create inconsistent state.

Specify assumptions about the network (connected, symmetric, no self-loops), message model (lossless, asynchronous), and fairness conditions sufficient to guarantee termination. Provide properties as temporal assertions to be checked by model checking.
