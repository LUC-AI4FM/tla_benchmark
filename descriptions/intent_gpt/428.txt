Specify a simple deterministic state machine that models a single integer-valued register and allows transitions that conceptually represent applying a collection of binary operations with a fixed right operand. The model should initialize the register to 0 and repeatedly perform one-step updates where the register is replaced by the result of applying one of several named binary operations to its current value and a constant operand (1). The set of binary operations should be abstract (their implementation is unspecified) but must be definable so that each operation returns some integer value given two integer inputs. The model must allow nondeterministic choice among those operations at each step.

Require the following correctness properties:
- Safety: The register must always remain an integer and, if desired, remain within any user-specified bounded domain. Express invariants asserting well-typedness and any bounds.
- Liveness: From every reachable state, it must be possible to continue taking transitions indefinitely (no deadlock).
- Distinguishability: It must be possible to assert that at least two of the abstract operations can produce different results when applied to the same inputs; the specification should allow stating and checking such relations among operations.
- Determinism option: Provide a variant in which each abstract operation is constrained to particular deterministic arithmetic behavior (e.g., addition or subtraction) so properties can be checked concretely.

Do not prescribe concrete operator names or syntax; allow the specification to parameterize the operations and the operand so the model can be used both abstractly and concretely for model checking.
