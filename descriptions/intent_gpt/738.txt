Specify a formal model of the following weighing-by-balance problem. A single solid of integer total weight N must be broken into exactly P integer-weight pieces. Using only a two-pan balance and those pieces, it must be possible to measure out any integer target weight w with 1 <= w <= N: for each target w there must exist a choice of some pieces placed on the same pan as the target and some (disjoint) pieces placed on the opposite pan so that the pans balance exactly (i.e., target weight + weight of pieces on target side = weight of pieces on opposite side).

Model the system at the level of piece weights and represent a break as a multiset (or ordered list) of P positive integers summing to N. Do not assume piece weights are distinct except where necessary to avoid symmetry. The model must capture all possible selections of pieces on each side for each target weight and allow nondeterministic choice of these selections.

State the correctness requirement: a break is a valid solution iff for every integer w in 1..N there exists a pair of disjoint subsets of the pieces whose weight difference equals w. Also specify a property enumerating all valid breaks for given N and P.

Include invariants or temporal properties necessary to verify that any candidate break indeed satisfies the per-weight representability condition. The model should be suitable for exhaustive checking for small N,P and for reasoning about the general characterization of solvable (N,P) instances.
