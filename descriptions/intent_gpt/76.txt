Specify a simple state machine that represents a boolean condition computed from a record-valued state and a deterministic update relation. The model should represent a state that is a record with a numeric field and an associated boolean projection. Initially, the record must be set so that its numeric field has a specific integer value and the boolean projection is determined by a deterministic expression over that record. The transition relation must allow arbitrary steps but must preserve the determinism of the projection: any transition yields a next record and a next boolean value computed from that record by the same deterministic expression. The system should support reasoning about reachability from the initial state and should permit specification of liveness properties (that some predicate eventually holds) and safety properties (that the boolean projection always equals the computed expression from the current record). Key correctness properties to guarantee: the projection is always a deterministic function of the numeric field; initialization yields the intended numeric value; every reachable state satisfies the projection invariant; and if the transition relation is nontrivial, the model must allow proving whether certain boolean outcomes are eventually reachable or invariantly maintained.
