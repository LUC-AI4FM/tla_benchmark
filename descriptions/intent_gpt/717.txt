Specify a model of a graph-to-DOT string converter that takes a finite directed graph and produces a DOT language representation of that graph. The model should accept an abstract graph with a set of nodes and a set of labeled directed edges (each edge carries a source node, destination node, and an edge label). The converter must map nodes to unique identifiers in the DOT output and include node label attributes derived from a supplied node-labeling function. It must map edges to DOT directed-edge statements and include edge label attributes derived from a supplied edge-labeling function. The order of output tokens need not be specified, but the output string must contain exactly one declaration for each node and one directed edge statement for each edge, and each declaration must include the correct label text corresponding to the supplied labeling functions. The model must also allow for deterministic mapping from nodes to stable identifiers so that repeated conversions of the same abstract graph yield the same DOT identifiers. Key correctness properties: completeness (all nodes and edges are represented), fidelity (labels in the output match the labeling functions), uniqueness (node identifiers are unique and stable), and syntactic well-formedness of the produced DOT fragments (each node declaration and edge statement conforms to expected DOT patterns).
