Specify a model of a simple concurrent or stateful system whose sole concern is exploring combinations of independent integer state components drawn from finite ranges. The system should initialize three independent state variables to arbitrary values from prescribed integer intervals: one from 1..100, another from 1..200, and a third from 1..20. After initialization, the system performs no state transitions: the state is stable and all variables remain unchanged. The specification should focus on representing the full initial-state space (the Cartesian product of the three ranges) and on expressing that the transition relation is the identity relation (no changes allowed). State what it means for an execution to be valid (it begins with a chosen triple from the allowed ranges and then does not modify any component). Include correctness properties that must hold for every reachable state: safety properties asserting each component remains within its original bounds, and a liveness property stating that no further state changes will ever occur (i.e., stability). The specification should be suited to model checking, making explicit that the number of initial states is the product of the three range sizes and that the system is deterministic after initialization.
