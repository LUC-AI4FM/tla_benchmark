Specify a concurrent system that repeatedly produces pairs of nonnegative integers and checks whether their sum is even, for all numbers in a bounded natural range. The system should allow multiple independent producers to generate pairs (x, y) where each value ranges over 0..Max, and each produced pair is submitted to a checker component. The checker must nondeterministically select pairs to verify and record whether the sum x + y is even. The system must guarantee safety: every recorded verification must correctly reflect the parity of the sum (i.e., be true iff the sum is even). It must also guarantee liveness: for any pair that is continuously offered for verification, the checker eventually examines and records it. The system should be able to run indefinitely, but values are bounded by the given Max value. Include an invariant that the checker never records an incorrect parity, and an eventuality property that every offered pair is eventually recorded. Model nondeterministic scheduling between producers and the checker and allow multiple outstanding unverified pairs. Do not commit to a particular implementation; state only the intended behaviors, constraints, and correctness properties.
