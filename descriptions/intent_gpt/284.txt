Specify a simple counter system parameterized by a nonnegative integer upper bound N. The system maintains a single integer-valued state variable that initially equals N and, on each step, increments by 1. The model should treat N as a constant parameter whose domain and intended type (an integer) are part of the specification assumptions. The specification must permit only integer arithmetic on the state and parameter.

Require the following correctness properties to be expressed and checked as temporal formulas. Safety: the state value is always an integer and remains within any required bounds derivable from the initial condition and the transition (for example, show invariants about monotonic growth). Liveness: from any reachable state, the system can always take another step (no deadlock). If N is required to be nonnegative, include a property that the state is always at least that nonnegative value. Also include a property showing eventual growth: from the initial state, the state will eventually exceed any fixed integer threshold (unbounded monotonic increase). Specify clear assumptions on N’s type and range so model checking can validate invariants and liveness; the implementation detail of how variables update must not be prescribed.
