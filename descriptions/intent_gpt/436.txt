Specify a system that models a simple binary relation constructor: given two inputs, the system must produce a set containing exactly those two inputs (allowing them to be equal, in which case the resulting set contains the single repeated element once). The model should accept arbitrary values for the two inputs from a specified universe and produce as output the unordered collection (set) containing them.

The specification must include:
- A clear input domain for the two values and a deterministic operator that computes the output set from the inputs.
- Behavior when inputs are identical: the output must be the singleton containing that value.
- Behavior when inputs differ: the output must contain both and only those two values, with no duplicates and no additional elements.
- The computation must be total (defined for every pair of input values) and deterministic (the same inputs always yield the same output).

Formal correctness properties to verify:
- Output is a set drawn from the input domain.
- For any inputs x and y, the output equals {x, y} (semantically: contains x and y, and contains nothing else).
- Idempotence under reordering: swapping the two inputs yields the same output.
- Stability under equality: if the inputs are equal, output has cardinality one; otherwise cardinality is two.

Include invariants and properties suitable for model checking these requirements.
