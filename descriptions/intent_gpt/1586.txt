Model a simple imperative program with a main block that nondeterministically chooses one of three alternatives and a single callable procedure that increments a shared variable by its argument. The model should capture the following components and requirements:

- A global state with at least three integer variables used by the main block and the procedure. One global variable is modified by the procedure, another by some alternatives in main, and a third may remain unused or unchanged.
- A main control flow that offers exactly three choices: (1) set the first variable to 1 and set the second variable to 0, then proceed to final checking; (2) set the second variable to 1, then proceed to final checking; (3) call the procedure with argument 1, return, then proceed to a local assertion before final checking.
- A procedure that accepts an integer argument and adds it to the designated global variable; the procedure must behave atomically from the caller’s perspective (it should push a return point, perform the increment, and return).
- After the procedure call option returns, a local assertion must check that the incremented global variable equals 1. After any chosen alternative completes, a final assertion must check that the sum of the first two global variables equals 1.
- The model must allow nondeterministic choice among alternatives, model call/return behavior correctly (including preserving other globals), and include termination detection.
- Specify invariants and correctness properties: the local assertion always holds whenever control reaches it after the procedure call, and the final assertion always holds at the end of execution. Also specify fairness/termination conditions ensuring the program can always reach termination and no assertion can fail.
