Model a generalized water-jug puzzle solver with an arbitrary finite set of jugs, each having a fixed positive integer capacity, and a target volume to measure. The model should represent system states as the current amount of water in every jug, start from the state where all jugs are empty, and allow nondeterministic steps that perform one of the basic operations: fill any single jug to its capacity, empty any single jug to zero, or pour from one jug to another until the source is empty or the destination is full. Steps may change only the amounts of the affected jugs.

Specify the reachable-state space and a safety property expressing that all states maintain valid jug contents (nonnegative integers not exceeding capacity). Define an initial predicate and a next-state relation that permits the allowed operations between states.

State the correctness goal as reachability: there must exist a reachable state in which some jug contains exactly the target volume. Also request an invariant check that would fail precisely when such a target-containing state is reachable, so that a counterexample trace gives a concrete sequence of operations that achieves the target. Optionally require the model to expose minimal examples of solution sequences and to detect unsolvability when no such state exists.
