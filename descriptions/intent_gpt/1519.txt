Specify a formal model of a symmetric mutual-exclusion protocol for a fixed finite set of concurrent threads that implements Dekker-style cooperative exclusion with a shared "turn" or "next" indicator and per-thread boolean intent flags. The model should abstract threads as identical processes that repeatedly try to enter a critical section, do some non-modeled work in the critical section, and then yield to another thread by setting the shared turn value to some other thread before retrying.

Requirements:
- The system must enforce mutual exclusion: at most one thread may be in the critical section at any state.
- Progress/liveness: every thread that continually attempts entry must eventually enter the critical section (strong fairness for each thread's enabled steps or an equivalent fairness assumption that prevents starvation).
- The protocol must use only two shared data structures: a map of per-thread boolean intent flags and a variable recording which thread has the turn. Threads may read and write only these shared variables (and their own local control/state).
- The protocol must allow arbitrary interleaving of atomic thread steps; steps should update local control state plus at most one of the shared variables per atomic transition consistent with the intended algorithmic steps.
- Model initialization where all flags are false and the turn variable is some thread in the set.
- Specify correctness properties to be checked: mutual exclusion invariants and the eventual entry liveness property for every thread. Also include a termination detection property that all threads can, in principle, complete a full iteration and return to a quiescent state, if applicable.
