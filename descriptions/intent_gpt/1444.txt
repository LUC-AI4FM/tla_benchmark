Model a simple discrete-state counter system that starts at zero and repeatedly increments by one until reaching a fixed upper bound. The model should capture states and state transitions, define an initial condition, and allow only the single atomic transition that increments the counter while it is below the bound. Specify safety and liveness properties to be checked over all infinite behaviors produced by the system.

Requirements:
- The system must initialize the counter to 0 and must permit only increment steps that increase the counter by one when the counter is strictly less than a specified maximum (for example 3). No other transitions or modifications to the counter are allowed.
- The specification must assert that every reachable state satisfies a safety invariant: the counter is always a natural number within the range [0, max].
- Liveness requirements must assert that the counter eventually reaches the maximum value and that the final increment from the predecessor of the maximum to the maximum occurs in some step (i.e., the step that moves the counter from max-1 to max actually takes place in every complete execution).
- Include additional post-condition checks that report execution metadata: the total number of generated states, the number of distinct states, and that specific named states (for example the state where the counter equals max-1 and the final increment step) are observed exactly once in the recorded trace summaries.
- Provide these checks as properties to be verified by the model checker, not as implementation constraints.
