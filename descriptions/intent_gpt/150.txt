Specify a model of a parametric module instantiation mechanism and name-resolution behavior for a simple functional language with local definitions and module instances. The model should represent modules that can be instantiated, parameters passed, and local bindings (scoped names) defined inside both modules and the instantiation site. The system must ensure that local bindings introduced by an instantiated module do not collide with identically named local bindings in the instantiating context; each local definition should be resolved to the correct scope according to lexical scoping rules. The model should allow nested or multiple instantiations and check that parameter substitution and local name bindings interact correctly: parameters passed into an instance override nothing outside, and local names inside an instance are isolated from local names outside. Specify the expected evaluation semantics for simple expressions that use LET/local definitions and module calls so that the evaluated result is unambiguous. State correctness properties asserting absence of name-capture, preservation of parameter values, and determinism of evaluation. Include properties to detect accidental name collisions when scoping rules are violated.
