Model a binary-search algorithm that searches for a given key in a sorted finite sequence of integers and specify its functional correctness and basic safety properties. The model should treat the input as an immutable sorted array (nondecreasing order) and a target key. It should allow the search to proceed by repeatedly narrowing an interval of potential indices until the key is found or the interval is empty.

Requirements:
- The algorithm must terminate in a finite number of steps for any finite input sequence and any key.
- If the key occurs in the input sequence, the algorithm must return an index within the valid index range such that the element at that index equals the key.
- If the key does not occur in the sequence, the algorithm must report failure (no index returned) and guarantee that no index returned points to the key.
- At every step the maintained search interval must be a closed subinterval of the original index range, and the invariant must ensure that if the key exists in the array then some index within the current interval contains the key.
- The model must account for off-by-one and mid-point computation correctness: mid selection must be an integer index in the current interval. The specification should allow any reasonable mid computation that respects integer bounds.
- Safety properties: the algorithm must never read or write outside array bounds, and any reported index must be within bounds.
- Liveness property: termination with either a correct index or a definitive failure answer.

Do not prescribe internal control-flow details; specify only the abstract state (array, key, current interval, and result/status) and the correctness invariants and termination property.
