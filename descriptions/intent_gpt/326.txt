Model a distributed partial link-reversal routing algorithm for a network of nodes forming a directed graph that may be disconnected. The system evolves in synchronous rounds in which a subset of sink nodes (nodes with no outgoing links and not equal to a designated destination) are allowed to reverse some of their incident links. The model should represent only abstract nodes and directed edges and must not hard-code local implementation steps.

Requirements:
- Initial state: a directed graph without directed cycles (a DAG), with a distinguished destination node.
- At each step, any nonempty subset of current sinks may act concurrently. Each acting sink may choose a subset of its incoming neighbors whose incident edges it will reverse (turn into outgoing edges for the sink). The rest of the network updates consistently to reflect those reversals.
- After each step the graph must remain acyclic.
- Progress requirement: once a node becomes a sink (other than the destination) it must eventually perform a reversal or cease to be a sink because others reversed edges; overall the system should avoid livelock where some sink forever defers reversal while the network makes no progress toward routing to the destination.
- Safety properties: no node creates self-loops; edge updates are symmetric and consistent (if an edge u->v is removed then v->u is added only when intended).
- Liveness/invariant to guarantee termination under fair scheduling: either each non-destination node eventually has a directed path to the destination, or the set of sinks stabilizes only when no sink exists.

Specify these behaviors and correctness properties abstractly so formal verification can check acyclicity invariants, edge consistency, and the required liveness/progress conditions.
