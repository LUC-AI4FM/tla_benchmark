Specify an asynchronous distributed algorithm that constructs a spanning tree in an undirected, connected graph starting from a single designated initiator. Model each node as an independent process that communicates by exchanging two kinds of messages over reliable but unordered channels: "explore" messages used to discover the network and establish parent links, and "acknowledge" messages used to announce child relationships back to parents. The system must allow the initiator to start by sending explore messages to all its neighbors; a non‑initiator adopts the first neighbor from which it receives an explore message as its parent and forwards explore messages to its remaining neighbors; every node must count messages from all neighbors and, after receiving one message from each neighbor, send an acknowledge to its parent (if any). Communication may be concurrent: multiple messages can be in flight, and message delivery order is arbitrary but messages are not lost or duplicated.

Formalize the global state, per‑node local state, and nondeterministic message delivery. Specify safety properties: the initiator never has a parent; any recorded parent of a node must be one of its neighbors; child sets reflect parent relationships (if a node records another as its child then that child has the node as its parent), and when all nodes have completed, parent links form an acyclic structure whose root is the initiator and that reaches every node (i.e., a spanning tree). Specify liveness: every node eventually completes the protocol. Also require type and invariants ensuring message formats and neighbor relations are well formed.
