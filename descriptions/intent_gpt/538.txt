Specify a system that computes the square of a nonnegative integer by iteratively summing odd numbers. The model should accept as input any natural number from a provided nonempty set of allowed inputs. The algorithm must start with a running total of zero and an iteration counter at zero, then repeatedly increment the counter and add the next odd integer (2*k − 1 for the current counter value k) to the total until the counter reaches the input value. On termination, the total must equal the square of the input and the iteration counter must equal the input.

Model the computation as a state-transition system that permits stuttering steps after termination (so termination is not treated as deadlock) and that allows arbitrary scheduling of the iterative step as long as it respects the sequential update of counter then total. The specification must require that for every allowed input value the process eventually reaches the terminated state (liveness: eventual termination). It must also require the invariant property that at all times the running total equals the sum of the odd numbers corresponding to the number of completed iterations (so the total is always equal to the current counter squared if proven), and the safety property that no step changes the input value. Finally, express a correctness property: upon termination, the total equals the square of the initial input and the counter equals that input.
