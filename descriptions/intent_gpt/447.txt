Specify a concurrent/state-machine system that maintains a single integer-valued register ranging over a small fixed ring (e.g., 0..4). The system repeatedly updates the register in discrete steps. Each step computes a temporary value by adding one to the current register, then maps that temporary value through a deterministic modular increment function provided by a separate component (an abstract module or subroutine) and stores the result back into the register after subtracting one. The separate component should be treated as an abstract, deterministic function that, given an integer input, returns an integer output; its behavior is fixed throughout an execution but may be specified independently.

Model initial condition: the register starts at 0. Model transitions that perform the described read-compute-write update atomically. Allow only those transitions and require weak fairness of the update action (so it cannot be permanently disabled if continuously enabled).

Specify and verify two correctness requirements:
- Safety: the register value always stays within the allowed ring of values (e.g., 0..4).
- Liveness: the system eventually reaches the designated target value (e.g., 4) infinitely often (or at least once, as appropriate), expressed as a recurrence property such as "always eventually target".

Do not prescribe how the separate component is implemented; model it abstractly and ensure the system's correctness properties hold for any compliant deterministic implementation of that component.
