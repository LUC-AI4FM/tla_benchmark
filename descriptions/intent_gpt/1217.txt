Specify a formal model of multisets (bags) and their common operations, and state the correctness properties those operations must satisfy. The model should treat a bag as a finite mapping from elements to positive integer multiplicities, allow an empty bag, and support converting between sets and bags (a set to the bag with one copy of each element, and the bag-to-set that returns elements with nonzero multiplicity). Include operations for bag union (sum of multiplicities), bag difference (subtract multiplicities, dropping elements with zero copies), element membership (true iff multiplicity > 0), counting copies of an element, computing the total cardinality (sum of multiplicities) for finite bags, and forming the image-bag of a function that maps each element to a value and aggregates multiplicities by value.

Model derived concepts: subset relation on bags (componentwise ≤), the set of all subbags of a bag, maximum multiplicity in a bag, and the union of a family of bags. Ensure operations are defined so undefined or infinite cases are handled safely (e.g., totals unspecified for infinite bags).

Specify invariants and lemmas to verify, including:
- Set-to-bag followed by bag-to-set recovers the original set.
- Bag union adds multiplicities elementwise; bag difference subtracts but never produces negative multiplicities.
- Empty bag is the identity for difference of a bag with itself and for union neutral element.
- Membership corresponds to positive multiplicity; copies function returns zero when not a member.
- Bag subset relation corresponds to domain inclusion and multiplicity comparison.
- Cardinality sums multiplicities and agrees with expected values for constructed examples.
- Bag-of-image preserves multiplicity aggregation (counts of target values equal sums of preimage multiplicities).
- Counting properties for composed operations (e.g., union and difference) and cardinality of subbag sets must match combinatorial expectations.
