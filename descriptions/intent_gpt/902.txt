Specify a formal model of a multicore write-through cache system with a global memory request queue and a single shared backing store. The model should represent multiple processors issuing read and write memory operations, each processor having a small private cache for addresses and a per-processor control state and request buffer. The system must queue outstanding memory requests up to a fixed queue length and process them in FIFO order to the backing store. Reads that miss in a processor’s cache should enqueue a read request and later be served from the backing store, updating that processor’s cache. Writes should be propagated (written through) to the backing store by enqueuing a write request; when a write is enqueued, cached copy values visible to other processors must be updated so caches remain coherent. Evictions may remove entries from a processor’s cache but must not occur while that processor is blocked waiting for a response to a request for the same address. The backing store’s visible state should evolve as if queued writes are applied in order; reads served from the queue should reflect the effect of prior queued writes to the same address. The specification must guarantee type-safety of all state components, the preservation of cache coherence (if two caches both hold a value for the same address they agree), FIFO semantics of the memory request queue, and that every issued request eventually receives a response (no permanent starvation), assuming the queue can make progress.
