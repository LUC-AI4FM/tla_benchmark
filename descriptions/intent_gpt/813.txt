Specify a formal model of a parallel graph reachability algorithm that discovers the set of nodes reachable from a distinguished root node in a finite directed graph. The model should describe a collection of concurrent worker processes that cooperatively traverse successors of nodes and mark nodes as discovered. The system must allow workers to pick unprocessed nodes, explore their outgoing edges, and add newly discovered nodes for further exploration, possibly concurrently with other workers doing the same. The algorithm must tolerate redundant work (multiple workers may examine the same node) but must never lose nodes: every node that is reachable from the root must eventually become marked, and no node should be marked unless there exists a path from the root to it in the graph. The specification must capture liveness that guarantees termination of marking: if the graph and the set of workers are finite and the workers repeatedly take enabled steps, then eventually no worker has any more work and the set of marked nodes equals the reachable set. Safety properties to assert include: marked nodes are always a subset of graph nodes; once a node is marked it remains marked; and only nodes reachable via a finite sequence of successor edges from the root may be marked. Liveness properties to assert include eventual completion and progress: reachable nodes are eventually marked, and the system reaches a quiescent state with no pending nodes. The model should abstract away implementation details like message formats or lock mechanisms and instead represent atomic actions of taking a node, exploring its successors, and adding discoveries.
