Model a simple concurrent/state-transition system that tracks three independent state components where one component is updated regularly, one component may be left unchanged by some transitions, and another component is an externally supplied constant value. The model must capture initialization, a repeated transition that increments the regularly-updated component while leaving the unchanged component stable, and the presence of a fixed constant supplied from outside the module. Specify the allowable initial values for each component, the guard that enables the increment step, and that the increment repeats until a termination condition is reached. Require that transitions explicitly indicate which components change and which remain unchanged. Guarantee the following correctness properties:

- Safety: the unchanged component never changes value in any reachable state while the incrementing action is enabled; the externally supplied constant remains equal to its initial supplied value in all states.
- Progress: the incrementing action is enabled repeatedly until the termination condition (a bound on the incrementing component) is reached.
- Invariant: all components always hold values from their declared finite domains.
- Liveness: from any reachable state where the incrementing guard holds, eventually a state with the incremented value is reached.

Do not commit to a particular implementation technique; allow the constant to be provided by instantiation or module composition.
