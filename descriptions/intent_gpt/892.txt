Specify a formal TLA+ model of a simple asynchronous one-way communication channel between a single sender and a single receiver. The model must capture that the sender can place messages into the channel and the receiver can extract messages, with the channel buffering at most one message at a time (it is either empty or contains exactly one message). The system should allow the sender to attempt to send only when the channel is empty, and the receiver to attempt to receive only when the channel is nonempty. Message values come from a fixed finite set.

State the safety properties that must be guaranteed: the channel's content is always either empty or a valid message from the message set, and no action can create an invalid channel value. Also require type safety for any auxiliary state used to track send/receive steps. Specify liveness requirements optionally: if the sender repeatedly tries to send a particular message when the channel is empty, then eventually the receiver will receive it (or at least the channel will transition accordingly), and if the receiver repeatedly tries to receive while the channel contains a message, then it will eventually succeed. Require that the specification be amenable to mechanical proof: include an invariant that proves the channel's type correctness and is preserved by all actions. The model should not commit to any particular implementation technique beyond these semantics.
