Specify a formal TLA+ model of a classical binary search algorithm that operates on finite sorted sequences of comparable keys. The model should accept as parameters a maximum allowed sequence length and a sequence drawn from all nonempty sequences whose length does not exceed that maximum. The algorithm must search for a target key and must correctly report whether the key exists in the sequence and, if so, return an index at which the key is located; if the key is not present, it must report failure deterministically. The model should permit arbitrary valid inputs within the bounded length and support the possibility of duplicates, but the correctness criteria must be defined relative to membership and index validity (i.e., any reported index must point to an element equal to the target and indices must lie within sequence bounds).

Specify the initial conditions, the allowed state transitions of the search (high-level, not implementation-specific), and the termination condition. State key invariants: the search always maintains that the target, if present, lies within the current search interval; interval bounds remain within sequence limits; and the search interval strictly decreases until termination. Define safety properties (no out-of-bounds access, only valid indices returned) and a liveness/property of eventual termination on all inputs within the bounded size. Include a formal property expressing correctness of the final result (found iff membership).
