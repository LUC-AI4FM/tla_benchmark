Specify a small expression-language sanity-check model that verifies operator precedence and associativity rules across many infix operators. The model should represent expressions built from fixed atomic operands and a wide variety of binary infix operators (including ordinary symbols, ASCII punctuation, and LaTeX-like symbols) and should evaluate or otherwise compare parsed expression trees to expected canonical groupings. The goal is to ensure that for each operator or combination of operators, the language’s parsing rules produce the intended left- or right-associative grouping and precedence with respect to other operators. Requirements:

- Represent atomic values and the binary application of any supported operator, including repeated uses of the same operator and mixed sequences of different operators.
- For each test case, assert that the parsed/constructed expression has the canonical nested structure expected by the precedence and associativity rules (for example, left-associative chaining produces ((a op b) op c)).
- Include tests that exercise interactions between operators with different precedence classes and confirm grouping across parentheses and grouping-sensitive operators.
- Report or fail when any asserted grouping or precedence expectation is violated.
- The model should be deterministic and finite so that model checking can exhaustively confirm all specified grouping properties.
