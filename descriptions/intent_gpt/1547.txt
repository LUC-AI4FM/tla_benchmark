Specify a formal TLA+ model of a buffered random-access file abstraction that exposes the same externally visible behavior as an unbuffered random-access file while maintaining an internal fixed-size in-memory buffer. The model should describe a single-threaded file object that permits seeking to arbitrary offsets, reading and writing sequences of bytes at the current pointer (which advances), and resizing the file. The buffered implementation must use an in-memory window covering a contiguous range of file offsets and may delay writing modified bytes to the underlying file until an explicit flush or when replacing the buffer region.

Requirements:
- Expose the abstract file contents and file pointer that clients observe; the buffered implementation must refine this abstract behavior (i.e., every buffered operation must correspond to a valid abstract operation and the observable file content/pointer must match the abstract file after each operation).
- Maintain invariants relating buffer position, current pointer, buffer contents, and whether the buffer is dirty, ensuring the buffer, when relevant, correctly overlays the logical file contents and that a dirty flag indicates divergence from on-disk content.
- Ensure read and write operations that operate entirely inside the current buffer succeed without disk access and update the pointer and dirty state appropriately; operations that move the pointer outside the buffer must arrange to make the correct buffer visible (possibly flushing first) so that subsequent reads/writes preserve semantics.
- Model flush and seek semantics: flush must propagate buffered modifications to the underlying file and clear the dirty flag; seek must position the pointer and, if needed, load the buffer region corresponding to the new position (without losing unflushed changes).
- Model set-length to truncate or extend the logical file, adjust pointer if necessary, and maintain buffer consistency where relevant (bytes outside new length become undefined/arbitrary).
- Specify safety properties: internal invariants always hold, buffered behavior refines the abstract file, and each buffered operation individually refines its abstract counterpart.
- Allow nondeterministic contents for newly extended or truncated regions (arbitrary symbols) so the model can represent unspecified bytes.
