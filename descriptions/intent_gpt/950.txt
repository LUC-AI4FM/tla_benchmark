Model a real-time hour clock that advances an abstract hour counter whenever a continuous real-valued global time reaches approximate one-hour intervals. The system must represent a real-valued monotonically increasing global time source and an hour counter that increments only when a one-hour epoch has elapsed, within a bounded timing jitter. The clock must guarantee that between successive hour increments the real time increases continuously and strictly, and that each increment occurs when the elapsed real time since the last increment is within a specified tolerance of exactly 3600 seconds. The tolerance is a positive constant: each hour tick must happen no earlier than 3600 − tolerance and no later than 3600 + tolerance after the previous tick. The model should permit arbitrary dense real time progress and fairness so that time can always advance beyond any given real value and hour increments are not starved by time progression. The specification must assert invariants capturing the timing bounds, liveness guaranteeing that hour ticks continue to occur as time progresses, and that the hour counter advances by exactly one on each tick. Abstract away scheduling/internal algorithmic details; focus on the real-time semantics, timing constraints for ticks, monotonicity of time, and the safety and liveness properties described.
