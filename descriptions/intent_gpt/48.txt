Specify a model of a simple integer-manipulation system with a mutable finite set of integers and a collection of deterministic integer functions. The system must allow operations that (a) increment a given integer, (b) add or remove integers from the mutable set, and (c) compute the factorial of a nonnegative integer. The model should treat the increment and factorial computations as atomic, deterministic computations (no nondeterministic choice in their result), and the factorial must be defined for all nonnegative integers using recursion or an equivalent functional definition. The mutable set must always remain a subset of the integers and only be changed by explicit add/remove operations. Specify initial conditions for the set and any parameters controlling allowed integers. Specify actions that apply an increment to an integer value, insert an integer into the set, and remove an integer from the set. Ensure the model captures termination and totality of the factorial computation for nonnegative inputs and that increment operations preserve integer-typedness. Formalize safety properties: the set always contains only integers, add/remove operations do not produce duplicates beyond set semantics, and factorial produces correct mathematical results for tested inputs. Formalize liveness or progress properties: any requested increment or set-operation eventually occurs (if modeled), and factorial evaluation completes for all nonnegative arguments. Include invariants and checks that these properties hold.
