Specify a simple discrete-state system in which a single integer-valued state variable initially takes one of two distinct values and on each step can be changed nondeterministically to one of two other distinct values. The model should capture all possible executions starting from either initial value and allowing either transition repeatedly.

Require the specification to assert safety properties that certain values are never reachable: explicitly forbid a small set of integer values throughout all reachable states. Also require an invariant that is a predicate over the state variable (for example, a positivity condition) to hold in all reachable states. The specification must verify that the stated invariant is preserved by every transition from every reachable state and that none of the forbidden values can ever occur.

Include verification goals: show that every reachable state satisfies the invariant and that the forbidden values are unreachable; if either property fails, the model should allow counterexamples showing an initial state and a sequence of transitions leading to the violation. Do not constrain the modeling to any particular implementation approach; describe only the allowed initial values, the allowed transitions, and the required global safety properties to be checked.
