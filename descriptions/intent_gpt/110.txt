Specify a simple reactive system that ensures a single boolean fault flag is never set. Model an environment that repeatedly executes steps and may nondeterministically attempt to set or clear the fault flag, and a controller that must prevent the flag from ever becoming true. The system should initialize with the flag cleared and then repeatedly progress through discrete steps where both the environment and the controller may act; the controller may inspect the current state and take actions to keep the flag cleared. The specification must allow the environment to propose making the flag true but require the controller to ensure the actual state never reaches true. Express transitions nondeterministically so that both the environment’s attempts and the controller’s responses are visible, but the global state must always satisfy that the fault flag is false. Formalize safety properties guaranteeing the flag is never set, and include an invariant and a proof obligation or checkable property asserting that every reachable state satisfies that invariant. Do not assume any particular scheduling or fairness; the correctness must hold under arbitrary interleaving of steps.
