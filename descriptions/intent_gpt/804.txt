Specify a model of a deterministic search procedure that, given a sorted finite sequence of comparable integer values and a target integer, repeatedly narrows an index range to determine whether the target appears in the sequence. The model should accept any sorted sequence and any target from a given domain. It must maintain a current inclusive lower and upper index bound that always lie within or immediately adjacent to the valid index range, and a result indicator that is either zero (meaning “not yet found” or “not present”) or an index pointing to a found element.

The model must capture the search loop that chooses a middle index of the current bound and examines the element at that index; if the element equals the target it must set the result to that index and terminate, otherwise it must shrink the bound to the appropriate half that could still contain the target. The model should allow termination when the bounds cross, indicating no element equals the target.

Specify the following correctness properties to be proved as invariants or temporal properties:
- Safety (partial correctness): if the procedure terminates with a nonzero result, the sequence element at that index equals the target; if it terminates with result zero, the target does not occur anywhere in the sequence.
- Invariant bounds and typing: indices and result stay within valid integer ranges throughout execution; bounds always define a contiguous integer interval or adjacent indices when empty.
- Progress/termination: from any initial state the procedure eventually reaches a terminal state (either found or proven absent) under fair scheduling.
- Preservation of sortedness and that narrowing always preserves the existence (or nonexistence) of any target element within the current bounds (i.e., if the target exists in the whole sequence, it is always contained within the current bound until found).
