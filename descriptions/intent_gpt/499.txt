Specify a formal model of a replicated consensus protocol that provides multi-slot consensus (multiple independent instance slots) for proposing and learning values. The model should represent a set of proposers, acceptors, and learners interacting by exchanging messages to reach agreement on a value for each slot. The system must permit multiple rounds (ballots) and must support quorums of acceptors whose votes determine that a value is chosen for a given slot and ballot.

The model should capture these requirements and correctness properties:

- Safety (consistency): For every slot, at most one value can be learned (or chosen) by learners — once a value is chosen for a slot, no other distinct value can become chosen for that slot.
- Nontriviality (validity): Any value learned for a slot must have been proposed by some proposer for that slot.
- Stability (persistence): Once a value is learned for a slot it remains learned thereafter (learned sets are monotonic).
- Progress under favorable conditions: If proposers make proposals and a majority/quorum of non-faulty acceptors participate, some proposed value will eventually be chosen for a slot (liveness under partial synchrony or sufficient synchrony assumptions).
- Quorum intersection: The model should enforce that any two quorums intersect (so that previously chosen values are preserved when newer ballots are used).

Model the state abstractly (messages in transit, proposers’ current ballots, acceptors’ highest promised ballots and per-slot votes, learners’ learned values) and specify allowable actions for proposers, acceptors, and learners (sending/receiving prepare/accept messages, updating ballots and votes, learning chosen values). Do not prescribe a specific implementation of leader election; instead allow multiple proposers and multiple concurrent ballots. Formalize chosen as the existence of a quorum of matching acceptor votes for the same slot and ballot. State invariants and temporal properties that ensure the safety and nontriviality requirements above, and include an eventuality property that under reasonable assumptions guarantees progress for some slot.
