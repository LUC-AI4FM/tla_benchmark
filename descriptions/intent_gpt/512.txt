Specify a distributed algorithm for constructing a shortest-path spanning tree from a distinguished root node in an undirected connected network, using asynchronous message passing over bidirectional channels. The model should represent a fixed set of nodes and undirected edges; every node initially knows only its neighbors and whether it is the root. Nodes communicate by sending and receiving integer distance estimates over per-edge FIFO-less channels (modeled as multisets or sets of messages on each directed channel). The protocol must converge so that every node eventually learns (a) its distance to the root equal to the length of a shortest path, and (b) a parent neighbor that lies on some shortest path to the root. Messages initially originate at the root with distance 0; non-root nodes initially consider their distance infinite and their parent unknown/self. When a node receives a message containing a distance d, it may update its stored distance to d+1 and set its parent to the neighbor from which the message arrived, then propagate its new distance to its other neighbors. The model should allow arbitrary interleaving and fair delivery of enabled message-processing steps. Key correctness properties to guarantee:

- Safety: Every node’s final stored distance equals the graph-theoretic shortest-path distance to the root, and the parent pointers form a spanning tree rooted at the root (no cycles, all nodes reachable from root via parent links).
- Monotonicity and validity: Distances never increase when a node adopts a smaller value; any adopted distance is one plus some neighbor’s previously known distance.
- Liveness (convergence): Under weak fairness of node actions and reliable message delivery, all nodes eventually stabilize to their final distance and parent, and no further messages are sent.

Do not constrain implementation details such as specific data structures for queues, explicit per-step assignments, or a particular recursive computation for reachability.
