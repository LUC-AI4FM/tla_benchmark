Specify a simple state machine that demonstrates and validates printing/logging operations for values of several basic types. The model should initialize six distinct data items, one each of: string, boolean, integer, set of strings, sequence of strings, and record mapping two string fields. It should allow transitions that perform print/log operations on these items in two ways: printing to a fresh (empty) output target, and printing to the current value of the same item (i.e., treating the item as the output target). Also include transitions that exercise a typed-print facility that inspects values and records their types. The print operations must not change the logical values of the items being printed.

The specification should treat printing as a side effect that is observable (e.g., by allowing a print action to occur) but does not mutate the modeled data items. It must allow repeated printing of the same values, and both forms of printing (to empty output and to the current value) must be enabled. The model should assert that the items always retain their initial types and values (invariance), that print actions never alter state (stuttering on the items), and that all print operations are reachable from the initial state (liveness of print actions). Model properties to check: type/value preservation invariants and eventual occurrence of each kind of print action.
