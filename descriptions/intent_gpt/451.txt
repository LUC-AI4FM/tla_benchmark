Specify a concurrent system of a single shared integer-valued variable that is manipulated by two independently-configurable modules: one module provides a parameterizable component that may be instantiated twice with different parameter bindings. Model the behavior of the shared integer as taking values in a fixed bounded range (0..4). The system must allow the parameterized components to access and possibly update the shared integer according to their own local rules, but the composition must ensure the global integer always stays within the allowed range.

Describe the module interface abstractly so it can be instantiated with different actual parameters: the interface should include an operation that can read and increment or reset the integer, and a specification of the legal changes that operation may perform relative to a parameter. Allow one instantiation to be created by explicit parameter substitution and another to be created by a binding that reuses the shared variable directly. The composed system must expose a global safety invariant that the integer remains in 0..4 at all times, and a liveness property that whenever the integer is below the top value, some component can eventually increase it. Also ensure there are no spurious behaviors introduced by different instantiation mechanisms—behavioral equivalence of the two instantiation styles should hold with respect to the observable effects on the shared integer.
