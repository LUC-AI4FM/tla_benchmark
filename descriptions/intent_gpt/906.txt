Specify a formal model of a two-layer communication abstraction: a low-level unreliable bit channel and a high-level reliable packet channel that the low-level layer implements by grouping bits into multi-bit data units. The model should describe processes that send and receive information through the low-level channel as sequences of bits, accumulate bits into fixed-size groups, and deliver an encoded multi-bit value on the high-level channel when enough bits have been transmitted. The system must also allow the low-level channel to nondeterministically exhibit an error that corrupts its state without performing a send or receive step, and when such an error occurs the high-level channel must be driven to a designated error value.

Requirements:
- Model the low-level communication primitive that can send a single bit or perform a receive operation; multiple low-level operations compose to represent one high-level data transmission.
- Define the encoding from a sequence of bits into a numeric data value and require that exactly when the requisite number of bits have been sent in order, the corresponding high-level data value becomes available on the high-level channel.
- Permit the low-level channel to change arbitrarily only via a special error transition; when such an error transition occurs, ensure the high-level channel is set to a special error value and no low-level send/receive action is recorded for that transition.
- Ensure safety: high-level data values must only appear as the result of completing the correct bit sequence; no spurious high-level value may appear. Ensure liveness: if bits continue to be sent without error, the model must eventually produce the corresponding high-level value after the required count of bits.
- Allow multiple independent instances of the bit-accumulation process (parameterized by the bits already sent) to run concurrently, and specify the initial conditions for both channels and accumulators.
