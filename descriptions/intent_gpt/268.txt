Specify a TLA+ model of a stateless collection of record/row value operations and the expected relationships among those operations. The model should describe abstract records with named fields (possibly different types per field) and support: constructing records with given field values; constructing a set of records from per-field value-sets (cartesian product over fields); accessing a field value from any record that contains that field; updating a single field in a record to a new value while leaving other fields unchanged; computing the domain (set of field names) of a record; and quantifying existence over a record set built from per-field value-sets.

The specification must assert properties that must always hold about these operations: construction produces non-empty values when non-empty inputs are given; building records from per-field sets yields exactly the set of pointwise records (the cartesian product); field access is polymorphic in the record’s other fields and returns equal results on records that share the same value for that field; single-field updates behave uniformly across different record “types” so that the updated field value is equal for corresponding updates; the domain of records constructed from the same field names is equal across different value assignments; and existential quantification over the constructed record set can find records whose individual fields lie in the specified per-field value-sets.

Do not model process scheduling or mutable state—this is a purely functional specification of record values and their algebraic properties. Include these properties as invariants suitable for model checking.
