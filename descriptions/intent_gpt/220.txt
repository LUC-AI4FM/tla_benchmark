Specify a small-state transition system that models a component making nondeterministic selections from a set of discrete choices over time. The model should start in a fixed initial state where three finite-valued state elements have particular initial values. At each step the component may update one or more of these elements by choosing values from specified finite sets; some choices are independent while others are constrained to occur together (i.e., certain combinations of simultaneous assignments are allowed or disallowed). Model the selection behavior as nondeterministic: any allowed choice may be taken at a step so long as it respects the combination constraints.

Require that the model capture reachable-state exploration under fair nondeterminism (no starvation of enabled choices). Specify invariants expressing that every state variable always takes a value from its intended finite domain. Specify safety properties forbidding certain forbidden combinations of values (for example, never allow two particular values to hold simultaneously, and never allow an illegal simultaneous assignment pattern). Specify basic liveness goals: from any reachable state it must always be possible to eventually reach a state in which a designated variable assumes each of its allowed values (i.e., each choice is eventually taken). Also require that if a transition chooses to change one variable in a way that requires another variable to take a particular dependent value, that dependent value must hold immediately in the same step. The specification should be abstract (no implementation details) and suitable for model checking.
