Model a simple system that maintains a single integer-valued state and exposes an instantiated component that reads that state. The system should initialize the integer to zero and never change it thereafter. The component should have a read-only expression that always evaluates to the current value of the integer in the enclosing system. Specify the system's behaviors (initial condition and transitions) and formalize properties that relate the component's read expression to the global state.

Require the following correctness properties: (1) The only reachable state is the initial one with the integer equal to zero. (2) The component's read expression always equals the global integer value in every reachable state. (3) It must be possible to assert the enabledness or truth of temporal formulas that refer to the primed (next-state) value of the component's read expression; such assertions should correctly reflect the next-state value of the underlying global integer. Also require that no transition modifies the integer, so invariance of the integer value holds globally and temporally (e.g., always integer = 0). Finally, specify that checks of enabledness or equality involving the primed component expression are well-defined and consistent with substituting the component's read expression by the actual global variable it accesses.
