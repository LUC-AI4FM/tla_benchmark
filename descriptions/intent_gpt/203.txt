Specify a system that models an integer-valued function defined recursively as the factorial of a nonnegative integer, and a simple two-state computation that initializes and later updates a stored value of that function. The model should treat the factorial definition abstractly as a total function from integers to integers with the intended mathematical meaning: for any integer n, if n ≤ 1 the function returns 1, otherwise it returns n times the function applied to n−1. The system must allow computing the factorial for several concrete nonnegative arguments and storing those computed results in a single mutable integer register.

Require the initial state to hold the register equal to the factorial of a specific argument (for example 4), and allow a single transition that updates the register to the factorial of another specified argument (for example 7). The specification should assert that the register always contains a positive integer (i.e., at least 1) in both the initial and all reachable states.

Key correctness properties to guarantee:
- The recursive factorial function is well-defined and total for the domain of integers considered (in particular nonnegative integers used as arguments).
- The register always holds the exact value of the factorial of some concrete integer argument and thus always satisfies the positivity invariant.
- The transition from the initial value to the updated value terminates and preserves the invariant.

Do not prescribe an implementation strategy; permit verification by unfolding or by reasoning about the recursive mathematical definition.
