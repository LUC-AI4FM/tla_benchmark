Model a nondeterministic two-state system representing a quantum-like bit that can be observed but not altered by the observer: initially the system must be in a definite "alive" state. The system may nondeterministically either remain in its current state or transition to a "dead" state at any step. The specification must treat the "alive" and "dead" values as mutually exclusive and exhaustive states of the system. Specify the initial condition, the allowed state transitions, and the liveness and safety requirements below.

Safety requirements:
- The only allowed states are the two named states; no other values are permitted.
- No transition may produce a state outside the defined two-state set.
- If the system is "dead", it must remain one of the defined states (no emergence of spurious values).

Liveness / progress requirements:
- From the initial "alive" state, the system must be able to stay "alive" indefinitely or eventually become "dead" nondeterministically.
- It must be possible to reach the "dead" state (i.e., the dead state is reachable from the initial state in some execution).
- If desired, assert a fairness condition that disallows perpetual postponement of the death transition so that the system cannot be forced to remain alive forever when progress is expected.

State clearly which properties are invariants versus liveness properties to be checked.
