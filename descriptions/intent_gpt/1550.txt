Specify a model of distributed termination detection for an arbitrary asynchronous message-passing system based on constructing a dynamic overlay tree rooted at a distinguished leader. The model should treat processes as either busy (active) or idle, allow asynchronous, unordered, reliable delivery of two kinds of messages (application messages that trigger work and control acknowledgments), and let any busy process send application messages to any neighbor according to a fixed directed network graph. The leader initially starts the computation; it cannot receive application messages. When a process receives an application message it becomes busy; busy processes may become idle at any time. For each application message a sender must eventually receive an acknowledgment from the receiver; receivers send acknowledgments subject to rules that enforce the overlay tree discipline: when a neutral (idle and fully acknowledged) process receives an application message its sender becomes its parent in the overlay tree; a process may send its last acknowledgment to its parent only when doing so would restore its neutrality, at which point it leaves the tree. The specification must capture message counts in transit, the invariant relationships among counters, and the fact that non-neutral processes always form a tree rooted at the leader. Require the following correctness properties: safety—if the leader is declared neutral then all processes are neutral (so no outstanding work or messages remain); liveness—if the global computation truly terminates (all processes idle and no messages in transit) then the leader eventually becomes neutral; and preservation of counter consistency (message/ack counters remain balanced). Do not prescribe implementation details beyond these behavioral rules.
