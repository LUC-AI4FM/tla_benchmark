Specify a formal model of a binary search procedure that operates over a finite array of integers encoded with a fixed bit width. The model should treat the array and the search key as parameters and must allow for empty arrays and arbitrary-length arrays up to the representable range. The specification must capture the algorithm’s control flow (initialization, iterative or recursive narrowing of the search interval, termination) but should not prescribe a particular coding style; it must describe what the algorithm is required to achieve.

Requirements:
- The algorithm must maintain and update a current search interval [low, high) (or equivalent inclusive/exclusive bounds) and must compute midpoints to examine elements.
- If the key occurs in the array, the procedure must eventually terminate and return an index where the array element equals the key.
- If the key does not occur, the procedure must eventually terminate and return a distinguished failure value.
- The procedure must never access array indices outside the legal range determined by the array length and the fixed integer width.
- All arithmetic on indices and midpoint computations must be defined within the fixed-width integer domain, avoiding overflow errors; the model must capture wrap-around behavior or otherwise forbid overflow.
- The model must prove termination and partial correctness: upon termination, the reported index (if success) must satisfy array[index] = key; if failure, no index in the array equals the key.
- The specification should also state invariants ensuring bounds are maintained and that progress is made (e.g., the interval strictly shrinks or the algorithm reaches a base case).
