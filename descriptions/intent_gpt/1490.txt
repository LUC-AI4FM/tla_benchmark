Model a simple finite-state transition system where a single state component takes integer values and evolves in discrete steps according to two elementary step types composed in sequence. The system must start in a designated initial state and repeatedly perform only transitions that are the sequential composition of a first step (choose one of several allowed immediate successor values depending on the current value) followed by a second step (again choose an allowed successor depending on the intermediate value). Specify the allowed source-to-target pairs for each elementary step abstractly so that some sources enable multiple targets and some sources have no outgoing moves for that step. The composed step must be atomic from the external observer’s viewpoint: both elementary steps occur together as one Next transition. Require invariants: (1) a safety property that the state always stays within a specified set of safe values; (2) a liveness or reachability constraint stating that either the state remains below a given threshold or the composed Next transition is enabled; and (3) a property asserting that a certain ordering of step types (the reverse composition) never occurs as a single atomic transition. Also specify a variant that requires the composed Next transition to always be enabled (global progress). Ensure the specification isolates initial condition, Next-step relation (as composition of two actions), and the safety/liveness properties to be model-checked.
