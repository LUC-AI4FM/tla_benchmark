Specify a simple system that models a single, persistent constant and a single mutable storage location holding an integer. The system should allow the integer storage to be read and updated nondeterministically at any time, subject only to being an integer. The constant represents a fixed parameter that cannot change. The model must capture initialization (the storage starts with some integer value) and arbitrary state transitions where the storage may be assigned any integer value. Formalize the state space, initial condition, and transition relation without tying the description to any specific implementation language or syntactic constructs.

Require the specification to guarantee basic safety and liveness properties: safety — the system never changes the constant; and safety — every state contains an integer in the mutable storage. Liveness — from any reachable state, it must be possible to reach a state where the storage holds any given integer value (i.e., the system can eventually assign any integer). Also require that the specification detects malformed or ambiguous definitions (for example, duplicate declarations or ill-formed expressions) during model checking, so that such issues are reported rather than silently ignored. Provide enough structure to enable exhaustive exploration of reachable states and verification of the stated properties.
