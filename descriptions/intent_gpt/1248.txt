Specify a formal model of the integer arithmetic abstraction used by a verification tool: the system should provide the semantics of whole-number values and arithmetic operations needed by higher-level specifications. Model an unbounded (mathematical) integer domain together with standard arithmetic and comparison operators (addition, subtraction, multiplication, unary negation, division and modulus if desired, and relational operators like equality, <, ≤, >, ≥). The model must allow these operators to be applied in expressions and used as values in formulas, preserving the usual algebraic laws (commutativity, associativity, distributivity where applicable), identities (0 for addition, 1 for multiplication), and inverses (additive inverse for every integer). It must also define ordering as a total order compatible with algebraic operations and support reasoning about signs (positive, negative, zero). Specify how arithmetic interacts with boolean expressions and logical quantification (e.g., quantifiers over all integers). Ensure the model is consistent (no contradictions such as distinct elements identified) and supports substitution and evaluation of expressions in proofs and model checking. The specification should not impose machine bounds; if a bounded variant is required, allow parameterization to restrict to a finite range while preserving the same operator semantics within that range.
