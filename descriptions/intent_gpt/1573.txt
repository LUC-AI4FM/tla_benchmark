Specify a concurrent system of three identical processes that read and use a shared numeric state to compute a local value and immediately assert a property about that value. The system must model:

- A single shared integer initialized to 0.
- Three processes that execute independently and may interleave arbitrarily.
- Each process, when it runs, must (atomically with respect to other actions) compute a local result equal to the shared integer plus one, and then compute a second local result equal to that first result plus one; the process then stores the second local result into its own local register and immediately checks an assertion that this stored value equals 2.
- Processes do not modify the shared integer (it remains constant at 0), and each process terminates after performing its computation and assertion.
- The system must allow processes to run in any order and model fairness so that every process that can take a step will eventually do so (weak or strong fairness as needed).

State the correctness properties to verify:

1. Safety: no execution should cause any process assertion to fail — i.e., every process's stored local value must equal 2 when asserted.
2. Termination: all processes eventually reach a terminated state.
3. Invariance: the shared integer remains equal to its initial value throughout execution.

Do not commit to a specific implementation or scheduling mechanism; model only the states, the atomic computation-and-assertion step of each process, allowed interleavings, and fairness assumptions required to prove termination and preservation of the invariant.
