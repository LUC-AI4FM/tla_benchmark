Specify a formal model of a deterministic functional update process that folds a sequence of keys into a finite map (function from keys to integers) by repeatedly setting the value for each key to 1. The system should start from a map that assigns 0 to each key in a fixed finite domain of string keys. Then, given an ordered sequence of keys (which may include each key at most once, but the model should allow arbitrary sequences drawn from the domain), the process must apply an operation for each element of the sequence in left-to-right order that updates the map so that the entry for that key becomes 1 while leaving other entries unchanged. The process is purely functional (no concurrent interference) and terminates after processing the whole sequence.

Specify properties to verify:
- Safety: after folding the entire sequence, every key that appears in the sequence must map to 1, and keys not appearing must retain their initial value (0).
- Totality: the folding operation must produce a well-defined map over the entire domain.
- Determinism: for a given initial map and sequence, the final map must be unique.
- Additionally, assert and check the negation of the intended invariant (that all domain keys equal 1 after folding a sequence that contains every domain element), so that the verifier can detect whether the negated assertion is unsatisfiable.

Parameterize the model by the finite domain of keys and by the input sequence; do not assume a particular concrete ordering beyond what the sequence provides.
