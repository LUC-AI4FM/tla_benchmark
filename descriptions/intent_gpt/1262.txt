Specify a generator that, given an execution trace produced by a model checker, constructs a separate, self-contained specification module that encodes the trace as a finite-state abstract program. The generator must accept a counterexample consisting of a sequence of named actions and an optional console flag, and produce a textual module in the target specification language that:

- Declares any needed extensions or imports so that referenced operators and values used by actions are available to the generated module.
- Exposes the trace length as a constant and provides an indexed transition relation that, for each index position in the trace, constrains the next-state relation to exactly the corresponding action instance (including the action name and concrete parameter values).
- Encodes an action-level constraint that, when the module is executed, forces the state transitions to follow the recorded sequence exactly, including repeated or parameterized actions, so the module reproduces the trace as its only possible behavior.
- Is written to a specified output file using a deterministic text format and character encoding, overwriting any existing file, and reports success or failure.

Model the generator and the generated module at an abstract level: inputs (trace, file path, format options), the structure of the produced module (imports, length constant, indexed next-definition, action constraint), and the correctness properties: output file is produced when a non-empty trace is supplied and the console flag allows writing; the generated module, when parsed/executed by the specification tool, permits exactly the original trace (trace preservation); and the generator does not run or modify the original model checker state. Ensure the model captures failure modes (file write errors or disabled console) and the condition that nothing is emitted for empty traces.
