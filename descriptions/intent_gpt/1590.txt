Model a simple recursive parity calculator that determines whether a nonnegative integer is even or odd by repeated decrement and alternating calls between two procedures. The system should accept a fixed initial nonnegative integer input and then execute a deterministic procedure that returns a Boolean indicating parity: TRUE for even, FALSE for odd. The model must capture procedure call/return behavior (including a call stack), argument passing by value, local parameter scopes, and the fact that each recursive call decrements the argument by one until reaching zero. It must allow a top-level invocation that calls the parity routine with a concrete initial value and then prints or exposes the result.

Specify safety properties: the algorithm never overwrites the stack or local parameters incorrectly (stack frames are well-formed), no illegal control transfer occurs, and the returned Boolean corresponds exactly to the parity of the initial input (i.e., result = TRUE iff the initial integer is even). Specify liveness properties: the computation always terminates (the call stack eventually empties and the process reaches a final "Done" state) for every nonnegative initial input, and there are no livelocks or infinite regress. Include invariants that ensure parameters remain nonnegative and that each recursive step decreases the numeric argument toward zero.
