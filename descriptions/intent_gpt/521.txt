Model a simple two-party message-exchange protocol in which one party produces messages drawn from a fixed finite set and the other party responds with single-bit acknowledgements. The model should capture unbounded but length-restricted FIFO channels in each direction (sender→receiver and receiver→sender) with a maximum buffer length. Specify the allowed messages and bits, the possible nondeterministic choices of which side performs a send or receive step, and rules for delivering, enqueuing and dequeuing messages consistent with FIFO semantics. The system must enforce type and state constraints (messages belong to the given set, acknowledgements are single bits, channel contents respect the maximum-length bound).

Require the following correctness properties to be specified and verifiable:

- Safety: If the acknowledgement channel is nonempty and its first element equals the bit of the current sender message, then the current sender and receiver messages must be equal. In other words, a matching bit at the head of the ack channel implies the two endpoints agree on the message value.
- Structural consistency: Both channels must at all times satisfy a “two-values monotonicity” property that constrains their sequences to change values in at most two contiguous segments (e.g., values form at most two runs).
- Liveness fairness: The model must include fairness assumptions to ensure that enabled send and receive actions are not permanently ignored so that progress can be reasoned about under weak fairness.

Do not prescribe an implementation; describe only the abstract behaviors, constraints, and the properties to be checked.
