Specify a concurrent system that manages a fixed finite set of independent agents that repeatedly perform purely internal steps and may also nondeterministically terminate; there is no shared mutable state. The model should treat each agent as an autonomous process that can either take an internal action or decide to stop participating, and agents do not communicate or synchronize with one another. The system must allow any interleaving of enabled internal steps from the live agents, and termination of any subset of agents at any time.

The specification must capture liveness: if an agent remains live (not terminated) then it should always be allowed to take further internal steps in the future (no permanent starvation). It must also capture safety: the system must never reach an erroneous global configuration (define a placeholder predicate for error states and require it is never true). Provide invariants expressing that the set of live agents always remains a subset of the original fixed set and that no shared data can be modified (i.e., global state is constant). Allow nondeterministic scheduling and termination decisions, and prove that the invariants and liveness property hold under all behaviors.
