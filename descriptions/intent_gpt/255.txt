Specify a formal model of a small library of finite-set operations and predicates, together with a suite of correctness properties those operations must satisfy. The model should treat sets as pure mathematical finite sets (allowing duplicates in input literals to be normalized) and should not commit to any particular implementation strategy.

The model must include:
- An operator that counts how many elements of a finite set satisfy a given predicate and must match the cardinality of the comprehension {x ∈ S: P(x)}.
- An operator that returns all k-sized subsets of a finite set for any integer k, producing the empty set when k is outside 0..|S|, and matching the comprehension {T ∈ SUBSET S: Cardinality(T)=k} when k is in range.
- A fold/reduce over a finite set with an associative binary operator and neutral element that yields the same result as summing or multiplying ranges and multisets when instantiated appropriately.
- A deterministic selection operator that returns the unique element of a set satisfying a predicate when exactly one exists; it must produce that element and be undefined or signal error otherwise.
- The symmetric difference operator on two finite sets with the usual semantics (elements in exactly one of the sets).
- Aggregate numeric operations SumSet and ProductSet over finite sets of integers that equal the ordinary sum and product of their elements.

State the key invariants and properties to be verified: equalities relating the counting operator to set comprehensions; equivalence of k-subset operator to the comprehension characterization; edge cases (empty sets, full set, k out of range); correctness of Fold on known numeric ranges and multisets; deterministic behavior of the unique-chooser; algebraic laws for symmetric difference; and numeric results for SumSet and ProductSet on example ranges.
