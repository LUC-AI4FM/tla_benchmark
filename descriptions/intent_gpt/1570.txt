Specify a model of a simple sequential program with nested procedure calls, local procedure variables, call-by-value parameters, and a call stack. The model should represent calling a top-level procedure that in turn calls another procedure, which then calls a third procedure, with each call allocating fresh local variables and passing computed argument values to the callee. The system must enforce that:

- Each procedure has its own local state that is isolated from others except through explicit parameter passing and returns.
- Calls push activation records on an explicit stack and returns pop them, restoring the caller’s local state and control point.
- Parameters are passed by value: the callee receives copies of evaluated expressions computed in the caller, and later changes to callee locals do not affect caller locals.
- Assertions placed at specific program points must hold: initial invariants on locals, preconditions on passed arguments, and final checks on computed values in the deepest callee.
- Control flow respects a single-threaded, deterministic execution order: only one procedure is active at a time and the stack discipline is preserved.

Specify correctness properties: safety (all assertions can never fail in any reachable state) and termination (the program eventually returns to the top-level caller and reaches its final "Done" state). Also specify that the stack never underflows, and that after each return the caller’s locals are restored to the values they had just before the call.
