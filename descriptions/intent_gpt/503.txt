Specify a formal TLA+ model of the core consensus decision problem for a distributed system of processes that must agree on a single value. The model should treat the set of possible values as a given parameter and represent the fact that processes may propose values and eventually one value becomes chosen. The system must guarantee the following safety properties: (1) validity — any chosen value must come from the allowed set of values; (2) agreement — at most one distinct value can be chosen in any execution (no two different values can both be chosen); and (3) integrity — once a value is chosen it cannot later be replaced by a different chosen value. The liveness requirements are optional but should be expressible: (4) eventual choice — under a fairness assumption that actions that remain continuously enabled are not postponed forever, some value from the allowed set will eventually become chosen; and (5) nontriviality — if no value has been proposed then choosing nothing is a permitted outcome (so liveness may require at least one proposal). The model must abstract away from specific communication details but allow specifying propose and learn events and the state that records which value (if any) has been chosen. Provide clear initial conditions, a next-state relation that permits at most a single transition to select a value, and state the invariants and temporal properties to be checked (safety and, under fairness, liveness).
