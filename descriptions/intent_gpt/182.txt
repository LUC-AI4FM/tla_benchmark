Specify a formal model of the computation of binomial coefficients arranged as Pascal’s triangle up to a fixed nonnegative integer N. The model should treat the triangle as a function mapping a pair of row and column indices (n, k) with 0 ≤ k ≤ n ≤ N to the corresponding integer value C(n,k). The model must allow computing any C(n,k) for indices in range, using the standard recursive combinatorial definition: C(n,0)=1, C(n,n)=1, and for 0<k<n, C(n,k)=C(n-1,k-1)+C(n-1,k). It should also ensure the edge cases are handled correctly (e.g., indices outside 0..n are not valid or are treated deterministically).

Specify properties to verify:
- Correctness: For all valid indices (n,k), the value equals the binomial coefficient n choose k.
- Symmetry: C(n,k) = C(n,n-k) for all valid indices.
- Boundary values: C(n,0)=C(n,n)=1 for all n in range.
- Consistency with Pascal recurrence: for 0<k<n, C(n,k)=C(n-1,k-1)+C(n-1,k).
- Nonnegativity and integer-ness: all values are integers ≥ 1.

Model should permit evaluation of particular entries and verification of these invariants for a given N.
