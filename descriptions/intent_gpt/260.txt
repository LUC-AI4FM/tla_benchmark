Specify a simple data-access service that provides read access to a nested record field. Model a system that receives requests asking for the value of a particular named field nested inside a record, and returns the corresponding value to the requester. The system must accept requests that identify (a) a target record and (b) the field name to read. It must validate that the target record exists and that the requested field is present and readable; if so it must return the field's value, and if not it must return an appropriate error or failure response. Multiple concurrent requesters must be supported: the system must preserve consistency of reads even under concurrent requests and should not deliver stale or corrupt values. Specify behaviors for both successful reads and error cases (missing record or missing field). Include invariants guaranteeing that a returned value always equals the value currently stored in the specified field of the specified record at the time the read is served, and that no successful response is returned for a nonexistent record or field. Specify liveness properties ensuring that valid requests are eventually answered (no indefinite blocking) and that error responses are eventually delivered for invalid requests. Allow the model to be parameterized by the set of records and their fields.
