Model an initialization subsystem for a finite-state component whose startup nondeterministically chooses its initial state from several disjoint categories and thereafter remains in that state. The model should represent an abstract variable whose initial value must come from one of several specified finite sets or satisfy simple numeric relations (e.g., being greater than the minimum of a set, belonging to a set, equal to a set member plus one, or having a parity property). The initialization semantics should allow multiple alternative initialization clauses (disjunction) so that exactly the states described by those clauses are the legal initial states of the component. After initialization, the component must perform no transitions that change that variable (it must remain stably equal to the chosen initial value).

Specify the set-valued and arithmetic predicates used to describe allowed initial values (e.g., membership, greater-than-minimum, equality with an offset, parity). The specification must ensure that each alternative contributes the correct number of concrete initial states (including possibly zero), that the union of alternatives is the full initial-state set, and that no further state changes are allowed. Key correctness properties to check: (1) Invariance: once initialized, the variable never changes. (2) Coverage: every actual initial state satisfies at least one of the provided initialization predicates. (3) Disjointness and counting: the model can be used to confirm how many distinct initial states each alternative produces (including verifying alternatives that are unsatisfiable produce zero states). (4) Well-definedness of "minimum" when used in predicates. Provide the model so these properties can be mechanically checked.
