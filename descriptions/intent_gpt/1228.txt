Specify a simple abstract algebraic data environment that defines and reasons about a family of binary operators which are semantically identical: each operator takes two operands and yields the unordered set containing those operands. Model a system where these operators are first-class named operations (different syntactic names) but are intended to have identical behavior. The model must allow building expressions using any of the operators, nesting them arbitrarily, and evaluating expressions to their canonical result (the unordered pair of the two operand values). It must support operands drawn from a fixed universe of values and permit equality checking of results independent of which operator names were used.

State correctness properties that ensure: (1) evaluation of any expression yields a two-element set containing exactly the two operands (or a singleton if operands are equal); (2) all operator names are observationally equivalent — any two expressions that differ only by operator names evaluate to the same result; (3) evaluation is deterministic and total for all well-formed expressions; and (4) nesting or associativity does not change the multiset of leaf operands (i.e., evaluation is idempotent and commutative at each application). Include simple invariants and a notion of equivalence between expressions to support model checking these properties.
