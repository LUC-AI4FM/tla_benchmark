Specify a formal model of a binary search procedure that operates on an arbitrary sequence of integers and a target integer. The model should treat the input sequence as potentially any finite sequence of integers and the key as any integer, without assuming sortedness beyond what the algorithm requires. The system should represent the algorithm’s control flow and index manipulation abstractly and must capture termination (either by finding the key or by exhausting the search range), the returned result (an index where the key occurs, or a distinguished value indicating “not found”), and a step counter that measures the number of algorithmic steps executed.

The specification must require that when the algorithm reports a successful find, the reported index is within the bounds of the input sequence and the sequence element at that index equals the key. When the algorithm reports “not found,” the specification must guarantee that no index in the input sequence contains the key. Termination must be guaranteed for all finite inputs, and the step counter must be nonnegative and bounded by a function linear in the logarithm of the input length (reflecting binary search progress). The model should allow reasoning about all possible input sequences and keys, and expose invariants that ensure index variables remain within valid ranges and that the search interval shrinks monotonically until termination.
