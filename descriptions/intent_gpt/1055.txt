Specify a TLA+ model of Dijkstra–Scholten termination detection for a diffusing distributed computation initiated by a single designated root. Model a fixed finite set of processes (nodes) that communicate by asynchronous point-to-point messages of two kinds: application (base) messages that propagate work and acknowledgement messages used to notify parents when children are done. The system begins with only the initiator active; other nodes become active only upon receiving a base message. Nodes may send base messages to any other node to create new activity, record who sent them their activating base message as their parent (thus building a dynamic spanning tree of active nodes), and later return acknowledgements to that parent when they and all their descendants become passive. A node that receives a base message and already has a parent must immediately send an acknowledgement back to that sender instead of adopting it. Leaf nodes that are passive and have no active children detach from the tree by sending an acknowledgement to their parent (or, if the parent is the initiator itself and becomes passive with no children, allowing the initiator to declare global termination).

Require the model to bound message counts for state-space finiteness but faithfully capture possible reactivation (a node can be reactivated after detaching) and concurrent interleavings. Specify the main correctness properties:
- Safety: termination may be declared only when the entire system is quiescent (no node active and no pending messages).
- Liveness: if the system reaches quiescence, termination will eventually be declared.
Also specify basic invariants (well-formed types, message-count bounds) and fairness assumptions needed to guarantee liveness of enabled actions.
