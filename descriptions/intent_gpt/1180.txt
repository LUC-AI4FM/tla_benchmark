Model a simple two-variable state machine where both variables are integers that start at zero and one of them toggles between 0 and 1 on every step while the other remains constant. The system should allow an initial state with both variables equal to zero and then repeatedly execute a step that flips the second variable between 0 and 1 while leaving the first variable unchanged.

Specify the temporal behavior of the system and require verification of safety and liveness properties. Safety: every reachable state must have both variables in the set {0,1}, and the first variable must remain equal to its initial value (never change). Liveness: from any reachable state, the second variable must eventually take the value 1 and also eventually take the value 0 (i.e., it must visit both binary values infinitely often). Also include a property that there is at least one reachable state in which the second variable equals 1.

Request that the model checker explore all reachable states and then check the temporal properties; if all states are explored and a temporal property fails, the checker should report the failure. Ensure the specification is precise about initial conditions, the allowed step relation, and the temporal safety and liveness properties to be verified.
