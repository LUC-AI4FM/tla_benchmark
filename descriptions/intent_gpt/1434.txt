Specify a transition-system model of a simple state variable that can take a small finite set of integer values and is initialized to a single starting value. The system should allow non-deterministic transitions that set the variable to various target values, where different transition alternatives may be syntactically distinct but semantically equivalent (i.e., they may permit the same next-state value). The model must capture how a model checker explores initial and next states and should make explicit that some syntactic forms of enabling conditions can cause duplicate semantic next states to be generated or avoided depending on evaluation strategy.

Requirements:
- The model should include a single state component ranging over a fixed finite set of integers and an initial predicate that fixes it to one starting integer.
- The next-state relation must include several non-deterministic alternatives, some of which set the variable to the same target value while differing in how they combine the assignment with boolean subexpressions (e.g., assignment conjunct placed before or after a disjunction, or membership of a conjunct wrapped to prevent eager evaluation).
- Specify safety invariants: the variable must always remain within an allowed set of values; certain predicates must hold in specific states (for example, a predicate true only when the variable equals a particular value).
- Specify properties that count or characterize how many distinct next states or named properties a model checker should report (i.e., expectations about which syntactic alternatives produce duplicate versus distinct states).
- Include a liveness-like requirement to leave the initial state (existence of a transition from initial value that changes the variable).
