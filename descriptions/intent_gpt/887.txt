Model a single-writer, single-reader linearizable shared-memory register that serves read and write operations submitted by concurrent threads. The model should treat the memory as a mapping from addresses to values and must allow an initial memory state to be chosen arbitrarily. The system must accept a sequence (possibly unbounded) of operation invocations, each being either a write(address, value) or a read(address). Each operation has an invocation and a completion (return) event; operations may overlap in time. The model should nondeterministically schedule invocation and completion events but must record a total ordering of completed operations that respects real-time precedence (if an operation completes before another is invoked, it must appear earlier in the order). Reads must return the value of the most recent write to the same address according to that total order, or the initial value if no preceding write exists. Writes must update the logical memory for subsequent ordered operations. The specification should assert safety (linearizability/atomicity of operations with respect to the total order) and liveness assumptions only as needed for fairness of scheduling (do not require progress of specific threads unless explicitly assumed). Allow the possibility of concurrent overlapping operations but require that every completed operation’s observed result is consistent with some total sequential execution that respects real-time order and the initial memory.
