Specify a simple state machine that models a boolean-valued variable representing an invariant predicate that must always hold. The system must initialize this boolean to true. In each step the system may update the boolean based on whether there exists a value in a finite set satisfying a given predicate. Concretely, at each transition the next value of the boolean should be the truth value of an existential condition over a fixed finite domain: true if some element of the domain satisfies the condition, false otherwise. The existential condition used to compute the update must be expressible as a simple membership-and-predicate check over the finite domain. The model must nondeterministically allow the system to perform such updates indefinitely.

Require as the main correctness property that the boolean invariant always holds (is always true) in every reachable state. Also require that the specification clearly distinguishes between computing the existential as a value (assigning the boolean to the truth of the existential) and branching on the existential to decide different updates, and that either form yields the same observable behavior for the boolean. Finally, the model should be amenable to model checking: finite domain, clear initial condition, and an invariant assertion to be checked.
