Model a single-message asynchronous unreliable channel with handshake semantics between a sender and a receiver. The system should allow a sender to place data items from a given finite set into the channel and the receiver to acknowledge receipt. The channel must hold at most one value at a time together with two bits representing readiness and acknowledgement. The sender may only write a new value when the readiness and acknowledgement bits are equal (indicating the previous value has been acknowledged); performing a send sets the stored data and flips the readiness bit. The receiver may only acknowledge when the readiness and acknowledgement bits differ (indicating an unacknowledged value is present); performing a receive flips the acknowledgement bit to match readiness. Specify initialization so the channel holds a valid data element and the readiness and acknowledgement bits start equal. Capture all possible interleavings of send and receive steps and allow nondeterministic choice of which data value is sent. Formalize invariants asserting that the channel’s state always respects the prescribed types (value from the given data set and bits in {0,1}) and that send and receive actions preserve these invariants. State and prove that the invariant “ready equals ack only at initialization or after a receiver step acknowledges” is maintained (i.e., the protocol never yields an invalid bit pattern) and that the system implements a reliable single-slot handshake: values are neither overwritten before acknowledgment nor acknowledged when absent.
