Model a simple concurrent system that maintains a single integer-valued state variable and supports nondeterministic state transitions that may change that value. The model should capture the following intent and correctness goals:

- The system must allow arbitrary steps that update the integer, including no-op steps, increments, and arbitrary assignments within a given integer domain. Steps may be chosen nondeterministically and may occur repeatedly, modeling an ongoing execution.

- Specify safety properties: the variable must always remain within a specified finite range (a lower and upper bound). Additionally, if there is a designated “legal” value in the range, require that any step that produces a value outside the legal set is forbidden.

- Specify liveness properties: from every reachable state, it must be possible to eventually reach a state where the variable equals a specified target value (strong eventual reachability), and the system must not deadlock — i.e., there must always be at least one enabled transition.

- Express invariants and temporal requirements separately: include an invariant asserting the range constraint and a temporal property asserting eventual reachability of the target value (e.g., "from every state, eventually target holds") and fairness assumptions to avoid trivial interleavings that prevent progress.

Do not prescribe specific implementation steps; instead describe the allowed transitions and the above safety and liveness requirements to be checked by the verifier.
