Specify a formal model of finite total functions and basic operations over small finite domains and ranges, intended to validate reasoning about function construction, indexing, and mapping into sets and powersets. The model should represent functions as first-class values mapping every element of a finite source domain to a value in a target codomain, including functions whose codomain elements are numbers, singleton sets, and subsets of a boolean domain. It must allow constructing functions from an explicit comprehension over a finite index set and then assert that looking up any index yields the corresponding computed value.

Require the model to support:
- Construction of a numeric function over a contiguous integer range and verification that each index maps to the expected incremented number.
- Construction of a function whose outputs are singleton sets, and verification of at least one specific mapping.
- Functions whose domain is itself a set of singleton sets and verification that indexing by a particular singleton returns the expected singleton-of-singleton.
- Mapping from subsets of a two-element boolean domain to their cardinalities, and equivalence of explicit enumerations with comprehension-based constructions.
- Quantified properties stating that any function from a finite boolean domain into its powerset has the correct domain and yields values that are subsets of the boolean domain.
- Quantified constraints that ensure functions from a small finite source set into a finite target respect equal source elements mapping to equal targets and satisfy domain and range membership conditions.

Express correctness properties as invariants or universal/existential assertions over all such finite functions, avoiding any implementation-level execution order.
