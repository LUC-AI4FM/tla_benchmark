Specify a simple state machine with a single control state that starts in an initial control value and can make two kinds of transitions. One transition deterministically sets the control to one designated value. The other transition nondeterministically chooses an integer from a small finite set and then sets the control to a different designated value; the chosen integer is not required to be observable after the transition. The model should treat the control value as the only externally relevant state and must allow the internal nondeterministic choice to be abstract (i.e., it need not be preserved beyond making the transition).

Require the following correctness properties be expressible and checkable:
- Safety: the control must never equal a particular forbidden value in any reachable state.
- Liveness: from the initial control value it must be possible to reach each of the two designated successor control values (i.e., no dead-end prevents making either transition).
- The nondeterministic choice in the second transition should not affect the safety property (safety must hold for all possible choices).

Also require that the model is finite-state (all domains are finite) and that transitions are described at the level of state-to-state relations so that standard temporal model checking can be applied.
