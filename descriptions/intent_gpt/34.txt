Specify a formal model of a tagged-union (variant) abstraction and its basic operations. The model should treat variants as values that pair a constant tag string with an associated payload value, supporting construction of variant values, selection of all payloads of a given tag from a collection, extraction of the tag name, and extraction of the payload with either a provided default or an unsafe/no-default access. The system must allow empty-payload (unit) variants as well as payload-bearing variants of arbitrary types and must permit collections (sets, sequences, or maps) that mix differently tagged variants.

Requirements:
- Construction: an operation to form a variant from a tag and a payload.
- Tag inspection: an operation that returns the tag string of a given variant.
- Safe extraction: an operation that, given a tag, a variant, and a default value, returns the payload if the tag matches, otherwise the default.
- Unsafe extraction: an operation that returns the payload for a given tag when present; behavior for mismatched tags may be unspecified but should be expressible.
- Filtering: an operation that, given a collection of variants and a tag, returns the collection of payloads whose variants carry that tag.
- Type and behavior constraints: the model should capture that tags are unique within a variant, filtering only returns payloads for variants whose tag equals the filter tag, and safe extraction never fails (always returns either payload or default). The model should be abstract about payload types, allowing reasoning about correctness properties of algorithms that manipulate mixed-tag collections.
