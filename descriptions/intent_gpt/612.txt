Specify a formal TLA+ model of a distributed consensus protocol for asynchronous, crash-prone processes that reach agreement on a single value through rounds of proposal, validation, and decision. The model should capture a set of processes that may fail by crashing (permanently stopping), and an unreliable network that may delay, reorder, duplicate, or drop messages but does not forge messages. The protocol proceeds in logical rounds; in each round some proposer(s) propose values and other processes exchange messages that include proposals, validity information, and identifiers. Processes must be able to propose arbitrary values and must retain enough local state to adopt and forward proposals, record validity evidence (e.g., a round index and proposal identifier), and decide when safe.

The specification must state safety requirements: (1) Agreement — no two non-faulty processes decide different values; (2) Validity — any decided value must come from some process’s original proposal; (3) Integrity — once a non-faulty process decides a value it never changes its decision. It must also state liveness under a partial synchrony assumption: eventually, if a period of sufficient synchrony occurs and a majority (or quorum) of processes remain non-faulty, then some non-faulty proposer’s value is eventually decided. Include invariants describing quorums and validity propagation, and specify what constitutes a decision and what message patterns justify advancing rounds or making a decision.
