Specify a specification of a state-manipulation system that models nested functional maps and controlled updates to them. The model should represent immutable mappings (functions from finite domains to values) and the operation of producing new mappings by making localized updates that do not mutate existing mappings. It must allow composing updates: first create a mapping by applying an update to a base mapping, then create a second mapping by applying a different update to the result of the first. The model should also allow constructing the second mapping in an alternative way — by applying the first update to the base mapping and then separately applying the second update — and show these two construction orders produce equivalent final values.

The specification must capture:
- a small finite domain and base values for that domain,
- an update that inserts or replaces a nested function value at a given key,
- a second update that writes a scalar into another key,
- the ability to express both the incremental-update construction (apply first update, then second) and the from-scratch construction (create base mapping, apply first update to a fresh copy, then apply second update to that fresh copy).

State the correctness property asserting that the final mapping obtained by performing the two updates incrementally is observationally equal (structurally equivalent) to the mapping obtained by performing the same updates on a fresh copy constructed from the base mapping. Ensure the model treats function/map values as immutable and prevents hidden sharing or aliasing that would make incremental updates corrupt previously created values. Include an invariant that formalizes the equivalence of the two final results.
