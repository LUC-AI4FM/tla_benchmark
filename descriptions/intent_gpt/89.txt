Specify a model of a single-message asynchronous communication channel connecting a sender and a receiver. The system must allow the sender to transmit values drawn from a given data domain and the receiver to accept them, while the channel can hold at most one message at a time and coordinates handoff using a pair of binary signals that indicate readiness and acknowledgement.

The model should represent the channel state and the two participants’ allowed behaviors abstractly (not their internal programs). The sender must be able to place a value into the channel only when the channel indicates it is idle; doing so flips its readiness signal. The receiver must be able to consume the current value only when the channel indicates a message is present; consuming flips its acknowledgement signal. Either participant may act whenever its enabling condition holds, and the environment does not drop or duplicate data.

Specify the initial condition (an idle channel with consistent control signals) and a step relation capturing both a nondeterministic send of any data value and a nondeterministic receive. Require the following correctness properties:

- Safety: The channel state always respects its type invariants (value in the data domain and control signals are binary).
- Mutual exclusion of conflicting actions: sends are allowed only when the control signals indicate idle; receives only when they indicate a message is present.
- Message discipline: values are never lost or spontaneously created; each received value must equal the last value sent without an intervening send.
- Liveness (optional but desirable): if the sender repeatedly attempts to send, a fair receiver will eventually consume the message; and if the receiver repeatedly attempts to receive when a message is present, it will eventually succeed.

Express invariants and temporal properties to prove these guarantees.
