Specify a formal model of multisets (bags) and operations on them, and state the correctness properties those operations must satisfy. The model should treat a bag as a collection in which each element may appear multiple times (finitely many occurrences per element), and it must permit potentially infinitely many distinct elements overall while guaranteeing only finitely many copies for any single element.

Include the following abstract components and operations (describe their behavior, not an implementation): creating the empty bag; forming the bag that contains one copy of every element of a given set; determining whether an element belongs to a bag and how many copies it has; taking the union (sum) of two bags that adds multiplicities; subtracting one bag from another, where subtraction removes at most as many copies as present (never producing negative multiplicities); forming the bag-union of a set of bags; checking subbag relation (componentwise ≤ multiplicities); producing the set of all subbags of a given bag; mapping a function over a bag to produce a bag of images with multiplicities preserved; and computing the total cardinality (total number of copies) for finite bags.

State invariants and properties to verify:
- Representational invariant: every modeled bag assigns a strictly positive integer count to each element in its domain, and absent elements are treated as having zero copies.
- Algebraic laws: commutativity and associativity of bag union; identity of empty bag; monotonicity of union and subtraction with respect to the subbag relation; that subtraction yields a subbag of the minuend and that adding a subbag back restores counts up to the minuend.
- Soundness of mapping and bag-union: mapping preserves total multiplicities according to preimage counts, and bag-union sums multiplicities across the set.
- Finiteness constraint for functions that require it: operations that sum multiplicities must be well-defined only when contributions are nonzero for finitely many elements.
- Correctness of subbag enumeration: the generated set of subbags should include exactly those bags with per-element multiplicities between 0 and the original bag’s multiplicity.

Specify these requirements so they can be checked by model checking or theorem proving without prescribing internal data structures or execution order.
