Specify a system that models a simple constant-valued configuration parameter and how it is used by a concurrent system. The model must include a constant whose value is fixed at system initialization and cannot change thereafter. The system should demonstrate that processes and actions may read and rely on this immutable configuration value at any time, and that any property depending on the configuration remains stable across all behaviors.

The specification should state the allowed domain or literal value(s) for the constant and ensure the constant is visible to all components of the system but not modifiable by them. It must capture initialization that sets the constant and the invariant that the constant never changes. Additionally, require that any process that reads the constant obtains the defined value and that no behavior can produce a contradiction where the constant is observed differently by different parts of the system.

Key correctness properties: (1) the constant is initialized exactly once and remains unchanged; (2) all reads of the constant return the same value; and (3) any invariants or safety properties parameterized by the constant hold for every reachable state. Liveness or termination properties may be included if they depend on the constant’s value.
