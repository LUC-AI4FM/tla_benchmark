Model a finite-state deterministic transition system with a single integer-valued state variable that can take a small fixed set of values. The system should allow three distinct states (call them 0, 1, and 2). The initial state set must permit the system to start in either of two of those states (specifically 0 or 1). The transition relation must deterministically cycle the state forward along a fixed three-state ring: from 0 to 1, from 1 to 2, and from 2 back to 0. Specify the temporal behavior as a standard state machine with an explicit initial condition and a next-state relation that enforces those transitions only.

State clearly what safety and liveness properties the model must guarantee:
- Safety: the state variable must always remain within the set {0,1,2} (never take other integer values), and every transition must respect the specified deterministic mapping (no other transitions are allowed).
- Liveness: from any reachable state the system must eventually visit every state in the cycle (in particular, starting from any allowed initial state, the system should visit the other two states infinitely often over time).

Also require the specification to be suitable for model checking: the state space should be finite and small, and the properties should be expressible as invariants and temporal formulas.
