Model a commutative monoid of sparse integer-valued functions over a fixed finite domain of keys, and specify an operation that combines a finite set of such functions into a single function by pointwise addition.

The model should treat each function as mapping a subset of keys to integer values, implicitly assigning zero to keys not present in a function's support. The fold operation must take any finite collection (set) of these functions and produce a function whose value at each key is the sum of values provided by the input functions for that key. The fold should be associative and commutative with respect to the collection order: folding over a set must not depend on any ordering of its elements.

Specify correctness properties:
- Pointwise correctness: for every key, the result equals the sum of inputs’ values at that key (treating absent keys as zero).
- Identity element: folding over the empty set yields the zero function (zero at every key).
- Closure: the fold of a finite set of functions is itself a function of the same kind (finite support within the global key set).
- Determinism / order independence: for any two finite multisets (or sets) with the same elements, the fold results are equal.
- Basic sanity tests: folding a singleton returns the same function; folding two disjoint singleton-support functions produces a function with both nonzero entries.

Include invariants and simple witness properties that can be model-checked for small domains and small integer ranges. Do not commit to a specific implementation strategy; instead specify the abstract algebraic and pointwise properties that any correct implementation must satisfy.
