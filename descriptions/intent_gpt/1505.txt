Model a simple unbounded counter system that starts at zero and repeatedly increments by one. The model should represent a state containing a single numeric value that is always a natural number, provide an initial condition that the value equals zero, and allow only transitions that increase the value by exactly one. The specification must permit an infinite execution where the counter continues to grow without bound.

State the intended safety and liveness requirements explicitly: safety — at every reachable state the counter must be a natural number and each state transition must change the counter to the current value plus one (no other transitions are allowed); liveness — from the initial state the system must always be able to take another increment step (i.e., execution does not deadlock), so there exist infinite behaviors that keep incrementing. Also specify any useful finite-range refinements: allow a variant of the model that restricts the counter to a small finite range for finite-state model checking, and require that such a restricted model refuses transitions that would exit the range. Finally, require that the specification be amenable to model checking: clearly separate initial condition, next-state relation, and invariants, and state the properties to be checked (invariant that the value is a natural number and progress property that an increment is always possible).
