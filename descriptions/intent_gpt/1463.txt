Specify a model of a simple deterministic computation that maps each element of a finite set to an integer value and computes the sum of those mapped values. The system must accept as parameters: a finite input set of records or elements, and a pure projection function that, given an element, returns an integer. The model should describe the computation as a sequence of steps that visits each element exactly once, applies the projection to obtain an integer, and accumulates these integers into a running total. The algorithm must tolerate arbitrary ordering of the input set (i.e., it must not rely on any particular enumeration order) and must be robust to empty sets.

Formal correctness properties to guarantee:
- Safety: the accumulator always equals the sum of projection values for the subset of elements already visited; no element contributes more than once.
- Liveness/Termination: the process terminates after a finite number of steps having visited every element, producing a final total.
- Functional correctness: the final total equals the mathematical sum over the entire input set of the projection function applied to each element.
- Determinism: given the same input set and projection function, the final total and the number of steps are uniquely determined.

Include explicit invariants and a termination argument (variant/well-founded measure) to prove termination.
