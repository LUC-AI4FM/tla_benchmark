Model a simple state machine over integers that begins at 0 and evolves by repeatedly applying one of two kinds of transitions. One transition increments the value by 1 but is allowed only when the current value is even. The other transition increments the value by 2 and is also allowed only when the current value is even. The model should expose the possibility that from the initial state an infinite run exists (by repeatedly choosing the +2 transition), while the +1 transition, when taken at an even state, leads to a state that has no outgoing transitions and thus is a deadlock. Specify the state space, initial condition, and the two transition relations abstractly (without prescribing an implementation). Require the verification to check for reachability of deadlock states (states with no enabled transition) and to detect whether any execution can get stuck. Guarantee that all infinite behaviors are allowed only when transitions remain enabled at every step. Formulate and check the liveness and safety properties: (1) absence of reachable deadlocks, and (2) if a transition is enabled infinitely often then it is taken infinitely often (fairness constraint), so that the model distinguishes genuine nonterminating executions from executions that are deadlocked.
