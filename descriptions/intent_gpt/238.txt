Specify a concurrent system that models a collection of identical processes (a small fixed set) that each maintain a per-process pointer into a local set of candidate values. The system should allow processes to nondeterministically pick one of the candidates from their local set and update their pointer to that candidate, or else do nothing in a step. The candidate sets are initially empty for every process, and every per-process pointer initially holds a default integer value (e.g., 1). The model must allow the candidate sets to be read (to choose a new pointer value) but not modified by the step that updates the pointer; non-deterministic choices must be explicitly modeled so a process can only assign its pointer to a value that currently belongs to its own candidate set.

Specify the safety properties that must always hold: pointer values must always be integers and, whenever a process updates its pointer, the new value must belong to that process’s candidate set at the time of the update. Also require that pointer updates do not affect candidate sets or other processes’ pointers. Include any stuttering step that leaves the entire state unchanged. Model the system for a small finite set of processes and state that the specification should be suitable for model checking (finite-state behavior).
