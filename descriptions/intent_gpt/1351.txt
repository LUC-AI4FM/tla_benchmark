Specify a formal model of a system that reasons about collections of partial functions and sequences over a small fixed set of symbols, where the system must support the construction, composition, and validation of mappings defined on arbitrary subsets of a finite domain. The model should allow an external parameter that supplies a family of candidate mappings, and it must treat that parameter abstractly (i.e., without enumerating all members). The system must:

- Represent finite domains of symbols and sequences over those symbols, with the ability to form sets of sequences even when they cannot be fully enumerated.
- Support partial functions whose domain is any subset of a given finite domain and whose codomain is a set of sequences; include operations to construct and inspect such partial functions.
- Allow a configured collection of mappings (the external parameter) to be treated as a nonempty set of candidate partial functions; the model must be able to assert properties about the existence and structure of those candidates without depending on explicit enumeration.
- Ensure soundness properties: all constructed objects are well-typed (domains and codomains match), partial functions are indeed functions on their specified subsets, and any reference to the external collection preserves nonemptiness and the intended types.
- State invariants that preserve domain-subset relationships and typing under any allowed operations, and specify liveness or reachability goals showing that valid candidate mappings can be selected and used to produce well-formed results.
