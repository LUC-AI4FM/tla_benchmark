Specify a formal model of a pure functional fold over a finite set of keys that builds a finite map by applying a binary update function repeatedly to each key. The system should represent: a finite domain of distinct keys; an initial map that assigns a default value to every key; a deterministic update operation that, given the current map and a specific key, produces a new map differing only at that key; and an iteration that applies this update to every key in the domain exactly once (order may be arbitrary). The model must capture the final map produced by folding the update across the entire domain.

The specification must state the intended correctness property: for every key in the domain, the final map assigns the value produced by applying the update to the initial map at that key (i.e., the update is applied to each key independently and no unintended interactions occur). It must also assert that no other keys outside the domain are created or modified and that the domain of the final map equals the original domain. Additionally, require determinism of the update function (same inputs yield the same output) and that folding over an empty domain yields the original map. Specify invariants and properties in a way that enables checking that any counterexample would indicate either interference between keys or an incorrect fold semantics.
