Specify a formal TLA+ model of a simple iterative computation that fills an array with the squares of its indices. The system initializes an index and an array of length n+1 with values in an appropriate numeric range and then repeatedly updates the array so that, when the algorithm completes, each array entry equals the square of its index. The model should capture three high-level control states: before updating the current index, after updating the current index, and finished. It must permit any nonnegative integer n and constrain values so indexes and array entries remain within safe numeric bounds.

Model the progression that advances an index from 0 up to n, with each step producing a correct square for the index being processed. The model must allow only legal transitions between the control states and must ensure the loop terminates with the index equal to n and every array cell set to the corresponding square.

Specify the following correctness properties to be checked with model checking: (1) type-safety/invariant: variables always remain within their declared domains; (2) partial-correctness invariant(s): after each update step, the already-processed portion of the array contains correct squares; (3) final correctness (postcondition): upon termination, all entries equal their index squared; and (4) liveness/termination: the algorithm eventually reaches the finished state for all allowed n.
