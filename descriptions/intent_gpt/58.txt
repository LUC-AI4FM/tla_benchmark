Specify a simple specification-checking scenario for a model checker that demonstrates and verifies the semantics of assumptions over values that are not compile-time constants. The system should define a finite set of state variables whose initial and next-state relations are unconstrained (i.e., allow arbitrary transitions), while also introducing a separate arithmetic expression that is computed from those variables or from a non-constant source. The specification must include an assumption that constrains that computed expression (for example, asserting it is positive), and the model checker should treat that assumption as a restriction on the set of behaviors to be considered during verification.

The model must clearly state what behaviors are allowed and which are forbidden by the assumption, and it must be possible to check satisfiability: whether there exists at least one execution trace that satisfies the assumption throughout (or at the point it is applied). The key correctness property is that the assumption is applied semantically to non-constant values (not only to compile-time constants) and thus filters traces accordingly. The specification should enable detection of regressions where assumptions over non-constant expressions are ignored or misapplied by the tool.
