Model a system that evaluates parametric (generic) function application and ensures correct instantiation of polymorphic operators at their call sites. The model should describe a small evaluator that holds named functions with parametric types and computes results of applying those functions to arguments of concrete types. It must allow the same parametric operator to be used with different type instantiations at distinct call sites, producing independent, type-correct results for each instantiation.

Specify the following requirements:
- There is a store containing deterministic pure functions defined over finite domains and values drawn from basic types (e.g., integers and booleans).
- There is an expression that applies a parametric operator to an argument; the system must replace the parametric operator by a type-specific instance at the call site so that type mismatches cannot occur.
- The system must evaluate multiple applications of the same parametric operator at different concrete types within one computation and produce a tuple of results, one per instantiation.
- The initial state must contain a known starting pair of results; a transition should compute the tuple of instantiation results and update the store atomically.
- Safety properties: each computed result must equal the value produced by applying the corresponding concrete function to its concrete argument; distinct instantiations must not interfere with one another.
- Liveness property: the computation that performs instantiation and evaluation eventually completes and yields the tuple of results.
