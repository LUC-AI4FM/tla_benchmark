Model a simple message-collection protocol executed by a fixed small set of participants across a bounded set of rounds. The system maintains a collection of messages; each message has an author identifier and an associated round number. Initially the message collection may be any subset of all possible (author, round) pairs, subject to the invariant that every message present must have its round equal to a particular terminal round value. The system must permit steps that do not change the collection (i.e., stuttering or idle transitions), but must require that at least one non‑empty state is reachable from the initial state.

Specify the state space, the initial condition, and the transition relation without committing to a particular algorithm for adding or removing messages. Key correctness properties to guarantee:
- Safety: every message in the collection always has its round equal to the designated terminal round (this must hold in all reachable states).
- Liveness: from the initial condition it must be possible to reach a state with a non‑empty message collection (i.e., the system does not deadlock in the empty-set case if the initial predicate allows non‑emptiness).
- Consistency of derived sets: for any reachable state define the set of unique authors appearing in the collection; this derived set must be well‑defined and remain consistent with the message contents (no phantom authors).

Also specify types for participants and rounds, and assert that the transition relation allows stuttering steps. Do not encode implementation details such as particular loop steps or concrete procedure names.
