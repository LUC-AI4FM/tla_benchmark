Specify a simple boolean-state transition system that has a single boolean state and repeatedly flips its value on every step, starting from true. Model the system as an infinite-state behavior (initial condition plus a step relation) so each behavior begins with the state true and every transition in a behavior negates the current boolean.

Specify a collection of derived predicates and higher-order-like function applications that can be used to refer to the system specification and to its step relation indirectly. The model should allow composing and passing around predicates (or names that denote predicates) so that one can form properties by applying those predicate-names to the system specification or to expressions describing "always" properties of the step relation.

Require the following correctness properties to be checked on the model:
- Safety: every reachable state is a boolean and the step relation always produces the negation of the prior state.
- Liveness-like consistency: the composed predicates, when applied to the system specification or to the temporal formula stating "always the step relation holds," must evaluate to true (i.e., these indirect references correctly reflect the underlying behavior).
- Equivalence of alternative indirect encodings: multiple ways of naming or wrapping the initial+step specification should be provably equivalent when used in properties (they must yield the same truth value when applied).

Do not insist on a particular internal encoding; focus on the system behavior and the correctness properties about direct and indirect references to the specification and step relation.
