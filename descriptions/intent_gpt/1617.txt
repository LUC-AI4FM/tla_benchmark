Specify a small imperative program with three sequential stages that operate on two integer registers and a control-state marker. The model should capture non-deterministic choice where the second stage can select one of two values, and the third stage branches based on the value selected. The system must start from a specific initial state for the two registers and the control marker. It must allow the steps to execute in order from stage one through stage three and then reach a terminal state, while also permitting stuttering after termination so runs may be considered infinite.

The model must express the following behavior and correctness requirements:

- Stage 1 deterministically assigns a fixed constant to the first register and advances control to stage 2.
- Stage 2 non-deterministically assigns one of two specified constants to the second register and simultaneously updates the first register by adding the chosen second-register value; control advances to stage 3.
- Stage 3 uses the current value of the second register to choose between two different updates to the first register (one update for one specific value, another update otherwise), performs that update, and then moves to a terminal control state. A side-effect free observable action may be associated with stage 3 (e.g., printing).
- The model must assert that termination is reachable (eventually the control reaches the terminal state) under the fairness assumption that every enabled step taken infinitely often is eventually executed.

Additionally, include an assertion about the count of reachable states satisfying (a) being at stage 3 and (b) being in the stage-2 state with the second register set to the larger of the two choices, so it is possible to verify those specific state counts in model checking.
