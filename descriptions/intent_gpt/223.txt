Specify a simple functional-evaluation system that models first-class anonymous functions (lambdas) and their application to arguments. The model should represent lambda expressions as values that can be created, passed around, and invoked; it should allow nested or higher-order lambdas (lambdas that return or accept other lambdas). The system must include an evaluation mechanism that applies a lambda to an argument and yields the correct result according to lexical scoping and parameter substitution semantics.

Requirements:
- Creation: The model must support creating an anonymous function that binds a parameter and has a body expression.
- Application: There must be a well-defined operation that applies a function value to an argument value and returns the result of evaluating the body with the parameter bound to the argument.
- Determinism: Application must be deterministic: given the same function value and argument, the evaluation produces the same result.
- Type/arity safety: The model must ensure functions are applied with the correct number of arguments; ill-formed applications should be disallowed or produce a defined error value.
- Simple correctness property: For a lambda that returns its parameter unchanged, applying it to a concrete value must yield that value.
- The specification should abstract away implementation details (e.g., no explicit stacks or code pointers); focus on semantics of lambda creation, value identity, and application.
