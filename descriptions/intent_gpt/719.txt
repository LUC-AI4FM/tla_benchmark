Specify a formal model of a small IO utilities and serialization test harness and the behaviors it must guarantee. Model an environment abstraction that provides named string-valued configuration entries (environment variables) and provide ways to read them; ensure that looking up any environment name in the domain yields a string value. Include conversion utilities: a decimal-string-to-integer parser that accepts optional leading minus and rejects non-numeric strings, and a zero-padding function that converts nonnegative integers to fixed-width decimal strings by left-padding with zeros as needed. The zero-pad function must preserve exact digits when the integer length exceeds the width.

Model file-based binary serialization and deserialization for a finite set of small TLA+ values (strings, sets, integers, ranges, finite records) and require round-trip equivalence: serializing a value to a named file and then deserializing it returns exactly the original value. Ensure the deserializer can successfully read string values that have not previously been interned in memory (i.e., the system must not rely on a global preexisting string table to access or print newly read strings).

Specify explicit correctness properties: environment lookups return strings, atoi produces the correct integer for valid inputs and raises a well-defined error for invalid inputs (empty or non-digit content), zeroPadN produces the specified padded string for tested inputs, serialization followed by deserialization is identity for the supported value shapes, and deserializing arbitrary stored strings does not cause undefined behavior or crashes. Include a bounded domain for any nondeterministic choice used to construct numeric test values so the model checking state space is finite.
