Specify a formal model of a synchronous, round-based distributed leader election protocol on a fixed undirected connected graph of N nodes. The system proceeds in repeated three-round cycles. In the first round each node broadcasts its current numeric proposal to its neighbors. Based on values received, an awake node may decide it is a local winner if its proposal is strictly greater than every received neighbor proposal; in the second round any neighbor that hears a neighbor declared as winner marks itself as a loser; in the third round losers notify their neighbors they have lost, and all nodes remove any neighbor that has announced it lost from future consideration and go to sleep if they have already become winner or loser. The protocol must allow nodes to change proposals nondeterministically between cycles (to model local updates), and nodes may begin awake or asleep.

Model requirements and correctness properties:
- Capture asynchronous message delivery within a synchronous round: messages sent in a round are delivered to neighbors within that same round before the next round begins.
- Preserve an undirected communication graph and allow arbitrary but fixed neighbor sets.
- Safety: at most one node in any edge may declare itself a winner (no two adjacent winners) — i.e., the set of winners must form an independent set.
- Termination/Progress: eventually every node becomes either a winner or a loser and then sleeps (global termination).
- Consistency: once a node is decided winner (resp. loser), it does not later revert to a different decision.
- Messages are only of three kinds: value proposals, winner announcements, and loser announcements; nodes act only on the content and origin of these messages.
- Allow an optional configuration flag that can enable or disable a modeled bug for testing robustness; when enabled, the model may relax the winner-selection predicate to simulate a faulty comparison.

Do not prescribe internal variable names or a particular implementation language; specify only the observable states, transitions per round, and the invariants and liveness goals above.
