Specify a formal TLA+ model of an asynchronous, round-based Byzantine consensus (voting) protocol used by a set of processes to agree on a single value despite up to T Byzantine faults. The model should capture repeating consensus rounds; in each round one proposer proposes a value, processes exchange three message types (propose, prevote, precommit), and each process maintains local state to decide when to lock on a value, update a valid value for future rounds, and ultimately decide. The model must allow arbitrary message delivery delays and reordering, and Byzantine processes may send arbitrary (possibly conflicting) messages; non-faulty processes follow the protocol rules. The protocol must guarantee safety: no two non-faulty processes ever decide different values. It must guarantee validity: if a non-faulty process decides a value, that value must come from the allowed set of valid application values (distinguishable from invalid values). It must guarantee liveness under reasonable assumptions: if proposer selection ensures an eventually non-faulty proposer and message delivery eventually succeeds, then all non-faulty processes eventually decide. Specify the proposer's role selection per round, quorum thresholds (with N and T parameters), the locking/locked-round semantics that prevent conflicting decisions, the rules for updating a process's valid value and valid round, and the decision condition based on receiving a sufficient set of precommit votes. Include invariants expressing safety and validity, and liveness as a temporal property (e.g., eventual decision under eventual synchrony and honest proposer). The model should be parametric in N, T, the set of valid and invalid values, and maximum number of rounds used for model checking.
