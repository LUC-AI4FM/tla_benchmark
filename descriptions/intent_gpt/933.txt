Model a simple hour-of-day clock system that maintains an integer hour value in the range 0..23 and repeatedly advances time by one hour on each tick, wrapping from 23 to 0. The model should allow an initial state in which the hour is any valid value in 0..23. The system must offer an atomic transition that represents a clock tick and updates the hour deterministically to (hour + 1) mod 24. It must permit stuttering steps (no change) to represent idling, but the tick transition must be the only action that changes the hour.

Specify the correctness properties to verify:

- Safety: the hour value is always within 0..23 in every reachable state.
- Invariance of initial condition: any behavior starting from a state satisfying the initial-hour predicate remains such that the initial-hour predicate is preserved as an invariant (i.e., the initial-hour condition implies an invariant property that holds in all future states).
- Liveness (optional): from any state, eventual occurrence of a tick is possible (the clock does not permanently deadlock), or, alternatively, fairness assumptions ensuring eventual progress of the tick action.

Avoid committing to any concrete implementation structure; describe only the state space, the allowed state transitions, the initial-state constraint, and the properties to prove (safety invariant and the chosen liveness/fairness requirement).
