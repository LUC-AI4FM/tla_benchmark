Specify a concurrent-state transition system that captures two interacting state components: a primary component that can nondeterministically take values from a given finite set, and a secondary component that can nondeterministically choose values from one of two disjoint allowed sets depending on a pair of enabling conditions. The model should include an explicit initial state and a transition relation that describes all legal single-step updates to both components.

Requirements:
- The primary component must always be set to an element of a specified domain on every transition.
- The secondary component must on each transition choose an element from exactly one of two specified domains; which domain is chosen may depend on separate control predicates (for example, guarded choices).
- The transition relation must also permit conditional constraints on the new value of the primary component such that some branches impose specific equalities or disallow certain values (i.e., guarded alternatives that may be mutually exclusive or impossible).
- The initial state must assign concrete initial values to both components that are within their intended domains.
- The specification must enforce safety: every reachable state satisfies the invariants that primary and secondary values are in their respective domains.
- The specification must allow liveness reasoning about progress: every infinite behavior is either stable or must repeatedly take transitions that satisfy the nondeterministic domain choices.

Describe the system abstractly (domains and guards as parameters) and state the invariants and desired liveness properties to be verified.
