Specify a simple, deterministic computation environment for defining and applying finite and parameterized functions and records, and for performing controlled, local updates to such function values. The model should allow:

- Definition of functions with typed/vectorized or tuple-structured parameters, including functions returning scalars and functions returning records (maps).
- Application of functions both by supplying positional arguments and by supplying a single tuple that bundles all arguments.
- Construction of lambda-style functions by explicitly mapping parameter domains to expressions.
- Nested function values (functions stored inside records and maps) and their access and invocation.
- A mechanism for creating a modified copy of a function or record by applying local update expressions that refer to the previous value at the same position (an "EXCEPT"-style override), supporting multiple simultaneous updates and updates that replace an entry by another function or by a value computed from the old entry.
- Indexing over product domains (tuples) and finite enumerated parameter sets.
- Simple arithmetic computations inside functions and correctness checks that evaluate to expected numeric results.

The specification must assert that all example computations yield their expected results (e.g., arithmetic outcomes, record field values after updates, and behavior of nested/overridden functions), and flag failures when any computed value differs. Ensure determinism and immutability of values except via explicit update operations that produce new values.
