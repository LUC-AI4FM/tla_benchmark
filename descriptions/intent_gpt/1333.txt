Specify a TLA+ model of Safra’s distributed termination-detection algorithm for N processes arranged in a unidirectional logical ring. The model should represent processes that can be active or passive, send and receive application messages asynchronously, and change an internal color (white or black) used by the algorithm. Processes maintain local counters that track the difference between the number of messages they have sent and the number they have received. Messages in transit must be explicitly modeled so that the system can have a nonzero number of in-flight messages.

Include a circulating token that can be initiated by a designated initiator and passed around the ring. The token carries a summary count of outstanding messages collected from a suffix of the ring and a color bit. The protocol must allow processes to start a probe round, pass the token only when passive, and update the token’s count and color in a way that reflects local counters and colors. Processes may become active when they receive application messages and may deactivate at arbitrary times when passive.

Formally state the correctness properties:
- Safety (detection soundness): if the token returns to the initiator white, with its count and the initiator’s local counter summing to zero and the initiator passive and white, then the global system has truly terminated (no active processes and no in-flight messages).
- An inductive invariant capturing Safra’s reasoning that relates the global number of in-flight messages, local counters, token position, token count, and colors, sufficient to prove the safety property.
- Liveness: if the system has terminated (no active processes and no in-flight messages), then eventually the initiator will observe the white token condition (termination will be detected).

Allow nondeterministic scheduling of sends, receives, and deactivations; bound state-space sizes for model checking; and make explicit any assumptions (finite N ≥ 1, unbounded but constrained counters/messages for analysis) needed to verify the invariant and liveness.
