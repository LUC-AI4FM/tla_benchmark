Specify a parameterized system that models a component configuration selection and validates constraints on chosen features. The system has a finite set of candidate features and must represent choosing any nonempty subset of those features subject to a declared constraint that at least one particular designated feature must be available in the candidate pool. The model must distinguish between the declaration of the available candidate set and the choice of an active configuration; it should allow any nonempty configuration drawn from the candidates. The specification must ensure that the declared candidate set is a subset of a known universe of features and that it is not empty. The correctness properties to verify are:

- Safety: every chosen configuration is a subset of the declared candidate set and never empty.
- Invariant: the declared candidate set always contains the designated feature.
- Liveness: it is always possible to pick some valid configuration (no deadlock).

Do not commit to a particular algorithm for selecting configurations; the model should allow nondeterministic selection from the permitted subsets. The spec should be parameterized by the universe of features and by which single feature must be present in the declared candidate set. Include assertions or invariants that enforce the above properties so they can be model-checked.
