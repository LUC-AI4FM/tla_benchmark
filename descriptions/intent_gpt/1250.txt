Specify a formal model of a simple arithmetic library over the natural numbers that will be used as a foundation for higher-level algorithms. The model must treat natural numbers as an infinite, well-founded domain and provide standard arithmetic operations (addition, subtraction with a defined notion of nonnegativity, multiplication, exponentiation, comparison relations, integer division and remainder, and contiguous ranges). The specification should state the intended semantics of each operation (for example, addition and multiplication are associative and commutative, subtraction yields a natural number only when the minuend is at least the subtrahend, division and remainder satisfy the identity a = b * (a div b) + (a % b) with 0 ≤ (a % b) < b for b > 0). Define ranges a..b as the set of integers between a and b inclusive, with empty result when a > b. Require properties needed by algorithmic clients: closure of operations in the naturals, monotonicity of addition and multiplication by nonnegative factors, correctness of comparisons, and determinism (operations return unique results). Include basic algebraic laws (commutativity, associativity, distributivity where applicable), identity and annihilator elements (0 and 1), and behavior at edge cases (division by zero undefined or explicitly disallowed; subtraction producing underflow must be treated as invalid or result in a special value). State invariants and safety properties expected of any implementation and enough detail so proofs about programs using these arithmetic primitives can proceed without ambiguity.
