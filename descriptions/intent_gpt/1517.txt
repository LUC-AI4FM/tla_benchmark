Specify a simple sequential system that models a boolean flag and an integer counter evolving over discrete steps. The system begins with the flag cleared (false) and the counter initialized to a fixed positive integer (one). On each step, the counter must deterministically increment by one. The boolean flag may nondeterministically take either true or false independently on each step. The model must treat steps as atomic transitions that update both state components simultaneously. Require that all reachable states preserve the counter as a natural number strictly increasing from its initial value (no decrements or non-integer values), and that the flag is always a valid boolean. Capture liveness and safety properties: safety—every state respects the type invariants (flag is boolean, counter is a natural); liveness—the counter continues to grow unboundedly (infinitely many increments). Also assert that flag changes do not constrain or block the counter’s progress (the counter’s increment must be enabled regardless of the flag’s value). Provide the specification so that standard model checking can verify the invariants and the unbounded growth property.
