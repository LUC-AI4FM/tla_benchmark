Specify a formal model of a simple internal memory controller that mediates memory access requests from a fixed set of clients. The model should describe the abstract state of the shared memory array, a per-client control state, and a per-client request/response buffer. The system must permit clients to issue read and write requests, have the controller perform the requested operation on shared memory, and deliver responses for reads. The protocol should enforce a clear three-phase interaction for each client: (1) a client may submit a memory request only when it is ready; (2) the controller performs the operation (writing a value or fetching a value for a read) while marking the client as busy; (3) the controller produces a response and returns the client to the ready state. The model must maintain an invariant that the memory state is always a well-formed mapping from addresses to values, every client’s control state is one of the allowed statuses (ready, busy, done), and each buffer entry is either empty, a valid memory request, or a valid response value. The specification should allow non-deterministic choice of which client progresses at each step, preserve the global memory when appropriate (requests do not immediately modify memory), and show the above type and safety properties hold invariantly.
