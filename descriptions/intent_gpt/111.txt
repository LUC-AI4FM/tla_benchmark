Specify a model of a simple three-round state update system that manipulates a set of labeled messages across rounds. The model should include an initial condition in which, for each round index, the state contains an arbitrary subset drawn from a fixed finite alphabet of three symbols. The system must permit a single state transition that replaces the contents of the final round with some chosen subset of its current contents, but only when that chosen subset has size at least two. The transition should be nondeterministic: any qualifying subset of the final-round set may be chosen. The specification must assert invariants and safety properties: (1) the contents of every round must always remain a subset of the fixed alphabet; (2) the transition never introduces elements that were not previously present in that round; and (3) if a transition occurs, the final-round set after the transition must have cardinality at least two. Also state and check a liveness property that it is possible (not inevitable) to perform such a qualifying replacement from some reachable initial state. Do not encode implementation details or action ordering; describe only the allowed states, the nondeterministic replacement operation, and the correctness properties above.
