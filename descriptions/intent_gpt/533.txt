Model a concurrent message-passing system that implements reliable, in-order delivery of a sequence of numbered tuples from a single sender to multiple receivers in the presence of message loss, duplication, and reordering. The sender generates tuples drawn from a fixed finite set and transmits them over unreliable channels to all receivers; messages may be dropped, duplicated, or delivered out of order, but not corrupted. The system should ensure each receiver eventually delivers every sent tuple exactly once and in the sender's sequence order.

Specify the components (sender, a set of receivers, and communication links) and the protocol rules for sending, retransmission, acknowledgment, and garbage collection of state at sender and receivers. Include an explicit mechanism to bound memory growth (e.g., sliding window or sequence-number pruning) so the system can operate with finite state despite an unbounded run length. Model fairness assumptions needed for liveness (e.g., weak fairness of retransmission or eventual delivery of retransmitted messages).

State safety properties: no receiver delivers a tuple that was never sent; no duplicate deliveries; delivery order per receiver matches the sender's send order. State liveness properties: every tuple sent is eventually delivered to every receiver under the specified fairness assumptions, and sender eventually reclaims state associated with delivered tuples.
