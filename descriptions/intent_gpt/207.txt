Specify a model of a small distributed system of fixed participants that hold nonnegative integer "voting power" values. The system should allow each participant’s voting power to change nondeterministically over time within a bounded range [0..M], where M is a small positive integer constant. The model must track the vector of voting powers for all participants and permit arbitrary updates that respect the bounds on each participant’s power.

Require the following correctness properties to be checked:

- Safety (global bound): The sum of all participants’ voting powers must always remain strictly less than a given threshold T. This invariant must hold in the initial state and after every allowed update.

- Type and domain constraints: Each participant’s voting power must always be an integer within the allowed range [0..M], and only the specified finite set of participants exist.

- Liveness/termination is not required, but the model should permit exploring reachable states until the safety invariant is violated (if ever), so an explicit state transition that changes voting powers nondeterministically is needed.

Also specify constants for the participant set, the per-participant maximum M, and the sum threshold T so different parameter choices can be model-checked. Provide the safety property as an assertion/invariant to be verified.
