Specify a formal model of a source-language static checker and control‑flow expander for a small imperative algorithm language that supports procedures, processes, labeled statements, conditionals, loops, nondeterministic choice, with-statements, calls/returns, and simple statements (assign, skip, assert, print, when). The model should take as input an abstract syntax tree describing an algorithm and verify that it is well‑formed: every construct has the required fields and types, identifiers for variables/procedures/processes are strings, sequences have appropriate nonemptiness where required, expressions are sequences of tokens, procedure and process parameter and local declarations are correct, and final statements occur only where allowed. It should also compute the program’s control structure by expanding labeled statement sequences into flattened labeled simple‑statement sequences that make control flow explicit (including explicit control variables or labels to indicate next control point), correctly handling while bodies, labeled if/either constructs, final statements that end a basic block, nested label scopes, and return/call semantics. The specification must assert safety properties: syntactic well‑formedness invariants, preservation of labels and flow targets during expansion, and that expansion yields only sequences of simple statements (no remaining compound constructs). It must also assert termination of the checker/expander on any syntactically finite input and report meaningful errors for malformed constructs.
