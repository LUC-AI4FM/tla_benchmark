Specify a TLA+ model of a synchronous round-based distributed agreement protocol for N processes that tolerates crash failures. The system repeatedly executes rounds in which each non-faulty process broadcasts a binary vote (Yes/No), receives votes from other processes, updates local counters recording how many Yes and No values it sent and received (including counts that reflect messages from crashed processes as failures), and decides when safety and liveness conditions allow termination. The model should capture that processes may crash (permanently stop participating) at arbitrary points, but the number of crashes is bounded by some f < N. Messages are delivered reliably within a round (no reordering across rounds) but a crashed sender may omit sending. The protocol must ensure agreement (no two non-faulty processes decide differently), validity (if all non-faulty processes start with the same input value then any decision equals that value), and termination (all non-faulty processes eventually decide despite up to f crashes). Specify counters and flags for sent/received Yes/No and for detected failures as part of the state abstraction, but do not prescribe a particular implementation. Include an invariant expressing that once a decision value is chosen by any non-faulty process, no other non-faulty process can decide the opposite. Also formalize progress: if the number of non-faulty processes exceeds a threshold sufficient for the protocol (e.g., >2f when required), then all non-faulty processes eventually decide.
