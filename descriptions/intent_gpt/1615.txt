Specify a model of a concurrent system with two identical processes that demonstrates nested procedure/macro invocation, argument passing, and local per-process state. The model should abstractly represent each process executing a short program with (1) a local variable initialized to some default, (2) a first step that sets the local variable to zero, and (3) a second step that performs a sequence of operations that includes: setting a shared variable to a fixed value, invoking a nested routine that assigns a passed argument into the process-local variable, and updating another shared variable to reflect a computed value derived from the nested call. The nested routine must receive parameters by value and may perform assignments both to the passed parameter and to process-local state through its return effects (i.e., the outer routine's subsequent actions observe the results).

Model the system as interleaving concurrency of the two processes, starting from a state where all variables have a common default value. Ensure fair execution of each process so that each can eventually make progress. Specify safety properties asserting that immediately after the second-step sequence of a process completes, the process-local variable has the value assigned by the nested routine and the shared variable has the fixed value assigned by that process. Also specify termination liveness: eventually both processes reach their terminal state. Additionally, check for assertion failures if the required relationships between local and shared state do not hold.
