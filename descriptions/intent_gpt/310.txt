Specify a formal model of a binary-search routine that operates over a fixed-length sequence of integers and searches for a given key. The model should describe the externally supplied inputs (a finite sequence of integers and a search key) and the routine’s required behavior without prescribing a particular implementation. It must capture the search’s control state (progress and termination) and the values that represent the current search interval and the eventual return value.

The model should ensure the routine repeatedly narrows a closed interval within array indices until it either finds an index whose element equals the key or can conclude the key is not present. It must guarantee termination in a bounded number of steps for any finite input sequence and any key. If the key exists in the sequence, the final return value must be an index within bounds whose element equals the key; if the key does not exist, the return value must indicate absence (e.g., a distinguished sentinel) and no index in the sequence should contain the key. At all times, the current interval must remain a valid subinterval of array indices and shrink monotonically toward termination. The model should also allow reasoning about corner cases: empty sequences, single-element sequences, and keys at either end. Provide assertions/formal properties for safety (interval invariants, correct return) and liveness (eventual termination).
