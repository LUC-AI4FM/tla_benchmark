Model a simple messaging buffer shared by a fixed set of producers and consumers. The system maintains a finite multiset (bag) of messages and supports these operations: producers may non-deterministically add messages to the buffer (subject to a global capacity bound), and consumers may non-deterministically remove messages from the buffer for processing. Producers and consumers act asynchronously and concurrently; actions may stutter (do nothing). The model must allow an arbitrary but fixed number of producers and consumers as parameters and must permit messages to be any abstract data values.

The specification must guarantee safety and liveness properties:
- Safety: The buffer size never exceeds the declared capacity, and consumers never remove messages when the buffer is empty. Each individual message removal yields a message that was previously added and not yet removed (no creation of phantom messages or double consumption).
- Liveness: If a producer repeatedly attempts to add a message and the buffer is not permanently full, eventually the message is placed in the buffer. If a consumer repeatedly attempts to consume and the buffer is not permanently empty, eventually the consumer succeeds. More generally, any message added is eventually consumed unless producers continually keep the buffer permanently full with higher priority messages.
- Fairness: Specify weak and strong fairness variants for producer and consumer actions so that progress properties can be checked under different scheduling assumptions.

Parameterize the model by number of processes, buffer capacity, and message domain. Keep the description implementation-agnostic (no concrete queue algorithm), focusing on state, allowed transitions, and the invariants and temporal properties required.
