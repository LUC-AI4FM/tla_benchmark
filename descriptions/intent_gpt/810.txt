Specify a formal model of the Boyer–Moore majority-vote decision procedure for finite sequences drawn from a fixed set of three possible values, where sequence lengths are bounded by a given natural-number limit. The model should treat sequences of any length from 0 up to the bound as valid inputs. The system must nondeterministically choose an input sequence and then run the majority-vote algorithm to produce a candidate element and a counter value that summarize the run.

The model must express the algorithm’s state transitions abstractly (without prescribing imperative structure) so that model checking can explore all possible choices of input elements and execution interleavings. It must allow verifying, for every possible input sequence within the bound, that the candidate produced by the procedure satisfies the following correctness property: if some element occurs strictly more than half the positions in the input sequence, then the candidate equals that majority element. Additionally, the model should capture that the counter never becomes negative and that the counter and candidate evolve only according to the allowed update rules of the majority-vote procedure.

Include invariants and temporal properties sufficient to check safety (the candidate is correct when a majority exists) and basic well-formedness of state (counter ≥ 0, candidate is either one of the three values or a distinguished “no candidate” marker). Do not constrain the model to a single input length—verify across all lengths up to the bound.
