Specify a simple single-boolean-state reactive system that alternates its value on every step, and state precise correctness properties to be verified. Model one state variable that can be true or false. The initial condition must set the variable to true. The transition relation must flip the boolean value on every step, so every step deterministically toggles the state. The system must expose a temporal specification composed of the initial condition together with the always-next behavior (an initial condition and a state-action temporal closure).

Require the following correctness properties to be checked against that temporal specification:
- Invariance of the form "every reachable state satisfies some formula": express and verify a property that refers to the next-state expression boxed with respect to the initial state expression (i.e., a temporal property that refers to the next-state of the variable over all steps). Include at least two syntactic variants of the same invariant expressed through local definitions or let-bindings, to ensure the model checker handles definitions uniformly whether used inside or outside of let-expressions.
- Equivalence: show that applying an identity-like definition to the entire temporal specification yields a formula equivalent to the original specification, and verify that this packaged specification implies the same invariant.
- Scoping and binding correctness: ensure that local function/definition bindings within expressions do not change semantics when the bound name shadows other names; verify that folded definitions produce identical results as inline expressions.

Do not constrain the model with extraneous fairness conditions. The properties must be purely safety-type (invariance/always) properties about the toggling behavior and the correctness of definition folding and scoping.
