Specify a model of the N‑queens search that finds all distinct solutions for placing N queens on an N×N chessboard so that no two queens attack each other. The model should represent partial and complete placements of queens as sequences or ordered lists of column indices, one index per row, and should allow incremental construction of placements row by row. It must explore nondeterministically all possible ways to extend a partial placement by putting a queen in any column of the next row that does not conflict with existing queens (no shared column or diagonal). The system must collect every complete placement of length N exactly once and preserve all partial placements that still can be extended.

Correctness requirements:
- Safety: Every collected solution must be a complete placement of length N with no pair of queens attacking (distinct columns and distinct absolute row–column offsets).
- Liveness/Progress: If a partial placement can be extended to a complete solution, the model must allow reaching such an extension (no spurious deadlock that prevents completion of extendable partials).
- Completeness: The set of collected solutions must eventually contain every valid N‑queen solution (no valid solution omitted).
- No duplicates: Each distinct solution should be recorded only once.

Allow parameterization by N and support model checking for small N.
