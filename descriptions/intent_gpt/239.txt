Specify a simple countdown system that starts with a nonnegative integer value and repeatedly decreases it by one until it reaches zero, then remains stable. The model must allow an arbitrary but fixed initial natural number as a parameter. The system should permit only two kinds of state transitions: decrementing the current value by exactly one when it is positive, or leaving the value unchanged when it is zero. The specification must express initialization (the value equals the chosen initial number) and the allowed state transitions so that all possible executions follow these rules.

Require safety: the value must never become negative at any reachable state. Require liveness: from any state with a positive value, it must be possible to eventually reach a state with a strictly smaller value (i.e., progress is enabled when positive), and from any positive starting value the system must eventually reach zero. Additionally, state that the value is always an integer and the initial parameter is restricted to natural numbers. Provide properties suitable for model checking: an invariant capturing nonnegativity and temporal properties capturing eventual termination at zero and perpetual stuttering at zero.
