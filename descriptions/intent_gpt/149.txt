Specify a formal TLA+ model of a local-parameterized left fold over a fixed integer sequence and a family of binary combining functions that capture an extra local parameter. The model should represent a pure functional fold-left operation that, given (1) a finite sequence of integers, (2) an integer base accumulator, and (3) a combining function generator that for each parameter value returns a binary integer function, computes the result of folding the sequence left-to-right using the binary function produced for a specific parameter. The system must allow the combining function to be expressed as composition of a simple associative operation (integer addition) together with an added contribution proportional to the parameter, so that changing the local parameter consistently shifts the fold result by the parameter times the sequence length.

State the expected relationship between the fold results for different parameter values as an invariant: for any integer parameter k, the fold result with parameter k equals the fold result with parameter 0 plus k multiplied by the length of the sequence. The model should treat the sequence and base as fixed constants and must prove the invariant for all integers k. Also specify a simple initial state and inert behavior that leaves the accumulator unchanged, so that the invariant can be checked as a property of the fold operator rather than of state transitions. Include correctness properties to assert the invariant holds universally and that the fold computation is deterministic and total for the given inputs (no undefined values).
