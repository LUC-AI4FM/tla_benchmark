Model a library of finite sequences (ordered tuples) and the basic sequence-manipulation primitives, and specify the expected behavior and correctness properties of those primitives. The model should treat sequences as indexed from 1 to their length, allow empty sequences, and support creating, accessing, slicing, concatenating, appending, mapping, filtering, folding, and converting between functions and sequences. It must specify semantics for head, tail, length, domain (index set), element access (with out‑of‑bounds behavior explicitly characterized), subsequence extraction, append, concatenation, map-by-index to build a sequence of given length, select/filter by predicate, left-fold with a binary operator and a neutral element, converting a finite function (mapping from 1..n) into a sequence with a specified capacity, and functional updates (an except-like operation) that replace an element while preserving length and domain.

State properties that must hold for representative test instances and universally:
- Constructors produce sequences with the expected elements and lengths (including empty).
- Head and tail return the first element and the sequence without the first element for nonempty sequences; calling them on empty sequences is identified as undefined or produces a detectable error condition.
- Indexing maps each valid index 1..Len(s) to the corresponding element; indexing outside the domain is out-of-bounds (must be exhibited as undefined or a distinguishable error).
- Subsequence extraction yields expected slices and the empty sequence when bounds produce no elements.
- Append and concatenation preserve element order and adjust lengths correctly.
- Fold over sequences yields the associative accumulation of elements via the provided operator and neutral element; folding an empty sequence yields the neutral element.
- Map/mk-sequence yields sequences computed elementwise from index-to-value functions, respecting specified lengths and capacity bounds.
- Filter/select preserves relative order of elements satisfying the predicate and yields empty on no matches.
- Converting a finite function to a sequence produces the sequence of function values for indices 1..n; larger capacity does not add elements.
- Functional update preserves sequence length and domain while changing the specified index’s value.

Include example instances and boolean assertions that demonstrate and check these properties on small concrete sequences (including empty and multi-element cases) as well as quantified properties over families of sequences.
