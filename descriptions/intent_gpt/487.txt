Specify a simple two-variable state-transition system representing two integer-valued registers that evolve nondeterministically each step. The system starts with both registers set to zero. In each step, the next-state relation must allow either a simultaneous swap of the two registers, or an assignment into the registers that nondeterministically chooses one of a small finite set of integer values for one register while constraining the other register to particular values. Precisely characterize all allowed next-state possibilities so that some transitions exchange the current contents of the registers, and other transitions set one register to a chosen element from a fixed finite set while the other register is constrained to a specific constant. Specify that all transitions are total over the two-register state (i.e., every step produces a defined pair of new register values). Require that execution traces are infinite sequences starting from the initial zero state and proceeding only by permitted transitions. State the following correctness properties to verify: (1) safety invariants asserting that every reachable register value lies within the union of the initial value and the small finite set of allowed assigned values; (2) that a swap transition preserves the multiset of register values (the unordered pair); and (3) that when the constrained assignment branch executes, the constrained register always attains the required constant and the nondeterministically assigned register always takes a value from the allowed finite set. Also require liveness that prohibits deadlock: from any reachable state some allowed transition exists.
