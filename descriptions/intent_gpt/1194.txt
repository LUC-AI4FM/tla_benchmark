Specify a model of a simple concurrent-state system that explores a large finite initial state space and then remains stable. The system has three independent integer components, each initially allowed to range over a given finite interval: the first component must be any integer from 1 to 100, the second any integer from 1 to 200, and the third any integer from 1 to 20. After initialization, the system performs no state-changing actions: it remains in whatever initial triple was chosen for the remainder of execution.

Require the specification to capture all possible initial combinations of the three components (the full Cartesian product of the three ranges) so that model checking can enumerate the large initial state space. The specification should assert that no transitions change any component value and that every reachable state satisfies a trivial invariant (for example, a tautology) as a baseline correctness property.

Key properties to guarantee:
- The initial-state predicate allows exactly the specified ranges for each component and nothing outside them.
- The transition relation is identity: every step preserves all component values.
- Safety: every reachable state satisfies the stated invariant.
- Liveness: the system can remain forever without state changes (stuttering is allowed).

Do not constrain or relate the components beyond the ranges; ensure the model is suitable for checking state-space generation and invariants without additional dynamics.
