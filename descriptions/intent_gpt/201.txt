Specify a formal model of a simple computation mechanism that evaluates a recursively defined integer function and stores its result in a single variable. The system must be able to initialize that variable to the value produced by applying the recursive function to a specified nonnegative integer input, and it must allow an alternative initialization with a different input. After initialization the stored value must remain unchanged by all subsequent steps. The recursive function should compute the natural-number result of subtracting one repeatedly until reaching a base case (i.e., it should return the input when the input is less than 1, otherwise return 1 plus the function applied to input minus one). The specification should permit instantiating the recursive function at different input values and must permit controlling how deep or explicit the recursion is expanded in the model checker. Formalize the state space, initial conditions (for both single and alternate initializations), and a transition relation that preserves the stored value. State safety properties asserting the stored value equals the expected numerical result for each initialization. Include the ability to check that the invariant holds under all reachable states and that no further changes to the stored value occur.
