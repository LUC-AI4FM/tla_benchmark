Model a system that initializes and maintains a pure, statically-defined functional value and ensures its identity and domain are preserved across system execution. The system should represent an immutable mapping from a finite, explicitly listed set of keys to values, constructed at initialization using a comprehension or literal notation. The initialization must produce a value equal in structure and domain to the mapping expression used to create it (i.e., the mapping's domain and membership must match the original expression). After initialization, the system must perform only idle steps that do not change the stored functional value.

Specify the types and constraints: the key set is a finite, explicit set of atom-like keys; the mapped values are elements of some value domain (e.g., integers). The specification must assert that the stored mapping's domain equals the intended key set and that the mapping behaves extensionally (looking up a key yields the expected value). The only allowed transitions after initialization are stuttering steps that leave the mapping unchanged.

State safety properties: the mapping's domain and pointwise values remain constant forever. Show that no reachable state can violate equality to the original comprehension-generated mapping. Also include an invariant asserting the mapping is a function (each key maps to exactly one value) with the prescribed finite domain. Do not prescribe implementation details of how the mapping is constructed or represented.
