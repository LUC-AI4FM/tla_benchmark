Specify a formal TLA+ model of a library of finite sequences (ordered lists) over arbitrary element domains and basic sequence operations, and prove simple correctness properties about those operations. The model should treat sequences as immutable finite ordered collections and provide operations including: membership test (whether a sequence belongs to the set of sequences over a given domain), concatenation of two sequences, length, append (add element at end), head and tail, subsequence extraction over an index interval, and selection/filtering of elements by a predicate. The specification must state the intended semantics of each operation (for empty and nonempty cases) and the domain constraints (e.g., indices are naturals, empty sequence has length zero). Require proofs or invariants that demonstrate key algebraic identities and edge cases, such as: an empty sequence concatenated with any sequence yields that sequence; concatenation is associative; length corresponds to number of elements; append extends length by one and preserves order; head and tail are defined only for nonempty sequences and behave as first element and remaining sequence respectively; extracting an interval outside normal bounds yields the empty sequence; filtering selects exactly those elements satisfying the predicate in original order. Include simple test properties to expose type-safety issues (e.g., sequences of naturals exclude negative integers). The model should be purely declarative (no algorithmic implementation) and focus on specifying semantics and proving the listed properties.
