Specify a simple state machine that models a fixed finite set and a Boolean flag representing the outcome of a check over that set. The system begins with the set initialized to a known finite collection of integers and the flag initialized to true. The only state change allowed updates the flag to reflect the result of a predicate that asserts "there exists an element in the set that is not equal to a particular constant" (the constant is one of the elements of the initial set). The set itself must remain unchanged forever.

Model the transition that recomputes the flag from the current set each step; no other state changes are permitted. The initial condition should establish the given finite set and the flag’s initial value. The safety property to verify is that the flag is always true in every reachable state: because the set contains at least one element different from the given constant, the existential predicate should always evaluate to true and therefore the flag should never become false.

Ensure the specification expresses the existential test over the concrete finite set (not a skolemized or otherwise weakened form) so that the invariant checking must rely on quantifier semantics and not on premature instantiation.
