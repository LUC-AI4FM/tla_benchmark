Specify a model of set and function comprehension and basic finite-set operations used to construct and reason about finite collections, tuples, Cartesian products, function spaces, and cardinalities. The model should capture arbitrary finite sets built by comprehension expressions of the form “{expression : generator(s) ; predicate}” and map comprehensions producing sets of functions. It must allow nested generators (including multiple variables ranging over finite sets and Cartesian products), empty generators, and duplicated elements in source sequences where duplicates do not affect resulting set membership. The system should support tuple construction and membership tests for tuples produced by comprehensions, arithmetic expressions inside comprehensions, and membership and equality comparisons between constructed sets and expected finite sets or intervals.

The specification must include the semantics for function spaces as sets of total functions from a finite domain to a finite codomain; it must support selecting functions by predicates on function application results and computing cardinalities of such sets and of Cartesian products and function spaces. Required correctness properties: comprehensions yield exactly the intended finite sets (duplicates are ignored, empty generators produce empty sets), Cartesian-product comprehensions enumerate all ordered pairs as expected, tuple membership checks succeed when elements match, interval and arithmetic-based comprehensions include the right integers, function-space cardinalities equal |codomain|^|domain|, and filtering by function-output predicates yields the correct counts. The model should expose assertions that fail if any of these properties are violated.
