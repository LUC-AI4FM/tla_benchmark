Specify a formal model of a pure recursive function system that computes factorial-like values and can be instantiated or referenced by other modules. The model should define a scalar numeric domain (natural numbers) and a total function F on that domain such that:
- F(0) = 1.
- For every positive integer n in the intended domain, F(n) = n * F(n-1).
- The model should allow external modules or instances to import or call F and rely on its recurrence, without prescribing a particular implementation strategy (e.g., iterative loop, memoization, or tail recursion). It must capture the mathematical semantics of the recursion, not low-level evaluation steps.

Specify correctness properties to verify:
- Base-case correctness: F(0) equals 1.
- Inductive correctness: for each n in a given finite test range, F(n) equals n times F(n-1).
- Concrete evaluations for a few sample inputs (for example, F(4) = 24) to serve as sanity checks.
- Totality and well-definedness over the modeled domain (no undefined or divergent values).

Include assertions or invariants that these properties hold and that any instance using F may assume them when used compositionally. Do not constrain how callers invoke the function internally.
