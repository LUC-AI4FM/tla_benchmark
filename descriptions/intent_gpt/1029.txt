Specify a TLA+ model of a unidirectional ring leader election algorithm in which N processes arranged in a logical ring elect a single leader by passing integer identifiers. The system should allow any subset of processes to start an election concurrently. Each process can send messages clockwise containing identifiers; upon receiving a message, a process may forward it, replace it with its own identifier, drop it, or declare itself leader according to the algorithm’s rules. Messages are delivered reliably and in FIFO order along each link, but delivery may be asynchronous and with arbitrary delays. The model must capture process-local state (including whether a process is idle, participating in an election, or decided leader), the set of in-flight messages, and which processes initiated elections.

Require the specification to prove the following correctness properties: safety — at most one process is ever declared leader; validity — if an identifier v is declared leader then v equals the identifier of some process in the ring; eventual leader election (liveness) — starting from any configuration with a finite number of messages and at least one initiating process, the algorithm eventually reaches a stable state with exactly one leader and all processes aware of the leader; and termination of each individual election instance — every message injected for an election is eventually processed. Allow parameter N as a positive integer, and state invariants that capture monotonic progress toward election termination.
