Specify a simple state machine that models a single integer-valued counter that can be incremented, reset, and tested for a target value. The system must expose three kinds of external operations: (1) an increment operation that increases the counter by 1, but only if the counter is currently strictly less than a fixed upper bound; (2) a reset operation that sets the counter back to zero; and (3) a test operation that nondeterministically checks whether the counter equals a designated target value and produces a boolean result reflecting that equality without modifying the counter. The model must allow operations to occur in any order, possibly repeating, and must allow stuttering steps that leave state unchanged.

Require that the counter is always a natural number and never exceeds the specified upper bound. Specify safety properties: the result of a test operation must be true exactly when the counter equals the target at that step; increment must not change the result of a simultaneous test unless the test observes the post-increment value. Specify liveness properties: from any state where the counter is below the upper bound, it must be possible to eventually reach the target value by a sequence of increments (unless a reset repeatedly intervenes), and the system should not deadlock—some operation must always remain enabled. Include the ability to parameterize the target value and the upper bound.
