Model a concurrent system in which multiple workers independently evaluate a nondeterministic computation and then a single shared register is updated to reflect a chosen result. The model should capture: an initial register value that is distinct from any valid result; a nondeterministic source representing the set of possible computed values each worker may produce; many workers that may evaluate that source concurrently and possibly produce different values; and a coordinator step that, when it executes, samples or selects one of those computed values and writes it into the shared register. The system should allow repeated coordinator updates over time.

Specify the safety property that after a coordinator update completes, every worker’s observed register value is some valid computed value (not the initial sentinel) and all workers observe the same register value (i.e., the register is consistent across workers). Specify a liveness expectation that coordinator updates continue to occur (the system should not deadlock with workers or the coordinator permanently stalled). Allow the input nondeterminism to be large enough that different workers can legitimately compute different values. Do not prescribe how workers coordinate or how selection is implemented; only require that the register update is atomic with respect to the consistency property and that the system supports multiple workers and repeated updates.
