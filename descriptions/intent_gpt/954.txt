Model a specification of finite sets over an abstract universe and algorithms that operate on them. The specification should define what it means for a set to be finite by relating sets to finite sequences (or lists) that enumerate their elements, and it should provide a way to compute the size (cardinality) of any finite set. The model must also capture and verify basic closure properties: unions, intersections, set difference, and powersets of finite sets should themselves be finite, and the cardinality operator must satisfy expected algebraic identities (for disjoint unions, cardinality of union = sum of cardinalities; cardinality of a singleton = 1; removal of an element reduces cardinality by one when the element is present). Include properties ensuring that the enumeration of a finite set can be chosen without duplicates and that every element of the set appears at some position in the sequence. The model must reject or leave undefined cardinality for infinite sets. Specify invariants and temporal properties to prove that any algorithm that builds or reduces a finite set preserves finiteness and updates cardinality correctly. Finally, state liveness/termination requirements for constructive procedures that enumerate or compute cardinality (they must terminate producing a finite sequence or a number when given a finite set).
