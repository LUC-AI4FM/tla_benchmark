Specify a formal model of a translator that takes an abstract-syntax representation of a procedural algorithm language with global and per-process constructs and produces a target specification in a state-based formalism. The translator must accept as input well-formed parse trees that represent programs with named procedures, local and global variable declarations, labeled statements (including assignments, conditional branches, nondeterministic choice/either, loops, with/when constructs, procedure calls/returns, and final/terminal statements), and multi- or uni-process top-level structure. The model should capture the intended semantics of the source constructs (control flow, scoping, parameter passing, nondeterministic choice, guarded execution, and procedure call/return behavior) abstractly so that the translation can be reasoned about independently of formatting choices.

Require the translator to produce, for any correct input program, a semantically equivalent target specification that:
- represents program control points and data state explicitly,
- models initialization from declared initializers,
- preserves the possible next-state transitions implied by each source statement,
- encodes procedure calls and returns so that call stacks and returns behave correctly across nested calls and across processes,
- supports optional fairness constraints at the process-action or global next-action level.

State the key correctness properties: semantic preservation (every behavior of the source program corresponds to a behavior of the translated specification and vice versa, modulo differences due solely to representation choices), preservation of safety properties (invariants and assertions in the source hold in the target), and preservation of termination/terminal-state behavior for final statements. Also require that the model identifies classes of syntactic/semantic input errors (such as duplicate declarations, non-constant initializers where forbidden, or illegal use of local names) and either rejects such inputs or makes explicit when translation is undefined.
