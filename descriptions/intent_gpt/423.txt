Specify a static mathematical specification of nested, recursively defined finite arrays and functions over small natural-number ranges, and assert a suite of arithmetic and domain properties about them. Model finite-tabulated functions whose indices range over explicit small intervals (for example 0..N), where entries can themselves be arrays defined by recursion on their indices. Include at least three independent families of recursively defined tables:

- A two-dimensional family where each cell may be either a number or a one-dimensional table; recursion should depend on both row and column indices and permit base cases that return simple numbers, and recursive cases that reference previously defined entries in the same family.

- A two-dimensional triangular family (rows 0..M, columns 0..row) defined so column‑0 entries are defined by copying a value from the previous row (with a base for row 0), and other columns increment previous column entries by a fixed external constant parameter.

- A fully two-dimensional rectangular family (rows and columns over 0..K) whose base cases and recursive steps combine indices and previously computed entries to produce predictable arithmetic values.

Do not model time evolution except to allow a trivial initial state; the correctness properties are static assertions about the defined tables. Specify and prove (or check with TLC) properties that include:

- Specific numeric equalities for certain indexed entries (e.g., particular cells equal given integers).
- Correctness of nested table shapes: domains of rows and of nested entries match expected intervals.
- That particular nested entries equal specific one-dimensional tables (structural equality).
- That arithmetic relationships across rows and columns hold (e.g., entries equal linear functions of indices and the external constant).

The specification should avoid describing any implementation algorithm; instead state the mathematical definitions and the invariant properties to be verified.
