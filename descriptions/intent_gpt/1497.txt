Specify a formal model of a deterministic choice procedure that repeatedly selects a single maximum element from a fixed finite totally ordered set. The model should describe a system with an environment that initializes with a specific numeric state and then repeatedly performs transitions that pick a "maximal" index from one of several bounded ranges. The system must permit two different transition steps, each choosing a maximum from a possibly different finite range, and each transition updates the state to the chosen index. The model should treat choices as deterministic selections of an element satisfying the maximality property (an element strictly greater than every other element in the chosen range). It must ensure that the initial conditions include a well-defined numeric state and any static preconditions about the ranges used by the transitions. Key correctness properties to guarantee: (1) Every chosen value is a member of the intended finite range for that transition. (2) Every chosen value satisfies the maximality property with respect to the ordering on the range. (3) Safety: the state always remains within the union of the allowed ranges whenever a transition occurs. (4) Liveness: if one of the transitions remains continuously enabled, it will eventually execute and produce a maximum for its range. Additionally, include invariants that prove the state is always a natural number and that the maximality predicate holds for chosen values. Do not prescribe how choice is implemented; only require existence of a value meeting the maximality constraint.
