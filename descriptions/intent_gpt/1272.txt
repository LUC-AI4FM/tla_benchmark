Model a simple cyclic counter with a toggling bit that evolves in discrete steps. The system has a numeric counter that starts at 1 and increments by one on each step until it reaches a fixed maximum (4). When it reaches the maximum it wraps back to 1 on the next step. Concurrently, a Boolean flag flips its value on every transition. Every step must be an atomic transition that updates both the counter and the flag (no partial updates visible).

Specify initial conditions: the counter equals 1 and the flag is false. Specify the transition relation: if the counter is less than the maximum, it advances by one; if it equals the maximum, it wraps to 1. In every case the flag is negated.

State the correctness properties to be checked:
- Safety: the counter's value is always within the allowed range 1..4 (i.e., it never exceeds the maximum).
- Progress/Liveness: from any reachable state, it is eventually possible for the counter to exceed the maximum (this property is intentionally to be tested and should fail if the model does not permit it); and also state properties to detect undesirable stuttering behaviors where no state change occurs when a transition is expected.
- Fairness: require weak fairness for the transition relation so that enabled transitions are not indefinitely postponed.

Also require the model to produce concrete counterexamples (finite or lasso-shaped) when any property is violated, including human-readable trace expressions that show counter values and flag values at each step.
