Specify a formal model of a multiset (bag) library and its core higher-order aggregation operators, and prove basic algebraic and safety properties. Model primitive bag constructions, element multiplicity, and standard bag operations: union/merge, addition of a single element, removal of a single occurrence, and removal of all occurrences. Include conversions between sets and singleton-element bags. Provide an operator that folds an associative binary operation over all occurrences of a bag (generalized fold), and a derived map-then-fold composition that maps elements to intermediate values and then folds them. Also include standard numeric aggregations built from fold: sum, product, and a concatenation/append fold for sequences.

Requirements:
- Operations must behave as expected on simple bags (e.g., adding an element increases its multiplicity by one; removing a non-present element leaves the bag unchanged; removing all occurrences yields the bag without that element).
- Conversions between sets and bags must be consistent: converting a finite set to a bag yields each element with multiplicity one; folding over such a bag with a mapping to singleton sets and union then yields the underlying set.
- Fold must be deterministic on finite bags and respect multiplicities (e.g., sum and product produce the arithmetic sum/product of elements counted with multiplicity). Ensure fold over empty bag returns the base value.
- Type and error conditions must be detectable: folding or numeric aggregates applied to invalid bag inputs or element values of wrong type should be flagged as errors.
- Include nontrivial test cases and edge cases (negative and zero multiplicities, large multiplicities, elements that cause neutral results) that must satisfy the algebraic equalities and error expectations.

State the correctness properties to check: equality of results between direct fold and map-then-fold composition for representative operators; preservation of bag semantics under add/remove operations; expected numeric outcomes for specified example bags; and that invalid inputs produce specified error diagnostics.
