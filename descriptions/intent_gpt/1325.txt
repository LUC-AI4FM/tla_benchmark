Specify a formal TLA+ model of a finite-state generator that nondeterministically produces sequences of integers of a fixed length and exposes checks that compare those sequences to an expected reference. The system should allow any number N (a small fixed constant) to determine the maximum index used in constructing sequences. The generator must be able to return either the exact expected sequence or any different sequence; both possibilities must be represented as nondeterministic choices. The model should include an operation that constructs a candidate sequence by mapping each position in 1..N+1 to an integer derived from the index (for example index minus one), and then compares that candidate to a given reference sequence. The specification must assert that the comparison outcome can be either equality or inequality and that the system can validly take either branch. Key correctness properties to guarantee: (1) Safety: any produced sequence is always constructed by the specified mapping from indices 1..N+1; (2) Liveness: from every reachable state the system can eventually perform a comparison step and reach a state where either equality or inequality holds; (3) Invariant: the set of possible sequences is exactly the set produced by the mapping (no stray sequences); (4) The nondeterministic choice between equal and unequal comparison outcomes is reachable. Do not prescribe an implementation strategy or operational encoding.
