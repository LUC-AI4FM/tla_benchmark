Specify a concurrent-state system with two integer-valued components that evolve in lockstep at discrete steps. The model should allow both components to read the other's current value and update deterministically according to conditional arithmetic expressions. The initial state must fix the two integers to different small constant values. At each step both components must be updated simultaneously according to rules that compare one component to a threshold and either assign a fixed upper value or compute the next value as the other component plus one.

State the behavioral requirements in both safety and liveness terms. Safety requirements: every reachable state must have integer-valued components within the full integer domain and all state transitions must conform to the simultaneous-update rule described; forbid any transition that updates only one component or that violates the conditional computation. Liveness requirements: express eventualities that must hold infinitely often or eventually — for example, require that one component eventually and repeatedly exceeds a small bound, and also include at least one liveness property that is false (to allow testing of counterexamples). The specification should allow model checking of reachability, invariants, and temporal properties including eventual and repeated eventual modalities.
