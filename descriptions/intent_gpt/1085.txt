Specify a model of a distributed system that explores how independent faults affecting processes lead to safety or liveness violations, and collect statistics about which fault combinations cause which outcomes. The system consists of a small finite set of identical processes that interact by exchanging messages or taking local steps; some steps may be nondeterministic. A test harness repeatedly selects subsets of one or more faults to inject simultaneously; a fault is any deterministic, reproducible deviation from the nominal behavior of a single process (for example: delay of a step, omission of a message, wrong message content, crash, or arbitrary state corrupt). Each trial runs the system to completion (or to a bounded length) under the chosen set of faults and reports one of: clean run (no property violated), assumption violation (precondition or environment assumption broken), safety invariant violation, or temporal-property (liveness) violation.

Model the selection of fault combinations uniformly from all nonempty subsets of a fixed fault set and allow multiple independent trials with different random seeds. Ensure the harness records, for each fault set and trial outcome, which class of outcome occurred. Specify correctness properties: (1) Safety invariants must hold in all executions without faults; (2) when faults are injected, the model must correctly classify executions into the four outcome categories; (3) trials must be independent and reproducible given the same seed and fault set; (4) the statistics collection must deterministically reflect the result of each trial (no lost or duplicate recordings). Include a bounded execution length to ensure termination of each trial.
