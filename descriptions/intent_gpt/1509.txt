Specify a simple finite-state system that maintains a single integer-valued state drawn from a fixed finite set {1,2,3,4,5}. The system should allow nondeterministic steps that may optionally leave the state unchanged, but must always preserve that the state remains within that finite set. Additionally, the system should expose an abstract total mapping from a small finite domain (three or more indices) into the same integer range such that at least one index in that domain maps exactly to the current state value at all times—this is an invariant to be enforced.

Model the initial condition as an arbitrary choice of the state from the finite set. Model transitions as arbitrary steps that may change the state to any other value in the finite set or choose to keep it unchanged, ensuring the state never leaves the set.

Specify the correctness property as a safety invariant: at every reachable state there exists an index in the mapping’s domain whose mapped value equals the current state. Also require a liveness property expressing that the system does not deadlock (i.e., always has at least one enabled transition). Do not prescribe how the mapping is implemented internally; treat it as an abstract function with a finite domain that must satisfy the invariant with respect to the state.
