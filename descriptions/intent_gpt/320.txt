Model a simple mutable map abstraction for two distinct key/value domains and operations that extend those maps by adding or updating a single key with an associated value. The system maintains two independent finite maps: one mapping strings to integers and the other mapping integers to strings. The only state transitions are atomic extensions of one of these maps that bind a specified key to a specified value; an extension either inserts the key if absent or updates the existing binding. The model should allow repeated, interleaved extensions to either map and permit starting from empty maps.

Specify the allowable operations and their preconditions (none beyond valid key/value types), and require that each extension produces a total map whose domain is the union of the previous domain and the singleton containing the updated key, and whose binding for any key equals the newly supplied value when that key was updated, or equals the previous binding otherwise.

Formally state these correctness properties: (1) type safety — all keys and values in each map are of the declared key and value types at all times; (2) extension semantics — after an extension of map M with (k, v), M(k) = v and for all other keys k' ≠ k, M(k') preserves its previous value; (3) domain monotonicity — each extension yields a domain equal to the previous domain ∪ {k}. Also state liveness: it must always be possible to perform further extensions on either map. Do not constrain how maps are represented internally.
