Specify a model of a system that generates total or partial integer-to-integer functions as values and then exposes them to a verifier. The model should treat a generated function as an atomic value whose internal representation is not inspected or modified by the rest of the system. The generator may nondeterministically produce any finite function mapping integers to integers, subject to a bound on the number of defined arguments, and the rest of the system must be able to hold and pass such a function value around unchanged.

The specification must assert and check the following correctness properties:
- Safety: after generation, the function value remains a stable value (no action in the system alters its mapping).
- Well-formedness: the generated function is not the empty mapping; at least one input is mapped.
- Representation-robustness: operations on or comparisons of function values must not depend on internal or implementation-specific junk bits; equality and domain tests must reflect semantic equality of mappings only.
- Finiteness: the function’s domain is finite and bounded by a configurable maximum size.

Model nondeterministic generation, storage, and simple inspection operations (domain membership and value lookup) but do not model internal representation details. Include assertions or invariants that would detect spurious counterexamples caused by representation artifacts rather than true semantic violations.
