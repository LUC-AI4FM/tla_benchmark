Specify a simple nondeterministic choice mechanism that repeatedly selects one of a fixed finite set of callbacks and executes it, updating a single integer state. The system should initialize the state by invoking one callback from a set of ten callbacks, each of which sets the integer to a distinct value in 1..10. After initialization, the system should allow an arbitrary sequence of steps; in each step the system nondeterministically picks one callback from the same set and executes it, assigning the integer to that callback’s associated value. The model must abstract away implementation details of how callbacks are represented and focus on the externally observable behavior: the state’s value and the legal transitions that assign it to one of the ten constants.

Specify the following correctness properties to be checked:
- Safety: the integer value is always positive (strictly greater than zero) in every reachable state.
- Liveness: from any reachable state, it must always be possible to eventually reach each of the ten possible integer values (each callback value is perpetually enabled in the nondeterministic choice).
- Closure: every transition assigns the state to one of the ten allowed constant values; no other values are ever produced.

Model the choice as truly nondeterministic (no fairness required unless needed for liveness checks) and keep the state domain as integers. Provide the initial condition, allowed transitions, and the invariants and temporal properties to verify.
