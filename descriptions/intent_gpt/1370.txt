Specify a distributed algorithm that constructs a spanning tree rooted at a distinguished node in an undirected graph and computes each node’s distance (hop count) from the root. The model should treat nodes as independent processes that communicate only by sending and receiving integer messages on reliable FIFO point-to-point channels between neighbors. Initially, the root knows distance 0 and other nodes have an effectively infinite distance. The algorithm must propagate distance information outward, allow nodes to choose a parent neighbor that yields a strictly smaller distance, and converge so that no messages remain in transit.

Model requirements and correctness properties:
- Liveness: the system must be fair so that if a process can act infinitely often it will; the protocol must eventually quiesce (no pending messages).
- Safety (distance correctness): when the system quiesces, every node’s recorded distance equals the graph-theoretic shortest-path distance (number of hops) to the root.
- Safety (parent relation): when quiesced, every non-root node’s parent is one of its neighbors and has distance exactly one less than the node’s distance.
- Termination implies no queued messages on any channel; the model must permit reasoning about message queues and their contents during execution.
- Channels are FIFO and per-edge; messages are small integers representing distances.
- The algorithm may use local variables per node for tentative distance, parent pointer, and acknowledgment flags; the specification should not commit to a particular message scheduling strategy beyond fairness.

Also require invariants that capture typing/limits (distances bounded by a known MaxNodes), and properties that allow proving eventual termination and the two safety conditions above.
