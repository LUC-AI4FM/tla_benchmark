Specify a model of a simple state system that is used to validate basic set, sequence, and quantifier semantics over empty collections. The system should have a trivial state that does not change but serves as a context to evaluate a suite of logical and set-theoretic facts. The specification must state the expected behavior of operations and expressions when applied to the empty set, empty sequence, empty domain, and empty ranges, independent of any particular implementation.

Requirements:
- The model must assert that common set-theoretic equalities and identities involving the empty set hold: e.g., the power-set of the empty set, unions over empty collections, indexed set comprehensions over empty domains, and finite integer ranges that evaluate to empty must be equivalent to the empty set where appropriate.
- The model must assert expected properties for sequences and functions with empty domain or codomain, such as the canonical representation of an empty sequence and mappings from or to the empty set.
- The model must assert the semantics of existential and universal quantifiers over an empty collection (existential is false, universal is true).
- Provide checks that detect any violation of these expectations and report which identity failed.
- The system should be invariant: state does not change and all checks are treated as invariant properties to be satisfied at all reachable states.

Specify the correctness properties as invariants that must hold for every reachable state and ensure clear failure reporting for each violated identity.
