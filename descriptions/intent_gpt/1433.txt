Specify a model of an initialization generator that produces the minimal set of distinct initial states of a single integer-valued state variable subject to a collection of logical initialization predicates. The model should represent an abstract checker that, given a finite set of initialization clauses each being a Boolean combination of equality tests and conjuncts/disjuncts that may mention the state variable, determines exactly which assignments to the state variable are legal initial states and returns each legal assignment once.

Requirements:
- The system must accept an arbitrary finite list of initialization predicates, where each predicate can be an arbitrary Boolean formula built from equalities between constants and the state variable, conjunctions, and disjunctions.
- An assignment to the state variable is considered a legal initial state iff at least one predicate evaluates to true under that assignment.
- The generator must not produce duplicate initial states: each distinct value for the state variable that satisfies at least one predicate must appear exactly once in the set of initial states.
- The decision about whether a predicate assigns the variable should be based only on satisfiability of that predicate under a given value; evaluation order of subexpressions must not cause spurious multiplicity or omission of assignments.
- The model must allow predicates that contain constant tautologies or contradictions, and these must be handled correctly (tautologies accept all values, contradictions accept none).
- Specify safety properties: the produced initial-state set equals {v | exists predicate p with p(v) = true}. Specify liveness property: generator eventually enumerates all such v (finite domain assumed).
