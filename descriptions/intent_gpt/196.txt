Specify a formal model of the N‑Queens search and solver that finds all ways to place N queens on an N×N chessboard so that no two queens attack each other. The model should treat a complete placement as an ordered list of N column positions, one per row, and allow reasoning about partial placements of length ≤ N used during search. The system must support an iterative/backtracking search that repeatedly extends partial placements by adding a queen in the next row only on columns that do not conflict (same column or same diagonal) with already placed queens. The model must characterize the transition relation of picking some partial placement and replacing it by all its nonconflicting one‑queen extensions; when a placement reaches length N it must be recorded as a complete solution. The specification must guarantee type and structural invariants (partial placements have length < N, solutions have length N, all placements use columns 1..N). Key correctness properties to assert: (1) Safety — every recorded complete placement satisfies the nonattacking constraint; (2) Liveness/termination — the search eventually exhausts the frontier (no partial placements remain) and thus all solutions are discovered; (3) Completeness — when the search frontier is empty, the recorded set equals the full set of all valid N‑queen solutions; and (4) Preservation of invariants across transitions. Allow N as a positive integer parameter.
