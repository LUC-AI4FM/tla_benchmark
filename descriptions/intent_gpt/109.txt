Specify a formal model of a library of finite-set utilities and combinatorial operators over finite, typed domains. The model should define operations to compute aggregated values (sum and product) over finite sets of numbers, quantify how many elements satisfy a predicate, and enumerate k-element subsets and Cartesian-choice selections without assuming infinite sets. It must provide deterministic selection of extrema (maximum and minimum) for nonempty finite integer sets, and a deterministic unique-element selector that fails when zero or multiple candidates satisfy a predicate. The model must handle only finite sets and explicitly document preconditions (e.g., nonemptiness for max/min). It must ensure commutativity and associativity assumptions where needed for reduction-based aggregation, but not rely on a particular traversal order. Correctness properties to guarantee include:
- Aggregation correctness: sum and product equal the usual arithmetic sum/product of the set elements.
- Cardinality and quantification: counting operators match the size of predicate-filtered subsets.
- k-subset enumeration: the k-subset operator enumerates exactly those subsets of given cardinality and yields the empty set for invalid k.
- Choice completeness: the choice-construction returns all selections that pick one element from each input set.
- Uniqueness enforcement: the unique chooser yields a value iff exactly one element satisfies the predicate, and otherwise is undefined/erroneous.
Also specify type constraints and invariants ensuring all operators terminate on finite inputs and produce results consistent under set-permutation (order-independence).
