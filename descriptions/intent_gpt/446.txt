Specify a small verification model that treats numeric literals in binary, octal, and hexadecimal notation as equivalent representations of the same integer values. Model a system that accepts integer constants written in base-2, base-8, and base-16 syntaxes (including both uppercase and lowercase digit/letter forms where applicable), and normalizes or interprets them as ordinary integers in the natural numbers. The model must capture expressions that compare these differently written constants for equality, and it must permit proving that different notations that represent the same numeric value are equal.

Requirements:
- Allow binary, octal, and hexadecimal forms that represent the same numeric value to be considered equal to the corresponding decimal integer.
- Support both upper- and lower-case variants of alphabetic hexadecimal digits and any accepted case variants of literal prefixes if the language permits them.
- Include checks that detect mismatches where different notations do not represent the same value.
- Specify and prove the core correctness property: for each pair of literal representations included in the model that denote the same numeric quantity, the model must assert their equality; for pairs that denote different quantities, the model must assert inequality.
- Ensure the domain of interpreted values is the natural numbers and that the interpretation function is deterministic and consistent across representations.
