Specify a concurrent algorithm that computes the strongly connected components (SCCs) of a directed graph using multiple worker threads that cooperatively perform on-the-fly exploration and merge discovered components. Model the graph as a fixed finite set of nodes and directed edges. Model multiple concurrent workers that repeatedly select not-yet-finalized nodes to explore, perform depth-first (or equivalent) exploration of outgoing edges, and detect cycles that indicate nodes belong to the same SCC. Workers may claim responsibility for components, maintain per-component metadata used for coordination (such as which workers are currently processing nodes of the component and which nodes in the component remain to be explored), and merge components atomically when a cross-edge reveals that two components belong to the same SCC.

The model must capture the algorithm’s termination condition (workers eventually finish when all nodes are finalized) and must preserve correctness: upon termination the partition of nodes produced by the algorithm must equal the partition induced by the graph’s SCC relation (reachability in both directions). Safety properties to require include: components are merged only when there is evidence of mutual reachability (no spurious merges), nodes are not lost (every node belongs to exactly one component at all times), and once a component is declared finalized (dead) its nodes are no longer re-explored. Liveness properties should assert eventual completion when exploration is possible and that workers make progress (no permanent livelock). The formal model should be amenable to checking both the safety equality of final SCC sets and termination/liveness claims.
