Specify a concurrent system of a fixed set of identical processes participating in a simple independent printing task. Each process repeatedly performs an atomic request to print a message; the system should allow every process to perform this printing action indefinitely, subject only to fairness, with no central coordination or mutual exclusion required. Model the processes as independent agents that may nondeterministically decide when to perform a print operation; printing is an observable event that identifies which process executed it. The model must capture the notion of a configured finite population of processes (the population size is a parameter) and allow reasoning about infinite execution traces.

The specification must guarantee these correctness properties:
- Safety: Every observable print event is produced by some valid process in the configured population; no spurious or malformed print events may occur.
- Liveness (weak fairness): Each process that remains continuously enabled to print will eventually perform a print; thus no process is permanently starved if it can always print.
- Progress: The system permits infinite runs containing infinitely many print events; it cannot deadlock into a state with no further prints possible unless the modelled configuration legitimately forbids printing.

Include configuration of the number of processes as a parameter and expose the set of observable print events so temporal properties can be checked.
