Specify a system that models inclusion and integration of a reusable specification component into a larger specification framework. The system must allow a base specification (the included component) to be combined with a host specification so that the host can rely on the component's defined constants, types, and invariants without redefining them. The model should describe how the host imports the component's assumptions and exposes only the intended interface, preserving abstraction boundaries and preventing accidental dependence on the component's internal auxiliary definitions.

The model must support reasoning about initialization and stepwise evolution where the included component contributes constraints to the global initial states and allowed transitions. It must guarantee that all global executions satisfy both the host's and the included component's invariants and that no transition exists in the combined system that would violate either side's safety properties. Also require that liveness properties proved in the included component remain valid when composed with the host, unless the host explicitly weakens assumptions; any weakening must be explicitly represented.

Specify correctness properties: preservation of the included component's invariants under composition, noninterference of private/internal definitions, explicit interface contracts for assumptions and guarantees, and compositional reasoning support so that proofs about the component remain applicable when integrated.
