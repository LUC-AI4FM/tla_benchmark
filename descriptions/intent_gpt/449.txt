Specify a declarative model that exercises and validates set- and tuple-manipulation semantics for Cartesian products, function and record constructors, set comprehensions, ranges, empty sets, and related derived operations. The model should represent simple states but mainly serve as a suite of logical checks: compute Cartesian products of finite sets of various arities (pairs, triples, quadruples), test membership of specific tuples in those products, and compare computed products against explicit enumerations. It must evaluate tuple-valued function expressions applied to concrete tuples (including mixed numeric domains) and verify their numeric results. It should check behavior when one or more component sets are empty, ensuring products and derived constructions produce empty results as expected. It must validate operations involving maps/records, subsets, intersections with function domains, set comprehensions that produce empty sets, unions, set difference with incompatible ranges, and nested constructions combining these features. The specification should declare invariants that assert equality or non-equality of computed expressions with expected values and fail if any assertion is violated. Correctness means every asserted equality holds and every asserted disequality is true, thereby confirming the language semantics for Cartesian products, membership, and related set and tuple operations on the tested finite examples.
