Specify a formal model of two independent one-dimensional resource allocation processes that run concurrently and interact only by competing to reach a shared numeric target. Each process maintains a map from a fixed finite set of resource names to nonnegative integer counts (its capacities), and a separate integer state that counts progress toward the global target. The system evolves by interleaving steps from the two processes: in a single step, one process may increment its progress state if and only if doing so does not exceed the capacity of the resource it would consume at that step, and it may never increase any resource counts beyond their fixed capacities. The two processes do not share mutable resources but both observe the same global numeric goal value and are trying to satisfy "progress >= goal" for the system. Model initial configurations with given capacity maps for each process and an initial goal value. Specify liveness that allows each process to take steps indefinitely unless the goal is reached, and fairness assumptions needed for progress. Specify safety properties: resource counts always stay within their capacity bounds, progress counters never decrease, and no step violates a process's capacity constraints. Specify the correctness property: if a process reaches the goal, then the system reports success; otherwise, under the fairness assumptions, it is impossible for the system to avoid eventually reaching the goal. Also require that any counterexample demonstrating unfair starvation must show a finite sequence of interleaved steps leading to a stuck state or deadlock.
