Specify a formal model of a library of finite sequences and sequence-manipulation operations. The model should treat sequences as ordered finite collections allowing duplicates and should provide operations for constructing, querying, transforming, and combining sequences. Required functionality includes: conversion between sequences, sets, bags, and functions; prefix/suffix and strict-prefix/suffix checks; membership tests; concatenation, head/tail access, length, subsequence extraction, reversing, flattening nested sequences, interleaving and zipping two sequences, and yielding all contiguous subsequences and all subsequences (not necessarily contiguous). Include operations to remove elements or the first matching element, replace at an index, replace all occurrences of a value, replace the first/ all occurrences of a subsequence, and compute the longest common prefix of a collection of sequences. Provide fold (left/right) and fold-over-sequence functions, and operations that enumerate all permutations/partial permutations of a set as sequences. Define selection operators that return the first/last index satisfying a predicate in a (sub)sequence. The specification must state the domain and type constraints for inputs and the behaviour on edge cases (empty sequences, empty patterns, non-present subsequences). Key correctness properties: operations preserve sequence order and multiplicity semantics; conversions round-trip where appropriate; replace/replaceAll semantics produce expected lengths and content; interleave/zip and flatten relationships hold; fold results match functional definitions; subsequence/prefix/suffix predicates satisfy set-theoretic relations; longest common prefix returns a maximal common prefix. Ensure determinism and totality (well-defined outputs) for all specified inputs.
