Specify a simple discrete-state system with a single integer-valued state that can be initialized to 0 and can non-deterministically update by applying one of several binary arithmetic-like operations with a fixed integer operand. The model should treat these operations as abstract binary operators that return an integer result; the specification must not assume any operator has special built-in meaning beyond producing an integer when applied to two integers. The system must allow the next-state relation to choose any one of the defined operator applications with operand 1 and assign that integer result to the state.

Require the following correctness properties:
- Safety: the state remains an integer at every reachable state.
- Invariance: the state always belongs to a specified integer domain (for example, all integers, or a bounded range if the domain is restricted).
- Nontriviality: from the initial state there is at least one enabled transition (the next-state relation is not deadlocked).
- Determinacy constraint: optionally specify whether each operator must be deterministic (given the same two integer inputs it always yields the same integer output) or may be unspecified/nondeterministic; the model must be able to express either choice.

Include the ability to name several distinct operator symbols and to assert axioms or properties about them (e.g., commutativity, identity element, or particular concrete definitions) so the same abstract model can be specialized to concrete arithmetic or left abstract for proof of properties independent of operator semantics.
