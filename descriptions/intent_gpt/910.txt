Specify a model of a simple hour clock that cycles through a fixed set of hour values and is initialized to a valid hour. The model should describe a single-state variable that holds an hour value drawn from a finite, ordered set representing the hours on the clock (for example 0..11 for a 12-hour clock). The model must allow transitions that advance the hour deterministically to the next hour, wrapping from the maximal hour back to the minimal hour. Include an initialization condition that constrains the state variable to be within the allowed hour set.

Formalize the behavior as an infinite-state execution: every step must either perform the deterministic hour-advance transition or stutter (no change). The specification must assert that the initialization predicate is an invariant: any state reachable from an initial state via any number of allowed transitions must satisfy the initialization predicate (i.e., the hour value always remains within the allowed set). Also assert that the system preserves the property that the hour variable always takes a value in the finite hour set and that advancement is the only non-stuttering action. Do not prescribe implementation details; focus on the state space, allowed transitions, initialization constraints, and the invariants that must hold for all reachable states.
