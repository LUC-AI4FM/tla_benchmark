Specify a model of a small message-retrieval subsystem where a fixed set of message identifiers maps to immutable message payloads. The system must provide an operation to obtain a message record by identifier; that operation returns a fresh record that contains both the payload and the requested identifier. Multiple invocations of the retrieval operation for the same identifier within a single step or transaction must yield records that are observationally equal (contain the same fields and values) but may be independent objects — i.e., copying behavior is allowed as long as contents match.

Model also an operation that takes a retrieved message and produces two results derived from it (for example, by printing or passing it to two consumers). The two results must be equal in value whenever they are produced from the same retrieval. The model should capture the expectation that retrieving the same identifier twice yields identical records and that consuming the same record twice yields identical outputs.

Key correctness properties:
- Retrieval returns a record containing both the original payload and the requested identifier.
- Two retrievals of the same identifier in the same context are value-equal.
- Consuming a retrieved record twice produces equal observable outputs.
- Records are immutable after retrieval (no later refinement can change their contained payload or identifier).

Do not prescribe how records are represented internally; focus on content equality, immutability, and the equivalence of repeated retrievals and repeated consumptions.
