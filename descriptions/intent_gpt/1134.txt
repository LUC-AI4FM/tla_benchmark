Specify a formal model of a predicate system over a finite universe of states that classifies sets of states as either universally-contained ("every") or existentially-overlapping ("some"), and provide a way to evaluate whether an arbitrary set of states satisfies such a predicate.

The model should include:
- A finite domain of states and arbitrary subsets of that domain representing collections of states.
- A type of predicate that pairs a label (either "every" or "some") with a subset of states. Semantics:
  - An "every" predicate is satisfied by a set X exactly when X is a subset of the predicate’s set.
  - A "some" predicate is satisfied by X exactly when X has a nonempty intersection with the predicate’s set.
- A correctness property for how satisfaction distributes over unions:
  - For "every" predicates, the union of two sets satisfies the predicate iff each set individually does.
  - For "some" predicates, the union satisfies the predicate iff at least one of the sets does.
- A representation mapping from subsets of the state domain to fixed-length bit vectors, with a bijective index-to-state enumeration, and boolean operations on vectors corresponding to set operations.
- A correctness property linking the vector representation to predicate satisfaction:
  - For "every", the bitwise AND of the vector for X with the predicate’s vector equals the vector for X iff X satisfies the predicate.
  - For "some", the bitwise AND is not the all-false vector iff X satisfies the predicate.

Require the model to be finite-state so it can be checked by model checking.
