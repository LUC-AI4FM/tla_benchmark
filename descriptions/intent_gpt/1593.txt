Specify a model of a recursive factorial computation performed by a simple call-stack-based procedure. The system should represent a caller that invokes a procedure with a nonnegative integer argument; the procedure multiplies an accumulating product by the current argument and then recurses with the argument decremented, returning when the argument reaches zero. The model must permit nested/recursive activation records so that local state is preserved across calls and restored on return, and it must allow an explicit return to the caller when recursion finishes.

Requirements:
- Inputs: an initial nonnegative integer n supplied by the caller.
- Observable output: a single integer representing the computed factorial n! stored in a global or externally observable location when the computation terminates.
- Correctness properties:
  - Partial correctness: if the procedure terminates, the stored result equals n!.
  - Termination: the procedure always terminates for every finite nonnegative integer n (i.e., recursion depth is finite and base case reached).
  - Safety: the accumulator holding the product remains a natural number at all times (no negative or non-integer values).
  - Stack discipline: each procedure invocation saves and later restores its caller’s local context so that after a return control resumes at the correct point with the correct locals.
- Progress properties: there must be progress steps corresponding to multiplication when argument>0, and eventual progress to termination (liveness).
- The model should be abstract about implementation details: represent call and return semantics and stack operations, but do not prescribe a particular implementation (e.g., do not hard-code a specific stack data structure; allow any representation that captures push, pop, and frame restoration).
