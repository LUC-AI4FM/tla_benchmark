Specify a formal model of a fixed-size circular buffer (ring buffer) accessed concurrently by multiple producer and consumer threads. The model should describe the buffer as a bounded array of slots holding either a value or a special empty marker, and expose operations for producers to write a value into a slot and for consumers to read a value from a slot. It must account for the buffer index wrap-around semantics: sequence numbers map to slot indices modulo the buffer size.

Model the concurrency of multiple producers and multiple consumers so that each logical read or write access may be implemented as a sequence of substeps (e.g., begin, perform, end) and so the model can track which threads currently hold read or write access to each slot. The system must forbid data races: at most one writer may be active on a given slot at a time, and no slot may have active readers and active writers simultaneously. The model should include type and bounds constraints (buffer size positive, sets of readers/writers nonempty, values distinct from the empty marker).

State the correctness requirements as invariants: safety properties ensuring absence of data races and preservation of slot contents except when a valid write occurs; and basic type safety for buffer structure. Also specify an initial state where all slots are empty and no threads hold access.
