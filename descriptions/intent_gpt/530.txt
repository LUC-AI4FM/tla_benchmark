Specify a model of a simple algorithm that computes the maximum element of a finite sequence of integers. The model should treat the input as a fixed sequence chosen from a given set of allowed sequences; every element of every allowed sequence must be at least some specified minimum value. The algorithm must iterate through the sequence left-to-right, examine each element, and maintain a variable that at all times holds the largest element seen so far (initialized to the specified minimum). If the sequence is empty the final maximum must remain the initial minimum.

Model the control flow as a terminating, sequential procedure that first checks a precondition requiring every element of the chosen input sequence to be strictly greater than the specified minimum (this check is required as an assertion the procedure relies on). Then perform the iteration that updates the running maximum when a larger element is found, advancing an index until the end of the sequence is reached. Upon termination, assert that if the input was empty the maximum equals the specified minimum; otherwise, the final maximum is equal to some element of the input and no input element exceeds it.

Specify liveness so the procedure eventually reaches termination. Express safety properties capturing: (1) the running maximum is always at least the specified minimum, (2) when the loop finishes the maximum is an element of the input (or the minimum for empty input), and (3) the final maximum is greater than or equal to every input element. Do not commit to implementation details such as variable names or step-by-step action decomposition.
