Specify a formal model of a library of finite partial functions and common function operations, and the properties those operations must satisfy. The model should treat functions as finite maps between finite domains and codomains, and include operations to: restrict a function by domain predicate or by value predicate; test whether a mapping is injective; compute a functional inverse (right-left inverse on the range of an injective function); construct a function that maps a sequence of keys to values (including anti-function from values back to keys); perform pointwise binary operations on two functions with the same domain; fold a binary operator over the values of a function or sequence, optionally restricted to a subset of keys; and test whether one function is a restriction of another.

Require precise semantics for each operation (inputs/outputs and error conditions when arguments have incorrect types). Key correctness properties to guarantee:
- Restricting by domain or by values yields the expected submap (only pairs whose key/value satisfy the predicate).
- Injectivity predicate is true iff distinct domain elements map to distinct values; handle degenerate cases (empty and singletons).
- Inverse exists and yields a function mapping each value in the range back to its unique original key when the original is injective; inverse(inverse(f)) = f for injective finite functions with matching type constraints.
- Anti-function behavior: building an inverse from a known bijection returns the expected mapping; composing anti-function twice restores the original.
- Pointwise operations apply operator to corresponding values for each key in the shared domain.
- Fold behaves deterministically, is well-defined for large finite domains, and signals errors for invalid argument types.
- IsRestriction correctly characterizes when every binding of the first map appears with same value in the second.

Also require that these operations are pure (no hidden side effects), total on correctly typed inputs, and produce informative runtime errors on misuse.
