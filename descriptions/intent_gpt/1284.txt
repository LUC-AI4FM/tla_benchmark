Specify a model of a randomized simulator that explores the execution space of a given concurrent/stateful system under different reward or scoring parameters. The model should represent a simulator driver that can repeatedly run a fixed verification task with a controllable randomness source (seed) and a tunable reward parameter, collecting whether each run succeeds or fails and recording outcome statistics. It must allow (a) running a baseline configuration without reward-based exploration, and (b) running the same task under several discrete reward values. Each run should be independent and parametrized by the seed and the reward value. The system should capture termination status (success/failure), count of successful runs per reward, and allow reporting of per-run outcomes. Correctness properties to guarantee: (1) determination of run termination is deterministic given seed and reward; (2) the driver does not change the task semantics—runs with identical seed and reward yield identical outcomes; (3) statistics collected (counts and lists of outcomes) accurately reflect the outcomes of all runs and are updated only when a run completes; (4) the baseline run is treated distinctly and recorded; (5) all considered reward values are exercised. Additionally, specify invariants ensuring no lost or duplicated run results, and liveness that all configured runs eventually complete.
