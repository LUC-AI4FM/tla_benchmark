Specify a system that models a pure mathematical function evaluator embedded in a stateful environment and verifies basic safety properties about values computed by that evaluator. The model should represent an evaluator that can compute the factorial of a nonnegative integer by the usual recursive definition: factorial(0) = factorial(1) = 1, and for n > 1, factorial(n) = n * factorial(n-1). The state of the system should include a storage location that holds an integer value produced by evaluating the factorial function at some argument. The system should allow an initial evaluation to store factorial(4) and then permit a single state transition that replaces the stored value with factorial(7). The specification must ensure the evaluator always produces positive integers for nonnegative inputs and that the storage location never becomes less than 1. The model should include a safety property asserting this lower bound invariant and should be suitable for checking that the initial state and the allowed transitions preserve the invariant. Do not model any particular evaluation strategy or implementation detail beyond the mathematical definition of factorial and the two described evaluations.
