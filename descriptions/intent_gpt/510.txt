Specify a distributed asynchronous algorithm that lets every node in an undirected connected graph learn its distance (shortest-path length in number of hops) to a designated root node and choose a neighbor as its parent on a shortest path to the root.

Model a fixed network topology given by a set of nodes and an undirected edge relation. Nodes communicate by point-to-point FIFO queues on each ordered neighbor pair; messages carry nonnegative integer distances. Initially the root knows distance 0 and all other nodes consider their distance unknown (or a large sentinel). Any node may repeatedly receive a message from an incoming queue and process one message at a time. When a node receives a message containing a distance d that implies a strictly shorter path (i.e., d + 1 is less than the node’s current distance), the node must update its distance to d + 1 and record the message sender as its parent; it then sends its new distance to all of its neighbors (except possibly to the neighbor that just supplied that distance, depending on chosen optimization). If the received message does not improve the node’s current distance, the message is simply discarded. Message transmission and delivery are asynchronous and reliable (no loss, arbitrary finite delays); nodes may act in any fair interleaving.

Require the following correctness properties:
- Convergence: eventually every node’s distance equals its graph-theoretic shortest-path distance to the root.
- Parent validity: every non-root node’s parent is a neighbor and lies on some shortest path from that node to the root (parent distance equals node distance − 1).
- Safety of distances: distances never increase after they have been set to their final shortest-path values.
- Liveness/fairness: under weak fairness of node processing, messages propagate so that convergence is guaranteed.

Do not commit to a specific queue representation or ordering beyond FIFO semantics; allow modeling optimizations (e.g., suppression of redundant sends) but keep them optional.
