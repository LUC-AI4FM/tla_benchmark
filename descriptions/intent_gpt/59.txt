Specify a simple state machine that models a single set-valued storage that starts empty and is otherwise immutable. The model should include a state that holds a set of integers and an initialization that sets this state to the empty set. There are no transitions that modify the set after initialization; subsequent steps must leave the set unchanged. The specification should permit reasoning about safety properties concerning the stored set: in particular, it must guarantee that the set is always a finite set of integers, that it is equal to the empty set in the initial state, and that it remains equal to that value in every reachable state. Provide temporal properties asserting that the initial emptiness condition holds now and always (invariance), and that no reachable behavior can introduce elements into the set. Also include a well-formedness requirement ensuring the set variable is never assigned a non-set value. The goal is to have a minimal, verifiable TLA+ specification that captures an immutable empty set resource and proves its invariance across all steps.
