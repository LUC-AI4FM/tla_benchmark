Specify a concurrent system of several identical processes that each reads a shared numeric state, computes a simple arithmetic expression based on that shared state, stores the result in its own local storage, and then terminates. The model should treat processes as independent actors that may interleave arbitrarily and must allow for termination (processes eventually stop making progress).

Requirements:
- Shared state: one integer variable that starts at a specified initial value.
- Local state: each process has its own local storage cell for the computed result and a local control state indicating whether it is still running or done.
- Each process must perform the same computation: read the shared integer, add one to it, then add one again (equivalently increment twice), and write the final value into its local cell.
- The computation must use the value of the shared integer read at the moment of the read; the shared integer does not change as a result of the computation.
- Each process must check an assertion that its computed value equals the expected numeric result for the given initial shared value (for example, if the shared integer starts at 0, the expected result is 2). The model should allow parameterizing the initial shared value and expected result.
- Correctness properties to prove:
  - Safety: Whenever a process finishes writing its local result, that stored value equals the expected result computed from the initial shared value.
  - Liveness: All processes eventually reach the terminated control state (termination).
  - Noninterference: Processes do not modify the shared integer during their computation.
- The specification should permit arbitrary interleaving and stuttering, and should not assume synchronous steps across processes.
