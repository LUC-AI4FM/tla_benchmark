Specify a concurrent mutual-exclusion protocol for N identical processes that use only a single shared bit per process (a boolean flag) and a bounded shared integer token used as a scanner index. The model should describe processes that repeatedly alternate between noncritical work and attempts to enter a critical section. The entry protocol must use only the per-process flag and the shared scanner index to ensure at most one process is in the critical section at any time, and must guarantee progress under weak fairness: any process that continually attempts to enter eventually either enters or is not permanently blocked by others that stop progressing.

Require the specification to include:
- A parameter N > 0 and a set of N processes.
- Shared state: an array of N booleans (one flag per process) and a shared array or per-process view of a scanner index used while entering.
- Each process can set and clear its flag, scan other processes’ flags by advancing the scanner index, wait for others’ flags to become false, and enter/exit the critical section.
- Safety: mutual exclusion — no two processes may be in the critical section simultaneously.
- Liveness: under weak fairness for each process’s entry/exit actions, a process that repeatedly attempts to enter the critical section will eventually succeed (no starvation).
- The model should allow verifying invariants and temporal properties (safety and weak-fairness liveness).
