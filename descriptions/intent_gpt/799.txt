Specify a formal model of a distributed algorithm that finds the highest value present among a collection of sequences of nonnegative integers, subject to imposed size and value bounds. The system receives an arbitrary set of finite sequences whose length is limited by a given maximum and whose elements are bounded by a given maximum natural number. The model should treat the input as nondeterministic: any finite sequence that respects the length and element bounds may be present initially or may be introduced nondeterministically. The algorithm must output an index and value pair representing a sequence element with the maximal numeric value among all elements of all sequences; if multiple elements tie for the maximum value any one such element may be chosen. If all sequences are empty, the algorithm must indicate that no maximum exists.

Model the progress of the computation (including possible concurrent or nondeterministic exploration of sequences) and termination: the procedure must eventually produce the correct result or the explicit “no maximum” indication. Key correctness properties to guarantee are safety (the reported value equals some element of some sequence and is at least as large as every other element) and liveness (from any reachable state with sequences satisfying the bounds, the procedure eventually reports a result). Also ensure invariants that all accessed sequence indices and element values remain within the stated bounds.
