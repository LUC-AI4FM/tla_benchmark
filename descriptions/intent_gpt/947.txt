Model a real-time transition system with a discrete real-valued global clock that can only advance forward up to a known maximum value. The system consists of a control state evolving by discrete actions and a clock that continuously advances between discrete steps. The model must allow two kinds of steps: (1) internal time progress where the control state stays the same and the global time variable strictly increases to a later real value, and (2) discrete control transitions where the control state changes instantaneously while the global time does not advance. Time progress must never decrease and must always remain within the bounded real domain [0, MaxReal].

Include timed guards and deadlines on actions by associating with each enabled discrete action a per-action timer measuring elapsed time since the action became enabled. For each action, specify a minimum enabling time (an action cannot occur until its timer has reached at least a given lower bound) and a maximum enabling time (the action must either occur or the timer reset before exceeding an upper bound). When an action fires or becomes disabled, its timer resets to zero; while it remains enabled and time advances, its timer accumulates the real time elapsed.

Express fairness for time: ensure that time is not indefinitely prevented from advancing (time-progress fairness), so that for any requested future instant there is eventual time advancement consistent with the continuous time progress rule.

State the key correctness properties to verify: (1) Safety: discrete transitions respect their timing guards and deadlines; timers never exceed their declared upper bounds; and the clock stays within the allowed domain. (2) Liveness: enabled actions that are allowed by their minimum-delay constraints eventually occur before their maximum deadline or become disabled; and time can always progress (no unfair starvation of time advancement). Provide the model so that these properties can be checked with model checking or temporal logic proofs.
