Specify a simple counter system that models a single integer-valued state variable initialized from a given constant and allowed to increment indefinitely. The system should accept a parameter N that is an integer and must be used as the initial value of the state. Model initialization so the state equals that supplied initial integer, and model a transition that increases the state by exactly one on each step. The specification should allow infinite execution sequences (liveness) as well as finite traces.

Require these correctness properties:
- Safety: the state is always an integer and never takes non-integer values; every reachable state equals the original initial integer plus the number of increments taken.
- Invariance: the difference between the current state and the initial parameter is always a nonnegative integer.
- Progress/Liveness: it is always possible to eventually perform another increment (the system does not deadlock), so traces can be extended by the increment action indefinitely.
- Parameter well-formedness: the initial parameter must be constrained to be an integer; the specification should fail or be considered invalid if the parameter is not provided as an integer.

Do not prescribe internal variable names or an algorithm implementation; focus on the abstract state, the allowed transition, and the required properties.
