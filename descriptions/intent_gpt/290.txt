Model a concurrent system of N deterministic processes, each with a local integer clock that can advance asynchronously. The system must allow arbitrary bounded clock drift between any pair of processes: when clocks change, the difference between any two clocks must remain within a fixed nonnegative bound. Processes can perform local actions that may optionally reset or adjust their own clock but never directly set other processes’ clocks. The model should permit nondeterministic scheduling of process steps and of clock adjustments, subject to the drift bound.

Specify the initial condition: every process clock starts at an integer value (possibly all equal). Specify legal state transitions for a single process step and for global time progress such that only one process acts at a time, but clock values may change in ways that preserve the per-pair drift bound.

State the following correctness properties to verify:
- Safety: at all times, for every ordered pair of processes, the absolute difference of their clocks is ≤ a given constant D.
- Progress/liveness: every process is eventually scheduled and thus can make a step (no starvation).
- Monotonicity: for each process, its clock value never decreases across its own steps (unless an explicit allowed reset action is taken; if resets are allowed, characterize and bound them).
- Consistency under resets: if a process resets its clock, the model must still enforce the drift bound immediately after the reset.

Allow the model to be parameterized by the number of processes N and drift bound D so that these properties can be checked for varying system sizes and bounds.
