Model a graph reachability procedure that explores nodes starting from a designated root and marks all nodes reachable via directed successor edges. The model should represent a finite set of nodes, a successor relation that assigns to each node a set of outgoing neighbors, and a distinguished root node. The specification must describe nondeterministic exploration steps that can choose an unmarked node reachable from the root via a sequence of successor edges (possibly discovered incrementally) and then mark it. The system must ensure progress: if there exists an unmarked node reachable from the root, the procedure may eventually mark some such node until no reachable unmarked nodes remain. The model should permit arbitrary exploration orders (not require breadth-first or depth-first), but must prevent marking nodes that are not reachable from the root. Safety properties to guarantee: (1) only nodes in the finite node set may ever be marked; (2) once a node is marked it remains marked (marks are monotonic); and (3) a node is marked only if there exists a path from the root to that node following the successor relation. Liveness properties to guarantee: every node that is reachable from the root is eventually marked (fairness assumptions may be stated explicitly). Include an invariant characterizing the set of marked nodes relative to reachability and assert termination when no further reachable unmarked nodes exist.
