Specify a formal TLA+ model of a binary-search procedure that, given an arbitrary finite sequence of integers and an integer search key, either returns the index of an occurrence of the key in the sequence or indicates that the key is not present. The model should treat the input sequence as immutable and assume it may be of any finite length (including zero) and contain arbitrary integer values; the search key may be any integer. The procedure must operate by repeatedly narrowing a search interval within the sequence using comparisons against the middle element and must terminate after a finite number of steps. The specification must capture the algorithm’s external behavior only: the final result (either a valid index within the original sequence whose element equals the key, or a special “not found” result) and termination. It must assert that if the sequence is sorted in nondecreasing order, the algorithm always terminates and returns either an index i such that 0 ≤ i < length(sequence) and sequence[i] = key, or a designated not-found value when the key is absent. Additionally, require that the number of iterations is bounded by a function proportional to the logarithm of the sequence length, and that no out-of-bounds accesses into the sequence occur during any step. Do not presuppose any particular implementation details such as loop structure, variable names, or exact mid-point computation; only state the allowed observable behaviors, invariants, and correctness properties.
