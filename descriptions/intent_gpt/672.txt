Specify a small specification of a system that constructs and manipulates finite functions and tests basic function operations. Model a state that contains a finite map from a small finite domain to values, and provide operations to create, query, update, and compose such maps. The model should allow insertion of new mappings, removal of existing mappings, overriding a mapping for an existing key, and extraction of the set of keys and the image (set of values) of the map. Include an operation that composes two finite maps (where composition is defined when the range of the first fits the domain of the second), and an operation that computes a pointwise update that updates the value at a given key only if that key currently maps to a specified old value.

The specification must assert invariants: the map always remains a finite function from the prescribed domain to the prescribed codomain; keys not in the domain are not mapped; composition produces a map whose domain is contained in the domain of the first map and whose values lie in the codomain of the second map; pointwise update preserves finiteness and the domain except when removing a mapping. Specify safety properties that no operation produces undefined values outside domains, and liveness properties ensuring that repeated attempts to perform a supported update eventually succeed when preconditions hold (fairness for enabled operations). Include example properties checking that remove followed by insert can restore a previous mapping and that composition followed by projection recovers expected values.
