Specify a simple state machine that models a single Boolean state variable that must always be initialized to true and then updated repeatedly by applying a fixed external function that takes two arguments: a descriptive tag and the current Boolean value, and returns the next Boolean value. The model should treat the external function as a constant parameter whose behavior is not fixed in the spec (it may represent arbitrary deterministic computation or an oracle). The system must initialize the state to true and must define a nonterminating step that replaces the state by whatever the external function returns when invoked with the fixed tag "no error" and the current state.

State the safety requirements the model must guarantee: the initializer must establish the initial truth value, every step must produce a well-defined Boolean value, and the transition relation must be total (every reachable state must have a valid successor according to the external function). Additionally, express liveness requirements: the system must be able to take infinitely many steps (no deadlock), and if the external function is such that it eventually produces a stable Boolean value, the model should be able to exhibit convergence. Allow the spec to be checked against different interpretations of the external function, including those that raise an error, to make clear which behaviors are ruled in or out.
