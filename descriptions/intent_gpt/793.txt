Specify a library of small, purely functional collection utilities to be used by larger specifications. The model must include operations over finite sets, finite sequences, and sets of sets, and must treat these collections as immutable values. Required operations:

- A test whether two sets intersect (nonempty intersection).
- Total functions that compute the maximum and minimum elements of a nonempty finite set of comparable natural values, returning a well-defined element.
- A generic fold/reduction over finite sets and over finite sequences that applies a binary operator and a base value to produce a single result; the set reduction must be order-independent and well-defined for any finite set.
- Conversion between a finite sequence and the corresponding set of its elements, and a way to test whether a sequence is empty.
- A function returning the last element of a nonempty sequence, and a function that removes all occurrences of a given element from a sequence, producing a sequence.
- An operation that computes the intersection of a set of sets (dual to union), defined for a finite collection of sets.
- A construction that enumerates all permutations of a finite set, represented as finite sequences containing each element exactly once.
- A deterministic index operation that returns some valid index of a given element in a sequence containing that element.

For each operation, state preconditions (e.g., nonemptiness), the expected result type, and key correctness properties: soundness (result satisfies the intended meaning), completeness (all valid outcomes are possible for nondeterministic choices), and termination on finite inputs. Ensure the set reduction is invariant under input element order and the sequence reduction follows sequence order. Include unit-test style assertions that fail visibly when an operation produces an incorrect result.
