Specify a formal model of Dijkstra’s ring-based distributed termination-detection algorithm for N processes arranged in a unidirectional logical ring. The model should represent processes that can be active or passive, each holding a local color (white or black), and a single circulating token carrying a color. Processes may send activation messages to other processes (possibly wrapping around the ring), which may cause the sender to become black if it activates a process “ahead” in ring order; active processes may become passive at any time. The token moves around the ring in the opposite direction of message activation and can be recolored to black when it passes a black process; a designated initiator can start a probe round by passing a white token. Model the interleaving of local actions (send activation message, deactivate) and token-passing steps, and permit arbitrary nondeterministic scheduling.

Express the following correctness properties to be checked:
- Safety (soundness): if the token returns to the initiator white, then every process is passive and no messages are in transit (i.e., the system has actually terminated).
- Liveness (progress): if the system truly becomes quiescent (no active processes and no further messages are sent), then eventually the initiator will detect termination by receiving a white token.
- No false positives: the initiator must never conclude termination (declare termination) while some process is still active or some activation message is pending.
- Eventual detection under fair scheduling assumptions: assuming weak fairness of token-passing actions, termination will eventually be detected whenever it has occurred.

Parameterize the model by the ring size N, and state necessary assumptions (N ≥ 1). Do not prescribe an implementation; describe only state, permitted behaviors, and the correctness properties to be proven.
