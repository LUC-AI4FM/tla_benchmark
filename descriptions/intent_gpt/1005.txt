Specify a TLA+ model of a distributed reliable broadcast protocol for a system of N processes, up to F Byzantine faults but with at most T crash failures counted separately, that ensures eventual agreement among all non-faulty processes. The model should treat processes as independent agents that can send and receive messages asynchronously over unreliable channels (messages may be delayed, duplicated, or reordered but not corrupted), and processes may crash permanently. The system must support broadcasting values from any process and implement the following properties:

- Validity: If a correct (non-faulty) process broadcasts a value v, then every correct process eventually delivers v.
- Integrity: No correct process delivers more than one value for a given broadcast instance, and if a value v is delivered by a correct process and the broadcaster was correct, then v is the value actually broadcast by that broadcaster.
- Agreement: If any correct process delivers a value v for a given broadcast instance, then every correct process eventually delivers v (agreement on delivered value).
- Termination/Liveness: Every correct process eventually either delivers a value for each broadcast initiated by some process, or irrevocably determines that no value will be delivered because the broadcaster crashed before sending.

Capture faults as two types: crash (process stops taking steps) and arbitrary omission/delay in communication; do not model malicious Byzantine behavior beyond omission/crash. Specify fairness assumptions needed for liveness (e.g., weak fairness of enabled send/receive actions or eventual reliable delivery of sent messages). Include invariants that express safety (integrity and agreement) and a temporal property for liveness (validity and termination). The model should allow parameterization by N, T, and F.
