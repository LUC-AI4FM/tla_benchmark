Specify a simple state machine that maintains a single integer-valued state variable which is initialized to a fixed value and remains unchanged by every step. The model must capture an initialization relation that assigns the designated initial integer, and a transition relation that allows only stuttering behavior (the state never changes). Formally state the state space, initial condition, and transition relation without prescribing an implementation.

Require the following correctness properties to be checked as part of the specification:
- Safety: an invariant that is always true or always false should be expressible; include at least one explicit invariant to be verified against all reachable states.
- Liveness: the system should permit infinite execution (non-termination is allowed) by enabling the transition at every step (stuttering enabled forever).
- Type/Well-formedness: the state variable must remain an integer at all times.

Also request that the specification be organized so that a model checker can verify reachability and invariants, and so that the invariant check will fail if the invariant is contradictory (e.g., false). Do not include any implementation-specific control flow or algorithmic description; focus on the abstract state, its initialization, its allowed transitions (no-change only), and the properties to be proven or refuted.
