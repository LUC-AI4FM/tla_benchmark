Specify a model of a replicated append-only log service maintained by a finite set of servers that achieves single-branch consensus on the sequence of committed terms. The model should treat each server as holding a ledger (a finite sequence of ordered terms) that can only grow by appending entries, and it must reflect that logs never diverge into conflicting branches: at any time, any two server logs must be comparable by the prefix relation (one is a prefix of the other). Servers can copy suffixes of longer logs from other servers and can also extend the longest known log by appending one or more new entries. The model must permit nondeterministic choices of which server acts and how many entries are appended, but must forbid actions that remove, reorder, or alter existing entries.

Requirements:
- Represent a finite set of servers and an ordered domain of term values with a minimum starting term that every initial log contains.
- Initialize each server with an identical minimal starting ledger and allow only append operations and copying of suffixes from longer logs.
- Ensure liveness enough to let leaders extend logs and for followers to catch up by copying longer prefixes; operations may be nondeterministic but must preserve the prefix order invariant.
- Specify safety properties: append-only (no server ever loses or modifies past entries) and no-divergence (any two logs are prefix-comparable).
- Specify that copy and extend behaviors are observationally equivalent to simpler axiomatized actions (so implementations that choose how to extend or copy preserve the abstract behavior).

State the invariants and the transition relation for these actions; do not commit to a particular implementation strategy (e.g., leader election protocol or message-passing), only to the allowed atomic effects on server logs.
