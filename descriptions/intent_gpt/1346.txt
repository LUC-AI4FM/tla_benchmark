Specify a model of a collection of nodes that maintain and update membership information sets. The system must represent a fixed finite set of nodes; each node holds one value representing its current membership set drawn from a small fixed domain. Initially, all nodes must start with the same membership value. In each step, any single node may change its membership value to one of the allowed values; concurrent multi-node updates are not permitted. The model should permit nondeterministic choice of which node and which allowed value is used on an update.

Formalize the state and transitions without committing to any particular implementation: describe allowed states, initial states, and the transition relation. Specify invariants that must hold in every reachable state: (1) every node’s membership value is always one of the allowed values, and (2) at most one node’s membership value may differ from the initial common value at any time if the allowed domain contains a distinguished alternative, or state precisely how many nodes may diverge based on the allowed domain. Specify liveness properties: every node should be enabled to perform an update infinitely often (fairness), and no execution should deadlock due to unavailable updates. Also specify that updates only change the membership value of the chosen node and leave other nodes’ values unchanged.
