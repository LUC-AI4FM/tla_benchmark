Specify a formal model of a small functional utilities library and a simple state that exercises those utilities. The model should include: a pure higher-order fold that can reduce either finite maps (by folding over their domain) or sequences, given a binary operator and an identity element; a predicate that characterizes all finite sequences over a given element set whose length is at most a fixed bound; and a sorting function for finite sequences parameterized by a total order relation. The system to be modeled should expose an initial state and an invariant that exercises these utilities with concrete test cases: several fold invocations on maps and sequences (including empty and single-element cases) that produce specified numeric results; membership checks that verify which sequences belong to the bounded-sequence predicate and which do not; a universal property that all sequences in a bounded set have length at most the bound; and sorting tests that check sorting behavior on empty, single-element and multi-element sequences with repeated elements under different comparison relations. The specification must declare which properties are required to hold in all reachable states (invariants), and clearly mark failing cases as violations. Do not constrain implementation structure beyond these functional requirements.
