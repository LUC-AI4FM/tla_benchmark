Specify a model of a deterministic computation that evaluates the Fibonacci function over integers and exposes the result as a single state variable. The system should initialize by computing the Fibonacci number for a fixed initial index and store that value. It should then allow a single state transition that updates the stored value to the Fibonacci number for a different fixed index. The Fibonacci function being modeled must follow the usual mathematical definition: nonpositive indices map to zero, the first two positive indices map to one, and for larger positive indices the value is the sum of the two preceding values. The specification should treat the Fibonacci evaluation as a pure, total mathematical function on integers and not depend on any particular evaluation strategy. Require as a safety property that the stored value is always at least 1. Also state the invariant that initialization and the single update must both produce values consistent with the Fibonacci specification. Do not constrain how the function is implemented, but ensure the model can check correctness of the stored values and the invariant after each allowed step.
