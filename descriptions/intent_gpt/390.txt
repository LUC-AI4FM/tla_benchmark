Specify a simple stateful system that models a single integer-valued variable evolving over discrete steps. The system should allow arbitrary state transitions except that, whenever the system takes a step, the variable must end up equal to zero in the next state. The initial state may be any integer. Model both the state space and the step relation that enforces the constraint that after every transition the variable's value is zero.

State the required safety property that every reachable successor state has the variable equal to zero. Also state a trivial liveness property that the system can always take a step (i.e., it is never deadlocked) provided that steps satisfying the postcondition exist; include a check that if a step is taken, the postcondition holds.

Express the specification so it is clear what counts as an initial condition, what counts as a valid next-state relation, and which formulas are invariants or theorems to be verified. Require that the model checker or theorem prover confirm that the safety invariant holds for all reachable states.
