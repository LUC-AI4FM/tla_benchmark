Specify a formal model of a small collection-manipulation library that provides deterministic, total operations on finite sets and finite sequences, intended for use as trusted building blocks in higher-level specifications. The model should define the semantics of the following abstract operations and the precise correctness properties they must satisfy, without committing to a particular implementation strategy:

- Sum: compute the sum of numeric elements of a finite set, returning 0 for the empty set, and otherwise returning the algebraic sum of all elements.

- BigUnion: compute the union of a finite set of finite sets, returning the empty set for an empty collection and otherwise returning the union of all member sets.

- SelectSeq: given a finite sequence and a boolean predicate on elements, produce the subsequence of elements that satisfy the predicate while preserving original order; the result of applying the operation to an empty sequence must be the empty sequence.

- Quantify: given a finite set and a predicate, return the count (nonnegative integer) of elements in the set that satisfy the predicate; counting an empty set must yield zero.

- Range: given a finite sequence, return the set of elements that appear in the sequence; the empty sequence yields the empty set.

- Mode: given a finite sequence and a default value, return an element that occurs with maximal multiplicity in the sequence; for an empty sequence return the provided default. If multiple elements tie for maximal multiplicity, selecting any one of them is allowed.

- IsInjective: decide whether a finite function (mapping with finite domain) is injective.

For each operation, state domain and type constraints, totality on empty inputs where required, preservation of element ordering for SelectSeq, idempotence/associativity properties where appropriate (e.g., union and sum over disjoint partitions), and relationships between Range, Quantify, and Mode (e.g., Mode’s result must belong to Range unless sequence is empty, Quantify(range, ...) equals the count over the sequence). Specify these properties as invariants and as theorem-style correctness obligations to enable formal proof.
