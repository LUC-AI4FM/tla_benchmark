Specify a simple concurrent system consisting of two independent integer-valued state locations that are both initialized to zero. The model should express the initial condition that both locations hold zero and that their values are equal at start. The specification must allow the system to make no further state changes (i.e., the state can remain stable forever). Capture the state space, the initial predicate, and the allowed transitions (including the possibility of stuttering/no-change steps). Do not prescribe particular update sequences or implementation details.

Require the following correctness properties to be verified:
- The initial-state invariant that both locations are zero and equal.
- An invariant that the values remain equal whenever any transition preserves both values unchanged (so equality holds on all reachable states if the only allowed transitions are stuttering).
- Safety with respect to unintended divergence: there must be no reachable state that violates the equality invariant given the allowed transitions.
Also include temporal properties expressing that the initial condition holds at time 0 and that all subsequent states satisfy the unchanged-values behavior (i.e., there are no transitions that modify the values). The model should be simple, deterministic in its initial condition, and structured so invariants and temporal assertions can be mechanically checked.
