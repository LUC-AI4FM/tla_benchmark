Specify a formal model of a deterministic fold (reduce) operation that applies a single-element update function across the elements of a finite set to produce a final mapping. The system should accept: (1) a finite domain of keys, (2) an initial total mapping from each key to an integer value, and (3) an update operator that, given a current mapping and a key, returns a new mapping differing only at that key. The model should capture that the fold visits every key in the domain (in any order) and applies the update operator exactly once per key, producing a resulting mapping whose value for each key reflects the update operator's effect when applied to that key starting from the initial mapping and without interference from other keys.

Require the following correctness properties:
- Totality: the fold terminates with a mapping defined on the entire domain.
- Determinism: for a fixed initial mapping, domain, and update operator, the final mapping is independent of the order of keys processed.
- Locality: the update operator only changes the value at the specified key; it does not alter other keys.
- Coverage: every key in the domain is processed exactly once.
- Expected result: for each key, the final mapping assigns the value produced by applying the update operator to the initial mapping and that key.

Also assert basic type and domain invariants (finite domain, initial mapping defined on domain, update operator returns mappings defined on the same domain).
