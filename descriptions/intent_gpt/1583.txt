Specify a model of a simple concurrent program composed of three integer state variables that are initialized to zero. The program starts by making an exclusive nondeterministic choice between two independent two-step behaviors: one behavior performs two updates to the first variable, the other performs two updates to the second variable. After that choice completes, the program executes a conditional update of the third variable whose effect depends only on the current value of the first variable. The conditional update must be enabled only when the first variable has one of two specific values; in each case it increments the third variable by a value determined by which of the two values the first variable has. The model should allow either branch of the initial choice to occur, and it should allow the conditional update to observe the result of that initial choice.

Specify the following correctness properties to check:

- Safety: after the initial two-step behavior finishes, the sum of the first and second variables must equal a fixed constant (the sum produced by the two-step choices).
- Safety: when the conditional update executes, the new value of the third variable must equal the current value of the first variable plus a constant offset (expressing the intended relationship between the first and third variables after the conditional update).
- Liveness: the execution must eventually reach a terminal state in which no further state changes occur.

Do not encode internal control-flow labels; model only the abstract sequencing of the two-step behaviors, the conditional update, and termination. Allow nondeterminism in the initial choice and ensure fairness so that enabled steps are not permanently ignored.
