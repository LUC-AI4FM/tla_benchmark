Specify a formal model of basic set and sequence arithmetic and their interaction with empty collections, suitable for model checking. The model should represent abstract sets, subsets, unions, Cartesian-product–style mappings from sets to sets, finite integer ranges, and sequences, and must capture their standard semantics when some operands are empty. It should permit a trivial state that does not change, so the focus is on static assertions about set and sequence expressions rather than dynamic behavior.

Ensure the specification states and enforces the following key facts as invariants that always hold:
- The power set of the empty set is the singleton containing the empty set.
- The union of an empty family of sets is empty.
- Set comprehensions over an empty domain produce the empty set.
- Functions indexed over an empty domain correspond to an empty sequence or appropriate empty mapping representation.
- Existential quantification over an empty domain is false; universal quantification over an empty domain is true.
- The domain of an empty sequence (length zero) is the empty set; the integer interval with upper bound less than lower bound is empty.
- The empty sequence is a valid sequence over the empty set; the one-element sequence whose element is the empty set is not a sequence over the empty set.
- There is no nonempty subset of the empty set.
- Mappings from the empty set to a nonempty codomain produce a singleton representation corresponding to the empty tuple; mappings from a nonempty domain to the empty codomain produce the empty set of mappings.
- Unions that include empty sets behave as identities for the nonempty members.
Include these assertions as invariants to be checked by the model checker; the system should report any violation.
