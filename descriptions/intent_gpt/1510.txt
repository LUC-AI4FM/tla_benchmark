Specify a system that models a simple deterministic state transformer over a small fixed index set of five elements. The system has two components: a control value drawn initially from a finite set of five integers, and a vector of five integer counters initialized to zero. The only changes allowed across steps are updates to the vector: when the control value equals a particular distinguished value, a single entry of the vector (the entry whose index equals that distinguished value) is overwritten with a fixed constant; in all other cases the vector remains unchanged. The control value itself must remain invariant across all steps. The model should permit execution traces starting from any allowed initial control value and the zero vector, and then repeatedly applying the vector update rule.

Specify the set of behaviors and the state space, and formulate temporal properties that must hold for every behavior: (1) the control value never changes, (2) the vector entries are always integers and never spontaneously change except as specified, (3) if the control equals the distinguished value at any step, then immediately in the next state the corresponding vector entry has the fixed constant, and (4) if the control does not equal that value then all vector entries remain equal to their previous values. Also assert fairness-free execution: no additional liveness beyond the deterministic update is required.
