Specify a model of a simple packet-processing component that receives and records packets from a set of known senders. The system should maintain a single current packet and a Boolean indicating whether an error condition is present. In each step the component may accept a new packet from the packet space. A packet consists of a sender identifier drawn from a fixed finite set (including a special empty/unknown sender) and a small numeric payload (non‑negative integer). The component must decide whether the newly received packet satisfies a declared “precondition” that makes it well-formed (for example: the sender is not empty and the payload is strictly positive). If the packet satisfies the precondition, the component must leave the error flag false; if the packet fails the precondition, the component must set the error flag true.

Model the initial state where some packet is present and the error flag is false. Allow arbitrary nondeterministic arrival of packets at each step. Specify the invariant that whenever the error flag is true, the current packet must indeed violate the well‑formedness condition (i.e., either the sender is the empty/unknown value or the payload is non‑positive). Require the model to check that this invariant holds for all reachable states (safety). Also ensure the model is finite-state so that model checking is feasible. Do not prescribe an implementation strategy for packet handling beyond the abstract receive-and-update behavior.
