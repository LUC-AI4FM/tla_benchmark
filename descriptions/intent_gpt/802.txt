Specify a formal model of finite zero-indexed sequences (arrays indexed 0..n-1, with a distinct empty sequence) and basic operations on them. The model should treat a sequence’s length, valid index set, and membership in the set of all sequences over a given element set as first-class concepts. Provide precise definitions for:
- the empty zero-indexed sequence and the domain of valid indices for any sequence;
- the length function that returns a natural number and differentiates the empty sequence;
- conversion functions between zero-indexed sequences and the conventional one-indexed sequence representation (including the empty case), ensuring round-trip consistency.

Include ordering and transformation operators and state their intended behavior and correctness properties:
- a lexicographic total preorder on sequences of potentially different lengths that compares elementwise and treats shorter prefixes appropriately;
- a left-rotation operator that rotates a nonempty sequence by a given offset modulo its length;
- the function that returns the set of all distinct rotations of a sequence.

Specify key invariants and correctness properties the model must guarantee:
- length and index-set definitions are consistent with one another and preserved by conversion and rotation operations;
- conversions between index conventions are inverses when applied in both directions (modulo empty sequence);
- lexicographic comparison is total and deterministic for any two sequences drawn from the same element domain;
- rotation preserves multiset of elements and length, and the rotations set contains exactly one rotation per offset (no duplicates) for nonempty sequences.

Do not constrain implementation; describe only the abstract data types, operations, and the properties they must satisfy.
