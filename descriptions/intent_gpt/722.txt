Model a JSON serialization/deserialization library and its expected behavior for converting between a host-language value model and JSON text. The model should specify functions that produce JSON text from values and functions that parse JSON text back into equivalent values, supporting primitives (booleans, numbers, strings), ordered collections (arrays/tuples/sequences), mappings/objects (records/dictionaries with string keys), and nested combinations thereof. The serializer must deterministically produce canonical JSON representations for given values (including a defined ordering when serializing unordered collections such as sets and maps so outputs are predictable) and must distinguish between array and object encodings according to the value type. The deserializer must reconstruct values that semantically match the original model types and contents; round-trip correctness must hold for supported value classes (serialize then deserialize returns an equal value). Also specify a newline-delimited JSON (ndjson) mode in which a sequence of values is written as successive JSON records, and the corresponding reader that recovers the original sequence even with trailing whitespace or empty lines. Define error conditions: attempts to serialize unsupported top-level types for a given mode must raise well-defined errors with informative messages. Specify unit-test style properties asserting canonical encodings for representative inputs and that serialize/deserialize round trips and ndjson read/write preserve content and length.
