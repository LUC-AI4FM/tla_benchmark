Specify a formal model of a distributed, eventually-consistent grow-only counter replicated across a finite set of nodes. The system maintains at each node a local vector of nonnegative integers, one entry per node, that records how many increments that node has observed or performed. The model should capture two kinds of atomic events: a local increment at a node that increases that node’s own counter entry, and pairwise gossip between nodes where the receiving node merges the sender’s vector by taking the elementwise maximum. The model must enforce that all vectors are always maps from nodes to vectors of natural numbers and that local counters never decrease (monotonicity). 

Specify safety properties: no node’s recorded count for some origin can ever be less than that origin’s self-count at any node (local view respects origin’s self increments). Specify liveness and convergence properties: given fairness assumptions that gossip interactions occur sufficiently often (e.g., every gossip action is weakly fair and eventually only gossip actions occur while increments happen only finitely often), the system must converge: eventually all nodes’ vectors become equal (state convergence) and the common vector reflects the total number of increments performed by each node. Also require that increments are asynchronous and may interleave arbitrarily with gossip before the fairness period. The specification should leave the set of nodes parameterized and finite.
