Specify a simple boolean-state single-variable system that models a clock-like bit which can flip between true and false. The system should initialize the bit to a valid boolean value and allow an unended discrete transition relation that toggles the bit at each step. The model must enforce that the state variable always has boolean type (no other values allowed). Include an initial-state condition that constrains the starting value to be a boolean and a transition relation that deterministically assigns the next-state value to be the logical negation of the current-state value.

Require the following correctness properties to be verified by the specification:
- Type safety: the state must always be a boolean in all reachable states.
- Invariance of determinism: for any reachable state there is exactly one successor state defined by the transition relation.
- Liveness or progress: from any state, a next-state exists (the system never deadlocks).
- Safety of toggling: every transition must change the bit (the next-state boolean must be the negation of the current-state boolean).

Also include a separate constraint (assumption) that syntactically relates the current value and its negation (for example, an assertion that applies a Boolean negation twice returns the original value) so model checking can validate that such relationships hold, but do not hard-code implementation structure.
