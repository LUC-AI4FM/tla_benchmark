Specify a system that models a procedure for incrementally constructing a finite set of integers drawn from a bounded universe, while maintaining a separately stored integer that represents the set’s cardinality. The model should allow nondeterministic addition of distinct elements until the set may contain any subset of the allowed universe, and it should maintain the invariant that the stored integer exactly equals the number of elements currently in the set.

Define the abstract state as the current set and the numeric counter, and allow an operation that nondeterministically selects a value from a fixed finite range and adds it to the set only if it is not already present, incrementing the counter accordingly. The initial state should be the empty set with counter zero. The model must permit repeated additions until the set reaches arbitrary subsets of the universe, but must never allow removals or counter manipulation that diverges from actual size changes.

Specify and prove the following correctness properties:
- Safety: the stored counter always equals the cardinality of the set.
- Progress/liveness: from any reachable state that is not the full set, it is possible to add another element (i.e., there is an enabled add operation), ensuring the system can grow toward any larger subset.
- Boundedness: the counter stays within 0 and the size of the fixed universe, and the set remains a subset of that universe.

Do not prescribe a specific syntactic method for computing cardinality; instead state the required relation between the set and the counter and allow any implementation that preserves it.
