Specify a formal model of a statically checked record-typed environment that enforces access to declared fields only. The system should represent records with immutable, statically known sets of named fields and associated value types (for example, a record type that declares "name" as a string and "a" as an integer). It must allow creating values that conform to these record types and permit well-typed reads of existing fields. The model must also capture attempts to access non-declared fields and treat such attempts as type errors: the language semantics should forbid or signal an error when code attempts to read a field that is not part of the record’s declared type. Specify correctness properties that ensure (1) every legal field access returns a value of the declared field type, (2) illegal accesses are never observed as returning arbitrary values (they must be rejected or flagged), and (3) record values preserve their declared field sets and types across program execution (no implicit addition, removal, or type change of fields). Include invariants and safety properties to express these guarantees; do not presuppose a particular implementation strategy for enforcing types.
