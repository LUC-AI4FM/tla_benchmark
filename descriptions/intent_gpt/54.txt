Specify a system that constructs and maintains a finite sequence of integer values drawn from a fixed small set {1,2,3}. The model should allow the sequence to start empty and, at nondeterministic steps, be replaced atomically by any finite sequence whose elements are each from {1,2,3}. The specification must not prescribe how nondeterminism is resolved, only that any allowed replacement is possible.

Requirements:
- The state includes a finite sequence whose elements are integers.
- Initial state: the sequence is empty.
- Transition relation: at any step, the sequence may become any finite sequence (including empty) composed solely of values from the set {1,2,3}.
- The model must permit reasoning about all reachable sequences and exclude sequences containing values outside {1,2,3}.

Key correctness properties to guarantee:
- Safety: every reachable sequence contains only values from {1,2,3}.
- Liveness (optional): from any reachable state, it is always possible to eventually reach every finite sequence over {1,2,3} (i.e., the replacement relation is sufficiently nondeterministic to reach all such sequences).
- Invariance: the sequence length is always a nonnegative finite integer.

Do not tie the specification to a particular representation of sequences; allow abstract finite sequences and standard sequence operations for expressing properties.
