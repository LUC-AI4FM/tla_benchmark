Specify a formal model of a directed graph cycle recognizer and validator. The system should accept as inputs a finite nonempty set of nodes and a total function from nodes to nodes (representing a deterministic outgoing edge for every vertex). It must determine whether the function induces a single simple directed cycle that visits every node exactly once — i.e., whether the graph is a permutation consisting of exactly one cycle that covers the entire set.

The model should capture the domain and range of the function, treat edges as ordered pairs (node → function(node)), and permit any finite node set. The specification must include an operation that, given the node set and function, decides membership in the predicate “simple cycle covering all nodes.” The predicate must require: (1) every node has exactly one outgoing edge (given by the function); (2) the edges form a single closed directed cycle with no repeats before returning to the start; and (3) the cycle length equals the cardinality of the node set (so every node is visited).

State invariants and temporal properties should assert that the decision is consistent (evaluating the predicate yields a boolean determined solely by inputs), and that for any structure satisfying the predicate, following the function repeatedly from any node visits every node exactly once before returning to the start. Also specify a separable predicate that detects failure cases: existence of multiple disjoint cycles, fixed points, or nodes unreachable from others. The model should be independent of any particular representation of sequences and should allow finite exhaustive checking by a model checker.
