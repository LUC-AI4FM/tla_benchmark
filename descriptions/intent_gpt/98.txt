Specify a simple declarative check system that models two fixed collections of integers and a predicate that determines whether a pair of integers, one from each collection, is acceptable. The model should treat the two collections and the predicate as fixed inputs (constants) and must evaluate whether there exists at least one pair consisting of an element from the first collection and an element from the second collection that satisfies the predicate. The specification should clearly state the domain of each collection and the type/signature of the predicate, and it should expose a single boolean property that is true exactly when such a good pair exists. The model must be purely observational: it should not modify the collections or the predicate, not introduce additional state, and not depend on any ordering or multiplicity beyond set membership. The key correctness property to guarantee is that the boolean outcome coincides with the existential condition over the two sets and the predicate. Optionally include checks that the predicate is only ever applied to elements drawn from the respective collections and that empty collections or a universally false predicate yield a negative result.
