Model a small expression language with let-polymorphism that demonstrates how naïve polymorphic type inference can cause exponential blowup in the number of type instances. The model should include: an expression form for pairing and for let-bound polymorphic functions; a mechanism for instantiating polymorphic type schemes at call sites; and a procedure that performs Hindley–Milner style type inference (unification with generalization at let-bindings and instantiation at use sites). The system must be able to construct a family of nested polymorphic let-bindings that, when each is instantiated at its use sites, forces repeated duplication of type structure so the number of distinct type instances grows exponentially with the nesting depth.

Specify the abstract syntax and typing environment, the rules for generalization and instantiation, and the unification process required to produce type constraints and solve them. State the correctness properties: soundness (every inferred type is consistent with the typing rules and unifies with the expression structure), and termination for fixed nesting depth (the inference algorithm should complete for any finite nesting depth). Also state a liveness-related observation: the inference procedure may require time and space exponential in nesting depth, and the specification should make explicit that the number of instantiated type expressions grows exponentially under the described pattern of let-bindings. Do not prescribe a particular implementation strategy for inference.
