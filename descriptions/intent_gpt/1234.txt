Specify a simple discrete-time counter system that repeatedly increments a counter modulo a fixed positive integer N. The system should initialize the counter to zero and then, at every step, update the counter to (current + 1) mod N. Model time as an infinite sequence of steps; each step must perform exactly one increment. Allow N to be a parameter (a natural number greater than zero) so different modulus values can be explored.

Require that the model captures all reachable states and transitions, and permit reasoning about invariants and temporal properties. Key correctness properties to guarantee:

- Safety: the counter value is always an integer in the range 0..N-1.
- Determinism: from any state there is exactly one enabled transition (the increment).
- Liveness: the counter visits every value in 0..N-1 infinitely often (strong fairness of the cyclic increment).
- Periodicity: after N steps the counter returns to its starting value; equivalently, for any state value v, the value v recurs at least every N steps.

Also include the ability to check simple temporal assertions such as "eventually the counter equals k" for any k in 0..N-1 and to instantiate the model with concrete N for model checking.
