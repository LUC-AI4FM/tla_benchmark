Specify a model of the following weighing problem. A single indivisible object of known integer total weight N must be partitioned into P integer-weight pieces. Using only a two-pan balance scale and those pieces, it must be possible to measure out any integer target weight w with 1 ≤ w ≤ N by placing some subset of pieces on the same pan as the target and some (disjoint) subset on the opposite pan so the pans balance.

Model the space of possible partitions of the total weight into P nonnegative integer pieces (ordering or multiplicity may be accounted for so that distinct partitions differing only by permutation are not considered different solutions). For a given partition, define what it means to represent a target weight w using two disjoint subsets of pieces (one subset on the target side, one on the counterweight side) so that the target plus the weight of its side equals the weight of the opposite side.

State the main correctness property: a partition is a valid solution iff for every integer w in 1..N there exist two disjoint subsets of pieces that represent w. Specify a property or predicate that enumerates all valid partitions for given N and P. Include the ability to test concrete instances (e.g., N=40, P=4) and to output the set of all solutions and, for each solution, a witness (for each w) showing which pieces go on each side of the scale.
