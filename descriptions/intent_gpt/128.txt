Specify a model of a deterministic fold (reduce) operation that combines a collection of integer elements into a set by repeatedly applying a binary combining function. The system should accept two inputs: an initial accumulator value that is itself a set of integers, and a finite sequence (or multiset) of integer items to be processed. The combining function must take the current accumulator set and an integer item and return the accumulator augmented by that item (i.e., the union of the accumulator with the singleton containing the item). The model should capture the semantics of processing every item in the sequence exactly once, in some fixed order, producing a final accumulator set.

Require properties to verify:
- Safety: the final accumulator is a subset of the union of the initial accumulator and the set of all items from the input sequence, and contains the initial accumulator.
- Idempotence: processing duplicate items does not produce duplicate elements in the final set (i.e., duplicates in the input sequence do not change element multiplicity).
- Determinism with respect to order invariance: for this combining function, the final set is independent of the order of items in the input sequence (any permutation yields the same final set).
- Correctness on sample inputs: when starting from a given initial set and processing a concrete multiset of items, the model should reach the expected final set equal to the union of the initial set with the set of items.

Include simple invariants and a property asserting that the fold termination results in the expected set. Do not constrain the algorithm to a particular implementation; describe only these behaviors and properties to be checked.
