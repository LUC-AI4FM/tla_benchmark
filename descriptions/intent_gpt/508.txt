Specify a simple program module that models a single integer-valued state variable constrained to lie in the closed interval 1..10, with a one-step execution that performs an assertion check on that variable and then terminates. The model should capture initialization, the single assertion action, and termination, allowing stuttering after termination so the system can remain quiescent indefinitely. Requirements:

- The system must initialize the integer to some value in 1..10.
- It must execute exactly one observable action that checks the invariant that the square of the integer is at most 100; the check must be enforced as an assertion that cannot be violated during any execution of the action.
- After the assertion action executes successfully, the system must reach a terminal quiescent state and remain there (stuttering allowed).
- Specify the state space, the initial predicate, the transition relation that includes the assertion action and the termination/stuttering behavior, and the temporal specification that constrains executions (safety and liveness where applicable).
- State correctness properties to verify: (1) safety property—every state reached during execution satisfies the asserted bound on the square of the integer; (2) termination property—the system eventually reaches the terminal quiescent state.
