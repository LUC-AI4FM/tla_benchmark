Specify a formal model of a language front-end feature that supports user-defined binary infix operators and built-in infix operators, and that allows those operators to be passed as parameters to higher-order definitions. The model should capture the following goals and requirements:

- The language must permit defining new binary infix operators with arbitrary symbol names (including punctuation and Unicode-like glyphs), and these operators must behave as first-class function values that can be supplied as arguments to and returned from definitions.
- The model must allow existing built-in infix operators (logical, set, and temporal/connective operators) to remain available and distinguishable from user-defined operators, and must support disambiguation when a symbol could name either a built-in or a user-defined operator.
- Operator application must be unambiguous: parsing and semantic resolution must determine, for any occurrence of an infix operator symbol between two operands, whether it refers to a particular user-defined operator or a built-in one, and then apply the corresponding binary operation.
- The model must support defining generic templates or higher-order operators that take an infix operator as a parameter and apply it to given operands.
- Correctness properties: (1) Passing an operator as an argument and applying it yields the same result as directly applying the operator definition; (2) no two distinct operator definitions with the same symbol can coexist in the same lexical/semantic scope; (3) built-in operators preserve their standard semantics and cannot be overridden in a way that changes their meaning; (4) operator application is deterministic (parsing plus resolution yields a unique meaning for every expression).
- Model scope management: operator definitions follow scoping rules (global vs. local/module instantiation), and instantiation or inclusion produces the expected resolution behavior without name collisions.

Include invariants and temporal properties that express determinism of resolution and equivalence of higher-order application to direct application.
