Specify a system that nondeterministically selects pseudo-random subsets from a finite universe for use in model-checking and analysis, and state the correctness properties that selection must guarantee.

Model the process that, given a finite set U, two integer parameters k and n with 0 ≤ n ≤ |U| and k ≥ 0, produces a collection of subsets of U obtained by performing k independent sampling trials. Each trial should yield a subset of U such that each element of U is included in a sampled subset with marginal probability n/|U|. The system should allow duplicate sampled subsets; the output is the set of distinct sampled subsets (hence its cardinality may be ≤ k). Sampling must be reproducible when required: define both a deterministic mode in which sampling decisions for a given input state are fixed (so repeated executions with the same state produce the same output), and a nondeterministic (simulation) mode in which samples are independent of any particular state. Provide an operator that returns multiple independent executions (e.g., five) to observe variability in the output cardinality.

Specify invariants and properties to check:
- Every produced element is a subset of U.
- Each trial’s marginal inclusion probability for any element equals n/|U|.
- The number of distinct sampled subsets is ≤ k.
- Reproducibility: in deterministic mode, repeated evaluations with identical inputs yield identical outputs.
- In nondeterministic mode, independence from the input state holds.

Also specify auxiliary checks to empirically estimate the expected size of an individual sampled subset and the distribution of the number of distinct subsets over multiple runs.
