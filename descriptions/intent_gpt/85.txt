Specify a simple discrete state machine that models a single integer-valued variable cycling through a small finite set of states with nondeterministic initialization. The model should allow the variable to start in one of two permitted initial values and thereafter evolve according to a deterministic transition relation that maps each possible current value to a unique next value. The system must permit representing the initial nondeterminism explicitly and must describe the transition relation as a mapping (or case distinction) from current value to next value, including how values outside the intended set are treated if relevant. Requirements: (1) All reachable states must be integers from the intended small domain and the transition must be total on those values. (2) From any initial state, the system must always progress according to the specified mapping (no stuttering or skipped transitions). (3) The system must be safe: it must never reach values that violate the defined mapping or fall outside the expected set unless explicitly allowed. (4) Optionally assert a liveness property showing eventual reachability of every value in the cycle from the allowed initial states (or characterize which values are reachable). Specify the initial condition, the transition relation, and the correctness properties (safety and optional liveness) to verify.
