Specify a simple clocked variable system that models a single integer clock value evolving over discrete steps. The system should start with the clock initialized to zero and allow only behaviors that do not change the clock value (i.e., the clock remains constant at its initial value). The model should express initial state, step relation, and the allowed behaviors as a temporal specification.

Require that the specification captures the invariants: the clock is always an integer and never becomes negative; the clock value is always equal to its initial value throughout any execution. Include a property that all reachable states satisfy the invariant that the clock equals the initial value (safety). Also include an explicit liveness requirement that any execution is infinite (if desired) while still preserving the clock’s immutability.

Provide the ability to check that no transition can modify the clock and that any auxiliary properties derived from the clock value (for example, predicates depending on whether it is zero) remain stable. Do not constrain how the model is encoded, but ensure the temporal semantics and invariants are clearly expressible for model checking.
