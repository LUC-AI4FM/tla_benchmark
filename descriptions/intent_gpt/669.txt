Model a distributed stream-processing pipeline that supports concurrent accumulation (folding) of events over sliding and tumbling windows. The system ingests an unbounded sequence of input events from multiple producers, partitions events by key, and maintains per-key state that is updated by deterministic fold functions. Specify how windows are defined (time-based and count-based), how events are assigned to windows, and how overlapping windows contribute to state. The model must allow out-of-order and duplicate event delivery and must include mechanisms for event deduplication, watermarking or lateness handling, and eventual emission of windowed fold results.

Require that for any finite input trace the outputs equal those produced by a sequential, deterministic fold per key and per window after accounting for allowed lateness — i.e., convergence: once all events for a window up to the allowed lateness have arrived, the emitted result equals the result of folding all unique events for that key in that window in arrival-agnostic order. Require safety properties: per-window determinism (identical final result regardless of concurrency, duplicates, or reordering) and no loss of unique events. Require liveness: every window eventually emits a final result when no more eligible events will arrive. Include invariants about monotonic progress of watermarks and bounded state growth (garbage collection of expired windows).
