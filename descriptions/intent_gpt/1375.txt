Specify a formal model of a system that checks and reasons about assertions over finite integer sets that may be defined in multiple places and compared for equality. The model should allow multiple set expressions whose elements are concrete integers; these expressions may be syntactically different but intended to denote the same abstract set. The system must support declaring such sets, asserting equality between them, and verifying whether the equality holds given the sets' contents. The model must capture the possibility of contradictory or surprising equalities (for example, where two written sets contain the same multiset of integer elements but are written in different orders or with different apparent element expressions). It must guarantee clear semantics for set equality (extensional equality) and produce a way to detect when an asserted equality is valid or invalid. The specification should include a notion of assumptions or axioms that can be introduced by the user and a mechanism to check consistency of these assumptions with the declared sets. Key correctness properties: (1) set equality must be decided by membership extensionality, (2) the model must report any inconsistency introduced by an equality assumption that contradicts actual set contents, and (3) any proof obligations derived from assumptions about set equality should be derivable only when they follow logically from the sets' definitions.
