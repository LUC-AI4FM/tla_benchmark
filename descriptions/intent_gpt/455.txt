Model a simple cyclic hour counter that repeatedly cycles through the integers 1 to 12, advancing by one at each step and wrapping from 12 back to 1. The model should treat the counter as a single scalar state that always contains an integer in the inclusive range 1..12. At every atomic transition the counter must either be incremented by one when its current value is 1..11, or be set to 1 when its current value is 12. Specify an initial condition requiring the counter to start inside the range 1..12. Specify the allowed transitions independently of any particular program encoding so that any behavior of the model is an infinite sequence of these transitions.

State the liveness and safety obligations to be verified: safety — show that every reachable state satisfies the invariant that the counter value lies in 1..12; liveness — if desired, express that the system makes forever-progressing steps so that the counter continues to advance (i.e., there is no stuttering forever). The specification should separate initial conditions and transition relation cleanly and enable verification that the invariant holds globally (always) for all reachable states. Provide the model in a way suitable for formal verification of the invariant and optional liveness property.
