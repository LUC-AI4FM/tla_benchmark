Model a system that reasons about computing the factorial function as a pure mathematical recurrence and how that function can be used to initialize and update a single integer state variable. The specification should treat the factorial function as a total integer-valued function defined by the usual recurrence: factorial(n) = 1 for n ≤ 1, and factorial(n) = n * factorial(n-1) for n > 1. The system must allow the state variable to be initialized to the factorial of a specific constant input and later updated nondeterministically to the factorial of another fixed constant input. The model must capture that the factorial is well-defined for the integer arguments used in initialization and update, and must record the numeric values assigned to the state by those calls.

State the required safety property that the state variable always remains at least 1 in every reachable state. Also state liveness expectations: show that both the initialization and any permitted update are reachable (i.e., there exists an execution where the initial assignment occurs and an execution where the update is taken). The specification should not commit to a particular algorithm for computing factorial (no imperative loop), but should specify the functional recurrence and the allowed state transitions that use it. Include necessary domain assumptions about the constant arguments so the factorial results are finite integers.
