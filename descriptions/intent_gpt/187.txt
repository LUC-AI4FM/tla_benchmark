Specify a TLA+ model of a polymorphic function-instantiation facility and its use with finite functions. Model a system that defines a polymorphic operator that, given any finite function mapping values of some type to integers, returns the domain of that function. The specification should allow instantiating that polymorphic operator at different concrete types (for example, at a string type and at an integer type) and applying it to distinct finite functions whose domains have different element types.

The model must assert and check that, for each instantiation, the operator returns the correct domain set for the supplied function, and that instantiations at different types do not interfere with one another. It must express invariants that compare the domain results for the different concrete instantiations and prove they equal the expected sets. The specification should permit these checks in different orders (e.g., asserting one result then the other, or binding results to local names before asserting) to ensure instantiation and scoping behave uniformly.

Key properties:
- Correctness of domain extraction for each concrete instantiation.
- Type-separation: results from differently-instantiated uses correspond to domains with elements of the appropriate concrete types and do not conflate values across instantiations.
- Invariance: the expected equalities about the returned domain sets hold in all reachable states.
