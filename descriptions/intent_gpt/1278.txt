Specify a simple state machine that maintains a single numeric state representing a digit and enforces a safety invariant about allowable values and parity at all times. The model should start with the state set to zero and thereafter allow only transitions that result in the state being an integer between 0 and 9 inclusive and always even. The specification must forbid any state outside 0..9 or any odd value. The model should express both the initial condition and the allowed step relation so that temporal reasoning can confirm that every reachable state satisfies the invariants forever. Key correctness properties to guarantee: (1) Initial condition: the state equals 0. (2) Safety: at every point in every execution the state is an integer in the range 0 through 9 and is even. (3) Stuttering/step closure: if steps do not change the state, the safety property remains preserved. Do not include implementation details such as concrete transition rules beyond the requirement that all successors satisfy the safety predicate. The specification should be suitable for model checking and proving that no execution can reach an invalid value.
