Specify a distributed algorithm that constructs a spanning tree rooted at a designated root process in a fixed undirected network. The model should treat processes as asynchronous nodes that can send messages only along existing network links and that may initially have no parent. The system must allow the root to originate tree-establishing messages and allow any non-root node to adopt a neighbor as its parent when it receives an appropriate message and has not yet chosen a parent. Once a node adopts a parent, it must record that parent permanently and may thereafter participate in forwarding or sending messages. Message delivery is unreliable in timing but must not create new links; messages are individual link-directed events queued in the network state until sent or consumed. Model the possibility of repeated message transmissions but ensure nodes do not repeatedly re-adopt or change parents after choosing one.

Required correctness properties:
- Safety: every non-root node’s parent, if set, must be a neighbor in the network and must not be changed later (parents are valid and stable).
- Liveness/termination: eventually every node either is the root or has selected a valid neighbor as parent (the algorithm completes forming a rooted spanning forest that in this connected case is a spanning tree).
- Type and mailbox invariants: messages are always pairs of processes over existing links and node state fields respect their declared domains.
- Progress fairness: if an enabled send or parent-adoption step remains continuously enabled for some process, it must eventually occur (so message sending or parent adoption cannot be permanently starved).

Describe the system abstractly (nodes, neighbor relation, messages, parent-choice and send-adopt transitions) and specify the above invariants and liveness goals without prescribing a particular programming-language structure.
