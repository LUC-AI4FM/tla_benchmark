Specify a simple state machine that models a system with a single integer-valued state and an invariant that the state remains zero. The system should start in an initial state where the integer equals zero, and it should include a persistent global assumption or environmental fact that is always true and must hold in every reachable state (this assumption is externally known and does not change the state). The transition relation of the system should allow no change to the integer (i.e., the value must remain the same across every step). 

The model must guarantee two key correctness properties: safety (the integer is always equal to zero in every reachable state) and consistency of the persistent assumption (the assumed fact holds in the initial state and is preserved by every transition). The specification should also allow checking that the assumption is indeed used by the model checker when validating the invariant, and that the invariant cannot be violated because transitions do not modify the state. Do not prescribe an internal encoding or algorithm; focus on the abstract behavior, initial condition, persistent assumption, transition relation (no state change), and the two correctness properties to be proved.
