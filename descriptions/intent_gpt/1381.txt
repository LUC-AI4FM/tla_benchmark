Model a simple discrete-state counter system that evolves in steps, with the following behavior and correctness requirements.

The system maintains a single integer-valued state representing a counter. Initially the counter starts at a specified nonnegative value (allow the initial value to be configurable). On each step, the system nondeterministically chooses one of two kinds of transitions:
- A constrained unary transformation that negates the counter (maps the counter to its arithmetic negation), but this transition is only permitted when the current counter value satisfies a global constraint restricting allowable states.
- An unbounded increment transition that increases the counter by one.

Specify the allowed state space and the transition relation so the negation transition may produce a negative result, while the increment transition always yields a strictly larger integer. Enforce an invariant requiring the counter remain nonnegative across all reachable states (this invariant may or may not hold; the model should allow checking it).

Include the ability to constrain the model checker to consider only steps starting from nonnegative states (a constraint on reachable states), and allow an alternative configuration with a different initial value for testing. Provide properties to be checked: the nonnegativity invariant, and an assertion that a particular counterexample trace exists (for testing the model checker) that demonstrates a sequence of states showing the generator of a counterexample pattern (for example, a trace where the counter goes from a nonnegative value to a larger one and then to a negative value). Do not prescribe implementation details; focus on states, transitions, initial conditions, constraints, and the correctness properties to verify.
