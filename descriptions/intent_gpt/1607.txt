Specify a concurrent system of processes that cooperatively compute factorials by invoking a shared recursive procedure. The system contains a fixed set of processes (some designated “main” processes and at least one “minor” process). Each process can call the common factorial procedure with an argument n (a nonnegative integer) and the procedure computes n! by repeated multiplication, returning when the argument reaches 0. Calls are local to each process (each process has its own call stack and local frame for the procedure), but they share a common array of results indexed by process identifiers; when the procedure multiplies, it updates that process’s entry in the shared results array. Processes may call the procedure concurrently and interleave arbitrarily; recursive calls must be supported (i.e., the procedure may call itself until reaching 0), using the per-process stack to restore local state on return.

Model the system at the level of atomic steps for invoking the procedure, performing a multiplication step, decrementing the local argument, returning from the procedure, and asserting postconditions. Specify initial conditions (results initialized to 1; each process in an initial control point), the allowed transitions, and fairness assumptions preventing starvation of enabled actions.

State the correctness properties to prove:
- Safety: for every process p, whenever that process completes a high-level call Fact(n) and reaches its post-call assertion, the shared result[p] equals n!; and the result array always contains only natural numbers.
- Liveness/Termination: every started call eventually returns (i.e., every process that begins a call reaches its post-call completion state), and eventually all processes reach quiescence (done).
Also require that recursive calls properly restore local state on return and that concurrent executions do not cause interference between processes’ results.
