Specify a model of parameterized module instantiation and consistency checking for a simple symbol binding mechanism used by a module system. The model should represent two distinct instances of the same module, each created with different values supplied for a single parameter. It must express how the module instances independently resolve a particular exported symbol in terms of their own parameter values, and it must allow the system to assert and verify relationships between the two instances’ resolved values. The specification should require that instantiation produces distinct namespaces so that each instance’s exported symbol evaluates according to the instance’s supplied parameter, not to a shared global. It must permit forming a tuple or pair of the two instances’ exported values and check that the tuple equals the pair of the two supplied parameter values. The model must also support asserting an identity between a local unqualified symbol and the parameter within the current scope to enable cross-checking. Key correctness properties: (1) each instance’s exported symbol equals the parameter value supplied at instantiation time; (2) instance namespaces do not interfere with each other; (3) composed assertions about multiple instances hold exactly when their underlying parameter values match the asserted tuple. Provide the system and invariants necessary to mechanically verify these properties.
