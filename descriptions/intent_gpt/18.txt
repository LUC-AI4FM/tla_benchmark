Model a distributed termination-detection protocol for a fixed-size unidirectional ring of asynchronous processes (nodes) running independently and communicating by message passing. The model must represent node local state (active/passive and a local color used by the algorithm), asynchronous message sends and receives (messages may be in transit), and a rotating token that is passed around the ring to detect global quiescence. The token carries at least a counter component and a color; nodes can affect the token when they hold it, and nodes can send messages while active which create in-flight messages and adjust local send/receive counters. The model should permit nondeterministic scheduling: any enabled node action or environment message action can occur at any time.

Specify the correctness properties:
- Safety: whenever the token returns to the designated initiator position in the “white” state and the token’s count together with the initiator’s local count indicate no in-flight messages to the left, then all nodes must be passive and there must be no messages in transit (i.e., the token’s white report implies global termination).
- Liveness: if the system truly reaches quiescence (no active nodes and no messages in transit), then eventually the protocol will detect termination (the initiator will receive a white token that correctly reports no outstanding messages).
- Maintain an inductive invariant sufficient to prove safety: conservation of total outstanding message accounting between local counters, token counter, and pending messages; and conditions relating token position, token counter, node colors, and passivity that ensure the token’s white report is sound.

Include a state-space bound parameter to keep counters and pending-message counts finite for model checking. Do not commit to a particular implementation strategy for token updates or node actions beyond the requirements above.
