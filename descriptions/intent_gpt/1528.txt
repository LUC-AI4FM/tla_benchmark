Specify a distributed algorithm that builds a breadth‑first spanning forest rooted at a designated root node in an undirected, static graph whose edge set is initially unknown (but fixed for each run). The model should treat the graph as any possible simple undirected graph over a fixed finite set of nodes and must allow exploration of all such graphs. Each node maintains a distance estimate from the root and a pointer to a parent (or itself if it has no parent). Initially, every node should consider itself its own parent and have a distance of infinity except the root, which has distance zero. The algorithm must allow nodes to adopt a neighbor as parent only when that neighbor’s distance is strictly smaller and to decrease their distance to one plus the chosen parent’s distance. The specification must require eventual quiescence: if no node can make a strictly improving parent/distance choice then every node’s state must satisfy a global postcondition characterizing a valid breadth‑first forest: nodes unreachable from the root retain infinite distance and self‑parenting; reachable nodes have finite distances equal to one plus their parent’s distance, and parents are neighbors. Guarantee safety (the postcondition holds whenever no step is enabled) and liveness (the system can reach such a postcondition). The model should treat the graph as an arbitrary input and not encode the algorithm’s scheduling or message delays beyond atomic local updates.
