Specify a simple system with a single boolean state that never changes after initialization. The model should represent an environment where the boolean is true initially and remains constant for all time (no transitions modify it). Include an explicit initial condition that the boolean is true and a stuttering-only behavior thereafter.

State the key correctness properties to be checked:
- Safety: the boolean is always true in every reachable state (invariant).
- Liveness/triviality: no action ever falsifies the boolean; the only allowed transitions are stuttering steps that preserve the state.
- Consistency: the initial condition is satisfiable and the invariant follows from it (i.e., the system has at least one valid initial state and all executions satisfy the invariant).

Also require that the specification be written to allow local helper definitions (pure logical/local functions and finite indexed definitions) that can be used to express the invariant but do not introduce additional mutable state or implicit recursion over time. The model should be minimal, avoid extraneous arithmetic constraints, and be amenable to automated model checking of the invariant and reachability of initial states.
