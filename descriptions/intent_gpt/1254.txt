Specify a formal model of finite sequences (ordered finite lists) over an arbitrary element domain, and provide a small collection of standard sequence operations together with correctness properties. The model should treat a sequence of length n as an ordered collection indexed from 1 to n and allow the empty sequence. Provide operations to: form the set of all sequences over a given set; compute the length of a sequence; concatenate two sequences; append an element to a sequence; take the head (first element) and the tail (sequence of remaining elements) of a non-empty sequence; extract a contiguous subsequence given start and end positions; and filter a sequence by a predicate to produce a subsequence preserving original order. Ensure each operator is total or else precisely specify its domain (for example, head/tail only defined for non-empty sequences). Specify semantics so that concatenation and append satisfy expected algebraic laws (associativity of concatenation, identity element being the empty sequence, append equivalence to singleton concatenation). Specify indexing conventions (1-based) and require that length, subsequence, and filter behave predictably with respect to indices (e.g., subsequence lengths, composition with concatenation, and preservation of element order in filtering). Include invariants and properties to check: lengths after operations, element-at-position preservation, and that filtering never introduces new elements and preserves original relative order.
