Specify a model of distributed termination detection for N processes arranged in a logical ring with synchronous message delivery and local computation. The model should capture process states (active or inactive), local actions that can deactivate a process or activate another process, and a global boolean that indicates whether termination has been detected. The system must allow arbitrary initial active/inactive assignments, and termination detection may occur only when every process is inactive. Processes may locally decide to stop being active or may send an activation to any other process; such activations can reawaken inactive processes. Termination detection is an explicit global event that can be raised only when the system is truly quiescent (all processes inactive). The specification must require safety: once termination is declared, the system state must indeed be quiescent (no active processes). It must require quiescence persistence: once the system reaches the all-inactive state it remains all-inactive thereafter. It must require liveness: whenever the system is quiescent, termination detection will eventually be raised (fairness that ensures detection cannot be perpetually deferred). Express the model for arbitrary positive N, and state the allowed transitions abstractly (local termination, activation of another process, and the detection event) without prescribing a particular detection algorithm.
