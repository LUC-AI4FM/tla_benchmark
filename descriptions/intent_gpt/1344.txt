Specify a model of two identical concurrent components that are instantiated twice and interact only through an externally observable clock equality constraint. The model should capture the lifecycle of each component from initialization onward, allow either component to be initialized first or simultaneously, and respect that the two clock values are always equal at initial time and remain unchanged thereafter. The system must nondeterministically choose any valid initialization ordering (first A then B, first B then A, or both at once) and then freeze the clocks so no further clock changes occur. Describe each component abstractly as a small state machine with its own local state variables and an Init condition, but do not prescribe an execution ordering internal to the components beyond the initialization choices.

Require the specification to preserve the local variables of both components after initialization (no further transitions that modify them or the clocks), and to make explicit the invariant that the two clocks are equal at the moment of initialization and forever after. The correctness properties to verify are: (1) every reachable state satisfies that the clocks are equal; (2) both components are initialized; and (3) no action changes the clock values or component local variables after initialization. Include liveness assertions that initialization completes in all fair executions for each allowed ordering.
