Specify a concurrent system of identical nodes that each maintain a local set-valued resource mapping and can update their own mapping by adding elements. The model should represent a network of three nodes and two independent but similarly-structured mappings of nodes to sets. Initially all node sets are empty. The system must allow only updates that add a single element to the set held by one specific node (the same targeted node in both mappings) and must perform those updates atomically with respect to each mapping: each step may add an element to the target node’s set in either or both mappings. The specification must capture all possible interleavings of such update steps.

Require the following correctness properties be formally specified and checked:
- Initialization: both mappings assign the empty set to every node.
- Safety (invariant): for a distinguished non-updated node, its sets in the two mappings remain equal at all times.
- Monotonicity: sets only grow (no removals) and additions are single-element insertions.
- Consistency between mappings for the updated node is not required, but the system must permit simultaneous updates to both mappings and also individual updates to either mapping.

Also express liveness goals: every enabled single-element addition to a mapping should eventually be allowed (fairness of update actions). The description should avoid prescribing an implementation strategy or sequencing beyond these functional requirements.
