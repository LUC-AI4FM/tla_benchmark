Model a parallel reachability-checking algorithm for a fixed finite set of processes that cooperatively explore a directed graph of states. The system should capture processes that repeatedly attempt to discover and mark a designated root set, propagate reachability information, and eventually terminate while preserving safety. Specify the initial conditions (no marks, all processes in starting control locations) and the allowed atomic steps for each process: steps that inspect or update shared reachability information, steps that mark a node as reached and possibly change a local program counter, and steps that complete and stop participating. The model must allow nonblocking interleaving of process steps and asynchronous choices of which process executes next.

Require these correctness properties:
- A global safety invariant: every update to the shared reachability data must maintain a representation invariant (e.g., consistency between per-process view and the global marked set), and no process may introduce an inconsistent marking.
- Termination safety: once all processes have reached their terminating control location, the shared reachability data is stable (unchanged thereafter).
- Refinement correctness: the parallel algorithm must implement an abstract sequential safety specification under a refinement mapping that relates concrete process-local and shared variables to abstract state; formally, every behavior of the parallel system maps to a behavior satisfying the abstract Init and Next.
- Type invariants: variables always remain within their declared finite domains (process set, node set, control labels).

Do not prescribe a particular implementation structure; instead, define states, allowed atomic transitions, and the invariants and refinement relation the model must guarantee.
