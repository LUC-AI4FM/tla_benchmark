Specify a model of a simple agent that inspects boxes to find an object and may change its orientation while doing so. The system has a fixed finite number of boxes arranged linearly and one agent that occupies a box index at any time. The agent can look into the current box to determine whether the target object is present, and it maintains an observable notion of which box it last inspected. The agent has a discrete orientation (e.g., "left" or "right") and may change this orientation as part of its behavior. The model should allow nondeterministic choices for moves, inspections, and orientation changes so different search strategies can be explored.

Specify initial conditions: the agent starts at some box, the last-observed box can be unspecified or set to a sentinel, and the initial orientation is one of the allowed values. Specify actions that move the agent between adjacent boxes within bounds, that inspect the current box and record it as the last observed, and that flip or set the orientation.

Formalize safety and liveness properties: safety — the recorded last-observed box must always be a valid box index or the sentinel and must equal the agent’s position immediately after an inspection; orientation must always be one of the allowed values and moves must stay within bounds. Liveness — if the target object is in some box, the specification should allow that the agent will eventually inspect that box (fairness constraints may be required). Also ensure absence of deadlock: the system should always have at least one enabled action.
