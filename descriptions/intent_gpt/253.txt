Specify a TLA+ model of a static finite-set cardinality computation that demonstrates and verifies an alternative way to compute the number of elements in a finite set by folding (reducing) over the set. The model should describe an environment that nondeterministically picks a finite subset of a known finite universe as the set to be measured, and then defines a separate, fold-based procedure that computes the set's cardinality by accumulating a count as the fold visits every element. The system must not modify the set after it is chosen.

The specification must require the fold-based count to always equal the standard library cardinality function on the chosen set. It must assert that for any possible initial subset of the given universe the fold-based computation yields the same integer value as the canonical cardinality, and it must state this as an invariant of the system. The universe should be finite and reasonably small (so model checking is feasible). The model should allow arbitrary nondeterministic choice of the initial subset and should treat the fold as abstractly traversing every element exactly once for finite sets. The property to verify is equivalence of the fold result and the canonical cardinality for all reachable states.
