Specify a formal model of a bounded buffer system with multiple independent producers and consumers that coordinate without shared locks. The system should allow any producer to append an item to the buffer when space is available and any consumer to remove an item when the buffer is nonempty. When the buffer is full, a producer that attempts to add an item must wait (become blocked) until space is freed; when the buffer is empty, a consumer that attempts to remove an item must wait until an item is produced. Waiting threads must be recorded so that when space or items become available one waiting thread may be resumed. The buffer capacity is a fixed positive integer and must never be exceeded; the buffer size must remain between 0 and capacity at all times. Producers and consumers are distinct nonempty sets of participants. The model must permit any enabled producer or consumer to act (nondeterministic scheduling), and when a waiting thread is resumed, it should be chosen nondeterministically from the set of waiting threads of the appropriate kind. Correctness properties to guarantee: safety (buffer length invariants and that no thread is both marked waiting in both roles), liveness-style progress constraints preventing global deadlock where every producer is waiting because the buffer is full and every consumer is waiting because the buffer is empty simultaneously, and that a resumed waiting thread can eventually perform its intended operation provided the buffer state allows it. The specification should abstract away implementation details of scheduling or exact wake-up order, only requiring that wake-ups are fair and nondeterministic.
