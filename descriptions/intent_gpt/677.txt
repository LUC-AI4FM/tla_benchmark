Specify a formal model of a finite multiset (bag) abstraction and common operations on it. The model should treat a bag as a collection where elements can appear multiple times with a natural-number multiplicity, and must support creating, inspecting, and transforming bags in ways that preserve multiset semantics.

Required operations and behaviors:
- Add a single occurrence of an element to a bag, increasing its multiplicity by one (or inserting it with multiplicity one if absent).
- Remove a single occurrence of an element, decreasing multiplicity by one and removing the element entirely when multiplicity reaches zero; if the element is absent, the bag remains unchanged.
- Remove all occurrences of an element, yielding a bag that contains no copies of that element.
- Aggregate or fold over the elements of a bag with a binary operator and a base value, where each element is processed as many times as its multiplicity. The fold must be parameterizable by:
  - a mapping from bag elements to values to be aggregated,
  - a binary associative operator (or a general operator with a specified evaluation order), and
  - an ordering/choice policy that determines the sequence in which distinct elements’ replicas are processed.
- Compute common numeric aggregates: sum and product of elements, defined via the fold.

Key correctness properties to assert:
- Preservation of multiplicities: add/remove operations update multiplicities precisely as specified; removal never produces negative multiplicities; removing nonexistent elements is a no-op.
- Structural invariants: the bag’s domain reflects exactly those elements with positive multiplicity.
- Fold soundness: folding with a mapping that yields identical values for equal elements should be consistent with unfolding the bag into a sequence that lists each element multiplicity times and folding that sequence using the operator and base.
- Aggregation identities: sum over a bag with no elements yields the additive identity; product over an empty bag yields the multiplicative identity.
- Deterministic outcomes when folding with a commutative and associative operator regardless of the chosen processing order; if the operator is not commutative/associative, the model should reflect dependence on the ordering policy.

Model only the abstract multiset semantics and correctness properties; do not prescribe a particular concrete representation or implementation algorithm.
