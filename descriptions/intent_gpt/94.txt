Specify a simple configuration preprocessing system that resolves symbolic configuration constants and supports override bindings before runtime. The model should represent a set of named configuration parameters, each with a default integer value, and an independent set of override bindings that can redirect a parameter name to the value of another parameter. The system must allow applying overrides transitively (an override can point to a parameter that itself has an override) and must detect and handle cycles in the override graph without causing undefined behavior.

Requirements:
- The model must represent the initial defaults for all configuration parameters and an initial set of override mappings that may form chains or cycles.
- Provide an operation that computes the resolved integer value for any parameter by following overrides until reaching a parameter with no override or a fixed value.
- If a cycle is encountered while resolving a parameter, the operation must report the cycle and avoid nontermination; resolution for that parameter must be defined to fail or return a distinguished error rather than loop forever.
- The model must allow updating override bindings and then re-evaluating resolutions, preserving the detection semantics for cycles.
- Correctness properties: every parameter resolution either yields the intended integer default value (if overrides terminate) or yields an explicit cycle/error indication; no resolution action can divergence or modify unrelated parameters.
