Specify a formal model of a system that analyzes and simplifies sequences of tokens representing linear expressions with parentheses. The model should accept any finite sequence of tokens where each token is either a left parenthesis, a right parenthesis, or a non-parenthesis symbol, and it must treat tokens as distinguishable by identity when necessary. The system must be able to determine whether a sequence of parentheses is well-formed (balanced and never dropping below zero nesting at any prefix). It must identify and remove parentheses that are redundant: parentheses whose removal does not change the well-formedness or the grouping semantics of the expression. The model should preserve the ordering and identity of non-parenthesis tokens and must not alter semantic grouping created by necessary parentheses.

Key correctness properties to guarantee:
- Soundness: Removing a parenthesis is allowed only when the resulting sequence remains well-formed and is semantically equivalent with respect to grouping (no change to the nesting relationship among non-parenthesis tokens).
- Completeness of detection: Every parenthesis that can be removed without violating soundness should be identified as removable by the system.
- Idempotence: Repeated application of the removal procedure reaches a fixed point where no further removable parentheses exist.
- Termination: The removal procedure must terminate in a finite number of steps for any finite input.
- Preservation of token identities: Non-parenthesis tokens (and parenthesis tokens that remain) retain their identities; the model must be able to relate positions in the original and simplified sequences.

Specify operations to query well-formedness, compute candidate removable parentheses, perform removals, and reason about equivalence of sequences with respect to nesting structure.
