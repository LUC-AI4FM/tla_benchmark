Specify a TLA+ model of a small polymorphic folding operator over finite sets that computes a mapping from set elements to integer values. The model should describe an operator that, given any finite set of elements of some abstract type and a binary combining operation, produces a function (map) whose domain is the set of elements and whose values are integers. The operator must accept: (1) a commutative associative binary transformer that takes a current function and a new element and yields an updated function, (2) an initial function value, and (3) the input set to fold over. The fold should deterministically process every element of the input set exactly once (order of processing may be unspecified), and the final result must be independent of processing order when the transformer exhibits the necessary algebraic properties.

Specify invariants stating that:
- For any input set, the fold result is a total function whose domain equals the input set.
- All function values are integers.
- When folding over the empty set, the result equals the provided initial function.
- If the transformer ignores element identity and always returns a constant value, folding any set yields that constant mapped over the set.

State safety properties (domain preservation, type correctness) and a liveness/termination claim: folding completes for every finite input set. Include a specification of the expected behavior on a singleton set as a minimal test.
