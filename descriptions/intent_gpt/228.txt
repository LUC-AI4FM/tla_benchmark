Specify a finite-state control system with a small integer data component and a control-state label that evolves nondeterministically through a few named stages. The system must initialize in a designated start control state with specific initial integer values. It must allow a transition that moves from the initial control state into one of two main behaviors: a deterministic simple action that sets the control state to a named value and updates integers to fixed constants, and a more complex guarded action that nondeterministically chooses an integer from a small finite set, performs simple set- and cardinality-based checks, and under those checks concurrently sets one integer to a fixed value and leaves another integer unchanged while also implying a transition predicate equivalent to invoking the earlier “start” transition. The system must permit the interleaving of these transitions as long as their guards hold.

Require an invariant stating that the control-state label must never equal a particular forbidden label in any reachable state. Also require that all transitions preserve integer types and stay within small prescribed finite domains. Specify liveness only as fairness of enabled transitions (weak fairness optional). Do not prescribe implementation structure; instead describe initial conditions, allowed transitions (their guards and effects), and the safety property that the forbidden control label is unreachable.
