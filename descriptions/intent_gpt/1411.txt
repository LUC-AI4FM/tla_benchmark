Specify a simple infinite-state counter system that starts at 1 and repeatedly increments by 1 on every step. The model should capture executions that begin in an initial state with the counter equal to 1 and allow a single deterministic transition that increases the counter by one, producing an unbounded sequence of natural-number values.

Require that the specification records safe-state predicates and supports checking an invariant that asserts the counter is always strictly less than 2. The model must make it possible to exhibit counterexamples when the invariant is violated: in particular, show the finite trace starting from the initial state with value 1 and taking a single increment to reach value 2. The system must therefore allow a next-state from 1 to 2 so that model checking can produce a concrete two-state trace illustrating the invariant breach.

Also require a formal postcondition describing the expected counterexample: the trace should consist of the initial state with counter=1 followed by the next state with counter=2, and the counterexample information should identify the transition taken. The specification should be suitable for model checking and for producing that explicit counterexample when the invariant fails.
