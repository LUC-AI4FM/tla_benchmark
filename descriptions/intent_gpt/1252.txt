Specify a real-time reactive system that combines asynchronous discrete actions with a monotonically increasing real-valued clock. The model should describe a system in which (a) the environment may advance a global continuous clock at any time by any positive real amount, and (b) the system executes atomic discrete transitions that may happen instantaneously with respect to the clock. The specification must allow an alternating interleaving of time progress and discrete actions, but must enforce that time only increases during time-progress steps and that discrete actions do not change the clock.

Require that for each distinguished action A the system can be equipped with a nonnegative real timer that measures time since A last executed (or since initialization). For every such timer, the following timing constraints must hold: (1) a hard upper bound E on the timer is never violated (the timer is always ≤ E), (2) whenever action A executes the timer reads 0 at that moment, and (3) if A has not executed for some duration then the timer's value is at least a specified lower bound D whenever A becomes enabled and then executes. The specification should permit the timer to increase with clock progress and to reset to zero exactly when A executes.

State safety and liveness properties to verify: safety—timers never exceed their bounds and reset behavior is correct; liveness—time can always advance (no deadlock by forbidding clock progress), and if action A remains continuously enabled then it will eventually occur after sufficient time progress consistent with the lower bound requirement. Do not commit to an implementation technique; the model should be high-level and suitable for temporal reasoning about combined discrete and continuous behavior.
