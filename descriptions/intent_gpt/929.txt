Specify a formal model of a simple discrete-time hour clock module and prove a basic invariant using temporal logic.

Model a clock that cyclically advances an hour value in a fixed finite range (e.g., 0..H-1 for some positive integer H). The system operates in discrete steps: on each step the clock either advances to the next hour value (wrapping from H-1 to 0) or remains unchanged. The model should permit nondeterministic interleaving of steps but ensure time-progress is represented by repeated application of the advance-or-stay step.

State the initial condition: the hour value starts within the allowed range. Specify the transition relation that captures the allowed step (advance by one modulo H, or stay the same).

Specify the safety property to be proved: the hour value always remains within the allowed range (an invariant). Formulate this as an invariant property and show that it is preserved by the transition relation and holds initially, so it is true globally (always). Also state the liveness expectation that the system exhibits repeated transitions (temporal behavior) though no particular fairness constraints are required beyond enabling the basic temporal reasoning for invariants. The specification should be suitable for mechanized proof in a temporal logic prover.
