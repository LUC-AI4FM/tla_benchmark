Specify a model of an algorithm that takes a well-formed parenthesized expression (a sequence of tokens that are left parentheses, right parentheses, or other tokens) and produces an equivalent expression with all immediately redundant parentheses removed. The input expressions must have balanced parentheses. The algorithm should repeatedly eliminate any pair of matching parentheses that are directly nested inside another matching pair and that contribute no syntactic information (i.e., removing them preserves token order and well‑formedness). The result must be an expression with no such immediately redundant nested pair remaining, and it must preserve the relative order and identity of non‑removed tokens.

Model the transformation as a stateful process that reads the input sequence and constructs an output sequence while tracking enough context to detect when a newly seen right parenthesis forms such a redundant nested pair with a previously emitted left parenthesis. The model should allow arbitrary well‑formed inputs (up to a bounded length for tractability) and should nondeterministically select which redundant pair to remove when multiple choices exist, but it must always converge to the canonical result obtained by repeatedly deleting any immediately redundant nested pairs until none remain.

Specify correctness properties:
- Soundness: the output is well‑formed (balanced parentheses) and is a subsequence of the input with the same tokens and order except for removed parentheses.
- Semantic preservation: removal does not change the sequence of non‑parenthesis tokens and the nesting relations of remaining parentheses.
- Maximality (normal form): no pair of adjacent matching parentheses that are directly inside another matching pair exists in the output.
- Termination: the algorithm terminates for every well‑formed input (within the bounded model).
