Specify a formal model of a deterministic left-fold operation that accumulates elements into a finite set. The system should take as inputs: (1) a binary accumulator function that, given a current set and an element, returns a new set; (2) an initial set seed; and (3) a finite sequence of elements to process. The fold must process the sequence elements one-by-one from left to right, applying the accumulator to the current accumulated set and the next element to produce the new accumulated set, and return the final accumulated set when the sequence is exhausted.

Require that the accumulator is associative in the sense relevant for sets (adding an element is idempotent and order-insensitive), so repeated identical inputs do not create duplicates. The model must permit the initial set to already contain some elements and the sequence to contain duplicates. The final result must equal the union of the initial set with the set of elements occurring in the sequence.

Specify correctness properties: termination (the fold completes after processing all sequence elements), determinism (given the same inputs the final set is unique), and extensionality (if two sequences have identical element multisets then the final result is the same). Include a concrete safety assertion: with initial set {4,4} and sequence <<1,2,3>> the result must be {1,2,3,4}. Also allow exploration of alternative accumulators and sequences to check these properties.
