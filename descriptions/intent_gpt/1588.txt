Model the Euclidean algorithm for computing the greatest common divisor (GCD) of a fixed positive integer A and an arbitrary positive integer B drawn from a given range. The model should treat A as a constant input and B as a nondeterministic initial input in 1..N. The algorithm repeatedly transforms a pair of positive integers (x,y) until termination, using only comparisons, assignments, and subtraction (no division except for defining correctness). It must allow swapping x and y when x < y and otherwise subtracting the smaller from the larger, continuing until one value becomes zero, at which point the other value is the GCD.

Specify the initial state, the allowed state transitions, and a fairness condition that ensures the loop does not unfairly starve progress. Require the model to guarantee:

- Safety: all intermediate values remain natural numbers within appropriate bounds and never become zero unexpectedly except as permitted by the algorithm's rules.
- Invariant: a nontrivial invariant capturing that at every step the set of common divisors of the two numbers is unchanged (i.e., the GCD of the pair remains equal to the GCD of A and the initial B).
- Liveness: eventual termination—under weak fairness of the loop steps, the algorithm reaches a halting state where one component is zero.
- Correctness at termination: when the algorithm halts, the nonzero component equals gcd(A, initial B).

Do not prescribe a particular implementation style; describe only the state space, allowable transitions (swap when less-than, subtract otherwise), invariants to maintain, and the safety and liveness properties to verify.
