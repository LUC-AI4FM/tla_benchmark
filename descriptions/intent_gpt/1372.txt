Specify a formal model of a dynamic partitioning system for a fixed universe of uniquely identified participants. The system organizes participants into a collection of disjoint groups (partitions), where each group has: a non‑empty set of member participants; for each group there is a designated successor reference which is either one specific participant from the universe or a distinguished "null" value; and an auxiliary boolean marker per group (for example, to indicate liveness or removal). The model must enforce that groups do not overlap (no participant belongs to more than one group) and that every group contains at least one member. Additionally, for each group the successor reference must either be null or must point to a participant that belongs to some group in the collection. The model should allow the partition collection to evolve over time by adding, removing, and modifying groups and members subject to the invariants above.

State the key safety properties to prove: group disjointness, non‑emptiness of groups, and successor validity (successor is null or is a member of some group). Also state liveness goals demonstrating that the system can reach meaningful configurations (e.g., creation of at least one valid group from an initially empty collection) and that successor references of newly created groups can become non‑null when appropriate. Do not prescribe a particular implementation or algorithm for maintaining partitions.
