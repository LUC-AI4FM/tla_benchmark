Specify a simple cyclic counter system that repeatedly advances through three states labeled 0, 1, and 2. The model should start in state 0 and at every step increment the state by one modulo 3, so the only possible infinite behavior is the periodic sequence 0 → 1 → 2 → 0 → 1 → 2 → ... . The specification must describe the initial condition, the allowed state transition, and the liveness of the cycle.

Require the following correctness properties to be verified:

- Safety: The state is always one of {0,1,2} and no other values are reachable.
- Determinism of next-state: From any given state there is exactly one permitted successor (0→1, 1→2, 2→0).
- Reachability assertions: State 1 and state 2 are each reachable from the initial state within a finite number of steps.
- Wrap-around occurrence: The transition from state 2 to state 0 must occur at least once (i.e., the model must include an execution that performs the wrap-around).
- Cycle liveness: The system should admit an infinite execution that repeatedly visits all three states forever.

Do not prescribe internal variable names or implementation details; express only the abstract states, initial condition, transition relation, and the above properties to be checked.
