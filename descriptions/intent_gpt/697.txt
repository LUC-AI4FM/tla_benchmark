Specify a formal model of binary relations on a finite set and the standard algebraic and graph-theoretic properties and closures used to reason about orders and connectivity.

The model should treat a relation as a binary predicate on a finite universe and allow checking common relation properties: reflexive, irreflexive, symmetric, antisymmetric, asymmetric, and transitive. It must support characterizing orders: strict partial orders, (weak) partial orders, strict total orders, and total orders, including the comparability/trichotomy requirements that distinguish them.

Include operators that compute the transitive closure of a relation over the given finite set and the reflexive-transitive closure derived from it. The transitive-closure operator should be guaranteed to produce the least transitive superset of the original relation (on the given finite domain). The reflexive-transitive closure must add all self-pairs.

Provide a predicate that determines whether the relation is connected in the graph sense: for every pair of elements there exists a (possibly length-zero) path between them using the relation (i.e., the reflexive-transitive closure relates every pair).

State precise preconditions and types (finite universe, binary relation). Specify expected invariants and correctness properties: soundness of closures (containment of original relation), transitivity/reflexivity guarantees, and that order predicates are logically equivalent to the conjunctions of the listed basic properties. Ensure all definitions are decidable over the finite universe so they are amenable to model checking.
