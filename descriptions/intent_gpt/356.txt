Specify a small deterministic state machine whose state is a single boolean flag that is initialized true and never changes. The model should primarily exercise and validate conditional-expression semantics: nested conditional expressions (if-then-else) and multi-branch selection expressions (case-like constructs) that may themselves contain nested selection expressions. The specification must evaluate a collection of expressions built from boolean literals, numeric literals, string literals, boolean operations, equality comparisons, and nested conditionals; each expression has an expected value or expected membership test. For each expression, the system must assert either success when the expression's evaluated result matches the expected value (or membership) or raise an explicit assertion failure when it does not. The model should also include at least one compound boolean expression that combines conjunctions, disjunctions, negation, and equalities involving incompatible types to validate short-circuiting and type-coercion behavior. Correctness properties: every assertion must hold for all reachable states (so that no assertion failure is reachable), and the machine must remain deadlock-free. The specification should not commit to any particular implementation of conditional evaluation order beyond standard deterministic semantics, but must require that nested and multi-branch conditionals evaluate to the intended results used in the assertions.
