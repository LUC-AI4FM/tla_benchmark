Specify a simple state machine that models a configuration value and its invariants. The system holds a single integer-valued configuration parameter that initially must equal a designated initial constant. The system may perform no transitions that change that parameter (it should remain stable across steps). The specification must state the initial condition, the allowed transitions (including stuttering steps that leave the configuration unchanged), and one or more candidate invariants that relate the configuration to specified constant values. Include at least one invariant that asserts the parameter is equal to a particular constant different from the initial constant, so the model can be used to check whether that invariant holds given the initial condition and transition relation. The goal is to verify whether the invariant is preserved by all behaviors starting from the initial state under the allowed transitions, and to report counterexamples if it is not. The specification should be minimal and self-contained, using named constants for the distinct values involved, and must allow automatic model checking to confirm or refute the invariant(s).
