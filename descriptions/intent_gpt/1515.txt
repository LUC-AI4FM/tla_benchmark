Model a simple stateful counter-like system that nondeterministically updates a single integer-valued state within specified bounds while constraining initial and ongoing values. The model should initialize the state to one of a small finite set of allowed starting values. Thereafter, at each step the system may perform an update only if the current state is strictly less than an upper threshold; when an update occurs, the next state must be chosen nondeterministically from a designated closed interval that lies strictly inside the overall value domain (i.e., not including the domain endpoints). The model should also permit stuttering (no change) steps as usual for temporal specifications.

Specify the safety and liveness expectations: safety requires that every reachable state and every state chosen after an enabled update remain within the global domain of acceptable integers; additionally, updates must not occur when the state is at or above the threshold. Liveness should assert that if updates remain continuously enabled, then progress can eventually be observed (i.e., an actual update may occur). Finally, provide properties to check that the initial-state set and the allowed update range are nonempty and lie within the global domain.
