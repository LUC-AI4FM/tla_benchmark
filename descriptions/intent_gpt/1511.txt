Specify a formal model of a simple predicate-evaluation subsystem that determines whether a collection of elements satisfies a parameterized predicate. The system receives two inputs: a predicate to apply to elements, and a finite nonempty set of elements. It must produce and hold a Boolean output that is true exactly when the predicate holds for every element of the input set, and false otherwise. The model must allow the predicate to be arbitrary (including predicates defined in terms of natural numbers) and the input set to be any finite subset of a chosen universe (for example, naturals), provided by the environment at initialization. Once the boolean result is computed, the system must keep it stable (no further state changes). Key correctness properties to guarantee: (1) Totality — the output is defined for every allowed input pair (predicate, set); (2) Agreement with universal quantification — the output is true iff the predicate holds of every element of the set; (3) Stability — after initialization the output never changes; (4) Determinism with respect to given inputs — repeated initializations with the same inputs yield the same output. Also specify that the model should detect and report counterexamples when the boolean output deviates from the universal-property expected.
