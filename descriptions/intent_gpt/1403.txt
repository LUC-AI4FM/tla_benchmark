Specify a simple state system that maintains a single integer-valued state cell and never changes it after initialization. The system should initialize that cell to zero and thereafter have no transitions that modify it. Model the notion of enabledness of a hypothetical next-state assignment that refers to the future value of the cell via a local binding: include an expression that binds a local name to the state’s successor value and then compares that bound name to zero, and treat the enabledness of that comparison as a predicate of the current state. The specification must capture (1) the concrete state space and initialization, (2) the absence of any state-changing transitions, and (3) the evaluation of whether the described next-state equality would be enabled if executed. The key correctness properties to assert are: safety (the state cell remains equal to zero in all reachable states) and that the enabledness predicate for the hypothetical assignment is false (or has the correct truth value consistent with an unchanging state). The model should expose these properties so that a model checker can verify invariance and the enabledness condition without depending on any particular implementation detail.
