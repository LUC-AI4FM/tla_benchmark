Specify a model of a simple state that holds a single value chosen from a fixed finite set of integers. The system must initialize that state to some element of the set that satisfies a predicate depending on the element and an additional Boolean condition. The Boolean condition is required to hold true for the chosen element, and the element must satisfy a numeric predicate (for example, be greater than a threshold). After initialization, the state must remain unchanged for all time (the system performs no further state updates).

The specification should make explicit:
- the universe of allowed integer values,
- the numeric predicate that filters which integers are acceptable at initialization,
- the additional Boolean requirement that must hold for the chosen value,
- that initialization nondeterministically chooses some value satisfying both constraints,
- that no transitions change the state afterwards.

Correctness properties to guarantee:
- Safety: every reachable state has a value in the allowed universe and satisfies both the numeric predicate and the Boolean requirement.
- Liveness is trivial: once initialized to a valid value, the value persists forever.
- If desired, assert that at least one allowed value exists (the initialization predicate is satisfiable).
