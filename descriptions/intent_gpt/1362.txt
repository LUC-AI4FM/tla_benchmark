Specify a concurrent/state-machine model of a simple functional-state updater that maintains a mapping from a finite set of immutable keys to integer-valued states. The model should:

- Represent a fixed, finite set of keys (each key is an abstract, indivisible identifier) and a state domain of small integers.
- Maintain a single global mapping that assigns to every key a current integer value.
- Initialize the mapping so that every key begins with a specified initial integer.
- Allow a non-deterministic step that updates the mapping by changing the value associated with exactly one key to some (possibly the same) integer, while leaving all other key-value pairs unchanged.
- Permit stuttering steps (steps that leave the mapping unchanged).

The specification should assert and check the following correctness properties:

- Safety (typing) invariant: at all reachable states the mapping is defined for every key and all mapped values lie within the declared integer domain.
- Liveness: the system does not deadlock; every enabled update step is eventually taken (or, equivalently, the system guarantees progress in that updates can continue indefinitely, modulo stuttering).
- Stuttering-insensitivity: properties should hold even when steps that perform no observable change are inserted.

Do not prescribe an implementation strategy; describe only the abstract state, allowed transitions, initial condition, and the invariants and liveness properties to be verified.
