Specify a formal model of Euclid’s algorithm for computing the greatest common divisor (GCD) of two positive integers. The system should take as input two positive integers, one fixed constant and one arbitrary in a given range, and repeatedly apply the standard subtraction-based Euclid loop until the algorithm converges. The model must capture nondeterministic initial choice of the second input within its allowed range and the loop that at each iteration ensures the larger of the two numbers is reduced by the smaller (swapping their values when necessary) or subtracts the smaller from the larger. Termination must be modeled: the algorithm should reach a designated terminal state when one of the numbers becomes zero, at which point the other number is the result.

Key correctness properties to guarantee:
- Partial correctness: when the algorithm terminates, the remaining nonzero value equals the mathematical GCD of the original two inputs.
- Invariance: throughout execution, both values remain nonnegative integers and positive until termination, and the pair of values always preserves the same set of common divisors as the original inputs.
- Termination: show that for all allowed initial second-input values, the algorithm eventually terminates (no infinite descent), or state and justify any conditions under which termination is ensured.
- Safety: no illegal states should be reachable (e.g., negative numbers, division by zero, out-of-range values).

Do not constrain the model to a particular imperative encoding; instead describe the allowed state space, the iteration rule (swap when needed, subtract), the terminal condition, and the properties to be verified.
