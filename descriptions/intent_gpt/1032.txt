Specify a formal model of a finite directed graph and operations that compute reachability and induce subgraphs, together with correctness properties about those computations.

Model a directed graph as a pair of a finite set of vertices and a set of ordered edges between vertices. Provide an operation that, given a set of start vertices, computes the set of all vertices reachable from that set via zero or more directed edge traversals. Provide an operation that, given a set of start vertices, produces the subgraph induced by all vertices reachable from those starts (i.e., the reachable vertices together with all edges whose source is a reachable vertex). Ensure the model makes no assumptions about acyclicity: reachability must behave correctly in the presence of cycles.

Require and prove the following properties:
- Safety: every vertex in the reachable set is indeed a vertex of the original graph, and every edge in the induced subgraph is an edge of the original graph whose source is in the reachable set.
- Correctness of reachability closure: the reachable set is the least set containing the start vertices and closed under taking direct successors (i.e., if a vertex is reachable then all its immediate children along outgoing edges from any reachable vertex are also reachable).
- Termination (for finite graphs): the reachability computation stabilizes in a finite number of steps and yields a fixed point.
- Idempotence of subgraph extraction: extracting the induced subgraph from an induced subgraph yields the same subgraph.
- Consistency: if the start set is empty, the reachable set is empty and the induced subgraph has no vertices or edges.

Include well-formedness invariants for graphs (edges connect existing vertices and are ordered pairs) and state all properties as invariants or theorems to be checked.
