Model a concurrent system of N identical processes that coordinate access to a single critical region using a binary semaphore that enforces mutual exclusion. The model should capture the full lifecycle of each process: repeatedly doing noncritical work, attempting to acquire the semaphore, executing in the critical region, and releasing the semaphore, indefinitely. The semaphore initially permits one holder and is acquired atomically by a process only when it is available; acquisition makes it unavailable until the holder releases it.

Specify actions at the abstraction level of high-level states (noncritical, waiting-to-enter, in-critical, releasing), not an implementation with locks or scheduling details. The model must allow asynchronous interleaving of process steps and fairness assumptions so that a process that repeatedly tries to enter is not permanently starved when the semaphore is repeatedly available.

Key correctness properties to guarantee:
- Safety (mutual exclusion): at most one process can be in the critical region at any time.
- Liveness (progress/fairness): if a process is continually enabled to acquire the semaphore (keeps trying), it will eventually enter the critical region; in addition, the semaphore never becomes permanently unavailable (no deadlock).
- Invariant: the semaphore state must accurately reflect whether the critical region is occupied (i.e., semaphore unavailable iff some process is in the critical region).
- Repetition: every process repeatedly returns to the noncritical state and can attempt entry again.

Allow parameterization by N (positive integer) and require the model to be suitable for model checking for small N.
