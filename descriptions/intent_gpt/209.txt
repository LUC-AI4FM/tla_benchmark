Specify a TLA+ model of a simple deterministic computation that iteratively computes factorial values for successive natural-number arguments using a reusable mathematical function. The system maintains a nonnegative integer counter that starts at zero and a value representing the factorial of the current counter. On each step, the counter increments by one and the factorial value updates to the factorial of the new counter. The factorial function must be defined as a pure mathematical mapping from a finite domain of small positive integers to integers (for example, 1..5), following the usual recurrence: factorial(1) = 1 and factorial(k) = k * factorial(k-1) for k > 1. The model must not rely on implementation-level recursion primitives; instead, the factorial should be specified as a deterministic function satisfying the recurrence for every domain element.

Required correctness properties:
- Safety: At every state, the stored factorial value equals the factorial of the current counter (consistency invariant).
- Progress: The counter increases unboundedly (or, if a bounded domain is used, the model should state expected behavior when the counter reaches the maximal domain value).
- Determinism: Given the same state, the next state is unique (no nondeterministic choices).
- Domain conformance: The factorial function is well-defined for every integer in its domain and respects the recurrence relation.

Also specify initial conditions, step relation, and temporal properties asserting the invariant and the chosen liveness property.
