Specify a model of a transaction coordinator and a set of resource managers that implement a two-phase commit protocol ensuring atomic commit or abort across all participants. The model should describe multiple independent resource managers that can be in one of a small set of states representing their local decision process (e.g., working, prepared, committed, aborted) and a coordinator that drives global decisions by sending prepare, commit, and abort decisions. The system must allow resource managers to make local choices (such as voting to prepare) and to respond to coordinator messages, and it must permit failures and recovery of participants and the coordinator in a way that preserves safety.

Require these correctness properties: (1) Consistency (atomicity): it is never the case that one resource manager reaches committed while another reaches aborted. (2) Valid state progression: each resource manager’s state transitions follow allowed sequences (e.g., cannot commit before preparing). (3) Termination/liveness variant: if all non-failing resource managers vote to prepare and the coordinator does not fail forever, then eventually all non-failing resource managers reach commit. Also specify that aborted outcome is reached if any participant votes to abort. The model should be parameterized by the set of resource managers and support nondeterministic scheduling of messages and failures so the properties can be checked under all interleavings.
