Specify a formal model of the binary-search algorithm over a finite, sorted sequence of integers. The model should accept as parameters a nonempty (possibly empty allowed) sequence of integers and a target key, and must reflect the behavior of a typical binary-search procedure that returns either the index of an occurrence of the key (if present) or a canonical “not found” indicator encoding the insertion position. The system must:

- Initialize search bounds to cover the entire sequence.
- Repeatedly narrow the search interval by comparing the key to an element selected from the current interval (middle element), updating the low or high bound accordingly, until termination.
- Terminate when the interval becomes empty or when an index containing the key is discovered.

Correctness properties to guarantee:

- Safety: If the algorithm reports an index r as found, then 0 ≤ r < length(seq) and seq[r] = key.
- If the algorithm reports a not-found value encoding an insertion point p, then 0 ≤ p ≤ length(seq) and inserting key at position p into the sequence preserves sorted order; equivalently, all elements before p are < key and all elements at or after p are > key.
- Progress/Termination: The algorithm must always terminate after a finite number of steps for any finite input sequence and integer key.
- Bounds invariants: At all times the search bounds must remain within [0, length(seq)] and the current target (if not found) must lie outside the eliminated portions.

Do not prescribe implementation details such as exact arithmetic for computing the middle (e.g., whether to use floor, ceiling, or overflow-avoiding formulas); instead allow any deterministic selection of a middle index that respects interval containment and strictly reduces the size of the remaining search interval on each step until termination.
