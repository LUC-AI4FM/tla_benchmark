Specify a model of a simple message-generation test harness for a system that produces a sequence of messages, each carrying a monotonically increasing sequence number and an associated ballot (or priority) value. The model should capture an initialization phase that creates an initial nonempty set of messages whose sequence numbers are all strictly less than the next sequence number to be assigned, and then a step that appends a newly generated message with the current next sequence number and some integer ballot, while incrementing the next sequence number.

The model must allow the ballot value of each new message to be an arbitrary integer (no probabilistic or distributional assumptions), and the initial set of messages may contain multiple messages with various ballots. The primary correctness property to guarantee is that the ballot values are nondecreasing with respect to sequence numbers: for any two messages, if one has a larger sequence number than the other, then its ballot must be greater than or equal to the other’s ballot. The specification should also state invariants ensuring that sequence numbers assigned to new messages increase by one each step and that existing messages remain present unless explicitly removed (and the model should include no other unexpected mutation). Describe the state space, the initialization and step relation, and assert the monotonicity property as an invariant to be checked.
