Specify a model of a single mobile agent that circulates around a fixed ring of nodes that each hold a nonnegative integer count of tasks. The system should allow nodes to generate additional tasks while task creation is enabled and allow the agent to observe and move around the ring to achieve local load balancing by carrying at most one task. The agent repeatedly alternates between (a) moving to the next node on the ring and (b) examining the current node’s load and the last observed neighboring load to decide whether to pick up a task, drop a task, or do nothing. When picking up, the agent removes exactly one task from the current node and holds one task; when dropping, it adds exactly one task to the current node and becomes empty. Task creation can be turned off permanently by an external action.

Model requirements and correctness properties to guarantee:

- Safety (conservation): the total number of tasks in the nodes plus any task the agent carries never changes except by explicit task-creation events; when creation is disabled, the total task count remains invariant.
- Bounds: node loads must always remain nonnegative and below a stated finite upper bound; the sum of loads must remain below a specified global limit.
- Termination/quiescence property: once task creation has been permanently disabled and all node loads are equal, the agent must eventually carry no task (it cannot indefinitely hold a task while system is quiescent).
- Progress (liveness): movement and look/act steps of the agent are not permanently disabled (if enabled, they eventually occur); if task creation is enabled infinitely often, creation events may occur repeatedly.
- Type invariants: the agent’s state (location in the ring, last observed load, ready-to-move flag, carry capacity) and node loads must always remain within their declared domains.

Do not presuppose a specific implementation of the agent’s control flow; allow nondeterministic scheduling of move, observe/act, stop-creating, and create-task actions. Ensure specifications assert both safety invariants and the required liveness properties.
