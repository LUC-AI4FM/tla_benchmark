Model a system that determines how to break a single integer-weight stone into a fixed number of integer-weight pieces so that, using a two-pan balance, any integer weight from 1 up to the stone's total weight can be measured exactly. The model should treat a break as an ordered multiset of piece weights that sum to the stone's total, where pieces may have equal weight; order should not affect correctness. Measuring an integer weight w is defined as a partition of the pieces into two disjoint subsets placed on opposite pans, possibly together with the unknown weight w on one pan, so that the pans balance. The system must decide, for given constants TotalWeight and NumPieces, whether there exists a break meeting the requirement that every integer w in 1..TotalWeight has a corresponding partition that balances the scale.

Specify the input parameters (total weight and number of pieces), the space of valid breaks, and the notion of a valid measurement for a given break. Require a predicate that identifies all breaks that solve the problem. State correctness properties: (1) Any reported break consists of nonnegative integer piece weights summing to the total and is canonical up to permutation; (2) for every target weight in 1..TotalWeight there exists a pair of disjoint subsets of pieces whose weights satisfy the balance equation; and (3) no solution is reported that fails either constraint. Optionally request generation of an example solution when one exists.
