Specify a system that models a single shared value initialized to zero and subject to a single transition that sets it to a fixed constant value. The model should represent an initial state where the stored value equals zero and allow one kind of state evolution in which the stored value becomes the constant (42). The specification must allow reasoning about the reachability of the constant value from the initial state and about stuttering or unchanged-state behavior where relevant. Required correctness properties: (1) Safety — once the transition to the constant occurs, the value must equal that constant in all subsequent states; (2) Reachability — the constant value must be reachable from the initial state (i.e., there exists an execution that attains the constant); (3) Absence of unexpected changes — no other values besides the initial zero and the constant should be permitted in any state; and (4) Liveness — either the value eventually becomes the constant or the system is permitted to remain forever in the initial state only if the model of stuttering is allowed. The specification should be minimal and intended for formal verification of these properties.
