Model a simple state-transition system in which the state is a single integer-valued variable representing a resource or counter. The system repeatedly applies nondeterministic operations chosen from a fixed, externally supplied set of operations that map the current state to a set of possible next states. Specify the initial state value and the allowed transition relation in terms of an abstract operation family: for any current state s, the set of possible successors is given by Op(s), where Op is a constant parameter of the specification. The model should not assume any particular form for Op beyond being a function from states to sets of states; Op may be nondeterministic, partial, or total. Require that every transition picks a next state from Op(current). Express liveness properties ensuring that the system can always perform a next transition when Op(current) is nonempty, and safety properties guaranteeing the state always stays within a user-specified invariant set. Allow the invariant set to be parameterized. Also include the ability to assert reachability properties (some state satisfying a predicate is eventually reachable) and to check absence of deadlock when Op maps reachable states to nonempty sets. The specification should be suitable for model checking different concrete instances of Op and of the invariant set.
