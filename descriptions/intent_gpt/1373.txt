Specify a simple state machine modeling initialization and stability of a small configuration value in a modular system. The model should capture that a system component has a value that must be set to a specific constant at system startup and then never changes. The specification should allow the constant to be provided externally (a parameter) but must require that the actual value assigned during initialization equals the expected constant. The model must record and expose diagnostic messages or observable events that indicate the initial assignment occurred and what the expected constant was, to support independent modules observing initialization. After initialization, the system must guarantee that the component's value remains invariant: no action may modify it. Key correctness properties: (1) Initialization property — the component is assigned the required value on the initial step; (2) Invariance property — the component’s value is unchanged by all subsequent transitions (safety); (3) Consistency with parameter — the externally provided constant parameter equals the initialized value; and (4) Observable initialization — the initialization exposes or logs the assigned value and the parameter for external inspection. Do not presuppose any particular implementation mechanism; describe only states, a single initialization followed by stuttering-only behavior, and the safety properties above.
