Specify a model of a simple state machine whose state comprises four components: a finite set of integers, a finite set of strings, a record (map) from a small fixed set of string keys to finite integer sets, and a function-valued map whose domain is a finite set and whose values are finite integer sets. The model should describe an initial state in which each component has a single concrete value (the integer-set contains 1,2,3; the string-set contains "a","b","c"; the record maps each of those three keys to the same integer-set; and the function-valued map maps that integer-set to the same integer-set). The system should allow transitions that can update the integer-set component to any representation that is semantically equal to that initial integer-set (including expressions that contain duplicates, different ordering, or computed comprehensions) while keeping the other components unchanged. No other components should change in those transitions. The correctness properties to verify are: (1) from the initial state only one distinct abstract state (up to set/map equality) should be reachable after such updates, i.e., all different syntactic ways of producing the same set/map value must be treated as the same state; and (2) an invariant that the four components always equal the original concrete values must hold (so any allowed transition results in a state indistinguishable from the initial state). Ensure the model is finite-state and suitable for model checking equality and canonical representation of sets, records, and function-valued maps.
