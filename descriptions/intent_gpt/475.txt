Specify a parameterized model of reliable broadcast by message diffusion in a system of N processes with up to F crash failures, where up to T is a resilience parameter (N, T, F are parameters with N > 2T and T ≥ F ≥ 0). Model processes that may be initially uninformed or hold an initial broadcast value, may crash, send and receive plain "ECHO" messages, and may accept the broadcast. The model should capture asynchronous delivery (messages can be delayed but eventually delivered to correct processes) and non-duplicating set-based message receipts.

Require the following functional behavior and correctness properties:

- Safety (Validity/No-forge): If no correct process is initially informed or starts by broadcasting, then no correct process ever accepts the value. Conversely, only values originating from some process can be accepted by correct processes.

- Agreement/Relay: If a correct process accepts the value, then eventually every correct process accepts the value (once any correct process accepts, acceptance is relayed to all correct processes despite crashes up to F).

- Liveness/Reliability: If a correct process sends an ECHO, then every correct process eventually receives that ECHO (channels are reliable for correct recipients), and if some correct process is initially informed, then eventually some correct process accepts; further, under fairness assumptions, acceptance propagates to all correct processes.

- Fault model: Processes may crash (stop) up to F total; crashed processes stop sending/receiving and do not accept. Crashes may occur at any time subject to the bound.

- Fairness requirement: Model weak fairness for actions that process receipt enables, so that enabled receive-and-react steps of correct processes eventually occur.

Specify system states and transitions abstractly (process statuses: uninformed, informed, accepted, crashed; message sets sent and received), and express the above properties as temporal formulas to be checked for all parameter values.
