Specify a concurrent state-generation system that nondeterministically explores a small finite set of distinct states and preserves a trivial invariant. Model a system with two state components where one component represents a control/value that may take one of three distinct values and the other remains constant. The system must allow an initial state where both components start with a fixed value; from that start, the system should be able to transition to any of the three distinct values for the first component while keeping the second component unchanged, or to stutter (leave both components unchanged). The model must permit all three distinct generated states to be reachable from the initial state. Specify a trace-based execution model supporting nondeterministic choice and stuttering steps, and ensure the specification expresses reachability rather than an algorithm for enumeration. Require a safety property that is always true (trivial invariant) and does not constrain reachable states further, and require a liveness/coverage requirement that every of the three distinct target values for the first component is reachable in some execution (or that for each such value there exists a complete execution reaching it). Do not constrain implementation order or force a particular generation mechanism.
