Specify a declarative model of a pure functional fold over a finite set that produces a finite sequence. The model should describe a deterministic fold-like operator that starts from an empty sequence and, for each element of an input set of integers, appends that element to the accumulating sequence. The order in which the set’s elements are processed is arbitrary (reflecting nondeterministic iteration over a set), but the fold must append each input element exactly once, producing a permutation of the original set as the final sequence.

The specification must capture the initial state (empty sequence) and the termination condition (the accumulator contains exactly the elements of the input set, with no duplicates and no omissions). It must require that the fold’s element-combining operation is pure (no side effects) and associative with respect to producing a sequence via successive appends (so that the only nondeterminism is the element processing order, not the combiner behavior).

Key correctness properties to guarantee:
- Safety: at every step the accumulator is a sequence of distinct elements drawn from the input set (no element appears twice and no new elements appear).
- Progress/termination: the process eventually finishes with a sequence whose multiset equals the input set.
- Result characterization: every possible final sequence is a permutation of the input set; conversely, every permutation is reachable by some processing order.
- Deterministic combiner behavior: the combiner applied to an accumulator and an element always yields the result of appending that element to the accumulator.

Do not constrain or name internal control variables or the iteration mechanism; focus on the abstract fold semantics, set-to-sequence mapping, and the invariants above.
