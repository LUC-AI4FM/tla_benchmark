Specify a concurrent system in which two independent components repeatedly choose and update numeric states drawn from a small set. Each step of the system may change either one component’s state or both simultaneously, but the chosen next values must always end up equal: after any step, the two components’ states must be identical. The system should allow the individual components to take on at least three distinct values over time and permit transitions that set a single component to a designated value, transitions that set both components to potentially different intermediate values before equating, and transitions that simultaneously swap or assign values so that the equality invariant is preserved.

Model the state as the pair of component values and define a nondeterministic transition relation capturing the allowed single-component and joint updates. Specify an initial condition that permits arbitrary starting values within the allowed set. Require invariants: (1) at all reachable states the two component values are equal; (2) liveness that ensures each designated value is eventually reachable by both components under fair scheduling; and (3) absence of deadlock (there is always some enabled transition). Also specify safety properties forbidding unreachable or invalid value combinations and prove that the equality invariant holds in all executions.
