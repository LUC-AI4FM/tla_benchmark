Specify a simple state machine that models an assignment operation which nondeterministically sets a single state element to either 0 or 1, but only allows that assignment to succeed when the chosen value is strictly positive. The model should represent an initial state in which the element has no concrete numeric value, then permit repeated steps that attempt the assignment. Each step may choose either 0 or 1 as the intended new value, but the system must only accept the transition when the chosen value is greater than zero; attempts to assign zero must not change the state. The model should allow infinite execution (stuttering or repeated accepted assignments) and must capture that the set of possible next-state values is exactly the singleton positive value when an assignment occurs. Key correctness properties to be checked: (1) safety — the state is never set to a value other than 0 or 1; (2) progress/consistency — whenever the system performs an accepting assignment, the new value is the positive option; and (3) invariance — once the state attains the positive value it remains a legal value in all subsequent states. The specification should abstract away implementation details and focus on the allowed choices and the predicate that forbids accepting the zero assignment.
