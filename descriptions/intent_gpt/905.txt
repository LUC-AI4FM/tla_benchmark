Specify a formal model of a simple digital hour display that represents an hour value using a fixed-size array of binary digit signals. The model should treat the display as an interface that exposes a collection of binary outputs, each output holding either 0 or 1, and should relate those bit outputs to the logical hour value they encode. The system to model is the encoding and continuous correctness relation between the bit-pattern and a valid hour (0–23 or a specified hour domain). The model must capture:

- The mapping from a finite indexed set of bit signals to a numeric value, interpreting each bit as a binary-weighted digit (least significant bit at index 0).
- The constraint that the interpreted numeric value is always a member of the legal hour range; if the bit pattern does not encode a valid hour, that state must be considered illegal or flagged.
- The invariant that the bit outputs must continuously reflect some legal hour value (i.e., at all observable times the numeric decoding of the bits equals a valid hour).
- An abstract specification of an external hour source: the model should support asserting existence of an intended hour value that the bit array implements, without prescribing how the bits are produced or updated.
- Properties to verify: (1) safety — the decoded value never leaves the valid hour range, and (2) functional consistency — there exists an hour value that the bit array encodes and maintains.

Do not prescribe update algorithms for the bits; specify only the relation between bit signals and the hour they represent and the invariants required to hold at all times.
