Specify a model of a function that computes the lexicographically least rotation (circular substring) of a finite string over a fixed finite alphabet. The system should accept as inputs a string length bound and an alphabet size, and operate on any concrete string whose length does not exceed the bound and whose symbols range over the alphabet. The model must express the notion of circular rotation and define the order used for comparing rotations (standard lexicographic order over the alphabet symbols).

The model must capture a deterministic algorithm that, given an input string, produces a rotation index specifying which rotation is least and the resulting rotated string. It should ensure the output rotation is valid (an index within the string length) and that the rotated string is equal to the original string rotated by that index. For empty strings or length-one strings the model should behave correctly (identity rotation).

Key correctness properties to guarantee:
- Minimality: the chosen rotation yields a string that is lexicographically no greater than any other rotation of the same input.
- Uniqueness or canonicality: if multiple rotations are lexicographically equal, the model should deterministically choose one canonical index (for example, the smallest index).
- Stability under equal-symbol alphabets and varying lengths up to the bound.
- Safety: the algorithm never produces out-of-range indices or symbols outside the alphabet.

Include invariants that relate the input, chosen index, and output, and specify termination (the algorithm always produces a result).
