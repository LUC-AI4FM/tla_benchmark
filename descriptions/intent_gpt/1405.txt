Specify a model of a two-component system in which an outer controller maintains a sequence of integers and an integer result variable, and a single inner service component can perform an atomic update that (1) sets the inner result to a specific nonzero value and (2) removes all occurrences of that new result value from the inner copy of the sequence. The outer controller and the inner service share the result and sequence values so that when the inner service runs it modifies the global result and sequence. The system should allow the outer component to stutter (do nothing) whenever the inner service is not enabled.

Model the following behavior and goals:

- Initial state: the sequence contains a finite nonempty list of positive integers (for example, 1,2,3) and the result variable equals zero.
- The only substantive transition is the inner service’s atomic action that changes the result from zero to a fixed nonzero value (e.g., 1) and simultaneously removes every element of the sequence equal to that new result value.
- The inner service should be treated as a fair component: if it remains continuously enabled, it must eventually take a step (weak fairness).
- The outer controller may take stuttering steps whenever the inner service is disabled.

Specify correctness properties to verify:

- Safety: the result value only ever changes from the initial zero to the specified nonzero value and never to other values; and the sequence is always equal to the original sequence with zero or more occurrences of that specific nonzero value removed.
- Liveness: under the assumed fairness, the inner service eventually executes and the system reaches a state where the service is no longer enabled (i.e., the result has been updated and all matching elements removed).
- Progress/termination: characterize and prove that the system reaches a stable state in which further execution only stutters (no enabled inner action remains).

Do not assume particular implementation details; capture the shared-state interaction, atomic update semantics, and fairness obligation abstractly.
