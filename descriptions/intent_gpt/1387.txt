Specify a simple state transition system that models an atomic update of a single component in a small state composed of two independent parts. The model should represent two state components, where initially both are in a well-defined base value. The system must include a single state transition that atomically sets one component to a specific target value while guaranteeing that the other component remains unchanged by that transition. The transition should be enabled from the initial state and may be executed repeatedly or once, but it must preserve the invariant that the untouched component never changes as a consequence of the defined transition. Formalize the initial conditions, the allowed transitions, and the notion of stuttering or unchanged variables so that it is clear which components can be modified and which must be preserved. Specify key correctness properties: (1) safety: after any number of transitions the modified component is equal to the target value and the preserved component retains its initial value; (2) invariant preservation: the preserved component is invariant across all reachable states; and (3) liveness: the system should allow the transition to occur (i.e., it is not permanently disabled in the initial state). Do not prescribe implementation details of the transition mechanism beyond its atomic effect.
