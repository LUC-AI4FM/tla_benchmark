Specify a model of a synchronous distributed reachability protocol running on a fixed finite network of nodes, where each node maintains a set of neighbors it forwards reachability information to, and communication happens in rounds. The model should describe how nodes exchange and accumulate knowledge of which nodes are reachable: initially each node knows only itself; in every round each node sends some subset of node identifiers it currently knows to each of its outgoing neighbors and updates its knowledge by unioning incoming information. The system must permit each node to forward to a bounded number of distinct neighbors (e.g., exactly two), and the choice of which neighbors receive messages may vary but stays within that bound. Model nondeterministic choices of forwarding and of initial neighbor selection subject to the bound.

Specify safety properties: no node ever learns an identifier that is not one of the network's nodes, and knowledge monotonicity holds (a node’s known set never shrinks). Specify liveness properties: under fair continual communication, every node eventually learns the identifiers of all nodes in its strongly connected component and, if the network is globally strongly connected, every node eventually learns all nodes. Also require termination detection: once no knowledge changes occur, the system reaches a quiescent state where further rounds do not alter known sets. Provide invariants capturing bounded forwarding and monotonic growth, and temporal properties expressing eventual global reachability under fairness assumptions.
