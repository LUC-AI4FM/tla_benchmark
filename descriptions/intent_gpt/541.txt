Specify a concurrent system of two independent processes that cooperate by updating a single shared integer variable. Each process should follow a short sequence of steps that may read and write the shared variable; both may execute concurrently and interleave arbitrarily. The model must allow non-deterministic scheduling and must permit any interleaving that preserves atomic execution of each individual step.

Require that both processes terminate (reach their respective termination states) in every fair execution. The primary safety property: whenever both processes have reached their termination states, the value of the shared integer must equal a specific constant (2). The model must capture and check that no reachable global state exists in which both processes are terminated yet the shared variable differs from that value.

Also specify basic liveness: from any reachable state, if a process is enabled infinitely often, it must eventually make progress and terminate (weak fairness for each process). Allow the possibility of transient intermediate values for the shared variable, but ensure the final value constraint holds at the joint termination point. Include an initial condition describing allowed initial values of the shared variable and initial program locations for the two processes.
