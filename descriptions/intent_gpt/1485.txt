Specify a simple single-decision consensus module in TLA+. The system has a fixed nonempty set of possible proposal values and a group of processes that must collectively decide on at most one value. The specification should model asynchronous steps that may choose a decision value exactly once: initially no value is decided; a single atomic decision step may later elect one value from the allowed set and thereafter the decided value remains fixed. The model must permit the decision to occur at any time (or never, under a purely safety specification), but a liveness variant should require that eventually some value is decided if processes keep taking enabled decision steps fairly.

Requirements:
- Safety: At all times, the set of decided values is a subset of the allowed values and contains at most one element; once a value is decided it cannot change.
- Initialization: No value is decided initially.
- Decision step: There exists an action that, when taken, sets the decided value to exactly one value chosen from the allowed set; this is the only action that can add a decided value.
- Liveness (optional mode): Under a weak fairness assumption for the decision action, if no value is chosen yet then eventually some value will be chosen.
- Type and well-formedness invariants: the decided value representation must be finite and respect cardinality constraints.

State only the system behavior and correctness properties; do not prescribe a particular implementation protocol or process-local variables.
