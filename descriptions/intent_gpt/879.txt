Specify a formal model of context-free grammars (BNF-style) that treats grammars as mappings from nonterminal names to sets of finite terminal/nonterminal symbol sequences, and specify operations and properties needed to reason about language generation and minimal grammars satisfying constraints.

The model should represent:
- A grammar as a finite map from nonterminal symbols to sets of right‑hand side sequences (each sequence is a finite list of symbols drawn from an alphabet that can include terminals and nonterminals).
- Concatenation, union, Kleene star, and one-or choices of languages built from sets of sequences, and an explicit empty sequence entity.

The specification must allow:
- Expressing the language generated by a nonterminal as the least set of terminal sequences closed under grammar derivations.
- Defining when a grammar satisfies a predicate (for example, generates or includes certain strings, excludes others, or conforms to syntactic restrictions).

Key correctness properties:
- The language operations (concatenation, union, Kleene star) must have the usual algebraic laws (associativity, distributivity where appropriate, identity elements).
- The generated language for a nonterminal must be the smallest set of terminal-only sequences that contains the direct productions and is closed under one-step derivation and finite composition.
- A minimality property: if a grammar meets a given predicate, there must exist a grammar that satisfies the predicate and is pointwise minimal (for each nonterminal its generated set is included in every other grammar satisfying the predicate).
- Definitions must be unambiguous about empty string inclusion and finiteness of right‑hand sides.

Include invariants and proof obligations to check closure properties and minimality, enabling formal verification that candidate grammars meet the stated requirements.
