- Declare an integer-valued state component representing a numeric resource whose initial value is strictly greater than 1 and equal to a concrete constant (use a small integer like 2).
- Ensure the state evolves by stuttering only: there are no state-changing transitions (the value remains constant forever).
- Encode a collection of sanity properties about set and sequence constructions derived from that integer: membership tests, singleton and comprehension equalities, existence quantification over singleton sets, and a small bounded family of sequences built from a singleton element. - Allow the model checker to print or report which of those assertions hold at initialization or during checking so that failing expressions are easily visible.

Specify the correctness properties to prove:
- The value remains constant and greater than 1 over all behaviors.
- Each stated equality and membership claim about sets and comprehensions involving the value is always true.
- The existence claims over the relevant sets are satisfied.
- The bounded family of sequences constructed from the singleton element equals the intended set (or, if left as a check, that any deviation is reported).

Do not prescribe how to implement printing or the internal variable names; focus on the state, the invariants to be verified, and that there are only stuttering steps.
