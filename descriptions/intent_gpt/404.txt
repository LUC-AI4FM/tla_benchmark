Specify a formal TLA+ model of a pure data-level equality and function-construction theory used to validate different syntactic representations of functions, tuples, records, and sequences. The model should allow constructing functions by explicit mapping, by mapping over Cartesian products, and by nested function comprehensions, as well as building tuples and records and performing functional updates ("except"). It must treat equivalent mathematical mappings and structured values as equal when they denote the same mapping or tuple contents, regardless of the syntactic construction used to produce them.

The specification must include a simple state machine to host assertions but should not depend on particular variable names. It must assert that:
- Functions defined by comprehensions over product domains equal the functions defined by indexing into ordered pairs representing those products when their pointwise values agree.
- Nested function comprehensions are extensionally equal to equivalent two-argument comprehensions.
- Sequence and tuple construction are extensionally equal to record-like mappings when indices and values match.
- Functional update (except) semantics produce values equal to the explicitly constructed values they are intended to represent, including updates that modify nested component fields.
- Empty function comprehensions yield the empty sequence/tuple where appropriate.
- Equality comparisons reject non-equal constructions and accept equal ones, providing diagnostic assertions that fail if any equality test is incorrect.

State the expected invariant properties describing these equalities and non-equalities; the model checker should be able to check them automatically without encoding algorithmic behavior beyond constructing and comparing these data objects.
