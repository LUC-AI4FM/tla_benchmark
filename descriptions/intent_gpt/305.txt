Specify a formal TLA+ model of the classic binary-search algorithm over a (finite) integer sequence. The model should treat the sequence and the search key as arbitrary inputs (with an optional precondition that the sequence is sorted in nondecreasing order). The model must express the algorithm’s control state (whether it has terminated), the current inclusive search interval, and a count of executed steps, but need not prescribe a particular implementation or loop structure.

Required behaviors and correctness properties to specify and verify:

- Initialization: the search interval should initially cover the full sequence, termination flag is false, result is undefined, and step count is zero.
- Step semantics: each nonterminal step must either shrink the search interval by moving its low or high endpoint or set termination with an appropriate return value; steps must increment the step count when the interval is inspected.
- Final result correctness: when the algorithm terminates, if the input sequence is sorted then the reported result must correctly indicate whether the key exists and, if so, return a valid index at which the key appears; if the key is absent the return value must indicate failure consistently (convention may be negative).
- Termination and progress: prove that the algorithm always terminates (for bounded integer arithmetic) or show a well-founded progress metric (the interval strictly contracts on each nonterminating step) that implies termination; provide a numeric bound on steps in terms of the machine integer width or length of the sequence.
- Safety: all array accesses must be within bounds; indices and arithmetic must respect given integer width constraints.

Do not commit to any particular mid-point computation or tie-breaking rule in the specification; allow the model to capture any reasonable conventional choice as long as it preserves the above properties.
