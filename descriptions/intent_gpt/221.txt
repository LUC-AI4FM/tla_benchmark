Model a finite-state system that maintains a subset drawn from a fixed finite universe of values. The system begins with the empty subset and evolves in discrete steps. At each step, it may either add a single value not currently present or remove a single value that is currently present. The model should be parametric in the size and contents of the universe so different finite sets of values can be plugged in.

Specify safety and liveness requirements. Safety: any state reached must always be a subset of the universe (no spurious elements). Also specify an invariant expressing that a particular “bad” configuration — the subset equal to the entire universe — is considered undesirable. The model should enable checking whether that bad configuration is reachable from the initial empty set.

Liveness: if additions are repeatedly chosen, the system should be able to reach the full-universe configuration in exactly as many additive steps as the universe has elements; conversely, provide the ability to remove elements so the system need not remain full once achieved. Ensure nondeterministic choice between add and remove actions is represented so multiple interleavings and schedules can be explored. Include a property that counts or bounds the minimum number of steps required to reach the full set.
