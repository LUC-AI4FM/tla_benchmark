Specify a pure combinatorics library that computes factorials and binomial coefficients and verifies their basic arithmetic properties. The model should represent natural numbers and define a deterministic function that returns n! for any nonnegative integer n, and a deterministic function that returns the binomial coefficient "n choose k" for integers n, k with 0 ≤ k ≤ n. The specification must require that these functions agree with the standard mathematical identities: 0! = 1; for n > 0, (n!) = n * (n-1)!; for all valid n,k, choose(n,k) = choose(n,n-k); and choose(n,0) = choose(n,n) = 1. It must guarantee the Pascal recurrence choose(n,k) = choose(n-1,k-1) + choose(n-1,k) for 0 < k < n, and monotonicity in k when appropriate (choose(n,k) ≥ choose(n,k-1) for k ≤ n/2). The model should check arithmetic consistency (no division by zero, values integral and finite) and produce invariants asserting nonnegativity and integrality of results. Include properties for boundary cases (k out of range) and indicate expected behavior (e.g., undefined or zero) for such inputs. Finally, include a set of assertions or temporal properties to be checked by model checking that these identities and invariants always hold.
