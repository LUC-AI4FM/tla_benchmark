Specify a formal TLA+ model of an abstract library for finite sequences and operations that extend the standard sequence algebra. The model should define a domain of finite sequences over an arbitrary element type and the following operations: concatenation, subsequence extraction, element insertion and deletion at arbitrary positions, mapping and filtering by predicates, sequence reversal, and a stable sort by a given comparator. The model must describe the algebraic properties these operations must satisfy (associativity and identity for concatenation, correctness of subsequence bounds, preservation of length and element multiset under defined transformations, idempotence where appropriate, and stability for sort). It must also specify edge cases for empty sequences and single-element sequences. Formalize invariants that capture safety properties (no out-of-bounds accesses, operations produce finite sequences, indices remain within valid ranges) and liveness-style correctness goals where applicable (e.g., mapping and filtering terminate producing a result). State and prove key theorems: that concatenation and subsequence behave consistently (extracting a subsequence from a concatenation yields expected results), that insertion followed by deletion at the same index is identity when indices match, that filtering preserves relative order of retained elements, that reversing twice yields the original sequence, and that stable sort preserves relative order of equal elements. Do not tie the specification to any particular implementation strategy.
