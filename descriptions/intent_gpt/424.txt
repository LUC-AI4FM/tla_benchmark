Specify a model of a distributed request-issuing system in which a fixed set of processors may asynchronously place read or write requests into per-processor queues, and a global partial order of issued requests is maintained. The model should describe the system state as the collection of each processor’s queue of requests and a set representing ordering relationships between issued request identifiers. The system must allow processors to append new requests to their own queues subject to a bounded-queue constraint (each processor’s queue length is limited). Each issued request must be given a unique identity that includes the issuing processor and the request’s position in that processor’s queue.

Require that the global request order be a strict partial order: transitive and irreflexive, and that it respect the local program order of each processor (if one request from the same processor appears earlier in that processor’s queue than another, the order must contain a relation from the earlier to the later request). The model should permit the global order to grow monotonically as new requests are issued (no removal of existing order relations), but it may add new relations consistent with the strict partial-order constraints.

State liveness only minimally: processors may nondeterministically issue requests while respecting the queue bound. Specify safety properties: type invariants on queues and order set, preservation of the bound on queue lengths, and invariants ensuring the global order remains a strict partial order and extends each processor’s program order.
