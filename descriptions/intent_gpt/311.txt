Specify a formal TLA+ model of a bounded binary search routine that operates on a fixed-length, finite array of integers and searches for a given target value. Model the algorithm at the level of states and transitions (not code), with state components representing the array, the current low and high search bounds, a termination flag, and the final return value. The model must allow arbitrary initial arrays of integers drawn from a bounded integer domain and a fixed target key. Define non-deterministic progress of the search loop that repeatedly narrows the search interval until it either finds the key or determines it is absent. Ensure the model captures comparisons with the middle element, the possibility of equality, and the updates that move either the low or the high bound while preserving bounds within the array indices.

Require these safety properties: (1) the algorithm never reads outside the valid index range; (2) once it announces termination the return value correctly indicates either an index where the array element equals the key or a distinguished value representing “not found”; (3) invariants relating low and high (e.g., low and high always remain within bounds and low ≤ high+1) hold throughout execution. Require liveness: the search must eventually terminate for any initial array and key. Include the ability to instantiate the model with concrete array length and integer bit-width to enable finite-state model checking.
