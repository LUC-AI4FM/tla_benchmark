Specify a model of a simple user-state management system for a fixed set of users. The system maintains, for each user, a state drawn from a small finite set of possible labels. Initially every user must be in a designated initial state. The system provides an operation that moves a single user from the initial state to a final/completed state; this operation may be applied to users independently and repeatedly until all users reach the completed state. The model must allow any ordering and interleaving of these per-user transitions, including the possibility that some users never transition.

Capture the following requirements and correctness properties:

- Initialization: every user in the given set has the initial label at the start.
- Transition semantics: a single user transition updates only that user’s label, leaving other users’ labels unchanged.
- Safety: no transition may assign an invalid label outside the defined finite set.
- Monotonicity/Progress invariant: once a user reaches the completed state, it cannot revert to the initial state or to any other state.
- Optional liveness property: if desired, express that eventually all users will reach the completed state under a fairness assumption that continuously enabled single-user transitions are eventually taken.

Model the system abstractly (user identity set and labels as parameters), and state the invariants and liveness properties to be checked.
