Specify a simple two-state cyclic controller that alternates between two operational modes and occasionally reaches a terminal "done" condition. The model should include an execution history that records past mode entries but must not grow without bound: the history will be used to express a resource constraint limiting how much past behavior can be remembered. The system must start in the first mode and on each step either switch to the other mode (recording the previous mode into the history) or remain in the other mode without appending to history, according to the allowed transitions. The model must allow infinite behaviors (liveness) but also support a safety constraint that the history length always stays below a fixed small bound. The specification must express a desired liveness property stating that eventually the system reaches a special terminal state. Additionally, include a checkable fairness or weak fairness constraint ensuring that if the switching action remains continuously enabled it will eventually occur, so that the liveness property is meaningful. Finally, make explicit the safety invariant (history length bound) and the temporal goal (eventual reachability of the terminal state).
