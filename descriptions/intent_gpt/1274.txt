Specify a concurrent/stateful system in which an initialization phase nondeterministically chooses a value for a single state component from a large finite domain using a potentially expensive computation, and thereafter the state remains stable. The model should represent the expensive choice as an abstract nondeterministic selection from a finite set, but the specification must emphasize that evaluating that choice may be costly in practice; the modeling must therefore avoid constructions that force repeated re-evaluation of the expensive selection during analysis. The system must show that after initialization completes exactly one value is assigned and that no subsequent steps change that value. Requirements: the initializer may select any element from the allowed domain; the chosen value must remain invariant for all future steps; there must be a clear separation between one-time initialization and steady-state stasis so that model-checking will not unnecessarily re-execute the expensive choice. Key correctness properties to guarantee: (1) existence of an initial assignment from the allowed set, (2) safety/invariance that the assigned value never changes, and (3) liveness that initialization occurs (i.e., the model does not allow skipping the initial assignment). The specification should be written to enable efficient model checking by representing expensive computation abstractly and ensuring it is evaluated only once.
