Model an asynchronous message-passing network between a fixed set of servers that nondeterministically delivers, reorders, duplicates, and drops messages according to one of four delivery guarantees: (1) point-to-point FIFO with no duplication, (2) point-to-point FIFO with possible duplication, (3) unordered delivery with no duplication, and (4) unordered delivery with possible duplication. The model should treat messages as first-class objects carrying at least source and destination, and should allow multiple in-flight messages between any pair of servers.

The specification must provide these operations: sending a message from one server (adds the message to the network), nondeterministic delivery of a message to its destination (removes the message from the network according to the guarantee), and nondeterministic loss/drop of messages. When duplication is allowed, sending or network actions may increase multiplicity; when no-duplication is required, each message instance must be unique in the network. When FIFO is required, per-destination-per-source delivery order must preserve send order; when reordering is allowed, any interleaving is permitted.

State the correctness properties to verify: safety properties that delivery preserves message identity/multiplicity constraints for each guarantee (no spontaneous creation when not permitted; multiplicity only increases via allowed actions), preservation of per-source FIFO order where required (a later message is never delivered before an earlier one from the same source to the same destination), and eventual delivery liveness assumptions (if desired, state optional guarantees such as weak fairness: sent messages are either eventually delivered or dropped). Also specify invariants for message set/bag consistency and that network actions never modify server-local state.
