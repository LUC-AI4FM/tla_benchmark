Model a library for dyadic rational arithmetic and normalization used by exact binary-fraction computations. The specification should treat dyadic rationals as pairs of an integer numerator and a power-of-two denominator; it must provide operations to halve a dyadic value repeatedly, to normalize equivalent representations (e.g., reduce 2/8 to 1/4 or represent canonical form with odd numerator when possible), and to compare dyadic values for equality and ordering. The model must ensure that halving is a deterministic, total function on dyadic rationals that preserves mathematical value (value(x) = value(Half(x)) / 2), and that repeated application of halving yields the expected sequence of values (for example, halving 1 yields 1/2, 1/4, 1/8, ...). It must also capture that halving a dyadic with an even numerator can produce an equivalent canonical representation with a smaller denominator (for example, halving a numerator 2 with denominator 8 results in the value represented by numerator 1 and denominator 8 after normalization). Correctness properties to check: value preservation under operations, idempotence of normalization (normalizing a canonical value yields the same canonical value), uniqueness of canonical representation (no two distinct canonical pairs represent the same value), and ordering consistency with real-number semantics. The model should enable checking these properties by exhaustive or symbolic exploration.
