Specify a model of a concurrent mutual-exclusion algorithm for N identical processes that implement a fast lock with bounded waiting and no deadlock. The model should describe processes that repeatedly alternate between a noncritical section and an attempt to enter a single critical section. The algorithm uses only shared atomic read/write registers (no built-in locks or atomic test-and-set); each process may write and read shared variables and may spin/wait until certain conditions on shared variables hold.

Requirements:
- Safety (mutual exclusion): At most one process may be in the critical section at any time.
- Progress/conditional liveness (no deadlock when there is contention): If some process is trying to enter the critical section (i.e., it is not in its noncritical state), then eventually some process will enter the critical section.
- Fairness: Individual process steps should not be permanently starved by the scheduler; assume weak fairness for the algorithmic steps that represent nonblocking progress points so the model can prove liveness properties.
- Bounded local resources: The algorithm must use only a constant number of local and shared scalar variables per process (no unbounded queues or counters that grow with time).
- Freedom from livelock under the fairness assumption: Under the specified fairness, every process that repeatedly attempts to enter the critical section will eventually succeed infinitely often.

Model goals:
- Capture concurrent interleaving and waiting on shared-variable conditions.
- Enable verification of the safety invariant and the liveness properties above for any fixed N > 0.
