Specify a formal TLA+ model of a library of finite-set utilities and their expected semantics. The model should describe pure mathematical operators on finite sets (no particular implementation details) that include: counting elements satisfying a predicate, selecting a unique element satisfying a predicate (with well-defined failure behavior when none exists), computing k-sized subsets of a set, set symmetric difference, sum and product of elements of numeric sets, folding/reducing over sets with an associative operator and a neutral element, flattening a set of sets by one level, and choosing an element from a set under a predicate. The model must support very small and very large finite domains (including domains beyond explicit enumeration) and should state expected results for representative examples (e.g., sums/products over ranges, behavior on empty sets, and behavior with duplicate literals in set notation). Key correctness properties to guarantee: the cardinality returned equals the size of the predicate-filtered set; k-subset operators enumerate exactly those subsets with cardinality k and produce empty set for impossible k; fold/reduce returns the standard reduction result and scales to large ranges without requiring intermediate explicit set construction; symmetric difference satisfies the usual algebraic identity; flatten removes exactly one nesting level; choose-unique returns the unique satisfying element and raises a well-defined error when none exists. Specify invariants and assertions that express these equalities and error conditions so they can be model-checked.
