Model a simple discrete-state counter system that repeatedly cycles through integer values 0..3, incrementing by one each step and wrapping to zero after reaching three. The model should describe only the abstract state (a single integer-valued counter) and the allowed state transitions (increment when less than three, otherwise reset to zero). Specify initial condition, the transition relation, and fair execution semantics so infinite behaviors are possible.

Specify and check the following temporal properties: (1) A progress/liveness property stating that it is always possible to eventually perform an increment step (i.e., infinitely often the system takes a transition that increases the counter by one when applicable). (2) A stronger property expressing that from some point onward every step is an increment step (i.e., eventually all steps satisfy the increment relation). Also specify safety properties: the counter never leaves the set {0,1,2,3} and every successor equals either the incremented value or zero as defined. Require explicit separation of safety versus liveness and make it possible to verify which of the temporal claims hold or fail under the given transition relation. Provide the model and properties so that model-checking can confirm the valid liveness and refute the impossible stronger liveness.
