Specify a model of a simple hour clock that continuously tracks the current hour of a 12-hour dial and supports atomic adjustments. The system must maintain a single integer state representing the displayed hour, constrained to the values 1..12. It must provide two kinds of externally visible atomic transitions: an automatic tick that advances the hour by one (wrapping from 12 back to 1), and an explicit set operation that assigns the clock to any valid hour value. Both transitions may occur nondeterministically and repeatedly; time should be modeled as discrete steps of these transitions. The model must forbid invalid hour values and ensure the display always remains within the valid range. Key correctness properties to assert: (1) Invariance: the hour is always between 1 and 12 inclusive. (2) Progress: from any reachable state, it is possible to eventually reach any target hour value via some finite sequence of transitions (the system is strongly connected over the 12-hour states). (3) Wrap-around correctness: a tick when at hour 12 yields hour 1. Additionally, the model should allow specifying an initial hour nondeterministically among valid values and expose the tick and set actions for temporal reasoning and model checking.
