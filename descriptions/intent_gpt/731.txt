Specify a simple bounded counter system that repeatedly increments a single integer value starting from zero, subject to an upper bound. The model should represent an infinite execution where in each step the counter increases by exactly one. The system must ensure the counter never reaches or exceeds a given strictly positive upper bound: all reachable states must satisfy the invariant that the counter value is less than the bound. Also require liveness that the counter continues to progress (no deadlock): from any state there is always a next increment step possible until the bound would be violated. Allow the bound to be a parameter (a nonnegative integer) so the same specification can be checked under different limits. The specification should capture initial condition, step relation, and the invariant constraint separately, and it should be possible to check both safety (the invariant never violated) and a simple progress property that increments keep occurring. Avoid committing to a particular implementation strategy; describe only the abstract state (a single integer), its allowed transitions (increment by one), the safety requirement (value < bound), and the intended liveness behavior (ongoing increments while the invariant holds).
