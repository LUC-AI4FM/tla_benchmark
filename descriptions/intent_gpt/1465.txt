Model a simple discrete-state system that maintains an integer-valued counter and an external trace recording the history of states. The model should describe an initial state and a single recurring step in which the counter monotonically increases by one, subject to an upper bound. The trace must always represent the complete sequence of past states up to and including the current state: its length must equal the current counter value, and each indexed element of the trace must reflect the counter value at that point in execution (i.e., the state at position i records the counter value i). The system must ensure the counter never exceeds a specified maximum and that every state transition appends the new state to the trace so the invariant on trace length and contents is preserved. Specify safety properties that assert the trace invariant and the numeric bound on the counter. Also include a simple liveness requirement that the counter can continue to make progress (increment) while below the bound. Do not commit to a particular representation of variables or implementation mechanism; focus on modeling the abstract state, the update relation, the trace-maintenance obligation, the numeric bound, and the required invariants and progress property.
