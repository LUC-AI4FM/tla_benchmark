Specify a distributed algorithm that assigns each node in a connected, undirected network a numeric depth value representing its distance in hops from a designated root node, and that ensures eventual global termination with these depths correct.

Model a network of fixed nodes and bidirectional communication channels where each node maintains a nonnegative integer depth estimate and can send messages containing depth information to neighbors. The network supports asynchronous message delivery and arbitrary message reordering, but no message loss. Nodes may update their parent pointer to a neighbor indicating the next hop toward the root. The root node must always have depth zero and never select a parent.

The system must guarantee:
- Safety: At all times, every node’s depth is a finite integer within a specified bound, and any message in transit carries a depth value no less than the sender’s current depth.
- Convergence (Termination): From any initial configuration, the algorithm must reach a quiescent state in which no node sends further messages and all message queues are empty.
- Correctness of depths: Once quiescent, every node’s depth equals the shortest-path distance (minimum number of hops) to the root, and parent pointers form shortest-path routes to the root.
- Progress assumption: The model may assume fairness of enabled actions to ensure eventual stabilization.

Include invariants to assert type correctness, message content constraints, and the above safety and liveness properties; state the postcondition tying final depths to graph distances.
