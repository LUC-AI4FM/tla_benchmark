Specify a formal model of a small, deterministic evaluator and updater for finite and simple infinite functions (total maps) that supports: function construction by explicit mapping, by tuples, and by lambda-like expressions over simple domains (e.g., Naturals, Strings); function application using either a single index or a tuple of indices; functional update expressions that override one or more entries of a function, including nested updates that modify entries of values that are themselves functions; and relative updates that refer to the previous value at a location (an “@+k” style increment) so that new values can be defined in terms of the old one.

Model the evaluator so it can compute the result of applying these functions to concrete indices and return the expected scalar or tuple values. Model the updater semantics so single and multiple EXCEPT-style overrides behave atomically and deterministically, including when updates target the same key multiple times or target nested fields. Ensure evaluation of maps created from explicit records (name→value) and tuples (position-indexed maps) is supported.

State correctness properties asserting that application returns the expected values for a comprehensive set of examples (e.g., numeric arithmetic, tuple projection, and nested function lookup), that updates produce the intended overrides (including nested and sequential-looking @-based modifications), and that conflicting multiple updates are resolved according to a deterministic rule. Also assert type invariants for domains and that the system is deterministic and total on the supported inputs.
