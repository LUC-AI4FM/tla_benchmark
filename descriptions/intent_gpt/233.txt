Model a simple stateful system with a single integer-valued state variable that evolves in discrete steps. The system must start from a specified initial integer value. At each step, the transition may increment the state by one if a predicate, provided externally to the transition rule, returns true on the current state; otherwise the state remains unchanged. The predicate should be considered a parameter of the system: allow substituting different predicate implementations without changing the transition definition. The system should capture both an internal default predicate and the ability to instantiate the system with an alternative predicate supplied from outside (so the same transition rule can be exercised with different predicate definitions).

Specify the safety property that the state always stays below a given upper bound that depends on which predicate is used (one bound when using the internal/default predicate; a possibly different bound when instantiated with an external predicate). Also specify the liveness property that, if the predicate is true perpetually from some point on, the state will eventually (in finitely many steps) exceed any smaller threshold less than the bound. Provide precise definitions of initial condition, transition relation, parameterization of the predicate, and the two correctness properties (safety and conditional progress).
