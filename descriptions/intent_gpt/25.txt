Specify a concurrent monitoring system that tracks a finite set of labeled resources and enforces an invariant about their availability. The system should model an initial configuration where a specific subset of resources is known to be present, and thereafter the set of monitored resources does not change (the configuration is stable). The model must express an invariant that, at all reachable times, the set of monitored resources is empty. The specification should capture states, an initial predicate describing the starting set of resources, a transition relation that permits only stuttering (no change to the resource set), and a safety property asserting emptiness of the resource set in every reachable state. Also require that the invariant is inductive: it holds initially and is preserved by every transition. The model must make explicit that the universe of possible resource identifiers is finite and known, and that the initial subset is chosen from that universe. Do not assume liveness obligations — the focus is purely on safety (the empty-set invariant) and stability of the system state.
