Model a library of total finite functions between sets and the common operations and predicates used to reason about them. The model should treat functions as finite mappings from a finite domain to values and provide operators to: restrict a function to a subset of its domain or to the domain elements whose images satisfy a predicate; compute the image (range) of a function or of a subset of its domain; apply a binary operator pointwise to two functions with compatible domains; compute an inverse mapping that maps values back to representative domain elements (and a special case returning the inverse on the whole range); and fold a commutative, associative binary operation over the values of a function (optionally restricted to a set of indices).

Specify predicates and sets to characterize injective, surjective, and bijective mappings between two sets, and predicates that assert existence of at least one injection, surjection, or bijection. Include an operator that checks whether one function is a restriction of another (domain subset and identical values where both defined).

The model must ensure these operators behave consistently with standard mathematical definitions: restrictions preserve values on kept domain elements; range and inverse are dual (inverse applied to the function’s range yields a left-inverse picking some preimage for each value); pointwise application only references indices common to the first function’s domain; fold is well-defined independent of evaluation order when the binary operator is associative and commutative. State the expected preconditions for each operator and the key correctness properties (e.g., range(Restrict(f,S)) ⊆ Range(f); composition of Inverse with original yields identity on the range up to choice; Injection implies |Range| = |Domain|, Surjection implies Range = target set).
