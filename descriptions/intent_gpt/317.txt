Specify a formal model of a deterministic binary-search algorithm that operates on an integer array and returns either the index of a target key or a distinguished “not found” value. The model should treat the input array and the search key as arbitrary but fixed at start, allow arbitrary finite integer array lengths, and assume array indices are standard 0-based positions. The system must begin with an initial state representing the array and key and variables representing the current low and high search bounds, a termination flag, a return value, and a step counter.

Model the search as a sequence of atomic, deterministic search steps that update the low/high bounds by comparing the middle element to the key, set the return value and termination flag when the key is found or when the search range is exhausted, and increment the step counter on each step. The model must ensure termination: every execution reaches a state with the termination flag true in a finite number of steps. When terminated, the return value must either be a valid index i such that array[i] equals the key, or a designated value indicating “not found”; no other return values are allowed. If the array contains multiple occurrences of the key, termination is allowed to return any one valid index. Additionally, guarantee invariants that low and high always remain within legal index bounds or the sentinel range denoting an empty interval, and that the algorithm never reads outside the array. Provide liveness and safety properties: safety asserts correctness of the returned index or “not found” result, and liveness asserts eventual termination for every initial array and key.
