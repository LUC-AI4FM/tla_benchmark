Specify a simple constant-checking configuration where a single state component must behave like an immutable constant value chosen at system instantiation. Model a system that has one value that is established at initialization and thereafter never changes. The specification should allow the value to be any element from an abstract domain supplied as a parameter at configuration time, but once the system starts that specific value is fixed for the entire execution. The model must capture initialization that assigns the chosen value to the state component and a transition relation that forbids any updates to that component. Express properties that assert: (1) the value equals the configured parameter in the initial state, and (2) the value remains equal to that same parameter in every reachable state (invariance). Also assert a safety property that the state component is constant across all steps (no step changes it) and a liveness-friendly form that every execution is either finite or respects the invariance indefinitely. Do not prescribe how the configuration parameter is made available, only require the model accept it and treat it as fixed for the run.
