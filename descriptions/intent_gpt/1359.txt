Specify a simple reactive system consisting of a single Boolean state that initially is false and can transition to true. The model should capture an environment of infinite time steps in which at each step the system either preserves its current state or makes the one allowed transition to true; once true it may remain true. The specification must include a safety property stating the initial value and the allowed state transitions, and it must include various liveness assumptions and obligations expressed separately so they can be combined in different ways: require that a particular transition relation is weakly fair with respect to the Boolean variable (i.e., if the transition is continuously enabled then it will eventually occur), allow composing that weak-fairness liveness assumption by conjunction, by universal quantification over a finite index set, and by reuse in multiple places. Also require variants where the same liveness condition appears both as an assumption and as an obligation so the modeler can explore redundancy and refinement relationships between liveness sets.

The correctness properties to guarantee are:
- Safety: the initial state is false and transitions do not violate the Boolean domain.
- Progress (liveness): when the weak-fairness condition is assumed, the system eventually reaches the true state under the fair scheduling of the transition.
- Composition: combining multiple identical or indexed liveness assumptions should not weaken the intended progress guarantee; the model should expose when redundant or overlapping liveness claims are equivalent or when they imply warnings about being improperly specified.
- Refinement: allow an abstract specification with only the safety and transition relation, and express a refinement check that the concrete spec with added liveness constraints implements the abstract spec.
