Model a small runtime that extracts a fixed-length subsequence from a sequence and uses it to make deterministic choices. The system accepts an input sequence of fixed finite length and must compute the subsequence consisting of a contiguous block of elements at a specified start position and of specified length. The model should allow different valid representations of input sequences (for example, sequences built by indexing over an integer range or by explicit tuple notation) and must treat equivalent inputs as equivalent when their element values agree at corresponding positions. Specify the extraction operation precisely and require that its result is independent of how the input sequence was constructed, depending only on element values and their positions.

The specification must also state that the extractor returns a subsequence of the requested length, preserves element order, and addresses out-of-range or invalid inputs deterministically (either by defining an error condition or by specifying behavior). Include correctness properties: (1) idempotence under identical input values — two syntactically different but value-equivalent inputs yield identical extracted subsequences; (2) bounds preservation — the indices of the returned subsequence are exactly the requested contiguous interval; and (3) stability — repeated extraction of the same interval yields the same result. Describe assumptions about input domain (finite sequences over naturals) and any preconditions required for the extraction to be well-defined.
