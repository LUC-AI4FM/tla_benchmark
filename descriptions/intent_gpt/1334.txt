Specify a formal model of a finite directed graph represented as a function that maps each vertex to exactly one outgoing neighbor (a functional digraph). The model should describe constructing and reasoning about cycles and paths in such graphs, supporting operations to (a) compute whether a given finite set of vertices forms a simple directed cycle under the function, (b) compute the image (range) of a function on a finite domain, (c) remove an element from a finite sequence and reason about resulting sequences, and (d) reduce/aggregate a range of function values with a binary associative operator (e.g., sum). The system must support finite sequences and finite sets, membership queries, and subsequence extraction.

Specify the correctness properties to guarantee:
- A predicate that characterizes exactly the simple cycles: for a set of vertices S and mapping f, S is a simple cycle iff every vertex in S has its f-successor also in S, f restricted to S is a permutation of S with a single cycle (no repeated vertices within the cycle), and the cycle length equals the cardinality of S.
- Range computation returns precisely the set of all images of domain elements.
- Sequence removal yields a sequence whose length is one less and whose elements are the original elements except the removed one in original order.
- Reduction over an index range produces the same result as repeatedly applying the associative operator to the specified subsequence, and is well-defined for an explicit base value.
Include invariants and termination conditions needed to prove the above properties for finite domains.
