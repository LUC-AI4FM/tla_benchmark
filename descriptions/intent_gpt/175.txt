Specify a simple discrete-state system of two integer-valued registers that alternate values on each step. The model should capture an initial state and a deterministic synchronous transition that swaps the contents of the two registers at each discrete time step. The specification must allow reasoning about reachability and invariants but should not rely on temporal operators embedded inside non-temporal Boolean expressions.

Require the following properties to be expressible and checkable:

- An explicit initial condition that sets concrete starting values for both registers.
- A deterministic state-transition relation that updates both registers simultaneously by swapping their current values.
- Safety properties: express invariants that must hold in every reachable state (for example, a relation fixing one register to a constant or relating the two registers), and ensure they are equivalent whether stated purely as state predicates or wrapped in a trivial time modality that does not change truth.
- Liveness or behavioral expectations: be able to state properties about eventual or persistent qualities without mixing temporal operators inside ordinary Boolean structure in a way that confuses semantics.
- Well-formedness: require that temporal properties are constructed using temporal logic at the top level (not nested within plain Boolean formulas) so that model checking or proof obligations treat temporal and non-temporal parts correctly.

The goal is to model the alternating-swap system and verify that intended invariants are preserved under the swap transition, and that the specification documents the separation between state predicates and temporal assertions.
