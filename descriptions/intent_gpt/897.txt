Specify a formal model of a shared-memory message-passing substrate used to implement a simple cache-coherent memory protocol. The model should represent an abstract internal message buffer that can hold at most one outstanding memory command and one outstanding reply (each message carries an originating processor identifier and an optional data value). The system must permit processors to issue Send commands that place a request into the buffer and to issue Reply commands that place a reply into the buffer, subject to the constraint that issuing a new message replaces the buffer’s previous contents for that channel (i.e., buffer holds a single value per channel). The initial state must have each buffer channel initialized to a well-defined default (a chosen processor id and a special NoVal payload). The model should not include low-level timing or network loss — messages are atomic updates to the buffer.

Require the following correctness properties:
- Safety: at all times the buffer contents are well-formed pairs (processor id, data-or-NoVal) and no illegal concurrent interleavings occur that would leave an inconsistent buffer.
- Invariant: issuing a Send or Reply must produce a deterministic new buffer value equal to the specified (processor id, data) pair.
- Liveness (weak): if a processor issues a Send (or Reply) and the system continues to run, then eventually the buffer reflects that message (no silent loss).
- Single-message containment: each buffer channel never contains more than one message.

Describe the model so it can be checked exhaustively for finite sets of processors and data values.
