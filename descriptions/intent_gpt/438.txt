Specify a simple state machine that models a single integer counter initialized to zero and able to evolve nondeterministically by a set of atomic update operations. The model should treat each update operation abstractly (no implementation details of how an operation is executed), and each operation must produce a new integer value based on the current value and a fixed argument (for example, 1). The system should allow any one of the defined update operations to be chosen at each step; operations may overlap in observable effect but must be distinguishable as separate choices in the specification.

Requirements:
- Initial state: the counter equals 0.
- At each step, exactly one of the allowed update operations is applied and the counter moves to the resulting integer value produced by that operation.
- All update operations must be total functions on integers: for every integer input and the fixed argument they must yield an integer result.
- The model must permit nondeterministic selection among operations, including the possibility that different operations yield the same numeric result.
- Safety properties: the counter must always be an integer and transitions must only occur by applying one of the defined operations.
- Liveness property: from any reachable state, it must always be possible to eventually perform some operation (no deadlock).
- The specification must be abstract so that various concrete definitions of the operations (e.g., addition, subtraction, identity) can be substituted and checked against the same safety and liveness properties.
