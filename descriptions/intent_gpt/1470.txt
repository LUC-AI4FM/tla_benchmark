Specify a TLA+ model of a simple discrete counter system that is initialized to 1 and repeatedly increments until reaching a specified upper bound. The model should capture the allowed states, the initial condition, and the atomic transition that increases the counter by one, terminating or becoming inapplicable once the counter reaches the bound. Include an observable action that records or exposes a human-readable message when a particular state is reached (for example, upon the first transition or at a designated initial value), without altering the counter semantics.

Require properties to be checked by model checking:

- Safety: the counter never decreases and always remains within the inclusive range from the initial value up to and including the upper bound; no transitions produce values outside this range.
- Liveness/progress: from the initial state there exists an execution reaching the designated midpoint value (e.g., the count 5) and eventually reaching the upper bound.
- Event occurrence counts: the model should allow querying or asserting how many times specific named actions or labels occur (for example, the label for the single-step increment and a label for reaching the midpoint), and these counts must match the expected values over the whole execution under the system’s transition rules.
- Determinism of transitions: each enabled transition must uniquely determine the next counter value (i.e., no nondeterministic choices that produce different successor counts).

Do not prescribe encoding details; focus on states, transitions, termination condition, observable messages, and the correctness properties to be verified.
