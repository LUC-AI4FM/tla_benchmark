Specify a model of a simple deterministic system whose state consists of four collections: a finite set of integers, a finite set of strings, a finite record mapping fixed string keys to sets of integers, and a finite set of total functions from a finite integer domain to a finite integer codomain. The system must start in a single, fully determined initial state: the integer-set equals {1,2,3}, the string-set equals {"a","b","c"}, each record field maps to the set {1,2,3}, and the set of functions contains exactly the total functions from {1,2,3} to {1,2,3} (or an explicitly equivalent characterization).

Model one atomic transition that leaves the three composite parts unchanged and updates the integer-set to a value equivalent to {1,2,3} (duplicates in a construction should be treated as set semantics so the resulting set equals the original). The model must be deterministic and have no other transitions.

Specify as correctness properties:
- Safety: an invariant asserting the state always equals the initial state (i.e., the four collections remain equal to the specified values) so that no reachable state differs from the initial one.
- Liveness: trivial termination or stuttering-freedom is acceptable, but the model must not introduce infinite progress that changes any of the three unchanged components.
- State uniqueness: the reachable-state space contains exactly one distinct state (the initial state), modulo set semantics.

Provide the model in a manner suitable for formal verification of these properties (model checking).
