Model a two-phase commit coordinator interacting with a fixed set of resource managers. The system initializes every resource manager in a working state. Each resource manager may move from working to prepared by indicating it is ready to commit. A commit decision for a given resource manager may be taken only when every resource manager is either prepared or already committed; when this condition holds, an individual resource manager may transition to committed. An abort decision for a given resource manager may be taken only if that resource manager is in working or prepared state and no resource manager has yet committed; when this condition holds, that resource manager may transition to aborted. The model should allow any resource manager to independently perform the prepare, commit, or abort steps subject to the global constraints above.

Specify the system so that executions are infinite sequences of state transitions starting from the initial configuration. Require and check the following safety properties: (1) no resource manager ever transitions from committed to any other state, and (2) no two conflicting global outcomes occur — once any resource manager commits, no resource manager can later abort. Also assert progress liveness conditions appropriate for two-phase commit: if all resource managers eventually prepare, then a commit decision should eventually be possible and taken; if some resource manager aborts while none have committed, the system may abort. The specification should permit reasoning about these properties for arbitrary finite nonempty sets of resource managers.
