Specify a model of a finite-state system whose state consists of several immutable collections: one set of three distinct integers, one set of three distinct strings, one record mapping three fixed string keys to identical sets of three integers, and one function (map) whose domain is a particular set of three integers and whose range is that same set of integers. The system should start in the single initial state in which those collections have the specified values.

Model a transition relation that can change only the integer set or only the string-set-to-int-record or only the integer-to-integer function in a single step, leaving the other components unchanged. Each allowed transition should be defined by a different but extensionally equivalent expression that yields the same target value (for example, different syntactic constructions that evaluate to the same set, sequence-derived sets, comprehension forms, or different representations of the same map). The purpose is to exercise equivalence of different expressions for the same collection value while preserving the intended extensional semantics.

State the correctness properties: (1) Invariance of the non-modified components when a single-component transition occurs, and (2) that all reachable states are extensionally identical to the initial state (i.e., there is exactly one distinct abstract state up to set/map/record equality). Also assert liveness/property coverage by ensuring each kind of transition is reachable so the model exercises each variation.
