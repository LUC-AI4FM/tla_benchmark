Specify a simple counter system that starts at 0 and repeatedly increments by 1, but is constrained never to exceed an upper bound (10). The model should represent discrete steps where each step increases the counter by exactly one, provided the resulting value would not violate the bound. The system should allow an unbounded sequence of such increment steps as long as the bound is respected.

Require the following correctness properties be checked:

- Safety: The counter value is never equal to a forbidden value (specifically, the value 2 must be detectable as a violation); in general the model must allow asserting and checking arbitrary single-value invariants about the counter.
- Bound preservation: Every increment step must preserve the invariant that the counter value is ≤ 10.
- Liveness/step availability: From any state with value < 10, an increment step must be permitted (the system should not deadlock before reaching the bound).
- Traceability: The specification should permit extraction of concrete counterexample traces showing the sequence of states and the action responsible for each transition when an invariant is violated.

Do not commit to internal representation choices; describe states as integer-valued counter snapshots and transitions as atomic increments by one subject to the bound. The model should be suitable for model checking and for producing counterexamples that record states and the names/locations of actions.
