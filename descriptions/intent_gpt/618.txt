Specify a formal TLA+ model of a round-based Byzantine-fault-tolerant consensus protocol in an asynchronous network with eventual synchrony (a Tendermint-style protocol). The model should represent a fixed set of processes, up to f Byzantine faulty processes, and rounds in which a designated proposer for each round broadcasts proposals. The protocol must allow processes to exchange three message types (proposal, prevote, precommit) and to maintain local state including current round, local step within the round, lock information (a locked value and the round it was locked), and a locally valid candidate value with the round that made it valid.

Model the normal-case and adversarial behaviors: correct processes follow protocol rules; Byzantine processes may send arbitrary messages. Network delivery is asynchronous but eventually delivers messages and allows for rounds to make observable progress. The model should include a rule for a correct process deciding a value only when receiving sufficient matching precommit support, and rules for updating locks and valid candidates based on received votes.

State the safety and liveness properties to verify:
- Safety: No two correct processes ever decide different non-null values (consensus safety, including preservation of locks).
- Validity: Any decided value must come from the set of valid proposals (e.g., proposed by a proposer and not an intrinsically invalid value).
- Agreement under f faults: If fewer than or equal to f processes are faulty and the network eventually synchronizes, then all correct processes eventually decide (termination / eventual consensus).

Also include invariants ensuring that lock and valid-candidate updates conform to vote quorums (i.e., decisions and lock changes require supermajority support), and allow parametrization of N and f, proposer rotation, and the set of legal values.
