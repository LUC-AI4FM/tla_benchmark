Model a simple specification that exercises basic set and sequence operations and verifies their expected outcomes. The model should define a system state with trivial, stable state (so the state does not evolve meaningfully) and include assertions that check elementary facts about finite sets, empty sets, set union, set intersection, set difference, subset relationships, and membership of sequences and tuples. Required checks include: union of overlapping integer sets produces the full combined set; intersection of overlapping sets yields exactly their common elements; intersection with the empty set yields the empty set (for both left and right operands); difference of a nonempty set with the empty set yields the original set; difference of the empty set with a nonempty set yields the empty set; and membership tests for a finite sequence being an element of appropriate sequence or function spaces. The specification must also include boolean-type typing of the trivial state variable and an invariant that always holds if all assertions succeed. The correctness properties are that all those set- and sequence-related assertions never fail during any reachable state, and the invariant is preserved by all transitions (the system being essentially stable). The model should be precise enough to catch any violation of the stated set/sequence laws.
