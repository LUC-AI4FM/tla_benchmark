Specify a formal model of a simple oracle-like component that provides a small fixed set of candidate deterministic mappings from a boolean input to an integer output, and a separate observable boolean flag that indicates whether a desired property has been discovered. The system should start in an initial state where the set of candidate mappings contains exactly one mapping: the function that maps true to a particular integer value (and implicitly defines no other mapping for false), and the flag is either true or false. No transitions change the state: the candidate set and the flag remain constant over time. The model must allow reasoning about membership: it must be possible to assert that the witness set contains that single function and to query whether the flag holds. Key correctness properties to check include (1) the invariant that the set of candidate mappings never changes, (2) the invariant that the flag remains a boolean, and (3) a safety property that when the flag is false, some named predicate "NotFound" holds. The specification should treat the set of mappings as a set of functions from booleans to integers and permit reasoning about equality and membership of such function-valued elements. The goal is to validate that the modeling language and model checker correctly handle sets whose elements are function values and that simple invariants about them are preserved.
