Specify a simple state machine that models a single integer-valued variable that can be repeatedly incremented by one. The system must allow an initial state where the integer is any natural number, and it must permit an action that increases the integer's value by exactly one while leaving nothing else changed. Ensure the model permits infinite execution sequences of repeated increments and also permits stuttering (steps that leave the value unchanged) if desired. State the allowed state space and transitions abstractly; do not prescribe implementation details such as specific control flow or program counters.

Require the following correctness properties be expressible and checkable:
- Safety: the value always remains a natural number (never becomes negative or non-integer).
- Monotonicity: every actual increment step strictly increases the value by one.
- No unintended jumps: there is no transition that changes the value by any amount other than 0 or +1.
- Liveness: from any reachable state, it is always possible to eventually perform another increment (i.e., increments are not permanently disabled).
Also include an invariant that bounds or relates values if a specific upper bound is provided, and allow both bounded and unbounded variants for model checking.
