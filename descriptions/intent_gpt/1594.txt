Specify a concurrent system in which a single repeatedly enabled process performs a bounded sequence of increment steps on a shared counter and must eventually terminate when the counter reaches a given bound. The model should expose the counter's integer value and a control state indicating whether the process is still looping or has finished. The process starts with the counter at zero and repeatedly performs an atomic action that increases the counter by one while it is strictly less than a specified positive bound N. Once the counter equals N, the process must stop taking increment actions and remain in the terminated control state forever (allowing stuttering). The specification must treat the loop as fairly scheduled: if the increment action remains continuously enabled it must eventually occur (weak fairness for the loop action). Required correctness properties to verify: (1) Safety — the counter never decreases and never exceeds the bound N; (2) Progress/Termination — eventually the process reaches the terminated control state (i.e., the loop cannot run forever when the counter is bounded); and (3) Liveness under fairness — under the chosen fairness assumption every enabled increment step is not perpetually ignored, ensuring eventual completion. Parameterize the model by the bound N so that different bounds can be checked.
