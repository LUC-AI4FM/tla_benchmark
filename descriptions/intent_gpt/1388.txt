Specify a simple state-transforming system that models an atomic operation which sets one register to a constant value while simultaneously resetting another register to zero. The model should represent two integer-valued storage locations that initially hold zero. The system must allow a single state transition that results in the first storage location taking a fixed constant (e.g., 42) and the second storage location becoming zero. Only that transition is permitted; after it occurs the state must remain stable. The specification should capture initial states, the allowed transition relation, and the notion of stuttering/unchanged variables so that no other spontaneous changes are allowed. Correctness properties to guarantee: (1) Safety — the only reachable states are the initial state and the state where the first location equals the constant and the second equals zero; (2) Invariance — once the final state with the constant is reached, both locations retain their values thereafter; (3) Liveness — the system may perform the transition (it is not deadlocked) unless already in the final state. Do not encode operational details of how the assignment is performed; specify only the state space, the permitted state change, and the required safety, invariance, and basic eventual-transition properties.
