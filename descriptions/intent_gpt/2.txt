Specify a model of a single cloud-backed key-value store and a set of clients that interact with it by alternating reads and writes. The store maintains a totally ordered sequence of committed values. Clients perform repeated read operations that request data according to a chosen consistency level, then perform a write that updates the store with a new value derived from the read. The read request should carry any client session metadata the store needs to satisfy session guarantees.

Model the communication between clients and the cloud as asynchronous, FIFO point-to-point message channels. Clients issue read requests tagged with one of several consistency choices (Eventual, Consistent Prefix, Session, Bounded Staleness with bounded lag K, and Strong). The cloud nondeterministically replies to a read by returning an element from the store that is permitted by the requested consistency semantics; for a write, the cloud appends the new value and acknowledges to the originating client. Clients update their local observed history and session metadata upon receiving replies, and increment an operation counter after each write. Allow indefinite interleaving of client and cloud steps.

Require the following correctness properties to be specified and checked:
- Safety of replies: every read reply contains a value that actually exists in the cloud’s committed sequence.
- Consistency-specific guarantees: each consistency mode must impose the appropriate constraint on which prefix element the cloud may return (e.g., Strong returns the latest element; Bounded Staleness returns an element within K of the latest; Session enforces monotonicity relative to the client’s session metadata; Consistent Prefix and Eventual restrict replies to some prefix/member of the committed sequence).
- Progress: every client read that is issued can eventually receive a reply, and every write is eventually acknowledged (given the asynchronous FIFO channels).
- Op-count termination: clients perform up to a specified maximum number of read-write operations.
