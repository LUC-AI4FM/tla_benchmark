Model a light-client detector for a blockchain that monitors validators for equivocation and liveness faults and produces evidence for peers when misbehavior is detected. The specification should capture multiple validator nodes with a bounded fraction of faulty nodes, a reference blockchain that advances over time, and a local client that maintains a small set of fetched block headers (light blocks) at various heights and a local clock that may drift relative to the reference clock. The detector must periodically attempt to verify higher target heights, check validator commit sets for equivocation (conflicting commits at the same height or at different heights within the trusting interval), and determine when a validator has been offline beyond the trusting period (liveness fault). When detection criteria are met, the detector must create evidence objects that include the conflicting light blocks or proof of prolonged absence, and expose them for relay to peers.

Correctness properties:
- Safety: Evidence must only be produced when it is valid: either two distinct signed commits by the same validator that contradict each other, or proof that a validator missed commits for longer than the trusted period computed using conservative clock drift bounds.
- Liveness: If a validator equivocates or is offline long enough (given the trusting period and bounded clock drift), the detector eventually produces corresponding evidence.
- Integrity: Evidence must reference authenticated light blocks consistent with the reference blockchain; the detector must not invent or accept blocks that cannot be justified by signatures from a quorum of validators.
- Monotonicity: Once a height is trusted (used as a base for detection), the detector should not regress to trusting a lower height.

Include parameters for trusted height, target height to inspect, trusting period, and both assumed and actual clock drift bounds. The model should allow nondeterministic message delivery, adversarial faulty validators within the allowed ratio, and show that the detector satisfies the above properties under these conditions.
