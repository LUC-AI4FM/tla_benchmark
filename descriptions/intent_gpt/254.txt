Specify a formal model of a library of mathematical function utilities and properties over finite sets and total functions between finite domains and codomains. The model should treat functions as maps from a finite source set to values and provide operators that: restrict a function to a subdomain; compute the range (image) of a function; construct a function from a set of pairs; compute an “anti-function” that swaps pairs (the inverse relation viewed as a function when defined); and fold/aggregate over a function’s values with a binary combiner. It should also support predicates and quantifiers to characterize injective, surjective, and bijective mappings, and provide existence predicates that state whether there exists an injection, surjection, or bijection between two finite sets.

The specification must state the intended semantics of each operator (total or partial where appropriate), and require the following correctness properties as invariants or theorems:
- Restriction yields exactly the mapping values on the specified subdomain.
- Range equals the set of all images of domain elements.
- The anti-function equals the inverse mapping when the original is injective on its range.
- Fold/aggregate returns the expected cumulative result over all values in the function’s domain, and folding restricted to an empty set yields the identity accumulator.
- The injective predicate is equivalent to the standard logical definition (distinct inputs map to distinct outputs).
- Membership predicates for Injection, Surjection, and Bijection match their mathematical definitions, and the existence predicates characterize when such mappings between two finite sets do or do not exist.

Include representative test instances: small concrete domains and codomains to exercise edge cases (empty domain, singleton, overlapping ranges, repeated values) and assert the above properties for those instances.
