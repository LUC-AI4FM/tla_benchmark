Specify a simple deterministic choice mechanism that selects a single value from a nonempty finite set and then remains constant forever. The model should represent a system that, at initialization, nondeterministically (but deterministically with respect to the requirement) chooses one element from a provided nonempty domain that satisfies a given predicate, and after that initial selection the chosen value never changes. The specification must require that a choice always exists when the domain is nonempty and the predicate holds for at least one element, and it must guarantee that once a value is selected it is immutable for all future steps. Formal correctness properties to assert include: (1) existence — at initialization the system yields some element from the domain that satisfies the predicate; (2) membership — the selected value is always an element of the original domain; (3) predicate preservation — the selected value always satisfies the predicate; and (4) stability — once selected the value never changes in any subsequent state. Allow the domain and predicate to be parameters so the same model can be instantiated with different finite domains and predicates.
