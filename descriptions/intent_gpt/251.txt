Specify a formal model of a multiset (bag) library and its core operations and predicates. The model should treat a bag as a finite mapping from elements to nonnegative integer multiplicities and must support creating single-element bags, the empty bag, and converting between sets and bags. It must define the following operations and queries and state their intended behavior:

- Constructions: create a bag with a given element and multiplicity; construct the empty bag; convert a set into the corresponding bag with multiplicity 1 for each element; obtain the set of elements present in a bag.
- Membership and counts: predicate that tests whether an element occurs in a bag; function returning the multiplicity (copies) of an element in a bag.
- Algebraic operations: bag addition (union-with-sum of multiplicities), bag subtraction (difference with nonnegative result), and a bag-union-over-collection operation that combines a set of bags by summing multiplicities per element.
- Relations: a subbag relation that requires every element’s multiplicity in one bag to be ≤ its multiplicity in another.
- Mapping: apply a function to all elements of a bag to produce a new bag, specifying behavior for injective and non-injective functions.
- Aggregates: compute the cardinality (total count of elements, i.e., sum of multiplicities).

State and prove key correctness properties: single-element and empty-bag constructions yield expected membership and multiplicity; set-to-bag and bag-to-set are consistent; addition and subtraction are commutative where appropriate and yield correct multiplicities; bag-union over many bags sums multiplicities by element; subbag relation properties (reflexivity, non-symmetry as appropriate); mapping preserves multiplicities under injective maps and accumulates multiplicities under collisions; cardinality equals the sum of multiplicities and respects addition and subtraction behavior. Ensure all multiplicities remain nonnegative and domains are finite.
