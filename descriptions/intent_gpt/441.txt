Specify a simple two-variable state machine that alternately updates one variable while leaving the other unchanged, and reason about which state transitions are enabled and what liveness must hold.

Model a system with two integer-valued state components that initially are equal to zero. One component is toggled between 0 and 1 on each step; the other remains unchanged by that same step. The system should nondeterministically allow any step that satisfies those constraints. Specify the safety behavior that all executions must start from the given initial state and thereafter each step must perform the described toggle on the first component while preserving the second. Also specify a strong fairness or weak fairness condition (as appropriate) that forces actual steps to occur so enabled actions do not remain perpetually disabled.

State the properties to be verified:
- Which elementary transitions are enabled in a given state (for example, characterize when a transition that would set the first component to 0 and the second to 1 is enabled).
- A safety invariant: reachable states must satisfy the relationship between the two components imposed by the update rule and initial condition.
- A liveness requirement: the system must ensure progress under the chosen fairness assumption (i.e., if an action is continuously enabled then it eventually occurs).
- A refinement or implication assertion relating the predicate “a specific combined assignment is enabled” to the existence of an enabled action under the model.
