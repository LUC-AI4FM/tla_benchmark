Specify a model of a graph state-space explorer that searches a directed state graph to detect safety violations or dead ends and, when found, produces a concrete path (counterexample) from an initial state to the offending state. The model should treat the set of graph states and the transition relation abstractly: the graph is given by a finite set of states, a designated subset of initial states, and a successor function that maps every state to a set of next states.

The explorer must maintain an explicit notion of which states have been discovered and which remain to be explored (a frontier), allow nondeterministic choice of which frontier state to expand next (no enforced BFS ordering), and record a spanning relation that associates every newly discovered state with a predecessor so that full paths can be reconstructed. Exploration of a state must add all of its previously unvisited successors to the frontier and record predecessor links; if a state has no successors, that must be detected as a dead end.

The model must detect two stopping conditions: reaching a state that belongs to a designated set of violation states, and reaching a dead-end state. Upon detecting either, it must mark exploration as finished and construct a finite sequence of states representing a path from some initial state to the detected state by following predecessor links backward. Key correctness properties to specify and prove are: safety (if a constructed counterexample ends in a violation or dead end, every adjacent pair in the path is a valid transition in the graph and the first state is initial), liveness (if any violation state exists then eventually a violation is found and a valid counterexample produced), and termination (the procedure eventually halts when either a violation is found or the frontier and pending successors are exhausted). Also require that the explorer never revisits a state as “unvisited” after it has been marked discovered.
