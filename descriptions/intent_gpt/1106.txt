Model a distributed algorithm that constructs a spanning tree over a fixed undirected network of processes. The system should start with a designated root process and other processes with no parent. Processes communicate by exchanging messages along network links. The algorithm must elect parent pointers so that, when it stabilizes, every process except the root has a parent that is one of its neighbors, the root has no parent, and the parent pointers form a connected, acyclic structure (a tree) spanning exactly the set of processes. The protocol should tolerate asynchronous message delivery but assume reliable channels (no message loss or duplication). Processes may concurrently send and receive messages; they can update their parent choices based only on local state and messages from neighbors.

Specify liveness and safety properties: safety guarantees that no two processes will have parents that create a cycle and that every parent pointer is always a neighbor; once stabilized the parent relation is a spanning tree rooted at the designated root. Liveness guarantees eventual convergence: from any reachable state, the system eventually reaches a stable configuration in which no further parent changes occur and the spanning-tree property holds. Also require that messages eventually quiesce (no infinite message generation after stabilization). Describe initial conditions, permitted message types abstractly, and the correctness invariants above—do not prescribe a particular protocol implementation.
