Model a simple two-variable state machine that repeatedly updates two integer-valued registers according to nondeterministic choices. The system starts with both registers equal to zero and repeatedly executes an atomic state-transition that must satisfy one of two alternatives each step: (1) swap the current values of the two registers, or (2) set the first register to the constant 1 while allowing the second register to be any value satisfying a designated predicate that recognizes the integer 2. The model should allow the nondeterministic resolution of which alternative is taken at each step and should not constrain the order of these choices beyond atomicity.

Specify the state space, initial condition, and the transition relation precisely enough to enable model checking. Require that all reachable states are well-defined integers. State the following correctness properties to be checked by the model checker: safety (no invariant violations) that the registers always remain integers; preservation of swap semantics when the swap action is taken (i.e., after a swap the two registers have exchanged their previous values); and that whenever the second alternative is chosen the first register becomes 1 and the second register satisfies the predicate for value 2. Also state liveness requirements: the system should be able to continue executing transitions indefinitely (no deadlock), and it should be possible to eventually perform each kind of action from some reachable state.
