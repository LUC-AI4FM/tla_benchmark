Specify a concurrent state machine that models a simple system with two integer-valued state components: one component representing a bounded counter that starts within a small positive range, and the other representing a flag or secondary value initialized to zero. The system should allow nondeterministic transitions that (a) increment the counter, (b) leave the counter unchanged while performing side-conditions that do not affect the secondary component, (c) set the counter to a specific distinguished constant and simultaneously change the secondary component to Boolean values, and (d) decrease the counter nondeterministically within a bounded range. Include transitions that are deliberately inert (no-op) to model spurious or unreachable branches. The model must enforce an invariant that both state components remain natural numbers throughout execution, and an additional global numeric constraint that keeps the counter strictly below a specified upper bound. Also require a more expensive, purely logical invariant that quantifies over finite sets or ranges to exercise model-checking of quantified properties (for example, universal quantification over subsets or ranges with membership/element constraints). Specify the initial condition, the global next-state relation combining the transitions, and a liveness or safety specification stating that every step must satisfy the defined next-state relation and the global constraint holds invariantly. The specification should not commit to a particular implementation strategy, only to the allowed state space, transitions, and correctness properties.
