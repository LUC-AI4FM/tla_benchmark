Specify a formal model of reachability in a finite directed graph. The model should describe what a directed graph is, what it means for a path to exist between two nodes, and what nodes are reachable from a given set of start nodes. The model must allow arbitrary finite sets of nodes and arbitrary adjacency information (successor relation) but must not commit to any particular internal representation. It must define a path as a nonempty finite sequence of nodes in which each consecutive pair is connected by a directed edge in the graph, and it must define the existence of a path from one node to another exactly when such a sequence exists. It must define the reachable-from operator that maps any set of start nodes to the set of all nodes reachable from some start node (including the start nodes themselves). Key correctness properties to guarantee: (1) Reflexivity: every start node is reachable from itself. (2) Transitive closure: if a node y is reachable from x and z is reachable from y, then z is reachable from x. (3) Soundness with respect to edges: if there is a direct edge from x to y, then y is reachable from x. (4) Finiteness: for finite graphs, reachable sets are finite. Additionally require invariance under equivalent representations of adjacency (e.g., edge-set vs. successor-function): the reachable-set must be representation-independent.
