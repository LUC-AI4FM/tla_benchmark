Specify a simple state machine that models a single integer-valued variable that starts at a specific negative value and repeatedly decrements until it reaches a fixed cutoff, after which it remains unchanged. The model should allow the variable to take any integer value consistent with those rules and should treat arithmetic according to standard integer semantics (including negative values). The system must include an initial condition that sets the variable to the chosen starting negative integer and a transition relation that either decreases the variable by one or leaves it unchanged once the cutoff value is reached. Capture the property that the variable never increases and that once the cutoff is reached it becomes and stays equal to that cutoff forever. Also state obvious invariants such as the variable always being an integer and always being at most its initial value. Formally express liveness so that from the initial state the system eventually reaches the cutoff value (or, if liveness is not desired, state that only safety properties are required). Do not commit to a particular implementation style; focus on the abstract behavior and the safety and (optionally) liveness guarantees.
