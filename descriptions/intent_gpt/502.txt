Specify a formal TLA+ model of a multi-decree Paxos-based replicated state machine in which every replica can act as proposer, acceptor, and learner. The model should support an unbounded sequence of independent slots (commands/consensus instances) and a finite set of replicas, ballots, and possible values. It must capture the two-phase Paxos pattern at a per-slot level but allow a proposer to aggregate the prepare phase across many slots (i.e., a prepare can be used to cover multiple future slots rather than only one). Model asynchronous message-passing between replicas with messages for Prepare, PrepareReply (carrying prior votes), Accept, AcceptReply, and local decisions (learns). Include local state that tracks leader ballot numbers, acceptor promised ballot, acceptor-voted value and ballot per slot, and per-replica proposal/learn status for each slot.

The specification must guarantee safety properties: (1) Agreement — at most one value can be chosen for any slot (no two different values can both become chosen), and (2) Integrity — any chosen value must have been proposed by some replica. It should also express quorum-based invariants: a value can be safely proposed for a slot only when a proposer collects replies from a majority that justify selecting that value (respecting highest prior votes), and a majority of acceptors is required to decide. Do not assume synchrony or lossless delivery; model messages being buffered and delivered nondeterministically. Include assertions or invariants that capture majority quorums and ballot monotonicity (promises never decrease).
