Specify a formal model of a simple iterative exponentiation routine that computes the nth power of an integer base. The model should describe a system that accepts as inputs a base and an exponent drawn from given domains (a set of integers for bases and a set of natural numbers for exponents), and then iteratively computes the product of the base multiplied by itself n times. The specification must not commit to a particular implementation technique (e.g., it may be implemented as a loop, recursion, or repeated multiplication), but must capture the observable behavior: starting from an initial product value equal to the multiplicative identity, repeatedly update the product until the number of multiplications performed equals the exponent, at which point the computation halts and produces a result.

Require the following correctness properties:
- Partial-correctness: if the algorithm terminates with result R for inputs (base, exponent), then R equals base^exponent.
- Safety of inputs: the base must be an integer and the exponent must be a natural number drawn from the allowed domains throughout the computation.
- Progress/termination: for each valid input pair the algorithm eventually completes the finite sequence of multiplications and reaches the halted state (termination).
- No unintended state corruption: inputs remain unchanged by the computation and the count of multiplications monotonically increases from zero up to the exponent.

Also state invariants to support proofs: the product at any intermediate step equals base raised to the power of the number of performed multiplications, and the number of performed multiplications never exceeds the exponent.
