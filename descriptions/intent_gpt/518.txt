Specify a formal TLA+ model of the Alternating Bit Protocol (ABP) for reliable, in-order delivery of a sequence of data items over an unreliable, lossy channel. The model should represent a sender, a receiver, and an unreliable network that may drop messages arbitrarily but does not corrupt message contents. The sender repeatedly sends data messages tagged with a single-bit sequence number and retransmits as needed; the receiver acknowledges correctly received messages by returning the corresponding bit. The receiver must accept each data item at most once and in the original order, and the sender must eventually advance to the next data item only after receiving acknowledgement of the current one (modulo possible losses). Model the network as two unbounded FIFO message queues (sender→receiver and receiver→sender), with nondeterministic loss of any queued message. Do not include timing assumptions or fair scheduling of message delivery; liveness can be optional, but safety properties are required.

Required correctness properties:
- Safety: The receiver never delivers duplicate data items; it never delivers data out of original send order.
- Consistency: The receiver's delivered data sequence is a subsequence of data values the sender attempted to transmit, preserving original order.
- Agreement between bits and messages: acknowledgements correspond to the sequence numbers of messages actually acknowledged; a delivered data item must have been sent with the matching bit.
- No silent corruption: data payloads and sequence bits do not change during transit.

Optionally, also specify liveness properties under reasonable fairness assumptions (e.g., eventual delivery if the network eventually stops losing messages, and sender eventually progresses).
