Specify a model of a simple growing set accumulator over a finite universe of positive integers {1..N}. The system repeatedly adds one element from the universe that is not yet in the set; when an element is added, an associated integer accumulator is increased by that element's value. Model only the abstract behavior: a state contains the current subset of the universe and the current integer accumulator. Initially the subset is empty and the accumulator is zero. A single atomic operation chooses any element from the universe that is not yet present in the subset, adds that element to the subset, and increases the accumulator by the value of that element.

Require that every execution be finite or potentially terminate when no unseen elements remain (i.e., no further additions are enabled when the subset equals the whole universe). Specify the key correctness properties:
- Functional consistency: at every reachable state the accumulator equals the sum of the elements present in the subset.
- Safety: the accumulator never over- or under-counts relative to the subset.
- Progress/termination expectations: additions are possible until the subset is the full universe; optionally show that if the system continues to take enabled additions it will eventually reach the full set.

Also include the usual invariants and assertions needed to verify the consistency property and make clear the finite-domain assumption (a fixed positive integer N).
