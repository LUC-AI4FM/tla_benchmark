Specify a simple state machine that maintains a single integer-valued state variable and models its allowed evolutions. The system must start in a defined initial state (a specific integer). At each step it may either leave the state unchanged or perform a state transition that assigns a particular constant integer value to the variable. The model should permit the transition only when the transition’s enabling condition is false (i.e., the transition should not rely on any positive enabling predicate elsewhere); the transition’s effect is simply to set the state to a fixed constant. The specification should treat the transition and the stuttering step as the only possible moves.

State the invariant properties that must always hold: the state is always an integer, and when the state differs from the initial value it must equal the fixed constant assigned by the transition. Also assert liveness properties ruling out infinite refusal to take the transition if it is ever required: if the system can forever refrain from changing, that behavior should be recognized, but any execution that does change must end in the fixed constant. Formally express initial condition, transition relation, type invariant, and the postcondition that any non-initial state equals the transition constant.
