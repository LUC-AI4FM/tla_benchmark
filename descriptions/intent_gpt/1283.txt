Specify a system that nondeterministically picks elements from finite sets and computes a dependent value, ensuring the computation is well-defined and stable across state transitions. The model should represent two stages: first initializing a large finite set of integers and choosing an element from it according to a numeric predicate; and then replacing that set with a different finite collection of integer subsets and choosing one subset that satisfies a predicate based on the sum of its elements.

The specification must capture the following behavior and requirements without fixing a particular algorithm:

- Stage A: initialize a finite set of distinct integers drawn from a given range; then choose some element from that set that satisfies a predicate expressed in terms of the element’s numeric value (for example, exceeding a threshold).
- Stage B: replace the current data with a finite collection of finite integer subsets (e.g., the power set of a smaller range); then choose one subset from that collection that satisfies a predicate expressed in terms of an aggregate of the subset (for example, the sum of elements exceeding a threshold).
- The system must model nondeterministic choice whenever multiple candidates satisfy a predicate, and must permit the chosen value to be undefined when no candidate exists.
- The choices must be deterministic in the sense of being a single selected value per stage (no simultaneous multiple choices).
- The spec must assert safety properties: each chosen value indeed belongs to the source set and satisfies the corresponding predicate; and liveness: the system progresses from Stage A to Stage B and terminates thereafter.
- Key invariants to check include membership and predicate satisfaction for chosen items, and that the stage progression happens exactly once.
