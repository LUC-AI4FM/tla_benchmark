Specify a simple state machine whose state includes a single boolean flag that is initialized true and never changes. The model is intended to exercise and validate boolean, numeric, and conditional expression semantics; it should evaluate nested if-then-else and multi-branch case-style expressions and assert that their computed results meet expected values. The system must compute a sequence of independent checks (pure expressions, not transitions) and for each check either record success or signal a violation if the computed expression does not equal the expected constant or set membership. The model should include checks that exercise: nested conditional expressions where branches themselves contain conditionals; multi-branch selection where some branches are unreachable; combinations of boolean operators (and, or, not) with contradictory and tautological clauses; and comparisons mixing different literal types to ensure type-related inequalities behave as expected. Correctness properties: every asserted check must hold in the initial state (i.e., no assertion fails), and no reachable state should violate any of these assertions. Additionally, the specification should make the checks observable (e.g., by reporting which checks passed) so that failures are identifiable. Do not constrain the design to any particular implementation of conditionals or printing; focus on the logical outcomes of the expressions.
