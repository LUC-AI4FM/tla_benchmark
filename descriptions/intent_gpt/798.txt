Specify a model of an algorithm that scans a finite, nonempty sequence of natural numbers and computes the maximum value in that sequence. The model should describe a procedure that reads the sequence elements one by one in a single pass, maintains a variable representing the current candidate for the maximum, and advances an index until every element has been inspected. The procedure must allow an initially empty-looking candidate (a sentinel) and update it whenever a larger element is observed. The model must terminate when the index has passed the last element and then expose the computed maximum.

Require the following correctness properties to be proved as invariants or theorems of the specification:
- Type/Domain invariants: the input is always a finite sequence of natural numbers, the index always ranges from 1 to length+1 during execution, and the candidate maximum is always either a natural number or the sentinel.
- Inductive invariant: after inspecting k elements, the candidate is at least as large as every element among the first k inspected elements.
- Termination property: the scan finishes (index reaches length+1) eventually.
- Postcondition (functional correctness): upon termination, the candidate is greater than or equal to every element of the input sequence (i.e., it is a valid maximum). Also state any necessary lemmas that relate the index at termination to having examined all elements.

Do not commit to a particular programming-language encoding; describe only states, the allowed single-step transitions that advance the index and possibly update the candidate, and the invariants and liveness properties to be established.
