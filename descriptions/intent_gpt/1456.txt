Specify a state-transition system that models a mutable subset drawn from a fixed finite universe of three elements, together with an immutable record of that universe. The system should initialize with the subset constrained to be contained in a proper subcollection (not necessarily empty) and with the universe set to the three-element set. Each step may change the subset but must not change the universe. Transitions should permit any next subset that is a subset of the universe, regardless of the current subset, but must allow reasoning about whether particular elements are gained. The specification must allow expressing and checking the following correctness properties:

- Safety: the subset is always a subset of the universe.
- Invariance of the universe: the universe value never changes.
- Reachability of a full set: whether it is possible to reach the state where the subset equals the full universe.
- Existence of a transition that adds a particular element (e.g., element 3): it must be possible in some step to go from a state not containing that element to a state that does.

Provide assertions or invariants that capture these properties and support model checking of counts of reachable states and transitions that satisfy named predicates (e.g., “full set reached”, “element gained”). The description should not prescribe an implementation strategy, only the required state space, allowed transitions, initial constraints, and the correctness properties to verify.
