Specify a system that computes the set of nodes reachable from a designated root in a directed graph. Model an algorithm that progressively discovers reachable nodes using two collections: one representing nodes already acknowledged as discovered and one representing pending nodes to process. The system must begin with the discovered set empty and the pending set containing only the root. Repeatedly, while the pending set is nonempty, choose a node from the pending set and either (a) if that node has not yet been acknowledged, acknowledge it and add all of its immediate successors to the pending set, or (b) if it is already acknowledged, remove it from the pending set. Termination should occur when the pending set is empty.

Require the model to guarantee the following correctness properties:
- Safety (partial correctness): if the algorithm terminates, the acknowledged set equals exactly the set of nodes reachable from the root.
- Invariants: the discovered and pending sets are always subsets of the graph's node set; every successor of an acknowledged node is either acknowledged or pending; and the union of acknowledged nodes with the set of nodes reachable from the pending set always equals the set reachable from the union of acknowledged and pending nodes. These invariants should imply the partial correctness claim.
- Liveness (termination): if the set of nodes reachable from the root is finite, the algorithm eventually terminates (under weak fairness of the processing step).

Also require type constraints on state components and that termination is represented explicitly so model checking and reasoning about invariants and liveness can be carried out.
