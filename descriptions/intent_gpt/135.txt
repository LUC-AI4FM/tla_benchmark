Specify a formal model of finite functions between finite sets and basic operations and predicates over them. The model should treat a function as a total mapping from a finite source set to values in a finite target set, and support computing the image (range) of a function, restricting a function to a subset of its domain, and producing an inverse mapping on a specified target set (choosing some preimage when multiple exist). It must define and characterize injective, surjective, and bijective mappings between sets, and must provide predicates that test existence of an injection, surjection, or bijection between two given finite sets.

Requirements:
- Represent domains and codomains as finite sets; functions are mappings from a domain to values in the codomain.
- Provide an operator to restrict a function to a subset of its domain; the restricted mapping should be defined only on that subset and preserve original values.
- Provide an operator to compute the range/image of a function (the set of values actually produced).
- Provide an operator that, given a function and two sets S and T, returns for each element of T either an element of S that maps to it (if any) or a well-defined chosen value otherwise; the behavior for elements with no preimage must be deterministic.
- Define predicates for injectivity, surjectivity, and bijectivity in clear mathematical terms.
- Define predicates that state whether at least one injection, surjection, or bijection exists between two sets.
- Specify invariants and type constraints ensuring domains, codomains, and returned values remain finite sets and functions preserve typing.
- Assert correctness properties: restriction preserves values on the subset, range equals image of domain, inverse mapping returns preimages when they exist, and the predicates correctly classify mappings.

Do not prescribe a particular implementation strategy; focus on the abstract operators and correctness properties to be verified.
