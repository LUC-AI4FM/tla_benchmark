Specify a simple data-structure and its observable behavior where there is a fixed global constant value and an operation that pairs that constant with an arbitrary input to produce a two-element tuple. The model should include: a constant parameter whose value does not change over time; a data constructor operation that, given any input element from a specified domain, returns an ordered pair whose first component is the constant and whose second component is the input; and a requirement that the constructor is pure (it has no side effects and does not modify any state). The specification should allow multiple independent uses of the constructor with different inputs and treat its results as immutable values. Key correctness properties to verify: (1) For every input in the allowed domain, the constructor returns a pair whose first component is equal to the global constant and whose second component equals the input; (2) Equality and identity of constructed pairs behave as expected (pairs are equal iff both components are equal); (3) The constant remains unchanged across all operations; and (4) The constructor does not create hidden state or non-determinism beyond that arising from choosing the input.
