Specify a small deterministic decision function that maps a single symbolic input value drawn from an enumerated domain to a boolean output according to these rules: when the input matches a distinguished, explicitly listed sentinel case, the function must yield false; for every other input value in the domain, the function must yield true. Model the input domain as a finite, nonempty set whose members include at least one distinguished sentinel element and at least one other element. The system should compute the output for any given input without side effects or state changes beyond returning the boolean result.

The specification must include a formal statement of the function's totality (it is defined for every element of the domain) and determinism (the same input always produces the same output). It must assert the two correctness properties: (1) the sentinel-case property — the output is false exactly when the input equals the distinguished sentinel; and (2) the default-case property — the output is true for every input not equal to the sentinel. Also require simple invariants that rule out undefined or nondeterministic results and show that the mapping is a projection to Bool. Finally, include sanity checks that the domain actually contains more than one element so the "other" behavior is exercised.
