Specify a distributed consensus-style protocol for N processes that repeatedly attempt to choose values from a finite set of possible inputs. The system must model an environment in which each process always has an input value (drawn from a given set of Inputs) and an output slot that may either hold a chosen value or indicate “no decision yet.” The protocol should allow processes to do two kinds of steps: (1) decide (or adopt) a value for its output, either by proposing a previously unchosen input from among the inputs present in the system or by adopting a value that was already globally chosen by a prior decide step; and (2) fail or reset its own output and change its current input value nondeterministically to any value in Inputs, thereby possibly introducing new inputs into the set of values seen by processes.

Model the global auxiliary notion of the set of all input values currently present among processes; that set must evolve whenever a process changes its input. Initially every process has some input value and every output slot is undecided (no decision made), and no global chosen value yet exists.

The specification must capture fairness-free nondeterministic execution (actions can be chosen arbitrarily) and require the following correctness properties:
- Safety (Agreement): if two processes have decided (their outputs are set to a concrete value), they must have the same decided value.
- Validity: any value that ever becomes a decided output must be a value that has been present as some process’s input at some point.
- Stability of chosen value: once a global chosen value exists, future decisions by other processes may adopt that same value but cannot introduce a different globally adopted value.
- Liveness variant (optional): characterize how failures and input changes can prevent progress; state whether eventual decisions for all non-failing processes are required or left unspecified.

Do not prescribe implementation details such as particular variables, choice operators, or step-by-step algorithms; describe only the allowed state components and the invariant and temporal properties the model must enforce.
