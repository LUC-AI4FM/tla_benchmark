Specify a formal model of a small library of functional collection utilities and their expected semantics when applied to finite sets, functions, and sequences. The model should describe pure, deterministic operators that transform collections by repeatedly folding an operation over the elements of a finite domain or index set. The utilities to be specified are: (1) constructing a set by iteratively adding each element of a given finite set, (2) producing a new function by iteratively updating each argument in the domain according to a simple rule, (3) building a function from a finite set by iteratively extending an initially empty function with a mapping computed from each element, and (4) building a sequence by iteratively appending values obtained from a total function on an index range. The model must state the expected result of each utility in plain mathematical terms (for example: the reconstructed set equals the original set; the updated function maps each domain element to its original value plus one; the built function equals the comprehension mapping each element to the computed value; the constructed sequence equals the canonical sequence of values over the index range). Include the assumptions about the domain (finite index range 1..N for a positive integer constant N) and totality of any functions used. Specify safety invariants asserting that the utilities always produce the mathematically equivalent results, and require determinism and termination of the fold-based procedures on finite inputs.
