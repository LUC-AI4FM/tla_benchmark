Specify a simple sequential conditional-control program that reads an input value from a fixed finite domain {1,2,3,4}, evaluates nested conditional branches based on that value, executes an associated check in each branch, and then proceeds to termination. The model should treat the input value as immutable during execution. The control flow must choose one of four mutually exclusive branch paths determined by the input: two branches when the value is less than 3 (distinguishing value 1 and 2), and two branches when the value is at least 3 (distinguishing value 3 and 4). In each taken branch the system must perform a local boolean assertion that must hold for the corresponding input value; if the assertion would fail, the execution should be considered an assertion violation. After performing the branch-specific check the system must continue to a common final step that performs an observable action (for example, a print) and then reaches a terminal state. The specification must guarantee that for every allowed initial input value the execution eventually reaches the terminal state without deadlock, unless an assertion fails, and must capture fairness so that internal stuttering does not prevent termination. Key correctness properties to assert: (1) mutual exclusion of branch choices (exactly one branch taken per input), (2) each branch's assertion holds for the corresponding input, and (3) eventual termination (liveness) to the terminal state for all valid inputs that satisfy assertions.
