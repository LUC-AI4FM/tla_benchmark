Specify a formal model of a typed sum/value-tagged union (variant) abstraction and a small, trivial system that uses it, to exercise and verify basic operations on variants. The model should capture: creation of variant values carrying a tag and an associated payload; a notion of variant subtyping or membership in a set of variants; filtering/selecting variants by tag from a collection; retrieving the tag string of a variant; unsafe extraction of a payload when the caller asserts the tag (with only a type-level guarantee); a safe get-with-default operation that returns a provided default when the tag does not match.

Require the model to expose the following behaviors and correctness properties as invariants or assertions:
- A constructed variant value belongs to the expected set/type of variants.
- A filter-by-tag operation over a finite set yields an element with the expected payload when such an element exists.
- The tag-returning operation returns the exact tag string used when the variant was created.
- The unsafe extraction operation returns the stored payload when the asserted tag matches, and otherwise it may be undefined; the model should allow detection of mismatched-tag cases separately.
- The safe extraction-with-default returns the stored payload when the tag matches and returns the provided default value when it does not.

Do not prescribe how variants are implemented internally; focus on the abstract operations, their input/output behaviors, and the invariants that must always hold in the trivial environment.
