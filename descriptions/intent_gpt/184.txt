Specify a concurrent system of two independent cyclic components that each repeatedly generate and accumulate identifiers into their local sets, and a global set that is always the union of those local sets. Each component repeatedly emits a fixed sequence of three distinct token identifiers (a cycle of three steps) and, when emitting a token, adds that token to its local set (sets grow monotonically; tokens are never removed). The components operate asynchronously and may interleave arbitrarily. Additionally, the system maintains a small finite-state controller (external to the token cycles) that nondeterministically transitions among a finite set of control states; the controller’s transitions are independent of the exact timing of token additions but may constrain global scheduling choices.

Model the system so that:
- Initially each component’s local set contains a single distinct token, and the global set equals the union of the two locals.
- On each step, one component may advance one position in its 3-token cycle and add that token to its local set; the other component may remain unchanged.
- The controller may change state nondeterministically between its allowed states at any step (including stuttering); its state space and allowed transitions should be finite and specified as a directed graph.
- The global set must always equal the union of the two local sets.

Specify the following correctness properties to be checked:
- Safety: the two local sets are never identical (they must differ at least by one element) at any reachable state.
- Invariance: the global set invariant (global = union(local1, local2)) holds in all reachable states.
- Liveness: each component’s cycle makes progress infinitely often (each token in a component’s cycle is eventually added again, assuming fairness).
