Specify a model of a simple growing set with an associated recorded size such that the recorded size always equals the number of distinct elements in the set. The system repeatedly performs an operation that atomically adds a new natural-number element (or integer) to the set and increments the recorded size by one. The element added at each step must be allowed to be any value not already present in the set (no duplicate insertion should change the set), and the operation must preserve that the recorded size increases exactly when a new element is added. The model must allow starting from an initial state with an empty set and size zero.

Require formal correctness properties:
- Safety: At every reachable state, the recorded size equals the mathematical cardinality of the set.
- Invariant preservation: Every transition must maintain the safety property.
- Well-foundedness: The model must forbid negative sizes and maintain that size is an integer.
- Progress: The model should allow infinitely many successful insertions (non-blocking growth), subject to the availability of fresh elements.

Allow nondeterminism in choosing which fresh element to add, but disallow actions that make the recorded size inconsistent with the set (e.g., increment without adding a new element, or adding an element without incrementing). Do not constrain the particular internal representation of cardinality; require only that its value matches the set's true cardinality.
