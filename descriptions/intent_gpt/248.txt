Specify a formal model of a small library of sequence, set, and higher-order utilities and test assertions that validate their behavior. The model should describe pure functions (no concurrency) that operate on finite sequences and finite sets of integers and permit higher-order arguments (functions passed as parameters). Required operations to model:

- Construction and basic manipulation of finite sequences: creating constant sequences, empty sequence, concatenation, subsequence selection, tail, length, and producing a sequence by applying a generator function across an index range (i.e., map by index, given a requested length).
- Folding (left fold) over sequences with an associative or arbitrary binary operator, and using folding to flatten a sequence-of-sequences.
- Selecting a subsequence by predicate (filter) and folding over the filtered sequence.
- Treating finite maps/functions on contiguous integer domains as sequences (extract values in index order) with a bound on capacity; behavior when the capacity equals the domain size and when it is larger.
- Folding over sets with a binary operator that combines an accumulator and an element, producing a set result.
- A nondeterministic choice operator that can pick an arbitrary element from a given finite set (including singleton and empty-set cases), used to model "guess" operations.

State the intended semantics (input domains, result types) and precise expected outcomes for representative test instances: e.g., concrete sequences and sets given as literals, sums produced by folding, concatenation flattening result, generated sequences with arithmetic functions, selection by parity, and set fold producing union. Specify correctness properties: each test expression should evaluate to the stated value; the guess operator must return an element of its input set, and behavior for an empty guess must be specified (e.g., any integer or vacuously satisfy a provided predicate). Ensure functions are total on their declared domain and that representations avoid accidental constant folding in the model so tests exercise library behavior rather than simplifications.
