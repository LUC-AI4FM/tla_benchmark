Specify a system that computes the maximum element of a finite nonempty or possibly empty sequence of integers supplied as input, and prove its safety and termination properties. The model should treat the input sequence as immutable and allow nondeterministic choice of which unexamined position to inspect next. The system must iterate until every index of the input has been considered exactly once and maintain a current candidate value for the maximum.

Requirements:
- Inputs: any finite sequence of integers (including the empty sequence). A separate constant lower bound is provided that is strictly below every element that may appear in the input.
- Behavior: repeatedly pick an index that has not yet been processed, compare the sequence element at that index with the current candidate, and update the candidate if the element is larger. Mark the index as processed. Do this until no unprocessed indices remain.
- Postcondition (safety): if the input is empty, the final candidate must equal the provided lower bound; otherwise, the final candidate must equal one of the elements of the input and must be greater than or equal to every element in the input (i.e., it is a maximum).
- Liveness/termination: from every initial state the algorithm must eventually finish processing all indices (reach a final or halting state).
- Model constraints: the input sequence must not be modified; processing order is arbitrary (nondeterministic); ensure that each index is processed exactly once. Include an assertion that enforces the postcondition at termination so that violations are detectable.
