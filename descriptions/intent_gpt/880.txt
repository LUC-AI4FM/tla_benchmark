Specify a formal model of solving an ordinary differential equation (ODE) initial-value problem for a system of n first‑order equations derived from a higher‑order ODE. The model should describe a domain of real-valued, sufficiently smooth functions on an open interval around a closed time interval [a,b], with derivatives defined up to order n. It must capture the notion of an n‑th order ODE expressed as an equation D(t, y0, y1, …, yn) = 0 that holds pointwise for all times in an open neighborhood of [a,b], where y0 is the function value and yi is its i‑th derivative. The specification should require initial values for y0, y1, …, y(n−1) at time a and state the existence and uniqueness guarantee for a solution y0 (and its derivatives) on [a,b] that satisfies both the ODE and the initial conditions. Additionally, provide an operator that, given D, a, b and the initial values, returns the vector of values y0(b), y1(b), …, y(n−1)(b) at the endpoint b. Key correctness properties to assert: existence of a solution on an open neighborhood of [a,b]; compatibility of the solution with the initial values; the ODE is satisfied pointwise; the returned endpoint values equal the solution’s values at b; and derivatives up to order n exist and are consistent with the ODE.
