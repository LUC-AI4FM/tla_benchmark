Specify a formal model of a distributed graph pruning protocol that removes redundant vertices while preserving connectivity of a spanning subgraph. The system consists of a fixed undirected graph of processors (nodes) connected by edges. Each processor holds local state and can send/receive messages along incident edges. The protocol proceeds in asynchronous rounds/phases where processors decide locally whether to deactivate (prune) themselves based on information exchanged with neighbors.

Model the following behavior and requirements:
- Initially all processors are active. In each phase, processors may exchange messages carrying identifiers, proposals, or votes with their neighbors and update local state accordingly. Communication is unreliable only in timing (asynchronous): messages are delivered eventually and in FIFO order per edge (unless an explicit weaker assumption is chosen); no message corruption.
- A processor may decide to deactivate only when it has sufficient evidence that doing so will not disconnect the remaining active processors from each other with respect to the intended spanning structure (for example, preserving reachability between specific roots or maintaining a connected spanning backbone).
- The protocol must guarantee safety: at all times, the set of active processors induces a connected subgraph that satisfies the target connectivity invariant (e.g., contains a path between every pair of designated terminals, or remains connected overall).
- It must guarantee liveness: if communication continues and processors follow the protocol, the system converges in a finite number of phases to a stable configuration where no further deactivations occur.
- Specify progress fairness assumptions needed for termination and precise conditions under which processors may change state or send messages.
- Include correctness properties: eventual termination, preservation of required connectivity, and absence of simultaneous conflicting deactivations that could violate safety.
