Specify a very simple system that contains a single immutable shared value chosen from some abstract set of constants. The model should represent that the system initializes that shared value to a particular constant and that the value never changes thereafter. The specification must allow reasoning about the initial condition and every step of the execution, where every step preserves the shared value unchanged.

State the required invariants and liveness assumptions clearly: an invariant saying the shared value always equals the initial constant, and a trivial safety invariant that is always true if necessary. Show that the initial predicate implies the invariant and that every transition preserves it. Also state that there are no enabled transitions that alter the shared value. Optionally include a simple temporal guarantee that the value remains equal to the constant on all future states (always property).

Keep the model abstract about the type of the constant (it may be declared as an uninterpreted constant from some set) and do not include any extraneous state or actions. The goal is to verify safety (value immutability) and trivially satisfied liveness (no progress required) for this single-variable, single-constant system.
