Specify a simple arithmetic-constant validation module that models a logic for interpreting numeric literals written in binary, octal, and hexadecimal notations and ensures they denote the expected natural numbers. The model should treat numeric literals written in those bases as syntactic forms that evaluate to integer values, and it must allow both uppercase and lowercase base prefixes and digits where appropriate. The system must accept multiple equivalent literal forms for the same numeric value (for example, the decimal value 63) and prove or assert that all provided representations evaluate to the same natural number.

Requirements:
- Define the accepted literal syntaxes for binary, octal, and hexadecimal integers, including variations in prefix case and digit letter case.
- Specify an evaluation function mapping each accepted literal form to a natural number.
- Require that for a chosen target value, a collection of example literals in different bases and with mixed-case prefixes/digits all evaluate equal to that target.
- Include checks that reject invalid digit characters for a given base and that the evaluated values are natural numbers.
- State logical properties to be verified: equality of evaluated results across all equivalent literals and validity of syntax-to-number mapping.

Do not include implementation details of parsing algorithms; focus on the abstract syntax, evaluation relation, and the equality and type-correctness properties to be established.
