Model a system that composes two components where one component is instantiated with a shared parameter provided by the other. The system should represent a single integer-valued state variable that ranges over a finite set of initial values and evolves deterministically according to a simple state-transition rule. The composed component should be able to refer to the shared integer as a parameter (read-only) and express enabledness of internal actions that may involve either the shared parameter or its own local primed variables. Specify the initial condition as a non-deterministic choice among a small finite set of integers for the global state. Specify the next-state relation as a deterministic function mapping the current global state to a new value (for example a reversible mapping within that finite set). Require that the full specification is the usual init /\ [][next]_var temporal formula.

State correctness properties that must be checked about the composition: (1) that a particular predicate asserted by the instantiated component when invoked inside the top-level temporal context is observationally equivalent to a separately constructed predicate that syntactically duplicates the instantiated component’s logic but refers directly to the top-level variable — i.e., the instantiation must correctly substitute the shared parameter and preserve enabledness and primed-variable relationships; (2) that enabledness and primed-variable constraints inside the instantiated component behave as expected when the parameter is instantiated, so no accidental capture or misbinding of primed identifiers occurs; and (3) that invariance or equivalence properties expressed about the composed component hold under all reachable behaviors of the top-level system.
