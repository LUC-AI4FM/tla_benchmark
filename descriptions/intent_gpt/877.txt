Specify a distributed algorithm that constructs and maintains a spanning tree rooted at a designated node in an undirected connected network. The model should represent a fixed set of nodes and undirected edges; each node knows its neighbors and can read and update only its own local state. The algorithm must establish, for every node, a parent pointer that points to a neighbor on a shortest (or strictly decreasing-distance) path toward the root and a nonnegative integer distance estimate from the root. Initially, the root must have distance zero and point to itself; other nodes may start with arbitrary nonnegative distances and parent pointers. The algorithm must permit local updates in which a node, after observing a neighbor with strictly smaller distance, atomically updates its parent to that neighbor and sets its distance to a value between the neighbor’s distance plus one and its previous distance minus one, ensuring progress toward the root without increasing any node’s distance.

Require formal properties to verify: safety — every parent pointer must always reference a valid node, every distance must always be a natural number, and every parent pointer must be a neighbor; invariants should ensure distances are consistent with parent links (parent distance < child distance); and liveness — eventually every node’s distance becomes finite and strictly decreases until it reflects its distance to the root, producing a stable spanning tree rooted at the designated root. Also require that the model forbids creation of cycles that contradict parent-to-root progress.
