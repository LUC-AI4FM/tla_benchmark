Specify a system that repeatedly and independently assigns two variables values drawn from the set {0,1} at each step, starting from a known initial state where both are zero. The model should treat each assignment as a nondeterministic choice of either 0 or 1 for every variable at every step, allowing all possible interleavings and combinations of choices over time. The specification must capture the initial condition, the state space of both variables as binary values, and the transition relation that replaces both values simultaneously at each step with independently chosen bits.

State the safety and liveness requirements the model must guarantee and check: safety — either the two variables are always equal at every reachable state, or if this equality is not guaranteed, the model should be able to exhibit counterexamples; liveness — the model should permit both variables to take each possible value infinitely often and allow any combination of future assignments consistent with the nondeterministic choice semantics. Provide properties to assert and check that cover invariance of equality, reachability of differing values, and fairness of nondeterministic choices so that evaluation can detect whether equality is preserved, violated, or both values recur indefinitely.
