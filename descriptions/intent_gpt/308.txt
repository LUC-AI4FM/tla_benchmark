Specify a formal model of the classic binary-search algorithm that searches for a key in a finite array of integers. The model should treat the array and the search key as inputs and must account for fixed machine-integer arithmetic with a given bit width (including wraparound behavior). The system must initialize a search interval that spans the array and then repeatedly examine a midpoint, compare the array element at that midpoint to the key, and refine the interval until the algorithm terminates with either a found result or a not-found indicator. The specification must not presuppose any particular program structure; instead describe states and next-state transitions that capture one iteration of the search.

Require the model to guarantee:
- Safety: array accesses are always within bounds for every executed midpoint calculation, under the chosen integer semantics.
- Correctness of result: when the algorithm reports success, the reported index refers to an array position whose value equals the key; when it reports failure, the return value unambiguously indicates the key is not present.
- Termination: for any valid inputs (including any bounded integer behavior), the search eventually terminates; provide a measurable progress metric (e.g., shrinking interval or step bound) to justify termination.
- Robustness: if the input array is not sorted, allow the model to avoid claiming correctness of a positive result; when assuming the array is sorted, guarantee the standard binary-search postcondition.

Also require invariants and proof obligations sufficient to verify the above properties under the specified fixed-width integer arithmetic.
