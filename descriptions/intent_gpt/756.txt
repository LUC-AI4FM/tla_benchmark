Model the classic two-jug water-measuring puzzle as a state machine parameterized by a finite set of jugs, each with a fixed nonnegative integer capacity, and an integer target quantity. The system state should record the current nonnegative integer amount of water in each jug, constrained by capacities and by total water conserved when no external source/sink is used. Allowed operations should include filling any jug to its capacity from an infinite source, emptying any jug to an infinite sink, and pouring from one jug to another until the source jug is empty or the destination jug is full. The model must permit arbitrary sequences of these operations from an initial state where all jugs are empty (or from another specified initial distribution). Specify the reachability problem: whether some state exists in which at least one jug contains exactly the target quantity. Guarantee that the model checks termination or bounded-step reachability (both a finite-step witness and invariants ruling out spurious solutions). Key correctness properties: safety (jug contents never exceed capacity and are never negative), conservation when appropriate (total water changes only via fill/empty actions), and liveness (if a solution is reachable, there exists a finite sequence of allowed operations leading to it). Also allow specifying particular capacities and target to explore concrete instances and require the model to produce a witness sequence when the target is reachable.
