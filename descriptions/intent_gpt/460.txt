Specify a simple finite-state system that exercises and validates propositional-logic reasoning over Boolean-valued state. The model should represent a system with a fixed, small set of Boolean state flags and an auxiliary numeric flag that does not change. The initial state must assign concrete Boolean values to the Boolean flags (some true, some false) and set the numeric flag to a fixed value. The system's transition relation should allow at least one trivial stuttering or no-op transition so that the state can persist across steps; nothing in the transition relation should change the Boolean flags or the numeric flag.

Require an invariant that encodes a comprehensive set of propositional logical assertions about the Boolean flags and about membership of the Boolean values in the Boolean type. The invariant must include examples of:
- Conjunctions, disjunctions, negations, and implications between flags.
- Equivalences and exclusive/equality-style relations.
- Compound formulas mixing Boolean flags and explicit equality with numeric representations of Boolean values.
- Assertions that test that TRUE and FALSE are members of the Boolean type and that the Boolean type equals the set {TRUE, FALSE}.

The specification must guarantee safety: every reachable state satisfies every clause of the invariant. The model should be amenable to model checking (finite state), and the invariant should be expressed so that violations produce informative diagnostics identifying which logical assertion failed.
