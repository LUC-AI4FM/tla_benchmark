Specify a formal model of a function-construction and substitution utility together with basic sanity checks that should always hold. Model a value space of finite sequences (finite functions from a contiguous integer domain) and an operation that, given a finite function and a rule that maps indices to new values, produces a new finite function that is identical to the original except that every index i in the original domain is assigned the value produced by the rule for i. The operation must be defined for arbitrary finite domains and must behave elementwise: if the rule returns e(i) for index i, the result must map i to e(i). Include in the model ordinary initialization and a trivial step relation that leaves global state unchanged so that the model is stable while checks run.

Require the following correctness properties to be verified:
- Construction identity: creating an empty set and assigning it to an alias yields the empty set; any conditional or inspection of that alias should reflect emptiness.
- Empty-indexed function handling: construction of a mapping over an empty index set should produce an empty finite function/sequence.
- Elementwise substitution correctness: applying the substitution operation to a concrete finite function with a simple rule (e.g., incrementing each index by one) must yield the expected transformed finite function.

State these as invariants or assertions that must hold in all reachable states. The specification should avoid committing to any particular implementation strategy and instead state only the required behavior and the properties above.
