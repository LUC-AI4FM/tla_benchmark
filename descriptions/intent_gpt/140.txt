Specify a simple discrete-state transition system with two integer-typed state components that each always take values from the finite set {1,2,3}. The system should start in any state where both components are in that set. Transitions must allow one component to change nondeterministically within the set, except when a given condition relating the new value of the second component to the old value of the first component holds; in that case the first component must be deterministically set to a particular value. The second component must remain unchanged by every transition. Precisely state the allowed initial states, the transition relation, and an invariant that the components always remain within the finite domain.

Require proving the following correctness properties:
- Safety: the first and second components always stay in {1,2,3}.
- Deterministic assignment under condition: whenever the condition comparing the first component and the next value of the second component holds, the first component’s next value equals the prescribed constant.
- Stuttering-respect: transitions that do not change the tuple of variables are permitted (i.e., allow stuttering steps).
Also specify that liveness is not required beyond the basic fairness implied by the transition relation.
