Model a simple concurrent-state system that has multiple groups of state components (each group containing several typed variables) and supports steps that may leave all state groups unchanged. The specification should initialize every state component to a concrete, well-typed value and allow a stable-transition step that does not modify any state component. The model must treat grouped state as collections (tuples or records) so that properties and actions can refer to whole groups or to nested groupings without ambiguity.

Requirements:
- Represent several independent state groups, each containing heterogeneous-typed components (booleans, integers, and strings).
- Provide an explicit initial state assigning a concrete initial value to every component.
- Provide at least one transition that is a no-op: it must preserve every state component simultaneously (i.e., the grouped state stays equal before and after the step).
- Allow specifying invariants and temporal properties over whole groups as well as individual components.
- Ensure the model’s semantics do not rely on evaluating or assigning any component before it is initialized; all references to grouped variables must be well-defined.
- Specify and check safety: every step preserves the grouped-state equality for the no-op action. Specify and check liveness if desired (e.g., the system can always take the no-op step).
