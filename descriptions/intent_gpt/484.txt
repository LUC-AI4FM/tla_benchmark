Specify a simple state-transition system with two integer-valued state components that evolves in discrete steps. The system starts in an initial state where the first component equals a given initial value (for example 0) and the second component may be unconstrained or set to a specified initial value. Each transition assigns new values to both components subject to a logical constraint: the chosen next pair of values must satisfy a Boolean condition that forbids a particular conjunction of assignments while allowing some other specific assignment. Precisely state which single combination of next values is disallowed and which combination is required to be possible, so that transitions cannot simultaneously pick the forbidden pair but can pick the allowed pair. The specification should permit only transitions that meet this constraint; stuttering steps (where no component changes) are allowed or ruled out according to an explicit choice. Require that the model record reachable states and transitions and ensure that every possible transition respects the constraint on next values. Formulate safety properties asserting that the forbidden next-pair never occurs and that the allowed next-pair remains reachable from the initial state. Optionally include a fairness or liveness property ensuring progress toward reaching the allowed pair.
