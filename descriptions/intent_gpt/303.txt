Specify a model of the classic binary search algorithm that operates over a fixed finite array of comparable values and a target key. The model should describe the abstract behavior of repeated halving of a search interval [low, high] until the algorithm either finds the key or concludes it is absent. The model must accept as parameters: the input sequence (an indexed finite sequence of values), the key to search for, and a machine integer width that bounds arithmetic operations. The model should initialize the search interval to cover the entire sequence and expose a termination flag plus a numeric result value.

Requirements:
- When the algorithm terminates having found the key, the result must be a valid index into the sequence that refers to an element equal to the key. If indices in the specification are 0-based, the returned index must use that convention; if 1-based, adjust accordingly.
- When the algorithm terminates without finding the key, the result must be a distinguished negative value that encodes the correct insertion point: the standard negative-of-(insertion-point+1) convention, where the insertion point is the index at which the key could be inserted to preserve sorted order.
- The model must guarantee termination (eventual setting of the termination flag) for any finite input sequence.
- All arithmetic must respect the provided machine integer width so operations that would overflow are considered invalid or constrained.
- The search must maintain the invariant that the key, if present in the input, always lies within the current [low, high] interval.
