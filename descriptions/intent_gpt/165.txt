Model a simple state machine that initializes a numeric system parameter and then allows arbitrary state evolution under a single non-deterministic step, while preserving basic type and structural invariants. The model should include:
- A constant integer parameter that must be constrained to be greater than a fixed threshold; the initial state must assign that parameter a concrete allowed value.
- A notion of an initial state and a next-state relation that permits non-deterministic transitions (the next-state relation may be unconstrained but must be well-typed).
- A representative collection of values and expressions (literal strings, integers, booleans, sets, tuples, records, functions, and finite sequences) so the specification captures typing and structural properties of typical data used by higher-level algorithms.
- Examples of derived operations over these data: set operations (union, intersection, subset relations, Cartesian products, filtering, mapping), sequence operations (head, tail, append, concatenation, subsequence, selection by predicate), function construction and update, and basic arithmetic and logical operators.
- Some examples of quantified properties (existential and universal) and choice expressions to exercise semantics.
- Correctness properties to check: the initial condition holds; all reachable states maintain the typing invariants for the various data structures; and the constrained numeric parameter never violates its bound. Also state a simple liveness-style claim that from any reachable state a next step is always possible (i.e., the next-state relation is total). Do not specify implementation details of transitions; focus on types, invariants, and the allowed non-deterministic evolution.
