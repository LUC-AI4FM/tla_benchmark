Specify a simple boolean-state system in which a single boolean state flips its value nondeterministically over time, starting from a known initial value. Model the system as a discrete-state transition system whose states include one boolean component initialized to a specific value. The system must allow the boolean to change value in steps, where each step may flip the boolean (true→false or false→true). Time should be represented as a sequence of states (traces) beginning with an initial state and evolving by repeated application of the transition relation.

Require the following correctness properties to be specified and checkable with temporal logic:
- Safety: Every state in every trace must have the boolean in either true or false (i.e., the state space is limited to the boolean domain).
- Liveness: From any reachable state, it must be possible to eventually reach a state where the boolean has the opposite value (i.e., flips are always eventually possible).
- Invariance of the initial condition: All traces must start in the specified initial boolean value.
- Fairness/Progress constraint: Prevent trivial traces that remain in the initial state forever if the transition relation permits flipping; ensure progress so that flipping occurs under a fairness assumption.

Also describe the system-level specification as an initial condition conjoined with a temporal closure of the transition relation, and state which temporal operators are required to express invariants and eventualities. Do not prescribe implementation details of the transition mechanism.
