Specify a formal model of the Dining Philosophers problem for N philosophers around a table sharing N forks. The model should capture each philosopher’s state (thinking, hungry, eating) and each fork’s state (which philosopher currently holds it, and whether it is clean or dirty). Philosophers may only eat when they hold both adjacent forks; forks may be picked up and put down according to the protocol described below. Include the possibility of asynchronous, interleaved steps where any philosopher may act when enabled.

The system must implement a distributed resource-exchange protocol that avoids deadlock and prevents starvation: every philosopher who becomes hungry must eventually be able to eat (liveness), and the system must never reach a global state in which progress is impossible because of circular waiting (safety). Ensure mutual exclusion on forks so that no two philosophers can hold the same fork concurrently (safety). Model the transfer of forks between neighbors, including rules that allow a philosopher to request a neighbor’s fork, to grant or refuse requests according to a cleanliness or priority mechanism, and to return forks after eating.

Specify invariants expressing safety properties (mutual exclusion and absence of illegal fork ownership patterns) and liveness properties (eventual entry to eating from hungry) suitable for model checking with temporal logic. Allow parameterization by the number of philosophers so the specification can be checked for varying N.
