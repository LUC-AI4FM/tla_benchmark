Specify a concurrent state-machine that repeatedly swaps two integer-valued registers. The system has two integer registers whose initial values are distinct constants. The only allowed state transitions are those that exchange the current values of the two registers (i.e., after a step, each register holds the previous value of the other). There are no other transitions and no external inputs that change values.

Formalize safety and liveness requirements for this system:

- Safety: the multiset of register values is preserved by every transition (i.e., the pair of values is only permuted), and each register value is always an integer. Also assert that certain forbidden values never appear in the system if they are not present initially.

- Liveness: show that a configuration in which a particular register equals one of the initial values recurs infinitely often (i.e., eventually and repeatedly that register attains that value). Also allow placing a liveness requirement that is unattainable (e.g., a register taking some value that is not reachable) to be expressible so that the model checker can distinguish realizable from unrealizable liveness claims.

Specify initial conditions, the single-step transition relation, and state predicates expressing the safety and liveness properties. Ensure liveness statements are written as temporal properties so model checkers can check both satisfiable and unsatisfiable liveness obligations.
