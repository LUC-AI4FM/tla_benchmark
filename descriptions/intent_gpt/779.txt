Model a library of pure mathematical functions and their relations that operates on total finite mappings between sets. The specification must describe abstract operators for: restricting a mapping to a subset of its domain or to domain elements or range values that satisfy a predicate; computing the image (range) of a mapping; testing whether one mapping is a restriction (submapping) of another; forming the pointwise combination of two mappings by a binary operator; constructing an inverse relation from values back to domain elements (including a partial inverse restricted to a target set); and computing the inverse of a bijection. Also specify predicates that characterize injective, surjective, and bijective mappings between two given sets, and define the sets of all injections, surjections, and bijections. Include existence tests that check whether at least one injection, surjection, or bijection exists between two sets.

Additionally, specify a fold operation that aggregates the values of a mapping by an associative, commutative binary operator (optionally restricted to a provided subset of indices), with an explicitly given base value and a deterministic result independent of iteration order.

State the domain and type constraints (finite domains, total functions from one set to another) and the required correctness properties: restriction operators preserve mapping values on kept domain elements; IsRestriction correctly characterizes submapping relation; Range yields exactly the set of images; pointwise combination is defined only when one domain is contained in the other and agrees elementwise; inverse maps each value to some original preimage when such exists; injectivity, surjectivity, bijectivity satisfy usual logical equivalences; the fold result is invariant under any permutation of indices (given operator properties).
