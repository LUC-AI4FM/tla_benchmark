Specify a simple deterministic function that takes no inputs and returns a fixed pair of boolean values. The model should treat the function as an atomic operation that, when invoked, produces a two-element ordered result consisting of the first element true and the second element false. The specification must capture the return value precisely (true, false) and rule out any other possible outputs. Include properties that assert the output is always a 2-tuple, that the first component is true, and that the second component is false. Also assert determinism: repeated invocations produce identical results and there is no nondeterministic choice or side effect associated with calling the function. Optionally include a simple safety property showing that the function cannot produce a tuple with either component negated (i.e., it cannot return (false, *) or (*, true)). Do not model or require any other state or behaviors beyond this function and its constant return value.
