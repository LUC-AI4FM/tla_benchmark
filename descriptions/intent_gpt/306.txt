Specify a formal TLA+ model of a bounded-width integer implementation of the iterative binary search algorithm over a static array. The model should treat the input as a fixed finite sequence of integers and the search target as a given integer. Machine integers must be represented with a fixed bit width so arithmetic may wrap; define the semantics of bounded addition and other integer operations accordingly.

The model must capture the algorithm's initialization and the loop that repeatedly inspects the midpoint of a current inclusive index interval [low, high], updates the interval based on comparison with the key, and halts either when a match is found or when the interval becomes empty. It must also count steps executed.

State the correctness properties the model must verify:
- Safety: when the algorithm terminates, if the input sequence contains the key then the returned index refers to an element equal to the key; if the key is not present then the return value encodes a negative-not-found result. Allow the property to be conditional on the input being sorted, and clearly state what is required when the input is unsorted.
- Termination: the algorithm must terminate within a bounded number of steps for all inputs under the bounded-width integer semantics, or provide a progress invariant showing that the search interval strictly shrinks on each non-terminating iteration.
- Progress/termination proof obligations should account for integer wrapping and avoid undefined arithmetic by constraining values to representable ranges.

Include assumptions about the input (e.g., sequence length, sortedness when required) and specify the exact semantics for mapping between sequence indices and returned values (zero-based vs one-based) so properties are unambiguous.
