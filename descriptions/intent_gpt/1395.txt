Specify a simple two-valued state machine that models a Boolean-valued flag which can change nondeterministically between true and false. The model should start with the flag false and allow any sequence of steps in which the flag can take either Boolean value at each transition (i.e., transitions are unconstrained except for Boolean typing). Capture both safety and liveness requirements.

Requirements:
- Initialize the system with the flag false.
- Every step may set the flag to either true or false; no further environment constraints are assumed.
- Guarantee type-safety: the flag is always a Boolean.

Correctness properties to specify and check:
- Safety property: the flag may never violate the Boolean invariant (type-safety).
- Temporal property "at-most-once": once the flag becomes true, it must never be allowed to become true again after having become false (i.e., whenever the flag is true, from that point onward it must be impossible to see a later true after any intervening false). (Express this as a safety/temporal constraint to check.)
- Liveness property: whenever the flag becomes true, it is eventually followed by a transition that sets it to false (i.e., true leads to false eventually).
- A property to check that a particular finite alternating counterexample (false → true → false → true) can be produced by the unconstrained transition relation, for diagnostic purposes.

Also include a weak fairness assumption with respect to the transition relation as an alternate experiment: allow checking the system both with and without weak fairness to observe its effect on the above properties.
