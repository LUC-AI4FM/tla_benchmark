Specify a formal model of a small functional-expression evaluator in which local definitions, higher-order functions, and scoping are the primary concerns. The model should capture expression formation with let-bindings (including nested lets), function abstractions and applications, nullary (constant) bindings, and passing functions as arguments (both named and anonymous/lambda). It must allow local helper functions to refer to surrounding parameters (lexical scoping) and to each other where appropriate, and should permit defining polymorphic or typed function signatures abstractly.

The model must specify evaluation semantics that preserve call-by-value behavior for expressions and function arguments, but also explicitly represent the semantics of passing function values (including functions that themselves take functions as parameters). It must handle folding over sequences and sets as examples of higher-order use. Local names should be allowed to shadow globals, and nullary locals should behave as constant inlining where appropriate. The specification must assert key correctness properties: that well-formed local definitions evaluate to the intended numeric or boolean results in representative test cases; that nested and chained local definitions compose correctly; that passing named or anonymous functions yields identical results when semantically equivalent; and that lexical scoping prevents accidental capture. Provide a concise set of executable assertions (test predicates) that validate these behaviors across examples including arithmetic, boolean negation, folds, and multi-level function composition.
