Specify a model of a cyclic biochemical amplification process that repeatedly alternates temperature-controlled phases to copy nucleic-acid templates using limited primer resources. The model should represent a population of double-stranded templates, single-stranded templates, free primers, and primer–template hybrids, and it should include discrete temperature modes that permit only certain transitions between phases. The system must support these phase types: denaturation (high temperature) that converts double strands and hybrids into single strands and returns primers from melted hybrids; annealing (cooling) that allows primers to bind to available single strands to form hybrids (up to the number of primers and templates available); extension (warming) that converts hybrids into new double strands and consumes those hybrids; and intermediate temperature flips that only change temperature without other effects. The dynamics must enforce conservation where appropriate (e.g., counts nonnegative, primer use reduces free primer, extension increases double-stranded count by the number of hybrids consumed). Model an explicit counter of completed amplification cycles that increments only when extension completes. Require progress fairness so each phase can eventually occur when enabled. Correctness properties to guarantee: (1) counts never go negative and types stay in their domains; (2) primers are monotonically nonincreasing except when returned by denaturation; (3) extension only increases double-stranded material by at most the number of currently formed hybrids; (4) every annealing that is enabled will eventually occur (liveness), and no temperature transition can produce illegal state changes; (5) primers are eventually depleted if cycles continue while primers are finite and no new primers are introduced; and (6) the cycle counter accurately reflects the number of completed extension phases.
