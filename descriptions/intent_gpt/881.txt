Specify a formal model of finite graphs and common graph-theoretic constructs that can be used to verify algorithms that operate on graphs. The model should allow representing directed and undirected graphs as collections of nodes and edges (edges are ordered pairs of nodes), and should support formation of subgraphs (both directed and undirected). It must provide a notion of simple paths (finite, nonempty sequences of nodes where each consecutive pair is an edge) and predicates for reachability between two nodes via such a path.

Require definitions and properties for:
- Directed graphs and undirected graphs (undirected graphs must have symmetric edges).
- Directed and undirected subgraphs constrained to use only nodes and edges from a parent graph.
- Simple paths through a graph and a reachability predicate that holds iff there exists a path from one node to another.
- Strong connectivity: every node can reach every other node.
- Rooted trees (directed trees with a designated root) characterized by: the root has no incoming edge, each non-root node has exactly one incoming edge (uniqueness of parent), all nodes are reachable from the root, and there are no extra structural elements (i.e., edges only between nodes of the tree).

State key invariants and correctness properties to be checked:
- Subgraph containment preserves edge symmetry for undirected subgraphs.
- Path concatenation and reversal properties where applicable (reversing a path in an undirected graph yields a path).
- For a directed rooted tree, uniqueness of paths from any node to the root and absence of directed cycles.
- Strong connectivity implies existence of paths in both directions for any node pair.

The model should be parameterized by an explicit finite set of nodes and support automated checking of these properties.
