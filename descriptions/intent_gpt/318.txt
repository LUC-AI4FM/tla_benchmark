Specify a model of a factorization search procedure that non-deterministically finds a nontrivial factorization of a given positive integer N. The model should describe an abstract system that repeatedly proposes candidate factor pairs (a, b) and, when it finds a pair whose product equals N, records that it has found a factorization and stops proposing further candidates. The system must allow arbitrary order of candidate generation and should not presuppose any particular search strategy (e.g., sequential, random, parallel); it should permit generating any candidate pair within a specified finite bound.

Requirements:
- The model must include an initial state in which no factorization has been recorded.
- The system may nondeterministically choose candidate factor pairs (a, b) from a given finite domain of positive integers greater than 1.
- If a chosen candidate satisfies a *a = N* (or equivalently a*b = N if modeling pairs), the model must record that a factorization has been found and move to a terminal or absorbing state indicating success.
- The system must allow for the possibility that no correct candidate exists in the chosen domain (i.e., the record remains unset).
- Key correctness properties to verify:
  - Safety: Once the model records success, the recorded factors must indeed multiply to N.
  - Liveness (when a correct candidate exists in the domain): The model is capable of eventually recording success (i.e., there exists an execution that finds the correct pair).
- Parameterize N and the candidate domain bound so the model can be used to explore different instances and verify the properties above.
