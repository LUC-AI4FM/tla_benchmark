Specify a simple countdown system that starts at a fixed nonnegative integer and repeatedly decrements by one until reaching zero. The model should treat the starting value as a constant parameter and represent the current value as a state variable that is initialized to that starting value. The only allowed state transitions are deterministic steps that reduce the current value by exactly one, and no other actions or nondeterminism should be introduced.

The specification must require that the system always preserves integer values and never goes below zero: once the value reaches zero it must remain at zero and no step may produce a negative value. It must also guarantee termination in the sense that, starting from any nonnegative initial value, after a finite number of decrement steps the system reaches zero and then stays there. Include invariants asserting that the value is always between zero and the initial constant inclusive, and a liveness property ensuring eventual arrival at zero from any initial state. The model should be suitable for model checking these safety and liveness properties.
