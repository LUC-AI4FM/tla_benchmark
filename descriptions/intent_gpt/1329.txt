Specify a model of a simple finite-state nondeterministic system that repeatedly chooses one of a fixed number of labeled actions and evolves indefinitely. The system must: start in an initial state; at each step nondeterministically pick one action from the finite set and move to the corresponding next state; allow some actions to be enabled only in certain states while others remain always enabled; and permit cycles so the execution can continue forever. Formalize invariants that must hold in every reachable state (e.g., a safety condition that forbids certain combinations of state predicates) and a liveness requirement that from any reachable state some designated desirable event eventually occurs infinitely often. The model should abstract away implementation details like scheduling and internal variables, focusing instead on the transition relation and the enabling conditions of actions. Provide a complete temporal specification asserting both safety (state invariant) and fairness/liveness (every computation is infinite and the desirable event recurs). Ensure the model supports model checking on a finite domain and is parametrizable by the number of distinct actions.
