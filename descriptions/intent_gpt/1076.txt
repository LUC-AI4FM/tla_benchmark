Specify a formal TLA+ model of a distributed token-based termination detection protocol for a fixed ring (or sequence) of N processes with asynchronous message passing. The system maintains per-process message queues (bags) that may hold either ordinary payload messages or a single unique token message that moves among processes. The model must capture: process-local state (active/inactive, color white/black, local counters), per-process bags of messages, and a globally unique token that carries a numeric counter and a color bit. Initially exactly one process holds the token (with q = 0 and color = black) and all message bags are empty; all processes are inactive and counters are zero.

Model actions for (at least): sending a payload to another process (which increments a sender counter and appends a payload message to the recipient’s bag), receiving a payload (decrementing a counter and possibly changing activity/color), passing the token to the next process (updating token position, q, and token color), and initiating probe/termination when appropriate. Messages are nondeterministically delivered and may be added/removed from per-process bags; ensure bags preserve typing and the token remains unique.

State the correctness properties to prove:
- Safety: at all times exactly one token exists in the system (unique token invariant), and all message bags contain only well-typed messages.
- Refinement: the abstract variables (per-process pending counts and the token tuple) recovered from the bags and token witness correspond to a known abstract specification of EWD998-style termination detection.
- Liveness/specification goal: when all processes become inactive and there are no payload messages outstanding, the protocol eventually reports global termination (token-based detection succeeds).

Do not presuppose a specific implementation; leave the algorithmic steps abstract as actions that manipulate process-local state and per-process message bags subject to the typing and uniqueness constraints above.
