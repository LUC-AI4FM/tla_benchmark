Specify a simple concurrent system of two independent integer-valued registers that evolve nondeterministically. The system must allow either register to be assigned any natural number at any step, including zero, with no implicit bounds. Model the possible initial configurations so that each register may start at any natural number. The specification should capture two separate liveness properties: one asserting that from every reachable state it is always possible for the first register to eventually take any given natural value, and similarly for the second register. Also specify safety properties that forbid undefined or uninitialized values: every state must explicitly assign a natural number to both registers. Include an invariant that asserts that both registers remain natural numbers in all reachable states. Finally, state a reachability requirement asserting that there exist executions that visit infinitely many distinct states (i.e., the state space can be unbounded) and a complementary requirement that some executions are terminating in the sense that no further changes occur after some step. The model should allow checking both that the invariants always hold and that the liveness and reachability requirements are satisfiable or can fail.
