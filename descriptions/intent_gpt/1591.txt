Specify a model of a simple recursive parity-checking routine that determines whether a given nonnegative integer N is even. The system should represent a program that starts by invoking a procedure to test parity on input N and computes a final boolean result indicating evenness. The model must allow the procedure to call a complementary procedure recursively, decrementing the argument at each recursive call, and must model proper call/return behavior so local argument values and the pending return targets are preserved across nested calls. The model should permit an arbitrary finite number of nested calls determined by N, and should handle the base cases that immediately set the result when the argument equals zero. The specification must guarantee termination: every execution starting from the initial invocation eventually returns and produces a stable final result. It must also guarantee functional correctness: the final boolean equals TRUE iff the original input N is even. Additionally, assert stack-safety properties: no call should corrupt stored return locations or older local arguments, and the call/return sequence must behave atomically so that after termination the stack is empty and no procedure is left active. Include invariants capturing these safety properties and liveness conditions ensuring eventual completion.
