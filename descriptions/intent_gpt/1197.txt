Specify a system that evaluates the application of a parameterized operation to a constant argument and exposes the result as a deterministic value. Model a setting where there is a family of operations indexed by an input value; one of these operations is selected by applying that family to a fixed, globally known argument. The model should capture the following requirements:

- The operation family is a total function from a domain of indices to a set of unary operations; each unary operation maps the chosen argument value to a well‑defined result.
- The argument value is a fixed constant visible throughout the system and does not change.
- The system computes the result of invoking the operation obtained from the family at the fixed argument, and the result must be uniquely determined by the operation family and the constant argument.
- There must be no nondeterminism in selecting either the argument or the application result; the mapping and application are deterministic.
- Specify as properties that the computed result equals the composition of the chosen operation and the constant argument, and that any two representations of the operation family that agree on the selected index produce identical results.

Express the model abstractly (no implementation details) and include invariants and a correctness property asserting determinism and consistency of the computed value.
