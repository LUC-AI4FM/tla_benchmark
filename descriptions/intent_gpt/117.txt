Specify a model of a deterministic fold (left-reduce) operation that iteratively updates a finite associative-like mapping from keys to integer counts by applying an update function to each element of a finite sequence. The model should represent:

- A finite domain of keys (a fixed, small set of string identifiers).
- An initial mapping from each key to an initial integer value (for example, zero).
- A finite sequence of keys (elements chosen from the domain) that will be processed in left-to-right order.
- A binary update operation that, given the current mapping and a key from the sequence, produces a new mapping by changing only the component for that key (for example, setting its value to 1 or incrementing a counter), leaving other components unchanged.

The specification must capture the fold-left semantics: starting from the initial mapping, repeatedly apply the update operation to the current mapping using each sequence element in order, producing a final mapping.

State the correctness properties:

- Totality: the fold is defined for every element of the sequence and terminates producing a mapping.
- Determinism: given the same initial mapping, sequence, and update operation, the final mapping is unique.
- Stability of unaffected keys: keys not appearing in the sequence must have their initial values preserved in the final mapping.
- Expected outcome for the given simple update: if the update sets the key's value to 1 when applied, then after folding over a sequence that covers some or all keys, the final mapping must map exactly those keys that appear at least once in the sequence to 1, and all other domain keys to their initial value.

Also require invariants that express these properties and that the fold respects domain constraints (no new keys are introduced).
