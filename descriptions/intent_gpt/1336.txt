Specify a model of an echo/broadcast-style distributed algorithm running on a small connected undirected network of distinct nodes. The system must allow any single node to act as an initiator that starts a flood/echo operation to disseminate a message (or token) to all other nodes and then collect acknowledgements back to the initiator. The network is reliable and undirected: links are symmetric, there are no self-loops, and every node is reachable from every other node. Nodes communicate by sending and receiving messages over point-to-point links; message delivery is asynchronous but reliable (no message loss, no duplication, but arbitrary delays).

Model the local behavior of each node: initiating the broadcast (if it is the chosen initiator), forwarding the broadcast to neighbors the first time the node receives it, recording the parent from which it first received the message, and sending back echo/ack messages to that parent once all neighbors except the parent have replied. The initiator should detect completion when all neighbors have sent back their echoes. Specify that nodes do not forward duplicate broadcast messages and that each node replies exactly once to its parent.

Formalize correctness properties:
- Safety: no node sends an echo to more than one parent; no duplicate forwarding of the same broadcast occurs.
- Liveness: eventually the initiator receives echoes from all neighbors and terminates the protocol (global termination).
- Termination implies that every node has seen the broadcast at least once and has sent its echo upstream.
- The parent relations form a spanning tree rooted at the initiator.

Include assertions that the network size and topology are parameters, and allow verification on small topologies (e.g., 3 nodes).
