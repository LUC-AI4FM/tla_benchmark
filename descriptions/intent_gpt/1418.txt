Specify a simple finite-state counter system that starts at zero and repeatedly increments by one until reaching a fixed upper bound, then stops. The model should capture an initial state and deterministic transition behavior that increments the counter when it is strictly less than the bound, and leaves it unchanged when the bound has been reached. The specification must support checking both safety and liveness properties.

Require the following correctness properties:

- Safety: The counter never takes values below the initial value or above the specified upper bound; every reachable state’s counter value is an integer within the closed interval from the initial value to the bound. Also ensure that each step either increments the counter by exactly one when below the bound, or leaves it unchanged at the bound.

- Progress (liveness): For any execution starting from the initial state, the system eventually reaches the bound (i.e., the counter will reach the upper bound in a finite number of steps). Express at least one liveness property in the form "eventually always" or "always eventually" so it conforms to model checker requirements for temporal formulas.

- Determinism: From any nonterminal state, there is exactly one enabled transition (no nondeterministic choices).

Additionally, the model should allow parameterization of the upper bound and be compatible with typical temporal model checking constraints (so liveness formulas are syntactically acceptable to standard temporal checkers).
