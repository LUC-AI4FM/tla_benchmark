Model a nondeterministic algorithm that computes the maximum element of a finite sequence of integers. The specification should treat the input sequence as immutable and allow the algorithm to inspect elements in any order (i.e., the next index to examine may be chosen nondeterministically from the set of remaining indices). The algorithm must maintain a variable representing the current recorded maximum, initialized to a known lower bound strictly smaller than every possible element in any nonempty input sequence. It must also maintain the set of indices not yet examined, initialized to all valid positions of the input sequence. At each step, one remaining index is chosen, the element at that index is compared with the current recorded maximum, and the recorded maximum is updated if that element is larger; the chosen index is then removed from the remaining set. The algorithm terminates when no indices remain.

Specify safety properties:
- On termination, if the input sequence is empty then the recorded maximum equals the initial lower bound.
- Otherwise on termination the recorded maximum equals one of the elements of the input sequence and is greater than or equal to every element in the sequence.

Specify liveness properties:
- Under weak fairness for the step that processes a remaining index, the algorithm eventually terminates (i.e., all indices are eventually processed).

Do not constrain the order of index selection beyond nondeterministic choice from remaining indices, and do not prescribe a particular implementation strategy.
