Specify a system that models a finite-state configuration space formed by all assignments of a fixed number of independent components, where each component can take values from a fixed finite domain. The model must capture the structure of the state space (the Cartesian product of component domains), allow initializing the system to any one state or to the entire set of states, and support a step relation that may leave the configuration unchanged. The specification should not include any built-in symmetry-breaking or compression techniques; it should represent the full combinatorial state space and enable exploration and counting of states.

The required correctness properties are:
- Safety: no reachable state violates the invariant that every component’s value lies inside the prescribed finite domain.
- Liveness: the model should allow termination or stuttering behavior (i.e., it must permit steps that do not change the configuration).
- Exhaustiveness: the model should make it possible to prove or compute the exact number of distinct configurations (the product of domain sizes) and demonstrate that the reachable state set equals the Cartesian product.
- Deterministic initialization: starting from the initialization relation, the only enabled changes to component values are those allowed by the step relation (which may be none).

Also include a way to print or report the computed size of the configuration space (for tooling output), and ensure the model scales to moderately large products of domain sizes so that state counting can be exercised.
