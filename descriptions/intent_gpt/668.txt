Specify a system that models operations on finite sets and verifies properties of set membership, subset relations, and set construction for a fixed finite universe. The model should allow creation of arbitrary finite subsets of a given universe, as well as operations that form unions, intersections, differences, and complements relative to the universe. It must support existential and universal quantification over elements and subsets, enabling reasoning about whether certain elements belong to constructed sets and whether one set is a subset of another.

The specification must capture tests and invariants about set cardinality: operations that preserve finiteness and respect expected size relationships (for example, the size of a union equals the sum of sizes minus the size of the intersection). It must ensure that computed complement and difference operations are consistent with membership semantics. The model should include properties that exercise edge cases such as empty set, full universe, singleton sets, and disjoint sets.

Correctness properties to guarantee include: closure under the specified operations within the finite universe; soundness of membership predicates after operations; preservation of subset and equality relationships when operations are applied; and satisfaction of standard set-theoretic identities (commutativity, associativity, distributivity) for the modeled operations.
