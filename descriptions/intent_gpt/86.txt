Specify a formal model of the Chang–Roberts ring leader election algorithm for a fixed-size unidirectional ring of N processes (with N ≥ 2). Model the system at the abstract algorithm level: processes have unique nonnegative numeric identifiers, can hold local state, and communicate by sending messages (containing identifiers) to their clockwise neighbor. The model must allow an arbitrary initial distribution of messages and local states (subject to type constraints), and must permit executions consisting of repeated local actions where a process may send, forward, or consume messages according to the Chang–Roberts protocol rules.

Require the specification to guarantee standard correctness properties of leader election:
- Safety: At any reachable state there is at most one process that has declared itself leader, and any declared leader must hold the maximum identifier among all nodes.
- Agreement/Uniqueness: Once a process declares itself leader, no other process may subsequently declare itself leader.
- Termination (under fairness): From any global state, assuming weak fairness for enabled actions, eventually exactly one process declares itself leader (the process with the maximal id), and all processes eventually recognize that leader.

Include type and structural invariants: Node set size equals N, identifiers are distinct and nonnegative, messages carry valid ids from nodes, and message buffers are bounded for model checking. Specify properties both as state invariants and as temporal formulas (safety and liveness) so they can be checked by model and symbolic model checkers.
