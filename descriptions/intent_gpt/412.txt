Specify a formal model of a multiset (bag) abstraction over a finite universe of elements and a set of basic bag-manipulation API. The model should describe bag values as collections that allow multiple occurrences of elements and support construction from sets, bag addition, bag subtraction, union of a set of bags, membership tests, conversion to the underlying set of distinct elements, cardinality (total number of elements counting multiplicity), and counting copies of a particular element. Also model a function that maps each element of a bag to a tuple and produces a new bag of such tuples.

The model must allow creating an empty bag and singletons derived from sets; adding two bags should sum multiplicities; subtracting a bag should remove up to the specified multiplicities (but not produce negative counts); bag-to-set should return distinct elements; bag-union over a set of bags should produce the elementwise maximum of multiplicities or the sum as defined by the intended API (specify which one the system uses); membership returns true iff multiplicity>0. The derived operations must preserve expected algebraic laws: empty is identity for addition, subtraction of a singleton from a bag reduces multiplicity by one (or to zero), conversion round-trips appropriately, counts are nonnegative integers, and cardinality equals sum of multiplicities. Include properties to assert typical examples (e.g., adding a singleton twice yields multiplicity 2) and invariants ensuring all bag counts remain finite and integral.
