Model a simple state machine with one integer-valued state variable that may change nondeterministically according to a fixed set of binary and unary operations. Specify the initial condition that the state equals a given integer constant. At each step the state may be updated to any value obtained by applying any one of a prescribed collection of total operators to the current state and a fixed constant argument, or by applying certain unary transformations to the current state. The set of allowed updates should include ordinary arithmetic (addition, subtraction, multiplication, division, exponentiation), boolean or comparison-derived transforms (less-than, greater-than, equality-like relations producing a value), sequence/interval-like and set-like combinators, and a number of symbolic operators whose semantics are abstract but must be total functions from integers (and an integer argument where binary) to integers. Also include a few postfix and prefix unary transforms. The model must allow nondeterministic choice among all these updates on each step.

Require the specification to state and check these correctness properties:
- Safety: the state variable always remains an integer and never becomes undefined.
- Liveness: from any reachable state there is always some allowed next step (no deadlocks).
- Determinism check: assert whether the transition relation is nondeterministic (it should be).
- Consistency: repeated application of any operator yields well-defined values (i.e., no operator application should cause a runtime/domain error).

Do not encode operator implementations; treat them as total mappings with the above behaviors for verification of the safety, liveness, and determinism properties.
