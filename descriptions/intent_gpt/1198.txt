Specify a formal model of a simple recursive arithmetic function system and its relationships, focusing on factorial-like behavior and consistency between mutually recursive definitions. The model should define an abstract domain of natural numbers and one or more total functions from naturals to naturals that compute factorial values. It must express the base case and recursive case for these functions (value at zero equals one; value at n>0 equals n times value at n-1). The system should allow multiple, possibly mutually-recursive, function names that are intended to denote the same mathematical factorial function; the specification must require they are extensionally equivalent on a useful range of inputs. Include assertions that specific values are correct (for example, factorial(0)=1, factorial(3)=6, factorial(4)=24) and a general property that for an index range the recurrence factorial(i) = i * factorial(i-1) holds. The model should also permit checking that two syntactically different recursive definitions are observationally identical on all natural inputs (or at least on a specified finite range), and it should support obvious consistency checks and simple diagnostics to indicate when those properties hold. Do not prescribe an implementation technique — only state the functions, their required equations, and the key correctness properties to be verified.
