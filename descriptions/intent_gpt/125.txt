Model a deterministic folding operation that incrementally builds a sequence from a set of distinct elements by repeatedly inserting one element at a time into the accumulating sequence using a given binary combining operation. The model should represent the following abstract system and guarantee its correctness properties:

- System: begin with an empty sequence and a finite set of distinct items. At each step, pick one remaining item from the set and apply a deterministic combining function that takes the current sequence and the chosen item and returns a new sequence that extends the accumulator by incorporating the chosen item (for example, by appending the item to the end). Continue until all items from the initial set have been consumed and the accumulator contains every element exactly once.

- Requirements:
  - Termination: the process must terminate after a finite number of steps exactly when the accumulator contains all elements from the initial set and the set of remaining elements is empty.
  - Determinism of fold: for any fixed combining function and initial set, each choice of ordering of set elements induces a well-defined final sequence (i.e., the combining function is a deterministic operator on (sequence, item) -> sequence).
  - Permutation correctness: the final accumulator must be a permutation of the original set — it contains each element exactly once and no others.
  - Independence property to check: specify and enable checking of a candidate invariant that would assert the final result belongs to the set of all permutations of the initial set. Also allow expressing the negation of that invariant to exercise a model checker’s ability to prove unsatisfiability when the invariant is true.
  - Explicitly state that the combining operation preserves distinctness (does not introduce duplicates) and that elements are never lost.

Do not constrain the model to any particular concrete implementation of the combining function beyond the deterministic signature and the distinctness-preservation property.
