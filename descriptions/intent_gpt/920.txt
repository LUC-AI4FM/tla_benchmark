Specify a formal model of a single-message synchronous channel that implements reliable handshaking between a sender and a receiver using a two-state ready/ack protocol and a data payload drawn from a fixed finite set. The model should capture an initially empty channel in a well-typed state, allow a sender to place a new data value into the channel only when the sender and receiver are synchronized (i.e., when ready equals ack), and allow a receiver to acknowledge and consume a pending message only when the sender has signaled a new message (i.e., when ready differs from ack). The channel must carry exactly one data value plus two control bits representing the ready and acknowledge signals. The specification should treat the data set as a constant parameter. It must ensure safety properties: the channel state always respects the type and range constraints, the sender never overwrites an unacknowledged message, and the receiver never acknowledges when there is no pending message. It must also ensure progress liveness: whenever the sender repeatedly attempts to send a value and the receiver eventually responds, the handshake completes (the ready and ack bits alternate to transfer each message). State invariants and transition relations should be written abstractly so they can be checked for invariant preservation and eventual message transfer, without prescribing implementation details or process scheduling.
