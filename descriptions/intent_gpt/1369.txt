Model a simple reactive system with two state components, where one component represents a counter that can be incremented and the other represents an independent value that is not modified by the incrementing step. The system initializes both components to zero. It repeatedly executes a step that increments the counter by one but never changes the other component; the counter must remain within a bounded range (1..10) when incremented. The specification must include standard safety and liveness structure: an initial-state predicate, a step relation describing allowed state changes, and an overall temporal specification that composes invariance of the step relation with a fairness condition asserting that the incrementing step is enabled and will happen fairly. Required correctness properties to guarantee: (1) Safety — the counter only takes values within the allowed range and the independent component is never modified by the increment step. (2) Liveness — if the incrementing step remains continuously enabled, it will eventually occur (weak fairness for the increment step). (3) Nontriviality — the system should permit infinite behaviors (so model checking exercises liveness). Do not commit to any particular encoding of variables or syntactic constructs; specify the abstract initial conditions, permitted transitions, fairness, and the three correctness properties above.
