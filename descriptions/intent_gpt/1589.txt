Specify a model of the classical Euclidean algorithm for computing the greatest common divisor (GCD) of two positive integers. The model should represent a sequential process that starts with two arbitrary positive integers (within some finite bound for model checking) and repeatedly applies the algorithmic steps until the computation terminates with the GCD. The system must allow the algorithm to swap the two values when appropriate and subtract the smaller from the larger (or otherwise reduce the pair) until one value becomes zero, at which point the other value is the GCD.

The specification must state the initial condition (two positive integers in a given range) and the allowed state transitions that capture the algorithm’s iteration without prescribing an implementation language or control structure. It must require termination: the algorithm eventually reaches a halting state. It must guarantee functional correctness: upon termination, the remaining nonzero value equals the greatest common divisor of the original two integers. Invariant properties to assert include that both values remain positive integers throughout, that the GCD of the pair remains invariant at each step, and that any swap action preserves correctness. Additionally, provide a liveness property ensuring progress to termination for all valid initial pairs within the chosen bound.
