Specify a formal model of a verifier that reasons about nested sets of pure mathematical functions and tracks whether a particular witness value satisfies a given predicate. The system should represent collections whose elements are functions from finite boolean sequences to functions from integers to integers, and should allow those collections to contain multiple such functions. Model an initial state in which a designated witness is chosen nondeterministically from a finite set of such functions, and a separate boolean flag records whether the predicate has been observed to hold. The system must not change the witness after initialization, but should permit the predicate flag to be checked or updated by an external inspection operation. Capture operations that (a) test the predicate against the current witness and set the flag true if the predicate holds and (b) leave both witness and flag unchanged to represent idle steps. Specify the invariant that whenever the flag is true, the witness indeed belongs to the initial allowed set and satisfies the predicate. Also require safety properties ruling out invalid predicate claims (no reachable state with flag true and witness not in the allowed set) and liveness properties ensuring that if the predicate eventually holds for the witness the flag can be set to true. Do not constrain internal representation details of functions beyond their types and extensionality.
