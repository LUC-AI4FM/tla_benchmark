Specify a model of a simple reactive system that maintains a single integer-valued state and allows certain guarded state transitions based on enabledness conditions. The model should capture an environment that can either perform a no-op step leaving the integer unchanged, perform a self-update step that assigns a new value computed from the current value, or perform a swap-like or symmetric transition that exchanges two values conceptually present in the guard expression. The specification must express enabledness of compound choices: a transition is allowed when at least one of several alternatives is enabled, including the no-op, the self-update, or the symmetric exchange. The system must support a composite guarded action that conjunctively combines a stuttering step on the main state with the enabledness of such a compound choice where one of the alternatives is a deterministic increment. Key correctness properties to guarantee: (1) safety — every state reached is an integer and no illegal value is introduced; (2) liveness — if the increment alternative becomes continuously enabled, it will eventually occur; and (3) nontrivial enabledness semantics — the enabledness predicate correctly reflects disjunction of alternatives even when paired with a stuttering constraint. The model should be abstract (no implementation details) and suitable for proving these properties.
