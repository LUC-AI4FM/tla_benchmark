Specify a concurrent-state machine that models a simple cyclic counter array with configurable size and multiple independent initial configurations. The system maintains an array of integer registers, each holding a value in 0..K-1, and an opaque index identifying which initial subgraph the execution belongs to. Repeatedly, a single register is chosen nondeterministically and incremented modulo K; the index value never changes. The model must allow different numbers of registers and different modulo sizes as parameters, and it must allow multiple distinct initial states (representing disjoint isomorphic subgraphs) selectable at startup.

The specification should assert and verify these correctness properties:
- Safety: every register value always remains in the range 0..K-1.
- Single-step atomicity: each transition changes at most one register and leaves the index unchanged.
- Liveness/Progress: the system can always perform another transition (i.e., there is always at least one enabled increment action).
- Symmetry/exhaustiveness: all possible choices of which register to increment are representable so the full state space of K^N counter values is reachable from the initial configurations.
- Parameter robustness: the model should detect or reject degenerate parameter settings (e.g., empty domains) and allow reasoning about how state-space size and per-step computation cost scale with parameters.

Do not prescribe implementation details such as data structures or a particular pseudocode control flow; describe only the abstract state, actions, parameters, and the properties to be checked.
