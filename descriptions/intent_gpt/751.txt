Specify a model of the classic cigarette smokers problem with a dealer and a set of smokers, each of whom has an infinite supply of exactly one distinct ingredient. The environment (dealer) repeatedly makes an offer by placing on the table a set of ingredients that is missing exactly one ingredient from the full ingredient set. Each smoker may consume an offer only when the offer contains the other ingredients he needs (i.e., all ingredients except the one he has). When a smoker consumes an offer he uses the ingredients, smokes for a while, and then signals completion; after the smoker finishes smoking the dealer must place a new offer.

Model the system so that it supports an arbitrary finite set of ingredients (not necessarily three), and so that offers are always subsets that omit exactly one ingredient. The model should allow the dealer and smokers to act asynchronously and nondeterministically, subject to the constraints above.

Specify the following correctness properties:
- Safety: at most one smoker may be smoking at any given time.
- Liveness: if the dealer has placed an offer that enables some smoker, then eventually some smoker will start smoking (no offer should remain forever unused).
- Progress of offers: the dealer eventually places offers repeatedly (the system does not deadlock without producing offers).
Also include type and domain invariants ensuring offers are valid subsets and smoking states are well-formed.
