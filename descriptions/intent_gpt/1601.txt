Model a timed mutual‑exclusion protocol for N symmetric processes that coordinate using a single shared memory location and local timers, as in Fischer’s algorithm. The model should abstract processes that repeatedly try to enter, execute, and exit a critical section, and a separate global “tick” activity that advances discrete time. The system must allow processes to perform the following high‑level steps: wait until the shared memory is empty, reserve the shared memory by writing their id, set a local timer to a shorter delay, and, when the timer expires, enter the critical section if still holding the reservation; on exit the process clears the shared memory. Timers count down synchronously on global ticks and can represent an “infinite” disabled value. The specification should treat process ids as 1..N, and model two timing constants: one long delay and one short delay, with the usual Fischer requirement that the long delay is at least the short delay.

Require safety: mutual exclusion must always hold—never may two distinct processes be simultaneously in the critical section. Require progress/liveness: every process that continuously attempts entry should eventually enter the critical section (strong fairness for each process’s entry routine), and the tick activity should be fair so timers advance. Also require that the model can express and check temporal properties that witness potential violations (e.g., existence of a state where two are in the CS, existence of a state where a process has claimed the lock but will not get the CS). Parameterize the model by N, the two delays, and an “infinite” timer sentinel.
