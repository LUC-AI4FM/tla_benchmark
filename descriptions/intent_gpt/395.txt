Specify a model of a simple concurrent state machine that maintains two separate map-like components and evolves them nondeterministically. The system must initialize both components to arbitrary allowed mappings drawn from two distinct type domains: one component maps a fixed finite key set to sets of integers from a given finite range; the other maps the same key set to sets of small records with two fields, where each field's values are drawn from separate finite sets. After initialization, the system repeatedly takes one of several steps: leave both components unchanged, update the first component to an arbitrary allowed mapping from its domain while leaving the second unchanged, or update the second component to an arbitrary allowed mapping from its domain (including specific single-element updates for particular record values) while leaving the first unchanged.

State the invariants the model must check: (1) that a particular target subset of the second component's mapping domain is never simultaneously equal to another specified subset shape (i.e., the model must detect when two distinct collection-typed state descriptions would coincide); (2) type-correctness of both components at all times (they always respect the declared finite domains and record shapes). The specification should permit nondeterminism in the choices of subsets and ensure that the invariant violation triggers an assertion failure. Also require that reachable-state exploration distinguishes initial-state diversity from later-state diversity so that distinct initial assignments are considered distinct states for the model checker.
