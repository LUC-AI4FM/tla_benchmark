Specify a small formal system that models a simple static assertion checker for first-order facts and constants. The system should accept a fixed universe of constants and a collection of ground assertions about those constants. It must support declaring a constant with a concrete value and asserting membership facts about values in singleton sets. The model should allow representing an initial environment that contains a set of declared constants and a set of asserted facts, and it must permit verifying whether a given goal formula follows from those declarations and assertions.

The specification must express what it means for a goal to be provable: the checker should succeed exactly when all conjuncts of the goal are entailed directly by the environment (no inference rules beyond syntactic equality and trivial membership in singletons). One required correctness property is soundness: if the checker reports the goal provable, then every conjunct is indeed true in the environment. Another required property is completeness for the supported fragment: if every conjunct is syntactically satisfied by the environment, the checker reports success. Also specify invariants capturing that the environment is immutable during checking and that the checker does not invent new constants or facts. Describe expected outcomes for both success and failure cases.
