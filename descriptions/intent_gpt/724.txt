Model a library for constructing, serializing, and validating simple SVG documents composed of element objects. The model should describe element values that encapsulate: a tag name, a collection of attributes (possibly represented as maps), an ordered sequence of child elements, and optional inner text. Provide constructors for common SVG primitives (at least line, circle, rect, text, and a grouping element) that produce the appropriate element value with the expected attribute names and textual numeric values. Specify an operation that converts an element value into a canonical SVG string: it must render attributes in a deterministic order, replace any attribute-name placeholder character (used because dashes are not allowed in record names) with the actual dash character in output, escape special characters in text and attribute values, and render children or innerText in the correct position. Include a top-level SVG document constructor that adds standard namespace and viewBox attributes and can accept additional attributes and children.

Specify correctness properties: constructors produce elements whose fields match the expected shapes and attribute/value encodings; the string conversion of an element round-trips in the sense that converting a constructed SVG document yields the precise expected serialized string for a set of representative cases (empty attrs, multiple attrs, nested children, innerText, mixed children+text); and serialization of a document with frame naming should deterministically produce a success indicator (model the success result) for different frame numbers.
