Specify a formal model of a non-deterministic in-place quicksort that sorts an array of N comparable elements using a recursive partitioning work set (stack of index intervals). The model should treat the array as an abstract finite sequence of values drawn from a totally ordered domain and should permit arbitrary choices of pivot positions and of how elements are rearranged by a single partition operation, subject only to the constraints below.

The system must repeatedly pick an interval [lo, hi] from a multiset/set of pending intervals. If lo < hi, it must choose a pivot index p with lo ≤ p < hi and perform a partitioning step that produces a new array that:
- preserves all elements outside the interval [lo, hi],
- permutes only the elements within [lo, hi],
- ensures every element in the left subinterval [lo, p] is ≤ every element in the right subinterval [p+1, hi].

After partitioning, the pending-interval collection must remove [lo, hi] and add [lo, p] and [p+1, hi]. If lo ≥ hi, the interval must simply be removed. The model should allow any partitioning that meets the above ordering and preservation constraints (i.e., it need not implement element comparisons, swaps, or a canonical partition algorithm).

Specify the following correctness properties to be verified:
- Safety: Every step preserves that the global array is a permutation of the original array (multiset preservation) and preserves values outside the currently processed interval.
- Ordering progress: When no pending intervals remain, the array is sorted in nondecreasing order.
- Liveness/termination: The algorithm eventually reaches a state with no pending intervals (termination), under fairness assumptions that prevent starvation of enabled partition choices.
State the domain, invariants, and fairness assumptions needed to prove these properties, but do not commit to a concrete implementation strategy.
