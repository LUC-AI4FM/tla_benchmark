Model a simple single-bit state machine that evolves in discrete steps. The system maintains one boolean state representing a bit. Initially the bit must be false. At each step the system nondeterministically performs one of several operations: a family of parameterized actions that set the bit according to a fixed operation applied to the constant false value, or an unconditional action that sets the bit to false. The parameterized actions are conceptually identical for any parameter value: they compute the next-bit value by applying a fixed boolean operation to false, and then proceed without changing other state. The model should allow the choice of which parameter value to use at each step and should allow the unconditional false-setting action as an alternative.

Specify the system so that all reachable states keep the bit a boolean. Guarantee that the initial condition and all actions preserve well-formedness. State and prove the invariants: (1) the bit is initially false, and (2) the bit is always a boolean. Additionally, assert that no action can introduce values outside the boolean domain, and that the step relation is total in the sense that every step is one of the listed actions. Include liveness-style fairness assumptions only if needed to rule out stuttering; otherwise keep the model purely safety-oriented.
