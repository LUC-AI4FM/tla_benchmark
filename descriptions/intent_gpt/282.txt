Specify a formal model of a single integer-valued variable that starts at zero and may evolve over discrete steps according to a deterministic transition rule. The model should capture an initial condition, the allowed state transitions, and an invariant property that is intended to hold in every reachable state. The transition rule must permit incrementing the value by one only when the current value is strictly negative; otherwise the value must remain unchanged. The invariant to be checked is that the variable never changes between steps (i.e., every transition must leave the value unchanged). Provide the system as a state machine with a clear initial predicate, a next-state relation encoding the conditional increment-or-stay behavior, and an assertion expressing the invariant. Specify the safety property to be verified: the invariant must hold in the initial state and be preserved by every transition. Also request that the model checker be used to search for counterexamples (finite traces) that demonstrate a violation of the invariant, so any reachable transition that changes the variable despite the invariant should be exposed. Include sufficient typing or domain constraints so the variable is treated as an integer.
