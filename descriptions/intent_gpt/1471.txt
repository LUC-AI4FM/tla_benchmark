Specify a simple deterministic counter system that starts at zero and repeatedly increments by one on each step. The model should represent a single, unbounded sequence of states (no branching or nondeterminism) in which a single integer value is maintained and updated. The initial state must set the counter to 0. Each transition must atomically increase the counter by exactly one and yield the next state. The system should allow infinite execution by default but also permit observing termination when the counter reaches a particular target value (a specified exit condition). The specification must expose the capability to check that the counter eventually attains any given natural-number bound (liveness), and must also allow invariant checking that the counter is always a natural number and never decreases (safety). Additionally, the model should permit monitoring or recording of simple run statistics (e.g., number of steps taken, generated state counts) for validation or testing, without affecting the counter’s semantics. Do not include concurrency, shared-memory races, or additional processes; the focus is on a single-threaded, monotonic counter with the stated safety and liveness properties.
