Model a system that manipulates and reasons about a binary relation defined on a finite set, and specify the properties and derived relations that must hold. The model should treat the relation abstractly as a predicate on ordered pairs of elements of a given finite domain. It must allow checking whether the relation is reflexive, irreflexive, symmetric, asymmetric, and transitive with respect to that domain. It must also define the transitive closure of the relation over the domain, and from that the reflexive-transitive closure. The transitive closure definition must be correct for finite domains (i.e., it eventually stabilizes and includes all pairs connected by one or more steps). Using these closures, the model must specify when the relation is connected: for every pair of elements in the domain there is a path (possibly of length zero) from one to the other. Required correctness properties to assert: (1) soundness of the closure constructions (the transitive closure is transitive and contains the original relation; the reflexive-transitive closure is reflexive and transitive and contains the original relation), (2) minimality of closures (no smaller relation with those closure properties contains the original relation), (3) equivalence between connectivity defined via the reflexive-transitive closure and existence of finite paths, and (4) closure stabilization within at most |domain| steps. The specification should not prescribe an implementation strategy.
