Model a distributed system of three labeled nodes where each node maintains a local set-valued function state (two independent maps of node → set). The system should initialize both maps so every node holds the empty set. The only allowed state transitions are local updates that, at any step, choose one of two designated nodes and reset that node’s entry in both maps to the empty set (other nodes remain unchanged). Specify the behavior as an asynchronous transition system whose steps nondeterministically pick an eligible node and perform the reset on that node for both maps simultaneously.

Require the following correctness properties:
- Safety: at every reachable state, the two maps must be identical (pointwise equality across all nodes).
- Liveness: progress should be possible whenever there exists a node whose current entries in the maps are already empty (i.e., the system should not deadlock when enabled resets exist).
- Invariance of initialization: every execution must start from the all-empty assignment and every reachable state must have entries only from the original node set and sets as values.

Also include properties useful for verification: express enabledness of the reset action, supply a state predicate for well-formedness of the maps (domain and value types), and state that only the specified nodes may be reset. Do not assume any additional hidden state or timing; model steps as atomic synchronous updates to both maps for a single chosen node.
