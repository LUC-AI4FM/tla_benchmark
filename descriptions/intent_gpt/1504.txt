Specify a simple reactive system that maintains a single boolean state and never changes it. The model should initialize the boolean to true and then allow an arbitrary number of steps in which the system performs no state updates. The specification must treat the single boolean as the only state of interest and must permit only stuttering steps (steps that leave the boolean value unchanged). The environment may repeatedly schedule steps, but those steps cannot alter the boolean. Formalize the state, initial condition, and allowed transitions so that it is clear the value is always true and invariant under all transitions. Include a liveness assertion that a Next-step is always enabled at every reachable state (i.e., the system never deadlocks). Also include an invariant property that the boolean remains true in all reachable states. The goal is to produce a concise, verifiable formal specification showing both the safety property (value never changes and is always true) and the liveness property (Next-step always enabled), without committing to any particular implementation strategy.
