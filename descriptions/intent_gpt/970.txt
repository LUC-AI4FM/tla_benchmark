Specify a model of a breadth‑first state‑space exploration algorithm that searches a directed state graph for violation states and returns a shortest counterexample path when one exists. The system should accept as input: a finite directed graph with a set of initial states and a set of target (violation) states; a predicate that can prune states depending on their BFS level; a configurable parallelism/window parameter K that controls how many of the next queued states may be chosen for expansion at each step; and a (possibly empty) set of known counterexample sequences for liveness reasoning.

The model must describe exploration semantics (not an implementation): new states are discovered by following transitions from explored states, constrained by the pruning predicate so that successors for which the predicate is false are not enqueued or recorded. Initial states may be explored in any order, and the queue ordering of unexplored states should be represented such that when K = 1 the algorithm always dequeues the head (strict BFS), while K > 1 allows nondeterministic dequeueing among the first min(K, queue length) positions (modeling parallel workers and degraded strictness). Detect and report a counterexample when an initial state or any discovered successor is a violation state, producing a concrete path from some initial state to that violation. Also detect deadlock states (no outgoing transitions except self‑loop) and report them as counterexamples.

Specify correctness properties:
- Safety: any reported counterexample is a valid path in the input graph from an initial state to a violation or deadlock.
- BFS minimality: when K = 1 and the pruning predicate does not remove states on a shortest path, any reported counterexample has minimum length among all reachable violation paths.
- Completeness modulo pruning: if a violation is reachable through states that satisfy the pruning predicate, the algorithm eventually reports some such violation (if the model is fair).
- Termination: if no reachable violation remains (modulo pruning), the exploration terminates with the queue empty.
- Liveness: if a set of known counterexamples is provided, the model should permit the algorithm to eventually stabilize on producing one of those counterexamples; when K = 1, the chosen counterexample should have minimal length among that set.

Do not encode implementation details such as explicit queue removal indices or pair encoding; abstractly model queue semantics, explored set, predecessor information sufficient to reconstruct reported paths, and the nondeterministic dequeue choice constrained by K.
