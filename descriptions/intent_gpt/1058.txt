Specify a TLA+ model of a distributed termination-detection protocol that implements the Dijkstra–Scholten tree algorithm over an arbitrary directed process network. Model a fixed finite set of processes and a fixed directed communication graph in which the distinguished leader has no incoming computation edges. Processes execute an independent computation and may be either busy (active) or idle; busy processes can send application (computation) messages to neighbors, and receiving a computation message makes the recipient busy. Messages (both computation and control/acknowledgment messages) are delivered asynchronously, unordered, and reliably (no loss or duplication). Control messages travel in the opposite direction of computation edges so that any sender of computation can receive acks.

The specification must capture the dynamic construction of an overlay parent relation: when an otherwise neutral process first receives a computation message, it associates that sender as its parent and only relinquishes that parent when it becomes neutral again. Each computation message must eventually be acknowledged to its sender; a process may delay sending an acknowledgment for a message from its parent until doing so would make it neutral. Neutrality means: the process is idle, has no outstanding acks to send for messages received, and has received acknowledgments for all computation messages it sent. The protocol must preserve the invariant that non-neutral processes form a directed tree rooted at the leader.

State the safety property that the leader can become neutral only when the entire system has no pending computation messages and all processes are idle. State the liveness property that if the global computation terminates (every process idle and no computation messages in transit), then eventually the leader becomes neutral (i.e., termination is detected). Also assert consistency relations between local counters and in-transit message counts so that bookkeeping for sent, received, and acknowledged messages is conserved.
