Specify a simple state system that models initialization of a single mutable value from a fixed constant. The system should include a constant parameter that represents an immutable value known at system instantiation time. The only state to model is a variable that must be set to that constant value when the system starts; no other evolution of the state is required or allowed. The specification should make explicit the initial condition that the variable equals the constant and should permit no transitions that change the variable after initialization. The goal is to formally guarantee that throughout every reachable state the variable always equals the constant. Required correctness properties: (1) Initialization safety — the initial state satisfies the equality between the variable and the constant; (2) Invariance — the equality remains true in all reachable states (i.e., it is an invariant); and (3) Liveness trivially holds for the initializer (if a notion of initialization action is used, show that it can occur to produce the initial state). The model should be minimal and leave the constant abstract (unspecified set or value), so proofs and checks must be parametric in that constant.
