Model a system that reasons about a fixed collection of distinct input strings and a deterministic hash function that maps each allowed string to a fixed 6-bit binary vector. The specification should treat the set of allowed inputs as given and the hash mapping as a constant (i.e., chosen at initialization and then immutable during execution). The model must capture only the constraints on the mapping, not any particular implementation of hashing: specifically, the mapping must be a total function from the allowed input set to the space of 6-bit vectors, and it must be injective so that different inputs produce different 6-bit outputs.

Specify an initial condition that allows any mapping satisfying the totality and injectivity constraints. There are no state transitions that change the mapping; the system is static with respect to the hash. Require an invariant that asserts pairwise distinctness of hash outputs for distinct allowed inputs. The correctness property to verify is that this invariant holds for all admissible initial mappings (i.e., that every chosen constant mapping satisfying the stated constraints indeed yields pairwise distinct hashes). The model should be suitable for automated checking over all possible assignments of the constant mapping within the finite domain.
