Specify a declarative model of a library for constructing, laying out, and serializing vector graphic documents (SVG-like). The model should treat graphic content as immutable, tree-structured documents composed of primitive element types (at least: lines, circles, rectangles, text, images, groups, and a root canvas). Each element must carry a name, a map of string attributes, an ordered sequence of children, and text content where appropriate. The system must provide compositional constructors that produce well-formed documents and guarantee attribute precedence when merging attribute maps (attributes supplied by a caller override or are overridden according to a deterministic rule). 

Model layout helpers that compute integer 2D coordinates for standard layouts: placing nodes evenly on a ring, placing points along a line segment, and producing node coordinates for simple directed multigraph layouts. These helpers must be pure functions that always return coordinates in a finite integer domain and must behave deterministically given the same inputs. 

Provide an operator that converts a document into a serializable representation and an operation that writes this representation to file with deterministic, uniquely named outputs (e.g., zero-padded frame numbers). Correctness properties to assert: well-formedness of produced documents (every child is a valid element), determinism of constructors and layout helpers, preservation of attribute precedence on merges, and that serialization produces unique filenames for distinct frame identifiers. Also assert absence of runtime errors (e.g., undefined attribute lookups) and that all produced coordinate values are integers within a specified finite range.
