Specify a simple discrete-state system that repeatedly applies a deterministic, stateless transformation to a single integer-valued state. The system starts from a specified initial integer value and, in each step, updates the state by applying a given total function from integers to integers. The function should be treated as a parameter of the specification (unknown concrete mapping) so that properties can be stated for all possible choices that satisfy constraints.

Require the model to expose the following correctness properties to be checked for every allowable function: (1) Safety: the state must never attain a particular forbidden integer value (the forbidden value is a given constant). (2) Reachability/Progress: optionally, be able to assert whether some target integer value can ever be reached from the initial state under repeated application of the function. (3) Termination/Loop detection: characterize whether execution can continue indefinitely or eventually cycles, and allow checking whether an infinite run exists.

Provide the ability to reason about invariants and to state conditions on the parameter function that guarantee the safety property holds. The specification should be abstract and not commit to any algorithm for enforcing the property; it should simply model state, initial condition, and the step of applying the parameter function.
