Specify a formal model of a pure selection operation on finite sequences: given an initial finite sequence of integers and a predicate on integers, the system should produce as its next state the first element of the sequence that satisfies the predicate, or an empty sequence/value that denotes “no selection” if no element satisfies the predicate. The model should treat the predicate as an abstract, boolean test that can be evaluated on any element, and the initial sequence should be a fixed finite sequence of known integers.

The specification must capture the state transition that replaces the current sequence by the selection result computed from the current sequence and the predicate. It must allow repeated application of this transition (so the selected result can be observed as a state). The model must guarantee that:
- If an element satisfying the predicate exists in the sequence, the new state equals that element (i.e., the selection returns the first such element).
- If no element satisfies the predicate, the new state represents “no element selected” (e.g., an empty sequence or distinct sentinel).
- The selection preserves order: the element returned is the earliest in the original sequence satisfying the predicate.
- No other changes to the state occur besides replacing the sequence with the selection result.

Also specify simple liveness/termination expectations: the selection transition is always enabled and deterministically yields the described result in one step. Include invariants expressing the deterministic nature and the correspondence between the prestate sequence and the poststate selection.
