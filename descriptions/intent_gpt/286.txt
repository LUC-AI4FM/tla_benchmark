Specify a formal model of a simple verifier that compares two function-valued expressions and determines whether they are equal, even when one or both functions have empty domains. The model should represent functions as finite mappings from sequences of strings to sequences of strings, allow explicit construction of a function by listing domain-to-value pairs, and allow the construction of a function with an empty domain and a given default or result sequence. The system must evaluate whether two such function expressions denote the same mapping and record a boolean verdict indicating equality. The specification should capture initial states where a function-valued expression is defined by an explicit singleton mapping and where an apparently equivalent expression is produced by a construction that yields an empty domain mapping to a particular value sequence; the equality check must correctly determine whether these two representations are equivalent. Key correctness properties: (1) the equality verdict is true exactly when the two function expressions denote identical mappings for all possible keys (including when domains are empty), (2) the model never produces a spurious equality when mappings differ on any key, and (3) the equality decision is stable (once decided it does not flip). Also include a property to assert that the equality decision is a boolean. The goal is to ensure the verifier treats empty-domain function constructions consistently with explicit finite mappings.
