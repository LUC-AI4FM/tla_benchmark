Specify a concurrent-state system that maintains a finite map from string identifiers to records that include a nonnegative integer counter. The system must support an initial global state where the map contains a predefined set of keys with specified initial counter values, and may also include additional keys initialized uniformly (for example, a small family of keys initialized to zero). The system evolves in discrete steps: in each step, either the entire map remains unchanged, or a single designated key’s counter may be decremented by one but never driven below zero. Decrements must be applied atomically to the chosen key’s counter; other keys remain unchanged during that step.

Model the state space, the allowed transitions, and the initialization so that all reachable states are well-defined maps from identifiers to records with integer counters. Specify that counters are always integers and that any decrement operation uses a nonnegative-result rule that yields zero if the arithmetic would otherwise produce a negative value.

Formalize the following correctness properties to verify:
- Safety: every counter in the map is always greater than or equal to zero.
- Invariance: a particular key’s counter never becomes negative under all behaviors.
- Reachability/termination: characterize reachable states (e.g., whether counters can be reduced to zero) and allow checking liveness queries if desired.

Do not commit to any particular implementation structure (e.g., imperative or algorithmic); instead specify the state variables, initial state, transition relation, and the invariants and properties to be checked.
