Specify a formal model of quantifier and choice-expression semantics for a small deterministic state machine whose state is trivial but whose invariant checks exercise predicate logic, bounded quantification, and deterministic choice. The model should represent a system that does not change state over time (a stuttering system), and its main purpose is to validate logical reasoning about existential and universal quantification over finite sets, empty sets, Cartesian products, tuples, and nested quantifiers, plus the deterministic selection operator that picks a unique element satisfying a predicate when one exists.

Requirements:
- Express quantifiers over finite sets (including repeated elements in a set literal and the empty set), over Cartesian products, and over tuple-structured domains.
- Express nested quantifiers mixing different domains and tuple variables, and allow quantification over sets that themselves contain sets.
- Specify a deterministic choice operator that returns the unique element satisfying a predicate when exactly one such element exists; the model should treat the choice as undefined or error if no unique element exists, and should permit reasoning about expected equalities when a unique choice is present.
- Include a collection of boolean assertions (invariants) that must hold in every reachable state; these assertions should capture typical logical identities and corner cases: existence and universal claims for true/false predicates, behavior over empty domains, interactions between exists/forall and tuples/products, and correctness of the choice operator in simple cases.
- The correctness property is that all assertions/invariants hold globally: every reachable state satisfies every logical test (i.e., no assertion failures). The model should enable checking and reporting which logical tests pass or fail.
