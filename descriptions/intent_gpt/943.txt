Specify a model of a simple 12-hour clock counter that cycles hours from 1 through 12 indefinitely. The model should represent a single state variable holding the current hour value and must allow only legal hour values in the set {1,2,...,12}. The transition relation must advance the hour by one on each step, wrapping from 12 back to 1. The behavior must start in a state satisfying the allowed-hour constraint and then follow the defined cyclic transitions forever.

Require the following correctness properties:
- Safety: every reachable state must contain a legal hour value (no illegal numbers appear at any time).
- Liveness/Progress: the system should be defined to make a step at each transition (the hour always advances according to the rule).
- Invariant preservation: the allowed-hour constraint must hold initially and be preserved by every transition.

Additionally, define an initial condition and a next-state relation concise enough to enable model checking; include a temporal formula stating that from any state satisfying the initial condition, the allowed-hour invariant holds globally. Avoid implementation details; focus on the abstract state space, the deterministic cyclical update rule, and the properties to be verified.
