Model a distributed spanning-tree construction and termination-detection protocol for a fixed connected undirected network of nodes. The system must produce a rooted spanning tree and determine when the construction is complete. The model should describe nodes that maintain a numeric depth value and a parent pointer toward a designated root, exchange nonincreasing sequence-valued messages over directed communication queues between neighbors, and update local state based only on received messages and local comparisons of depths. The intended guarantees are:

- Safety: At all times depth values are integers in a bounded range, parent pointers refer to valid neighbor nodes (or the root), and message contents respect the invariant that each queue carries a sequence of node identifiers in strictly decreasing order with elements bounded below by the sender’s current depth.
- Convergence: Eventually no messages remain in any communication queue (global quiescence).
- Correctness of the final tree: When the system reaches quiescence, every node’s parent pointers define a tree rooted at the designated root, and each node’s depth equals its graph distance (number of hops) to the root. In particular, following parent pointers from any node reaches the root in exactly depth hops.
- Liveness: The protocol must guarantee termination (global quiescence) from any initial legal configuration in the connected network.

Specify the network topology, neighbor relations, allowed message contents, and the abstract local update rules sufficient to achieve these properties; do not prescribe a concrete implementation or ordering of internal steps. Include invariants and the final-postcondition to be proven.
