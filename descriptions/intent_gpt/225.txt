Specify a simple finite-state control process that begins in a designated initial state and can nondeterministically transition between named control states. The model should include at least one deterministic transition and at least one transition that nondeterministically selects a value from a small finite domain and then moves to a particular target state. Require that the initial state is a unique, explicitly named starting point. Require that every step of the system is either the deterministic move to a specific state or the nondeterministic choice-based move to another specific state. Formally capture execution as a sequence of states linked by those allowed transitions.

State the desired safety property: the system must never reach a particular forbidden control state. Specify this as an invariant to be checked over all reachable states. Also require that reachability and invariant verification consider the nondeterministic choices in the transition that selects values from the finite domain. Do not prescribe an implementation strategy; instead, describe the system behavior, allowed transitions, initial condition, and the invariant to be maintained so a formal specification can be written and model-checked.
