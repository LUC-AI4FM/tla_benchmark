Specify a formal model of finite sets and their basic properties suitable for reasoning about algorithms that manipulate small collections. The model should express what it means for a set to be finite, provide a definition of the number of elements in a finite set, and support reasoning about membership and containment without relying on a particular implementation. The specification must:

- Define finiteness by existence of a finite sequence (or equivalent construct) whose elements are exactly the elements of the set, ensuring duplicate-elimination semantics typical of sets.
- Define a total cardinality function only for finite sets that returns the exact number of distinct elements; the definition may be recursive or constructive but must be well-founded and deterministic.
- Guarantee that cardinality obeys standard algebraic laws: the empty set has cardinality zero; adding an element not already present increases cardinality by one; removing an element present decreases cardinality by one; cardinality of a subset is ≤ cardinality of the set.
- Support proofs (or invariants) that rely on enumeration: every element of a finite set appears at some position in some finite sequence enumerating the set, and conversely every element of that sequence belongs to the set.
- Make clear that the cardinality operator is undefined or inapplicable for infinite sets and that finiteness must be checked before using cardinality.

Model these requirements abstractly so they can be composed with higher-level algorithms that manipulate finite collections.
