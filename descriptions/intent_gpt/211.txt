Specify a system that incrementally builds a finite set drawn from a fixed finite universe and maintains a separate numeric value that always equals the set's cardinality. The system should allow adding individual elements from the universe to the set one at a time (including adding an element already present, which leaves the set unchanged). The numeric value must be updated whenever the set changes so that it always equals the number of distinct elements currently in the set.

Model the control state and data state abstractly: the data state includes the current set (a finite subset of the universe) and the current stored size (a nonnegative integer). Define initial conditions in which the set is empty and the stored size is zero. Define transitions that represent selecting an element from the universe and adding it to the set, together with the corresponding update to the stored size.

Specify correctness properties: (1) safety — invariance that the stored size equals the true cardinality of the set at all reachable states; (2) type and bound invariants — the set remains a subset of the universe and the stored size is within valid numeric bounds (nonnegative and no larger than the universe size); and (3) liveness — every element of the universe can eventually be added (if desired), so the model permits execution sequences that reach any desired subset. Do not constrain the implementation technique for computing cardinality; allow abstract or recursive definitions as needed but require that they satisfy the invariants.
