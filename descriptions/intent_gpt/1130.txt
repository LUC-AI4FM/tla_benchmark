Model a bounded FIFO message queue system used by a single producer and single consumer where the queue holds at most a fixed number of messages drawn from a fixed finite message set. The model should describe the abstract states of the queue (its contents as a sequence), and the two kinds of atomic operations that may change the state: an enqueue that appends a message to the tail if the queue is not full, and a dequeue that removes the head element if the queue is not empty. The specification must allow nondeterministic choices of which message to enqueue (from the finite set) and of when either operation occurs, but must never allow enqueues beyond the capacity or dequeues from an empty queue.

Formally state safety properties to be checked: (1) message integrity — every element in the queue is always a valid message from the allowed finite set, and (2) capacity safety — the queue length never exceeds the fixed capacity. Also require liveness properties expressing that whenever the queue is non-full and the environment continually attempts to enqueue, eventually an enqueue can occur, and whenever the queue is non-empty and the environment continually attempts to dequeue, eventually a dequeue can occur (i.e., no permanent starvation under continuous requests). Finally, allow checking for state-space explosion behavior by making the message set and capacity parameters adjustable so that experiments can measure memory, disk, and handle usage of the model checker.
