Model a binary-search algorithm that operates on a fixed-width machine integer address space and a read-only, finite sequence of integers. The model should take as parameters: the input sequence, the search key, and the machine integer bit width (so arithmetic and overflow wrap-around behavior can be captured). The system must initialize a search interval covering the whole array and then repeatedly narrow the interval by comparing the key with the element at a chosen midpoint until the algorithm terminates with either a successful index or a sentinel indicating "not found."

Specify the following requirements and correctness properties, independent of any particular implementation:

- Preconditions: the input sequence is provided and may be required to be sorted for classical binary search correctness; the machine integer width bounds arithmetic.
- Termination: for any allowed input and key, the algorithm must eventually terminate (no infinite loop) under the intended semantics of fixed-width integers.
- Safety (result semantics): when the algorithm reports success it must return an index that points to an element equal to the key; when it reports failure it must return a value that unambiguously indicates that the key is not present (use the same convention as many libraries: a negative sentinel encoding the would-be insertion point).
- Soundness under sorting assumption: if the input sequence is sorted, then the success/ failure decision must be consistent with membership of the key in the sequence.
- Robustness of arithmetic: the specification must account for integer wrap-around and guarantee that midpoint computation and interval updates do not violate indexing bounds or produce undefined behavior in the modeled machine arithmetic.
- State observables: distinguish termination flag and returned value so properties can assert correctness only when the search completes.

Do not prescribe loop structure or exact midpoint formula; allow any design that satisfies the above termination and correctness requirements while respecting fixed-width integer semantics.
