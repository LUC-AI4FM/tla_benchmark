Specify a formal model of a deterministic functional graph cycle detector and validator for a finite set of nodes. The model should treat the system as a function that maps every node to exactly one successor (a total function on a finite nonempty vertex set). The model must capture the notion of a single simple directed cycle that visits every vertex exactly once: there exists an ordering of the vertices such that following the successor function repeatedly from any starting vertex yields that ordering cyclically and returns to the start after exactly N steps (where N is the number of vertices). The model must permit arbitrary finite nonempty vertex sets and arbitrary total successor mappings, and must characterize precisely when such a mapping constitutes a Hamiltonian directed cycle (simple cycle covering all vertices).

State the correctness properties to verify:
- Existence property: if the mapping is claimed to be a simple cycle, then every vertex has a unique predecessor and unique successor, and repeated application of the mapping from any vertex visits all vertices before returning to the start after N steps.
- Uniqueness property: there is no smaller positive k < N such that k repeated applications of the mapping return to the start for every vertex (i.e., the cycle length equals the vertex count).
- Safety property: no vertex is repeated before all distinct vertices have been visited.
Also require invariants expressing finiteness and totality of the mapping, and provide an artifact suitable for model checking of these properties over arbitrary finite vertex sets.
