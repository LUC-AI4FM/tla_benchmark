Specify a simple two-component state machine that models transferring ownership of two distinct resources between two collections while tracking a small control tag. The system has a finite set of possible values for each resource type and a distinguished initial value for each type. Initially, the first collection is empty, the second collection contains the second resource's distinguished value, and a control string records the initial phase. The system must allow exactly one transition that moves the first resource into the first collection, removes the second resource from the second collection, and updates the control string to indicate the transition occurred. Model the state as three components: the first collection (a set of values of the first resource type), the second collection (a set of values of the second resource type), and a control tag (a string). The spec should define the initial condition, the single-step state change, and the reachable states.

Require the following correctness properties be specified and checked:
- An invariant stating that at any reachable state, at least one of the two distinguished resources is present in its respective collection (i.e., the second resource is in the second collection or the first resource is in the first collection).
- Safety: the transition must preserve the invariant.
- Liveness: the single transition should be enabled from the initial state and leads to a state where the control tag is updated to the transition phase.

Do not commit to implementation details such as variable names or the exact encoding of types; describe only state components, transitions, and properties to verify.
