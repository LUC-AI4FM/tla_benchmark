Specify a model of a simple iterative exponentiation process that computes powers of a fixed integer base by repeated multiplication. The system should start with a fixed positive integer base and with an initial exponent counter and accumulator representing base^counter. It should repeatedly perform a step that increments the counter by one and multiplies the accumulator by the base. The specification must capture the invariant relationship that the accumulator always equals the base raised to the current counter.

Model requirements:
- The base is constant throughout execution and is an integer chosen at initialization.
- The counter is a nonnegative integer that increases by exactly one on each step.
- The accumulator is an integer that is updated on each step to be the previous value multiplied by the base.
- The initial values must satisfy the invariant: accumulator = base^counter.

Correctness properties to guarantee:
- Safety: At every reachable state the invariant accumulator = base^counter holds.
- Determinism of the step relation: each step deterministically increments the counter by one and multiplies the accumulator by the base.
- Preservation of base: the base value never changes.

Additionally, state any necessary type or domain constraints (e.g., integers) and require that the invariant is maintained for all reachable states. No implementation detail about how the step is written should be assumed.
