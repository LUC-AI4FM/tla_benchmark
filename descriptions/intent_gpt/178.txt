Specify a small sequential system that models evaluation of a local binding (a non-nullary let) inside a larger expression and the effect of that evaluation on a simple state variable. The model should represent a state with an integer-valued variable that initially equals zero and can transition to a state where the variable equals one. Concurrent behavior and fairness are not required.

The specification should capture that the expression being evaluated contains a locally defined function (a lambda-like binding that takes an argument) and that this local function is applied to an integer constant during evaluation. The semantics to model are: the local binding is created, the local function is invoked with the constant argument, the invocation yields a Boolean result (true), and that evaluation occurs as part of an atomic step that also updates the state variable from zero to one.

Formally specify the initial condition, the allowed transition(s), and the invariant properties. Required correctness properties:
- Safety: the only possible state values are 0 and 1; starting from 0 any state where the variable is 1 must have been reached by the evaluation step described.
- The local function application always yields true for the given constant argument.
- The evaluation and update occur atomically (no intermediate states where the local binding exists separately from the state update).

Also include a simple temporal property: eventually the variable becomes 1.
