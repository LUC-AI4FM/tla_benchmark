Specify a simple state machine that cycles through named abstract states and can nondeterministically transition between them. The model should capture an initial state labeled "Init" and two possible atomic transitions that move the system into two distinct states named "A" and "B". Transitions should be enabled at any time (nondeterministic choice) and execute atomically, producing the indicated target state. The specification must assert that the initial condition and transitions are the only ways the state can change, with no hidden or extra state components.

Require a safety property that forbids ever reaching the particular state named "B" (i.e., "B" is an illegal/forbidden state) and ensure that this invariant holds in all reachable states of the system. Also require that the model cleanly represents reachability from the initial state using the defined transitions only.

State the correctness criteria: (1) the invariant is true in the initial state, and (2) it is preserved by every allowed transition. The specification should be suitable for model checking the invariant and for finding counterexamples if the forbidden state is reachable.
