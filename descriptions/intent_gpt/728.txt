Model an abstract library for finite undirected graphs and their basic analysis routines. The specification should support graphs given as a finite set of nodes and a finite set of undirected edges (each edge is an unordered pair of distinct nodes). The model must provide operations to enumerate all simple paths (no repeated nodes) in a graph, to compute the connected components, and to decide whether two nodes are connected. It must also specify a predicate that checks whether a graph is connected (single component). The model should treat isolated nodes and empty graphs correctly.

Required functional behavior:
- Simple-path enumeration returns exactly the set of sequences of distinct nodes that correspond to paths in the graph (paths length ≥ 1, including single-node trivial paths).
- Connected-components returns a partition of the node set into disjoint, nonempty subsets such that nodes are in the same subset iff there exists a path between them.
- A connectivity predicate returns true exactly when there exists a path between the two given nodes.
- The graph-connectedness predicate returns true exactly when the connected-components partition is a singleton containing all nodes.

Key correctness properties to assert:
- Paths contain only nodes from the graph and adjacent nodes in a path are connected by an edge.
- No path repeats nodes.
- Connected-components are pairwise disjoint, cover exactly the node set, and correspond to reachability equivalence classes.
- Connectivity and graph-connectedness are consistent with the connected-components result.

Specify these behaviors and properties for arbitrary finite graphs; include test-style assertions expressing expected results on representative small examples (empty graph, isolated nodes, single-edge, small connected graphs).
