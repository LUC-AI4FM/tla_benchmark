Model a pure mathematical recursive function computation that represents factorial-like evaluation with a mutual-recursive dependency on an externally provided procedure instance. The specification should capture an abstract evaluator that computes a numeric function f(n) defined by:

- f(0) = 1.
- For any positive integer n, f(n) = n * g(n-1), where g(x) denotes the value supplied by an instantiated external computation for argument x.

The model must allow the external computation to be instantiated or supplied as a parameter so the evaluator composes with it (i.e., mutual recursion where one side is provided by an external module). Specify how the evaluator invokes the external computation and uses its numeric result to compute f(n), for natural-number arguments.

State the intended facts that the system must guarantee: base-case correctness for 0, correct multiplicative recursion for successive integers, and consistency with factorial values for a sample set of inputs (for example: f(0)=1, f(4)=24, and for all i in some small range, f(i)=i*f(i-1)). Express these as invariants or assertions to be checked by the model checker. Also include a simple mechanism to output or report successful verification of these properties. The specification should be abstract (no operational code), focused on correctness properties and compositionality with the external instance.
