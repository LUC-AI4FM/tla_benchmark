Specify a simple state-transition system that models a single integer-valued state variable representing a counter. Initially the counter must be zero. The system repeatedly performs one of two kinds of updates in each step: a short update that sets the counter to the result of a deterministic, terminating computation that computes the factorial of a small constant (e.g., 3), or a long update that sets the counter to the result of a deterministic, terminating computation that computes the factorial of a larger constant (e.g., 9). Both computations must be total and guaranteed to terminate for the given constant inputs; their results are assigned atomically to the counter in a single step. The system should allow either update nondeterministically at every step.

Specify the allowed initial states, the transition relation, and the overall behavior as all executions starting from the initial state and taking only the permitted transitions. State the safety properties that must hold: the counter is always equal to one of the concrete factorial values produced by those computations, and every transition assigns exactly one such value. Also state liveness expectations: the system does not deadlock (there is always some enabled transition) and executions may choose either kind of update indefinitely. Do not prescribe how the factorial computations are implemented internally beyond that they terminate and return the correct integer result for the specified inputs.
