Model a simple single-variable sender that repeatedly emits sequence-labeled messages until it finishes, and formally specify its reachable states and safety properties. The system maintains an unbounded (but finite in any execution) ordered log of sent message identifiers drawn from the set {1,2} and a small integer-controlled send counter that starts at a specified initial value within 0..3. On each enabled send step, if the counter indicates a value in the allowed send range, the system must append the counter's current value to the end of the log and increment the counter by one. When the counter exceeds the allowed send bound, the system must stop performing send steps and remain quiescent thereafter (no further changes to state).

Specify the initial conditions, the transition relation (send step and quiescent termination), and the invariant that the state always satisfies the type constraints: the log is a finite sequence of elements from {1,2} and the counter always stays within 0..3. Require that once the system reaches the quiescent state it remains stable (stuttering). Also require that every element in the log equals a value the counter had at the time it was appended, and that the log contains at most one occurrence of any counter value appended after the counter had advanced past that value (no retroactive appends). Finally, prove that the system cannot append values outside {1,2} and that from the given initial counter the send behavior either produces a finite sequence of valid messages and then halts, or else continues only while the counter is within the allowed range.
