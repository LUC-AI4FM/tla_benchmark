Specify a formal model of a language or expression-evaluation subsystem that supports user-defined binary and unary infix and operator-symbol forms, including punctuation and Unicode operator symbols. The model should treat every operator symbol as a first-class binary or unary operator with well-defined arity and deterministic evaluation semantics, independent of whether the symbol is alphanumeric or nonalphanumeric. It must allow the same operator meaning to be referenced in both infix and prefix notation, and permit multiple syntactic spellings (e.g., alternative Unicode equivalents or symbol-variants) to denote the same semantic operator. The model must also allow operators to be asserted by assumption (external definitions) and used uniformly in expressions, sets, and function-application contexts.

Key correctness properties:
- Well-formedness: every parsed expression has a clear operator, operand count matching the operator's arity, and a unique interpretation.
- Consistency: if two syntactic forms are declared equivalent to the same operator, any evaluation or equality checks yield identical results.
- Determinism: evaluation of any expression composed from assumed operator definitions yields a unique value.
- Compositionality: evaluation of complex expressions is determined solely by the operator meanings and operand values (no hidden context-sensitive rules).
- Conservativity: introducing user-defined operators cannot change semantics of unrelated built-in constructs.
Also require the model to support simple set and membership assumptions so operators can be used inside set expressions, and include properties that permit checking that a concrete assumed mapping of a few sample operator forms produces the expected tuple-encodings of arguments.
