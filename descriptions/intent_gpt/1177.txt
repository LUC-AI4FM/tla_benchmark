Specify a simple parametric test harness that models evaluation of assumptions used by a model checker. The system should represent a single distinguished test selector that can be set to one of several fixed test cases. For each test case, define a different assertion or assumption about basic expressions that the model checker will evaluate immediately at model initialization. The harness must include at least: (a) a test that asserts a plain contradiction so that the model's initial assumption is unsatisfiable, and (b) a test that asserts an ill-typed or runtime-error-producing expression so that evaluation of the assumption fails with a type or evaluation error. The model should be organized so that only the assumption corresponding to the chosen test case is active during initialization. The specification must state the expected outcome for each test case: the contradiction test should produce an unsatisfiable-assumption result, and the ill-typed test should produce an evaluation error. Specify no implementation details about how the model checker reports these results, and do not prescribe particular variable or operator names—only the logical behavior of the selector, the per-test assumption activation, and the required observable outcomes.
