Specify a formal model of the classic Dining Philosophers system with N philosophers sitting around a circular table and N forks (one between each adjacent pair). Philosophers repeatedly alternate between thinking and trying to eat. To eat a philosopher must hold both adjacent forks; each fork can be held by at most one philosopher at a time. The model should allow asynchronous, interleaved actions of philosophers and not prescribe a particular scheduling policy.

Requirements:
- Safety: never allow two adjacent philosophers to eat simultaneously (no two neighbors may hold the same fork, so adjacent eating states are forbidden).
- Mutual exclusion for forks: a fork can be held by at most one philosopher at any time.
- Liveness / progress: each philosopher that tries to eat will eventually succeed (starvation freedom). The model should express both weak fairness for philosopher steps and the stronger liveness requirement that each philosopher infinitely often enters the eating state.
- Parameterization: the model must be parameterized by N (N ≥ 1), so correctness must hold for any number of philosophers.
- Symmetry and leader option: allow modelling a symmetric protocol in which philosophers use the same local algorithm, and permit an alternative protocol variant where one distinguished philosopher may use a different order of picking forks (to break potential deadlock).
- Nonimplementation constraints: specify the intended behaviors and correctness properties, not a particular encoding—do not hardcode process program counters or stack mechanics.

Express the system in TLA+ with an initial state, a Next relation capturing legal atomic steps, invariants for safety, and temporal formulas for starvation freedom and fairness.
