Specify a formal TLA+ model of the Slush consensus primitive (the simplest Avalanche-family protocol) as a distributed, asynchronous message-passing system of N hosts. The model should describe how hosts initially uncolored acquire an initial color from clients, repeatedly sample a fixed-size set of other hosts, query them for their current preferred color, and update their own preference based on a threshold of matching responses. The model must support concurrent execution of querying (querying processes) and answering (query processes) with messages in flight and without relying on probabilistic choice in the specification (sampling and message delivery may be modeled nondeterministically). Sampling must be from the set of other hosts and exclude self. Hosts must run a bounded number of consensus rounds; after completing their rounds they broadcast termination so that responders stop answering. The specification should capture: initialization of node colors (uncolored or one of two colors), query and reply message structure, the selection of a sample set of fixed cardinality, the per-round tally and threshold rule to adopt a color, and message removal after processing.

State the correctness properties to be verified:
- Safety: once all non-terminated hosts have the same preferred color, no subsequent actions can cause any host to adopt the opposite color (consensus is absorbing).
- Agreement (eventual strong agreement for deterministic traces): if all hosts terminate, they agree on a single color.
- Termination liveness: every host that begins with a color completes the prescribed number of rounds and eventually enters termination.
- No message corruption: replies correspond to queries sent earlier (no spurious messages).
Also specify invariants to check: color domain preservation, message typing, sample-set size constraint, and that queries are always directed to distinct other hosts.
