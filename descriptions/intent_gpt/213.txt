Specify a system that manages a set of records representing entities with several immutable identity fields and several mutable attributes (including an integer age and some boolean flags). The system must allow adding a new record with fixed values for all fields, and it must allow incrementing the age of an existing record, producing a new record that replaces the old one. Adding the same record twice should not create duplicates: the set of records must behave as a mathematical set (no duplicates). When updating age, the update must actually change the record (the new record must not be syntactically identical to the old one). The system should also permit steps that leave the set unchanged.

Model the system as an unbounded discrete-state transition system over a set of records. Require that initially the set is empty and the system starts in a valid state. The primary safety invariant is that every record’s age remains strictly less than a fixed upper bound (15) at all times. The specification must assert that every transition preserves this invariant. Also specify that the “add” transition always produces a well-formed record with all fields defined, and the “increment age” transition only applies to an existing record and yields a record whose age is one greater. Finally, include a liveness property that from any reachable state it is always possible to either add a new record, increment some record’s age (without violating the age bound), or stutter (do nothing).
