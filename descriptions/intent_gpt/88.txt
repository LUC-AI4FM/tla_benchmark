Model a single-message, two-way handshake channel that reliably transfers data values from a sender to a receiver using ready/acknowledge signaling. The model should describe a stateful channel that can hold at most one datum at a time and uses two binary control signals to coordinate send and receive: a "ready" indicator set by the sender to announce a new datum, and an "ack" indicator set by the receiver to consume it. Specify the allowed initial states, the send operation that places a datum into the channel only when the handshake is idle, and the receive operation that consumes the datum only when the handshake indicates data is available. The model must enforce typing and domain constraints on data and the control signals, and must preserve those invariants by every transition.

Formally state safety properties: (1) the channel never holds more than one datum, and control bits are always boolean; (2) a send may only occur when ready equals ack (handshake idle); (3) a receive may only occur when ready differs from ack (data available); and (4) the value read by a receive is the last datum sent while the handshake was in the appropriate state. Also state liveness requirements informally: sent data must eventually be acknowledged (the handshake must progress) and the protocol should not deadlock when sender and receiver continue to attempt their actions. Finally, require a theorem asserting that the type invariant holds in all reachable states.
