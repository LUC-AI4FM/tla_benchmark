Specify a state machine that models a single integer-valued counter which starts at an unspecified value within a given inclusive starting range. The counter may evolve nondeterministically in discrete steps; at each step the counter can increase by an amount that depends on the current value, with two distinct growth regimes determined by threshold ranges. The model should permit growth that is nondeterministic but bounded above by a regime-specific maximum increment and must never decrease. The specification must also express an invariant property asserting that the counter never equals a particular forbidden value. Formally state initial states, all allowed transitions, and the invariant to be checked. Additionally, include liveness goals showing that the counter can always continue to make a next step when it is below very large upper bounds (i.e., it should not deadlock while still within allowed ranges). Provide assertions or temporal properties to check that (a) all reachable states respect the invariant, and (b) from any reachable state within the allowed operational ranges, a successor state satisfying the transition rules exists. Do not prescribe an implementation strategy; describe only the abstract state space, transition relation, and correctness properties.
