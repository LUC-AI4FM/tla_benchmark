Specify a model of a small distributed system that tracks a numeric global phase and a collection representing currently-known nodes. The system begins in an initial state with the numeric phase equal to a fixed initial value and the collection empty. One atomic transition moves the system from that initial phase to a next phase value and simultaneously updates the collection to some subset of a fixed finite universe of node identifiers; the update may choose any subset but must be well-defined as a subset of the universe.

The specification should treat the universe of node identifiers as a constant parameter and allow any nonempty finite set for it. The model must ensure that the numeric phase variable always equals the designated initial value in all reachable states where the type invariant is checked (i.e., provide an invariant that constrains the phase to the initial value), so the tool can verify whether that invariant holds under the transition relation. Also specify an initial-state predicate and a single-step transition relation that captures the phase increment and the simultaneous replacement of the node collection by an arbitrary subset of the universe.

Finally, require checks for deadlock (whether the system can reach a state with no outgoing transitions) and verification of the phase-type invariant. Do not prescribe internal naming or implementation style; only describe the state components, their allowed values, the initial condition, the single-step behavior, and the correctness properties to be proved.
