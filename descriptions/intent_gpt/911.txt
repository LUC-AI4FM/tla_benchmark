Specify a model of a simple 12-hour clock that advances its hour reading once on each discrete step and wraps from 12 back to 1. The model should treat the hour as a single state component ranging over the integers 1..12. The system must always start in a valid hour value and, on every transition, either increment the hour by one when it is less than 12, or reset it to 1 when it is currently 12. No other changes to state are permitted. The specification should make clear that steps are atomic, deterministic, and repeated indefinitely.

State the safety properties that must hold: the hour value is always within the set {1,2,...,12} (invariant), and every transition conforms to the specified increment-or-wrap rule (transition correctness). Also state the liveness expectation that the clock continues to advance forever (no deadlock): from any reachable state there is always a next transition. Finally, include a proof obligation that if the initial state satisfies the valid-hour predicate, then it continues to satisfy it for all future steps (i.e., initial validity implies invariant holds globally).
