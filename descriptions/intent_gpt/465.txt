Specify a model of a simple state machine that maintains a single boolean state and does not change it after initialization. The system must start in a state where the boolean is true and every step must leave the state unchanged (i.e., the only allowed transitions are stuttering steps). The specification should express and check a collection of set-construction and membership expectations about finite sets and Cartesian products that act purely as invariants (they are logical assertions about constant expressions, not dynamic behavior). In particular, require assertions that verify: (a) set comprehensions with integer elements and duplicates yield the expected unordered set; (b) set comprehensions over empty domains produce empty sets; (c) Cartesian-product-based comprehensions produce the expected ordered-pair elements; and (d) numeric expressions built from iterated comprehensions produce the expected ranges and contain particular integers. The model must assert these properties at all reachable states (they are invariants) and must fail the check if any asserted set equality, membership, or cardinality condition is false. The goal is to validate that the language semantics for finite set constructors, Cartesian products, tuple membership, and finite-range expressions behave according to mathematical set semantics while the machine otherwise remains inert.
