Specify a formal model of a persistent mapping from a small finite set of integer keys to finite sets of integer values. The model should allow the mapping to start in any of several initial shapes: either defined only on a single key with an empty value set, or defined on no keys at all (an empty map), or defined on no keys with a separately described potential mapping that would map an absent key to a non-empty singleton set. The system must treat the mapping as an immutable or stable state after initialization (no transitions that change the mapping are allowed). 

Require the specification to represent maps whose domain may be empty or contain a single integer key, and whose range for each present key is a finite set of integers (including the empty set). The model must explicitly allow and distinguish the possibility of an empty map versus a map with a key mapped to an empty set and versus a map where a key is mapped to a singleton set. 

Specify invariants that rule out any state that is not one of the allowed initial shapes and prove that all reachable states satisfy those invariants (i.e., the map never changes and remains one of the permitted configurations). Also require explicit typing constraints ensuring keys and values are integers and the mapping is a function from a finite domain to finite sets.
