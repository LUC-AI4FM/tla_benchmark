Specify a TLA+ model of an algorithm that, given a fixed finite circular string (a sequence of characters drawn from a known finite character set), computes the starting index of the lexicographically least rotation of that string. The model should treat the input string as immutable and represent rotations as cyclic shifts of the string; equal rotations are ordered by their numeric starting index to break ties (i.e., prefer the smallest index among equal rotations). The algorithm must examine characters (and possibly maintain auxiliary indices and a small auxiliary array) but the specification must not commit to a particular implementation technique—only the abstract behavior and required invariants.

Require the following correctness properties:
- Safety: At termination, the reported index denotes a rotation that is lexicographically less-than-or-equal-to every other rotation of the input string; if a rotation equals it, its starting index is not smaller.
- Type and domain invariants: all data structures and indices always remain within their declared finite domains (array indices inside bounds, indicator values drawn from specified sentinel values when used).
- Termination: the procedure terminates after a finite number of steps for any finite input string.

Also specify useful auxiliary definitions: what a rotation is, lexicographic ordering of sequences, and the set of all rotations. Express the main correctness property in terms of these definitions and ensure the model allows checking those invariants and termination for arbitrary finite inputs.
