Specify a simple state-transition system that models choosing a nontrivial subset from a fixed finite set and replacing the set with that subset in a single step. The initial state contains a given finite set of distinct elements (for example, three distinct atoms). The system must allow exactly one kind of state change: pick any subset of the current set whose cardinality is at least two and make that subset the new current set. The model should permit non-deterministic choice among all qualifying subsets, but must not permit choosing the empty set or any singleton. Stuttering (no-change) transitions may be excluded or explicitly represented as a separate allowed step, but the primary requirement is that any transition that changes the state results in a subset with size ≥ 2. Specify the invariant that the current set is always a subset of the original initial set and that its cardinality never increases. Specify a liveness property that eventually no further strict subset with size ≥ 2 can be chosen (i.e., the process can terminate in a state where no allowed transition exists), and a safety property that every reachable state contains at least two elements until termination. Also require that all possible choices are represented (non-determinism exhaustive) and that the model treats the initial set as immutable except via the allowed subset-replacement transitions.
