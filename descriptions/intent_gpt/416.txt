Specify a small concurrent state-transition system in which a shared mutable array of fixed length and an independent integer-valued control variable evolve under nondeterministic atomic steps. The array has at least two positions initialized to distinct values; the control variable is initialized to a particular constant. The system must allow three kinds of transitions: (1) a step that updates the control variable to a new value and performs an array update whose effect may depend on the new value of the control variable (i.e., the array update should be able to observe or use the concurrently updated control value), (2) a step that updates the control variable to the same new value but performs an array update that must not observe that new value (i.e., the array update must behave as if it saw the old control value), and (3) stuttering steps that leave both the array and the control variable unchanged.

Model must capture that the two update behaviors are distinct and testable: one transition should be considered correct only if the array entry reflects the new control value after the transition; the other should be considered correct only if the array entry remains reflecting the old value. Specify safety properties asserting these expected outcomes for the respective steps, and include an invariant that the array always remains a mapping from the fixed index set to integers. Also require fairness conditions or nondeterminism sufficient to allow each of the two update steps to occur from the initial state so the differing observational behaviors can be exercised and checked.
