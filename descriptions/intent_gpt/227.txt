Specify a simple finite-state reactive system that models a component with an internal mode that can change nondeterministically between a small set of named states. The model should capture an initial mode and two kinds of transitions: one that moves the component deterministically to a particular named mode, and another that moves it nondeterministically to a different named mode while allowing local quantified choices and local temporary collections used only in the computation of that transition. The nondeterministic transition should include at least one existential choice over a small finite domain and may bind auxiliary local sets or values whose scope is limited to that transition. The system should allow either transition at each step.

Specify an invariant property stating that a particular named mode is never reached. The specification must express that the initial mode is the given start value, define the allowed step relation as the disjunction of the two transition kinds, and require that the invariant holds in all reachable states. Also require that the model be suitable for model checking: finite state space, explicit finite domains for all quantified choices, and clear separation between global state and transition-local auxiliary data.
