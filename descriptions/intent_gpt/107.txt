Specify a simple discrete-state system with two integer-valued state components that start at zero and evolve in synchronous atomic steps. In each step, the system nondeterministically chooses a pair of integers (i, j) from a given Cartesian product of two finite integer ranges, and updates the two state components to those chosen values. The ranges for the first and second components must be parameters of the specification (for example, the first range could be 1..2 and the second 3..4), so the model can be reused with different bounds.

The specification should assert the initial condition that both state components equal zero, and define the step relation that assigns the chosen pair to the two components in a single atomic transition. It must allow nondeterministic existential choice of any pair in the Cartesian product on each transition.

Specify and verify the following correctness properties: (1) Safety — every reachable state has each component equal to some value within its prescribed range or equal to the initial zero state only before any transition; (2) Invariance — once a component takes a value within its range it never leaves the set comprised of that range (i.e., no values outside the union {0} ∪ range); (3) Liveness — from the initial state, it is always possible to reach a state where both components have values from their respective ranges; and (4) absence of deadlock — from any reachable state there exists a next transition. Include the ranges as parameters so they can be adjusted for model checking.
