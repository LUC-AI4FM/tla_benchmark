Specify a protocol that constructs a spanning tree rooted at a designated root process in a connected undirected network of processes. Model each process as an asynchronous agent that can send point-to-point messages along existing network links and can record a chosen parent. The system must start with no parent assignments and no sent messages. Only the root or a process that already has a parent may send a message over a link. When a process without a parent receives a message from a neighbor, it may adopt that neighbor as its parent. Once a process adopts a parent, it must record that fact and may no longer be in the unparented state. Messages may be sent repeatedly but self-consistency of parent choices must be preserved with respect to the network topology (a chosen parent must be a neighbor). The specification should guarantee eventual termination: eventually every non-root process has selected a parent that is one of its neighbors. Key safety properties: (1) parent pointers are always either a special “no parent” value or a neighbor; (2) once a process has a parent, that stored parent value persists (no spontaneous change); (3) no process other than the root ever sends messages while it remains unparented. Key liveness property: every non-root process eventually becomes parented. Also require a type invariant for messages (messages are pairs of processes) and for parent and acknowledgement status. Do not prescribe message delivery ordering or timing beyond eventual progress assumptions sufficient to ensure termination.
