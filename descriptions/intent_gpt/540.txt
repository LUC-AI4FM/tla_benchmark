Specify a sequential algorithm that, given a nonnegative integer parameter n, computes in a finite sequence of steps the first n square numbers and stores them in an indexed array of length n+1 (indices 0..n). The system should initialize the array so that every entry is zero and use an iterative loop that updates entries deterministically until completion. The algorithm must not read or write outside the index range 0..n and must terminate with a program-counter or control-state indicating completion.

The specification must require that after termination:
- The k-th array entry (for each k in 0..n) equals k^2.
- Every update step changes exactly one array entry (or otherwise clearly documents which entry is updated), and the index updated must remain within bounds.
- The iteration count increases monotonically and starts at 0, ensuring termination in at most n iterations.

Formalize safety properties asserting:
- Bounds safety: indices accessed or assigned are always in 0..n.
- Correct update invariant: whenever the loop has progressed to index i (0 ≤ i ≤ n), the array entries 0..i equal the squares 0^2..i^2.
- Single-writer property for each step: no simultaneous conflicting updates occur.

Formalize the liveness property:
- Termination: the control-state eventually reaches the completed state and the array satisfies the square-number postcondition.
