Specify a TLA+ model of a distributed mutual exclusion algorithm based on Lamport’s Bakery idea adapted for a message-passing network. The system consists of a fixed finite set of processes (nodes) and bidirectional communication links between every ordered pair of distinct nodes. Each process repeatedly executes a protocol to enter a critical section: it reads other processes’ announced ticket numbers, chooses a positive ticket larger in the lexicographic ordering than any competing tickets it observed, broadcasts its ticket to others, waits for acknowledgements or conditions that guarantee it has priority, enters the critical section, and on exit broadcasts a release (ticket 0). Message delivery is asynchronous but reliable and FIFO per sender-recipient pair; messages are either "write" (ticket value) or acknowledgement. Message handling may update local views of peers’ tickets and generate replies.

Model the local state of each process (its program control point and local ticket), the per-link message queues, and any auxiliary bookkeeping needed to simulate reading remote values and tracking pending acknowledgements. The spec must assert and prove the following correctness properties:
- Safety (mutual exclusion): no two distinct processes are in the critical section simultaneously.
- Liveness (starvation-freedom): if a process starts the entry protocol it will eventually enter the critical section under weak fairness of process steps and message deliveries.
- Type and integrity invariants: values and message formats remain within their intended domains, and per-link FIFO ordering and message semantics are preserved.

Do not commit to a concrete implementation strategy; allow nondeterministic message arrival and nondeterministic choices of ticket numbers consistent with the protocol’s ordering constraints.
