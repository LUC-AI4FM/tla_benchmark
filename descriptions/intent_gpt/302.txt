Specify a formal model of a binary-search procedure over a finite, ordered array of integers. The model should describe a deterministic algorithm that, given an input sequence and a search key, repeatedly narrows an inclusive search range until it terminates with a single result. The model must capture only the algorithmic intent and the observable outcomes, not a particular implementation.

Requirements:
- Inputs: a finite sequence of integers and a single integer key.
- The algorithm must maintain an inclusive low and high index that bound the remaining candidate positions; initially the range must cover the entire sequence.
- Termination is signaled explicitly and yields an integer result value.
- If the key appears at one or more positions in the input, the result must encode a valid index of an occurrence (use zero-based or one-based indexing consistently and state which convention is used).
- If the key does not occur, the result must be a negative value that deterministically encodes the insertion point (the index where the key could be inserted to preserve order), following the standard convention used by many libraries (negative of insertion-index minus one).
- The model must allow reasoning about the invariant that the true set of matching indices lies within the current low..high interval while the search is in progress.
- Specify the halting condition and a postcondition that relates the final result value to the membership (or absence) of the key in the input.
- State assumptions: input sequence is sorted in nondecreasing order and indices and arithmetic are within a given machine-integer range; avoid overflow in midpoint computation.
