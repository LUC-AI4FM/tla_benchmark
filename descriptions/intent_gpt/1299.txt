Specify a model of finite partial and total functions and tuple/sequence values, intended to validate reasoning about element selection, update, and equality between different representation forms. The model should represent finite maps (functions over a finite integer domain) and sequences/tuples as distinct value types, allow selecting an element by index, and allow creating updated values that replace a particular position with a new element. The system must support comparing a map and a sequence for semantic equality when they represent the same mapping from indices to values. It must also define and detect valid and invalid index-update operations, and report or classify attempts to update an index that is outside the domain of a value. Specify operations that: given a map or a sequence, return the value at a given index; produce a new map or sequence with a single index updated; and compare whether two values (map and sequence, or sequences) represent the same element-wise contents. The correctness properties must state that updating an index in a map or the equivalent sequence yields values that are equal when domains match; that out-of-domain updates are handled safely (either produce a well-defined extended value or are rejected and flagged as an error); and that equality comparison is symmetric and respects element-wise equivalence. Provide invariants ensuring no silent mismatches between map and sequence representations.
