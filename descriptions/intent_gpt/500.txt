Model a multi-decree consensus system (Multi-Paxos) with distinct proposers, acceptors, and learners that repeatedly agrees on values for an unbounded but finite set of ordered slots. The model should capture message-passing between processes and the two-phase prepare/accept protocol used to establish a value for each slot across ballots (proposal numbers). The system must allow proposers to pick ballot numbers, run an aggregated prepare (collecting replies from a quorum of acceptors to learn previously accepted values per slot), and then propose values for particular slots in a given ballot. Acceptors must record the highest ballot they have seen and the highest accepted (ballot, value) for each slot, and must only respond to prepare or accept requests according to the Paxos rules (refuse lower ballots, reply with prior accepted information, and accept a value when the ballot is not lower than their promise). Learners must determine that a value is chosen for a slot when they observe matching acceptances from an entire quorum.

Specify the safety properties: (1) Agreement — for each slot, at most one value may ever be chosen; (2) Integrity — if a value is chosen for a slot, it must have been proposed by some proposer; (3) Monotonic ballots — acceptors never decrease their promised ballot numbers; and (4) Valid quorum intersection — any two quorums intersect (assume this as a system parameter). Also state liveness goals to be satisfied under eventual reliable communication and a stable leader: progress for deciding slots (eventual learning of proposed values) when a single correct proposer repeatedly acquires increasing ballots and a majority of acceptors respond. The model should be parameterized by finite sets of proposers, acceptors, quorums, learners, slots, ballots, and possible values.
