Specify a system that models a single boolean flag whose evolution depends on a computed set derived from the current state. The model should treat the flag as the only externally visible state and require that initially the flag is true. On every step, the system either leaves the flag unchanged or updates it according to whether a certain derived collection is empty. The derived collection is computed deterministically from the current flag value: when the flag has a particular value, the collection contains a fixed mapping; otherwise it is empty. The transition rule must enforce that, whenever the next value of the flag is chosen, it equals "empty?" — true iff the derived collection is empty. Permit stuttering steps (no change) as well as steps that change the flag according to that rule.

Specify the following correctness properties to be verified:
- Safety: the flag never takes a value other than true or false, and every non-stuttering transition satisfies the relation "next flag value equals (derived collection is empty)".
- Liveness: from any reachable state it is always possible (not necessarily inevitable) to perform either a stuttering step or a step that sets the flag consistently with the emptiness of the derived collection.
- Invariance: if the system starts with the flag true, any state reachable by only stuttering steps preserves the derived collection corresponding to true.
