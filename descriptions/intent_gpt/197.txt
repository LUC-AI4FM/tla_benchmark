Model a nondeterministic set-transformation system that maintains a finite set of integers drawn initially from the range 1..10 and having at least five elements. The system repeatedly picks an element from the current set and transforms the set according to a rule that depends only on whether the chosen element is even or odd. If an even element is chosen, it is removed and the element equal to twice its value is inserted in its place. If an odd element is chosen, it is removed. The choice of which element to pick at each step is nondeterministic. The model must allow values produced by doubling to leave the initial 1..10 range and must permit sets to shrink below the initial size when odd elements are removed.

Specify the initial condition, the step relation expressing the two alternative transformations, and the reachable-state space. State and check these correctness properties: (1) Safety: every reachable state contains at least one positive integer; (2) Invariance of finiteness: the set remains finite in all states; (3) Reachability/termination-related property: characterize whether infinite execution is possible (i.e., whether the process can continue forever without deadlock) and whether there exist executions that eventually stabilize (no further change). Also specify liveness properties to express fairness of choices (optional) and, if fairness is assumed, the effect on eventual removal or repeated doubling of particular elements.
