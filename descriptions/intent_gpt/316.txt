Specify a formal model of a binary search algorithm that operates on a finite sequence of integers and a target integer key. The model should treat the input sequence and the search key as arbitrary but fixed values for a single run, and should not assume any particular implementation details such as variable names or step-by-step code structure. The system must perform a binary search over the sequence indices, using explicit low and high bounds that converge toward the target position or an empty interval, and must terminate either by reporting an index where the key resides or by indicating the key is not present.

Require that the model enforce these functional properties:
- If the algorithm returns an index, the index is within the legal range of sequence indices and the element at that index equals the key.
- If the algorithm reports failure (no index), then the key does not occur anywhere in the input sequence.
- The search invariants that enable binary search are preserved: at every point, all elements to the left of the current low bound are either known to be less than (or greater than) the key as appropriate, and all elements to the right of the current high bound are known to be greater than (or less than) the key, ensuring the target, if present, remains within [low, high].
- The algorithm terminates after a finite number of steps for any finite input sequence.

Additionally, require a measure or variant function that strictly decreases each iteration to prove termination, and specify properties to detect invalid outputs (out-of-range indices or incorrect element matches).
