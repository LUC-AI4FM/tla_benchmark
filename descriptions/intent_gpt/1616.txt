Specify a small sequential program that nondeterministically chooses among a few simple assignments and then computes and prints a result. The model should capture an initial state, a sequence of labeled steps, and termination, but must not prescribe a particular implementation structure.

Requirements:
- The system starts with two integer state items initialized to zero.
- In the first step, a fixed constant value is assigned to the first item.
- In the next step, the second item is assigned either of two possible small integer values; this choice is nondeterministic. Immediately after that assignment, the first item is updated by adding the new value of the second item.
- After that, the flow branches depending on the value of the second item: if that value equals one, the first item is incremented by one and then doubled in a subsequent step; otherwise, the first item is incremented by the second item and the algorithm proceeds directly to termination.
- The algorithm prints the final value of the first item and then halts.
- The model must allow fairness so that enabled steps eventually occur, and it should permit stuttering after termination to avoid deadlocks.

Correctness properties to specify and check:
- Safety: the computation of the first item follows the arithmetic described above and no other values are produced.
- Liveness: the system always reaches the termination state (eventual termination).
- Deterministic outcomes: enumerate the possible final printed values and assert that only those values are reachable.
