Specify a formal TLA+ model of a pure, deterministic fold-left operation that iteratively combines an initial set with the elements of a finite sequence using set-union as the binary operator. The model should represent an immutable sequence of integers and a fixed initial set of integers; no concurrency or mutable state beyond representing the inputs and the result is needed. Define the fold-left semantics so that processing the sequence in left-to-right order produces a final set equal to the union of the initial set and every element of the sequence. Require the model to capture the case where the sequence may contain duplicate elements and ensure duplicates do not affect the final set beyond normal set semantics. Specify correctness properties:

- Functional correctness: the fold-left result equals initial_set ∪ {all elements appearing in the sequence}.
- Determinism and termination: the fold completes in a finite number of steps and yields a unique result independent of any irrelevant implementation choices.
- Idempotence on duplicates: including repeated occurrences of an element does not change the final set beyond the element being present.
- Robustness to element order: for set-union, the final set must be independent of the order of elements in the sequence (i.e., any permutation of the same multiset of elements yields the same result).

Also include a safety assertion that would be violated if the fold-left were incorrectly implemented to exclude any element present in the inputs.
