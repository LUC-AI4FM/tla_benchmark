Specify a concurrent-state system that models a simple state machine with seven state components, some of which are controllable and others that are environment-supplied. The system must repeatedly perform a single atomic transition that simultaneously updates a subset of the state components according to fixed deterministic or nondeterministic rules, while leaving the remaining components unchanged. The model should capture an initial condition that constrains one numerical component to a given starting value and imposes no constraints on the other components at start-up.

The specification must express that every step of the system performs the transition atomically, and it must allow one component to nondeterministically take any value from a fixed finite set in each transition. Another component must be set deterministically to a particular constant value on every transition. A further component must be assigned the Boolean result of an equality test between two external constants. Two components and one additional component must be explicitly unchanged by the transition relation.

Formal properties to guarantee:
- Invariant: the designated numerical component is not required to change except by the initial condition; behavior must preserve that its only initial value is the specified one, and transitions can later update it to the specified value.
- Liveness/temporal shape: the behavior must be captured as always following the atomic transition relation (i.e., all steps satisfy the transition).
- Safety: all updates must conform to the allowed deterministic or nondeterministic value sets; unchanged components must remain constant across every transition.

Provide the model so that it can be checked with model checking tools for these safety and temporal properties.
