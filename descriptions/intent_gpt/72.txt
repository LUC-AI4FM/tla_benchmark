Specify a model of a simple typed-record construction facility and a trivial expression evaluation in which the system builds a record with a fixed type tag and then computes a constant result. The model should describe two conceptual steps: (1) create a record-like value that carries an explicit type identifier (a string or symbolic tag) and zero or more named fields; and (2) evaluate or return a simple constant expression that does not depend on the record fields. The specification must make explicit the intended shape of the record (the presence and name of the type tag and any fields), the invariant that the type tag equals a particular constant string, and that the record construction produces a well-formed record value. The model should also state that the subsequent evaluation step yields a particular constant value of an appropriate type (for example, a string or symbol) regardless of the record contents. Key correctness properties: record-formation invariants hold whenever the record value exists; the type tag equals the required constant; evaluation of the trivial expression always terminates and returns the specified constant; and the evaluation does not change the record-formation invariant. The specification should be abstract and avoid committing to an implementation strategy.
