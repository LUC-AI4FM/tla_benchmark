Model a small distributed system in which each node holds a flag indicating a request for a resource and independently chooses a target node to contact. The model should capture the following elements and requirements:

- Two nodes in the system; each node has a Boolean-like request indicator (requested vs not requested) and a chosen target (a node identifier). A node that is not requesting may still have a target choice; the target must always be one of the nodes.
- Define the allowed pairs of (request flags, target choices) so that whenever a node’s request flag is set, its chosen target must equal that node itself (i.e., a requesting node must point to itself). Non-requesting nodes may point arbitrarily to any node.
- Model state evolution where the system may update the whole collection of request flags and targets in an atomic step; transitions must preserve the above consistency constraint across all nodes.
- Specify initial states where no node is requesting, and targets may be arbitrary (but valid).
- Require invariants: (1) the self-pointing condition for requesting nodes holds in all reachable states; (2) targets are always valid node identifiers. Also require that safety properties hold under all permitted transitions (no transition can produce an inconsistent pairing).
- Include a liveness requirement that the system can always perform at least one transition (no deadlock) provided there exists some valid update that preserves the consistency constraint.
