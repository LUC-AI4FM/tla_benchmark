This TLA+ module represents the initial skeleton of a binary search specification, labeled as Version 1 in a tutorial series.

The module defines three constants: INPUT_SEQ (a sequence of integers representing the array to search), INPUT_KEY (the integer value being searched for), and INT_WIDTH (the bit-width for machine integer representation). These are typed for the Apalache model checker.

The specification establishes mathematical definitions for integer bounds based on the specified bit-width: MAX_UINT represents the maximum unsigned integer value (2^INT_WIDTH), MAX_INT represents the maximum signed integer value (2^(INT_WIDTH-1) - 1), and MIN_INT represents the minimum signed integer value (-2^(INT_WIDTH-1)). These definitions suggest the specification will eventually model overflow-aware integer arithmetic.

The behavioral specification is essentially empty in this version. The Init predicate is simply TRUE, meaning any initial state is valid. The Next predicate is also TRUE, meaning any state transition is permitted. Both contain comments indicating "don't care," signaling this is a template awaiting actual implementation.

This module imports Integers, Sequences, and Apalache extensions. No invariants, safety properties, liveness conditions, or fairness constraints are specified. The module serves as scaffolding for subsequent versions that will implement the actual binary search algorithm.
