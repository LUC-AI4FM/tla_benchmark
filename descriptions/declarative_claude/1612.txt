This TLA+ module tests the semantics of simultaneous multi-assignment statements involving arrays in PlusCal.

The specification models three concurrent processes (numbered 1 through 3), each executing independently. Each process maintains its own local array A (initialized with values 1 through 5 at indices 1 through 5) and a variable x (initialized to 0).

The key behavior occurs in a single atomic step where each process performs a simultaneous swap: array element A[1] receives the value of A[3], A[3] receives the value of A[1], and x is set to 7. The critical aspect being tested is that this multi-assignment executes atomically using the original values—meaning A[1] and A[3] are swapped correctly rather than one assignment affecting the other. After this step, A[1] should equal 3 and A[3] should equal 1.

The variables include pc (program counter tracking each process's location), A (a function mapping each process to its 5-element array), and x (a function mapping each process to its integer value).

The specification includes weak fairness for each process, ensuring all processes eventually complete. The module verifies a termination property asserting that all processes eventually reach the "Done" state. Assertions embedded in the algorithm confirm the swap executed correctly, validating that simultaneous assignments see pre-update values.
