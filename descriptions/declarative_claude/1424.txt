This TLA+ module specifies a simple system that demonstrates type heterogeneity in state transitions, where a single variable can take on values of incompatible types.

The system models a variable `x` that starts at zero and can transition to values of three different types: natural numbers, booleans, or strings.

**Variable:** The sole variable `x` holds the system state.

**Initial State:** The variable `x` begins with the value zero.

**Next-State Relation:** The `Next` action allows three possible transitions. The variable can become any natural number from 1 to 100, creating numerous successor states. Alternatively, it can become the boolean value `FALSE` or the string `"abc"`. This design intentionally creates many successor states to test hash collision behavior in model checking data structures.

**Temporal Specification:** The specification `Spec` requires the initial condition to hold and permits stuttering steps where `x` remains unchanged, following the standard TLA+ pattern with the stuttering-allowed next-state formula.

**Liveness Property:** The property `Prop` asserts that eventually the system reaches a state from which `TRUE` holds forever. Since `TRUE` is a tautology, this property trivially holds for any behavior—it essentially checks that some continuation of the behavior exists.
