This TLA+ module is a test suite for the FiniteSetsExt library, which provides extended operations on finite sets. The module contains no state machine behavior—it consists entirely of ASSUME statements that verify the correctness of various set operations at specification load time.

The module tests several operators from the FiniteSetsExt library. **Quantify** counts elements satisfying a predicate, verified against equivalent cardinality computations, including a test with two million elements to confirm it avoids intermediate set construction. **kSubset** returns all subsets of a given cardinality k, tested for correctness against a pure TLA+ definition using set comprehension, including edge cases with negative k or k exceeding set size. **FoldSet** applies a binary function across set elements with an accumulator, tested on integer summation including a large range to verify stack efficiency. **ChooseUnique** selects the unique element satisfying a predicate, with error handling tests for cases with zero or multiple matching elements. **SymDiff** computes symmetric difference between sets. **SumSet** and **ProductSet** compute sum and product of numeric sets. **ReduceSet** generalizes folding with an operator. **FlattenSet** unions nested sets into a single set.

The configuration specifies Init and Next, though the actual definitions are commented out, as TLC requires a behavior specification to evaluate ASSUME statements during initialization.
