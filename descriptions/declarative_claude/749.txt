This module provides type annotations and concrete values for model-checking the classic Cigarette Smokers problem, extending an underlying `CigaretteSmokers` specification via instantiation.

The specification models a concurrency problem involving a dealer and multiple smokers. Each smoker has one unique ingredient and needs two others to smoke. The dealer repeatedly places two random ingredients on a table, enabling exactly one smoker to proceed.

**Constants**: `Ingredients` represents the set of three ingredients (matches, paper, tobacco), while `Offers` contains all possible two-ingredient combinations the dealer can provide—each being the complement of one ingredient.

**Variables**: The `smokers` variable maps each ingredient to a record tracking whether that smoker is currently smoking. The `dealer` variable holds the set of ingredients currently offered on the table.

**Specification**: The module inherits its temporal specification `Spec` from the instantiated `CigaretteSmokers` module, which defines the initial state and next-state relation governing dealer offers and smoker actions.

**Invariants**: Two safety properties are checked. `TypeOK` ensures variables maintain correct types throughout execution. `AtMostOne` verifies that at most one smoker smokes at any given time, preventing simultaneous smoking—the core mutual exclusion property of this synchronization problem.
