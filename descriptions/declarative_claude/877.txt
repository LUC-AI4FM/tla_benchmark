This module provides a formal TLAPS proof that the SpanTree specification preserves its type invariant across all reachable states.

The module extends an existing SpanTree specification, which models a distributed spanning tree algorithm on a graph. The algorithm operates on a set of Nodes connected by Edges, with a designated Root node. The constants include Nodes, Edges, Root, and MaxCardinality (an upper bound on the node count). The variables are dist (mapping each node to its distance from the root) and mom (mapping each node to its parent in the spanning tree).

The proof establishes the theorem TypeCorrect, which states that the specification implies the type invariant TypeOK holds in all states. TypeOK requires that dist maps nodes to natural numbers and mom maps nodes to nodes.

The proof proceeds by induction: first showing that Init establishes TypeOK, then showing that any Next step (or stuttering step) preserves TypeOK. The Next action allows a node to update its distance and parent when it discovers a shorter path through a neighbor. The proof demonstrates that when a node n adopts a new distance d derived from neighbor m's distance, the resulting d remains a natural number, and m remains a valid node, thus preserving the type invariant.
