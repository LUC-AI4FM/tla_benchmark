This module specifies a solution to the classic "100 Prisoners and a Light Bulb" puzzle. A group of prisoners must determine when all of them have visited a room containing two switches, with only one designated counter allowed to track progress.

The constants define a set of prisoners and a distinguished counter prisoner. The variables track the boolean states of switches A and B, how many times each non-counter prisoner has flipped switch A up (limited to twice), and the counter's tally of switch A flips down.

The strategy works as follows: non-counter prisoners flip switch A up when they find it down, but only if they haven't already done so twice; otherwise they toggle switch B. The counter flips switch A down whenever it's up, incrementing the count; otherwise the counter toggles switch B. The initial state allows either switch position, with all counts at zero.

The next-state relation allows either the counter or any other prisoner to take a step. Weak fairness on all prisoner actions ensures every prisoner enters the room infinitely often.

The specification verifies a safety property stating that when the count reaches twice the number of non-counter prisoners, every prisoner has visited the room at least once. A liveness property confirms this done condition is eventually reached. An auxiliary invariant relates the count to the sum of individual switch-ups, and an additional property checks that count equals zero infinitely often. The configuration uses four prisoners with p1 as counter.
