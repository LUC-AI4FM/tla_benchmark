This TLA+ module is a test suite for verifying the correctness of sequence operators from the SequencesExt library. It uses Apalache-style type annotations throughout.

The module defines a trivial state machine with both Init and Next set to TRUE, creating a single-state system. This structure allows all tests to be checked as state invariants rather than as properties of state transitions.

The specification tests numerous sequence operations including: ToSet (converting sequences to sets), SetToSeq and SetToSortSeq (converting sets to sequences with optional sorting), Contains (membership testing), Reverse, Remove, ReplaceAll, InsertAt, RemoveAt, ReplaceAt, Cons, Front, Last, prefix and suffix predicates (IsPrefix, IsStrictPrefix, IsSuffix, IsStrictSuffix), Prefixes, CommonPrefixes, LongestCommonPrefix, folding operations (FoldSeq, FoldLeft, FoldRight), FlattenSeq, Zip, SubSeqs, IndexFirstSubSeq, and ReplaceFirstSubSeq.

Each test is a named boolean definition asserting expected behavior for specific inputs, covering edge cases like empty sequences and various element types including integers, strings, and sets. The module references an Apalache instance for helper functions like FunAsSeq and SetAsFun.

The AllTests definition conjoins all individual test predicates into a single invariant. When model-checked, this verifies that every sequence operator produces correct results, serving as a regression test for the SequencesExt library implementation.
