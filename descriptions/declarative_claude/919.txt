This TLA+ module provides a machine-checked proof of type correctness for a channel specification defined in a separate Channel module.

The module extends two components: the Channel module (which contains the actual system specification) and TLAPS (the TLA+ Proof System library for formal verification).

The sole purpose of this module is to establish the theorem TypeCorrect, which states that the specification Spec implies the temporal property that TypeInvariant holds in all reachable states (expressed as []TypeInvariant, meaning "always TypeInvariant").

The proof proceeds in two steps following the standard invariance proof pattern. Step 1 establishes that the initial condition Init implies TypeInvariant holds initially. Step 2 shows that TypeInvariant is preserved by any transition: if TypeInvariant holds and either a Next action occurs or the channel variable stutters, then TypeInvariant continues to hold in the successor state. This step relies on the definitions of TypeInvariant, Next, Send, and Rcv actions from the Channel module.

The final QED step combines these results using PTL (propositional temporal logic) reasoning to conclude that the invariant holds throughout all behaviors satisfying Spec.

This module contains no system behavior itself—it exists purely to formally verify a safety property of the Channel specification.
