This TLA+ module defines a simple specification that demonstrates higher-order operator usage and remains in a fixed state throughout execution.

The module defines two operators: `Foo` is a higher-order operator that takes an operator `Op` and a set `S`, returning true if and only if `Op` holds for every element in `S`. `Bar` applies `Foo` with a lambda expression that checks whether each element belongs to the natural numbers.

The specification has a single variable `x`. The initial state sets `x` to the result of `Bar({1,2,3})`, which evaluates whether all elements of the set {1, 2, 3} are natural numbers. Since 1, 2, and 3 are all natural numbers, `x` is initialized to `TRUE`.

The temporal specification `Spec` combines this initial condition with a stuttering-allowed next-state relation that requires `x` to remain unchanged in every transition. This means the system has no meaningful state changes after initialization—it simply maintains the constant boolean value computed at the start.

No explicit safety or liveness properties are specified beyond the specification itself. The model-checking configuration uses `Spec` as the specification to verify, essentially checking that the initial state evaluation succeeds and that the unchanging behavior is valid.
