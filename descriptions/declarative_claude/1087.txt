This TLA+ module named `Utils` defines a utility operator for graph analysis, specifically for detecting simple cycles in a functional representation of a directed graph.

The module extends standard TLA+ modules for integers, sequences, finite sets, and functions to provide foundational mathematical operations.

The sole operator defined is `IsSimpleCycle(S, r)`, which determines whether a relation `r` forms a simple cycle over a set of vertices `S`. The relation `r` is interpreted as a directed graph where an edge exists from vertex `s` to vertex `t` if and only if `r[s] = t`—meaning each vertex has exactly one outgoing edge (a functional graph).

The operator works by iteratively building a sequence: starting from an arbitrary vertex in `S`, it follows the edges defined by `r` for exactly `|S|` steps, prepending each visited vertex to the sequence. If the resulting sequence's range equals `S`, then every vertex was visited exactly once before returning to the start, confirming a simple cycle that covers all vertices.

A comment notes that recursive definitions are avoided due to lack of support in PlusPy, a tool for executing TLA+ specifications in Python. This module contains no variables, temporal logic, fairness conditions, or properties to check—it purely provides a helper predicate for use in other specifications.
