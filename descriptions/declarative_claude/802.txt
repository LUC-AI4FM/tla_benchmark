This TLA+ module defines a library of operators for working with zero-indexed sequences, where a sequence of length n is represented as a function with domain {0, 1, ..., n-1}, contrasting with TLA+'s built-in one-indexed sequences.

The module provides foundational definitions including the empty zero-indexed sequence and an operator to obtain valid indices for any such sequence. It defines the set of all zero-indexed sequences over a given set of elements, analogous to the standard Seq operator but for zero-based indexing.

Key operators include length computation for zero-indexed sequences, and conversion functions between standard one-indexed sequences and zero-indexed sequences, enabling interoperability between the two representations.

The module defines a lexicographic ordering relation on zero-indexed sequences, implemented recursively by comparing elements position by position, with shorter sequences considered less than longer sequences when one is a prefix of the other.

Additionally, the module provides rotation operations: one operator computes a left rotation of a sequence by a specified number of positions using modular arithmetic, while another generates the set of all possible rotations of a sequence, each paired with its shift amount.

This is purely a library module containing operator definitions; it specifies no system behavior, declares no variables, and contains no temporal properties, invariants, or fairness conditions.
