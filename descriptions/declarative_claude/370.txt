This TLA+ module is a test suite for verifying the correct behavior of labels and subexpression selectors in TLA+. It systematically exercises the language's ability to reference labeled subexpressions and navigate complex nested definitions using the subexpression selector syntax (the `!` operator).

The module defines a single constant C, set to 4 in the configuration, used throughout various test expressions.

The specification consists entirely of ASSUME statements that verify expected equalities hold. There are no VARIABLES, no next-state relation, and no temporal properties or fairness conditions—this is purely a static verification module for the TLA+ tooling itself.

The tests cover numerous TLA+ constructs including: higher-order operators with functional arguments, LET-IN definitions with user-defined operators (including infix operators like `++`), labeled expressions accessed via selectors, set comprehensions, CHOOSE expressions, record and tuple constructions, function definitions with EXCEPT clauses, quantified expressions (universal, existential, and temporal), CASE expressions, and module instantiation with substitution.

The module also instantiates an auxiliary module test206a, testing that subexpression selectors work correctly across module boundaries with parameterized instantiation.

Two theorems are declared: Thm with a FALSE assumption (making it vacuously true) and Thm2 which is trivially TRUE, both containing labels that are subsequently referenced via selectors.
