This TLA+ module tests recursive function definitions and mutual recursion in TLA+. It does not model a distributed system or algorithm but instead serves as a verification of TLA+'s recursion mechanisms.

The module defines two mutually recursive operators, f and g. The operator f computes a factorial-like function: it returns 1 when the argument is 0, otherwise multiplies the argument by g of the predecessor. The operator g simply calls f with the same argument, creating mutual recursion that effectively computes the factorial function.

Additionally, the module defines a recursive function fact using TLA+'s function syntax over natural numbers. A helper function fact1 references fact, and fact itself computes the standard factorial: returning 1 for 0, otherwise multiplying n by fact1 of n minus 1.

The module contains three ASSUME blocks that serve as compile-time checks. The first verifies that f correctly computes factorial values for inputs 0 through 5. The second performs identical checks for g. The third confirms that the function-based fact and fact1 definitions produce correct factorial values and match the results from g. Each assumption block prints a confirmation message upon successful evaluation.

No variables, temporal properties, fairness conditions, or invariants are specified. The empty configuration indicates this module exists purely for testing recursive definition semantics rather than model checking system behavior.
