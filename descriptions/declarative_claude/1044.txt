# DijkstraMutex Module Description

This module specifies Dijkstra's 1965 mutual exclusion algorithm, the first published solution to the concurrent programming mutual exclusion problem. The specification models multiple processes competing to enter a critical section.

**Constants and Variables:** The constant `Proc` represents an arbitrary set of process identifiers. Global variables include boolean arrays `b` and `c` (both initially true for all processes), an integer `k` initialized nondeterministically to some process, process-local variable `temp`, and program counter `pc` tracking each process's control location.

**Algorithm Behavior:** Each process repeatedly cycles through: signaling intent by setting its `b` entry false, competing for the turn variable `k`, checking other processes via array `c`, entering the critical section, and returning to a non-critical section. The algorithm uses a complex protocol where processes check if they hold the turn (`k = self`), and when not, they defer by setting `c` true and potentially claiming the turn when the current holder's `b` is true. Before entering the critical section, a process verifies no other process has `c` false.

**Specification and Fairness:** The main specification `Spec` combines initial conditions, the next-state relation, and weak fairness for each process. An alternative specification `LSpec` applies fairness only when processes are outside their non-critical section.

**Properties:** The module defines `MutualExclusion` as a safety invariant ensuring no two processes occupy the critical section simultaneously. Liveness properties include `DeadlockFree` and `DeadlockFreedom` (some waiting process eventually enters the critical section) and `StarvationFree` (every waiting process eventually enters), with notes that the algorithm satisfies deadlock freedom but not starvation freedom.
