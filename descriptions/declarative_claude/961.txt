This TLA+ module specifies the complete formal grammar of the TLA+ specification language itself, expressed using BNF (Backus-Naur Form) grammar constructs.

The specification defines the syntactic structure of TLA+ modules through a set of grammar productions. It begins by establishing lexical elements: reserved words (like ASSUME, MODULE, THEOREM), identifiers constructed from letters, numerals, and underscores (excluding reserved words), number literals in various bases (decimal, binary, octal, hexadecimal), and string literals. It also defines the prefix, infix, and postfix operators available in the language.

The grammar productions describe the hierarchical structure of TLA+ specifications. A Module consists of a header with dashes, the MODULE keyword, a name, optional EXTENDS clause, zero or more units, and a closing line of equals signs. Units include variable declarations, constant declarations, operator definitions, function definitions, module instantiations, assumptions, theorems, and nested modules—some optionally marked LOCAL.

The Expression production is the most elaborate, covering identifiers, operator applications, quantified expressions (universal and existential), CHOOSE expressions, set constructions (enumeration, filtering, mapping), function definitions and applications, record constructions, tuple notation, temporal operators (box, diamond, fairness conditions WF_ and SF_), IF-THEN-ELSE, CASE expressions, and LET-IN constructs.

The specification concludes by computing the least fixed-point grammar satisfying all these productions using the LeastGrammar operator from the BNFGrammars module.
