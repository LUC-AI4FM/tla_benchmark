This module specifies the intended behavior of the Alternating Bit protocol, describing what the protocol should accomplish rather than how it operates internally.

The specification models a system with three concurrent processes: a sender (A), a receiver (B), and an environment (E). Messages are records containing a data element from the constant set Data and a single bit (0 or 1).

The system uses three variables: AVar holds the current message at the sender, BVar holds the last message received, and NewValQueue is a sequence of pending data values from the environment.

Process E represents the external environment, which can enqueue new data values whenever the sender and receiver are synchronized (their bits match). Process A, the sender, dequeues a value when available, creates a new message with that data, toggles its bit, and updates AVar. Process B, the receiver, waits until the sender's bit differs from its own, then copies the sender's message to BVar, achieving synchronization.

The temporal specification requires that the system starts in a valid initial state, follows the next-state relation, and satisfies weak fairness for processes A and B. This ensures that sending and receiving eventually occur when enabled. Process E has no fairness constraint, reflecting that the environment may or may not supply new data.

No explicit safety or liveness properties are stated in the module for model checking.
