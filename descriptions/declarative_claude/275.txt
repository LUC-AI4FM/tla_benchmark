This TLA+ module specifies a trivial system designed to demonstrate invariant failure during model checking.

The specification defines the simplest possible state machine with no constants or variables. The initial state predicate `Init` is unconditionally true, meaning any state is a valid initial state. The next-state relation `Next` is also unconditionally true, meaning any transition between any two states is permitted. This creates a system that can always advance and has no constraints on its behavior whatsoever.

The module includes a single invariant `Inv` that is unconditionally false. Since an invariant must hold in all reachable states, and this invariant is never satisfied, any model checker will immediately report a violation upon examining the initial state.

This specification serves as a minimal test case, specifically created to address an issue in the Apalache model checker. It verifies that the tool correctly detects and reports invariant violations even in degenerate cases where the system has no meaningful structure. The specification contains no temporal properties, fairness conditions, or liveness requirements—only the always-failing safety invariant.
