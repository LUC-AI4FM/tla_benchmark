This TLA+ module is a test suite for the standard Naturals module, verifying that arithmetic operators behave correctly during model checking.

The specification defines a single variable x that is initialized to zero and never changes. The system has exactly one state with no transitions, making it a static test harness.

The invariant Inv contains twenty-one tests that verify various arithmetic operations from the Naturals module. These tests check exponentiation (powers of two, zero raised to a power), subtraction (including verifying that negative results are not natural numbers), multiplication, comparison operators (less than, greater than, less than or equal, greater than or equal), integer division and modulo operations (including the division identity that a number equals the quotient times divisor plus remainder), and integer range construction (including empty ranges and enumerated sets). The tests also verify behavior with negative numbers through expressions like zero minus one.

Each test uses a conditional: if the arithmetic expression evaluates correctly, it prints a success message; otherwise, it triggers an assertion failure. Since Inv is declared as an invariant in the configuration, the model checker evaluates all these conditions in the initial state.

The specification contains no liveness properties or fairness conditions. Its sole purpose is to validate that TLC correctly implements natural number arithmetic operations as defined in the Naturals module.
