This TLA+ module serves as a test suite for the GraphViz module, which provides functionality for converting graph structures into DOT format strings suitable for visualization with GraphViz tools.

The module extends GraphViz (the module being tested), along with standard modules for Sequences, Naturals, and TLC utilities.

The specification contains two ASSUME statements that execute at model-checking initialization time. The first assumption prints "GraphViz" to the console, serving as a test header or confirmation that the tests are running.

The second assumption defines a test case for the DotDiGraph operator. It constructs a directed graph G with three nodes (1, 2, and 3) and three labeled edges: an edge from node 1 to node 2 with label 1, an edge from node 2 to node 3 with label 2, and an edge from node 2 back to node 1 with label 3. The test verifies that DotDiGraph correctly transforms this graph structure into a DOT-formatted string, using identity functions for node labels and extracting the third element of edge tuples for edge labels. The expected output string contains hash-based node identifiers with appropriate labels and directed edge declarations.

This module contains no variables, actions, or temporal properties—it purely validates the GraphViz module's graph-to-DOT conversion functionality through compile-time assertions.
