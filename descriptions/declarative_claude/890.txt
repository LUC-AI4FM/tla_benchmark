This module provides a machine-checked proof of type correctness for an asynchronous interface specification defined in the AsynchInterface module.

The specification models an asynchronous communication interface between a sender and receiver, using three variables: `val` for the data value being transmitted, `rdy` (ready) as a signal from sender to receiver, and `ack` (acknowledge) as a signal from receiver to sender. The interface operates through two actions: `Send`, where the sender places a value and signals readiness, and `Rcv`, where the receiver acknowledges receipt.

The proof establishes the theorem `TypeCorrect`, which states that the specification implies the type invariant holds in all reachable states. The proof proceeds in two steps: first showing that the initial state satisfies the type invariant, then showing that the type invariant is preserved by any transition (either a `Next` step or a stuttering step). The final step combines these using propositional temporal logic reasoning.

The module extends TLAPS (the TLA+ Proof System) to provide the proof infrastructure. This is a safety property verification, confirming that variables maintain their expected types throughout all executions of the asynchronous interface protocol.
