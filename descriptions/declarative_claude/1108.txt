This TLA+ module provides a machine-checked proof of a safety property for a spanning tree construction protocol defined in a separate "spanning" module.

The specification models a distributed algorithm where processes form a spanning tree rooted at a designated root node. Processes communicate by sending messages, and non-root processes set their parent pointer upon receiving messages from neighbors.

The module proves that the property SntMsg holds throughout all executions. SntMsg states that any non-root process whose parent has not yet been set has sent no messages. This ensures that only processes that have joined the spanning tree (either by being the root or by having their parent set) can send messages.

To establish this invariant, the proof introduces a strengthening predicate called SentMeansCanSend, which captures the dual property: if a message from process i to process j exists in the message set, then either i is the root or i has already set its parent. The combined invariant Inv includes both SntMsg and SentMeansCanSend, along with a domain constraint on the parent function.

The proof proceeds by showing that the initial state satisfies Inv and that the next-state relation preserves Inv. The proof analyzes the Update, Send, and Parent actions separately, demonstrating that each maintains the invariant. The module uses TLAPS (the TLA+ Proof System) to mechanically verify all proof steps, ultimately establishing that the specification implies the temporal property that SntMsg holds in all reachable states.
