This TLA+ module specifies a parallel algorithm for computing the set of nodes reachable from a root node in a directed graph. It is designed as a multiprocess implementation that refines Misra's sequential reachability algorithm from the Reachable module.

The constants include Nodes and Succ (the graph structure, imported from Reachability), Root (the starting node), and Procs (a finite, nonempty set of process identifiers). The variables are: marked (nodes confirmed reachable), vroot (frontier nodes to explore), pc (program counter per process), u (current node each process examines), and toVroot (successor nodes each process is adding to the frontier).

Each process repeatedly selects a node from vroot, and if unmarked, adds it to marked and incrementally transfers its successors to vroot one at a time. If already marked, the node is removed from vroot. Processes terminate when vroot becomes empty, though one process may terminate early while others continue working.

The specification includes weak fairness for each process, ensuring progress. The module defines an invariant Inv capturing type correctness and control-state relationships. A refinement mapping relates the parallel algorithm's state to Misra's algorithm via vrootBar (combining vroot with all pending toVroot sets) and pcBar (done only when all processes finish). The key theorem asserts that the parallel algorithm implements Misra's algorithm under this refinement, decomposed into safety and liveness components.
