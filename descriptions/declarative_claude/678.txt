This TLA+ module provides a library of bitwise arithmetic operations for non-negative integers, implemented purely through mathematical definitions without modeling any dynamic system behavior.

The module defines five bitwise operations as recursive functions operating on the binary representations of natural numbers including zero. The **bitwise AND** operator (`&`) computes the conjunction of corresponding bits by multiplying the respective bit values at each position. The **bitwise OR** operator (`|`) combines bits using modular arithmetic to achieve the logical disjunction effect. The **bitwise XOR** operator (`^^`) uses modular addition to flip bits where inputs differ, with the double caret avoiding conflict with the exponentiation operator. The **bitwise NOT** operator flips each bit of its argument by toggling between zero and one at every position. Finally, **shiftR** performs logical right-shifting by the specified number of positions, effectively dividing by powers of two while discarding remainder bits.

Each binary operation ensures correct behavior regardless of operand order by always recursing based on the larger operand's magnitude. The recursive implementations process numbers bit-by-bit from least significant to most significant position, accumulating the result by adding appropriately weighted bit contributions.

This module contains no variables, temporal specification, state transitions, or properties to verify. It serves purely as a reusable library for specifications that require bitwise manipulation of integers.
