This TLA+ module provides a library interface for CSV (Comma Separated Values) file operations. It does not specify a system or algorithm with state transitions; instead, it defines utility operators intended to be overridden by Java implementations during model checking with TLC.

The module contains no CONSTANTS or VARIABLES, as it serves purely as an operator library rather than a behavioral specification.

Four operators are defined. CSVWrite takes a printf-style template, a sequence of values, and a file path, enabling formatted output to CSV files. CSVWriteRecord writes a TLA+ record to a file with a specified delimiter and optional header row generation. CSVRead accepts column names, a delimiter, and a file path, returning file contents as a sequence of records mapping column names to string values. CSVRecords returns the number of rows in a CSV file, returning zero for nonexistent files.

In pure TLA+, CSVWrite, CSVWriteRecord, and CSVRead evaluate to TRUE, while CSVRecords nondeterministically chooses a natural number. The actual file operations occur only when TLC executes these operators with their Java override implementations, making them side-effecting operations useful for logging, data export, and interfacing with external tools during model checking.

The module defines no temporal specification, fairness conditions, safety properties, or liveness properties.
