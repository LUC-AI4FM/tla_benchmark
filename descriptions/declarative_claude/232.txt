This TLA+ module is a test specification verifying the correct behavior of the `SetAsFun` operator from the Apalache model checker's extended operators. `SetAsFun` constructs a function from a set of key-value pairs represented as tuples.

The specification declares three variables with different type signatures: `strToInt` maps strings to integers, `intsToInt` maps sets of integers to integers, and `funToFun` maps functions to strings. This last variable demonstrates that TLA+ functions can themselves serve as domain elements of other functions.

The `Init` predicate constructs each variable using `SetAsFun` with explicitly enumerated tuple pairs. For example, `strToInt` is built from pairs mapping "a" to 2 and "b" to 3. The `funToFun` variable shows nested function construction, where the domain elements are themselves functions created via `SetAsFun`.

The `Next` relation specifies that all variables remain unchanged, making this a static specification focused purely on testing initial state properties.

The `Inv` invariant comprehensively checks that each function has the expected domain and maps each domain element to its correct value. This validates that `SetAsFun` correctly interprets tuple sets as function definitions across various type combinations, including the advanced case of functions indexed by other functions.
