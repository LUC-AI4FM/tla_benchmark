This TLA+ module models a discrete Markov chain with explicit probability tracking. The system simulates probabilistic state transitions where each path accumulates its probability through multiplication.

The specification uses two variables: `state` tracks the current Markov chain state, and `p` represents the accumulated probability along the current execution path, encoded as a rational number pair (numerator, denominator). The constant `One` (100000) serves as the initial probability numerator.

The Markov chain begins in state "s0" with probability 1. The transition structure defines a binary branching tree: from s0, the system moves to s1 or s2 with equal probability (1/2 each). States s1 through s6 are intermediate states, while states I through VI are accepting (terminal) states. Some transitions create loops (s3 back to s1, s6 back to s2), allowing indefinite cycling.

The next-state relation permits transitions only when the current state is not accepting and the accumulated probability remains positive. Each transition multiplies the current probability by the edge's transition probability.

The specification includes weak fairness on the next-state action, ensuring progress when transitions are continuously enabled.

The theorem `Converges` asserts that every execution eventually either reaches an accepting state or has its probability drop to zero (through the normalization operation), establishing a liveness property about termination of the probabilistic process.
