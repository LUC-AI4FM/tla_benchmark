This TLA+ module provides Apalache type annotations for an underlying specification of Non-Blocking Atomic Commit with failure detectors, instantiated from the module `nbacg_guer01`.

The system models a distributed consensus protocol where N processes attempt to reach agreement on committing or aborting a transaction, with the ability to detect failures among participants.

The constant N represents the number of processes in the system.

The specification tracks several variables: `nSntNo` and `nSntYes` count how many processes have sent "no" or "yes" votes respectively, while `nSntNoF` and `nSntYesF` track similar counts related to failure scenarios. Each process maintains local counters `nRcvdYes` and `nRcvdNo` (indexed by process identifier) recording how many "yes" and "no" votes it has received. The variable `someFail` indicates whether each process has detected a failure, and `pc` represents the program counter or local state of each process as a string.

The model is configured with 3 processes. The specification checks a type invariant `TypeOK` to ensure all variables maintain their expected types and domains throughout execution. The temporal specification `Spec` defines the complete system behavior including initial states and allowed transitions, inherited from the instantiated module.
