This TLA+ specification demonstrates mutual recursion between two modules through constant substitution.

The **Base** module defines a framework for determining number parity. It declares a constant operator `IsOdd` that takes one argument, leaving its implementation unspecified. The module defines `IsEven` as an operator that returns TRUE for zero, otherwise delegates to `IsOdd` with the predecessor value. An assumption asserts that `IsEven(2)` holds, serving as a basic sanity check.

The **UndeclaredRecursion** module extends Base and provides the concrete implementation `DefIsOdd`, which returns FALSE for zero and otherwise calls `IsEven` with the predecessor value. This creates mutual recursion: `IsEven` calls `IsOdd`, and `DefIsOdd` calls `IsEven`.

The **configuration** binds the abstract constant `IsOdd` to the concrete operator `DefIsOdd`, completing the mutual recursion cycle. When model-checked, evaluating `IsEven(n)` for any natural number will alternate between the two predicates, decrementing until reaching zero.

This specification contains no variables, actions, temporal formulas, or invariants to check. It primarily illustrates TLA+'s module system capabilities for achieving indirect mutual recursion through constant operator substitution, where neither module alone contains explicit recursive definitions.
