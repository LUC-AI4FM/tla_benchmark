This TLA+ module is a minimal test specification designed to verify the handling of various annotation formats and edge cases in tooling that processes TLA+ specifications.

The module defines a single variable `S`, which represents a set. The variable declaration includes extensive type annotations in comments, specifying that `S` is a set of integers, with the annotations deliberately formatted across multiple lines to test parser handling of complex comment structures.

The initial state predicate `Init` establishes `S` as the empty set. The next-state relation `Next` transitions `S` to the singleton set containing the integer 1. This means the system has exactly two reachable states: the empty set and the set containing 1.

The safety invariant `Inv` asserts that the integer 2 is never a member of `S`. Given the specification's behavior, this invariant holds trivially since `S` only ever contains either nothing or the value 1.

The module includes commented annotations for unit testing following a proposed RFC, with directives for preconditions, postconditions, and test actions. These annotations reference the `Init` predicate, an `Assertion` identifier, and specify a test involving the `Next` action.
