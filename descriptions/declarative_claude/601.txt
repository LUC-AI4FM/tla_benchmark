This TLA+ module specifies a test configuration for model checking an optimized commit timestamp protocol, extending the `OptimizedCommitTS` module which contains the main specification logic.

The module models a distributed transaction system with two keys (1 and 2) and two concurrent clients (c1 and c2). Each client is assigned a distinct primary key: client c1 uses key 1 as its primary, and client c2 uses key 2. This setup enables verification of concurrent transaction behavior where clients operate on overlapping data.

The specification being checked is `PercolatorSpec`, which defines the temporal behavior of the system based on the Percolator distributed transaction protocol with optimized commit timestamps.

The model checker verifies eight invariants. `TypeInvariant` ensures variables remain within their declared types. `WriteConsistency`, `LockConsistency`, `CommittedConsistency`, `AbortedConsistency`, and `RollbackConsistency` verify correctness properties related to different transaction states and their interactions. `UniqueWrite` ensures no duplicate writes occur. `SnapshotIsolation` verifies that the system maintains snapshot isolation semantics, guaranteeing transactions see a consistent snapshot of the database.

This configuration provides a minimal but meaningful test case with two interleaving clients to detect concurrency bugs while keeping the state space tractable for model checking.
