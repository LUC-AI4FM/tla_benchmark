This TLA+ module specifies a simple cyclic counter system that increments through three states in a repeating pattern.

The system models a single variable `x` that cycles through values 0, 1, and 2. Starting from an initial state where `x` equals 0, the system transitions by incrementing `x` modulo 3, creating an endless loop: 0 → 1 → 2 → 0 → 1 → 2, and so forth.

The module defines several state-level predicates for testing purposes: `AtOne` holds when `x` equals 1, `AllDone` holds when `x` equals 2, and `Unreachable` represents a state where `x` equals 5, which can never occur given the system's behavior.

Two action-level predicates are also defined: `WrapAround` captures the transition from 2 back to 0, while `BigJump` describes a jump of 2, which is impossible since the next-state relation only increments by 1 modulo 3.

The main temporal specification `Spec` combines the initial condition with a stuttering-allowed next-state relation. An alternative specification `SpecOnlyInit` uses a next-state relation that is always false, creating a specification with only initial states and no transitions—designed to test edge cases in model checking where no state transitions exist.
