This TLA+ module specifies Dijkstra's mutual exclusion algorithm, the first published solution to the concurrent programming mutual exclusion problem from 1965.

The algorithm models multiple processes attempting to coordinate entry into a critical section without simultaneous access. The constant Proc defines an arbitrary set of process identifiers. The global variables include two boolean arrays b and c (both initially true for all processes), and an integer k initialized nondeterministically to some process. Each process also has a local variable temp and a program counter pc tracking its location.

The algorithm proceeds through labeled steps: a process signals intent by setting its b entry false, then enters a loop checking whether k equals itself. If not, it sets c true, potentially updates k, and retries. If k matches, the process sets c false and checks that no other process has c false; if any does, it restarts. Only when all checks pass does the process enter its critical section, afterward resetting c and b to true before entering its non-critical section.

The specification combines initial conditions with the next-state relation (any process taking a step) and weak fairness for each process. The module defines MutualExclusion as a safety invariant ensuring no two processes occupy the critical section simultaneously. Liveness properties include DeadlockFree and DeadlockFreedom, asserting that waiting processes eventually lead to some process entering the critical section. StarvationFree is defined but noted as not satisfied by this algorithm. An alternative specification LSpec weakens fairness to permit processes remaining in non-critical sections indefinitely.
