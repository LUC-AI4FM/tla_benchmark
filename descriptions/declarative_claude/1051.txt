This TLA+ module is a utility library providing definitions for reasoning about binary relations over finite sets. It does not model a system or algorithm with state transitions; instead, it offers reusable mathematical operators.

The module defines several predicates that test standard properties of relations. A relation R is represented as a Boolean function indexed by pairs of elements from a set S. The predicates include: reflexivity (every element relates to itself), irreflexivity (no element relates to itself), symmetry (the relation is bidirectional), asymmetry (no two elements mutually relate), and transitivity (related pairs chain together).

Two closure operators are provided. The transitive closure computes the smallest transitive relation containing R by iteratively adding indirect connections up to the cardinality of S iterations. The reflexive transitive closure extends this by additionally relating every element to itself.

Finally, the module defines connectivity, which tests whether every pair of elements in S is connected through some path in the reflexive transitive closure.

The module extends Naturals and FiniteSets for arithmetic and cardinality operations. There are no declared constants, variables, temporal specifications, fairness conditions, or properties to check. This is purely a definitional library intended for import into other specifications that need relation-theoretic concepts.
