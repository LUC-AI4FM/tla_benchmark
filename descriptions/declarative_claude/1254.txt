This TLA+ module defines the standard library for finite sequences in TLA+. It provides fundamental operators for working with sequences, where a sequence of length n is represented as a function with domain 1..n, making tuples and sequences equivalent.

The module locally imports the Naturals module for arithmetic operations without re-exporting those definitions.

The key operators defined are:

**Seq(S)** constructs the set of all finite sequences whose elements come from set S, defined as the union of all functions from 1..n to S for every natural number n.

**Len(s)** returns the length of a sequence by finding the natural number n such that the sequence's domain equals 1..n.

**Concatenation (\o)** joins two sequences into one, placing the second sequence's elements after the first.

**Append(s, e)** adds a single element to the end of a sequence, defined via concatenation with a singleton sequence.

**Head(s)** returns the first element of a sequence, while **Tail(s)** returns all elements except the first, with Tail being undefined for empty sequences.

**SubSeq(s, m, n)** extracts elements from position m through n inclusive.

**SelectSeq(s, Test)** filters a sequence, keeping only elements satisfying the given predicate Test, using a recursive definition over the sequence indices.

These operators are overridden by optimized Java implementations in TLC for efficient model checking.
