This TLA+ module is a test suite for the standard Bags library, verifying the correctness of multiset (bag) operations through a series of assertions.

The module defines no meaningful state variables or system behavior—both Init and Next are trivially TRUE, creating a single-state specification used purely for property checking.

A helper operator SingleElemBag constructs a bag containing one element with a specified multiplicity. The module then defines individual test predicates for each bag operation:

- **TestIsABag** verifies that bags require non-negative multiplicities
- **TestBagToSet** and **TestSetToBag** check conversions between bags and sets
- **TestBagIn** confirms element membership testing
- **TestEmptyBag** verifies the empty bag contains no elements
- **TestPlus** and **TestMinus** validate bag addition and subtraction, including commutativity of addition
- **TestBagUnion** tests union of multiple bags
- **TestSqsubseteq** checks the sub-bag ordering relation
- **TestBagOfAll** verifies applying functions to bag elements
- **TestBagCardinality** tests counting total element copies
- **TestCopiesIn** validates retrieving element multiplicities

The invariant Inv is the conjunction of all test predicates. Model checking confirms that all assertions hold simultaneously, effectively serving as a unit test that validates the Bags library implementation behaves according to expected mathematical multiset semantics for both integer and string element types.
