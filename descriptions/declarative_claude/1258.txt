This TLA+ module provides a utility for visualizing TLC model checker counterexamples as GraphViz DOT format diagrams.

The module imports several standard library modules for TLC interaction, file I/O, sequences, functions, and GraphViz support.

The single CONSTANT `_DotTraceFile` specifies the output file path where the generated DOT graph will be written.

The main operator `_DotTrace` checks whether a counterexample exists from model checking. If no counterexample states exist, or if console output is explicitly disabled in the counterexample structure, the operator simply returns TRUE and performs no action.

When a counterexample is present, the operator constructs a directed graph from it. The nodes are taken from the counterexample's state set. The edges are derived from the counterexample's action set, restructured as tuples containing source state, target state, and transition information. This graph is then converted to DOT format using the `DotDiGraph` function, with custom formatting: node labels display the state variables and their values, while edge labels show the action names.

The resulting DOT representation is serialized to the specified file using UTF-8 encoding, with options to create the file or truncate any existing content. Upon successful write (exit value zero), a confirmation message is printed indicating where the counterexample was written.
