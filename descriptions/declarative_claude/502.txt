The module specifies Multi-decree Paxos (Multi-Paxos) with an aggregated prepare phase, where every replica simultaneously plays the roles of proposer (leader), acceptor, and learner across a finite set of consensus slots.

The constants are `Replicas` (at least three), `Values` (at least two non-zero values), `Slots` (non-empty finite set of slot identifiers), and `Ballots` (non-empty finite subset of the natural numbers). The variables are a shared message set `msgs`; per-replica leader state `lBallot` (current ballot as leader) and `lStatus` (per-slot phase: `""`, `"Preparing"`, `"Accepting"`, or `"Learned"`); per-replica acceptor state `rBallot` (highest ballot seen) and `rVoted` (last accepted ballot and value per slot); and global `proposed` and `learned` sets per slot.

Each replica interleaves five actions. In `Prepare`, a replica picks a ballot higher than any it has used and not already in flight, broadcasts a Prepare message, and moves all non-learned slots to `"Preparing"`. In `PrepareReply`, an acceptor responds with its full voted-record to any Prepare with a higher ballot. In `Accept`, a leader in the `"Preparing"` phase for a slot collects a quorum of PrepareReply messages, uses `ValuePreparedIn` to select a safe value respecting Paxos phase-1 constraints, and broadcasts an Accept. In `AcceptReply`, an acceptor records the vote and echoes it. In `Learn`, a leader in `"Accepting"` collects a majority of AcceptReply messages for the same value and slot, marks the slot `"Learned"`, and records the value in `learned`. The temporal specification is `Init ∧ [][Next]_vars` with no explicit fairness or named safety/liveness properties in the module itself.
