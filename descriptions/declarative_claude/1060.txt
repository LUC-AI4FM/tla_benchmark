This module provides Apalache type annotations for the EWD840 specification, which models Dijkstra's token ring algorithm for detecting termination in a distributed system (originally described in EWD 840).

The system models N nodes arranged in a ring topology. Each node can be active or inactive, and the algorithm detects when all nodes have become inactive with no pending messages.

The constant N specifies the number of nodes in the ring. The variables track: active, a function mapping each node to a boolean indicating whether it is currently active; color, a function mapping each node to a string representing its color (used to detect potential interference); tpos, an integer indicating the current position of the termination detection token; and tcolor, a string representing the token's color.

The specification is imported via INSTANCE from the EWD840 module, which defines the initial states, the next-state relation governing node activation, deactivation, message passing, and token circulation.

The model-checking configuration uses three nodes and verifies two invariants: TypeOK, ensuring variables maintain proper types, and TerminationDetection, the key safety property asserting that when the algorithm reports termination, all nodes are genuinely inactive. Deadlock checking is disabled since termination states are expected.
