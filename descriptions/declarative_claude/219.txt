# SelectSeqTests Module Description

This TLA+ module is a test suite that verifies the correctness of the `SelectSeq` operator from the standard Sequences library. The module tests filtering functionality on sequences of integers.

## Structure

The module defines a single variable `x` of type integer, which serves as minimal state to satisfy TLA+'s requirement for a specification structure. The actual purpose lies entirely in the invariants.

## Constants and Definitions

The module defines four predicate operators used as filter functions: `AllPass` (always true), `AllFail` (always false), `AllEven` (checks divisibility by 2), and `AllGt1` (checks if greater than 1). A constant sequence `seq` is defined as the three-element sequence containing 1, 2, and 3.

## State Transitions

The specification has trivial behavior: `Init` sets `x` to 0, and `Next` sets `x` to 1. This creates a simple two-state system.

## Properties Checked

The module verifies four invariants about `SelectSeq` behavior: filtering with a universally-true predicate returns the original sequence; filtering with a universally-false predicate returns an empty sequence; filtering for even numbers returns only the element 2; and filtering for values greater than 1 returns the subsequence containing 2 and 3. The combined invariant `Inv` asserts all four conditions hold simultaneously.
