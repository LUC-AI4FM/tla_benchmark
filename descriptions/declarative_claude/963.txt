This module provides a formal TLAPS (TLA+ Proof System) proof that the Alternating Bit Protocol specification maintains its type invariant throughout execution.

The module extends the main AlternatingBit specification and the TLAPS proof library. It proves the theorem that if the system satisfies the alternating bit specification (ABSpec), then the type invariant (ABTypeInv) holds in all reachable states.

The proof establishes several helper lemmas about sequence operations: AppendType confirms that appending an element of type T to a sequence of T produces a sequence of T; TailType shows that taking the tail of a non-empty sequence preserves the sequence type; HeadType confirms the head of a sequence belongs to the element type; and LosePreservesType demonstrates that removing an element from a sequence (modeling message loss) maintains the sequence type.

The main theorem TypeCorrect proceeds by proving two conditions: first, that the initial state ABInit satisfies ABTypeInv; second, that any step satisfying the next-state relation ABNext (or a stuttering step) preserves the type invariant. The second condition examines all possible actions: sending new values, resending messages, receiving messages, sending acknowledgments, receiving acknowledgments, losing messages, losing acknowledgments, and stuttering steps. The proof concludes using PTL (propositional temporal logic) reasoning to establish the invariance property.
