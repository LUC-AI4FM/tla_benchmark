This TLA+ module serves as a type-annotated wrapper around a base specification called `Prisoners`, which models the classic "100 Prisoners and a Light Bulb" puzzle or a variant thereof.

The specification models a scenario where a set of prisoners must coordinate to count how many of them have visited a room, using only light switches as communication. One designated prisoner acts as the Counter who tracks progress.

**Constants:** `Prisoner` represents the set of all prisoners, and `Counter` identifies the specific prisoner responsible for counting visits.

**Variables:** Two boolean switches (`switchAUp` and `switchBUp`) represent the state of light switches in the room. The `timesSwitched` function maps each prisoner to an integer tracking how many times they have toggled a switch. The `count` variable tracks the Counter's running tally.

The module uses `INSTANCE Prisoners` to import all definitions, actions, and properties from the underlying `Prisoners` module, while adding Apalache-specific type annotations for model checking purposes.

**Concrete configuration:** For model checking, the specification instantiates three prisoners with `p1_OF_PRISONER` designated as the Counter. The actual behavioral logic, state transitions, fairness conditions, and any safety or liveness properties being verified are defined in the referenced `Prisoners` module.
