This TLA+ module specifies the Tower of Hanoi puzzle, a classic mathematical game involving moving disks between three rods while maintaining size ordering.

The specification models three towers as sequences of natural numbers, where each number represents a disk's size. The constants A, B, and C define the initial configurations of the three towers, typically with all disks stacked in ascending order on the first tower.

The single state variable `towers` is a three-element sequence containing the current state of all towers. The initial state assigns the constant configurations to the towers.

The next-state relation allows moving the top disk from any tower to another, subject to the puzzle's rules: the source must differ from the destination, the source tower must be non-empty, and the moved disk must be smaller than the destination's top disk (or the destination must be empty).

The specification includes several invariants for model checking. TypeOK ensures towers maintain proper structure as sequences of natural numbers. NoNewElements verifies that only the original disks exist throughout execution. TotalConstant confirms the total disk count remains unchanged.

The NotSolved property is particularly notable: it asserts the puzzle remains unsolved (not all disks on the third tower in ascending order). When model checking finds a violation, the counterexample trace reveals the sequence of moves that solves the puzzle.
