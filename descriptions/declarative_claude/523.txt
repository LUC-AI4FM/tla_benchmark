This module defines a model-checking configuration for an alternating bit protocol implementation with an environment component.

The specification models a communication system between two processes A and B, with an environment that proposes new data values. The system uses message channels (AtoB for messages from A to B, BtoA for acknowledgments) and queues new values proposed by the environment.

Constants include a Data set instantiated with three names: Fred, Mary, and Ted.

Variables track the state at each process (AVar and BVar as messages containing data and a bit), queues for proposed values (NewValQueue), and the two directional channels (AtoB and BtoA).

State constraints bound all queue and channel lengths to at most three elements, keeping the state space finite for model checking.

The type invariant ABE_TypeOK ensures variables have correct types: process variables are messages, NewValQueue is a sequence of data, AtoB carries messages, and BtoA carries single bits (0 or 1).

An additional invariant ABE_Inv captures a consistency property relating acknowledgment bits to process agreement, though comments note this may be violated when the environment proposes values faster than the protocol can synchronize.

The property ABE_TwoValsSeq constrains channel contents to contain at most two distinct consecutive value groups.

The module checks refinement against a higher-level specification (ABESpecProperty) to verify the implementation satisfies its abstract specification.
