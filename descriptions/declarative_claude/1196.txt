This TLA+ module tests the language's support for lambda expressions (anonymous functions) and their use as higher-order operator arguments.

The module defines an operator `Op` that accepts a single-argument operator `A` as a parameter and applies it to the value 4. This demonstrates higher-order operator functionality where operators can receive other operators as arguments.

The constant `bar` is defined by passing a lambda expression that squares its input to `Op`, resulting in 4 squared, which equals 16.

The module contains three assumptions that serve as compile-time tests. The first assumption verifies that passing a lambda creating a two-element set to `Op` produces the expected set {4, 2}. The second assumption confirms that `bar` evaluates to 16. The third assumption tests module instantiation with lambda expressions by instantiating a separate module `test201a`, substituting a cubing lambda for parameter `A` and the value 4 for parameter `b`, then verifying that the instantiated definition `foo!def` equals 64 (which is 4 cubed).

Each assumption includes a `PrintT` call to output confirmation messages when the tests pass. The module extends the Naturals and TLC standard modules for arithmetic operations and printing capabilities. No temporal properties, variables, or model-checking configuration are present; this is purely a static validation of lambda expression semantics.
