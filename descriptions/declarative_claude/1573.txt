This TLA+ module specifies a simple concurrent system with three processes that demonstrates the use of defined operators in PlusCal algorithms.

The system models three identical processes (labeled 1, 2, and 3) that each perform a single computation involving defined expressions. The specification uses a global variable `n` initialized to 0, and each process has a local variable `i`. Two operators are defined: `nplus1` equals `n + 1`, and `nplus2` equals `nplus1 + 1` (effectively `n + 2`).

Each process executes one action: it assigns the value of `nplus2` to its local variable `i`, then asserts that `i` equals 2. Since `n` is initialized to 0 and never modified, `nplus2` always evaluates to 2, so the assertion should always succeed.

The variables include a program counter `pc` tracking each process's location, the global `n`, and a function `i` mapping each process identifier to its local value.

The temporal specification requires initial conditions followed by valid transitions, with weak fairness for each process, ensuring every process eventually executes if continuously enabled. The specification includes a termination property asserting that eventually all processes reach the "Done" state. Infinite stuttering is permitted after termination to avoid spurious deadlock detection.
