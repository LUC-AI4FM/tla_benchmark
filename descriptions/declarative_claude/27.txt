The module models a simple pedestrian-controlled traffic light with two Boolean variables: `isGreen`, indicating whether the light is currently green (false means red), and `requestedGreen`, indicating whether the button has been pressed to request a green light since the light last turned green.

Initially, the light is red and no request is pending. Three actions compose the next-state relation. `RequestGreen` fires when the light is red and no request is already pending, setting `requestedGreen` to true. `SwitchToGreen` fires when the light is red and a request is pending, turning the light green and clearing the request flag. `SwitchToRed` fires whenever the light is green, turning it red without affecting the request flag. The overall next-state relation `Next` is the disjunction of these three actions, and `StutteringNext` wraps it with a stuttering step `[Next]_vars`. The module defines one temporal property, `RequestWillBeFulfilled`, which asserts that whenever a green-light request is pending, the light will eventually become green — a liveness property stating that every button press is eventually honored. No fairness assumptions are stated explicitly within the module itself.
