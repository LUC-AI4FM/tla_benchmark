This TLA+ module defines a library of operators for working with directed graphs (digraphs). It does not specify a system with state transitions or temporal behavior; rather, it provides reusable mathematical definitions.

A digraph is represented as a pair (two-element tuple) where the first element is the set of vertices and the second element is the set of edges. Each edge is an ordered pair of vertices.

The module defines several operators: **Vertices** and **Edges** extract the respective components from a digraph. **IsDigraph** is a predicate that validates whether a given structure is a well-formed digraph, checking that all edges connect vertices within the vertex set.

**Children** computes the set of vertices directly reachable from a given vertex via outgoing edges. **Descendants** is a recursive operator that computes the transitive closure of reachability from a set of starting vertices, returning all vertices reachable by following edges forward.

**SubDag** constructs a subgraph containing a given set of vertices plus all their descendants, along with all edges originating from vertices in this combined set.

This module contains no variables, no next-state relations, no temporal formulas, and no properties to check. It serves purely as a definitional library for directed graph concepts that other specifications may import and use.
