The module defines two alternative initial conditions: InitA starts x at 0, while InitB starts x at -1. The primary next-state relation NextAB allows x to transition to either 0 or 1. An extended transition relation NextC additionally permits x to become 2.

AtMostOnceC is a variant where after such a sequence, x must remain 2 instead. LeadsTo asserts that from x equals 0, the system eventually reaches a state where x being 1 implies it stays 1 permanently. Tautology is a trivially true leads-to property included likely for testing purposes.
