This module specifies the Paxos consensus algorithm as described in "Paxos Made Simple." The system models a message-passing protocol among acceptors and leaders (proposers) attempting to reach agreement on a single value.

The constants include a set of possible values, a set of acceptors, and a collection of quorums, which must be subsets of acceptors with the property that any two quorums intersect. Ballot numbers are natural numbers, and ballots and acceptors are assumed disjoint.

Four variables track the protocol state: for each acceptor, maxBal records the highest ballot promised, maxVBal and maxVVal record the highest ballot and value accepted, and msgs accumulates all messages ever sent. Messages are of four types corresponding to Paxos phases: 1a (prepare), 1b (promise), 2a (accept request), and 2b (accepted).

Leaders can send 1a messages for their ballot or, after collecting a quorum of 1b responses showing a value is safe, send 2a messages proposing that value. Acceptors respond to 1a messages with 1b promises when the ballot exceeds their current maximum, and respond to 2a messages with 2b acceptances when permitted by their promises.

The temporal specification is a standard safety specification with no fairness constraints. The module defines a type invariant TypeOK and a correctness property stating that if two values are chosen (accepted by a quorum), they must be equal—ensuring consensus agreement.
