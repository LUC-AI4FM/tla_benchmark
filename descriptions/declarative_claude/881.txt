This TLA+ module provides a library of definitions for reasoning about graph structures. It does not specify a system with state transitions or temporal behavior; rather, it defines mathematical predicates and operators for graphs.

The module defines what constitutes a directed graph: a record with node and edge fields where edges are pairs of nodes. It provides an operator to generate all directed subgraphs of a given graph.

For undirected graphs, the module requires that every edge has a corresponding reverse edge, treating undirected edges as symmetric pairs. A corresponding subgraph operator filters directed subgraphs to those satisfying the undirected property.

The module defines paths as non-empty sequences of nodes where consecutive nodes are connected by edges. Using paths, it defines connectivity between two nodes and strong connectivity, where every pair of nodes has a connecting path.

Finally, the module characterizes trees with a designated root: directed graphs where no edge points to the root, each non-root node has exactly one outgoing edge, and every node can reach the root via some path.

This module contains no variables, actions, temporal formulas, or properties to check. It serves as a reusable library of graph-theoretic definitions that other specifications can import and use for modeling and verification purposes.
