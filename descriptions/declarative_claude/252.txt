This TLA+ module serves as a regression test for the Apalache model checker, specifically testing the ability to pass built-in operators as arguments to higher-order operators.

The module defines a higher-order operator `Sum` that takes a binary operator `F` as its first parameter along with two additional arguments `x` and `y`, then applies `F` to those arguments. A helper operator `IsMem` checks set membership.

Three test cases verify that built-in operators can be passed correctly: `TestPlus` confirms that passing the addition operator `+` to `Sum` with arguments 1 and 2 yields 3; `TestUnion` verifies that passing the set union operator `\union` with singleton sets produces their union; and `TestBool` checks that `FALSE` is a member of the `BOOLEAN` set.

The specification has trivial temporal behavior with both `Init` and `Next` defined as `TRUE`, meaning the system allows any state and any transition. This reflects the module's purpose as a static test rather than a behavioral specification.

The `AllTests` operator serves as the primary invariant, conjoining all three test predicates. When model-checked, this invariant verifies that all test cases evaluate to true, confirming correct handling of built-in operators as arguments.
