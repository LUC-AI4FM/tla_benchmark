This TLA+ module defines debugging and visualization aliases for the `ccfraft` specification, which models a Raft consensus protocol variant (likely for the Confidential Consortium Framework). The module does not specify system behavior itself but provides diagnostic output formatting for model checking.

The module creates visualization helpers for examining Raft protocol state during TLC execution. It defines color-coding functions that assign distinct terminal colors to servers and terms, and compact symbolic representations for log entry types (reconfiguration, signature, entry) and leadership states.

The `DebugAliasGlobals` operator tracks global metrics including cumulative leader elections, currently blocked nodes, active cluster members, and a timeline showing which node acts in each state transition.

The `DebugAliasAggregates` operator maintains per-node historical data: votes ever granted, delivered message counts, nodes voted for, and sequences of state transitions with timestamps.

The `DebugAliasVars` operator exposes the core Raft variables: pre-vote status, configurations, message queues, current terms, leadership and membership states, vote records, join status, logs, commit indices, granted votes, sent and match indices, retirement status, and inter-server message channels.

The `AnimateLogAndStateAlias` operator enables animated state display by overwriting previous output, showing logs and leadership states with color-coded formatting.

These aliases use TLC extension features like `TLCGetAndSet` for accumulating statistics across states and `FoldSeq`/`FoldSet` for constructing formatted output strings.
