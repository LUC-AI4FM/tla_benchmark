This TLA+ module serves as a benchmark collection for testing inefficient coding patterns ("antipatterns") in the Apalache model checker. Its purpose is to measure performance impacts of these constructs across different Apalache versions.

The module defines a single constant N representing a size parameter, with five initialization predicates setting N to values 10, 20, 40, 80, and 160 for different test configurations.

The specification has trivial behavior: both Init and Next are simply TRUE, meaning any state is initial and any transition is valid. The module's substance lies in its operator definitions demonstrating antipatterns.

Four inefficient constructs are defined using fold operations from Apalache extensions. RemakeSet reconstructs a set by folding union operations over its elements. IncrementalFnChange modifies a function by sequentially updating each domain element. IncrementalFnBuild constructs a function by incrementally extending an empty function. SeqFromFun builds a sequence by repeatedly appending elements from a function.

The invariant Inv verifies these antipattern implementations produce correct results by checking that RemakeSet returns the original range, IncrementalFnChange properly increments function values, IncrementalFnBuild correctly builds an identity function, and SeqFromFun properly converts a function to a sequence. Each antipattern is compared against its efficient equivalent to confirm semantic correctness despite inefficient implementation.
