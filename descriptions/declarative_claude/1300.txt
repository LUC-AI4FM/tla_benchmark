This TLA+ module specifies a minimal system with a single boolean variable that transitions from false to true, primarily serving to demonstrate constant-level invariant checking.

The module declares one constant, C, which represents a set provided at model-checking time, and one variable, b, a boolean flag.

The initial state predicate establishes that b starts as FALSE. The next-state relation simply sets b to TRUE. The temporal specification combines the initial condition with a stuttering-allowed next-state formula, meaning the system can either take a Next step or stutter (leave b unchanged).

The key element is the invariant ConstLevelInvariant, which asserts that the constant C must be a subset of the natural numbers. This invariant depends only on the constant C, not on any state variables, making it a constant-level property that can be verified once rather than checked across all reachable states.

The accompanying configuration instantiates C as the set {1, 2, 3}, specifies Spec as the system specification, and requests verification of ConstLevelInvariant. Since {1, 2, 3} is indeed a subset of natural numbers, this invariant holds. The module demonstrates how TLA+ can express and check constraints on model constants independently of system behavior.
