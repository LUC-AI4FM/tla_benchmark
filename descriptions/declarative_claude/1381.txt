This TLA+ module specifies a simple integer counter system designed to test TLC model checker behavior with state constraints and counterexample generation.

The system models a single variable x that starts at zero and can either be negated (action A) or incremented by one (action B). Action A applies when x is a natural number and sets x to its negation, while action B unconditionally increments x.

The specification uses a state constraint limiting exploration to states where x is a natural number, which restricts the model checker's state space. An action constraint variant also exists that limits transitions based on the successor state.

The invariant asserts that x remains non-negative. However, the combination of actions allows a violation: starting from zero, incrementing to one, then negating produces negative one, breaking the invariant.

The postcondition predicates verify expected model checker behavior by checking that counterexample traces match specific sequences. The primary configuration expects the trace from zero to one to negative one. An alternative initial condition starting at one expects a shorter counterexample going directly to negative one.
