This TLA+ module specifies a ring counter system through a parameterized inner module called Ring. The system models a value that can be incremented or decremented within a finite ring of natural numbers, wrapping around at the boundaries.

The inner Ring module defines a counter operating on values from 0 to cardinality minus 1. The single variable **value** holds the current counter state. Incrementing adds one modulo the cardinality, while decrementing either subtracts one or wraps from zero to the maximum value. The ring requires cardinality greater than one.

The outer module instantiates Ring with cardinality 7, creating a counter cycling through values 0 to 6. Multiple specifications are defined: **SpecA** directly uses the Ring specification; **SpecB** combines initialization, increment-only transitions, weak fairness on all actions, and a modular arithmetic sanity check; **SpecC** allows both increment and decrement with strong fairness on increment actions.

The module defines liveness properties including **AECheck**, which asserts that the counter eventually cycles from 6 back to 0 infinitely often. A custom infix operator performs modular addition for sanity checking that expressions remain within bounds.

Failing test cases include **FalseAECheck**, which incorrectly expects cycling to value 1, and **ModInsanityCheck**, which tests an impossible arithmetic condition.
