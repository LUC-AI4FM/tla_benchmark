This TLA+ module specifies a simple counter system with two variables. The constant `Limit` is a natural number that serves as a boundary value.

The system maintains two variables: `x`, an integer counter, and `y`, a boolean flag that toggles with each state change. Initially, `x` starts at zero and `y` is false.

The system defines two actions. The `Increment` action increases `x` by one and flips `y`. The `Decrement` action, enabled only when `x` is positive, decreases `x` by one and also flips `y`. The next-state relation allows either action to occur.

Two specifications are defined. The basic `Spec` allows stuttering and permits any sequence of increments and decrements. The `LiveSpec` adds weak fairness on the `Increment` action, ensuring that if incrementing remains continuously enabled, it must eventually occur.

The module defines a safety property asserting that `x` never equals `Limit`, and a liveness property asserting that `x` eventually reaches `Limit`. These properties are in tension: the safety property fails precisely when the liveness property succeeds.

Four alias definitions provide different mappings of the state variables, used for trace exploration or output formatting purposes.
