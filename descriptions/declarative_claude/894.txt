This TLA+ module demonstrates how to use the TLC model checker as a calculator to evaluate and print TLA+ expressions. It does not specify a system, algorithm, or state machine—there are no variables, actions, or temporal logic involved.

The module extends the standard Naturals and TLC modules, importing arithmetic operators and the Print operator. The Print operator in TLC returns its second argument while causing TLC to display both arguments as a side effect during evaluation.

The module defines a helper operator PrintVal that takes an identifier string and an expression, then prints them as a pair for clarity when outputting multiple values.

The core of the module is a single ASSUME statement containing a conjunction of two PrintVal calls. TLC evaluates assumptions before model checking begins, and since conjunctions are evaluated left-to-right, this ensures the values print in order. The first expression computes a simple arithmetic result: accessing the "cat" field from a record and adding three. The second expression demonstrates record manipulation using the EXCEPT construct to create a modified copy of a baseball statistics record with updated player name and home run count.

The configuration file is empty since no constants, specification, or properties need declaration—the module exists solely to demonstrate expression evaluation and printing capabilities.
