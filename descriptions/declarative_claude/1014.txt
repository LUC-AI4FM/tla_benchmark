This TLA+ module provides a machine-checked proof for the VoucherLifeCycle specification. It establishes that the specification VSpec guarantees the invariant combining VTypeOK and VConsistent holds throughout all behaviors.

The module extends the base VoucherLifeCycle specification and imports the TLA+ Proof System (TLAPS) for formal verification. It defines a combined invariant Inv as the conjunction of VTypeOK (type correctness) and VConsistent (consistency properties).

The main theorem Spec_TypeOK_Consistent asserts that VSpec implies the invariant Inv holds globally (indicated by the temporal always operator). The proof proceeds in two steps: first showing that the initial state VInit establishes Inv, then demonstrating that Inv is preserved by all transitions—both actual VNext steps and stuttering steps over the variables vState and vlcState. The proof relies on the definitions of the actions Issue, Transfer, Redeem, and Cancel from the base module.

The QED step combines these results using propositional temporal logic (PTL) to conclude the invariance property. This proof confirms that the type correctness and consistency properties together form an inductive invariant for the voucher lifecycle system, meaning the system maintains these properties from initialization through all possible state transitions.
