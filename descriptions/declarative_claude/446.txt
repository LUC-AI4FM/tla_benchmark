This TLA+ module is a test specification that verifies the correctness of numeric literal parsing in TLA+ across different number bases: binary, octal, and hexadecimal.

The module extends the Naturals module to access basic natural number operations and comparison.

The specification consists entirely of a single ASSUME block containing a conjunction of equality assertions. These assertions verify that the decimal number 63 can be equivalently expressed using alternative numeric literal notations supported by TLA+. Specifically, it tests that binary notation (\b or \B prefix) with the value 111111, octal notation (\o or \O prefix) with the value 77, and hexadecimal notation (\h or \H prefix) with the value 3F all evaluate to the decimal value 63.

The tests also verify case insensitivity for both the prefix letters (lowercase \b, \o, \h versus uppercase \B, \O, \H) and for hexadecimal digits (3f versus 3F).

This module contains no variables, no actions, no temporal logic, and no behavioral specification. It defines no state machine or system model. Its sole purpose is to serve as a parser and evaluator test, ensuring that the TLA+ tooling correctly interprets numeric literals in non-decimal bases. The ASSUME statement causes these conditions to be checked when the specification is processed.
