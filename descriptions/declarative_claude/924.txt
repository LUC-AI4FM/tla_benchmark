This TLA+ module specifies a FIFO (First-In-First-Out) queue that connects an input channel to an output channel through an internal buffer. The system models asynchronous message passing with buffering.

The module imports a Channel specification twice: once for the input channel and once for the output channel, parameterized by a Message type constant. The state consists of three variables: `in` (the input channel), `out` (the output channel), and `q` (an internal sequence serving as the buffer queue).

Four actions define the system behavior: SSend allows sending any message from the Message set into the input channel. BufRcv receives a message from the input channel and appends it to the tail of the internal queue. BufSend, enabled only when the queue is non-empty, sends the head of the queue to the output channel and removes that element. RRcv receives a message from the output channel.

The initial state establishes both channels in their initial configurations with an empty queue. The next-state relation permits any of the four actions to occur.

The temporal specification uses stuttering-allowed semantics with no fairness constraints, meaning the system may indefinitely delay any action.

The module states a theorem that the specification maintains a type invariant ensuring both channels satisfy their type constraints and the queue remains a sequence of messages.
