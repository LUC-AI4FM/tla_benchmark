This TLA+ module is a test suite for a JSON serialization library, validating the behavior of JSON conversion operators rather than modeling a distributed system or algorithm.

The module tests the `Json` library's operators for converting TLA+ values to JSON strings and for file-based serialization. It declares one constant, `ModelValueConstant`, used to verify that TLA+ model values serialize correctly.

The tests are organized into several categories. First, empty value tests confirm that empty sets and sequences both serialize to empty JSON arrays. Primitive value tests verify correct JSON encoding of booleans, integers, strings, and model values. Structural value tests check serialization of sets, sequences, functions, records, Cartesian products, powersets, and integer ranges using `ToJson`, `ToJsonArray`, and `ToJsonObject` operators.

File serialization tests exercise `JsonSerialize`, `JsonDeserialize`, `ndJsonSerialize`, and `ndJsonDeserialize` operators (the "nd" prefix indicating newline-delimited JSON format). These tests write sequences of objects, arrays, and primitives to files and read them back, verifying round-trip integrity. Two round-trip tests confirm that complex nested structures survive serialization and deserialization unchanged.

Error handling tests verify that the serialization operators reject invalid inputs—sets for `JsonSerialize` and non-sequences for `ndJsonSerialize`—by checking that appropriate error messages are produced.

All tests use `ASSUME` statements, meaning they execute at specification load time rather than during model checking. The module contains no variables, actions, or temporal properties.
