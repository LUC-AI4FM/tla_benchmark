This TLA+ module is a test specification designed to verify that TLC's fingerprinting mechanism correctly identifies equivalent values represented in different syntactic forms.

The specification declares five variables: x (a record), y (a sequence), z (a set), w (a function), and u (a modified function). It also defines helper functions f and g, which compute the same values over equivalent domains expressed differently, and m, a simple mapping.

The initial state sets x to a record with fields a and b, y to a two-element sequence, z to a set containing 1, 2, and 3, w to function f, and u to a modified version of m. An assertion checks that sequences and equivalent functions compare as equal.

The next-state relation offers multiple disjunctive alternatives, each producing values that should be semantically identical to the initial values despite different constructions. These include: records built via explicit function notation, sequences constructed through concatenation or EXCEPT expressions, sets specified with duplicates or as ranges or through set mapping, and functions defined over Cartesian products versus nested domains.

The invariant is trivially true. The specification's purpose is to confirm that TLC generates exactly one distinct state, demonstrating that fingerprinting correctly recognizes all these equivalent representations as identical states rather than exploring redundant states.
