This TLA+ module is a regression test for the Apalache model checker, specifically testing its handling of nested function sets (function sets that contain other function sets).

The specification defines two variables: `witness`, which holds a set of functions with a complex nested type structure (functions from sequences of booleans to functions from integers to integers), and `found`, a boolean flag.

In the initial state, `witness` is chosen from one of two specific singleton function sets. Each option maps the singleton set containing the sequence `<<TRUE>>` to a function set: either mapping `{1}` to `{2}` or mapping `{3}` to `{4}`. The `found` variable is initialized to an arbitrary boolean value.

The next-state relation specifies that both variables remain unchanged throughout execution, meaning the system is completely static after initialization.

The module includes one property called `NotFound`, which asserts that `found` is always false. This serves as a simple invariant for testing purposes.

The primary purpose of this module is not to model a meaningful system but to verify that the Apalache model checker correctly handles the type-checking and evaluation of nested function set constructions, addressing a specific issue (GitHub issue 1774) in the tool's implementation.
