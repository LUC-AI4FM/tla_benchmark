This TLA+ module specifies a framework for assigning logical colors to theorem proof steps based on the states of proof obligations. It models part of a proof management system, likely for the TLA+ Toolbox.

The specification defines how proof trees are structured, where each tree has a root step with an optional proof. Leaf proof trees either have no proof or contain leaf proofs with zero or more obligations. The module introduces dummy obligations for missing or omitted proofs.

The single constant, ProofStatesSpec, is a sequence of sequences of strings that defines the possible statuses for each prover. The specification assumes three provers: Isabelle (with statuses untried, proving, proved, failed, stopped), Other (same statuses), and TLAPM (none, trivial).

Obligation states are either dummy states (missing or omitted) or proof states consisting of a status tuple for each prover. The StateNumber operator provides a bijective enumeration of all obligation states by assigning consecutive integers starting from zero, with missing mapped to zero and omitted to one, followed by all valid prover status combinations.

The module defines Sum and Product as recursive helper functions over function domains. A theorem IsNumbering asserts that StateNumber correctly enumerates states without collisions. The NumberToState function inverts this enumeration.

The module instantiates ColorPredicates to define how color predicates—based on sets of obligation states and quantifier type—determine proof tree coloring.
