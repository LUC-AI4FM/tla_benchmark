This TLA+ module is a test suite for verifying the correct behavior of the Cartesian product operator (`\X`) in TLA+ and its model checker TLC.

The specification uses a single variable `x` that is initialized to 1 and never changes, creating a trivial system with exactly one state. This minimal structure exists solely to provide a framework for running the invariant checks.

The invariant `Inv` contains sixteen tests that exercise various aspects of Cartesian products. These tests verify: equality of finite Cartesian products with explicitly enumerated sets of tuples; function application over products of infinite sets (naturals and integers); tuple membership in products of finite and infinite sets; intersection of function spaces with Cartesian products; subset relationships involving products; and nested Cartesian products of three and four sets, confirming that tuples flatten correctly.

Each test uses a conditional that triggers an assertion failure if the expected mathematical property does not hold, otherwise printing a success message. The tests cover both two-way and higher-arity products, products involving infinite domains like `Nat` and `Int`, and combinations with other set operations like intersection and subset.

The configuration specifies `Init` as the initial predicate, `Next` as the next-state relation, and `Inv` as an invariant to check. Since the system has only one reachable state, model checking effectively runs all tests once to validate Cartesian product semantics.
