This module specifies Jayadev Misra's algorithm for computing the set of nodes reachable from a given root node in a directed graph. The algorithm is a variant of breadth-first search designed to facilitate parallel implementation.

The specification extends a Reachability module that defines the graph structure through constants Nodes and Succ (successor function), and provides the ReachableFrom operator. An additional constant Root designates the starting node, assumed to be in Nodes.

Two variables track progress: `marked` holds nodes confirmed as reachable, and `vroot` holds candidate nodes to explore. A program counter `pc` tracks termination. Initially, marked is empty, vroot contains only Root, and pc is "a".

The main action repeatedly selects a node v from vroot. If v is not yet marked, the algorithm adds v to marked and adds all its successors to vroot. If v is already marked, it simply removes v from vroot. The algorithm terminates when vroot becomes empty. The specification includes weak fairness on the next-state relation.

The module defines several invariants: TypeOK ensures variables have proper types; Inv1 states that successors of marked nodes remain in marked or vroot; Inv2 and Inv3 establish relationships between marked, vroot, and reachable nodes.

Two correctness properties are stated as theorems: partial correctness asserts that upon termination marked equals the reachable set, and termination asserts that if Reachable is finite, the algorithm eventually completes.
