This TLA+ module is an internal utility module for the Apalache model checker, designed to resolve circular dependencies between Apalache's core functionality and community modules. It is not intended for direct use by specification authors.

The module defines three operators that serve as placeholder implementations, which Apalache's internal machinery replaces with optimized versions during model checking.

The first operator, `__ApalacheFoldSet`, performs a fold operation over a set. It takes a binary operator, an initial accumulator value, and a set, then combines all set elements using the operator to produce a single result.

The second operator, `__ApalacheFoldSeq`, performs a left fold over a sequence. It similarly takes a binary operator, an initial value, and a sequence, processing elements from left to right.

The third operator, `__ApalacheMkSeq`, constructs a sequence by applying a function to consecutive integers from one to a specified length, avoiding the overhead of general function constructors.

All three operators have dummy implementations that simply return trivial values (the initial value for folds, an empty sequence for the constructor). These placeholders exist solely to provide valid TLA+ syntax; Apalache rewires them to efficient internal operations during analysis. The module contains no variables, temporal properties, or invariants—it purely provides operator definitions for internal use.
