This TLA+ module serves as a type-annotated wrapper for a RingBuffer helper module, designed for use with the Apalache model checker. The wrapper adds explicit type annotations while keeping the original RingBuffer specification free of tool-specific syntax.

The module models a ring buffer data structure with the following constants: Size defines the buffer capacity; Readers and Writers specify sets of threads that can access the buffer; Values represents the set of possible data values; and NULL represents an empty or uninitialized slot.

The single variable ringbuffer is a record containing three components: slots maps buffer positions to stored values, readers tracks which threads are currently reading each position, and writers tracks which threads are currently writing each position.

The module imports definitions from RingBuffer via INSTANCE, which provides an Init predicate and parameterized actions for Write, EndWrite, BeginRead, and EndRead operations. Notably, RingBuffer intentionally omits a Next-state relation because it functions as a helper module rather than a complete specification. The actual protocol controlling buffer access and ensuring the NoDataRaces property must be defined by concrete specifications such as Disruptor_SPMC or Disruptor_MPMC that use this ring buffer.

This wrapper has no model-checking configuration and is intended only for type-checking verification with Apalache.
