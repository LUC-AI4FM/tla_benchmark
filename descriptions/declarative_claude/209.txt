The module Rec7 models a simple stepping system that exercises a recursive function defined without TLA+'s native recursive-function syntax. It uses two variables: `n`, an integer counter, and `f`, which holds the value of a factorial function at the current step.

The factorial function `Fact` is defined via a CHOOSE expression that selects a function from the set `[1..5 -> Int]` satisfying the standard factorial recurrence: for every index `k` in its domain, `fun[k]` equals 1 if `k ≤ 1`, and `k * fun[k-1]` otherwise. This definition avoids the recursive-function syntax deliberately, serving as a test case for tools such as Apalache that handle CHOOSE differently from explicit recursion.

In the initial state, `n` is set to 0 and `f` is set to `Fact[0]`. Each step increments `n` by one and updates `f` to `Fact[n']`, the factorial of the new counter value. The module defines no temporal specification, fairness conditions, invariants, or properties; it is essentially a test or demonstration module intended to check whether a model checker can correctly evaluate a CHOOSE-based recursive function definition across successive states.
