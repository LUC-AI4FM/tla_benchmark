This module provides Apalache-compatible type annotations for a spanning tree construction algorithm specified in a separate `spanning` module, which it imports via INSTANCE.

The specification models a distributed algorithm where processes collaboratively build a spanning tree over a network. The system consists of a set of processes (`Proc`) connected by a neighbor relation (`nbrs`), with one designated `root` process. A special value `NoPrnt` indicates a process has no parent yet.

The state is captured by three variables: `prnt` maps each process to its parent in the spanning tree, `rpt` tracks whether each process has reported its status, and `msg` holds the set of messages (process pairs) currently in transit.

The module instantiates the underlying `spanning` specification, inheriting its `Init` initial state predicate and `Next` transition relation. The configuration explicitly uses these predicates without fairness conditions, since Apalache cannot handle weak fairness. The `TypeOK` invariant is checked to ensure variables maintain their expected types throughout execution.

Concrete constant values define a three-process system where p1 serves as root, connected linearly: p1 neighbors p2, and p2 neighbors p3, with bidirectional edges. This small instance enables model checking of the spanning tree protocol's safety properties.
