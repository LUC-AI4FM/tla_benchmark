This TLA+ module specifies a simple one-variable system that models a boolean flag transitioning from false to true.

The system has a single variable `b` representing a boolean state. The initial state sets `b` to FALSE, and the only possible transition sets `b` to TRUE.

Three specification variants are defined: `SpecNoFair` allows stuttering indefinitely with no fairness requirement; `SpecWithFair` adds weak fairness on the Next action, ensuring the transition eventually occurs if continuously enabled; and `SpecWithCustomFair` directly asserts eventual truth of `b` as part of the specification.

Several temporal properties are defined for checking. `SafetyProp` states that once `b` becomes true, if it ever becomes false again, it stays false forever. `EventuallyB` asserts `b` eventually becomes true. `LeadsToB` specifies that `b` being false leads to `b` being true. `InfOftenB` requires `b` to be true infinitely often. `EventuallyAlwaysB` requires `b` to eventually stay true forever. `VacuousLive` is an implication that if `b` is true, then eventually `b` becomes false.

The module also instantiates a helper module H, which provides a more abstract specification where `b` can be any boolean and transitions can set it to any boolean value. Refinement mappings relate the concrete specification to this abstract one, both with and without fairness.
