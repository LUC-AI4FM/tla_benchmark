This TLA+ module specifies a simple two-variable system that models minimal state transitions for testing TLC's temporal property checking capabilities.

The system uses two variables: `x` and `y`, both natural numbers. The initial state sets both variables to zero. The next-state relation keeps `x` unchanged (always equal to its previous value) while `y` alternates between 0 and 1 by computing `1-y` at each step.

The resulting state space is minimal: starting from the initial state (0,0), the system transitions to state (0,1), then back to (0,0), creating a cycle between these two states. The variable `x` remains permanently at zero throughout all executions, while `y` oscillates indefinitely.
