This TLA+ module specifies a simple system with a single Boolean variable that can toggle freely between true and false states. The specification serves as a test case for TLC model checker behavior, particularly around counterexample generation.

The system has one variable, x, which starts as FALSE. The next-state relation allows x to take any Boolean value in each step, meaning it can remain unchanged, flip from false to true, or flip from true to false.

The main temporal specification combines the initial condition with the next-state relation but does not include fairness, allowing stuttering and arbitrary behavior.

The key property being checked is AtMostOnce, which states that once x becomes true and subsequently becomes false, it must remain false forever. This property restricts x from returning to true after transitioning from true to false. An equivalent formulation AtMostOnceEquiv expresses the same constraint differently.

The PostCondition definition verifies that the model checker produces a specific counterexample trace: FALSE to TRUE to FALSE to TRUE. This four-state sequence violates AtMostOnce because x returns to true after having been true then false.

Additional definitions include a fair specification variant with weak fairness, the negation of AtMostOnce, a leads-to property EventuallyFlipBack, and a trivial tautology.
