This TLA+ module serves as a test case for TLC model checker functionality, specifically related to GitHub issue 807. It tests the model checker's ability to produce counterexamples and specification metadata in a particular format.

The specification models a simple counter system with a single variable x representing an integer value. The system initializes x to zero and repeatedly increments it by one, with the constraint that x cannot exceed ten.

The Init action sets x to zero. The Add action increments x by a delta value while ensuring the result stays at or below ten. The Next action wraps Add, using a trivially true conditional that always produces delta of one. The specification Spec combines initialization with stuttering-allowed next steps.

The invariant IsNotTwo asserts that x should never equal two, which is deliberately violated when the counter reaches that value.

The PostCondition is a test oracle that verifies TLC produces the expected counterexample structure and specification metadata. It checks that the counterexample shows the trace from x equals zero through one to two, and validates detailed coverage and location information for all specification components including actions, initial states, invariants, and variables.

The configuration runs the specification, checks the IsNotTwo invariant, and validates the PostCondition after model checking completes.
