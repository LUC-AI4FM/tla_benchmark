This TLA+ module presents a minimal working example demonstrating a limitation in the Apalache model checker, specifically related to issue #1126.

The specification defines a single variable `seq`, which is typed as a sequence of integers. The system begins in an initial state where `seq` is an empty sequence.

The next-state relation attempts to non-deterministically select any sequence from the set of all possible sequences over the elements {1, 2, 3} and assign it to `seq`. This includes sequences of any length—empty, finite, or conceptually infinite—constructed from those three integers.

The module highlights an incompatibility: while TLA+ semantically allows quantification over the set `Seq(S)` (all finite sequences over set S), the Apalache model checker does not support this construct. The set `Seq({1, 2, 3})` is infinite, containing sequences of unbounded length, which makes direct enumeration impossible for bounded model checking tools.

The specification contains no invariants, safety properties, liveness conditions, or fairness requirements. It serves purely as a demonstration of this specific tooling limitation rather than modeling any meaningful system behavior.
