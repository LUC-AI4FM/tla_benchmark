This TLA+ module extends the DieHard specification, which models the classic puzzle from the movie Die Hard 3 involving measuring exactly 4 gallons of water using a 3-gallon and a 5-gallon jug.

The module defines three alias records used for debugging and trace exploration during model checking. These aliases select different subsets of state variables to display:

**AliasSub** exposes only the `water_to_pour` variable, hiding the bucket states and action information.

**AliasSub2** exposes only the `action` variable, which tracks what operation was performed (such as filling, emptying, or pouring between buckets).

**AliasSup** is a superset alias that includes all standard variables (`bigBucket`, `smallBucket`, `action`, `water_to_pour`) plus an additional `extraVar` that captures the current search level from TLC using the `TLCGet("level")` function, providing debugging insight into the model checker's exploration depth.

The module itself contains no new behavioral specifications, invariants, or properties. It serves purely as a utility module for configuring how state information is displayed during model checking of the underlying DieHard specification. The actual system behavior, including the bucket-filling actions and the goal of measuring exactly 4 gallons, is inherited from the extended DieHard module.
