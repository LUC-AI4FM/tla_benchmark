This TLA+ module specifies a simple system where elements from a set of humans are progressively added to a collection.

The specification declares two constants: **Humans** and **Others**, representing two disjoint sets of entities. A symmetry set is defined combining permutations of both constants, allowing the model checker to reduce state space by treating symmetric configurations as equivalent.

The single variable **set** tracks which humans have been added to the collection. The type invariant **TypeOK** ensures that **set** always remains a subset of Humans, never containing elements from Others or any other values.

The **Init** predicate establishes the initial state with an empty set. The **Next** relation specifies that in each step, some human from the Humans constant is non-deterministically selected and added to the set via union. Since union is idempotent, adding an already-present human leaves the set unchanged, meaning the system can stutter once all humans are included.

The model configuration instantiates Humans and Others as singleton sets, applies symmetry reduction across both constants, and checks the TypeOK invariant. This specification appears designed to test TLA+ tooling behavior regarding symmetry sets that span multiple constants, as suggested by the module name referencing a GitHub issue.
