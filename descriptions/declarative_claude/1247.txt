This TLA+ module defines the standard library **FiniteSets**, which provides fundamental operators for reasoning about finite sets in specifications.

The module locally imports Naturals and Sequences without re-exporting them, keeping its interface minimal.

**IsFiniteSet** is a predicate that determines whether a given set S is finite. The definition states that S is finite if and only if there exists a finite sequence whose elements cover all members of S—that is, every element of S appears at some position in the sequence.

**Cardinality** computes the number of elements in a finite set S. It uses a recursive definition over subsets of S: the cardinality of the empty set is zero, and the cardinality of any non-empty subset T equals one plus the cardinality of T with an arbitrarily chosen element removed. This recursion terminates because each step reduces the subset size by one.

The module contains no variables, actions, temporal formulas, or properties to check—it is purely a library of operator definitions. In practice, TLC overrides both operators with efficient Java implementations rather than evaluating the mathematical definitions directly, which would be computationally expensive. These operators are commonly used throughout TLA+ specifications whenever finite set membership testing or counting is needed.
