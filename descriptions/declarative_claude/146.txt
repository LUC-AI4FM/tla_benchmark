This is a test module for verifying the handling of `LET-IN` expressions within temporal formulas during model checking. It models a simple two-variable system over integers where the variables `x` and `y` swap values on every step.

The initial state sets `x` to 0 and `y` to 1, and the `Next` action exchanges their values, so the system alternates between the states `(x=0, y=1)` and `(x=1, y=0)` indefinitely. The module defines two temporal properties that each use nested `LET-IN` expressions to introduce a local operator `Plus` and a local alias `var1` for `x`. `Liveness` asserts that `[]<>(Plus(Plus(var1, y), var1) = 2)` — that is, infinitely often `2*x + y = 2` — which holds because the system cycles through both states and the condition is satisfied when `x=1, y=0`. `FalseLiveness` asserts `<>[](Plus(var1, y) = 2)` — that eventually `x + y = 2` holds forever — which is false because `x + y` is always either 1 or 1 (i.e., constantly 1), so the sum never stabilizes at 2. The module's primary purpose is to exercise and test how a tool parses and evaluates `LET-IN` definitions embedded inside temporal operators.
