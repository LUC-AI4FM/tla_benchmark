This TLA+ module specifies a minimal system designed to test the behavior of Apalache's `ApaFoldSeqLeft` operator when folding over a sequence to construct another sequence.

**System Being Modeled:**
The module defines a trivial static system with no meaningful state transitions, serving primarily as a test harness for verifying the fold operation.

**Variables:**
- `x`: An integer variable that remains constant throughout execution.

**Key Actions:**
- `Init`: Initializes `x` to zero.
- `Next`: Leaves `x` unchanged, meaning the system has no dynamic behavior.

**Operators:**
- `A`: A binary operator that appends an integer to a sequence, used as the combining function for the fold operation.

**Invariant:**
- `Inv`: Asserts that folding the append operator `A` over the sequence `<<1,2,3>>` starting from an empty sequence produces `<<1,2,3>>`. This verifies that `ApaFoldSeqLeft` correctly reconstructs a sequence by successively appending each element from left to right.

The specification contains no temporal properties, fairness conditions, or liveness properties. Its sole purpose is to validate that the Apalache model checker's sequence fold operation behaves correctly when building sequences through successive appends.
