# EventCounter Module Description

This TLA+ module specifies a simple event counting mechanism designed to support bounded model checking of other specifications.

## Variable

The module declares a single variable `nEvents` that tracks the number of events that have occurred in the system.

## Constant Definition

The constant `maxEvents` is defined as -1, representing an unlimited event mode. When set to a positive value, it would establish an upper bound on the number of events permitted.

## Initialization

The `InitEvents` predicate initializes the event counter to zero at the start of any execution.

## Key Action

The `CountEvent` action provides conditional behavior based on the `maxEvents` setting. When `maxEvents` equals -1 (unlimited mode), the counter remains unchanged—this prevents infinite state spaces during model checking. When `maxEvents` is set to a finite bound, the action increments the counter only if the current count is below the maximum, effectively blocking further events once the limit is reached.

## Purpose

This module serves as a utility component intended to be composed with other specifications. It provides a mechanism to bound the number of certain tagged actions during model checking, making finite verification possible for systems that might otherwise have unbounded behaviors.
