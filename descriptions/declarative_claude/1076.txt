This TLA+ module contains **machine-checked proofs** about the EWD998PCal specification, which models Dijkstra's EWD998 termination detection algorithm using PlusCal with an explicit network of message bags.

## System Being Modeled

The specification models a distributed termination detection algorithm where nodes communicate via a network represented as per-node bags of messages. Messages are either payload messages ("pl") or a unique circulating token ("tok"). The module proves that this PlusCal implementation correctly refines the original EWD998 specification.

## Key Definitions

**Type Invariants**: The module defines `PCalTypeOK` comprising typing constraints on `active` (boolean per node), `color` (white/black per node), `counter` (integer per node), and `NetworkOK`—which ensures the network contains well-typed message bags with exactly one token of multiplicity one across all nodes.

**Message Types**: Messages are either payload records `[type: {"pl"}]` or token records `[type: {"tok"}, q: Int, color: ColorSet]`.

## Proven Properties

The module establishes several lemmas:
- `InitNetworkOK` and `InitTypeOK`: The initial state satisfies network well-formedness and type invariants
- `InitPending` and `InitToken`: Initial refinement mapping correctness for pending counts and token state
- `InitRefinement`: The PlusCal initial state implies EWD998's initial state under the refinement mapping
- `TypeOK_Step`: The type invariant is preserved by all transitions (partially shown, with some cases truncated)

Helper lemmas prove that bag operations (`BagAdd`, `BagRemove`) preserve message typing and token uniqueness, which are essential for the inductive invariant proofs.
