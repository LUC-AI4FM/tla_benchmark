# EWD998_opts Module Description

This module extends the EWD998 termination detection algorithm specification to support experimental variants and statistical data collection during simulation. It is designed exclusively for TLC's random trace generation mode to measure the efficiency of different algorithm optimizations.

The module introduces a constant **F**, a subset of feature flags (pt1 through pt5) that enable algorithm variants. These variants modify token-passing behavior: pt1 and pt2 allow active nodes to pass tokens when tainted; pt3 and pt4 "short-circuit" inconclusive rounds by returning tokens directly to the initiator; pt5 restricts the initiator to only start rounds when inactive.

The specification uses **InitSim** to constrain initial states to realistic starting configurations by randomly sampling from possible active and color assignments. The actions **SystemOpts** and **EnvironmentOpts** replace the original system and environment actions, incorporating the feature flag logic. Message sending probability decreases over time based on trace length.

The module collects performance statistics using TLC registers and CSV output. **AtTermination** records when actual termination occurs, while **AtTerminationDetected** triggers when termination is detected, writing metrics including trace length, detection delay, and action counts to a file.

The configuration reads the number of nodes **N** and feature set **F** from environment variables, enabling automated experiments across different configurations. The spec requires TLC's generation mode, unlimited depth, and disabled deadlock checking since the algorithm naturally terminates.
