This TLA+ module defines the standard natural numbers and basic arithmetic operations by importing them from a more fundamental module called ProtoReals.

The module establishes **Nat** as the set of natural numbers, derived from the ProtoReals module's definition.

It defines the standard **arithmetic operators**: addition (+), subtraction (-), multiplication (*), and exponentiation (^), all delegating to corresponding operations in ProtoReals.

The module specifies **comparison operators**: less-than-or-equal (≤) comes from ProtoReals, while greater-than-or-equal (≥), strict less-than (<), and strict greater-than (>) are defined in terms of ≤ and inequality.

The **range operator** (a .. b) produces the set of all integers from a to b inclusive, using the Int set from ProtoReals.

**Integer division** (div) is defined as the unique integer n such that when multiplied by the divisor and added to some remainder between 0 and b-1, it equals the dividend. The **modulo operator** (%) computes the remainder as the difference between the dividend and the product of divisor and quotient.

This is a foundational library module providing arithmetic primitives used throughout other TLA+ specifications. It contains no state variables, temporal properties, or behavioral specification—it purely defines mathematical operators over natural numbers and integers.
