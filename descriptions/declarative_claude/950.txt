# RealTimeHourClock Module Description

This module specifies a real-time hour clock that extends the basic HourClock specification by adding timing constraints on how frequently the hour hand advances.

## Constants and Variables

The specification uses variable `hr` (inherited from HourClock) for the hour value, and `now` representing the current real time. The constant `Rho` is a positive real number representing the allowed timing tolerance.

## System Behavior

The specification combines three components: the basic hour clock behavior (HC), a real-time now variable (RTnow), and timing constraints (HCTime) expressed through an existentially quantified timer variable `t`.

The `now` variable models advancing real time—it can only increase and starts as a real number. A weak fairness condition ensures time continually advances past any real value.

## Timing Constraints

The inner module defines a timer `t` that resets to zero whenever the hour clock ticks (HCnxt) and otherwise accumulates elapsed time. Three properties govern timing: the timer starts at zero and follows the reset/accumulate pattern (Timer), the hour clock must tick before `t` exceeds 3600 + Rho seconds (MaxTime), and each tick can only occur after at least 3600 - Rho seconds have elapsed (MinTime).

## Overall Specification

RTHC combines the hour clock behavior with real-time progression and timing bounds, ensuring the hour advances approximately every 3600 seconds (one hour), within tolerance Rho.
