This TLA+ module specifies a simplified Tendermint consensus protocol extended with proposer-based timestamps (PBTS). The specification models Byzantine fault-tolerant consensus where processes progress through rounds, exchanging proposals, prevotes, and precommits to reach agreement on values with associated timestamps.

The model distinguishes correct processes (Corr) from faulty/Byzantine ones (Faulty), with parameters defining thresholds for Byzantine tolerance (T), valid and invalid values, maximum rounds, and a proposer function mapping rounds to designated proposers. Time-related constants capture message delay, clock precision (maximum difference between local clocks), clock accuracy (deviation from real time), and optional clock drift.

State variables track each process's current round, step (PROPOSE, PREVOTE, PRECOMMIT, or DECIDED), decision, locked and valid values/rounds, and local clocks. Global variables maintain real time, message pools for each message type per round, evidence of messages used in transitions, and timing metadata for proposals.

The next-state relation advances real time, optionally advances local clocks with drift, and allows message processing actions including broadcasting proposals, receiving and validating proposal timeliness against local clocks, casting prevotes and precommits based on quorum thresholds (2T+1), and making decisions when sufficient precommits exist.

Key safety invariants verify agreement on decided values and timestamps, that decided timestamps fall within valid bounds relative to consensus start/end times and clock precision, and that timestamps are consistent with real-time proposal times. A liveness property ensures timely proposals from correct proposers are eventually received.
