This module provides Apalache-specific type annotations for an asynchronous interface specification, wrapping the original `AsynchInterface` module via instantiation to keep the base specification free of tool-specific syntax.

The system models an asynchronous communication interface between a sender and receiver, using a standard handshaking protocol. The interface consists of three variables: `val` holds a data value from the set `Data`, while `rdy` (ready) and `ack` (acknowledge) are integer signals used for synchronization between the communicating parties.

The constant `Data` represents the set of possible data values that can be transmitted. For model checking, this is instantiated with a concrete two-element set containing symbolic datum values.

The module imports all definitions from `AsynchInterface` through the `INSTANCE` statement, including the specification `Spec` which defines the initial state and next-state relation governing how the handshaking signals and data value evolve.

The configuration specifies that `TypeInvariant` should be checked as a safety property, ensuring that all reachable states maintain proper typing constraints on the variables. The temporal specification `Spec` from the instantiated module governs the overall system behavior, defining valid executions of the asynchronous interface protocol.
