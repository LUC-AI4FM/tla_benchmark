This TLA+ module is a test case designed to demonstrate ill-typed record access behavior, specifically testing how record membership checks handle mismatched field structures.

The module imports the Integers standard module and defines a single operator called TestAccess. This operator constructs a record r1 with two fields: field "a" containing the integer 28, and field "b" containing the string "abc". It then tests whether this record belongs to a set of records that have a different structure—specifically, records with field "a" ranging from 1 to 3, field "b" being either "foo" or "bar", and an additional field "c" of Boolean type.

This specification serves as a test for type checking or model checking tools to identify problematic record operations. The membership test is ill-typed for multiple reasons: the value 28 is outside the range 1 to 3, the string "abc" is not in the set containing "foo" and "bar", and the record r1 lacks the field "c" entirely that the record set requires.

The module contains no variables, temporal operators, fairness conditions, or explicit invariants. It exists purely to test how TLA+ tools handle record type mismatches during static analysis or evaluation.
