This TLA+ module defines type aliases used for type-checking specifications related to a Byzantine fault-tolerant consensus protocol, likely Tendermint or a similar algorithm.

The module specifies no behavior itself but establishes a type system for a distributed consensus model. It defines basic types: PROCESS and VALUE as strings representing participants and proposed values, STEP and ACTION as strings for protocol phases, ROUND as integers for consensus rounds, TIME as integers for timestamps, and TRACE as sequences of strings for execution traces.

Composite types capture protocol data structures. PROPOSAL pairs a value with a timestamp. DECISION extends this with a round number, representing finalized consensus outcomes. Three message types are defined: PROPMESSAGE for proposals containing source, round, proposal content, and valid round information; PREMESSAGE for prevote or precommit messages with source, round, and proposal identifier; and MESSAGE as a unified type combining fields from both message types.

RCVPROP represents a received proposal as a process-message pair. The STEP type appears in message type fields, indicating protocol phases like propose, prevote, or precommit.

The module contains only a trivial TRUE definition, serving purely as a type declaration file for use with the Apalache model checker's type system, to be imported by behavioral specifications modeling the consensus protocol.
