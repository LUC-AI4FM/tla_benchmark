This module provides a model-checking configuration for a Multi-Paxos distributed consensus specification. Multi-Paxos extends the basic Paxos algorithm to handle multiple consensus instances (slots) efficiently, allowing a replicated state machine to agree on a sequence of commands.

The configuration instantiates the system with two proposers, three acceptors forming three possible majority quorums, one learner, two values, and two slots. Ballots are restricted to zero and one for tractable model checking. Symmetry reductions are applied across all finite sets to reduce the state space.

The module defines helper predicates for reasoning about the protocol: whether values have been proposed or voted for in particular ballots and slots, whether acceptors cannot vote in certain ballots, and whether values have been chosen by a quorum.

The type invariant specifies that messages belong to well-formed sets covering phase-1a, phase-1b, phase-2a, and phase-2b messages, and that proposer and acceptor state variables maintain appropriate types.

Three key properties are checked. The nontriviality invariant ensures learned values were previously proposed. The consistency invariant guarantees at most one value is learned per slot. The module also verifies refinement to a ConsensusMulti specification, which transitively ensures nontriviality, stability, and consistency properties hold. Deadlock checking is disabled since termination is expected in consensus protocols.
