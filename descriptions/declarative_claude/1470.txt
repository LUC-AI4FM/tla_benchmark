This TLA+ module demonstrates TLC's diagnostic features for tracking model checker statistics and storing/retrieving custom values during execution.

The specification models a simple counter system with a single variable **x** that starts at 1 and increments until reaching 10.

**Variable:** The sole variable **x** represents an integer counter.

**Initial State:** The **Init** predicate sets x to 1 and simultaneously stores the string "TLCSet works." in TLC's internal storage slot 1 using the TLCSet operator.

**Next-State Relation:** The **Next** action increments x by 1 while x remains below 10, and prints the value previously stored in slot 1 (retrieved via TLCGet) at each step.

**Model Configuration:** The configuration specifies Init and Next as the initial and next-state relations. It uses the special _POSSIBLE directive to track how often the predicates **AtFive** (true when x equals 5) and **Step** (describing the increment transition) are satisfiable during state exploration.

**Postcondition:** The **PossibleCounts** predicate serves as a postcondition checked after model checking completes. It verifies that TLC's internal statistics show AtFive was possible in exactly 1 state and Step was possible in exactly 9 states, confirming expected model checker behavior regarding state space exploration.
