This TLA+ module specifies a simple sequential algorithm demonstrating non-deterministic choice using PlusCal's "either-or" construct.

The algorithm operates on three integer variables x, y, and z, all initialized to zero. A program counter pc tracks execution progress through labeled steps.

The algorithm begins at label "a" with a non-deterministic choice: either set x to 1 and proceed to label "b", or set y to 1 and proceed to label "c". At label "b", x is incremented by 1, resulting in x equals 2. At label "c", y is incremented by 1, resulting in y equals 2. Both paths then converge at label "d".

At label "d", another non-deterministic choice occurs based on guards: if x equals 0, z is incremented by 1; if x equals 2, z is incremented by 3. After this choice, two assertions verify invariants: x plus y must equal 2, and z must equal x plus 1.

The temporal specification combines the initial state, the next-state relation allowing any defined action or stuttering, and weak fairness on the next-state relation to ensure progress.

The module checks a termination property ensuring the algorithm eventually reaches the "Done" state. The assertions embedded in action "d" serve as runtime safety checks validating the expected relationships between variables at that point.
