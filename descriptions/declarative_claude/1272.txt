The Alias module specifies a simple cyclic counter system with two variables: an integer x that cycles through values 1 to 4, and a boolean y that toggles with each step.

The system has two variables: x (an integer) and y (a boolean). The initial state sets x to 1 and y to FALSE.

Two actions define the next-state relation. Action A increments x by one while x is less than 4 and toggles y. Action B resets x to 1 when x equals 4, also toggling y. Together, these create a cycle where x repeatedly traverses 1 through 4.

The specification Spec defines the initial state and allows stuttering steps. FairSpec adds weak fairness on the Next action, ensuring progress cannot be blocked indefinitely.

The module checks one safety invariant, Inv, asserting that x remains less than 4. This invariant is violated when x reaches 4. The liveness property Prop asserts that eventually x exceeds 4, which is impossible since x never exceeds 4.
