This TLA+ module, named Github1145, is a minimal test specification designed to verify the correct behavior of sequence operations when applied to functions constructed in different ways. It does not model a distributed system or algorithm but instead serves as a regression or consistency test for the TLA+ tooling.

The module imports the Naturals and Sequences standard modules. It defines a helper operator F that extracts a single-element subsequence from position 2 to 2 of a given sequence.

The specification contains two ASSUME statements that assert equality conditions must hold during model initialization. The first assumption checks that applying F to a function defined over the integer range 1 to 4, with the second element modified to 1, produces the same result as applying F to an explicit tuple sequence. The second assumption performs an identical check but constructs the function using an explicitly enumerated set domain rather than an interval.

These assumptions verify that functions constructed via different syntactic forms—integer ranges versus enumerated sets—behave identically when used as sequences and processed by SubSeq. The module contains no variables, temporal logic, fairness conditions, or properties to check beyond the static assumptions validated at specification load time.
