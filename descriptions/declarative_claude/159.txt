This TLA+ module specifies a model-checking configuration for a Two-Phase Commit protocol with seven resource managers.

The system models a distributed transaction protocol coordinating between a transaction manager and multiple resource managers. The module instantiates a specification called TwoPhaseTypedInv with a concrete set of seven resource managers labeled "0_OF_RM" through "6_OF_RM".

The specification tracks four state variables: rmState maps each resource manager to its current state as a string; tmState holds the transaction manager's state as a string; tmPrepared contains the set of resource managers that have sent "Prepared" messages to the transaction manager; and msgs represents the set of messages in the communication channel.

The module uses typed annotations indicating that rmState is a function from resource managers to strings, tmState is a string, tmPrepared is a set of resource managers, and msgs is a set of message records.

This configuration module serves to instantiate the abstract TwoPhaseTypedInv specification with specific constant values, enabling model checking of the Two-Phase Commit protocol's properties with exactly seven participants. The actual transition relations, invariants, and properties being verified are defined in the referenced TwoPhaseTypedInv module.
