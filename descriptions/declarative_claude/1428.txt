This TLA+ module is a test suite for JSON serialization and deserialization operators provided by the Json library extension. It contains no state machine or temporal behavior—only ASSUME statements that verify correctness at specification evaluation time.

The module tests the ToJson, ToJsonArray, and ToJsonObject operators, which convert TLA+ values into JSON string representations. It verifies correct handling of empty values (sets and sequences become empty arrays), primitive values (booleans, integers, strings, and model values), and structural values (sets, sequences, functions, records, Cartesian products, and power sets). The configuration declares a single model value constant used to test serialization of TLA+ model values.

The module also tests round-trip serialization and deserialization using JsonSerialize/JsonDeserialize and their newline-delimited variants ndJsonSerialize/ndJsonDeserialize. These tests write TLA+ data structures to files and read them back, verifying the reconstructed values match the originals. Test cases cover sequences of records, nested arrays, primitive sequences, and complex nested structures.

Finally, the module includes error-handling tests using AssertError to verify that serialization operators properly reject invalid inputs, such as sets or non-sequence values where sequences or records are required.
