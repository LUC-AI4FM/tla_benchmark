This TLA+ module specifies a model-checking configuration for the Yo-Yo leader election algorithm with pruning, instantiating the `YoYoPruning` module with a concrete graph topology.

The system models a distributed leader election algorithm running on an undirected graph. The specification defines a small network of 5 nodes (numbered 1 through 5) connected by 5 edges forming a specific topology. A larger commented-out configuration with 11 nodes and 14 edges is also present as an alternative test case.

The module declares five variables: `active` tracks which nodes remain active in the election, `phase` indicates each node's current algorithm phase, `incoming` and `outgoing` represent directed edge relationships between nodes, and `mailbox` handles message passing between neighbors.

The specification checks several correctness properties. The `TypeOK` invariant ensures variables maintain proper types throughout execution. The `NeighborInv` invariant verifies consistency of neighbor relationships. The `FinishIffTerminated` invariant connects the algorithm's finish condition to termination. The `Liveness` property ensures the algorithm eventually completes. A `NoNewSource` property is commented out as it fails for the small example graph.

Deadlock checking is disabled, indicating that terminal states where no further transitions are possible are acceptable—representing successful algorithm termination when a leader has been elected.
