This module specifies a simple algorithm that finds the highest value in a sequence of natural numbers. The algorithm iterates through a sequence, tracking the maximum value seen so far.

The specification uses three main variables: `f` represents an input sequence of natural numbers, `h` tracks the current highest value found (initialized to -1), and `i` is the loop index (starting at 1). A program counter `pc` tracks execution state.

The algorithm consists of a single labeled action `lb` that implements a while loop. On each step, if the index has not exceeded the sequence length, the action updates `h` to the maximum of its current value and the current sequence element, then increments the index. When the loop completes, the program counter moves to "Done" and variables remain unchanged through stuttering steps.

The specification includes a type invariant `TypeOK` asserting that `f` remains a sequence of naturals, `i` stays within valid bounds, and `h` is either -1 or a natural number. An inductive invariant states that all previously examined sequence elements are less than or equal to `h`.

The main correctness property asserts that upon termination, `h` is greater than or equal to every element in the sequence. The module includes TLAPS proofs demonstrating that the type invariant, inductive invariant, and correctness property all hold. A termination property is also defined but not proven.
