This TLA+ module is a utility library providing JSON serialization and deserialization operations for use within TLA+ specifications. It does not model a distributed system, algorithm, or state machine, and contains no VARIABLES, temporal logic, fairness conditions, or properties to verify.

The module defines several operators for converting TLA+ values into JSON-formatted strings. The core conversion logic uses recursive helper operators: ToJsonObjectString constructs JSON object notation with curly braces and key-value pairs, while ToJsonArrayString constructs JSON array notation with square brackets. The main ToJson operator dispatches to the appropriate format based on whether the input appears to be a sequence or finite set versus a record structure.

Three public conversion operators are provided: ToJson for automatic format selection, ToJsonArray for forcing array output, and ToJsonObject for forcing object output. Each handles empty domains as a special case.

The module also declares operators for file-based serialization and deserialization: JsonSerialize and JsonDeserialize for standard JSON format, and ndJsonSerialize and ndJsonDeserialize for newline-delimited JSON. These operators have placeholder definitions—JsonSerialize returns TRUE, and the deserialize operators return an arbitrary chosen value—indicating they serve as stubs for TLC operator overrides that would provide actual file I/O functionality.
