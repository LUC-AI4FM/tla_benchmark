This TLA+ module serves as a type-annotated wrapper for the LiveHourClock specification, designed for compatibility with the Apalache model checker. It models a simple hour clock that cycles through hour values.

The module declares a single variable `hr` (hour), annotated with integer type for Apalache's type system. Through the INSTANCE mechanism, it imports all definitions from the underlying LiveHourClock module, binding the local `hr` variable to the imported specification's hour variable.

The model-checking configuration specifies `HCini` as the initial condition and `HCnxt` as the next-state relation. The original specification includes weak fairness on the hour transition (`WF_hr(HCnxt)`), ensuring the clock eventually advances rather than stuttering indefinitely, though the configuration focuses on the core state machine structure.

The underlying clock behavior models an hour display that increments through valid hour values in a cyclic manner, representing continuous time progression on a 12-hour or similar clock face.

The configuration checks `HCini` as an invariant, which verifies that the initial condition properties hold in all reachable states—essentially confirming that the hour variable remains within its valid range throughout execution.
