This module specifies the classic Towers of Hanoi puzzle with a generalized number of disks and towers.

The specification models disk configurations using bitwise encoding, where each tower's state is represented as a natural number. Each disk corresponds to a power of two, so a tower containing multiple disks stores their sum. This encoding enables efficient operations using bitwise arithmetic to check disk presence and movement legality.

The constants D and N represent the number of disks and towers respectively. The single variable towers is a function mapping tower indices to natural numbers representing which disks each tower holds.

Initially, all disks reside on the first tower, encoded as the value 2^D - 1, while other towers are empty. The next-state relation allows moving any disk that is the smallest on its source tower to any destination tower where it would also be smaller than all existing disks. Movement validity is determined through bitwise operations checking that no smaller disk exists above the moved disk.

The type invariant ensures tower values remain bounded natural numbers. The conservation invariant Inv verifies that the sum across all towers equals the total disk value, ensuring no disks appear or disappear.

The predicate NotSolved checks whether the final tower contains all disks. When used as an invariant during model checking, TLC produces counterexamples that demonstrate solutions to the puzzle, with optimal solutions requiring 2^D - 1 moves.
