This TLA+ module demonstrates a classic example of exponential type inference complexity in let-polymorphism, inspired by Mairson's 1990 work on ML typability.

The module defines two operators. The first, `Pair`, is a simple helper that constructs an ordered pair from two arguments, with an explicit type annotation indicating it takes two values of potentially different types and returns a tuple.

The main operator `Exp` constructs a nested sequence of function definitions over empty domains. Starting with `F0`, which maps elements of the empty set to pairs of themselves, each subsequent function `F1` through `F5` is defined by composing the previous function with itself twice. Specifically, each `Fi` applies `F(i-1)` to the result of applying `F(i-1)` to its argument.

Although these functions have empty domains and thus no actual values to compute, the nested let-polymorphic structure creates exponentially growing type expressions during type inference. Each level doubles the complexity of the type from the previous level, causing type checkers that perform full polymorphic inference to require exponential time and memory.

The module contains no variables, state transitions, temporal formulas, or properties to check. It serves purely as a stress test for type inference systems, particularly the Apalache model checker's type inference algorithm.
