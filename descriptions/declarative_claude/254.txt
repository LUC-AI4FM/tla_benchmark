This TLA+ module is a functional test suite for operators defined in the TLA+ Community Modules' Functions library, designed for verification with the Apalache model checker.

The module specifies a trivial state machine where both the initial state and next-state relation are simply TRUE, meaning the system has a single state that stutters indefinitely. This minimal structure exists solely to enable model checking of test predicates as state invariants.

The tests verify correctness of various function-related operators from the community modules. These include Restrict (domain restriction), Range (computing a function's range), IsInjective (testing one-to-one functions), FoldFunction and FoldFunctionOnSet (folding operations over functions), AntiFunction (computing inverse functions), and operators for classifying functions as Injection, Surjection, or Bijection, along with existence predicates for each.

Each test defines expected inputs and outputs, asserting equality or membership conditions. For example, tests verify that IsInjective correctly identifies functions where distinct inputs map to distinct outputs, and that FoldFunction properly aggregates function values using a binary operator. Several tests verify equivalence between optimized community module implementations and pure TLA+ definitions.

The AllTests predicate conjoins all individual tests into a single invariant. When model-checked, this invariant passes if and only if every community module operator behaves as expected on the test cases.
