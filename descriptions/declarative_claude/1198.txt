This TLA+ module tests recursive function definitions and mutual recursion in the language. It does not model a distributed system or algorithm but rather serves as a verification of TLA+'s recursion mechanisms.

The module defines two mutually recursive operators, f and g. The operator f computes the factorial: it returns 1 when the argument is 0, otherwise multiplies the argument by g of the predecessor. The operator g simply calls f with the same argument, creating mutual recursion that together compute the factorial function.

Additionally, the module defines two recursive functions using TLA+'s function syntax: fact and fact1. These are mutually referencing functions over the natural numbers that also compute factorials, where fact1 delegates to fact and fact computes the standard factorial recurrence.

The module contains three ASSUME blocks that serve as compile-time or model-checking-time assertions. The first verifies that f correctly computes factorials for values 0 through 5. The second performs identical checks for g. The third confirms that the function-based definitions fact and fact1 produce correct factorial values and agree with g for inputs 0 through 5. Each assumption block prints a confirmation message upon successful verification.

There are no VARIABLES, no next-state relation, no temporal properties, and no invariants. The module purely tests that recursive definitions evaluate correctly.
