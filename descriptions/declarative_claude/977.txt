This TLA+ module provides multiple equivalent definitions for computing the transitive closure of a relation. A relation is modeled as a set of ordered pairs, where the transitive closure TC(R) is the smallest relation containing R that is closed under transitivity.

The module defines a Support operator that extracts all elements appearing in any pair of the relation. Five different transitive closure operators are then specified:

TC uses an unbounded path-based definition stating that two elements are related if there exists a connecting path through the graph, but cannot be evaluated by TLC due to infinite sequences.

TC1 bounds the path length to the support's cardinality plus one, making it evaluable for finite relations.

TC2 uses relation composition, iteratively computing R, R composed with R, and so forth, until reaching the support's cardinality.

TC3 employs a recursive fixed-point approach, repeatedly composing the relation with itself until no new pairs are added, achieving logarithmic recursion depth.

TC4 implements Warshall's algorithm, iteratively adding pairs that can be connected through intermediate nodes.

TC5 provides an alternative formulation for relations represented as Boolean-valued operators rather than sets.

The module includes two ASSUME statements that verify equivalence of all definitions by checking them against all possible relations on small sets of integers from zero to three elements. No temporal properties, variables, or model-checking configuration are present; this is purely a library module demonstrating mathematical definitions.
