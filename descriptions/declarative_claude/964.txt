This TLA+ module specifies the Alternating Bit Protocol, a fundamental reliable data transmission protocol that operates over lossy channels.

The protocol involves a sender and receiver communicating through two FIFO queues: msgQ for data messages and ackQ for acknowledgments. The CONSTANT Data represents the set of possible data values. The VARIABLES track the message and acknowledgment queues, the sender's current bit (sBit) and last received acknowledgment bit (sAck), the receiver's current bit (rBit), and the most recently sent and received data values.

The protocol operates through several actions: SndNewValue transmits new data with a flipped bit when the previous transmission is acknowledged; ReSndMsg retransmits the current message when awaiting acknowledgment; RcvMsg delivers a message to the receiver, updating its bit and received data; SndAck sends an acknowledgment with the receiver's current bit; and RcvAck processes incoming acknowledgments. Critically, LoseMsg and LoseAck model unreliable channels by allowing arbitrary message loss from either queue.

The specification includes fairness conditions: weak fairness on retransmission and acknowledgment sending, and strong fairness on message and acknowledgment reception. These ensure progress despite losses.

The module states a type invariant theorem asserting that all variables maintain their expected types throughout execution. The specification captures the essential mechanism of using alternating sequence numbers to achieve reliable delivery over unreliable channels.
