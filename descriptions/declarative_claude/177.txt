# NonFoldDefined Module Description

This TLA+ module defines a collection of recursive utility operators commonly used in specifications, implemented without relying on fold operations. The module extends Apalache, indicating it is designed for use with the Apalache model checker.

The module contains no variables, constants, temporal logic, or state transitions—it is purely a library of helper definitions.

**Sum** computes the sum of all elements in a set of numbers by recursively selecting and removing elements until the set is empty.

**BigUnion** computes the union of all sets within a set of sets, flattening nested set structures into a single set.

**SelectSeq** filters a sequence, returning a new sequence containing only elements that satisfy a given predicate Test.

**Quantify** counts how many elements in a set satisfy a given predicate P, returning an integer.

**Range** extracts the set of all values appearing in a sequence, converting the sequence to a set.

**Mode** finds the most frequently occurring element in a sequence, returning a default value if the sequence is empty. It uses Quantify internally to count occurrences.

**IsInjective** tests whether a function is injective (one-to-one), ensuring distinct domain elements map to distinct range elements.

This module serves as a reusable library providing common computational patterns for other TLA+ specifications.
