This TLA+ module instantiates a parameterized specification for the classic "100 Prisoners and a Light Switch" puzzle, configured with 5 prisoners.

**System Being Modeled:** The specification models a coordination problem where prisoners must collectively determine when all have visited a room containing switches, with only one designated "counter" prisoner allowed to make the final declaration.

**Constants:** The module defines a set of 5 prisoners with one designated as the Counter ("456_OF_PRISONER"). These constants parameterize the imported `PrisonersTyped` module.

**Variables:** Four state variables track the system: `switchAUp` and `switchBUp` represent the boolean states of two switches in the room; `timesSwitched` maps each non-counter prisoner to the number of times they've flipped switch A up (bounded at 2); `count` tracks how many times the Counter has flipped switch A down.

**Specification:** The actual state transitions and temporal logic are defined in the `PrisonersTyped` module, which this module instantiates with the concrete prisoner set.

**Properties:** The invariant `Inv` is defined as the negation of `Done`, meaning model checking will terminate when a "done" state is reached—this technique finds a counterexample trace representing a valid solution to the puzzle.

**View Operator:** A state symmetry reduction operator aggregates `timesSwitched` values into a set, reducing the state space during model checking.
