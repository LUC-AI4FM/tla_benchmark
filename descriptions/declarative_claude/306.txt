The module specifies a tutorial model of binary search, closely following the Java `Arrays.binarySearch` implementation, and evolves across eight versioned iterations to introduce bounded (fixed-width) machine integers and verify correctness, termination, and progress.

**Constants and variables.** Three constants parameterize the model: `INPUT_SEQ` (the sequence being searched), `INPUT_KEY` (the search target), and `INT_WIDTH` (the bit-width of machine integers). Derived bounds `MAX_UINT`, `MAX_INT`, and `MIN_INT` define the integer range. Five variables track the algorithm state: `low` and `high` (the inclusive search interval endpoints), `isTerminated` (whether the algorithm has halted), `returnValue` (the result index or encoded "not found" value), and `nSteps` (a step counter).

**Behavior.** `Init` sets `low = 0`, `high = Len(INPUT_SEQ) - 1`, `isTerminated = FALSE`, and `nSteps = 0`. Each `Next` step, when not yet terminated and `low ≤ high`, computes `mid` via bounded integer addition `IAdd`, compares `INPUT_SEQ[mid+1]` with `INPUT_KEY`, and updates `low`, `high`, or sets `returnValue = mid` and terminates. When `low > high`, it terminates with `returnValue = -(low+1)` (the Java convention for "not found"). Once terminated, all variables are left unchanged. `IAdd` wraps results outside `[MIN_INT, MAX_INT]` using modular arithmetic over `MAX_UINT`.

**Properties checked.** `Postcondition` asserts that on termination the return value correctly locates the key or is negative when absent. `PostconditionSorted` weakens this to require correctness only when the input is sorted. `Termination` asserts the algorithm halts within `INT_WIDTH` steps. `Progress` is an action property asserting that each non-terminating step strictly shrinks the search interval.
