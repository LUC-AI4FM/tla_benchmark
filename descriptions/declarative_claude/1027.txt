This TLA+ module provides Apalache-specific type annotations for a Chang-Roberts leader election algorithm specification. The module acts as a wrapper around an underlying `ChangRoberts` module, adding type information required by the Apalache model checker while keeping the original specification free of tool-specific syntax.

The specification models the Chang-Roberts ring-based leader election algorithm for N processes. Each process has a unique identifier, and the goal is to elect the process with the highest identifier as the leader.

**Constants:** `N` specifies the number of processes in the ring (set to 3), and `Id` is a sequence assigning unique identifiers to each process (configured as the permutation 3, 1, 2).

**Variables:** `msgs` maps each process position to the set of messages (identifiers) in transit to that process; `pc` tracks each process's program counter; `initiator` indicates whether each process initiated the election; `state` records each process's current state (such as whether it has been elected leader).

**Model checking configuration:** The checker verifies two invariants—`TypeOK` (type correctness of all variables) and `Correctness` (the algorithm's safety property, ensuring proper leader election). Deadlock checking is disabled, and fairness conditions from the original specification are omitted since Apalache does not verify liveness properties.
