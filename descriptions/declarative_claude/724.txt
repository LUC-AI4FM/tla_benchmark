This TLA+ module is a test suite for an SVG (Scalable Vector Graphics) library. It contains no state machine, variables, or temporal specification—only static assertions evaluated at module load time.

The module tests the SVG library's functionality through ASSUME statements that verify expected behavior. The tests cover two main areas: converting SVG element records to XML strings, and constructing SVG element objects from helper operators.

For string conversion, tests verify that the SVGElemToString operator correctly transforms TLA+ records representing SVG elements into properly formatted XML strings. This includes handling elements with attributes, empty attributes, attributes specified as functions rather than records, single and multiple children, inner text content, and combinations thereof. A special test confirms that underscores in attribute names are converted to dashes for SVG compatibility.

For element construction, tests verify that helper operators Line, Circle, Rect, Text, and Group produce correctly structured records with appropriate element names, attributes, child sequences, and inner text fields.

Additional tests cover the NodeOfRingNetwork operator for computing node positions in a ring layout, the SVGDoc operator for creating complete SVG documents with namespaces and viewBox attributes, and the SVGSerialize operator for writing SVG documents to files with frame numbering.

The module extends SVG, Sequences, Naturals, TLC, and TLCExt, using AssertEq for equality assertions. No invariants or liveness properties are checked since this is purely a unit test module with no dynamic behavior.
