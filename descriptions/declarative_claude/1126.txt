This TLA+ module contains a machine-checked proof of correctness for the Transaction Commit protocol specified in the TCommit module.

The module proves that the temporal specification TCSpec implies that the conjunction of TCTypeOK and TCConsistent holds globally (in all reachable states). This is expressed as the theorem TCorrect, which states that TCSpec implies always Inv, where Inv is defined as the conjunction of the type correctness invariant TCTypeOK and the consistency invariant TCConsistent.

The proof proceeds by standard invariant reasoning with two main steps. The first step establishes that the initial condition TCInit implies the invariant Inv. The second step shows that if the invariant holds in a state and either the TCNext action occurs or the state variable rmState remains unchanged, then the invariant continues to hold in the successor state.

The second step is further decomposed into cases corresponding to the protocol's actions: the Prepare action for any resource manager, the Decide action for any resource manager, and the stuttering case where rmState is unchanged. Each case is discharged using the relevant definitions including Prepare, Decide, canCommit, and notCommitted.

The final conclusion combines these steps using propositional temporal logic reasoning to establish the global invariance property. This module extends both the TCommit specification and the TLAPS proof system library.
