This module provides a model-checking configuration for Peterson's mutual exclusion algorithm generalized to N processes.

The configuration instantiates the main Peterson algorithm specification with concrete values: N is set to 3 processes, and Procs is defined as the set {0, 1, 2} representing the process identifiers.

The module defines two key properties to be verified:

**MutualExclusion** is a safety property asserting that no two distinct processes can simultaneously be in the critical section. It states that for any two different processes p and q, they cannot both have their program counter at the "cs" (critical section) location at the same time.

**StarvationFree** is a liveness property ensuring that every process attempting to enter the critical section will eventually succeed. Specifically, whenever any process i reaches the "enter" state, it must eventually reach the "cs" state. This guarantees progress for all participating processes.

The model checker will explore the state space of the three-process Peterson algorithm under the Spec specification (which presumably includes appropriate fairness conditions from the parent module) to verify that mutual exclusion always holds and that no process can be indefinitely prevented from entering its critical section.
