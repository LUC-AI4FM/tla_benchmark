This TLA+ module defines a library of operators for working with **variant types** (also known as tagged unions or sum types), a common pattern for representing values that can take one of several different forms.

The module provides a standard untyped implementation intended to be used with Apalache, which enforces type safety on these operators.

**Key definitions:**

- **UNIT**: A constant representing the unit type, useful for variants that carry no meaningful payload (e.g., enumeration-like cases such as colors).

- **Variant**: Constructs a variant by wrapping a value with a tag name, implemented as a single-element function mapping the tag to the value.

- **VariantFilter**: Given a set of variants and a tag name, returns the set of unwrapped values for all elements tagged with that name.

- **VariantTag**: Extracts the tag name from a variant by choosing the single element in its domain.

- **VariantGetOrElse**: Safely extracts the value from a variant if it matches the given tag; otherwise returns a provided default value.

- **VariantGetUnsafe**: Extracts the value associated with a tag without checking, which may fail if the tag does not match.

The module contains no variables, temporal formulas, or properties to check—it is purely a utility library providing reusable operators for specifications that need variant data structures.
