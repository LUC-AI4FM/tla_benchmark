This TLA+ module specifies an inductive invariant for verifying the Tendermint consensus protocol's accountability properties, extending a base Tendermint specification.

The specification models a Byzantine fault-tolerant consensus algorithm where processes exchange proposals, prevotes, and precommits across rounds to reach agreement on values. The module defines type constraints for all message types and process state variables including round numbers, protocol steps (PROPOSE, PREVOTE, PRECOMMIT, DECIDED), decisions, locked values and rounds, valid values and rounds, and message sets for each round.

The core contribution is a comprehensive inductive invariant combining multiple properties: evidence only contains actual sent messages; correct processes never send messages for future rounds or steps; processes in certain steps must have sent corresponding messages; decided processes received valid proposals and sufficient precommits; locked rounds correspond to locked values and sent precommits; correct processes never equivocate; and critically, once enough processes precommit a value, future rounds cannot gather sufficient prevotes for different values.

The module states three theorems without proof: that the typed invariant is inductive (assuming no faulty quorum of two-thirds or more Byzantine processes), that agreement holds when fewer than one-third of processes are faulty, and that with fewer than two-thirds faulty processes, either agreement holds or accountability can identify misbehavior through equivocation or amnesia evidence.
