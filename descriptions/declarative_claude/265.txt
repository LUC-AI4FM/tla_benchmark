This TLA+ module is a test case designed to demonstrate ill-typed field access on record values.

The module contains a single definition called TestAccess, which tests the behavior of accessing a non-existent field on a record. The specification constructs a singleton set containing one record with two fields: field "a" mapped to the integer 28, and field "b" mapped to the string "abc". It then uses existential quantification to bind this record to variable r and attempts to access a field "c" that does not exist in the record, comparing it to the value 10.

This module serves as a test case for type checking or static analysis tools that work with TLA+ specifications. The comment indicates this tests "ill-typed access over new records," suggesting it verifies that tooling properly detects or handles attempts to access fields that are not present in a record's definition.

The module contains no CONSTANTS, VARIABLES, temporal operators, fairness conditions, or invariants. It is not a behavioral specification of a system but rather a minimal test case for record field access semantics, specifically testing how the language or associated tools handle references to undefined record fields.
