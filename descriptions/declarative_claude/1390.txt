This specification models a system of bounded FIFO (first-in, first-out) message queues, one per endpoint.

**Constants and Variables:**
- `Endpoints`: a set of communication endpoints, each with its own queue
- `Messages`: a set of possible message values
- `MaxSize`: the maximum number of messages a queue can hold
- `channel`: a function mapping each endpoint to a sequence representing its message queue

**Initial State:**
Each endpoint starts with an empty queue.

**Actions:**
- `Write(endpoint, message)`: Appends a message to an endpoint's queue, provided the queue has not reached its maximum size.
- `Read(endpoint)`: Removes the first message from an endpoint's queue, provided the queue is non-empty.

**Next-State Relation:**
Non-deterministically selects an endpoint and either reads from it or writes an arbitrary message to it.

**Temporal Specification:**
The specification allows stuttering steps where the channel remains unchanged.

**Refinement Property:**
The specification attempts to verify that each endpoint's queue behavior refines a separate FIFO module specification. The FIFO module defines a simple unbounded queue with put and get operations. The refinement property asserts that for every endpoint, the local queue behavior satisfies the FIFO specification. A comment notes this parametric instantiation approach did not work as intended.

**Model Configuration:**
Two endpoints, two messages, and queues bounded at size two.
