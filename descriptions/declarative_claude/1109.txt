This TLA+ module specifies a distributed spanning tree construction algorithm over a network of processes.

The system models processes that coordinate to build a spanning tree rooted at a designated root node. The constants include a set of processes, a special value indicating no parent, the root process, and a neighbor relation defining which processes can communicate directly.

Three variables track the system state: each process maintains a parent pointer (initially none), a report flag indicating whether it has reported its parent selection, and a set of messages in transit.

The algorithm operates as follows: processes that are either the root or already have a parent can send messages to their neighbors. When a non-root process without a parent receives a message from another process, it adopts the sender as its parent. After selecting a parent, a process can report this selection by setting its report flag.

The specification includes weak fairness on the next-state relation, ensuring continuous progress when actions are enabled.

The module verifies several properties: a type invariant ensuring parent assignments respect the neighbor relation, a termination property guaranteeing all non-root processes eventually select valid parents, a stability property ensuring parent assignments never change once set, and an invariant that processes without parents have not sent any messages.
