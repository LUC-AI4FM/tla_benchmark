This TLA+ module specifies Booth's 1980 algorithm for finding the lexicographically least circular substring (minimal rotation) of a string. The algorithm efficiently determines the starting position that yields the smallest rotation when characters are read cyclically.

The constant CharacterSet defines the alphabet, assumed to be a subset of natural numbers for comparison purposes. The variables include: b, an input string from the corpus of zero-indexed sequences; n, the string length; f, a failure function array initialized to nil (negative one) with indices from zero to twice n; and loop control variables i, j, and k, where k ultimately holds the answer.

The algorithm iterates j from one to twice n. At each step, it computes failure function values while comparing characters at positions determined by modular arithmetic. When a character mismatch reveals a lexicographically smaller rotation, variable k is updated to track this new candidate starting position. The failure function f records pattern-matching information similar to the KMP algorithm, enabling linear-time execution.

The specification includes a type invariant constraining all variables to their expected domains. The correctness property asserts that upon termination, k identifies the lexicographically minimal rotation of b, breaking ties by choosing the smallest shift value. A termination property ensures the algorithm eventually completes.
