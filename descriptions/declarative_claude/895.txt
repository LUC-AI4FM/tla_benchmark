This module provides a mechanized proof that the internal memory specification preserves its type invariant. It extends the InternalMemory module and uses the TLA+ Proof System (TLAPS) to formally verify type correctness.

The specification models a memory system where processors interact with memory through a request-response protocol. Each processor has a control state (ready, busy, or done) and a buffer that holds either requests or response values.

The key insight is that the basic TypeInvariant alone is not inductive—it cannot be proven preserved by examining single transitions. The proof introduces a strengthening invariant called BufConsistent, which captures the relationship between each processor's control state and its buffer contents: when ready, the buffer holds a value or NoVal; when busy, it holds a memory request; when done, it holds a value or NoVal.

The combined invariant Inv conjoins TypeInvariant with BufConsistent. The proof proceeds by showing that the initial condition IInit establishes Inv, and that each possible action (Req, Do, Rsp, or stuttering) preserves Inv when starting from a state satisfying Inv. The proof carefully tracks how buffer contents change through the protocol phases.

The final theorem TypeCorrect establishes that ISpec implies the type invariant holds in all reachable states, derived from the stronger inductive invariant using propositional temporal logic reasoning.
