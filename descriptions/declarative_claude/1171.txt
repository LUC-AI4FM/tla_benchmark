This TLA+ module is a utility specification for collecting and recording model-checking statistics to a CSV file. It does not model a system or algorithm but instead serves as infrastructure for benchmarking or monitoring TLC runs.

The module uses extended functionality from TLC, IOUtils, and CSV modules to perform file operations and access TLC's internal state.

The specification defines a CSV filename constant and includes an ASSUME statement that conditionally writes column headers to the CSV file when it is empty, ensuring headers appear only once across multiple runs.

The main component is the PostCondition operator, designed to be invoked after model checking completes. It writes a row of statistics including: the specification name and run identifier from environment variables, a timestamp, TLC revision information (timestamp, tag, and date), the number of worker threads used, and key model-checking metrics—the search diameter, number of generated states, number of distinct states, queue size, and total duration.

This module contains no state variables, initial conditions, or next-state relations. It defines no safety or liveness properties. Its sole purpose is capturing TLC execution metadata and performance statistics for external analysis, typically used in conjunction with other specifications being benchmarked.
