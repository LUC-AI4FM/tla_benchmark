This TLA+ module is an internal utility module for the Apalache model checker, not intended for direct use in user specifications.

The module defines two internal operators used by Apalache for rewiring standard and community modules. The first operator, `__ApalacheSeqCapacity`, takes a sequence and returns an integer representing the static upper bound on the sequence's length. Its implementation here is a placeholder (returning zero) that Apalache binds to its internal sequence capacity operation during model checking.

The second operator, `__NotSupportedByModelChecker`, accepts a string message and is designed to halt the model checker with that message when encountered during verification. Its dummy implementation uses an empty CHOOSE expression. This operator allows the type checker to process specifications containing unsupported constructs while ensuring the model checker fails gracefully with an informative error if such constructs are actually reached during checking.

The module contains no variables, constants, state transitions, or properties to verify. It serves purely as an infrastructure component providing hooks between TLA+ specifications and Apalache's internal implementation. The explicit warning in the comments indicates this module's interface may change without notice as Apalache evolves.
