This TLA+ module defines a library of operators for working with bags (also called multisets), which are collections that allow duplicate elements.

**Core Concept**: A bag is represented as a function mapping elements to positive natural numbers, where the number indicates how many copies of that element exist in the bag.

**Fundamental Operators**: The module provides `IsABag` to test if a value is a valid bag, `BagToSet` to extract the underlying set of elements, `SetToBag` to create a bag from a set (with one copy of each element), `BagIn` to test membership, `EmptyBag` for the empty bag, and `CopiesIn` to count how many times an element appears.

**Bag Arithmetic**: Two binary operators combine bags: `(+)` performs bag union by summing element counts, while `(-)` performs bag difference by subtracting counts and removing elements that would have zero or negative copies.

**Comparison and Subsets**: The `\sqsubseteq` operator tests if one bag is contained in another (all elements present with at most as many copies). `SubBag` returns the set of all bags that are sub-bags of a given bag.

**Aggregate Operations**: `BagUnion` combines a set of bags into one, `BagOfAll` applies a function to all elements while preserving multiplicities, and `BagCardinality` counts the total number of elements including duplicates.
