This TLA+ specification demonstrates module extension with operator redefinition, modeling a simple boolean state machine with layered definitions.

The system consists of a base module and an extending module that wraps and modifies the base behavior. A single variable `x` holds a boolean value representing the system state.

The base module defines straightforward behavior: `x` starts as FALSE, and transitions either set `x` to TRUE (via action `A` with any parameter from {1,2,3}) or keep it FALSE (via action `B`). The base invariant requires `x` remain boolean.

The extending module redefines initialization to allow `x` to start as any boolean while also satisfying the base initialization—though since base initialization forces `x` to FALSE, only FALSE satisfies both. The redefined next-state relation executes the base transition but additionally requires that action `A(1)` specifically does not occur, effectively restricting which transitions are permitted.

The module includes redefined operators that wrap base operators with print statements for debugging, outputting labels before delegating to original definitions. The strengthened invariant requires both the base invariant and that `x` equals FALSE, meaning any transition setting `x` to TRUE would violate this property.

No temporal properties, fairness conditions, or liveness properties are specified. The specification explores TLA+ module composition and operator overriding patterns.
