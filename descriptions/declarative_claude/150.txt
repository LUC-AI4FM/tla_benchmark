This TLA+ module tests a specific scoping behavior related to local module instantiation, addressing issue #576 in the TLA+ tooling.

The specification consists of two parts: an inner module named `inst` and an outer module named `LocalInstanceClash576`. The inner module `inst` defines a simple operator `Foo` that takes a parameter `x`, binds it to a local name `msg` within a LET expression, and returns that value.

The outer module uses `LOCAL INSTANCE inst` to import the definitions from the inner module while keeping them local to this module (not exported to modules that instantiate this one). It then defines an operator `Bar` that also uses a LET expression binding the name `msg` to the value 3, and subsequently calls `Foo` with its parameter.

The specification tests that the two separate LET bindings of `msg`—one inside `Foo` in the instantiated module and one inside `Bar` in the outer module—do not interfere with each other. This verifies that local instantiation properly maintains distinct scoping, ensuring that identically named local definitions in different contexts do not cause name collisions. The module contains no variables, temporal properties, or invariants; it exists purely to verify correct name resolution behavior in the TLA+ tools.
