This TLA+ module specifies a condition-based consensus protocol where processes attempt to agree on the maximum proposed value, based on the algorithm from Mostéfaoui et al. (2003).

The system models N processes that can tolerate up to T Byzantine failures, with F actual crash failures occurring. Constants include the set of proposable Values and a Bottom sentinel. Variables track each process's program counter (pc), local view of other processes' values (V), initial proposal (v), computed maximum estimate (w), decision value (dval), crash count, and message sets for sending and receiving.

The protocol proceeds in two phases. In phase one, each process broadcasts its initial value, collects at least N-T phase-one messages, and computes the maximum value seen. In phase two, processes broadcast both their initial value and computed maximum, then attempt to decide. A process decides on a value if it receives at least N-T phase-two messages agreeing on that maximum value. If a process receives messages from all processes without reaching quorum agreement, it deterministically chooses a value from its view. Processes may crash at any point, limited to F total crashes.

The specification includes weak fairness on all non-crash actions. Safety properties checked are type correctness, validity (decisions must be proposed values), and agreement (no two processes decide differently). Liveness properties include termination and conditional termination when Condition1 holds—specifically, when more than F processes propose the maximum value.
