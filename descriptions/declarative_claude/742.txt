This TLA+ module specifies a combinatorial puzzle from the Car Talk radio program: given an N-pound stone, find how to break it into P pieces such that any integral weight from 1 to N pounds can be measured using a balance scale.

The module declares two constants: N (the total weight of the stone) and P (the number of pieces). A "break" is modeled as a function from piece numbers (1 through P) to weights (1 through N), where pieces are ordered by non-decreasing weight to eliminate equivalent permutations, and the weights must sum to N.

The key operator IsRepresentation determines whether a target weight w can be balanced using two disjoint subsets of pieces: one set placed with the item being weighed, the other on the opposite scale pan. A break is a solution if every weight from 1 to N has such a representation.

The specification defines AllSolutions as the set of all breaks satisfying this condition. This is a purely declarative, non-temporal specification with no state transitions, actions, or fairness conditions—it simply characterizes the solution set.

An auxiliary operator ExpandSolutions generates human-readable output showing which pieces go on each side of the balance for every weight. When evaluated with N=40 and P=4, TLC finds the unique solution: pieces weighing 1, 3, 9, and 27 pounds (powers of 3), reflecting that any integer can be represented in balanced ternary.
