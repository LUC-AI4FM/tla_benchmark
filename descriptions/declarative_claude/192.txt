This TLA+ module demonstrates a polymorphic fold operation using the Apalache model checker's extended features.

The specification defines a polymorphic operator `PolyOper` that takes a set of any type and produces a function mapping elements to integers. The operator uses `ApaFoldSet`, an Apalache-specific construct for folding over sets. The inner `Add` function takes an existing function and an element, then returns a new function whose domain is extended to include that element, with all values mapped to zero. Starting from an empty function, the fold iteratively builds a function whose domain equals the input set, with every element mapped to zero.

The module has trivial state transitions: `Init` is simply TRUE (any state satisfies initialization), and `Next` is also TRUE (any transition is permitted). This means the specification allows all possible behaviors and focuses solely on testing the fold operation.

The invariant `Inv` verifies that applying `PolyOper` to the singleton set containing 1 produces the expected result: a function with domain {1} where the element 1 maps to 0. This serves as a test case confirming the polymorphic fold behaves correctly for a concrete input, validating Apalache's handling of polymorphic type annotations and set folding.
