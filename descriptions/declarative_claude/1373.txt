This TLA+ module serves as an auxiliary specification designed to be instantiated by another module (Github362.tla) for testing name resolution and overloading behavior in TLC.

The module declares one constant C and one variable x. It defines two operators that deliberately share names with definitions in the parent module: overloadedName (which equals x) and overloadedConst (which equals C). This naming is intentional to verify that definitions in the instantiating module do not conflict with these local definitions.

The initial state predicate Init establishes that variable x must equal the string "x" and constant C must equal 42. It includes Print statements for debugging purposes, displaying the values of overloadedName and overloadedConst during initialization. The predicate verifies that overloadedName resolves to the variable x with value "x", and overloadedConst resolves to constant C with value 42.

The next-state relation Next specifies that x remains unchanged, meaning the system has no state transitions after initialization.

The temporal specification Spec combines the initial condition with a stuttering-allowed next-state relation, permitting the system to either take a Next step or stutter indefinitely.

This module primarily tests TLC's handling of operator name overloading across module instantiation boundaries rather than modeling a real system.
