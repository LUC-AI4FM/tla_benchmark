This TLA+ module is a standard library specification that defines fundamental operators for working with finite sequences. It does not model a system or algorithm with state transitions; instead, it provides reusable mathematical definitions.

The module represents sequences as functions from the domain 1..n to some set of values, treating n-tuples and sequences identically. It locally imports the Naturals module for arithmetic operations without re-exporting those definitions.

The module defines several core sequence operators. **Seq(S)** constructs the set of all possible finite sequences whose elements come from set S. **Len(s)** returns the length of a sequence by finding the natural number n where the domain equals 1..n. The concatenation operator **\o** joins two sequences into one. **Append** adds a single element to a sequence's end. **Head** and **Tail** provide the standard operations for accessing the first element and the remaining sequence respectively. **SubSeq** extracts a contiguous subsequence between given indices. **SelectSeq** filters a sequence by keeping only elements satisfying a given predicate Test, using a recursive function definition.

This module contains no variables, actions, temporal formulas, fairness conditions, or properties to verify. It serves purely as a library of operator definitions that other specifications import and use when modeling systems involving sequential data structures.
