This TLA+ module specifies a simple counter system that increments from zero up to five.

The system has a single variable `x` representing a counter. The initial state sets `x` to zero. The next-state relation `Next` increments `x` by one, but only while `x` remains below five. Once `x` reaches five, no further `Next` steps are enabled.

The temporal specification `Spec` combines the initial condition with a standard stuttering-allowed formula: the system either takes a `Next` step or leaves `x` unchanged.

The module defines five action-level properties without asserting them as checked properties. `ActionLivePropA` states that `x` strictly increases. `ActionLivePropB` is simply the `Next` action itself. `ActionLivePropC` allows either a `Next` step or stuttering. `ActionLivePropD` uses the square-bracket notation, equivalent to `Next` or unchanged variables. `ActionLivePropE` uses the angle-bracket notation, requiring `Next` to occur with an actual change to variables.

No fairness conditions are specified, so the system may stutter indefinitely. No safety invariants or liveness properties are formally checked in this module; it primarily demonstrates various action-level formula constructions for reference or testing purposes.
