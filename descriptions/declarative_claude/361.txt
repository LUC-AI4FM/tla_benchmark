This TLA+ module specifies a system designed to test model checker performance when handling a large initial state space.

The system uses three variables: x, y, and z, all natural numbers. The initial state predicate defines x as any value from 1 to 100, y as any value from 1 to 200, and z as any value from 1 to 20. This creates a combinatorial explosion of 100 × 200 × 20 = 400,000 possible initial states.

The next-state relation specifies that all three variables remain unchanged indefinitely. This means the system has no actual transitions—once initialized to any of the 400,000 possible starting configurations, the state never changes.

The specification includes a single invariant that is trivially true (the constant TRUE), meaning it can never be violated regardless of which initial state is chosen.

The model-checking configuration directs the checker to use Init as the initial predicate, Next as the transition relation, and to verify the trivial invariant Inv.

This module serves purely as a stress test for TLA+ model checkers, evaluating their ability to enumerate and process a large number of initial states rather than modeling any meaningful algorithm or system behavior.
