This TLA+ module provides a mathematical proof that doubling any natural number always yields an even result. It is a pure proof module with no system modeling, state variables, or temporal logic.

The module defines two predicates: Even, which holds when a number is divisible by two (remainder zero), and Odd, which holds when a number has remainder one when divided by two.

The main result is stated as a universal theorem: for all natural numbers x, the sum x+x is even. The module demonstrates two different proof approaches for this same theorem.

The first proof is concise, delegating the entire verification to the Z3 SMT solver in a single step.

The second proof, labeled T1, proceeds through explicit case analysis. It first establishes that every natural number is either even or odd. For the even case, it reasons about modular arithmetic properties to show that adding an even number to itself preserves evenness. For the odd case, it similarly shows that one plus one equals two, which is even. Both cases use the SMT backend for arithmetic reasoning about remainder operations.

The module relies on the Naturals standard module for natural number definitions and TLAPS (the TLA+ Proof System) for proof verification infrastructure.
