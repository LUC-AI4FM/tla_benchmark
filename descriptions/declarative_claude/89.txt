The module specifies a simple one-place, handshake-based communication channel, adapted from the *Specifying Systems* textbook with explicit typing. It models the transfer of a single data value between a sender and a receiver using a ready/acknowledge protocol.

The single variable `chan` is a record with three fields: `val`, drawn from the constant set `Data`; `rdy`, a bit toggled by the sender; and `ack`, a bit toggled by the receiver. The `TypeInvariant` asserts that `chan` always inhabits this typed record structure. Initialization requires the type invariant to hold and that `ack` equals `rdy`, meaning the channel starts idle with no pending message.

The `Send(d)` action fires when the channel is idle (`rdy = ack`), placing value `d` into `val` and toggling `rdy` to signal that a message is waiting. The `Rcv` action fires when a message is pending (`rdy ≠ ack`), toggling `ack` to acknowledge receipt and returning the channel to idle. The next-state relation `Next` is the disjunction of some send and the receive action. The temporal specification `Spec` is `Init` conjoined with a stuttering-tolerant always-`Next` box formula. The module concludes with a theorem asserting that `Spec` guarantees `TypeInvariant` holds in every reachable state.
