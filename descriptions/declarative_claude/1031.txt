This TLA+ module defines foundational concepts for DAG-based blockchain consensus protocols, where network nodes collaboratively build a directed acyclic graph of blocks organized by rounds.

The module declares three constants: N (the set of network nodes), R (the set of rounds), and Leader (an operator mapping each round to its designated leader node). DAG vertices are modeled as pairs of a node and a round, representing blocks in the protocol.

Key definitions establish the structure of leader vertices. Each round has exactly one leader vertex, determined by the Leader operator. A special Genesis vertex (represented as an empty sequence) serves as the DAG's root and is assumed to be a leader.

The module provides utility operators for working with DAGs. OrderSet converts a set into a sequence using deterministic but arbitrary ordering. PreviousLeader finds the most recent leader vertex in a DAG before a given round. The Linearize operator recursively produces a total ordering of DAG vertices by traversing from leader to leader back to Genesis, ordering intermediate vertices arbitrarily between consecutive leaders.

The Compatible predicate checks whether two sequences share a common prefix, which is essential for verifying agreement properties in consensus protocols.

This module serves as a library of definitions for higher-level consensus specifications rather than specifying a complete system with state transitions or temporal properties.
