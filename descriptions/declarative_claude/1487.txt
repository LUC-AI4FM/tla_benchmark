The TLAPS module is a library of backend prover pragmas and proof rules for the TLA+ Proof System. It does not model a system or algorithm; instead, it provides infrastructure for mechanized proof checking of TLA+ specifications.

The module defines numerous operator constants that serve as pragmas to invoke specific backend provers. These include SMT solvers (CVC3, Yices, veriT, Z3), the Zenon automated theorem prover, the SPASS superposition prover, the LS4 propositional temporal logic prover, and the Isabelle interactive theorem prover with various tactics. Many pragmas have variants accepting timeout parameters or offering progressively longer timeouts. Composite pragmas like AllProvers, AllSMT, and AllIsa attempt multiple backends in sequence.

The module states two foundational theorems: SetExtensionality, which asserts that sets with identical membership are equal, and NoSetContainsEverything, which asserts every set excludes some element.

A substantial portion of the module declares temporal logic proof rules for future TLAPS support. These include rules from the paper "The Temporal Logic of Actions": RuleTLA1 and RuleTLA2 for temporal reasoning, RuleINV1 and RuleINV2 for invariant proofs, and rules WF1, SF1, WF2, and SF2 for weak and strong fairness reasoning about liveness properties. Additional rules cover invariant implication and step simulation. These temporal rules are placeholders whose names are reserved for future implementation.
