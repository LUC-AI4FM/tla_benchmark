This TLA+ module provides Apalache-compatible type annotations for a Dining Philosophers specification defined in a separate `DiningPhilosophers` module, which it imports via `INSTANCE`.

The specification models the classic dining philosophers problem with a configurable number of philosophers set by the constant `NP` (configured as 5 for model checking). The system tracks three variables: `forks` maps each fork identifier to a record containing which philosopher holds it and whether it is clean; `pc` maps each philosopher to a string representing their program counter or control state; and `hungry` maps each philosopher to a boolean indicating hunger status.

The actual state machine logic—initialization predicate `Init` and next-state relation `Next`—is inherited from the `DiningPhilosophers` module. The model-checking configuration notes that the original specification includes weak fairness conditions for each philosopher's actions, but these are omitted here because Apalache cannot handle that quantified fairness form. Consequently, this configuration focuses on safety checking only.

Two invariants are verified: `TypeOK` ensures all variables maintain their expected types throughout execution, and `ExclusiveAccess` ensures mutual exclusion—that no two adjacent philosophers simultaneously hold the fork between them, preventing the resource conflict the algorithm is designed to avoid.
