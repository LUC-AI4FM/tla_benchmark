The module specifies a spanning-tree algorithm for an undirected graph with a designated root node. The graph is represented by constants `Nodes`, `Edges`, `Root`, and `MaxCardinality` (an upper bound on the node count used in place of infinity). An assumption block enforces that `Root` is in `Nodes`, every edge is a two-element subset of `Nodes`, and `MaxCardinality` is a natural number at least as large as the cardinality of `Nodes`.

The two variables are `mom`, a function mapping each node to its designated parent, and `dist`, a function mapping each node to its current distance estimate from the root. Initially, `dist[Root] = 0`, all other nodes have `dist[n] = MaxCardinality`, and `mom[n] = n` for all nodes. The `Next` action non-deterministically picks a node `n` and a neighbor `m` such that `dist[m] + 1 < dist[n]`, then sets `dist[n]` to some value `d` strictly between `dist[m]` and `dist[n]` (inclusive of `dist[m]+1` but exclusive of `dist[n]`), and sets `mom[n] = m`. The temporal specification `Spec` combines `Init`, the always-`Next` safety frame, and weak fairness of `Next`, ensuring the algorithm cannot stall while a step remains enabled.

The postcondition characterizes correct termination: the root has distance 0 and is its own parent; unreachable nodes retain `dist = MaxCardinality` and `mom[n] = n` with all neighbors also at `MaxCardinality`; and all other nodes have their distance equal to `dist[mom[n]] + 1` with `mom[n]` an actual neighbor. The checked properties are `TypeOK` (an invariant), `Safety` (whenever `Next` is disabled the postcondition holds), and `Liveness` (the algorithm eventually terminates). The model instantiates a five-node, seven-edge connected graph with `Root = n1`.
