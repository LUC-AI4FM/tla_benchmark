This module provides Apalache type annotations for a specification of an Atomic Commit Protocol with a Single Broadcast (ACP_SB). It serves as a typed wrapper around the underlying ACP_SB specification, enabling type-checked model verification while keeping the original specification free of tool-specific syntax.

The system models a coordinator-based atomic commit protocol involving a set of participants. The constants define the participant set and seven string tags representing protocol states: vote values (yes, no), decision outcomes (commit, abort, undecided), and message states (waiting, notsent).

Two variables capture the system state. The participant variable maps each participant to a record containing their vote, liveness status, decision, fault status, and whether their vote has been sent. The coordinator variable is a record tracking vote requests sent to participants, received votes, broadcast messages, the coordinator's decision, and its liveness and fault status.

The configuration instantiates the protocol with three concrete participants and maps the abstract tags to string literals. The specification checks a type invariant (TypeInv) to ensure all variables maintain their expected structure. The next-state relation is named progN, and deadlock checking is disabled, suggesting the protocol may legitimately terminate or block under certain conditions.
