The module demonstrates defining recursive functions in TLA+ without using explicit recursive definition syntax, following the pattern from *Specifying Systems* (p. 67). It models a growing set of integers and tracks its cardinality.

The `Card` operator computes the cardinality of a set `S` by selecting, via a bounded `CHOOSE`, a function `f` over all subsets of `S` mapping to integers, such that `f` satisfies the recursive cardinality relation: the empty set maps to 0, and every non-empty subset `T` maps to one more than the cardinality of `T` with one element removed. The result is `f[S]`.

The state consists of two variables: `Set`, a set of integers, and `size`, an integer counter. Initially both are empty/zero. Each step nondeterministically picks an integer `x` from 1 to 10 that is not already in `Set`, adds it to `Set`, and increments `size` by one. The invariant `Inv` asserts that `Card(Set)` always equals `size`, verifying that the recursively defined cardinality function agrees with the explicitly maintained counter throughout all reachable states. The module also notes that the approach requires expanding the function set `[SUBSET S -> Int]`, which was unsupported in Apalache v0.6.0.
