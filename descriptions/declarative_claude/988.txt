This TLA+ module specifies a non-blocking atomic commitment protocol (ACP_NB) adapted for model checking with TLC. It extends a base module ACP_NB and configures it for efficient verification.

The system models a distributed atomic commitment protocol among a set of participants. Each participant can vote (yes or no) and reach a decision (commit or abort), transitioning through states including waiting, notsent, and undecided.

The CONSTANTS define the set of participants (configured as two participants p0 and p1) along with symbolic values for participant states and decisions. The VARIABLES (defined in the base module) track each participant's state and decision.

The module introduces an alternative formulation of the AC4 property (decision stability) that TLC handles more efficiently. This property states that once a participant decides to commit or abort, that decision remains unchanged in all subsequent states.

The specification SpecNB governs system behavior, with deadlock checking disabled to accommodate legitimate termination states.

Safety properties verified include AC1, AC2, AC3_1, and the reformulated AC4_alt, ensuring consistency of commit and abort decisions across participants. Liveness properties AC3_2 and AC5 guarantee that decisions are eventually reached under appropriate conditions.

The configuration leverages symmetry reduction through participant permutations to optimize state space exploration, having been verified with up to four participants.
