This module provides model-checking configuration for a graph reachability algorithm specified in a parent module called Reachable.

The specification models an algorithm that computes nodes reachable from a designated root node in a directed graph. The system operates over a finite set of nodes with a successor relation defining graph edges.

**Constants:** The configuration instantiates four nodes (n1 through n4) with n1 as the root. The successor function is constrained by `ConnectedToSomeButNotAll`, which selects a successor mapping where every node has exactly two outgoing edges. The sequence operator is bounded by `LimitedSeq`, which limits sequences over any set to length at most equal to the number of nodes, making the state space finite for model checking.

**Specification:** The module inherits its specification `Spec` from the parent Reachable module, which defines the initial state and next-state relation for the reachability computation.

**Safety Properties:** Five invariants are checked: `TypeOK` (type correctness), `Inv1` through `Inv3` (intermediate correctness conditions), and `PartialCorrectness` (ensuring the algorithm's result is correct upon termination).

**Liveness Property:** The `Termination` property verifies that the algorithm eventually terminates, ensuring it does not run forever on the bounded graph structure.
