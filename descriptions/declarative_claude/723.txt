This TLA+ module is a test suite for the `Relation` module, verifying that various relation-property predicates behave correctly when applied to standard mathematical relations over a finite set of natural numbers.

The module defines a constant set S containing the integers 0 through 3. It then uses ASSUME statements to validate expected outcomes of relation-checking operators from the Relation module.

The tests cover fundamental properties of binary relations: reflexivity (every element relates to itself), irreflexivity (no element relates to itself), symmetry (if x relates to y then y relates to x), antisymmetry (if x relates to y and y relates to x then x equals y), asymmetry (if x relates to y then y does not relate to x), and transitivity (if x relates to y and y relates to z then x relates to z).

The module tests these properties against equality, strict less-than, and less-than-or-equal relations. It also verifies composite ordering properties: strict partial orders, partial orders, strict total orders, and total orders.

Two tests construct custom relations by modifying the less-than relation to demonstrate that antisymmetry and transitivity checks correctly detect violations when the properties are broken.

This module contains no variables, actions, or temporal logic—it consists entirely of static assumptions that are checked when the specification is parsed, serving as a unit test for the Relation library module.
