This TLA+ module specifies a simple bounded message queue system, designed primarily as a stress test for the TLC model checker rather than to model a realistic distributed system.

The specification models a queue that can hold up to a fixed number of messages. The constant Size defines the maximum queue length (set to 10), and Messages defines the set of possible message values (integers 1 through 5). The single variable queue represents the current state of the queue as a sequence.

The system begins with an empty queue. Two actions govern state transitions: Send non-deterministically selects a message from the message set and appends it to the queue, provided the queue has not reached its maximum capacity. Receive removes the first message from the queue when the queue is non-empty.

The temporal specification combines the initial condition with a next-state relation allowing either Send or Receive to occur, with stuttering permitted. No fairness conditions are specified, meaning the system may stutter indefinitely without progress.

The specification includes one safety property: an invariant asserting that all elements in the queue belong to the Messages set. This is expressed both as Inv and as a temporal property Prop stating the invariant holds in all states. The comment notes this configuration produces approximately ten million reachable states.
