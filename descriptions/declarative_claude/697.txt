This TLA+ module is a utility library providing definitions for analyzing binary relations over a finite set. It does not model a system with state transitions or temporal behavior; instead, it offers reusable operators for checking mathematical properties of relations.

Relations are represented as Boolean-valued functions over pairs from a set S, where R[x,y] being true means x is related to y. The module defines predicates for fundamental relation properties: reflexivity (every element relates to itself), irreflexivity (no element relates to itself), symmetry (mutual relatedness), antisymmetry (mutual relatedness implies equality), asymmetry (no mutual relatedness), and transitivity (relatedness chains collapse).

Building on these, the module characterizes ordering relations. A strict partial order is irreflexive, antisymmetric, and transitive. A partial order is reflexive, antisymmetric, and transitive. Total orders add comparability between all element pairs.

The module provides closure operations: transitive closure computes the smallest transitive relation containing R using iterative expansion bounded by the set's cardinality, and reflexive transitive closure adds reflexivity. A connectivity predicate tests whether all pairs are reachable through the reflexive transitive closure.

Each property has two variants: one taking an explicit relation function, and an "Under" variant constructing the relation from a binary operator. No invariants, temporal properties, or model-checking configuration are included.
