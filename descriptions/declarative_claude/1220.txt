This TLA+ module tests the LET construct in TLA+ through a series of three embedded test cases evaluated as an invariant.

The specification defines a single variable x, initialized to zero, that never changes. The Next action leaves x unchanged, making this effectively a single-state system used purely to verify expression evaluation.

The module defines a helper operator FcnSubst that takes a function f and a unary operator e, returning a new function that applies e to each index in the domain of f. The implementation uses nested LET definitions including a recursive function FSub that processes the domain element by element.

The invariant Inv contains three tests executed via LET expressions. Test 1 verifies that a LET binding an empty set to A, then A to B, correctly identifies B as empty. Test 2 checks that defining a function C over an empty domain B produces an empty sequence. Test 3 validates the FcnSubst operator by applying an increment function to the sequence one-two-three and confirming the result is two-three-four.

Each test prints a success message or triggers an assertion failure. The model-checking configuration runs Init as the initial predicate, Next as the transition relation, and checks Inv as a safety invariant, effectively executing these tests during state exploration.
