This module instantiates and configures a model-checking test for the OptimizedCommitTS specification, which models an optimized variant of the Percolator distributed transaction protocol with commit timestamp optimization.

The test configuration establishes a small finite model with three keys (1, 2, 3) and three concurrent clients (c1, c2, c3). All three clients share the same primary key (key 1), making them symmetric with respect to their transaction coordination. This symmetry is exploited for state-space reduction during model checking through the declared permutation symmetry on clients.

The specification being checked is PercolatorSpec from the extended OptimizedCommitTS module, which defines the temporal behavior of the transaction protocol including how clients acquire locks, write data, and commit or abort transactions.

The model checker verifies eight invariants: TypeInvariant ensures variables remain within their declared domains; WriteConsistency, LockConsistency, CommittedConsistency, AbortedConsistency, and RollbackConsistency verify protocol-specific consistency conditions for writes, locks, committed transactions, aborted transactions, and rollback operations respectively; UniqueWrite ensures no duplicate writes occur; and SnapshotIsolation verifies that the protocol correctly implements snapshot isolation semantics, guaranteeing transactions see a consistent snapshot of the database.
