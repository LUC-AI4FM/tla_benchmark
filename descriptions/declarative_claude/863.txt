# Overview

This TLA+ specification models an improved Software-Defined Perimeter (SDP) architecture designed to address security flaws related to service hiding. The model examines Single Packet Authorization (SPA) protocol interactions between a legitimate user, SDP controller, firewall, target server, and an attacker.

## Constants

The specification defines configuration parameters for the client (login credentials, IP, key), SDP controller (IP, port), target server (IP, port), and attacker (IP). Additional constants control NAT scenarios, port ranges, and special values like `MATCH_ANY` and `UNKNOWN_AUTH_ID`.

## Variables

The model tracks state for five entities: the **legitimate user** (authentication state, TCP connections, auth sessions), the **SDP controller** (processed sessions, accounts, replay/spoof detection counters), the **firewall** (ACL rules, dropped packets), the **attacker** (captured authentication and data knowledge, attack sessions), and the **target server** (TCP connections, service info). Public channel variables model network communication.

## Key Actions

The specification models an enhanced SPA authentication where the user simultaneously initiates authentication and data-plane TCP connection. The firewall processes ACL configuration commands from the SDP controller and filters data packets. The attacker can sniff authentication messages and attempt replay or spoofing attacks. TCP connection establishment follows standard three-way handshake semantics with retransmission support.

## Security Analysis

The SDP controller maintains counters for detected replay and spoof attacks. The model captures attack sessions and compares them against legitimate sessions to verify the improved architecture's resistance to these attack vectors.
