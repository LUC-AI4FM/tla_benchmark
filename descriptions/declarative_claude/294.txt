The module specifies an **Asynchronous Spanning Tree (AST)** construction algorithm over a fixed undirected graph of five processes connected by a set of directed neighbor pairs forming a ring-like topology, with process 1 designated as the root.

The state consists of three variables: `prnt`, a mapping from each process to its chosen parent (or the sentinel value `NoPrnt` if none has been chosen yet); `rpt`, a per-process boolean flag indicating whether a process has acknowledged its parent assignment; and `msg`, a set of directed messages in flight between neighbors. Initially, no parent is assigned, no reports have been made, and no messages exist. The three actions are: `Send`, which allows a process that already has a parent (or is the root) to forward a message along a neighbor edge it has not yet messaged; `Update`, which allows a parentless non-root process that has received an incoming message to adopt the sender as its parent; and `Parent`, which allows a process with a parent to set its report flag. The `Next` relation gives priority to `Update` when applicable. The temporal specification adds weak fairness over the entire next-state relation, ensuring progress.

The module checks a `TypeOK` type invariant, the safety property `OneParent` (parent assignments are immutable once set), the auxiliary safety predicate `SntMsg` (a parentless non-root process sends no messages), and the liveness property `Termination`, which asserts that eventually every non-root process has a valid parent edge in the neighbor graph.
