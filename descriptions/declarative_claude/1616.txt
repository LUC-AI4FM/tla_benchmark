This TLA+ module specifies a simple sequential algorithm called NoLoop2 that performs arithmetic operations with nondeterministic choice.

The algorithm uses two integer variables, x and y, both initially zero, plus a program counter pc tracking execution progress through labeled steps.

The execution proceeds as follows: Step "a" assigns the constant 3 to x. Step "b" nondeterministically chooses a value j from the set {1, 2}, assigns it to y, and updates x to the sum of x and the new y value. Step "c" branches based on y's value: if y equals 1, it increments x and proceeds to step "d"; otherwise, it adds y to x and skips directly to step "e". Step "d" doubles x. Step "e" prints the final value of x and terminates.

The specification includes weak fairness on the next-state relation, ensuring the algorithm eventually progresses when steps are enabled. A terminating action allows infinite stuttering once the algorithm completes, preventing spurious deadlock detection.

The module checks one liveness property: Termination, asserting that the program counter eventually reaches "Done". According to the comments, the algorithm should print either 10 (when y=1) or 7 (when y=2), representing the two possible execution paths through the nondeterministic choice.
