This TLA+ module specifies a simple two-action system with a boolean toggle controlling which action can execute.

The system uses two variables: `x`, a natural number, and `b`, a boolean flag. Initially, `x` can be any value from 0 to 3, and `b` can be either true or false.

Two actions define the system's behavior. Action `A` is enabled when `x` is less than 5 and `b` is true; it flips `b` to false while leaving `x` unchanged. Action `B` is enabled when `b` is false; it flips `b` back to true and increments `x` by one. Together, these actions create an alternating pattern where `b` toggles between true and false, with `x` incrementing only when `b` transitions from false to true.

The temporal specification includes weak fairness on the next-state relation, ensuring that if some action remains continuously enabled, it must eventually be taken.

The module checks one liveness property called `Xshrinks`, which asserts that whenever `x` equals 2, it will eventually equal 1. This property is expected to be violated, since the system only increments `x` and never decrements it, making it impossible for `x` to decrease from 2 to 1.
