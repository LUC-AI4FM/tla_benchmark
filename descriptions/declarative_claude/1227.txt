This TLA+ module is a parser and operator handling test suite, not a specification of a system or algorithm. Its purpose is to verify that the TLA+ toolchain correctly parses and processes a comprehensive set of infix operator symbols when passed as higher-order operator arguments.

The module defines approximately 70 user-defined infix operators, each implemented identically to return a two-element set containing its operands. These cover arithmetic symbols, comparison operators, set-theoretic notations, and various special symbols available in TLA+ syntax.

The core testing mechanism uses higher-order operators like TestOpArg, which accepts a binary operator as a parameter and applies it to test values. Similar helper operators test TLC-specific operators, boolean operators, and set operators.

The module includes an ASSUME block containing 95 numbered test cases. Each test passes a specific operator symbol to the appropriate test function and verifies the result matches the expected value, printing success messages or failing with assertions.

The module also tests temporal and action operator symbols through TempTest, which accepts leads-to, maps-to, and composition operators as arguments. Two submodules are instantiated via INSTANCE declarations.

There are no variables, no state transitions, no temporal specification, and no invariants or liveness properties. The module contains no model-checking configuration. This is purely a static validation of parser behavior for operator symbol handling in higher-order contexts.
