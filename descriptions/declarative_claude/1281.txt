This TLA+ module explores bidirectional state transitions and the relationships between different fairness conditions and temporal properties.

The module defines a single variable x that takes natural number values. Two pairs of transition systems are specified, each involving opposing or alternative state changes.

The first system uses actions A and B over a three-state space. Action A increments x modulo 3, while action B can set x to any value in 0 through 2 nondeterministically. Spec1A starts at zero, allows either action, and requires weak fairness on A. Spec1B instead requires weak fairness on B. The module checks whether fairness on one action implies fairness on the other, and whether certain actions must occur infinitely often.

The second system uses actions C and D over a four-state space. Action C increments x modulo 4, while action D decrements x with wraparound from zero to three. Spec2 and Spec2C differ in which action receives the fairness condition. Similar properties examine whether fairness on one direction implies fairness or infinitely many occurrences of the other.

Additional properties include XChanges, a leads-to property asserting x eventually leaves state 1, XCyclesToZero checking that x reaches zero infinitely often, and a trivial tautology. Negated properties are defined for model-checking purposes.
