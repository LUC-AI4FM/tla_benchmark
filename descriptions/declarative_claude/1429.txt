This TLA+ module specifies a simple toggle system where a boolean variable alternates between true and false states.

The system models a single variable x that starts as TRUE and can flip to its negation in each step. The VARIABLE x represents this boolean state, with vars defined as an alias for x.

The initial condition Init sets x to TRUE. The next-state relation Next specifies that x transitions to its logical negation. The temporal specification Spec combines the initial condition with a stuttering-allowed next-state formula, meaning the system either performs a Next step or leaves x unchanged.

The module explores different ways of expressing temporal properties through local and global operator definitions. The property Prop uses a LET expression to define a local identity function x1 that simply returns its argument, then applies it to a temporal formula requiring that x either changes or the auxiliary variable x0 (aliased to x) stutters. An equivalent global operator x1 and property Prop2 express the same thing without LET.

Additional specifications Spec3 and Spec4 demonstrate applying identity functions to the full specification formula, showing that wrapping a temporal formula in an identity operator preserves its meaning.

The model checks the specification Spec against the temporal property Prop.
