This TLA+ module specifies a simple system modeling communication channels between pairs of processes.

The system consists of two processes, "A" and "B", forming a set P. The constant C represents all ordered pairs of processes (the Cartesian product P × P), yielding four possible channels: (A,A), (A,B), (B,A), and (B,B).

The single variable `var` is a function mapping each channel (source-destination pair) to a sequence. Initially, all channels are empty sequences.

The next-state relation allows any channel to be updated by replacing its contents with a single-element sequence containing a record with a "hello" message type. At each step, some source and destination are chosen non-deterministically, and that channel's value is overwritten.

The specification combines the initial condition with the next-state relation under stuttering, meaning the system may also take steps where `var` remains unchanged. No fairness conditions are imposed.

The module checks a property called Termination, defined as "eventually false." This property can never be satisfied by any behavior, so the model checker will report a counterexample for every possible execution, effectively exploring all reachable states to verify the specification is non-trivially executable.
