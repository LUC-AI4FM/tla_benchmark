This TLA+ module is a test suite for the `UndirectedGraphs` module, verifying the correctness of graph-theoretic operators through static assertions evaluated at specification parse time.

The module tests three main operators from the `UndirectedGraphs` library:

**SimplePath**: Computes all simple paths in an undirected graph. The tests verify that an empty graph yields no paths, a graph with isolated nodes yields single-node paths, and a graph with one edge produces paths including both directions of traversal between connected nodes.

**ConnectedComponents**: Partitions graph nodes into maximal connected subsets. Tests confirm that an empty graph has no components, a graph with nodes {1,2,3} and edge {1,2} produces components {{1,2}, {3}}, and a fully connected five-node graph yields a single component containing all nodes.

**AreConnectedIn and IsStronglyConnected**: Helper predicates tested alongside the component operator. Tests verify that nodes sharing an edge are connected, nodes in different components are not connected, and a graph where all nodes belong to one component is strongly connected.

The module uses `AssertEq` from `TLCExt` to compare computed results against expected values. All assertions execute during model initialization rather than state exploration, making this a compile-time verification of the underlying graph library's correctness.
