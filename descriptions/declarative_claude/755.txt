This module provides an Apalache-compatible wrapper for model-checking the DieHardest specification, specifically its interleaved composition variant (Section 4 of the original module).

The specification models the classic "Die Hard" water jug puzzle extended to multiple concurrent jug systems. Two separate jug configurations operate in parallel: one system has two jugs with capacities 5 and 3 gallons, while the other has three jugs with capacities 5, 3, and 3 gallons. The goal is to measure exactly 4 gallons in some jug.

The module declares four variables: c1 and c2 represent the capacity functions for each jug system (mapping jug names to their maximum capacities), while s1 and s2 track the current water levels in each system. The constants Capacities (a sequence of capacity functions) and Goal (the target volume) configure the puzzle instance.

Rather than using a traditional TLC configuration file, the module employs a ConstInit predicate to initialize constants, making it compatible with Apalache's constraint-based model checking. The capacity functions use explicit function constructors instead of TLC-specific operators.

The wrapper instantiates the DieHardest module and relies on its NextInterleaved action for state transitions. The safety property NotSolved (checked as an invariant) is expected to be violated, producing a counterexample trace showing how to achieve the goal in 12 steps.
