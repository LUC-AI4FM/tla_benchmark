This TLA+ module specifies a simple test for unfolding recursive definitions, specifically demonstrating the factorial function.

The module defines a single integer variable `f` that holds factorial computation results.

The specification includes a recursive definition of the factorial function `Fact(n)`, which returns 1 when n is less than or equal to 1, and otherwise returns n multiplied by the factorial of n-1. Two special constants guide the unrolling of this recursive definition during model checking: `UNROLL_TIMES_Fact` set to 8 indicates the maximum recursion depth to expand, and `UNROLL_DEFAULT_Fact` set to -1 provides a default value if recursion exceeds this depth.

The initial state sets `f` to the factorial of 4 (which equals 24). The next-state relation updates `f` to the factorial of 7 (which equals 5040). This creates a minimal two-state system that transitions from computing one factorial value to another.

The safety invariant `Inv` asserts that `f` is always greater than or equal to 1, which should hold since factorial results for non-negative integers are always positive.

This module primarily serves as a test case for tools that need to handle recursive operator definitions through unfolding techniques.
