This TLA+ module provides a functional test suite for record operations in TLA+, specifically designed to verify correct behavior of record-related operators.

The module defines a trivial state machine where both the initial state and next-state relation are simply TRUE, meaning the specification permits any behavior. This minimal structure exists solely to support running the tests as state invariants during model checking.

The module tests six aspects of record functionality. TestCtor verifies that explicit record construction produces non-empty sets. TestRecCtor confirms that record set constructors generate the expected Cartesian product of field values. TestRowAccess demonstrates polymorphic field access, showing that a generic accessor function can retrieve field values from records with different structures. TestRowUpdate tests the EXCEPT construct for updating record fields polymorphically across different record types. TestDomain verifies that records with identical field names but different value types share the same domain. TestRecExists checks existential quantification over record sets.

The type annotations present indicate this specification is designed for use with the Apalache model checker, which uses typed TLA+. The annotations describe polymorphic row types, allowing functions to operate on records with varying additional fields.

AllTests combines all individual tests into a single conjunction, intended to be checked as an invariant to verify that all record operations behave correctly.
