This TLA+ module specifies the high-level behavior that the Alternating Bit protocol is intended to achieve, serving as an abstract specification rather than the protocol implementation itself.

The system models two processes, A (sender) and B (receiver), communicating data values. The constant Data represents the set of possible data items to transmit. Messages are records containing a data field and a single bit (0 or 1).

Two variables capture the system state: AVar holds the sender's current message record, and BVar holds the receiver's current message record. Initially, both variables are equal, with the bit set to 1.

Process A represents the sender's behavior: when the bits of AVar and BVar match, the sender can choose any data value from Data and update AVar with this new data while flipping the bit. Process B represents the receiver's behavior: when the bits differ, the receiver copies AVar to BVar, thereby acknowledging receipt.

The next-state relation allows either process to act when its guard condition is satisfied. The temporal specification requires the initial condition to hold and all subsequent transitions to follow the Next relation or leave variables unchanged (stuttering steps).

No explicit safety or liveness properties are defined in this module. The specification describes the idealized, reliable data transfer abstraction against which an actual Alternating Bit protocol implementation would be verified.
