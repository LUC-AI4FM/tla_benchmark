This TLA+ module is a utility library defining mathematical concepts and operations on functions, rather than specifying a system or algorithm with state transitions.

The module provides definitions for common function-related notions. It defines operators to restrict a function's domain to a subset, either directly, by a predicate on domain elements, or by a predicate on range values. The Range operator extracts all values a function maps to. The Pointwise operator combines two functions element-wise using a binary operation.

The module defines the inverse of a function and an AntiFunction operator that computes the inverse over the function's entire domain and range. It includes IsInjective to test whether a function maps distinct domain elements to distinct range elements.

Central definitions characterize the sets of injections, surjections, and bijections between two sets. Injection collects all functions from one set to another that are injective. Surjection collects functions that cover every element of the target set. Bijection is their intersection. Corresponding existence predicates check whether these sets are non-empty.

The module also provides fold operations over functions: FoldFunctionOnSet and FoldFunction combine function values using an associative, commutative binary operator. Specialized operators SumFunctionOnSet and SumFunction compute numeric sums of function values.

No variables, temporal formulas, fairness conditions, or properties to be model-checked are present. This is purely a library of reusable function-theoretic definitions.
