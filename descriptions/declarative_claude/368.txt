This TLA+ module is a test specification that verifies the ability to define and invoke user-defined operators using prefix notation rather than the standard infix notation. It does not model a system or algorithm but instead serves as a language feature test for the TLA+ tooling.

The module systematically redefines a large collection of TLA+ infix operators—including arithmetic operators like plus, times, and division; comparison operators like less-than and greater-than; set operators like subset and superset; and various symbolic operators like double-bar, ampersand, and dollar signs. Each redefined operator returns a tuple containing a unique numeric identifier followed by its two arguments, allowing verification that the operator was correctly invoked.

For each redefined binary operator, an ASSUME statement checks that calling the operator in prefix form with arguments four and six produces the expected tuple. For example, the redefined plus operator returns the tuple containing two, four, and six when called as a prefix function.

The module also tests several postfix operators (closure operators like plus, star, and hash) and one prefix operator (unary minus), each returning a tuple with an identifier and the single argument.

Additionally, the module verifies that built-in operators like set membership and union can also be invoked using prefix notation. The specification contains no variables, temporal logic, fairness conditions, or invariants—it consists entirely of static ASSUME statements validated at parse or evaluation time.
