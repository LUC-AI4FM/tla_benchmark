This TLA+ module specifies a framework for reasoning about real-time properties of systems. It provides operators for expressing timing bounds on actions and for modeling the progression of real time.

The module declares a single variable `now` representing the current real time.

The `RTBound(A, v, D, E)` operator defines a bounded response-time property for an action A with respect to variables v, with minimum delay D and maximum delay E. It uses an auxiliary timer variable (existentially quantified) that resets to zero whenever action A occurs or becomes disabled, and otherwise advances with the passage of time. The property requires that the timer never exceeds E (the maximum time bound) and that whenever A occurs, at least D time units must have elapsed (the minimum time bound).

The `RTnow(v)` operator specifies how the `now` variable behaves. It constrains `now` to be a real number that can only increase (never decrease or stay constant when time passes), while other variables v remain unchanged during pure time steps. The weak fairness condition ensures time progresses unboundedly—for any real number r, time eventually advances beyond r, preventing time from stopping (Zeno behavior).

This module provides building blocks for specifying and verifying real-time systems with explicit timing constraints.
