This TLA+ module specifies the **Fast Paxos consensus algorithm**, an optimized variant of Paxos that allows values to be chosen in two message delays under favorable conditions, compared to three in classic Paxos.

**Constants** define the set of proposable values, acceptors, coordinators, round numbers (partitioned into fast and classic rounds), quorum functions parameterized by round number, and coordinator assignment per round. The specification assumes quorum intersection properties that are stronger for fast rounds.

**Variables** track acceptor state (current round, last voted round and value), coordinator state (current round and chosen value), leader status, sent messages, proposed values, learned values, and a "good set" representing non-failed agents.

**Actions** model the protocol phases: coordinators execute Phase1a (starting rounds) and Phase2a (sending values after collecting Phase1b responses), choosing values according to Fast Paxos rules that handle collisions in fast rounds. Acceptors respond with Phase1b and Phase2b messages. Both coordinated and uncoordinated collision recovery mechanisms are specified. Additional actions model value proposals, learning (when a quorum sends matching Phase2b messages), leader selection changes, agent failures/repairs, and message loss.

**Fairness conditions** require that good coordinators and acceptors eventually act when enabled, and learnable values are eventually learned.

**Safety properties** include type correctness, nontriviality (learned values were proposed), and consistency (at most one value learned). A **liveness property** states that under stable leadership and quorum availability, some value is eventually learned.
