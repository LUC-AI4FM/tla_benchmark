This TLA+ module specifies the Dijkstra-Scholten algorithm for detecting termination of a distributed computation initiated by a designated root node. The algorithm maintains a dynamic spanning tree containing all active nodes, where inactive leaf nodes detach themselves but may later reattach upon receiving messages.

The constants define a finite set of nodes, a distinguished initiator node, and a bound on pending messages for model checking. The variables track whether termination has been detected globally, a network structure holding per-node message and acknowledgment counters, each node's active status, its parent in the spanning tree, and count of active children.

Each node process can perform five actions: send a base message to another node while incrementing its child count, become inactive, receive a base message which reactivates the node and either establishes the sender as parent or sends an acknowledgment, receive an acknowledgment and decrement the child count, or detach from the tree when inactive with no children by either declaring termination (if the initiator) or sending an acknowledgment to its parent.

The specification combines initial conditions with the next-state relation under weak fairness for all node processes, ensuring continued progress.

The safety property TerminationDetection asserts that termination is declared only when the system is truly quiescent—all nodes inactive with no pending messages or acknowledgments. The liveness property Liveness ensures that quiescence eventually leads to termination detection.
