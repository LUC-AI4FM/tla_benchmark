This module specifies a spanning tree algorithm tested across all possible undirected graphs over a fixed set of nodes. It extends the SpanTree algorithm by making the edge set a variable rather than a constant, enabling exhaustive verification over every graph topology.

The specification uses three constants: Nodes (the set of graph vertices), Root (a distinguished starting node), and MaxCardinality (an upper bound at least as large as the node count). Three variables track state: mom records each node's parent in the spanning tree, dist holds each node's distance from Root, and Edges represents the graph's undirected edges as two-element subsets of Nodes.

Initially, every node is its own parent, the Root has distance zero while all others have distance MaxCardinality, and Edges is nondeterministically chosen as any valid set of edges. The Next action allows a node to update its distance and parent when a neighbor offers a shorter path to Root—specifically, when a neighbor's distance plus one is less than the node's current distance. The edge set remains fixed after initialization.

The specification includes weak fairness on the Next action. Safety asserts that when no further steps are enabled, a postcondition holds: the Root has distance zero, unreachable nodes retain MaxCardinality with no reachable neighbors, and reachable nodes have consistent parent-distance relationships. Liveness guarantees the postcondition is eventually achieved.
