This TLA+ module is a test suite that verifies the equality semantics of various function representations in TLA+. It checks that different syntactic forms producing equivalent functions are recognized as equal by the model checker.

The specification uses a single variable x, which remains constant at value 1 throughout execution. Three uninterpreted constants a, b, and c are declared and assigned model values. Several auxiliary function definitions demonstrate different construction styles: f is a multi-argument function over a Cartesian product, g is an equivalent function taking tuple arguments explicitly, h is a nested curried function, and m maps integers to tuples.

The initial state sets x to 1, and the next-state relation leaves x unchanged, creating a single-state behavior. The core logic resides in the invariant Inv, which performs thirteen equality tests covering diverse function representations. These tests compare functions defined via mapping expressions against tuples, records, EXCEPT modifications, set comprehensions, and function set constructions. Each test prints success or triggers an assertion failure.

The tests verify equivalences such as: integer-indexed functions equaling tuples, string-indexed functions equaling records, EXCEPT expressions producing expected modifications, empty functions equaling empty tuples, function sets equaling record sets, and multi-argument functions equaling tuple-argument functions. Test 10 confirms that a flat multi-argument function differs from its curried counterpart.

The model-checking configuration specifies Init, Next, and checks Inv as an invariant, with constants assigned as distinct model values.
