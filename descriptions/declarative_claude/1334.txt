This TLA+ module defines a utility library of helper operators for use in other specifications. It does not model a system or algorithm itself, nor does it declare any CONSTANTS or VARIABLES. Instead, it provides reusable functional operators built on top of the standard Integers, Sequences, and FiniteSets modules.

The module includes five main operators. **Reduce** performs a fold operation over a function's co-domain within a specified integer range, accumulating values using a provided binary operator and base value. **sum** is a simple addition operator, usable as an argument to Reduce. **Contains** checks whether an element exists within a sequence by searching through all positions. **RemoveAt** produces a new sequence with the element at a given index removed, shortening the sequence by one. **Range** extracts the set of all values in a function's co-domain.

The **IsSimpleCycle** operator determines whether a relation forms a simple cycle over a set of vertices, treating the relation as a graph and checking if traversing edges visits all vertices exactly once before returning to the start.

This module contains no temporal logic, no next-state relations, no invariants, and no properties to check. It serves purely as a library of auxiliary definitions to be extended by other modules.
