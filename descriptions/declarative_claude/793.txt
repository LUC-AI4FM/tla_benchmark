# Util Module Description

This TLA+ module provides a library of general-purpose utility operators for use in other specifications. It does not model a specific system or algorithm but instead defines reusable helper functions for set and sequence manipulation.

The module extends standard TLA+ modules for sequences, functions, naturals, and the TLC model checker.

**Set Operations:** The module defines `intersects` to test whether two sets share elements, `max` and `min` to select extremal elements from a set, `ReduceSet` to fold a binary operator over a set with an accumulator, and `INTERSECTION` to compute the intersection of all sets in a collection (dual to the built-in `UNION`).

**Sequence Operations:** It provides `ReduceSeq` for folding over sequences, `Index` to find the position of an element, `SeqToSet` to convert a sequence to a set, `Last` to retrieve the final element, `IsEmpty` to test for empty sequences, and `Remove` to filter out all occurrences of a given element.

**Permutations:** The `PermSeqs` operator generates all permutations of a finite set as sequences.

**Testing Support:** The `test` operator assists with unit-test-style assertions, printing diagnostic output when an expected equality fails.

This module contains no variables, temporal formulas, fairness conditions, or properties to check.
