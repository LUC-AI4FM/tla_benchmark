The module specifies the **Klotski sliding-block puzzle**, a classic combinatorial puzzle played on a 4×5 grid. The single variable `board` represents the current state of the puzzle as a set of pieces, where each piece is a set of grid positions (pairs of integers) that it occupies.

The board is initialized to the standard Klotski configuration (`Klotski`), which places ten pieces of varying sizes on a 4×5 grid, leaving two cells empty. The `Next` relation computes the set of currently unoccupied positions and, for each empty cell, considers the four cardinal neighbors that are occupied by some piece. A piece adjacent to an empty cell can slide into that empty space provided its entire translated footprint lies within the grid bounds and does not overlap any other piece. The `update` operator computes all boards reachable by such a single slide, and `Next` nondeterministically chooses one of them.

The invariant `TypeOK` asserts that `board` is always a set of pieces (subsets of grid positions). The reachability goal `KlotskiGoal` checks whether the 2×2 block occupying positions `{<<1,3>>, <<1,4>>, <<2,3>>, <<2,4>>}` is present in `board`, representing the puzzle's winning condition — sliding the large square piece to the bottom-center exit. The module is a typed variant (annotated with Apalache type comments) of the original TLA+ Examples `SlidingPuzzles` specification.
