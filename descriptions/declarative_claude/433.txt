This TLA+ module is a test harness designed to verify that various operator aliases from the standard library modules work correctly and interchangeably in TLC.

The module tests operator synonyms across three standard modules: the less-than-or-equal and greater-than-or-equal operators from Naturals, the sequence concatenation operator from Sequences, and the bag addition and subtraction operators from Bags.

The specification defines a single variable x that initializes to zero and never changes, creating a trivial one-state system. This minimal state space serves only as a vehicle to check the invariant once.

The invariant performs seven equality and comparison tests. Tests one and two verify that bag addition and subtraction work identically whether written with the symbolic operators or their ASCII aliases. Test three confirms that sequence concatenation produces the same result using either notation. Tests four through seven check that numeric comparisons using both Unicode-style and ASCII-style operators for less-than-or-equal and greater-than-or-equal evaluate correctly.

Each test prints a success message if the condition holds and triggers an assertion failure otherwise. The specification contains no liveness properties or fairness conditions. Its sole purpose is to confirm during model checking that TLC correctly interprets these alternative operator notations as equivalent, functioning as a regression test for the tool's standard module implementations.
