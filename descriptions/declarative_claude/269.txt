This TLA+ module specifies a simple request-acknowledgment protocol for processing withdrawal requests against a balance, serving as a test case for a Variants module that implements tagged union types.

The system models three state components: an integer balance initialized to 100, a set of messages that can be either requests (containing an ask amount) or acknowledgments (containing a success flag), and a log sequence recording events as either successful withdrawals or lacking-funds notifications.

Two actions define the system's behavior. SendRequest allows sending a request message for any positive amount from 1 to 10, adding a tagged Req variant to the message set. ProcessRequest handles pending requests by examining the balance: if sufficient funds exist, it deducts the amount, logs a Withdraw event, removes the request, and sends a successful acknowledgment; otherwise, it logs a Lacking event recording the shortfall, leaves the balance unchanged, and sends a failed acknowledgment.

The next-state relation permits either sending new requests for any amount in the specified range or processing any existing request message filtered from the message set.

The module contains no explicit invariants, liveness properties, or fairness conditions. It demonstrates the use of variant types for modeling heterogeneous message and event types with type annotations for the Apalache model checker.
