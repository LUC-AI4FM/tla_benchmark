This TLA+ module specifies an algorithm for enumerating all k-subsets of an n-element set in lexicographic order, based on Knuth's combinatorial generation techniques.

The algorithm generates all subsets of cardinality k from the set {0, ..., n-1}, producing them in a specific sorted order. The CONSTANTS N and K define sets of possible values for n and k respectively, both constrained to be natural numbers with k being positive.

The VARIABLES track the algorithm's state: n and k are the chosen parameters; s holds the current subset being constructed as a sequence; r accumulates all generated subsets as a sequence of sequences; i and j are loop indices; and idx is an array maintaining the current combination state as a strictly increasing sequence of indices.

The algorithm operates in a main loop with three labeled steps. At "l1", it constructs the current k-subset from idx while determining which index position needs incrementing next. It then appends the subset to r. At "l2", it checks for termination (when all combinations are exhausted) or prepares to advance to the next combination. At "l3", it updates higher indices to maintain the strictly increasing property.

The invariant Inv asserts that upon termination, the collected subsets exactly match the expected set of all k-subsets, and they appear in the predefined lexicographic order defined by the Sorted operator.
