This TLA+ module specifies an algorithm that computes integer exponentiation by repeated multiplication. The algorithm calculates m raised to the power n, where m is an integer and n is a natural number.

The specification uses two constants: MSet, a subset of integers representing possible base values, and NSet, a subset of natural numbers representing possible exponent values. Four variables track the computation state: m holds the base value, n holds the exponent, res accumulates the result (initialized to 1), and i serves as a loop counter (initialized to 1). A program counter variable pc tracks execution progress through labeled steps.

The algorithm proceeds in two main phases. First, it asserts that the inputs satisfy the expected type constraints. Then it enters a while loop that multiplies res by m exactly n times, incrementing the counter i each iteration. Upon loop termination, it asserts that the computed result equals m to the power n, verifying correctness.

The temporal specification defines standard sequential execution with an initial state, a next-state relation combining the algorithm steps, and allowance for stuttering after termination to prevent spurious deadlock detection.

The module includes a Termination property asserting that the algorithm eventually reaches the Done state, though this liveness property is not enabled in the provided configuration, which only specifies the main Spec formula for checking.
