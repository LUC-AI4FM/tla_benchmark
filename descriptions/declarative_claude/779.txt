This TLA+ module is a library of mathematical definitions for reasoning about functions, originally contributed by Tom Rodeheffer at Microsoft Research.

The module defines operators for manipulating and characterizing functions. **Restrict** limits a function to a specified subset of its domain, while **RestrictDomain** and **RestrictValues** filter a function based on predicates applied to domain elements or function values respectively. **IsRestriction** tests whether one function is the restriction of another. **Range** computes the set of all values a function produces.

**Pointwise** combines two functions element-wise using a binary operator. **Inverse** and **AntiFunction** construct inverse mappings by swapping domain and range elements.

The module provides fundamental function classification operators: **IsInjective** tests whether a function maps distinct domain elements to distinct range elements. **Injection**, **Surjection**, and **Bijection** construct the sets of all injective, surjective, and bijective functions between two sets respectively. Corresponding existence predicates (**ExistsInjection**, **ExistsSurjection**, **ExistsBijection**) test whether such functions exist.

Finally, **FoldFunction** and **FoldFunctionOnSet** aggregate function values using an associative and commutative binary operator, generalizing fold operations from functional programming to arbitrary function domains.

This is a utility module containing only operator definitions with no variables, state transitions, temporal formulas, or properties to check.
