This TLA+ module specifies a simple sequential process that appends integer values to a queue.

The system models a sender that iteratively adds elements to a sequence until a counter exceeds a threshold, then remains idle.

**Variables:**
The single variable `S` is a record containing two fields: `q`, a sequence that accumulates integer values, and `i`, a counter ranging from 0 to 3.

**Initial State:**
The system starts with an empty sequence and the counter set to 1.

**Actions:**
The `Send` action is enabled when the counter is at most 2. It atomically increments the counter and appends the current counter value to the sequence. The `Done` action is enabled when the counter exceeds 2, leaving the state unchanged and allowing the system to stutter indefinitely.

**Next-State Relation:**
The `TestNext` relation permits either sending a value or remaining done, covering all behaviors once the counter progresses past 2.

**Type Invariant:**
The `TestTypeInv` predicate constrains `q` to be a sequence over the set containing elements 1 through 2, and `i` to range from 0 to 3.

No temporal properties, fairness conditions, or liveness properties are specified. The module appears designed for trace examination or debugging purposes, as suggested by its name.
