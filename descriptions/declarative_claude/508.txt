A minimal PlusCal/TLA+ exercise module that verifies a simple arithmetic assertion. The system models a single-step sequential algorithm with one global variable `x`, initialized nondeterministically to any integer in the range 1 through 10, and a program counter `pc`.

The sole action, `Lbl_1`, fires when `pc` equals `"Lbl_1"` and asserts that `x² ≤ 100` before advancing `pc` to `"Done"` while leaving `x` unchanged. A `Terminating` stuttering action holds `pc` at `"Done"` indefinitely, preventing a false deadlock report. The temporal specification `Spec` is the conjunction of the initial condition and the always-enabled next-state relation. The module also states a `Termination` liveness property asserting that `pc` eventually reaches `"Done"`, though this property is not explicitly checked in the provided configuration. Because `x` ranges over 1 through 10, `x²` ranges over 1 through 100, so the assertion `x² ≤ 100` holds for all possible initializations. The module serves as a teaching or demonstration artifact illustrating how TLC evaluates an assertion across all nondeterministic initial values.
