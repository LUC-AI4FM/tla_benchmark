This module specifies a bounded FIFO buffer with asynchronous handshake channels for input and output communication. It models a system where messages flow from a sender through an internal queue to a receiver, using two-phase handshake protocols on both ends.

The constant Message represents the set of possible message values. Three variables capture the system state: in and out are channel records containing a value field, a ready bit, and an acknowledgment bit; q is a sequence representing the internal buffer queue.

Each channel operates via a two-phase handshake protocol. The sender toggles the ready bit when ready and acknowledgment bits match; the receiver toggles the acknowledgment bit when they differ. The input channel handles messages entering the buffer, while the output channel handles messages leaving.

Four main actions compose the next-state relation: SSend allows sending a message into the input channel, BufRcv receives from the input channel and appends to the queue, BufSend sends the queue head through the output channel when non-empty, and RRcv completes reception on the output channel.

The temporal specification requires the initial state followed by stuttering-allowed transitions. The module states a theorem that the specification maintains a type invariant ensuring channels have valid structure and the queue contains only messages. No fairness conditions are specified.
