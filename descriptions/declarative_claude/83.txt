This TLA+ module specifies a mathematical puzzle from the Car Talk radio program: given an N-pound stone, find how to break it into P pieces such that any integer weight from 1 to N pounds can be measured using a balance scale.

The specification defines two constants: N (the total stone weight) and P (the number of pieces). A recursive Sum operator computes the sum of function values over a set.

The set Break contains all valid ways to partition the stone, represented as functions from piece numbers (1 through P) to weights (1 through N). Valid breaks must sum to exactly N pounds, with pieces ordered by non-decreasing weight to eliminate equivalent permutations.

The IsRepresentation operator determines whether a target weight w can be measured using break B by placing some pieces (set S) on the corn's side and other pieces (set T) on the opposite side, requiring the weights to balance. IsSolution checks whether a break can represent every weight from 1 to N.

AllSolutions collects all breaks satisfying IsSolution. The ExpandSolutions operator provides detailed verification by showing, for each weight, which pieces go on each side of the balance.

This is a purely declarative specification with no state transitions or temporal properties. It uses TLC's expression evaluation feature to compute solutions rather than model-checking behaviors. For N=40 and P=4, the unique solution is pieces weighing 1, 3, 9, and 27 pounds.
