This TLA+ module specifies a simple 12-hour clock that cycles through hour values from 1 to 12.

The specification uses a single variable `hr` representing the current hour. The module extends `Naturals` to use natural number operations.

The initial condition `HCini` states that the hour must be a value between 1 and 12 inclusive. The next-state relation `HCnxt` defines how the clock advances: if the current hour is not 12, it increments by one; otherwise, it wraps around to 1.

The temporal specification `HC` combines the initial condition with a temporal formula requiring that every step either satisfies the `HCnxt` transition or leaves `hr` unchanged (a stuttering step). This is expressed using the standard TLA+ notation `[][HCnxt]_hr`, meaning the next-state relation holds for all transitions, allowing for stuttering.

The module includes a theorem stating that the specification `HC` implies the invariant `[]HCini` always holds—that is, the hour value remains within the valid range 1 to 12 throughout all behaviors. No fairness conditions are specified, so the clock is not required to eventually advance; it may stutter indefinitely.
