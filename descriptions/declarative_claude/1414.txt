This TLA+ module specifies a static constraint system over two variables with no meaningful state transitions.

The specification defines a set S containing two elements, "n1" and "n2". It establishes a relationship between two variables x and y through a layered predicate structure. The Direct predicate requires that x be a function from S to the singleton set containing "a", and y be a function from S to S, with the constraint that whenever x maps an element s to "a", y must map s to itself (the identity). Since x is constrained to always map to "a", this effectively requires y to be the identity function on S.

The predicates Indirect and InIndirect simply wrap Direct, with InIndirect introducing a local definition that aliases its first argument.

The variable x is a function from S to {"a"}, and y is a function from S to S (specifically the identity function, due to the implication constraint).

The initial state satisfies the InIndirect constraint. The next-state relation allows transitions only when the primed variables also satisfy InIndirect, or the variables remain unchanged (stuttering). Since the constraints fully determine both variables' values, the system remains in a single state indefinitely.

No safety or liveness properties beyond the specification itself are checked.
