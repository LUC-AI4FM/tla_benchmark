This TLA+ module is a test specification for TLC model checker behavior, specifically testing GitHub issue 652 related to equality and comparison operations between values of incompatible types.

The module contains no variables, actions, or temporal logic—it consists entirely of ASSUME statements that are evaluated statically before any state exploration. These assumptions test how TLC handles comparisons between different value types: functions, records, tuples, and sets.

The first group of assumptions tests equality comparisons between functions with different domains or incompatible range types, such as comparing a function mapping integers to booleans against a tuple, or comparing two functions with non-identical domains. These cases previously caused errors about comparing integers with non-integers.

The second group, labeled as behaving according to "Specifying Systems," tests similar comparisons that should succeed—functions and records with different domains are considered unequal without raising type errors.

Additional tests cover tuple comparisons of different lengths and Cartesian products of sets with mixed types.

The final assumption uses AssertError from TLCExt to verify that TLC correctly raises a specific error message when attempting to construct a set of records where the field type mixes booleans and integers inappropriately.

The empty CONFIG section indicates this module runs only the assumption checks without exploring any behaviors.
