This module provides a model-checking configuration for a breadth-first search or shortest-path tree construction algorithm over a graph, extending a base module called Session10set.

The system models message-passing between nodes in an undirected graph. The constants define a specific graph topology with six nodes (including a distinguished root) connected by six edges, along with a maximum node count bound.

The variables track the computed depth of each node from the root, each node's parent in the spanning tree, and message queues between adjacent nodes. Messages are sets of depth values, suggesting a set-based messaging approach rather than sequences.

The type invariant ensures depths are bounded non-negative integers, parents map nodes to nodes, message queues contain valid depth values, and queued depths are at least as large as the receiving node's current depth.

The specification checks three key properties. First, TypeOK verifies type correctness throughout execution. Second, DepthCorrect is a safety property stating that upon termination (when all message queues are empty), every node's path to the root through parent pointers has length equal to its true shortest-path distance from the root. Third, Termination is a liveness property asserting that all queues eventually become empty.

Deadlock checking is disabled, indicating the algorithm may terminate in a quiescent state.
