This TLA+ module is a test suite for operators defined in the FiniteSetsExt community module, which extends standard finite set operations.

The specification defines a trivial state machine where both Init and Next are simply TRUE, meaning the system has a single state that transitions only to itself. This minimal structure exists solely to support running tests as state invariants during model checking.

The module tests several extended finite set operators. **Quantify** counts elements in a set satisfying a predicate, verified against equivalent cardinality expressions across various sets of strings and integers. **kSubset** returns all subsets of a given set having exactly k elements; tests verify correctness for boundary cases (negative k, k exceeding set size), equivalence with a pure definition using SUBSET filtering, and specific enumerated results. **FoldSet** aggregates set elements using a binary operator and initial value, tested with summation. **ChooseUnique** selects the unique element satisfying a predicate. **SymDiff** computes symmetric difference between sets, tested across empty sets and various overlapping configurations. **SumSet** and **ProductSet** compute sum and product of integer sets respectively.

The invariant AllTests conjoins all individual test predicates. When model-checked, if AllTests holds in the single reachable state, all operator implementations behave correctly according to their expected semantics.
