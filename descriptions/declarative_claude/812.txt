This TLA+ module specifies the Boyer-Moore majority vote algorithm, which determines a candidate element that could potentially have an absolute majority in a sequence with a single linear pass.

The specification uses one constant, Value, representing the non-empty set of possible sequence elements. Four variables track the algorithm state: seq holds the input sequence (modeled as a variable to enable model checking across all sequences up to some bound), i is the current position being examined, cand is the current majority candidate, and cnt maintains a lower bound on candidate occurrences in the processed prefix.

The algorithm initializes with an arbitrary sequence and candidate, position 1, and count 0. The next-state relation processes one sequence element per step: if the count is zero, the current element becomes the new candidate with count 1; if the current element matches the candidate, the count increments; otherwise, the count decrements. The sequence itself never changes during execution.

The specification includes weak fairness on the Next action, ensuring the algorithm eventually terminates when enabled.

The main correctness property, Correct, states that upon termination (when i exceeds sequence length), any value with an absolute majority must equal cand. An inductive invariant Inv is provided for proving this property, relating the count and candidate occurrences to position within the sequence.
