A small PlusCal/TLA+ playground module that models a single-process sequential computation using two procedures with simulated return values. The system has one process (`main`, process id 1) and two procedures, `add` and `to_string`, whose results are communicated back via the shared global variable `retval`. A second global variable `output` holds the final result.

The process executes four labeled steps: it calls `add(3, 7)`, which stores `10` in `retval`; then calls `to_string(retval)`, which asserts its argument equals `10` and stores the string `"10"` in `retval`; then copies `retval` into `output`; and finally asserts that `output` equals `"10"`. Procedure calls are managed through an explicit stack variable, following PlusCal's standard translation. The specification includes weak fairness on the main process and both procedures, ensuring progress. The temporal property `Termination` (and the equivalent `Liveness` property checked by the model) requires that the process eventually reaches the `Done` state. The two embedded `Assert` calls serve as inline safety checks during model checking, verifying the intermediate and final values of the computation.
