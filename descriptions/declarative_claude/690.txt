This TLA+ module is a library of mathematical theorems about functions, not a system specification. It provides formally stated properties and relationships concerning function operations, primarily intended for use in proofs within the TLA+ Proof System (TLAPS).

The module extends the Functions, Integers, and FiniteSets standard modules and establishes theorems in several categories. First, it covers basic function operations including properties of function restriction and the range of a function. Second, it addresses injections, surjections, and bijections with introduction rules for proving a function belongs to these classes, properties that follow from membership, transitivity of composition, and behavior under inverses and restrictions.

A significant portion addresses existence predicates (ExistsInjection, ExistsSurjection, ExistsBijection), proving reflexivity, symmetry, and transitivity properties. The module includes a formalization of the Cantor-Bernstein-Schroeder theorem, which states that mutual injections between two sets imply the existence of a bijection, along with several corollaries and equivalent characterizations.

Additional theorems relate these concepts to natural number intervals, establishing when bijections exist between sets and intervals of the form 1..n, proving uniqueness of cardinality, and handling addition and removal of elements.

Finally, the module provides theorems about FoldFunctionOnSet, covering empty sets, non-empty sets, type preservation, equality conditions, and properties when the folding operator is associative and commutative.
