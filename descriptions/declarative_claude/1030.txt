This TLA+ module serves as a test suite for the `BlockDag` module, verifying that various operators work correctly on small concrete directed acyclic graph (DAG) structures used in blockchain or consensus protocols.

The module defines a minimal configuration with two nodes (N equals the set containing 1 and 2) and three rounds (R equals 1 through 3). A Leader function designates node 1 as leader for rounds 1 and 3, and node 2 as leader for round 2. These constants are passed to the imported BlockDag module.

Six vertices are defined as node-round pairs: v11 through v23, where the first digit indicates the node and the second indicates the round. A concrete DAG structure called dag1 is constructed containing these vertices plus a Genesis vertex, along with edges representing dependencies between vertices.

The module consists entirely of ASSUME statements that function as compile-time assertions, testing various BlockDag operators. These tests verify: extraction of node and round from vertices, identification of leader vertices for each round, correct permutation behavior of the OrderSet operator, finding previous leader vertices in the DAG structure, and linearization of the DAG from a given vertex. The linearization test confirms that vertices are ordered with leaders appearing in sequence followed by non-leader vertices.

This module contains no temporal behavior, variables, or state transitions—it exclusively validates static operator definitions.
