This TLA+ module defines the set of integers by extending the natural numbers. It imports the `Naturals` module and locally instantiates the `ProtoReals` module to access its integer definition.

The module provides two key components:

1. **Int**: A set representing all integers, obtained from the `ProtoReals` module's definition of integers. This extends beyond the natural numbers to include negative whole numbers.

2. **Unary negation operator (-.)**:  Defines the negation of a value `a` as `0 - a`, allowing expressions like `-.5` to represent negative five.

This is a foundational standard library module in TLA+ that enables specifications to work with negative numbers. By building upon `Naturals` (which provides basic arithmetic operations including subtraction) and referencing `ProtoReals` (which provides a formal construction of integers), this module makes the complete set of integers available for use in other specifications.

The module contains no variables, temporal logic, actions, or properties to check—it purely defines mathematical objects (the integer set and negation operator) for use by other TLA+ specifications that need integer arithmetic.
