This TLA+ module specifies a minimal consensus protocol where a single value is chosen from a set of possible values exactly once.

The system models the core abstraction of consensus: initially no value is chosen, and at most one value can ever be selected. The constant `Value` represents the set of possible values that may be chosen. The single variable `chosen` is a set that holds the selected value (if any).

The initial state sets `chosen` to the empty set. The next-state relation `Next` allows a transition only when no value has been chosen yet; it then non-deterministically selects some value from `Value` and sets `chosen` to the singleton containing that value. The temporal specification `Spec` combines initialization with stuttering-allowed next steps.

The type invariant `TypeOK` requires `chosen` to be a finite subset of `Value`. The main safety invariant `Inv` additionally ensures the cardinality of `chosen` never exceeds one—meaning at most one value is ever chosen, and once chosen, it cannot change.

The module also defines a live specification `LiveSpec` that adds weak fairness on `Next`. Under this fairness condition, the liveness property `Success` guarantees that eventually some value will be chosen. The module includes TLAPS proofs establishing that the invariant holds and that liveness follows from fairness when `Value` is non-empty.
