This TLA+ module defines a collection of directed state graphs used as test fixtures for verifying model-checker specifications, specifically for testing TLCMC and MCReachability tools.

The module provides a library of predefined graph structures, each represented as a record with three fields: a set of states (typically integer ranges), a set of initial states, and an actions sequence where each element specifies the set of successor states reachable from the corresponding state index.

Fifteen test graphs are defined, ranging from simple structures to complex ones. Graph G1 through G6 are small graphs with four to five states each, exhibiting various topological properties like multiple initial states, disconnected components, and strongly connected components. Graph G7 is a medium-sized graph with fifty states. Graphs G8 through G13 cover edge cases including self-loops, empty graphs, graphs with no initial states, and simple linear sequences. Graph GDH represents the state space of the DieHard puzzle with 101 states.

Each graph has an associated violation set (V1 through VDH) identifying states that should be flagged as violations, and a counterexample set (CX1 through CXDH) containing sequences representing expected error traces reaching those violation states.

The TestCase operator selects which graph to use based on an environment variable GRAPH, defaulting to graph seven. This allows external configuration of which test case to execute during model checking.
