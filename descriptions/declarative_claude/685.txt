This TLA+ module defines a library of utility operators for working with finite sets, extending the standard FiniteSets module with additional functionality.

The module provides several categories of set operations. **Folding operations** include `FoldSet`, which reduces a set to a single value by applying a binary operator across all elements with a given base value, along with `SumSet` and `ProductSet` for computing arithmetic totals. The `ReduceSet` operator exists as a backward-compatible alias for `FoldSet`, and `MapThenSumSet` combines element transformation with summation.

**Set manipulation operators** include `FlattenSet`, which unions a set of sets (equivalent to TLA+'s built-in UNION), `SymDiff` for computing the symmetric difference of two sets, and `Choices`, which generates all possible sets formed by selecting one element from each set in a collection.

**Counting and selection operators** include `Quantify`, which counts elements satisfying a predicate, `kSubset`, which returns all subsets of exactly size k, `Max` and `Min` for finding extremal integers in a set, and `ChooseUnique`, which selects an element matching a predicate but requires exactly one such element to exist.

This is a utility library module containing only operator definitions—no variables, state transitions, temporal formulas, or properties to check. It is designed for reuse in other specifications requiring extended finite set operations.
