This TLA+ module named "Utils" is a utility library that provides two fundamental helper operators for working with sets of integers.

The module extends the Integers module to access integer comparison operations.

**Operators Defined:**

- **Max(S)**: Returns the maximum element from a non-empty set S. It selects an element x from S such that all other elements y in S are less than or equal to x.

- **Min(S)**: Returns the minimum element from a non-empty set S. It selects an element x from S such that x is less than or equal to all other elements y in S.

Both operators use TLA+'s CHOOSE construct, which deterministically picks an element satisfying the given predicate. These operators assume the input set S is non-empty and contains comparable values; applying them to an empty set would leave the result unspecified.

This module contains no variables, state transitions, temporal formulas, or properties to check. It serves purely as a reusable library of definitions intended to be imported by other TLA+ specifications that need to compute maximum or minimum values from sets of integers.
