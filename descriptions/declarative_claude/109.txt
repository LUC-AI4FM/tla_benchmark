This TLA+ module provides a typed test version of the FiniteSetsExt community module, which extends TLA+'s standard finite set operations with additional utility operators.

The module defines several higher-order operators for working with finite sets. The core operator is **ReduceSet**, which implements a fold/reduce pattern over sets by recursively applying a commutative binary operation to all elements, accumulating a result. This enables defining **Sum** (adds all elements of a numeric set) and **Product** (multiplies all elements).

**Quantify** counts how many elements in a set satisfy a given predicate, implemented via cardinality of the filtered subset.

**kSubset** returns all subsets of a given set that have exactly k elements, useful for combinatorial operations involving binomial coefficients.

**Max** and **Min** select the maximum and minimum elements from a non-empty set of integers using CHOOSE with universal comparison.

**Choices** computes the Cartesian-style product over a set of sets, returning all possible sets formed by picking exactly one element from each input set, using choice functions.

**ChooseUnique** selects an element satisfying a predicate, but unlike standard CHOOSE, it requires exactly one element to satisfy the predicate—failing if zero or multiple elements match.

This module contains no variables, state transitions, temporal formulas, or properties to check. It serves purely as a library of reusable set operations for use in other specifications.
