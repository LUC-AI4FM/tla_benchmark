# Specification Overview

This module specifies Dijkstra's EWD840 algorithm for distributed termination detection on a ring of N nodes, where N is set to 2 in the configuration.

## System Being Modeled

The algorithm detects when all nodes in a distributed system arranged in a ring have become inactive. A token circulates around the ring from node 0 to node N-1 and back; nodes can be colored white or black, as can the token itself. Termination is detected when node 0 holds a white token while itself being white and inactive.

## Variables

- **active**: maps each node to a boolean indicating whether it is active
- **color**: maps each node to white or black
- **tpos**: current position of the token
- **tcolor**: current color of the token

## Actions

The next-state relation comprises system actions and environment actions. System actions include **InitiateProbe** (node 0 sends a white token when conditions warrant) and **PassToken** (non-zero nodes pass the token, potentially staining it black). Environment actions allow active nodes to send messages (activating other nodes, turning the sender black if the recipient has a higher index) or deactivate themselves.

## Temporal Properties and Fairness

The specification requires weak fairness on system actions, ensuring the token eventually circulates.

## Checked Properties

The configuration verifies **TypeOK** (type correctness) and **Inv** (Dijkstra's inductive invariant ensuring the algorithm's safety). The module also defines termination detection correctness and liveness properties.
