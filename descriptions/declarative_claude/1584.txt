This TLA+ module specifies a simple sequential algorithm demonstrating nondeterministic branching using PlusCal's "either" construct.

The system models a single-process algorithm with three integer variables x, y, and z, all initially zero, plus a program counter pc tracking execution state.

At label "a", the algorithm makes a nondeterministic choice among three branches: set x to 1 then proceed to label "b", set y to 1 then proceed to label "c", or set z to 100 and proceed directly to label "d". Labels "b" and "c" increment x and y respectively before reaching "d".

At label "d", another nondeterministic choice occurs based on guards: if x equals 0, increment z by 1; if x equals 2, increment z by 3. Two assertions then check invariant conditions: either x plus y equals 2, or z equals 101 with x plus y equaling 0; additionally, if z is less than 100, then z must equal x plus 1.

The temporal specification combines the initial state, the next-state relation under stuttering, and weak fairness on all actions, ensuring progress when steps are enabled.

The module checks a termination liveness property, asserting that the program counter eventually reaches "Done". The assertions embedded in action "d" serve as runtime safety checks verified during model checking.
