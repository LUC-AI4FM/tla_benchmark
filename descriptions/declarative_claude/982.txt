This TLA+ module specifies a model-checking configuration for the Yo-Yo leader election algorithm without pruning, instantiating the main specification from the `YoYoNoPruning` module.

The system models a distributed leader election protocol on an undirected graph. The module defines a concrete network topology with five nodes (numbered 1 through 5) connected by five edges forming a specific graph structure. A commented-out alternative configuration shows a larger network with eleven nodes and fourteen edges.

The specification uses four variables: `phase` tracks the current phase of each node in the algorithm, `incoming` and `outgoing` represent the directed edge relationships between nodes as the algorithm orients edges, and `mailbox` holds messages in transit between nodes.

The module checks two invariants: `TypeOK` ensures all variables maintain their expected types throughout execution, and `NeighborInv` verifies consistency of neighbor relationships in the graph structure.

Two temporal properties are verified: `NoNewSource` ensures that once a node loses its status as a potential leader (source), it cannot regain that status, and `Liveness` guarantees that the algorithm eventually terminates with a leader elected.

The specification imports integer operations and delegates the behavioral specification, including the initial state and next-state relation with any fairness conditions, to the `YoYoNoPruning` module.
