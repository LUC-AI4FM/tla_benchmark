The module ABCorrectness specifies an idealized, channel-free reference model of the Alternating Bit Protocol, intended to capture the correct high-level behavior against which a full implementation can be verified (e.g., via refinement mapping).

The state consists of a sender bit `sBit`, a sender acknowledgement `sAck`, a receiver bit `rBit`, a currently-sent data value `sent`, and a most-recently received data value `rcvd`, all over a finite set `Data` (instantiated as `{d1, d2}`). Initialization allows any consistent starting state where all three bits agree. The action `CSndNewValue` fires when the sender has been acknowledged (`sAck = sBit`), picks a new data value, and flips `sBit` to signal a new transmission. `CRcvMsg` fires when the receiver's bit differs from the sender's, updating `rBit` and copying `sent` into `rcvd` to model successful message delivery. `CRcvAck` fires when the sender's acknowledgement lags behind the receiver's bit, advancing `sAck` to match `rBit`. Weak fairness is required on both `CRcvMsg` and `CRcvAck`, ensuring that pending deliveries and acknowledgements are eventually processed. The specification `ABCSpec` combines initialization, the stuttering-closed next-state relation, and the fairness conditions. The only checked property is the type invariant `TypeInv`, which asserts all bits remain in `{0,1}` and data values stay within `Data`.
