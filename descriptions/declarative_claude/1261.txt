This TLA+ module is a utility specification for exporting TLC model-checker counterexamples to a file in TLA+ module format. It is not a system or algorithm model but rather a helper for tooling and debugging.

The module declares a single constant, `_TLAPlusCounterExampleFile`, which specifies the output file path for the generated counterexample module.

The local operator `_TLAPlusCounterExampleModule` constructs a string representing a valid TLA+ module. It derives the module name from the file path by removing the `.tla` extension, then formats a module containing the `CounterExample` operator with the counterexample trace obtained from TLC's built-in `CounterExample` construct.

The main operator `_TLAPlusCounterExample` conditionally writes this generated module to disk. If no counterexample exists (empty state set) or if console output is explicitly disabled in the counterexample record, the operator evaluates to `TRUE` without side effects. Otherwise, it serializes the module text to the specified file using UTF-8 encoding with write-create-truncate options, and prints a confirmation message indicating successful output.

The module imports several utility modules locally, including `IOUtils` for file operations, `TLC` and `TLCExt` for model-checker integration, and sequence manipulation modules for string processing.
