This TLA+ module is a test suite for the BagsExt library, which extends the standard Bags module with additional bag manipulation operators.

The module contains no state machine specification—it uses a minimal configuration with Init and Next but defines neither. Instead, the entire module consists of ASSUME statements that verify the correctness of various bag extension operators at specification load time.

The tests cover several categories of operators:

**Bag modification operators**: BagAdd adds an element to a bag, BagRemove removes one occurrence of an element, and BagRemoveAll removes all occurrences of an element.

**Fold operations**: MapThenFoldBag applies a mapping function then folds over bag elements. FoldBag folds a binary operator over all elements of a bag, with elements appearing according to their multiplicity. The module includes a pure TLA+ reference implementation (TLAFoldBag) to test the Java override of FoldBag.

**Arithmetic bag operations**: SumBag computes the sum of all elements times their multiplicities. ProductBag computes the product similarly.

**Error handling**: Tests verify that appropriate error messages appear when FoldBag receives invalid arguments, such as bags with negative multiplicities or non-bag values.

**Performance tests**: Two tests specifically verify that the Java override handles large multiplicities efficiently, which would fail with a pure TLA+ implementation.

The module imports Integers, TLC, Bags, BagsExt, Sequences, and TLCExt to support these operations.
