This TLA+ module is a test suite for verifying the correctness of function definition and application syntax in TLC, the TLA+ model checker.

The specification defines a trivial system with a single boolean variable x that starts true and never changes. The actual purpose lies entirely in the invariant Inv, which executes a comprehensive battery of 31 tests when checked.

The module defines several recursive function constructs over integers: f1 adds two to its argument; f2 sums two arguments; f3 and f6 compute weighted sums of multiple arguments including tuple-destructured parameters; f4 returns a record with fields a and b; and f5 sums three arguments.

The invariant tests multiple aspects of function handling. It verifies basic function application with single and multiple arguments, both in curried form and as tuples. It tests anonymous function constructors using the mapsto notation. Significant attention goes to the EXCEPT construct for function modification, including nested modifications, record field updates within function results, and the use of the @ symbol to reference previous values. The tests also verify that functions defined with tuple patterns can be called equivalently with flattened or nested tuple arguments.

Each test prints success or triggers an assertion failure. The specification passes if all 31 tests confirm expected values, validating that TLC correctly implements TLA+'s function definition and application semantics.
