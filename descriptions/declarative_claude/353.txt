This TLA+ module is a test suite for verifying the correct behavior of TLA+'s DOMAIN operator and function set constructs. It does not model a distributed system or algorithm but instead serves as a validation harness for the TLC model checker's handling of function-related operations.

The specification uses a single Boolean variable that remains constant throughout execution—initialized to TRUE and never modified. This trivial state machine exists solely to provide a context for evaluating the invariant, which contains all the actual tests.

The invariant consists of twenty-five individual test cases that verify various properties. Tests examine whether specific elements belong to function domains, including functions defined over integers, subsets of integers, and Cartesian products. They check membership in function sets (the set of all functions from one set to another), verify cardinality computations for both domains and function sets, and test record domain operations. Several tests confirm that functions with incorrect domains or codomains are properly excluded from function sets.

The function set S maps the domain 1..4 to natural numbers, used in multiple membership tests. Tests also verify multi-argument function domains produce correct Cartesian product domains.

Each test prints success or triggers an assertion failure, allowing the model checker to report which specific operations behave incorrectly. The specification checks these conditions as a safety invariant that must hold in every reachable state.
