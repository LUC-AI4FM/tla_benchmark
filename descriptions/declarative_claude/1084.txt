This TLA+ module is a utility library defining common mathematical notions about functions, originally contributed by Tom Rodeheffer at Microsoft Research.

The module provides operators for manipulating and classifying functions. **Restrict** limits a function to a specified subset of its domain, while **RestrictDomain** and **RestrictValues** filter a function based on predicates applied to domain elements or range values respectively. **IsRestriction** tests whether one function is a restriction of another.

**Range** computes the set of all values a function produces. **Pointwise** combines two functions element-wise using a binary operator. **Inverse** and **AntiFunction** construct inverse mappings from range elements back to domain elements.

The module defines fundamental function classifications: **IsInjective** tests whether a function maps distinct inputs to distinct outputs. **Injection**, **Surjection**, and **Bijection** construct the sets of all injective, surjective, and bijective functions between two given sets respectively. Companion operators **ExistsInjection**, **ExistsSurjection**, and **ExistsBijection** test whether such functions exist.

Finally, **FoldFunction** and **FoldFunctionOnSet** aggregate function values using an associative and commutative binary operator, similar to fold operations in functional programming. These rely on the locally imported Folds module.

This module contains no variables, state transitions, temporal formulas, or properties to check—it serves purely as a reusable library of function-related definitions.
