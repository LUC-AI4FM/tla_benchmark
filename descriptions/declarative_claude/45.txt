This TLA+ module specifies a simple counter system that demonstrates the distinction between state invariants and action invariants.

The system models a single integer variable `x` that starts at zero and increases by either one or two at each step. The constant behavior is deterministic in initialization but nondeterministic in progression, allowing the counter to grow at varying rates.

The single variable `x` is typed as an integer and represents the current counter value.

The initial state predicate `Init` sets `x` to zero. The next-state relation `Next` specifies that in each transition, `x` either increments by one or by two, introducing nondeterminism into the system's evolution.

The module defines four properties to illustrate different invariant types. `NonNegativeInv` is a state invariant asserting `x` is never negative, which holds given the initialization and strictly increasing transitions. `PositiveInv` is a false state invariant claiming `x` is always positive, which fails in the initial state where `x` equals zero. `IncreaseInv` is an action invariant comparing the current and next states, asserting the counter always increases, which holds for all transitions. `KeepInv` is a false action invariant asserting the counter remains unchanged, which no valid transition satisfies.
