This TLA+ module defines basic combinatorial functions as mathematical operators rather than modeling a dynamic system.

The module extends the Naturals module to access natural number operations.

It defines two mathematical operators. The first is `factorial`, specified as a recursive function over natural numbers. For input zero, it returns one; otherwise, it returns the product of the input and the factorial of the input minus one. This follows the standard mathematical definition of n! (n factorial).

The second operator is `choose`, which computes the binomial coefficient "n choose k"—the number of ways to select k items from n items without regard to order. It implements the standard formula n! / (k! × (n-k)!), using integer division.

This module contains no variables, no state transitions, no temporal logic, and no properties to verify. It serves purely as a library module providing reusable combinatorial functions that other TLA+ specifications can import and use in their definitions, invariants, or property specifications. The module represents static mathematical definitions rather than a behavioral specification of any system or algorithm.
