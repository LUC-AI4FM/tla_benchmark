# SPA_Attack Module Description

This TLA+ specification models the Software-Defined Perimeter (SDP) architecture with Single Packet Authorization (SPA) protocol, focusing on security attack scenarios including replay attacks, spoofing attacks, and data plane hijacking attempts.

## System Overview

The specification models four main entities: a legitimate user (SDP client), an SDP controller, a firewall, a target server, and an attacker. The legitimate user authenticates via SPA messages to the SDP controller, which then instructs the firewall to permit data plane access to the target server. The attacker attempts to compromise this system through various attack vectors.

## Constants

The module defines configuration for the client (login credentials, IP, encryption key), SDP controller (IP/port), target server (IP/port), and attacker (IP). Additional constants control port allocation, NAT behavior, and special marker values for unknown authentication sessions.

## Variables

Variables track each entity's state machine: the user's authentication state and TCP connections; the SDP controller's processed sessions and attack detection counters; the firewall's ACL rules; the attacker's captured knowledge and attack sessions; and the server's connection state. Communication channels model network interfaces between entities.

## Key Actions

The specification defines actions for: user SPA authentication and TCP connection establishment; SDP controller processing SPA messages with replay and spoof detection; firewall ACL management and packet filtering; attacker sniffing SPA/data messages and launching replay, spoof, and hijacking attacks; and server TCP handshake processing.

## Security Properties

The module checks safety properties including that attackers cannot establish connections with the target server and that successful attacks are properly detected. Attack detection counters track identified replay and spoofing attempts, validating the SDP architecture's defensive capabilities against Dolev-Yao style intruders.
