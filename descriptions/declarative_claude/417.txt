This TLA+ module is a test suite for verifying the correct behavior of function application syntax in TLC, the TLA+ model checker.

The specification defines a minimal system with a single variable x constrained to the value 1, and three uninterpreted constants a, b, and c (each assigned to model values of the same name in the configuration).

The system behavior is trivial: the initial state sets x to 1, and the next-state relation leaves x unchanged forever. This creates a single-state system whose sole purpose is to evaluate the invariant.

The invariant Inv serves as the test harness. It contains a series of conditional checks that test function application expressions. Each active test constructs a function and applies it, comparing the result against an expected value. If the result differs from expectation, the test fails via Assert; otherwise, it prints a success message. The active tests verify: applying a function defined over a finite set of integers to retrieve a mapped value, and applying a record by string key to retrieve a field value.

Many additional tests are commented out, which would have tested tuple indexing, functions over infinite domains like Nat, nested function application, EXCEPT expressions with multiple overrides, multi-argument functions, and the @ operator for referencing previous values.

The configuration runs model checking with Inv as the invariant to verify, ensuring all active function application tests pass.
