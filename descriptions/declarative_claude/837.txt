# Queens Module Description

This TLA+ module specifies the N-queens problem and an iterative backtracking algorithm to compute all valid placements of N queens on an N×N chessboard such that no two queens attack each other.

## Problem Representation

Queens placements are modeled as sequences mapping row numbers to column numbers. The constant N specifies the board size and number of queens, constrained to be a positive natural number. The predicate Attacks determines whether two queens threaten each other via shared column or diagonal, while IsSolution verifies that no pair of queens in a placement attacks each other.

## Algorithm State

Two variables track the algorithm's progress: **todo** holds partial solutions (sequences shorter than N) awaiting extension, and **sols** accumulates complete valid solutions found.

## Behavior

The initial state starts with an empty sequence in todo and no solutions. The PlaceQueen action selects a partial solution from todo, computes all valid single-queen extensions that avoid conflicts, and either adds complete solutions to sols or returns partial extensions to todo for further processing.

## Specification and Properties

The temporal specification includes weak fairness on PlaceQueen, ensuring progress. The TypeInvariant constrains variable domains. The main Invariant asserts that sols contains only valid solutions and, when todo empties, contains all solutions. The Termination property states that todo eventually becomes empty. NoSolutions is an auxiliary property for forcing TLC to display found solutions.
