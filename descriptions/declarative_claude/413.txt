This TLA+ module serves as a test suite for the standard FiniteSets module, verifying that the `IsFiniteSet` and `Cardinality` operators function correctly.

The specification uses a single variable `x` that acts as a trivial placeholder. The initial state sets `x` to zero, and the next-state relation keeps `x` unchanged indefinitely, creating a static system with no meaningful state transitions.

The actual purpose lies in the invariant `Inv`, which executes four validation tests each time the model checker evaluates a state. Test 1 checks that `IsFiniteSet` returns true for the two-element set containing "a" and "b". Test 2 verifies that `IsFiniteSet` correctly identifies the empty set as finite. Test 3 confirms that the `Cardinality` operator returns zero for the empty set. Test 4 validates that `Cardinality` returns two for the set containing "a" and "b".

Each test prints a success message when passing and triggers an assertion failure with an error message if the test fails. The model-checking configuration specifies `Init` as the initial predicate, `Next` as the transition relation, and `Inv` as the invariant to verify.

This module does not model any distributed system or algorithm; it purely validates library functionality through model-checker execution.
