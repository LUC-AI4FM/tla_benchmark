This TLA+ module, named Slicer2, specifies a simple state machine designed for testing the slicing of symbolic transitions in a model checker.

The specification defines a single variable `state`, typed as a string, which tracks the current state of the system.

The initial state predicate `Init` sets `state` to the value "Init".

The system has two possible actions. Action `A` transitions the state to "A" unconditionally. Action `B` uses existential quantification over the set {1, 2, 3}, though the bound variable is not actually used in determining the next state—it simply sets `state` to "B". This construct appears intended to test how symbolic transition analysis handles existential quantifiers.

The next-state relation `Next` allows either action `A` or action `B` to occur at each step, representing a nondeterministic choice between the two transitions.

The invariant `Inv` asserts that the state should never equal "B". Since action `B` explicitly sets the state to "B", this invariant will be violated whenever action `B` is taken, making the specification useful for testing whether a model checker correctly identifies reachable states through symbolic transition slicing.
