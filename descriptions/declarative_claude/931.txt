This TLA+ module serves as a type-annotated wrapper around the HourClock specification, designed to enable the Apalache model checker to process the original HourClock module while keeping that module free of tool-specific annotations.

The module models a simple hour clock that cycles through values representing hours. It extends the Naturals module and declares a single variable `hr` of integer type, which represents the current hour displayed on the clock.

The module uses INSTANCE to import all definitions from the underlying HourClock module, effectively inheriting its complete behavioral specification. This includes the initial state predicate, next-state relation, and any defined properties.

The model-checking configuration specifies that the temporal specification being checked is `HC`, which defines the overall system behavior including initial conditions and permitted state transitions. The configuration also checks the invariant `HCini`, which verifies that the initial state condition holds as a safety property throughout execution.

This wrapper module exists primarily to support examples from the Specifying Systems book's chapter on liveness properties, allowing sibling modules to extend HourClock functionality while maintaining compatibility with the Apalache type system through the integer type annotation on the hour variable.
