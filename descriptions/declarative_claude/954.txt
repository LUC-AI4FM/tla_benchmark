This TLA+ module defines the standard library for finite sets, providing two fundamental operators for reasoning about and measuring finite collections.

The module specifies two operators without any constants, variables, or temporal logic constructs—it is a purely definitional library module.

The **IsFiniteSet** operator determines whether a given set S is finite. It defines finiteness by the existence of a finite sequence that contains every element of S. Specifically, a set is finite if and only if there exists some sequence over S such that every element of S appears at some position in that sequence.

The **Cardinality** operator computes the number of elements in a finite set S. It uses a recursive local definition over the powerset of S: the empty set has cardinality zero, and any non-empty set has cardinality one plus the cardinality of that set with one arbitrarily chosen element removed. This recursion terminates for finite sets and yields the count of distinct elements.

The module locally imports Naturals and Sequences for internal use but does not export these dependencies, keeping its interface minimal. This module contains no state machine, actions, invariants, or properties—it serves solely as a foundational utility for other specifications that need to reason about finite sets and their sizes.
