This TLA+ module specifies a simple turn-based mutual exclusion protocol for N processes using an alternating token mechanism.

**System Overview:** The specification models N processes (numbered 0 through N-1) that cycle through four states: a non-critical section, an entry protocol, a critical section, and an exit protocol. Access to the critical section is controlled by a shared turn variable that acts as a rotating token.

**Constants and Variables:** The constant N defines the number of processes, and Procs is the set of process identifiers from 0 to N-1. The variable `turn` holds the identifier of the process currently permitted to enter the critical section. The variable `pc` tracks each process's current program counter location.

**Key Actions:** Each process loops indefinitely. In the non-critical section (ncs), it proceeds freely. At the entry point (enter), it waits until the turn variable equals its own identifier. It then enters the critical section (cs) and upon exiting (exit), passes the token to the next process by incrementing turn modulo N.

**Temporal Specification:** The specification requires the system to start in a valid initial state and take steps according to the Next relation, which allows any enabled process to act. No fairness conditions are specified, meaning processes may be indefinitely starved.

**Properties:** No explicit safety or liveness properties are declared for model checking in this module.
