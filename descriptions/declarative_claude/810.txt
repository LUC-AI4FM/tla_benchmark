This TLA+ module specifies a model-checking harness for verifying the Boyer-Moore majority vote algorithm over bounded input sequences.

The module is designed to exhaustively check the majority vote algorithm (defined in an imported Majority module) for all possible sequences containing three distinct elements up to a specified maximum length.

**Constants:** The specification uses three model values A, B, and C representing the possible element values, and a bound parameter limiting the maximum sequence length for model checking.

**Variables:** Four variables track the algorithm's state: seq holds the input sequence being processed, i represents the current position in the sequence, cand stores the current candidate for majority element, and cnt maintains a counter used by the voting algorithm.

**Key definitions:** The Value set contains the three possible elements. The BoundedSeq operator generates all finite sequences over a given set with lengths from zero up to the bound, replacing the standard infinite Seq operator to enable finite-state model checking.

**Specification:** The module instantiates the Majority module, inheriting its specification (Spec), which defines the initial states and next-state relation implementing the majority vote algorithm.

**Properties checked:** The model verifies three invariants—TypeOK for type correctness, Correct for algorithm correctness, and Inv for additional safety properties. Deadlock checking is disabled, indicating the algorithm intentionally terminates.
