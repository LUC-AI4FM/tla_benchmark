This TLA+ module defines a formal grammar specification for TLA+ model checker configuration files using the BNFGrammars framework.

The module specifies the syntactic structure of configuration files used by TLA+ tools like TLC. It defines character classes including letters, numbers, and special characters, then establishes keyword sets: singular keywords (SPECIFICATION, INIT, NEXT, VIEW, SYMMETRY) that take a single identifier, plural keywords (CONSTRAINT, INVARIANT, PROPERTY and their variants) that take zero or more identifiers, and constant-related keywords.

The grammar defines identifiers as sequences containing at least one letter, explicitly excluding reserved keywords from valid identifier names.

The main ConfigGrammar operator constructs a least fixed-point grammar with several production rules. A configuration file consists of one or more statements. Statements can be singular keyword declarations with one identifier, plural keyword declarations with multiple identifiers, or constant blocks containing replacements and assignments. Replacements use the arrow syntax to substitute one identifier for another. Assignments use equals signs to bind identifiers to values, which can be identifiers, numbers, strings, or set literals containing comma-separated values. Numbers are optional negative signs followed by digit sequences. Strings are quoted sequences of permitted characters.

This specification provides a precise formal definition of the configuration file format, suitable for reasoning about parser correctness or generating valid configuration files.
