This TLA+ module provides a formal framework for specifying BNF (Backus-Naur Form) grammars using set-theoretic operations on languages.

The module defines languages as sets of sequences of strings, then introduces operators for constructing grammars. The `OneOf` operator creates singleton sequences from each character in a string. The `tok` operator wraps a string as a single-token sequence, while `Tok` does the same for sets of strings.

The core language operations include `Nil` representing the empty sequence (epsilon in grammar terminology), concatenation (`&`) which combines all pairs of sequences from two languages, and alternation (`|`) implemented as set union. The module defines the positive closure (`^+`) as the union of one or more repetitions of a language, computed recursively over natural numbers. The Kleene star (`^*`) includes the empty sequence plus the positive closure.

The definition operator (`::=`) establishes language equality, mirroring BNF production rules. A `Grammar` is typed as a function mapping strings to sets of string sequences, representing how non-terminals expand.

The `LeastGrammar` operator selects the smallest grammar satisfying a given predicate, using subset ordering pointwise across all strings. This enables defining grammars as least fixed points of recursive specifications, which is essential for giving meaning to mutually recursive grammar rules.
