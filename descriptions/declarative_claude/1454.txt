This TLA+ module is a test specification for verifying string deserialization functionality in TLC, specifically testing that deserializing the same file multiple times produces consistent results without creating duplicate string objects.

The module uses the IOUtils extension to deserialize data from an external file. The filename is obtained dynamically via TLCGet from a Java system property. The specification defines a PartialSet containing two known lorem ipsum strings that should be part of the serialized data on disk.

The core behavior involves deserializing the same file twice into SetOnDisk1 and SetOnDisk2, then combining these with PartialSet into EntireSet.

Four ASSUME statements encode the properties being verified at initialization time. First, the combined EntireSet must have exactly five elements, which would fail if deserialization created duplicate string instances. Second and third, PartialSet must be a subset of both deserialized sets, confirming the known strings appear correctly. Fourth, both deserializations must produce identical sets, ensuring deterministic behavior.

This module contains no VARIABLES, actions, or temporal logic. It operates entirely through constant-level assumptions evaluated before any state exploration. The specification serves as a unit test for TLC's IODeserialize operator, verifying it correctly handles string interning and produces consistent results across multiple invocations on the same file.
