This TLA+ module is a test specification designed to demonstrate behavior related to record field access, specifically when attempting to modify a non-existent field using the EXCEPT construct.

The module defines a single operator called TestAccess that constructs a record r1 with two fields: field "a" containing the integer 28, and field "b" containing the string "abc". It then attempts to create a second record r2 by using the EXCEPT syntax to modify field "c" of r1, setting it to TRUE. However, field "c" does not exist in the original record r1.

The specification asserts that the domain of the resulting record r2 equals the set containing only "a" and "b", indicating that the EXCEPT operation on a non-existent field does not add that field to the record. This test appears to verify that the traditional TLA+ record semantics silently ignore updates to fields that are not present in the original record, rather than extending the record with new fields.

The module contains no variables, temporal logic, fairness conditions, or properties to model-check. It serves as a unit test for type-checking or semantic validation of record operations in TLA+ tooling.
