This TLA+ module specifies a simple PlusCal algorithm demonstrating nondeterministic choice using an "either-or" construct combined with a procedure call.

The algorithm models a system with three integer variables x, y, and z, all initially zero. A procedure named Foo takes a parameter and adds it to x before returning.

The main algorithm begins at label "a" with a three-way nondeterministic choice: the first branch sets x to 1 and y to 0; the second branch sets y to 1; the third branch calls procedure Foo with argument 1, and upon return at label "b", asserts that x equals 1. After the either block completes, the algorithm reaches label "d" and asserts that the sum of x and y equals 1.

The specification uses a program counter variable pc, a call stack for procedure handling, and the procedure parameter a. The constant defaultInitValue represents uninitialized values.

The temporal specification combines initial conditions with the next-state relation under stuttering, plus weak fairness on all actions, ensuring progress when enabled.

The module checks two safety properties via assertions: that x equals 1 after the procedure call branch, and that x plus y equals 1 at termination. The liveness property Termination specifies that the algorithm eventually reaches the "Done" state.
