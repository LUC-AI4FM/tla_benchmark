This TLA+ module specifies a simple system with two integer variables, x and y, that can evolve through several alternative transitions.

The system initializes with x set to some value between 1 and 3, and y set to 0. The specification defines several actions governing state transitions: Action A increments x by 1 while leaving y unchanged, provided both are natural numbers. Action B leaves both variables unchanged when x is a natural number (it includes a trivially true predicate over subsets). Action C sets x to TRUE and y to FALSE when x equals 42, effectively changing variable types. Action D non-deterministically decreases or maintains x within the range 0 to its current value. Actions U1, U2, and U3 are unreachable stuttering actions guarded by the impossible condition that x is negative.

The temporal specification allows any sequence of these actions, with stuttering permitted. A state constraint limits model checking to states where x is less than 20.

Two invariants are checked, both asserting that x and y remain natural numbers. Each invariant includes computationally expensive predicates involving power set enumeration over small integer ranges, apparently for testing coverage and cost statistics during model checking. The invariants also contain trivially true nested conditions.
