# ColorPredicates Module Description

This TLA+ module formalizes the mathematical concept of **color predicates** over finite state sets. It is a purely definitional specification without system dynamics—there are no variables, actions, or temporal behaviors.

## Core Concepts

The module defines a **color predicate** as a record containing a type (either "every" or "some") and a set of states. A state set **satisfies** a color predicate under two conditions: for "every"-type predicates, the state set must be a subset of the predicate's set (all states must be in the "good" set); for "some"-type predicates, the state set must have non-empty intersection with the predicate's set (at least one state must be in the "bad" set).

## Constants

- **State**: A finite set of possible states
- **StateEnumeration**: A bijective mapping from natural number indices to states, enabling bit-vector representations

## Theorems Specified

**UnionTheorem** asserts compositionality: satisfaction of a union of state sets can be computed from individual satisfactions—via conjunction for "every"-type predicates and disjunction for "some"-type predicates.

**VectorComputation** establishes that satisfaction can be computed using bit-vector operations: bitwise AND with equality check for "every"-type, and bitwise AND with non-zero check for "some"-type predicates.

Both theorems are intended for verification by TLC model checking on small finite instances rather than formal proof.
