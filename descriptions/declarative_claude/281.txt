This TLA+ module is a minimal test specification designed to verify correct type-checking behavior for the UNCHANGED operator when applied to tuple syntax.

The specification declares two integer-typed state variables: x and y. The initial state predicate sets x to 1 and y to 2.

The next-state relation consists of two conjuncts, both using the UNCHANGED operator with tuple notation. The first specifies that x remains unchanged (written as a single-element tuple), while the second specifies that both x and y remain unchanged (written as a two-element tuple). Since both variables are constrained to stay the same, this specification describes a system that remains permanently in its initial state after initialization.

The module serves as a regression test for issue #660 in a TLA+ type checker, specifically testing that the type checker correctly interprets angle-bracket syntax within UNCHANGED expressions as tuples rather than some other construct. The specification contains no temporal properties, fairness conditions, or invariants to check—its purpose is purely to exercise the type-checking infrastructure on a particular syntactic pattern involving UNCHANGED applied to tuples of varying lengths.
