This TLA+ module specifies a static model of blockchain chains with client tracking, created as a test case for verifying a bug fix in the Apalache model checker.

The specification models a system where multiple blockchain chains each maintain a set of clients with associated heights. The CONSTANTS define the set of chain identifiers, the maximum number of clients per chain, and the maximum height a client can have.

The single VARIABLE `chains` maps each chain identifier to a record containing a client ID counter and a clients mapping. The clients mapping associates client IDs (integers from 0 to MaxClientsPerChain-1) with heights, where heights range from 1 to MaxClientHeight, with 0 representing a null height for uninitialized clients.

The initial state creates all chains with empty client mappings (all clients at null height) and counters set to zero. The configuration initializes two chains ("chain-A" and "chain-B") with a maximum of 4 clients each and maximum height of 4.

The next-state relation specifies no changes occur—the system remains static with chains unchanged throughout execution.

Two properties are defined: TypeOK verifies that chains conform to the expected type structure mapping chain IDs to properly-formed chain records, and Inv is a trivially true invariant. This module primarily serves to test type-checking capabilities rather than model meaningful system behavior.
