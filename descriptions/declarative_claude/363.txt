This TLA+ module tests the functionality of lambda expressions (anonymous functions) within the TLA+ language.

The module defines an operator `Op` that takes a single-argument operator `A` as a parameter and applies it to the value 4. This demonstrates higher-order operator usage where operators can accept other operators as arguments.

The constant `bar` is defined by passing a lambda expression that squares its input to `Op`, resulting in 4 squared, which equals 16.

The module contains three ASSUME statements that serve as compile-time checks. The first verifies that applying a lambda creating a two-element set to `Op` yields the set {4, 2}. The second confirms that `bar` equals 16, validating the squaring lambda. The third involves an instantiation of a separate module `test201a`, where the parameter `A` is bound to a cubing lambda and `b` is set to 4, then checks that the instantiated definition `def` equals 64 (which would be 4 cubed).

Each assumption includes a `PrintT` call to output confirmation messages when the tests pass. The module has no variables, temporal logic, or model-checking configuration—it purely validates lambda expression semantics through static assumptions evaluated during parsing.
