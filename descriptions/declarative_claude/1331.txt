The module specifies Shmuel Safra's distributed termination detection algorithm on a ring of N nodes (EWD 998), modeling message channels explicitly as FIFO sequences rather than sets. Each node tracks whether it is `active`, its `color` (white or black), and a `counter` of sent-minus-received payload messages; `inbox` holds a sequence of messages for each node, carrying either payload messages (`"pl"`) or the single circulating token (`"tok"` with fields `q` and `color`).

Initialization places the token in node 0's inbox (colored black, q=0) and non-deterministically sets node activity and colors. The environment actions let active nodes send payload messages (incrementing their counter and appending to a receiver's inbox), receive payload messages (decrementing counter, blackening the node, reactivating it), or deactivate voluntarily. The system actions implement the token-passing protocol: `InitiateProbe` fires at node 0 when the current token round is inconsistent (token or node is black, or the sum of counters is nonzero), forwarding a fresh white token to node N−1; `PassToken(i)` lets an inactive node i pass the token toward node i−1, accumulating counter values and propagating black coloring. The temporal specification is `Init ∧ [][Next]_vars` with weak fairness on system actions. The module also defines a refinement mapping to the abstract `EWD998` module (which uses set-based channels), states the theorem `Spec => EWD998Spec`, and checks the invariant `EWD998!Inv` and `TypeOK`. A state constraint bounds in-flight messages and counter values to keep the model-checking state space finite.
