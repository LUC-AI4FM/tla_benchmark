This TLA+ module is a theorem library for the FiniteSetsExt module, providing formal mathematical statements about operations on finite sets. It contains no system model, variables, or temporal logic—only theorem declarations without proofs.

The module establishes properties for several set operations. For FoldSet, which applies a binary operator across set elements with a base value, theorems cover the empty set case, the recursive structure for non-empty sets, type preservation, and behavior when the operator is associative and commutative, including how folding distributes over disjoint unions.

For SumSet, which computes the sum of set elements, theorems establish that summing naturals yields a natural and integers yield an integer, that the empty sum is zero, recursive decomposition properties, distribution over disjoint unions, subset bounds for naturals, and characterization of when the sum equals zero.

For ProductSet, parallel theorems cover type preservation, the empty product being one, recursive structure, distribution over disjoint unions, characterization of when the product equals one or zero, and subset bounds for non-zero naturals.

For MapThenSumSet, which maps elements through an operator then sums results, theorems address type preservation, empty and non-empty cases, distribution over unions, subset bounds, zero characterization, and monotonicity properties.

Finally, theorems about Min and Max establish existence conditions for finite and bounded integer sets, and compute extrema for intervals.
