This TLA+ module is a regression test for the Apalache model checker, specifically testing the handling of UNCHANGED expressions as documented in issue 471.

The specification declares one constant N, typed as an integer, and two variables: f, a function mapping integers to integers, and i, a single integer.

The ConstInit operator sets N to 3, providing constant initialization for model checking. The Init predicate establishes the initial state where f is a function over the domain 1 to 3 that maps each element j to twice its value (producing the mapping 1→2, 2→4, 3→6), and i is set to 2.

The Next relation specifies that in every transition, the tuple containing f, i, the value of f at index i, and N all remain unchanged. This effectively creates a system with no state changes after initialization—a stuttering specification where the system stays in its initial state forever.

The module tests whether the model checker correctly handles UNCHANGED applied to a tuple containing both simple variables and a function application expression (f[i]). No explicit safety or liveness properties are defined; the specification exists purely to verify correct treatment of this syntactic construct.
