This TLA+ module is a test specification that verifies the ability to define and invoke user-defined binary and unary operators using prefix notation (function-call syntax) rather than the standard infix or postfix notation.

The module contains no constants, variables, state transitions, or temporal properties. It consists entirely of operator definitions and ASSUME statements that serve as compile-time or parse-time checks.

Each binary operator (such as +, *, /, ^, <, >, .., |, &, $, and many symbolic operators like \uplus, \sqcap, \prec, \subset, \approx, etc.) is redefined to return a tuple containing a unique numeric identifier followed by its two arguments. The corresponding ASSUME statement then verifies that calling the operator in prefix form produces the expected tuple.

Similarly, several postfix operators (^+, ^*, ^#) and the prefix negation operator (-.) are redefined to return tuples with their argument, and ASSUME statements verify correct prefix invocation.

The module also tests that synonymous operator notations (such as \leq with <= and =<, or \oplus with (+)) all resolve to the same user-defined operator when invoked in prefix form.

Finally, the module confirms that built-in operators like \in and \cup can also be called using prefix notation with their standard semantics.

This specification serves purely as a language feature test with no behavioral modeling.
