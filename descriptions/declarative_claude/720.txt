This TLA+ module is a test suite for the IOUtils library, specifically targeting Unix-like operating systems. It contains no state machine or temporal logic—instead, it consists entirely of ASSUME statements that execute at specification load time to verify the correctness of external I/O operators.

The module tests several IOUtils operators for executing shell commands and handling file operations. The IOExec operator runs external commands, verifying that arguments with spaces and quotes are passed correctly, exit values are captured, and stdout/stderr streams are returned properly. Tests include running echo commands and intentionally failing cat commands on nonexistent files.

The IOExecTemplate operator is tested for template-based command construction with parameter substitution. Environment variable handling is verified through IOEnvExec and IOEnvExecTemplate operators, which allow passing custom environment variables to spawned processes. Tests confirm that both explicitly provided environment variables and inherited ones (via IOEnv) work correctly.

More complex tests verify that TLC itself can be launched as a subprocess, running nested specifications with various configurations and classpath settings.

Finally, the module tests file serialization and deserialization using the Serialize and Deserialize operators with text format, verifying that content including escape characters round-trips correctly through a temporary file.
