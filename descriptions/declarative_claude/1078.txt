This TLA+ module provides an animation layer for visualizing Dijkstra's EWD998 distributed termination detection algorithm. It extends the EWD998ChanID specification and uses SVG rendering to create visual representations of algorithm execution.

The module visualizes a ring network of nodes where each node has three state attributes: active or inactive (shown as circles versus squares), white or black coloring indicating whether the node is tainted, and a message counter tracking sent and received messages. A token circulates around the ring carrying its own color state and an accumulated queue count.

The visual layout positions nodes in a circular ring formation with the token traveling on a larger concentric circle. Messages between nodes appear as directed lines with arrows, distinguishing between messages arriving in the current step (solid lines) and messages still in flight (dashed lines). A status indicator displays whether the system is running, has terminated, or has detected termination.

The module defines two main output mechanisms. AnimWatch generates a single SVG file that overwrites on each state change, suitable for interactive debugging with live preview. AnimAlias serves as a TLC alias that generates sequentially numbered SVG frames for creating screencasts, while also exposing the underlying state variables for inspection.

Key visual elements include a legend explaining the symbol meanings, color-coded status indicators, and step numbers for tracking progression through the state space. The animation leverages access to both current and next-state values to show message transitions accurately.
