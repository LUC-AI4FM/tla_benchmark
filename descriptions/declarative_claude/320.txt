This TLA+ module demonstrates let polymorphism in the type system, specifically showing that a single parametric operator can be instantiated with different concrete types.

The specification defines two state variables: `strToInt`, a function mapping strings to integers, and `intToStr`, a function mapping integers to strings. These variables have explicitly annotated types.

The module defines a polymorphic operator `Extend` that takes a function, a key, and a value, returning a new function with the domain extended to include the new key mapped to the given value. The operator is annotated with a parametric type signature using type variables `a` and `b`, allowing it to work with functions of any key-value type combination.

The initial state sets both functions to empty mappings—`strToInt` has an empty domain mapping to integer zero, and `intToStr` has an empty domain mapping to the empty string.

The next-state relation simultaneously extends both functions: `strToInt` gains a mapping from the string "a" to integer 1, while `intToStr` gains a mapping from integer 1 to string "a". This demonstrates that the same `Extend` operator can be correctly type-checked when applied to functions with different type signatures within the same specification.

The module contains no invariants, temporal properties, or fairness conditions—it exists purely to test type checker capabilities regarding parametric polymorphism.
