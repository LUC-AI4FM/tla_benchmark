This TLA+ module is a test suite for an Option library, verifying the correctness of various option-type operations commonly found in functional programming. The module extends an Option library that provides sum-type constructors (Some and None) for representing optional values.

The specification defines no mutable state variables. Instead, it uses the Init predicate to assert that all test predicates hold simultaneously, effectively serving as a compile-time verification of the Option library's behavior.

The tests verify several operations: OptionMap applies a function to a value inside Some or passes through None unchanged; OptionCase provides pattern matching on options with separate handlers for each variant; OptionFlatMap chains computations that may fail; OptionToSeq and OptionToSet convert options to single-element or empty collections; OptionGuess converts a set to an option containing an arbitrary element or None for empty sets; OptionFunApp applies a function to an optional argument; and OptionPartialFun extends a function's domain by returning None for undefined inputs.

A helper function MaxSet demonstrates practical usage by folding over a set to find its maximum element, returning None for empty sets.

The Next relation is trivially TRUE, and no temporal properties or fairness conditions are specified. The module is designed for static checking with Apalache rather than model checking state transitions.
