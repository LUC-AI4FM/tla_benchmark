This TLA+ module is a utility library providing JSON serialization and deserialization operations for use within TLA+ specifications. It does not model a distributed system, algorithm, or stateful behavior—it contains no VARIABLES, no temporal logic, no next-state relations, and no invariants or properties to check.

The module defines several operators for converting TLA+ values into JSON-formatted strings. The main operator, ToJson, accepts a value and converts it to a JSON string representation, treating records as JSON objects and tuples or sequences as JSON arrays. Two specialized variants exist: ToJsonArray forces array output, while ToJsonObject forces object output. The conversion logic uses recursive helper operators that iterate through the domain of a function, building the string representation with appropriate delimiters and formatting.

For file operations, the module declares JsonSerialize and ndJsonSerialize for writing values to files in standard JSON or newline-delimited JSON formats, and JsonDeserialize and ndJsonDeserialize for reading values back. These file operations are stubs—the serialize operators simply return TRUE, and the deserialize operators use a nondeterministic CHOOSE expression, indicating they are meant to be overridden by TLC's Java-based implementation.

This module serves as infrastructure for other specifications needing JSON interoperability, not as a system model itself.
