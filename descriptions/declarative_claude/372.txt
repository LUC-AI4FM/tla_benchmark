This TLA+ module is a test specification for SANY2, the TLA+ syntax analyzer, specifically examining the scoping rules of NEW declarations within hierarchical proofs.

The module tests how identifiers introduced by NEW in proof statements have their visibility restricted. The core rule being verified is that NEW declarations are normally scoped only to the statement's own proof, with the exception of SUFFICES statements, where the introduced identifiers remain visible to the rest of the current proof level.

The specification defines a simple binary operator for pairing and then presents a theorem with a structured proof containing multiple levels. The proof deliberately introduces identifiers (I, J, K, L, F) at various points using NEW, ASSUME, DEFINE, and SUFFICES constructs. It then references these identifiers in different scopes to test whether the analyzer correctly determines their visibility.

For instance, K introduced via SUFFICES at step 1.3 is expected to be visible at step 1.4, while K introduced in a regular ASSUME at step 1.2 should not persist. Similarly, the module defines identifiers like I, J, and F at the module level after the theorem to test that proof-local bindings do not conflict with module-level definitions.

The module contains no temporal operators, invariants, or liveness properties. It exists purely to validate SANY2's scope resolution behavior during parsing and semantic analysis, printing a test identification message upon loading.
