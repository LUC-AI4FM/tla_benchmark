This TLA+ module provides a formal specification of the Peano axioms for natural numbers, presented as a purely mathematical definition without any system dynamics or state transitions.

The module defines a predicate `PeanoAxioms` that characterizes when a triple of values constitutes a valid Peano structure. The predicate takes three parameters: N (the set of natural numbers), Z (the zero element), and Sc (the successor function). The axioms require that zero belongs to N, the successor function maps N to itself, every element except zero is the successor of some element, and the principle of mathematical induction holds—any subset containing zero and closed under successor must be all of N.

The module assumes the existence of some structure satisfying these axioms. It then uses the CHOOSE operator to extract canonical definitions: `Succ` selects a successor function from any valid Peano structure, `Nat` is defined as the domain of this function, and `Zero` is the unique element satisfying the axioms with respect to the chosen successor function and natural numbers.

This specification contains no variables, actions, temporal formulas, or properties to check. It serves as a foundational mathematical definition that could be imported by other specifications needing a rigorous characterization of natural numbers based on Peano's axiomatization.
