This TLA+ module defines a polymorphic fold operation over sets and verifies its behavior through an invariant check, primarily serving as a test case for the Apalache model checker's type system.

The module extends Integers and Apalache, utilizing Apalache's specialized operators and type annotations.

The core definition is `PolyOper`, a polymorphic operator that takes a set of any type and produces a function mapping elements to integers. It uses `ApaFoldSet` to iteratively build a function by starting with an empty function and progressively adding each element from the input set to the function's domain, mapping all elements to zero. The `Add` helper function extends an existing function's domain to include a new element while assigning zero to all positions.

The specification has trivial state transitions: both `Init` and `Next` are simply `TRUE`, meaning any state is initial and any transition is permitted. This indicates the module is not modeling a dynamic system but rather testing static properties.

The invariant `Inv` asserts that applying `PolyOper` to the singleton set containing 1 produces a function with domain {1} that maps 1 to 0. This serves as a correctness check for the polymorphic fold operation's behavior with Apalache's type system.
