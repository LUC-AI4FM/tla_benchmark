This TLA+ module is a utility library that defines standard mathematical operations on binary relations. It does not specify a state machine, algorithm, or system with variables and transitions; instead, it provides reusable operator definitions for reasoning about relations in other specifications.

The module represents relations as Boolean-valued functions indexed by pairs of elements from a set S. It defines predicates to test fundamental relational properties: reflexivity (every element relates to itself), irreflexivity (no element relates to itself), symmetry (the relation holds in both directions or neither), asymmetry (the relation never holds in both directions simultaneously), and transitivity (related pairs chain together).

The module also provides computational operators. TransitiveClosure computes the smallest transitive relation containing R by iteratively adding pairs reachable through intermediate elements, using the cardinality of S as a bound on iterations. ReflexiveTransitiveClosure extends this by adding all self-loops. IsConnected tests whether every pair of elements in S is linked through some path in the reflexive transitive closure.

The module extends Naturals and FiniteSets for arithmetic and cardinality operations. There are no constants, variables, initial states, next-state relations, temporal formulas, fairness conditions, or properties to check, as this is purely a library of helper definitions.
