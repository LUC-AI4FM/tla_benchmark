This module provides TLAPS machine-checked proofs for safety properties of the Two-Phase Commit protocol specified in a companion TwoPhase module.

The specification concerns a distributed transaction protocol involving multiple Resource Managers (RMs) and a Transaction Manager (TM). RMs can prepare, commit, or abort, while the TM collects prepare messages and broadcasts commit or abort decisions.

The module proves two main theorems. First, it establishes type correctness: the specification maintains proper typing of all variables throughout execution, where RM states range over working/prepared/committed/aborted, TM states range over init/committed/aborted, and messages have appropriate structure.

Second, it proves transaction consistency: no two RMs can end up in conflicting final states where one is committed and another is aborted. This property is not directly inductive, so the proof constructs a strengthened inductive invariant with ten conjuncts tracking message-sequencing facts. Key invariant components include: mutual exclusion between Commit and Abort messages in the channel, correlation between TM state and which decision message has been broadcast, the fact that tmPrepared only contains RMs that sent Prepared messages, and case analysis showing aborted RMs either received an Abort message or never sent Prepared.

The proof structure demonstrates both properties are inductive by showing they hold initially and are preserved by all protocol actions including TMCommit, TMAbort, TMRcvPrepared, RMPrepare, RMChooseToAbort, RMRcvCommitMsg, RMRcvAbortMsg, and stuttering steps.
