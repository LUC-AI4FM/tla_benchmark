This TLA+ module serves as a test suite for the `Combinatorics` module, verifying the correctness of factorial and binomial coefficient implementations.

The module extends `Combinatorics`, which presumably provides a `factorial` function (defined as a function over natural numbers) and a `choose` operator for computing binomial coefficients.

The specification contains no variables, actions, or temporal logic—it consists entirely of static assumptions that are checked when the module is parsed or evaluated.

The first assumption verifies that the `factorial` function from the Combinatorics module matches a pure recursive definition of factorial for all integers from 0 to 12. The recursive definition states that 0! equals 1 and n! equals n times (n-1)!.

The second assumption checks that the `choose(n, k)` operator correctly computes binomial coefficients by comparing it against the standard formula n! divided by (k! times (n-k)!) for all valid combinations where n is at least k, both ranging from 0 to 12.

The third assumption verifies fundamental combinatorial identities for a wider range (0 to 63): that choosing 0 items from n yields 1, choosing all n items from n yields 1, and choosing 1 item from n yields n.

This module functions as a validation check rather than modeling system behavior.
