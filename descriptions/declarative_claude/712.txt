This TLA+ module serves as a test suite for the `DyadicRationals` module, which it extends. Dyadic rationals are fractions whose denominators are powers of two.

The module contains no variables, constants, actions, or temporal logic specifications. Instead, it consists entirely of static assertions (ASSUME statements) that verify the correctness of the `Half` operator defined in the parent `DyadicRationals` module.

The tests validate that the `Half` function correctly computes half of a dyadic rational number represented as a record with `num` (numerator) and `den` (denominator) fields. The first test confirms that halving `One` (presumably the rational number 1) produces one-half. Subsequent tests verify a chain of halvings: one-half becomes one-quarter, one-quarter becomes one-eighth, and so on, continuing through denominators of 16, 32, 64, 128, 256, and finally 512.

The final test checks that the `Half` operator properly simplifies fractions, demonstrating that halving two-eighths yields one-eighth rather than one-sixteenth, indicating the function reduces fractions when the numerator is even.

Upon loading, the module prints its name using TLC for diagnostic purposes. If any assumption fails during model checking, TLC will report an error.
