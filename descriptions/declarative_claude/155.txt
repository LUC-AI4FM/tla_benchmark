This TLA+ module specifies a model-checking configuration for a two-phase commit protocol with three resource managers.

The system models distributed transaction commitment coordination between a transaction manager and three resource managers (labeled "0_OF_RM", "1_OF_RM", "2_OF_RM"). The specification imports the actual protocol logic from a separate TwoPhaseTyped module.

The module declares four variables: rmState maps each resource manager to its current state string; tmState holds the transaction manager's state; tmPrepared tracks which resource managers have sent "Prepared" messages to the transaction manager; and msgs represents the set of messages in the system.

The module defines several symmetry-reduction views for state-space exploration. These views use a CountImg function that computes a Parikh image—counting how many resource managers are in each state rather than tracking individual identities. View1 is the coarsest (fastest), View2 adds transaction manager state, and View3 includes all state components.

Four example-finding properties are defined as negated conditions: TMAbortedEx and TMCommittedEx search for traces where the transaction manager reaches aborted or committed states respectively; RMAllAbortedEx and RMAllCommittedEx search for traces where all resource managers reach aborted or committed states. These are used to generate execution traces demonstrating protocol behaviors rather than verify invariants.
