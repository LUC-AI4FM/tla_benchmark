This module specifies model-checking configurations for the Alternating Bit Protocol, extending a base AlternatingBit module and importing correctness conditions from ABCorrectness.

The Alternating Bit Protocol is a reliable data transmission mechanism that uses single-bit sequence numbers to ensure messages are delivered correctly over unreliable channels that may lose or duplicate messages. The sender attaches a bit to each message and waits for acknowledgment with the matching bit before toggling and sending the next message.

The constants include Data representing the set of possible messages (instantiated as two elements), plus msgQLen and ackQLen which bound the lengths of the message and acknowledgment queues respectively, both set to two.

The specification uses ABSpec as its main temporal specification. The key constraint SeqConstraint limits queue lengths to enable finite-state model checking by ensuring message and acknowledgment queues never exceed their specified bounds.

The module checks ABTypeInv as a safety invariant, ensuring type correctness of all variables. Two temporal properties are verified: ABCSpec from the correctness module, and SentLeadsToRcvd, a liveness property stating that for any data value, if it has been sent and the sender is awaiting acknowledgment, eventually that same value will be received. This captures the protocol's fundamental correctness guarantee of reliable delivery.
