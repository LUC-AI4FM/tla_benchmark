This TLA+ module specifies a comparison between two methods of computing the Fibonacci sequence: an iterative approach and a recursive function definition.

The specification uses four integer variables: `n` tracks the current position in the sequence, `fibComp` holds the iteratively computed Fibonacci value, `fibCompPrev` stores the previous Fibonacci value needed for iteration, and `fibSpec` contains the value obtained from the recursive definition.

The recursive function `Fib` is defined over the domain 0 through 15, returning 0 for non-positive inputs, 1 for inputs 1 or 2, and the sum of the two preceding Fibonacci numbers otherwise.

The initial state sets the sequence position to zero, initializes the iterative computation with `fibComp` at 0 and `fibCompPrev` at 1, and sets `fibSpec` to the recursive result for position 0.

The next-state relation increments the position, updates the iterative computation by shifting values (the new value becomes the sum of the previous two), and updates `fibSpec` using the recursive function at the new position.

The invariant `Inv` asserts that the recursively computed value always equals the iteratively computed value, verifying that both computation methods produce identical results at every step of the sequence.
