This TLA+ module specifies a model-checking configuration for a Tendermint consensus protocol with amnesia faults, instantiating a trace-based verification scenario.

The specification models a four-process Tendermint system with two correct processes ("c1", "c2") and two faulty processes ("f3", "f4"). The fault tolerance threshold is set to one, with a maximum of two rounds. Valid values are "v0" and "v1", while "v2" represents an invalid value.

The module tracks standard Tendermint consensus variables for each process: current round, protocol step, decision value, locked value and round, valid value and round. Message pools store propose, prevote, and precommit messages per round, along with an evidence set and current action.

The specification follows a predetermined execution trace representing a specific attack or scenario sequence. The trace progresses through two complete rounds, each executing proposal handling, prevote processing, and precommit without decision, with a round catchup transition between them. This trace structure is typical for demonstrating amnesia attacks where faulty processes violate locking rules.

The proposer assignment is left unconstrained via constant initialization, allowing verification across all possible proposer schedules. This configuration inherits behavior and properties from the TendermintAccTrace_004_draft module, focusing on safety verification under the specified fault model.
