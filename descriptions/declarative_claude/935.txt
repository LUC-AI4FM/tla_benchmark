This module provides a machine-checked proof that the internal memory specification preserves its type invariant. It extends the InternalMemory module and uses the TLA+ Proof System (TLAPS) to formally verify correctness.

The specification models a memory system where processors interact with memory through a request-response protocol. Each processor has a control state (ready, busy, or done) and a buffer that holds either requests or values depending on the protocol phase.

The key insight is that the basic TypeInvariant alone is not inductive—it cannot be proven preserved by examining single transitions in isolation. The proof introduces a strengthening predicate called BufConsistent, which precisely tracks the relationship between each processor's control state and its buffer contents: when ready or done, the buffer holds a value or NoVal; when busy, the buffer holds a memory request.

The combined invariant Inv conjoins TypeInvariant with BufConsistent. The proof proceeds by showing this strengthened invariant is inductive: it holds initially (from IInit) and is preserved by all possible transitions—the Req, Do, and Rsp actions for each processor, plus stuttering steps.

The main theorem establishes that the temporal specification ISpec implies the type invariant holds in all reachable states, derived as a consequence of the inductive invariant lemma using temporal logic reasoning.
