This TLA+ module is a regression test for issue #285, demonstrating the behavior of a CASE expression without an OTHER (default) clause.

The specification models a simple three-state cyclic counter system with a single integer variable x.

**Variable:** The module declares one variable x, typed as an integer, which represents the current state of the system.

**Initial State:** The Init predicate specifies that x can start as either 0 or 1, giving two possible initial states.

**Next-State Relation:** The Next action defines state transitions using a CASE expression. When x equals 0, it transitions to 1; when x equals 1, it transitions to 2; and when x equals 2, it cycles back to 0. Notably, the CASE expression lacks an OTHER clause, meaning if x somehow takes a value outside {0, 1, 2}, the behavior is undefined according to TLA+ semantics.

**Behavior:** Starting from either 0 or 1, the system cycles through states 0 → 1 → 2 → 0 indefinitely. If initialized to 1, it follows the sequence 1 → 2 → 0 → 1 → ...

The module contains no explicit invariants, liveness properties, or fairness conditions—its purpose is specifically to test tool handling of CASE expressions without default branches.
