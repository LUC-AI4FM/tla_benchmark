This TLA+ module extends a write-through cache specification by adding liveness conditions to ensure the system makes progress.

The module builds upon WriteThroughCacheInstanced, which models a write-through cache system with processors, a cache, memory, and a queue for memory operations. The system state comprises memory interface state, working memory, buffers, control state for each processor, the cache itself, and a memory queue.

The specification defines a condition QCond that holds when either the memory queue has reached its maximum length or contains at least one read operation.

The liveness property combines several fairness conditions for all processors: weak fairness on response and direct read actions, and strong fairness on read-miss handling and direct write actions. Additionally, there is weak fairness on memory queue operations, specifically requiring progress on memory queue writes when QCond holds, or on memory queue reads.

The complete live specification LSpec conjoins the base safety specification Spec with these liveness conditions. This ensures that processors eventually receive responses to their requests and that the memory queue is eventually serviced, preventing indefinite stalling of cache operations.

The module includes an alternative, simpler liveness definition that applies weak fairness unconditionally to memory queue writes and reads, without the QCond guard.
