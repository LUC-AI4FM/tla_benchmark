This TLA+ specification models a simple discrete state machine where transitions are governed by a configurable constant operator.

The module declares one constant operator `F`, which takes a single argument, and one variable `x` representing the system state.

The initial state predicate `Init` sets `x` to zero. The next-state relation `Next` updates `x` by applying the operator `F` to its current value, so each step transforms the state according to whatever function `F` represents.

The model configuration instantiates `F` as a specific finite function: `F(0)` yields 1, `F(1)` yields 2, and `F(2)` yields 2. This creates a deterministic sequence where `x` progresses from 0 to 1 to 2, then remains at 2 indefinitely since `F(2)` equals 2.

The invariant `Inv` asserts that `x` must never equal 2. Given the configured behavior of `F`, this invariant will be violated after two steps when `x` transitions from 1 to 2. The specification thus demonstrates how constant operator configuration works in TLA+ and provides a simple example where model checking will find a counterexample to the stated safety property.
