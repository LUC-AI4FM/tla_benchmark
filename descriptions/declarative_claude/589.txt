This module is a TLA+ model-checking wrapper (test harness) rather than a standalone system specification. It instantiates the `CollapseRollbacks` module — which extends a Percolator-style distributed transaction protocol — with a concrete, minimal configuration intended for finite-state verification using TLC.

The module fixes two symbolic constants `c1` and `c2` representing two concurrent clients, a key space of `{1, 2}`, and a `ClientPrimaryKey` mapping that assigns primary key 1 to `c1` and primary key 2 to `c2`. These bindings are passed to the parent module's parameters `KEY`, `CLIENT`, and `CLIENT_PRIMARY_KEY` through the configuration file. The temporal specification used is `PercolatorSpec`, inherited from `CollapseRollbacks`. The configuration instructs TLC to check eight invariants defined in the parent module: `TypeInvariant`, `WriteConsistency`, `LockConsistency`, `CommittedConsistency`, `AbortedConsistency`, `RollbackConsistency`, `UniqueWrite`, and `SnapshotIsolation`. Together these invariants verify correctness properties of the transaction protocol, including type safety, lock and write coherence, proper handling of committed and aborted transactions, rollback soundness, uniqueness of writes, and snapshot isolation guarantees, all under the smallest non-trivial scenario of two keys and two clients.
