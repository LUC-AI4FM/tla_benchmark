This module extends a base specification (Session10) to define model-checking configurations and correctness properties for a breadth-first search (BFS) algorithm that computes shortest-path distances in an undirected graph.

The system models distributed BFS starting from a designated root node. Nodes communicate via message queues, building a spanning tree where each node records its parent and depth (distance from root).

The constants define a graph with six nodes connected by six edges, with node "r" as the root. MaxNodes bounds sequence lengths.

The variables (from the base module) include: depth, mapping each node to its computed distance; parent, mapping each node to its parent in the BFS tree; and msgs, a function from queues to message sequences.

TypeOK is a type invariant ensuring depth values are bounded integers, parent maps nodes to nodes, message queues contain valid sequences, and messages within each queue are strictly decreasing and bounded below by the sender's depth.

The specification defines auxiliary functions: PPath constructs the path from any node to root via parent pointers; DistanceFrom and Dist compute actual graph distances.

DepthCorrect is a safety property stating that upon termination, each node's path length to root equals its true shortest-path distance.

Termination is a liveness property asserting all queues eventually become empty.

Deadlock checking is disabled, as termination with empty queues is expected behavior.
