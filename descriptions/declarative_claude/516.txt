This TLA+ module specifies the high-level behavior that the Alternating Bit protocol is intended to achieve, serving as an abstract specification rather than a detailed implementation.

The system models communication between two processes, A (sender) and B (receiver), exchanging messages from a constant set Data. Messages are records containing a data field and a single-bit tag. Two variables track the system state: AVar holds the sender's current message record, and BVar holds the receiver's acknowledged message record.

Initially, AVar is set to some message with bit value 1, and BVar equals AVar, indicating synchronization. Process A can send a new message only when its bit matches B's bit, at which point it selects arbitrary data and flips its bit. Process B can receive only when the bits differ, whereupon it copies AVar to BVar, achieving synchronization.

The next-state relation allows either process A or B to execute when their respective conditions are met. The temporal specification includes weak fairness on both processes, ensuring that each process eventually executes whenever it remains continuously enabled.

No explicit safety or liveness properties are stated in the module beyond the specification itself. The fairness conditions guarantee progress: the protocol will not stall indefinitely when communication is possible, capturing the essential liveness requirement of the Alternating Bit protocol's abstract behavior.
