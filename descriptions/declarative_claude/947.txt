This TLA+ module specifies a framework for modeling real-time constraints in system specifications, using a bounded model-checking approach.

The module models the passage of real time alongside system state changes. Time is represented as a bounded set of naturals from zero to MaxReal, rather than actual real numbers, to enable finite model checking.

The specification uses a variable `now` to track the current time. The initial condition RTini requires that time starts within the valid range. The next-state relation RTNext describes two possible transitions: either the system state v remains unchanged while time advances to any greater value, or the system state changes while time remains constant. This captures the intuition that time passes only when the system is idle.

The TimerInit and TimerNext operators provide a mechanism for tracking elapsed time with deadline and response-time constraints. A timer t resets to zero when an action A occurs or becomes disabled; otherwise, it accumulates elapsed time. The timer enforces that t never exceeds an upper bound E (maximum time constraint) and that action A can only occur after a minimum delay D has elapsed.

The RTFairness condition specifies weak fairness on time advancement, ensuring that time eventually progresses past any given point when the system state remains stable.
