This TLA+ module serves as a regression test for TLC issue #1305, which involves the handling of view expressions when applied to function-typed variables.

The specification defines a single variable `fun`, which is a function mapping integers to integers. Initially, `fun` maps each element in the domain {1, 2} to itself, so fun[1] = 1 and fun[2] = 2.

The next-state relation offers two possible transitions: either the function remains unchanged, or each value in the function is incremented by its corresponding key. Under the second option, fun[x] becomes fun[x] + x for all x in the domain.

The invariant `Inv` asserts that fun[1] should never equal 2. This invariant will be violated after one step of the incrementing transition, since fun[1] starts at 1 and becomes 1 + 1 = 2.

The `View` definition specifies that state equivalence for model checking purposes should be determined by the value of `fun`. This is central to the regression test, as it exercises TLC's view functionality specifically with function-valued expressions, ensuring that the model checker correctly handles such views after internal refactoring of TLC operators.
