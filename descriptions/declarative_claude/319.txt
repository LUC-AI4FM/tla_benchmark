This TLA+ module demonstrates parametric type instantiation through a simple specification involving polymorphic operators.

The specification defines a single variable `pair`, which holds a tuple containing an integer and a boolean value.

The module introduces three operators. Operator `A` is a polymorphic function that applies a function `f` to an element `e`, returning the result of the function application. Operator `B` wraps `A` with a more constrained type signature where the domain and codomain types must match. Operator `C` constructs two identity functions—one over the integers zero, one, and two, and another over booleans—then applies `B` to each with appropriate arguments, demonstrating that `B` (and consequently `A`) can be instantiated with different concrete types (integers and booleans) within the same expression.

The initial state sets `pair` to the tuple containing zero and false. The next-state relation updates `pair` to the result of `C`, which evaluates to the tuple containing one and true (the identity function applied to one and true respectively).

This specification serves as a test case for type checking tools, verifying that parametric operators can be correctly instantiated with different type arguments at different call sites within a single computation.
