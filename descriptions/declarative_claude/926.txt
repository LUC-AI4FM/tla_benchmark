This TLA+ module provides type annotations for an hour clock specification, wrapping the HourClock2 module to enable model checking with the Apalache model checker while keeping the original specification free of tool-specific syntax.

The specification models a simple 12-hour clock system. It declares a single variable `hr` representing the current hour, annotated with integer type for Apalache's type checker. The module extends the Naturals for arithmetic operations and imports the HourClock2 specification via INSTANCE, gaining access to its definitions.

The HourClock2 module referenced here is described as an alternative formulation of an hour clock that computes the next hour using modular arithmetic—specifically the expression `(hr % 12) + 1`—rather than conditional logic. This mathematical approach provides an equivalent but stylistically different specification of hour advancement.

The model-checking configuration specifies HC2 as the temporal specification to verify, which defines the allowed system behaviors including initial states and transitions. The invariant HCini is checked, which likely ensures the hour value remains within valid bounds (1 through 12) throughout all reachable states.

The module notes that the two formulations (HourClock and HourClock2) are claimed equivalent via a theorem stating their temporal specifications are logically identical.
