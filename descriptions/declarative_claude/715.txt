This TLA+ module is a test suite that verifies the correctness of operators defined in a separate Functions module. It contains no state machine or temporal behavior—only static ASSUME statements that must evaluate to TRUE when the module is loaded.

The module tests several function-manipulation operators. **RestrictDomain** filters a function's domain based on a predicate, while **RestrictValues** filters based on the function's output values. **IsInjective** checks whether a function is one-to-one, meaning no two domain elements map to the same value; the tests cover sequences, records, and general functions, including error handling for invalid inputs.

**FoldFunction** and **FoldFunctionOnSet** perform fold operations over functions, aggregating values using a binary operator. **AntiFunction** computes the inverse of an injective function, swapping domain and range. The tests verify that applying AntiFunction twice returns the original function.

**Pointwise** applies a binary operator element-wise to two functions with the same domain. **IsRestriction** checks whether one function is a restriction of another, meaning the first function agrees with the second on their shared domain.

The module uses TLC's AssertError to verify that operators correctly reject invalid arguments with appropriate error messages. All tests are purely declarative assertions with no variables, actions, or temporal properties—this module serves exclusively as a unit test for the Functions library.
