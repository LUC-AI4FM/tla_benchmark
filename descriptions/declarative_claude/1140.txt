This TLA+ module specifies a data structure and well-formedness conditions for mapping between TLA+ specifications and PlusCal code, supporting translation tooling between these two specification languages.

The specification defines several key data types. A Location represents a position in a file via line and column numbers, with a comparison relation for ordering locations. A Region pairs two locations marking a contiguous text span. Three kinds of TPObjects exist: TLATokens marking regions in TLA+ code, Parens indicating beginning or ending boundaries in PlusCal code, and Breaks representing discontinuities between non-adjacent PlusCal regions with an associated nesting depth.

The module defines recursive computation of parenthesis depth at any position in a sequence of TPObjects. The IsWellFormed predicate requires that sequences begin with an opening paren, end with balanced parens, and never have negative depth. TokensInOrder ensures TLAToken regions appear left-to-right. MatchingParen finds the corresponding closing paren for any opening paren.

The main predicate IsTPSpec combines well-formedness, token ordering, constraints that breaks occur only between closing and opening parens, and ordering requirements on matched parentheses and their nested structures. TPSpec is the set of all valid specification sequences.

Helper functions at the end create test objects with simplified single-line locations for debugging purposes. The module contains no temporal logic, actions, or properties to check—it purely defines structural predicates over static data.
