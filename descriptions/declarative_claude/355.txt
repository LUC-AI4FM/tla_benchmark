This TLA+ module is a test suite for verifying the correct behavior of tuples, Cartesian products, and sequence operations in the TLC model checker.

The specification uses a single Boolean variable x that is initialized to TRUE and never changes. This trivial state machine exists solely to provide a context for evaluating the invariant, which contains all the actual tests.

The invariant Inv performs eleven tests covering various tuple and Cartesian product operations. Tests 1 and 3 verify cardinality calculations for finite Cartesian products, confirming that a three-element set crossed with a four-element set yields twelve elements, and a further cross with a two-element set yields twenty-four. Tests 2, 3, and 10 check membership in Cartesian products involving infinite sets like Int, function spaces, and sequences. Tests 4 and 11 verify that tuples with incorrect component values are correctly identified as non-members. Test 5 confirms that indexing a tuple produces the expected set of values matching a record's domain. Tests 6 and 7 verify that function constructors over contiguous integer domains produce tuples, testing both equality and inequality. Tests 8 and 9 check sequence membership, including sequences over subset-defined integer ranges.

Each test uses Assert to fail if the condition is violated, or prints a success message otherwise. The configuration specifies Inv as an invariant to be checked during model checking.
