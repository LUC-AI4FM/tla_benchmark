# RealTime Module Description

This TLA+ module provides a standard framework for specifying real-time constraints in system specifications, as described in Chapter 9 of "Specifying Systems" by Leslie Lamport.

## Purpose and Structure

The module extends the Reals and introduces a single variable `now` representing the current time as a real number.

## Key Definitions

**RTBound(A, v, D, E)** defines a real-time bound on action A with respect to variables v. It uses an auxiliary timer variable t (existentially quantified) that tracks how long action A has been continuously enabled. The timer resets to zero when A occurs or becomes disabled, and otherwise advances with the passage of time. The constraint enforces that the timer never exceeds E (upper bound) and that A can only occur when the timer is at least D (lower bound). This captures the requirement that action A must occur within time E of becoming enabled and cannot occur sooner than time D.

**RTnow(v)** specifies how the `now` variable behaves: it starts as a real number, can only increase (never decrease), leaves other variables v unchanged when advancing, and satisfies a fairness condition ensuring time eventually progresses past any finite bound—preventing time from stopping.

## Limitations

The module note indicates that TLC cannot model-check specifications using these constructs due to their reliance on real numbers and existential quantification over auxiliary variables.
