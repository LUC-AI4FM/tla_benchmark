This TLA+ module defines type aliases for modeling an ERC20 token contract, which is a standard interface for fungible tokens on Ethereum-like blockchains.

The module establishes several record types for token operations. A **transfer** record captures direct token transfers with fields for transaction ID, failure status, sender address, recipient address, and transfer value. An **approve** record models approval operations where an owner authorizes a spender to use tokens on their behalf. A **transferFrom** record represents delegated transfers where a sender moves tokens from one address to another using a prior approval.

The **TX** type is a discriminated union encompassing all transaction types: no operation, transfer, approve, or transferFrom variants.

The **STATE** type alias defines the complete system state, containing: a mapping from addresses to integer balances, a two-dimensional mapping from address pairs to allowance amounts (how much one address may spend on behalf of another), a set of pending transactions awaiting processing, the most recently processed transaction, and a counter for generating unique transaction identifiers.

This module serves purely as a type definition library for a companion ERC20 specification module. The single definition `ERC20_typedefs == TRUE` is a placeholder that allows the type annotations to be parsed. No behavior, actions, or properties are specified here.
