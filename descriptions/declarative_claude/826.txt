This module provides a TLAPS (TLA+ Proof System) machine-checked proof that the Missionaries and Cannibals specification maintains type correctness as an invariant.

The module extends a base specification called MissionariesAndCannibals, which models the classic river-crossing puzzle where missionaries and cannibals must cross a river in a boat without the cannibals ever outnumbering the missionaries on either bank.

The specification tracks two state variables bundled as `vars`: `bank_of_boat` indicating which river bank (East or West) currently holds the boat, and `who_is_on_bank` recording which people are present on each bank.

The module defines the complete temporal specification `Spec` as the conjunction of initial conditions and the next-state relation under stuttering. This explicit definition is necessary for the proof since the original module relied on implicit specification through a configuration file.

The main theorem `TypeCorrect` establishes that the specification implies the type invariant `TypeOK` holds in all reachable states. The proof proceeds by standard invariant reasoning: first showing that initial states satisfy the type invariant, then showing that any transition (either a `Move` action or a stuttering step) preserves the invariant. The Move action analysis carefully tracks that moving a subset of people between banks maintains the constraint that `bank_of_boat` remains in the set of valid banks and `who_is_on_bank` remains a function mapping banks to subsets of cannibals and missionaries.
