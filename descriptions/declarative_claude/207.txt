The module Rec5 is a test case for model checkers that must handle recursive operator definitions through bounded unrolling rather than native recursion.

The module defines a fixed set of three processes (`Procs = {"a", "b", "c"}`) and a single variable `votingPower`, which maps each process to an integer voting power in the range 0 to `MAX_POWER` (3). The recursive operator `Sum` computes the total voting power over a set by repeatedly picking an arbitrary element, adding its voting power, and recursing on the remainder, bottoming out at 0 for the empty set. Two unrolling annotations, `UNROLL_TIMES_Sum = 3` and `UNROLL_DEFAULT_Sum = 0`, instruct compatible tools to unfold the recursion exactly three times and substitute 0 as the default base value, matching the three-element process set.

The `Init` predicate assigns `votingPower` to any function from `Procs` into `0..MAX_POWER`, and `Next` non-deterministically reassigns it to any such function, making every state reachable from every other. The invariant `Inv` asserts that the sum of all voting powers is strictly less than 10. Since each of the three processes can hold up to 3, the maximum possible sum is 9, so the invariant holds in all reachable states.
