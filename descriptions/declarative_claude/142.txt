This TLA+ module is a regression test for the Apalache model checker, specifically testing the handling of named assumptions that are referenced within the initial state predicate.

The module specifies a trivial system with a single integer variable `x`. The system's behavior is entirely static: `x` is initialized to zero and never changes.

The module declares a named assumption `NamedAssumption` that asserts the trivially true statement that one equals one. Notably, this assumption is not only declared at the top level but is also conjoined into the initial state predicate `Init`. This unusual pattern—referencing a named assumption within `Init`—is the specific construct being tested for correct handling by the model checker.

The next-state relation `Next` specifies that `x` remains unchanged across all transitions, meaning the system has only one reachable state.

The invariant `Inv` asserts that `x` always equals zero, which trivially holds given the system's behavior.

There are no liveness properties or fairness conditions specified. The module contains no constants. This specification serves purely as a test case to verify that the Apalache tool correctly processes named assumptions when they appear inline within state predicates.
