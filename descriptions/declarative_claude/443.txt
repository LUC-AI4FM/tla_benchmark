This TLA+ module explores subtle semantic aspects of the INSTANCE mechanism and ENABLED operator behavior, serving as a test case rather than modeling a real-world system.

The module declares a single variable `u` and imports the Naturals module.

The operator `G` takes two parameters: a variable `v` and an action `A`. It returns whether any of three alternative actions is enabled: the action `A` itself, an action that leaves both `u` and `v` unchanged, or an action that swaps the values of `u` and `v`.

The operator `H` combines a stuttering step for `u` (where `u` remains unchanged) with a call to `G`. In this call, `u` is passed as the first argument (substituting for the formal parameter `v`), and the action `u' = u + 1` is passed as the second argument `A`.

This module tests how TLA+ handles variable substitution within the ENABLED operator, particularly when the same variable appears in multiple roles through parameter passing. The specification examines whether enabling conditions are correctly evaluated when formal parameters are instantiated with actual variables that also appear free in the operator definition.

No temporal specification, invariants, fairness conditions, or properties to check are defined in this module.
