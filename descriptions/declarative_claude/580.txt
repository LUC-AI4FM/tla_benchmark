This TLA+ module specifies a bounded model-checking version of a single-node system that handles both read-write and read-only transactions. It extends two parent modules: SingleNodeReads (which defines the core read transaction logic) and MCSingleNode (which provides bounded single-node behavior).

The specification models a system where clients can issue read-write transactions and read-only transactions against a single node. The module bounds the system's behavior by limiting the history length to enable finite model checking.

The key actions include bounded versions of read-only transaction requests and responses, which only proceed when the history length remains below the configured limit. The next-state relation combines the bounded single-node actions with these bounded read-only transaction actions.

The configuration sets the history limit to seven entries and uses a single branch. Transaction types and statuses are modeled as distinct constants for requests, responses, and status notifications, with committed and invalid as possible transaction outcomes.

The specification checks numerous safety invariants covering: uniqueness of transactions, transaction identifiers, and sequence numbers; serializability of read-write transactions; proper observation ordering where committed transactions observe only sent requests; ensuring invalid transactions are not observed by other transactions; and at-most-once observation semantics. Additional invariants verify that all committed transactions are properly observed, including by read-only transactions.

Deadlock checking is disabled, indicating the focus is on safety properties rather than progress.
