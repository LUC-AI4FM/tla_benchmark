The module specifies a message-passing formulation of the Paxos consensus algorithm, adapted from the canonical TLA+ Examples version and annotated with Apalache type aliases. It models three acceptors (`a1_OF_A`, `a2_OF_A`, `a3_OF_A`), two values (`0_OF_V`, `1_OF_V`), ballots ranging over `1..10`, and a single quorum `{a1_OF_A, a2_OF_A}`. Learners and explicit leader processes are omitted.

The state consists of per-acceptor variables `maxBal`, `maxVBal`, and `maxVal` tracking the highest ballot promised and the highest ballot/value voted, plus a global set `msgs` accumulating all messages ever sent (of types M1a, M1b, M2a, M2b). The four protocol actions are `Phase1a`, which broadcasts a ballot-opening M1a message; `Phase1b`, in which an acceptor responds with its current vote state if the incoming ballot exceeds its `maxBal`; `Phase2a`, in which a ballot leader sends an M2a message for a value demonstrably safe at that ballot, provided no M2a for that ballot already exists and a quorum of M1b responses has been collected; and `Phase2b`, in which an acceptor votes by sending M2b and updating its local state. The temporal specification is `Init /\ [][Next]_vars` with no fairness conditions. The module defines an inductive invariant `Inv` asserting consistency between acceptor state and the `votes` derived function, well-formedness of M1b messages, and the critical agreement property that all M2a messages for the same ballot carry the same value and are backed by a safe quorum. A partial `ShowsSafeAt` predicate used in `Inv` contains explicit range-approximation fixes noted as modifications from the original.
