# Specification Overview

This TLA+ module serves as a test suite for validating the syntactic constraints that TLA+ places on temporal operators to prevent invalid combinations known as "raw TLA" formulas.

## Purpose

The module systematically tests which temporal formula constructions are permitted and which violate TLA+'s level restrictions. These restrictions ensure that temporal formulas remain well-formed according to TLA+'s semantic rules.

## Variable

The specification declares a single variable `x` used throughout the test expressions.

## Test Cases

The module defines multiple named formulas testing various temporal operator combinations:

- **Leads-to operator (~>)**: Tests show that unprimed expressions leading to boxed expressions are valid, while primed expressions in leads-to formulas are errors.

- **Leads-to-eventually operator (-+->)**: Similar pattern where primed expressions on either side constitute errors.

- **Eventually and always operators**: The formula using the angle-bracket action notation with eventually is valid, but bare eventually applied to primed expressions is invalid. Similarly, always applied directly to primed expressions is forbidden, though the stuttering-closure form is acceptable.

- **Quantified formulas with temporal operators**: When quantifiers bind over sets, using primed expressions in the set definition while the body contains temporal operators is invalid.

The comments marking "ERROR" indicate which formulas should be rejected by the TLA+ tools as syntactically or semantically invalid level violations.
