This TLA+ module is a comprehensive test suite for the `SequencesExt` library, which extends the standard `Sequences` module with additional sequence manipulation operators. The module contains no state machine specification; instead, it consists entirely of `ASSUME` statements that verify the correctness of various sequence operations at module loading time.

The tests cover numerous sequence utility functions: `ToSet` and `ToBag` for converting sequences to sets and bags; `SetToSeq` and `SetToSeqs` for converting sets to sequences; `Reverse`, `Remove`, `ReplaceAll`, and `ReplaceAt` for basic transformations; prefix and suffix predicates (`IsPrefix`, `IsStrictPrefix`, `IsSuffix`, `IsStrictSuffix`); `Contains` for membership testing; fold operations (`FoldLeft`, `FoldRight`, `FoldSeq`) for aggregation; `LongestCommonPrefix` for finding shared prefixes across sequence sets; `FlattenSeq` for flattening nested sequences; `Interleave` and `Zip` for combining sequences; `SubSeqs` and `AllSubSeqs` for generating subsequences; `ReplaceFirstSubSeq` and `ReplaceAllSubSeqs` for pattern replacement; and various selection and removal functions.

Many tests compare the library's Java-implemented operators against equivalent pure TLA+ definitions to ensure correctness. The tests exercise edge cases including empty sequences, single-element sequences, duplicate elements, and string sequences. Error handling is verified using `AssertError` for invalid inputs. No temporal properties, fairness conditions, or model-checking configuration exist since this module purely validates operator implementations through static assertions.
