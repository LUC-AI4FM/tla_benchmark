This TLA+ module specifies a simple three-state cyclic counter system, created as a regression test for issue #285 related to CASE expressions without an OTHER clause when dealing with boolean conditions.

The specification defines a single integer variable x that cycles through three values: 0, 1, and 2.

The initial state allows x to be either 0 or 1, establishing two possible starting points for the system.

The next-state relation uses a CASE expression to define transitions based on the current value of x. When x equals 0, it transitions to 1; when x equals 1, it transitions to 2; and when x equals 2, it cycles back to 0. This creates a deterministic circular progression through the three states.

The module notably omits an OTHER clause in the CASE expression, which is relevant to the regression test purpose. Since the initial states and transitions ensure x only ever takes values 0, 1, or 2, the CASE conditions are exhaustive within reachable states.

No explicit safety properties, liveness conditions, or invariants are specified in this module. The specification serves primarily as a test case for tooling behavior rather than modeling a complex system.
