# ActionCompositionDistributive Module Description

This specification demonstrates a subtle semantic property of TLA+ regarding how module instantiation interacts with action composition (the `\cdot` operator). It serves as a test case showing that instantiation does not distribute over action composition.

The specification uses two variables `x`, `y`, and `z`. It instantiates a helper module `HL` with both of HL's variables (`x` and `y`) mapped to the single variable `z`. The helper module HL defines two actions: action `A` increments `y` by one while keeping `x` unchanged, and action `B` requires `x` and `y` to differ, then sets `y` equal to `x` while keeping `x` unchanged. The composition `A \cdot B` in HL represents performing A followed by B in a single atomic step.

The main module defines two specifications for comparison. `ASpec` uses the composed action from HL after instantiation—composing first, then substituting. `BSpec` substitutes first in each action, then composes them. Due to TLA+ instantiation semantics, these produce different behaviors: when both HL variables map to `z`, the instantiated composition in `ASpec` yields `z' = z`, while `BSpec` becomes unsatisfiable because `z # z` is always false.

The initial state sets `z` to 1 and both `x` and `y` to 0.
