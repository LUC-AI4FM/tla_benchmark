This TLA+ module is a test suite for verifying the correct behavior of TLA+'s DOMAIN operator and function set constructs. It does not model a distributed system or algorithm but instead validates tooling behavior through a series of assertions.

The specification uses a single boolean variable x that remains constant throughout execution—initialized to TRUE and never modified. This trivial state machine exists solely to provide a context for checking the invariant.

The invariant Inv consists of 25 sequential tests that verify various properties of functions and function sets. Tests 1–3 confirm that DOMAIN correctly identifies elements belonging to the domain of functions defined over integers and subsets of integers. Tests 4–6 verify that DOMAIN returns sets with expected cardinalities for functions with finite and more complex domains, including functions whose domain is itself a function set. Tests 7–19 examine membership in function sets, checking that functions with correct domains and ranges are included while those with incorrect domains, wrong range values, or mismatched domain sizes are excluded. Tests 20–21 enumerate and display a small function set. Test 22 verifies cardinality computation for larger sets. Tests 23–25 confirm that multi-argument function constructors produce domains that are Cartesian products.

The configuration specifies Init as the initial state, Next as the transition relation, and Inv as a safety invariant that must hold in all reachable states.
