This TLA+ module specifies the original protocol of the Nano cryptocurrency blockchain, modeling a distributed ledger system with cryptographic primitives.

The specification models a network of nodes maintaining individual ledgers that store blocks organized in a block-lattice structure. Each account has its own chain of blocks rather than a single global chain.

**Constants** define the cryptographic infrastructure: hash values, a hash calculation operator, private/public key pairs, network nodes, the total coin supply (GenesisBalance), and which private key each node owns.

**Variables** track the last computed hash, each node's copy of the distributed ledger (mapping hashes to signed blocks), and blocks received but not yet validated.

The protocol supports five block types: genesis (initial coin creation), send (transferring funds), open (creating a new account by receiving funds), receive (accepting sent funds), and change (updating representative). Each block type has creation and processing actions with specific validation rules ensuring cryptographic signatures match, referenced blocks exist, and balances remain valid.

**Key actions** include CreateGenesisBlock for initialization, CreateBlock actions where nodes generate new blocks broadcast to all nodes' received sets, and ProcessBlock actions where nodes validate and commit received blocks to their local ledgers.

**Safety invariants** verify that all blocks in the ledger have valid cryptographic signatures matching the account's public key. A balance invariant ensures total account balances never exceed the genesis balance. The type invariant constrains variable domains.

The specification uses standard temporal logic with no fairness conditions, checking safety properties without liveness guarantees.
