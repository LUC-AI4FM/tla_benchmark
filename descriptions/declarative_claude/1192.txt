This TLA+ module is a test suite designed to verify the correct handling of one-tuples (single-element tuples) in the TLC model checker.

The specification uses a single variable x, which is a boolean that starts as TRUE and never changes. This minimal state space exists solely to provide a context for evaluating the invariant tests.

The module defines a set S containing one-tuples of the integers 1 through 4, expressed as singleton sequences. The invariant Inv consists of six tests that exercise various operations involving one-tuples:

The first test checks membership of a one-tuple in the set S. The second test verifies that existential quantification with tuple destructuring works correctly. The third test confirms that indexing into a one-tuple to access its single element functions properly. The fourth test validates set filtering with tuple pattern matching. The fifth test ensures that concatenating two one-tuples produces a two-tuple. The sixth test checks that function application with one-tuple keys returns correct values.

Each test uses an assertion that causes model checking to fail if the expected condition is not met, while printing a success message otherwise. The specification has no meaningful state transitions; its purpose is purely to validate TLC's tuple-handling semantics during invariant checking. If all tests pass, the invariant holds and model checking succeeds.
