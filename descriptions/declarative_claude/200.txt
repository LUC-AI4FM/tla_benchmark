This TLA+ module tests the behavior of a specification tool's unroller when handling recursive functions with incomplete unrolling annotations.

The module defines a single integer variable `f` that stores factorial values. It specifies a recursive `Fact` function implementing the standard factorial computation: returning 1 for inputs of 1 or less, and otherwise multiplying the input by the factorial of one less than the input.

The module includes partial configuration for recursive function unrolling used by model checkers. It defines `UNROLL_DEFAULT_Fact` as 0, which provides a default value when recursion depth is exceeded, but intentionally leaves `UNROLL_TIMES_Fact` undefined (commented out). This setup tests whether the specification tool properly detects and reports the missing unroll depth parameter.

The initial state sets `f` to the factorial of 4 (which equals 24). The next-state relation transitions `f` to the factorial of 7 (which equals 5040). This creates a simple two-state system.

The safety invariant `Inv` asserts that `f` is always greater than or equal to 1, which holds for all positive factorial results.

The specification serves as a test case for tooling behavior rather than modeling a real system, specifically checking error handling when recursive unrolling configuration is incomplete.
