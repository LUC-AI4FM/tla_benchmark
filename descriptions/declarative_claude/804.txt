This TLA+ module specifies a binary search algorithm that finds a value in a sorted sequence of integers.

The specification models an algorithm that searches for a value `val` within a sorted sequence `seq`. The algorithm maintains search bounds using variables `low` and `high`, starting with the full sequence range. The variable `result` stores either the index where the value is found or zero if the value is absent. The program counter `pc` tracks execution state.

The algorithm operates through a single action that repeatedly computes the midpoint of the current range, compares the middle element with the target value, and either returns the index (if found), narrows the search to the lower half (if the target is smaller), or narrows to the upper half (if the target is larger). The loop continues while the search range is valid and no result has been found.

The temporal specification combines initial conditions with the next-state relation under stuttering, plus weak fairness on transitions to ensure progress.

The module defines a safety property `resultCorrect` stating that upon termination, if the value exists in the sequence then `result` points to a matching element, otherwise `result` equals zero. An inductive invariant `Inv` captures type correctness and the key property that if the value exists anywhere in the sequence, it must exist within the current search bounds.

The module includes a complete TLAPS-verified proof that the specification guarantees the safety property `resultCorrect` always holds.
