The module specifies a tutorial model of binary search, closely following the Java `Arrays.binarySearch` implementation. It is parameterized by three constants: `INPUT_SEQ` (the integer sequence to search), `INPUT_KEY` (the value to find), and `INT_WIDTH` (the machine integer bit-width, used to derive `MAX_UINT`, `MAX_INT`, and `MIN_INT` for potential overflow reasoning).

The four variables track the current search interval endpoints `low` and `high` (both inclusive, zero-based), a termination flag `isTerminated`, and the `returnValue`. The initial state sets `low` to 0, `high` to the last valid index, and marks the algorithm as not yet terminated. Each step of `Next` computes the midpoint `mid` and compares the corresponding element to `INPUT_KEY`: if the element is smaller, `low` advances past `mid`; if larger, `high` retreats below `mid`; if equal, `returnValue` is set to the zero-based index and the algorithm terminates. When the interval becomes empty (`low > high`) without a match, the algorithm terminates with `returnValue` set to `-(low + 1)`, mirroring Java's convention. Once terminated, the state is left unchanged.

The safety property `Postcondition` asserts that whenever the algorithm has terminated, `ReturnValueIsCorrect` holds: if any index in `INPUT_SEQ` equals `INPUT_KEY`, then `returnValue + 1` must be one of those indices; otherwise `returnValue` must be negative. This captures the standard guarantee that the return value is non-negative if and only if the key is found.
