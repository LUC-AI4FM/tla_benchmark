This TLA+ module specifies a utility library for input/output operations and external process execution, designed to interface TLA+ specifications with the external system during model checking.

The module provides operators that are overridden by Java implementations in TLC to perform actual I/O operations. In pure TLA+, these operators evaluate to trivial values (TRUE or arbitrary chosen values), but when executed with TLC's Java overrides, they perform side effects.

The module offers several categories of functionality. For serialization, it provides operators to serialize TLA+ values to files using Java's object serialization format and deserialize them back, with optional compression support. The Serialize and Deserialize operators offer more flexible serialization with format-specific options.

For external process execution, IOExec spawns external commands as subprocesses and returns a record containing the exit value, stdout, and stderr. IOEnvExec extends this by allowing environment variables to be passed. Template variants (IOExecTemplate, IOEnvExecTemplate) support printf-style parameter substitution in commands.

The IOEnv operator provides access to the process's environment variables as a function from strings to strings.

Two utility operators handle string-to-number conversion: atoi converts a string representation of an integer to its numeric value, and zeroPadN formats a natural number as a zero-padded string of specified width.
