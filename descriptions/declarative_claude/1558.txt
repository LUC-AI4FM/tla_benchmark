This TLA+ module named "Utils" is a utility library providing helper functions for other specifications rather than modeling a complete system itself.

The module extends several standard TLA+ libraries including Integers, Sequences, FiniteSets, TLC, Functions, and SequencesExt to build upon their functionality.

The module defines two related predicates for working with cycle structures in graphs:

**IsSimpleCycle** takes a set S and a relation r, interpreting r as a directed graph where S represents vertices and edges exist from s to t when r[s] equals t. The predicate determines whether r forms a simple cycle visiting every element of S exactly once. It constructs a sequence by iteratively following the relation from an arbitrary starting vertex, building up a path of length equal to the set's cardinality, then verifies that this path covers all vertices in S.

**SimpleCycle** provides an alternative recursive implementation that constructs a cyclic mapping from a set. It converts the set to a sequence and recursively builds a function mapping each element to the next in sequence, with the final element mapping back to the first, thereby creating a cycle structure.

The module contains no variables, temporal properties, or invariants—it serves purely as a function library for use by other specifications. A note indicates that IsSimpleCycle is compatible with PlusPy while SimpleCycle offers better TLC performance but lacks PlusPy support.
