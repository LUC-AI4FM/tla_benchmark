This TLA+ module is a **test suite** for a `Bitwise` library module. It does not model a system or algorithm with state transitions; instead, it uses `ASSUME` statements to verify at parse time that bitwise operations behave correctly.

The module tests four bitwise operators imported from the `Bitwise` module: bitwise AND (`&`), bitwise OR (`|`), bitwise XOR (`^^`), bitwise NOT (`Not`), and right shift (`shiftR`). The constant `ZeroToM` defines the test range as integers 0 through 99.

For each operator, the module defines a pure TLA+ reference implementation using recursive arithmetic on binary digits. For AND, `AndPure` computes the result bit-by-bit; similarly `OrPure` and `XorPure` provide reference implementations for OR and XOR, and `NotPure` for bitwise complement. The helper `LowBit` extracts the least significant bit.

The tests verify fundamental properties: AND with zero yields zero; AND with self yields self; XOR satisfies identity (with zero), self-inverse, commutativity, and associativity; right shift by one equals integer division by two. Specific value tests check XOR and NOT against expected results for small integers.

All assertions compare the `Bitwise` module's operator results against either explicit expected values or the pure reference implementations using `AssertEq` from `TLCExt`. The module contains no variables, no temporal logic, and no invariants—it serves purely as a validation harness for bitwise operator correctness.
