This TLA+ module models the "Car Talk Puzzle": given an N-pound stone, find how to break it into exactly P pieces such that any integral weight from 1 to N pounds can be measured using a balance scale.

The module declares two constants: N (total stone weight) and P (number of pieces). A helper operator Sum computes the sum of a function's values over a finite set.

The set Break contains all valid ways to partition the stone—represented as functions from piece indices (1..P) to weights (1..N)—where weights sum to N and are ordered non-decreasingly to eliminate symmetric duplicates.

The predicate IsRepresentation checks whether a target weight w can be balanced by placing some stone pieces (set S) on the corn's side and others (set T) on the opposite side, requiring disjoint sets where w plus the weight of S equals the weight of T.

IsSolution determines if a break can measure every weight from 1 to N by finding appropriate piece placements. AllSolutions collects all breaks satisfying this criterion.

The module includes ExpandSolutions, which expands each solution into an N-tuple showing exactly which pieces go on each side for every weight—useful for verification.

This specification contains no state variables, actions, or temporal properties; it is purely a constant-level computation. TLC evaluates AllSolutions directly, finding for N=40 and P=4 the unique solution: pieces weighing 1, 3, 9, and 27 pounds (powers of 3).
