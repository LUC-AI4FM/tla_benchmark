This TLA+ module is a test suite for operator inlining functionality in the Apalache model checker. It verifies that various patterns of operator definitions, applications, and transformations are handled correctly during inlining.

The module defines no meaningful system state—both Init and Next are trivially TRUE, creating a specification with a single unchanging state. The purpose is purely to validate static properties through the AllTests invariant.

The tests cover diverse operator patterns: simple local LET definitions and global operators, nested LET expressions where inner operators reference outer parameters, linear dependency chains between global operators, nullary operators (taking no arguments), and operators passed by name to higher-order functions like ApaFoldSet and ApaFoldSeqLeft from the Apalache library.

More advanced tests examine lambda expressions, higher-order operators that accept other operators as arguments, double higher-order patterns where operators return or consume other operators, polymorphic operator applications with type annotations, and long chains of nested LET definitions where each operator calls the previous one.

The AllTests conjunction serves as an invariant asserting that all fifteen test predicates evaluate to TRUE. Each test predicate checks that a specific operator application equals its expected result, confirming correct inlining behavior. The module uses Apalache-specific type annotations to guide the type checker for higher-order and polymorphic operators.
