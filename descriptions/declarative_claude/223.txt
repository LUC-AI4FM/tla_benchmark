This TLA+ module defines a minimal specification that demonstrates the use of higher-order operators (lambda expressions) in TLA+.

The module introduces a single operator `L` that takes two arguments: a function `F` (which itself takes one argument) and a value `n`. The operator simply applies the function `F` to the value `n` and returns the result.

The specification has no declared constants or variables. The `Init` predicate is trivially true, meaning any state satisfies the initial condition. The `Next` predicate is also trivially true, meaning any transition between states is permitted. Together, these define a system where essentially anything is allowed—there are no constraints on state or behavior.

The invariant `Inv` tests the higher-order operator by applying `L` to a lambda expression representing the identity function (which returns its input unchanged) and the value 3. The invariant asserts that this application equals 3, which verifies that the lambda mechanism and the operator `L` work correctly together.

This module serves primarily as a test or demonstration of TLA+'s support for lambda expressions and higher-order operators rather than modeling any real system or algorithm.
