This module provides mechanically verified TLAPS proofs for safety properties of the SimpleAllocator specification, which it extends.

The SimpleAllocator models a resource allocation system where clients request, receive allocations of, and return subsets of a finite resource pool. The module imports the base specification's constants (Clients and Resources), variables (tracking requests, allocations, and available resources), and behavioral definitions.

The module proves two theorems establishing that the SimpleAllocator specification preserves safety properties globally:

The first theorem, TypeCorrect, proves that TypeInvariant holds in all reachable states. The proof demonstrates that TypeInvariant is directly inductive: it holds initially and is preserved by every possible transition (Request, Allocate, Return actions and stuttering steps).

The second theorem, Mutex, proves that ResourceMutex—ensuring no resource is simultaneously allocated to different clients—holds throughout execution. This proof requires a strengthened inductive invariant combining both TypeInvariant and ResourceMutex. The key insight is that the Allocate action only grants resources from the available pool, which by definition is disjoint from all current allocations. Therefore, newly allocated resources cannot conflict with any other client's holdings.

Both proofs follow the standard temporal logic pattern: establish the invariant holds initially, prove preservation under the next-state relation, then apply temporal reasoning to conclude the invariant holds globally throughout all behaviors satisfying the SimpleAllocator specification.
