The module Rec9 is a small model-checking demonstration that verifies a recursive set-cardinality function against TLA+'s built-in `Cardinality` operator.

The module defines a constant upper bound `MAX_NUM` equal to 5 and a number domain `NUMS` equal to `1..5`. Two variables are used: `set`, a subset of `NUMS`, and `size`, an integer tracking the computed cardinality. The recursive function `Card` is defined over all subsets of `NUMS`: it returns 0 for the empty set and otherwise picks an arbitrary element, removes it, and adds 1 to the recursive result. The module notes that this definition, while elegant, forces construction of the full powerset of `NUMS` and is at least double-exponential in cost.

The initial state sets `set` to the empty set and `size` to 0. Each step nondeterministically picks some element `i` from `NUMS`, adds it to `set`, and updates `size` by applying `Card` to the new set. The invariant `Inv` asserts that `size` always equals `Cardinality(set)`, confirming that the hand-written recursive `Card` function produces the same result as the built-in operator across all reachable states.
