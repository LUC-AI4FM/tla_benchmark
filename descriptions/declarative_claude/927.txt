This module serves as a type-annotated wrapper around the HourClock specification, designed for use with the Apalache model checker. It demonstrates a pattern for adding tool-specific type annotations without modifying the original specification.

The module declares a single variable `hr` representing the current hour, annotated with integer type for Apalache's type system. Through the INSTANCE statement, it imports all definitions from the HourClock module, which models a simple 12-hour clock.

The underlying HourClock specification models a clock that cycles through hours 1 through 12. The hour variable takes values in this range, and the clock advances by incrementing the hour, wrapping from 12 back to 1.

The model-checking configuration specifies that the temporal specification HC should be checked. This specification defines the complete behavior of the hour clock, including its initial state and transition relation.

The configuration also checks the invariant HCini, which verifies that the hour variable always remains within the valid range of 1 to 12. This safety property ensures the clock never displays an invalid hour value throughout all possible executions.

The module extends Naturals to provide basic arithmetic operations needed for hour calculations and comparisons.
