The Graphs module is a library specification providing mathematical definitions for reasoning about directed and undirected graphs in TLA+. It does not model a dynamic system with state transitions, but instead defines a collection of operators for graph-theoretic concepts.

A graph is represented as a record with two fields: a set of nodes and a set of edges (ordered pairs of nodes). The module defines predicates to test whether a structure is a directed graph or an undirected graph (where edges are symmetric). It provides operators for constructing subgraphs, computing graph unions, and transposing directed graphs.

The module defines paths as non-empty sequences of nodes connected by edges, and simple paths as paths without repeated nodes. Connectivity operators determine whether two nodes are connected and compute a connection matrix using an efficient algorithm based on Warshall's method. Strong connectivity checks if all node pairs are mutually reachable.

Additional operators characterize trees with designated roots, bipartite graphs with given partitions, cycles, and directed acyclic graphs. The module provides functions to compute immediate successors and predecessors of nodes, as well as ancestors and descendants via transitive closure. Degree functions count incoming and outgoing edges, while operators identify root nodes (no predecessors) and leaf nodes (no successors).

The module also defines the empty graph and the set of all possible graphs over a given node set.
