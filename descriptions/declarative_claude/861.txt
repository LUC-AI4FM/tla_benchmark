This TLA+ module specifies a solution to the classic readers-writers synchronization problem using a queue-based approach to ensure fair access to a shared resource.

The system models a set of actors (numbered 1 through NumActors) that can request read or write access to a resource. Three variables track the system state: `readers` (the set of actors currently reading), `writers` (the set of actors currently writing), and `waiting` (a queue of pending access requests, where each entry is a pair indicating the request type and actor).

Actors can perform several actions: TryRead and TryWrite add requests to the waiting queue if the actor isn't already waiting for that operation. ReadOrWrite processes the head of the queue when no writer holds the resource—granting read access immediately or write access only when no readers are active. Stop allows any active reader or writer to release the resource.

The specification includes weak fairness conditions on all actions, ensuring that enabled actions eventually occur.

Two safety invariants are checked: TypeOK ensures variables maintain proper types, while Safety guarantees mutual exclusion—readers and writers never access the resource simultaneously, and at most one writer can be active.

The liveness property asserts that every actor infinitely often becomes a reader, becomes a writer, and also eventually stops each activity, ensuring no actor is permanently starved.
