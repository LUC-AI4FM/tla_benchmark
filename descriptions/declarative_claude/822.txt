This TLA+ module provides a mathematical specification of reachability in directed graphs. It defines the foundational concepts needed to determine which nodes can be reached from a given starting set by following directed edges.

The module declares two constants: **Nodes**, representing the set of all nodes in the graph, and **Succ**, a successor function. An assumption constrains Succ to be a function mapping each node to a subset of Nodes, representing the nodes directly reachable via outgoing edges from that node.

The specification defines three key predicates. **IsPathFromTo(p, m, n)** characterizes when a sequence p constitutes a valid path from node m to node n: the sequence must be non-empty, start at m, end at n, and each consecutive pair must follow an edge according to the successor function. **ExistsPath(m, n)** asserts that some path exists between two nodes by existentially quantifying over all possible sequences of nodes. **ReachableFrom(S)** collects all nodes reachable from any node in a given set S, defined as nodes for which a path exists from some member of S.

This module contains no variables, actions, or temporal formulas—it is purely a definitional module providing mathematical foundations for reasoning about graph reachability, suitable for use by other specifications or for formal proofs.
