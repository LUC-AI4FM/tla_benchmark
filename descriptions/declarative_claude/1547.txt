This specification models a buffered random access file system, specifically modeling Java's `BufferedRandomAccessFile` class. It captures how buffered I/O operations interact with an underlying file through a fixed-size memory buffer.

The system maintains eight variables: `dirty` indicates whether the buffer has unwritten changes; `length` tracks the logical file length; `curr` is the current read/write position; `lo` marks the file offset where the buffer begins; `buff` holds the in-memory buffer contents; `diskPos` tracks the disk position; and `file_content` and `file_pointer` represent the underlying file state.

The constant `BuffSz` defines the buffer size. The specification includes actions for flushing the buffer to disk, seeking to arbitrary positions, setting file length, reading and writing single bytes, and bulk read/write operations. Seeking may trigger buffer refills when the target position falls outside the current buffer window.

The specification establishes five internal invariants (Inv1-Inv5) ensuring consistency between buffered and disk states. It also defines a refinement relationship to a simpler `RandomAccessFile` specification, where the logical file content combines disk content with buffered modifications.

Key properties verified include: type correctness, all five internal invariants, that each operation correctly refines its abstract counterpart, that seeking establishes the buffer positioning invariant Inv2, and that dirty buffers eventually become clean (liveness). The specification also verifies that Inv2 can always be restored through appropriate flush and seek operations.
