This TLA+ module specifies a generalized water jug puzzle, extending the classic Die Hard problem to handle an arbitrary collection of jugs with varying capacities.

The specification uses three constants: `Jug`, representing the set of all available jugs; `Capacity`, a function mapping each jug to its positive integer capacity; and `Goal`, the target amount of water to measure. An assumption constrains these parameters appropriately.

A single variable `contents` tracks the current water level in each jug, represented as a function from jugs to natural numbers. The type invariant `TypeOK` ensures contents remains well-formed. Initially, all jugs start empty.

Three actions define possible state transitions: `FillJug(j)` completely fills jug j to its capacity; `EmptyJug(j)` empties jug j entirely; and `JugToJug(j, k)` pours water from jug j into jug k, transferring the minimum of j's current contents and k's remaining capacity. The next-state relation `Next` allows any jug to be filled or emptied, or water to be poured between any two distinct jugs.

The temporal specification `Spec` requires behaviors to start with all jugs empty and permits only `Next` transitions or stuttering steps.

The predicate `NotSolved` holds when no jug contains exactly `Goal` units of water. By checking `NotSolved` as an invariant, model checking finds counterexample traces that constitute solutions to the puzzle.
