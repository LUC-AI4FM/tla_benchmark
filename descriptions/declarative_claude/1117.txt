This TLA+ module defines a bitwise AND operation for integers, intended as a utility library rather than a standalone specification of a system.

The module provides an infix operator `&` that computes the bitwise AND of two non-negative integers. The implementation uses a recursive helper function that processes the binary representation of the inputs bit by bit. For each bit position, it extracts the corresponding bits from both operands using division and modulo operations, multiplies them together (which yields 1 only if both bits are 1), and accumulates the result weighted by the appropriate power of two.

The module is designed to work with TLC model checking through a Java override mechanism. A companion Java class can provide a more efficient native implementation of the AND operation. The TLA+ definition serves as a fallback specification and as documentation of the intended semantics. The module includes extensive comments explaining how to compile and use the Java override, along with diagnostic messages that indicate whether the override loaded successfully.

This is a library module with no variables, state transitions, temporal properties, or invariants. It exports only the bitwise AND operator for use by other specifications that require bit manipulation, such as algorithms involving bit vectors or binary encodings.
