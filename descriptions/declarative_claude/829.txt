This module models a classic puzzle: a cat hides in one of N boxes arranged in a line, moves to an adjacent box each night, and an observer opens one box each morning trying to find the cat.

The constant Number_Of_Boxes specifies the number of boxes, which must be at least two. Three variables track the state: cat_box records which box currently contains the cat, observed_box records which box the observer checks, and direction indicates whether the search pattern moves left or right.

The cat occupies any box from 1 to N, while the observer only checks boxes 2 through N-1. The search strategy sweeps back and forth through this interior range, reversing direction upon reaching either end.

Each step combines two simultaneous actions. The cat moves one box left or right, staying within bounds. The observer advances one box in the current direction if possible, or reverses direction and stays put when reaching the search boundary.

The temporal specification requires that every step follows the next-state relation and enforces weak fairness on the cat's movement, ensuring the cat cannot stall indefinitely.

The module checks one liveness property called Victory: eventually the observer and cat occupy the same box. A type invariant TypeOK confirms all variables remain in their expected domains.
