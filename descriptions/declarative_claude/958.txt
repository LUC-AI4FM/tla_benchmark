# ProtoReals Module Description

This TLA+ module provides an axiomatic specification of the real numbers built upon the Peano naturals. It defines a predicate `IsModelOfReals` that characterizes when a set R with operations Plus, Times, and ordering Leq constitutes a valid model of the real numbers.

The specification requires that the naturals (from the Peano module) embed into R, with successor corresponding to adding one. The reals must form an abelian group under addition with zero as identity, and the nonzero reals must form an abelian group under multiplication with one as identity. Multiplication must distribute over addition. The ordering must be total, antisymmetric, transitive, and compatible with the algebraic operations. Crucially, the specification includes the completeness axiom: every bounded subset has a least upper bound.

The module asserts (as a theorem) that such a model exists and uses CHOOSE to select one, defining Real as its carrier set. It then extends the reals with positive and negative infinity, defining comparison operations that handle these extended values appropriately. Subtraction and division are defined via their inverse relationships to addition and multiplication.

Finally, the module defines exponentiation through a CHOOSE construction that captures the standard properties of powers, including laws for integer and positive real exponents.
