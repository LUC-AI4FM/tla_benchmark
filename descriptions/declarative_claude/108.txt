This TLA+ module specifies a simple system with a single Boolean variable that tests the behavior of existential quantification when used as a value assignment.

The system contains one variable, `x`, which holds a Boolean value.

The initial state sets `x` to TRUE.

Two alternative next-state relations are defined. The first, `Next`, assigns to `x'` the result of evaluating an existential quantifier: it checks whether there exists some value `y` in the set {1, 2} such that `y` is not equal to 1. Since 2 satisfies this condition, the expression evaluates to TRUE, so `x'` becomes TRUE. The second variant, `Next2`, uses the same existential expression as a conditional test rather than a direct assignment, explicitly setting `x'` to TRUE if the condition holds and FALSE otherwise. Both actions produce equivalent behavior since the existential formula is always true.

The module specifies one invariant, `Inv`, which asserts that `x` must always be TRUE. This property should hold given that both the initial state and all transitions maintain `x` as TRUE.

No temporal specification combining initial conditions with the next-state relation is explicitly defined, nor are any fairness conditions or liveness properties specified.
