This TLA+ module defines a library of pure operators for generating HTML document strings. It contains no state, no temporal logic, and no properties to check—it is a utility module intended for use by other specifications.

The module provides string-manipulation helpers and HTML-generation operators. The `HTMLFill` operator performs placeholder substitution in a template string using a sequence of find-replace pairs. A local helper concatenates sequences of strings with separators.

The main operators construct various HTML components as strings. `HTMLDocument` assembles a complete HTML document from a header, body, and scripts. `HTMLHeader` generates the head section including title, links, and an embedded stylesheet built from CSS classes and attributes via `HTMLStyleSheet`, `HTMLClass`, and `HTMLAttribute`. `HTMLBody` wraps content in body tags. Several operators produce structural elements: `HTMLFrame`, `HTMLGridContainer`, `HTMLBox`, `HTMLCircle`, `HTMLText`, and `HTMLSVG` for embedding SVG graphics.

The module also provides JavaScript-related operators: `HTMLScript` and `HTMLScriptFile` for script blocks and external script references, plus `HTMLJSLine`, `HTMLJSLineDash`, `HTMLJSKeyListener`, and `HTMLJSNavigationKey` for generating JavaScript code strings, particularly for drawing lines between elements and handling keyboard navigation.

There are no CONSTANTS, VARIABLES, initial states, actions, fairness conditions, or invariants. This is purely a functional library for HTML string construction.
