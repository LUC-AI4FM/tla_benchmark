This TLA+ module tests the equality semantics of various function representations in TLA+. It verifies that different syntactic forms for defining equivalent functions are recognized as equal by the model checker.

The specification uses a single variable x, which is initialized to 1 and never changes. Three uninterpreted constants a, b, and c are declared for use in some tests. Several helper function definitions are provided: f defines a function over a Cartesian product using explicit indices, g defines the same function using tuple notation, h defines a nested (curried) function, and m maps integers to pairs.

The core logic resides in the invariant Inv, which executes a series of equality tests during model checking. Each active test compares two function representations that should be equal, triggering an assertion failure if they differ or printing success otherwise. The active tests verify that a function defined over an unordered set equals a tuple representation, that functions defined over different but equivalent domains are equal, and that an empty function equals an empty tuple. Several additional tests are commented out, covering record syntax equality, EXCEPT modifications, function set comprehensions, and comparisons between the helper functions.

The temporal specification is trivial: the system initializes x to 1 and stutters indefinitely. The model configuration declares the invariant Inv, causing all equality tests to execute during state exploration.
