The MPFactorial module specifies a concurrent factorial computation using three parallel processes that each compute 5! through a recursive procedure.

The system models three processes: two instances of "Main" (processes 1 and 2) and one "Minor" process (process 3). Each process independently calls a recursive factorial procedure and stores its result in a shared array.

The VARIABLES include: `result`, an array mapping process identifiers 1 through 3 to computed values (initially all 1); `pc`, tracking each process's program counter; `stack`, maintaining call stacks for the recursive procedure; `arg1`, the procedure's argument for each process; and `u`, an unused local variable. The CONSTANT `defaultInitValue` provides initial values for procedure parameters.

The `FactProc` procedure recursively computes factorial by multiplying the current result by the argument and recursing with a decremented value until reaching zero. Each process calls this procedure with argument 5, then asserts that its result equals 120.

The temporal specification combines an initial state, a next-state relation allowing any enabled process action or stuttering upon termination, and weak fairness conditions on all process and procedure actions. This ensures each process eventually makes progress.

The module checks a liveness property `Termination`, requiring all processes eventually complete. It also declares an invariant asserting `result` is a natural number, though this appears incorrectly typed since `result` is actually a function, not a single natural.
