This TLA+ module is a test case designed to verify correct handling of local operator definitions and variable scoping, specifically addressing issue #576 in the TLA+ tooling.

The module defines three operators that test potential name collision scenarios when local definitions are inlined by the SANY importer.

The first operator, Foo, is declared LOCAL and simply binds its argument to a local name before returning it. The second operator, Bar, defines its own local variable with the same name as the one inside Foo, then calls Foo. This tests whether the importer correctly maintains separate scopes when inlining Foo's definition, avoiding collision between the two identically-named local bindings.

The third operator, Baz, similarly defines a local variable with the same name, then calls Foo twice within a tuple. This verifies that multiple instantiations of the same local operator within a single expression do not produce naming conflicts.

The module contains no variables, constants, initial state predicate, next-state relation, temporal specification, fairness conditions, or properties to check. It exists purely as a regression test to ensure the TLA+ tooling properly handles scoping when inlining local operator definitions that contain LET-IN expressions with potentially conflicting names.
