This TLA+ module specifies a collection of theorems about the `MapThenFoldSet` operator, which folds a binary operation over a finite set after applying a mapping function to each element. The module extends the `Folds` and `FiniteSets` modules and provides formal statements of properties without proofs (proofs reside in a separate module).

The theorems establish fundamental properties of the fold operation. The first theorem defines the recursive equation characterizing `MapThenFoldSet`: for an empty set it returns the base value, otherwise it applies the binary operator to the mapped chosen element and the fold of the remaining set. Two corollary theorems separate the empty and non-empty cases for easier application.

Additional theorems address important mathematical properties. One shows that folding over two sets related by a bijection compatible with choice and mapping functions yields identical results. Another proves that mapping functions agreeing on set elements produce equal folds. A type preservation theorem guarantees the fold result belongs to the expected type when the operator and mapping function respect type constraints.

For associative and commutative operators, specialized theorems allow selecting any element for removal rather than the chosen one, and prove that folding distributes over disjoint set union when the base serves as the operator's neutral element. These theorems provide the mathematical foundation for reasoning about fold operations in TLA+ specifications.
