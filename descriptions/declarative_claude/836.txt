This TLA+ module specifies an iterative algorithm for solving the N-queens problem, where N queens must be placed on an N×N chessboard such that no two queens attack each other.

The constant N represents the board size and number of queens. Queens placements are modeled as sequences where the i-th element indicates the column position of the queen in row i. The Attacks predicate checks whether two queens threaten each other via same column or diagonal positions, and IsSolution verifies that no pair of queens in a placement attacks each other.

The algorithm uses two variables: todo, a set of partial solutions still being explored, and sols, the set of complete solutions found. A program counter pc tracks execution state. Initially, todo contains only the empty sequence, and sols is empty.

The main action nxtQ repeatedly selects a partial solution from todo, computes all valid column extensions that avoid attacks, and either adds complete solutions to sols or adds partial extensions back to todo. The algorithm terminates when todo becomes empty.

The TypeInvariant ensures todo contains sequences shorter than N and sols contains sequences of exactly length N. The main Invariant asserts that sols always contains only valid solutions and, upon termination, contains all solutions. The Termination property asserts eventual completion. A liveness specification LiveSpec adds weak fairness to guarantee progress. NoSolutions is an auxiliary property used to make TLC display computed solutions.
