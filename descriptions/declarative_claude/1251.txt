This TLA+ module provides utility operators for pseudo-random subset selection, primarily designed to support inductive invariance checking in TLC model checking.

The module defines three operators for randomized set operations. **RandomSubset** takes a number k and a set S, returning a randomly chosen subset of S containing exactly k elements. **RandomSetOfSubsets** takes parameters k, n, and S, producing a pseudo-randomly chosen collection of subsets of S (a subset of the powerset of S). Each subset T in the result is constructed so that each element of S has probability n/Cardinality(S) of inclusion, yielding subsets with an average size of n. The parameter k controls how many such subsets are generated, though duplicates may reduce the final count below k. **TestRandomSetOfSubsets** is a diagnostic operator that returns a sequence of five cardinality measurements from repeated calls to RandomSetOfSubsets, helping users calibrate parameters.

The formal definitions use CHOOSE expressions, but TLC overrides these with Java implementations that perform actual pseudo-random selection. An important behavioral note: in breadth-first search mode, random choices are deterministic based on the originating state, ensuring reproducible error traces. In simulation mode, choices are state-independent.

This module contains no variables, temporal properties, or invariants—it is purely a library of operators for use within other specifications.
