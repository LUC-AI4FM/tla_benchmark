The module MsgSetOld models a simple message-passing system where two kinds of messages — integer messages and string messages — can be added to and removed from a shared message set, with flags tracking whether specific values have been observed.

There are three variables: `msgs`, a set of records representing the current pool of unprocessed messages; `found3`, a Boolean flag; and `foundC`, a Boolean flag. Messages are either of type `"int"` carrying an integer field `x` drawn from `{1,2,3}`, or of type `"str"` carrying a string field `y` drawn from `{"a","b","c"}`. The system starts with an empty message set and both flags set to `FALSE`. The four actions are `AddIntMsg`, which nondeterministically adds an integer message; `AddStrMsg`, which nondeterministically adds a string message; `CheckIntMsg`, which removes an integer message from the set and sets `found3` to `TRUE` if its `x` field equals `3`; and `CheckStrMsg`, which removes a string message and sets `foundC` to `TRUE` if its `y` field equals `"c"`. No fairness conditions or temporal properties are stated. The only declared property is the type invariant `TypeOk`, asserting that `msgs` remains a subset of the full `Messages` set. The module has no model-checking configuration and appears to serve primarily as a small illustrative or test example for typed message sets.
