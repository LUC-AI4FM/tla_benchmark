This TLA+ module serves as a test case for the TLAPS (TLA+ Proof System) to verify that the proof directives USE and HIDE correctly reject invalid arguments.

The module declares a single theorem named "bar" that asserts the tuple containing 1 and 2. This theorem is not meant to represent meaningful mathematical content but exists to test proof system behavior.

The specification tests three error conditions related to proof directives. First, a module-level USE directive attempts to reference both the theorem "bar" and an invalid selector expression "bar!1", which should trigger an error since USE cannot contain arbitrary expressions as facts. Second, a module-level HIDE directive attempts to hide both the theorem "bar" and the literal value TRUE, which should also produce an error for the same reason.

Third, within the proof of theorem "xx" (which trivially asserts false from true), a USE directive at proof step 1.2 attempts to include TRUE as a literal fact and "xx!1" as a selector expression, both of which should be flagged as errors.

The module contains no variables, constants, state transitions, or temporal properties. It exclusively tests the syntactic and semantic constraints on proof directive arguments in the TLA+ proof system.
