This module contains machine-checked proofs for safety properties of a parallel reachability algorithm specified in the ParReach module.

The module proves two main results using the TLA+ Proof System (TLAPS). The first lemma establishes that the invariant Inv is preserved by the specification: it shows that Init implies Inv, and that Inv combined with any next-state transition maintains Inv in the successor state. The proof relies on assumptions about the root node and successor function from the parent module.

The second theorem proves that the parallel algorithm refines Misra's sequential reachability algorithm. Specifically, it demonstrates that the parallel specification implies both the initial condition of the refined specification and that every transition of the parallel algorithm corresponds to either a valid transition of Misra's algorithm or a stuttering step. The refinement uses mapping functions pcBar and vrootBar to relate the parallel state to the sequential specification's state.

The proofs proceed by case analysis over the algorithm's actions (labeled a, b, and c), the termination condition, and stuttering steps. Key to the refinement proof is showing that certain parallel transitions—particularly when multiple processes are active—map to stuttering steps in the abstract specification while the overall behavior remains faithful to the sequential algorithm's safety properties.
