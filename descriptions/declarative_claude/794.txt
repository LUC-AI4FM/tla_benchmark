This TLA+ module specifies the Knuth-Yao algorithm for generating a fair six-sided die roll using only fair coin flips. The algorithm uses a binary tree structure where each internal node represents a coin flip, and leaves represent the six possible outcomes.

The module extends DyadicRationals to track probabilities as dyadic fractions (rationals with power-of-two denominators).

Three variables track the system state: `p` represents the probability of reaching the current state, `state` identifies the current position in the decision tree, and `flip` records the most recent coin toss result.

The `Transition` function defines a finite automaton with seven internal states (s0 through s6) and six terminal states representing die outcomes 1 through 6. Each internal state transitions based on the coin flip result (heads or tail).

Initially, the system starts in state s0 with probability one and an arbitrary coin flip. The next-state relation applies when not in a terminal state: it follows the transition function based on the current flip, halves the probability (reflecting the coin toss), and non-deterministically chooses the next flip.

The temporal specification includes weak fairness on the Next action, ensuring the algorithm eventually terminates rather than stuttering indefinitely.

A commented theorem suggests the algorithm converges: for any positive probability threshold, the system eventually either reaches a terminal state or the remaining probability falls below that threshold.
