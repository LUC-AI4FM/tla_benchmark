This TLA+ module specifies a one-place asynchronous communication channel using a four-phase handshake protocol between a sender and receiver.

The system models message passing through a single channel record containing three fields: a data value, a ready bit, and an acknowledgment bit. The constant Data represents the set of possible message values that can be transmitted.

The channel variable maintains the current state with the data payload and two binary control signals. The type invariant constrains the channel to valid combinations of these fields.

Initially, the channel satisfies the type invariant with the ready and acknowledgment bits equal, indicating an idle state with no pending message.

Two actions govern state transitions. The Send action allows transmitting data when the channel is idle (ready equals acknowledgment); it places new data and toggles the ready bit. The Rcv action models reception when a message is pending (ready differs from acknowledgment); it toggles the acknowledgment bit to complete the handshake.

The temporal specification permits stuttering steps where the channel remains unchanged, following standard TLA+ conventions for composition.

The module includes a theorem stating that the specification maintains the type invariant globally—the channel always contains valid data and binary control signals. No liveness properties or fairness conditions are specified, so the system may stutter indefinitely.
