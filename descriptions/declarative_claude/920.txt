This TLA+ module specifies an asynchronous communication channel using a four-phase handshake protocol between a sender and receiver.

The system models a single channel represented by the variable `chan`, which is a record containing three fields: `val` (the data being transmitted, drawn from the constant set `Data`), `rdy` (a ready bit), and `ack` (an acknowledgment bit). Both `rdy` and `ack` are binary signals toggling between 0 and 1.

The initial state requires the type invariant to hold and that the ready and acknowledgment bits are equal, indicating an idle channel ready for transmission.

Two actions define the system behavior. The `Send` action allows the sender to transmit data when the channel is idle (ready equals acknowledgment) by placing a value on the channel and toggling the ready bit. The `Rcv` action allows the receiver to acknowledge receipt when data is pending (ready differs from acknowledgment) by toggling the acknowledgment bit.

The temporal specification combines the initial condition with a next-state relation permitting either sending any data value, receiving, or stuttering.

The module includes a theorem stating that the specification preserves the type invariant—ensuring the channel always maintains valid structure with appropriate data and binary control signals throughout execution.
