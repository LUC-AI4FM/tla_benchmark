This module serves as a type-annotated wrapper around the `SyncTerminationDetection` specification, designed for use with the Apalache model checker. It provides Apalache-specific type annotations while instantiating the original specification to keep that module free of tool-specific syntax.

The specification models a synchronous termination detection algorithm for a distributed system with N nodes.

**Constants and Variables:**
- `N` is an integer constant representing the number of nodes in the system (set to 7 in the model-checking configuration).
- `active` is a function mapping node identifiers (integers) to booleans, indicating whether each node is currently active.
- `terminationDetected` is a boolean flag indicating whether the system has detected that all nodes have terminated.

**Specification Structure:**
The module uses `INSTANCE` to incorporate all definitions from `SyncTerminationDetection`, inheriting its initial state predicate, next-state relation, and any fairness conditions defined there.

**Properties Checked:**
The configuration verifies two invariants:
- `TypeOK`: A type correctness invariant ensuring variables maintain their expected types.
- `TDCorrect`: A safety property ensuring the termination detection mechanism is correct—that termination is only detected when all nodes are genuinely inactive.

The specification checks these properties under the `Spec` temporal formula from the instantiated module.
