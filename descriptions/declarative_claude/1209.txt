This TLA+ module is a test specification designed to verify the correctness of Leibniz operator checking in the TLA+ tooling. It tests the rule that non-Leibniz operators (those whose arguments appear primed or within temporal contexts) cannot be substituted for constant operators during module instantiation.

The module declares a single variable x and defines several operators with varying Leibniz properties. Leibniz operators like `Leibniz` and `Leibniz2` reference the primed variable x but not their parameters in primed form. Non-Leibniz operators like `NonLeibniz` and `NonLeibniz2` prime their own parameters, making them non-Leibniz with respect to those arguments.

The specification creates multiple parameterized instances of an external module `test212b` with different substitutions for variable y, including uses of the ENABLED operator which affects Leibniz properties.

The core test consists of ten instantiations of module `test212a`, which expects constant operators Op and Op2. Five instantiations (L1 through L5) are marked as legal, substituting only Leibniz operators. Five instantiations (I1 through I6) are marked as illegal, each attempting to substitute at least one non-Leibniz operator where a constant operator is required.

This module contains no temporal specification, invariants, or properties to check—it exists solely to test static semantic checking of operator substitution rules during module instantiation.
