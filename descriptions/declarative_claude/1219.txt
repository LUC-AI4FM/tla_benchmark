This TLA+ module is a test suite for the UNCHANGED operator in TLA+, verifying that the model checker correctly evaluates UNCHANGED across various expression forms.

The system has two variables: x, initialized as a function mapping indices 1 through 3 to their respective values (so x[1]=1, x[2]=2, x[3]=3), and y, initialized to 1.

The next-state relation is a disjunction of eleven test cases. Most tests keep both variables unchanged while checking that UNCHANGED correctly recognizes stability of various derived expressions: individual array elements, records constructed from array elements, existential and universal quantifications over array elements, CHOOSE expressions, set comprehensions, set filters, and the domain of the array. Two tests (10 and 11) increment y from 1 to 2 while keeping x unchanged, then verify that UNCHANGED still correctly identifies unchanged expressions involving x or sets containing the old value of y.

Each test prints a success message if the UNCHANGED condition evaluates as expected, or triggers an assertion failure otherwise. This validates that UNCHANGED works properly not just on variables directly but on complex expressions derived from those variables.

The invariant is trivially TRUE, meaning the specification imposes no safety constraints beyond the implicit requirement that all assertions pass during model checking.
