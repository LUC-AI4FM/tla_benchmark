This TLA+ module is a test suite for the Graphs library module. It contains no system model, state transitions, or temporal properties—only static assertions evaluated at specification-load time.

The module extends the Graphs library and TLCExt for testing utilities. It uses ASSUME statements with AssertEq to verify that various graph-theoretic operators return expected results.

The tests cover the following operators from the Graphs module:

**SimplePath**: Verifies computation of simple paths in graphs, including empty graphs and graphs with directed edges.

**AreConnectedIn and ConnectionsIn**: Checks connectivity queries between nodes, ensuring both operators agree on reachability for all node pairs in a six-node directed graph.

**GraphUnion**: Confirms that combining two graphs merges their nodes and edges correctly.

**IsBipartiteWithPartitions**: Tests bipartite graph verification with specified partitions.

**IsDag**: Validates directed acyclic graph detection, checking that graphs with self-loops or cycles return false while acyclic structures return true.

**Successors, AllSuccessors, Predecessors, AllPredecessors**: Tests immediate neighbor queries in both directions.

**Ancestors and Descendants**: Verifies transitive closure computations for reachability in both directions.

**Roots and Leaves**: Tests identification of nodes with no incoming edges (roots) and no outgoing edges (leaves).

The module defines no CONSTANTS, VARIABLES, or behavioral specification—it serves purely as a validation suite for the Graphs library's operators.
