This TLA+ module provides a mathematical specification of undirected graphs and operations on them. Unlike directed graph representations, edges are modeled as unordered two-element sets of nodes, ensuring symmetry.

The module defines predicates for recognizing valid undirected graphs. **IsUndirectedGraph** checks that a structure has node and edge components where each edge is a set of two nodes. **IsLoopFreeUndirectedGraph** additionally requires that the two nodes in each edge be distinct, prohibiting self-loops. **UndirectedSubgraph** generates all valid undirected subgraphs of a given graph.

Path-related operators define sequences of nodes connected by edges. **Path** captures all non-empty node sequences where consecutive nodes share an edge. **SimplePath** restricts this to paths where no node appears more than once, bounded by the graph's node count.

The **ConnectedComponents** operator computes the connected components using a fold operation: starting with each node in its own singleton component, it iterates over edges and merges components whenever an edge connects nodes in different components.

Two connectivity predicates are provided: **AreConnectedIn** tests whether two nodes belong to the same connected component, and **IsStronglyConnected** checks whether the entire graph forms a single connected component.

This module contains no variables, temporal operators, or model-checking configuration—it serves as a library of graph-theoretic definitions.
