The module specifies Dijkstra's distributed termination detection algorithm for a ring of N nodes, known as EWD 840. The system models a ring of nodes (indexed 0 to N−1) where nodes can be active or inactive and exchange messages, alongside a token-passing mechanism that detects when all computation has ceased.

The four variables are: `active`, a mapping from nodes to booleans indicating whether each node is currently computing; `color`, a mapping from nodes to either "white" or "black" encoding whether a node has sent a message in the "wrong" direction since last whitened; `tpos`, the current position of the token; and `tcolor`, the color of the token. Initially, the token is black and all other variables may take any type-correct values.

The next-state relation is split into System and Environment actions. System actions implement the detection algorithm: node 0 initiates a new probe (resetting the token to white) when it holds a black token or is itself black, and any other node holding the token passes it leftward, potentially blackening it and whitening itself. Environment actions model the underlying computation: an active node may send a message to any other node (blackening itself if it sends to a higher-numbered node, i.e., against the token direction), or any active node may spontaneously deactivate. The temporal specification `Spec` requires weak fairness on System actions, ensuring the token-passing protocol continues making progress. The invariant `TypeOK` asserts well-typedness of all variables.
