This module specifies the Alternating Bit Protocol (AB2), a reliable data transmission protocol over lossy channels, using ordered pairs instead of records for messages.

The constant **Data** represents the set of possible data values to transmit. Messages in **Msgs** are pairs of a data value and a single bit (0 or 1).

Four variables model the system state: **AVar2** holds the sender's current message (data plus alternating bit), **BVar2** holds the receiver's most recently accepted message, **AtoB** is a sequence representing the channel from sender to receiver, and **BtoA** is a sequence representing the acknowledgment channel from receiver to sender.

Three concurrent processes execute: Process **A** (sender) either appends its current message to AtoB or, when an acknowledgment arrives matching its current bit, selects new data and flips its bit, then removes the acknowledgment. Process **B** (receiver) either sends an acknowledgment containing its current bit or, when a message arrives with a different bit than expected, accepts the message and updates its state, then removes the message from the channel. Process **LoseMsgs** models unreliable channels by nondeterministically removing any message from either channel.

The specification **Spec** combines the initial state with stuttering-allowed next-state transitions. No fairness conditions or explicit safety/liveness properties are declared in this module; only the basic protocol behavior is specified.
