This module provides a machine-checked proof that the Die Hard water jug puzzle specification maintains type correctness as an invariant.

The specification extends the base DieHard module, which models the classic puzzle involving two jugs—a large jug with 5-gallon capacity and a small jug with 3-gallon capacity—where the goal is to measure exactly 4 gallons. The module also extends TLAPS, the TLA+ Proof System library.

The proof establishes the theorem TypeCorrect, which states that the specification implies the type invariant TypeOK holds in all reachable states. The type invariant constrains the big jug contents to the range 0 through 5 and the small jug contents to the range 0 through 3.

A helper lemma MinNat establishes properties of the minimum function over natural numbers, which is essential for reasoning about the pouring actions.

The main proof proceeds by temporal logic induction. First, it shows the initial state satisfies TypeOK. Then it demonstrates that each possible action—filling either jug, emptying either jug, pouring from small to big, pouring from big to small, or stuttering—preserves the type invariant. The pouring cases require the most detailed reasoning, using the MinNat lemma to show the resulting water levels remain within valid bounds.

The module explicitly notes that NotSolved, the puzzle's search property, is not proved here since it is meant to be violated when a solution is found.
