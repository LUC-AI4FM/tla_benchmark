This module provides machine-checked proofs for properties of an asynchronous termination detection algorithm specified in the imported AsyncTerminationDetection module.

The specification models a distributed system where nodes can be active or inactive, may send and receive messages, and where a separate mechanism detects when all nodes have terminated and no messages remain in transit.

The module proves four main results using the TLAPS proof system. First, TypeCorrect establishes that type correctness is an inductive invariant: if the system starts in a valid initial state and only takes valid transitions, the type invariant TypeOK always holds.

Second, the Safety theorem proves that the Safe property is invariant—termination detection never signals completion incorrectly while activity or pending messages exist.

Third, the Stability theorem establishes Quiescence, meaning once the system reaches a terminated state (all nodes inactive with no pending messages), it remains terminated forever. This captures that termination is irreversible.

Fourth, the Liveness theorem proves that under the specification's fairness conditions, if the system has terminated but detection has not yet occurred, detection will eventually happen. The proof uses an intermediate lemma characterizing when the DetectTermination action is enabled.

All proofs proceed by showing the relevant properties are inductive invariants or by applying temporal logic reasoning through PTL combined with the established type correctness.
