This TLA+ module provides Apalache-compatible type annotations for a spanning tree specification defined in a separate SpanTree module, which it imports via INSTANCE.

The specification models a distributed spanning tree construction algorithm over a graph. The system operates on a set of nodes connected by edges, with a designated root node from which the spanning tree grows.

**Constants:** `Nodes` represents the set of all nodes in the graph. `Edges` contains the undirected edges as two-element sets of nodes. `Root` identifies the starting node for tree construction. `MaxCardinality` bounds the maximum number of nodes, used for model checking.

**Variables:** `mom` maps each node to its parent in the spanning tree. `dist` records each node's distance from the root.

**Concrete instantiation:** The configuration uses a three-node graph where nodes are connected linearly: n1 connects to n2, and n2 connects to n3, with n1 as the root.

**Checked properties:** The model checks `TypeOK` as an invariant, ensuring variables maintain their expected types and value ranges. The specification `Spec` from the imported SpanTree module governs system behavior. Deadlock checking is disabled, indicating the algorithm may legitimately terminate when the spanning tree is complete.

The module demonstrates how to add Apalache type annotations to an existing specification without modifying the original.
