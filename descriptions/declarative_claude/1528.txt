This specification extends the SpanTree module by treating the graph's edge set as a variable rather than a constant, enabling exhaustive testing of a spanning tree algorithm across all possible undirected graphs over a fixed node set.

The system models a distributed algorithm that computes a spanning tree rooted at a designated node. Each node maintains two values: its parent in the tree (mom) and its distance from the root (dist). The algorithm works by having nodes discover shorter paths to the root through their neighbors.

The constants include Nodes (the set of graph vertices), Root (the spanning tree's root), and MaxCardinality (an upper bound used to represent infinite distance for unreachable nodes).

The variable Edges is initialized non-deterministically to any valid set of undirected edges between nodes. Variables mom and dist track each node's parent and distance respectively. Initially, every node is its own parent, the root has distance zero, and all other nodes have distance MaxCardinality.

The next-state relation allows a node to update its distance and parent when it discovers a neighbor with a strictly smaller distance, adopting that neighbor as its parent. The edge set remains constant after initialization.

The specification includes weak fairness on the next-state action. Safety asserts that when no further steps are possible, every node either is the root, is unreachable, or has a valid parent at distance one less. Liveness asserts this postcondition is eventually reached.
