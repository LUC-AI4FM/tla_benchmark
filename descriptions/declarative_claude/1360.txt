This TLA+ module specifies a minimal system with a single boolean variable that can change arbitrarily between true and false values.

**Variable:**
The specification declares one variable `b`, which represents a boolean state.

**Temporal Specification:**
The `Spec` formula defines the complete system behavior through a conjunction of two parts:
1. An initial condition requiring `b` to be a boolean value (either TRUE or FALSE)
2. A next-state relation wrapped in the temporal "always" operator (square brackets), stating that in every step, the new value of `b` must also be a boolean, with stuttering steps (where `b` remains unchanged) permitted

This specification is notably permissive: it allows `b` to freely transition between TRUE and FALSE in any pattern, remain constant indefinitely, or alternate in any sequence. There are no fairness conditions, meaning the system may stutter forever without making progress.

**Properties:**
The module contains no explicit invariants or liveness properties to check. It serves as an abstract specification that permits all possible boolean behaviors, likely created as a test case or minimal example related to GitHub issue 1198 in the TLA+ tools repository.
