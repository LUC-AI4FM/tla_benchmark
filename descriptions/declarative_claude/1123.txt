This module serves as an Apalache-compatible wrapper around the TCommit specification, which models a transaction commit protocol for distributed resource managers.

The specification models a system where multiple resource managers must reach consensus on whether to commit or abort a transaction. The constant RM represents the set of participating resource managers, instantiated with three concrete values for model checking. The variable rmState maps each resource manager to its current state, represented as a string.

By instantiating TCommit, this module inherits the complete behavioral specification from that module, including the initial state predicate, the next-state relation defining how resource managers transition between states, and any fairness conditions defined there. The type annotations provided here enable the Apalache model checker to perform type-safe verification.

The model-checking configuration specifies TCSpec as the temporal specification to verify. Two invariants are checked: TCTypeOK, which ensures the state variable maintains proper typing throughout execution, and TCConsistent, which verifies the core safety property that resource managers never reach inconsistent commit decisions. Deadlock checking is disabled, indicating that terminal states where no further transitions are possible are acceptable behavior in this protocol, representing completed transactions.
