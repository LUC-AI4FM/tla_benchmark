This TLA+ module serves as a regression test for the exponentiation operator (a^b) in the Apalache model checker, specifically addressing a reported bug.

The specification models iterative exponentiation computation using three integer variables: `base` represents the fixed base number, `power` tracks the current exponent value, and `exp` holds the computed result of raising the base to the power.

The initial state sets the base to 3, the power to 1, and the exponential result to 3, establishing that 3^1 equals 3.

The next-state relation increments the power by one and multiplies the current exponential result by the base, while keeping the base unchanged. This effectively computes successive powers of the base through repeated multiplication rather than direct exponentiation.

The invariant `Inv` asserts that at every reachable state, the computed value `exp` equals the base raised to the current power using the built-in exponentiation operator. This property verifies that the iterative multiplication approach correctly tracks the mathematical definition of exponentiation.

The specification contains no fairness conditions or liveness properties. It serves purely to verify that the exponentiation operator behaves correctly when compared against an equivalent iterative computation.
