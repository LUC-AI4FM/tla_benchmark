This TLA+ module is a model-checking configuration for verifying an ERC20 token contract specification using the Apalache model checker.

The module instantiates a separate ERC20 specification with concrete parameters for verification. It models a token system with three participant addresses: Alice, Bob, and Eve. The system tracks token balances and spending allowances between accounts, along with pending and executed transactions.

The specification uses five state variables: `balanceOf` maps each address to an integer token balance; `allowance` maps pairs of addresses to approved spending amounts (owner, spender); `pendingTransactions` holds a set of transactions awaiting execution; `lastTx` records the most recently executed transaction; and `nextTxId` provides unique transaction identifiers.

Constants define the address set, allow amounts to range over all integers, and initialize each address with a balance of 100 tokens.

The module imports type definitions from ERC20_typedefs and inherits all behaviors, actions, and properties from the main ERC20 module through the INSTANCE statement. This configuration enables Apalache to explore the state space with these specific bindings, checking whatever invariants and temporal properties the parent ERC20 specification defines for token transfer and approval operations.
