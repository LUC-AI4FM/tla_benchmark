This TLA+ module specifies a system demonstrating action composition, where two actions are combined using the sequential composition operator.

The system models state transitions over a single natural number variable x, which starts at zero. Two actions, A and B, define possible state changes. Action A can transition x from 0 to any value in {1, 2, 3}, or from 4 to 5. Action B can transition x from values in {1, 2} to values in {2, 4}, or from 5 to 6.

The next-state relation uses TLA+'s action composition operator (·) to define Next as A composed with B. This means a single Next step represents the sequential execution of A followed immediately by B, where B's precondition must be satisfied by A's result. Effectively, this creates atomic transitions that chain through an intermediate state invisible to the specification.

The temporal specification allows stuttering steps where x remains unchanged. The module checks several properties: Inv asserts x always belongs to {0, 1, 2, 4, 6}; Inv2 states that when x reaches 3 or higher, a Next step must remain enabled; Prop verifies that the reverse composition B·A never occurs as a step; and Prop2 confirms the standard next-state behavior. An action constraint requires non-stuttering Next steps.
