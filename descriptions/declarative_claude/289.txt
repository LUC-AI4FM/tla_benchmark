The `FoldExcept` module is a performance-measurement specification for the Apalache model checker, designed to compare two implementation styles of the same logical behavior in the presence of a known anti-pattern involving iterated `EXCEPT` updates.

The module models a set of named processes (`Proc`), each holding an integer clock value in `clocks` (a function from process names to integers), and a pairwise drift table in `drift` (a function from pairs of process names to integers). In `Init`, the clocks are initialized to arbitrary natural numbers and the drift is set to the pairwise differences of those clocks.

Two next-state actions model uniform clock advancement by a positive integer delta. `NextFast` constructs the updated `clocks` and `drift` functions directly via comprehension, without iteration. `NextSlow` performs the same update but builds both functions incrementally using `ApaFoldSet` with `EXCEPT`-based update operators applied element by element — one loop over `Proc` for clocks and one loop over `Proc × Proc` for drifts. Both actions are semantically equivalent but differ in how Apalache processes them internally, with the fold-based approach being the slower anti-pattern under investigation. The invariant `DriftInv` asserts that pairwise clock drifts are unchanged after any step, which holds because all clocks advance by the same delta. No temporal specification or fairness conditions are defined; the module serves purely as a benchmarking artifact.
