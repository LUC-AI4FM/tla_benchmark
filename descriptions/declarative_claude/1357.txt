This TLA+ module specifies a simple message-passing protocol between two parties, labeled "A" and "B".

The system models parties that can send "hello" messages to each other over a network. The network is represented as a mapping from directed connections (ordered pairs of distinct parties) to message sequences. Each party has a program counter tracking its state.

The specification uses two variables: `network`, which holds message queues for each possible connection between distinct parties, and `pc`, which tracks each party's current state (either "Start" or "Done").

Initially, all network channels are empty and all parties are in the "Start" state. The main action, `Start`, allows a party in the "Start" state to send a hello message to any other party by placing it in the appropriate network channel, then transitioning to "Done". A `Terminating` action provides a stuttering step when all parties have finished.

The temporal specification combines the initial condition with the next-state relation under stuttering, plus weak fairness conditions on each party's `Start` action. This fairness ensures that if a party can take its start action, it eventually will.

The module checks one liveness property: `Termination`, which asserts that eventually all parties reach the "Done" state.
