The module Bug1682 models a simplified Raft-like leader election protocol over a fixed set of three servers using typed variant messages. It uses the Apalache type-checker's `Variants` extension to define a tagged union type `MESSAGE` with three constructors: `RequestVote`, `Vote`, and `AppendEntries`, each carrying a term number and relevant server identifiers.

The state consists of `currentTerm`, a function mapping each server to its current term (within `0..2`), and `messages`, a set of in-flight messages. In the initial state, all terms are zero and no messages exist. The actions are: `BecomeCandidate`, in which a server increments its term and broadcasts a `RequestVote` message; `Vote`, in which a server responds to a `RequestVote` whose term exceeds its own by sending a `Vote` message and updating its term; and `BecomeLeader`, in which a server that has collected votes from a quorum appends an `AppendEntries` message without changing terms. A `Noop` action allows stuttering. The specification is `Init /\ [][Next]_vars` with no fairness conditions.

The module checks two invariants: `Safety`, asserting that no two different servers send `AppendEntries` in the same term (at-most-one-leader safety); and `Inv`, a stronger inductive invariant combining type correctness, the property that a server never sends messages with terms exceeding its own, uniqueness of votes per server per term, and the at-most-one-leader condition across all terms.
