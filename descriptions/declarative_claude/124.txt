This TLA+ module specifies a system that manipulates sets of integers based on their sums, serving as a regression test for the Apalache model checker's FoldSet operation across different specification components.

The system uses a single variable `values`, which holds a set of integers. The constant N is fixed at 10, defining the range of possible integer elements (1 through 10).

A helper operator Sum computes the sum of all elements in a set using Apalache's FoldSet operation with addition.

The initial state selects any subset of integers from 1 to N whose elements sum exactly to N, and assigns this subset to `values`.

The next-state relation allows the system to transition by selecting a new subset whose sum is strictly less than the current sum of `values`, then updating `values` to this new subset. This creates a decreasing sequence of sums over time.

The invariant Inv asserts that twice the sum of the current values never exceeds N times (N + 1), which equals the sum of all integers from 1 to N multiplied by 2. This bounds the sum of any subset by the total sum of the complete range.

No fairness conditions or liveness properties are specified; the module focuses solely on this safety invariant.
