This suggests the underlying system models two processes that each increment a shared counter, and the invariant verifies that both increments are correctly reflected in the final value.

The model-checking configuration specifies that the `Spec` definition from the extended `Session7` module should be used as the temporal specification to check. The `AddCorrect` invariant is configured to be verified as a safety property—the model checker will explore all reachable states to ensure this condition is never violated.
