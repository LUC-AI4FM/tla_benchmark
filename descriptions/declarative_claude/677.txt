This TLA+ module defines a library of operators for manipulating bags (multisets), extending the standard Bags module with additional functionality. It is not a behavioral specification of a system but rather a collection of reusable operator definitions.

The module provides operators for element manipulation in bags. BagAdd increases an element's multiplicity by one, adding it to the bag if not present. BagRemove decreases an element's multiplicity by one, removing it entirely when the count reaches zero. BagRemoveAll completely removes all occurrences of an element regardless of its multiplicity.

The module also provides folding operations for aggregating over bag elements. MapThenFoldBag is a general-purpose fold that applies a mapping function to each element, then combines results using a binary operator starting from a base value. The fold processes all replicas of each element consecutively. FoldBag is a simplified version that folds directly over elements without mapping.

Two arithmetic convenience operators are built on the fold mechanism: SumBag computes the sum of all elements in a bag (counting multiplicities), and ProductBag computes their product.

The module imports the standard Bags and Integers modules along with a Folds module that provides the underlying MapThenFoldSet operation. No variables, temporal properties, invariants, or behavioral specifications are present—this is purely a library of functional operators for use in other specifications.
