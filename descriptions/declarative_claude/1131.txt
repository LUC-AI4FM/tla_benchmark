This TLA+ module specifies a system that repeatedly transfers a set of messages between two collections across multiple iterations.

The system models four distinct message constants (M0 through M3) forming a message set, plus an Iterations constant controlling how many complete transfer cycles occur.

Four variables track state: "left" holds messages yet to be sent in the current iteration, "right" holds messages already sent, "iteration" counts completed cycles, and "count" tracks total individual message transfers.

The system initializes with all messages in the left set, an empty right set, and both counters at zero.

Two actions define transitions. The Send action non-deterministically selects a message from left, removes it from left, adds it to right, and increments the count. The Iteration action triggers when left is empty and iterations remain; it increments the iteration counter, moves all messages from right back to left, and empties right.

The specification allows stuttering steps and imposes no fairness constraints.

The safety invariant Inv asserts that the union of left and right always equals the original message set, ensuring no messages are lost or created. The temporal property Prop requires this invariant holds in all states.

The module defines symmetry over the message set for state-space reduction during model checking, and specifies a view definition excluding the count variable.
