This TLA+ module specifies a distributed algorithm for computing shortest paths to a root node in an undirected graph. Each node in the graph discovers its minimum distance (depth) from a designated root and identifies its parent on a shortest path.

The constants define a set of Nodes connected by undirected Edges, a designated root node, and MaxNodes bounding the node count. Assumptions ensure edges connect exactly two distinct nodes and that all nodes are reachable from the root.

The variables include msgs, a mapping from directed queue pairs to sequences of depth values representing messages in transit; depth, tracking each node's current known distance from root; and parent, recording each node's predecessor on the shortest path.

Initially, the root broadcasts depth zero to its neighbors, sets its own depth to zero, and other nodes set depth to MaxNodes with themselves as parent. In each step, a node receives a message from an incoming queue. If the received value improves its depth by at least two, it updates its depth and parent, removes the message, and propagates its new depth to other neighbors. Otherwise, it simply discards the message.

The specification combines the initial condition with the next-state relation under stuttering and imposes weak fairness on each node's action, ensuring every enabled node eventually acts. No explicit safety or liveness properties beyond fairness are checked in the configuration.
