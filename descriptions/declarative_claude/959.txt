This TLA+ module defines the basic infrastructure for real numbers by extending the Integers module and importing definitions from a ProtoReals module.

The module establishes three key definitions. First, it defines the set `Real` which represents the set of all real numbers, imported from the ProtoReals module. Second, it defines the division operator `/` for two operands `a` and `b`, delegating to the division operation defined in ProtoReals. Third, it defines `Infinity` as a constant representing mathematical infinity, also imported from ProtoReals.

The ProtoReals module is imported locally, meaning its definitions are not directly exported to modules that extend Reals—only the explicitly defined operators (`Real`, `/`, and `Infinity`) are made available.

This is a foundational library module rather than a behavioral specification. It contains no variables, no state transitions, no temporal formulas, and no properties to check. It serves as a building block for other specifications that need to reason about real-valued quantities, providing the mathematical foundation for real number arithmetic on top of the integer arithmetic already available through the Integers module.
