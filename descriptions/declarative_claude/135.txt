This TLA+ module specifies a library of operators for reasoning about functions, focusing on fundamental mathematical notions such as injection, surjection, and bijection. It is a typed version of the Functions module from the TLA+ Community Modules.

The module defines several operators without any constants or variables, serving purely as reusable definitions. The **Restrict** operator restricts a function to a given subset of its domain. The **Range** operator computes the set of all values that a function maps to. The **Inverse** operator constructs an inverse function from a target set back to a source set, selecting a preimage when one exists.

The **IsInjective** predicate determines whether a function is injective, meaning distinct domain elements map to distinct range elements. The **Injection** operator yields the set of all injective functions between two sets. Similarly, **Surjection** produces the set of all functions where every element in the target set has at least one preimage, and **Bijection** gives functions that are both injective and surjective.

Three existence predicates—**ExistsInjection**, **ExistsSurjection**, and **ExistsBijection**—test whether the respective function sets are nonempty, indicating whether such mappings between two sets are possible.

The module contains no state transitions, temporal formulas, or properties to check; it provides foundational definitions for use in other specifications.
