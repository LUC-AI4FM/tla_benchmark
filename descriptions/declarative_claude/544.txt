This TLA+ module specifies a concurrent increment algorithm where N processes each attempt to increment a shared variable x by one, using a binary semaphore for mutual exclusion.

The system models N concurrent processes that follow a classic lock-protected read-modify-write pattern. The constant N represents the number of processes and must be a positive natural number. The global variables are x (the shared counter, initially 0) and sem (the semaphore, initially 1 indicating available). Each process also has a local variable t for temporarily storing the read value.

Each process executes four steps: first, it acquires the lock by waiting until the semaphore equals 1, then atomically setting it to 0; second, it reads x into its local variable t; third, it writes t+1 back to x; finally, it releases the lock by setting the semaphore back to 1.

The semaphore ensures mutual exclusion—only one process can hold the lock at a time, preventing concurrent access to the critical section. The next-state relation allows any process to take a step or allows stuttering when all processes have terminated.

The specification includes a temporal formula Spec combining initialization with the next-state relation. A termination property is defined asserting that eventually all processes reach the Done state, though no fairness conditions are specified in the main specification.
