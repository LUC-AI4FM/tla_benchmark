This module specifies Dijkstra's 1965 mutual exclusion algorithm, the first published solution to the critical section problem for concurrent processes.

The specification models a set of processes (the constant Proc) competing for access to a critical section. Global variables include two boolean arrays, b and c, both indexed by processes and initially true, plus an integer k initialized to an arbitrary process identifier. Each process also has a local variable temp used during the protocol.

The algorithm proceeds through labeled control points. A process signals intent by setting its b entry false, then enters a loop checking whether k equals itself. If not, it sets its c entry true, potentially updates k, and retries. When k matches, the process sets its c entry false and iterates through all other processes; if any has c false, it restarts. Only after confirming all others have c true does it enter the critical section. Upon exiting, it resets c and b to true and proceeds to its non-critical section before looping.

The next-state relation allows any process to take its next step. The main specification Spec includes weak fairness for each process's actions.

The module defines MutualExclusion as a safety invariant ensuring no two processes occupy the critical section simultaneously. Liveness properties include DeadlockFree and DeadlockFreedom, asserting that waiting processes eventually lead to some process entering the critical section. StarvationFree is also defined but noted as not satisfied by this algorithm. An alternative specification LSpec weakens fairness to permit processes to remain indefinitely in their non-critical sections.
