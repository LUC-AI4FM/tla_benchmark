This TLA+ module is a test suite for variant type operators, designed for use with the Apalache model checker. It specifies a trivial state machine that exists solely to enable invariant checking of variant-related operations.

The module extends standard libraries for integers, finite sets, and Apalache-specific features including a Variants library that provides sum type functionality.

The single variable x is an integer that initializes to zero and never changes, creating a static system where the focus is entirely on testing operator behavior through invariants.

The specification defines several variant values with explicit type annotations. VarA and VarB represent variants of a sum type with two possible tags: A containing an integer, or B containing a record with a string field. VarC is a singleton variant tagged C with a record value.

Five test predicates verify different variant operations: TestVariant checks variant set membership; TestVariantFilter tests filtering variants by tag name; TestVariantTag verifies tag extraction; TestVariantGetUnsafe tests unsafe value extraction when the tag matches; and TestVariantGetOrElse confirms that default values are returned when tags do not match.

The AllTests conjunction combines all test predicates into a single invariant. The specification serves as a functional validation that variant operators behave correctly when checked by the model checker.
