This TLA+ module defines type definitions and utility operators for modeling a container orchestration system similar to Docker SwarmKit. It does not specify system behavior itself but provides foundational types used by other modules.

The module defines several constants: **Node** represents the set of worker nodes, **ServiceId** and **TaskId** are types for identifying services and tasks, and **maxReplicas** bounds the number of replicas a service can have. A special value **global** indicates a service should run one replica per node.

**ServiceSpec** defines service descriptions with a replica count (or global mode) and a removal flag. **Task** records contain an identifier, owning service, current status, desired state, assigned node, and slot number.

The module establishes a strict ordering of task states through their lifecycle: new, pending, assigned, accepted, preparing, ready, starting, running, then terminal states (complete, shutdown, failed, rejected, remove, orphaned). Tasks can only transition to states with higher rank in this sequence. Comparison operators allow checking state precedence.

Key utility operators include **Runnable** to check if a task could still reach running state, **VSlot** for computing virtual slots (actual slot for replicated services, node for global services), and **Id** for generating unique task identifiers as tuples to reduce model-checking state space compared to simple task IDs.
