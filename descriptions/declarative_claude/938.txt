This module specifies a liveness-enhanced version of an internal memory system, extending the base InternalMemory module.

The specification models a memory system with multiple processors that can issue requests and receive responses. The system state comprises four variables: memInt (the memory interface), mem (the memory contents), ctl (control state for each processor), and buf (buffer for each processor).

The module defines two equivalent formulations of liveness conditions. The primary liveness condition (Liveness2) requires weak fairness on the disjunction of Do and Rsp actions for every processor p in the set Proc. This ensures that if a processor can either perform a memory operation or respond, it will eventually do so. An alternative formulation (Liveness) expresses this as separate weak fairness requirements on Do and Rsp actions individually.

The main specification LISpec combines the base internal memory specification ISpec with the Liveness2 fairness condition, creating a complete specification that guarantees progress.

The module specifies a liveness property (LivenessProperty) asserting that whenever any processor p has issued a request (indicated by ctl[p] = "busy"), eventually a response will occur (setting ctl[p] = "rdy"). This is expressed using the leads-to temporal operator.

A theorem states that LISpec implies LivenessProperty, which can be verified by model checking.
