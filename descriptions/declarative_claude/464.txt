This TLA+ module serves as a test suite for the standard Integers module, verifying that basic arithmetic operations and comparisons work correctly in TLC.

The specification uses a single variable x, initialized to zero, which never changes. The system has trivial behavior—it remains in its initial state indefinitely—because the sole purpose is to check arithmetic properties through the invariant.

The invariant Inv consists of a conjunction of seventeen active tests (two are commented out). Each test evaluates an arithmetic expression and either prints a success message or triggers an assertion failure. The tests cover: subtraction yielding a value outside the natural numbers (2 minus 3 not in Nat), multiplication (123 times 345 equals 42435), strict inequalities (less than and greater than), non-strict inequalities (less-than-or-equal and greater-than-or-equal), integer division and modulo operations including the fundamental division identity (a number equals its divisor times the quotient plus the remainder), division and modulo edge cases with divisor one and dividend zero, and integer range construction (verifying that 3..2 produces the empty set while 2..4 produces the set containing 2, 3, and 4).

The model checker verifies Inv as a safety invariant. If any arithmetic test fails, the Assert causes model checking to halt with an error message identifying the failed test.
