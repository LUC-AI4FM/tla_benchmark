This TLA+ module is a model-checking configuration for verifying an Alternating Bit Protocol implementation defined in Session11d against a fair abstract specification.

The module instantiates Session11d and configures it for finite-state model checking. The constant Data is bound to a concrete set containing three values: "Fred", "Mary", and "Ted", representing the data items that can be transmitted.

A state constraint limits model checking by restricting both channel sequences AtoB and BtoA to at most three elements each, keeping the state space finite.

The specification tracks four variables: AVar and BVar represent the sender's and receiver's current message states (each containing data and a bit), while AtoB and BtoA are the communication channels modeled as sequences.

Three invariants are checked. AB_TypeOK ensures type correctness of all variables. AB_Inv captures a key safety property: when the acknowledgment channel is non-empty and its head matches the sender's bit, the sender and receiver must agree on the current message. AB_TwoValsSeq constrains channel contents to have a specific two-value structure where sequences contain at most one transition point between consecutive equal values.

The module instantiates Session11afair as ABSpec and checks that the implementation satisfies ABSpecProperty, verifying that the concrete protocol refines the abstract fair specification through a liveness property.
