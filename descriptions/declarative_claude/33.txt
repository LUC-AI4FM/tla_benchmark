This TLA+ module is a utility library providing option type operators for use with the Apalache model checker. It does not specify a system or algorithm with state transitions, but instead defines reusable operators implementing the option type pattern common in functional programming.

The module extends Apalache and Variants to leverage variant types. It defines an option type alias representing values that are either present (Some) or absent (None).

The core constructors are `Some`, which wraps a value, and `None`, which represents an empty value using the UNIT type. Predicates `IsSome` and `IsNone` test which variant an option holds.

The module provides several functional operators for working with options: `OptionCase` performs case analysis by applying one of two functions depending on the variant; `OptionMap` applies a function to a wrapped value if present; `OptionFlatMap` sequences partial computations that may fail; `OptionGetOrElse` extracts a value with a default fallback.

Conversion operators `OptionToSeq` and `OptionToSet` transform options into singleton or empty collections. `OptionGuess` non-deterministically selects an element from a set, returning None for empty sets. `OptionFunApp` applies a function at an optional index, and `OptionPartialFun` converts a total function into one returning options for undefined inputs.

This module contains no variables, temporal properties, or invariants—it is purely a library of operators.
