This TLA+ module defines a library for working with dyadic rational numbers—fractions whose denominators are powers of two. It provides no system behavior or state transitions; it is purely a collection of operator definitions intended for use by other specifications.

The module represents rational numbers as records with numerator and denominator fields. It includes internal helper operators for divisibility testing, finding divisors, computing greatest common divisors, and reducing fractions to lowest terms.

The primary exported operators include: a predicate to test whether a rational is dyadic (denominator equals some power of two), constants for zero and one, an addition operator that exploits the property that dyadic rationals share power-of-two denominators to simplify finding common denominators, a halving operator that doubles the denominator, and a pretty-printing operator for display purposes.

The addition operation finds the larger denominator as the least common multiple shortcut, scales both operands appropriately, sums the numerators, and reduces the result. The halving operation simply doubles the denominator and reduces.

This module contains no variables, no initial state, no next-state relation, no temporal formula, and no properties or invariants to check. It serves as a reusable mathematical utility library rather than a behavioral specification.
