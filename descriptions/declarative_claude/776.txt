This TLA+ module specifies a Conflict-free Replicated Data Type (CRDT) implementing a distributed grow-only counter using a gossip protocol.

The system models a finite set of nodes, each maintaining a vector of counters indexed by all nodes. The single variable `counter` is a two-dimensional array where `counter[n][o]` represents node `n`'s view of node `o`'s count.

Two actions define the system dynamics. The Increment action allows a node to increase its own counter entry. The Gossip action enables one node to send its state to another, where the recipient takes the pointwise maximum of both views, ensuring monotonic growth without conflicts.

The specification defines several properties. TypeOK ensures counters map nodes to natural numbers. Safety asserts each node's view of its own count is at least as large as any other node's view of that count. Monotonicity requires counter values never decrease across transitions.

The fairness condition combines weak fairness on all gossip actions with an assumption that eventually only gossip actions occur indefinitely—meaning increments happen only finitely many times. Under these conditions, the Convergence property states that repeatedly, all nodes will have identical counter states, capturing eventual consistency characteristic of CRDTs.
