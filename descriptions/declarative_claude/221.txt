This TLA+ module specifies a simple set manipulation system where elements can be added to or removed from a set, used as a regression test for the Apalache model checker's handling of set union operations.

The specification models a system with a constant set called Values and a single variable called set that tracks the current contents. The constant initialization constraint establishes Values as the integers from 0 through 6.

The system begins with an empty set. At each step, the system can perform one of two actions: either add an element by selecting some value not currently in the set and including it via set union, or delete an element by selecting some value currently in the set and removing it via set difference.

The next-state relation permits either action to occur, allowing the set to grow or shrink non-deterministically at each transition.

The invariant checks whether the set is not equal to the complete Values set—essentially asking whether a configuration where all values have been added is reachable. This invariant is expected to be violated, demonstrating that the system can reach a state containing all seven values. As noted in the comments, this complete configuration is reachable in exactly N steps where N equals the cardinality of Values.
