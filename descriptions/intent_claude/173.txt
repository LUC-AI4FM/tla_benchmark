# Specification Request

## System Description

I need a formal specification for a simple two-state oscillating system with two integer counters that continuously swap their values. The system starts with one counter at zero and the other at one, then alternates between these two configurations indefinitely.

## Behavioral Requirements

1. **Initial State**: The system begins with the first counter set to 0 and the second counter set to 1.

2. **State Transitions**: At each step, the two counters exchange their values simultaneously, creating an oscillation pattern (0,1) → (1,0) → (0,1) → ...

## Correctness Properties

The specification should demonstrate and verify complex temporal properties that combine boolean and temporal operators:

### Valid Liveness Property
The system must satisfy a compound temporal property asserting that:
- The first counter repeatedly reaches the value 1 (infinitely often)
- For all states, either the second counter is less than 1, or it will eventually equal 1
- The first counter never permanently stays above 5

### Invalid Liveness Property (Expected to Fail)
Additionally, define a similar property that should be *violated* by the system—specifically one that incorrectly claims the first counter will eventually stay permanently above 5.

## Purpose

This specification is intended as a test case for model checkers to verify correct handling of nested boolean and temporal operators, particularly the interaction between always (□), eventually (◇), and boolean connectives in liveness properties.
