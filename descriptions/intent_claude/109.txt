# Specification Request: Extended Operations on Finite Sets

## Overview

I need a formal specification for a library of utility operations on finite sets, extending the basic finite set operations typically available in formal specification languages. This library should provide commonly needed set computations that arise when modeling systems and algorithms.

## Required Operations

### Fold/Reduce Over Sets
The library must support reducing a set to a single value by iteratively applying a binary operation. This is analogous to fold operations in functional programming. The operation should work correctly regardless of the order in which set elements are processed (i.e., the binary operation is assumed to be commutative and associative). Common instantiations should include:
- **Summation**: Computing the sum of all elements in a set of numbers
- **Product**: Computing the product of all elements in a set of numbers

### Counting with Predicates
Provide an operation to count how many elements in a set satisfy a given predicate, without requiring explicit construction of the filtered set as an intermediate step.

### K-Subsets
Support efficient generation of all subsets of a given set that have exactly k elements (k-combinations). This is useful for modeling scenarios involving selection of fixed-size groups.

### Extrema
Provide operations to find the maximum and minimum elements of a non-empty finite set of integers.

### Choice Sets (Cartesian-like Selection)
Given a collection of sets, compute all possible sets formed by choosing exactly one element from each input set. This models scenarios where independent choices must be made from multiple option sets.

### Unique Selection
Provide an operation that selects an element from a set satisfying a predicate, but with the additional constraint that exactly one such element must exist. This should fail if zero or more than one element satisfies the condition, providing stronger guarantees than ordinary choice operations.

## Correctness Requirements

1. **Reduce operations** must produce the same result regardless of element processing order when the combining operation is commutative
2. **Sum and Product** must return the appropriate identity element (0 and 1 respectively) for empty sets
3. **K-subset** operation must return exactly those subsets with the specified cardinality; for k outside the valid range, return the empty set
4. **Max/Min** must return an element that is indeed greater/less than or equal to all other elements in the set
5. **Choice sets** must contain exactly the sets representable by selecting one element per input set
6. **Unique selection** must guarantee the selected element is the only one satisfying the predicate
