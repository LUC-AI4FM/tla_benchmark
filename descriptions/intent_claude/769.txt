Specify a Single Producer, Multiple Consumer (SPMC) Disruptor ring buffer in TLA+. The system consists of exactly one producer thread and one or more consumer threads sharing a fixed-size circular ring buffer. The producer publishes events sequentially into the ring buffer, writing each slot exclusively before advancing its write cursor. Each consumer independently reads every published event in order, advancing its own read cursor after each access. The producer must not overwrite a slot until all consumers have advanced past it (i.e., the producer may be at most one full buffer capacity ahead of the slowest consumer).

The specification must enforce two correctness properties. First, a safety property: no data races occur, meaning the producer never writes a slot while any consumer is reading it, and no two threads access the same slot concurrently in conflicting ways. Second, a liveness property: every consumer must eventually read every published value, and the value read at each position must equal the sequence number published there (multicast semantics — all consumers receive all events). Weak fairness should be assumed for consumer actions. The model should be bounded by a maximum number of published events to make model checking feasible.
