# Specification Request: Multiset (Bag) Operations

## System Description

I need a formal specification for a simple multiset (also known as a bag) data structure that supports dynamic addition and removal of elements.

## Requirements

The system should model a multiset over a fixed finite domain of elements (specifically, small non-negative integers). The multiset should support two fundamental operations:

1. **Adding an element**: Any element from the domain can be added to the multiset, increasing its count by one
2. **Removing an element**: Any element from the domain can be removed from the multiset, decreasing its count by one

The system should start with an empty multiset and allow arbitrary sequences of additions and removals.

## Behavioral Notes

- The specification should use standard bag/multiset semantics where elements can appear multiple times
- Both operations should be available at any time for any element in the domain
- This is intended as a basic test or demonstration of multiset operations rather than a complete application

## Purpose

This specification serves as a foundational model for exploring multiset behavior and verifying that the bag operations work correctly in a formal setting. It can be used to test properties of multiset implementations or as a building block for more complex specifications that require multiset semantics.
