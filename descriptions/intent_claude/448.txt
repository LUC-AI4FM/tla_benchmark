# Specification Request: Variable Expression Module

I need a formal specification for a simple system that tracks a single numeric state value and provides a way to compute a derived value from it.

## System Description

The system maintains one piece of state: a natural number. The specification should define a helper operation that computes the successor (the value plus one) of the current state.

## Requirements

1. **State**: The system has a single numeric variable representing the current value.

2. **Derived Computation**: There should be an operation that returns the current value incremented by one, without modifying the underlying state.

## Purpose

This appears to be a foundational module intended to be instantiated or imported by other specifications. The module should be designed to support TLA+'s module instantiation mechanism, particularly testing how instantiation works within local definition contexts (such as inside LET expressions in other modules).

## Properties

The specification itself is primarily definitional—it establishes state and a computation over that state. Correctness properties would be defined by modules that instantiate this one.
