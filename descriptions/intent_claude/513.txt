# Specification Request: Alternating Bit Protocol

## System Overview

I need a formal specification of the Alternating Bit Protocol, which is a simple network communication protocol that ensures reliable message delivery over an unreliable channel. The protocol uses a single alternating bit to detect lost or duplicated messages.

## System Description

The system involves two communicating parties: a sender and a receiver. The sender transmits data messages along with a sequence bit (0 or 1), and the receiver acknowledges received messages. The protocol alternates the bit value to distinguish between new messages and retransmissions.

## Requirements

1. **Message Domain**: The system should handle a finite set of data values that can be transmitted (for example, a small set of names or identifiers for verification purposes).

2. **Sender State**: The sender maintains its current message and the associated bit value.

3. **Receiver State**: The receiver maintains information about the most recently accepted message and its corresponding bit value.

## Key Correctness Properties

1. **Type Safety**: Both the sender's and receiver's states must always consist of valid messages paired with valid bit values.

2. **Consistency Invariant**: Whenever the sender and receiver agree on the current bit value (indicating the receiver has acknowledged the current message), they must also agree on the message content itself. In other words, if the bits match, the sender and receiver have identical views of the current message.

## Purpose

This specification should serve as an abstract behavioral model that captures the essential safety guarantees of the alternating bit protocol, which can then be used to verify that more detailed implementations correctly refine this high-level behavior.
