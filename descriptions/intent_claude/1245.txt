Write a TLA+ specification for the translation from a +CAL algorithm's abstract syntax tree to its TLA+ description. The system being modeled is a translator that takes a well-formed +CAL algorithm (after macro expansion, with all labels and variable names distinct) and produces a sequence of TLA+ lexemes constituting a valid TLA+ specification.

The specification must define the grammar of valid +CAL abstract syntax trees, covering both uniprocess and multiprocess algorithms, including procedures, processes, variable declarations, labeled statements, while loops, if/either/with statements, calls, returns, combined call-returns, gotos, and simple statements (assignment, when, print, assert, skip). It must then define a Translation operator that, given an algorithm AST and a fairness option (none, weak fairness per action, weak fairness of the whole next-state action, or strong fairness per action), produces the sequence of lexemes for the corresponding TLA+ specification, including variable declarations, an Init predicate, per-label action definitions, a Next-state action, a Spec formula, and a Termination property. The translation must correctly handle control flow via pc assignments, procedure call and return via stack manipulation, subscripting of local variables in multiprocess algorithms, and priming of changed variables with appropriate UNCHANGED clauses.
