# Specification Request: Bounded Counter

## System Description
I need a formal specification for a simple bounded counter system. The counter should start at zero and increment by one until it reaches a configurable upper limit.

## Behavioral Requirements
- The counter begins at zero
- The counter can only increase, and only by increments of one
- The counter must stop incrementing once it reaches the specified maximum value
- The maximum value should be a configurable parameter within a reasonable range (between 1 and 10)

## Key Properties to Verify
- The counter never exceeds the configured bound
- The counter value is always non-negative
- Progress is possible as long as the counter has not yet reached its limit

## Purpose
This specification serves as a basic example of a bounded state machine where a value monotonically increases up to a fixed limit. It can be used to verify that the counter respects its upper bound under all possible executions.
