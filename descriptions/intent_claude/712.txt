# Specification Request: Dyadic Rational Number Arithmetic

## System Overview

I need a formal specification for arithmetic operations on **dyadic rational numbers** — fractions whose denominators are powers of 2 (e.g., 1/2, 3/4, 5/16, etc.). This representation is useful for systems that need exact fractional arithmetic without floating-point errors, such as probabilistic systems, fair schedulers, or binary subdivision algorithms.

## Core Requirements

### Data Representation
The system should represent dyadic rationals as fractions with a numerator and a power-of-two denominator.

### Required Operations
The primary operation needed is a **halving operation** that divides a dyadic rational by 2. This operation should:

1. Take any dyadic rational as input and produce another valid dyadic rational as output
2. Be mathematically correct (the result should equal half the input value)
3. Produce results in a **normalized or canonical form** when possible — for example, if the numerator is even, the result should simplify by reducing the numerator rather than increasing the denominator

### Key Correctness Properties

1. **Closure**: Halving a dyadic rational must produce another valid dyadic rational
2. **Mathematical correctness**: The halving operation must preserve the mathematical relationship (result × 2 = original value)
3. **Normalization**: When the numerator is divisible by 2, the operation should reduce the numerator and keep the denominator unchanged, rather than doubling the denominator unnecessarily

## Expected Behavior Examples

- Halving "one" should yield one-half
- Repeatedly halving one-half should produce one-quarter, one-eighth, one-sixteenth, etc. (denominator doubles each time since numerator is 1)
- Halving a fraction with an even numerator should reduce the numerator instead of increasing the denominator (maintaining simpler representation)
