Please write a formal specification for a simple generic container or wrapper structure.

**System Description:**
The system should model a basic data structure that wraps or encapsulates a value of any type into a record with a single field. This is similar to an "optional" or "box" type found in many programming languages, where a value is wrapped in a container structure.

**Requirements:**
1. Define a generic wrapper that can accept a value of any type
2. The wrapper should produce a record structure containing the wrapped value
3. The specification should support type polymorphism, allowing the same wrapper to be used with different value types (integers, sets, other records, etc.)

**Key Properties:**
- The wrapper should correctly preserve the type relationship between the input value and the contents of the resulting record
- The specification should be type-safe when used with a type-checking system

**Context:**
This is a minimal specification primarily intended to verify that the type system correctly handles generic/polymorphic type definitions, particularly ensuring that type unification works properly when a generic type parameter appears in the output type wrapped in a set constructor or similar type operator.
