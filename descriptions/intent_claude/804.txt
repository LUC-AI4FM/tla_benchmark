Write a formal specification for a binary search algorithm that finds a target value within a sorted sequence of integers.

**System Description:**
The algorithm takes as input a sorted sequence of integers and a target value to search for. It should efficiently locate the target by repeatedly narrowing the search range, examining the middle element of the current range and eliminating half of the remaining elements based on comparison with the target.

**Functional Requirements:**
- The input sequence must be sorted in non-decreasing order
- The algorithm must terminate for any valid input
- Upon completion, if the target value exists in the sequence, the algorithm must return a valid index where the target is located
- If the target value does not exist in the sequence, the algorithm must indicate this (e.g., by returning zero or a special "not found" indicator)

**Correctness Properties to Verify:**
1. **Partial Correctness:** When the algorithm terminates, the result is correct—either it points to an element equal to the target value, or it correctly indicates the value is absent from the sequence
2. **Type Safety:** All index variables remain within valid bounds throughout execution (indices used to access the sequence never go out of range)
3. **Termination:** The algorithm eventually completes for any finite sorted input sequence

**Key Challenge:**
Binary search is notoriously easy to get wrong in subtle ways (off-by-one errors, incorrect midpoint calculations, infinite loops). The specification should support verification that the implementation correctly maintains the invariant that if the target exists in the sequence, it remains within the current search bounds until found.
