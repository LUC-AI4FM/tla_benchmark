# Specification Request: Simple State Machine with Nondeterministic Transitions

## System Overview

I need a formal specification for a basic state machine that transitions between a small number of named states. The system should start in an initial state and then nondeterministically move to one of two possible target states.

## Behavioral Requirements

The system should:

1. **Start in a designated initial state** when the system begins execution.

2. **Support two different transition paths** from the initial state:
   - One transition that moves the system to a first target state (simple/deterministic)
   - Another transition that moves the system to a second target state, but this transition should involve nondeterministic choice over some values (even if those choices don't affect the outcome)

3. **Allow either transition to occur** at any step after initialization.

## Correctness Property

The specification should include an invariant that asserts **the system never reaches the second target state**. 

Note: This invariant is expected to be *violated* by the system's behavior—it serves as a test property to verify that the model checker correctly identifies reachable states and can find counterexamples when transitions to that state are possible.

## Purpose

This specification is intended to test symbolic execution and transition slicing capabilities in a model checker. The nondeterministic transition with nested existential quantifiers (choosing values from sets) is specifically designed to exercise how the verification tool handles and simplifies such constructs during state space exploration.
