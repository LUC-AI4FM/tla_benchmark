# Specification Request: Hour Clock System

## System Overview

I need a formal specification of a simple hour clock that tracks time in hours, similar to a 12-hour analog clock face.

## Functional Requirements

The system should model a clock that:

1. **Displays valid hours**: The clock must always show a valid hour value within the range of 1 to 12 (inclusive), representing the hours on a standard clock face.

2. **Advances time**: The clock should be able to tick forward, incrementing the hour. When the clock reaches 12, the next tick should wrap around to 1.

3. **Maintains stability**: The system should allow for the possibility that the hour doesn't change (representing time standing still or stuttering steps).

## Correctness Properties

The specification must guarantee the following safety property:

- **Hour Range Invariant**: At every point in the system's execution, the displayed hour must be a valid value between 1 and 12. This property must hold initially and be preserved by every possible state transition. The clock should never display an invalid hour such as 0, 13, or any value outside the valid range.

## Verification Goal

I need a formal proof that the hour range invariant is maintained throughout all possible behaviors of the clock system. This means proving that:

1. The initial state satisfies the invariant
2. Every transition (including stuttering) preserves the invariant
3. Therefore, the invariant holds globally across all reachable states
