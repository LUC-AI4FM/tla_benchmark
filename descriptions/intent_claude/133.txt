# Specification Request: Synchronized Function Update System

## System Overview

I need a formal specification for a system that maintains two parallel mappings from a fixed set of nodes to sets of nodes. The system should model how these two data structures evolve together over time.

## Requirements

### Initial State
- The system manages two separate mappings, both defined over the same fixed set of three nodes.
- Both mappings should start in an identical state, with each node initially mapped to an empty set.

### System Behavior
- The system should allow updates to occur on a restricted subset of nodes (specifically, only two of the three nodes should be eligible for updates).
- When an update occurs, it must modify both mappings simultaneously and in exactly the same way—resetting the selected node's associated set to empty in both structures.
- Updates are atomic: both mappings change together in a single step.

### Key Correctness Property

The critical invariant to verify is **synchronization equivalence**: the two mappings must remain identical to each other at all times. Since both start in the same state and every transition applies the same modification to both, the system should preserve this equality as an invariant.

## Verification Goal

The specification should allow verification that the parallel update mechanism keeps the two data structures permanently synchronized, serving as a simple model for reasoning about redundant or mirrored state management.
