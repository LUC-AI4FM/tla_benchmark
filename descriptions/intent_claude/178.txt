# Specification Request

I need a formal specification for an extremely simple state transition system that demonstrates basic state machine behavior with a helper predicate.

## System Description

The system consists of a single integer counter that starts at zero and transitions exactly once to the value one. The transition should be gated by a helper function that always permits the action to occur.

## Requirements

1. **Initial State**: The counter must start at zero.

2. **State Transition**: The system should support a single transition where the counter changes from zero to one.

3. **Transition Guard**: The transition should be enabled based on a predicate that is parameterized (takes an argument) but always evaluates to true, allowing the transition to proceed unconditionally.

## Correctness Properties

The specification should be straightforward enough that:
- The initial state is well-defined
- The next-state relation is deterministic
- The helper predicate mechanism works correctly with parameters

This is essentially a minimal example to verify that parameterized local definitions work correctly within a specification context.
