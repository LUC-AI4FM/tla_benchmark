# Specification Request: Bounded Decrementing Counter

## System Overview

I need a formal specification for a simple countdown counter that starts at a specific initial value and decrements by one on each step.

## Functional Requirements

1. The counter should begin at an initial value of 3
2. On each transition, the counter should decrease by exactly 1
3. The counter continues decrementing indefinitely (there is no stopping condition built into the transitions)

## Correctness Property to Verify

The key safety property I want to check is whether the counter ever becomes negative. Specifically, I want to verify (or find a counterexample for) the invariant that the counter value remains non-negative throughout execution.

## Intent

This specification is meant to explore what happens when a decrementing counter has no guard preventing it from going below zero. The system is expected to eventually violate the non-negativity property, demonstrating a counterexample after a sufficient number of steps. This serves as a simple illustration of how model checking can detect when a system's behavior diverges from a desired safety property.
