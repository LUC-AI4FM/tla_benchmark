# Specification Request: Module Instantiation with Parameter Substitution

## System Overview

I need a formal specification for a simple single-step computation that demonstrates the ability to use parameterized module instantiation within a specification. The system should import functionality from an external module, supply specific parameter values to that module, and then use the imported definitions to compute a result.

## Functional Requirements

The system should:

1. Start with a numeric variable initialized to zero
2. In a single computational step, assign to that variable the result of a computation defined in a separate, parameterized module
3. The external module should perform a simple arithmetic operation (specifically, summing two parameter values)
4. The parameters passed to the external module should be specific constant values (in this case, 3 and 4)
5. Terminate after performing this single assignment

## Correctness Properties

The specification must guarantee:

1. **Termination**: The system must eventually reach its final state
2. **Value Correctness**: The numeric variable must only ever hold valid values—either its initial value (zero) or the expected computed result (the sum of the parameters, which is 7)

## Key Modeling Concern

The specification should specifically demonstrate that parameterized module instantiation works correctly when multiple parameters are substituted, ensuring that the imported operation produces the expected result based on the supplied parameter values.
