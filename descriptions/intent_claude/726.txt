# Specification Request: Sequence Utility Library

## System to be Modeled

A comprehensive library of utility operations for manipulating sequences (ordered lists) in a formal specification language. This library should extend basic sequence operations with additional functionality commonly needed when working with sequences in formal specifications and algorithm modeling.

## Functional Requirements

The library must provide the following categories of operations:

### Conversion Operations
- Convert a sequence to a set (extracting unique elements)
- Convert a sequence to a bag/multiset (preserving element counts)
- Convert a set to a sequence (in some deterministic or non-deterministic order)
- Generate all possible sequence orderings of a set's elements

### Element Manipulation
- Reverse a sequence
- Remove all occurrences of a specific element
- Replace all occurrences of one element with another
- Replace an element at a specific position
- Remove only the first occurrence of an element or matching condition
- Flatten nested sequences into a single level

### Subsequence and Prefix/Suffix Operations
- Determine if one sequence is a prefix of another (strict and non-strict variants)
- Determine if one sequence is a suffix of another (strict and non-strict variants)
- Check if a sequence contains a specific element
- Find the longest common prefix among a set of sequences
- Extract all contiguous subsequences of a sequence
- Extract all subsequences (not necessarily contiguous) of a sequence
- Compute all suffix sequences

### Search Operations
- Find the index of the first element satisfying a condition
- Find the index of the last element satisfying a condition
- Search within a specified range of the sequence

### Folding Operations
- Left fold: accumulate values by processing elements left-to-right
- Right fold: accumulate values by processing elements right-to-right
- Fold with access to element indices/positions

### Sequence Combination
- Interleave two sequences (alternating elements)
- Zip two sequences into a sequence of pairs
- Replace first occurrence of a subsequence with another sequence
- Replace all occurrences of a subsequence with another sequence

## Correctness Properties

The library must guarantee:

1. **Set Conversion Consistency**: Converting a sequence to a set and back should preserve all unique elements, though order may change.

2. **Reverse Involution**: Reversing a sequence twice yields the original sequence.

3. **Prefix/Suffix Transitivity**: If A is a prefix of B and B is a prefix of C, then A is a prefix of C.

4. **Fold Equivalence**: For associative operations with identity elements, left and right folds should produce equivalent results.

5. **Containment Consistency**: An element is contained in a sequence if and only if it appears in the set derived from that sequence.

6. **Subsequence Completeness**: The set of all contiguous subsequences must include the empty sequence and the original sequence itself.

7. **Replacement Correctness**: After replacing all occurrences of a pattern, the pattern should no longer appear in the result (unless the replacement reintroduces it).

8. **Length Preservation**: Operations like zip and interleave should have predictable effects on sequence length based on input lengths.

9. **String Compatibility**: All operations should work correctly with strings (sequences of characters), including proper handling of escape sequences.
