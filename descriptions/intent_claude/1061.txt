# Specification Request: Synchronous Termination Detection

## System Overview

I need a formal specification for a **synchronous termination detection algorithm** in a distributed system with a fixed number of nodes.

## Problem Description

Consider a distributed system where multiple nodes (processes) can be either active or inactive. Active nodes may perform work and can potentially activate other nodes. The system needs a mechanism to detect when **global termination** has occurred—that is, when all nodes in the system have become inactive and will remain inactive.

## Requirements

### System Model

1. The system consists of a fixed number of nodes (N nodes, where N ≥ 1)
2. Each node has a binary state: either **active** or **inactive**
3. Active nodes may become inactive on their own
4. Active nodes may activate other (currently inactive) nodes
5. Inactive nodes cannot spontaneously become active—they can only be activated by other active nodes

### Termination Detection

The system must include a termination detection mechanism that determines when all nodes have become inactive. This detection should be performed synchronously (i.e., with some form of coordinated checking across all nodes).

## Correctness Properties

The specification must guarantee the following properties:

### Safety Property
- **No false positives**: Termination must never be declared while any node is still active. If the system reports that termination has been detected, then all nodes must actually be inactive.

### Liveness Property
- **Eventual detection**: If all nodes become inactive and remain inactive, termination must eventually be detected. The algorithm should not miss a true termination state indefinitely.

## Goal

Provide a TLA+ specification that models this synchronous termination detection problem, capturing the essential behavior of nodes transitioning between active and inactive states, and a detection mechanism that correctly identifies global termination.
