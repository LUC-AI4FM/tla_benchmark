# Specification Request: N-Queens Puzzle Solver

## System Overview

I need a formal specification for a system that solves the classic N-Queens puzzle. The puzzle involves placing N chess queens on an N×N chessboard such that no two queens threaten each other—meaning no two queens share the same row, column, or diagonal.

## Functional Requirements

The system should:

1. **Systematically explore** all possible placements of queens on the board
2. **Track partial solutions** (valid configurations with fewer than N queens) that could potentially lead to complete solutions
3. **Identify and collect all valid complete solutions** where exactly N queens are placed with none attacking each other
4. **Terminate** when all possibilities have been explored

## Correctness Properties

The specification must guarantee:

1. **Safety**: Every solution recorded must be a valid N-Queens solution—no two queens in any recorded solution may attack each other
2. **Completeness**: When the algorithm terminates, all possible valid solutions for the given board size have been found
3. **Progress**: The system must eventually terminate (no infinite loops or deadlocks)
4. **Solution Validity**: Each solution must contain exactly N queens, one per row, with no conflicts on columns or diagonals

## Configuration

The specification should be parameterized by the board size N, allowing verification of the algorithm for different puzzle sizes. For practical model checking, a small value (such as N=4) should be used to keep the state space manageable.

## Purpose

This specification will serve to verify that a search algorithm for the N-Queens problem correctly explores the solution space and identifies all valid configurations without missing any or including invalid ones.
