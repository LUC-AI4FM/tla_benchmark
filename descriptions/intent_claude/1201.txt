# Specification Request: TLA+ Parser Conformance Test for Prefix-Style Operator Invocation

## Goal

Create a test specification that verifies a TLA+ parser or tool correctly handles the invocation of user-defined operators using prefix notation (functional application syntax) rather than infix notation.

## System Description

This is not a behavioral system specification but rather a **language conformance test suite** for TLA+ tooling. The test should verify that when a user redefines any of the overloadable infix or postfix operators in TLA+, those redefined operators can be invoked using prefix-style syntax with parenthesized arguments.

## Requirements

### Core Capability to Test

1. **Prefix invocation of redefined binary operators**: When a binary operator symbol (like `+`, `*`, `/`, `<`, `>`, etc.) is redefined by the user, it should be callable using the syntax `OpSymbol(arg1, arg2)` as an alternative to `arg1 OpSymbol arg2`.

2. **Prefix invocation of redefined postfix operators**: When a postfix operator (like `^+`, `^*`, `^#`) is redefined, it should be callable using the syntax `OpSymbol(arg)`.

3. **Prefix invocation of redefined prefix operators**: User-defined prefix operators (like `-.`) should also support functional application syntax.

4. **Operator symbol synonyms**: For operators with multiple equivalent spellings (e.g., `\leq`, `<=`, and `=<`), all spellings should invoke the same user-defined operator when called in prefix style.

### Coverage Requirements

The test should cover:
- Basic arithmetic symbols (`+`, `*`, `/`, `^`)
- Comparison operators (`<`, `>`, `\leq`, `\geq`)
- Range operators (`..`, `...`)
- Logical connective symbols (`|`, `||`, `&`, `&&`)
- Double-symbol variants (`++`, `--`, `**`, `//`, `^^`, `@@`, `!!`, `%%`, `##`, `$$`, `??`)
- Turnstile and related operators (`|-`, `|=`, `-|`, `=|`)
- Assignment-like operators (`:=`, `::=`, `<:`, `:>`)
- Set-theoretic symbols (`\uplus`, `\sqcap`, `\sqcup`, `\subset`, `\supset`, etc.)
- Relational symbols (`\prec`, `\succ`, `\preceq`, `\succeq`, `\sim`, `\simeq`, `\ll`, `\gg`, etc.)
- Circled operators (`\oplus`, `\ominus`, `\odot`, `\otimes`, `\oslash`)
- Composition operator (`\circ`, `\o`)
- Built-in operators used in prefix form (`\in`, `\cup`)

### Known Limitations to Document

- Binary minus (`-`) does not support prefix invocation as a user-redefined operator (parser ambiguity with unary minus).

### Correctness Property

Each redefined operator, when invoked with prefix notation, must produce exactly the same result as when invoked with its standard infix/postfix notation—confirming syntactic equivalence of the two calling conventions.
