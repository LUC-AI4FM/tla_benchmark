# Specification Request: User State Tracking System

## System Overview

I need a formal specification for a simple user state tracking system that manages the lifecycle state of multiple users.

## What the System Should Model

The system tracks a collection of users, where each user has an associated state. Users begin in an initial state and can transition to a completed state.

## Functional Requirements

1. **Initialization**: The system should start with a given set of user identifiers, where every user begins in an initial/starting state.

2. **State Transitions**: Any user should be able to transition from their initial state to a "done" or completed state.

3. **Multi-User Support**: The system must handle multiple users independently, with each user having their own separate state that can evolve independently of other users.

## Key Properties to Verify

- All users start in the initial state
- Users can only transition to the completed state
- Each user's state is tracked independently

## Context

This appears to be a foundational module intended for composition or refinement with other specifications. It should be designed to work with different sets of user identifiers that may be provided by instantiating modules.
