# Specification Request: Graph Partition Structure with Successor Pointers

## System Overview

I need a formal specification for a data structure representing a partition of graph nodes, where each partition block can have a successor pointer to another block.

## Requirements

### Basic Structure

The system should model a collection of disjoint vertex groups (blocks) over a fixed set of nodes (for example, 5 nodes). Each block in the partition has:
- A non-empty subset of nodes that belong to it
- A successor pointer that either references a node in some block or is null
- A status flag indicating whether the block is "dead" or active

### Partition Constraints

The partition must satisfy these structural invariants at all times:

1. **Disjointness**: No node can belong to more than one block simultaneously. The node sets of any two distinct blocks must be completely disjoint.

2. **Non-emptiness**: Every block in the partition must contain at least one node—empty blocks are not permitted.

3. **Valid successor references**: If a block has a non-null successor pointer, that pointer must reference a node that actually exists in some block of the current partition. Dangling references are forbidden.

### Initial State

The system should start with an empty partition (no blocks defined yet).

## Correctness Properties

The key property to verify is **type correctness**: the partition structure must always satisfy all the constraints above—disjointness, non-empty blocks, and valid successor pointers forming a well-formed partition.

## Purpose

This appears to be a foundational data structure specification, possibly for use in algorithms involving graph partitioning, union-find structures with successor chains, or similar graph decomposition problems where blocks need to reference each other.
