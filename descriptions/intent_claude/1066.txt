# Specification Request: Synchronous Termination Detection

## System Overview

I need a formal specification for a **synchronous termination detection** protocol in a distributed system. The system consists of multiple nodes (or processes) that can be either active or inactive. The goal is to correctly detect when all nodes in the system have terminated (become inactive) and will remain so.

## System Description

The system should model:

1. **A collection of nodes** that can each be in an active or inactive state
2. **A termination detection mechanism** that determines when the entire system has reached a quiescent (fully terminated) state
3. **The ability for inactive nodes to be reactivated** (woken up), representing how processes might receive messages or be triggered by other processes

## Required Behaviors

The specification must capture:

- **Termination**: Individual nodes can transition from active to inactive
- **Wakeup**: Nodes that have become inactive may be reactivated (until global termination is detected)
- **Detection**: The system can announce that termination has been detected, but only when appropriate

## Correctness Properties

### Safety Properties

1. **Type correctness**: All system variables remain within their expected domains throughout execution

2. **Correct detection**: Termination must never be falsely detected. If the system announces that termination has been detected, then all nodes must actually be in a terminated state.

3. **Quiescence (stability)**: Once all nodes have genuinely terminated (the system reaches a truly quiescent state), it must remain in that state permanently. The terminated condition, once achieved, cannot be reversed.

### Liveness Property

4. **Eventual detection**: If the system reaches a state where all nodes are terminated, then termination detection must eventually occur. The protocol cannot remain forever in a state where termination has happened but goes unannounced.

## Fairness Requirements

The detection mechanism should be treated with weak fairness—if detection becomes possible and remains continuously possible, it must eventually happen.
