# Specification Request: Multi-User System with Per-User Behavior Guarantees

## System Overview

I need a formal specification for a multi-user system where multiple users can interact concurrently, but the system must preserve certain behavioral guarantees for each individual user as if they were operating in isolation.

## Core Requirements

The system should model:

1. **Multiple concurrent users**: The system supports a configurable set of user identities who can perform actions simultaneously or in an interleaved fashion.

2. **User operations**: Each user can perform some sequence of operations within the system (the specific operations depend on the application domain).

## Key Correctness Properties

The critical requirement is **per-user behavioral equivalence**: For any given user in the multi-user system, their observable behavior must be equivalent to what would occur if that user were the only one using the system.

Specifically, I need to verify:

1. **Single-user refinement**: The behavior experienced by any individual user (e.g., user 2 or user 3) in the multi-user setting must refine or satisfy the specification of a single-user system.

2. **Universal user guarantees**: This property must hold for *all* users in the system, not just specific ones. Every user should experience the system as if they had exclusive access.

3. **Parameterized verification**: The specification should support checking these properties for specific user identities as well as universally across all users.

## Verification Goals

The model checker should confirm that:
- Picking any specific user from the set, their view of system behavior matches the single-user specification
- This guarantee holds regardless of which user we examine
- The property scales correctly when we consider different user identities

## Configuration

The specification should allow configuring the set of user identifiers (e.g., a range of numeric IDs) to test the properties with different numbers of concurrent users.
