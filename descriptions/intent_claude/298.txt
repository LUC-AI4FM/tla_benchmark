# Specification Request: Binary Search Algorithm

## System to Model
I need a formal specification of the binary search algorithm operating on a sorted sequence of elements.

## Description
Binary search is a classic divide-and-conquer algorithm that efficiently locates a target value within a sorted array by repeatedly halving the search space. The algorithm compares the target to the middle element and eliminates half of the remaining elements based on whether the target is smaller or larger than the middle element.

## Functional Requirements
1. The algorithm should operate on a sorted sequence of integers
2. Given a target value, the algorithm should determine whether the target exists in the sequence
3. If the target exists, the algorithm should identify its position
4. The search space should be reduced by half in each iteration
5. The algorithm should terminate when either the target is found or the search space is exhausted

## Key Correctness Properties
1. **Partial Correctness**: If the algorithm reports finding the target at a position, that position must actually contain the target value
2. **Completeness**: If the target exists in the sequence, the algorithm must eventually find it
3. **Termination**: The algorithm must always terminate in a finite number of steps
4. **Search Space Invariant**: Throughout execution, if the target exists in the original sequence, it must remain within the current search bounds
5. **Monotonic Progress**: The search space must strictly decrease with each iteration until termination

## Expected Behavior
- The specification should model the state of the search (current bounds being examined)
- It should capture the decision logic for narrowing the search range
- It should handle edge cases such as empty sequences and targets not present in the sequence
