# Specification Request

## System Description

I need a formal specification for a simple two-state oscillator system. The system consists of two integer values that continuously swap with each other on every step.

## Behavior Requirements

1. **Initial State**: The system starts with one value at zero and the other at one.

2. **State Transitions**: On each step, the two values exchange places—the first takes the value of the second, and the second takes the value of the first. This creates an alternating pattern that cycles forever between two configurations.

## Correctness Properties

The specification should verify the following temporal properties:

1. **Reachability Property (should hold)**: The system must infinitely often reach a state where a certain arithmetic combination of the values equals 2. Specifically, this involves adding the values together in a way that uses one of them twice in the sum.

2. **Stability Property (should not hold)**: As a counterexample, verify that the system does NOT eventually stabilize permanently in a state where the simple sum of the two values equals 2. Since the values always sum to 1 (just swapping 0 and 1 back and forth), this property should be false.

## Purpose

This specification is primarily intended to test the handling of local definitions and nested expressions within temporal formulas, ensuring that the model checker correctly evaluates properties that use helper functions and intermediate variable bindings in their definitions.
