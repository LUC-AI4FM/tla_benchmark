# Specification Request: Invariant Violation Detection Test

## System Description

I need a minimal TLA+ specification designed to test or demonstrate the behavior of a model checker when an invariant is immediately violated in the initial state.

## Requirements

The system should be as simple as possible:
- Start with a single state variable initialized to a specific value
- Allow any behavior after initialization (the system can stutter or change arbitrarily)

## Correctness Properties

The specification should include an invariant that is **intentionally false in the initial state**. Specifically, the initial value of the state should violate the invariant condition from the very first state.

## Purpose

This appears to be a test case (likely for a bug report or regression test) to verify that the model checker correctly detects and reports invariant violations that occur in initial states, rather than only catching violations that arise during state transitions.
