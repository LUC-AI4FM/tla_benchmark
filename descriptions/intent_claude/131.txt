# Specification Request: Synchronized Function Update System

## System Overview

I need a formal specification for a simple system that maintains two identical mapping structures and updates them in lockstep.

## Description

The system manages two separate data structures that map integer keys to sets of integers. Both structures should be initialized identically and should always be modified together using the same operations, ensuring they remain equivalent throughout execution.

## Requirements

1. **Initialization**: Both mapping structures start in the same initial state, with the same domain of keys, each mapping to an empty set.

2. **Synchronized Updates**: Any modification to one structure must be accompanied by an identical modification to the other structure in the same atomic step. Specifically, when adding an element to a set at a particular key in one structure, the same element must be added to the same key in the other structure.

## Correctness Property

**Equivalence Invariant**: The two mapping structures must always be identical to each other. At every reachable state of the system, the contents of both structures should be exactly the same.

## Purpose

This specification serves to verify that parallel or redundant data structures remain synchronized when updated together, which is a fundamental pattern in systems requiring data replication or redundancy verification.
