Write a specification for a system that computes Fibonacci numbers and tracks the result in its state.

**System Description:**
The system should model a simple state machine that holds a Fibonacci number value. It starts by computing a specific Fibonacci number as its initial state, then transitions to holding a different Fibonacci number in its next state.

**Fibonacci Definition:**
The specification must include a recursive definition of the Fibonacci function following the standard mathematical definition:
- For values at or below zero, the result is zero
- For values 1 and 2, the result is one
- For all other values, the result is the sum of the two preceding Fibonacci numbers

**Behavioral Requirements:**
- The system initializes with the 4th Fibonacci number
- The system then transitions to hold the 5th Fibonacci number

**Correctness Property:**
The key invariant that must hold is that the stored value is always at least 1 (i.e., the system never holds a non-positive Fibonacci result for the indices being used).

**Additional Context:**
This specification is intended to serve as a test case for tools that need to handle recursive operator definitions, particularly for verifying that such definitions can be properly unfolded or expanded during analysis. The recursion depth needed is bounded and known in advance.
