# Specification Request

## System to Model

A simple sequential algorithm that demonstrates nondeterministic choice combined with procedure calls, used to verify that exactly one of several mutually exclusive initialization paths is taken.

## Description

The system should model an algorithm that begins with three counters all initialized to zero. The algorithm must then make a nondeterministic choice among three possible actions:

1. Set the first counter to 1 and reset the second counter to 0
2. Set the second counter to 1 (leaving the first counter unchanged)
3. Call a procedure that increments the first counter by a given amount (specifically, by 1)

After any of these branches completes, the algorithm should continue to a final verification step.

The procedure should accept a numeric parameter and add that value to the first counter before returning to the caller.

## Key Correctness Properties

1. **Branch consistency**: If the third branch (procedure call) is taken, immediately after the procedure returns, the first counter must equal 1.

2. **Mutual exclusion of outcomes**: After the nondeterministic choice completes (regardless of which branch was taken), exactly one of the first two counters should equal 1, meaning their sum must be exactly 1.

3. **Termination**: The algorithm must eventually complete under fair scheduling.

## Purpose

This specification serves to verify that a nondeterministic choice construct correctly explores all branches, that procedure calls within such constructs work properly with parameter passing and return semantics, and that invariants hold across all possible execution paths.
