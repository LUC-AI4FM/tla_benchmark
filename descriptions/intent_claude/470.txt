Please write a formal specification for a simple state machine with the following characteristics:

**System Description:**
A system with two primary state variables where one variable transitions to a fixed value while the other is constrained by a condition relating its current and next states.

**Requirements:**

1. The system should start with one of the variables initialized to zero.

2. On each step, the first variable must transition to the value 1.

3. The second variable has a constraint: it cannot simultaneously transition to one specific value while currently being at a different specific value. In other words, certain combinations of "before and after" states for this variable are forbidden.

4. The specification should allow for stuttering steps where the relevant variables remain unchanged.

**Correctness Properties:**
The specification should ensure that the forbidden state transition pattern for the second variable is never violated during any step of the system's execution.
