# Specification Request: Function Argument Order Verification

## System Overview
I need a formal specification to verify that argument order is correctly preserved when functions are composed or wrapped by other functions.

## Goal
Create a simple test specification that checks whether a predicate function maintains correct behavior when its arguments are passed through an intermediate wrapper function that reverses the argument order.

## Requirements

### Core Functionality
- Define a base comparison function that checks whether two values are not equal
- Define a wrapper function that calls the base function with its arguments in reversed order
- The system should demonstrate that the composition of these functions produces the expected result

### Correctness Properties
- The key invariant is that when the wrapper function is called with specific distinct values (like 1 and 2), the result should be true (since after reversal, the base inequality check should still hold for distinct values)
- This serves as a regression test to ensure the specification language correctly handles argument passing and function composition

## Purpose
This specification acts as a minimal test case to verify that the formal specification tooling correctly evaluates nested function calls where argument order matters, ensuring there are no bugs in how arguments are threaded through multiple levels of function application.
