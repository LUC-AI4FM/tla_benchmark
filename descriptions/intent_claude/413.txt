Write a specification that serves as a test harness for verifying the correctness of finite set operations from a standard library.

The system should validate fundamental operations on finite sets, specifically:

1. **Finite set detection**: The ability to correctly identify whether a given set is finite, including both non-empty sets (like a set containing two distinct elements) and the empty set.

2. **Cardinality computation**: The ability to correctly count the number of elements in a set, verifying that:
   - The empty set has cardinality zero
   - A set with multiple distinct elements reports the correct count

The specification should be structured as a simple test suite that checks these operations against known expected results. Each test case should clearly indicate success or failure, with descriptive output identifying which test passed or failed.

The key correctness property is that all test assertions must hold—the finite set operations must return the mathematically expected results for the given test inputs.
