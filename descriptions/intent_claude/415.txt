# Specification Request: Module Extension and Constant Initialization

## System Overview

I need a formal specification that demonstrates modular specification composition through module extension. The specification should show how a base module can define foundational elements that other modules can build upon.

## Requirements

### Core Functionality

1. **Parameterized Initialization**: The system should define an initialization predicate that checks whether a given value equals a designated constant parameter. This allows the constant to be instantiated differently in various contexts while maintaining a consistent initialization pattern.

2. **Constant Declaration**: The specification should declare a constant that serves as the reference value for initialization comparisons. This constant represents a configuration parameter that is fixed for any particular system instance but can vary between different instantiations.

### Design Goals

- **Modularity**: The specification should be structured to serve as a reusable building block that other specifications can extend and incorporate.
- **Flexibility**: By using a constant rather than a fixed value, the initialization logic should be adaptable to different use cases without modifying the core specification.

### Correctness Properties

The specification should ensure that:
- The initialization predicate correctly identifies when a value matches the designated constant
- The module structure supports clean extension by dependent specifications
