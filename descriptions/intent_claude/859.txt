# Specification Request: Readers-Writers Synchronization

I need a formal specification of the classic **readers-writers synchronization problem**.

## System Description

The system models concurrent access to a shared resource where multiple processes can be either readers or writers. The fundamental constraint is that readers can access the resource simultaneously with other readers, but writers require exclusive access—no other readers or writers may access the resource while a writer is active.

## Requirements

The specification should model:

1. **Multiple processes** (parameterized by some count, e.g., 3) that can attempt to read or write to a shared resource
2. **Waiting queues or sets** for processes that want to read or write but cannot yet proceed
3. **State transitions** for processes requesting access, gaining access, and releasing the resource

## Key Correctness Properties

The specification must guarantee:

1. **Mutual exclusion for writers**: At most one writer can access the resource at any time
2. **Reader-writer exclusion**: If a writer is accessing the resource, no readers may access it simultaneously
3. **Multiple readers allowed**: Multiple readers may access the resource concurrently when no writer holds it

## Verification Goals

I want to use model checking to explore the state space and understand the system's behavior, including examining scenarios where:
- All processes might be reading simultaneously
- All processes might be waiting to write
- The interaction between waiting readers and waiting writers under various conditions

The goal is to have a working model that can be checked against safety properties and used to explore different scheduling or fairness policies for the readers-writers problem.
