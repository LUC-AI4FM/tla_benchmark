# Specification Request: Alternating Bit Protocol Over Lossy Channels

## System to Model

I need a formal specification of the **Alternating Bit Protocol** for reliable data transmission between a sender and receiver communicating over unreliable channels where messages can be lost.

## System Description

The system consists of:

1. **A sender process** that transmits data items tagged with an alternating bit (0 or 1) and waits for acknowledgments before moving to the next data item.

2. **A receiver process** that receives data messages, delivers new data (detected by a changed bit), and sends acknowledgments back to the sender.

3. **Two communication channels** (one in each direction) that behave as FIFO queues but are unreliable—messages can be spontaneously lost at any time.

4. **A lossy environment** that models the unreliability by nondeterministically removing messages from either channel.

## Behavioral Requirements

- The sender should repeatedly transmit its current message until it receives a matching acknowledgment, then move on to a new data item with a flipped bit.
- The receiver should accept incoming messages and update its state when it sees a new bit value, acknowledging with the current bit.
- Both the sender-to-receiver and receiver-to-sender channels must allow arbitrary message loss.
- Messages are pairs consisting of a data value and a single bit.
- The system should start in a consistent state where sender and receiver agree on the initial message.

## Correctness Properties

The specification should support verifying:

1. **Safety**: The receiver only accepts data that the sender has sent, and data is delivered in the correct order without duplication.

2. **Agreement**: The protocol maintains consistency between sender and receiver states despite message loss.

3. **Type correctness**: Messages in the channels conform to the expected format (data paired with a bit value).

The model should be suitable for checking refinement against a higher-level specification of reliable data transfer.
