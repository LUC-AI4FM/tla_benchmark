Write a specification to verify the correctness of a fold operation over sequences that accumulates elements into a set.

**System Description:**
Model a simple static system (no state changes) that tests a left fold operation. The fold should take a sequence of integers and combine them into a set by successively adding each element to an accumulator set that starts with an initial value.

**Key Operation to Verify:**
A fold-left operation that:
- Starts with an initial set (containing a duplicate element, e.g., {4, 4} which is just {4})
- Processes a sequence of integers (e.g., 1, 2, 3) from left to right
- Uses a combining function that unions the accumulator set with a singleton set containing the current element
- Should produce the union of the initial set and all elements in the sequence

**Correctness Property:**
The specification should verify that folding the union operation over a sequence produces the expected set result—specifically, that the final set contains exactly the initial elements plus all elements from the sequence. The property should be expressed as a negation to enable verification via unsatisfiability checking (i.e., assert the negation of the expected equality to confirm the fold behaves correctly when the solver finds no counterexample).

**Purpose:**
This is a test specification to validate that the encoding of sequence fold operations in a model checker or SMT solver is correctly constrained. By asserting something that should be false (the result does NOT equal the expected set), successful verification confirms the fold semantics are properly implemented.
