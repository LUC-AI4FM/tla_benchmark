Write a specification for a system that manages a collection of user records with age-based constraints.

**System Overview:**
The system maintains a set of records, where each record represents an entity with properties including an identifier, name, age, and several boolean flags. The system should support adding new records and modifying existing ones.

**Required Operations:**
1. **Add a new record:** The system should be able to introduce a new record with predefined default values into the collection.
2. **Increment age:** The system should be able to select an existing record and increase its age by one, effectively replacing the old record with an updated version.
3. **Idle:** The system may also take no action, leaving the collection unchanged.

**Key Correctness Property:**
The system must guarantee that all records in the collection always have an age strictly below 15. This age limit must be maintained as an invariant throughout all system operations.

**Additional Behavioral Requirement:**
The system should track whether the age constraint is satisfied across all current records, maintaining an indicator of the overall validity state after each transition.
