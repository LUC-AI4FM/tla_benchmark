# Specification Request: Simple Bounded Counter with Action Properties

## System Description

I need a formal specification of a simple bounded counter that increments from zero up to a maximum value. The counter should start at zero and increase by one on each step until it reaches its upper bound, at which point it should stop advancing.

## Behavioral Requirements

1. The counter must initialize to zero
2. The counter may increment by exactly one on each transition
3. The counter must never exceed a specified upper bound (e.g., 5)
4. Once the counter reaches the upper bound, no further increments should occur

## Key Properties to Explore

The main purpose of this specification is to serve as a testbed for exploring different ways to express **action-level temporal properties** (properties that refer to transitions/steps rather than just states). Specifically, I want to define and examine several variations of liveness or action properties:

- A property asserting that the counter strictly increases in a step
- A property equivalent to the system taking its defined transition
- A property that allows either a proper transition or the counter remaining unchanged
- A property using the "square bracket" (stuttering-allowed) form of the transition
- A property using the "angle bracket" (non-stuttering) form of the transition

## Notes

The specification should clearly distinguish between action-level properties (which reason about state transitions) and state-level properties (which reason about individual states). Properties involving enablement conditions are out of scope for this exercise, as they reduce to state-level predicates.
