Please write a formal specification for a distributed spanning tree construction protocol.

**System Description:**

Model a distributed algorithm where a collection of processes collaboratively build a spanning tree rooted at a designated root process. The processes communicate by sending messages to their neighbors in an underlying network graph. Each non-root process must eventually select one of its neighbors as its parent in the spanning tree.

The protocol should capture:
- A fixed set of processes with a designated root process
- A neighbor relation defining which processes can communicate directly
- The ability for processes to send messages to neighbors
- A mechanism for non-root processes to set their parent when they receive a message (if they haven't already chosen a parent)
- Some form of reporting or acknowledgment once a process has joined the tree

**Key Correctness Property:**

The specification must guarantee the following safety property:

*A non-root process that has not yet selected a parent has never sent any messages.*

In other words, only processes that have already joined the spanning tree (either the root, or a process that has set its parent) are permitted to send messages. This ensures that the tree grows outward from the root in an orderly fashion—a process must first be "activated" by receiving a message and selecting a parent before it can propagate messages further.

**Goal:**

Provide a formal model suitable for mechanically proving that this message-sending discipline is maintained as an invariant throughout all executions of the protocol.
