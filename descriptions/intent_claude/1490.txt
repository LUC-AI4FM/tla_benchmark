# Specification Request: Action Composition System

## System Overview

I need a formal specification for a system that demonstrates **sequential composition of actions** — where two distinct operations must execute as an atomic combined step, with the second operation immediately following the first within a single transition.

## System Description

The system manages a single numeric state that evolves through composed transitions. There are two separate operations that can modify the state:

- **First operation**: Can transition the state from certain values to a set of possible successor values
- **Second operation**: Can transition the state from different values to other successor values

The key requirement is that these two operations are **not** executed independently. Instead, they must be **composed sequentially** — meaning whenever the system takes a step, it performs the first operation and then immediately (atomically) performs the second operation, using the intermediate result of the first as the input to the second.

## Behavioral Requirements

1. The system starts in an initial state (value zero)
2. Each system transition consists of the sequential composition of both operations as a single atomic step
3. The intermediate state produced by the first operation is never externally visible — only the final result after both operations complete
4. Transitions only occur when valid composition is possible (the output of the first operation must be a valid input for the second)

## Correctness Properties

The specification should verify:

1. **State boundedness**: The system state remains within an expected finite set of reachable values
2. **Progress capability**: From certain states, further transitions should remain possible (the system shouldn't deadlock unexpectedly in those states)
3. **Ordering constraint**: The reverse composition (second operation followed by first) should never occur
4. **Transition validity**: All transitions conform to the composed action pattern

## Purpose

This specification explores how atomic sequential composition of actions restricts reachable states compared to allowing either action independently, and demonstrates formal reasoning about action composition in concurrent/reactive systems.
