Write a TLA+ specification for the translation of +CAL (PlusCal) algorithms into TLA+ specifications. The module should define the abstract syntax of a +CAL algorithm as a grammar of records and sequences, covering both uniprocess and multiprocess algorithms, including procedures, processes, labeled statements, while loops, if/either/with constructs, assignments, calls, returns, call/return combinations, gotos, and simple statements like when, print, assert, and skip. Given this grammar, define an operator Translation(alg, fairnessOption) that produces, as a sequence of lexemes, the TLA+ specification corresponding to the algorithm's abstract syntax tree. The translation must expand labeled statements into atomic actions with explicit pc assignments, handle procedure call and return via stack manipulation, add process-local variable subscripts for multiprocess algorithms, generate Init and Next definitions, define ProcSet for multiprocess algorithms, and append a Termination property. The fairnessOption parameter must support four values: no fairness, weak fairness of all process actions, weak fairness of the entire Next action, and strong fairness of all process actions. The output must replace internal placeholder variable names with the actual names pc and stack.
