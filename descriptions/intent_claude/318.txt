# Specification Request: Integer Factorization Search

## System Overview

I need a formal specification for a system that searches for a non-trivial factorization of a specific composite number.

## Goal

The system should find two factors of the number 999,999, where both factors are greater than 1 (i.e., excluding the trivial factorization of 1 × 999,999).

## Requirements

1. **Search Space**: The system should search for factor pairs where both factors fall within a reasonable range (e.g., from 2 up to some upper bound like 1,000,000).

2. **Valid Factorization**: When the system finds a solution, the product of the two discovered factors must equal exactly 999,999.

3. **Non-trivial Factors**: Both factors must be at least 2, ensuring we find a meaningful decomposition rather than the trivial case.

## Correctness Property

The key property to verify is whether a valid factorization can be found. Specifically, I want to use model checking to demonstrate that:

- **A factorization exists**: The model checker should find a counterexample to the claim "no factorization has been found," thereby discovering and reporting actual factors of the target number.

This is essentially using the model checker as a constraint solver—by asserting that no solution exists, a counterexample will reveal the actual factors.

## Notes

This specification is intended to leverage symbolic model checking (which can efficiently handle large numeric constraints) rather than explicit-state enumeration (which would need to iterate through an enormous search space).
