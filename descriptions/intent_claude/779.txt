# Specification Request: Function Theory Utility Library

## Overview

I need a formal specification that provides a comprehensive library of mathematical function utilities for use in formal modeling and verification. This library should define standard concepts from set theory and discrete mathematics related to functions, enabling their use in other specifications.

## Required Capabilities

### Function Restriction Operations
The library must support restricting a function's domain in multiple ways:
- Restricting a function to an arbitrary subset of its domain
- Restricting based on a predicate that tests domain elements
- Restricting based on a predicate that tests the function's output values
- Determining whether one function is a restriction of another (i.e., has a subset domain with matching values)

### Basic Function Properties
- Computing the range (image) of a function
- Computing the inverse of a function, mapping outputs back to inputs
- Applying a binary operation pointwise to corresponding elements of two functions with compatible domains

### Classification of Functions
The library must provide definitions for the classical function classifications:
- **Injective functions** (one-to-one): distinct inputs always produce distinct outputs
- **Surjective functions** (onto): every element of the target set is mapped to by some input
- **Bijective functions**: functions that are both injective and surjective

Additionally, provide:
- The sets of all injections, surjections, and bijections between two given sets
- Predicates to determine whether such mappings exist between two sets

### Aggregation Operations
Support folding/reducing over all values in a function:
- Combine all function values using an associative, commutative binary operator and a base value
- Support folding over a specified subset of the domain indices

## Key Mathematical Properties

The definitions must correctly capture standard mathematical semantics:
- Injectivity means no two domain elements share the same image
- Surjectivity means the range equals the entire codomain
- Bijections establish a one-to-one correspondence between sets
- Inverse functions should correctly reverse the mapping when the original is injective
- Fold operations must be well-defined for associative, commutative operators regardless of evaluation order
