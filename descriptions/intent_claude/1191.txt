# Specification Request: Empty Set Semantics Validation

## Goal

Create a test harness to verify that a TLA+ model checker correctly implements the mathematical semantics of the empty set across various set-theoretic and sequence operations.

## System Description

This is not a distributed system or algorithm specification, but rather a **conformance test suite** for validating that a TLA+ tool (such as TLC) handles empty set edge cases according to standard mathematical definitions.

## Requirements

The specification should verify the following mathematical properties involving the empty set:

1. **Power set of empty set**: The set of all subsets of the empty set should contain exactly one element: the empty set itself.

2. **Distributed union of empty collection**: Taking the union of no sets should yield the empty set.

3. **Set comprehension over empty domain**: Filtering elements from an empty set should produce an empty set.

4. **Function with empty domain**: A function defined over an empty domain should be equivalent to an empty sequence/tuple.

5. **Existential quantification over empty set**: "There exists an element in the empty set such that..." should always be false.

6. **Universal quantification over empty set**: "For all elements in the empty set..." should always be true (vacuous truth).

7. **Domain of empty sequence**: The domain of an empty sequence should be the empty set.

8. **Descending integer ranges**: An integer range where the lower bound exceeds the upper bound should equal the empty set.

9. **Sequence set membership**: The empty sequence should be a member of the set of all sequences over any set, including the empty set.

10. **Sequences over empty set**: No non-empty sequence can be formed from elements of the empty set.

11. **Function spaces involving empty sets**: The set of functions from the empty set to any set should contain exactly the empty function; the set of functions from a non-empty set to the empty set should be empty.

12. **Union with empty set**: Including the empty set in a union operation should not change the result.

## Correctness Properties

All the above mathematical identities must hold. If any identity fails, the test should report an assertion failure indicating which specific property was violated.
