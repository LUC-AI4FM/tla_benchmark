# Specification Request: First Matching Element Selector

## System Overview

I need a formal specification for a sequence filtering operation that finds and returns the first element in a sequence that satisfies a given predicate condition.

## Functional Requirements

The system should model a selection operation on sequences with the following behavior:

1. **Input**: A sequence of integers and a boolean test condition (predicate)
2. **Operation**: Scan through the sequence from the beginning and locate the first element that passes the test
3. **Output**: Return that matching element, or an empty sequence if no element satisfies the condition

## Example Behavior

The specification should demonstrate this selection mechanism working on a concrete example:
- Start with a simple integer sequence
- Apply a predicate (such as testing for even numbers)
- Produce the result of the selection operation

## Key Properties to Verify

The specification should help verify:

1. **Correctness**: The returned element, if any, actually satisfies the predicate
2. **Minimality**: No earlier element in the sequence satisfies the predicate (the result is truly the *first* match)
3. **Completeness**: If any element in the sequence satisfies the predicate, the operation returns a result (not empty)
4. **Termination**: The selection process handles all cases, including empty sequences and sequences with no matching elements

## Purpose

This specification serves as a foundation for modeling systems that need to search through ordered collections and retrieve the first item meeting specific criteria—a common pattern in scheduling, resource allocation, and query processing systems.
