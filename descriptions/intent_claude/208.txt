# Specification Request: Incremental Set Summation

## System Description

I need a formal specification for a system that incrementally builds up a set of integers while maintaining a running total of their sum.

## Behavior Requirements

The system should:

1. Start with an empty collection and a counter initialized to zero
2. Repeatedly select integers from a fixed range (1 through some maximum value N) that haven't been added yet
3. For each selected integer, simultaneously add it to the collection and increase the running counter by that integer's value
4. Continue until all integers in the range have been added (or as long as unselected integers remain)

## Key Correctness Property

The critical invariant that must always hold: **the running counter must equal the mathematical sum of all integers currently in the collection**.

This property verifies that the incremental accumulation approach correctly tracks what would be computed by summing the entire set from scratch at any point in the execution.

## Purpose

This specification demonstrates the equivalence between an iterative accumulation process and a recursive set summation, ensuring that maintaining a running total produces the same result as computing the sum over the entire collection at each step.
