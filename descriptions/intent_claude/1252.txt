# Specification Request: Real-Time Bounds for Actions

## System Overview

I need a formal specification framework for reasoning about **real-time constraints** on system actions. The goal is to model systems where certain actions must occur within specified time bounds — not just eventually, but within concrete time limits measured against a continuous real-valued clock.

## Core Requirements

### Continuous Time Model

The specification must include a model of real time that:
- Represents time as a continuously advancing real number
- Ensures time always moves forward (never goes backward or stops)
- Guarantees time will eventually exceed any finite bound (time doesn't "freeze")
- Allows the system state to remain stable while only time advances

### Bounded Response Time for Actions

The primary capability needed is to express that a particular action in the system is constrained by **both lower and upper time bounds**:

1. **Upper bound (deadline)**: Once an action becomes possible, it must occur within a maximum time limit. The system cannot indefinitely delay performing an enabled action.

2. **Lower bound (minimum delay)**: An action cannot occur too quickly — there must be a minimum elapsed time before the action is permitted to happen.

The timing measurement should reset appropriately: when the action occurs, or when the action becomes disabled (meaning there's nothing to wait for), the "clock" tracking the action's timing should reset to zero.

## Key Correctness Properties

1. **Deadline enforcement**: If an action is continuously enabled, it must execute before the upper time bound expires.

2. **Minimum spacing**: The action cannot fire until the lower time bound has elapsed since the timer started.

3. **Progress of time**: Real time must continue to advance and cannot be blocked indefinitely.

## Intended Use

This framework should be composable with other specifications — allowing a designer to take an untimed specification of system behavior and add real-time constraints to specific actions, creating a system where correctness depends on meeting timing requirements.
