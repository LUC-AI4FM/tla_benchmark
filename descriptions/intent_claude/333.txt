# Specification Request: Age-Based License Eligibility System

## System Overview

I need a formal specification for a simple system that tracks whether a person is eligible to hold a license based on their age. The system should model the passage of time (years) and determine license eligibility by comparing a person's current age against a minimum required age.

## Core Requirements

The system must:

1. **Track the current year** as time progresses
2. **Determine a person's age** based on a fixed birth year and the current year
3. **Maintain license status** indicating whether the person currently holds or is eligible for a license
4. **Enforce age restrictions** such that a license can only be held once the person reaches a specified minimum age

## Configuration Parameters

The specification should be parameterized by:
- A birth year (e.g., 1980 represented in two-digit format as 80)
- A minimum age required for license eligibility (e.g., 18 years old)

## Correctness Properties

The specification must guarantee:

1. **Safety**: A person cannot have a license if they are below the minimum required age
2. **Consistency**: The license eligibility determination must correctly account for the relationship between current year, birth year, and minimum age threshold

## Context

This appears to model a Y2K-era scenario where years may be represented in two-digit format, which should be handled appropriately in age calculations. The specification should support verification using model checking tools with explicitly instantiated constant values.
