# Specification Request: Echo Algorithm for Distributed Networks

## System Overview

I need a formal specification of the **Echo algorithm**, which is a fundamental distributed algorithm used for collecting information or performing computations across all nodes in a network. The algorithm starts from a single initiator node and propagates through the network, with responses "echoing" back once all branches have been explored.

## System Requirements

### Network Model

The system operates on an undirected graph representing a distributed network where:
- The network consists of a set of nodes that can communicate with their neighbors
- The connectivity relationship between nodes must be **symmetric** (if A can reach B, then B can reach A)
- The connectivity must be **irreflexive** (no node has a connection to itself)
- The network must be **connected** (there exists a path between any two nodes)

### Algorithm Behavior

The algorithm should model the following behavior:
- One distinguished node acts as the **initiator** and starts the algorithm
- Messages propagate outward from the initiator through the network
- Each node, upon receiving its first message, forwards messages to all its other neighbors
- Once a node has received responses from all neighbors it contacted, it sends a response back toward the initiator
- The algorithm terminates when the initiator has received responses from all its neighbors

## Correctness Properties

The specification should guarantee:

1. **Termination**: The algorithm eventually completes, with the initiator knowing that all nodes have participated

2. **Complete Coverage**: Every node in the connected network is reached exactly once during the forward propagation phase

3. **Proper Acknowledgment**: The initiator only declares completion after all nodes have finished their local processing

## Verification Scope

For model checking purposes, I need to verify this algorithm works correctly on small network configurations, including fully-connected (mesh) topologies. The specification should be parameterized so that different network topologies and initiator choices can be tested without modifying the core algorithm logic.
