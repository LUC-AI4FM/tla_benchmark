# Specification Request: Incremental Set Construction with Cardinality Tracking

## System Overview

I need a formal specification for a simple system that incrementally builds a set of integers while maintaining an accurate count of the set's size. The system should demonstrate that a manually tracked size counter stays synchronized with the actual cardinality of the set as elements are added one at a time.

## Desired Behavior

The system should:

1. **Start from an empty state**: Initially, there should be an empty set and a size counter initialized to zero.

2. **Grow incrementally**: At each step, the system adds exactly one new element to the set and increments the size counter by one. The elements added should be distinct (using the current size value as the new element ensures uniqueness).

3. **Maintain consistency**: The size counter should always reflect the true number of elements in the set.

## Key Correctness Property

The critical invariant that must hold at all times is:

**The tracked size variable must equal the actual cardinality of the set.**

This property verifies that the manual bookkeeping of the size stays perfectly synchronized with the mathematical cardinality of the set contents throughout all system executions.

## Purpose

This specification serves as a test case for verifying that a model checker can correctly reason about recursive definitions (specifically, a recursive cardinality computation) and confirm that such computations match expected values during state exploration. The specification should support verification with bounded unfolding of recursive operators.
