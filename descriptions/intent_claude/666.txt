# Specification Request: Combinatorics Library Verification

## System Overview

I need a formal specification that tests and verifies the correctness of combinatorial operations. This should serve as a test suite or validation module for a combinatorics library.

## Goal

The specification should validate that standard combinatorial functions and operations behave correctly according to their mathematical definitions. This includes operations such as:

- Permutations and combinations
- Factorial calculations
- Binomial coefficients
- Set partitions and selections
- Sequence arrangements

## Requirements

1. **Mathematical Correctness**: All combinatorial operations must produce results consistent with established mathematical definitions and identities.

2. **Edge Case Handling**: The specification should verify correct behavior for boundary conditions, such as:
   - Empty sets or zero-length sequences
   - Single-element inputs
   - Cases where selection size equals the total size

3. **Identity Verification**: Standard combinatorial identities should hold, such as:
   - Pascal's triangle relationships
   - Symmetry properties of binomial coefficients
   - Relationships between permutations and combinations

## Correctness Properties

- Results must match expected values for known test cases
- Counting functions must return non-negative integers
- The cardinality of generated sets must equal the corresponding counting function
- No duplicate elements in result sets where uniqueness is required

## Purpose

This specification acts as a smoke test to ensure the foundational combinatorics operations are implemented correctly before they are used in more complex specifications that depend on them.
