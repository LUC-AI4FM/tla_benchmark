# Specification Request: Predicate Logic and CHOOSE Operator Test Suite

## Goal

Create a test specification to verify the correct behavior of first-order predicate logic operators and the CHOOSE operator in TLA+. This is essentially a conformance test suite for a TLA+ model checker's implementation of these fundamental logical constructs.

## System Description

The specification should be a static test harness (no meaningful state transitions) that evaluates a series of logical expressions and reports whether each produces the expected result. The system exists purely to validate the semantics of quantifiers and selection operators.

## Requirements

### Existential Quantification Tests
- Verify that existential quantification correctly identifies when at least one element in a set satisfies a predicate
- Confirm that both syntax forms of existential quantification behave identically
- Verify that existential quantification over an empty set always yields false
- Verify that existential quantification returns false when no element satisfies the predicate

### Universal Quantification Tests
- Verify that universal quantification correctly determines when all elements satisfy a predicate
- Confirm that both syntax forms of universal quantification behave identically
- Verify that universal quantification over an empty set always yields true (vacuous truth)
- Test universal quantification with sets containing duplicate elements

### CHOOSE Operator Tests (optional/extended)
- Verify that CHOOSE returns an element satisfying the given predicate
- Test CHOOSE with tuple patterns and Cartesian products
- Test CHOOSE with nested set expressions

### Multi-variable Quantification (optional/extended)
- Test quantification over multiple bound variables simultaneously
- Test quantification with tuple destructuring patterns
- Test combinations of Cartesian products and multiple variable bindings

## Correctness Properties

- Each test must either pass (print success) or fail (trigger an assertion)
- The specification should be satisfiable only when all logical operators behave according to standard predicate logic semantics
- Empty set quantification must follow classical logic: existential yields false, universal yields true

## Known Limitations to Document

The test suite should acknowledge that CHOOSE is not guaranteed to be deterministic across different set representations—the same logical set expressed with different element orderings may yield different CHOOSE results.
