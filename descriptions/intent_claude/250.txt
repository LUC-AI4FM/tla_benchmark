# Specification Request: Extended Bag (Multiset) Operations Library

## System Overview

I need a formal specification for an extended library of bag (multiset) operations that builds upon standard bag functionality. A bag is a collection where elements can appear multiple times, with each element having an associated count.

## Required Operations

The library should provide the following operations on bags of integers:

1. **Add Element**: Add a single occurrence of an element to a bag, incrementing its count by one.

2. **Remove Element**: Remove a single occurrence of an element from a bag, decrementing its count by one. If the element doesn't exist in the bag, the bag should remain unchanged.

3. **Remove All Occurrences**: Completely remove all occurrences of a specific element from a bag, regardless of how many times it appears.

4. **Sum of Bag**: Compute the weighted sum of all elements in a bag, where each element is multiplied by its count and all results are summed together.

5. **Product of Bag**: Compute the weighted product of all elements in a bag, where each element is raised to the power of its count (or equivalently, multiplied by itself count-many times) and all results are multiplied together.

## Correctness Properties

The operations must satisfy these properties:

- Adding an element should be equivalent to combining the bag with a singleton bag containing that element
- Removing an element should be equivalent to subtracting a singleton bag containing that element
- Removing an element not present in the bag should leave the bag unchanged
- Removing all occurrences of an element should result in a bag where that element has zero count
- The sum operation must correctly account for element multiplicities (e.g., element 3 appearing twice contributes 6 to the sum)
- The sum and product operations must handle negative integers correctly
- The product operation must correctly account for element multiplicities

## Context

This specification is intended to verify that extended bag operations behave correctly and consistently with the standard bag union and difference operations. The operations should work with bags containing integer elements with positive multiplicities.
