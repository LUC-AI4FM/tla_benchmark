# Specification Request: Internal Memory System with Multiple Processors

## System Overview

I need a formal specification for a shared memory system that handles read and write requests from multiple processors. The system should model how processors interact with a central memory through a request-response protocol.

## System Description

The system consists of:
- A shared memory that maps addresses to values
- Multiple processors that can issue memory operations (reads and writes)
- A communication interface between processors and the memory system

## Behavioral Requirements

Each processor should be able to:
1. **Submit a request**: A processor that is idle can send either a read or write request to the memory system, specifying an address (and a value for writes)
2. **Process the request**: The memory system executes the pending operation—for writes, it updates the memory at the specified address; for reads, it retrieves the current value from memory
3. **Receive a response**: After processing, the system sends a response back to the requesting processor (returning the read value or acknowledging the write), and the processor returns to an idle state

## Key Constraints

- Each processor can have at most one outstanding request at a time
- Processors must complete their current request-response cycle before initiating a new request
- Memory operations are atomic—each read or write executes as a single indivisible step
- The system must properly track which processors are idle, have pending requests, or are awaiting responses

## Correctness Properties

The specification must guarantee **type safety**: 
- Memory always remains a valid mapping from addresses to values
- Each processor's status is always in a well-defined state (ready, busy processing, or done)
- Any buffered data for a processor is always either a pending request, a response value, or empty (as appropriate for the processor's current state)

## Interface Requirements

The system should use a standard memory interface for communication, with proper send and reply operations that maintain the integrity of the processor-memory communication channel.
