Specify a simple two-variable state machine where both variables start at zero and can be updated according to constrained rules.

The system should model transitions where the first variable always becomes 1, while the second variable can either become 2, or take on the new value of the first variable (which would also be 1). When the second variable copies the first, they must simultaneously swap or mirror each other's new values.

The specification should define the allowed state transitions as a stuttering-allowed temporal property, meaning the system may also remain in its current state indefinitely.

Key requirements:
- Both variables initialize to zero
- Any actual state change must set the first variable to 1
- The second variable either becomes 2, or becomes equal to the first variable's new value
- The system should permit but not require progress (stuttering steps are allowed)
