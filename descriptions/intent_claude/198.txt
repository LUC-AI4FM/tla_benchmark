# Specification Request: Constant-Initialized Static System with Range Existence Check

## System Description

I need a formal specification for a very simple static system where a single value is initialized based on a configurable constant parameter and then remains unchanged throughout execution.

## Requirements

1. **Configuration**: The system should have a configurable constant that must be set to the value 1.

2. **Initialization**: The system state consists of a single integer value that starts equal to the configured constant.

3. **Behavior**: After initialization, the system state never changes - it remains static indefinitely.

## Correctness Properties

The key property to verify is an existence condition over a computed range:

- **Range Existence Invariant**: There must always exist a value equal to 3 within the integer range starting from one more than the constant up through 4. In other words, given the constant's value, the range from (constant + 1) to 4 must contain the number 3.

## Purpose

This specification appears designed to test or demonstrate how a model checker handles:
- Constant constraints and their interaction with invariants
- Range expressions that depend on constant values
- Existential quantification over dynamically-computed ranges

The invariant's satisfiability depends directly on the constant's value - if the constant is 1, the range 2..4 contains 3, making the invariant hold. Different constant values could cause the invariant to fail.
