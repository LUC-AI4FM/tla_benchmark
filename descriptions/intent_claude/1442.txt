# Specification Request: Cyclic Counter with Verification Scenarios

## System Overview

I need a formal specification for a simple cyclic counter that repeatedly cycles through a fixed set of values. The counter should increment and wrap around in a deterministic loop.

## Functional Requirements

The system should model a counter that:
- Starts at an initial value of zero
- Increments by one on each step
- Wraps back to zero after reaching a maximum value (specifically, cycling through values 0, 1, 2, and back to 0)

## Verification Properties

The specification should include several predicates designed to test different verification scenarios:

### Reachable State Conditions
- A predicate that identifies when the counter is at value 1 (should be satisfiable)
- A predicate that identifies when the counter reaches value 2 (should be satisfiable)
- A predicate for a value outside the reachable state space (should never be true)

### Transition Conditions
- A predicate that captures the specific moment when the counter wraps from its maximum value back to zero
- A predicate describing a transition that increments by more than one step (should never occur given the system's behavior)

## Additional Test Scenarios

The specification should also support a degenerate configuration where:
- The system can initialize but has no valid transitions (a "stuck" initial state)
- This is useful for testing verification tools against edge cases where action-level analysis has nothing to evaluate

## Purpose

This specification serves as a test harness for verification tooling, particularly for checking that tools correctly:
- Identify reachable vs. unreachable states
- Detect impossible vs. possible transitions
- Handle edge cases like specifications with no transitions
