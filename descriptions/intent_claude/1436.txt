# Specification Request: Infinite Empty Loop

## System Description

I need a formal specification of the simplest possible non-terminating process: a system that enters an infinite loop and does nothing forever.

## Behavioral Requirements

The system should:
- Start execution and immediately enter a perpetual loop
- Continue looping indefinitely without performing any actions or state changes
- Never terminate or reach a final state

## Purpose

This specification represents a minimal model of a non-terminating computation—essentially a "busy wait" or spin loop with no body. It could serve as:
- A base case for testing liveness properties
- A skeleton for modeling systems that must run continuously
- An example of a process that makes no progress

## Correctness Properties

The key property this system should exhibit:
- **Non-termination**: The system never reaches a completed state; it remains active forever
- **Stutter**: Since the loop body is empty, the system essentially stutters indefinitely without meaningful state transitions
