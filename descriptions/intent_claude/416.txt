# Specification Request: Prime Operator Behavior with Parameterized Actions

## System Overview

I need a formal specification that serves as a test harness to verify the correct behavior of primed variables when passed as arguments to parameterized actions. This is essentially a semantic test for how a temporal logic specification language handles the distinction between primed and unprimed values in operator parameters.

## Goal

The specification should demonstrate and verify the difference between two scenarios when updating a data structure based on a parameter:

1. **Using the next-state value**: When an action updates a field using the *new* (primed) value of a parameter variable
2. **Using the current-state value**: When an action updates a field using the *current* (unprimed) value of a parameter variable

## Requirements

### State Components
- A mapping/array structure that can be updated
- A simple variable that changes value during transitions

### Behavioral Requirements

The system should support two distinct transition patterns:

1. **Transition Type A**: Update an element of the mapping to reflect what the auxiliary variable *will become* in this step (its next-state value)

2. **Transition Type B**: Update an element of the mapping to reflect what the auxiliary variable *currently is* (its current-state value)

### Correctness Properties

The specification must verify:

1. When using the primed version of a parameter in an update, the mapping element should equal the new value of that parameter after the transition

2. When using the unprimed version of a parameter in an update, the mapping element should retain the old value of that parameter after the transition

3. These two behaviors must be distinguishable and produce different results

## Purpose

This specification serves as a regression test or conformance test to ensure that a model checker correctly interprets the scoping and evaluation timing of primed expressions when they appear within parameterized operator definitions. The key semantic question being tested is whether priming applies at the point of definition or the point of use.
