# Specification Request

## System Description

I need a formal specification for a simple two-state oscillating system. The system consists of two integer values that continuously swap with each other. One value starts at zero and the other starts at one, and at each step they exchange their values, creating an infinite alternating pattern.

## Behavioral Requirements

- The system should initialize with one component set to 0 and the other set to 1
- At every transition, the two components should swap their values
- The system should run indefinitely, alternating between its two possible states

## Correctness Properties

The specification should verify the following liveness properties:

1. **Reachability of valid state**: The system should eventually reach a state where the first component equals 1. This property should hold since the oscillation will naturally bring the system to this configuration.

2. **Unreachability of invalid state**: As a negative test case, verify that the system does NOT eventually reach a state where the first component equals 2. This value is impossible given the initial conditions and transition behavior.

## Testing Purpose

This specification is intended to test how a model checker handles temporal formulas with redundant or nested temporal operators (specifically, multiple "always" modalities stacked together). The core system logic is intentionally simple so that the focus remains on validating the correct processing of such formulas.
