# Specification Request: Variant (Tagged Union) Operations

## System to Model

I need a formal specification that tests and validates operations on **variant types** (also known as tagged unions or sum types). This is a utility specification to verify that a type system's variant operations behave correctly.

## Overview

Variant types allow a value to be one of several different types, each identified by a unique tag. For example, a value might be either an integer tagged as "A" or a record with a string field tagged as "B". The specification should verify that the core operations for working with such variants function as expected.

## Required Operations to Verify

The specification must test the following variant operations:

1. **Variant Construction**: Creating variant values with a tag name and an associated value of the appropriate type.

2. **Variant Membership**: Checking whether a variant belongs to a set of variants (standard set membership should work correctly with variants).

3. **Variant Filtering**: Given a set of variants with different tags, extracting only those variants matching a specific tag and unwrapping their values.

4. **Tag Extraction**: Retrieving the tag name from a variant value.

5. **Unsafe Value Extraction**: Extracting the underlying value from a variant when you assert you know its tag (with type-level guarantees only).

6. **Safe Value Extraction with Default**: Attempting to extract a value for a given tag, but returning a default value if the variant's actual tag doesn't match.

## Correctness Properties

The specification must verify as invariants:

- Constructed variants are properly recognized in set membership tests
- Filtering a set of variants by tag correctly yields only matching variants with their unwrapped values accessible
- Tag extraction returns the correct tag string
- Unsafe extraction returns the correct value when the tag matches
- Safe extraction with default returns the actual value when tags match, and returns the provided default when they don't

## Purpose

This specification serves as a **functional test suite** for variant type operations, ensuring the variant library/extension works correctly within the model checking framework.
