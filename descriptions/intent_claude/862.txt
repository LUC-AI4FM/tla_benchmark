# Specification Request: Single Packet Authorization (SPA) Protocol Security Analysis

## System Overview

I need a formal specification of a Single Packet Authorization (SPA) authentication system, with a focus on modeling potential security attacks against the protocol. The system involves clients authenticating to access protected servers through an SDP (Software-Defined Perimeter) gateway.

## System Components

The model should include:

1. **Legitimate Client**: A user with valid credentials (login ID and cryptographic key) attempting to authenticate and access a protected service
2. **SDP Server/Gateway**: The authorization server that validates SPA packets and controls access to protected resources
3. **Protected Server**: The backend service that clients want to reach after successful authentication
4. **Attacker**: A malicious actor attempting to gain unauthorized access, potentially sharing network characteristics (like source IP) with legitimate clients

## Key Behaviors to Model

- The SPA authentication flow where clients send specially crafted authorization packets
- NAT (Network Address Translation) scenarios where multiple entities may share the same apparent source IP address
- The attacker's ability to observe, replay, or forge authentication attempts
- Firewall rule dynamics that grant or deny access based on authentication state

## Correctness and Security Properties

The specification must allow verification of:

1. **Authentication Integrity**: Only clients with valid credentials should successfully authenticate
2. **Resistance to Replay Attacks**: Previously captured valid SPA packets should not grant access when replayed
3. **Resistance to Spoofing**: Attackers sharing network resources (NAT) with legitimate users should not gain unauthorized access
4. **Access Control Correctness**: The system should properly distinguish between authenticated and unauthenticated entities when granting access to protected services

## Configuration Parameters

The model should be parameterizable with network configurations (IP addresses, ports), authentication identifiers, and flags to enable/disable NAT scenarios for exploring different attack surfaces.
