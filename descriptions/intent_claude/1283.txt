# Specification Request: Staged Set Construction with Constrained Selection

## System Overview

I need a formal specification for a simple sequential system that performs set construction and constrained element selection across multiple stages. The system should exercise the model checker's handling of large set computations and selection operators during state transitions.

## Functional Requirements

The system operates in discrete stages, progressing through a fixed sequence of operations:

1. **Stage 1**: Construct the power set of a moderately large range of integers (e.g., 1 through 20), then select a subset from this collection where the sum of elements exceeds a threshold value (specifically, greater than 4).

2. **Stage 2**: Construct the power set of a smaller range of integers (e.g., 1 through 8) using a recursive computation approach, then again select a subset meeting the same summation threshold.

3. **Termination**: After completing both stages, the system should halt with no further transitions possible.

## Key Aspects to Model

- The system must track its current stage and maintain the constructed set and selected element at each point.
- Power set construction should be possible both through built-in operators and through explicit recursive definition.
- Element selection must use a deterministic choice operator constrained by a summation predicate.

## Correctness Properties

The specification should allow verification that:
- The system progresses through all stages in order
- At each stage, a valid selection is made (an element satisfying the constraint exists)
- The system eventually reaches a terminal state

## Performance Considerations

The specification should be suitable for testing model checker performance, particularly around:
- Evaluation of large set expressions during initial state computation
- Handling of constrained choice operators over large domains
- Comparison between built-in and recursively-defined set operations
