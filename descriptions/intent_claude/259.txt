# Specification Request: Record Field Access Operation

## System Description

I need a formal specification for a basic record field accessor operation. The system should model the fundamental operation of extracting a specific field value from a record data structure.

## Requirements

The specification should define an operation that:

1. Takes a record (structured data with named fields) as input
2. Returns the value stored in a designated field of that record
3. Works generically across different record types, as long as they contain the required field

## Key Properties

- **Determinism**: Given the same record input, the operation must always return the same value
- **Type Safety**: The operation should only be applied to records that actually contain the target field
- **Value Preservation**: The returned value must be exactly the value stored in that field, with no transformation

## Context

This is a foundational utility operation that would typically be used as a building block in larger specifications where record manipulation is needed. It represents the most basic form of field projection from a record type.
