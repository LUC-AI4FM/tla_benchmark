# Specification Request: Countdown Counter

## System Description

I need a formal specification for a simple countdown counter system. The system should model a counter that starts at some initial value and decrements by one at each step.

## Requirements

1. **Initialization**: The counter should begin at a configurable starting value (a constant parameter provided to the system).

2. **Behavior**: At each step, the counter should decrease its value by exactly one.

## Purpose

This specification will serve as a basic model for systems that count down from an initial value, such as:
- A simple timer mechanism
- A resource depletion model
- A countdown sequence controller

## Notes

The specification should be minimal and focus purely on the decrementing behavior. No termination condition or bounds checking is required at this level—the counter should simply decrement indefinitely.
