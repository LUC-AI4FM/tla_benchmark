Please write a TLA+ specification for a simple system that tracks two pieces of state: a boolean flag and a natural number counter.

**System Behavior:**
- The system should start with the boolean flag set to false and the counter initialized to 1.
- At each step, the counter should increment by 1, while the boolean flag can non-deterministically take on either true or false (modeling some unpredictable or arbitrary boolean condition).
- The system should allow for stuttering steps where no state change occurs.

**Purpose:**
This is a minimal model that combines deterministic progression (the incrementing counter) with non-deterministic choice (the boolean flag). It could serve as a foundation for testing or debugging, or as a teaching example demonstrating how to model both predictable and unpredictable state evolution in a specification.

No specific safety or liveness properties need to be checked beyond the basic specification—this is primarily a structural model of the described behavior.
