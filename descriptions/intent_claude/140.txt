Write a specification for a simple state machine with two integer variables that demonstrates conditional state transitions.

**System Description:**
Model a system with two integer values, each drawn from a small fixed set (such as {1, 2, 3}). The system should exhibit different transition behavior based on a condition involving the relationship between the two values.

**Behavioral Requirements:**
- Both values should initially be chosen nondeterministically from the allowed set.
- On each step, the first value may change while the second remains constant.
- The transition rule for the first value should depend on whether a specific condition holds: when the condition is true, the first value should be set to a specific constant; otherwise, it may transition nondeterministically to any value in the allowed set.

**Key Properties:**
- The second value never changes after initialization.
- The first value always remains within the allowed set.
- The system should allow stuttering (steps where no visible change occurs).
