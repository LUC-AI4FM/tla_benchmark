# Specification Request

I need a formal specification that defines a simple binary predicate over integers.

## System Description

The system should model a basic operator that takes two integer arguments and returns a boolean result. This is a foundational building block that could be used as part of a larger specification involving integer comparisons or relations.

## Requirements

1. Define an operator that accepts exactly two integer parameters
2. The operator should produce a boolean (true/false) result
3. The type signature must be properly specified to ensure type-safe usage when integrated with type-checking tools

## Correctness Properties

- The operator must be well-typed, accepting integers as inputs and producing a boolean output
- The specification should be compatible with static type analysis tools for TLA+

## Purpose

This serves as a minimal specification to establish correct typing conventions for multi-argument operators in TLA+, particularly ensuring that the function type notation is handled correctly by analysis tools.
