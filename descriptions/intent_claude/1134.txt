# Specification Request: Color Predicates and Bit Vector Computation

## System Overview

I need a formal specification for a system that defines and evaluates "color predicates" over finite sets of states, along with an efficient bit-vector-based computation method.

## Core Concepts

The system should model **color predicates**, which are conditions that can be checked against sets of states. There are two kinds of predicates:

1. **Universal predicates ("every")**: Satisfied when *all* states in a given set belong to a designated "good" set
2. **Existential predicates ("some")**: Satisfied when *at least one* state in a given set belongs to a designated "bad" set

## Required Properties

### Compositionality over Union

The specification must establish that predicate satisfaction is compositional with respect to set union:
- For universal predicates: the union of two state sets satisfies the predicate if and only if *both* individual sets satisfy it
- For existential predicates: the union of two state sets satisfies the predicate if and only if *at least one* of the individual sets satisfies it

### Bit Vector Representation

The specification should define how to encode state sets as bit vectors (boolean arrays indexed by position) using an enumeration of the finite state space. It must then prove that predicate satisfaction can be computed using bitwise operations on these vectors:
- Universal predicates can be evaluated using bitwise AND and equality comparison
- Existential predicates can be evaluated using bitwise AND and a non-zero check

## Verification Goals

The specification should support model checking of the key theorems on small finite instances (e.g., 4 states) to validate:
1. The union compositionality theorem for both predicate types
2. The correctness of the bit vector computation method as equivalent to the set-theoretic definition

## Purpose

This formalization provides a foundation for efficient implementation of predicate evaluation in systems that need to track which subsets of states satisfy certain universal or existential conditions, with proven-correct bitwise computation methods.
