Write a specification for a simple state transition system that demonstrates tuple-based existential quantification over a Cartesian product of integer ranges.

**System Description:**
Model a system with two integer state components that can be updated simultaneously by selecting a pair of values from predefined ranges.

**Behavior Requirements:**
- The system should start with both state components initialized to zero.
- In each transition, the system non-deterministically selects a pair of values: the first value from a small range of integers (e.g., 1 to 2), and the second value from another small range (e.g., 3 to 4).
- Both state components are updated together in a single atomic step based on the selected pair.

**Key Characteristics:**
- The selection of the value pair should be expressed as choosing a tuple from the Cartesian product of the two integer ranges.
- The specification should exercise existential quantification over tuples rather than nested quantification over individual variables.

**Purpose:**
This specification serves as a test case for verifying that a model checker correctly handles existential quantification with tuple unpacking over Cartesian products of sets.
