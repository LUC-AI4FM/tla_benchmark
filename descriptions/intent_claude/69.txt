# Specification Request: Symbolic Constant Generation Independence

## System to Model

A specification testing framework that generates symbolic constants for model checking, specifically focusing on the behavior of a constant generation primitive when called multiple times.

## Requirements

The system should model the generation of symbolic integer constants where:

1. **Independent Generation**: When the constant generation mechanism is invoked multiple times (even with identical parameters), each invocation must produce an independently chosen value. Two separate calls to generate a constant should not be constrained to return the same value.

2. **Distinct Values Possible**: It must be possible for two independently generated constants to have different values. The system should not deadlock when requiring that two generated constants are unequal.

## Correctness Properties

1. **No Spurious Deadlocks**: A specification that generates two constants and requires them to be different must have valid initial states—it should not deadlock due to the generator incorrectly producing identical values for separate generation calls.

2. **Parameter Independence**: The ability to generate distinct values should hold regardless of whether the generation calls use the same arguments or different arguments.

## Context

This is a regression test scenario for a symbolic model checker's constant generation feature. The underlying bug being guarded against is one where the generator would incorrectly reuse the same symbolic constant when called multiple times with identical parameters, causing specifications to spuriously deadlock when they legitimately require two generated values to differ.
