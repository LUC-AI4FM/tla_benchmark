# Specification Request

I need a formal specification to verify a basic property of set theory as it relates to finite set cardinality.

## System Description

This is not a dynamic system specification per se, but rather a verification that the mathematical foundations for counting elements in finite sets work correctly. Specifically, I need to confirm that the cardinality operation behaves as expected for fundamental set constructions.

## Requirements

The specification should establish that:

1. The system can reason about sets and their sizes using standard finite set operations.

2. The cardinality function correctly counts the number of elements in a set.

## Key Correctness Property

The critical property to verify is that a set containing exactly one element (specifically, a singleton set whose only member is the empty set) has cardinality equal to 1.

## Purpose

This specification serves as a basic sanity check or regression test to ensure that the cardinality operator properly distinguishes between a set being empty versus a set containing the empty set as an element. The empty set `{}` is a valid set element, and a set containing it should have size 1, not 0.
