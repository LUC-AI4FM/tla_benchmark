# Specification Request: Bitwise Operations Library for Natural Numbers

## Goal

Create a TLA+ utility library that provides standard bitwise operations on non-negative integers. Since TLA+ does not have built-in support for bitwise operations, this library should implement them mathematically, treating integers as their binary representations.

## Required Operations

The library should provide the following bitwise operations for non-negative integers (natural numbers including zero):

1. **Bitwise AND**: Takes two non-negative integers and returns a new integer where each bit is 1 only if both corresponding input bits are 1.

2. **Bitwise OR**: Takes two non-negative integers and returns a new integer where each bit is 1 if at least one of the corresponding input bits is 1.

3. **Bitwise XOR (Exclusive OR)**: Takes two non-negative integers and returns a new integer where each bit is 1 if exactly one of the corresponding input bits is 1.

4. **Bitwise NOT**: Takes a non-negative integer and flips all bits within the number's binary representation (treating only the significant bits, not infinite leading zeros).

5. **Logical Right Shift**: Takes a non-negative integer and a shift amount, returning the result of shifting the binary representation to the right by the specified number of positions, with zeros filling in from the left.

## Requirements

- All operations must be defined purely mathematically using integer arithmetic, without relying on any external bitwise primitives.
- Operations should be usable in infix notation where natural (AND, OR, XOR).
- The operations must handle the case where the two input operands have different magnitudes.
- The library should be self-contained and reusable by other TLA+ specifications that need bitwise manipulation of integers.

## Correctness Properties

The operations must satisfy the standard mathematical equivalents of bitwise operations:
- AND, OR, and XOR should be commutative
- Results should match the expected behavior when treating integers as binary sequences
- Right shift by n positions should be equivalent to integer division by 2^n (for non-negative integers)
