# Specification Request: Nondeterministic Value Selection System

## System Overview

I need a formal specification for a simple system that repeatedly selects values from a bounded range in a nondeterministic manner.

## Functional Requirements

The system should:

1. **Initialize with a valid selection**: Start by picking some value from the range 1 through 10 (inclusive).

2. **Continuously select new values**: At each step, the system nondeterministically chooses a new value from the same range (1 through 10).

3. **Use a callback-style selection mechanism**: The selection process should be abstracted such that a "picker" mechanism can invoke a callback with any valid value from the range. This models scenarios where value selection is delegated to some external or abstract chooser.

## Correctness Properties

The specification must guarantee:

- **Positive value invariant**: The selected value must always be strictly positive (greater than zero). This should hold in all reachable states of the system.

## Purpose

This specification serves as a minimal example demonstrating:
- How to model nondeterministic choice over a finite set
- How to express callback-style or higher-order patterns in a specification
- Basic safety property verification for bounded value selection
