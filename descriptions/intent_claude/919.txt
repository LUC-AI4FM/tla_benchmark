# Specification Request: Asynchronous Communication Channel

## System Description

I need a formal specification of a basic asynchronous communication channel that allows a sender to transmit messages to a receiver. This models the fundamental abstraction of message-passing communication between two parties.

## Required Behavior

The system should support two core operations:
1. **Sending**: A sender can place a message into the channel
2. **Receiving**: A receiver can retrieve a message from the channel

The channel acts as an intermediary buffer between the sender and receiver, decoupling their operations.

## Correctness Properties

The specification must guarantee **type correctness**: the channel state must always remain within its valid domain of values throughout all possible executions. Specifically, the channel should only ever contain well-formed messages or be in a well-defined "empty" state.

## Verification Requirements

I need a machine-checked proof that type correctness is an invariant of the system—that is, if the system starts in a valid initial state, it will remain type-correct after any sequence of send and receive operations (including stuttering steps where no action occurs).
