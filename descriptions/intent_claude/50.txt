# Specification Request: Minimal State Machine with Invariant Violation

## System Overview

I need a formal specification for the simplest possible state machine that demonstrates an invariant violation scenario. This is essentially a "smoke test" or diagnostic specification.

## System Description

The system should model a trivial state machine with a single integer state variable that:

1. **Initialization**: The initial state should be unconstrained (any value is acceptable)
2. **Transitions**: The system should have a stuttering behavior where the state remains unchanged between transitions

## Correctness Properties

The specification must include an invariant that is **always false**. This is intentionally designed to fail verification, serving as a test case to confirm that a model checker correctly identifies invariant violations.

## Purpose

This specification appears to be designed for one of the following purposes:
- Testing model checker functionality to ensure it properly detects invariant violations
- Demonstrating what happens when a specification has an overly permissive initial state (no constraints)
- Serving as a minimal failing example for educational or debugging purposes

## Expected Behavior

When verified, this specification should immediately fail because the invariant can never be satisfied. The model checker should report a counterexample on any initial state.
