# Specification Request: Initial State Generation Behavior in TLA+ Model Checkers

## System to Model

I need a formal specification that explores and documents how a TLA+ model checker generates initial states when the initialization predicate contains various combinations of conjunctions, disjunctions, and variable assignments.

## Goal

The specification should serve as a test harness or reference model that demonstrates the different ways initial states can be produced depending on the syntactic structure of the Init predicate. Specifically, it should reveal how the order of conjuncts, the presence of tautological disjunctions, and the use of logical transformations (like double negation) affect the number and identity of initial states generated.

## Requirements

1. **Single variable system**: The system should use a single state variable that can take on distinct integer values, allowing clear observation of which initial states are generated.

2. **Multiple initialization clauses**: The Init predicate should be composed of several alternative initialization formulas, each demonstrating a different structural pattern:
   - Assignment followed by a tautological disjunction
   - Tautological disjunction followed by an assignment
   - Logically transformed tautologies (e.g., double negation) combined with assignments
   - Assignments combined with unsatisfiable disjunctions
   - Nested disjunctions with mixed satisfiability
   - Simple direct assignments

3. **Static behavior**: After initialization, the system should not change state (stuttering only), as the focus is purely on initial state generation.

## Correctness Properties

The key concern is understanding **which initial states appear exactly once** versus which might be duplicated due to the model checker exploring multiple branches of tautological disjunctions. The specification should help verify:

- The model checker produces a minimal, non-redundant set of initial states
- Unsatisfiable initialization clauses correctly produce no states
- The syntactic position of variable assignments relative to other predicates affects state generation behavior
