Write a specification to test the behavior of a sequence filtering operation.

**System Description:**
A test harness that verifies the correctness of filtering elements from a sequence based on various predicate functions. The system should confirm that a standard sequence-filtering mechanism correctly selects elements that satisfy a given condition.

**Requirements:**

1. The specification should test filtering a sequence of integers using different selection criteria:
   - A predicate that accepts all elements (always true)
   - A predicate that rejects all elements (always false)
   - A predicate that selects only even numbers
   - A predicate that selects numbers greater than a threshold value

2. **Correctness Properties:**
   - When filtering with an always-true predicate, the result must be identical to the original sequence
   - When filtering with an always-false predicate, the result must be an empty sequence
   - When filtering for even numbers, only the even elements should remain, preserving their original order
   - When filtering by a numeric comparison, only elements satisfying that comparison should remain, preserving order

The specification serves as a validation suite to ensure the sequence selection operation behaves correctly across edge cases (all pass, none pass) and typical filtering scenarios (partial selection based on element properties).
