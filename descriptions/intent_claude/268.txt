# Specification Request: Record Operations Test Suite

## System to Model

A test harness for verifying the correctness of fundamental record (struct) operations in a specification language. The system should validate that basic record manipulation primitives work as expected.

## Goal

Create a formal verification of record-related operations to ensure they behave correctly. This serves as a functional test suite that can be checked as invariants, confirming that the underlying record semantics are sound.

## Requirements

The specification must verify the following capabilities for records (key-value structures with named fields):

1. **Record Construction**: Creating individual records with specific field names and values should produce non-empty, valid data structures.

2. **Set of Records Generation**: Constructing the set of all possible records from given domains for each field should correctly enumerate all combinations.

3. **Polymorphic Field Access**: Accessing a field by name should work uniformly across records of different shapes, as long as the requested field exists. The operation should be agnostic to other fields present in the record.

4. **Polymorphic Field Update**: Updating a specific field's value should work correctly regardless of what other fields exist in the record, preserving the record's structure while modifying only the targeted field.

5. **Domain Extraction**: Retrieving the set of field names from a record should return consistent results for records sharing the same field names, regardless of the types of values those fields hold.

6. **Existential Quantification over Record Sets**: It should be possible to quantify over sets of records and access their fields within predicates.

## Correctness Properties

All of the above operations must satisfy their expected semantics simultaneously. The test suite should pass as an invariant of a trivial state machine, meaning these properties must hold in every reachable state (which, given the minimal state machine, effectively means they must hold unconditionally as mathematical facts about record operations).
