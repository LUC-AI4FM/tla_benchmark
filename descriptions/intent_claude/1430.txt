# Specification Request

## System to Model

A simple two-state toggle system that alternates between two boolean states indefinitely.

## Behavior Requirements

The system should:
1. Start in an initial "true" or "on" state
2. Toggle to the opposite state at each step (true becomes false, false becomes true)
3. Allow stuttering steps where no change occurs

## Key Correctness Property

The specification should verify that a particular temporal property holds. Specifically, the property of interest involves the system's behavior with respect to state changes being appropriately "boxed" (always holding) when evaluated through higher-order operator compositions.

## Additional Context

The main purpose of this specification appears to be testing or demonstrating how temporal formulas (particularly those using the "always" modality over state transitions) behave when:
- Passed through higher-order operators that accept operator arguments
- Defined using LET expressions versus top-level definitions
- Composed through identity-like wrapper functions

The specification should confirm that defining temporal properties inline within LET expressions produces equivalent results to defining them at the module's top level, particularly when those definitions involve operators that take other operators as parameters.
