Write a TLA+ specification for Lamport's Fast Mutex algorithm running on N processes, where process identities are drawn from 1 to N. The system uses shared variables representing a "last writer" register x, a "doorway" register y, and a per-process boolean flag array b. There are two syntactically distinct process groups: a single special process with identity 1, and a parameterized group covering identities 2 through N, both executing the same logical protocol. Each process repeatedly attempts to enter a critical section by announcing interest via its flag, writing its identity to x and conditionally to y, then either backing off (if y is already claimed) or verifying it won the race by scanning all flags. A process that loses the race waits until y is clear before retrying. All processes must run under weak fairness. The key safety property is mutual exclusion: no two distinct processes may be in the critical section simultaneously. The key liveness property is that some process reaches the critical section infinitely often. The module serves as a test that the PlusCal translation correctly handles two differently-typed process definitions within the same algorithm.
