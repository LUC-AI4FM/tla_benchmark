# Specification Request: Round-Robin Mutual Exclusion Protocol

## System Overview

I need a formal specification for a mutual exclusion protocol that coordinates access to a critical section among a fixed number of concurrent processes using a strict round-robin (alternating) turn-based approach.

## System Description

The system consists of N processes (numbered 0 through N-1) that repeatedly cycle through phases of non-critical work, attempting to enter a critical section, executing within the critical section, and then exiting. Access to the critical section is controlled by a shared turn indicator that determines which process is currently permitted to enter.

## Functional Requirements

1. **Process Behavior**: Each process continuously loops through:
   - Performing non-critical section work
   - Waiting for permission to enter the critical section
   - Executing in the critical section
   - Releasing access and passing the turn to the next process

2. **Turn-Based Entry**: A process may only enter the critical section when it is explicitly that process's turn.

3. **Round-Robin Handoff**: After a process exits the critical section, it must pass the turn to the next process in sequence (wrapping around from process N-1 back to process 0).

4. **Fairness**: Each process should be guaranteed to eventually make progress (weak fairness for all processes).

## Correctness Properties

The specification must guarantee:

1. **Mutual Exclusion**: At most one process may be in the critical section at any given time.

2. **Starvation Freedom**: Every process that wishes to enter the critical section will eventually be able to do so (guaranteed by the round-robin ordering combined with fairness).

3. **Strict Ordering**: Processes enter the critical section in a fixed cyclic order (0, 1, 2, ..., N-1, 0, 1, ...).

## Parameters

- **N**: The number of processes in the system (must be a positive integer)
- The initial turn may be assigned to any valid process
