Please write a TLA+ specification for a simple conditional operator that demonstrates the use of a CASE expression with a fallback clause.

**System Description:**
The specification should define a single operator that evaluates a conditional expression. The expression should check a condition and return one value if the condition holds, otherwise return a default fallback value.

**Requirements:**
- Use a CASE expression structure with an "other" (default) branch
- The primary condition should always be true
- When the primary condition matches, return false
- The fallback case should return true (though it will never be reached given the always-true condition)

**Purpose:**
This is a minimal demonstration specification to verify that CASE expressions with OTHER clauses are properly handled, particularly for XML export/parsing scenarios. The specification serves as a test case for tooling rather than modeling any real distributed system or algorithm.
