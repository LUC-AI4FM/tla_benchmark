# Specification Request: Variant Data Type Library

## System Overview

I need a formal specification for a **variant (tagged union) data type library** that provides fundamental operations for working with discriminated unions in a specification language. This library should enable mixing values of different shapes or types into unified collections while maintaining the ability to distinguish and extract values by their associated tags.

## Core Requirements

### Data Representation

The system must support:

1. **A unit value** - A canonical representation for variants that don't need to carry any payload data. This enables defining enumeration-like variants (e.g., representing simple choices like colors or states without associated data).

2. **Tagged value construction** - A way to wrap any value with a string tag, creating a variant that carries both the tag identifier and the wrapped value.

### Required Operations

The library must provide these fundamental operations:

1. **Construction** - Create a variant by associating a tag name with a value.

2. **Filtering** - Given a set of variants and a tag name, extract all values that were tagged with that specific tag (unwrapping them in the process).

3. **Tag inspection** - Retrieve the tag name associated with a given variant value.

4. **Safe extraction with default** - Attempt to extract the value associated with a specific tag; if the variant has a different tag, return a provided default value instead.

5. **Unsafe extraction** - Extract the value assuming a specific tag, without checking (behavior undefined if the tag doesn't match).

## Correctness Properties

1. **Tag preservation** - Inspecting the tag of a constructed variant must return the original tag used during construction.

2. **Value preservation** - Extracting from a variant with its correct tag must return the original wrapped value.

3. **Filter soundness** - Filtering a set by a tag must return exactly the unwrapped values of variants carrying that tag.

4. **Safe extraction correctness** - Safe extraction must return the wrapped value when tags match, and the default value otherwise.

## Design Goals

- The library should work as an untyped implementation that can also be used with type systems that enforce variant type safety
- Operations should compose naturally with standard set and function operations
- The representation should be simple enough to reason about in formal proofs
