# Specification Request: TLA+ Model Checker Fingerprinting Test for Set Representations

## Goal

Create a test specification to verify that a TLA+ model checker correctly identifies equivalent set values as identical states, regardless of how those sets are syntactically constructed or expressed.

## System Description

This is a test harness for validating the state fingerprinting mechanism of a TLA+ model checker. The specification should define a system with state components holding various types of set-based values (simple sets, sets of strings, record sets, and function sets). The system should then attempt transitions that re-express these same values using alternative but semantically equivalent constructions.

## Requirements

1. **Initial State**: The system should start with state components initialized to specific set values, including:
   - A simple numeric set
   - A set of string values
   - A set of records with multiple fields
   - A set of functions (a function space)

2. **Transitions**: The system should have transitions that assign values to state components using various equivalent expressions, such as:
   - Sets with duplicate elements (which should collapse to the same set)
   - Sets with elements in different orders
   - Range expressions that produce the same set
   - Set comprehensions that filter or map to the same result
   - Domain extractions that yield equivalent string sets
   - Function spaces with reordered domain/range specifications

3. **Key Correctness Property**: The model checker should find **exactly one distinct state**. Despite the multiple syntactic ways of expressing the same set values, the fingerprinting mechanism must recognize them all as identical, producing no new states beyond the initial state.

## Purpose

This specification serves as a regression test to ensure the model checker's fingerprint computation for sets is based on semantic equality (the actual membership of sets) rather than syntactic representation. If the checker incorrectly treats equivalent sets as distinct states, it would report multiple states instead of one, revealing a fingerprinting bug.
