# Specification Request

## System to Model

A simple bounded counter that starts at zero and increments by one on each step, with an upper limit preventing it from exceeding a maximum value (10).

## Required Behavior

1. The counter should initialize to zero
2. On each step, the counter increases by exactly one
3. The counter must never exceed the value 10 (this acts as a bound on the state space)

## Key Correctness Property

The system should be checked against an invariant that the counter never reaches the value 2. This invariant is expected to be **violated**, producing a counterexample trace.

## Verification Goal

This specification is designed as a **test case for model checker tooling**, specifically to verify that:

1. When the invariant is violated, the model checker produces a correct counterexample showing the path from the initial state (0) through intermediate states (1) to the violating state (2)
2. The model checker's introspection capabilities correctly report metadata about the specification, including:
   - Which invariants were checked and how many states they covered
   - Which actions were explored, with counts of generated and distinct states
   - Initial state coverage information
   - Variable tracking information
   - Source location information for all named elements

The postcondition should confirm that the counterexample structure and the specification metadata match expected values, validating that the model checker's reporting features work correctly.
