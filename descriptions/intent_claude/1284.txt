# Specification Request: TLA+ Model Checker Simulation Comparison Framework

## System Overview

I need a test harness that compares the performance of different simulation strategies in the TLA+ model checker (TLC). Specifically, the system should run TLC's simulator multiple times with different configurations and collect results to evaluate how reinforcement learning-guided simulation compares to baseline random simulation.

## Goal

The purpose is to experimentally evaluate whether reinforcement learning (RL) techniques can improve the efficiency of state space exploration in TLC's simulation mode. The framework should automate running a target specification (a Calculator model) under both standard simulation and RL-enhanced simulation with various reward parameter settings.

## Requirements

### Baseline Execution
- Run TLC in simulation mode against a target specification using standard (non-RL) exploration
- Execute with extended statistics collection enabled for performance measurement
- Use fixed random seeds to ensure reproducibility across runs

### Reinforcement Learning Variant Testing
- Run the same specification with RL-guided simulation enabled
- Test multiple reward values systematically (both positive and negative rewards of varying magnitudes)
- Each reward configuration should be tested independently

### Execution Parameters
- Simulations should run for a substantial number of traces (thousands) to gather meaningful statistics
- Each trace should explore to significant depth (hundreds of steps)
- The framework should be parameterized by a revision/version tag for tracking experiments

### Correctness Properties

1. **Successful Execution**: All simulation runs (both baseline and RL variants) must complete successfully without errors
2. **Coverage**: The framework must test the full range of specified reward values
3. **Reproducibility**: Fixed fingerprint and seed values ensure deterministic behavior for comparison purposes

### Output Requirements
- Report successful completion of baseline runs
- Report results for each reward value tested
- Flag any execution errors clearly with diagnostic information

## Context

This is a meta-level testing framework—it doesn't model a distributed system itself, but rather orchestrates external tool invocations to benchmark model checking strategies. The "Calculator" specification being tested is a separate concern; this framework focuses on the experimental methodology for comparing simulation approaches.
