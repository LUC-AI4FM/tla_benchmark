Specify a TLA+ model of Dijkstra's distributed termination detection algorithm for a ring of N nodes (EWD 840). There is a set of computational nodes arranged in a ring, each of which can be active or inactive and colored white or black. Active nodes may send messages to other nodes (reactivating them) and may spontaneously become inactive. A token circulates around the ring in one direction, carrying a color, used by a background detection algorithm. When a node sends a message to a higher-numbered node, it turns black. The token is blackened when it passes through a black node, and nodes whiten themselves as the token passes. Node 0 initiates a new probe whenever it holds the token and either the token or itself is black. The system must guarantee weak fairness of the token-passing actions.

The key safety property is that termination detection is only declared when all nodes are truly inactive: specifically, whenever the token is at node 0, white, and node 0 is itself white and inactive, then every node must be inactive. The key liveness property is that if all nodes are indeed inactive, termination is eventually detected. Additionally, the specification should maintain Dijkstra's inductive invariant relating the token position and color to node activity and colors.
