# Specification Request: Graph Theory Definitions Library

## Overview

I need a formal specification that provides foundational definitions and operations for working with graph structures. This should serve as a reusable library of graph-theoretic concepts that can be imported into other specifications involving graph-based systems or algorithms.

## System Description

The specification should define mathematical graph structures and provide a comprehensive set of predicates and operations for reasoning about them. It must support both directed and undirected graphs, with graphs represented as structures containing a set of nodes and a set of edges (where edges are ordered pairs of nodes).

## Required Definitions

### Graph Structure Predicates
- A way to determine if a structure is a valid directed graph (edges must connect nodes within the graph)
- A way to determine if a graph is undirected (edges exist symmetrically in both directions)
- Generation of all possible subgraphs of a given graph
- A transpose operation that reverses edge directions

### Path and Connectivity
- Definition of what constitutes a valid path through a graph
- Definition of simple paths (paths with no repeated nodes)
- Ability to determine if two nodes are connected
- An efficient connectivity computation (inspired by Warshall's algorithm) for determining reachability between all node pairs
- Strong connectivity checking (all nodes can reach all other nodes)

### Tree Structure
- Verification that a graph forms a tree rooted at a specific node (single path from each node to root)

### Graph Operations
- Union of two graphs (combining nodes and edges)
- Bipartiteness checking with respect to given partitions

### Cycle Detection
- Detection of whether a graph contains any cycles
- Verification that a directed graph is acyclic (DAG property)

### Node Relationships
- Finding immediate successors and predecessors of a node
- Finding successors/predecessors of a set of nodes
- Computing all ancestors of a node (via transitive closure)
- Computing all descendants of a node (via transitive closure)

### Degree Calculations
- In-degree of a node (number of incoming edges)
- Out-degree of a node (number of outgoing edges)

### Special Node Sets
- Identification of root nodes (nodes with no predecessors)
- Identification of leaf nodes (nodes with no successors)

### Graph Construction
- Definition of an empty graph
- Generation of all possible graphs over a given node set

## Key Properties

The definitions must be mathematically precise and suitable for use in formal verification. The connectivity computation should be designed for efficiency when evaluated by model checkers, allowing results to be cached rather than recomputed. All operations should handle finite graphs with finite node and edge sets.
