# Specification Request: Set Membership Witness Tracking

## System Overview

I need a formal specification for a simple system that tracks whether a witness element has been found within a structured mathematical set. The system should model the concept of searching for or identifying elements within sets of functions.

## Requirements

### State Components

The system should maintain:
1. A witness value that belongs to a specific set of functions (functions mapping boolean values to integers)
2. A flag indicating whether a matching element has been found

### Behavior

- The system should initialize with a witness drawn from a constrained set of possible function values
- After initialization, the system state remains stable (no dynamic transitions)

### Correctness Properties

The specification must verify:
- **Not Found Invariant**: The "found" flag should remain false throughout execution

## Purpose

This specification serves as a test case for model checking tools to correctly handle complex set constructions, specifically sets whose elements are themselves sets of functions (function spaces). The goal is to verify that the model checker can properly reason about nested set membership and function set representations.

## Context

This is primarily a validation specification to ensure formal verification tools correctly process and analyze specifications involving:
- Function sets with specific domain and codomain constraints
- Sets containing function set elements
- Type annotations for complex mathematical structures
