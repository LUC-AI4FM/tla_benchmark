# Specification Request: Binary Search Algorithm with Bounded Integer Arithmetic

## System to Model

A binary search algorithm that finds a target key within a sorted sequence of integers, operating under the constraints of fixed-width machine integer arithmetic.

## Goal

Create a formal specification of binary search that accounts for real-world limitations of computer arithmetic—specifically, the possibility of integer overflow when computing indices. The specification should model how binary search behaves when intermediate calculations (such as computing the midpoint of two indices) must fit within bounded signed or unsigned integers of a specified bit width.

## Requirements

### Inputs
- A sequence of integers representing the sorted array to search
- A target key value to locate within the sequence
- A bit width parameter defining the size of machine integers (e.g., 32 or 64 bits)

### Functional Requirements
- The algorithm should search for the target key within the input sequence
- The search should use the binary search approach of repeatedly narrowing the search range by examining the middle element

### Arithmetic Constraints
- All index calculations must respect the bounds of signed integers for the given bit width
- All index calculations must also consider unsigned integer bounds where applicable
- The specification must account for potential overflow when computing midpoint indices (the classic `(low + high) / 2` overflow bug)

### Correctness Properties
The specification should enable verification of:
1. **Termination**: The search eventually completes
2. **Correctness**: If the key exists in the sequence, it is found; if not, the algorithm correctly reports its absence
3. **Overflow safety**: No arithmetic operation produces a value outside the representable integer range
4. **Index safety**: All array accesses use valid indices within the sequence bounds

## Context

This is intended as an educational specification demonstrating how to formally model algorithms that must operate within realistic hardware constraints, particularly focusing on the subtle bugs that can arise from integer overflow in seemingly simple calculations.
