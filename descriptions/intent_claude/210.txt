# Specification Request: Iterative Factorial Verification

## System Overview

I need a formal specification that models the computation of the factorial function and verifies that an iterative computation method produces the same results as the mathematical definition.

## What Should Be Modeled

The system should model a step-by-step iterative process for computing factorial values, where each step computes the factorial of the next integer by multiplying the previous result by the current number. Alongside this iterative computation, the system should track what the factorial value *should* be according to its recursive mathematical definition.

## Behavioral Requirements

1. The system should start at the first positive integer with factorial value 1
2. At each step, the system should advance to the next integer
3. The iteratively computed factorial should be updated by multiplying the previous computed value by the current integer
4. The specification-based factorial should reflect the true mathematical factorial of the current integer

## Correctness Property

The key invariant that must hold is: **the iteratively computed factorial must always equal the mathematically-defined factorial for the current integer**.

This ensures that the simple iterative algorithm (which just keeps a running product) correctly implements the factorial function at every step of the computation.

## Purpose

This specification serves to verify that a straightforward iterative factorial algorithm—which avoids recursion by maintaining a running product—is equivalent to the recursive mathematical definition of factorial. The model should allow checking this equivalence across a bounded range of input values.
