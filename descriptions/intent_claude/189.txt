Please write a TLA+ specification for a simple polymorphic set membership function.

**System Description:**
I need to model a generic function that takes two values of the same type and uses set membership to determine which value to return. The function should create a singleton set containing the first argument, then check if the second argument is a member of that set. If the second argument is found in the set, return the first argument; otherwise, return the second argument.

**Key Requirements:**
- The function must be polymorphic, working with any type
- It should leverage set containment as the decision mechanism
- The logic is essentially: if both arguments are equal, return the first; otherwise return the second

**Correctness Property:**
When the function is called with two identical values (e.g., both arguments are 1), it must return that same value. This verifies that the set membership check correctly identifies when the second argument equals the first.
