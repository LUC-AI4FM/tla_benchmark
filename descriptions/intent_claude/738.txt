# Specification Request: Balance Scale Weighing Puzzle

## System to Model

I need a formal specification that solves a classic weighing puzzle: Given a stone of a certain total weight, find how to divide it into a specified number of pieces such that any integer weight from 1 up to the total can be measured using a two-pan balance scale.

## Problem Description

The key insight is that with a balance scale, weights can be placed on *either* side of the scale. This means that to measure a quantity of some material (like corn), we can place some stone pieces on the same side as the material and other pieces on the opposite side. The material's weight equals the difference between the weights on the opposing side and the weights on the same side.

## Requirements

1. **Input parameters**: The specification should be parameterized by:
   - The total weight of the stone to be divided
   - The number of pieces to break it into

2. **Valid divisions**: A valid way to break the stone must:
   - Divide it into exactly the specified number of pieces
   - Have all pieces with positive integer weights
   - Have the piece weights sum to the total stone weight

3. **Weighing capability**: For each integer weight from 1 up to the total, there must exist a way to partition some subset of the pieces into two groups (pieces on the corn side vs. pieces on the opposite side) such that the target weight plus the weight of pieces on its side equals the weight of pieces on the opposite side.

## Correctness Property

A division is a valid solution if and only if **every** integer weight from 1 through the total can be measured using the balance scale with those pieces. The specification should identify all such valid divisions.

## Expected Output

The specification should enable computing the set of all solutions—all valid ways to divide the stone that allow measuring every required weight. For verification purposes, it should also be possible to see, for each solution, exactly which pieces go on which side of the scale to measure each specific weight.
