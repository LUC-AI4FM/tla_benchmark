# Specification Request: Simple Nondeterministic State Transition System

## System Overview

I need a formal specification for a minimal state machine that starts in an initial state and can nondeterministically transition to one of two possible successor states in a single step.

## System Requirements

1. **Initial State**: The system must begin in a designated starting state.

2. **Transitions**: From the initial state, the system should be able to transition to either of two distinct target states. The choice between these two transitions is nondeterministic—both are always enabled and either may occur.

3. **Single-Step Behavior**: Each transition moves the system directly to one of the target states, replacing whatever the current state was.

## Correctness Properties

The specification should include an invariant that checks whether one specific target state is ever reached. In particular:

- **Safety Property**: The system should never enter one of the two possible target states (let's call it the "forbidden" state). The other target state is considered acceptable.

This invariant is expected to be *violated* by the system, since the nondeterministic choice allows the system to reach the forbidden state. The purpose is to demonstrate that the system *can* reach that state, making this useful for testing model checking, symbolic execution, or transition slicing capabilities.

## Purpose

This specification serves as a minimal test case for verifying that analysis tools correctly handle nondeterministic branching and can identify which transitions lead to property violations.
