# Specification Request: Coffee Can Bean Problem

## System Overview

I need a formal specification of the classic "Coffee Can Problem" (also known as the bean game or urn problem). This is a mathematical puzzle involving a can containing black and white beans, where beans are repeatedly removed and replaced according to specific rules until only one bean remains.

## Problem Description

The system models a coffee can that initially contains some number of black beans and white beans. The process involves repeatedly selecting two beans at random from the can and applying the following rules:

- If both selected beans are the same color, they are both discarded and a new black bean is placed in the can
- If the selected beans are different colors, the black bean is discarded and the white bean is returned to the can

This process continues until only a single bean remains in the can.

## Requirements

1. **Initial State**: The can should start with a configurable number of black and white beans, bounded by some maximum count

2. **Bean Operations**: The system must model the two possible operations:
   - Selecting two beans of the same color (both removed, one black added)
   - Selecting two beans of different colors (black removed, white returned)

3. **Termination**: The process should continue until exactly one bean remains

4. **Non-negativity**: The count of each bean color must never become negative

## Key Correctness Properties

1. **Conservation Property**: There should be an invariant relationship involving the parity (odd/even nature) of the white bean count that remains constant throughout execution

2. **Deterministic Outcome**: The color of the final remaining bean should be predictable from the initial configuration—specifically determined by whether the initial number of white beans is odd or even

3. **Progress**: The total number of beans must strictly decrease with each operation (by exactly one bean per step)

4. **Termination Guarantee**: The process must eventually terminate with exactly one bean

## Goal

The specification should formally verify that the final bean's color is completely determined by the initial parity of white beans, demonstrating this classic result from combinatorial mathematics.
