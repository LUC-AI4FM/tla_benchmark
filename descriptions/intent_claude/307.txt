# Specification Request: Binary Search with Bounded Integer Arithmetic

## System to Model

A binary search algorithm that finds a key in a sorted sequence, implemented using fixed-width signed integer arithmetic as would occur on real computer hardware.

## Functional Requirements

The algorithm should search for a given key within an input sequence:

1. Maintain a search interval that starts covering the entire sequence
2. Repeatedly narrow the interval by comparing the key against the middle element
3. If the middle element matches the key, return its position (as a non-negative index)
4. If the middle element is less than the key, search the upper half
5. If the middle element is greater than the key, search the lower half
6. If the interval becomes empty without finding the key, return a negative value indicating the key is not present

## Key Constraints

The specification must model **bounded integer arithmetic** with a configurable bit-width:
- All arithmetic operations (addition for computing the midpoint, index adjustments) must use fixed-width signed integer semantics
- Integer overflow must wrap according to two's complement representation
- This captures the real-world bug where computing `(low + high) / 2` can overflow

## Correctness Properties

The specification should verify:

1. **Postcondition correctness**: When the algorithm terminates on a sorted input, the return value is non-negative if and only if the key exists in the sequence. If the key is found, the returned index must point to a matching element.

2. **Termination**: The algorithm must terminate within a bounded number of steps (specifically, logarithmic in the sequence length, bounded by the integer bit-width).

3. **Progress**: Each iteration must strictly narrow the search interval (either the low bound increases or the high bound decreases).

4. **Array bounds safety**: The computed midpoint index must always be within the valid range of the input sequence when accessed.

## Parameterization

The specification should be parameterized by:
- An arbitrary input sequence
- A search key
- The bit-width of the integer representation (to explore overflow behavior at different sizes)
