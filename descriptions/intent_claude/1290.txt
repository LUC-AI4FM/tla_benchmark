# Specification Request

## System Description

I need a formal specification for a simple alternating counter system. The system consists of a numeric counter and a boolean toggle that controls which operation can occur.

## Behavior Requirements

The system should model two alternating phases:

1. **Toggle phase**: When the toggle is in one state, the system can flip the toggle without changing the counter value, but only if the counter is below a threshold (less than 5).

2. **Increment phase**: When the toggle is in the opposite state, the system can flip the toggle back while simultaneously incrementing the counter.

The counter should start from a small initial value (somewhere in the range 0 to 3), and the toggle can start in either state.

## Liveness Requirements

The system should guarantee fair execution—it must eventually make progress and not stutter forever when actions are enabled.

## Property to Verify

I want to check whether the following temporal property holds: **if the counter ever reaches the value 2, will it eventually decrease to 1?**

This is essentially asking whether the system can "undo" progress on the counter, or whether the counter only moves in one direction.
