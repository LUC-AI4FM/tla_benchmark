# Specification Request: Voting Power Sum Verification

## System Overview

I need a formal specification for a simple distributed system model where a fixed set of processes each have an associated voting power value. The system should allow these voting power values to change over time, and I want to verify properties about the total combined voting power across all processes.

## System Requirements

### Components
- A fixed set of three processes (named "a", "b", and "c")
- Each process has an integer voting power that can range from 0 up to a defined maximum (e.g., 3)

### Behavior
- The system should start with each process having some arbitrary valid voting power within the allowed range
- At each step, the voting powers can change to any valid configuration (modeling arbitrary updates or votes being reassigned)
- This represents a highly non-deterministic model where any valid power assignment can occur at any time

### Key Computation
- The specification must be able to compute the sum of voting powers across all processes
- This sum calculation should work over the entire set of processes by accumulating each process's individual voting power

## Correctness Properties

### Primary Invariant
The main property to verify is that the **total voting power across all processes remains below a specified threshold** (specifically, less than 10).

This invariant should hold in all reachable states of the system.

## Purpose

This specification serves as a test case for verifying that recursive definitions (specifically, summing values over a finite set) can be properly handled and unfolded by analysis tools. The model is intentionally simple to focus on the correct handling of recursive computations over finite sets in the context of model checking.
