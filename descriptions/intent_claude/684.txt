# Specification Request: Theorems for Extended Finite Set Operations

## System to be Specified

I need a formal specification of mathematical theorems about operations on finite sets, specifically focusing on folding (reducing) operations over sets, and derived operations like summation, products, and extrema (minimum/maximum).

## Goal

Create a library of proven mathematical properties for aggregate operations on finite sets. This serves as a reference and foundation for reasoning about computations that combine all elements of a set using a binary operator.

## Core Operations to Characterize

1. **Generic Fold Operation**: A higher-order operation that combines all elements of a finite set using a binary operator and a base value.

2. **Set Summation**: Computing the sum of all elements in a finite set of integers.

3. **Set Product**: Computing the product of all elements in a finite set of integers.

4. **Map-then-Sum**: Applying a function to each set element, then summing the results.

5. **Minimum and Maximum**: Finding the smallest or largest element in a set of integers.

## Required Properties

### For Generic Folding:
- Folding an empty set returns the base value
- Folding a non-empty set can be decomposed by removing any element (when the operator is associative and commutative)
- The result type is preserved when the operator is closed over the type
- Folding distributes over disjoint set union when the operator has a neutral element

### For Summation:
- Type preservation (naturals sum to natural, integers sum to integer)
- Sum of empty set is zero
- Decomposition property for adding/removing elements
- Distribution over disjoint unions
- Subset sums are bounded by the full set sum (for naturals)
- Characterization of when a sum equals zero

### For Products:
- Type preservation for naturals and integers
- Product of empty set is one
- Decomposition property for adding/removing elements
- Distribution over disjoint unions
- Characterization of when a product equals zero (contains zero) or one
- Subset products are bounded by the full set product (for positive naturals)

### For Map-then-Sum:
- Type preservation based on the mapping function's codomain
- Empty set yields zero
- Decomposition and distribution properties
- Monotonicity: if one function is pointwise ≤ another, so are their map-sums
- Strict monotonicity when at least one value is strictly less

### For Min/Max:
- If a set contains its own bound, that element is the min/max
- Every finite non-empty integer set has a min and max
- Bounded non-empty integer sets have extrema
- The extrema of an integer interval are its endpoints
- Every non-empty set of natural numbers has a minimum (since naturals are bounded below)

## Correctness Requirements

All theorems must be mathematically sound and applicable to finite sets. The properties should support compositional reasoning—allowing complex set computations to be analyzed by breaking them into simpler parts.
