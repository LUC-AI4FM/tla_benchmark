# Specification Request: Cat-in-Boxes Search Puzzle

## System Overview

I need a formal specification for a classic pursuit-evasion puzzle involving a cat hiding in a row of boxes. The scenario involves two parties: a searcher who can inspect one box each turn, and a cat that moves between adjacent boxes.

## Problem Description

There are N boxes arranged in a line, numbered sequentially. A cat begins hidden in one of these boxes. The puzzle proceeds in rounds with the following rules:

1. Each round, the cat must move to an adjacent box (she cannot stay in place, and cannot wrap around from the first box to the last or vice versa)
2. Each round, the searcher chooses exactly one box to inspect
3. The searcher wins if they inspect the box currently containing the cat

The cat's initial position is unknown to the searcher, and the cat's movements are adversarial (she can choose either adjacent box when both options exist).

## Search Strategy to Model

The specification should model a specific deterministic search pattern: the searcher sweeps back and forth through the interior boxes (excluding the two endpoints), reversing direction upon reaching either end of this range. For example, with 5 boxes the pattern would be: 2, 3, 4, 4, 3, 2, 2, 3, 4, ... (repeating).

## Correctness Requirements

The specification must verify the following property:

**Guaranteed Capture**: No matter which box the cat starts in, and no matter how the cat chooses to move each round, the searcher will eventually find the cat. This must hold as long as the cat continues moving (she cannot simply stop to evade capture indefinitely).

## Scope and Assumptions

- The number of boxes must be at least 2 (the single-box case is degenerate since the cat cannot move)
- The searcher may begin the sweeping pattern at any point and in either direction
- The cat's movement and the searcher's observation can be considered simultaneous for modeling purposes
