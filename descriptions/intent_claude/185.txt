# Specification Request: Concurrent Set Growth with State Machine

## System Overview

I need a formal specification for a system that models two independent sets growing concurrently, alongside a separate state machine that transitions through various states. The system should track how these sets evolve and maintain their combined union.

## System Description

The system consists of:

1. **Two growing sets**: Two separate collections that each grow by adding elements in a cyclic pattern. Each set follows its own independent cycle of additions (e.g., one set cycles through adding elements 1→2→3→1..., while the other cycles through 4→5→6→1...). The presence of certain elements enables the addition of the next element in the cycle.

2. **A combined result set**: A third set that always represents the union of the two growing sets, updated whenever either set changes.

3. **A concurrent state machine**: An independent control state that transitions through numbered states (0 through 4) according to its own transition rules, operating in parallel with the set growth.

## Behavioral Requirements

- The two sets should grow independently of each other—changes to one set should not directly affect the other
- Each set's growth should follow a deterministic cyclic pattern based on what elements are currently present
- The combined set must always accurately reflect the union of the two component sets
- The state machine should allow for non-deterministic choice between multiple possible transitions from certain states
- The state machine may also remain unchanged in some steps

## Key Correctness Property

**The two component sets must never become equal to each other.** Despite both sets potentially growing and potentially sharing some elements (since their cycles can both add element 1), the sets themselves must always remain distinct from one another.

## Purpose

This specification appears designed to test model checker performance when dealing with set operations, particularly the union operation and set equality checking, combined with concurrent non-deterministic state transitions.
