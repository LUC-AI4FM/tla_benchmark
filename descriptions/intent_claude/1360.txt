# Specification Request

I need a formal specification for the simplest possible model of a boolean state variable that can change over time.

## System Description

The system consists of a single piece of state that holds a boolean value (true or false). The system should be able to transition between these two values non-deterministically.

## Requirements

1. **State Domain**: The system state must always be a valid boolean value
2. **Transitions**: At any point, the state may change to any boolean value (including staying the same), or it may remain unchanged through a stuttering step

## Correctness Properties

- **Type Safety**: The state must always be a boolean - it should never hold any other type of value
- **Flexibility**: The specification should allow any sequence of boolean values over time, imposing no restrictions on how the value changes beyond maintaining type correctness

## Purpose

This serves as a minimal abstract model of any system component that can be in one of two states, without constraining the specific conditions under which transitions occur. It could represent an abstract view of a flag, toggle, or any binary condition in a larger system.
