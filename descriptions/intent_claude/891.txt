Specify a simple asynchronous interface between a sender and a receiver communicating over a one-place buffer. The system uses a ready/acknowledge handshake protocol with single-bit toggle signals to coordinate transfers. The sender may transmit a new data value only when the ready and acknowledge signals are equal, after which it updates the data and toggles the ready signal. The receiver may accept a value only when the ready and acknowledge signals differ, after which it toggles the acknowledge signal to match ready. The system starts in any state where the type constraints hold and the acknowledge signal equals the ready signal. The key correctness property to verify is a type invariant: the data value must always come from a fixed set of possible data values, and both the ready and acknowledge signals must always be single bits (drawn from the set {0, 1}). The specification should allow stuttering steps and be checked with a concrete finite instantiation of the data set to confirm the invariant holds throughout all reachable states.
