# Specification Request: Initial State Predicate Testing Framework

## System Overview

I need a formal specification that serves as a test harness for validating how a model checker handles various forms of initial state predicates. The system should demonstrate different ways of constraining an initial variable's value and verify that the model checker correctly computes the set of valid initial states for each constraint style.

## Requirements

### Core Functionality

The specification should define a single state variable that can take on integer values, and explore multiple distinct approaches to specifying initial conditions:

1. **Existential selection with filtering**: Initialize the variable by selecting from a set, but only accepting values that exceed the minimum element of that set.

2. **Universal quantification**: Attempt to constrain the variable such that it equals every element of a set simultaneously (which should yield valid states only for singleton sets).

3. **Set membership with minimum exclusion**: Require the variable to belong to a set while also being strictly greater than the set's minimum.

4. **Set membership with arithmetic constraint**: The variable must come from a specified set and satisfy an equation involving addition.

5. **Set membership with parity filter**: The variable must belong to a set and satisfy an oddness predicate.

### Combination of Initial Conditions

The specification should combine multiple initial state predicates using disjunction, allowing the model checker to compute the union of valid initial states from each approach. This tests whether the tool correctly handles composite initial conditions.

### Behavioral Constraint

After initialization, the system should remain in a valid state according to one of the initial predicates, with the state variable unchanged—essentially a stuttering-only specification after the initial state.

## Correctness Properties

The key validation is implicit: the specification should produce a predictable number of distinct initial states based on how each predicate style interacts with its input set. Some predicates should yield exactly one valid state, others should yield none (due to unsatisfiable constraints), demonstrating the model checker's ability to correctly evaluate different predicate forms during state space initialization.
