# Specification Request: Concurrent Counter Increment

## System Overview
I need a formal specification of a simple concurrent system where two independent processes both attempt to increment a shared counter variable.

## System Description
The system consists of:
- A shared counter initialized to zero
- Two concurrent processes that each perform an increment operation on the shared counter

Each process should read the current value of the counter and write back an incremented value. The processes operate independently and may interleave their operations in any order.

## Correctness Property
The key property I want to verify is **addition correctness**: when both processes have completed their execution, the shared counter should equal 2 (reflecting that two increment operations were performed).

## Purpose
This specification should help analyze whether naive concurrent increments on a shared variable produce the expected result, or whether race conditions can lead to incorrect final values. The model checker should explore all possible interleavings of the two processes' operations.
