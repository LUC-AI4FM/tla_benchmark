Please write a formal specification for a simple modular counter system.

**System Description:**
The system models a counter that cycles through a fixed range of values. The counter starts at zero and increments by one on each step, wrapping around when it reaches the maximum value (creating a cycle of 6 values: 0 through 5).

**Behavioral Requirements:**
- The counter must begin at zero
- On each transition, the counter advances to the next value in its cycle
- The counter should wrap around from its maximum value back to zero (modulo 6 arithmetic)
- The system should allow for stuttering steps where the counter remains unchanged

**Correctness Properties to Verify:**
1. The counter value always remains a natural number (non-negative integer)
2. This natural number property should hold as an invariant throughout all executions

The specification should also demonstrate that basic arithmetic properties (like simple addition) can be expressed and verified within the formal framework.
