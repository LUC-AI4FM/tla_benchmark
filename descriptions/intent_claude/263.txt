# Specification Request

## System Overview

I need a formal specification for a simple state machine that models non-deterministic initialization and state transitions over integer values.

## Functional Requirements

### Initialization
The system should start in one of two possible initial states, chosen non-deterministically. The initial state values should be 0 or 1.

### State Transitions
At each step, the system should non-deterministically transition to one of two fixed values (specifically 2 or 3), regardless of the current state.

## Correctness Properties

### Safety Invariants
The specification should include an invariant asserting that the system never reaches certain "forbidden" states. Specifically, the state value should never equal 2, 3, or 4.

**Note:** This invariant is expected to be violated by the system's transitions—this appears to be a test case for verifying that a model checker correctly identifies invariant violations.

### Additional Property
Include a state predicate that checks whether the state value is strictly positive.

## Purpose

This specification appears designed as a test case for tooling that handles labeled sub-expressions within TLA+ operators (for initialization, transitions, and invariants). The labeling should allow diagnostic tools to pinpoint exactly which disjunct or conjunct is responsible for enabling a transition or causing an invariant violation.
