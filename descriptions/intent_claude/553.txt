# Specification Request: Peterson's Algorithm for N Processes

## System to Model

I need a formal specification of Peterson's mutual exclusion algorithm generalized to N processes (specifically, I want to verify it with 3 processes). This is the classic algorithm that allows multiple concurrent processes to safely access a shared critical section without hardware support, using only shared memory.

## Functional Requirements

The system should model:

1. **Multiple competing processes**: N processes (numbered 0 through N-1) that repeatedly attempt to enter a critical section
2. **Entry protocol**: Each process must execute Peterson's multi-process entry protocol before accessing the critical section
3. **Critical section**: A section of code where only one process should be executing at any time
4. **Exit protocol**: After leaving the critical section, a process releases its claim so others may enter

## Key Correctness Properties

The specification must guarantee:

1. **Mutual Exclusion**: At no point in time can two different processes both be in the critical section simultaneously. This is the fundamental safety property.

2. **Starvation Freedom**: Every process that begins attempting to enter the critical section will eventually succeed in entering it. No process should be indefinitely prevented from making progress while others repeatedly access the critical section.

## Verification Scope

I want to verify these properties for a concrete instance with 3 processes to gain confidence that the algorithm works correctly for the multi-process case, which is more complex than the original 2-process version.
