# Specification Request

I need a minimal TLA+ specification that verifies the module initialization and assumption-checking mechanisms are working correctly.

## System Description

This is essentially a "hello world" or smoke test for the TLA+ toolchain. The specification should confirm that the model checker is properly initialized and can execute basic diagnostic output during the assumption-evaluation phase.

## Requirements

1. The specification should produce diagnostic output when the model checker loads and evaluates the module's assumptions
2. Two distinct messages should be printed to confirm the assumption mechanism works:
   - A first message that demonstrates the standard print function with an explicit boolean return
   - A second message using a simplified print variant

## Correctness Properties

- All assumptions must evaluate to TRUE (allowing the model checker to proceed)
- The diagnostic messages must be displayed during the model checking initialization phase

## Purpose

This specification serves as a basic validation that the TLA+ environment is functioning correctly and can be used as a template or starting point for more complex specifications that require debugging output.
