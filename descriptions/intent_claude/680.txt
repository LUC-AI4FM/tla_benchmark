# Specification Request: Combinatorial Mathematics Functions

I need a formal specification that defines fundamental combinatorial mathematical functions for use in other specifications or proofs.

## System Description

The specification should provide mathematical definitions for basic counting operations used in combinatorics. These are pure mathematical functions, not a stateful system—they serve as building blocks that other specifications can use when reasoning about counting, permutations, or combinations.

## Required Functionality

1. **Factorial computation**: Define the factorial operation for natural numbers, which gives the product of all positive integers up to a given number (with the base case that 0 factorial equals 1).

2. **Binomial coefficient**: Define the "n choose k" operation that computes how many ways there are to select k items from a set of n items, regardless of order.

## Mathematical Properties

The definitions should satisfy standard mathematical identities, including:

- Factorial of 0 is 1
- Factorial of n is n times the factorial of (n-1) for positive n
- The binomial coefficient should equal the standard formula using factorials

## Purpose

These definitions would be imported by other specifications that need to reason about combinatorial quantities—for example, when proving properties about algorithms that enumerate combinations, or when establishing bounds on the size of state spaces.
