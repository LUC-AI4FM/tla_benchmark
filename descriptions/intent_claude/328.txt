# Specification Request: Quantum State Observation Model

## System Description

I need a formal specification for a simple system that models an entity which can exist in one of two possible states: alive or dead. This is inspired by the Schrödinger's cat thought experiment, where observation affects the system's state.

## Behavioral Requirements

1. **Initial Condition**: The system must start in the "alive" state.

2. **State Transitions**: At any point in time, the system may either:
   - Remain in its current state (no change), OR
   - Transition to the "dead" state

3. **Irreversibility**: Once the system reaches the "dead" state, it should be possible for it to stay there (the transition to dead is effectively permanent in practice, since there's no path back to alive).

## Correctness Property to Verify

The key property I want to check is whether the system can **always remain alive** - that is, whether the "alive" state is an invariant that holds forever.

## Purpose

This specification should help demonstrate that while the system *starts* alive and *can* stay alive, the invariant that it remains alive is **not guaranteed** - the system has the non-deterministic freedom to transition to dead at any moment. The model checker should find a counterexample showing a trace where the entity dies.
