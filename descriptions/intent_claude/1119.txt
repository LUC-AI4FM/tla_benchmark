# Specification Request: Tower of Hanoi Puzzle

## System to Model

I need a formal specification of the classic **Tower of Hanoi** puzzle. This is a mathematical puzzle involving three rods and a collection of disks of different sizes that can slide onto any rod.

## Initial Setup

The puzzle begins with a configurable initial arrangement of disks across three positions. The typical starting configuration has all disks stacked on the first rod in ascending order of size (smallest on top), but the specification should allow for arbitrary valid initial configurations to be provided as parameters.

## Rules and Behavior

The system should model the legal moves in the puzzle:

1. **Single disk movement**: Only one disk may be moved at a time
2. **Top disk only**: A move consists of taking the topmost disk from one rod and placing it on another rod
3. **Size constraint**: A larger disk may never be placed on top of a smaller disk
4. **Valid destinations**: A disk can be moved to an empty rod or onto a rod where the top disk is larger

## Correctness Properties

The specification should verify the following invariants:

1. **Well-formed state**: Each rod maintains a valid stack structure containing disk sizes represented as numbers

2. **Conservation of disks**: The total number of disks in the system remains constant throughout all moves—no disks appear or disappear

3. **Preservation of disk identity**: The set of disk sizes present in the system never changes—only the original disks exist, with no new sizes introduced

## Goal State and Solution Discovery

The ultimate objective is to move all disks to the third (rightmost) rod, with disks properly ordered by size (smallest on top, forming sizes 1, 2, 3, ... from top to bottom).

The specification should be structured so that a model checker can discover a sequence of moves that solves the puzzle by searching for a path from the initial state to the goal state.
