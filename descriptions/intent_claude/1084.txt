# Specification Request: Function Properties and Operations Library

## Overview

I need a formal specification of a mathematical library for reasoning about functions (mappings) between sets. This library should provide fundamental definitions and operations that are commonly needed when specifying and verifying systems that involve mappings, lookups, and correspondences between collections of elements.

## Core Capabilities Required

### Function Restriction Operations
The library must support narrowing a function's domain in several ways:
- Restricting a function to an arbitrary subset of its domain
- Filtering a function based on a predicate applied to domain elements
- Filtering a function based on a predicate applied to the function's output values
- Determining whether one function is a restriction of another (i.e., represents a "subset" of the mapping relationship)

### Basic Function Analysis
- Computing the range (set of all output values) of a function
- Constructing the inverse of a function, mapping outputs back to inputs
- Combining two functions pointwise using a binary operation

### Classification of Functions
The library must provide definitions for the standard mathematical classifications of functions between two sets:
- **Injective functions (one-to-one)**: No two distinct inputs map to the same output
- **Surjective functions (onto)**: Every element of the target set is mapped to by some input
- **Bijective functions**: Functions that are both injective and surjective

Additionally, the library should support:
- Constructing the set of all injections, surjections, or bijections between two given sets
- Testing whether at least one such function exists between two sets

### Aggregation Over Functions
The library should support folding/reducing over all values in a function using an associative and commutative binary operation, optionally restricted to a subset of the domain indices.

## Correctness Requirements

- All definitions must be mathematically precise and consistent with standard mathematical conventions
- The restriction operations must preserve the function values for elements that remain in the domain
- The inverse operation must correctly reverse the mapping for injective functions
- The classification predicates must correctly identify injective, surjective, and bijective functions according to their standard mathematical definitions
