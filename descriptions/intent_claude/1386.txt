# Specification Request

I need a formal specification for a system that attempts to perform a logically contradictory state update.

## System Description

The system should model a simple state machine with a single numeric state component that starts at zero. The system should then attempt a transition that simultaneously requires the state to change to a new value while also requiring it to remain unchanged.

## Purpose

This specification is intended as a test case or demonstration of how a model checker handles contradictory or unsatisfiable action constraints. The goal is to explore what happens when a specification contains an inherent logical inconsistency in its transition relation.

## Key Properties to Investigate

- Whether the system can make any transitions at all given the contradictory requirements
- How the model checker reports or handles specifications with unsatisfiable next-state relations
- The behavior of deadlock detection when no valid transitions exist from the initial state

This appears to be a minimal reproducer for testing tool behavior rather than a specification of a real system.
