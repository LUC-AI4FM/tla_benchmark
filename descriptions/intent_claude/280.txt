Write a formal specification for a minimal test system designed to verify that a TLA+ toolchain correctly handles a specific language feature: using operator-defined tuples of variables within UNCHANGED expressions, including nested tuple references.

The system should model a static configuration with multiple state variables of different types (booleans, strings, integers). The system initializes these variables to fixed values and then permits no changes—every transition must leave all variables unchanged.

The key requirement is that the "unchanged" constraint must be expressed using indirection: rather than listing variables directly, the specification should define operators that group variables into tuples, and then define a top-level operator that nests these tuple operators together. The UNCHANGED expression should reference this top-level nested tuple operator.

The purpose is to ensure the specification tools correctly expand such operator references when processing UNCHANGED expressions, rather than producing errors about variables being used before assignment. The system itself has trivial behavior (complete stasis after initialization), but the specification structure exercises the grouped-variable UNCHANGED pattern with multiple levels of nesting.
