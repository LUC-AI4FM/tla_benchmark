# Specification Request: Finite Sequence Operations Library

## Overview

I need a formal specification of a library that defines fundamental operations on finite sequences. This library should serve as a foundational building block for specifications that manipulate ordered collections of elements.

## Data Model

A finite sequence should be represented as a mathematical function mapping consecutive positive integers (starting from 1) to elements. This representation should naturally unify the concepts of sequences and tuples—an n-element tuple is simply a sequence of length n.

## Required Operations

The library must provide the following capabilities:

1. **Set of all sequences**: Given a set of elements, define the collection of all possible finite sequences (of any length, including empty) drawn from that set.

2. **Length**: Determine how many elements a sequence contains.

3. **Concatenation**: Combine two sequences end-to-end to produce a new sequence containing all elements of the first followed by all elements of the second.

4. **Append**: Add a single element to the end of an existing sequence.

5. **Head**: Extract the first element of a non-empty sequence.

6. **Tail**: Obtain the sequence consisting of all elements except the first.

7. **Subsequence extraction**: Given start and end positions, extract the contiguous portion of a sequence between those positions (inclusive).

8. **Filtered selection**: Given a predicate (test condition), produce a new sequence containing only those elements that satisfy the predicate, preserving their original relative order.

## Key Properties

The operations should satisfy standard mathematical properties one would expect:

- Concatenating with an empty sequence should yield the original sequence
- Length of a concatenation should equal the sum of the individual lengths
- Head and tail together should account for all elements of a non-empty sequence
- Appending an element should increase length by exactly one
- Filtering should produce a sequence no longer than the original

## Usage Context

This library is intended for use in formal specifications where ordered collections must be manipulated—such as message queues, logs, buffers, or any system where element ordering matters.
