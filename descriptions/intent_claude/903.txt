# Specification Request: Asynchronous Communication Channel

## System to Model

I need a formal specification of an asynchronous communication channel that allows a sender and receiver to exchange data values without a shared clock. This is a fundamental building block for modeling distributed or concurrent systems where components communicate through message passing.

## Functional Requirements

The channel should support:

1. **Data transmission**: A sender should be able to place data values onto the channel for delivery to a receiver.

2. **Asynchronous handshaking**: Since sender and receiver operate independently, the channel must use some form of signaling protocol to coordinate when new data is available and when previously sent data has been consumed.

3. **Ready/Acknowledge protocol**: The coordination mechanism should indicate:
   - When the sender has placed new data that is ready to be read
   - When the receiver has acknowledged receipt of the data

## Correctness Properties

The specification should guarantee:

1. **No data loss**: Data placed on the channel must remain available until the receiver acknowledges it.

2. **No duplication**: Each piece of sent data should be received exactly once.

3. **Proper sequencing**: The handshake signals must alternate correctly—the sender should not overwrite unacknowledged data, and the receiver should not re-read already-acknowledged data.

## Additional Context

This channel specification should be reusable as a component in larger system specifications. It represents a classic asynchronous interface pattern and should be suitable for composition with other modules modeling senders, receivers, or more complex communication infrastructures like FIFO queues.

The data values transmitted through the channel should be parameterized so the specification can be instantiated with different data domains as needed.
