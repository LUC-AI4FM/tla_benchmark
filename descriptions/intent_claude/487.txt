Please write a formal specification for a simple two-variable state machine that tests the interaction of existential and universal quantifiers with variable assignments.

**System Description:**
The system maintains two integer variables that start at zero. The transition relation should combine multiple assignment constraints using logical connectives and quantifiers in a way that exercises how the specification language resolves potentially conflicting or redundant assignment expressions.

**Behavioral Requirements:**
- Both variables must initialize to zero
- Transitions should include:
  - A disjunction where one branch requires both variables to take each other's next-state values simultaneously, and another branch existentially quantifies over a small set to assign one variable
  - A direct assignment constraining one variable to a specific value
  - A universal quantification over a singleton set that also constrains one variable's next value

**Key Properties to Explore:**
The specification should help verify how the formal language handles:
1. The resolution of multiple constraints on the same variable's next-state value within a single action
2. The interaction between existential choice and fixed assignments
3. Whether universal quantification over a singleton effectively acts as a direct assignment
4. Stuttering steps should be permitted

The goal is to create a test case for understanding quantifier semantics in assignment contexts, not to model a realistic distributed system.
