Please write a formal specification for a **sequential algorithm that computes squares of consecutive integers**.

## System Description

The system should model an algorithm that populates an array with the squares of all integers from 0 up to some input value n. For example, if n=3, the algorithm should produce an array where position 0 contains 0, position 1 contains 1, position 2 contains 4, and position 3 contains 9.

## Requirements

1. **Input**: The algorithm takes a non-negative integer n as input
2. **Output**: An array indexed from 0 to n, where each position j contains the value j²
3. **Computation**: The algorithm should iterate through the indices, computing and storing the square of each index

## Correctness Properties

The specification must verify:

1. **Functional Correctness**: Upon termination, every array element at index j must equal j² (for all j from 0 to n)

2. **Type Safety**: Throughout execution:
   - The input n remains a natural number
   - Array values stay within the valid range (0 to n²)
   - The loop index stays within bounds (0 to n)

3. **Loop Invariant**: The specification should capture that at each iteration, all previously processed elements have been correctly computed as squares

## Verification Scope

The specification should be verifiable using model checking with small concrete values for n (such as 0, 2, and 7) to validate the algorithm's correctness before trusting it for arbitrary inputs.
