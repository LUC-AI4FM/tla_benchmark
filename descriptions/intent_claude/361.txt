# Specification Request: Large State Space Initialization Test

## System Description

I need a formal specification for a simple static system that serves as a test harness for verifying that a model checker can handle large initial state spaces efficiently.

## Requirements

The system should:

1. **Initialize with a large combinatorial state space**: The system should begin with three independent numeric parameters, each drawn from a distinct range of natural numbers. The ranges should be chosen such that their Cartesian product creates a substantial number of initial states (on the order of hundreds of thousands of possible starting configurations).

2. **Remain static after initialization**: Once the system is initialized, no state changes should occur. The system should simply hold its initial values indefinitely.

## Correctness Properties

The specification should include a trivially satisfied invariant (always true) to enable basic model checking without introducing property violations. The purpose is purely to stress-test the state space enumeration capabilities, not to verify meaningful behavioral properties.

## Purpose

This specification is intended as a benchmark or regression test for model checking tools, specifically to validate their ability to enumerate and process large initial state spaces without errors or performance degradation.
