# Specification Request: Die Hard Water Jug Puzzle

## System to Model

I need a formal specification of the classic "Die Hard 3" water jug puzzle. In this puzzle, you have two jugs of different capacities (typically a 3-gallon jug and a 5-gallon jug) and an unlimited water supply. The goal is to measure out exactly a specific amount of water (typically 4 gallons) using only these two jugs.

## Required Operations

The system should model the following possible actions:
- Fill either jug completely from the water supply
- Empty either jug completely
- Pour water from one jug into the other (stopping when either the source is empty or the destination is full)

## Correctness Properties

The specification should allow verification that:
1. **Goal Reachability**: It is possible to reach a state where exactly the target amount of water (e.g., 4 gallons) is measured in one of the jugs
2. **Safety Constraints**: Neither jug ever contains a negative amount of water or more than its capacity

## Additional Requirements

I'd also like the ability to define different "views" or projections of the system state for debugging and trace analysis purposes. This would allow me to:
- Show only certain variables of interest when examining traces
- Add diagnostic information (like trace depth/level) to the output
- Create minimal or expanded views of the state as needed for different analysis purposes

This aliasing capability should be modular, extending the base puzzle specification without modifying it.
