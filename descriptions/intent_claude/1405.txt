Write a TLA+ specification demonstrating module instantiation with variable substitution, specifically to verify that a liveness property holds correctly across an outer and inner module boundary. The system has an outer module that instantiates an inner module, mapping the inner module's variables to the outer module's variables. The inner module describes a single step that transitions a result variable from zero to one, and simultaneously filters a sequence to remove elements equal to the new result value. The outer module initializes the sequence to contain the values one, two, and three, and the result to zero. The system either takes the inner step when enabled, or stutters when the step is no longer enabled. The key correctness property to verify is a liveness condition: the system must eventually reach and remain in a state where the inner step is no longer enabled, meaning the computation terminates. Weak fairness on the inner step must be assumed to guarantee this progress. This module serves primarily as a test or demonstration of how `SelectSeq` and module instantiation interact under liveness checking in TLA+.
