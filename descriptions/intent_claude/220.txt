# Specification Request

I need a formal specification for a system that models concurrent or composed nondeterministic choices over three integer state variables.

## System Description

The system should track three integer values that start in a specific initial configuration (beginning at consecutive values 0, 1, and 2). The system then evolves through transitions that involve multiple simultaneous nondeterministic selections, where the choices interact in complex ways.

## Requirements

The transition relation must capture the following structure of composed choices:

1. **Nested conjunctive and disjunctive selections**: The next-state relation should combine multiple layers of "either/or" choices with "both/and" requirements. Some selections are independent, while others are coupled together.

2. **Conflicting constraints**: The specification should include cases where the same variable might be constrained by multiple, potentially contradictory requirements within the same conjunction. This models scenarios where different subsystems or rules impose overlapping demands on shared state.

3. **Hierarchical choice structure**: Selections should be organized hierarchically, where some disjunctive branches themselves contain conjunctions of further choices, creating a tree-like structure of possible transitions.

## Key Properties to Analyze

The specification should allow exploration of:
- Whether any valid transitions exist given the overlapping constraints
- What combinations of final values are actually reachable
- How conflicting requirements on the same variable affect system behavior (specifically, whether requiring a variable to simultaneously take two different values results in deadlock)

## Purpose

This specification serves to analyze how complex, nested nondeterministic choices with shared variables behave, particularly when constraints may conflict or when the same variable appears in multiple selection clauses within a single transition.
