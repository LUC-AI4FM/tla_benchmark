# Specification Request: Function Properties Library

## Overview

I need a formal specification that defines fundamental mathematical concepts about functions (mappings) between sets. This should serve as a reusable library of definitions for reasoning about function properties in other specifications.

## Required Definitions

The specification should provide the following capabilities:

### Basic Function Operations
- **Domain restriction**: Given a function and a set, produce a new function that only maps elements from that set
- **Range computation**: Given a function, compute the set of all values it produces

### Function Inversion
- **Inverse function**: Given a function and its domain/codomain sets, construct a function that reverses the mapping (where possible)

### Function Classification
The specification must formally define these standard mathematical properties of functions:

- **Injectivity (one-to-one)**: No two distinct domain elements map to the same range element
- **Surjectivity (onto)**: Every element in the codomain is mapped to by some domain element
- **Bijectivity**: A function that is both injective and surjective

### Set Constructions
For any two sets, provide ways to characterize:
- The set of all injective functions between them
- The set of all surjective functions between them
- The set of all bijective functions between them

### Existence Predicates
Predicates to determine whether:
- An injection exists between two sets
- A surjection exists between two sets
- A bijection exists between two sets

## Requirements

1. All definitions should be pure mathematical definitions suitable for use in formal proofs
2. The definitions should be general enough to work with functions over arbitrary types
3. The specification should be usable as a library module that other specifications can extend or reference

## Purpose

This library will support formal verification of systems that require reasoning about mappings, permutations, cardinality comparisons between sets, or any algorithm involving one-to-one correspondences.
