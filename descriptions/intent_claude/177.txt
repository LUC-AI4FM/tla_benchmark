# Specification Request: Recursive Utility Functions Library

## System Overview

I need a formal specification for a library of fundamental utility functions that operate on sets and sequences. These functions implement common collection operations using explicit recursive definitions, suitable for use in a formal verification context where built-in fold/reduce operations may not be available.

## Required Operations

### Set Operations

1. **Numeric Summation**: Compute the sum of all elements in a finite set of numbers. An empty set should yield zero.

2. **Flattening Nested Sets**: Given a set whose elements are themselves sets, compute the union of all contained sets into a single flat set. An empty collection of sets should produce the empty set.

3. **Counting with Predicate**: Count how many elements in a set satisfy a given boolean predicate. An empty set should yield a count of zero.

### Sequence Operations

4. **Filtering**: Given a sequence and a boolean test, produce a new sequence containing only those elements (in their original order) that satisfy the test. An empty input sequence yields an empty output sequence.

5. **Element Collection**: Extract the set of all values that appear in a sequence (effectively computing the range/image of the sequence viewed as a function). An empty sequence yields the empty set.

6. **Statistical Mode**: Find the most frequently occurring element in a sequence. If the sequence is empty, return a specified default value. If there are ties, any of the most frequent elements may be returned.

### Function Properties

7. **Injectivity Check**: Determine whether a function (represented as a mapping over its domain) is injective—that is, whether distinct domain elements always map to distinct range elements.

## Key Properties to Guarantee

- All recursive operations must terminate for finite inputs
- Operations on empty collections must return appropriate identity elements (0 for sums/counts, empty set for unions, empty sequence for filtering)
- The filtering operation must preserve the relative order of elements
- The mode operation must return an element that appears at least as frequently as any other element in the sequence
- The injectivity check must correctly identify when a function maps two different inputs to the same output
