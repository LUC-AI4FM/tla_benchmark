# Specification Request: Hour Clock System

## System Overview

I need a formal specification of a simple hour clock that tracks time in a 12-hour format (or similar bounded hourly display). The clock should model the basic behavior of an hour hand that advances through valid hour values in a cyclic manner.

## Functional Requirements

1. **Hour Tracking**: The system must maintain the current hour value, which should always be within a valid range (e.g., 1 through 12 for a standard clock face).

2. **Time Advancement**: The clock must be able to advance to the next hour, wrapping around appropriately when it reaches the maximum value (e.g., after 12 comes 1 again).

3. **Stuttering Tolerance**: The specification should allow for the possibility that time doesn't always advance (the system may "stutter" or remain in the same state).

## Correctness Properties

The key property that must be formally verified:

1. **Invariant Preservation**: Once the clock is initialized to a valid hour, it must **always** remain in a valid hour state. The valid hour constraint must be an invariant of the system—no sequence of transitions should ever result in an invalid hour value.

## Verification Goals

The specification should support a formal proof that the valid hour property is maintained throughout all possible executions of the system. This means proving that:
- The initial state satisfies the validity constraint
- Every possible transition (including stuttering steps) preserves the validity constraint
- Therefore, the validity constraint holds globally for all time
