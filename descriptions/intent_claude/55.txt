Write a specification for a system that computes integer exponentiation through repeated multiplication.

**System Description:**
Model a simple iterative exponentiation calculator that computes powers of a fixed base number. The system should start with a base value and incrementally build up the result of raising that base to successively higher powers.

**Behavior Requirements:**
- The system begins with a specific base number (e.g., 3) and initializes to represent that base raised to the first power.
- At each step, the system increments the exponent by one and updates the computed result accordingly by multiplying by the base.
- The base value remains constant throughout execution.

**Correctness Property:**
The key invariant that must always hold is that the computed result equals the mathematical value of the base raised to the current power. This ensures the iterative multiplication process correctly tracks the true exponential value at every step.

**Purpose:**
This specification serves to verify that an incremental approach to exponentiation—where we multiply by the base each time we increase the exponent—correctly maintains the mathematical relationship between the running product and the true power function.
