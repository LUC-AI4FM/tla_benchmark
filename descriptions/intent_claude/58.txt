# Specification Request

## System Description

I need a formal specification for a minimal state machine that serves as a test case for verifying how a model checker handles assumptions over non-constant values.

## Requirements

The system should be trivially simple—essentially a "do nothing" state machine where any state is valid initially and the system can remain in any state indefinitely. The actual state transitions are not the focus here.

## Key Correctness Properties

The specification must include:

1. **A defined operator** that evaluates to a specific positive integer value
2. **An assumption declaration** that asserts this operator's value satisfies a positivity constraint

## Purpose

The primary goal is to test the model checker's behavior when an `ASSUME` statement references a value that is defined as an operator rather than declared as a constant parameter. This is specifically meant to verify that the tool correctly processes assumptions that depend on non-constant definitions, catching any regressions in this functionality.
