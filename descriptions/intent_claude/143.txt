# Specification Request

I need a formal specification for an extremely simple static system that models a constant value.

## System Description

The system should represent a single piece of state that is initialized to a specific integer value and never changes. Think of it as modeling an immutable constant or a read-only register.

## Requirements

1. **Initialization**: The system state should be set to the value 3 when the system starts.

2. **Behavior**: After initialization, the system should remain completely static—no changes to the state should ever occur.

## Correctness Properties

The specification should ensure:
- The state always equals 3 (invariant)
- The system exhibits no dynamic behavior after initialization

This is essentially the simplest possible reactive system specification—one that does nothing but maintain a constant value.
