# Specification Request: 12-Hour Clock System

## System Overview

I need a formal specification of a simple 12-hour clock that tracks and advances the current hour.

## Desired Behavior

The system should model a clock that:

1. Maintains the current hour as a value between 1 and 12 (inclusive), representing a standard 12-hour clock face
2. Can advance from one hour to the next in sequence
3. Wraps around correctly from hour 12 back to hour 1

## Initial Conditions

The clock should be able to start at any valid hour (1 through 12).

## Key Correctness Properties

The specification must guarantee:

1. **Safety**: The hour value is always within the valid range of 1 to 12—the clock never displays an invalid hour
2. **Liveness**: The clock continues to advance; it doesn't get stuck on any particular hour forever

## Purpose

This specification serves as a foundational example for reasoning about temporal properties, particularly liveness conditions in a cyclical system. It should be simple enough to use as a teaching example while still demonstrating meaningful correctness properties.
