Please write a formal specification for a **Bag (Multiset) Data Structure Library**.

## System Description

I need a specification that defines the mathematical concept of a *bag* (also called a multiset) and provides a comprehensive set of operations for working with bags. Unlike ordinary sets where each element can appear at most once, bags allow elements to appear multiple times, with each element having an associated positive count.

## Required Operations

The specification should support the following operations:

1. **Bag construction**: Create a bag from a set (with each element appearing once), and create an empty bag.

2. **Element membership**: Determine whether an element exists in a bag (has at least one copy).

3. **Copy counting**: Query how many copies of a given element exist in a bag.

4. **Set conversion**: Extract the underlying set of distinct elements from a bag.

5. **Bag union**: Combine two bags by adding together the counts of each element.

6. **Bag difference**: Remove elements of one bag from another, subtracting counts element-wise (elements with zero or negative resulting counts should be removed entirely).

7. **Generalized union**: Compute the union of an entire set of bags.

8. **Subbag relationship**: Determine whether one bag is a subbag of another (every element has at most as many copies in the first bag as in the second).

9. **Subbag enumeration**: Generate the set of all subbags of a given bag.

10. **Mapping over bags**: Apply a function to each element of a bag, producing a new bag where the count of each result value equals the sum of counts of all elements that map to it.

11. **Cardinality**: Compute the total number of elements in a bag (counting multiplicities).

## Correctness Properties

The specification should be validated by checking properties such as:
- Bag union is associative and has the empty bag as identity
- Subtracting a bag from itself yields the empty bag
- The subbag relation is reflexive and transitive
- Converting a set to a bag and back recovers the original set
- Cardinality counts multiplicities correctly
- The number of subbags follows expected combinatorial formulas
