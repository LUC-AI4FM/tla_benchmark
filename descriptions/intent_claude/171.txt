Write a specification for a system that converts a finite set of elements into a sequence.

**System Description:**
The system should take an arbitrary finite set as input and progressively transform it into a sequence (ordered list) containing all the same elements. The transformation happens incrementally, moving one element at a time from the set into the sequence.

**Behavioral Requirements:**
- The system starts with the complete input set and an empty output sequence
- At each step, the system selects an arbitrary element from the remaining set elements and appends it to the end of the sequence
- This process continues until all elements have been moved from the set to the sequence
- Once the set is exhausted, the system should remain in its final state

**Key Correctness Property:**
The specification must guarantee that at all times, the union of the elements still remaining in the set and the elements already placed in the sequence equals exactly the original input set. This invariant ensures that:
1. No elements are lost during the transformation
2. No elements are duplicated
3. No spurious elements are introduced

The specification should work for any finite set of elements, with the nondeterministic choice of which element to move next allowing the model checker to explore all possible resulting sequence orderings.
