# Specification Request: Conway's Game of Life

## System Overview

I need a formal specification of Conway's Game of Life, a cellular automaton simulation on a finite two-dimensional grid.

## Description

The system should model a square grid of cells where each cell can be either alive or dead. The grid has a fixed size (N×N) and the simulation evolves in discrete time steps according to deterministic rules based on each cell's neighborhood.

## Behavioral Requirements

1. **Initial State**: The simulation should be able to start from any arbitrary configuration of living and dead cells on the grid.

2. **Evolution Rules**: At each step, every cell's next state is determined simultaneously based on the count of its living neighbors (the 8 adjacent cells in cardinal and diagonal directions):
   - A living cell with exactly 2 or 3 living neighbors survives
   - A dead cell with exactly 3 living neighbors becomes alive
   - All other cells become (or remain) dead

3. **Boundary Handling**: Cells at the edges of the grid should treat positions outside the grid as dead (non-wraparound boundaries).

4. **Synchronous Updates**: All cells must update simultaneously—the next state of every cell is computed based on the current state before any changes are applied.

## Parameters

- The grid dimension N should be configurable as a natural number

## Correctness Properties

1. **Type Safety**: The grid must always be a valid mapping from grid positions to boolean (alive/dead) values

## Notes

- The specification should support reasoning about the evolution of any initial pattern
- The model should be amenable to type checking with appropriate type annotations for grid positions and the grid state
