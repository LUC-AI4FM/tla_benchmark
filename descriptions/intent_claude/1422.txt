# Specification Request: Nondeterministic State Transitions with Liveness Analysis

## System Description

I need a formal specification for a simple nondeterministic system with two independent state components. The system should model:

1. **A binary numeric state** that can be either 0 or 1
2. **A binary symbolic state** that can be either of two distinct values (e.g., "a" or "b")

## Behavioral Requirements

- The system should start in a specific initial configuration (numeric state at 0, symbolic state at the first value)
- At each step, both state components can nondeterministically transition to any of their possible values, independently of each other
- The system should guarantee progress specifically with respect to the numeric state component—it must not stutter forever on that component while allowing the symbolic state to change freely

## Properties to Verify

### Liveness Property (Expected to Fail)
I want to check whether the following holds: whenever the numeric state is 0, eventually the system reaches a configuration where permanently thereafter, if the numeric state becomes 1, the symbolic state will always remain at "a".

This property is expected to produce a counterexample demonstrating a lasso-shaped trace (a finite prefix followed by an infinite loop), since the nondeterministic nature of the system means the symbolic state cannot be constrained in this way.

### Tautological Property (Baseline Check)
As a sanity check, verify a trivially true leads-to property where any state eventually reaches itself—this should always hold.

## Purpose

This specification is designed to explore liveness checking and counterexample generation in a model checker, particularly for understanding how leads-to properties interact with nondeterministic systems and how lasso-shaped counterexamples are produced.
