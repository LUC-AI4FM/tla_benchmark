# Specification Request: Simple Cycle Detection in a Functional Graph

## System to Model

I need a formal specification for detecting whether a finite set of nodes forms a simple cycle when connected by a functional relationship (where each node maps to exactly one successor).

## Description

The system should determine if a given finite set of nodes and a mapping function together form a single cycle that visits every node exactly once. This is essentially checking whether a functional graph (where each vertex has exactly one outgoing edge defined by the function) restricted to a set of nodes constitutes a Hamiltonian cycle.

## Requirements

1. **Input**: A finite set of nodes and a function that maps each node to its successor
2. **Graph interpretation**: The function defines directed edges—there is an edge from node A to node B if and only if the function maps A to B
3. **Cycle detection**: Starting from any node in the set, repeatedly following the successor function should eventually return to the starting node
4. **Complete coverage**: The cycle must pass through every node in the set exactly once before returning to the start
5. **Simple cycle**: No node should be visited more than once (except the starting node which is both start and end)

## Correctness Properties

- The specification must correctly identify when all nodes in the set are connected in a single cycle
- Following successors starting from any node must eventually visit all nodes in the set
- The path length must equal the number of nodes (ensuring no node is skipped or repeated)
- The result should be a boolean indicating whether the structure forms a valid simple cycle

## Purpose

This utility would be useful for verifying ring topologies, token-passing protocols, or any distributed system where processes must be arranged in a circular structure with each process knowing exactly one successor.
