# Specification Request: Sequence Folding Over Function Updates

## System to Model

I need a formal specification that demonstrates the behavior of a left-fold operation over a sequence, where the folding operation progressively updates a function (record/map) structure.

## Goal

The specification should verify that applying a fold operation across a sequence of keys correctly transforms an initial function mapping into a final expected state. Specifically, this models the pattern of iteratively processing a sequence of identifiers and updating a function's values for each identifier encountered.

## Requirements

1. **Initial State**: Start with a function that maps a fixed set of string keys (e.g., three distinct identifiers) all to an initial value of zero.

2. **Folding Operation**: Define an accumulator operation that, given the current function state and a key from the sequence, updates the function so that the specified key maps to a new value (specifically, setting it to one).

3. **Sequence Processing**: Process a sequence containing exactly the keys from the function's domain, applying the update operation from left to right.

## Correctness Property

The key invariant to verify is that after folding the update operation over a sequence containing all keys in the function's domain, every key in the resulting function maps to the updated value (one). This should hold regardless of the order in which keys appear in the sequence.

This property confirms that:
- The fold operation correctly threads the accumulator through the sequence
- Each key update is properly preserved through subsequent fold iterations
- The final result reflects all updates having been applied
