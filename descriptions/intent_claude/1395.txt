# Specification Request: One-Time Boolean Flag System

## System Description

I need a formal specification for a simple system with a single boolean flag that can toggle between true and false states. The system should start with the flag in the false state, and at any point, the flag may nondeterministically change to either true or false.

## Goal

The primary purpose of this specification is to explore and verify a temporal property about "at most once" behavior—specifically, whether once the flag becomes true and then returns to false, it must remain false forever afterward.

## Requirements

1. **Initial State**: The system begins with the flag set to false.

2. **State Transitions**: At each step, the flag may take on any boolean value (true or false), representing unconstrained nondeterministic behavior.

3. **No Mandatory Progress**: The system should allow stuttering—the flag is not required to change.

## Correctness Property to Verify

The key property to check is an "at most once" condition expressed temporally:

- **At Most Once**: If the flag ever becomes true, then from that point forward, if it ever becomes false again, it must stay false forever.

In other words, the flag is allowed to transition from false to true at most once, and from true to false at most once. A behavior where the flag goes `false → true → false → true` should violate this property.

## Expected Outcome

The specification should be designed to demonstrate that this property is **not** satisfied by the unconstrained system. Model checking should produce a counterexample showing a trace where the flag oscillates (e.g., false → true → false → true), violating the "at most once" constraint.
