# Specification Request: Integer Exponentiation Algorithm

## System to Model

I need a formal specification of a simple iterative algorithm that computes integer exponentiation (raising a base to a power).

## Functional Requirements

The algorithm should:

1. Accept two inputs: an integer base (which may be negative, zero, or positive) and a non-negative integer exponent
2. Compute the result of raising the base to the given power through repeated multiplication
3. Use an iterative approach that multiplies the base by itself the appropriate number of times

## Input Constraints

- The base must be an integer (can be any integer value)
- The exponent must be a natural number (zero or positive integer)
- The specification should verify these constraints hold at the start of execution

## Correctness Properties

The specification must guarantee:

1. **Partial Correctness**: When the algorithm terminates, the computed result must equal the mathematical value of base raised to the exponent power (base^exponent)

2. **Termination**: The algorithm must eventually complete for all valid inputs

## Verification Approach

The specification should be parameterized to allow model checking over configurable sets of base and exponent values, enabling verification that the algorithm works correctly across a representative range of inputs including edge cases (such as exponent of zero, base of zero, negative bases, etc.).
