# Specification Request: Directed Graph Operations Library

## System Overview

I need a formal specification for a library of directed graph (digraph) operations. This should provide fundamental definitions and operations for working with directed graphs in a mathematical/formal setting.

## Core Requirements

### Graph Representation
The system should define what constitutes a valid directed graph:
- A directed graph consists of a collection of vertices and a collection of directed edges
- Each edge connects exactly two vertices (a source and a target)
- All edges must connect vertices that exist within the graph's vertex set

### Required Operations

1. **Vertex and Edge Access**: Provide ways to retrieve the set of vertices and the set of edges from a graph structure.

2. **Graph Validation**: Define a predicate that determines whether a given structure is a valid directed graph according to the constraints above.

3. **Immediate Successors**: Given a graph and a vertex, compute the set of all vertices that are direct targets of edges from that vertex (i.e., one hop away following edge direction).

4. **Transitive Reachability**: Given a graph and a starting set of vertices, compute all vertices that can be reached by following edges in their directed order through any number of hops. This is the transitive closure of the "child" relationship starting from the given vertices.

5. **Induced Subgraph from Reachability**: Given a graph and a set of starting vertices, extract the subgraph containing:
   - All the starting vertices plus all vertices reachable from them
   - All edges from the original graph where the source vertex is in this reachable set

## Key Properties to Guarantee

- The graph validation predicate must correctly identify well-formed directed graphs
- The reachability computation must include all vertices reachable through any finite path
- The subgraph operation must produce a valid directed graph that is a proper subset of the original
- The children/successors operation must only return vertices that are directly connected by a single edge

## Usage Context

This specification is intended as a foundational module for reasoning about directed graphs, potentially to support specifications of algorithms involving dependency graphs, DAGs, or general graph traversal problems.
