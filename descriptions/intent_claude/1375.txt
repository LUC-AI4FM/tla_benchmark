# Specification Request: Set Equality Verification

## System Overview

I need a formal specification that demonstrates and verifies the fundamental property of set equality in a mathematical/logical system.

## Requirements

The specification should:

1. **Define two sets containing the same integer elements** but potentially written in different orders or constructed differently.

2. **Verify set equality semantics** - Specifically, confirm that two sets are considered equal if and only if they contain exactly the same elements, regardless of the order in which those elements are specified.

## Key Correctness Properties

The specification must guarantee:

- **Set equality is order-independent**: Two sets with identical elements must be recognized as equal even when the elements are listed in different orders.

- **Reflexive equality holds**: The mathematical property that {a, b} = {b, a} for any elements a and b must be validated by the specification checker.

## Purpose

This serves as a basic validation that the specification language correctly implements standard set-theoretic equality semantics, particularly for sets containing large integer values (both positive and negative).
