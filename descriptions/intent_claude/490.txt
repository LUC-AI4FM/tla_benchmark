Please write a formal specification for a simple two-variable state machine system.

**System Description:**
The system maintains two integer state variables that start at zero. The system should model transitions where the first variable always becomes 1, while the second variable is constrained by one of two conditions: either both variables swap to each other's new values simultaneously, or the second variable becomes 2.

**Requirements:**
- The system should initialize both state variables to zero
- On any transition, the first variable must be set to 1
- Additionally, each transition must satisfy at least one of these constraints:
  - The two variables exchange values (swap)
  - The second variable takes the value 2

**Correctness Properties:**
- The specification should allow for stuttering steps (where the state remains unchanged)
- The system should maintain the invariant relationships implied by the transition constraints
