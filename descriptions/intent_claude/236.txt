# Specification Request: Function State Evolution with View-Based State Space Reduction

## System Overview

I need a formal specification for a simple system that maintains and evolves a mathematical function (mapping) over a fixed integer domain. The system should demonstrate state transitions where the function's values can be incrementally modified.

## System Description

The system manages a function that maps integers to integers over a small, fixed domain (specifically integers 1 through 2). The function starts with an identity-like mapping where each input maps to itself.

## Behavior Requirements

The system should support two possible behaviors at each step:
1. **Idle**: The function remains unchanged
2. **Increment**: Each value in the function is increased by its corresponding key/index

The system should be able to take either action at any time, creating a non-deterministic evolution of the function's state.

## Correctness Properties

The specification should include an invariant that checks whether a specific element of the function reaches a particular threshold value. Specifically, the system should verify whether the first element of the function ever equals 2.

## State Space Considerations

The specification should support view-based state space reduction, where the entire function serves as the distinguishing characteristic for identifying equivalent states. This is important for model checking efficiency and for testing that the model checker correctly handles functions as view expressions.

## Purpose

This specification serves as a test case to verify that formal verification tools correctly support using function-typed expressions for state space symmetry reduction or view-based abstractions.
