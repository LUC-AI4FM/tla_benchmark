# Specification Request: Configuration Value Verification System

## System Overview

I need a formal specification for a simple system that initializes a configuration parameter to a specific value and maintains it unchanged throughout execution.

## Requirements

### Initialization
- The system should start with a configuration value set to a defined constant (let's call it the "initial value").

### Behavior
- Once initialized, the configuration value should remain constant and never change during system operation.

### Correctness Property

The key invariant to verify is:
- The configuration value must always equal a specific "expected value" (which may be defined separately from the initial value).

## Purpose

This specification appears designed to test or demonstrate a scenario where:
1. A system is initialized with one configuration value
2. An invariant checks against a *different* expected value
3. This would reveal a discrepancy between the initialization logic and the correctness requirements

The specification should help verify whether configuration replacement or substitution mechanisms work correctly—specifically checking if the initial value and the expected invariant value are properly synchronized or can be independently configured for testing purposes.
