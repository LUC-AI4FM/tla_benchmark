# Specification Request: Binary Relation Properties and Operations Library

## Overview

I need a formal specification that provides a reusable library for working with binary relations over finite sets. This should serve as a foundation for reasoning about relations in other specifications that involve ordering, reachability, or graph-like structures.

## System Description

The library should model binary relations as functions that take two elements from a set and return a boolean indicating whether those elements are related. All operations should work over a specified finite domain set.

## Required Capabilities

### Property Checks

The specification must provide predicates to test whether a given relation satisfies the following standard mathematical properties:

1. **Reflexivity**: Every element is related to itself
2. **Irreflexivity**: No element is related to itself
3. **Symmetry**: If one element is related to another, the reverse also holds
4. **Asymmetry**: No two elements can be mutually related to each other
5. **Transitivity**: If x relates to y and y relates to z, then x relates to z

### Closure Operations

The specification must provide operations to compute:

1. **Transitive closure**: The smallest transitive relation containing the original relation
2. **Reflexive transitive closure**: The smallest relation that is both reflexive and transitive while containing the original relation

### Connectivity Analysis

The specification should provide a way to determine whether a relation connects all elements of the set—that is, whether there exists a path (following the relation in either direction) between any two arbitrary elements.

## Correctness Requirements

- The transitive closure computation must terminate for any finite set
- The transitive closure must actually be transitive and must be the minimal such extension
- The reflexive transitive closure must satisfy both reflexivity and transitivity
- All property checks must correctly implement their standard mathematical definitions

## Intended Use

This library is meant to be imported by other specifications that need to reason about orderings, dependency graphs, reachability in state machines, or any system where binary relations play a role.
