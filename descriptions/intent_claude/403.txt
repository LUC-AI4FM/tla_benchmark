# Specification Request: TLA+ Primed Variable Evaluation Test Suite

## System to Model

A test harness that validates the correct evaluation of primed (next-state) variables within various TLA+ expression contexts during action evaluation.

## Goal

Create a specification that systematically verifies that a TLA+ model checker correctly handles references to primed variables when they appear in different syntactic constructs within an action formula. The test should confirm that primed variables can be used not just in simple assignments, but also within comparisons, set constructions, set comprehensions, and quantified expressions.

## Requirements

The specification should test that primed variables are properly evaluated when used in:

1. **Simple comparisons** – A primed variable should be usable in relational expressions (e.g., greater-than comparisons)

2. **Range set construction** – A primed variable should work correctly as a bound in interval notation to generate a set of integers

3. **Set mapping expressions** – A primed variable referenced inside a set-builder mapping operation should evaluate correctly

4. **Set filtering expressions** – A primed variable should be properly accessible within filter predicates of set comprehensions

5. **Existential quantification over sets containing primed values** – Quantified formulas should correctly bind and evaluate primed variable references

6. **Existential quantification with primed variables in both the domain and the predicate** – More complex quantified expressions using primed variables in multiple positions should evaluate correctly

## Correctness Properties

- The specification should be satisfiable (the Next action should be enabled)
- All test conditions embedded in the action should pass, confirming each syntactic usage of primed variables evaluates as expected
- The system should produce confirmation output for each successfully validated test case
