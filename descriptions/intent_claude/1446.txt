Specify a simple bounded producer system that appends sequential values to a queue. The system should model a process that iterates through a fixed range of indices (1 through 2) and, on each step, appends the current index value to a queue before advancing to the next index.

The system starts with an empty queue and an initial counter set to 1. While the counter is within bounds, the system should append the current counter value to the queue and increment the counter. Once the counter exceeds the upper bound, the system should stutter (remain idle) without further state changes.

The specification should include a type invariant ensuring that:
- The queue only ever contains values from the expected domain
- The counter remains within a reasonable range (0 through 3, accounting for the final incremented state)

This models a basic sequential append pattern where the order and completeness of enqueued values matter, potentially useful for testing trace generation or debugging race condition scenarios in model checking tools.
