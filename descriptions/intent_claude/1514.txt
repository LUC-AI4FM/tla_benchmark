# Specification Request: Simple Boolean Toggle System

## System Description

I need a formal specification for a minimal reactive system that maintains a single boolean state and alternately toggles between true and false values.

## Behavioral Requirements

1. **Initial State**: The system should start in a "true" or "on" state.

2. **State Transitions**: The system should be able to toggle its state from true to false or from false to true. The system may also stutter (remain unchanged).

3. **Configuration**: The specification should demonstrate how to define a constant parameter and bind it to a concrete value (such as 42) through configuration, even if that constant is not actively used in the main behavior.

## Purpose

This appears to be a minimal test or debugging specification, likely used to verify that a TLA+ tooling environment (such as a model checker or IDE integration) correctly handles:
- Basic temporal logic specifications
- Constant substitution via configuration files
- Simple state variable declarations and transitions

## Correctness Properties

No specific invariants or liveness properties are required beyond the implicit property that the specification is syntactically valid and can be processed by TLA+ tools.
