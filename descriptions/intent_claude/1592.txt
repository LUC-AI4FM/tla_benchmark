# Specification Request: Recursive Factorial Computation with Mutual Recursion

## System to Model

A recursive algorithm that computes the factorial of a natural number using **mutually recursive procedures**. The computation should use two distinct procedures that call each other in alternation to accomplish the factorial calculation.

## Functional Requirements

1. **Factorial Computation**: The system must correctly compute n! (n factorial) for a given input natural number n, where factorial is defined as the product of all positive integers from 1 to n, with 0! = 1.

2. **Mutual Recursion Structure**: The computation must be structured using two separate procedures that depend on each other:
   - The first procedure, when given a non-zero argument, should multiply by that argument and delegate the remaining computation to the second procedure with a decremented value
   - The second procedure should behave symmetrically, calling back to the first procedure
   - Both procedures should terminate immediately when given zero as an argument

3. **Accumulator Pattern**: The result should be accumulated in a shared variable, with each recursive step multiplying the current accumulated value by the current argument.

4. **Test Case**: The specification should demonstrate correctness by computing 5! and verifying the result equals 120.

## Correctness Properties

1. **Type Safety**: The accumulated result must always remain a natural number throughout the computation.

2. **Termination**: The algorithm must eventually complete—it should not run forever or get stuck.

3. **Functional Correctness**: Upon termination, the final result must equal the factorial of the input (specifically, 5! = 120 for the test case).

## Purpose

This specification serves to verify that a mutually recursive implementation of factorial correctly computes the expected result and maintains type invariants throughout execution, demonstrating that mutual recursion with a call stack behaves equivalently to simple recursion for this computation.
