# Specification Request: Set to Sequence Transformation

## System Overview

I need a formal specification for a simple algorithm that converts a finite set of integers into a sequence. The algorithm should progressively move elements from the input set into an output sequence until all elements have been transferred.

## Functional Requirements

The system should:

1. **Accept a finite set of integers as input** - The algorithm starts with a predefined set of integers that needs to be converted.

2. **Produce a sequence as output** - The final result should be a sequence containing all the elements from the original input set.

3. **Process elements one at a time** - In each step, the algorithm should select one element from the remaining unprocessed elements and append it to the output sequence.

4. **Terminate when all elements are processed** - Once every element from the input set has been added to the sequence, the algorithm should stop making changes.

5. **Allow non-deterministic ordering** - The algorithm does not need to impose any particular order on how elements are selected; any valid permutation of the input set is an acceptable output sequence.

## Key Correctness Properties

The specification must guarantee the following invariant:

- **Conservation of elements**: At every point during execution, the union of the remaining unprocessed elements and the elements already in the output sequence must equal the original input set. No elements should be lost or duplicated during the transformation.

## Example Scenario

For testing purposes, consider an input set containing the integers 1 through 4. The algorithm should eventually produce some permutation of these four numbers as a sequence, such as ⟨3, 1, 4, 2⟩ or ⟨1, 2, 3, 4⟩, depending on the non-deterministic choices made during execution.
