# Specification Request: Multi-Slot Consensus System

## System Overview

I need a formal specification for a distributed consensus system that manages multiple independent slots, where each slot must reach consensus on exactly one command from a set of possible commands.

## System Description

The system maintains a collection of slots, each of which can hold a chosen command. Initially, no slot has any command assigned. Over time, the system allows commands to be assigned to slots, but once a slot has a command assigned, it cannot be changed.

The key behavior is:
- Each slot starts empty (no command chosen)
- A command can be assigned to any empty slot
- Once a command is assigned to a slot, that assignment is permanent
- The system should eventually make progress in assigning commands to slots (it shouldn't stall indefinitely when assignments are possible)

## Requirements

1. **Independence**: Each slot operates as an independent consensus instance. The choice made for one slot has no effect on what can be chosen for other slots.

2. **Single-choice per slot**: Each slot must choose at most one command. Once a command is chosen for a slot, no other command can be chosen for that same slot.

3. **Progress**: The system must be fair in the sense that if it's possible to assign a command to a slot, eventually some assignment will occur.

## Correctness Properties

The main correctness requirement is that **each slot individually satisfies the consensus specification**. Specifically:

- **Agreement**: Each slot can have at most one command chosen
- **Validity**: Any chosen command must come from the valid set of commands
- **Termination**: Under fair execution, slots should eventually have commands assigned

## Configuration

The specification should be parameterized by:
- A set of possible commands (e.g., Read and Write operations)
- A set of slot identifiers (e.g., two slots)

The system should be verified to ensure that the multi-slot structure correctly implements independent consensus for each slot position.
