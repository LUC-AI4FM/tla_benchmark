# Specification Request

## System Description

I need a formal specification for a simple non-deterministic state machine that cycles through a fixed set of three symbolic states. The system should model a variable that can hold one of three distinct values (think of them as labels or modes), where transitions between any of the states are always possible.

## Behavioral Requirements

1. **Initialization**: The system should start in any one of the three possible states, chosen non-deterministically.

2. **State Transitions**: At each step, the system can transition to any of the three states (including potentially staying at the same state value by transitioning to itself).

3. **Bounded Exploration**: For practical verification purposes, the system should stop taking transitions after a reasonable depth (around 50 steps) to ensure model checking terminates, since the state space would otherwise allow infinite behaviors.

## Correctness Properties

The specification should define the basic safety property that the system only stutters or takes valid transitions according to the allowed next-state relation. No specific invariants beyond type correctness are required—this is primarily a simple system for exploring or demonstrating basic non-deterministic behavior and state exploration.

## Purpose

This specification serves as a minimal example of non-deterministic choice, useful for testing, debugging, or demonstrating how a model checker explores multiple possible execution paths from various initial states.
