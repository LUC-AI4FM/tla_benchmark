# Specification Request: Asynchronous Communication Channel

## System to Model

I need a formal specification of an asynchronous communication channel that enables data transfer between a sender and receiver using a handshaking protocol.

## Functional Requirements

The system should model a communication channel where:

1. **Data transmission**: A sender can place data values from a defined set onto the channel
2. **Handshake mechanism**: The channel must implement a ready/acknowledge handshaking protocol to coordinate between sender and receiver
3. **Asynchronous operation**: The sender and receiver operate independently, using the handshake signals to synchronize their actions

## Behavioral Requirements

- The sender should be able to signal when new data is available (ready)
- The receiver should be able to signal when it has consumed the data (acknowledge)
- The protocol should ensure proper alternation between sending and receiving phases
- Data should only change when the protocol state permits it

## Correctness Properties

The specification should guarantee:

1. **No data loss**: Every piece of data placed on the channel can be received
2. **No duplication**: Data is not received multiple times for a single send
3. **Protocol integrity**: The handshake signals follow the correct sequence (ready precedes acknowledge, which precedes the next ready)
4. **Type safety**: Only valid data values from the specified data set appear on the channel

## Additional Notes

The specification should be parameterized by the set of possible data values that can be transmitted through the channel. The model should support verification with concrete example data values for testing purposes.
