# Specification Request: Function with Infinite Domain and Point Update

## System Overview

I need a formal specification that models a simple stateful system involving a function defined over an infinite domain (the integers), where a single point in that domain is modified from a default value.

## Requirements

### Initial State
- The system should initialize a function that maps all integers to a default value (zero), except for one distinguished point (the origin) which should hold a specific non-default value.

### Behavior
- The system is static after initialization—the function should remain unchanged over time.

### Correctness Properties

The specification must verify that:
1. **Value Preservation**: The distinguished point in the function permanently retains its specially assigned value throughout all system states.

## Purpose

This specification serves as a test case for verifying that a model checker can correctly handle:
- Functions with infinite (unbounded) domains
- The EXCEPT construct for point-wise function updates applied to infinite-domain functions
- Invariant checking over such mathematical structures

The key challenge is ensuring the tools can reason about a function defined over all integers while only a finite portion is explicitly modified.
