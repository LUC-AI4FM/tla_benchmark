# Specification Request

## System Description

I need a formal specification for a simple two-variable counter system where two integer values influence each other's progression in a leapfrog pattern. The system should model two counters that alternately drive each other upward until they both reach and stabilize at a terminal value.

## Desired Behavior

The system consists of two integer variables that update simultaneously based on each other's current values. Each variable checks whether the *other* variable has exceeded a threshold:
- If the other variable is above the threshold, the current variable jumps to a final stable value
- Otherwise, the current variable takes on a value derived from the other variable, incrementing the progression

The two variables start at different initial values (consecutive integers) and should eventually both converge to the same terminal state.

## Key Correctness Properties

The specification must verify the following temporal properties:

1. **Eventual Stability (Expected to Hold):** The system should eventually reach a state where one of the variables permanently equals the terminal value. Once this stable state is reached, it should persist forever.

2. **Bounded Progress (Expected to Fail):** As a counterexample, verify that the property "eventually the variable always stays below a small bound" does NOT hold—demonstrating that the system does indeed progress beyond initial values and doesn't remain stuck near its starting point.

## Purpose

This specification is intended to test and demonstrate the behavior of temporal logic formulas that combine the "eventually" and "always" operators (the diamond-box pattern), validating that the model checker correctly handles liveness properties involving eventual permanent stability.
