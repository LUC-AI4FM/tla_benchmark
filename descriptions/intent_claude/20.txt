# Specification Request: Message Set Processing System

## System Overview

I need a formal specification for a simple message processing system that maintains a set of messages and tracks whether specific "interesting" values have been observed during processing.

## System Description

The system should model an asynchronous message queue or mailbox that can hold two different types of messages:

1. **Integer messages** — carrying a numeric payload from a small fixed set of integers (e.g., 1, 2, 3)
2. **String messages** — carrying a text payload from a small fixed set of strings (e.g., "a", "b", "c")

The system should support the following operations:
- **Adding messages**: Either type of message can be added to the set at any time, with any valid payload value for that message type
- **Processing messages**: Messages can be removed from the set and examined; when processed, the system should note whether the message contained a specific "target" value

## Detection Requirements

The system must track two boolean flags indicating whether certain special values have been encountered:
- One flag for detecting a specific integer value (e.g., the number 3) in an integer message
- One flag for detecting a specific string value (e.g., "c") in a string message

When a message is processed, the corresponding flag should be updated to reflect whether that particular message contained the target value.

## Key Properties

The specification should ensure:

1. **Type Safety**: All messages in the system must be well-formed — integer messages carry valid integers, string messages carry valid strings, and no malformed messages exist in the set.

## Behavioral Notes

- Messages are processed nondeterministically (any message in the set may be chosen)
- The detection flags reflect only the most recently processed message of each type, not a cumulative history
- Adding and processing can occur in any interleaving
