# Specification Request: Mutually Recursive Even/Odd Predicate System

## System Overview

I need a formal specification that models the classic mutually recursive definition of even and odd natural numbers. The system should determine whether a given natural number is even or odd through mutual recursion between two predicates.

## Functional Requirements

The specification must define two predicates that work together:

1. **Even predicate**: A number is even if it is zero, or if its predecessor is odd.
2. **Odd predicate**: A number is odd if it is not zero and its predecessor is even.

These definitions should be mutually recursive—each predicate depends on the other to compute its result.

## Technical Challenge

The specification should demonstrate how to handle mutual recursion across module boundaries, where one predicate needs to reference another that isn't yet defined in scope. This requires a technique for forward-declaring one of the predicates so the mutual dependency can be established.

## Correctness Properties

The specification must guarantee:

1. **Base case correctness**: Zero must be classified as even (not odd).
2. **Consistency**: The even and odd predicates must be logical complements—a number cannot be both even and odd, and every natural number must be exactly one or the other.
3. **Recursive correctness**: The predicates should correctly classify small test cases (e.g., 2 should be verified as even).

## Goal

Demonstrate a modular approach to specifying mutually recursive functions in a formal specification language, showing how dependencies between predicates can be resolved through parameterization and instantiation.
