# Specification Request: Simple Cyclic Counter

## System Description

I need a formal specification for a simple cyclic counter that rotates through three distinct states in a fixed sequence.

## Behavioral Requirements

1. **Initialization**: The system should be able to start in one of two initial states (either the first or second value in the cycle).

2. **State Transitions**: The system must cycle through exactly three states in a deterministic sequence, where:
   - The first state transitions to the second state
   - The second state transitions to the third state
   - The third state transitions back to the first state

## Key Properties to Verify

1. **Determinism**: From any given state, there should be exactly one possible next state.

2. **Completeness**: The transition logic should be well-defined for all reachable states (no undefined behavior when the system reaches any state in the cycle).

3. **Liveness** (optional): The system should eventually visit all three states in the cycle.

## Notes

This specification should help verify that conditional case expressions handle all reachable cases correctly, particularly ensuring that the system behaves properly even when not all cases are covered by an explicit "other" or default clause.
