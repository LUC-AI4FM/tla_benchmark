# Specification Request: Binary Relation Properties Library

## System Overview

I need a reusable library for reasoning about binary relations over sets in TLA+. The library should provide operators to test whether a given relation satisfies various fundamental mathematical properties from order theory and set theory.

## Required Functionality

The library must be able to classify binary relations according to the following properties:

### Basic Relation Properties
- **Reflexivity**: Every element is related to itself
- **Irreflexivity**: No element is related to itself
- **Symmetry**: If x is related to y, then y is related to x
- **Antisymmetry**: If x is related to y and y is related to x, then x equals y
- **Asymmetry**: If x is related to y, then y is not related to x
- **Transitivity**: If x is related to y and y is related to z, then x is related to z

### Composite Order Properties
- **Strict partial order**: Irreflexive and transitive (which implies asymmetric)
- **Partial order**: Reflexive, antisymmetric, and transitive
- **Strict total order**: A strict partial order where any two distinct elements are comparable
- **Total order**: A partial order where any two elements are comparable

## Key Requirements

1. The operators should work with arbitrary binary relations defined over a specified domain set
2. The library should support both relation-as-function representations and standard comparison operators
3. Each property check should correctly handle edge cases and produce accurate boolean results

## Correctness Properties

The implementation must correctly identify:
- Equality as reflexive, symmetric, antisymmetric, transitive, and a partial order (but not a total order on sets with multiple elements)
- Strict less-than as irreflexive, asymmetric, transitive, and both a strict partial and strict total order
- Less-than-or-equal as reflexive, antisymmetric, transitive, and a total order

The library should also correctly reject relations that fail these properties, such as detecting when adding contradictory pairs breaks antisymmetry or transitivity.
