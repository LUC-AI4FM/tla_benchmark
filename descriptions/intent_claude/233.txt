# Specification Request: Module Extension with Function Injection

## System Overview

I need a formal specification that demonstrates a modular design pattern where a base module defines generic behavior that can be customized by an extending module through function injection.

## What Should Be Modeled

The system should model a simple counter with conditional incrementing, where:

1. **Base Module**: Defines a generic framework with:
   - A counter that can be incremented
   - A placeholder predicate function that always returns true (serving as a default)
   - A higher-order checking mechanism that applies a given predicate function to a value

2. **Extension Module**: Customizes the base behavior by:
   - Providing a concrete predicate function (e.g., checking if a value is below a threshold)
   - Using the base module's checking mechanism but injecting its own predicate
   - Overriding the goal/invariant with a different bound

## Functional Requirements

- The counter should start at a fixed initial value (e.g., 2)
- At each step, the system checks a condition by applying a predicate function to the current counter value
- If the condition is satisfied, the counter increments by 1; otherwise, it remains unchanged
- The extending module must be able to substitute its own predicate while reusing the base module's higher-order application logic

## Key Correctness Properties

1. **Base Module Goal**: The counter should remain below a stricter bound (e.g., less than 3)
2. **Extension Module Goal**: The counter should remain below a more relaxed bound (e.g., less than 5)

## Purpose

This specification tests the ability to:
- Define higher-order operators that accept functions as parameters
- Instantiate modules and selectively override behavior
- Inject custom predicate functions into a generic checking framework
- Maintain separate invariants at different module levels
