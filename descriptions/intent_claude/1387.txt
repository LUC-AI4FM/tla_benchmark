# Specification Request

The system should attempt to perform an update where one variable is assigned a new value (specifically 42), while simultaneously declaring that both variables remain unchanged.

## Purpose

This specification is intended to demonstrate or test how a model checker handles **contradictory or inconsistent state transitions**. The next-state relation contains logically conflicting requirements: it both assigns a new value to a variable and asserts that same variable stays unchanged.
