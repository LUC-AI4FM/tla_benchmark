# Specification Request: Euclid's GCD Algorithm

## System to Model

I need a formal specification of Euclid's algorithm for computing the Greatest Common Divisor (GCD) of two positive integers.

## Description

The algorithm should take two positive integers as inputs (chosen from some range up to a maximum value) and compute their GCD through repeated subtraction. The basic approach is:

1. Start with two positive integer values
2. Repeatedly subtract the smaller value from the larger value
3. When the values become unequal after subtraction, swap them if necessary so the algorithm can continue properly
4. Continue until one value reaches zero
5. The remaining non-zero value is the GCD

The algorithm uses subtraction rather than the modulo operation, representing a more elementary form of Euclid's method.

## Requirements

- The algorithm must work for any pair of positive integers within the specified range
- The computation must terminate for all valid inputs
- When values need to be swapped (when the first becomes smaller than the second), this swap should happen atomically

## Correctness Properties

The key property that must be verified:

**Partial Correctness**: Upon termination, the computed result must equal the mathematical GCD of the two original input values.

The specification should allow verification that for all possible pairs of initial values in the given range, the algorithm correctly computes their greatest common divisor.
