# Specification Request: 12-Hour Clock System

## System Overview

I need a formal specification for a simple 12-hour clock that tracks and advances the current hour.

## Functional Requirements

The system should model a clock that:

1. **Tracks the current hour** using a 12-hour format (hours 1 through 12)
2. **Advances the hour** in a cyclic manner, where after hour 12, the clock wraps back to hour 1
3. **Uses modular arithmetic** for the hour advancement logic (computing the next hour as a modulo operation plus one)

## Correctness Properties

The specification must guarantee:

1. **Hour Range Invariant**: The hour value must always be a valid 12-hour clock value (an integer from 1 to 12, inclusive)
2. **Proper Cycling**: The clock must correctly cycle through all 12 hours in sequence, returning to 1 after 12

## Additional Context

This specification should be equivalent to an alternative formulation that uses conditional logic (if-then-else) for determining when to wrap around. The two approaches—modular arithmetic versus conditional branching—should produce identical behavior and satisfy the same correctness properties.
