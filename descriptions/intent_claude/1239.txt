# Specification Request: TLA+ Set Comprehension and Function Space Semantics

## System to be Modeled

I need a test harness that validates the correct behavior of TLA+ set construction operations, specifically focusing on:

1. **Set filtering** (selecting elements from a set that satisfy a predicate)
2. **Set mapping** (applying an expression to elements drawn from one or more sets)
3. **Function space construction** (building the set of all functions between two sets)

## Goal

The purpose is to verify that a TLA+ model checker correctly implements the semantics of set comprehension expressions and function spaces according to TLA+ language rules. This serves as a conformance test suite.

## Requirements

The specification must verify the following properties:

### Set Filtering Behavior
- Filtering a set with duplicate elements should treat the set as having no duplicates
- Filtering over Cartesian products should correctly evaluate predicates on tuples
- Filtering should work correctly with infinite base sets (like integers) when membership is tested
- Filtering an empty set should always yield an empty set

### Set Mapping Behavior
- Mapping expressions over multiple bound variables should produce all combinations
- Expressions can bind multiple variables from different sets, including tuple unpacking
- Mapping over any empty set should produce an empty set
- The resulting set should contain exactly the range of the expression over all valid combinations

### Function Space Semantics
- The set of all functions from domain D to range R should have cardinality |R|^|D|
- Sets with duplicate elements should be treated as their deduplicated equivalents
- Function spaces involving nested set comprehensions should evaluate correctly
- Filtering function spaces by predicates on function application should work properly

### Edge Cases
- Duplicate elements in set literals must be collapsed (e.g., {1,3,3,3,4} equals {1,3,4})
- Empty sets in Cartesian products yield empty products
- Complex nested expressions combining unions, subsets, and function spaces should evaluate correctly

## Correctness Properties

Each test case must produce the mathematically expected result. Any deviation from expected set equality or membership should be flagged as a failure. All tests passing confirms that the set construction operations conform to TLA+ semantics.
