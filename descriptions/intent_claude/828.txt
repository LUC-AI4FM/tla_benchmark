# Specification Request: Cat Search Game

## System Overview

I need a formal specification for a classic pursuit-evasion puzzle involving searching for a hidden cat among a row of boxes.

## Problem Description

There is a linear arrangement of boxes (a configurable number). A cat is hiding in one of these boxes. Each day/turn, two things happen:
1. A searcher opens and checks one box
2. The cat moves from its current box to an adjacent box (it cannot stay in place)

The searcher cannot see the cat move and must deduce a strategy to guarantee finding the cat.

## Behavioral Requirements

1. **Initial State**: The cat starts in some box, the searcher picks a box to check, and a search direction is established
2. **Cat Movement**: The cat must move to a neighboring box each turn - it cannot remain stationary. At the ends of the row, the cat can only move inward.
3. **Searcher Strategy**: The searcher systematically checks boxes, following some directional pattern through the row
4. **Turn Alternation**: Each round consists of checking a box and then the cat moving (or vice versa, but in consistent order)

## Key Parameters

- The number of boxes should be configurable as a constant parameter

## Correctness Properties

The specification should allow verification of:

1. **Guaranteed Capture**: Does there exist a search strategy that will eventually find the cat regardless of how the cat moves?
2. **Strategy Soundness**: If following a particular systematic search pattern, will the searcher always succeed?
3. **Termination**: The search process should eventually end with the cat being found

## Purpose

This specification should model the state space of the puzzle to verify whether proposed search strategies are complete (guaranteed to find the cat) against all possible cat movement patterns.
