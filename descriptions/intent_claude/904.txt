# Specification Request: 12-Hour Clock System

## System Description

I need a formal specification for a simple 12-hour clock that tracks only the current hour. This models the basic behavior of an analog clock face or any system that cycles through hours 1 through 12.

## Behavioral Requirements

The clock system must:

1. **Track the current hour**: The system maintains a single piece of state representing which hour is currently displayed (1 through 12).

2. **Advance through hours cyclically**: The clock must be able to tick forward, moving from one hour to the next in sequence. After reaching hour 12, the next tick should return to hour 1.

3. **Start in a valid state**: The clock should begin showing some valid hour between 1 and 12.

## Correctness Properties

The specification must guarantee:

1. **Hour range invariant**: The displayed hour must always be a valid value between 1 and 12, inclusive. The clock should never show hour 0, hour 13, or any other invalid value.

2. **Proper wraparound**: The transition from hour 12 must correctly cycle back to hour 1, not to 0 or 13.

## Purpose

This specification serves as a foundational example for reasoning about cyclic systems and can be composed with other clock components (such as minute hands or AM/PM indicators) to model more complex timekeeping systems.
