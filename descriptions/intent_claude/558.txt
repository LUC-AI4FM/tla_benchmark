# Specification Request: Water Jug Puzzle

## System Overview

I need a formal specification for the classic water jug puzzle (as featured in the movie "Die Hard"). The system involves two unmarked jugs of different capacities, and the goal is to measure out a specific quantity of water using only basic operations.

## System Description

The system consists of two jugs with configurable capacities (a smaller jug and a larger jug). Both jugs start empty, and there is an unlimited water supply available. The jugs have no measurement markings, so you can only know when a jug is completely full or completely empty.

## Allowed Operations

The system should model the following physical operations that can be performed at any time:

1. **Fill either jug completely** from the water supply
2. **Empty either jug completely** (pour out all water)
3. **Pour water from one jug into the other** until either:
   - The source jug becomes empty, or
   - The destination jug becomes completely full (with any excess remaining in the source)

## Requirements

- The jug capacities should be configurable parameters
- Both jugs must start in an empty state
- Each operation should be atomic and deterministic
- The water volume must be tracked precisely (no spillage or loss)
- Any of the allowed operations can be performed in any order

## Correctness Properties to Verify

The primary use of this specification is to explore whether certain target volumes can be achieved. Specifically, I want to be able to:

1. **Check reachability**: Determine if a specific water quantity can be measured in either jug
2. **Find solutions**: Use model checking to discover sequences of operations that achieve a target measurement
3. **Verify impossibility**: Confirm when certain measurements cannot be achieved with given jug sizes

The classic problem instance uses a 3-gallon jug and a 5-gallon jug, with the goal of measuring exactly 4 gallons.
