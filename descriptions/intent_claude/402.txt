# Specification Request

## System Overview

I need a test harness specification that validates the correctness of basic TLA+ set operations and expressions when they involve state variables. This is essentially a self-checking test suite that runs during model initialization.

## Purpose

The goal is to verify that fundamental TLA+ constructs work correctly when applied to specification variables, rather than just constant expressions. This includes testing set comprehensions, set mappings, existential quantification, and comparison operations.

## Required Test Cases

The specification should validate the following capabilities:

1. **Basic numeric comparison**: Confirm that a variable can be compared against constant values (e.g., verifying a value is greater than some threshold)

2. **Set mapping with variables**: Verify that applying a function to each element of a singleton set containing a variable produces the expected result (e.g., incrementing each element)

3. **Set filtering with variables**: Confirm that filtering a set based on a predicate involving the variable correctly selects matching elements

4. **Existential quantification over variable-dependent sets**: Verify that existential statements over sets containing variables evaluate correctly

## Correctness Properties

- All test assertions must pass during initialization
- Each successful test should produce a printed confirmation message
- The specification should have a trivially true invariant (the real "checking" happens in the initial state predicate)
- The system should be static after initialization (no meaningful state changes)

## Additional Considerations

The specification should also include (potentially for future expansion) test cases for:
- Range expressions involving variables
- Bounded sequence generation using variables as set elements or bounds
