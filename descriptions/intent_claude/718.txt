# Specification Request: Graph Theory Library

## Overview

I need a formal specification of a reusable library for directed graph operations. The library should provide fundamental graph-theoretic concepts and queries that can be used when modeling systems involving dependencies, networks, or any structure representable as nodes and directed edges.

## System Description

The library should support directed graphs represented as a collection of nodes and directed edges between them. It must provide a comprehensive set of operations for analyzing graph structure and relationships between nodes.

## Required Operations

### Graph Construction and Combination
- Define what constitutes a valid directed graph over a given set of nodes
- Support combining two graphs into their union (merging both node sets and edge sets)
- Represent an empty graph with no nodes or edges

### Path and Connectivity Analysis
- Enumerate all simple paths (paths without repeated nodes) within a graph
- Determine whether two nodes are connected (reachable from one to the other)
- Compute the full connectivity relation for all pairs of nodes

### Structural Classification
- Determine whether a graph is a directed acyclic graph (DAG) — that is, contains no cycles
- Check whether a graph is bipartite with respect to a given partition of its nodes

### Node Relationship Queries
- Find the immediate successors of a node (nodes reachable via a single outgoing edge)
- Find the immediate predecessors of a node (nodes with edges pointing to it)
- Extend these to sets of nodes (all successors/predecessors of any node in a set)
- Compute transitive closure relationships:
  - All ancestors of a node (nodes from which the target is reachable)
  - All descendants of a node (nodes reachable from the source)

### Special Node Identification
- Identify root nodes (nodes with no incoming edges)
- Identify leaf nodes (nodes with no outgoing edges)

## Correctness Requirements

1. **Empty graph handling**: Operations should behave sensibly on graphs with no edges or no nodes
2. **Consistency**: The connectivity check and the connectivity relation matrix must agree for all node pairs
3. **Boolean completeness**: Predicates like connectivity and DAG checks must return definite true/false values for all valid graphs
4. **Cycle detection accuracy**: The DAG check must correctly identify self-loops, two-node cycles, and larger cycles as violations
5. **Transitive closure correctness**: Ancestor and descendant computations must capture the full transitive reachability, including handling cycles where a node can be its own ancestor/descendant
