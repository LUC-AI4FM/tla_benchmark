# Specification Request

I need a formal specification for an extended bag (multiset) data structure and its operations.

## System Description

The system should model a **bag** (also known as a multiset) — a collection data type that, unlike a traditional set, allows multiple occurrences of the same element. The specification should cover extended operations beyond basic bag functionality.

## Required Functionality

The specification must define and verify operations on bags, including but not limited to:

- Creating bags from sequences or sets
- Adding and removing elements (with proper multiplicity handling)
- Computing bag cardinality (total count of all elements including duplicates)
- Union, intersection, and difference operations on bags
- Subset and equality comparisons between bags
- Converting bags to other representations
- Folding/reducing operations over bag contents

## Correctness Properties

The specification should guarantee:

1. **Multiplicity Integrity**: Element counts must always be non-negative integers, and operations must correctly maintain multiplicity counts
2. **Algebraic Properties**: Bag operations should satisfy expected mathematical properties (e.g., commutativity and associativity of union where applicable)
3. **Consistency**: Converting between representations (e.g., sequence to bag and back) should preserve the essential information
4. **Boundary Conditions**: Empty bags and singleton bags must be handled correctly as edge cases

## Purpose

This specification serves as a test suite to validate that extended bag operations behave correctly according to their mathematical definitions. It should be suitable for model checking to catch any violations of the expected bag semantics.
