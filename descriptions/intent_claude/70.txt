# Specification Request: Non-Empty Function Domain Verification

## System Description

I need a formal specification to model a simple stateful system that holds a function (mapping from integers to integers) as its state. The system should initialize with some arbitrary function and then remain unchanged over time.

## Requirements

1. **State**: The system maintains a single function that maps integers to integers.

2. **Initialization**: The function should be initialized to some arbitrary/generated value at startup.

3. **Behavior**: After initialization, the system is static—the function never changes.

## Correctness Property

The key invariant that must be verified:

- **Non-Empty Domain**: The function must always have a non-empty domain. That is, there must exist at least one input value for which the function is defined.

## Purpose

This specification is intended to verify that when arbitrary functions are generated or considered during model checking, they always satisfy basic well-formedness criteria—specifically, that they are not degenerate empty mappings. This is essentially a test of the model checker's function generation capabilities to ensure they produce meaningful, non-trivial function values.
