# Specification Request

## System Description

I need a formal specification that demonstrates **module instantiation and constant validation** in a modular specification system.

## Requirements

### Core Functionality

1. **Constant Declaration with Constraint**: The specification should declare a constant value that is constrained to equal 42 (when added to zero, confirming basic arithmetic identity).

2. **Module Composition**: The specification must demonstrate how to import and instantiate another module (an external dependency), binding local values to that module's parameters. Specifically:
   - One parameter should receive the declared constant
   - Another parameter should receive the value zero

3. **Multiple Instantiation Styles**: Show both:
   - Direct (anonymous) module instantiation that merges definitions into the current namespace
   - Named module instantiation that creates a qualified namespace for accessing the imported definitions

## Correctness Properties

1. **Assumption Validity**: The constant must satisfy the arithmetic constraint (adding zero yields 42), serving as a precondition for the specification.

2. **Theorem Consistency**: The same arithmetic property should be expressible as a provable theorem, demonstrating that the assumption leads to a verifiable fact.

## Purpose

This specification serves as a test case for verifying that a formal methods tool correctly handles:
- Module parameterization and instantiation
- Constant substitution during instantiation
- The relationship between assumptions, theorems, and definitions expressing the same property
