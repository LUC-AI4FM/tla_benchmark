Please write a formal specification for a **graph visualization export utility**.

## System Overview

The system should provide functionality to convert graph data structures into the DOT language format used by GraphViz for rendering directed graphs.

## Requirements

### Input
- A directed graph structure consisting of:
  - A set of nodes (vertices)
  - A set of edges, where each edge connects a source node to a destination node and may carry additional metadata (such as a label or weight)

### Functionality
- Convert the graph into a valid DOT language string representation suitable for GraphViz processing
- Support custom labeling of nodes through a user-provided function that maps each node to its display label
- Support custom labeling of edges through a user-provided function that extracts or computes the edge label from edge data

### Output Format
- Generate a syntactically correct DOT `digraph` declaration
- Each node should appear with a unique identifier and a label attribute
- Each directed edge should appear with proper source-to-destination syntax and a label attribute
- The output should be a single string that can be passed directly to GraphViz tools

## Key Properties

1. **Completeness**: Every node in the input graph must appear in the output, and every edge must be represented
2. **Correctness**: Edge directionality must be preserved—if an edge goes from node A to node B in the input, it must go from A to B in the output
3. **Valid Syntax**: The generated string must be valid DOT language that GraphViz can parse
4. **Determinism**: The same graph with the same labeling functions should produce consistent output (node identifiers may be implementation-dependent, but the structure must be correct)
