# Specification Request: Mathematical Formula Verification Framework

## Overview

I need a framework for verifying mathematical formulas and logical properties using a model checker. The system should allow me to express mathematical assertions and have them automatically checked for validity.

## Goals

The primary purpose is to provide an interactive environment where I can:

1. **Verify propositional logic tautologies** - Check whether logical equivalences and implications hold for all possible truth values
2. **Verify set-theoretic identities** - Confirm that set operations behave as expected
3. **Disprove non-tautologies** - Demonstrate that certain formulas are NOT universally valid by finding counterexamples

## Requirements

### Supported Mathematical Domains

The system should support:

- **Boolean logic**: Conjunction, disjunction, implication, negation, equivalence
- **Set theory**: Union, intersection, set difference, subset relations, set membership, power sets
- **Quantification**: Universal and existential quantifiers over finite domains

### Formula Checking Capabilities

1. **Propositional tautology checking**: Given a propositional formula, verify it holds for all assignments of TRUE/FALSE to its variables

2. **Set identity verification**: Given set expressions, verify they are equal or satisfy specified relationships for all sets within a bounded universe

3. **Counterexample discovery**: When checking that a formula is NOT a tautology, the system should confirm this by exhaustively checking all cases

### Constraints

- All quantification must be bounded (over explicitly defined finite sets)
- The system should support a collection of distinct symbolic constants that are guaranteed to be unequal to each other and to any other values
- Standard set operations and boolean operators must be available

## Correctness Properties

Each asserted formula should be verified to be TRUE. If any assertion fails, the system should report which specific formula failed and ideally provide a counterexample showing why it failed.

The framework should make it easy to isolate errors by allowing multiple independent assertions rather than requiring one large conjunction.
