# Specification Request: Fold Operations Over Collections

## System Description

I need a formal specification that demonstrates and verifies the correctness of fold (reduce) operations over finite collections. The system should model how fold operations work on both sets and sequences.

## Requirements

### Core Functionality

1. **Fold over sets**: The specification should verify that folding an associative, commutative binary operation over a finite set produces the expected aggregate result. Specifically, summing the elements of a set should yield their total.

2. **Fold over sequences**: The specification should verify that folding a binary operation over an empty sequence returns the initial accumulator value unchanged.

### Correctness Properties

The specification must guarantee:

1. **Set fold correctness**: Folding addition with an initial value of 0 over a set containing the elements {1, 2, 3} must equal 6.

2. **Empty sequence identity**: Folding any binary operation over an empty sequence must return exactly the initial accumulator value (demonstrating the identity property of folds on empty collections).

### Context

This is essentially a static verification—the system state does not change over time. The purpose is to use the model checker to verify mathematical properties of fold operations rather than to model dynamic system behavior. The specification serves as a test or proof that the fold primitives behave correctly according to their mathematical definitions.
