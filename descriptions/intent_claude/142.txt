# Specification Request

## System Overview

I need a formal specification for an extremely simple stationary system that maintains a single integer value. This is primarily intended as a test case for verifying that a model checker correctly handles named assumptions when they appear inline within state predicates.

## System Requirements

The system should:

1. Initialize with a single integer state component set to zero
2. Never change its state after initialization (the system is completely static)

## Correctness Properties

The specification must guarantee:

1. **Invariant**: The integer value remains zero at all times

## Special Requirements

The specification must include a **named assumption** (a basic tautology that is always true) that is:
- Declared as a named, referenceable assumption at the module level
- Referenced inline as a conjunct within the initialization predicate

This structure is specifically designed to test whether formal verification tools correctly process named assumptions when they are used inline within other definitions, rather than only at the top level.
