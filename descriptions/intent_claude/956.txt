# Specification Request: Natural Number Arithmetic Operations

## System to Model

I need a formal specification that defines the set of natural numbers along with standard arithmetic operations and comparison relations over them.

## Requirements

The specification should provide:

### Core Definitions
- A definition of the natural numbers (non-negative integers: 0, 1, 2, ...)

### Arithmetic Operations
- **Addition** of two numbers
- **Subtraction** of two numbers
- **Multiplication** of two numbers
- **Exponentiation** (raising a number to a power)
- **Integer division** (quotient when dividing, truncating toward zero)
- **Modulo operation** (remainder after integer division)

### Comparison Relations
- **Less than or equal to** comparison
- **Greater than or equal to** comparison
- **Strict less than** comparison
- **Strict greater than** comparison

### Range Construction
- A way to construct the set of all integers within a closed interval (from some lower bound to some upper bound, inclusive)

## Key Properties

1. Integer division should produce a quotient such that there exists a valid remainder between 0 and one less than the divisor
2. The modulo operation should be consistent with integer division (the remainder when reconstructing the original value)
3. Comparison relations should have their standard mathematical meanings and relationships to each other (e.g., greater-than-or-equal is the converse of less-than-or-equal)
4. Strict inequalities should be equivalent to non-strict inequality combined with distinctness

## Goal

This specification serves as a foundational module that other specifications can use when they need to reason about natural numbers and perform standard arithmetic. It should provide clean, mathematical definitions that can be reliably used throughout larger system specifications.
