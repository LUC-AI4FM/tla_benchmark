# Specification Request: Simple Unbounded Counter

## System Description

I need a formal specification for a basic counter system that starts at a configurable initial value and increments indefinitely.

## Desired Behavior

The system should:

1. **Initialize** the counter to a specified constant starting value
2. **Increment** the counter by one on each step, continuing forever

## Configuration

- The system should accept a constant parameter representing the initial counter value (an integer)

## Properties of Interest

This is primarily a foundational specification to verify basic counting behavior. The main aspects to consider are:

- The counter should always hold an integer value
- The counter should increase monotonically
- Each transition should advance the counter by exactly one

## Notes

This is a minimal specification intended for testing purposes, particularly around type annotation requirements in the modeling tool. The specification should be simple enough to highlight any issues with type checking or variable declarations.
