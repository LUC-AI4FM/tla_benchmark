# Specification Request: Extended Sequence Operations Library

## Goal

Create a formal specification for a library of extended sequence (ordered list) operations that go beyond the standard sequence primitives. This library should provide a comprehensive set of utilities for manipulating, querying, and transforming finite sequences in a specification language.

## System Description

The library should define operations on sequences (finite ordered collections indexed from 1) that support common programming patterns for list manipulation. These operations should work with sequences containing any element type, including integers, strings, sets, and nested sequences.

## Required Operations

### Conversion Operations
- Convert a sequence to its corresponding set of elements (removing duplicates and ordering)
- Convert a set to a sequence containing exactly those elements
- Convert a set to a sorted sequence given a comparison function

### Element Query Operations
- Check whether a sequence contains a specific element
- Retrieve the last element of a sequence
- Retrieve all elements except the last (front of sequence)

### Sequence Modification Operations
- Prepend an element to the front of a sequence
- Reverse a sequence
- Remove all occurrences of a specific element from a sequence
- Replace all occurrences of one element with another
- Insert an element at a specific position
- Remove the element at a specific position
- Replace the element at a specific position

### Prefix and Suffix Operations
- Determine if one sequence is a prefix of another
- Determine if one sequence is a strict (proper) prefix of another
- Determine if one sequence is a suffix of another
- Determine if one sequence is a strict suffix of another
- Compute the set of all prefixes of a sequence
- Find common prefixes among a set of sequences
- Find the longest common prefix among a set of sequences

### Higher-Order Operations
- Fold/reduce a sequence from left to right with an accumulator
- Fold/reduce a sequence from right to left with an accumulator
- Flatten a sequence of sequences into a single sequence

### Structural Operations
- Zip two sequences together into a sequence of pairs (truncating to shorter length)
- Compute all contiguous subsequences of a sequence

### Subsequence Search and Replace
- Find the index of the first occurrence of a subsequence within a sequence
- Replace the first occurrence of a subsequence with another sequence

## Key Correctness Properties

1. **Set-Sequence Round-Trip**: Converting a sequence to a set and back should preserve all elements (though not necessarily order)

2. **Sorted Output**: When converting a set to a sorted sequence, the result must contain exactly the input elements and respect the given ordering

3. **Containment Consistency**: An element is contained in a sequence if and only if it appears in the set of sequence elements

4. **Reverse Involution**: Reversing a sequence twice yields the original sequence

5. **Removal Completeness**: Removing an element eliminates all its occurrences

6. **Prefix/Suffix Transitivity**: Prefix and suffix relations should be transitive and reflexive (for non-strict versions)

7. **Prefix Set Completeness**: The set of all prefixes includes the empty sequence and the sequence itself

8. **Fold Accumulation**: Fold operations must process all elements exactly once in the specified order

9. **Flatten Preservation**: Flattening preserves all elements from all subsequences in order

10. **Zip Length**: The result of zipping has length equal to the minimum of the two input lengths

11. **Subsequence Replacement**: Replacing a subsequence should only affect the first occurrence while preserving the rest of the sequence
