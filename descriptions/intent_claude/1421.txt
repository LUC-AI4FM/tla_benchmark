# Specification Request

## System Description

I need a formal specification for a simple state machine that models a system with a numeric state variable that can transition between a small set of integer values (typically 0, 1, and possibly 2).

## Behavioral Requirements

The system should:

1. **Start in an initial state** — either at value 0 or at value -1, depending on which initialization variant is used.

2. **Transition non-deterministically** — the basic transition relation should allow the state to move between values 0 and 1. An extended variant should additionally allow transitioning to value 2.

3. **Include fairness** — the system should guarantee that transitions eventually happen (weak fairness), preventing the system from stuttering forever.

## Correctness Properties to Verify

The specification should allow exploration of several temporal properties:

1. **"At most once" pattern** — Once the system reaches value 1 and subsequently returns to value 0, it must remain at 0 forever. This captures a notion of irreversible commitment or a one-shot event.

2. **Alternative "at most once" variant** — A similar property where after visiting 1 and then 0, the system must eventually settle at value 2.

3. **Liveness/leads-to property** — From the initial state, the system should eventually reach a condition where once it enters state 1, it stays in state 1 permanently.

4. **Trivial tautology** — Include a trivially true temporal property for testing purposes.

## Purpose

This specification appears intended for testing or demonstrating model checker behavior, particularly around liveness properties, counterexample generation (including lasso-shaped traces), and different initialization/transition combinations.
