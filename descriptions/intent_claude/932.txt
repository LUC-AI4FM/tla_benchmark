# Specification Request: Live Hour Clock

## System Overview
I need a formal specification of a simple clock that displays hours and continuously advances through a 12-hour cycle.

## Functional Requirements
The system should model a clock that:
- Displays an hour value in a 12-hour format (1 through 12)
- Can start at any valid hour
- Advances from one hour to the next in sequence
- Wraps around from 12 back to 1, creating a continuous cycle

## Correctness Properties
The specification must guarantee:
- **Safety**: The displayed hour is always a valid value between 1 and 12 (inclusive)
- **Liveness**: The clock must eventually advance—it cannot remain stuck on the same hour forever. Time must always make progress.

## Purpose
This specification serves as a foundational example of modeling a simple reactive system with both safety invariants (valid state bounds) and liveness requirements (guaranteed progress), demonstrating how to formally reason about systems that must continuously operate and make forward progress.
