Write a small TLA+ module that demonstrates passing higher-order operators as arguments in TLA+. The module should define a generic set-filter operator that takes a set, a unary predicate, and a binary predicate, and returns the subset of elements satisfying both predicates simultaneously. The demonstration should initialize a variable to a value drawn from the result of applying this operator to the set {1,2,3,4,5}, filtering for elements greater than 1 and elements that are both odd and paired with the Boolean TRUE. The system should then remain static with no further state changes. No explicit correctness properties beyond well-formedness are required; the purpose is purely to illustrate that higher-order operator arguments with lambda expressions work correctly in TLA+.
