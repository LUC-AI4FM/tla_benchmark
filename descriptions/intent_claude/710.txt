# Specification Request: CSV File I/O Operations

## System Overview

I need a formal specification for a CSV (comma-separated values) file input/output utility system that can write structured data to files and read it back, with support for custom delimiters and templates.

## Core Functionality Requirements

The system must support the following operations:

1. **Templated CSV Writing**: Write data to a CSV file using a format template. The template should support placeholder substitution (similar to printf-style formatting) where multiple values of different types (integers, strings, records/structures) can be serialized into a single line.

2. **CSV Reading**: Read CSV data back from a file, parsing it according to a specified delimiter and mapping columns to named fields based on a provided header schema.

3. **Record Counting**: Count the number of records (lines) in a CSV file without fully parsing its contents.

## Key Requirements

- **Custom Delimiters**: The system should support arbitrary delimiter characters, not just commas. A delimiter like `#` should be usable for separating fields.

- **Heterogeneous Data Types**: The write operation must handle mixed data types including:
  - Numeric values
  - String values
  - Structured records/objects

- **Round-Trip Consistency**: Data written to a file should be readable back, though the system may represent all values as strings upon reading (with appropriate quoting/escaping preserved).

- **Graceful Handling of Missing Files**: When asked to count records in a non-existent file, the system should return zero rather than failing.

## Correctness Properties

1. **Write Success Implies Readable**: If a write operation succeeds, the resulting file must contain exactly the expected number of records.

2. **Data Preservation**: Written data must be recoverable through the read operation, with values accurately represented (accounting for string serialization).

3. **Non-Existent File Safety**: Operations on non-existent files must behave predictably without causing system failures.
