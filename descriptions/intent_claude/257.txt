# Specification Request: Function Constructor and Function Set Semantics

## System to Be Modeled

A test suite that verifies the correctness of function-related operations in a formal specification language, specifically focusing on how functions are constructed, how function sets are enumerated, and how domain equality is handled.

## Goal

Create a specification that serves as a correctness test for the core semantics of function constructors and function sets. The tests should validate that a model checker or specification tool correctly implements the mathematical foundations of functions over various domain types.

## Requirements

The specification must verify the following capabilities:

1. **Basic function construction**: Functions defined over large integer ranges should correctly map each domain element to its specified value.

2. **Functions returning sets**: When a function maps elements to singleton sets, each domain value should map to the singleton containing exactly that value.

3. **Functions with set-valued domains**: Functions whose domain consists of sets (rather than primitive values) should correctly handle set elements as keys, including proper nesting when the codomain also contains sets.

4. **Functions over powersets**: Function construction should work correctly when the domain is a powerset, and the resulting function should be equivalent regardless of how the powerset is represented (enumerated explicitly vs. using the powerset operator).

5. **Function set enumeration with codomain constraints**: When enumerating all functions from one set to another (particularly involving powersets), every enumerated function must have the correct domain and each output must belong to the specified codomain.

6. **Consistent treatment of equal domain elements**: When a domain set contains elements that are equal (even if expressed differently), any function from that domain must map all equal elements to the same value. This tests that function set enumeration respects the mathematical requirement that functions are well-defined.

## Key Correctness Properties

- Function application must return the value specified by the function's definition
- Domain membership and equality must be handled correctly for complex types (sets, nested sets)
- The set of all functions between two sets must only contain mathematically valid functions
- Equal elements in a domain must never map to different values in any function from a function set
