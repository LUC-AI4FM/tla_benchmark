# Specification Request: Function Construction from Sets of Pairs

## System to Model

I need a formal specification that tests and validates the behavior of constructing functions from sets of key-value pairs. This is essentially a verification that a utility for converting sets of tuples into proper mathematical functions works correctly across various type scenarios.

## Requirements

The specification should demonstrate function construction in three distinct scenarios:

1. **Simple string-to-integer mapping**: Create a function that maps string keys to integer values (e.g., mapping names to numbers).

2. **Set-to-integer mapping**: Create a function where the domain consists of sets of integers, and each set maps to a single integer value. This tests that complex domain types (sets as keys) are handled correctly.

3. **Function-to-value mapping**: Create a function where the domain elements are themselves functions. This tests the ability to use functions as first-class values that can serve as keys in another function.

## Correctness Properties

The specification must guarantee:

1. **Domain correctness**: The domain of each constructed function contains exactly the keys specified in the input pairs, no more and no less.

2. **Mapping correctness**: Looking up any key in the constructed function returns exactly the value it was paired with in the original set of pairs.

3. **Type flexibility**: The construction mechanism works uniformly regardless of whether domains are simple values (strings), complex values (sets), or even other functions.

## Goal

The purpose is to verify that function construction from pair-sets behaves as a mathematically sound bijection between the set of pairs and the resulting function's graph—ensuring the function faithfully represents the intended mappings and can be queried correctly for all specified keys.
