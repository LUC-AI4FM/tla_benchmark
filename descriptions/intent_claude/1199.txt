# Specification Request: Recursive Function with Module Instantiation

## System Overview

I need a formal specification that tests the behavior of recursive functions when combined with module instantiation in TLA+. Specifically, I want to verify that recursion works correctly when a recursive function delegates part of its computation to an operator defined in a separate module.

## What Should Be Modeled

A factorial computation where:
- A recursive function computes the factorial of a natural number
- The recursive call is made indirectly through an instantiated module, where the recursive function itself is passed as a parameter to that module
- The instantiated module provides an operator that invokes the passed-in function

## Requirements

1. **Recursive delegation**: The main recursive function should call into an external module's operator for its recursive step, passing itself as a parameter to enable the callback
2. **Base case correctness**: The function must return 1 when given input 0
3. **Recursive case correctness**: For any positive input n, the function must return n multiplied by the result of the function applied to (n-1)

## Correctness Properties

The specification must verify:
- The base case: factorial of 0 equals 1
- A specific test case: factorial of 4 equals 24
- The general recursive property: for all values from 1 to 5, the factorial satisfies the standard recurrence relation (f(i) = i × f(i-1))

## Goal

Demonstrate and verify that TLA+'s recursive function definitions work correctly when the recursion passes through module instantiation boundaries, ensuring that higher-order function-like patterns (passing a recursive function as a module parameter) behave as expected.
