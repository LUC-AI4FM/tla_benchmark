# Specification Request: Lexicographically Least Circular Substring

## System Overview

I need a formal specification of Booth's algorithm (1980) for finding the lexicographically smallest rotation of a circular string. Given a string viewed as circular (where the end wraps around to the beginning), the algorithm should identify which starting position produces the smallest string when read in order.

## Problem Description

Consider a string of characters that can be rotated—meaning we can take characters from the beginning and move them to the end. For example, the string "cab" can be rotated to "abc", "bca", or back to "cab". Among all possible rotations, exactly one (or more, in case of ties) will be lexicographically smallest. The algorithm must find the starting index of this minimal rotation.

## Input Requirements

- A finite sequence of characters drawn from a totally ordered character set (a subset of natural numbers)
- The string should be treated as circular, meaning positions wrap around using modular arithmetic

## Functional Requirements

The algorithm must:
1. Process an arbitrary input string from the defined character set
2. Examine the string as if it were doubled (to handle the circular nature without explicit wraparound)
3. Compute and return an index representing where the lexicographically smallest rotation begins
4. Terminate for all valid inputs

## Correctness Properties

The specification must guarantee:

1. **Termination**: The algorithm always finishes executing for any valid input string.

2. **Minimal Rotation**: Upon completion, the computed index identifies a rotation of the input that is lexicographically less than or equal to every other possible rotation of the same string.

3. **Canonical Selection**: When multiple rotations are equally minimal (the string has repeated patterns), the algorithm should return the smallest such index, ensuring a unique canonical answer.

4. **Type Safety**: All intermediate computations stay within expected bounds—indices remain valid, and auxiliary data structures maintain their intended structure throughout execution.

## Context

This algorithm is useful for canonical representation of circular structures, such as comparing cyclic DNA sequences, finding normal forms of necklaces in combinatorics, or detecting rotational equivalence of strings efficiently.
