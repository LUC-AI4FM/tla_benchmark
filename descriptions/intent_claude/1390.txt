# Specification Request: Multi-Endpoint FIFO Channel System

## System Overview

I need a formal specification for a message-passing system that provides independent FIFO (first-in, first-out) communication channels for multiple endpoints. Think of it as a collection of bounded message queues, one per endpoint, where each queue operates independently.

## System Requirements

### Basic Functionality

1. **Multiple Endpoints**: The system should support a configurable set of communication endpoints, where each endpoint has its own dedicated message queue.

2. **Message Operations**: For each endpoint, the system must support:
   - **Writing a message**: Adding a message to the end of that endpoint's queue
   - **Reading a message**: Removing a message from the front of that endpoint's queue

3. **Bounded Capacity**: Each queue should have a maximum size limit. Writes to a full queue should be blocked (not allowed).

4. **FIFO Ordering**: Messages must be read in the same order they were written (first-in, first-out semantics).

### Initial State

All endpoint queues should start empty.

## Correctness Properties

### Key Property: Refinement to Abstract FIFO Specification

The critical correctness requirement is that **each individual endpoint's queue must behave exactly like a standalone FIFO queue**. Specifically:

- Each endpoint's behavior should refine (implement correctly) a simple, canonical FIFO queue specification
- This refinement should hold independently for every endpoint in the system
- The abstract FIFO queue starts empty and supports put (append) and get (remove from front) operations

This refinement property ensures that the multi-endpoint system doesn't introduce any behaviors that would violate the expected semantics of independent FIFO queues.

## Configuration Parameters

The specification should be parameterized by:
- The set of endpoints
- The set of possible messages
- The maximum queue size
