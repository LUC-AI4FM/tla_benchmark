Specify a system that tests the consistency of record merging operations in a message-passing context.

The system should model a simple message store where messages can be retrieved and augmented with additional metadata. Specifically, when fetching a message by its destination identifier, the system should merge the destination information into the retrieved message record.

**Key requirements:**

1. The system must support a collection of messages, where each message is a record containing data fields.

2. A retrieval operation must combine the original message content with routing information (the destination identifier used to look up the message).

3. When record merging occurs, the operation must be deterministic—retrieving the same message multiple times must yield identical results.

**Correctness properties to verify:**

1. **Idempotency of retrieval**: Fetching the same message twice must produce two equal values. If a message is retrieved and stored in a pair, both elements of that pair must be identical.

2. **Consistency under evaluation**: The merged record structure must remain stable across multiple references or evaluations within the same expression context.

The specification should confirm that the record combination operator behaves predictably and that no unexpected variation occurs when the same logical retrieval is performed multiple times within a single computation.
