# Specification Request: Boolean Toggle System with Operator Abstraction

## System Description

I need a formal specification of the simplest possible state-changing system: a single boolean flag that alternates between true and false states.

## Behavioral Requirements

1. The system should start with the flag in the "off" (false) state
2. Each step of the system should toggle the flag to its opposite value
3. The system should be allowed to stutter (remain unchanged) at any point

## Key Correctness Properties

- **Initial State**: The system must begin in a well-defined initial configuration
- **Deterministic Transitions**: Each non-stuttering step must flip the boolean value
- **Safety**: The flag can only ever hold boolean values

## Additional Modeling Goal

I want to explore different ways of structuring the temporal specification formula itself. Specifically, I'm interested in understanding how wrapping the standard specification components (initial conditions, action formulas, and temporal formulas) inside identity operators affects the specification's meaning or behavior. This is primarily an exercise in understanding TLA+ semantics around:

- Applying operators to state predicates
- Applying operators to action formulas
- Applying operators to temporal formulas

The goal is to verify that these different structural formulations are semantically equivalent and behave correctly under model checking.
