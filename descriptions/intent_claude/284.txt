# Specification Request: Simple Unbounded Counter with Configurable Initial Value

## System Description

I need a formal specification for a simple counter system that starts from a configurable initial value and increments indefinitely.

## Requirements

### Functional Requirements

1. **Configurable Starting Point**: The system should have a configurable constant that determines the initial value of the counter. This value should be provided as a parameter when the system is instantiated.

2. **Counter Behavior**: The system maintains a single integer counter that:
   - Begins at the configured initial value
   - Increments by one at each step
   - Continues incrementing without bound

### Key Properties

The specification should allow verification that:
- The counter is always at least as large as its initial value
- The counter increases monotonically over time

## Additional Context

This is a minimal specification intended primarily to test or demonstrate type-checking capabilities in a formal specification tool. Specifically, I want to explore what happens when type annotations are incomplete—the initial value parameter should intentionally be left without a type annotation to trigger a type-checking warning, while the counter variable itself should be properly annotated as an integer.
