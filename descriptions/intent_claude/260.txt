# Specification Request

I need a formal specification for a simple record field accessor utility.

## System Description

The system should provide a basic data extraction mechanism that retrieves a specific field value from a structured record. Specifically, given any record that contains a field named "x", the system should return the value stored in that field.

## Requirements

1. **Field Access**: The system must be able to access and return the value of the "x" component from any record structure that contains such a field.

2. **Deterministic Behavior**: Given the same input record, the operation should always return the same result.

## Purpose

This appears to be a helper definition intended for use in larger specifications where records with an "x" field are commonly accessed. It provides a reusable, named operation for this common pattern rather than using direct field access syntax throughout a specification.

## Correctness Properties

- The returned value must exactly equal the value stored in the "x" field of the input record.
- The operation should be purely functional with no side effects.
