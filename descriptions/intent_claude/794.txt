# Specification Request: Fair Die Simulation Using Coin Flips

## System Overview

I need a formal specification for the Knuth-Yao algorithm, which simulates a fair six-sided die using only fair coin flips. The algorithm should produce each outcome (1 through 6) with exactly equal probability of 1/6, despite only having access to a binary random source.

## What the System Must Do

The system should model a state machine that:

1. Starts in an initial state and repeatedly flips a fair coin
2. Transitions between internal states based on coin flip outcomes (heads or tails)
3. Eventually terminates in one of six final states, each representing a die face (1-6)
4. Uses a specific tree structure of transitions designed to achieve uniform distribution over the six outcomes

The algorithm works by traversing a binary tree where:
- Each internal node represents flipping a coin
- Branches correspond to heads or tails outcomes
- Some paths lead back to earlier nodes (to handle the fact that 6 doesn't evenly divide powers of 2)
- Leaf nodes represent the final die roll outcomes

## Key Correctness Properties

The specification must guarantee:

1. **Termination with probability 1**: The algorithm must eventually reach a final state (produce a die result) with certainty, assuming fair weak fairness on coin flips

2. **Fairness of outcomes**: Each of the six possible die values must be equally likely (probability 1/6)

3. **Probability tracking**: The model should track the probability mass at the current state, which halves with each coin flip, to enable reasoning about the probabilistic behavior

4. **Convergence**: For any positive probability threshold, the system should eventually either terminate or have remaining probability mass below that threshold

## Mathematical Foundation

The specification should utilize dyadic rationals (fractions with powers of 2 in the denominator) to precisely represent the probabilities involved in the coin-flipping process, since all intermediate probabilities in this algorithm are of this form.
