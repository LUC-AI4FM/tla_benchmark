Please write a formal specification for a system that explores different categories of operator definitions based on how they handle their arguments and state variables.

The specification should define and demonstrate:

1. **A parameterless operator** that references the next-state value of a variable (a primed variable expression)

2. **Simple parameterized operators** (with one and two arguments) that combine their parameters with a state variable into tuple structures, treating arguments in a standard substitutable manner

3. **Operators with non-substitutable argument behavior**, specifically:
   - An operator that tests whether its argument (treated as an action) is enabled
   - An operator that applies the prime operator to one of its arguments directly

The goal is to illustrate the distinction between operators where arguments can be freely substituted (Leibniz equality applies) versus operators where the syntactic form of the argument matters for the semantics (such as when arguments appear under ENABLED or are primed within the operator body).

This specification serves as a test case or reference for understanding how TLA+ treats different operator argument contexts, particularly the distinction between ordinary expressions and action contexts.
