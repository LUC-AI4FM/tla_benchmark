# Specification Request: Peano Natural Numbers

## System to Model

I need a formal specification that defines the natural numbers from first principles using Peano's axioms. This should establish the foundational structure of natural numbers as an axiomatic system.

## Requirements

The specification should capture the essential properties that uniquely characterize the natural numbers:

1. **Zero exists**: There must be a distinguished starting element that serves as the first natural number.

2. **Successor function**: Every natural number must have a unique successor that is also a natural number.

3. **Zero is not a successor**: The starting element cannot be reached by applying the successor operation to any natural number—it has no predecessor within the system.

4. **Injectivity of successor**: If two numbers have the same successor, they must be the same number (equivalently, every non-zero number has exactly one predecessor).

5. **Induction principle**: The natural numbers contain no "extra" elements beyond what can be reached from zero by repeated succession. Any set containing zero and closed under the successor operation must contain all natural numbers.

## Correctness Properties

The specification must guarantee that:

- A valid model of the Peano axioms exists
- The set of natural numbers, the zero element, and the successor function are all well-defined and consistent with each other
- The construction uniquely determines the standard natural number structure (up to isomorphism)

## Goal

The purpose is to have a rigorous, axiomatic foundation for natural numbers that can serve as a basis for reasoning about arithmetic properties in a formal verification context.
