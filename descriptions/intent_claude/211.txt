# Specification Request: Set Cardinality Tracking System

## System Overview

I need a formal specification for a system that incrementally builds up a set of numbers while maintaining an accurate count of how many elements are in the set at any given time.

## System Description

The system manages a collection of numbers drawn from a bounded range (for example, integers from 1 to some maximum value). Starting from an empty collection, the system can add numbers to this collection one at a time. Each time a number is added, the system must compute and store the current size of the collection.

The cardinality (size) computation should be defined recursively: an empty set has size zero, and a non-empty set has size equal to one plus the size of the set with any single element removed.

## Behavioral Requirements

1. **Initial State**: The system starts with an empty collection and a size of zero.

2. **Addition Operation**: At any step, the system may add any number from the allowed range to the collection. When a number is added, the size is recomputed to reflect the new collection's cardinality.

3. **Bounded Domain**: All numbers must come from a finite, predefined range of integers.

## Correctness Property

**Cardinality Invariant**: At all times, the tracked size value must exactly equal the true cardinality of the current set. This property ensures that the recursive cardinality computation always produces the correct result and stays synchronized with the actual set contents throughout all possible executions.

## Purpose

This specification serves to verify that a recursively-defined cardinality function correctly computes set sizes, and that maintaining cardinality incrementally as elements are added preserves correctness. It demonstrates the relationship between a custom recursive definition of counting and the standard mathematical notion of set cardinality.
