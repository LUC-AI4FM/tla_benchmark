# Specification Request: Year 2000 (Y2K) Age Verification System

## System Overview

I need a formal specification for a simple age verification system that determines whether a person is old enough to obtain a license (such as a driver's license). The system operates in a context where years are represented using only two digits (00-99), reflecting the classic Y2K-era date representation limitation.

## Requirements

### Core Functionality

The system should model:
- A person's birth year (represented as a two-digit value)
- A minimum age threshold required to obtain a license
- Logic to determine if a person has reached the required age for licensing

### Constraints

- Birth years should be represented in two-digit format (0-99)
- The minimum licensing age should be a reasonable value (somewhere in the range of 10-99 years)

### Verification Goals

The specification should allow for model checking with configurable parameters, where the birth year and licensing age can be set to various values within their valid ranges to explore the system's behavior under different scenarios.

## Purpose

This specification serves as a teaching example or test case for exploring how date-related calculations can be formally verified, particularly in contexts where legacy two-digit year representations may cause issues. The model should be suitable for automated verification tools to check correctness properties across the valid parameter space.
