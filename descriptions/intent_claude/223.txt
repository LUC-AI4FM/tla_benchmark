Please write a TLA+ specification that demonstrates the use of higher-order functions, specifically the ability to pass anonymous functions (lambdas) as arguments to other operators.

The specification should define a simple operator that accepts a function and an argument, then applies that function to the argument. This is essentially modeling basic function application in a lambda calculus style.

The key correctness property to verify is that when the identity function (a function that returns its input unchanged) is applied to a value, the result equals that same value. This serves as a basic sanity check that higher-order function application works correctly.

The specification can use a minimal state model since the focus is on demonstrating and verifying the functional programming constructs rather than modeling state transitions.
