Bags (also called multisets) are collections where elements can appear multiple times, with each element having an associated count. I need a comprehensive set of operations for manipulating bags that goes beyond basic functionality.

**Required Operations:**

The specification should define and verify operations for:
- Creating bags from various inputs
- Combining bags (union, intersection, difference)
- Querying bag properties (membership, cardinality, element counts)

- Converting between bags and other data structures (sets, sequences)

5. Relationships between operations are consistent (e.g., adding then removing an element returns to original state)
