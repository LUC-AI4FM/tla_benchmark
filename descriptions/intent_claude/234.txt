Write a specification for a simple system that tests function domain preservation through variable aliasing.

**System Description:**
The system should verify a basic property about TLA+ functions: that when a function is assigned to a local variable (creating an alias), the domain of the aliased variable equals the domain of the original function.

**Requirements:**
1. Define an operation that takes any function as input
2. Create a local copy/alias of that function
3. Extract the domain from the aliased copy
4. Compare it against the domain of the original function
5. Return whether these domains are equal

**Behavior:**
- The system initializes by applying this domain-comparison check to a simple test function (a function mapping a single string to an integer)
- After initialization, the system remains static with no state changes

**Correctness Property:**
The key property being validated is that function domain extraction is consistent regardless of whether you access the domain through the original function reference or through an aliased local variable. The domains should always be identical.
