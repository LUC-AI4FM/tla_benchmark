# Specification Request: Factorial Function Evaluation

## System Overview

I need a formal specification that models the step-by-step evaluation of the factorial function over a sequence of natural numbers.

## Desired Behavior

The system should:

1. **Define the factorial function**: Establish a mathematical definition of factorial where factorial(0) = 1, factorial(1) = 1, and for any number k > 1, factorial(k) = k × factorial(k-1).

2. **Iterate through values**: Starting from 0, the system should progress through successive natural numbers, computing and tracking the factorial value at each step.

3. **Track current state**: At any point, the system should maintain both the current number being considered and its corresponding factorial value.

## Key Requirements

- The factorial function should be defined for a bounded domain (e.g., integers 1 through 5) to keep the state space finite and tractable.
- The system should start at zero and increment through natural numbers one at a time.
- Each state transition should correctly associate the new number with its factorial value.

## Correctness Properties

The specification should allow verification that:

- The factorial values computed match the standard mathematical definition of factorial
- The system correctly relates each natural number to its factorial at every step
- The recursive nature of factorial (where each value depends on the previous) is properly captured

## Notes

The factorial function definition should be expressed in a way that doesn't rely on explicit recursive function syntax—instead using a declarative approach that characterizes the function by the properties it must satisfy (base cases and the recursive relationship).
