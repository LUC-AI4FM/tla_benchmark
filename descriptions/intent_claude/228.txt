# Specification Request: State Machine with Constrained Transitions

## System Overview

I need a formal specification for a simple state machine system that manages state transitions along with two numeric counters. The system should model how a process moves between different named states while updating associated numeric values.

## Functional Requirements

### Initial Configuration
The system should start in a designated initial state with the two counters initialized to specific starting values (one at zero, one at a small positive integer).

### State Transitions
The system must support multiple types of transitions:

1. **Direct transition**: A straightforward move to one particular state that updates both counters to new fixed values.

2. **Conditional transition**: A more complex transition that:
   - Involves selecting from a small set of possible choices
   - Includes validation checks on set cardinalities
   - Only proceeds when certain selection criteria are met
   - Updates one counter while preserving the other
   - Changes the state based on certain preconditions being satisfied

### Transition Preconditions
Some transitions should have guards that:
- Verify the current state is not a particular "forbidden" state
- Include trivially true conditions (for testing purposes)

## Correctness Properties

### Safety Property
The primary invariant to verify is that the system should **never reach a specific "bad" state**. This property is expected to be violated by the system's transitions, making it useful for testing model checking and symbolic execution capabilities.

## Purpose

This specification is intended as a **test case for verification tooling**, particularly for testing how tools handle:
- Symbolic transition slicing
- Existential quantification over finite sets
- Nested let-expressions and set comprehensions
- Cardinality constraints
- Combined transition guards with multiple conditions

The specification should be simple enough to analyze but contain enough structural complexity to exercise slicing algorithms in symbolic model checkers.
