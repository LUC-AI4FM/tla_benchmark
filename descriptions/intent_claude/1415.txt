# Specification Request

## System Overview

I need a formal specification for a simple state machine that transitions from an initial empty state to a configuration involving two mapping functions over a fixed set of nodes.

## Requirements

### Setup
- The system operates over a fixed set of two nodes (e.g., "n1" and "n2").
- The system maintains two state variables, both initially empty.

### State Transition
- From the initial state, the system should transition to a state where:
  1. The first variable becomes a mapping that assigns a constant value (like a tag or label "a") to each node in the set.
  2. The second variable becomes a mapping from nodes to nodes.

### Key Constraint
- There is a critical consistency requirement between the two mappings: whenever a node is assigned the special tag/label in the first mapping, the second mapping must map that node to itself (i.e., it must be a fixed point for that node).

### Behavioral Properties
- The specification should allow stuttering (the system may remain in a valid state without changing).
- The constraint between the two mappings must hold in any non-initial state.

## Purpose

This appears to be a test case or minimal example for verifying that a model checker correctly handles:
- Nested predicate definitions (predicates calling other predicates)
- Local variable bindings within predicates
- Constraints involving primed variables (next-state values) passed through multiple layers of abstraction

The specification should demonstrate that the logical constraints propagate correctly through indirect predicate references.
