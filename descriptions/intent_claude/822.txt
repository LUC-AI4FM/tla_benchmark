# Specification Request: Graph Reachability Definition

## System to Model

I need a formal mathematical definition of **reachability in a directed graph**. This is not a dynamic system or algorithm, but rather a foundational specification that precisely defines when nodes in a directed graph can be reached from other nodes by following directed edges.

## Requirements

### Graph Representation
The specification should model a directed graph consisting of:
- A set of nodes
- Directed edges between nodes, where each node has an associated set of successor nodes (the nodes it has edges pointing to)

### Core Definitions Needed

1. **Path Definition**: Formally define what constitutes a valid path in the graph. A path from node *m* to node *n* should be a sequence of nodes where:
   - The sequence is non-empty
   - It starts at *m* and ends at *n*
   - Each consecutive pair of nodes in the sequence respects the edge direction (there is an edge from each node to the next)

2. **Path Existence**: Define a predicate that determines whether a path exists between any two given nodes.

3. **Reachable Set**: Define the set of all nodes reachable from a given set of starting nodes. A node is reachable from a set *S* if there exists a path from some node in *S* to that node.

## Key Properties

The definitions should capture these intuitive properties:
- Every node is reachable from itself (via a trivial single-node path)
- If node *b* is reachable from *a*, and *c* is reachable from *b*, then *c* is reachable from *a* (transitivity)
- Reachability respects edge direction—you can only follow edges in the direction they point

## Purpose

This specification will serve as a foundational mathematical definition that can be used in other specifications involving graph algorithms, network protocols, or any system where reasoning about connectivity and reachability is required.
