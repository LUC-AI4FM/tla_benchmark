# Specification Request: Binary Search with Bounded Integer Arithmetic

## System to Model

I need a formal specification of the classic binary search algorithm operating on a sorted sequence, but with realistic constraints that reflect how the algorithm behaves when implemented with fixed-width signed integers (as in languages like Java or C).

## What the Algorithm Must Do

The algorithm searches for a given key within a sorted sequence of integers. It should:

1. Maintain a search interval that narrows with each iteration by comparing the middle element to the target key
2. Return a non-negative index if the key is found in the sequence
3. Return a negative value if the key is not present (specifically, an encoding that indicates where the key would be inserted)
4. Terminate in logarithmic time relative to the sequence length

## Key Constraints and Challenges

The specification must model **bounded integer arithmetic** with a configurable bit-width. This means:

- Integer addition can overflow or underflow
- The classic midpoint calculation `(low + high) / 2` is dangerous because the sum can overflow
- The specification should use overflow-safe arithmetic (computing the midpoint as `low + (high - low) / 2`)

## Correctness Properties to Verify

1. **Postcondition correctness**: When the algorithm terminates on a sorted input:
   - If the key exists in the sequence, the returned index points to a matching element
   - If the key does not exist, the return value is negative

2. **Termination guarantee**: The algorithm must terminate within a bounded number of steps (specifically, within the bit-width of the integers, reflecting logarithmic complexity)

3. **Progress**: Each iteration must make progress by strictly narrowing the search interval

4. **Array bounds safety**: Every access to the sequence during search must be within valid bounds

5. **Robustness to unsorted input**: The specification should clarify that correctness guarantees only hold when the input sequence is actually sorted

## Purpose

This specification serves as a tutorial example demonstrating how subtle bugs in binary search implementations (particularly integer overflow in midpoint calculation and off-by-one errors in bounds) can be detected through formal methods.
