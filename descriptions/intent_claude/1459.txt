Write a TLA+ specification for a simple counter system that serves as a demonstration of a trace expression specification with no errors. The system models a single integer variable that starts at zero and increments by one on each step until it reaches a fixed upper bound of 3, after which it remains unchanged indefinitely. The specification should define an initial state where the counter is zero, a next-state relation that either increments the counter when it is below the bound or stutters when the bound has been reached, and a temporal formula combining the initial condition with the always-enabled next-state relation under stuttering. The configuration should bind a named constant to the value 3 and point to the overall temporal specification. This module is intended as a test or demonstration artifact to verify that a trace evaluation or model-checking tool runs cleanly and produces no errors on a well-behaved, straightforwardly terminating counter behavior.
