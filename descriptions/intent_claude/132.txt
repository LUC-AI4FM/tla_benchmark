# Specification Request

I need a formal specification for a simple system that tracks relationships between nodes in a small network.

## System Description

The system maintains two separate mappings, where each node in a fixed set of three nodes is associated with a collection of other nodes it knows about or is connected to. Both mappings start empty and evolve identically over time.

## Behavior Requirements

1. **Initial State**: Both mappings should begin with every node having an empty set of associated nodes.

2. **Evolution**: The system should allow a specific node to accumulate connections to other nodes. When this happens, both mappings must be updated in exactly the same way simultaneously—specifically, one designated node should be able to add another designated node to its association set.

## Correctness Properties

The key property to verify is that the two mappings remain consistent with each other for nodes that are not being directly modified. Specifically, nodes that are never targeted by updates should have identical association sets in both mappings throughout all system executions.

## Purpose

This specification appears to be a test case or demonstration of how function updates work when applied uniformly to multiple data structures, verifying that parallel updates preserve equality for unaffected entries.
