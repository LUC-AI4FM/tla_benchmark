# Specification Request: Euclid's GCD Algorithm

## System to Model

I need a formal specification of **Euclid's algorithm for computing the greatest common divisor (GCD)** of two positive integers using the subtraction method.

## Functional Requirements

The algorithm should:

1. **Accept two positive integer inputs**: one fixed value (24) and one that varies across a range (1 to some upper bound N, such as 500) to allow verification across multiple input combinations.

2. **Compute the GCD through repeated subtraction**: The algorithm should iteratively reduce the larger number by subtracting the smaller number from it, continuing until one value reaches zero.

3. **Handle ordering of operands**: When the first operand becomes smaller than the second, the algorithm should swap them to maintain the invariant that subtraction always occurs from the larger value.

4. **Terminate with the GCD**: When the process completes, the non-zero remaining value should be the greatest common divisor of the original inputs.

## Correctness Properties

The specification must verify:

1. **Partial Correctness**: Upon termination, the result equals the mathematical GCD of the two original input values. This should be checked against a mathematical definition of GCD (the largest integer that divides both inputs).

2. **Termination**: The algorithm must always terminate for any valid positive integer inputs within the specified range. The system should eventually reach a completed state.

## Verification Scope

The specification should test the algorithm against a substantial range of second input values (e.g., 1 through 500) while keeping the first input fixed, ensuring the algorithm correctly computes the GCD for all these input combinations.
