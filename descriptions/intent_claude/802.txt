# Specification Request: Zero-Indexed Sequence Library

## Overview

I need a formal specification for a library of operations on **zero-indexed sequences** (arrays). This is needed because the standard sequence type uses one-based indexing, but many algorithms and data structures are more naturally expressed with zero-based indexing where a sequence of length *n* has valid indices 0, 1, 2, ..., n-1.

## Core Requirements

### Data Representation
- Define what constitutes a valid zero-indexed sequence
- A sequence of length *n* should be accessible at indices 0 through n-1
- Support an empty sequence with no valid indices

### Basic Operations
The library must provide:

1. **Index Set**: Given a sequence, return the set of all valid indices for that sequence
2. **Length**: Compute the length of a zero-indexed sequence
3. **Sequence Type**: Define the set of all possible zero-indexed sequences over a given element set

### Conversion Operations
Since standard sequences use one-based indexing, provide bidirectional conversion:
- Convert a standard (one-indexed) sequence to a zero-indexed sequence
- Convert a zero-indexed sequence back to a standard sequence

### Sequence Comparison
- Define **lexicographic ordering** on zero-indexed sequences: one sequence is "less than or equal to" another if it comes first in dictionary order, or is a prefix of the other

### Rotation Operations
- **Single rotation**: Rotate a sequence left by a specified number of positions (elements that "fall off" the left end wrap around to the right)
- **All rotations**: Generate the set of all possible rotations of a sequence, along with the shift amount that produced each rotation

## Correctness Properties

1. Converting a sequence to zero-indexed form and back should yield the original sequence
2. The length operation should return the correct count of elements
3. The index set for a sequence of length *n* should be exactly {0, 1, ..., n-1}
4. Lexicographic comparison should define a total order on sequences
5. Rotating a sequence by its length should yield the original sequence
6. The number of distinct rotations of a non-empty sequence of length *n* should be at most *n*
