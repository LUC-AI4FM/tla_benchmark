Please write a formal specification for a simple two-component state machine system.

**System Description:**
The system consists of two independent state variables. One variable remains constant after initialization, while the other alternates between two values indefinitely.

**Behavior Requirements:**
- Both components start in an initial "off" or "zero" state
- One component never changes from its initial value
- The other component continuously toggles between two states (like a binary flip-flop)

**Verification Goal:**
The specification should be structured to test a model checker's ability to detect violations of temporal properties after the complete state space has been explored. Specifically, it should serve as a test case where a temporal property is expected to fail, demonstrating the model checker's error reporting for liveness or temporal logic violations.

**Key Properties to Examine:**
- The system should be used to verify that the model checker correctly identifies when a specified temporal property does not hold
- The specification should generate a counterexample or error during temporal property checking
