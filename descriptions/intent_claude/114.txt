# Specification Request

I need a formal specification for a simple static mapping system.

## System Description

The system should model a fixed lookup table that maps pairs of integers to their computed values. Specifically, I need to define a function that takes two-element tuples of integers as keys and returns an integer result.

## Requirements

1. **Initial State**: The system should initialize with a predefined set of key-value pairs, where each key is a pair of integers and the corresponding value is derived from those integers (specifically, their sum).

2. **Static Behavior**: Once initialized, the mapping should remain unchanged throughout the system's execution. This is essentially a constant lookup table with no dynamic updates.

3. **Domain**: The function should be defined only over a specific, finite set of integer pairs—not all possible pairs.

## Correctness Properties

- The mapping must be well-defined: every pair in the specified domain must have exactly one associated value.
- The system should be stable: the mapping never changes after initialization.

## Purpose

This specification serves as a basic test case for verifying that a model checker or type system correctly handles functions with tuple domains (multi-argument functions represented as functions over Cartesian products).
