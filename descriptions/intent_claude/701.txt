# Specification Request: Extended Sequence Operations Library

## System Overview

I need a formal specification of a comprehensive library of utility operations for working with sequences (ordered lists/arrays). This library should extend basic sequence functionality with rich operations for conversion, manipulation, searching, structural analysis, and folding.

## Core Requirements

### Conversion Operations

The library must support bidirectional conversion between sequences and other data structures:

- Convert a sequence to the set of its elements (removing duplicates and order)
- Convert a sequence to a multiset/bag (preserving element counts)
- Convert a set to a sequence containing all elements exactly once
- Generate all possible orderings (permutations) of a set's elements
- Convert a set to a sorted sequence given a comparison relation
- Generate all k-permutations of a set for all valid k values

### Sequence Construction

Provide ways to define bounded collections of sequences:

- All tuples of exactly length n over a given element set
- All sequences up to length n over a given element set

### Element Operations

Support common element-level manipulations:

- Test whether a sequence contains a specific element
- Reverse a sequence
- Remove all occurrences of an element
- Remove only the first occurrence of an element
- Replace all occurrences of one element with another
- Find the index of the first/last element satisfying a predicate
- Search within a subsequence range

### Structural Manipulation

Enable position-based modifications:

- Insert an element at a specific position
- Replace the element at a specific position
- Remove the element at a specific position
- Prepend an element to the beginning
- Append an element to the end
- Extract all but the last element
- Extract the last element

### Prefix and Suffix Analysis

Support comprehensive prefix/suffix reasoning:

- Test if one sequence is a prefix/suffix of another
- Test for strict (proper) prefix/suffix relationships
- Enumerate all prefixes/suffixes of a sequence
- Find common prefixes across a set of sequences
- Compute the longest common prefix of multiple sequences

### Higher-Order Folding Operations

Provide flexible aggregation mechanisms:

- Fold over sequence elements in unspecified order (for associative/commutative operations)
- Left-to-right fold with explicit ordering guarantees
- Right-to-left fold with explicit ordering guarantees
- Fold over the domain (indices) rather than elements

### Sequence Combination and Decomposition

Support operations on sequences of sequences:

- Flatten a sequence of sequences into a single sequence
- Zip two sequences into a sequence of pairs
- Interleave two equal-length sequences element by element
- Generate all contiguous subsequences
- Generate all (not necessarily contiguous) subsequences

### Subsequence Search and Replace

Enable pattern-based transformations:

- Find the index of the first occurrence of a subsequence
- Replace a subsequence at a specific position
- Replace the first occurrence of a subsequence pattern
- Replace all occurrences of a subsequence pattern (handling overlaps by preferring leftmost matches)

## Key Correctness Properties

1. **Conversion roundtrip**: Converting a set to a sequence and back to a set must yield the original set
2. **Length preservation**: Operations should maintain appropriate length invariants (e.g., insertion increases length by one)
3. **Content preservation**: Non-destructive operations must preserve sequence contents
4. **Prefix/suffix transitivity**: Prefix and suffix relations must be transitive
5. **Fold ordering**: Left and right folds must process elements in their specified directions
