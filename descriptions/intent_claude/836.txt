# Specification Request: N-Queens Solver

## System Overview

I need a formal specification for an iterative algorithm that solves the N-Queens puzzle. The N-Queens problem asks: given an N×N chessboard, find all possible ways to place N queens such that no two queens threaten each other.

## Problem Description

Queens in chess can attack along rows, columns, and diagonals. A valid solution places exactly one queen in each row and each column, with no two queens sharing a diagonal. Since every solution must have exactly one queen per row, a placement can be represented as a mapping from row numbers to column numbers.

## Algorithm Requirements

The algorithm should work iteratively by:
1. Starting with an empty board (no queens placed)
2. Maintaining a collection of partial placements still being explored
3. Maintaining a collection of complete solutions found so far
4. Repeatedly selecting a partial placement and attempting to extend it by adding a queen in the next row
5. Only extending with column positions that don't create an attack with any already-placed queen
6. When a placement reaches N queens, recording it as a complete solution
7. Continuing until no partial placements remain to explore

The algorithm should use a backtracking-style search, exploring all valid extensions of partial solutions.

## Correctness Properties

The specification must guarantee:

1. **Partial Correctness**: Every placement recorded as a solution is actually valid—no two queens in that placement attack each other.

2. **Completeness**: When the algorithm terminates (no more partial placements to explore), the set of found solutions contains every possible valid N-queens solution.

3. **Termination**: Under appropriate fairness assumptions (the algorithm keeps making progress), it eventually finishes exploring all possibilities.

4. **Type Safety**: Partial placements are always sequences shorter than N, and complete solutions are always sequences of exactly length N, with all column values in the valid range 1 to N.

## Parameters

The specification should be parameterized by N, the board size, which must be a positive natural number.
