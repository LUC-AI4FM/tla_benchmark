Write a TLA+ specification for a simple counter that starts at zero and increments by one on each step, bounded by a configurable upper bound. The counter should have a single natural-number variable initialized to zero, with a next-state relation that strictly increments it. The specification should include a state constraint that limits exploration to states where the counter is strictly less than the upper bound, and a safety invariant asserting the same bound holds throughout execution. The upper bound should be a constant parameter, set to 10 for model checking purposes. The module should print a diagnostic label on startup using TLC. This is primarily a small demonstration or test module intended to verify that a bounded counter behaves correctly under TLC model checking, confirming that the invariant holds within the explored state space.
