# Specification Request

## System to Model

A simple concurrent system with multiple processes that share access to a global counter and use derived (computed) values based on that counter.

## Description

Model a system with three concurrent processes that each perform a single operation: reading a computed value derived from a shared global counter. The global counter starts at zero, and the system should provide named expressions that compute values based on this counter—specifically, the counter plus one, and the counter plus two (building on the first derived value).

## Required Behavior

1. Initialize a shared global counter to zero
2. Define computed expressions that derive values from the counter:
   - One expression computes the counter's value incremented by one
   - Another expression computes that result incremented by one more (i.e., counter plus two)
3. Each of the three processes should read the doubly-incremented derived value into its own local variable
4. All processes should eventually complete their operation

## Key Correctness Properties

1. **Computation Correctness**: When any process reads the derived value (counter plus two), it must equal 2, given that the counter remains at its initial value of zero
2. **Termination**: All three processes must eventually complete their execution

## Purpose

This specification serves to verify that:
- Derived definitions in a concurrent setting correctly reflect the current state of shared variables
- Multiple processes can independently and correctly access shared computed values
- The evaluation of chained definitions (where one definition references another) produces the expected results
