# Specification Request: Parameterized Pair Relation Checker

## System Overview

I need a formal specification that verifies the existence of "good" pairs between two sets, where the definition of what makes a pair "good" is configurable through a user-supplied binary relation.

## Core Functionality

The system should:

1. Accept two sets of integers as input
2. Accept a binary predicate that determines whether a pair of elements (one from each set) satisfies a desired relationship
3. Determine whether there exists at least one pair of elements—one drawn from each set—that satisfies the given predicate

## Key Requirements

The specification must be parameterized so that:
- The two input sets can be instantiated with different concrete values
- The "goodness" predicate can be swapped out for different relationships (e.g., equality, inequality, or any other binary relation on integers)

## Correctness Properties

The specification should correctly identify:
- When overlapping sets contain at least one matching pair under an equality relation
- When disjoint sets contain no matching pairs under an equality relation
- When disjoint sets contain matching pairs under an inequality relation
- When identical singleton sets contain no matching pairs under an inequality relation

## Purpose

This specification serves as a test harness or demonstration of TLA+'s module instantiation feature with higher-order parameterization—specifically, passing operator definitions (not just values) as module parameters. The goal is to verify that a generic "pair existence" checker works correctly across multiple instantiations with different sets and different predicates.
