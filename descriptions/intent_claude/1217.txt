# Specification Request: Bag (Multiset) Data Structure Library

## System Overview

I need a formal specification for a **bag (multiset) data structure library** — a collection type that, unlike ordinary sets, can contain multiple copies of the same element. The specification should define the fundamental operations on bags and establish their mathematical properties.

## Core Functionality Required

The library must support the following operations:

1. **Basic bag construction and inspection:**
   - Determine whether a given structure is a valid bag
   - Convert between sets and bags (a set becomes a bag with one copy of each element)
   - Extract the underlying set of distinct elements from a bag
   - Test membership of an element in a bag
   - Create an empty bag

2. **Bag arithmetic:**
   - **Union of two bags:** combining bags so that element counts are summed
   - **Difference of two bags:** removing copies of elements, where each copy in the second bag removes one copy from the first
   - **Union of a set of bags:** generalizing union to an arbitrary collection of bags

3. **Bag comparison:**
   - **Subbag relation:** one bag is a subbag of another if it has at most as many copies of every element
   - **Enumerate all subbags:** generate the set of all bags that are subbags of a given bag

4. **Counting and transformation:**
   - Count the number of copies of a specific element in a bag
   - Compute the total cardinality (sum of all copy counts)
   - Apply a function to each element of a bag, producing a new bag where multiplicities are preserved and combined appropriately

## Key Correctness Properties

The specification should ensure:

- A bag maps each element in its domain to a strictly positive natural number (the copy count)
- Bag union is commutative and associative
- The empty bag is an identity element for union
- Subtracting a bag from itself yields the empty bag
- The subbag relation correctly reflects element-wise count comparisons
- The number of subbags of a bag where each element has one copy equals the number of subsets of the underlying set
- Cardinality correctly sums all element multiplicities
- Transforming a bag by a function properly aggregates multiplicities when multiple elements map to the same value

## Validation Requirements

The specification should be testable with concrete examples to verify that all operations behave correctly on sample bags with known expected results.
