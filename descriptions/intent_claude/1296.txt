**Specification Request: Distributed Termination Detection Algorithm**

I need a formal specification of Dijkstra's ring-based termination detection algorithm (EWD840).

**System Description:**

Model a distributed system consisting of N processes arranged in a logical ring topology. Each process can be either active (performing computation) or passive (idle). Active processes may send messages to other processes, which can cause passive processes to become active again. The goal is to detect when the entire distributed computation has terminated—meaning all processes are passive and no messages are in transit.

**Algorithm Requirements:**

- A special token circulates around the ring from process to process
- The token can only be passed by a passive process to its predecessor in the ring
- The token and processes carry color information (black/white) to track whether "interference" has occurred (e.g., a message was sent backward in the ring)
- When the token completes a full circulation under the right conditions, global termination can be declared

**Key Correctness Properties:**

1. **Safety**: The algorithm must never incorrectly announce termination while any process is still active or while messages are still in transit. If termination is detected, the system must truly be in a terminated state.

2. **Liveness**: If all processes eventually become permanently passive and all messages are eventually delivered, the algorithm must eventually detect termination.

**Environment Assumptions:**

- Processes may spontaneously become passive
- Active processes may send messages to any other process
- Message delivery is reliable but may be delayed
- Only one token exists in the system
