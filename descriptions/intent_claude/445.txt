# Specification Request: Enabled Action Semantics with Parameterized Operators

## System Overview

I need a formal specification that explores the semantics of action enablement in a temporal logic setting, specifically examining how the "enabled" predicate behaves when applied through different mechanisms.

## Requirements

The system should model a simple state space with two integer components:
- One component that remains unchanged during transitions
- One component that increments by one during transitions

## Key Behaviors to Model

1. Define a basic transition that keeps one state component fixed while incrementing another
2. Examine the enablement of this transition in two different ways:
   - Through a parameterized operator that takes an action as an argument and checks if it is enabled
   - Through direct application of the enablement check to the action

## Correctness Properties to Investigate

The specification should help verify whether these two approaches to checking action enablement are semantically equivalent:
- Does wrapping the ENABLED predicate in a parameterized operator produce the same result as applying ENABLED directly?
- Are there subtle differences in how variable substitution or scoping works between these two formulations?

## Purpose

This specification is intended as a test case for understanding the precise semantics of how action parameters interact with the ENABLED operator, particularly in contexts where module instantiation with variable substitution might be involved. The goal is to ensure that formal reasoning tools handle these constructs correctly and consistently.
