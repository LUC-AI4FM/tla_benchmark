# Specification Request: Finding the Maximum Element in a Sequence

## System Overview

I need a formal specification for an algorithm that finds the highest (maximum) value in a sequence of natural numbers.

## Functional Requirements

The system should:

1. Take a sequence of natural numbers as input
2. Traverse through the sequence examining each element
3. Track the largest value seen so far during the traversal
4. Upon completion, correctly identify the maximum value in the entire sequence

## Correctness Properties

The specification must guarantee:

1. **Partial Correctness**: When the algorithm terminates, the result equals the maximum value present in the input sequence
2. **Termination**: The algorithm must eventually complete for any finite input sequence
3. **Progress**: The algorithm makes progress through the sequence on each step

## Model Checking Requirements

For verification purposes, the specification should support bounded model checking with:

- A configurable maximum sequence length to keep the state space finite
- A configurable maximum natural number value to bound the domain of sequence elements

This allows exhaustive verification of the algorithm's correctness across all possible input sequences within the specified bounds.
