# Specification Request: Tendermint Consensus with Byzantine Faults and Amnesia

## System to be Modeled

I need a formal specification of the Tendermint Byzantine fault-tolerant consensus protocol, specifically focusing on scenarios where some validators may exhibit "amnesia" behavior (a type of Byzantine fault where processes forget their previous commitments).

## System Description

The system consists of a fixed set of validator processes that must agree on a value through multiple rounds of voting. The protocol follows a propose-prevote-precommit structure typical of Tendermint-style consensus:

- In each round, a designated proposer suggests a value
- Validators vote in two phases: first a prevote, then a precommit
- Validators track locked values and valid values across rounds to ensure safety
- The protocol may progress through multiple rounds if consensus is not reached

## Configuration Requirements

The specification should model:
- A network of 4 validators total
- 2 correct (honest) validators and 2 faulty (Byzantine) validators
- A maximum fault tolerance threshold that allows the system to function despite Byzantine behavior
- A bounded number of rounds (at least 2)
- A set of valid values that can be proposed, plus invalid values that faulty processes might inject

## Behavioral Requirements

The model should capture:
- The ability for faulty validators to deviate from the protocol (including amnesia attacks)
- Message passing for proposals, prevotes, and precommits organized by round
- Round synchronization and the ability to catch up to higher rounds
- Evidence collection for detecting Byzantine behavior

## Correctness Properties

The specification must verify:
1. **Agreement (Safety)**: No two correct validators decide on different values
2. **Validity**: If a value is decided, it must be a valid value (not an invalid/Byzantine-injected value)
3. **Evidence soundness**: The system correctly identifies protocol violations

## Analysis Goals

The specification should support trace-based exploration, allowing verification of specific execution sequences through the protocol phases to ensure safety holds even under Byzantine amnesia attacks in a 4-validator network with 2 faults.
