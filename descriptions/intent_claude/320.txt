# Specification Request: Polymorphic Function Extension System

## System Overview

I need a formal specification for a simple system that demonstrates the use of a generic (polymorphic) helper operation for extending partial functions with new key-value mappings. The system should work uniformly across different types of mappings.

## What the System Should Model

The system maintains two distinct lookup tables (partial functions):
1. A mapping from strings to integers
2. A mapping from integers to strings

Both mappings start empty and can be extended by adding new entries.

## Core Requirements

### Generic Extension Operation
The system must include a single, reusable operation that can extend *any* partial function with a new key-value pair. This operation should:
- Accept a function of any type (from some key type to some value type)
- Accept a new key (of the appropriate key type) and a new value (of the appropriate value type)
- Return an extended function that includes the new mapping while preserving all existing mappings

The critical requirement is that this same operation must work for functions with different type signatures without needing separate implementations for each type combination.

### Behavior
- The system initializes both mappings as empty
- In a single step, the system extends both mappings: adding a string-to-integer entry to one, and an integer-to-string entry to the other
- Both extensions use the same generic operation

## Key Correctness Property

The specification must be **type-correct under let-polymorphism** (also known as parametric polymorphism). Specifically:
- The generic extension operation must be definable with a polymorphic type signature
- The type checker must successfully instantiate this polymorphic operation at two different concrete types within the same transition
- This demonstrates that the type system supports proper polymorphic type inference, not just simple monomorphic typing

## Purpose

This specification serves as a test case for TLA+ type checking tools, verifying that they correctly support let-polymorphism—the ability to define a generic operation once and use it at multiple different type instantiations.
