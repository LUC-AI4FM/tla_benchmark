# Specification Request: Binary Search with Bounded Integer Arithmetic

## System to Model

A binary search algorithm that finds a key in a sorted sequence, implemented using fixed-width signed integer arithmetic (as would be found in real programming languages like Java).

## Functional Requirements

The algorithm should:

1. Search for a given key within a sorted input sequence
2. Return a non-negative index if the key is found (indicating the position where the key exists)
3. Return a negative value if the key is not found (following the convention used in standard library implementations like Java's `Arrays.binarySearch`)
4. Operate correctly under bounded integer arithmetic, avoiding overflow bugs when computing the midpoint of the search interval

## Key Constraints

- The implementation must use fixed-width signed integers with a configurable bit width
- Integer operations (especially addition) must correctly handle overflow by wrapping according to two's complement semantics
- The midpoint calculation must avoid the classic overflow bug that occurs with naive `(low + high) / 2` computation

## Correctness Properties to Verify

1. **Postcondition correctness**: When the algorithm terminates on a sorted input:
   - If the key exists in the sequence, the returned index points to a matching element
   - If the key does not exist, the return value is negative

2. **Termination**: The algorithm must terminate within a bounded number of steps (specifically, logarithmic in the sequence length, bounded by the integer bit width)

3. **Progress**: Each iteration must make progress by strictly shrinking the search interval (either the lower bound increases or the upper bound decreases)

4. **Memory safety**: All sequence accesses must be within bounds—the computed midpoint must always be a valid index into the input sequence

## Input Assumptions

- The input sequence may or may not be sorted
- The correctness guarantees about the return value only apply when the input is sorted
- The key and all sequence elements are integers within the representable range
