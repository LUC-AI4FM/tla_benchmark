# Specification Request: Annotated Integer Operations Library

## System Overview

I need a formal specification for a simple mathematical library that provides basic integer operations, with a focus on demonstrating how type annotations and purity markers can be applied to different kinds of operator definitions in a specification language.

## Core Requirements

### Functional Components

The system should define:

1. **A parameterized set structure** - The specification should support a configurable integer constant and maintain a set of integers as state.

2. **Basic arithmetic operations** - Include simple increment and decrement operations on integers.

3. **Factorial computation** - Provide a recursive factorial function that computes n! for non-negative integers, returning 1 for values less than or equal to 1.

### Definition Styles to Support

The specification should demonstrate multiple ways of defining operations:
- Standard named operators
- Local (module-private) operators
- Operators defined within LET expressions
- Recursive operator definitions
- Recursive function definitions using function syntax

## Key Properties and Annotations

### Type Safety
All operators should have clear type signatures indicating:
- Input parameter types (integers)
- Return types (integers)
- For the set variable, the type should indicate it holds a set of integers

### Purity
Certain operations should be marked as pure (side-effect free), indicating they are mathematical functions that always return the same output for the same input.

### Recursion Optimization
Recursive definitions (both operator-style and function-style factorial) should be annotated to indicate they are candidates for tail-recursion optimization, even if the implementation isn't strictly tail-recursive.

## Goals

The primary goal is to create a specification that serves as a reference for how different styles of operator definitions can be annotated with metadata about types, purity, and optimization hints. This supports tooling that performs type checking, verification, or code generation from formal specifications.
