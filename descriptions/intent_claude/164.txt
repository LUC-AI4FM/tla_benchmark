# Specification Request

## System Description

I need a formal specification for a simple two-variable coordination system where two integer counters influence each other's progression. The system should model a feedback loop where each variable's next value depends on whether the other variable has crossed a threshold.

## Behavior Requirements

The system consists of two integer variables that start at different initial values (one at zero, one at one). On each step, both variables update simultaneously based on the other's current value:

- If one variable exceeds a threshold value of 5, the other variable jumps to a terminal value of 10
- Otherwise, the variable takes on a value derived from the other variable plus an increment

This creates an interdependent progression where the two values chase each other until one crosses the threshold, triggering both to eventually reach a stable high value.

## Purpose

This specification is intended as a **test case for temporal logic model checking**, specifically to verify that a model checker correctly handles redundant (superfluous) temporal operators in liveness formulas. The focus is on ensuring that nested eventually operators are processed correctly—multiple consecutive "eventually" operators should behave equivalently to a single one.

## Correctness Properties

1. **Achievable Liveness**: The system should eventually reach a state where the first variable exceeds 2. This property should hold and demonstrates that the system makes progress.

2. **Unachievable Liveness**: The system should NOT be able to reach a state where the first variable equals 11. This property should fail to hold (be false), confirming that certain states are unreachable.

Both properties should be expressed with multiple nested eventually operators to test that the model checker handles such redundancy correctly without changing the semantic meaning of the properties.
