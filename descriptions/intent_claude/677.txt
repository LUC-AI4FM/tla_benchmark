# Specification Request: Extended Multiset (Bag) Operations Library

## Overview

I need a formal specification for an extended library of operations on **multisets** (also called bags), which are collections that allow elements to appear multiple times. This library should supplement basic multiset functionality with additional manipulation and aggregation capabilities.

## System Description

A multiset differs from a regular set in that it tracks how many times each element appears (its "multiplicity" or "count"). For example, a multiset containing two 1s, one 2, and three 3s is distinct from one containing just one of each.

## Required Operations

### Element Manipulation

1. **Add Single Occurrence**: Add one copy of an element to a multiset. If the element already exists, its count increases by one. If it's new, it appears with count one.

2. **Remove Single Occurrence**: Remove one copy of an element from a multiset. If the element's count is greater than one, decrement it. If the count is exactly one, remove the element entirely. If the element isn't present, leave the multiset unchanged.

3. **Remove All Occurrences**: Completely remove an element from a multiset regardless of how many copies exist. If the element isn't present, leave the multiset unchanged.

### Aggregation Operations

4. **Generalized Fold with Transformation**: Apply a transformation function to each element, then combine all results using a binary operation and starting value. Each element should be processed according to its multiplicity (if an element appears three times, it contributes three times to the fold). Support specifying the order in which distinct elements are processed.

5. **Simple Fold**: Combine all elements of a multiset using a binary operation and starting value, respecting multiplicities.

6. **Sum**: Compute the sum of all elements in a multiset of numbers, counting each element according to its multiplicity.

7. **Product**: Compute the product of all elements in a multiset of numbers, counting each element according to its multiplicity.

## Correctness Properties

- Adding then removing the same element should return the original multiset
- Removing an element not in the multiset should leave it unchanged
- The sum of a multiset should equal the sum where each distinct element is multiplied by its count
- The fold operations must process each element exactly as many times as its multiplicity indicates
- Operations should preserve the multiset invariant (all counts remain positive integers)

## Use Cases

This library supports modeling systems that need to track resource counts, message queues with duplicates, inventory systems, or any scenario where the number of occurrences matters rather than just presence or absence.
