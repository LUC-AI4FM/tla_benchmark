# Specification Request: Binary Search Algorithm Verification

## System to Model

I need a formal specification of the **binary search algorithm** operating on a sorted sequence of integers. The specification should model the classic iterative binary search that finds whether a given key exists in a sorted input sequence.

## Functional Requirements

The algorithm should:

1. Accept a sorted sequence of integers and a target key to search for
2. Maintain a search range that narrows with each iteration by comparing the middle element to the target key
3. Terminate when either the key is found or the search range becomes empty
4. Return an appropriate result indicating whether the key was found (and potentially its location)

## Key Constraints

- The implementation must work within **bounded integer arithmetic** (specifically 8-bit integers), meaning all intermediate calculations must avoid integer overflow
- The algorithm must handle arbitrary sorted sequences up to the maximum representable length
- The specification should support verification across all possible valid inputs, not just specific test cases

## Correctness Properties to Verify

The specification must guarantee:

1. **Termination**: The algorithm always terminates for any valid input
2. **Soundness**: If the algorithm reports finding the key, the key actually exists in the sequence at that position
3. **Completeness**: If the key exists in the sorted sequence, the algorithm will find it
4. **Safety**: All arithmetic operations stay within the bounds of the integer representation (no overflow in computing the midpoint)

## Verification Approach

The specification should be structured to allow model checking with symbolic/arbitrary inputs rather than just concrete test values, enabling verification that the algorithm works correctly for all possible sorted sequences and search keys within the integer bounds.
