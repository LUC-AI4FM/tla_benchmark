# Specification Request: Set Selection with Decreasing Sum

## System Overview

I need a formal specification for a simple state machine that manages a set of integers, where the system selects and transitions between sets based on their sum values.

## System Description

The system maintains a collection of distinct integers drawn from a fixed range (1 through some upper bound N). The system should:

1. **Initialize** by selecting any subset of integers from the range whose elements sum to exactly N.

2. **Transition** by replacing the current set with a different subset from the same range, but only if the new subset has a strictly smaller sum than the current one.

## Key Requirements

- The integers in the set must always be drawn from the range 1 to N (inclusive)
- The initial set must have a sum equal to exactly N
- Each transition must strictly decrease the total sum of the selected integers
- The system should allow nondeterministic choice among all valid subsets at each step

## Correctness Property

The specification must guarantee that the sum of the current set never exceeds the maximum possible sum of all integers in the range. Specifically, if the range is 1 to N, the sum should never be greater than half of N×(N+1), which is the sum of the entire range divided by 2.

## Purpose

This specification is intended to verify that fold/reduce operations over sets work correctly in different contexts within the model—during initialization, state transitions, and invariant checking. The model should be suitable for verification with a model checker that supports set comprehension and aggregate operations.
