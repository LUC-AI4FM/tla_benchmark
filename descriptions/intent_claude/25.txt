# Specification Request

I need a formal specification for a trivially simple static system that demonstrates a basic invariant violation.

## System Description

The system should model a state that is initialized once and never changes. Specifically, the initial state should be set to contain a single element (the number 2, selected from a small set of numbers by filtering for elements equal to 2).

## Behavior

After initialization, the system should remain completely static with no state changes occurring.

## Correctness Property

The specification should include an invariant asserting that the state is empty. This invariant is intentionally designed to be violated immediately upon initialization, since the state will actually contain one element.

## Purpose

This appears to be a test case or teaching example for a model checker, demonstrating how an invariant violation is detected when the initial state itself violates the specified property. The specification should make it easy to verify that the model checker correctly identifies this contradiction between the initial condition and the invariant.
