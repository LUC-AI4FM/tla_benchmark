# Specification Request

## System to Model

A simple sequential decision process that demonstrates nondeterministic branching with multiple exclusive paths, followed by a conditional action based on the path taken.

## Description

The system should model a process that:

1. **Initial phase**: Makes a nondeterministic choice among three mutually exclusive paths:
   - Path A: Performs a two-step increment sequence on one counter (incrementing it twice, resulting in value 2)
   - Path B: Performs a two-step increment sequence on a second counter (incrementing it twice, resulting in value 2)
   - Path C: Sets a third counter directly to a large value (100)

2. **Conditional phase**: After the initial choice completes, performs a guarded action where:
   - If the first counter was never modified (stayed at 0), increment the third counter by 1
   - If the first counter reached its maximum value (2), increment the third counter by 3

## Key Correctness Properties

The specification must guarantee that upon termination:

1. **Path consistency**: Either one of the two-step paths completed (leaving the sum of the first two counters equal to 2), OR the direct assignment path was taken (leaving the third counter at 101 with both other counters unchanged at 0)

2. **Value relationship**: Whenever the third counter remains below 100, its value must equal the first counter's value plus one

The system must always terminate and must never deadlock during execution.
