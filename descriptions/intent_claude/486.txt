Please write a formal specification for a simple two-variable state machine with the following characteristics:

**System Description:**
The system maintains two integer variables that start at zero. The system should model transitions where the first variable always becomes 1, while the second variable is constrained by one of two conditions.

**Behavior Requirements:**
- Both variables begin initialized to zero
- On any transition, the first variable must be set to 1
- Additionally, one of the following must hold for the transition:
  - The two variables swap their new values (they equal each other after the transition), OR
  - The second variable becomes 2

**Specification Style:**
- The specification should allow stuttering (the system may remain in its current state)
- Model this as a simple state machine with an initial condition and a next-state relation

**Key Properties to Consider:**
The specification should capture the logical constraints on how the two variables can change together, particularly the interplay between the requirement that the first variable becomes 1 and the disjunctive constraint on the second variable's value.
