# Specification Request: Axiomatic Definition of Real Numbers

## System to Model

I need a formal specification that defines what it means for a mathematical structure to be a valid model of the real numbers. This should be an axiomatic characterization that captures all the essential properties of the reals, built on top of a foundation that already defines natural numbers (Peano arithmetic).

## Requirements

### Core Algebraic Structure

The specification must define when a set with two binary operations (addition and multiplication) and an ordering relation constitutes the real numbers. Specifically:

1. **Embedding of naturals**: The natural numbers must be contained within the reals, and the successor operation must correspond to adding one.

2. **Additive structure**: The reals under addition must form an abelian group with zero as the identity element.

3. **Multiplicative structure**: The non-zero reals under multiplication must form an abelian group with one as the identity element.

4. **Distributivity**: Multiplication must distribute over addition.

### Ordering Properties

The ordering relation must satisfy:
- **Totality**: Any two elements are comparable
- **Antisymmetry**: Two elements are equal if and only if each is less than or equal to the other
- **Transitivity**: The usual transitive property
- **Compatibility with operations**: Addition and multiplication by non-negative elements must preserve the ordering

### Completeness

The specification must include the **least upper bound property**: every non-empty set that has an upper bound must have a least upper bound (supremum).

## Derived Concepts

Once a model of the reals is established, the specification should define:
- Extended reals with positive and negative infinity, including how the ordering extends to these values
- Subtraction and division as derived operations
- The integers as a subset of the reals
- Exponentiation with appropriate domain restrictions and laws (including power rules and monotonicity for positive bases)

## Correctness Property

The key theorem to establish is that such a model exists—that there is indeed a structure satisfying all these axioms.
