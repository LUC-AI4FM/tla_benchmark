# Specification Request: Predicate Logic and CHOOSE Operator Test Suite

## Goal

Create a test specification that validates the correct behavior of first-order predicate logic operators and the CHOOSE operator in TLA+. This is essentially a conformance test suite to ensure these fundamental logical constructs work as expected.

## System Description

This is not a dynamic system but rather a static test harness that verifies the semantics of logical operators. The specification should execute a series of logical assertions that must all evaluate correctly for the test suite to pass.

## Requirements

### Existential Quantification Tests
- Verify that existential quantification correctly identifies when at least one element in a set satisfies a predicate
- Confirm that existential quantification over an empty set always returns false
- Test both syntactic forms of existential quantification (symbol and keyword variants)
- Validate existential quantification with multiple bound variables, including tuple patterns and Cartesian products

### Universal Quantification Tests
- Verify that universal quantification correctly determines when all elements in a set satisfy a predicate
- Confirm that universal quantification over an empty set always returns true (vacuous truth)
- Test both syntactic forms of universal quantification (symbol and keyword variants)
- Validate universal quantification with multiple bound variables, including tuple patterns and Cartesian products

### CHOOSE Operator Tests
- Verify that CHOOSE returns an element satisfying the given predicate when exactly one such element exists
- Verify that CHOOSE returns some valid element when multiple elements satisfy the predicate
- Test CHOOSE with tuple patterns and compound conditions
- Test CHOOSE with nested set expressions, including sets containing infinite sets like natural numbers and integers

### Complex Expression Tests
- Validate correct evaluation of quantifiers over Cartesian products
- Test arithmetic expressions within predicates involving multiple bound variables
- Verify correct handling of tuple destructuring in quantifier bindings

## Correctness Properties

1. All logical expressions must evaluate to their mathematically expected truth values
2. The test suite must pass completely—any single test failure should be clearly reported and halt verification
3. Duplicate elements in set literals should not affect quantifier semantics (sets have no duplicates)
