Please write a TLA+ specification for a simple two-variable state machine with the following characteristics:

**System Description:**
A system with two state variables that can hold numeric values. The system should start with one variable initialized to zero, while the other variable's initial value is unconstrained.

**Transition Behavior:**
The system should allow transitions where both variables are updated simultaneously. The key constraint is that after any transition, both variables must equal 2. Additionally, the specification should explicitly rule out any transition that would result in the first variable being 1 while the second is 2.

**Specification Style:**
The specification should use a stuttering-allowance formulation, but only with respect to the first variable (not both). This means the system can remain idle as long as the first variable doesn't change, regardless of what happens to the second variable.

**Properties to Verify:**
The main interest is in understanding the reachable states given these constraints and whether the logical combination of requirements produces a consistent or contradictory specification.
