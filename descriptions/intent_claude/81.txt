Write a specification for a simple system that tests the correctness of existential quantification under negation, particularly when nested inside local definitions.

**System Description:**
The system maintains a fixed set of integers and a boolean flag. On each step, the flag is updated based on whether there exists an element in the set satisfying a certain property.

**Behavior Requirements:**
1. The system starts with a set containing at least two distinct integers (specifically 1 and another value) and the boolean flag set to true.
2. On each transition, the flag is set to the result of checking whether there exists some element in the set that is not equal to 1. The set itself remains unchanged.

**Key Correctness Property:**
The boolean flag must always remain true. Since the set permanently contains an element different from 1, the existential check "does there exist an element not equal to 1?" must always evaluate to true, and therefore the flag should never become false.

**Purpose:**
This specification serves as a test case to verify that logical reasoning about existential quantifiers remains sound when the quantified expression appears within a local definition (LET-IN construct) and may be subject to logical transformations like Skolemization. The invariant should hold because the existential statement is genuinely true given the contents of the set, regardless of how the model checker internally handles the formula.
