Write a formal specification for testing parameterized module instantiation in a specification language that supports modular composition.

**System Overview:**
The goal is to verify that a specification language correctly handles different syntactic forms of parameterized module instantiation, where an external module's behavior is imported and bound to local state variables.

**Requirements:**

1. **Parameterized Instantiation:** The system should support instantiating an external module that operates on some state variable, where the external module's parameter is bound to a local variable in the importing module.

2. **Multiple Instantiation Syntaxes:** The specification should test at least two different syntactic approaches for achieving the same parameterized instantiation:
   - A functional/operator-style instantiation where the parameter is passed as an argument
   - An explicit substitution-style instantiation where the parameter mapping is declared inline

3. **Behavioral Equivalence:** Both instantiation methods should produce equivalent specifications that govern the same local state variable.

4. **State Constraints:** The local state variable should be constrained to a small finite domain (specifically, non-negative integers up to some bound like 0 through 4).

**Correctness Properties:**

- **Bounded State Invariant:** The state variable must always remain within the specified finite range, ensuring the external module's behavior respects the expected bounds.

**Purpose:**
This specification serves as a test case for verifying that a formal methods tool correctly processes different forms of parameterized module instantiation and that both syntactic variants are handled equivalently by the tooling.
