# Specification Request: Binary Search Algorithm

## System to Model

A binary search algorithm that searches for a key in a sorted sequence of integers, modeled at a level that accounts for machine integer representation and bounds.

## Functional Requirements

The algorithm should:

1. Accept a sequence of integers and a target key to search for
2. Maintain a search interval that progressively narrows to locate the key
3. Terminate with a result value indicating either:
   - The position where the key was found (as a non-negative index), or
   - A negative value indicating the key is not present in the sequence

## Environmental Constraints

The specification should account for:
- Fixed-width integer arithmetic (parameterized bit-width)
- The bounds of signed and unsigned integer representation
- Sequence indexing conventions (the algorithm uses 0-based indexing internally)

## Correctness Properties

The algorithm must guarantee the following postcondition upon termination:

1. **Found case**: If the key exists in the sequence, the return value must be a valid index (non-negative) where the key can be found
2. **Not-found case**: If the key does not exist in the sequence, the return value must be negative

This property can be summarized as: the return value is non-negative if and only if the key is present in the sequence.

## Purpose

This specification serves as a formal model for verifying the correctness of binary search implementations, particularly those based on standard library implementations (such as Java's `Arrays.binarySearch`). The goal is to ensure the algorithm correctly distinguishes between successful and unsuccessful searches through its return value convention.
