# Specification Request: Branching Computation with Conditional Guards

## System Overview

I need a formal specification for a simple sequential algorithm that demonstrates non-deterministic branching with multi-step paths and guarded conditional choices.

## Behavior Description

The system should model a computation that:

1. **Initial branching choice**: At the start, the algorithm must non-deterministically choose between two different computation paths. Each path performs a two-step increment sequence on a different counter:
   - One path increments a first counter twice (set to 1, then add 1)
   - The other path increments a second counter twice (set to 1, then add 1)

2. **Guarded conditional action**: After completing the chosen path, the algorithm must perform a guarded choice that depends on the outcome of the first branch:
   - If the first counter was never modified (remained zero), increment a third counter by 1
   - If the first counter was fully incremented (reached 2), increment the third counter by 3

## Key Correctness Properties

The specification must verify that upon completion:

1. **Sum invariant**: The sum of the first two counters always equals exactly 2 (since exactly one path completes its two increments)

2. **Dependent computation correctness**: The third counter's final value equals the first counter's value plus 1 (ensuring the guarded choice correctly corresponds to which branch was taken)

3. **Termination**: The algorithm must eventually terminate under fair execution

## Purpose

This specification tests the interaction between non-deterministic branching, sequential multi-step operations within branches, and subsequent guarded commands that depend on which branch was selected. It verifies that the guards correctly synchronize with the branching outcomes.
