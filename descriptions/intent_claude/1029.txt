# Specification Request: Leader Election in a Unidirectional Ring Network

## System Overview

I need a formal specification of the Chang-Roberts algorithm for leader election in a distributed system where processes are arranged in a unidirectional ring topology.

## System Description

The system consists of a fixed number of processes (N) arranged in a ring, where each process can only send messages to its neighbor in one direction (e.g., clockwise). Each process has a unique identifier. The goal is for all processes to collectively elect exactly one leader—specifically, the process with the highest (or lowest) identifier among the participants.

## Functional Requirements

1. **Ring Communication**: Processes can only communicate by passing messages around the ring in one direction to their successor.

2. **Process Participation**: Any subset of processes may choose to initiate the election by declaring themselves as candidates.

3. **Message Passing**: Processes compare received identifiers with their own and decide whether to forward, suppress, or act on messages accordingly.

4. **Termination**: Eventually, exactly one process should determine that it is the leader, and this should be the process with the maximum (or minimum) identifier among those that initiated the election.

## Key Correctness Properties

1. **Safety - Unique Leader**: At most one process can ever be elected as the leader.

2. **Safety - Legitimate Leader**: If a leader is elected, it must be the process with the highest identifier among all initiating processes.

3. **Liveness - Guaranteed Election**: If at least one process initiates the election, eventually some process will be elected leader.

## Model Checking Requirements

The specification should be parameterized by the number of processes N to allow verification across different ring sizes.
