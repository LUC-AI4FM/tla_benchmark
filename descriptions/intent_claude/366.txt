# Specification Request: Recursive Function with Module Instantiation

## System Overview

I need a formal specification that tests the correct behavior of recursive function definitions that interact with instantiated modules. Specifically, the system should demonstrate that recursion can work correctly when part of the recursive computation is delegated to an operator defined in a separate module.

## Requirements

### Core Functionality

The specification should define a recursive mathematical function (specifically, the factorial function) where:

1. The recursion is split across module boundaries - the main recursive function calls an operator from an instantiated submodule
2. The instantiated module receives the recursive function itself as a parameter, creating an indirect recursive loop
3. The base case returns 1 when the input is 0
4. The recursive case multiplies the current value by the result of continuing the recursion through the external module

### Correctness Properties

The specification must verify the following properties:

1. **Base case correctness**: The function returns 1 when given input 0
2. **Specific value correctness**: The function correctly computes factorial of 4 as 24
3. **Recursive relationship**: For all positive integers in a reasonable range, the function satisfies the standard factorial recurrence relation (each value equals the input times the function applied to one less than the input)

## Purpose

This specification serves as a test case to verify that a TLA+ implementation correctly handles:
- Recursive function definitions
- Module instantiation with substitution of recursive operators
- Cross-module operator references within recursive computations

The goal is to confirm that the language's module system and recursion mechanisms interact correctly when combined in this manner.
