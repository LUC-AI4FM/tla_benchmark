# Specification Request: Real Number Arithmetic Foundation

## System Overview

I need a formal specification that extends integer arithmetic to support real numbers and basic real number operations.

## Requirements

### Core Functionality

1. **Real Number Domain**: Define the set of all real numbers as a mathematical domain that can be used in specifications.

2. **Division Operation**: Provide a division operation that works on numbers, producing real-valued results (not just integer division).

3. **Infinity Representation**: Include a representation of infinity as a value that can be used in specifications involving unbounded quantities or limit cases.

## Purpose

This specification should serve as a foundational module that other specifications can build upon when they need to reason about real-valued quantities, ratios, continuous measurements, or calculations that go beyond integer arithmetic.

## Key Properties

- The real numbers should form a proper extension of the integers
- Division should be well-defined for appropriate operands
- The specification should be composable with existing integer arithmetic foundations
