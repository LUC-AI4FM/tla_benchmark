# Specification Request: Binary-Encoded Hour Clock

## System Overview

I need a formal specification for an hour clock that represents the current hour using a binary encoding rather than a simple numeric value. The system should model a clock that tracks hours (1 through 12, or 0 through some maximum hour value) but stores this information as an array of individual bits.

## Functional Requirements

1. **Binary Representation**: The clock's state should be maintained as a fixed-length array of binary digits (0s and 1s), where the combined bit pattern encodes the current hour value.

2. **Hour Clock Behavior**: Despite the binary encoding, the underlying behavior must correspond exactly to a standard hour clock - the value represented by the bits must always be a valid hour, and transitions must follow proper hour clock semantics (incrementing through valid hours and wrapping appropriately).

3. **Bit Array Interpretation**: The specification should define how a bit array maps to a numeric hour value, using standard positional binary notation (each bit position contributes its value times the corresponding power of 2).

## Correctness Properties

1. **Representation Invariant**: At all times, the binary encoding must represent a valid hour. The bit array must always decode to a legitimate hour value - never an invalid or out-of-range number.

2. **Behavioral Equivalence**: The binary clock must be a valid refinement of a standard hour clock. There must exist a corresponding hour value such that the binary representation always equals that hour, and the overall system behavior satisfies the standard hour clock specification.

## Goals

The purpose of this specification is to demonstrate that a lower-level, binary-encoded implementation correctly implements the abstract behavior of an hour clock. This serves as an example of refinement mapping, showing how an implementation with a different state representation can be proven equivalent to a higher-level specification.
