# Specification Request: Module Instantiation with Type Annotations

## System Overview

I need a formal specification that demonstrates module composition in a typed specification language, specifically focusing on how type annotations are preserved when one module instantiates another with variable substitution.

## What Should Be Modeled

The specification should model a simple stateful system with:

1. **A reusable utility module** that:
   - Operates on an array/function data structure
   - Provides operations to access elements from this array
   - Includes helper operators with explicit type annotations (specifically, operators that take functions as arguments)

2. **A main module** that:
   - Maintains its own array variable (a function from integers to integers)
   - Instantiates the utility module, binding the utility's array to its own
   - Has trivial initialization and transition behavior (the focus is on the instantiation mechanism, not complex state changes)

## Requirements

- The array should be a function mapping integers to integers
- The utility module should define an operator that extracts a value from the array at a specific index
- A higher-order helper operator should accept a function parameter and access an element from it
- Type annotations must be properly specified on both variables and operators
- The main module must correctly substitute its variable when instantiating the utility module

## Correctness Properties

The key correctness concern is **type consistency across module boundaries**:
- Type annotations on operators within the utility module must remain valid after the module is instantiated with variable substitution
- The substituted variable's type must be compatible with the expected type in the utility module
- Higher-order operators with type-annotated parameters must work correctly in the instantiated context

## Purpose

This specification serves as a validation that the type-checking system correctly handles the interaction between type annotations and module instantiation with variable substitution—ensuring that types are properly propagated and checked when modules are composed together.
