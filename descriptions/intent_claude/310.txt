# Specification Request: Binary Search Algorithm with Fixed-Width Integer Arithmetic

## System to Model

I need a formal specification of the **binary search algorithm** that operates under realistic constraints of fixed-width integer arithmetic. The model should capture how binary search finds (or fails to find) a target element in a sorted sequence.

## Functional Requirements

The algorithm should:

1. Search for a specified key value within a sorted input sequence
2. Maintain and update search boundaries to progressively narrow the search space
3. Terminate with a result indicating whether the key was found (and if so, its position)
4. Handle edge cases including empty sequences and keys not present in the sequence

## Key Constraints

The specification must model **bounded integer arithmetic** with a configurable bit width (e.g., 8-bit integers). This is critical because:

- Real implementations face integer overflow risks, particularly when computing midpoint indices
- The classic midpoint calculation `(low + high) / 2` can overflow even when both operands are valid indices
- The specification should either demonstrate this vulnerability or verify a safe implementation

## Correctness Properties

The specification should allow verification of:

1. **Partial Correctness**: If the algorithm terminates and reports finding the key, the key actually exists at the reported position
2. **Termination**: The algorithm always terminates for any valid input
3. **Completeness**: If the key exists in the sequence, the algorithm finds it
4. **Safety under Bounded Arithmetic**: The algorithm behaves correctly despite the limitations of fixed-width integers, or the specification reveals where overflow can cause incorrect behavior

## Configuration Parameters

The specification should be parameterized by:
- The bit width for integer representation
- An input sequence (assumed sorted)
- The key value to search for
