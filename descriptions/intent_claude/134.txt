# Specification Request

## System Description

I need a formal specification for a simple state machine involving a mapping from a fixed set of process identifiers to sets of integers.

## Requirements

The system should model the following:

1. **State Structure**: There is a single process (or a small fixed set of processes), and each process is associated with a set of integers.

2. **Initialization**: Each process starts with its associated set containing only the value zero.

3. **Transitions**: Any process can take a step, and when it does, the entire mapping is reset so that every process's set contains only zero.

## Correctness Properties

The key property that must be guaranteed:

- **Type Safety**: The mapping must always be a valid function from the process set to subsets of integers. This ensures the state remains well-typed throughout all executions.

## Notes

This appears to be a minimal example, possibly intended to test or demonstrate how a model checker handles functions whose codomain involves infinite sets (subsets of integers). The specification should be simple enough to verify that type invariants hold when working with mappings into potentially infinite domains.
