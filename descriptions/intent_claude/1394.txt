Write a small TLA+ module that demonstrates correct handling of a constant operator substituted for a variable via an INSTANCE WITH clause, particularly inside an UNCHANGED expression. The setup involves two modules: a main module that declares two variables and defines a constant-valued operator, then instantiates a second module by substituting that operator for one of the second module's variables. The second module has three variables, an Init predicate choosing initial values from a small set, and a Next action that increments one variable while leaving the other two unchanged via UNCHANGED. The specification is the standard Init-and-always-Next form. The main purpose is to confirm that TLC does not crash or report the substituted identifier as undefined when it appears inside an UNCHANGED expression after instantiation. The specification should check for absence of errors during model checking with deadlock checking disabled.
