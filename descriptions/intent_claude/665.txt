# Specification Request: Combinatorics Operations Test Suite

## Overview

I need a formal specification for a test suite that validates combinatorial operations. This should serve as a lightweight "smoke test" version of a more comprehensive combinatorics testing module.

## System Description

The system should verify the correctness of fundamental combinatorial functions and operations, such as:

- Permutations of sets and sequences
- Combinations (choosing k elements from n)
- Factorial calculations
- Binomial coefficients
- Cartesian products
- Other standard combinatorial constructions

## Requirements

1. **Inheritance**: The test suite should build upon and extend an existing, more complete combinatorics test specification, inheriting all of its definitions and test cases.

2. **Lightweight Validation**: This should function as a quick sanity check that can be run frequently to catch obvious errors in combinatorial implementations without running the full exhaustive test suite.

3. **Correctness Properties**: The tests should verify that:
   - Combinatorial operations produce results of the expected cardinality
   - Generated combinations and permutations contain only valid elements from the input
   - Results satisfy fundamental combinatorial identities (e.g., |P(n,k)| = n!/(n-k)!)
   - Edge cases are handled correctly (empty sets, zero selections, etc.)

## Goal

Provide a fast-running subset of combinatorics tests that can serve as a smoke test to quickly validate that the core combinatorial operators are functioning correctly, suitable for frequent execution during development or as part of a continuous integration pipeline.
