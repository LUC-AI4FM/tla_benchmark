# Specification Request: Balance Scale Weighing Puzzle

## System to Model

I need a formal specification that solves a classic weighing puzzle: Given a stone of a specified total weight, find all ways to break it into a specified number of pieces such that any integer weight from 1 up to the total can be measured using a balance scale.

## Problem Description

The scenario involves a balance scale where weights can be placed on either side. To measure a quantity of some material (like corn), you can place the material on one side and then distribute the stone pieces between both sides of the scale. A target weight can be measured if there exists some arrangement where the material plus any pieces on its side balances exactly with the pieces on the opposite side.

## Requirements

1. **Input Parameters**: The specification should be parameterized by:
   - The total weight of the stone
   - The number of pieces to break it into

2. **Valid Breaks**: Enumerate all valid ways to partition the stone into the specified number of integer-weighted pieces, where the piece weights sum to the total weight.

3. **Measurement Capability**: For each potential break, determine whether every integer weight from 1 through the total weight can be measured. A weight is measurable if the pieces can be partitioned into two disjoint groups such that the target weight plus one group's total equals the other group's total.

4. **Find All Solutions**: Identify all breaks that allow measuring every required weight.

## Correctness Properties

- Every solution must consist of pieces whose weights sum exactly to the total stone weight
- For any solution, every integer from 1 to the total weight must be representable as the difference between two disjoint subsets of pieces
- The specification should be verifiable by exhaustive enumeration for reasonable parameter values

## Expected Output

The specification should enable a model checker to compute and display all valid solutions, showing exactly which piece weights solve the puzzle for given parameters.
