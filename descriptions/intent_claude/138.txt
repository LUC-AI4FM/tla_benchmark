# Specification Request: 12-Hour Clock

## System to Model

I need a formal specification of a simple 12-hour clock that tracks the current hour.

## Behavioral Requirements

The clock should:

1. **Start in a valid state**: The clock begins showing some hour between 1 and 12 (inclusive), representing a standard 12-hour clock face.

2. **Advance hours correctly**: When the clock ticks, it should move to the next hour. After hour 12, it should wrap around to hour 1, just like a real clock.

3. **Allow stuttering**: The specification should permit the clock to remain unchanged between ticks (to allow for composition with other specifications or to model that time advancement is not forced at every step).

## Correctness Properties

The specification must guarantee:

1. **Type safety**: The hour value must always remain within the valid range of 1 through 12. The clock should never display an invalid hour like 0 or 13.

2. **Invariant preservation**: If the clock starts in a valid configuration, it must remain in a valid configuration forever—the initial condition should be maintained as an invariant throughout all executions.

## Purpose

This is a foundational example of modeling a simple cyclic counter with wraparound behavior, suitable for demonstrating basic temporal logic specifications and invariant verification.
