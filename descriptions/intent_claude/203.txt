Write a specification for a system that computes factorial values and tracks the result of factorial computations over time.

**System Description:**
The system should model a simple state machine that holds the result of factorial calculations. The factorial function itself needs to be defined recursively in the standard mathematical way (n! = n × (n-1)! with base case 1! = 1).

**Behavior:**
- The system starts with the factorial of a small number (like 4) as its initial state.
- The system can transition to hold the factorial of a larger number (like 7).

**Correctness Properties:**
- The stored factorial value must always be a positive integer (at least 1). This reflects the mathematical property that factorials of non-negative integers are always positive.

**Additional Context:**
The specification should support verification tools that need to handle recursive definitions, potentially requiring bounds on recursion depth for analysis purposes.
