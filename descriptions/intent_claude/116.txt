# Specification Request: Fold Operation Over Sequences to Update Function Records

## System to Model

I need a formal specification that models a **fold (reduce) operation** applied to a sequence of keys, where each step updates a function (record/map) by setting the value at the current key to a fixed value.

## What the System Must Do

The specification should demonstrate a left-fold operation that:

1. Starts with an initial function/map that assigns a default value (zero) to a fixed set of keys
2. Processes a sequence of keys one by one from left to right
3. For each key encountered, updates the function to set that key's value to 1
4. Produces a final result after processing all keys in the sequence

## Key Correctness Properties

The specification must verify that:

1. **Complete coverage property**: When the sequence contains all keys from the function's domain (regardless of order), the fold operation should produce a function where every key maps to 1

2. **Equivalence property**: The result of folding over a sequence that covers all domain elements should be equivalent to directly constructing a function that maps every element in the domain to 1

## Purpose

This specification is intended to test or validate that a model checker's encoding of fold operations over sequences correctly handles function/record updates. Specifically, it should confirm that iteratively updating a function through a fold produces the expected cumulative result, ensuring the underlying constraint encoding properly captures the semantics of sequential function updates.
