Write a specification for a simple message-passing system between a fixed set of participants.

**System Description:**
Model a communication system where participants can send messages to each other. The system should track messages sent between every possible pair of participants (including a participant sending to themselves). Each communication channel between a sender and receiver maintains a log of messages.

**Behavior Requirements:**
- The system starts with all communication channels empty (no messages have been sent)
- At any point, any participant may send a "hello" message to any other participant (or to themselves)
- When a message is sent, it is recorded in the appropriate channel for that sender-receiver pair

**Property to Check:**
Verify whether the system can terminate—that is, whether it eventually reaches a state where no further actions are possible. The specification should be checked against a termination property to determine if the system ever stops executing.
