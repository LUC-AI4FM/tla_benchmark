Please write a formal specification for a distributed termination detection algorithm in a ring network topology.

**System Overview:**
Model a network of nodes arranged in a logical ring, where each node can be either active (performing computation) or inactive. Active nodes may send messages to other nodes, which can reactivate inactive nodes. The goal is to detect when the entire distributed system has terminated—meaning all nodes are inactive and no messages are in transit.

**Termination Detection Mechanism:**
Implement a token-based detection scheme where a special token circulates around the ring. The token is used to determine whether global termination has occurred. The detection mechanism must account for the fact that nodes can become active again upon receiving messages, and must correctly handle the race condition between message passing and token circulation.

**Key Requirements:**

1. Nodes can transition between active and inactive states
2. Active nodes can send messages to other nodes in the network
3. Receiving a message activates an inactive node
4. A token circulates through the ring to probe for termination
5. The token carries information that helps detect whether termination has truly occurred (accounting for messages that may have been sent "behind" the token)

**Correctness Properties:**

1. **Safety (Main Invariant):** If the algorithm reports that termination has been detected, then the system must actually be terminated—all nodes must be inactive and there must be no pending messages anywhere in the system.

2. **No false positives:** The detection mechanism must never incorrectly claim termination when there are still active nodes or messages in flight.

**Additional Notes:**
This is based on Dijkstra's classic EWD840 algorithm for termination detection in a ring. The specification should capture the essential correctness guarantee that detected termination implies actual termination.
