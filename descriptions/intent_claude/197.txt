# Specification Request: Set Transformation System with Positive Element Preservation

## System Overview

I need a formal specification for a system that manages a collection of distinct positive integers and transforms them according to rules based on whether elements are even or odd.

## Initial Conditions

The system should start with a set of integers selected from a bounded range (e.g., 1 through 10). The initial set must contain at least a minimum number of elements (at least 5) to ensure the system has meaningful starting material to work with.

## Transformation Rules

The system should support two types of non-deterministic transformations on the set:

1. **Even number transformation**: Any even number in the set can be removed and replaced with its doubled value. This allows even numbers to grow while maintaining the set structure.

2. **Odd number removal**: Any odd number in the set can simply be removed without replacement.

At each step, the system non-deterministically chooses one of these applicable transformations.

## Key Correctness Property

The critical safety property that must always hold: **the set must never become empty of positive elements**. At every reachable state, there must exist at least one element in the set that is greater than zero.

## Verification Goals

The specification should allow verification that:
- Starting from any valid initial configuration
- Following any sequence of allowed transformations
- The system maintains the invariant that positive elements always exist

This property ensures the system never reaches a degenerate state where all elements have been removed or transformed into non-positive values.
