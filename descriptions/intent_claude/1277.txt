Please write a formal specification for a system with the following characteristics:

**System Description:**
A simple state machine that manages a single state variable, starting from an empty or uninitialized state.

**Behavioral Requirements:**
- The system should begin in an uninitialized state (represented as empty)
- After initialization, the system may transition by selecting a value from a small binary range (0 or 1)
- Transitions should only occur when the selected value is strictly positive (i.e., the value 1)
- The system should allow stuttering steps where no change occurs

**Key Properties:**
- The specification should constrain what future states are permissible based on the transition relation
- The system should maintain type safety by only allowing values from the defined domain during transitions

**Notes:**
This appears to be exploring an unusual pattern where the next-state relation references the primed (next) variable directly in its predicate, rather than the current state. The specification should capture this forward-looking constraint style where we're essentially filtering which next-state values are acceptable.
