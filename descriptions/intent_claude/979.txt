Please write a formal specification for a **two-phase protocol** system.

## System Description

The system should model a coordination protocol that operates in two distinct phases, involving a set of participants and a coordinator. This is a fundamental pattern used in distributed systems for achieving agreement or coordinating actions across multiple parties.

## Requirements

1. **Participants and Coordinator**: The system should include multiple participant processes and a coordinator process that orchestrates the protocol.

2. **Two-Phase Structure**: The protocol must proceed through two distinct phases, where the first phase gathers information or votes from participants, and the second phase makes and communicates a final decision.

3. **State Tracking**: The system needs to track the state of both the coordinator and each participant as they progress through the protocol phases.

4. **Initial Conditions**: Define appropriate starting conditions where all processes begin in their initial states before the protocol commences.

## Correctness Properties

The specification should be suitable for verifying key correctness properties of the two-phase protocol, such as:

- **Agreement**: All participants that complete the protocol reach the same final decision
- **Validity**: The final decision is consistent with the inputs or votes provided by participants
- **Termination**: The protocol eventually reaches a conclusion under appropriate conditions

## Model Checking Support

The specification should support model checking with configurable initial values and transition behaviors that can be instantiated for verification purposes.
