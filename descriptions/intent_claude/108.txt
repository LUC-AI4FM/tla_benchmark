Write a specification for a simple boolean state system that tests the evaluation of existential quantifiers when used as values.

**System Description:**
The system maintains a single boolean state variable. The system should demonstrate that existential quantifier expressions (checking whether some element in a set satisfies a condition) can be used directly as boolean values in assignments, not just as conditions in control flow.

**Behavior Requirements:**
1. The system starts with its boolean state set to true.
2. The system can transition by setting its state equal to the result of evaluating whether there exists an element in a small finite set that satisfies a simple inequality condition.
3. An alternative transition should express the same logic using a conditional (if-then-else) structure, where the existential check is used as the condition rather than directly as an assigned value.

**Correctness Property:**
The boolean state should always remain true. This implicitly verifies that the existential quantifier evaluates to true (since there does exist an element in the set {1, 2} that is not equal to 1, namely 2), regardless of whether the quantifier is used directly as a value or as a conditional guard.
