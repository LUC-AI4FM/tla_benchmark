Specify a solution to the Dining Philosophers problem for N philosophers seated around a circular table, each requiring two shared forks (one on each side) to eat. Model the forks as binary semaphores. Break the deadlock that arises from a naive symmetric solution by having all philosophers except one pick up their right fork first and then their left fork, while the remaining philosopher picks them up in the opposite order. Each philosopher loops forever, acquiring both forks, eating, and then releasing both forks. The system must satisfy two correctness properties: a safety property guaranteeing that no two adjacent philosophers eat simultaneously, and a liveness property guaranteeing that every philosopher eats infinitely often (starvation freedom). Assume strong fairness for every philosopher's process so that liveness can be verified. The number of philosophers N should be a configurable constant assumed to be a natural number.
