# Specification Request: Set Accumulation with Symmetric Elements

## System Description

I need a formal specification for a simple set accumulation system. The system maintains a collection that can grow over time by adding elements from a designated pool of candidates.

## Behavioral Requirements

1. **Initial State**: The collection starts empty.

2. **Growth Operation**: At each step, the system may add any element from a predefined set of valid candidates to the collection. Elements can only be added, never removed.

3. **Membership Constraint**: The collection must only ever contain elements from the designated pool of valid candidates (not from any other category of elements in the model).

## Symmetry Considerations

The model includes two distinct categories of elements. The specification should support symmetry reduction for both categories independently, which is useful for efficient model checking when the specific identity of elements doesn't matter—only their category membership.

## Correctness Properties

- **Type Safety**: The accumulated set must always be a subset of the valid candidate pool, never containing elements from other categories.
