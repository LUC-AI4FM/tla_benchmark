# Specification Request: Nondeterministic Sequence Assignment

## System Description

I need a formal specification for a simple system that manages a sequence of integers. The system should be able to nondeterministically select and assign any possible sequence composed of elements from a fixed set of values.

## Desired Behavior

The system maintains a single sequence that:
- Starts empty initially
- Can transition to **any arbitrary sequence** whose elements are drawn from the set {1, 2, 3}

This includes sequences of any length (including remaining empty), with any combination and ordering of the allowed values, and with possible repetition of elements.

## Key Requirements

1. **Initial State**: The sequence must begin empty
2. **Transitions**: At each step, the system should be able to choose any valid sequence over the permitted element set—not just extend or modify the current sequence, but replace it entirely with any possible sequence

## Purpose

This specification is intended to explore or demonstrate the behavior of nondeterministic choice over an infinite domain (the set of all finite sequences over a finite alphabet). The focus is on the ability to express unconstrained selection from the space of all possible sequences.

## Correctness Properties

The primary concern is whether the specification can be properly analyzed—specifically whether tools can handle reasoning about transitions that quantify over an infinite set of possible sequence values.
