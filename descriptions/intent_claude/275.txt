# Specification Request

I need a formal specification for the simplest possible system that demonstrates invariant violation checking.

## System Description

Model a trivial system with no meaningful state or constraints. The system should be able to start in any configuration and transition freely without any restrictions on its behavior.

## Requirements

1. **Initialization**: The system should accept any initial state whatsoever—there are no preconditions or setup requirements.

2. **Transitions**: The system should always be able to take a step. Every state should have valid successor states, meaning the system never deadlocks or gets stuck.

## Correctness Property

The specification must include an invariant that is **never satisfied**—it should fail immediately and in every reachable state. This serves as a test case or sanity check to verify that a model checker correctly detects and reports invariant violations.

## Purpose

This specification is intended as a minimal test case for model checking tools, specifically to verify that the checker properly identifies specifications where:
- The system has unconstrained behavior
- An invariant is universally false
- Violation should be reported immediately upon checking
