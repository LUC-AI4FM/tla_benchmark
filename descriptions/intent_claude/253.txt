# Specification Request: Set Cardinality via Fold Operation

## System to Model

I need a formal specification that demonstrates how to compute the cardinality (size) of a finite set using a fold/reduce operation, rather than relying on a built-in cardinality function.

## Goal

The purpose is to show that a fold-based approach to counting set elements produces results equivalent to the standard mathematical definition of set cardinality. This serves as both a verification that the fold operation works correctly over sets and as an example of implementing derived set operations from primitive folding.

## Requirements

### Functional Requirements

1. The system should work with arbitrary finite sets of integers (specifically subsets of a bounded range for tractability)
2. A custom cardinality computation must be defined that:
   - Uses a fold/reduce operation over the set
   - Accumulates a count by adding 1 for each element encountered
   - Starts from an initial count of zero
3. The set under consideration can be any possible subset of the bounded integer range

### Behavioral Requirements

1. The system should be able to initialize with any valid finite set from the defined domain
2. The set remains unchanged over time (this is a static property verification, not a dynamic protocol)

## Correctness Properties

The key invariant that must hold:

- **Equivalence Property**: The custom fold-based cardinality computation must always produce exactly the same result as the standard set cardinality function, for any possible finite set in the domain.

This property must hold for all reachable states, meaning it must be true regardless of which subset is chosen during initialization.
