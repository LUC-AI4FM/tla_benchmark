# Specification Request: Propositional Logic Test Suite

## Overview

I need a TLA+ specification that serves as a test harness to verify the correct behavior of propositional logic operators and boolean expressions in TLA+. This is essentially a unit test suite for the logical foundations of the specification language itself.

## System Description

The specification should establish a fixed boolean context (specific true/false assignments to several boolean variables) and then systematically verify that various propositional logic expressions evaluate as expected under that assignment.

## Requirements

### Initial Setup
- Define a fixed truth assignment where some boolean variables are set to true and others to false
- The system should remain in this initial state (no meaningful state transitions)

### Test Coverage

The test suite must verify correct evaluation of:

1. **Basic logical operators:**
   - Conjunction (AND)
   - Disjunction (OR)
   - Negation (NOT)

2. **Implication:** Verify that logical implication behaves correctly, including cases with negated antecedents and consequents

3. **Equivalence:** Test both forms of logical equivalence operators to confirm they work identically

4. **Double negation:** Confirm that double negation resolves correctly

5. **Mixed expressions:** Test compound expressions combining multiple operators

6. **Boolean set membership:** Verify that TRUE and FALSE are properly recognized as members of the BOOLEAN set, and that the BOOLEAN set equals exactly {TRUE, FALSE}

7. **Type mixing:** Include some tests that mix boolean values with equality comparisons against non-boolean values to verify proper handling

## Correctness Properties

The specification must guarantee that:

1. Every logical expression evaluates to its mathematically expected result given the fixed truth assignment
2. All tests pass—any test failure should halt execution with a clear error message indicating which test failed
3. Successful tests should produce confirmation output

## Purpose

This specification is intended as a regression test or validation tool to ensure that a TLA+ implementation correctly handles propositional logic. It should catch any bugs in how logical operators are parsed or evaluated.
