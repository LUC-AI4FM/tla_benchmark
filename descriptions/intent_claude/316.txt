# Specification Request: Binary Search Algorithm

## System to Model

A binary search algorithm operating on a sorted sequence of integers, designed to find a specific key value. The algorithm should work within the constraints of fixed-width integer arithmetic (8-bit integers).

## Functional Requirements

The system should model a binary search that:

1. Takes as input a sequence of integers and a target key to search for
2. Maintains search bounds that progressively narrow to locate the key
3. Computes midpoints to divide the search space
4. Terminates with a result indicating whether the key was found (and where)

## Key Correctness Properties

The specification must verify:

1. **Termination**: The algorithm must always terminate within a bounded number of steps, regardless of input
2. **Correctness**: If the input sequence is sorted and contains the key, the algorithm must find it; if the key is not present, the algorithm must correctly report this
3. **Integer overflow safety**: All arithmetic operations (particularly the midpoint calculation) must not overflow given the fixed-width integer constraints
4. **Bound invariants**: The search bounds must remain valid throughout execution (low ≤ high when still searching, both within array bounds)

## Verification Approach

The specification should support verification against arbitrary input sequences and keys (not just fixed test cases), to ensure the algorithm is correct for all valid inputs within the integer width constraints. This includes reasoning about sequences up to the maximum representable length and keys across the full integer range.

## Context

This models the classic binary search algorithm, with particular attention to the well-known integer overflow bug that can occur when computing the midpoint as `(low + high) / 2` with fixed-width integers.
