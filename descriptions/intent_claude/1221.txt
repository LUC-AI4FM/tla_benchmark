Write a TLA+ specification that serves as a fingerprint/state-count test for a LazyCache model. The system involves a shared memory mapping addresses to data values, a per-processor cache that may hold data or a "not present" sentinel for each address, and per-processor input and output queues. Multiple processors can independently update the cache, enqueue or dequeue operations from their input queues (holding address-data operation pairs, optionally tagged), and enqueue or dequeue responses from their output queues. The shared memory can also be updated arbitrarily. The input and output queues are bounded by configurable maximum lengths. The specification should compute and print the total number of distinct reachable states at initialization, derived analytically from the cardinalities of the data and address sets and the queue length bounds. The invariant to check is that all four components remain within their correct type domains throughout execution: memory maps addresses to data, caches map addresses to data-or-sentinel, input queues are bounded sequences of operations, and output queues are bounded sequences of data-address pairs. No liveness properties are required.
