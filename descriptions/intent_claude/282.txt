# Specification Request: Invariant Stability System

## System Description

I need a formal specification for a simple integer-based system that demonstrates stability behavior. The system should model a counter or state variable that eventually reaches and maintains a stable, unchanging state.

## Behavioral Requirements

1. The system should start with an initial state of zero.

2. The system should have two modes of operation:
   - When in a "recovery" state (negative values), the system should increment toward stability
   - When in a "stable" state (non-negative values), the system should remain unchanged

3. Given the initial condition, the system should immediately be in its stable regime and never change from its starting value.

## Correctness Properties

The key property I want to verify is **perpetual stability**: once the system is initialized, the state variable should never change throughout any execution. This is an invariant asserting that every transition preserves the current value.

## Purpose

This specification is intended to explore or test how stability properties (specifically, the property that a variable remains unchanged) can be expressed and verified as system invariants. The goal is to confirm that from the given initial state, no execution path ever modifies the system state.
