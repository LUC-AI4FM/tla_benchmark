Write a TLA+ specification that demonstrates procedural composition with simulated return values in PlusCal. Model a single sequential process that calls two procedures in sequence: one that adds two integers and stores the result in a shared return-value variable, and another that converts an integer to its string representation (only needing to handle the specific value 10) and likewise stores the result. The process should call the addition procedure with arguments 3 and 7, pass the numeric result to the conversion procedure, store the final string result in an output variable, and assert that the output equals the string "10". The specification should guarantee liveness: the process must eventually reach a completed state. This is primarily a demonstration of how PlusCal procedures can fake return values through shared variables, and correctness is verified through runtime assertions confirming intermediate and final values are as expected.
