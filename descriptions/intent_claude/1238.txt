# Specification Request: Test Suite for Set Operations

## Goal

Create a test harness that verifies the correctness of fundamental set operations as implemented by a TLA+ model checker or theorem prover. The purpose is to confirm that the tool correctly evaluates set union, intersection, difference, and subset relations across various scenarios.

## System Description

The system should be a static test module that executes a comprehensive battery of assertions checking set-theoretic operations. It needs to validate that the implementation conforms to standard mathematical set theory semantics.

## Operations to Verify

The test suite must cover the following set operations:

1. **Set Union**: Combining two sets yields all elements from both
2. **Set Intersection**: Finding common elements between two sets
3. **Set Difference**: Removing elements of one set from another
4. **Subset Relation**: Checking whether all elements of one set belong to another

## Test Scenarios Required

The verification must include:

- Basic operations on finite enumerated sets
- Operations involving infinite sets (integers, natural numbers)
- Operations with set comprehensions (sets defined by predicates)
- Edge cases with empty sets
- Operations on sequences treated as sets
- Operations on function spaces
- Operations involving Cartesian products combined with other set constructions
- Commutativity checks where applicable (e.g., union with operands reversed)

## Correctness Properties

Each test case must either:
- Pass silently (or with confirmation output) when the set operation produces the mathematically expected result
- Fail with an explicit assertion error when the operation produces an incorrect result

The overall invariant is that all test cases pass, confirming the tool's set operations match standard mathematical definitions.

## Key Requirements

- The test framework should report which specific test failed if any operation is incorrect
- Tests should cover both membership tests and set equality comparisons
- The suite should verify that infinite set operations work correctly when combined with finite sets
