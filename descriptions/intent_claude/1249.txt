# Specification Request: JSON Serialization Library for TLA+

## Overview

I need a utility library that enables TLA+ specifications to convert data structures into JSON string representations, as well as serialize and deserialize values to and from JSON files.

## Goal

Provide a set of operations that bridge TLA+ data types and JSON format, allowing specifications to:
1. Convert in-memory TLA+ values to JSON-formatted strings
2. Write TLA+ values to files in JSON format
3. Read JSON files and reconstruct TLA+ values

## Functional Requirements

### String Conversion

The library should support converting TLA+ values to their JSON string equivalents:

- **Records** should convert to JSON objects, where field names become keys and field values become the corresponding JSON values
- **Tuples and sequences** should convert to JSON arrays, preserving element order
- **Scalar values** (numbers, strings, booleans) should convert to their natural JSON representations
- **Empty structures** should produce the appropriate empty JSON notation (`{}` for objects, `[]` for arrays)

The library should provide:
- A general-purpose conversion that automatically determines whether to produce an object or array based on the input type
- Explicit conversions that force output as either a JSON array or JSON object

### File Serialization

The library should support writing values to files in two JSON formats:
1. **Standard JSON**: A single JSON document per file
2. **Newline-delimited JSON (NDJSON)**: Multiple JSON values separated by newlines, useful for streaming or log-style data

### File Deserialization

The library should support reading JSON from files and reconstructing TLA+ values:
- JSON objects should become TLA+ records
- JSON arrays should become TLA+ tuples
- Both standard JSON and newline-delimited JSON formats should be supported

## Key Properties

- The conversion should handle nested structures recursively
- File paths should be specified as absolute paths
- The serialization/deserialization should maintain round-trip compatibility where JSON objects map to records and JSON arrays map to tuples

## Context

This library is intended as infrastructure support for TLA+ specifications that need to interact with external data in JSON format, whether for test fixtures, logging model checker state, or interoperating with other tools.
