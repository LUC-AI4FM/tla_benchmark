# Specification Request: Binary Search Algorithm

## System to Model

I need a formal specification of the **binary search algorithm** operating on a sorted sequence of integers. The algorithm should search for a given key within the sequence and return an appropriate result indicating whether the key was found (and if so, where).

## Functional Requirements

The system should model:

1. **Input**: A sequence of integers and a target key to search for
2. **Search process**: The classic binary search approach that repeatedly narrows the search range by comparing the middle element with the target key
3. **Termination**: The algorithm must eventually terminate with a definitive result
4. **Bounded arithmetic**: The specification should account for fixed-width integer arithmetic (e.g., 8-bit integers) to model realistic computer implementations where overflow is possible

## Key Correctness Properties

The specification must guarantee:

1. **Soundness**: If the algorithm reports finding the key at a position, the key must actually be at that position in the input sequence

2. **Completeness**: If the key exists in a sorted input sequence, the algorithm must find it

3. **Termination**: The algorithm must terminate within a bounded number of steps

4. **Correct handling of edge cases**: The algorithm should handle empty sequences, sequences with duplicate values, and keys that are not present in the sequence

## Verification Approach

The specification should support verification across **all possible input sequences and keys** within the integer bounds, rather than just checking specific concrete test cases. This enables exhaustive verification that the algorithm is correct for any valid input, which is particularly important for catching subtle bugs related to integer overflow in the midpoint calculation.
