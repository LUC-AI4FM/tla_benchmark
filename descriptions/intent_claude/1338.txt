Please write a formal specification for a system that demonstrates the behavior of existential quantification over an empty set in temporal logic.

**System Description:**
The system should model a trivial single-variable state machine that initializes to a fixed value. The key aspect to explore is what happens when the transition relation is defined using an existential quantifier that ranges over an empty set.

**Requirements:**

1. The system should have a single state component that starts at a specific initial value (such as 1).

2. The next-state relation should be defined as an existential quantification over an empty domain, attempting to leave the state unchanged.

3. The specification should use a stuttering-tolerant form that allows the system to remain in its current state even when no explicit transitions are enabled.

**Key Properties to Verify:**

1. Demonstrate that existential quantification over an empty set is logically equivalent to FALSE (no transitions are ever enabled through this mechanism).

2. Show that despite the next-state relation being unsatisfiable, the overall specification remains valid due to the stuttering allowance—the system can always stutter in place.

3. Verify that trivial safety properties (like "TRUE always holds") are satisfied by this specification.

**Purpose:**
This specification serves as an educational example illustrating an important logical principle: when you quantify "there exists an element in the empty set such that...", the result is always false since there are no elements to witness the existential claim. The example should also show how stuttering steps rescue a specification from deadlock when no "real" transitions are possible.
