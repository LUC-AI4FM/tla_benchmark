Specify the Yo-Yo leader election algorithm with pruning, verified over all connected undirected loop-free graphs on a fixed number of nodes N. Initially, each node's edges are oriented by numeric order (lower-numbered node is incoming, higher-numbered is outgoing), and the topology is chosen nondeterministically from all connected subgraphs. Nodes alternate between a down phase, in which they propagate the minimum identifier received toward their outgoing neighbors, and an up phase, in which they reply yes or no and optionally request pruning of edges, progressively eliminating non-minimum sources and redirecting or removing edges until a single leader remains. The algorithm must satisfy the following properties: a type-correctness invariant; a neighbor consistency invariant ensuring that the outgoing/incoming relationship between any two nodes is coherent except when a reversal or pruning message is in transit; a termination condition stating that the algorithm finishes if and only if the node with the globally smallest identifier is the sole leader, all other nodes are inactive, and all mailboxes are empty; and a liveness property guaranteeing that this terminated state is eventually reached under weak fairness of all node actions.
