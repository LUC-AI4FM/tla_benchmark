# Specification Request: Graph Reachability Algorithm

## System Overview

I need a formal specification of a graph reachability algorithm that computes all nodes reachable from a designated root node in a directed graph.

## Problem Description

Given a directed graph represented by a set of nodes and a successor function (which maps each node to the set of its direct successors), the system should identify all nodes that are reachable from a specified root node by following directed edges.

## Functional Requirements

1. **Input**: The algorithm takes as input:
   - A finite set of nodes representing the graph vertices
   - A successor relation defining directed edges (for each node, which nodes can be reached in one step)
   - A designated starting/root node

2. **Computation**: The algorithm must systematically explore the graph starting from the root, following successor edges to discover all reachable nodes.

3. **Output**: Upon termination, the algorithm should have identified exactly the set of nodes reachable from the root.

## Correctness Properties

The specification must guarantee:

1. **Soundness**: Every node identified as reachable must actually be reachable from the root via some path through the successor relation.

2. **Completeness**: Every node that is reachable from the root must eventually be identified.

3. **Termination**: The algorithm must terminate for any finite graph.

4. **Root Inclusion**: The root node itself must be included in the reachable set (a node is reachable from itself via the empty path).

## Additional Context

The specification should model the algorithm at an abstract level, capturing the essence of iterative marking or exploration strategies commonly used for graph reachability (similar to breadth-first or depth-first search patterns, but without committing to a specific traversal order).

A small example configuration with 3 nodes forming a nearly complete graph (each node connects to all others except itself) starting from a designated root would be useful for validation and model checking.
