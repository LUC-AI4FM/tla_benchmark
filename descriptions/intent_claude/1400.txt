# Specification Request: Testing TLA+ Tooling for ENABLED Expressions with Module Instantiation

## System Overview

I need a formal specification to test the behavior of TLA+ model checking tooling when handling `ENABLED` expressions that involve operators imported from instantiated modules, particularly when those operators reference primed variables.

## Goal

Create a minimal test harness that exercises the model checker's ability to correctly evaluate enabledness conditions when:
1. An inner module defines an operator that references a primed (next-state) variable
2. The outer module instantiates this inner module with variable substitution
3. An invariant checks whether the instantiated operator is enabled under certain conditions

## Requirements

### Basic Structure
- A simple system with a single state variable that remains constant (starts at a fixed value and never changes)
- A separate inner module that defines an operator involving the primed version of its variable
- The outer module should instantiate the inner module, substituting its own variable

### Correctness Properties to Verify

1. **ENABLED Expression Handling**: The specification must allow checking whether an expression involving a primed variable from an instantiated module can be evaluated correctly in an `ENABLED` context

2. **State Coverage Tracking**: The model checker should be able to report statistics about:
   - How many times specific state predicates are evaluated
   - How many times specific transition predicates (stuttering steps) are encountered

3. **Expected Counts**: When examining model checker statistics:
   - A predicate checking the variable's value should be evaluated exactly twice
   - A stuttering transition predicate should be counted exactly once

## Purpose

This specification serves as a regression test or diagnostic tool for TLA+ tooling, specifically to expose or verify correct behavior when combining module instantiation with `ENABLED` operators that reference primed variables from the instantiated module.
