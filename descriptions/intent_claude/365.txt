# Specification Request: Mutually Recursive Factorial Definitions

## System to Model

I need a formal specification that demonstrates and verifies different approaches to defining the factorial function using mutual recursion in TLA+.

## Requirements

### Core Functionality

1. **Mutually Recursive Operators**: Define two operators that call each other to compute factorial. One operator should handle the base case (returning 1 when the input is 0) and delegate to the other for recursive computation. The second operator should simply forward to the first, creating a mutual recursion pattern.

2. **Mutually Recursive Functions**: Similarly, define two recursive functions (using function syntax rather than operator syntax) that reference each other to compute factorial values over the natural numbers.

### Correctness Properties

The specification must verify the following properties for all recursive formulations:

1. **Base Case**: The factorial of 0 equals 1.

2. **Specific Value Check**: The factorial of 4 equals 24 (verifying a concrete non-trivial case).

3. **Recurrence Relation**: For all positive integers up to a reasonable bound (e.g., 1 through 5), the factorial satisfies the standard recurrence: factorial(n) = n × factorial(n-1).

4. **Equivalence**: All different formulations of factorial (mutual recursion via operators and mutual recursion via functions) must produce identical results for the same inputs.

## Goal

The purpose of this specification is to serve as a test suite validating that TLA+'s support for mutual recursion works correctly—both for recursive operators and recursive functions. The specification should confirm that mutually recursive definitions can correctly implement well-known mathematical functions and that different syntactic approaches yield equivalent results.
