# Specification Request: N-Queens Problem Solver

## System Overview

I need a formal specification for an algorithm that solves the classic N-Queens puzzle. The puzzle requires placing N chess queens on an N×N chessboard such that no two queens threaten each other. Since queens can attack horizontally, vertically, and diagonally, a valid solution must have exactly one queen per row, one per column, and no two queens sharing a diagonal.

## Problem Representation

Queens placements should be represented as sequences where the position in the sequence indicates the row and the value indicates the column. For example, in a solution sequence, the k-th element tells you which column the queen in row k occupies. This representation inherently enforces the one-queen-per-row constraint.

## Algorithm Requirements

The system should implement an iterative search algorithm that:

1. Starts with an empty board (no queens placed)
2. Maintains a work set of partial solutions (boards with fewer than N queens that don't yet have conflicts)
3. Progressively extends partial solutions by placing additional queens in valid positions
4. Collects complete solutions (exactly N queens placed with no conflicts) as they are found
5. Continues until all possibilities have been explored

The algorithm should only extend a partial solution with queen placements that don't create any attacking relationship with already-placed queens.

## Conflict Detection

Two queens attack each other if they are:
- In the same column
- On the same diagonal (either direction)

The specification must define what it means for queens to attack each other based on their row and column positions.

## Correctness Properties

The specification must guarantee:

1. **Type Safety**: All partial solutions in progress have fewer than N queens; all collected complete solutions have exactly N queens, with column values in the valid range.

2. **Soundness**: Every solution collected by the algorithm is actually a valid solution where no two queens attack each other.

3. **Completeness**: When the algorithm finishes (no more partial solutions to explore), the collected solutions include all possible valid solutions to the N-Queens problem.

4. **Termination**: The algorithm must eventually complete its search, leaving no partial solutions unexplored.

## Reference Definition

The specification should include a declarative definition of what constitutes the complete set of valid solutions, independent of the algorithm, so that the algorithm's correctness can be verified against this mathematical definition.
