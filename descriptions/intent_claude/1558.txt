# Specification Request: Simple Cycle Detection and Construction for Finite Sets

## System Overview

I need a formal specification for utility operations that work with simple cycles over finite sets, treating the set elements as vertices in a directed graph structure.

## Goal

The specification should provide two capabilities:

1. **Cycle Verification**: Given a finite set of elements and a function mapping each element to another element, determine whether the function represents a simple cycle that visits every element in the set exactly once before returning to the starting point.

2. **Cycle Construction**: Given a finite set of elements, construct a function that arranges all elements into a simple cycle (a Hamiltonian cycle where following the function from any starting element will eventually visit all elements and return to the start).

## Key Concepts

- A **simple cycle** over a set S means that if you pick any element and repeatedly apply the mapping function, you will visit every element in S exactly once before returning to your starting point.
- The mapping function should be viewed as defining directed edges: an edge exists from element `a` to element `b` if the function maps `a` to `b`.
- The set of elements is finite.

## Requirements

1. The cycle verification predicate must confirm that:
   - Starting from any element in the set
   - Repeatedly following the mapping
   - Eventually visits every element in the set exactly once
   - The range of elements visited equals the entire set

2. The cycle construction operation must:
   - Accept any finite set as input
   - Produce a valid mapping function
   - The resulting mapping must form a simple cycle covering all elements

## Correctness Properties

- For any valid simple cycle mapping over set S, the range of the mapping must equal S
- Every element must have exactly one successor in the cycle
- Following the cycle for |S| steps from any starting point must return to that starting point
- The cycle must be connected (no element is isolated or in a separate sub-cycle)
