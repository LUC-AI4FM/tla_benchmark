# Specification Request: Utility Functions for Sequence and Set Operations

## Overview

I need a formal specification of a library of general-purpose utility functions that support common operations on sequences, sets, and functions. These utilities are meant to be reused across other specifications that need to manipulate collections of data.

## Required Functionality

### Aggregation/Folding Operation
The system should provide a way to aggregate or reduce a range of values from a function's domain using a binary operator. Given a function, a range of indices, a combining operation, and a starting value, it should compute a single result by successively applying the operation across the specified range.

### Arithmetic Helpers
Include a basic addition operation that can be used as a combining function for aggregation (e.g., to sum a range of values).

### Sequence Membership Test
Provide a way to check whether a particular element appears anywhere within a sequence.

### Sequence Element Removal
Support removing an element at a specific position from a sequence, producing a new sequence that is one element shorter with all other elements preserved in order.

### Function Range Extraction
Given a function, compute the set of all values in its range (co-domain image).

### Cycle Detection in Functional Graphs
Provide a way to determine whether a finite function, when viewed as a directed graph (where each element maps to its successor), forms a simple cycle that visits every element in a given set exactly once.

## Key Properties

1. **Reduction correctness**: The aggregation operation should process elements in order from the starting index to the ending index, combining each with the accumulated result.

2. **Removal preserves order**: When removing an element from a sequence, all elements before and after the removed position should maintain their relative order.

3. **Cycle completeness**: The cycle detection should verify that following the function from any starting point eventually visits every element in the set exactly once before returning to the start.

## Context

These utilities are intended as building blocks for larger specifications and should work with standard TLA+ integers, sequences, and finite sets.
