# Specification Request: Alternating State System with Liveness Properties

## System Overview

I need a formal specification for a simple two-component system that alternates between two configurations indefinitely. The system should swap the values of its two components on each step, creating an oscillating behavior.

## System Requirements

The system consists of two integer components that start in a specific initial configuration (one at 0, one at 1). On each transition, the system swaps the values of these two components, so they continuously alternate between two possible states.

## Correctness Properties

The specification should verify the following temporal properties:

1. **Valid Liveness Property**: The system should *always eventually* reach a configuration where the values are swapped from their initial state. This property should hold because the system oscillates and will always return to this swapped configuration infinitely often.

2. **Invalid Liveness Property (for testing)**: As a counterexample, include a property claiming the system always eventually reaches an impossible configuration (both components at 0). This property should be violated, demonstrating the difference between achievable and unachievable states.

## Purpose

This specification is intended to test and demonstrate the behavior of temporal logic operators, specifically the combination of "always" (box) followed by "eventually" (diamond) operators. It should serve as a verification test case for model checking tools handling these nested temporal operators.
