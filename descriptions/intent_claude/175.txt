# Specification Request

## System Description

I need a formal specification for a simple two-state oscillating system. The system consists of two integer values that swap with each other on every step. One value starts at zero and the other starts at one, and they continuously exchange their values.

## Behavioral Requirements

1. The system should initialize with one component set to zero and the other set to one
2. At each step, the two components should swap their values (the first takes the second's value, and the second takes the first's value)

## Correctness Properties to Verify

The main purpose of this specification is to explore how different formulations of properties behave when checking whether a condition holds:

1. **Simple boolean property**: Check whether the first component equals zero (as a state predicate)
2. **Mixed boolean-temporal property**: Check the same condition but combined with a trivially true temporal formula
3. **Explicit invariant**: Check whether the first component being zero holds in all reachable states

The goal is to understand and verify whether these different formulations produce equivalent or different verification results, particularly examining how boolean predicates behave when used as temporal properties versus when explicitly wrapped in temporal operators.
