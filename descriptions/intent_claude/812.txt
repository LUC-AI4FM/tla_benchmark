# Specification Request: Boyer-Moore Majority Vote Algorithm

## System to Model

I need a formal specification of the Boyer-Moore majority vote algorithm, a classical single-pass streaming algorithm that identifies a potential majority element in a sequence.

## Problem Description

Given a sequence of values, the algorithm must process the sequence in a single linear pass and produce a candidate value with the following guarantee: if any value appears more than half the time in the sequence (i.e., has an absolute majority), that value must be the reported candidate. The algorithm is allowed to report any value if no majority exists, but it must never miss a true majority element.

## Functional Requirements

1. **Input**: A finite sequence of values drawn from some non-empty set of possible values.

2. **Processing**: The algorithm examines each element of the sequence exactly once, in order, maintaining only constant additional state (not proportional to the sequence length or the number of distinct values).

3. **Output**: Upon completing the pass through the sequence, the algorithm reports a single candidate value.

## Correctness Properties

The key correctness guarantee is:

- **Majority Detection**: If any value occurs more than half the time in the input sequence, then that value must be the candidate reported by the algorithm. Equivalently, any value that is *not* the reported candidate is guaranteed *not* to be a majority element.

Note that this is a one-sided guarantee. The algorithm filters out all non-majority values but may report a candidate that doesn't actually have a majority. (A second verification pass would be needed to confirm whether the candidate truly has a majority, but that is outside the scope of this specification.)

## Verification Goals

The specification should:
- Allow verification across all possible input sequences up to some bounded length
- Support proving the correctness property as an invariant that holds upon termination
- Ensure the algorithm terminates after processing all elements
