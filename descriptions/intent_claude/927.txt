# Specification Request: Hour Clock System

## System Overview
I need a formal specification of a simple hour clock that tracks time in a 12-hour format.

## Functional Requirements
The system should model a clock that:
- Maintains the current hour as its state
- Displays hours in the range of 1 through 12 (standard 12-hour clock format)
- Advances the hour by one each time the clock ticks
- Wraps around from hour 12 back to hour 1, cycling continuously

## Correctness Properties
The specification must guarantee:
- **Type Invariant**: The hour value is always a valid hour on a 12-hour clock (an integer from 1 to 12, inclusive)
- **Progress**: The clock can always advance to the next hour
- **Cyclical Behavior**: After reaching hour 12, the next tick brings the clock back to hour 1

## Purpose
This is intended as a foundational example of a simple state machine with a finite, cyclical state space. The specification should be minimal and clear, suitable for demonstrating basic temporal modeling concepts.
