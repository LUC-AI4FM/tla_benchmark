Write a TLA+ specification for the translation phase of a PlusCal-to-TLA+ compiler. The system takes as input an Abstract Syntax Tree (AST) of a PlusCal algorithm and a fairness condition (none, weak fairness of all process actions, weak fairness of the entire next-state action, or strong fairness of all process actions), both supplied by an external module. The specification must define three main components: a validator confirming the AST represents a legal PlusCal algorithm (covering both uniprocess and multiprocess forms, all statement types, variable declarations, procedures, and processes); a label checker verifying there are no duplicate labels within any scope and that every goto target names an existing label; and a translator producing a sequence of TLA+ tokens representing the complete translated specification. The translator must handle all PlusCal statement types including assignment, conditionals, loops, either-or nondeterminism, with-blocks, calls, returns, combined call-returns, goto, skip, when, print, and assert. It must correctly introduce pc and stack variables, generate Init, Next, and Spec definitions, handle subscripting of local variables in multiprocess algorithms, produce appropriate UNCHANGED conjuncts, generate ProcSet and fairness conditions, and emit a Termination formula. The specification should detect errors such as wrong argument counts on procedure calls, multiple assignments to the same variable, and assignments to undeclared variables.
