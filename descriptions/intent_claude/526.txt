# Specification Request: Alternating Bit Protocol - High-Level Behavior

## System Overview

I need a formal specification that captures what the Alternating Bit protocol is supposed to accomplish at an abstract level—not the protocol implementation itself, but the observable behavior it should exhibit between a sender and receiver.

## System Description

Model a simple data transmission system with three components:

1. **A Sender**: Responsible for transmitting data values to a receiver, one at a time
2. **A Receiver**: Accepts data values from the sender
3. **An Environment**: Generates new data values to be transmitted (representing external input to the system)

The system transmits data items drawn from some fixed set of possible data values. Each transmission includes the data along with a single-bit tag that alternates between 0 and 1 with each new value sent.

## Behavioral Requirements

- The sender and receiver should start in a synchronized state (both holding the same initial value)
- The environment may introduce new data to send only when the previous transmission has completed (i.e., sender and receiver are synchronized)
- The sender updates to a new data value by toggling its bit and taking the next item from the input queue
- The receiver accepts a value from the sender when it detects the sender's bit has changed
- New data values should be queued and processed in order

## Fairness Requirements

- The sender must eventually process queued data (cannot ignore pending transmissions forever)
- The receiver must eventually accept transmitted data when available
- The environment need not be fair (it may or may not generate new data)

## Key Correctness Properties

The specification should serve as a reference model that any correct implementation of the Alternating Bit protocol should refine. The essential guarantee is that data values are reliably transferred from sender to receiver in order, with the alternating bit serving as an implicit acknowledgment mechanism indicating when a transfer is complete.
