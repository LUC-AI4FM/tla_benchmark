# Specification Request: Reliable Communication Channel

## System Overview

I need a formal specification of a basic communication channel that allows messages to be sent and received between processes. This is a fundamental building block for modeling distributed systems and message-passing protocols.

## Functional Requirements

The system should model:

1. **Message Sending**: A sender process should be able to transmit a message through the channel
2. **Message Receiving**: A receiver process should be able to retrieve a message from the channel
3. **Channel State**: The channel should track whether it currently holds a message available for receipt

## Data Requirements

- The channel must handle messages from some defined set of valid message values
- The channel state should clearly indicate whether a message is present and available

## Correctness Properties

The specification must guarantee **type correctness** as a safety property:

- The channel must always remain in a valid state throughout all possible executions
- All values stored in or transmitted through the channel must be well-typed according to the message domain
- This type invariant must hold in the initial state and be preserved by every possible system transition

## Purpose

This specification serves as a foundational model that can be extended or composed with other specifications to build more complex communication protocols. The formal proof of type correctness should be machine-checkable to provide high assurance of the model's basic validity.
