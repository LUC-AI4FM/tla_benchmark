# Specification Request: Binary Search Algorithm

## System to Model

I need a formal specification of the classic binary search algorithm operating on a sorted sequence of integers. The algorithm should search for a given key within the sequence and return information about whether and where the key was found.

## Functional Requirements

The algorithm must:

1. Search through a sorted integer sequence to locate a specific target key
2. Use the standard binary search approach of repeatedly halving the search interval
3. Maintain a search interval that narrows with each step until either the key is found or the interval is exhausted
4. Return a result that indicates:
   - If the key exists in the sequence: the index where it was found
   - If the key does not exist: a negative value indicating the key's absence

## Key Correctness Properties

The specification must guarantee the following postcondition upon termination:

1. **Correctness of positive results**: If the algorithm returns a non-negative index, that index must actually contain the search key in the input sequence

2. **Correctness of negative results**: If the algorithm returns a negative value, then the search key does not exist anywhere in the input sequence

3. **Found/not-found indicator**: The sign of the return value must reliably indicate whether the key was found—specifically, a non-negative return value if and only if the key exists in the sequence

## Modeling Considerations

The specification should account for:
- Fixed-width machine integers with defined bounds for signed and unsigned representations
- Sequences with 1-based indexing semantics (as typical in mathematical notation)
- The algorithm's index arithmetic, which may use 0-based conventions internally

This specification follows the behavior of standard library binary search implementations (such as Java's `Arrays.binarySearch`), where the return value encoding distinguishes between successful and unsuccessful searches.
