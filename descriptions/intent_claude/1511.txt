Please write a TLA+ specification for a simple static verification system that checks whether all elements of a given set satisfy a particular property.

The system should:

1. **Support higher-order property checking**: Define a general mechanism that can test whether every element in a set satisfies an arbitrary predicate function passed as a parameter.

2. **Implement a specific natural number membership check**: Use the general mechanism to verify that all elements of a specific set are natural numbers.

3. **Model a static computation**: The system should compute the result of this verification once at initialization and then remain unchanged—this is a one-shot check, not a dynamic process.

**Key correctness properties:**

- The specification should evaluate to true if and only if every element in the test set belongs to the natural numbers.
- Once the verification result is determined, it must remain stable (the system state never changes after initialization).

The concrete example to verify should be the set {1, 2, 3}, checking that all its elements are natural numbers.
