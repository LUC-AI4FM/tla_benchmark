Write a specification that verifies the semantic equivalence of different sequence construction methods in TLA+.

**System to Model:**
A test harness that confirms different ways of creating sequences with the same logical content produce identical results when operated upon.

**Requirements:**

1. The specification should demonstrate that a sequence can be constructed in multiple equivalent ways:
   - As an explicit tuple literal
   - As a function with a contiguous integer domain (1..n)
   - As a function with an equivalent set-based domain ({1, 2, ..., n})

2. When these differently-constructed sequences have the same values at each index, applying sequence operations (such as extracting a subsequence) should yield identical results regardless of the construction method.

**Key Correctness Properties:**

- Extracting an element from a subsequence of a function-based sequence must equal the same extraction from an equivalent tuple-based sequence.
- The domain specification style (range notation vs. set enumeration) must not affect the behavior of sequence operations.
- Functions that map integer indices to values should be interchangeable with tuple sequences when the domains and values match.

**Goal:**
Confirm that the TLA+ sequence operations treat structurally equivalent sequences uniformly, regardless of how they were syntactically defined. This serves as a regression test to ensure consistent semantics across different sequence representations.
