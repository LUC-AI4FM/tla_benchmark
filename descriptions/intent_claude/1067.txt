Write a TLA+ specification for the termination detection problem in a ring of N nodes with synchronous communication. The system consists of a fixed number of nodes, each of which is either active or inactive, plus a boolean flag indicating whether termination has been detected. Termination means all nodes are simultaneously inactive. Nodes may spontaneously deactivate, and an active node may wake up any other node. Once all nodes are inactive, a separate detection action may set the termination-detected flag. The initial state allows nodes to be in any combination of active or inactive states, with termination optionally already detected if all nodes happen to start inactive. The specification should enforce weak fairness on the detection action so that termination is eventually reported. Three correctness properties must hold: first, termination must never be falsely reported — the detected flag may only be true when all nodes are genuinely inactive; second, termination is a stable property — once all nodes are inactive they remain so forever; third, liveness requires that whenever all nodes are inactive, termination is eventually detected and reported.
