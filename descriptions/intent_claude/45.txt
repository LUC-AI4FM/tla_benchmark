# Specification Request: Monotonically Increasing Counter

## System Description

I need a formal specification for a simple counter system that starts at zero and increases by either 1 or 2 at each step. The counter should never decrease and should always make forward progress.

## Requirements

1. **Initial State**: The counter begins at zero.

2. **Behavior**: At each step, the counter increases by either 1 or 2 (nondeterministically chosen).

## Correctness Properties to Verify

The specification should allow testing of different kinds of invariants:

1. **Non-negativity** (should hold): The counter value is always greater than or equal to zero.

2. **Strict positivity** (should NOT hold): The counter is always strictly greater than zero. This should fail because the initial state has the counter at zero.

3. **Monotonic increase** (should hold): Every transition must increase the counter—the new value must be strictly greater than the previous value.

4. **Stability** (should NOT hold): The counter value remains unchanged between steps. This should fail because the system always increments.

## Purpose

This specification serves as a test case for verifying both state invariants (properties about individual states) and action invariants (properties about transitions between states). It should demonstrate the distinction between these two types of properties and provide examples of both valid and invalid invariants of each kind.
