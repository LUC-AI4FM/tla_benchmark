# Specification Request: Finite Set Operations

## System to Model

I need a formal specification that defines fundamental operations for reasoning about finite sets in a mathematical context. This should serve as a foundational library module that other specifications can import when they need to work with finite sets and their properties.

## Required Operations

The specification must provide two core capabilities:

1. **Finiteness Test**: A way to determine whether a given set is finite. A set should be considered finite if and only if all of its elements can be enumerated in some finite sequence.

2. **Cardinality Computation**: A way to compute the number of elements in a finite set. This operation is only meaningful for sets that are finite.

## Key Properties and Requirements

- The finiteness definition should be mathematically precise and align with the standard mathematical concept of finite sets (those that can be put in one-to-one correspondence with an initial segment of natural numbers).

- The cardinality operation should return 0 for the empty set and should correctly count elements without double-counting (each distinct element contributes exactly 1 to the count).

- The cardinality definition should work recursively through the set structure, processing elements one at a time until the set is exhausted.

## Context and Usage

This module will serve as a standard library component, meaning:
- It should be self-contained, importing only basic mathematical concepts (natural numbers and sequences)
- It should not expose its internal dependencies to modules that import it
- The definitions should be suitable for use by model checkers and theorem provers, potentially with optimized implementations overriding the mathematical definitions
