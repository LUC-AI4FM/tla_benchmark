# Specification Request: Large State Space Initialization Test

## System Overview

I need a formal specification for a simple static system designed to test and validate the handling of large initial state spaces in a model checker.

## Goal

The primary purpose of this specification is to stress-test the state space enumeration capabilities of a verification tool. The system should generate a substantial number of initial states through combinatorial explosion of multiple independent variables, then remain static.

## Requirements

### State Structure
- The system should consist of three independent numeric components, each bounded within different ranges
- The ranges should be chosen to create a meaningful combinatorial product (on the order of hundreds of thousands of initial states)
- The specific ranges should vary in size to test non-uniform enumeration

### Behavior
- The system should be purely static after initialization—no state transitions should occur
- All behavior is confined to the initial state generation

### Correctness Properties
- The specification should always satisfy its invariant (trivially true)
- The focus is on successful enumeration of the initial state space rather than verifying meaningful system properties

## Purpose

This specification serves as a benchmark or regression test for model checking tools, verifying they can efficiently enumerate and handle large initial state spaces without errors or performance degradation.
