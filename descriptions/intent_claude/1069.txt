Specify a termination detection algorithm for a ring of N nodes communicating asynchronously. Each node is either active or inactive, and any active node may send messages to any other node, incrementing that node's pending message count. A node deactivates itself voluntarily, and receiving a pending message reactivates a node. True termination occurs when every node is inactive and has no pending messages; once terminated, the system stays terminated (quiescence). A boolean flag records whether termination has been detected.

The specification must capture that termination detection is sound (the flag is only set when the system has genuinely terminated) and live (if the system does terminate, the flag will eventually be set). The initial state allows nodes to start in any mix of active and inactive states with no pending messages; if all nodes are already inactive at startup, the detection flag may optionally be set immediately. Model checking should be feasible by bounding pending message counts. The key correctness properties are: safety — the detection flag never lies; quiescence — once terminated the system cannot become un-terminated; and liveness — actual termination is eventually detected.
