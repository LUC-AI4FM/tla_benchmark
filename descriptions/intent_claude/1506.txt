# Specification Request: Recursive Function Definition Evaluation in Nested Scopes

## System to Be Modeled

A simple static system that tests the correct evaluation of recursive function definitions, particularly when those definitions appear within nested lexical scopes (nested LET expressions).

## Goal

Create a trivial specification where a single boolean variable is initialized to true and never changes. The real purpose is to define multiple invariant properties that exercise a specification language's ability to correctly evaluate:

1. Recursive functions that reference themselves
2. Multiple mutually-visible function definitions in the same scope
3. Deeply nested LET bindings where inner definitions reference outer ones
4. Combinations of recursive function definitions with ordinary operator definitions
5. Multiple levels of nesting (outer/inner/innermost scopes)

## Requirements

The base system should:
- Start with a single boolean flag set to true
- Never modify this flag (a completely static system)

The invariant properties should all be logically equivalent ways of asserting "the flag is true," but expressed through increasingly complex patterns of:
- A recursive function over a small finite domain that returns the flag's value
- The same recursive function but with the recursion being trivially unused
- Two function definitions in the same scope where one references the other
- Nested scopes where an inner function calls an outer recursive function
- A regular (non-recursive) operator defined alongside recursive functions that invokes them
- Three levels of nested definitions

## Correctness Properties

All defined invariants must:
1. Evaluate to true in every reachable state
2. Be semantically equivalent to simply checking that the flag equals true
3. Demonstrate that the evaluation engine correctly resolves references across nested scopes and handles recursive definitions properly

The specification serves as a test case to verify that a model checker correctly handles these scoping and recursion patterns without errors in name resolution or evaluation.
