# Specification Request: Concurrent Recursive Factorial Computation

## System Overview

I need a formal specification for a concurrent system where multiple independent processes each compute the factorial of a number using a recursive procedure. The goal is to verify that recursive procedure calls work correctly in a multi-process environment where each process maintains its own computation state.

## Functional Requirements

1. **Multiple concurrent processes**: The system should have several processes (at least three) that can execute simultaneously and independently.

2. **Recursive factorial computation**: Each process should compute the factorial of an input number (specifically, 5! = 120) using a recursive procedure. The procedure should:
   - Handle the base case (factorial of 0) by returning immediately
   - Handle the recursive case by multiplying a running result by the current value and recursively calling itself with a decremented argument

3. **Per-process results**: Each process must maintain its own separate result value, initialized to 1, that accumulates the factorial computation without interference from other processes.

## Correctness Properties

1. **Functional correctness**: Upon completion, each process's result must equal the correct factorial value (120 for input 5). This should be verified through assertions after the computation completes.

2. **Termination**: All processes must eventually complete their factorial computations.

3. **Process isolation**: The recursive computations of different processes must not interfere with each other—each process should correctly compute its factorial regardless of the interleaving of steps with other processes.

## Purpose

This specification serves to verify that:
- Recursive procedure calls with local state work correctly in a concurrent setting
- Process-local storage properly isolates computations
- The factorial algorithm is correctly implemented
- Fair scheduling ensures all processes complete
