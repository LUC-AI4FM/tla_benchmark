# Specification Request: Packet Validation System

## System Overview

I need a formal specification for a simple packet validation system that processes data packets and determines whether they meet certain well-formedness criteria.

## System Description

The system receives packets that contain:
- A sender identifier (which can be empty or reference a valid account)
- Associated data that includes a numeric amount field

The system should validate incoming packets and flag an error state when packets fail validation.

## Validation Rules

A packet is considered valid (well-formed) when:
1. The sender field is not empty (must reference an actual account)
2. The amount in the data payload is strictly positive (greater than zero)

## Behavioral Requirements

The system should:
1. Start with an arbitrary packet and no error condition
2. Continuously receive new packets
3. For each new packet, set the error flag based on whether the packet passes or fails validation
4. Clear the error flag when processing valid packets
5. Set the error flag when processing invalid packets

## Key Correctness Property

The main invariant to verify is that **the error state is consistent with the validation rules**. Specifically, whenever the system is in an error state, the current packet must actually violate at least one of the well-formedness conditions—either the sender is empty, or the amount is zero or negative.

This property ensures the validation logic correctly identifies malformed packets and that the error flag accurately reflects the validity status of packets being processed.
