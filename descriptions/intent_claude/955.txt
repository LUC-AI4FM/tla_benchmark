# Specification Request: Integer Arithmetic Extension

## Overview

I need a formal specification that extends the natural numbers to include the complete set of integers, enabling arithmetic operations that involve negative numbers.

## System Description

The system should define the mathematical set of all integers (positive, negative, and zero) by building upon an existing foundation of natural numbers. This is essentially extending the number system to support values less than zero.

## Requirements

1. **Integer Set Definition**: Define the complete set of integers that includes all positive whole numbers, zero, and all negative whole numbers.

2. **Negation Operation**: Provide a unary negation operator that, given any integer, produces its additive inverse (the number that when added to the original gives zero).

## Key Properties

- The integer set must be a proper superset of the natural numbers
- Negation of zero should equal zero
- Double negation of any integer should return the original value
- The negation operation should be well-defined for all integers

## Purpose

This specification serves as a foundational mathematical module that other specifications can build upon when they need to reason about quantities that can be negative, such as account balances, temperature differences, coordinate systems, or any domain where values below zero are meaningful.
