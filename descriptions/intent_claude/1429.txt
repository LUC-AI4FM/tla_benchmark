# Specification Request: Boolean Toggle System with Identity Properties

## System Description

I need a formal specification for the simplest possible state-toggling system: a single boolean value that alternates between true and false states.

## Behavioral Requirements

1. **Initial State**: The system starts with the boolean value set to true.

2. **State Transitions**: At each step, the boolean value toggles to its opposite (true becomes false, false becomes true).

3. **Stuttering**: The system should allow for stuttering steps where no change occurs.

## Correctness Properties

The main purpose of this specification is to verify that certain temporal properties hold, specifically:

- **Liveness/Safety of Changes**: The system should satisfy a property asserting that the boolean value is permitted to change over time (expressed as a temporal formula about state changes).

## Additional Verification Goals

I want to confirm that wrapping temporal formulas and specifications inside identity functions (functions that simply return their argument unchanged) does not alter their meaning or validity. Specifically:

- A property defined using a local identity function should be equivalent to the same property defined with a module-level identity function.
- A specification wrapped in an identity function should be equivalent to the unwrapped specification.

This serves as a test case for ensuring that definitional equivalence holds for temporal operators when used within function applications and local definitions.
