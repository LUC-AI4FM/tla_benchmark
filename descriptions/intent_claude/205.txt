# Specification Request: Fibonacci Sequence Computation Verification

## System to Model

A system that computes the Fibonacci sequence iteratively and verifies that the iterative computation produces correct results by comparing against the mathematically defined Fibonacci function.

## Goal

The purpose of this specification is to demonstrate equivalence between two methods of computing Fibonacci numbers:
1. An iterative approach that maintains running state and computes each successive Fibonacci number by adding the two previous values
2. A recursive mathematical definition of the Fibonacci sequence

This serves as a verification that the iterative algorithm correctly implements the Fibonacci sequence.

## Functional Requirements

- The system should step through the Fibonacci sequence one number at a time, starting from the beginning of the sequence
- At each step, the system should compute the next Fibonacci number using an iterative method that tracks the current and previous values
- The system should also have access to a recursive definition of Fibonacci that serves as the reference specification
- The computation should cover a bounded range of the sequence (e.g., the first 15 or so numbers)

## Correctness Properties

**Primary Invariant:** At every step of the computation, the iteratively computed Fibonacci value must equal the value given by the recursive mathematical definition for the same position in the sequence.

This invariant ensures that the iterative algorithm is a faithful implementation of the Fibonacci sequence as defined recursively.
