# Specification Request: Nested Function Update Consistency

## System Overview

I need a formal specification to verify the correctness of nested function update operations in a mathematical model. Specifically, this concerns how a system handles sequential modifications to function values, particularly when functions are indexed by other functions.

## What Should Be Modeled

The specification should model a scenario involving:

1. **Higher-order function structures**: Functions whose domain consists of other functions (i.e., functions indexed by function values)
2. **Sequential update operations**: Applying multiple "EXCEPT" style updates to these nested function structures, where each update modifies a specific point in the function
3. **Independent computation paths**: Both incremental updates (building on previous results) and from-scratch computation (recomputing the entire expression)

## Requirements

The system must handle the following:

- Define a base function mapping function-valued keys to initial values
- Apply a first update that modifies the value at one function-key
- Apply a second update to the result, modifying the value at a different function-key
- Compute the same final result through an independent, single-expression evaluation

## Key Correctness Property

**Update Independence**: The final state produced by applying sequential function updates must be identical to the result obtained by computing the equivalent nested update expression from scratch. 

In other words, the incremental approach (update A, then update B on the result) must yield exactly the same mathematical object as directly specifying both updates in a single composed expression. The system must ensure that intermediate representations do not interfere with subsequent updates—there should be no "corruption" or unintended sharing effects between the incrementally-built value and fresh computations.

## Goal

Verify that the implementation of function update operations maintains referential transparency and produces consistent results regardless of whether updates are applied incrementally or computed as a single expression.
