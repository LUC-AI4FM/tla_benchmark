# Specification Request: Basic TLA+ Module Validation

## System Description

I need a minimal TLA+ specification that serves as a basic validation or "hello world" test for the TLA+ tooling environment.

## Requirements

The specification should:

1. **Verify tooling setup**: Confirm that the TLA+ model checker (TLC) is properly installed and functioning by successfully loading and processing the specification.

2. **Demonstrate output capability**: Produce visible console output during model checking to confirm that diagnostic/debugging print functionality is operational.

## Correctness Properties

- The specification should be syntactically valid and processable by TLC
- Expected output messages should appear in the console when the specification is evaluated
- The specification should complete without errors

## Purpose

This is essentially a smoke test to verify that the TLA+ environment is correctly configured and that basic features like printing diagnostic messages work as expected before developing more complex specifications.
