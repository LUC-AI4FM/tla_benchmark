# Specification Request

I need a formal specification for the simplest possible stateful system that can serve as a test case or minimal example.

## System Description

Model a trivial system that:
- Maintains a single integer counter or state value
- Initializes to a fixed starting value (specifically, the value 1)
- Never changes its state after initialization (the system is completely static)

## Behavior Requirements

- The system should start in exactly one initial state
- All transitions should be stuttering steps—the state remains unchanged forever
- No interesting computation or state evolution occurs

## Correctness Properties

The specification should include an invariant that is **intentionally unsatisfiable** (always false). This creates a specification that will always fail model checking, which is useful for:
- Testing that a model checker correctly identifies invariant violations
- Reproducing bugs in verification tools
- Serving as a minimal failing test case

## Purpose

This appears to be a regression test or bug reproduction case for a verification tool, where the goal is to have a minimal specification that demonstrates some specific behavior (likely a bug) in the tooling rather than to model any real system.
