# Specification Request: Element Processing with Doubling Transformation

## System Overview

I need a formal specification for a simple set-processing system that takes elements from an input collection, processes them one at a time, and produces transformed outputs. The transformation doubles each input value.

## Functional Requirements

The system should:

1. **Initialize** with a non-trivial input set (containing more than 2 elements) drawn from a small integer range, with empty processed and output collections.

2. **Process elements** by repeatedly selecting an element from the input, moving it to a "completed" collection, and adding its doubled value to the output collection.

3. **Terminate gracefully** when no input elements remain, allowing the system to stutter (take no further meaningful action).

## Correctness Properties

The specification should demonstrate three levels of invariant checking:

### State Invariants
- **Valid property**: Elements that have been processed should never simultaneously appear in the pending input set (mutual exclusion between processed and unprocessed).
- **Example invalid property**: Claiming processed elements must be a subset of pending input (which becomes false as processing proceeds).

### Action Invariants (Transition Properties)
- **Valid property**: Either the input is empty, or exactly one element was added to the processed set during the transition.
- **Example invalid property**: Claiming the input set grows by one element each step (when it actually shrinks).

### Trace Invariants (Execution Properties)
- **Valid property**: Either processing is incomplete, or the final output set equals exactly the doubled values of the original input set.
- **Example invalid property**: Using an incorrect transformation factor (e.g., tripling instead of doubling) when relating initial input to final output.

## Purpose

This specification serves as a teaching example for understanding different kinds of invariants in formal verification—showing how to express and check properties about individual states, state transitions, and complete execution histories.
