# Specification Request: Binary Search Algorithm

## System Overview
I need a formal specification of the binary search algorithm, which is a fundamental searching technique used to find the position of a target value within a sorted sequence.

## Functional Requirements
The system should model the binary search process that:
- Operates on a sorted sequence of elements
- Searches for a specific target value within that sequence
- Repeatedly divides the search space in half by comparing the target to the middle element
- Terminates when either the target is found or the search space is exhausted

## Key Correctness Properties
The specification must guarantee:

1. **Termination**: The algorithm must always terminate, regardless of whether the target exists in the sequence

2. **Soundness**: If the algorithm reports finding the target at a particular position, the target must actually be at that position in the sequence

3. **Completeness**: If the target exists in the sequence, the algorithm must find it

4. **Search Space Invariant**: Throughout execution, if the target exists in the sequence, it must remain within the current search bounds

## Model Checking Considerations
For practical verification, the specification should support bounded model checking where:
- Sequences are limited to a configurable maximum length
- The element domain is finite to enable exhaustive state exploration

This allows verification of the algorithm's correctness properties across all possible sorted sequences up to the specified bounds.
