# Specification Request: Extended Operations for Finite Sets

## Overview

I need a library of utility operations for working with finite sets of values, particularly sets of integers. This library should provide common mathematical operations and set manipulations that go beyond the basic set operations, making it easier to write specifications that involve aggregations, selections, and set transformations.

## Required Operations

### Aggregation Operations

The library must support folding (reducing) a set of elements into a single value using a binary operation and a starting value. This fold operation should work correctly regardless of the order in which elements are processed (assuming the operation is commutative and associative for deterministic results).

Building on the fold capability, provide:
- **Sum**: Calculate the sum of all integers in a set
- **Product**: Calculate the product of all integers in a set
- **Map-then-sum**: Apply a projection function to each element, then sum the results (useful for summing a field across a set of records)

### Set Relationship Operations

- **Symmetric difference**: Given two sets, produce the set of elements that belong to exactly one of them (elements in either set but not in both)

### Counting and Selection Operations

- **Quantify**: Count how many elements in a set satisfy a given predicate, without explicitly constructing the intermediate filtered set
- **K-subsets**: Generate all subsets of a given set that have exactly k elements (useful for combinatorial problems)
- **Choose unique**: Select the single element from a set that satisfies a predicate, but fail if zero or more than one element matches (stricter than standard choice)

### Extrema Operations

- **Maximum**: Find the largest integer in a non-empty finite set
- **Minimum**: Find the smallest integer in a non-empty finite set

### Set Combination Operations

- **Flatten**: Combine a set of sets into a single set containing all elements (union of all member sets)
- **Choices**: Given a collection of sets, generate all possible sets formed by choosing exactly one element from each input set (related to Cartesian product, but producing sets rather than tuples)

## Correctness Requirements

1. All operations must work correctly on finite sets
2. The sum of an empty set should be 0; the product of an empty set should be 1
3. Symmetric difference must be commutative
4. The unique choice operator must only succeed when exactly one element satisfies the predicate
5. K-subsets of a set S where k is outside the valid range (0 to |S|) should return the empty set
6. Maximum and minimum operations assume non-empty input sets

## Design Goals

- Operations should be defined mathematically in a way suitable for formal reasoning
- Where possible, implementations should avoid unnecessary enumeration of large intermediate sets (this is a performance consideration for tooling, not a correctness requirement)
- Provide backward-compatible aliases where naming conventions have changed
