# Specification Request: Function Domain Subset Membership Verification

## System Overview
I need a formal specification to verify the behavior of function set membership when a function's domain is a proper subset of another domain used in a function set definition.

## Goal
The specification should model and verify whether a function defined over a smaller domain is considered a member of a set of functions defined over a larger domain.

## Key Verification Property
The system must check the following correctness property:
- Given a function that maps from a subset (e.g., a single-element set) to some codomain
- And a set of all functions from a larger superset to the same codomain
- Determine whether the function with the smaller domain is considered an element of that function set

## Requirements
1. The specification should be minimal—no complex state transitions are needed
2. The focus is purely on verifying set-theoretic properties of functions
3. The invariant should capture the membership relationship between a concretely-defined function and a function space with a different (larger) domain

## Purpose
This specification appears designed to test or demonstrate how a model checker handles function set membership when domains don't exactly match—specifically whether `[A -> B]` only contains functions with domain exactly `A`, or could include functions with smaller domains.
