# Specification Request: Set Cardinality via Recursive Definition

## System Overview

I need a formal specification that demonstrates how to define a recursive mathematical function—specifically set cardinality (counting elements)—without using explicit recursive syntax. This serves as an illustration of a technique for defining recursive functions using implicit characterization.

## Goal

The primary goal is to define a cardinality function that counts the number of elements in a finite set, where the function is specified implicitly by describing the properties it must satisfy rather than through direct recursive definition.

## Functional Requirements

1. **Cardinality Function**: Define a function that computes the size of any finite set of integers by:
   - Returning 0 for the empty set
   - Returning 1 plus the cardinality of the remaining set when any single element is removed

2. **Dynamic Set Construction**: Model a simple system where:
   - A set starts empty with a counter at zero
   - Elements can be added to the set one at a time (from some bounded domain)
   - A counter tracks how many elements have been added

## Correctness Properties

The specification must guarantee the following invariant:

- **Cardinality Consistency**: The recursively-defined cardinality function, when applied to the current set, must always equal the running count of elements that have been added.

## Additional Context

This specification explores an alternative technique for defining recursive functions that may be useful in contexts where explicit recursion syntax is problematic or unavailable. The approach characterizes the desired function by its properties and uses choice to select a function satisfying those properties.
