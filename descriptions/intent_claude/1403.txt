# Specification Request

I need a formal specification for an extremely simple static system that never changes state.

## System Description

The system consists of a single state component that is initialized to zero and remains constant forever. There is no actual behavior or state transitions—the system simply maintains its initial state indefinitely.

## Requirements

1. **Initialization**: The system must start with its state set to zero.

2. **Behavior**: The system must never change—it should remain in its initial state for all time.

## Correctness Properties

The key property to verify is an **enabledness condition**: it must always be possible (from any reachable state) to take a step that would set the state to zero. This property tests whether a particular form of temporal logic expression involving potential future states is consistently satisfiable.

## Purpose

This specification appears designed to test or demonstrate how a formal verification tool handles a specific syntactic pattern—namely, checking whether certain actions are enabled when the expression describing the action uses a local definition to refer to the next-state value. The actual system logic is trivial; the interest lies in verifying the tool correctly evaluates the enabledness predicate under this particular expression structure.
