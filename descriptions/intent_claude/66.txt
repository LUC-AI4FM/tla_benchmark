# Specification Request

## System Description

I need a formal specification for a simple nondeterministic integer assignment system. The system manages a single integer value that can be set to any value within a fixed range.

## Behavior Requirements

1. **Initial State**: The system should start with the integer value initialized to zero.

2. **Transitions**: At each step, the system should be able to nondeterministically set the integer to any value from 0 through 19 (inclusive). Each possible assignment should be available as a distinct transition option.

3. **Bounded Range**: The integer value must always remain within the range [0, 19].

## Purpose

This specification appears to be a test case or stress test for tooling, particularly to verify that tools can handle specifications with many separately-defined transition options that have verbose naming conventions. The focus is on ensuring the model checker or other TLA+ tools correctly process a large disjunction of transitions.

## Correctness Properties

- **Type Safety**: The integer value should always be a valid integer within the expected bounded range.
- **Reachability**: All values in the range 0-19 should be reachable from the initial state in a single step.
