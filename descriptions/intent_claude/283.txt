# Specification Request

## System Description

I need a formal specification to test the behavior of state preservation (unchanged expressions) in a model checking context, specifically for regression testing purposes related to how a model checker handles unchanged expressions.

## What Should Be Modeled

A minimal stateful system consisting of:
- A function/array that maps indices to integer values
- An index variable pointing to a position in that function
- A constant parameter defining some bound

## Required Behavior

1. **Initialization**: The system should start with:
   - A function initialized over a small fixed domain where each element is double its index
   - An index variable set to a specific valid position
   - A constant parameter set to a small positive integer

2. **Transitions**: After initialization, the system should remain completely static—no state changes should occur. This includes:
   - The entire function remaining unchanged
   - The index variable remaining unchanged
   - Specific indexed lookups (like accessing the function at the current index position) remaining unchanged
   - The constant parameter remaining unchanged

## Key Correctness Properties

The specification should verify that when multiple forms of "unchanged" expressions are combined—including unchanged variables, unchanged data structures, unchanged expressions involving lookups into those structures, and unchanged constants—the model checker correctly handles them all simultaneously without errors or inconsistencies.

## Purpose

This is a regression test specification to ensure that a model checker properly processes unchanged expressions in various forms, particularly when they involve redundant or overlapping references to the same underlying state components.
