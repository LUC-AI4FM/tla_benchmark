Write a formal specification for computing values in Pascal's triangle using a recursive mathematical definition.

**System Overview:**
The specification should model Pascal's triangle, the classical number triangle where each entry is the sum of the two entries directly above it. The goal is to define this triangle as a recursive mathematical function and verify that it produces correct binomial coefficient values.

**Requirements:**

1. **Recursive Definition:** Define Pascal's triangle entries using the fundamental recurrence relation: each entry equals the sum of the entry directly above-left plus the entry directly above in the triangle.

2. **Base Cases:** Handle the boundary conditions appropriately:
   - Entries at the edges of the triangle (where the position index equals zero or equals the row number) should evaluate to 1
   - Entries outside the valid triangle region should be handled consistently

3. **Domain:** The function should be defined over a bounded range of row and position indices (e.g., rows 0 through some maximum N).

4. **Correctness Property:** The specification should verify that specific computed values match their expected mathematical results. For example, the entry at row 4, position 2 should equal 6 (corresponding to "4 choose 2" = 6).

**Purpose:**
This specification serves as a test case for expressing and evaluating recursive functions with multiple arguments in the specification language, while also demonstrating that the recursive definition correctly computes binomial coefficients.
