# Specification Request: Bitwise AND Operation for Natural Numbers

## Overview

I need a TLA+ module that provides a bitwise AND operation for non-negative integers. This is a utility module intended to be used by other specifications that require bit-level manipulation of integer values.

## Goal

The module should define a bitwise AND operator that takes two non-negative integers and returns their bitwise conjunction—that is, the integer whose binary representation has a 1 in each bit position where both input numbers have a 1, and 0 elsewhere.

## Requirements

1. **Infix operator**: The bitwise AND should be available as an infix operator (similar to how arithmetic operators like `+` work) for readability in specifications that use it.

2. **Mathematical definition**: The operation must be defined purely in terms of mathematical operations (division, modulo, exponentiation, multiplication, addition) so that it has a clear mathematical meaning independent of any programming language's bit representation.

3. **Performance override**: Since a pure mathematical/recursive definition may be slow for model checking, the module should support being overridden by a compiled Java implementation for efficient execution in TLC. The specification should be structured so that TLC can load a Java class that provides a native implementation.

4. **Correctness**: For any two non-negative integers x and y, the result should equal the standard bitwise AND as defined in computer science—examining each bit position and returning 1 only where both inputs have 1.

## Context

This module is intended as a reusable library component. Other specifications (such as puzzle solvers or algorithms that use bit manipulation for compact state representation) should be able to import this module and use the bitwise AND operator directly in their expressions.
