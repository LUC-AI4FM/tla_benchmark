# Specification Request: Nested Macro Expansion with Variable Assignment

## System Overview

I need a formal specification for a simple concurrent system that tests the correct behavior of nested procedural abstractions (like macros or inline procedures) when they modify both local and shared state.

## What the System Should Model

The system consists of multiple concurrent processes (at least two) that each perform a sequence of variable assignments through nested procedure calls. The key aspect is that these procedures can be nested multiple levels deep, where:

- An outer procedure calls an inner procedure
- The inner procedure may call yet another procedure
- Each level can modify different variables (both process-local and globally shared)

## Behavioral Requirements

1. **Sequential Execution Within a Process**: Each process should execute its operations in a defined order, with clear synchronization points.

2. **Nested Procedure Semantics**: When a procedure is invoked, it should:
   - Be able to call other procedures
   - Correctly pass parameters through multiple nesting levels
   - Properly assign values to variables at each level

3. **Mixed Variable Scope Handling**: The system must correctly handle:
   - Process-local variables that are private to each process
   - Global variables that are shared across all processes

4. **Atomic Compound Operations**: A sequence of nested procedure calls should execute atomically within a single step when appropriate, ensuring that all variable assignments from the nested calls complete together.

## Correctness Properties

1. **Termination**: All processes must eventually complete their execution.

2. **Post-Condition Correctness**: After executing the nested procedure calls, specific conditions must hold:
   - Local variables must contain the values assigned by inner procedures
   - Shared variables must reflect the assignments made by the procedures
   
3. **Parameter Passing Integrity**: Values passed through nested procedure calls must arrive correctly at their destination assignments.

## Purpose

This specification serves to verify that a system correctly implements nested procedural abstraction with proper variable scoping and parameter passing in a concurrent setting.
