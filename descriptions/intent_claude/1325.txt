Please write a formal specification for a token-based termination detection algorithm in a ring network.

**System Description:**
Model a distributed system where N processes are arranged in a logical ring topology. The goal is to detect when all processes have terminated their work (become "passive") and no messages are in transit. A single token circulates around the ring to help detect this global termination condition.

**Key Requirements:**

1. Processes can be either active (doing work) or passive (idle/terminated)
2. Active processes may send messages to other processes, which can reactivate passive processes
3. A token travels around the ring, collecting information about the state of the system
4. The algorithm must correctly detect when termination has occurred globally

**Correctness Properties:**

- **Safety:** The algorithm must never incorrectly announce termination while any process is still active or while messages are still in transit
- **Liveness:** If all processes eventually become passive and remain passive, the algorithm must eventually detect termination

**Additional Constraints:**
The specification should be parameterized by the number of processes N (test with N=2). Include mechanisms to ensure the model checker can verify both safety invariants and liveness properties.
