# Specification Request: Set Fold Operation Verification

## System Description

I need a formal specification to verify the correctness of a **fold (reduce) operation over sets**. Specifically, I want to confirm that folding a union operation across a set of integers, starting from an initial accumulator set, produces the expected combined result.

## Goal

The specification should demonstrate and verify that:

1. A fold operation that accumulates elements by set union works correctly
2. When folding over a set of integers using union as the combining operation, the result is the union of the initial accumulator with all elements from the input set
3. The operation correctly handles the inherent properties of sets (duplicate elements are naturally eliminated)

## Key Correctness Properties

The specification must verify this invariant:

- Folding a union operation over the set {1, 2, 3}, starting with initial set {4}, produces exactly the set {1, 2, 3, 4}

## Requirements

- The fold operation should take a binary combining function, an initial value (seed set), and an input set to fold over
- The combining function unites the accumulator set with each element from the input set (wrapping the element as a singleton)
- The system should be stateless with respect to the fold verification—the property is essentially a static check that the fold operator behaves as expected

## Context

This is a verification of a set-based fold primitive, likely testing a model checker's built-in fold functionality to ensure it handles set semantics correctly (idempotence of duplicate elements, proper accumulation via union).
