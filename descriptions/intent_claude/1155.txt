# Specification Request: Model Checker Performance Testing System

## Overview

I need a formal specification for a simple state-space exploration system designed to stress-test and benchmark a TLA+ model checker. The system should generate a configurable and predictable state space with tunable computational complexity.

## System Description

The system consists of an array of counters that cycle through values, combined with mechanisms to control:
- The total number of reachable states
- The computational cost of evaluating each transition
- The number of independent initial configurations

## Requirements

### Core Behavior
- Maintain a collection of counter variables indexed by a fixed domain
- Each counter should cycle through a range of values (wrapping around to zero after reaching a maximum)
- On each step, exactly one counter is non-deterministically selected and incremented
- Support multiple independent starting configurations that create disjoint portions of the state graph

### Configurability Parameters
The specification must support tuning:
1. **State space width**: The number of counters in the array
2. **State space depth**: The range of values each counter can hold (determines total distinct states)
3. **Evaluation cost**: A mechanism to make each transition evaluation computationally expensive in a controlled way (exponential in a parameter)
4. **Initial state multiplicity**: The number of distinct initial states, creating isomorphic but separate subgraphs

### Computational Complexity Control
Include a mechanism that forces the model checker to perform expensive set computations during transition evaluation. Specifically, the system should be able to trigger power set enumeration over a configurable set size, making single-state computation time grow exponentially with a parameter.

## Correctness Properties

### Safety Property
All counter values must remain within their valid range—no counter should ever hold a value equal to or exceeding the configured maximum.

## Purpose

This specification serves as a benchmarking tool for model checker implementations, allowing systematic measurement of:
- State generation throughput
- Memory usage scaling
- Performance characteristics under varying computational loads per transition
