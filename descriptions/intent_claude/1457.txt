Write a TLA+ specification that demonstrates a simple two-variable system that intentionally reaches a deadlock. The system tracks a natural number counter and a boolean flag, both starting at initial values of zero and false respectively. On each step, the counter increments by one and the boolean toggles, but transitions are only enabled while the counter remains within a bounded range. Once the counter exceeds that bound, no further steps are possible and the system deadlocks. The specification should use a standard temporal spec with stuttering tolerance. The configuration should check the specification without any invariants or properties, so that a model checker will detect and report the deadlock condition. This module is intended as a test or demonstration artifact for exercising trace exploration or deadlock detection tooling, not as a model of a real system.
