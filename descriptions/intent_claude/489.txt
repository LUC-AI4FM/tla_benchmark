Please write a formal specification for a simple state machine system with the following characteristics:

**System Overview:**
A system that tracks several state variables, some of which are updated according to fixed rules while others remain unchanged during transitions.

**Behavior Requirements:**

1. The system should initialize with a specific starting state for at least one tracked variable.

2. When the system takes a step, it should:
   - Set certain variables to fixed constant values
   - Set one variable based on a comparison/equality check between two system parameters
   - Select one variable's value non-deterministically from a defined set of possible parameter values
   - Leave a subset of variables completely unchanged across transitions

3. The system has external parameters that influence its behavior but are not modified during execution.

**Correctness Properties:**

The specification should allow stuttering steps (steps where the key observable variables don't change), meaning the system doesn't have to continuously make progress. The liveness or safety properties should focus on a subset of the state variables rather than requiring all variables to participate in every meaningful transition.

**Additional Context:**
This appears to be a basic specification pattern demonstrating how to combine deterministic assignments, boolean expressions, non-deterministic choice, unchanged variables, and stuttering in a single transition system.
