# Specification Request: Cartesian Product Operator Validation

## Goal

Create a test harness to verify the correctness of the Cartesian product operator (`\X`) in a TLA+ model checker implementation. The purpose is to ensure that the tool correctly handles Cartesian products across a variety of use cases.

## System Description

This is a validation suite for the Cartesian product operation on sets. The tests should confirm that the model checker properly computes and reasons about:

1. **Basic Cartesian products** of finite sets, producing the expected set of tuples
2. **Cartesian products involving infinite sets** (like natural numbers and integers), particularly for function definitions and membership tests
3. **Higher-arity Cartesian products** (three or more sets), ensuring tuples are flattened appropriately rather than nested
4. **Membership testing** for tuples against Cartesian product sets
5. **Interactions with other set operations**, including:
   - Intersection of Cartesian products with function spaces
   - Subset relationships involving Cartesian products
6. **Function definitions over Cartesian product domains**, verifying correct tuple indexing and evaluation

## Correctness Properties

The test suite must verify:

- A two-set Cartesian product yields all ordered pairs with first element from the first set and second from the second set
- Cartesian products of three or more sets produce flat tuples (not nested pairs)
- Functions defined over Cartesian product domains can be correctly indexed using tuple notation
- Tuple membership in Cartesian products (both finite and infinite) is correctly determined
- The intersection of a function space with a Cartesian product computes correctly
- Subset membership for sets of tuples against powersets of Cartesian products is properly evaluated

## Requirements

All test cases must pass. If any expected equality or membership relationship fails to hold, the system should halt with an assertion failure identifying which test failed.
