Write a TLA+ specification for a simple monotonically growing set that accumulates data elements over time. The system starts with an empty set and at each step nondeterministically adds one element drawn from a fixed finite universe of data values. The set never shrinks — elements can only be added, never removed. The specification should model this accumulation behavior for a small, concrete set of data values (two is sufficient). No temporal properties or invariants need to be checked; the goal is simply to capture the state space of a growing set, suitable as a minimal reproducible example or test case for a model checker.
