# Specification Request: Nondeterministic Choice with Consistent Outcome

## System Overview

I need a formal specification of a simple sequential process that makes a nondeterministic choice between two alternative execution paths, where each path performs equivalent work but on different resources.

## Behavior Description

The system should:

1. **Start** with two counters, both initialized to zero.

2. **Make a nondeterministic choice** between two mutually exclusive paths:
   - **Path A**: Increment the first counter twice (first setting it to 1, then incrementing it to 2)
   - **Path B**: Increment the second counter twice (first setting it to 1, then incrementing it to 2)

3. **Complete** after finishing whichever path was chosen.

The increments in each path should happen in two distinct steps (not atomically combined), representing a multi-step operation.

## Key Correctness Properties

1. **Deterministic Final Sum**: Regardless of which path is chosen nondeterministically, the sum of both counters must equal exactly 2 upon completion. This verifies that both branches produce equivalent observable outcomes.

2. **Termination**: The process must always eventually terminate—it should not deadlock or run forever.

3. **Mutual Exclusion of Paths**: Only one path should be executed; the other counter should remain at zero throughout execution.

## Purpose

This specification tests that nondeterministic branching with symmetric alternatives produces consistent, predictable results. It serves as a verification that regardless of which branch the system "chooses," the final state satisfies the same invariant about the total work completed.
