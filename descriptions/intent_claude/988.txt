# Specification Request: Non-Blocking Atomic Commitment Protocol

## System to Model

I need a formal specification of a **non-blocking atomic commitment protocol** for distributed transaction processing. This protocol coordinates a set of participants to reach a unanimous decision on whether to commit or abort a distributed transaction.

## System Description

The system involves multiple distributed participants that must collectively decide the outcome of a transaction. Each participant has a local vote (whether it can commit) and must eventually reach a decision that is consistent with all other participants. The protocol must be "non-blocking," meaning participants can reach a decision without waiting indefinitely for failed or slow participants.

## Key Requirements

1. **Agreement**: All participants that reach a decision must decide on the same outcome—either all commit or all abort.

2. **Validity**: 
   - If all participants vote to commit and there are no failures, the decision should be to commit
   - If any participant votes to abort, the final decision must be abort

3. **Termination**: Every non-failed participant must eventually reach a decision (non-blocking property)

4. **Decision Stability**: Once a participant has decided to commit or abort, that decision cannot be changed—decisions are irrevocable

## Correctness Properties

The specification must guarantee:

- **Safety**: No two participants ever decide differently
- **Irrevocability**: A commit decision remains commit forever; an abort decision remains abort forever
- **Consistency with votes**: The commit decision is only possible if all participants were willing to commit

## Additional Considerations

The specification should be suitable for model checking with a finite set of participants, and should exploit symmetry among participants to reduce the state space during verification.
