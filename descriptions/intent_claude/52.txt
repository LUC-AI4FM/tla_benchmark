# Specification Request

## System Description

I need a formal specification for a simple system that models a bounded time or value range defined by two constant parameters representing minimum and maximum bounds.

## Requirements

The system should:

1. Define two constant parameters representing a minimum and maximum value (both integers)
2. Establish that these constants form a valid range where the minimum does not exceed the maximum
3. The system itself has trivial behavior—it can start in any state and take any step—as the focus is entirely on the constant constraints

## Correctness Properties

The specification must guarantee:

1. **Range validity**: The minimum bound must always be less than or equal to the maximum bound

## Purpose

This specification is intended as a minimal test case to verify that constant initialization constraints are properly propagated during model checking. The key concern is ensuring that when constants are initialized with specific constraints (like maintaining a valid min/max relationship), those constraints are respected when checking invariants throughout the model.
