# Specification Request: Binary Search Algorithm

## System to Model

I need a formal specification of the classic binary search algorithm that searches for a key within a sorted sequence of integers.

## Functional Requirements

The algorithm should:

1. Accept a sorted sequence of integers and a target key to search for
2. Maintain a search interval that progressively narrows to locate the key
3. Return an indication of whether the key was found, and if so, its position; if not found, return information about where the key would be inserted to maintain sorted order (typically encoded as a negative value based on the insertion point)
4. Terminate in all cases

## Constraints

The specification should account for bounded machine integers with a configurable bit-width. This means:
- All intermediate calculations must respect signed integer bounds
- The representation should capture both the maximum and minimum representable integer values
- The algorithm must avoid integer overflow during index calculations (a well-known bug in naive binary search implementations)

## Key Correctness Properties

1. **Termination**: The algorithm must always terminate after a finite number of steps
2. **Correctness on found**: If the key exists in the sequence, the algorithm must return its index
3. **Correctness on not found**: If the key does not exist, the algorithm must return an appropriate indicator (such as a negative encoding of the insertion point)
4. **Interval invariant**: Throughout execution, if the key exists in the sequence, it must remain within the current search interval
5. **Progress**: Each iteration must strictly reduce the size of the search interval

## Notes

This is intended as an incremental, tutorial-style specification. The current phase establishes the algorithm's structure and handles the base case where the search interval becomes empty (key not found). The core loop logic for narrowing the search interval remains to be specified in subsequent versions.
