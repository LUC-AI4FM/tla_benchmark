# Specification Request: Hour Clock System

## System Description

I need a formal specification for a simple hour clock that tracks the current hour in a 12-hour format. The clock should model time progression where the hour advances cyclically through valid hour values.

## Behavioral Requirements

The clock must:
- Start in a valid hour state (representing hours 1 through 12)
- Progress through hours in sequence, wrapping from 12 back to 1
- Only allow valid hour transitions (either staying the same or advancing to the next hour)

## Correctness Properties

The key property that must be proven is **invariance of valid hour values**: once the clock starts with a valid hour, it must always display a valid hour. The system should never enter a state where the displayed hour is outside the valid range of 1 to 12.

This invariant must hold:
- In the initial state
- After any sequence of clock transitions
- For all possible behaviors of the system

## Verification Goal

Provide a machine-checked proof that the hour validity property is indeed an invariant of the clock specification. The proof should demonstrate that starting from any valid initial state, all possible executions of the clock maintain valid hour values forever.
