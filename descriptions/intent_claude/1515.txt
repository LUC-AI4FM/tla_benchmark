# Specification Request

I need a formal specification for a simple bounded counter or state machine system.

## System Description

The system maintains a single numeric state that starts within a small initial range and can transition to values within a bounded interval. The system should model non-deterministic state changes where the next state is chosen from a set of possible values rather than being deterministically computed.

## Requirements

1. **Initialization**: The system should start in one of two possible initial states (either 0 or 1).

2. **State Transitions**: While the current state is below a threshold (10), the system may transition to any value within a fixed range (1 through 9). The choice of next state within this range is non-deterministic.

3. **Termination Condition**: Once the state reaches or exceeds the threshold, no further transitions should occur (the system stutters or halts).

## Key Properties

- The state should always remain bounded within reasonable limits
- The system should be able to make progress from its initial state
- Transitions should only occur when the enabling condition (state below threshold) is met

## Purpose

This appears to be a debugging or teaching example to explore non-deterministic state transitions and understand how model checkers enumerate possible behaviors when multiple next-states are valid.
