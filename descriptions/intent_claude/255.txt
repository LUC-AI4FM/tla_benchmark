# Specification Request: Extended Finite Set Operations Library

## Goal

Create a formal specification that defines and validates a collection of utility operations for working with finite sets. These operations extend the basic set operations to include commonly needed functionality for counting, folding, selecting, and computing differences between sets.

## System Description

The specification should define a library of pure mathematical operators over finite sets, including:

1. **Counting elements matching a predicate**: Given a set and a boolean predicate, count how many elements satisfy that predicate.

2. **Subsets of fixed size**: Given a non-negative integer k and a set S, produce all subsets of S that have exactly k elements.

3. **Folding/reducing over sets**: Apply a binary combining function across all elements of a set, starting from an initial value, to produce a single result (like summing all elements).

4. **Unique element selection**: Given a set and a predicate that exactly one element satisfies, return that unique element.

5. **Symmetric difference**: Compute elements that belong to exactly one of two sets (in either but not both).

6. **Numeric aggregations**: Compute the sum and product of all elements in a set of numbers.

## Requirements

- The counting operation must return the same result as computing the cardinality of the filtered subset.
- The fixed-size subset operation must return an empty collection when k is negative or exceeds the set's size.
- The fixed-size subset operation must return exactly those subsets whose cardinality equals k.
- The fold operation must correctly handle sets with duplicate-free semantics and produce mathematically correct aggregations.
- The symmetric difference must be commutative and handle empty sets correctly.
- The unique selection operation should work when exactly one element matches the given predicate.

## Correctness Properties

- All operations must produce results equivalent to their pure mathematical definitions using basic set comprehension and cardinality.
- The fixed-size subset operator must be consistent with filtering the powerset by cardinality.
- Numeric operations (sum, product) must produce correct arithmetic results for integer ranges.
- Operations must handle edge cases including empty sets, single-element sets, and boundary conditions on size parameters.
