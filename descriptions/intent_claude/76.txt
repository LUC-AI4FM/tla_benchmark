# Specification Request: Record Field Access Error Detection

## Overview
I need a formal specification that demonstrates and verifies the behavior of accessing a non-existent field on a record data structure.

## System Description
The system should model a simple scenario involving record (struct-like) data structures where an attempt is made to access a field that does not exist in the record's definition.

## Requirements
1. Define a record with a specific set of fields
2. Attempt to access a field name that was not defined in the record
3. The specification should help verify how the model checker handles undefined field access

## Correctness Properties
The key goal is to observe and document the behavior when:
- A record is created with certain fields
- Code attempts to read a field that is not part of that record's schema

This specification serves as a test case for tooling behavior around type safety and record field validation, specifically to capture edge cases or potential bugs in how such invalid accesses are processed.
