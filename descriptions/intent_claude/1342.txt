# Specification Request

I need a formal specification for the simplest possible system: a static, unchanging state.

## System Description

Model a system that initializes to a known starting state and then remains completely frozen—no transitions, no changes, no activity whatsoever. Think of it as a baseline "do nothing" system or a placeholder specification.

## Requirements

1. **Initialization**: The system should start in a well-defined initial state (e.g., a single counter or clock value set to zero).

2. **Behavior**: After initialization, the system must exhibit no changes. It should allow only stuttering steps where nothing happens.

## Correctness Properties

- The system state must remain constant for all time after initialization.
- The initial value must never change throughout any execution.

## Purpose

This serves as a minimal template or baseline specification—useful for testing tooling, demonstrating the simplest valid TLA+ structure, or as a starting point to extend with actual behavior.
