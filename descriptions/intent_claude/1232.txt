Write a specification that tests string handling capabilities in TLA+, specifically verifying that strings can be treated as sequences.

The specification should confirm the following behaviors:

1. **String concatenation**: The system must verify that concatenating two strings produces the expected combined result (e.g., joining "abc" and "def" yields "abcdef").

2. **String length**: The system must correctly compute the length of strings, counting individual characters.

3. **Escape sequence handling**: The system must properly handle escape sequences within strings, including:
   - Backslash characters
   - Quote characters
   - Newline characters
   
   The length calculation must count escape sequences as single characters (not as their multi-character representations in source code).

4. **Concatenation with escape sequences**: String concatenation must work correctly even when strings contain escape sequences, and the result should be equivalent to a single string literal containing the same characters.

The key correctness properties are:
- String concatenation must be associative and produce predictable results
- The length operator must return the actual number of characters in a string, treating escape sequences as single characters
- Strings with escape sequences must be equal to equivalent concatenated forms
