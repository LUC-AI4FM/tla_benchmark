# Specification Request: Integer Square Computation by Successive Odd Numbers

## System Overview

I need a formal specification of an algorithm that computes the square of a non-negative integer using only addition. The algorithm should be based on the mathematical property that any perfect square can be expressed as the sum of the first n odd numbers (1 + 3 + 5 + ... + (2n-1) = n²).

## Functional Requirements

The system should:

1. Accept any non-negative integer as input from a defined set of valid inputs
2. Compute the square of that integer through an iterative process
3. Build up the result by successively adding odd numbers (1, then 3, then 5, etc.)
4. Terminate after exactly n iterations, where n is the input value

## Correctness Properties

The specification must guarantee:

1. **Termination**: The algorithm must eventually complete for any valid input
2. **Partial Correctness**: Upon termination, the computed result must equal the square of the input value (result = n²)
3. **Loop Invariant**: At each step of the iteration, the accumulated sum should equal the square of the number of iterations completed so far

## Input Constraints

- The input set must consist only of natural numbers (non-negative integers)
- The algorithm should work correctly for any value from this input set, including zero

## Purpose

This specification serves as a verification exercise to formally prove that the sum-of-odd-numbers method correctly computes squares, demonstrating how TLA+ can verify mathematical algorithms through model checking.
