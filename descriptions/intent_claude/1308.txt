Please write a formal specification for a **module extension and operator redefinition system**.

The goal is to model a layered specification architecture where:

1. **A base module** defines a simple boolean state machine with:
   - A boolean variable that starts as false
   - A basic logical operator (negation)
   - Multiple transition options: either applying the operator to update state, or resetting to false
   - Transitions can be parameterized by values from a finite set

2. **An extending module** that imports and wraps the base module to:
   - Add additional initialization constraints while preserving the base initialization
   - Restrict which transitions from the base module are permitted (filtering out certain parameterized actions)
   - Wrap base operators with additional behavior (such as logging/tracing) while still invoking the original
   - Support higher-order operator patterns where operators can be passed as arguments
   - Strengthen invariants by combining base invariants with additional constraints

**Key requirements:**

- The extension mechanism must allow selective restriction of the base system's behavior
- Wrapped operators should be able to execute additional logic (like debug output) before or alongside the original operation
- The system should support parameterized operators that can accept other operators as arguments
- Extended invariants must logically imply the base invariants (strengthening, not weakening)

**Correctness properties:**

- The extended system's behaviors should be a subset of (or equal to) the base system's behaviors
- The strengthened invariant must hold in all reachable states of the extended system
- The boolean state variable must always remain within its declared type
