# Specification Request: Function Properties and Operations Library

## System Overview

I need a formal specification of a mathematical library for reasoning about functions (mappings) between sets. This library should provide fundamental operations on functions and predicates for classifying functions according to their mathematical properties.

## Required Capabilities

### Function Manipulation Operations

The library must support:

1. **Domain restriction**: Given a function and a set, produce a new function whose domain is limited to that set while preserving the original mappings.

2. **Filtered restriction**: Restrict a function's domain based on a predicate applied either to domain elements or to the corresponding range values (similar to a "filter" operation in functional programming).

3. **Restriction checking**: Determine whether one function is a restriction of another—that is, whether the first function agrees with the second on all elements of its (smaller) domain.

4. **Range computation**: Compute the set of all values that a function maps to.

5. **Pointwise combination**: Given two functions with compatible domains and a binary operator, produce a new function by applying the operator element-wise to corresponding values.

6. **Function inversion**: Construct an inverse mapping from range elements back to domain elements.

### Function Classification Predicates

The library must define predicates and set constructors for:

1. **Injectivity (one-to-one)**: A function where distinct domain elements always map to distinct range elements.

2. **Surjectivity (onto)**: A function where every element in the target set is mapped to by some domain element.

3. **Bijectivity (one-to-one correspondence)**: Functions that are both injective and surjective.

4. **Existence tests**: Predicates to determine whether an injection, surjection, or bijection exists between two given sets.

### Aggregation Operations

The library must support folding/reducing over function values:

1. **Fold over subset**: Combine function values for a specified subset of the domain using an associative, commutative binary operator.

2. **Fold over entire domain**: Combine all function values using such an operator.

3. **Summation**: Specialized operations to sum numeric function values over all or part of the domain.

## Key Correctness Properties

- Restriction operations must preserve the original function's behavior on the restricted domain
- Inverse functions must correctly reverse the original mapping (for bijections)
- The sets of injections, surjections, and bijections must contain exactly those functions satisfying the respective mathematical definitions
- Fold operations must correctly aggregate values regardless of the order in which elements are processed (given associativity and commutativity of the operator)
