Specify a TLA+ model of the Quicksort algorithm operating on an array of integers. The system begins with an arbitrary array of length N (where N is a positive natural number) whose values are drawn from 1..N. Sorting proceeds by maintaining a set of index-interval pairs that still need to be partitioned. On each step, one unsorted interval is chosen nondeterministically: if the interval contains more than one element, a pivot index within it is chosen nondeterministically and the subarray is rearranged (nondeterministically among all valid rearrangements) so that every element to the left of the pivot is no greater than every element to the right, while elements outside the interval are unchanged; the interval is then replaced by the two sub-intervals on either side of the pivot. If an interval has length one or zero, it is simply removed. The algorithm terminates when no intervals remain. The key correctness property to verify is liveness: the algorithm must always eventually terminate. A permutation helper should be used to characterize valid rearrangements of the array during partitioning.
