# Specification Request: Utility Operators for Function Folding and Bounded Sequences

## System Overview

I need a TLA+ specification that defines and validates reusable utility operators for working with functions and sequences. This is essentially a test harness to verify that certain helper operators behave correctly.

## Required Utility Operators

### 1. Fold/Reduce Operation Over Functions

I need an operator that takes any function (including sequences, which are functions from indices), a binary combining operation, and an identity element, then reduces all values in the function's range down to a single result by applying the binary operation repeatedly.

**Requirements:**
- Must work with functions of any finite domain (not just sequences)
- Must work with sequences (which have integer domains starting at 1)
- Must return the identity element when given an empty function or sequence
- Must correctly combine all values regardless of the order they are processed

### 2. Bounded Sequence Set Constructor

I need an operator that generates the set of all sequences over a given element set, where the sequence length is bounded by a maximum.

**Requirements:**
- Must include sequences of all lengths from 0 up to and including the specified bound
- Must include the empty sequence
- Must only contain sequences whose elements are drawn from the specified set
- Must not include sequences longer than the bound

## Correctness Properties to Verify

The specification should validate the following behaviors:

**For the fold operation:**
- Multiplying three values of 3 together yields 27
- Summing the sequence 3, 4, 5, 6 yields 18
- Summing a single-element sequence returns that element
- Folding over an empty sequence returns the identity element

**For bounded sequences:**
- Short sequences within bounds are included in the set
- Sequences exceeding the length bound are excluded
- Sequences containing elements outside the element set are excluded
- The empty sequence is always included (when bound ≥ 0)
- All sequences in the set respect the length bound

**For sequence sorting (using a standard library sort):**
- Sorting with ≤ produces non-decreasing order
- Sorting with < also produces a valid sorted sequence
- Sorting an empty sequence returns empty
- Sorting a single-element sequence returns that element

## Purpose

This specification serves as a unit test suite to ensure these utility operators are correctly implemented and can be relied upon in larger specifications.
