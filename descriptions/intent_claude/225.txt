# Specification Request: Simple State Transition System for Symbolic Analysis Testing

## System Overview

I need a formal specification of a minimal state machine that can be used to test symbolic transition slicing capabilities in a model checker or verification tool.

## System Description

The system should model a simple process that:

1. Starts in an initial state
2. Can transition to one of two possible destination states through different actions
3. One transition is deterministic (a simple state change)
4. The other transition involves a non-deterministic choice from a small finite set, even though the choice doesn't affect the resulting state

## Behavioral Requirements

- The system must begin in a designated starting state
- From any state, the system can move to either of two target states
- One of the transitions should include existential quantification over a small set of values, creating multiple symbolic paths that lead to the same outcome

## Correctness Property

The specification should include an invariant that is **expected to be violated**. Specifically, the system should be able to reach a state that the invariant declares unreachable. This creates a simple test case for verifying that:

1. The model checker can detect the reachable "forbidden" state
2. Symbolic slicing correctly handles transitions with non-deterministic elements that don't materially affect the state

## Purpose

This specification serves as a test fixture for tooling that analyzes or optimizes symbolic state exploration, particularly for verifying that transition slicing works correctly when dealing with existentially quantified variables in action definitions.
