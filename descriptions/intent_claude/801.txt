# Specification Request: Least Circular Substring Algorithm

## System Overview

I need a formal specification for an algorithm that finds the lexicographically smallest rotation of a string. Given a string, imagine arranging its characters in a circle—the algorithm should identify which starting position in this circular arrangement produces the smallest string when read sequentially.

## Functional Requirements

The system should:

1. Accept an input string composed of characters from a defined character set
2. Compute all possible rotations of the string (or efficiently determine the minimum without enumerating all)
3. Identify and return the starting position (or the rotation itself) that yields the lexicographically smallest result

For example, given the string "cab", the rotations are "cab", "abc", and "bca"—the algorithm should identify "abc" as the lexicographically smallest rotation.

## Correctness Properties

The specification must guarantee:

1. **Correctness**: The returned rotation is indeed the lexicographically smallest among all possible rotations of the input string
2. **Determinism**: For any given input, the algorithm produces a consistent, unique result
3. **Termination**: The algorithm completes for all valid inputs within the specified bounds

## Model Checking Constraints

For verification purposes, the specification should be checkable with:
- A bounded character set (finite alphabet of configurable size)
- Strings up to a configurable maximum length

This allows exhaustive verification of the algorithm's correctness across all possible inputs within these bounds.
