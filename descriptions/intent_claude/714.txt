Please write a formal specification for a **test suite for fold operations over finite sets**.

## System Description

I need a specification that verifies the correctness of a `MapThenFoldSet` operation—a higher-order function that applies a mapping to elements of a set and then combines the results using a fold (reduce) operation with a specified binary operator and initial value.

## Functional Requirements

The `MapThenFoldSet` operation should:
1. Take a binary combining operator (like addition or multiplication)
2. Take an initial/identity value for the fold
3. Take a mapping function to transform elements before combining
4. Take a selection function to determine the order of processing elements
5. Take a finite set to operate over

## Test Cases to Verify

The specification should confirm correct behavior for a small integer sequence (1, 2, 3, 4) with various combinations:

1. **Summation tests**: Folding with addition starting from 0 should yield the sum (10), regardless of processing order (max-first or min-first)

2. **Product tests**: Folding with multiplication starting from 1 should yield the product (24), regardless of processing order

3. **Zero-product tests**: Folding with multiplication starting from 0 should always yield 0

4. **Order-sensitive tests**: Folding with subtraction (a non-commutative operation) starting from 0 should produce different results depending on whether elements are processed in ascending order (-2) versus descending order (+2)

5. **Error handling tests**: The operation should produce an appropriate error when given an invalid input (a scalar value instead of a proper set)

## Correctness Properties

- For commutative and associative operations, the result should be independent of element processing order
- For non-commutative operations, the processing order should deterministically affect the result
- The operation should properly handle identity elements (0 for addition, 1 for multiplication)
- Invalid inputs should be rejected with meaningful error messages
