Write a TLA+ specification that tests the semantics of ENABLED when used with module instantiation. The setup involves a single boolean-like variable that toggles between 0 and 1, with a fairness condition ensuring it keeps toggling forever. A separate module is instantiated by mapping both of that module's variables to this single variable, effectively making them aliases of each other. The correctness properties to verify include an invariant combining two conditions drawn from the instantiated module (one that must hold, one that must not hold), a property asserting that the instantiated module's initial condition holds in the initial state, and additional properties imported from the instantiated module covering both safety and liveness. The purpose is to confirm that ENABLED expressions and related temporal properties behave correctly under module instantiation with substitution, particularly when multiple formal parameters are mapped to the same concrete variable.
