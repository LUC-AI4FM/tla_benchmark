# Specification Request: Recursive Factorial Computation

## System to Model

A recursive procedure that computes the factorial of a given natural number. The system should model the classic recursive definition of factorial where n! = n × (n-1) × ... × 1, with the base case that 0! = 1.

## Functional Requirements

1. **Input**: The system should compute the factorial of a specific input value (in this case, 5).

2. **Recursive computation**: The factorial should be computed using a recursive approach that:
   - Returns immediately when the input reaches zero (base case)
   - Otherwise multiplies the current accumulated result by the current input value and recurses with a decremented input

3. **Accumulator pattern**: The computation should maintain a running result that accumulates the product as recursion proceeds.

## Correctness Properties

1. **Termination**: The algorithm must eventually complete its computation and reach a final state.

2. **Correct result**: Upon completion, the computed result must equal the mathematical factorial of the input (for input 5, the result must be 120).

3. **Type safety**: The result must always remain a natural number throughout the computation.

4. **Progress during computation**: While actively computing (not at base case), each multiplication step should increase the result value.

5. **Bounded computation steps**: The computation should perform exactly as many recursive multiplications as expected based on the input value (for input 5: exactly 5 recursive steps and 4 actual multiplications, since multiplying by the final value before reaching 0 counts but the base case does not multiply).
