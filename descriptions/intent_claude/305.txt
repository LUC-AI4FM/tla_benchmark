# Specification Request: Binary Search Algorithm

## System to Model

A binary search algorithm that searches for a key within a sorted sequence of integers, following the behavior of standard library implementations (such as Java's `Arrays.binarySearch`).

## Functional Requirements

The algorithm should:

1. Accept a sorted sequence of integers and a target key to find
2. Maintain a search interval that narrows with each step
3. On each iteration, examine the middle element of the current interval:
   - If the middle element equals the key, return its index (success)
   - If the middle element is less than the key, search the upper half
   - If the middle element is greater than the key, search the lower half
4. If the interval becomes empty (no match found), return a negative value encoding where the key would be inserted

## Correctness Properties

The specification must verify the following properties:

1. **Postcondition correctness**: When the algorithm terminates:
   - If the key exists in the sequence, the returned index points to a matching element (non-negative result)
   - If the key does not exist, the return value is negative

2. **Conditional correctness**: The postcondition should hold whenever the input sequence is properly sorted

3. **Termination guarantee**: The algorithm must terminate within a bounded number of steps relative to the bit-width of the integers used (logarithmic in the sequence length)

4. **Progress**: Each step that doesn't terminate must strictly shrink the search interval (either the lower bound increases or the upper bound decreases)

## Modeling Constraints

- The specification should account for fixed-width integer arithmetic (parameterized bit-width)
- The model should be checkable across all valid inputs for a given bit-width
- Index handling should correctly translate between zero-based algorithm indices and one-based sequence indices
