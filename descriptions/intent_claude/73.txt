# Specification Request

## System Overview

I need a formal specification for a simple stateful system that maintains a typed record structure, with auxiliary operator support from a separate module.

## Requirements

### State Management
- The system should maintain a single record with a type field that holds a string value
- The record should be initialized with a specific type designation (e.g., "B")

### Behavior
- The system should support invoking auxiliary operations defined in a helper module
- The main state should remain unchanged during normal operation (the system is essentially static after initialization)

### Modular Design
- The specification should demonstrate separation of concerns by importing functionality from an auxiliary module
- External operators should be callable from the main specification's transition relation

## Purpose

This specification serves as a test case to verify that a formal verification tool correctly handles:
1. Module imports with auxiliary definitions
2. Type annotations on record structures
3. Local operator bindings (LET expressions) that reference imported operators
4. Specifications where the state remains constant

## Correctness Properties

The key property is that the record's type field maintains its initial value throughout all system executions (state invariance).
