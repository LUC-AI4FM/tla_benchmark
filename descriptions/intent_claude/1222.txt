# Specification Request: TLA+ Expression Evaluation Test Suite

## Overview

I need a formal specification that serves as a test harness to verify that various TLA+ language constructs and expressions evaluate correctly. This is essentially a self-checking test module that validates the TLA+ tooling's handling of fundamental operations.

## System Purpose

The system should initialize a simple numeric state and then verify that a series of standard TLA+ expressions produce expected results. The goal is to confirm correct behavior of:

1. **Basic comparison operators** - Verify that numeric comparisons work as expected
2. **Range set construction** - Confirm that range notation produces the correct set of integers
3. **Set mapping (transformation)** - Verify that applying a function to set elements yields the expected result set
4. **Set filtering** - Confirm that selecting elements from a set based on a predicate works correctly
5. **Existential quantification** - Verify that existential checks over sets evaluate properly
6. **Bounded sequence generation** - Confirm that constructing all sequences up to a given length from a set produces the correct collection of sequences

## Requirements

1. The specification must check each expression and report success or failure for diagnostic purposes
2. All tests should pass during initialization (the system should only reach a valid initial state if all expressions evaluate correctly)
3. After initialization, the system should remain stable with no state changes
4. The specification should define an operator for generating all sequences of bounded length from a given set

## Correctness Properties

- The system should satisfy a trivial invariant (always true) since the real verification happens during initialization
- If any expression evaluates incorrectly, the system should either fail to initialize or print a failure message

## Intent

This specification acts as a unit test for TLA+ expression evaluation rather than modeling a distributed system or algorithm. It's meant to validate tooling correctness.
