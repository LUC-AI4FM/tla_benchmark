# Specification Request: Mutually Recursive Function Definitions

## System Overview

I need a formal specification that tests TLA+'s support for recursive and mutually recursive function definitions, specifically focused on computing the factorial function through different recursive patterns.

## Requirements

### Core Functionality

The specification should define the factorial function using multiple equivalent formulations:

1. **Mutually recursive operators**: Two operators that call each other, where one handles the base case (returning 1 when the input is 0) and otherwise multiplies the input by the result of calling the other operator with a decremented argument.

2. **Mutually recursive function definitions**: Similar mutual recursion but using TLA+'s recursive function syntax with explicit domains over the natural numbers.

### Correctness Properties

The specification must verify that all recursive formulations correctly compute factorial by checking:

1. **Base case correctness**: The factorial of 0 equals 1 for all formulations.

2. **Known value verification**: The factorial of 4 equals 24 for all formulations.

3. **Recursive relationship**: For inputs 1 through 5, each formulation satisfies the standard factorial recurrence relation (n! = n × (n-1)!).

4. **Equivalence across formulations**: All different recursive implementations produce identical results for the same inputs.

### Purpose

This specification serves as a test suite to verify that the TLA+ tooling correctly handles:
- Mutual recursion between operators
- Mutual recursion between recursive functions
- The interaction between operators and recursive function definitions

The specification should confirm successful verification by printing confirmation messages for each test group.
