# Specification Request: Function Comparison with Empty Domain

## System to Model

I need a formal specification to test the behavior of function comparison operations, specifically focusing on edge cases involving functions with empty domains.

## Goal

The specification should verify how a model checker handles equality comparisons between functions when one or both functions have an empty domain. This is essentially a test case for validating correct semantics of function equality in the specification language and its associated tools.

## Requirements

1. **Function Definition**: The system should define a function that maps sequences of strings to tuples of strings.

2. **Comparison Semantics**: The specification must test whether a function with a non-empty domain can simultaneously satisfy equality with a function that has an empty domain. This explores the mathematical property that functions are equal if and only if they have the same domain and agree on all values in that domain.

3. **State Invariance**: Once initialized, the system state should remain unchanged (this is a static test of initial state constraints rather than a dynamic system).

## Key Correctness Properties

- The specification should help identify whether the model checker correctly handles the edge case where an empty-domain function is compared against a non-empty-domain function.
- The initialization constraints involve a logical contradiction (a function cannot simultaneously have a non-empty domain and equal a function with an empty domain), so the expected behavior is that no valid initial states exist.

## Context

This specification serves as a regression test for formal verification tools to ensure they correctly implement function comparison semantics, particularly around empty domain edge cases.
