# Specification Request: Value-Swapping System with Liveness Properties

## System Overview

I need a formal specification for a simple two-register system that continuously swaps values between two storage locations. This system should be used to test and demonstrate liveness properties in cyclic state transitions.

## System Description

The system consists of two integer registers that repeatedly exchange their values. Both registers hold bounded non-negative integers within a fixed range. The system must start with the two registers holding distinct values, and the only operation is a simultaneous swap of both values.

## Functional Requirements

1. **Initialization**: Both registers must be initialized to non-negative integers within a defined upper bound, and they must start with different values from each other.

2. **Operation**: The system performs a single repeating action where the contents of the two registers are exchanged atomically.

## Correctness Properties

The specification should verify the following liveness property:

- **Reachability through cycling**: If the first register ever holds zero, then eventually the system will reach a state where the first register is non-zero AND the second register holds zero. This property should hold because the swap operation will move the zero from the first register to the second.

Additionally, demonstrate that a similar but subtly different property does NOT hold:

- **False liveness**: It is NOT the case that if the first register holds zero, eventually BOTH registers will hold zero simultaneously. This is impossible given that the registers must start with distinct values and swapping preserves distinctness.

## Purpose

This specification serves as a test case for model checking tools to verify their handling of systems with cyclic behavior and multi-state loops, particularly for validating liveness properties in systems that cycle indefinitely between states.
