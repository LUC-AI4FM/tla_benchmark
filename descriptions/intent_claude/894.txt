# Specification Request: Expression Evaluation and Output Utility

## Goal

I need a simple utility mechanism for TLA+ that allows me to calculate and display the values of arbitrary expressions during model checking. This is primarily for learning, debugging, and exploratory purposes—essentially a way to use TLC as a calculator that can evaluate and show the results of TLA+ expressions.

## Requirements

### Core Functionality

1. **Expression Evaluation Display**: Provide a way to have TLC compute and print the value of any TLA+ expression when the model checker runs.

2. **Labeled Output**: Each printed value should be accompanied by an identifying label or description string, so that when multiple values are printed, I can easily tell which output corresponds to which expression.

3. **Ordered Output**: When printing multiple values, the output should appear in a predictable, specified order rather than an arbitrary one.

### Use Cases to Support

The mechanism should be able to evaluate and display results for various TLA+ constructs, including:

- **Record field access**: Extracting values from record structures
- **Arithmetic expressions**: Computing numeric results
- **Record modification**: Showing the result of updating records using EXCEPT notation, including self-referential updates (where a new field value depends on the old value)

### Example Scenarios

- Print the result of accessing a field from a record and performing arithmetic on it
- Print a modified version of a record where some fields have been updated, demonstrating how record update expressions work in TLA+

## Purpose

This is not a specification of a concurrent system or algorithm. Rather, it's a teaching and utility tool that leverages TLC's assumption-checking behavior to turn the model checker into an expression evaluator and printer. The goal is to help users understand TLA+ expression semantics by seeing computed results.
