# Specification Request: Integer Squaring Algorithm

## System to Model

I need a formal specification of an iterative algorithm that computes the square of a non-negative integer. The algorithm should calculate n² using only addition operations (no direct multiplication), building up the result incrementally.

## Functional Requirements

The algorithm takes a non-negative integer as input and must compute its square through an iterative process. It should use the mathematical property that squares can be computed by summing consecutive odd numbers (1 + 3 + 5 + ... + (2n-1) = n²), or an equivalent incremental approach.

## Correctness Properties

The specification must guarantee the following:

1. **Partial Correctness**: When the algorithm terminates, the result must equal the square of the input value.

2. **Type Safety**: Throughout execution:
   - The input remains a natural number
   - The accumulator stays within valid bounds (between 0 and the final square)
   - Any loop counter remains bounded appropriately

3. **Loop Invariant**: At each iteration of the main loop, the intermediate result must maintain a consistent mathematical relationship with the loop counter—specifically, the accumulated value should equal the square of the progress made so far.

4. **Termination State**: Upon completion, both the result and any auxiliary counter should reflect that the full computation has been performed for the given input.

## Verification Goals

The specification should be model-checkable with small concrete input values to verify that all correctness properties hold across all reachable states of the algorithm.
