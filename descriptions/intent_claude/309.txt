# Specification Request: Binary Search Algorithm

## System to Model

I need a formal specification of the **binary search algorithm** operating on a sorted sequence of integers. The specification should model how binary search locates a target key within a bounded integer sequence.

## Functional Requirements

The system should model:

1. **Input**: A sequence of integers and a key value to search for
2. **Search process**: The algorithm should repeatedly narrow down the search range by comparing the key against the middle element of the current range
3. **Termination**: The algorithm must eventually terminate with a result indicating whether the key was found (and if so, its position)

## Constraints

- The specification should work with **bounded integers** (specifically 8-bit integer width) to enable model checking
- The algorithm should be verified against **arbitrary input sequences** rather than just specific test cases
- The specification should track the **number of steps executed** to reason about algorithmic complexity or termination

## Correctness Properties

The specification should allow verification of:

1. **Termination**: The algorithm always terminates within a bounded number of steps
2. **Correctness**: If the algorithm reports finding the key, it is actually present at the reported position in the sequence
3. **Completeness**: If the key exists in a properly sorted input sequence, the algorithm finds it
4. **Safety**: The search bounds remain valid throughout execution (no out-of-bounds access)

## Verification Approach

The specification should support symbolic reasoning over all possible input sequences and keys (within the integer bounds) rather than requiring enumeration of specific test cases. This allows checking that the algorithm works correctly for any valid input, not just a handful of examples.
