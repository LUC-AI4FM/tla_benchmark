# Specification Request

## System Description

I need a formal specification for a simple set-based state machine that demonstrates annotation and documentation capabilities for a specification language toolchain.

## Core Behavior

The system should model a minimal state machine with the following behavior:
- The system maintains a single set that starts empty
- The system can transition to a state where the set contains exactly the element 1

## Correctness Properties

The specification must guarantee the following safety property:
- The value 2 must never be a member of the set at any point during execution

## Additional Requirements

The specification should serve as a test case for tooling features, particularly:
- Support for type annotations that span multiple lines and include type aliases
- Proper handling of comments that contain code-like syntax (such as assignment expressions)
- Support for unit testing annotations that can reference other definitions in the specification

The specification can be minimal in terms of actual state machine complexity, as its primary purpose is to validate that the specification language toolchain correctly parses and processes various annotation formats and edge cases in comments.
