# Specification Request: Polymorphic Function Merging with Additive Combination

## System Overview

I need a formal specification for a system that combines partial functions (representing sparse mappings from arbitrary keys to integers) by merging their domains and summing their values where they overlap.

## Core Functionality Requirements

The system should support:

1. **Creating singleton functions**: A way to construct a simple function that maps a single element to the value 1.

2. **Pairwise function addition**: An operation that takes two partial functions and produces a new function where:
   - The domain is the union of both input domains
   - For each element in the combined domain, the output value is the sum of the corresponding values from each input function (treating missing entries as zero)

3. **Aggregate summation over sets of functions**: A way to combine an arbitrary set of such partial functions into a single result by folding the pairwise addition operation across all functions in the set.

## Key Properties to Verify

The specification must guarantee that when combining singleton functions created from distinct elements:
- The resulting function's domain contains exactly those elements
- Each element maps to the expected accumulated value (in the simple case of distinct singletons, each should map to 1)

## Context and Constraints

- The system should be polymorphic, working with keys of any type
- The addition operation should handle functions with disjoint, overlapping, or identical domains correctly
- The fold operation over sets should produce consistent results regardless of the order in which functions are combined (leveraging the associativity and commutativity of addition)

## Verification Goal

Confirm that the aggregate summation correctly merges a collection of singleton functions, producing a function with the expected domain and values.
