Write a specification that tests and validates the treatment of strings as sequences in TLA+.

**System Description:**
The specification should verify that strings in TLA+ behave correctly as sequences of characters, supporting standard sequence operations.

**Requirements:**

1. **String Concatenation:** The system must confirm that strings can be concatenated using the sequence concatenation operator, and that the result is the expected combined string.

2. **String Length:** The system must verify that the length operator correctly counts the number of characters in a string.

3. **Escape Sequence Handling:** The specification must validate that escape sequences within strings (such as escaped backslashes, escaped quotes, and newline characters) are handled correctly:
   - Each escape sequence should count as a single character for length purposes
   - Strings containing escape sequences should concatenate properly
   - The representation of special characters (backslash, double quote, newline) must be correctly interpreted

**Correctness Properties:**

- Concatenating two string literals must produce the expected combined string
- The length of a string must equal the actual number of characters (with escape sequences counting as single characters)
- String equality must hold when comparing a string with escape sequences to its concatenated equivalent parts
- Escape sequences must be properly parsed so that `\\` represents one backslash, `\"` represents one quote, and `\n` represents one newline character
