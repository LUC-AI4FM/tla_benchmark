# Specification Request: Mutually Recursive Even/Odd Checker

## System to Model

A simple recursive algorithm that determines whether a natural number is even or odd using mutual recursion between two procedures.

## Description

The system should model the classic mutually recursive approach to checking parity:
- To determine if a number is even: if the number is zero, it's even; otherwise, check if the predecessor is odd
- To determine if a number is odd: if the number is zero, it's not odd (it's even); otherwise, check if the predecessor is even

The algorithm should be invoked on a specific test input (the number 2) and produce a boolean result indicating whether that number is even.

## Requirements

1. **Mutual recursion**: The even-checking logic must call the odd-checking logic for non-zero inputs, and vice versa, each time decrementing the input by one.

2. **Base cases**: 
   - Zero should be identified as even (return true)
   - Zero should be identified as not odd (return false)

3. **Result storage**: The algorithm should store its final determination in a shared result variable.

4. **Termination**: The algorithm must eventually complete its computation.

## Correctness Properties

1. **Termination guarantee**: The algorithm must always eventually reach a completed state.

2. **Correct result**: Upon termination, the result should accurately reflect whether the input number was even (for input 2, the result should be TRUE).

## Notes

This specification is intended to explore how mutual recursion with procedure calls and a call stack behaves in a formal model, particularly examining whether non-deterministic initialization of the result variable could lead to incorrect final answers or specification violations.
