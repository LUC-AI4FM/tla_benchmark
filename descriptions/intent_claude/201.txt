# Specification Request

## System Overview

I need a formal specification that tests the handling of recursive operators when they are imported from another module via instantiation.

## Goal

The specification should verify that a model checker or verification tool correctly handles recursive operator definitions that are accessed through module instantiation (rather than being defined directly in the main module).

## Requirements

1. **Recursive Operator Definition**: Define a recursive operator in a separate inner module that computes a simple recursive function (such as a function that adds 1 for each recursive call until reaching a base case).

2. **Module Instantiation**: The main specification must import the inner module using instantiation, making the recursive operator available through the instance.

3. **Usage of Instantiated Recursive Operator**: Initialize a state variable by evaluating the instantiated recursive operator with specific input values.

4. **Static System**: After initialization, the system should not change state (the specification is primarily testing the recursive operator evaluation, not dynamic behavior).

## Correctness Properties

- **Invariant**: The state variable should equal the expected result of the recursive computation. For example, if the recursive operator effectively computes an identity function on non-negative integers, the result should match the input value.

## Purpose

This specification serves as a regression test to ensure that recursive operators declared in one module and accessed via instantiation in another module are handled correctly by the verification tooling, without causing errors or incorrect evaluations.
