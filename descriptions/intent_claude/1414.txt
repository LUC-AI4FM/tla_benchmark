# Specification Request

## System Overview

I need a formal specification for a system involving two related mapping structures over a fixed set of nodes. The system should model a static configuration where certain consistency constraints must hold between the two mappings.

## Requirements

### Structure

The system manages two mappings over a small fixed set of nodes (two nodes):

1. **First mapping**: Associates each node with a fixed label/status value (specifically, a single designated value).

2. **Second mapping**: Associates each node with another node from the same set (a pointer or reference relationship).

### Key Constraint

There is a fundamental consistency requirement linking the two mappings: whenever a node has the designated label in the first mapping, the second mapping must point that node to itself (self-reference). In other words, nodes marked with the special status must be self-loops in the reference structure.

### Behavioral Properties

- The system should be able to initialize into any valid configuration satisfying the constraint.
- The system may transition between states, but every state (both initial and subsequent) must maintain the consistency constraint between the two mappings.
- The constraint should be preserved as an invariant across all system behaviors.

## Correctness Properties

The specification should guarantee:

1. **Constraint preservation**: The self-reference property for specially-labeled nodes holds in every reachable state.

2. **Well-formedness**: Both mappings remain properly defined over the node set at all times.

## Notes

The constraint logic should be structured in a modular, layered fashion to support reuse and composition with other specifications. The core constraint definition should be separable from how it gets applied to system state.
