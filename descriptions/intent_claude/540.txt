# Specification Request: Iterative Square Computation

## System Overview

I need a formal specification for an algorithm that computes perfect squares using only addition and subtraction—specifically, by exploiting the mathematical property that any perfect square can be expressed as a sum of consecutive odd numbers.

## What the System Should Do

The algorithm should compute the squares of all integers from 1 up to some input value. Starting from zero, it should iteratively build up an array where each position contains the square of its index. The computation must use only the recurrence relation based on odd numbers (i.e., each square is the previous square plus the next odd number) rather than direct multiplication.

## Input

The system should accept any natural number as input, representing how many squares to compute.

## Expected Behavior

Given an input value, the algorithm should:
1. Initialize storage for results
2. Iteratively compute each square by adding successive odd numbers to the previous result
3. Terminate after computing all requested squares

## Key Correctness Properties

1. **Termination**: The algorithm must always terminate for any valid input.

2. **Correctness of Results**: Upon termination, the computed value at each position should equal the square of that position's index. That is, after the algorithm completes, the result at position k should equal k².

## Purpose

This specification serves as a simple demonstration of verifying a computational algorithm that uses an incremental mathematical identity. It should confirm that the loop correctly implements the relationship: n² = (n-1)² + (2n - 1).
