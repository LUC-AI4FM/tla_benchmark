# Specification Request: Nested Record and Function Update Operations

## System Overview

I need a formal specification that demonstrates and validates complex update operations on nested data structures. The system should model a state machine that performs various kinds of in-place modifications to composite data types, specifically focusing on updating fields within records that are stored as values in functions (lookup tables), and updating elements within tuples that are nested inside records.

## Data Structure Requirements

The specification should work with three distinct data structures:

1. **An indexed table** mapping integer keys to records, where each record contains both an integer field and a string field
2. **A string-keyed lookup table** mapping string keys to string values (to verify that string-indexed functions are handled differently from records)
3. **A nested record** containing both a simple integer field and a tuple field with mixed-type elements

## Behavioral Requirements

The system should demonstrate the ability to:

- Update a specific field within a record that is itself a value in an indexed table (reaching "through" the function to modify a nested field)
- Perform multiple such nested updates simultaneously in a single step
- Combine nested field updates with complete record replacements at different indices
- Update elements within a tuple that is nested inside a record
- Update string-keyed function values without confusing them with record field access

## Key Properties to Verify

The specification should confirm that:

1. Nested update syntax correctly modifies only the targeted nested field while preserving all other data
2. Multiple nested updates can be combined in a single expression
3. The distinction between function application (using keys) and record field access is maintained correctly, especially for string-typed keys
4. Tuple element updates work correctly when the tuple is nested within a record structure

## Purpose

This specification serves as a test case for verifying that a TLA+ toolchain correctly handles the advanced EXCEPT syntax for nested data structure updates, ensuring the implementation properly parses and evaluates these complex update expressions.
