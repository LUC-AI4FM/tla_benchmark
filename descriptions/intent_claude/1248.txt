# Specification Request: Integer Arithmetic Operations

## System Overview

I need a formal specification that defines the mathematical foundation for integer arithmetic, extending the natural numbers to include negative whole numbers.

## Goal

Create a module that provides the complete set of integers (positive, negative, and zero) along with the standard arithmetic operations that work over this extended number domain. This module should serve as a foundational building block that other specifications can import when they need to reason about integer values rather than just natural numbers.

## Requirements

### Core Definitions

1. **The Integer Set**: Define the set of all integers, which includes zero, all positive whole numbers, and all negative whole numbers.

2. **Negation Operator**: Provide a unary minus (negation) operator that, given any integer, returns its additive inverse.

### Relationship to Natural Numbers

The specification should build upon natural number arithmetic, inheriting operations like addition, subtraction, multiplication, comparison, and division where appropriate, while extending them to work correctly over the full integer domain.

### Properties to Guarantee

- The set of integers properly contains all natural numbers
- Negation of any integer produces a valid integer
- Negation is self-inverting: negating a number twice returns the original
- Zero is its own negation
- The integers are closed under negation

## Usage Context

This module is intended as a standard library component that tools and other specifications will use. The actual implementation of integer arithmetic may be provided by the verification tool itself, with this specification serving as the formal interface contract for what integer operations mean and how they should behave.
