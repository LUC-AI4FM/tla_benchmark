# Specification Request: Binary Search Algorithm with Fixed-Width Integer Arithmetic

## System to Model

A binary search algorithm that operates on a sorted sequence to find a target element, implemented using fixed-width integer arithmetic (specifically 8-bit integers).

## Functional Requirements

The system should model the classic binary search algorithm that:

1. Takes a sorted sequence and a target key as inputs
2. Searches for the target key within the sequence
3. Returns an appropriate value indicating whether the key was found (and potentially its position)
4. Properly terminates after a finite number of steps

## Key Constraints

- All arithmetic operations must respect 8-bit integer bounds and behavior
- The algorithm must correctly handle edge cases including empty sequences
- The search boundaries must be properly maintained throughout execution

## Correctness Properties

The specification should verify:

1. **Termination**: The algorithm always terminates
2. **Correctness**: If the key exists in the sequence, it is found; if it doesn't exist, the algorithm correctly reports its absence
3. **Integer Safety**: The algorithm avoids integer overflow issues that can occur in naive binary search implementations when computing the midpoint (a well-known bug in many binary search implementations)
4. **Bound Invariants**: Search boundaries remain valid throughout execution

## Purpose

This specification serves as a model-checking instance to verify the binary search implementation against specific test cases (such as searching for value 10 in an empty sequence) while ensuring the algorithm behaves correctly under fixed-width integer arithmetic constraints.
