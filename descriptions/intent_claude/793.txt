# Specification Request: TLA+ Utility Library for Common Operations

## Overview

I need a reusable utility library for TLA+ specifications that provides common helper operations for working with sets and sequences. This library should serve as a foundation that other specifications can extend, avoiding the need to repeatedly define these basic operations.

## Required Functionality

### Set Operations
- Determine whether two sets have any elements in common (non-empty intersection)
- Find the maximum element in a set of comparable values
- Find the minimum element in a set of comparable values
- Compute the intersection of all sets within a collection of sets (analogous to how UNION works, but for intersection)
- Fold/reduce over a set with a binary operator and base value

### Sequence Operations
- Fold/reduce over a sequence with a binary operator and accumulator
- Find the index position of a given element within a sequence
- Convert a sequence to the set of its elements
- Retrieve the last element of a sequence
- Check whether a sequence is empty
- Remove all occurrences of a specific element from a sequence

### Combinatorial Operations
- Generate all permutations of a finite set, where each permutation is represented as a sequence

### Testing Support
- Provide a helper for writing inline assertions that print diagnostic output when a test condition fails, useful for validating the utility functions themselves

## Design Goals

1. **Reusability**: Operations should be general-purpose and applicable across many different specifications
2. **Simplicity**: Each operation should have clear, obvious semantics
3. **Composability**: Operations should work well together and with TLA+'s built-in operators

## Intended Use

This library will be imported by other TLA+ modules that need these common operations without cluttering their specifications with boilerplate definitions.
