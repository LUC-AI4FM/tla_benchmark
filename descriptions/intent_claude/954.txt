# Specification Request: Finite Set Operations

## System Overview

I need a formal specification that provides fundamental operations for working with finite sets in a mathematical or formal methods context. This should serve as a utility library that other specifications can rely upon when reasoning about collections with a bounded number of elements.

## Required Operations

### Finiteness Test
The specification must provide a way to determine whether a given set is finite. A set should be considered finite if and only if all of its elements can be enumerated in some finite sequence—that is, there exists an ordering that lists every element of the set exactly once within a bounded length.

### Cardinality Computation
The specification must provide a way to compute the number of elements in a finite set. This operation is only meaningful for sets that are actually finite. The cardinality should satisfy the intuitive property that:
- The empty set has cardinality zero
- Adding one distinct element to a set increases its cardinality by exactly one

## Key Properties and Guarantees

1. **Soundness of finiteness**: The finiteness predicate should correctly identify sets that can be fully enumerated.

2. **Cardinality correctness**: For any finite set, the cardinality operation must return a natural number equal to the count of distinct elements.

3. **Base case**: The empty set must be recognized as finite with cardinality zero.

4. **Inductive structure**: The cardinality computation should work by systematically accounting for each element exactly once, regardless of which element is considered at each step.

## Context and Usage

This specification should be suitable for importing into other formal specifications that need to reason about finite collections—for example, specifications involving bounded buffers, finite state machines, resource pools, or any system where counting distinct items is necessary for correctness properties.
