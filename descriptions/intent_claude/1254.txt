# Specification Request: Finite Sequence Operations Library

## Overview

I need a formal specification of a library that defines fundamental operations on finite sequences. A sequence should be modeled as an ordered collection of elements where positions are indexed starting from 1.

## Core Requirements

The library must provide the following capabilities:

### Sequence Construction and Representation
- Define what constitutes the set of all possible finite sequences whose elements are drawn from a given set
- Sequences of length n should be representable as mappings from positions 1 through n to elements

### Basic Query Operations
- Determine the length of any sequence
- Access the first element of a non-empty sequence
- Obtain all elements after the first (the remaining portion of a sequence)

### Sequence Building Operations
- Concatenate two sequences to produce a new sequence containing all elements of the first followed by all elements of the second
- Append a single element to the end of an existing sequence

### Extraction Operations
- Extract a contiguous subsequence given starting and ending positions
- Filter a sequence by selecting only those elements satisfying a given predicate, preserving their relative order

## Key Properties

The operations should satisfy intuitive mathematical properties:
- The length of a concatenation equals the sum of the input lengths
- Appending an element increases length by exactly one
- Head and tail together reconstruct the original sequence
- Subsequence extraction respects the original ordering
- Filtering preserves the relative order of retained elements

## Constraints

- Sequences are finite (though there is no fixed upper bound on length)
- Indexing is 1-based
- The tail operation should only be defined for non-empty sequences
- All operations should be purely functional (no mutation)
