# Specification Request: Configurable State Transformation System

## System Overview

I need a formal specification for a simple discrete state machine where the state evolves according to a user-configurable transformation function.

## Requirements

### Basic Behavior

The system should:
- Start from an initial state of zero
- At each step, compute the next state by applying a configurable function to the current state
- The transformation function should be a parameter that can be supplied when the specification is instantiated, allowing different behaviors to be analyzed

### Configurable Component

The specification must support plugging in an arbitrary unary function that determines how the state changes. This allows the same specification framework to be used for analyzing different transformation rules without modifying the core specification.

### Correctness Property

The system must guarantee that the state never reaches the value 2. This invariant should be verifiable for any specific transformation function that is configured.

## Purpose

This specification is intended to serve as a template or framework for analyzing systems where the evolution rule can vary. By parameterizing the transition function, we can check whether different transformation strategies maintain the required safety property.
