# Specification Request

## System Description

I need a formal specification that models a simple state machine where a single piece of state can hold values of fundamentally different types. The system should start in an initial numeric state and then be able to transition to various other values, including numbers across a reasonable range, boolean values, and string values.

## Behavioral Requirements

1. The system should begin in a well-defined initial state (starting at zero)
2. From any state, the system should be able to transition to:
   - Any number within a moderate range (sufficient to create many possible successor states)
   - A boolean value
   - A string value
3. The system should allow stuttering (remaining in the same state)

## Correctness Properties

The specification should verify a basic liveness property asserting that the system can eventually reach and remain in a stable condition (trivially satisfiable).

## Purpose

The primary purpose of this specification is to test how a model checker handles heterogeneous typing—specifically, situations where a variable can take on values of incompatible types (numbers, booleans, and strings) across different execution paths. The specification should generate enough successor states to stress-test internal data structures that track state space exploration, particularly to reveal any issues with hash collisions or type handling in the verification tooling.
