# Specification Request

## System to Model

A simple concurrent system with multiple processes that share access to a global counter and use derived (computed) values based on that counter.

## Description

Model a system where:

1. There is a shared global counter that starts at zero.
2. The system should define helper expressions that compute values derived from this counter—specifically, the counter plus one, and the counter plus two (building on the first derived value).
3. Multiple identical processes (e.g., three of them) run concurrently.
4. Each process reads the "counter plus two" derived value and stores it in its own local variable.

## Key Requirements

- The derived expressions should be defined once and reusable across all processes.
- All processes should be able to execute and complete.
- The derived values must correctly reflect the current state of the global counter at the time they are evaluated.

## Correctness Properties

1. **Computation correctness**: Since the global counter is initialized to zero and never modified, every process should observe the derived "plus two" value as exactly 2. Each process must verify this after reading the value.

2. **Termination**: All processes should eventually complete their execution.

## Purpose

This specification tests that shared definitions (computed expressions based on global state) work correctly in a multi-process environment, ensuring that all concurrent processes see consistent derived values when the underlying state is stable.
