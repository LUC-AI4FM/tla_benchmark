# Specification Request: Mutual Exclusion Protocol

## System to Model

I need a formal specification of a mutual exclusion algorithm that allows multiple concurrent processes to safely coordinate access to a critical section. The specification should model Peterson's algorithm (or a similar mutual exclusion protocol) for N processes.

## Requirements

### Basic Behavior
- The system consists of a configurable number of processes (e.g., 3 processes numbered 0 through 2)
- Each process should be able to request entry to a critical section, execute within it, and then exit
- Processes operate concurrently and asynchronously

### Key Correctness Properties

**Mutual Exclusion (Safety)**: At no point in time should two different processes be simultaneously executing in the critical section. This is the fundamental safety property that must never be violated.

**Additional Desirable Properties** (depending on the specific algorithm variant):
- **Deadlock Freedom**: The system should not reach a state where processes are waiting indefinitely with no progress possible
- **Starvation Freedom**: Every process that requests access to the critical section should eventually be granted access

## Purpose

This specification will serve as a model for verifying that the mutual exclusion protocol correctly prevents concurrent access to shared resources, which is essential for avoiding race conditions and data corruption in concurrent systems.
