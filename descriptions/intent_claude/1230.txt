# Specification Request: Numeric Literal Format Verification

## Overview

I need a formal specification that verifies the correctness of alternative numeric literal representations in a system that supports multiple number bases.

## System Description

The system should support expressing natural numbers in multiple numeral systems beyond standard decimal notation:

1. **Binary notation** - base-2 representation using digits 0-1
2. **Octal notation** - base-8 representation using digits 0-7
3. **Hexadecimal notation** - base-16 representation using digits 0-9 and letters A-F

## Requirements

### Functional Requirements

- The system must correctly interpret numeric literals written in binary, octal, and hexadecimal formats
- Each alternative representation must evaluate to the same mathematical value as its decimal equivalent
- Hexadecimal digit letters must be case-insensitive (both uppercase and lowercase letters should be accepted and treated identically)
- The notation prefix indicators themselves should be case-insensitive

### Correctness Properties

The specification must verify that:

1. **Equivalence**: A number expressed in any supported base evaluates to the correct natural number value
2. **Case insensitivity**: For hexadecimal literals, using uppercase versus lowercase letters (A-F vs a-f) produces identical results
3. **Consistency**: The same numeric value can be correctly represented and recovered across all supported bases

## Verification Approach

The specification should use concrete test cases demonstrating that a known decimal value equals its equivalent representation in each supported base, including variations in letter casing for hexadecimal digits.
