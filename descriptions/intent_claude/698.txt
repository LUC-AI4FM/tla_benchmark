# Specification Request: SVG Graphics Construction Library

## Overview

I need a formal specification for a **library that constructs SVG (Scalable Vector Graphics) documents** as structured data. This is not a behavioral system with state transitions, but rather a **functional library** that provides operators for building SVG element trees that can be serialized to standard SVG format.

## Goals

The library should enable TLA+ specifications to construct visual representations of system states—useful for creating diagrams, visualizations of distributed systems, or animation frames showing how a specification evolves over time.

## Required Capabilities

### Core Element Construction

The library must support creating common SVG primitives:
- **Lines** defined by start and end coordinates
- **Circles** defined by center point and radius
- **Rectangles** defined by position, width, and height
- **Text labels** positioned at specific coordinates
- **Images** with source references and dimensions
- **Groups** that contain collections of other elements
- **SVG containers** that wrap content with proper namespaces and viewport settings

Each element should accept both its required geometric parameters (as integers) and an extensible set of additional attributes (as key-value pairs) for styling or other SVG features.

### Element Representation

Elements must be represented as structured records containing:
- The element type name
- A mapping of attribute names to string values
- An ordered collection of child elements
- Optional inner text content (for text elements)

When attributes are specified both as core parameters and in the additional attributes, the core parameters should take precedence.

### Layout Helpers

The library should provide geometric utilities for common visualization patterns:
- **Ring network layout**: Calculate positions for nodes arranged in a circle, given the center, radius, and total node count
- **Directed graph layout**: Compute node positions for visualizing graphs with nodes and edges
- **Line interpolation**: Find points along a line segment

### Serialization

The library must support:
- Converting the structured element representation to valid SVG markup strings
- Writing SVG documents to files with sequential numbering (for generating animation frames)

## Design Constraints

- All coordinate and dimension values should be integers to work within TLA+'s mathematical foundations
- Complex operations (trigonometry for ring layouts, graph layout algorithms, string serialization) may require implementation outside pure TLA+ due to performance or capability limitations
- The attribute merging mechanism must have well-defined precedence when the same attribute appears in multiple places

## Use Cases

This library enables specifications to generate visualizations showing:
- Network topologies with nodes arranged in rings or arbitrary graphs
- State diagrams with labeled nodes and transitions
- Animated sequences showing system evolution across specification levels
