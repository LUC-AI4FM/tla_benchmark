Write a specification for a simple system that computes factorial values.

**System Description:**
The system should model a state machine that holds a factorial computation result. The system initializes with the factorial of one number and then transitions to hold the factorial of another number.

**Requirements:**
1. Define a recursive factorial function that computes n! (n factorial) using the standard mathematical definition: factorial of n equals n multiplied by the factorial of (n-1), with the base case being 1 for inputs of 1 or less.

2. The system should start in a state where it holds the factorial of a small positive integer (e.g., 4).

3. The system should be able to transition to a state holding the factorial of a larger positive integer (e.g., 7).

**Correctness Properties:**
- **Non-negativity invariant:** The stored factorial value must always be at least 1. Since factorials of non-negative integers are always positive, this property should hold in all reachable states.

**Additional Context:**
This specification is intended for use with model checking tools that handle recursive definitions through unrolling. The specification should be structured to test how such tools behave when recursion unrolling parameters are only partially configured—specifically, when a default value for the recursion is provided but the maximum unrolling depth is left unspecified.
