# Specification Request: Balance Scale Weighing Puzzle

## System Overview

I need a formal specification that solves a classic weighing puzzle: given a stone of a certain total weight, find how to break it into a fixed number of pieces such that any integer weight from 1 up to the total can be measured using a two-pan balance scale.

## Problem Description

The key insight is that with a balance scale, weights can be placed on *either* side of the scale. When measuring an unknown quantity (like corn), some stone pieces can go on the same side as the corn, and others on the opposite side. This allows pieces to effectively "subtract" weight, not just add it.

The specification should:

1. **Model the decomposition**: Represent all valid ways to partition a stone of total weight N into exactly P integer-weighted pieces. The pieces must sum to exactly N.

2. **Model the weighing capability**: For any target weight from 1 to N, determine whether there exists a way to partition the P pieces between the two sides of the balance (with the target weight on one side) such that the scale balances.

3. **Find all solutions**: Identify which decompositions allow *every* integer weight from 1 to N to be measured.

## Parameters

- **N**: The total weight of the stone (e.g., 40 pounds)
- **P**: The number of pieces to break it into (e.g., 4 pieces)

## Correctness Requirements

A valid solution must satisfy:

1. **Complete coverage**: Every integer weight w where 1 ≤ w ≤ N must be measurable
2. **Balance equation**: For each target weight w, there must exist two disjoint subsets of pieces where the target weight plus one subset's total equals the other subset's total
3. **Exact partition**: The pieces must sum to exactly N

## Expected Output

The specification should compute the set of all valid piece-weight combinations that solve the puzzle. For the classic problem (N=40, P=4), there should be exactly one solution.

## Optional Enhancement

It would be useful to also generate, for each solution, a demonstration showing exactly which pieces go on which side of the balance for each possible target weight.
