# Specification Request: Binary Search Algorithm

## System to Model

I need a formal specification of the **binary search algorithm** operating on a sorted sequence of integers. The specification should model the step-by-step execution of binary search as it narrows down the search range to find a target key.

## Functional Requirements

The system should model:

1. **Input**: A sequence of integers (assumed to be sorted) and a target key to search for
2. **Search process**: The algorithm should repeatedly narrow the search range by comparing the middle element with the target key, adjusting the bounds accordingly
3. **Termination**: The algorithm must eventually terminate, either finding the key or determining it doesn't exist in the sequence
4. **Result**: Upon termination, the algorithm should return an appropriate value indicating either the position where the key was found or that it wasn't found

## Key Constraints

- The specification should use **bounded integer arithmetic** (specifically 8-bit integers) to model realistic computer arithmetic and potential overflow concerns
- The algorithm should track the number of steps executed to enable reasoning about termination
- The specification should support verification over **arbitrary input sequences and keys**, not just concrete test cases

## Correctness Properties

The specification must guarantee:

1. **Termination**: The algorithm always terminates within a bounded number of steps
2. **Soundness**: If the algorithm reports finding the key at a position, the key must actually be at that position in the sequence
3. **Completeness**: If the key exists in a sorted sequence, the algorithm should find it
4. **No arithmetic overflow**: The midpoint calculation and bound updates should not cause integer overflow within the specified bit width

## Verification Approach

The specification should be suitable for model checking with symbolic execution, allowing verification across all possible sorted sequences and search keys within the integer bounds, rather than just checking specific test cases.
