# Specification Request: Boolean Flag Transition System

## System Description

I need a formal specification of an extremely simple state transition system consisting of a single boolean flag that can transition from false to true. This system serves as a minimal example for exploring the relationship between fairness assumptions and liveness properties in temporal logic.

## System Behavior

The system should model:
- A single boolean state that starts as false
- A single possible action: setting the flag to true
- Once true, the flag remains true (or the action simply becomes a no-op)

## Correctness Properties to Verify

I want to explore several temporal properties and understand how they relate to different fairness assumptions:

### Liveness Properties
1. **Eventual truth**: The flag eventually becomes true
2. **Leads-to relationship**: Being false leads to eventually being true
3. **Infinitely often true**: The flag is true infinitely often
4. **Eventually always true**: The flag eventually becomes and stays true

### Safety Properties
1. Once the flag transitions from true back to false, it stays false forever (this explores vacuous or boundary conditions)

### Vacuous/Edge Case Properties
1. If the flag is true, it eventually becomes false (this should be vacuously satisfied or have interesting behavior depending on the specification)

## Fairness Exploration

The specification should define multiple variants:
1. **No fairness**: Only safety guarantees, where stuttering forever is allowed
2. **Weak fairness**: The standard fairness assumption that if the action is continuously enabled, it eventually occurs
3. **Custom fairness via liveness**: Directly asserting eventual truth as part of the specification instead of using fairness

## Refinement Requirements

The system should also demonstrate refinement checking against a more abstract specification where the boolean can be any boolean value (a more permissive, nondeterministic specification). I want to verify that:
- The unfair version refines the abstract unfair version
- The fair version refines the abstract fair version

## Goal

The primary purpose is educational: to clearly demonstrate how fairness assumptions affect which liveness properties can be proven, and to show the difference between specifying liveness through fairness conditions versus directly as temporal formulas.
