# Specification Request

I need a formal specification for a simple system that demonstrates modular composition through instantiation.

## System Description

The system should model a basic state machine where the core behavior is defined in a separate, reusable module. The main specification should instantiate that external module, binding its own local state to the parameters expected by the imported module.

## Requirements

1. **Modular Design**: The specification must be structured so that the actual system behavior is defined in an external module, and this module imports and instantiates that behavior.

2. **State Binding**: The main module should have its own state variable that gets mapped to the corresponding state expected by the instantiated module.

3. **Behavior Delegation**: The complete system specification (including initialization and transitions) should be inherited from the instantiated module rather than defined directly in this module.

## Correctness Properties

The system should satisfy whatever safety and liveness properties are defined in the instantiated module, with the understanding that the local state of this module corresponds to the state managed by the imported specification.

## Purpose

This specification serves as a wrapper or adapter that allows reusing an existing formally specified behavior while giving the importing module control over naming and potentially combining multiple such instantiations.
