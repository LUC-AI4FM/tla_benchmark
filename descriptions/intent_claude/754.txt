# Specification Request: Coffee Can Bean Selection Problem

## System Overview

I need a formal specification for a classic mathematical puzzle involving a coffee can containing black and white beans. The system models a repeated random selection process that reduces the bean count until only one bean remains.

## Problem Description

A coffee can starts with some number of black beans and white beans (at least one bean total). The following process repeats until only one bean remains:

1. Randomly select two beans from the can
2. If both beans are the **same color**: discard both beans, then add one black bean to the can
3. If the beans are **different colors**: discard the black bean and return the white bean to the can

Each iteration reduces the total bean count by exactly one, so the process must eventually terminate with a single bean remaining.

## Key Question

The fundamental question to answer: **Can we determine the color of the final remaining bean based solely on the initial counts of white and black beans?**

## Requirements

The specification should:

1. **Model the state space**: Track the count of black beans and white beans in the can, with configurable maximum counts for bounded model checking

2. **Capture all possible moves**: Represent the three distinct cases (two black selected, two white selected, one of each selected) as separate transitions

3. **Handle termination**: The process must stop when exactly one bean remains, avoiding spurious deadlock detection

4. **Ensure progress**: The system should not stutter indefinitely; it must eventually complete the bean selection process

## Correctness Properties to Verify

1. **Monotonic progress**: Every non-stuttering step must strictly decrease the total number of beans

2. **Guaranteed termination**: The system must eventually reach a state with exactly one bean

3. **Invariant preservation**: Identify what quantity is preserved (modulo some value) across all transitions—this is the key to predicting the final outcome

4. **Final state hypothesis**: Verify that the color of the final bean is completely determined by a specific property of the initial white bean count (specifically, whether it is odd or even)

## Goals

- Use bounded model checking to validate the properties for finite bean counts
- Structure the specification so that the invariant relationship between initial conditions and final outcome is clearly expressible and checkable
- The specification should support future extension to a full proof covering all natural numbers
