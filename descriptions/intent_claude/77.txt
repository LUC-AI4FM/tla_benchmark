# Specification Request

## System Description

I need a formal specification for a simple system that demonstrates the handling of bounded integer parameters. The system involves two configuration parameters representing a range defined by minimum and maximum integer values.

## Requirements

### Configuration Parameters
The system should accept two integer constants that define a valid range:
- A lower bound value
- An upper bound value

### Core Constraint
The fundamental requirement is that the lower bound must always be less than or equal to the upper bound. This constraint defines what constitutes a valid configuration.

### System Behavior
The system itself is trivial in terms of state transitions—it essentially remains idle with no meaningful state changes. The focus is entirely on the relationship between the configuration parameters.

## Correctness Properties

### Primary Invariant
The specification must verify that the ordering relationship between the minimum and maximum bounds is maintained. Specifically, the minimum value should never exceed the maximum value.

### Assumption vs. Verification
The valid range constraint should be both:
1. Stated as an assumption about valid configurations
2. Verified as an invariant that the system maintains

## Purpose

This specification serves as a minimal example to test whether model checking tools correctly propagate constraints established during constant initialization when verifying invariants. The goal is to confirm that assumptions about constants are properly considered during invariant checking.
