# Specification Request: Simple Bounded Counter with Liveness Properties

## System Overview

I need a formal specification for a simple bounded counter system that increments from zero up to a maximum value.

## Functional Requirements

The system should model a counter with the following behavior:
- The counter starts at zero
- The counter can increment by one at each step
- The counter stops incrementing once it reaches a specified upper bound (e.g., 5)
- The system should allow stuttering (the counter may remain unchanged)

## Correctness Properties

### Safety
- The counter should only take on valid values within the expected range
- The counter should only increase (never decrease or skip values)

### Liveness Investigation
The primary purpose of this specification is to investigate how a model checker handles liveness properties that involve universally quantified formulas over sets, particularly:

1. **Empty set quantification**: What happens when a liveness property is expressed as a universal quantification over an empty set? (Vacuously true cases)

2. **Non-empty set quantification**: How does the same liveness property behave when quantified over a non-empty set?

The goal is to understand edge cases in temporal logic handling, specifically whether quantified temporal formulas behave correctly when the domain of quantification is empty versus non-empty. This appears to be a test case for verifying model checker behavior around vacuous truth in liveness properties.

## Expected Outcome

The specification should help identify potential issues in how temporal formula checking handles:
- Vacuously true conditions in liveness properties
- The interaction between first-order quantification and temporal operators
- Proper error reporting for malformed or edge-case temporal formulas
