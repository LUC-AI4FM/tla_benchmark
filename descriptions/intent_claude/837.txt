# Specification Request: N-Queens Problem Solver

## System Overview

I need a formal specification of an algorithm that solves the classic N-queens puzzle. The puzzle asks: how can N chess queens be placed on an N×N chessboard such that no two queens threaten each other?

## Problem Description

Two queens attack each other if they share the same column or lie on the same diagonal. Since each row must contain exactly one queen, a solution can be represented by recording which column each queen occupies in its respective row.

## Algorithm Requirements

The system should implement an iterative search algorithm that:

1. Starts with no queens placed on the board
2. Incrementally builds up partial solutions by placing one queen at a time, row by row
3. Only extends partial placements that remain conflict-free (no attacking queens)
4. Collects all complete valid placements of N queens
5. Eventually terminates when all possibilities have been explored

The algorithm should explore the search space by maintaining a work set of partial solutions still to be extended, and a result set of complete solutions found.

## Correctness Properties

The specification must guarantee:

1. **Soundness**: Every configuration reported as a solution is actually valid—no two queens in the configuration attack each other.

2. **Completeness**: When the algorithm terminates, all possible solutions have been found. No valid N-queens placement is missing from the results.

3. **Termination**: The algorithm must eventually finish exploring all possibilities and halt.

4. **Type Safety**: Partial solutions should always have fewer than N queens placed, and complete solutions should have exactly N queens placed, with all column positions being valid board coordinates.

## Parameters

The board size N should be configurable, where N is any positive natural number.
