# Specification Request: Voucher Lifecycle Management System

## System Overview

I need a formal specification for a voucher lifecycle management system that tracks the state of vouchers through their complete lifecycle, from issuance through to final disposition.

## What the System Should Model

The system should model how vouchers (such as gift cards, coupons, or digital tokens) progress through different stages of their existence. A voucher typically begins by being issued, can potentially be transferred between parties, and eventually reaches a terminal state either by being redeemed for value or being cancelled/voided.

## Required Operations

The system must support the following operations on vouchers:

1. **Issuance** - Creating a new voucher and putting it into circulation
2. **Transfer** - Moving ownership or possession of a voucher from one party to another
3. **Redemption** - Using the voucher to claim its value, consuming it in the process
4. **Cancellation** - Voiding or invalidating a voucher before it can be redeemed

## Key Correctness Properties

The specification must guarantee the following properties:

1. **Type Safety** - The voucher state and any lifecycle tracking state must always remain within their valid domains. States should only take on well-defined values that represent legitimate voucher conditions.

2. **Lifecycle Consistency** - The voucher's internal state must remain consistent with its position in the lifecycle at all times. This means:
   - Operations should only be possible when the voucher is in an appropriate state
   - State transitions must follow valid lifecycle progressions
   - Terminal states (redeemed, cancelled) should be final
   - The relationship between different state components must remain coherent throughout all operations

## Goal

The goal is to have a formally verified model demonstrating that starting from a valid initial state, the system maintains both type correctness and lifecycle consistency through all possible sequences of operations. This should be provable as an inductive invariant that holds in every reachable state of the system.
