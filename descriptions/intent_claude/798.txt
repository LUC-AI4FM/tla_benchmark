# Specification Request: Find Maximum Element in a Sequence

## System Overview

I need a formal specification for a simple sequential algorithm that finds the largest value in a sequence of natural numbers. This is intended as a learning exercise for writing and proving invariants and correctness properties in a formal verification context.

## Functional Requirements

The algorithm should:

1. Accept an arbitrary finite sequence of natural numbers as input
2. Iterate through the entire sequence from beginning to end
3. Track the highest value seen so far during the traversal
4. Upon completion, report the maximum value found in the sequence

## Correctness Properties

The specification must establish and prove the following properties:

### Type Safety
All variables must remain within their expected domains throughout execution:
- The input sequence remains a valid sequence of natural numbers
- The index used for iteration stays within valid bounds
- The tracked maximum is either a natural number or a designated initial sentinel value

### Partial Correctness (Inductive Invariant)
At any point during execution, the tracked maximum must be greater than or equal to every element in the portion of the sequence already examined.

### Total Correctness
When the algorithm terminates, the result must be greater than or equal to every element in the entire input sequence. In other words, the final value is truly the maximum of all sequence elements.

## Verification Goals

The specification should support formal proofs of:
1. The type invariant holds in all reachable states
2. The inductive invariant is maintained by every step of the algorithm
3. The relationship between termination and having processed all elements
4. The main correctness theorem follows from the established invariants

This exercise demonstrates the methodology of proving algorithm correctness through establishing type invariants first, then strengthening to inductive invariants, and finally deriving the desired correctness property as a consequence.
