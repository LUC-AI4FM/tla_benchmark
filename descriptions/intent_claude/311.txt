# Specification Request: Binary Search Algorithm with Bounded Integers

## System to Model

I need a formal specification of the **binary search algorithm** that operates on a sorted sequence to find a target element. The specification should account for **fixed-width integer arithmetic** to model realistic computer implementations where integer overflow is a concern.

## Functional Requirements

The algorithm should:

1. Search through a sorted sequence of integers to locate a specific target key
2. Maintain two boundary indices that progressively narrow the search space
3. Return an appropriate result indicating whether the key was found (and its position) or that it does not exist in the sequence
4. Terminate in all cases, including edge cases like empty sequences

## Key Constraints

- All integer arithmetic must respect **bounded integer representation** (specifically 8-bit integers for verification purposes)
- The algorithm must handle the classic binary search pitfall where computing the midpoint could potentially overflow in naive implementations
- The specification should be parameterized to allow testing with different input sequences and search keys

## Correctness Properties

The specification must guarantee:

1. **Termination**: The algorithm always terminates, regardless of input
2. **Soundness**: If the algorithm reports finding the key at a position, the key actually exists at that position
3. **Completeness**: If the key exists in the sequence, the algorithm will find it
4. **Safety**: No integer overflow occurs during execution that could corrupt the search logic

## Verification Goals

The specification should support model checking with concrete parameters (empty sequences, specific key values) to verify correctness properties hold under bounded integer arithmetic constraints.
