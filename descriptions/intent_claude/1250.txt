# Specification Request: Natural Number Arithmetic Operations

## System Overview

I need a formal specification that defines the fundamental arithmetic operations and relations on natural numbers (non-negative integers). This should serve as a foundational mathematical module that other specifications can build upon.

## Requirements

### Core Data Type

The specification must define the set of all natural numbers (0, 1, 2, 3, ...).

### Arithmetic Operations

The following binary operations must be defined:

1. **Addition**: Combining two natural numbers to produce their sum
2. **Subtraction**: Finding the difference between two natural numbers
3. **Multiplication**: Computing the product of two natural numbers
4. **Exponentiation**: Raising a natural number to a power
5. **Integer Division**: Dividing one natural number by another, returning the quotient (floor division)
6. **Modulo**: Computing the remainder after integer division

### Comparison Relations

The following comparison relations must be defined:

1. **Less than**
2. **Greater than**
3. **Less than or equal to**
4. **Greater than or equal to**

### Range Constructor

A way to construct the set of all integers within a given inclusive range (from a lower bound to an upper bound).

## Key Correctness Properties

1. **Division-Modulo Relationship**: For any natural numbers where the divisor is positive, the original number must equal the divisor times the quotient plus the remainder. This is the fundamental property connecting integer division and modulo.

2. **Range Semantics**: The range from a to b must produce exactly the set of integers i such that a ≤ i ≤ b.

## Purpose

This module provides placeholder definitions that tools are expected to override with proper implementations. The actual semantics should follow standard mathematical definitions as documented in formal references for specifying systems.
