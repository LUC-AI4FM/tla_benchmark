Please write a formal specification for a **distributed breadth-first search (BFS) tree construction algorithm** on a graph.

## System Description

The system consists of a network of nodes connected by edges, with one designated root node. The goal is to construct a spanning tree rooted at the designated node such that each node's position in the tree reflects its shortest-path distance from the root in the original graph.

Nodes communicate by passing messages through queues associated with the edges connecting them. The algorithm should work in a distributed manner where each node only has local knowledge of its neighbors and must coordinate through message passing to collectively build the BFS tree.

## Requirements

1. **Tree Construction**: Every node must eventually determine its parent in the spanning tree, establishing a path back to the root.

2. **Distance Tracking**: Each node should track its depth (distance from the root) in the tree being constructed.

3. **Message-Based Coordination**: Nodes communicate via message queues on edges. Messages should carry depth information to help receiving nodes determine their correct position in the tree.

4. **Termination**: The algorithm must eventually terminate, indicated by all message queues becoming empty.

## Correctness Properties

1. **Type Safety**: Node depths must be bounded non-negative integers, parent pointers must reference valid nodes, and message queues must contain properly ordered depth values.

2. **BFS Correctness (Postcondition)**: Upon termination, the parent pointers must form a valid BFS tree—meaning for every node, the path length to the root through parent pointers equals the actual shortest-path distance to the root in the underlying graph.

3. **Termination**: The algorithm must eventually reach a terminated state where no messages remain in transit.
