# Specification Request: Enumeration of Injective Mappings from Labels to Fixed-Size Subsets

## System Overview

I need a formal specification that computes all possible ways to assign subsets of a given size to a collection of labels, where the assignments maximize distinctness—that is, different labels should receive different subsets whenever possible.

## Requirements

### Input Parameters
- A base set of elements (e.g., integers in some range)
- A set of labels/keys that need to be assigned values
- A fixed subset size parameter

### Desired Output
The system should produce all functions mapping each label to a subset of the base set, where:
1. Every assigned subset has exactly the specified size
2. The mapping uses as many *distinct* subsets as possible—specifically, the number of distinct subsets in the range should equal the minimum of:
   - The number of labels being mapped
   - The total number of possible subsets of the given size

### Key Properties

**Uniformity**: Every subset assigned must have exactly the specified cardinality.

**Maximally Injective**: The mapping should be "as injective as possible"—if there are enough distinct subsets available to give each label a unique one, then every label must receive a different subset. Only when there are more labels than available subsets should repetition occur.

**Completeness**: The result should include *all* such valid mappings, not just one.

## Purpose

This specification should enumerate the complete set of assignment functions satisfying these constraints, which could be useful for analyzing configuration spaces, testing coverage scenarios, or reasoning about resource allocation where resources are sets of fixed size and we want maximal diversity in assignments.
