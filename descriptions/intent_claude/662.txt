# Specification Request: Bitwise Operations Test Suite

## Overview

I need a formal specification that serves as a test suite for verifying the correctness of bitwise operations. The specification should validate that implementations of standard bitwise functions behave according to their expected mathematical definitions.

## System to Model

A collection of bitwise operations commonly found in low-level programming and hardware design, including operations such as:

- Bitwise AND, OR, XOR, and NOT
- Bit shifting (left shift, right shift)
- Bit extraction and manipulation
- Any other fundamental bitwise primitives

## Requirements

### Functional Requirements

1. **Operation Coverage**: The test suite should exercise all fundamental bitwise operations across a representative range of input values.

2. **Edge Case Validation**: Tests should include boundary conditions such as:
   - Operations on zero
   - Operations on maximum/minimum values for the bit width
   - Single-bit values (powers of two)
   - All-ones patterns

3. **Consistency Verification**: Verify that operations satisfy known algebraic properties (e.g., commutativity, associativity, identity elements, De Morgan's laws where applicable).

## Correctness Properties

The specification should ensure:

1. **Mathematical Correctness**: Each bitwise operation produces results consistent with its formal mathematical definition.

2. **Property Preservation**: Standard bitwise identities hold (e.g., `x AND x = x`, `x XOR 0 = x`, `x OR 0 = x`).

3. **Determinism**: The same inputs always produce the same outputs.

## Purpose

This specification will serve as a validation framework to ensure that any implementation of bitwise operations in the modeling language correctly implements the expected semantics, enabling their reliable use in larger specifications that depend on bit-level manipulation.
