# Specification Request: Distributed Spanning Tree Construction

## System Overview

I need a formal specification of a distributed algorithm that constructs a spanning tree across a network of processes. The algorithm should start from a designated root process and gradually build a tree structure by having processes discover and record their parent in the tree.

## System Description

The system consists of a fixed set of processes connected by a neighbor relation (representing a network topology). One process is designated as the root of the spanning tree. The goal is for every process in the network to eventually become part of the spanning tree by establishing a parent relationship with one of its neighbors.

## Algorithm Behavior

The algorithm should work as follows:
- The root process initiates the tree construction by sending messages to its neighbors
- When a process that is already part of the tree (has a parent or is the root) can propagate messages to its neighbors
- When a process not yet in the tree receives a message from a neighbor, it can adopt that neighbor as its parent, thereby joining the tree
- Once a process has joined the tree (established its parent), it can report this fact

## Key Requirements

1. **Message Propagation**: Only processes that are part of the tree (the root, or processes with an established parent) may send messages to their neighbors

2. **Parent Selection**: A non-root process without a parent may adopt a neighbor as its parent only after receiving a message from that neighbor

3. **Parent Stability**: Once a process establishes its parent, that parent relationship must never change

4. **Neighbor Constraint**: A process can only have a neighbor as its parent (the tree must respect the network topology)

## Correctness Properties

1. **Progress (Spanning Tree Formation)**: Eventually, every process should be part of the spanning tree—meaning every non-root process has established a parent that is one of its neighbors

2. **Safety (Parent Immutability)**: Once a process sets its parent, the parent value must remain unchanged forever

3. **Type Consistency**: Parent relationships must always point to actual neighbors, and message/reporting state must remain well-formed

## Fairness

The specification should include weak fairness to ensure the algorithm makes progress and eventually completes the spanning tree construction.
