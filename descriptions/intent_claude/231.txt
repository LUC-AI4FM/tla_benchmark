Please write a formal specification for a system that manages a collection of named entities, each tracking a counter value.

**System Description:**
The system maintains a registry of named items (such as "A", "B", "C"), where each item has an associated counter. The registry is initialized by combining default values with specific overrides—some items start with preset counter values while others receive default values of zero. When entries overlap, one set of values takes precedence over another.

**Behavior Requirements:**
1. The system should initialize the registry with a mix of specifically configured items and default-initialized items
2. The system must support a decrement operation on a particular item's counter
3. The decrement operation should be "guarded" or "clamped" so that it never produces negative values—if decrementing would go below zero, the counter should remain at zero instead

**Key Correctness Property:**
The specification must guarantee that a specific item's counter (the one subject to decrement operations) never becomes negative. This invariant should hold in all reachable states of the system.

**Additional Notes:**
- The system may also stutter (remain unchanged)
- The initialization involves merging or overriding mappings, where the order of combination determines which values take precedence for overlapping keys
