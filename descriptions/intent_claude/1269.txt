# Specification Request: Ordered Enumeration of Fixed-Size Subsets

## System to Model

An algorithm that systematically generates all subsets of a given size from a set of consecutive integers, producing them in a specific lexicographic order.

## Problem Description

Given a set of integers from 0 to n-1 and a desired subset size k, enumerate every possible k-element subset exactly once. The subsets must be produced in a well-defined sorted order based on comparing their elements position-by-position (lexicographic ordering on the sorted element sequences).

For example, with n=5 and k=3, the algorithm should generate all 10 possible 3-element subsets of {0,1,2,3,4} in order: {0,1,2}, {0,1,3}, {0,1,4}, {0,2,3}, {0,2,4}, {0,3,4}, {1,2,3}, {1,2,4}, {1,3,4}, {2,3,4}.

## Functional Requirements

1. The algorithm must enumerate subsets one at a time, maintaining state between iterations to know which subset to produce next
2. Each subset should be represented in sorted order (smallest to largest element)
3. The algorithm must terminate after producing all possible k-subsets
4. The approach should work for any valid combination where k ≤ n

## Correctness Properties

The specification must verify two key properties upon termination:

1. **Completeness and Correctness**: The collection of generated subsets, when viewed as sets, must equal exactly the mathematical set of all k-element subsets of {0, ..., n-1}. No subset should be missing, duplicated, or incorrect.

2. **Ordering Guarantee**: Consecutive subsets in the output sequence must follow a strict lexicographic ordering. Specifically, for any two adjacent subsets in the sequence, there must exist a position where the earlier subset has a smaller value, with all preceding positions being equal or appropriately ordered.

## Context

This type of algorithm is fundamental for efficiently representing and comparing sets in systems where sets need a canonical form. When all subsets follow a predefined order, operations like equality checking become efficient (linear time via single-pass comparison). The algorithm is based on classical combinatorial generation techniques.
