Please write a TLA+ specification for a simple constant aliasing system.

**System Description:**
The system should define a constant value and create a chain of aliases that reference it. Specifically, there should be one named reference that directly refers to the constant, and another named reference that indirectly refers to the constant through the first reference.

**Requirements:**
- Define a single constant parameter that can be instantiated with any value
- Create two derived definitions where one references the constant directly and the other references it indirectly through the first definition

**Purpose:**
This specification serves as a basic test or demonstration of how TLA+ handles definition chaining and constant references, ensuring that indirect references resolve correctly to the underlying constant value.
