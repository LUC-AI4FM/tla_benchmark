# Specification Request: Nested Conditional Branching with Value Verification

## System Description

I need a formal specification for a simple sequential process that demonstrates correct handling of nested conditional branching based on an integer input value.

## Functional Requirements

The system should:

1. **Accept an input value**: Start with an integer value in the range 1 through 4.

2. **Perform nested conditional dispatch**: Based on the value, the system should branch through a two-level decision structure:
   - First, determine if the value is in the "low" range (less than 3) or the "high" range (3 or greater)
   - Then, within each range, further distinguish between the two possible values

3. **Verify correct routing**: At the end of each branch path, the system must confirm that it arrived at the correct destination for the given input value. Specifically:
   - If the input is 1, verify we're in the path designated for value 1
   - If the input is 2, verify we're in the path designated for value 2
   - If the input is 3, verify we're in the path designated for value 3
   - If the input is 4, verify we're in the path designated for value 4

4. **Complete execution**: After verification, the system should reach a final completion state.

## Correctness Properties

1. **Routing correctness**: Each possible input value must be routed to exactly the branch path intended for that value. The verification at each branch endpoint must always succeed.

2. **Termination**: The system must eventually complete for any valid input value.

3. **No assertion failures**: The verification checks at each branch must never fail, confirming that the branching logic correctly partitions the input space.

## Purpose

This specification serves to verify that nested conditional logic correctly handles all cases in a partitioned input domain, ensuring no value is misrouted to an incorrect branch.
