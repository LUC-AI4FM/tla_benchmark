# Specification Request

## System Description

I need a formal specification of a simple sequential computation that performs arithmetic operations with a nondeterministic choice, followed by conditional branching based on that choice.

## Behavior Requirements

The system should:

1. **Initialize** with two numeric values starting at zero.

2. **First step**: Set the first value to a fixed constant (specifically 3).

3. **Second step**: Nondeterministically choose between two options (1 or 2), store that choice, and add it to the first value.

4. **Conditional branching**: Based on which value was chosen in the previous step:
   - If the smaller value (1) was chosen: increment the first value by 1, then double it
   - If the larger value (2) was chosen: add the chosen value to the first value again (without the extra step)

5. **Final step**: Output the resulting value.

## Expected Outcomes

Due to the nondeterministic choice, the computation should produce exactly one of two possible final results:
- Following one branch should yield 10
- Following the other branch should yield 7

## Correctness Properties

1. **Termination**: The computation must always eventually complete.

2. **Deterministic outcome per path**: Once the nondeterministic choice is made, the remaining computation should be deterministic.

3. **Bounded results**: The final output should be constrained to the expected set of values (7 or 10).

## Purpose

This specification models a simple branching computation to verify that nondeterministic choices lead to the expected distinct outcomes, useful for validating the model checker's ability to explore all execution paths and confirm arithmetic properties along each branch.
