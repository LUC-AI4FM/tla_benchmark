# Specification Request: TLA+ Set Equality and Set Operations Test Suite

## Goal

Create a test harness to verify that a TLA+ model checker correctly implements set equality semantics and various set construction operations. The purpose is to confirm that sets defined through different syntactic forms are recognized as equal when they contain the same elements, regardless of how they are expressed.

## System Description

This is not a distributed system or algorithm specification, but rather a **conformance test suite** for TLA+ tooling. The specification should verify the fundamental mathematical property that sets are equal if and only if they have the same members, independent of:

- Element ordering
- Duplicate elements in the definition
- The syntactic method used to construct the set

## Requirements

The test suite must validate set equality across the following set construction methods:

1. **Literal enumeration** with varying element order and duplicates
2. **Set filter expressions** (selecting elements from a set based on a predicate)
3. **Set map expressions** (transforming elements of one set to produce another)
4. **Power set construction** and its equivalence to explicit enumeration of subsets
5. **Generalized union** of a set of sets
6. **Binary set union** of multiple sets
7. **Set intersection** operations
8. **Set difference** operations
9. **Integer range notation**
10. **Domain extraction** from function definitions (both explicit function mappings and record structures)
11. **Function set construction** edge cases (specifically, functions into empty codomains)

## Correctness Properties

The specification must assert that:

- Two sets constructed via different methods but containing the same elements are equal
- The subset relation is correctly evaluated (including negative cases where subset should not hold)
- The empty set is correctly identified when appropriate

Each test should produce a clear pass/fail indication, halting execution on failure and reporting success otherwise.
