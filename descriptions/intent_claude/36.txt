Write a specification for an internal utility module that provides special operator bindings for a TLA+ model checker implementation.

**System Description:**

This module should define internal helper operators that the model checker tool uses behind the scenes to support various features. These operators serve as placeholders in the specification language that get bound to actual model checker functionality at runtime.

**Required Operators:**

1. **Sequence Capacity Query**: An operator that, given a sequence, returns its static capacity (the maximum length the sequence can have). This is useful for bounded model checking where sequences have predetermined size limits.

2. **Unsupported Feature Handler**: An operator that can be invoked when the specification uses a feature not supported by the model checker. When encountered during model checking, it should halt execution and display an error message. However, it must still be well-typed so that the type checker can process specifications containing it without errors.

**Key Requirements:**

- The operators should have proper type signatures that allow type checking to succeed
- The actual implementations in the specification are placeholders; the real behavior is provided by the model checker at runtime
- The unsupported feature handler must accept an error message string and can notionally return any type (to fit into arbitrary expression contexts)
- This module is strictly for internal tooling purposes and should not be used directly in user specifications

**Correctness Properties:**

- Type safety: All operators must have well-defined types that the type checker can verify
- The sequence capacity operator must return an integer
- The unsupported feature handler must cause model checking to terminate with an appropriate error when reached
