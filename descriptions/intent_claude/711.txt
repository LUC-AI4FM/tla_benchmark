# Specification Request: Combinatorics Library

## System Overview

I need a formal specification for a combinatorics utility library that provides fundamental counting functions used in discrete mathematics and probability theory.

## Required Functionality

The library should provide two core mathematical operations:

1. **Factorial computation**: Calculate the factorial of a non-negative integer (n!), which is the product of all positive integers up to n, with 0! defined as 1.

2. **Binomial coefficient computation**: Calculate "n choose k" (the number of ways to select k items from n items without regard to order), commonly written as C(n,k) or (n k).

## Correctness Properties

The implementation must satisfy the following mathematical properties:

### Factorial Properties
- The factorial function must match the standard recursive mathematical definition: 0! = 1, and n! = n × (n-1)! for n > 0
- Must be correct for a reasonable range of non-negative integers (at least 0 through 12)

### Binomial Coefficient Properties
- Must equal the standard formula: C(n,k) = n! / (k! × (n-k)!) for all valid inputs where n ≥ k
- Must satisfy fundamental identities:
  - C(n, 0) = 1 for all n (there's exactly one way to choose nothing)
  - C(n, n) = 1 for all n (there's exactly one way to choose everything)
  - C(n, 1) = n for all n (there are n ways to choose one item from n items)
- These identities should hold across a wide range of values (at least 0 through 63)

## Purpose

This library would serve as a foundational module for specifications involving counting arguments, probabilistic reasoning, or any system that needs to reason about combinations and permutations.
