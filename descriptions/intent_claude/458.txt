# Specification Request: TLA+ Module Instantiation with Parameter Substitution

## System to Model

I need a formal specification that demonstrates and verifies the behavior of TLA+ module instantiation with parameter substitution. The specification should show how a parameterized module can be instantiated multiple times with different constant values, and how those instances behave independently.

## Requirements

1. **Base Module**: Create a foundational module that defines a constant parameter and an operator that references or returns that constant.

2. **Multiple Instantiation**: The main specification should instantiate the base module multiple times, each time substituting a different concrete value for the constant parameter.

3. **Instance Independence**: Each instantiation must maintain its own independent binding of the substituted value, so that operators from different instances return their respective substituted values.

4. **Direct Import**: The specification should also demonstrate direct extension (inheritance) of the base module without substitution, where operators refer to the original unsubstituted constant.

## Correctness Properties

The specification must verify:

- When the base module is instantiated with different constant values (e.g., 42 and 44), accessing the same operator through each instance returns the respective substituted value
- When the base module is extended directly (without substitution), operators continue to reference the original constant symbol rather than any substituted value
- The instantiation mechanism correctly isolates the parameter bindings between different named instances
