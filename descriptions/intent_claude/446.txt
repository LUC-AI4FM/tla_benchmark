# Specification Request: Numeric Literal Representation Verification

## System Overview

I need a formal specification that verifies the correctness of numeric literal parsing across different base representations in a specification language.

## Goal

Create a specification that confirms numeric values can be correctly expressed and interpreted in multiple numeral systems (bases), and that equivalent values in different representations are recognized as equal.

## Requirements

The specification must verify that:

1. **Multi-base numeric literals are supported**: The system should accept numeric literals in at least:
   - Decimal (base 10)
   - Binary (base 2)
   - Octal (base 8)
   - Hexadecimal (base 16)

2. **Case insensitivity**: Both uppercase and lowercase variants of:
   - Base prefixes/indicators
   - Hexadecimal digit characters (A-F)
   
   must be accepted and produce identical values.

3. **Value equivalence**: A numeric value expressed in any supported base must be equal to the same mathematical value expressed in any other supported base.

## Correctness Properties

- All representations of the same mathematical value must be provably equal
- The specification should validate these equivalences as assumptions that must hold for the model to be valid
- No runtime behavior needs to be modeled; this is purely a compile-time/parse-time verification of the language's numeric literal handling
