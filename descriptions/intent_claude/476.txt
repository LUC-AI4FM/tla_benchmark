# Specification Request

I need a formal specification for a system involving two coordinated state variables that must always swap their values while simultaneously being constrained to equal each other after any transition.

## System Description

The system maintains two state components that evolve together. On each step, the system attempts to update both components according to certain rules while enforcing that they exchange values and end up equal to one another.

## Requirements

1. The system should allow transitions where the first component can be set to specific values (like 1, or 2 under certain conditions).
2. After any transition, both components must have swapped their previous values.
3. Additionally, after any transition, both components must be equal to each other.

## Key Correctness Properties

The specification should capture a system where the combined constraints on transitions are logically stringent—specifically, the requirement that two variables simultaneously swap values AND become equal to each other creates a highly constrained (possibly unsatisfiable) transition relation. The specification should accurately model whether any valid transitions exist under these combined requirements.
