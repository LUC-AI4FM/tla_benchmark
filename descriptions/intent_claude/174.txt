# Specification Request: Non-Looping Counter System

## System Description

I need a formal specification for a simple two-counter system that demonstrates behavior in a non-cycling state space. The system consists of two integer counters that update simultaneously based on each other's values.

## Behavioral Requirements

1. **Initialization**: Both counters start with values in a bounded range (0 to 50), but they must begin with different values from each other.

2. **State Transitions**: On each step, both counters update simultaneously:
   - Each counter takes on a value that is one more than the other counter's previous value
   - This creates a mutual dependency where the counters essentially "swap and increment"

## Correctness Properties

The specification should verify the following liveness properties:

1. **Primary Liveness Property**: Once one counter exceeds the upper bound of the initial range, the other counter will eventually and permanently also exceed that bound. This captures the idea that once the system "escapes" the bounded region, both counters will eventually stabilize in the unbounded region.

2. **False Liveness Property** (expected to fail): A property asserting that if one counter reaches a certain threshold, the other counter will always remain above a much higher threshold. This serves as a sanity check to confirm the model checker correctly identifies invalid temporal claims.

## Purpose

This specification is intended to test and demonstrate model checking behavior on systems without cyclic state spaces—where the state continuously evolves without returning to previous states. The mutual update rule ensures the counters grow without bound and never revisit earlier configurations.
