# Specification Request: Alternating Bit Protocol

## System to Model

I need a formal specification of the **Alternating Bit Protocol**, a classic reliable data transmission protocol that operates over an unreliable communication channel. This protocol enables a sender to transmit a sequence of data values to a receiver, ensuring reliable delivery despite the possibility of message loss.

## System Description

The system consists of:

1. **A sender** that transmits data values to a receiver, tagging each message with a single-bit sequence number (0 or 1) that alternates with each new value sent.

2. **A receiver** that accepts messages and sends acknowledgments back to the sender, including the bit value of the last correctly received message.

3. **Two unreliable channels**: one for data messages (sender to receiver) and one for acknowledgments (receiver to sender). Messages in either channel may be lost at any time, but messages are not corrupted or reordered.

## Required Behaviors

The protocol must handle:

- **Sending new data**: The sender can transmit a new data value when the previous one has been acknowledged
- **Retransmission**: The sender can resend the current message if no acknowledgment has been received
- **Message reception**: The receiver processes incoming messages and updates its state when receiving new data
- **Acknowledgment**: The receiver sends acknowledgments to confirm receipt
- **Message loss**: Either data messages or acknowledgments can be lost from their respective channels

## Key Correctness Property

The specification must guarantee **type safety**: all protocol state must remain well-formed throughout execution. Specifically:

- Sequence numbers must always be valid bits (0 or 1)
- Message and acknowledgment channels must be valid sequences containing properly formatted entries
- Data values must come from the defined data domain

This type invariant should be preserved by the initial state and maintained by every possible protocol transition, including message loss events and stuttering steps.
