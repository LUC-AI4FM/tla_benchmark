# Specification Request

## System Overview

I need a formal specification for checking the existence of a "compatible pair" between two sets of integers, where compatibility is determined by an arbitrary user-defined relation.

## Requirements

The specification should model a simple predicate that determines whether there exists at least one pair of elements—one drawn from each of two distinct integer sets—that satisfies a given compatibility criterion.

## Inputs

- Two sets of integers (which may be disjoint, overlapping, or identical)
- A binary predicate that defines what it means for two integers to be "good" or compatible together

## Key Property

The specification must express a single boolean property: whether any compatible pair exists across the two sets. This should evaluate to true if and only if there is at least one element from the first set and at least one element from the second set such that the compatibility predicate holds for that pair.

## Purpose

This serves as a foundational building block for specifications that need to reason about relationships between elements of different domains, where the specific notion of compatibility is left abstract and can be instantiated differently depending on the use case.
