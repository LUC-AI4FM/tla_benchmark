# Specification Request: Utility Functions for Integer Set Operations

I need a small utility library that provides basic mathematical operations on sets of integers. This will serve as a foundation module that other specifications can extend and reuse.

## Required Functionality

The library should provide operations to find extreme values within a set:

1. **Maximum**: Given a non-empty set of integers, determine the largest element in that set.

2. **Minimum**: Given a non-empty set of integers, determine the smallest element in that set.

## Assumptions and Constraints

- These operations will only be applied to finite, non-empty sets of integers.
- The operations should return an element that is actually contained within the input set (not just a bound).

## Purpose

This module is intended to be imported by other specifications that need to reason about maximum or minimum values when modeling systems involving ordered quantities, resource limits, priorities, or similar concepts.
