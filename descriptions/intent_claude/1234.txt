# Specification Request: Modular Counter System

## System Description

I need a formal specification for a simple cyclic counter that repeatedly counts through a fixed range of values. The counter should start at zero and increment by one each step, wrapping around to zero after reaching the maximum value.

## Behavioral Requirements

1. **Initial State**: The counter must begin at zero.

2. **Counting Behavior**: On each step, the counter should advance to the next value in sequence, cycling through the range continuously.

3. **Wraparound**: When the counter reaches its maximum value (4 in this case, for a modulo-5 counter), the next increment should return it to zero rather than continuing to increase.

4. **Stuttering**: The specification should permit stuttering steps where the counter value remains unchanged.

## Key Properties

- The counter value should always remain within the valid range (0 through 4, inclusive).
- The system should be deterministic in its progression when it does change state.
- The counter should be capable of cycling indefinitely without reaching an invalid state.

## Purpose

This specification is intended to serve as a foundation for testing parametrized instantiation, where another module might instantiate this counter with different parameters or compose multiple counters together. The simplicity of the counter makes it suitable for verifying that module instantiation mechanisms work correctly.
