# Specification Request

I need a formal specification that models a simple system with two state variables, both initialized to zero.

The system should attempt to define a transition that simultaneously:
1. Sets one variable to zero
2. Sets another variable to a specific non-zero value (like 42)
3. Keeps both variables unchanged

**Key Correctness Concern:**
The primary purpose of this specification is to test or demonstrate how a model checker handles logically contradictory or unsatisfiable transition conditions. The transition relation contains inherently conflicting requirements—it demands that variables both change to new values AND remain unchanged simultaneously.

**Expected Behavior:**
The specification should help verify that the model checker correctly identifies when a `Next` relation is unsatisfiable (no valid transitions exist), resulting in a system that deadlocks immediately after initialization since no successor state can satisfy all the conflicting constraints.
