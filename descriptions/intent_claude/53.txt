# Specification Request: Empty Domain and Range Function Initialization

## System Description

I need a formal specification that models the initialization of a function (mapping) where the domain and/or range may be empty sets. This is essentially a test case for how a specification language handles edge cases in function definitions.

## Requirements

The system should:

1. **Initialize a function variable** that can be defined over potentially empty domains and ranges
2. **Support three distinct initial configurations:**
   - A function from a singleton set to an empty set (which should be impossible/empty)
   - A function from an empty set to an empty set (the unique empty function)
   - A function from an empty set to a singleton set (also the unique empty function)

3. **Remain static after initialization** - once the function is established, it does not change

## Key Correctness Properties

The specification should help verify:

- How the system handles function spaces where the domain is empty (should yield exactly one function: the empty function)
- How the system handles function spaces where the range is empty but domain is non-empty (should yield no valid functions)
- That the model checker correctly computes the cardinality of these edge-case function spaces

## Purpose

This specification serves as a test case for verifying that the tooling correctly handles mathematical edge cases involving functions with empty domains or empty ranges, particularly ensuring proper type handling and state space exploration for these degenerate cases.
