# Specification Request: Model Value Type Verification

## System Overview

I need a formal specification that serves as a test harness to verify the behavior of model values in a TLA+ model checker. Model values are a special kind of constant that should be distinguishable from ordinary TLA+ values like strings, sets, and natural numbers.

## Goal

The specification should confirm that when constants are declared as model values (distinct uninterpreted constants), the model checker correctly recognizes them as being different from:

1. String values
2. Specific set literals
3. Natural numbers (including those defined by set comprehension)
4. Other model values declared in the same specification

## Requirements

### Constants to Test
The specification should declare three distinct model value constants that will be instantiated as model values during model checking.

### Verification Properties

The specification must verify the following properties about model values:

1. **Not strings**: A model value should not be a member of the STRING type
2. **Not equal to sets**: A model value should not be equal to any specific set literal
3. **Not natural numbers**: A model value should not be a member of the natural numbers, even when the naturals are expressed through set comprehension
4. **Distinct from each other**: Each model value should be distinguishable from other model values (i.e., one model value should not be contained in a set of other model values)

### Behavior

The system itself can be trivial (a static, non-changing state) since the purpose is purely to test type-checking properties of model values, not to model any dynamic behavior.

### Output Requirements

Each test should produce clear output indicating success, and should halt with an assertion failure if any test unexpectedly fails (indicating a bug in model value handling).
