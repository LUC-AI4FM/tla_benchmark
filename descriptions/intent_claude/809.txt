# Specification Request: Boyer-Moore Majority Vote Algorithm

## System to Model

I need a formal specification of the Boyer-Moore majority vote algorithm, which determines whether any element appears more than half the time in a sequence of values.

## Description

The algorithm should process a sequence of elements one at a time, maintaining a candidate element and a counter. As it scans through the sequence, it either increments the counter when seeing the current candidate, decrements it when seeing a different element, or adopts a new candidate when the counter reaches zero. After processing all elements, the candidate (if one exists) is the potential majority element.

## Functional Requirements

1. The system should accept an arbitrary sequence drawn from a fixed set of possible values
2. It must iterate through the sequence exactly once (single-pass algorithm)
3. It should track a current candidate for the majority element
4. It should maintain a count that reflects the "strength" of the current candidate relative to other elements seen
5. Upon completion, if a majority element exists in the sequence, it must be identified as the candidate

## Key Correctness Properties

1. **Termination**: The algorithm must eventually complete for any finite input sequence

2. **Majority Detection**: If any value appears strictly more than half the time in the sequence, that value must be the final candidate when the algorithm terminates

3. **Counter Invariant**: Throughout execution, the counter should remain non-negative and bounded by the number of elements processed

4. **Progress**: Each step of the algorithm must advance through the sequence, ensuring the scan position strictly increases until the entire sequence is consumed

## Context

This is a classic streaming algorithm that uses only constant extra space (one candidate value and one integer counter) regardless of input size, making it important for processing large datasets where memory efficiency matters.
