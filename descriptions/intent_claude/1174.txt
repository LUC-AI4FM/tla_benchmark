# Specification Request

I need a formal specification for a system involving a fixed set of **5 concurrent processes** (or participants/nodes).

## System Description

The specification should model a distributed or concurrent system where multiple processes (numbered 1 through 5) can interact or execute. This appears to be a foundational setup for modeling process behavior.

## Requirements

1. **Process Set**: The system should have exactly 5 distinct processes that can be identified and referenced.

2. **Extensibility**: The specification should be structured to support reasoning about finite sets and natural numbers, as these will likely be needed for modeling process states, counters, or set-based operations.
