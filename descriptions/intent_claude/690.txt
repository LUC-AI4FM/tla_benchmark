# Specification Request: Formal Theory of Functions and Cardinality

## System Overview

I need a formal mathematical library that establishes foundational theorems about functions between sets, with particular emphasis on proving properties related to injectivity, surjectivity, bijectivity, and set cardinality comparisons.

## Core Concepts to Formalize

### Function Operations
The library should support reasoning about:
- **Function restriction**: Limiting a function's domain to a subset
- **Function range**: The set of all output values
- **Function inverse**: A reverse mapping (where applicable)
- **Function composition**: Combining functions transitively

### Classification of Functions
Define and prove properties for three fundamental function types between sets:
- **Injections** (one-to-one): Distinct inputs always produce distinct outputs
- **Surjections** (onto): Every element in the codomain is mapped to by some input
- **Bijections** (one-to-one correspondence): Both injective and surjective

## Required Theorems

### Basic Properties
- Restriction of a function preserves typing and point-wise values
- The range of a function is a subset of the codomain
- Introduction and elimination rules for each function classification
- Composition preserves injectivity, surjectivity, and bijectivity

### Inverse Properties
- The inverse of a surjection is an injection
- The inverse of an injection is a surjection
- The inverse of a bijection is a bijection, and double-inversion recovers the original

### Existence Predicates
Establish when injections, surjections, or bijections exist between sets:
- Reflexivity, symmetry (for bijections), and transitivity
- A surjection from S to T implies an injection from T to S
- A surjection that is "smallest" (no proper subset of the domain also surjects) must be a bijection

### The Cantor-Bernstein-Schroeder Theorem
Prove this fundamental result: if injections exist in both directions between two sets, then a bijection exists between them. Include useful corollaries about equivalent characterizations of when bijections exist.

### Finite Set Cardinality
Connect function existence to natural number cardinality:
- Injection from 1..n to 1..m exists if and only if n ≤ m
- Bijections from 1..n to a set uniquely determine n
- Adding/removing elements adjusts the cardinality bijection appropriately
- Subsets of finite sets are finite with smaller or equal cardinality

### Fold Operations
Support folding a binary operator over function values indexed by a finite set, with theorems about:
- Base cases and recursive structure
- Type preservation
- Equality when functions agree on indices
- Simplification rules when the operator is associative and commutative

## Correctness Requirements

All theorems must be machine-checkable proofs establishing the logical relationships between these concepts, suitable for use as a reusable foundation in larger formal developments.
