# Specification Request: Byzantine Fault-Tolerant Consensus Protocol

## System to Model

I need a formal specification of a Byzantine fault-tolerant consensus protocol based on the Tendermint algorithm. The system should model a distributed network of processes attempting to reach agreement on a value, where some processes may be Byzantine (arbitrarily faulty).

## System Requirements

### Network Configuration
- The system should support a configurable number of total processes, with a designated subset being correct (honest) and the remainder being Byzantine (faulty)
- There should be a fault tolerance threshold that determines how many Byzantine faults the system can withstand
- The protocol operates in rounds, with a designated proposer for each round

### Protocol Behavior
- Processes proceed through multiple rounds of voting to reach consensus
- Each round involves proposal, prevote, and precommit phases
- Processes maintain local state including their current round, locked values (values they've committed to supporting), and valid values they've observed
- Processes exchange proposal messages, prevote messages, and precommit messages
- Byzantine processes may send arbitrary or conflicting messages

### Valid and Invalid Values
- The specification should distinguish between valid values that can legitimately be proposed and invalid values that should be rejected
- Only valid values should be decidable by correct processes

## Correctness Properties

### Safety
- **Agreement**: No two correct processes should decide on different values
- **Validity**: If a correct process decides a value, it must be a valid value

### Evidence Collection
- The system should track evidence of Byzantine behavior (such as equivocation) that can be detected from message patterns

## Analysis Goals

The specification should be suitable for model checking with a small instance (4 processes, up to 3 faulty, bounded rounds) to verify safety properties hold even under Byzantine attacks, with arbitrary proposer selection across rounds.
