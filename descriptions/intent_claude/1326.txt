Please write a formal specification for a token-based termination detection algorithm in a distributed system (specifically Dijkstra's EWD840 algorithm).

**System Overview:**
Model a ring network of N nodes where each node can be either active or inactive. The system should detect when all nodes have become inactive (global termination), using a single token that circulates around the ring.

**Core Requirements:**

1. **Node States:** Each node has an activity status (active or inactive) and a color (white or black). Nodes can spontaneously become inactive, and inactive nodes can be reactivated by receiving messages from other nodes.

2. **Token Mechanism:** A single token circulates through the ring. The token also carries a color (white or black) and tracks its position in the ring.

3. **Termination Detection:** The algorithm must correctly detect when all nodes have terminated (become inactive) and no further reactivation is possible.

**Key Correctness Properties:**

1. **Safety:** The algorithm must never falsely announce termination while any node is still active or could become active.

2. **Liveness:** If all nodes genuinely terminate, the algorithm should eventually detect this condition.

**Additional Testing Context:**
The specification should support simulation and model checking with a small number of nodes (e.g., 2 nodes). Include mechanisms to observe the enabled status of key actions and to bound exploration depth for testing purposes. The model checking setup should exercise certain internal evaluation paths involving sequence operations and state access.
