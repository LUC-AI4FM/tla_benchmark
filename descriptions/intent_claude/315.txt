# Specification Request: Binary Search Algorithm

## System to be Modeled

A binary search algorithm operating on a sorted sequence of integers, searching for a specific key value.

## Goal

Create a formal specification of the binary search algorithm that can be verified for correctness across all possible input sequences and search keys within a bounded integer domain. The specification should model the step-by-step execution of the search process.

## Functional Requirements

1. **Input**: The algorithm takes two inputs:
   - A sequence of integers (assumed to be sorted)
   - A key value to search for

2. **Behavior**: The algorithm should repeatedly narrow down the search range by comparing the key against the middle element of the current range, adjusting the bounds accordingly until either:
   - The key is found, or
   - The search range is exhausted

3. **Output**: The algorithm should return a value indicating either:
   - The position where the key was found, or
   - An indication that the key is not present in the sequence

4. **Termination**: The algorithm must eventually terminate for any valid input.

## Constraints

- All integer arithmetic must be performed within a fixed bit-width (8-bit signed integers), meaning the specification must account for potential overflow issues in index calculations
- The specification should be parameterized to allow reasoning about arbitrary input sequences and keys, not just specific test cases

## Correctness Properties

1. **Termination**: The algorithm must always terminate within a bounded number of steps
2. **Soundness**: If the algorithm reports finding the key at a position, the key must actually be at that position in the sequence
3. **Completeness**: If the key exists in a sorted input sequence, the algorithm must find it
4. **Progress**: Each iteration must make progress toward termination (the search range must strictly decrease)

## Verification Approach

The specification should support symbolic reasoning over all possible input sequences and key values of appropriate types, rather than just checking specific concrete test cases.
