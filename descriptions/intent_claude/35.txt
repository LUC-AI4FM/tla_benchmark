Write a formal specification for an internal utility module that provides primitive folding and sequence construction operations for use by a model checker's internal rewriting system.

## System Description

The module should define foundational operators that enable aggregate computations over collections. These operators are not meant for direct use by specification authors, but rather serve as internal building blocks that the model checker can intercept and replace with optimized implementations during analysis.

## Required Operations

1. **Fold over sets**: An operator that combines all elements of a set into a single accumulated value, given a binary combining function and an initial value. This enables expressing computations like summation, counting, or any reduction over set elements.

2. **Fold over sequences (left fold)**: An operator that processes a sequence from left to right, threading an accumulator through successive applications of a binary combining function. This supports sequential reductions where order matters.

3. **Sequence construction from a generating function**: An operator that builds a sequence of a specified length by applying a function to each index position (1 through N). This provides a more direct way to construct sequences than converting from function notation.

## Key Requirements

- All operators should have well-defined type signatures that support generic element types for both the accumulator and collection elements
- The operators must serve as hook points that the model checker can recognize and replace with semantically equivalent but more efficient internal encodings
- The module exists to break circular dependencies between the model checker's core system and higher-level library modules
- Placeholder implementations may return trivial values since the actual computation is handled by the model checker's internal rewiring mechanism
