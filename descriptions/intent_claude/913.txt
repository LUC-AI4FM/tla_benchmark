# Specification Request: Internal Memory System

## System Overview

I need a formal specification for an internal memory subsystem that handles read and write requests from multiple processors. The system should model how processors interact with a shared memory through a request-response protocol.

## System Description

The system consists of:
- A shared memory that maps addresses to values
- Multiple processors that can issue memory operations
- A communication interface between processors and the memory subsystem

Each processor should be able to:
1. Issue read requests to retrieve values from specific memory addresses
2. Issue write requests to store values at specific memory addresses
3. Receive responses after their requests have been processed

## Behavioral Requirements

The memory system must implement a three-phase protocol for each processor:
1. **Request acceptance**: When a processor is idle, it can submit a new memory request (either read or write)
2. **Request processing**: The system processes the pending request by either updating memory (for writes) or fetching the value (for reads)
3. **Response delivery**: After processing, the system sends an appropriate response back to the processor

For write operations, the memory should be updated with the new value. For read operations, the current value at the requested address should be returned to the processor.

## Concurrency Model

- Multiple processors operate concurrently and independently
- Each processor handles one request at a time (no pipelining within a single processor)
- The system should allow different processors to be in different phases simultaneously

## Correctness Properties

The specification must guarantee **type safety**: 
- Memory always maintains a valid mapping from addresses to values
- Each processor's control state is always one of the valid protocol phases
- Each processor's buffer contains either a pending request, a value to be returned, or is empty, as appropriate for the protocol phase

## Interface Requirements

The system should integrate with an external memory interface that defines:
- The set of valid processors, addresses, and values
- The format of memory requests
- How requests are sent and responses are received through the interface
