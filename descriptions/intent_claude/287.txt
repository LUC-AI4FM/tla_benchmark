# Specification Request

## System Overview

I need a formal specification for a simple integer counter system that can be incremented, decremented, or left unchanged at each step.

## Functional Requirements

The system should model a single integer value that:
- Starts at zero
- Can increase by one
- Can decrease by one
- Can remain the same

At each step, the system non-deterministically chooses one of these three operations.

## Correctness Properties

The key property to verify is whether the counter **always remains at zero**. This is expected to be violated since the system can increment or decrement away from zero, but specifying this invariant allows exploration of how the system can deviate from its initial state.

## Analysis Requirements

For state space exploration and model checking purposes, I want to be able to analyze system behaviors based on the **sign of the counter** rather than its exact value. Specifically, states should be grouped into three equivalence classes:
1. Counter is negative
2. Counter is positive  
3. Counter is zero

This abstraction should help reduce the state space when checking properties or generating counterexamples, focusing on qualitative behavior (which "region" the counter is in) rather than precise numeric values.
