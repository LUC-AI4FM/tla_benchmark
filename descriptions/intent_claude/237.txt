# Specification Request

I need a formal specification for a simple state machine system that models a variable that essentially remains unchanged.

## System Description

The system should track a single integer value that starts at zero. The system should model the possibility of state transitions, but in practice, the only meaningful behavior is that the value stays the same indefinitely.

## Behavioral Requirements

1. **Initial State**: The system begins with the value set to zero.

2. **Transitions**: The system should include:
   - A stuttering step where nothing changes
   - A theoretical alternative transition path that is structured to be logically impossible to execute (i.e., contains contradictory or unsatisfiable conditions)

## Key Properties

The main correctness property of interest is that the value should remain at its initial value forever, since no feasible transition actually modifies it. This is essentially a model of a "stuck" or "stable" system where apparent transition options are actually dead code paths.

## Purpose

This specification appears designed to test how a model checker handles unreachable code paths or logically impossible transitions within a disjunctive next-state relation.
