Write a TLA+ specification demonstrating mutually recursive procedures that determine whether a natural number N is even or odd. The system models two procedures, Even and Odd, that call each other recursively: Even returns true if its argument is zero, otherwise it delegates to Odd with the argument decremented by one, and Odd returns false if its argument is zero, otherwise it delegates to Even with the argument decremented by one. The main program calls Even on the constant N and then prints the resulting boolean. The key correctness property is termination: the computation must always eventually complete regardless of the value of N. The specification should use N = 6 as the concrete test case and verify that across all reachable states, the Odd procedure is entered exactly 3 times and the transition from Even into Odd occurs exactly 3 times, confirming the expected recursive call pattern for an even input of 6.
