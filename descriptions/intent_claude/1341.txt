# Specification Request

I need a formal specification for an empty or minimal system template.

## System Description

I want to model a system that serves as a blank starting point or placeholder. This could represent:

- A null system with no state or behavior
- A template structure for future specification development
- A trivially correct system that performs no operations

## Requirements

The system should:

1. Represent the simplest possible valid specification
2. Contain no state variables or transitions
3. Serve as a baseline that can be extended with actual system behavior later

## Correctness Properties

Since this is an empty system:

1. It should be trivially safe (no bad states can be reached because no states exist)
2. It should be trivially consistent (no invariants can be violated)
3. Any properties should hold vacuously

## Purpose

This specification is intended as either:
- A starting template for developing new specifications
- A placeholder module that can be imported or referenced
- A demonstration of the minimal valid TLA+ module structure
