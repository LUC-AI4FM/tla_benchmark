# Specification Request: Generalized Water Jug Puzzle

## System Overview

I need a formal specification for the classic water jug measuring puzzle, generalized to work with any number of jugs of arbitrary capacities. This is the type of puzzle famously featured in "Die Hard 3," where characters must measure an exact quantity of water using unmarked jugs.

## Problem Description

The system models a collection of water jugs, each with a known fixed capacity but no measurement markings. The goal is to determine whether it's possible to measure out an exact target quantity of water, and if so, to find a sequence of actions that achieves this.

## Available Operations

The only operations permitted are:
1. **Fill a jug completely** from an unlimited water source
2. **Empty a jug completely** (pour all water out)
3. **Pour water from one jug into another** until either the source jug is empty or the destination jug is full (whichever happens first)

All jugs start empty. Water cannot be measured or estimated—only the physical constraints of the jugs determine how much water moves.

## Configuration Parameters

The specification should be parameterized by:
- The set of available jugs (can be any finite collection)
- The capacity of each jug (positive integers)
- The target quantity to measure (a natural number)

## Correctness Properties

The key property to verify is **reachability of the goal state**: whether there exists any sequence of valid operations that results in at least one jug containing exactly the target amount of water.

Rather than proving this as a safety property directly, the specification should support using a model checker to find a solution by searching for a counterexample to the claim "no jug ever contains the goal amount." A counterexample trace would demonstrate the sequence of moves needed to solve the puzzle.

## Purpose

This specification enables:
1. Determining if a given puzzle configuration is solvable
2. Finding an explicit solution (sequence of moves) when one exists
3. Exploring how the puzzle generalizes beyond the classic two-jug or three-jug versions
