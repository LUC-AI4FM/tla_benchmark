# Specification Request: Functional Test Suite for Set Operations

## System to Model

I need a formal specification that serves as a comprehensive test suite for validating the correctness of set-theoretic operations in a model checker or verification tool. This is essentially a static verification harness—not a dynamic system—that checks whether fundamental set operations behave according to their mathematical definitions.

## Goal

The purpose is to verify that a tool correctly implements standard set operations when sets are constructed in various ways, including cases where internal representations might contain duplicates or "ghost" elements (elements that were filtered out but may persist in internal data structures). The tests should pass as invariants that hold in all states.

## Requirements

The specification must test the following set operations for correctness:

1. **Set equality and inequality**: Verify that sets with the same elements are equal regardless of how they were constructed, and that distinct sets are recognized as unequal.

2. **Basic set operations**: Union, intersection, and set difference must produce the mathematically correct results.

3. **Cartesian product**: The cross product of sets must yield all ordered pairs and have the correct cardinality.

4. **Cardinality**: The size computation must return the correct count of distinct elements, including for empty sets and sets of sets.

5. **Membership testing**: Both positive membership (element is in set) and negative membership (element is not in set) must work correctly.

6. **Subset relations**: The subset-or-equal relation must correctly identify when one set is contained in another.

7. **Set comprehensions and mapping**: Filtering sets by predicates and mapping functions over sets must produce correct results.

8. **Power sets**: The set of all subsets must be correctly computed, with proper cardinality and membership.

9. **Distributed union**: Flattening a set of sets into their union must work correctly.

10. **Quantifiers over sets**: Universal and existential quantification over set elements must evaluate correctly.

11. **Choice operators**: Selecting an element satisfying a predicate from a set must return a valid element when one exists.

12. **Finite set detection**: The system must correctly identify finite versus infinite sets.

## Key Correctness Properties

All test predicates must evaluate to true. The specification should be structured so that the conjunction of all tests can serve as a system invariant—if the invariant holds, all set operations are implemented correctly. Any test failure indicates a bug in the underlying set implementation.
