# Specification Request

I need a formal specification to verify the correctness of set-theoretic operations involving function sets and union constructions.

## System Description

This is not a dynamic system but rather a verification of mathematical properties concerning:
- Functions (mappings) constructed from domain-value pairs
- Function set notation (the set of all functions from a domain to a codomain)
- Union operations over collections of function sets

## Goal

The specification should serve as a test case or verification that certain equivalent mathematical expressions are properly recognized as equivalent by the specification language or model checker.

## Key Properties to Verify

1. **Function membership in union of function sets**: Verify that a specific function (mapping 0 to 1) is correctly identified as a member of a union of function sets, where the union is taken over a collection containing a single domain set.

2. **Existential formulation equivalence**: Verify the same membership property expressed as an existential statement—that there exists a domain in the collection such that the function belongs to the corresponding function set.

## Correctness Requirements

The two formulations of membership should be logically equivalent:
- Direct membership in a UNION of function sets constructed via set comprehension
- Existential quantification over the same collection with direct function set membership

This specification appears designed to test whether a verification tool handles these equivalent formulations consistently, particularly around the interaction of union operations with function set constructors.
