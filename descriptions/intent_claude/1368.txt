# Specification Request

I need a formal specification for a minimal system that demonstrates module composition and variable binding across module boundaries.

## System Description

The system should model a simple static state machine where:

1. A primary module maintains a single piece of state (a set)
2. This state is shared with a secondary module through variable substitution/binding
3. The secondary module defines what constitutes the complete system state

## Behavioral Requirements

- The system should initialize with an empty set as its state
- After initialization, the system should remain completely unchanged—no state transitions occur
- The definition of "all variables" should come from the imported module rather than being defined locally

## Key Properties

- **Stability**: Once initialized, the system state never changes
- **Modularity**: The specification must demonstrate that variable definitions can be imported from other modules and used to define stuttering/unchanged behavior
- **Correct Binding**: When instantiating the helper module, the local state must be properly bound to the imported module's variable

## Purpose

This appears to be a test case for verifying that a model checker correctly handles module instantiation with variable substitution, particularly when the imported module's definitions (like a tuple of all variables) are used in the main module's transition relation.
