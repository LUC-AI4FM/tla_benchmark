# Specification Request: Test Suite for Extended Sequence and Set Operations

## Overview

I need a formal specification that serves as a **compatibility test suite** for an extended library of sequence and set operations. The goal is to verify that a symbolic model checker's implementations of these extended operators produce results consistent with the standard TLA+ semantics.

## System Purpose

This specification should validate the correctness of several higher-order operations that extend the basic TLA+ standard library:

1. **Left fold over sequences**: An operation that iteratively applies a binary function to accumulate a result from a sequence, processing elements left to right.

2. **Sequence construction from a function**: An operation that generates a sequence of a given length where each element is computed by applying a function to its 1-based index.

3. **Function-to-sequence conversion**: An operation that converts a function with a domain of consecutive integers (1 to n) into an equivalent sequence representation.

4. **Non-deterministic selection ("guess")**: An operation that selects an arbitrary element from a non-empty set, useful for modeling non-determinism.

5. **Fold over sets**: An operation that accumulates a result by applying a binary function across all elements of a set.

## Key Correctness Properties

The specification must verify:

- **Fold correctness**: Left-folding addition over a sequence of integers yields their sum; folding concatenation over a sequence of sequences yields their flattening.

- **Identity behavior**: Folding over empty sequences returns the initial accumulator value unchanged.

- **Composition**: The extended operations must compose correctly with standard operations like `SubSeq`, `Tail`, `SelectSeq`, and sequence concatenation.

- **Sequence construction**: Constructing a sequence of length n using a doubling function produces the expected even numbers; construction of length zero yields an empty sequence.

- **Function conversion**: Functions mapping consecutive integers produce equivalent sequences; empty-domain functions convert to empty sequences.

- **Set selection**: The guess operator returns an element that actually belongs to the input set, particularly when filtering reduces the candidate sets.

- **Set fold with duplicates**: Folding over sets correctly handles the mathematical set semantics (ignoring representation-level duplicates).

## Constraints

The test suite should be structured as a collection of boolean assertions that can be checked as invariants, where each assertion validates one specific behavior of the extended operators.
