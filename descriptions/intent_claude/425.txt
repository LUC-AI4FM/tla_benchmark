# Specification Request: Integer Decrement Counter

## System Description

I need a formal specification for a simple countdown counter that operates over negative integers. The system should model a counter that starts at a negative value and decrements until it reaches a stopping point.

## Behavioral Requirements

1. The counter should initialize to -1
2. On each step, the counter should decrement by 1 (moving further into negative numbers)
3. The counter should stop decrementing once it reaches -3, at which point it remains at that value indefinitely

## Key Properties

- The specification should demonstrate compatibility with integer arithmetic, including negative numbers
- The system should be able to use mathematical operations from standard library modules that support both natural numbers and integers

## Purpose

This specification serves primarily as a test case to verify that a formal modeling language can correctly handle the combination of modules that provide natural number operations alongside integer operations, ensuring negative number arithmetic works correctly when these capabilities are composed together.
