# Specification Request

## System Overview

I need a formal specification for a simple state transition system that manages two distinct collections of typed elements, where the system must maintain continuous coverage across these collections as it transitions between states.

## System Description

The system should model a single-step state machine with two phases:
- An initial phase where one collection is empty and another contains a designated element
- A subsequent phase where the collections swap their populated/empty status, with the first collection now containing its own designated element

The system operates with two distinct types of elements (which should be treated as uninterpreted/model values for verification purposes), each with a representative constant of that type.

## Requirements

1. **Initial State**: The system begins with the first collection empty and the second collection containing its designated typed element. The system should also track which phase it is in.

2. **State Transition**: The system performs a single transition where:
   - The first collection becomes populated with its designated element
   - The second collection becomes empty
   - The phase indicator updates accordingly

## Key Correctness Property

**Coverage Invariant**: At all times, at least one of the two designated elements must be present in its respective collection. There must never be a state where both collections are simultaneously missing their designated elements.

This property ensures that the system maintains a form of "handoff" guarantee—before one element is removed from its collection, the other element must already be present in its collection.
