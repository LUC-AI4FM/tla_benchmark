# Specification Request: Binary Search Algorithm Verification

## System to Model

I need a formal specification of the classic binary search algorithm as implemented in standard library functions (like Java's `Arrays.binarySearch`). The goal is to verify that the algorithm correctly searches for a key in a sorted sequence and handles both successful and unsuccessful searches properly.

## Functional Requirements

The algorithm should:

1. Search for a given key within an input sequence of integers
2. Maintain a search interval that narrows with each step by comparing the key against the middle element
3. When the key is found, return its index (using 0-based indexing)
4. When the key is not found, return a negative value that encodes the insertion point
5. Terminate in all cases

The specification should be parameterized by:
- An input sequence to search
- A key value to find
- A bit-width for machine integers (to enable analysis of potential overflow issues)

## Correctness Properties

The specification must verify the following properties:

1. **Correct positive result**: If the key exists in the sequence, the algorithm returns a valid index where that key is located (return value ≥ 0)

2. **Correct negative result**: If the key does not exist in the sequence, the algorithm returns a negative value (return value < 0)

3. **Sorted input assumption**: The correctness guarantees should hold when the input sequence is sorted in non-decreasing order. The specification should make this precondition explicit.

4. **Bounded arithmetic**: The specification should define the bounds of signed and unsigned integers for a given bit-width, enabling future analysis of integer overflow vulnerabilities in the midpoint calculation.

## Verification Goal

The primary goal is to verify that for all possible inputs (within the bounds of a fixed bit-width), when the algorithm terminates on a sorted sequence, the return value correctly indicates whether the key was found—specifically, that a non-negative return value is produced if and only if the key exists in the sequence.
