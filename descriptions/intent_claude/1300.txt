# Specification Request

## System Description

I need a formal specification for an extremely simple state machine that demonstrates how to express and verify constraints on configuration parameters (constants) that are provided at model-checking time, independent of the system's dynamic behavior.

## Behavioral Requirements

The system itself should be trivial:
- It starts in an initial "off" or "inactive" state
- It can transition exactly once to an "on" or "active" state
- Once activated, no further meaningful state changes occur

## Configuration Requirements

The system should accept a configuration parameter that represents a set of values. This parameter is fixed before the system runs and does not change during execution.

## Correctness Properties

The key property to verify is a **constraint on the constant parameter itself**: the configured set must contain only natural numbers (non-negative integers). This invariant should hold regardless of the system's state and serves to validate that the model has been instantiated with legal configuration values.

## Purpose

This specification should illustrate the pattern of using invariants to check properties of constants/parameters rather than (or in addition to) properties of the dynamic state. This is useful for catching configuration errors at model-checking time.
