# Specification Request: 12-Hour Clock

## System Description

I need a formal specification of a simple 12-hour clock system. The clock displays an hour value that cycles through the numbers 1 through 12, similar to an analog clock face.

## Desired Behavior

The system should model a clock that:

1. Starts at some valid hour between 1 and 12
2. Advances by incrementing the hour value
3. Wraps around from 12 back to 1, continuing the cycle indefinitely

The clock should be allowed to stutter (remain unchanged) at any point, representing the passage of time between hour changes.

## Correctness Properties

The specification must guarantee:

1. **Type Safety**: The hour value must always remain within the valid range of 1 to 12, inclusive. The clock should never display 0, 13, or any other invalid hour.

2. **Invariant Preservation**: Any state reachable from a valid initial state must also be a valid clock state.

## Notes

This is a basic cyclic counter model. The specification should be minimal but complete enough to verify that the hour value never escapes its valid domain throughout all possible executions of the system.
