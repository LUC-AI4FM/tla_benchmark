I need to specify a simple utility for representing an unordered pair of two elements.

**System Description:**

I need a basic mathematical construction that takes two elements and produces a set containing exactly those two elements. This is essentially a way to represent an unordered pair, where the relationship between the two elements is symmetric—there's no notion of "first" or "second" element, just membership in the pair.

**Requirements:**

1. Given any two elements, the system should produce a collection (specifically, a set) containing both elements.

2. The construction should be symmetric: providing elements in either order should yield the same result.

3. If both inputs happen to be the same element, the result should be a singleton set containing just that element (standard set behavior).

**Correctness Properties:**

- Both input elements must be members of the resulting set.
- No elements other than the two inputs should be in the resulting set.
- The operation should be commutative with respect to its inputs.
