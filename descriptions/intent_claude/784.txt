Specify a model of Conway's Game of Life cellular automaton on a finite two-dimensional grid.

**System Description:**
The system represents a square grid of cells, where each cell can be either alive or dead. The grid has a fixed size N×N. The simulation should evolve the grid state according to the standard Game of Life rules, treating cells outside the grid boundaries as permanently dead (fixed boundary conditions).

**Behavioral Requirements:**
- The grid should be able to start from any arbitrary initial configuration of live and dead cells
- At each step, the entire grid updates simultaneously based on the number of live neighbors each cell has
- A live cell survives to the next generation if it has exactly 2 or 3 live neighbors; otherwise it dies
- A dead cell becomes alive in the next generation if it has exactly 3 live neighbors; otherwise it remains dead
- Neighbors are defined as the 8 adjacent cells (horizontal, vertical, and diagonal)
- Cells on the edges and corners of the grid have fewer than 8 in-bounds neighbors; out-of-bounds positions should be treated as dead when counting neighbors

**Correctness Properties:**
- The grid state should always be a valid mapping from positions to alive/dead states
- The evolution rule should be deterministic: given any grid configuration, the next state is uniquely determined
