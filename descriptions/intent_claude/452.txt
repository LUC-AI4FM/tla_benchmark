# Specification Request: Modular Counter System

## System Overview
I need a formal specification for a simple cyclic counter that counts through a fixed range of values and wraps around when it reaches the maximum.

## Functional Requirements
The system should model a counter with the following behavior:
- The counter starts at zero
- On each step, the counter increments by one
- When the counter reaches its maximum value (4 in this case), it wraps back around to zero on the next increment
- The counter cycles through exactly 5 distinct values: 0, 1, 2, 3, 4, and back to 0

## Behavioral Characteristics
- The system should allow stuttering steps where the counter value remains unchanged
- The counter should operate deterministically—given any state, the next value (if changed) is always predictable
- The counting behavior should continue indefinitely in a cyclic pattern

## Purpose
This specification is intended to serve as a foundation for testing parametrized instantiation, where this module could be instantiated by other specifications with different parameters or used to verify modular composition of specifications.

## Correctness Properties to Consider
- The counter value should always remain within the valid range (0 through 4)
- The counter should eventually cycle through all values (under fairness assumptions)
- The increment operation should preserve the cyclic invariant
