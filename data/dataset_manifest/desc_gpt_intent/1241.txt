Specify a TLA+ specification for a translator from a parsed, macro-expanded PlusCal-style algorithm into its corresponding TLA+ specification. The input should be an abstract syntax tree for either a single-process or multi-process algorithm, including declarations, optional procedures, labeled statements, conditionals, loops, nondeterministic choice, scoped choice, guards, assignments, assertions, printing, procedure calls/returns, and jumps. The output should be represented abstractly as a sequence of TLA+ lexemes, not with precise pretty-printing.

The generated specification must declare all algorithm variables, define the initial predicate, per-label actions, the overall next-state action, the complete temporal specification, and a termination predicate. It must preserve PlusCal control flow by enabling exactly the action for the current control location, implement atomic multiple assignment with unchanged variables made explicit, model procedure invocation and return with saved local state, and index process-local state correctly in multi-process algorithms. It should support no fairness, weak fairness per action, weak fairness of the whole next action, or strong fairness per action.
