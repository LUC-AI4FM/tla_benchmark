Specify a small TLA+ demonstration module modeling a finite computation over two pieces of state: one set of strings and one finite sequence of integers. Initially, the string set contains exactly `"a"` and `"b"`, and the integer sequence is exactly `<<1, 2, 3>>`. The computation should update the set so that it also contains `"c"`, update the sequence so that its second element becomes `4` while the other positions remain unchanged, and print or otherwise expose the resulting updated values.

The model is intended as a simple example of set union, sequence update, and printing, not as a concurrent protocol. It should have a well-defined terminating state and allow stuttering after termination so that the behavior is non-deadlocking. The key safety property is that any completed behavior ends with the set exactly `{"a", "b", "c"}` and the sequence exactly `<<1, 4, 3>>`. The key liveness property is that termination is eventually reached.
