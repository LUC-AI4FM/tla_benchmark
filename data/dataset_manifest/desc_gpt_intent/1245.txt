Specify a TLA+ specification for a partial, executable model of a translator from a parsed, macro-expanded global-naming PlusCal algorithm into its corresponding TLA+ description. The model should define the accepted abstract syntax trees for uniprocess and multiprocess algorithms, including declarations, procedures, processes, labeled statements, expressions, assignments, guards, conditionals, nondeterministic choice, loops, procedure calls and returns, gotos, assertions, printing, and skips.

The translator should produce a sequence of TLA+ lexemes representing declarations, initialization, action definitions, the next-state relation, the complete temporal specification, optional fairness assumptions, and a termination predicate. The generated behavior must preserve PlusCal control flow, make labeled actions executable only at the appropriate control location, implement procedure calls and returns with saved control and procedure-local state, initialize globals, locals, process-local state, and procedure state correctly, and leave all unassigned variables unchanged. Multiprocess translations must distinguish global from process-local state and quantify actions over process identities. The model should detect at least multiple assignment to one variable in an action and assignment to undeclared variables in the generated action text.
