Specify a TLA+ specification for an abstract alternating-bit data transfer protocol between one sender and one receiver. Data values come from a fixed finite set. The sender may introduce a new value only when the previous value has been acknowledged; introducing it marks it with the opposite one-bit sequence number. The receiver may accept a value only when it observes a sequence bit different from the last one it accepted, after which its delivered value becomes the sender’s current value. The sender may process an acknowledgment only when the receiver’s accepted bit differs from the sender’s recorded acknowledgment bit.

The model should allow arbitrary initial data values and an arbitrary initial bit, provided sender, receiver, and acknowledgment bits are initially consistent. It must maintain type correctness: all bits are binary and all data values remain in the data set. Safety should capture that at most one unacknowledged value is in flight and duplicate acceptance of the same bit is impossible. Under weak fairness for message delivery and acknowledgment processing, every newly sent value is eventually received and then eventually acknowledged.
