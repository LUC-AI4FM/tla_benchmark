Specify a small TLA+ demonstration model of a nondeterministic state machine whose transition relation is parameterized by a configurable unary set-valued operation. The model should have one piece of state, initialized to a distinguished non-set value, and on every transition the next state is chosen from the set returned by applying the configured operation to the current state. In the intended configuration, that operation ignores its argument and always returns the powerset of the fixed set `{1, 2, 3}`.

The specification should show that, after initialization, each transition may choose any subset of `{1, 2, 3}` independently of the previous value. The main safety property is a type invariant: the state is either the initial distinguished value or a subset of `{1, 2, 3}`, and after the first step it is always such a subset. No fairness or eventual-coverage requirement is intended; infinite behavior is possible because a successor is always available.
