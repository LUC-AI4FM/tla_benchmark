Specify a TLA+ specification for basic single-decree Paxos in an asynchronous system, with proposers and acceptors but no explicit leaders or learners. Model a finite set of acceptors, a finite set of client values, ballot numbers with an initial zero ballot, and quorums that are majorities and always intersect. The protocol should allow prepare requests, promises recording the highest ballot seen and any previously accepted value, accept requests based on a quorum of promises, acceptor acceptance unless it has promised a higher ballot, and a decision when a quorum has accepted the same ballot.

The proposer’s accept value must follow Paxos rules: if the promise quorum reports no previously accepted value, any real value may be chosen; otherwise the value with the highest reported accepted ballot must be used. The main safety properties are type correctness, nontriviality that any learned value was actually proposed in an accept request, and consistency that at most one value can ever be learned. Do not require guaranteed termination in all executions.
