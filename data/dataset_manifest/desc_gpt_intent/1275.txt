Specify a very small TLA+ demonstration model of a system with a single integer-valued state component. The model should describe an initialization rule in which the initial value is chosen nondeterministically from the set containing 0 and 1, but is also constrained to be strictly less than 1, so the only permitted initial value is 0. After initialization, the system performs no real state-changing behavior; every subsequent step leaves the state exactly as it was, allowing only infinite stuttering behavior.

The main safety property to check is that the state component is always strictly less than 1. This property should hold because the initialization constraint establishes it and the transition relation never changes the state. There are no meaningful progress or fairness requirements beyond the existence of an infinite behavior that can stutter forever. The specification is intended as a minimal test or demonstration of constrained initialization and invariant preservation.
