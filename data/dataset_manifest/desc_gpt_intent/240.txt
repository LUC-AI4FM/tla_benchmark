Write a TLA+ specification for a minimal demonstration model with one state component whose value comes from a fixed constant of an abstract type. The initial state should set that component to the configured constant value, and every subsequent transition should leave the component unchanged, so all behaviors are infinite stuttering behaviors after initialization. The model is intended mainly as a small utility/test specification, not a real algorithm: it should exercise use of a typed constant assigned to state and a transition relation that preserves state exactly. The essential safety guarantee is that the state component never changes from its initial constant value in any reachable state. There are no meaningful progress requirements beyond allowing the behavior to continue forever by stuttering. Include a trivial invariant check, since the purpose is to confirm the model is well formed rather than to prove a substantive property.
