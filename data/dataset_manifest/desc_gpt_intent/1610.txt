Specify an abstract TLA+ specification for nondeterministic quicksort on a finite array of length `N` whose initial contents are arbitrary values from `1..N`. The model should represent the algorithm at a high level: maintain a collection of subranges still to be processed, repeatedly choose any pending subrange, discard it if it has size zero or one, and otherwise partition it around some pivot position strictly inside the range. Partitioning may be modeled abstractly as any permutation of the current array segment that leaves elements outside the segment unchanged and ensures every element in the left part is less than or equal to every element in the right part. The two resulting subranges should then be scheduled for later processing.

The specification should guarantee that all array states remain permutations of the initial array, that partitioning never changes elements outside the selected subrange, and that when processing finishes the final array is sorted in nondecreasing order. It should also state and check termination: every execution eventually reaches the completed state.
