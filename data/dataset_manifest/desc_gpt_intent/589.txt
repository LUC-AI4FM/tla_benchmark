Specify a TLA+ specification for a small model-checking instance of a Percolator-style transactional key-value store. Model one table with exactly two keys and two concurrent clients, where each client has a distinct primary key. Transactions should execute under arbitrary interleavings, using timestamped reads and writes, locks, commit records, abort records, and rollback records as needed to represent the protocol, including collapsed rollback behavior.

The specification should capture the essential safety requirements of the protocol: all states are well typed; locks and write records are consistent with the transaction that created them; committed and aborted transaction metadata cannot contradict each other; rollback information is consistent with aborted or absent writes; no two distinct writes may occupy the same key/timestamp position; and every committed execution must satisfy snapshot isolation, so concurrent transactions cannot both commit conflicting writes visible in the same snapshot. The model is intended primarily for exhaustive TLC safety checking; no separate progress or fairness guarantee is required beyond permitting all protocol behaviors.
