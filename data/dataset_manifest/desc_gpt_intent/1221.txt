Specify a small finite-state TLA+ model, intended as a model-checker fingerprint test, for a LazyCache-like system with a fixed finite set of addresses, data values, processors, and a distinguished “no data” value. The model should include a global store mapping every address to a data value, per-processor local cache contents that map each address either to a data value or to the no-data marker, and bounded per-processor input and output sequences. Initially, the store contains only allowed initial data values, each cache entry either matches the corresponding initial store value or is no-data, and all sequences are empty. The behavior should allow arbitrary nondeterministic changes within the finite type domains, including store changes, cache changes, and enqueue/dequeue of bounded input and output records. Input records may represent ordinary data/address pairs or marked variants; output records are data/address pairs. The required safety property is type correctness and preservation of the configured sequence length bounds. No fairness or progress guarantee is required.
