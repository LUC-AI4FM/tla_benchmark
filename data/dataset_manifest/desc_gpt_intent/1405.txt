Specify a small TLA+ demonstration module for a one-shot service that starts in a pending state with a fixed sequence containing the values 1, 2, and 3. The service has a single meaningful operation: when pending, it completes by setting its result/status value to 1 and updating the sequence to keep only elements different from that completed result value. Thus, after completion, the remaining sequence should exclude all 1s and preserve the order of the other elements.

The specification should allow stuttering behavior, but should constrain all non-stuttering behavior to this single completion operation. Once the operation has completed, it must no longer be enabled and the system may only stutter forever.

Include weak fairness for the completion operation, so the system cannot remain forever in the initial pending state by stuttering while the operation is continuously enabled. The key liveness property is that the service eventually reaches a terminal state in which the completion operation is permanently disabled.
