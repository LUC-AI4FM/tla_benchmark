Specify Dijkstra’s classical self-stabilizing token ring algorithm for a unidirectional ring of N processes, with one distinguished process and all process values drawn from a finite modulo-M domain. Assume N and M are positive and the value domain is large enough for stabilization, specifically N ≤ M + 1. The model should allow arbitrary initial assignments of local values within the domain. It should capture the algorithm’s intended moves: the distinguished process can advance its value modulo M to create/advance the token under the appropriate local condition, while every other process can adopt its predecessor’s value when it is out of sync.

The specification must preserve type correctness: every local value always remains in the finite modulo domain. Under weak fairness for system progress, it must establish self-stabilization: from every initial state, the system eventually reaches a configuration with exactly one token/privilege in the ring, and from then on every reachable configuration continues to have exactly one token.
