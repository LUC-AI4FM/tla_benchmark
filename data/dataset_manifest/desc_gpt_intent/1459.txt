Specify a small TLA+ specification for a simple bounded counter demonstration. The system consists of one integer counter that initially has value 0. During execution, the counter may either remain unchanged or, while it is below the threshold value 3, increase by exactly one. Once the counter has reached 3, it must never change again. The model should allow arbitrary stuttering at any point, including infinite stuttering before the counter reaches the threshold; therefore it should not require eventual progress or fairness.

The key safety requirements are that the counter never becomes negative, never exceeds 3, never decreases, and never changes by more than one in a single non-stuttering transition. If the counter is already at the threshold, all future states must keep it at that threshold. The specification is intended as a minimal no-error test/example rather than a full application protocol.
