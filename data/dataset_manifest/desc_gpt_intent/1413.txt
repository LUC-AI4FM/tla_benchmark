Specify a very small TLA+ demonstration module for checking a basic temporal-logic tautology over a trivial state machine. The modeled system should contain one state component that is initialized to a fixed value and is never modified by any transition; all allowed behaviors are infinite stuttering behaviors in which the state remains constant forever.

The specification should make clear the safety requirement that the state component always retains its initial value throughout every behavior. It should not require any progress, fairness, or real operational activity, since the system is intentionally inert.

The main property to state and verify is a pure temporal-logic validity: if truth eventually holds, then eventually truth holds forever. Since the proposition involved is simply logical truth, the property should be satisfied independently of the state machine’s behavior. This module is intended as a minimal regression or proof-checking example rather than a model of a practical distributed or concurrent algorithm.
