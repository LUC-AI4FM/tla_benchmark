Write a TLA+ specification for a small demonstration model that exercises a recursively defined factorial computation inside state transitions. The model should have one numeric state component, initially set to zero. Define factorial recursively over positive natural inputs, with the usual base case at one, and use it in the transition relation.

At each non-stuttering step, the system may update the state component to either the factorial of 3 or the factorial of 9. Stuttering steps must also be allowed, so the behavior may remain unchanged forever and no fairness or progress requirement should be imposed.

The key safety requirement is that all reachable state values are limited to the initial value and the two factorial results: 0, 6, and 362880. Any actual state change must produce one of the two factorial results. The specification should serve as a utility/test module demonstrating that recursive definitions used in actions are handled finitely and do not cause unbounded recursion during model checking analysis such as coverage or cost computation.
