Specify a small TLA+ demonstration module that exercises random sampling from a very large finite set without explicitly enumerating the entire set. The model should define a finite domain of integer keys and a finite integer codomain, consider the set of all total functions from the domain to the codomain, and initialize the system by choosing one function from a randomly generated sample of 1,000 such functions. The intended purpose is to test that the randomization mechanism can handle sampling from a function space whose full cardinality is far too large to enumerate during model checking.

After initialization, the system should not perform any meaningful state changes; it may only stutter forever. The essential safety requirement is that the chosen value, if any behavior is produced, is a well-formed total function from the specified domain to the specified codomain. There are no additional substantive invariants or progress requirements beyond existence of the initial sampled choice and infinite stuttering behavior.
