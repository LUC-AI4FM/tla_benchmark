Specify a small TLA+ demonstration model for checking subset constraints in next-state expressions and for validating TLC’s reporting of possible state/action predicates. The model should have a mutable set-valued state component and a second state component representing the fixed universe {1,2,3}. Initially, the mutable set may be any subset of {1,2}, while the universe component is exactly {1,2,3}. On each step, the universe component remains unchanged, and the next value of the mutable set may be any subset of that universe.

The specification must guarantee that every reachable mutable set is a subset of {1,2,3}, that the universe component never changes from {1,2,3}, and that from every reachable state it is possible to choose a next mutable set contained in {1}. Also include TLC checks demonstrating that the full-universe mutable set is observed exactly eight times and that transitions newly adding element 3 are observed exactly sixteen times.
