Specify a small TLA+ model-checking test for a lazy-cache-like system with a finite set of addresses, data values, processors, and bounded per-processor queues. The model should include a shared memory mapping each address to a data value, a private cache for each processor where each cached address may hold either a data value or a distinguished “no data” marker, and per-processor input and output streams. Initially, memory contains only allowed initial data values, each cache entry either matches the corresponding initial memory value or is marked no-data, and all streams are empty.

The behavior should deliberately over-approximate the system: memory contents, cache contents, and stream contents may evolve nondeterministically as long as they remain within their declared domains and stream length bounds. Input streams contain bounded sequences of cache-operation records, and output streams contain bounded sequences of data/address pairs. The key safety property is a type and bounds invariant for all components. No progress or fairness requirement is needed; stuttering is allowed.
