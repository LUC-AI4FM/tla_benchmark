Specify a TLA+ specification for a small TLC test model of an asynchronous spanning-tree construction algorithm on a finite undirected graph whose edges are chosen randomly for each run. The model should take a finite set of nodes, a distinguished root, and a maximum distance bound at least as large as the number of nodes. Each node maintains a parent pointer and a natural-number distance label, initially pointing to itself, with the root at distance zero and all others at the maximum bound.

The algorithm should allow nodes to improve their distance by adopting a neighboring node with a smaller distance as parent, modeling nondeterministic asynchronous progress under weak fairness. The specification must preserve type correctness: parent pointers refer to nodes, distances are natural numbers, and graph edges are two-element subsets of the node set.

Correctness should state that convergence eventually occurs, and that any quiescent state is well formed: the root remains its own parent at distance zero, unreachable nodes remain self-parented at the maximum distance with no lower-distance neighbor, and all other nodes point to a neighbor whose distance is exactly one less.
