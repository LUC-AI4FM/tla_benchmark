Specify a TLA+ specification for a simple asynchronous one-place data interface using a two-phase handshake between a sender and a receiver. The interface carries values drawn from a fixed set of data items and uses two binary handshake indicators, one controlled by the sender and one by the receiver. Initially there is no outstanding item: the two indicators agree, while the stored data value may be any allowed data item.

The sender may place an arbitrary allowed data item into the interface only when the previous item has been acknowledged; doing so toggles the sender’s indicator. The receiver may accept the currently stored item only when an unacknowledged item is present; doing so toggles the receiver’s indicator. Thus sends and receives must alternate, ignoring stuttering steps, and there can never be more than one outstanding unacknowledged item.

Require safety invariants ensuring the stored value is always from the data set and both handshake indicators remain binary. No nontrivial liveness guarantee is required; infinite stuttering is permitted.
