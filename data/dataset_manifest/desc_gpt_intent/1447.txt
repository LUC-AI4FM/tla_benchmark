Specify a small TLA+ demonstration model of two independent binary state values. Both values should initially be zero. On each non-stuttering transition, each value is chosen independently from the set {0, 1}; the model may also allow stuttering behavior. The purpose is to illustrate that two separate nondeterministic or random choices over the same finite set are not guaranteed to produce the same result, even when they start equal.

The specification should ensure the basic safety condition that both state values always remain binary. It should also include, as a checked assertion for demonstration purposes, the intentionally over-strong claim that the two values are always equal. A model checker should be able to find a counterexample to that equality claim after a transition where the two independent choices differ. No meaningful liveness requirement is needed beyond permitting the transition relation to continue indefinitely.
