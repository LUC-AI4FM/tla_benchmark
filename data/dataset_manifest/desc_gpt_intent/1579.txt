Specify Dijkstra’s self-stabilizing token-ring algorithm for a finite ring of N processes, with N positive and a counter domain of size K greater than N. Each process stores a value in the counter domain; the initial state may be arbitrary. The first process is distinguished: it is enabled when its value matches its predecessor’s value and then advances its own value modulo K. Every other process is enabled when its value differs from its predecessor’s value and then copies the predecessor’s value. Model asynchronous execution with weak fairness for each process so that a continuously enabled process eventually acts.

Define token possession according to the standard rule: the distinguished process has the token when it matches the last process, and any other process has the token when it differs from its predecessor. The specification must guarantee that some process always holds a token, and that every behavior eventually reaches and remains in a legitimate state in which exactly one process holds the token.
