Specify a small TLA+ demonstration module for a one-state Boolean transition system. The system should start in the true state. At each real, non-stuttering transition, it should compute whether a state-dependent set is empty: when the current Boolean is true, the set is nonempty; when the current Boolean is false, the set is empty. The next Boolean state is exactly the result of that emptiness test, so the state alternates between true and false on every non-stuttering transition.

The specification should allow ordinary TLA+ stuttering steps, so an execution may remain in the same state for any number of steps. The required safety properties are that the state is always Boolean, the initial state is true, and every non-stuttering transition flips the Boolean value. Do not impose fairness or progress requirements beyond the transition relation itself.
