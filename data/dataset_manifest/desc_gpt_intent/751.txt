Specify a TLA+ specification for the classic cigarette smokers synchronization problem. Model a finite set of ingredients and a set of possible dealer offers, where each offer contains all but one ingredient. There is one smoker associated with each ingredient, representing the ingredient they already possess in unlimited supply. The dealer repeatedly places one valid offer on the table. When an offer is present, exactly the smoker whose own ingredient completes the full ingredient set may smoke, and the table becomes empty. Once that smoker finishes, no smoker is smoking and the dealer may place another valid offer.

The specification should allow repeated cycles of offering, smoking, and finishing. It should maintain type correctness: smoker states are Boolean and the dealer’s table is either empty or contains a valid offer. The key safety property is mutual exclusion: at any time, at most one smoker is smoking. Under a fair version of the behavior, the system should not remain forever idle when a next offer, smoke, or finish transition is continuously possible.
