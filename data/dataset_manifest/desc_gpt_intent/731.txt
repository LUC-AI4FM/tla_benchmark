Specify a small TLA+ demonstration model of a natural-number counter intended for TLC checking with a configurable finite exploration bound. The counter should start at zero. Each allowed non-stuttering transition should increase the counter by exactly one, and stuttering behavior may be permitted. The model should be parameterized by an upper bound used as a TLC state constraint so that model checking only explores states in which the counter value is strictly below that bound.

The main safety property to state and check is that, under the configured state constraint, every reachable explored state has a counter value less than the upper bound. The counter should also remain a natural number and should never decrease. There is no required progress or fairness condition: the model is not meant to guarantee eventual increments or eventual termination, only to demonstrate bounded exploration of a simple incrementing counter.
