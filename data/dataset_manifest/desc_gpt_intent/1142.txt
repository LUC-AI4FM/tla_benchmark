Specify a TLA+ specification for a small utility that models source-location metadata used to map a selected region of generated TLA+ text back to the corresponding PlusCal text. The model should include line/column locations, ordered source regions for significant generated tokens, nested PlusCal delimiters representing syntactic units, and separators for nonadjacent PlusCal regions. A valid mapping description must contain at least one token, have properly balanced nesting, keep generated-token regions in source order, place separators only between adjacent closed and opened syntactic regions, and ensure matching and sibling PlusCal regions are ordered by location.

Given a selected TLA+ source region, the utility should determine the contiguous token range selected by it. If the region falls entirely in insignificant whitespace, it should select the nearest neighboring token, with sensible handling of boundary-touching token regions. The specification should also model computing the delimiter-depth change and minimum delimiter depth across the chosen token range. Safety should assert that these computed values equal the abstract nesting-depth definitions, and liveness should require the computation to terminate.
