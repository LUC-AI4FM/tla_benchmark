Specify a TLA+ specification for a simple asynchronous single-place communication interface using a two-phase handshake between one sender and one receiver. The interface should store a payload drawn from a fixed set of data values, plus two Boolean-style handshake indicators: one controlled by the sender to signal that a value is ready, and one controlled by the receiver to acknowledge it.

Initially, the interface is idle: the sender’s ready indication and the receiver’s acknowledgment agree, while the stored payload may be any valid data value. When idle, the sender may choose any data value, store it, and toggle its ready indication to make a message pending. While a message is pending, the sender must not overwrite the stored value or send another one. The receiver may acknowledge exactly one pending message by toggling its acknowledgment indication, returning the interface to idle.

The specification should preserve the type invariant for all reachable states. It should allow stuttering and should not require fairness or eventual progress.
