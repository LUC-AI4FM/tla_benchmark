Specify a very small TLA+ demonstration module for a degenerate state machine whose purpose is to check enabledness of a stuttering transition. The model should have a single Boolean state component, initially set to true. The system has no meaningful state-changing behavior: every allowed transition must leave the entire state exactly as it was. The specification should therefore describe an infinite behavior consisting only of stuttering steps over the initial state.

The key safety requirement is that the Boolean component is never changed and thus remains true in every reachable state. The key progress/deadlock-freedom requirement is that the next-state relation is enabled in every reachable state, since a stuttering step is always possible. No stronger liveness or fairness guarantee is required; the example is intended only to show that a transition relation that permits unchanged-state steps is continuously enabled.
