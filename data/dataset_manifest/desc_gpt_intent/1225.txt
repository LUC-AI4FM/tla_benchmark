Specify a small TLA+ demonstration model of processors issuing memory-style requests. The model should have finite sets of processors, registers, addresses, and values. Each processor maintains a bounded sequence of issued entries, initially empty. An issued entry may represent either a read/write request over an address and value or an associated register entry. In each step, some processor may issue one new request associated with some register, appending a corresponding entry to that processor’s sequence.

Also model an abstract ordering relation over currently existing request identifiers, where an identifier is the pair of a processor and a position in that processor’s sequence. The ordering may be extended when new requests are issued, but existing order facts must never be removed. It must always relate only existing request identifiers, be transitive and irreflexive, and it must respect per-processor program order: earlier entries in a processor’s sequence must precede later entries from the same processor. The key safety property is type correctness of the queues and ordering relation. No additional liveness requirement is needed beyond allowing issue steps.
