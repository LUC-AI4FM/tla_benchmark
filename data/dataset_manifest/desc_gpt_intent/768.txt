Specify a TLA+ specification for a bounded multi-producer, multi-consumer Disruptor-style ring buffer. Producers concurrently claim monotonically increasing sequence numbers, write the claimed sequence number as the event value into the corresponding ring slot, and then publish it. Consumers are multicast subscribers: every consumer must observe every published event, in sequence order, rather than competing for events.

The model should account for wraparound in a fixed-size ring buffer and ensure producers cannot overwrite a slot until all consumers have advanced far enough that the old contents are no longer needed. It should also handle producers publishing out of order: consumers may only read the contiguous prefix of events that is safely published, not later events whose predecessors are still unpublished.

The specification should be bounded by a maximum number of claimed/published events for model checking. It must include type correctness, absence of producer/consumer data races on ring slots, and a liveness property stating that, under fair consumer progress, every consumer eventually reads each event that becomes available, with the value equal to its sequence number.
