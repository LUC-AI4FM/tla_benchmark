Specify a simple twelve-hour clock as a TLA+ specification. The model should represent the clock’s displayed hour as a single state component whose value is always an integer hour from 1 through 12. Initially, the display may be any valid hour in that range. On a real clock tick, the display advances by exactly one hour; if the current display is 12, the next tick wraps around to 1. The specification may also allow stuttering steps in which the display does not change, so it should not require time to advance on every state transition.

The main safety property to establish is that the displayed hour is always valid: every reachable state must keep the display within 1 through 12. The transition relation must never produce 0, 13, or any non-hour value. No additional liveness or fairness requirement is needed; in particular, the model need not guarantee that ticks occur infinitely often.
