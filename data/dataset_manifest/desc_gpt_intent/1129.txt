Specify a TLA+ specification for a simplified Two-Phase Commit protocol with a fixed finite set of resource managers coordinated by one transaction manager. Initially every resource manager is working, the transaction manager is undecided, and no messages have been sent. A working resource manager may either prepare and send a prepared notification to the transaction manager, or independently abort. The transaction manager may learn about prepared notifications, may commit only after it has learned that every resource manager has prepared, and may instead abort while still undecided. Its final decision is broadcast as either commit or abort, and resource managers may adopt that decision when the corresponding broadcast exists.

Model communication abstractly for safety only: sent messages remain available, receivers are never required to receive them, and no progress or fairness assumptions are needed. The specification should guarantee type correctness and the transaction-commit safety properties: final decisions are stable, no resource managers reach conflicting final outcomes, and a commit decision is possible only when all resource managers have prepared. No liveness or eventual termination property is required.
