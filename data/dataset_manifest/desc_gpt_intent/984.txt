Specify a TLA+ specification for the Yo-Yo leader election algorithm with pruning, verified over every connected, loop-free undirected graph on a fixed positive number of numbered nodes. The model should choose an arbitrary connected graph initially and run the asynchronous algorithm using local node state and message passing, where edges are oriented according to node identifiers and nodes proceed through downward value propagation and upward replies that may reverse or prune edges.

The specification must guarantee type and message well-formedness: all node states, phases, neighbor views, and messages remain valid, messages refer only to appropriate neighboring nodes, and there is at most one pending message of a given kind from a neighbor to a recipient. It must preserve consistency of neighboring views, allowing only transient disagreement justified by pending edge-reversal or pruning messages. Under fair execution, the algorithm must eventually terminate with exactly the minimum-identifier node as the sole leader, all other nodes inactive, and no pending messages. Deadlock must be possible exactly in that terminated state.
