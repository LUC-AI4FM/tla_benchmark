Specify a small TLA+ demonstration module for an incrementing counter over natural numbers, intended to exercise constant/operator substitution for the standard natural-number set, including when a similar counter specification is placed in a nested module and instantiated from the enclosing module.

The modeled behavior should have a single counter initialized to zero. At every step, either the system may stutter or, if the current counter value belongs to the configured natural-number domain, the counter advances by exactly one. The configuration should allow the standard natural-number domain to be replaced by a small finite range, so model checking explores only a bounded fragment.

The key safety requirements are that the counter never decreases, every non-stuttering transition increments it by one, and under the finite replacement domain starting at zero, only the expected bounded successor values are reachable. No progress or fairness guarantee is required; infinite stuttering is allowed.
