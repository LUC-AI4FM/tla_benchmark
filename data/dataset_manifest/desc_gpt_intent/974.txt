Specify a TLA+ specification for a small N-process ring algorithm using single-writer regular shared registers. Each process owns one shared Boolean register, initially 0, and one private Boolean storage location, initially 0. A process writes 1 to its own shared register using regular-register semantics, meaning a read concurrent with the write may return either the old value or the value being written; a non-overlapping read returns the current stable value. After performing its write, the process reads the shared register owned by its predecessor in the ring and records the value locally, then terminates.

Model the regular registers explicitly enough to allow a register in transition between 0 and 1 to return either value, while stable registers return a single value. The specification should be parameterized by a positive number of processes. It must preserve type correctness: shared registers always represent nonempty Boolean value sets, local storage remains Boolean, and process control states are well formed. The main safety property is that whenever all processes have terminated, at least one process has recorded the value 1. No fairness-based termination guarantee is required.
