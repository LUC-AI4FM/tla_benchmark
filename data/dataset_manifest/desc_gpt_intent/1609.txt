Specify a TLA+ specification for an abstract, nondeterministic quicksort algorithm over a fixed finite indexed array. The initial array should be arbitrary, with length given by a natural constant and values drawn from the same finite range. The model should sort by recursively processing subranges: when a range has more than one element, an abstract partition operation may choose any split point and rearrange only the elements inside that range, preserving all elements outside it, such that every element in the left part is less than or equal to every element in the right part. The two resulting subranges are then sorted recursively.

The specification should allow nondeterministic choices of initial contents, pivot/split positions, and valid partition rearrangements. It must guarantee that, when the algorithm finishes, the final array is a permutation of the initial array and is sorted in nondecreasing order. It should also include a liveness requirement that every execution eventually terminates.
