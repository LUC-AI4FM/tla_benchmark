Specify a small TLA+ test specification demonstrating a deterministic modulo counter, suitable for checking that locally scoped helper-module instantiation behaves correctly. The modeled system should have a single numeric state component initialized to zero. Its real transition advances the value by one modulo five, so the observable sequence of non-stuttering updates is 0, 1, 2, 3, 4, 0, and so on. The transition computation should be expressed using a locally defined expression and a locally instantiated helper module, rather than by writing the arithmetic update directly, to exercise that feature of the language.

The specification may allow stuttering steps, but it must impose weak fairness on the real transition so that execution cannot stutter forever while the increment step remains possible. The required safety property is that the state value always remains in the range 0 through 4. The required liveness property is that from every point in every behavior, the value 4 is eventually reached again.
