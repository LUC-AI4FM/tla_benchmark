Specify a small TLA+ demonstration of Euclid’s subtraction-based algorithm for computing the greatest common divisor of two positive integers. The model should exhaustively choose both initial inputs from a fixed finite range, such as 1 through 20, then run the algorithm on those values. The algorithm repeatedly compares the two current numbers, swaps them when the first is smaller than the second, subtracts the second from the first, and stops when the first number becomes zero.

The specification should define the mathematical greatest common divisor independently, in a simple declarative way, so the algorithm’s result can be checked against it. The main safety property is that whenever the computation has finished, the remaining nonzero value is exactly the greatest common divisor of the two original inputs. The main liveness property is that every execution eventually terminates for all allowed positive input pairs. The model is intended for bounded TLC checking over all chosen inputs.
