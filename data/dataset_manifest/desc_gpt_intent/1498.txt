Specify a very small TLA+ demonstration model of a system with one Boolean flag. The flag starts in the false state. At each non-stuttering transition, the system must choose one of two possible alternatives, but both alternatives have the same externally observable effect: they replace the current flag value with its logical negation.

The model should capture that no other state values are possible and that every actual transition changes the flag. The reachable behavior should therefore alternate strictly between false and true, starting from false. The two alternatives should remain nondeterministic in the sense that either may be selected whenever a step occurs, even though they lead to the same next state.

The key safety properties are that the flag is always Boolean, the initial value is false, and every transition flips the flag rather than preserving or assigning an unrelated value. For infinite executions with continual transitions, the flag should visit both Boolean values repeatedly.
