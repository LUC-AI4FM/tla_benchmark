Specify an abstract TLA+ model of termination detection for a finite, nonempty set of processes, intended as the reference behavior for a synchronous ring termination-detection algorithm. Each process is either active or inactive. Initially, processes may be in any combination of active and inactive states, and the system may already report termination only if all processes are inactive.

The model should allow an active process to finish its current work and become inactive. It should also allow an active process to create work for another process, making that process active. Inactive processes must not spontaneously become active. Termination means that every process is inactive, and once this condition holds it must remain true forever.

The specification should include an abstract indication that termination has been detected. Detection must be sound: it may never be reported unless the system is truly terminated. It must also be live: whenever the system reaches a terminated state, termination is eventually reported.
