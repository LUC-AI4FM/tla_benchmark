Specify a small TLA+ demonstration model for testing deadlock and stuttering behavior. The system should consist of a simple finite execution over two pieces of state: a natural-number counter and a Boolean indicator. Initially, the counter is zero and the indicator is false. A real transition is permitted only while the counter has not exceeded three; such a transition advances the counter by one and flips the Boolean value. The temporal specification should also permit ordinary TLA+ stuttering, so the behavior may pause forever at any reachable state and, after the fourth real transition, only stuttering remains possible.

The key safety requirements are that every reachable state matches this pattern: the counter is always between zero and four, it never decreases, and the Boolean value reflects the parity of the number of real advances. The model should not impose any liveness or fairness obligation requiring progress. It should be suitable as a minimal test case showing a bounded computation that reaches a terminal non-progress state without requiring further non-stuttering behavior.
