Specify a minimal TLA+ demonstration system consisting of a single-state behavior. The model should represent a degenerate state machine whose entire state is fixed at its initial value and never changes over time. There are no meaningful operations, inputs, outputs, failures, or environment interactions; every behavior is simply an infinite repetition of the same state.

The key safety requirement is invariance: the modeled state must always equal its designated initial value in every reachable state. No transition may alter it or introduce any additional reachable state. The key liveness requirement is only that the behavior is infinite and may continue forever by stuttering; no progress, fairness, or eventual state change is required. This specification is intended as a smallest possible valid temporal model useful for testing or illustration, not as a functional algorithm.
