Specify a small TLA+ specification demonstrating a sequential PlusCal-style program that emulates procedure return values. The model should have one fair main thread that calls an addition routine with arguments 3 and 7, then passes the returned numeric result to a routine that converts the integer 10 to the string "10", and finally records that returned string as the program’s output. The string conversion routine only needs to support the value 10 and should treat any other input as an assertion failure.

The key safety requirements are that all assertions are satisfied, the addition result is correctly propagated to the conversion routine, and the final recorded output is exactly "10". The model should also allow normal termination without deadlock, permitting stuttering after termination. The key liveness requirement is that, under the specified fairness assumptions, the single main thread eventually reaches its completed state.
