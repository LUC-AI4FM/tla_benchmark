Specify a small TLA+ demonstration module for a fixed-index table update. The model should choose one distinguished index nondeterministically from the set 1 through 5, initialize a table over those same five indices with all entries equal to 0, and then repeatedly allow behavior that either stutters or applies one conditional update based on the chosen index. The chosen index must never change. If the chosen index is 1, a non-stuttering transition should set the table entry at index 1 to 42 while preserving all other entries. If the chosen index is not 1, non-stuttering transitions should leave the entire table unchanged. The table’s domain must always remain exactly the five indices 1 through 5. The safety properties should guarantee preservation of the chosen index, preservation of unaffected table entries, and absence of out-of-domain updates. Do not require fairness or eventual progress; infinite stuttering is permitted.
