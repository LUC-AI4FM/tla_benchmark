Specify a small TLA+ regression-test module demonstrating that module instantiation works when a formal state variable of an imported module is substituted by a constant expression, including in an “unchanged” condition. The instantiated behavior should model a simple system with one numeric state component initialized nondeterministically to 1, 2, or 3, another numeric component also initialized in that range and then kept fixed, and a constant value that satisfies the imported module’s original initialization constraint.

The system’s only non-stuttering transition should be allowed while the changing numeric component is less than 10, increasing it by exactly 1 and leaving the fixed component unchanged. Stuttering should be permitted. The safety properties should ensure the fixed component never changes, the changing component never decreases or skips values, and all reachable values of the changing component remain between its initial range and 10. No liveness or deadlock-freedom requirement is needed.
