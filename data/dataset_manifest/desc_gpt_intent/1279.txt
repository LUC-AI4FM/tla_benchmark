Specify a small TLA+ demonstration module modeling a system with one integer-valued state component. The component should begin at a fixed nonzero value outside a small choice range, and thereafter the system may either leave the state unchanged or perform an update that chooses a value from the range 0 through 1, but only accepts choices that make the resulting value strictly positive. The purpose is to illustrate that a next-state relation can constrain an assigned next value after nondeterministically selecting it, and that stuttering behavior is allowed.

The key safety property is that the state component is never equal to zero in any reachable state. This must hold initially and be preserved by every permitted update or stuttering step. No progress, fairness, or eventual-update requirement is needed; infinite executions that stutter forever are acceptable.
