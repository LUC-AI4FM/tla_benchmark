Specify a TLA+ specification for a small abstract concurrent double-ended queue service. There is a fixed set of clients and a fixed set of values. Each client repeatedly performs one atomic operation chosen nondeterministically: either attempt to insert some value or attempt to remove a value. A successful insert may place the value at either the front or the back and returns an “okay” response; an insert may also fail without changing the contents and return “full”. A remove on a nonempty structure may remove and return either the front element or the back element. A remove on an empty structure leaves the contents unchanged and returns “empty”. After each operation, the client’s response is cleared before it can perform another operation.

The specification should model arbitrary interleavings of clients, keep the stored contents as a finite sequence of allowed values, and constrain the length to a fixed maximum bound. Safety should ensure every response matches the operation effect. Liveness should ensure every client continues to get chances to act forever.
