Specify a TLA+ specification for a minimal single-decision consensus abstraction. The model should have a constant set of admissible values and represent only the core act of deciding a value, omitting proposal and learning mechanisms. Initially no value has been decided. The system may nondeterministically decide one admissible value, and once a decision has been made no different or additional value may ever be decided; executions that never decide are allowed in the basic safety specification.

The key safety requirement is consistency: throughout every behavior, the collection of decided values is a finite subset of the admissible values and contains at most one element. The specification should also include a liveness variant with an appropriate weak fairness assumption ensuring that, when the admissible value set is nonempty and deciding remains continuously possible, the system eventually decides some value. The liveness property should state that some value is eventually decided.
