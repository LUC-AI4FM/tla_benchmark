Specify a small TLA+ demonstration of mutually recursive computation of integer parity. The model should take a fixed natural-number input, begin by asking whether that number is even, and compute the answer by alternating between the two parity cases while decreasing the argument until the base case is reached. The computation should produce a Boolean answer that is true exactly when the original input is even and false exactly when it is odd, and it should model proper procedure-call/return behavior for the mutual recursion.

The specification should allow normal termination and harmless stuttering after termination, so the completed state is not a deadlock. A required liveness property is that, for the configured input value 6, the computation eventually terminates. As a small coverage/test expectation for that same input, the run should enter the odd-parity routine three times, corresponding to the three transitions from an even argument to the next odd argument.
