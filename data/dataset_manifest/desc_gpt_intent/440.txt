Specify a small TLA+ demonstration module testing `ENABLED` under module instantiation when two formal variables of an instantiated module are both mapped to the same concrete state variable. Model a simple one-variable system whose state starts at zero and then repeatedly alternates between zero and one forever; the alternating transition should be weakly fair so the behavior cannot stutter forever.

The specification should instantiate a separate parameterized helper specification over two variables, substituting both of them with the single concrete variable of the main system. The purpose is to check that all formulas imported from the instance are interpreted with the correct substitution semantics, especially formulas involving enabledness of actions.

The required correctness properties are that the instantiated helper’s initial-state condition holds for the main initial state, that one designated enabledness-based assertion from the helper is invariantly true, and that another designated enabledness-based assertion is invariantly false. The model should serve as a regression test for correct handling of enabledness through instantiation.
