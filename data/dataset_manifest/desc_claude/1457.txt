A minimal test module used to demonstrate or verify deadlock detection in a TLA+ trace-expression (TE) specification context. It models a simple two-variable system with a natural number `x` initialized to `0` and a Boolean `y` initialized to `FALSE`. The `Next` action increments `x` by one and toggles `y` on each step, but is only enabled when `x <= 3`, meaning the system can take exactly four steps before no further transitions are possible. The temporal specification `Spec` combines `Init` with a stuttering-tolerant next-state relation. Because `Next` becomes permanently disabled once `x` reaches `4`, the system will deadlock at that point — no non-stuttering step is possible. The configuration file simply identifies `Spec` as the specification to check, with no additional invariants or properties declared, making deadlock detection (the implicit check that the system always has an enabled next-state action) the sole verification concern.
