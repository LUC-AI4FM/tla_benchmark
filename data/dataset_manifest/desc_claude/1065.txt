The module specifies Dijkstra's EWD 840 distributed termination detection algorithm for a ring of N nodes. The system models both the termination detection mechanism (the "System" actions) and the underlying computation (the "Environment" actions).

The state consists of four variables: `active`, a mapping from nodes to booleans indicating whether each node is active; `color`, a mapping from nodes to {"white", "black"}; `tpos`, the current position of a token; and `tcolor`, the color of the token. Initially the token is black, while other variables may take any type-correct values.

The System actions govern token circulation. Node 0 initiates a new probe by sending a white token to node N−1 whenever it holds a black token or is itself black. Non-zero nodes pass the token leftward when they are inactive, black, or hold a black token, staining the token black if the passing node is black and whitening that node. Environment actions allow any active node to send a message to another node (activating it and blackening the sender if the target has a higher index) or to deactivate itself at any time. The overall specification `Spec` requires weak fairness of System actions, ensuring the token continues to circulate.

The key safety invariant `TerminationDetection` states that whenever termination is detected (white token at node 0 with node 0 white and inactive), all nodes are indeed inactive. The liveness property `Liveness` asserts that if all nodes are terminated, termination will eventually be detected. The module also includes Dijkstra's inductive invariant `Inv`, a `CheckInductiveSpec` for verifying inductiveness, and an instantiation of a higher-level `SyncTerminationDetection` specification to verify refinement.
