Write a small TLA+ demonstration module that exercises a subtle interaction between a boolean state variable and a set-comprehension expression that depends on it. The system has a single boolean variable that starts true. In each step, the variable updates to reflect whether a particular filtered function set is empty — specifically, the set of all functions from the singleton domain {0} to the singleton codomain {0} whose existence is conditioned on the current value of the variable. Because the variable begins as true, the filtered set is non-empty on the first step, causing the variable to become false; once false, the filtered set becomes empty, causing the variable to become true again, and so on. The specification should capture this stuttering-allowed transition system. There are no explicit correctness properties to verify beyond the specification being well-formed and parseable by TLA+ tools; the module serves primarily to demonstrate that set comprehension over a function set using a boolean guard evaluates correctly as the guard variable changes over time.
