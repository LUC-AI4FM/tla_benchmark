Specify a simple asynchronous one-directional channel that transmits values from a sender to a receiver using a ready/acknowledge handshake protocol. The channel carries a single data value drawn from a given constant set, along with two single-bit signals — one controlled by the sender and one by the receiver — each toggled between 0 and 1. Initially the two bits are equal, indicating the channel is idle. A sender may transmit a new data value only when the channel is idle (both bits equal), toggling the ready bit to signal that data is available. The receiver may consume the data only when the channel is busy (bits differ), toggling the acknowledge bit to confirm receipt and return the channel to idle. The key safety property is a type invariant: at all times the channel state must be a record with a data value drawn from the allowed set and both handshake bits strictly in the set {0, 1}. The specification should be checked with three concrete data values to confirm the invariant is preserved across all reachable states.
