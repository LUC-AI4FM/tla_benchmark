Write a small TLA+ module that demonstrates how a next-state relation can constrain a variable's successor value simultaneously through both an assignment and an additional predicate. The system has a single integer variable initialized to 23. Each step nondeterministically assigns the variable some value from the set {0, 1}, but only those assignments that also satisfy a strict positivity condition are permitted, meaning the new value must be greater than zero. The specification should allow stuttering steps. The key correctness property to verify is that the variable never equals zero — that is, since the assignment and the positivity guard are applied together in every transition, the value zero can never actually be reached despite being a candidate in the nondeterministic choice.
