Write a TLA+ specification that models Euclid's algorithm for computing the greatest common divisor of two integers. The algorithm starts with a fixed value of 24 for one variable and a nondeterministically chosen value between 1 and 50 for the other. It repeatedly checks whether the first variable is nonzero; if so, and if it is smaller than the second, the two values are swapped, then the second is subtracted from the first. This continues until the first variable reaches zero, at which point the second variable holds the GCD. The specification should demonstrate that the algorithm always terminates regardless of the initial nondeterministic choice, and that the system reaches a done state in finite steps. No explicit safety or liveness properties beyond termination need to be checked — the primary purpose is to demonstrate that the iterative subtraction-based GCD procedure terminates for all valid inputs in the given range.
