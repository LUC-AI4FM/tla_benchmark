Specify an N-process shared-memory algorithm in which each process i owns a shared register and a private local register. Each process performs three steps: it begins writing the value 1 to its shared register (entering a transitional state where the register may return either its old value 0 or the new value 1), completes the write so the register stably holds 1, and then reads the shared register of its left neighbor (process (i−1) mod N) into its local register. The shared registers are regular rather than atomic: during an ongoing write from old value to new value, a concurrent read may nondeterministically return either the old or the new value, and this must be modeled explicitly.

The key correctness property is that when all N processes have finished, at least one process must have read the value 1 into its local register. The specification must prove this safety property as an invariant. Additionally, the system must be live in that all processes eventually complete. The specification should be verified for concrete values of N (e.g., N = 8) and include a proof of the safety property using an inductive invariant.
