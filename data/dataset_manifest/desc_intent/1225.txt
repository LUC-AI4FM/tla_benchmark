Write a TLA+ specification for a simplified multiprocessor request-ordering system. There are a fixed set of processors, registers, addresses, and values. Each processor maintains a queue of issued requests, where each request involves an address, a value, and an operation (read or write). The system also maintains a global partial order over all outstanding request identifiers, where each identifier is characterized by the issuing processor and the request's index within that processor's queue.

The only action in the system is a processor issuing a new request, which appends an entry to that processor's queue and nondeterministically extends the global request order. The request order must always remain a strict partial order — irreflexive and transitive — and must respect per-processor program order, meaning earlier requests from the same processor must precede later ones in the ordering.

The key correctness property to verify is a type invariant: the per-processor queues must contain valid request records, and the global order must be a relation over valid request identifiers. Use a state constraint to keep the queues short enough for finite-state model checking. The specification serves primarily as a regression test to validate correct TLA+ tool behavior.
