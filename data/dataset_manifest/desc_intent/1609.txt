Write a TLA+ specification for a recursive quicksort algorithm operating on a fixed-length array of integers. The array should be initialized nondeterministically as a mapping from index positions to values within the same range. The algorithm sorts the array in place using a partition-then-recurse strategy: given a subarray range, nondeterministically choose a pivot index within that range, rearrange the subarray (leaving elements outside the range untouched) so that all elements on the left of the pivot are no greater than all elements on the right, then recursively sort each half. The nondeterminism in both pivot selection and partitioning should be modeled abstractly — any valid partitioned permutation of the subarray is acceptable. The specification must guarantee two correctness properties: liveness, meaning the algorithm always terminates, and safety, meaning that upon termination the final array is a permutation of the original and is sorted in non-decreasing order across all index pairs. The constant controlling array length should be configurable so the model can be checked for small sizes such as 4 or 5.
