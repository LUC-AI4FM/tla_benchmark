Specify Dijkstra's self-stabilizing token ring algorithm (EWD426) for a ring of N nodes, where each node holds a counter value drawn from a domain of size M, with the constraint that N ≤ M + 1. A single token circulates around the ring, defined implicitly by the relationship between neighboring counter values rather than by an explicit token variable. Node 0 is privileged (holds the token) when its counter equals its predecessor's counter, and it advances the token by incrementing its counter modulo M. Any other node is privileged when its counter differs from its predecessor's, and it passes the token by copying its predecessor's counter value. The system may start from any arbitrary configuration of counter values. The key correctness property is stabilization: regardless of the initial state, the system must eventually reach and remain in a configuration where there is exactly one token in the ring — meaning there is a unique position in the ring where the counter value transitions, with all preceding nodes agreeing with node 0's value and all following nodes holding the predecessor value. Verify this stabilization property as a liveness requirement under weak fairness on all transitions.
