Write a TLA+ specification for a simple boolean toggle system with a single state variable that starts as false. The system has two actions, both of which flip the boolean variable to its opposite value. Either action may fire at each step, forming the transition relation. No specific invariants or temporal properties need to be verified beyond what the model checker checks by default — this is essentially a minimal demonstration of a two-action system where both actions have identical effect on the state, showing that multiple named transitions can produce the same state change. The specification should define an initialization predicate setting the variable to false, a negation operator applied to compute the toggled value, and a next-state relation that allows either action to execute.
