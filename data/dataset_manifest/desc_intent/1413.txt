Write a TLA+ specification that demonstrates a minimal, trivial system used to verify a temporal logic tautology with the TLA+ proof system (TLAPS). The system itself has a single variable that never changes, initialized to zero, with a stuttering-only next-state relation. The property to verify is the temporal tautology that if eventually TRUE holds, then eventually TRUE holds forever — that is, `<>TRUE => <>[]TRUE`. This property should be stated as an invariant of the specification and verified both by model checking and by a TLAPS proof using propositional temporal logic reasoning. The goal is not to model a real algorithm but to confirm that the proof assistant correctly handles this tautology, serving as a regression test or demonstration that TLAPS can discharge simple propositional temporal logic obligations automatically.
