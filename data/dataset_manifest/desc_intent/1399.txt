Write a TLA+ specification that demonstrates a simple two-state system where a single Boolean variable alternates between true and false on every step. The system starts with the variable set to true, and each transition flips it to its opposite value. The specification should be checked against the property that the variable is always true, which is intentionally violated (serving as a minimal test case demonstrating that a toggling Boolean fails a simple invariant). Include additional properties for experimentation: one asserting the variable equals true as a state predicate, one that is trivially always satisfied, and expose the variable directly as a property to illustrate different forms of property checking.
