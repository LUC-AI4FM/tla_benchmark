Write a TLA+ specification that serves as a fingerprint test for a lazy cache system. The model has a shared memory mapping addresses to data values, a per-processor cache that may hold either a data value or a "not dirty" marker for each address, and per-processor input and output queues of bounded length. Input queue entries are either read or write operations (addressed data, with writes distinguished by a marker), and output queue entries are address-data pairs. The system should print the total number of distinct states at initialization so that TLC's fingerprint count can be verified against a known baseline.

The safety invariant to check is that memory always maps addresses to valid data values, each processor's cache maps addresses to data values or the no-data marker, each processor's input queue contains only valid operations and does not exceed the maximum input length, and each processor's output queue contains only address-data pairs and does not exceed the maximum output length. The specification need not enforce deep behavioral correctness beyond these type constraints, but must faithfully enumerate all relevant state transitions so the state-space size matches the analytically computed count printed at startup.
