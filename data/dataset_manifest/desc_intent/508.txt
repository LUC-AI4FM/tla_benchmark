Write a TLA+ specification that demonstrates a simple assertion check using PlusCal. The system initializes a single integer variable chosen nondeterministically from the range 1 to 10, then verifies that the square of that value does not exceed 100. The specification should use TLC to evaluate this assertion at runtime, confirming that for every possible initial value in the given range the squaring property holds. The key correctness property is that the system always terminates, meaning it eventually reaches a done state regardless of which initial value was chosen.
