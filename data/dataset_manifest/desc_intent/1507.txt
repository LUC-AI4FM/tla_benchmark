Write a TLA+ specification that demonstrates a simple boolean clock system, primarily intended as a test or demonstration of TLC's coverage tracking behavior for recursive operators. The system models a single boolean variable that toggles between TRUE and FALSE on every step. The initial state is established via a recursive operator, and a state constraint is enforced using another recursive operator. A type invariant checks that the clock variable holds a boolean value, also implemented through a recursive checking operator. The key correctness property is the type invariant: the clock must always be a boolean. The specification is not modeling a real-world system but rather exercises TLC's handling of recursive operator invocations, particularly the nuance that a recursive call appearing as an initializer may be skipped in coverage reporting even though its parameters are evaluated — this edge case in TLC's coverage analysis is the central motivation for the module.
