Specify Euclid's algorithm for computing the greatest common divisor of two positive integers. The system should non-deterministically select two starting values, each drawn from 1 up to some fixed maximum (use 20), and then iteratively reduce them using the classic subtraction-based GCD procedure: at each step, if the smaller value is in the first position, swap the two values; then subtract the second value from the first. This repeats until the first value reaches zero, at which point the second value holds the GCD of the two original inputs.

The specification must guarantee two correctness properties. First, a safety invariant: upon termination, the computed result equals the true greatest common divisor of the two initial values, where GCD is defined as the largest common divisor in the naive mathematical sense. Second, a liveness property: the algorithm always eventually terminates regardless of the chosen inputs. The bound of 20 should be treated as a constant assumption, and TLC should be able to model-check all pairs of inputs in that range and verify both properties.
