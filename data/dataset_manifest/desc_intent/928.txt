Write a TLA+ specification that demonstrates the equivalence of two formulations of a 12-hour clock. The clock has a single variable representing the current hour, which ranges from 1 to 12. The initial condition sets the hour to some value in that range, and each step advances the hour forward by one, wrapping from 12 back to 1. The primary formulation expresses the next-state transition by checking whether the hour equals 12 and resetting to 1, or otherwise incrementing by 1. A second equivalent formulation expresses the same transition more compactly using modular arithmetic. The specification should extend an existing HourClock module and define the alternative next-state relation and the combined specification built from the shared initial condition. The key correctness property to verify is that the two specifications — the base one and the modular-arithmetic variant — are equivalent, meaning each implies the other. The module should include a theorem asserting this equivalence, and the model checker configuration should verify that the primary specification satisfies the alternative formulation as a temporal property.
