Specify a minimal TLA+ model of the single-value consensus problem. There is a fixed set of candidate values and a notion of a "chosen" value. Initially nothing is chosen. At any point, one value from the candidate set may be nondeterministically selected and permanently recorded as chosen; this can happen at most once. No fairness constraint is built into the base safety specification, but a liveness variant should add weak fairness so that if a choice is possible it will eventually be made.

The specification must enforce two correctness properties. The safety invariant requires that the set of chosen values is always a subset of the candidate values, is finite, and contains at most one element — capturing the "agreement" and "validity" requirements of consensus. The liveness property requires that, under the fair variant of the specification, some value is eventually chosen — capturing the "termination" requirement. Model checking should be done with deadlock checking disabled, since the system legitimately stops after a choice is made.
