Write a small TLA+ module that demonstrates the use of a recursive operator alongside a simple state machine. The system has a single variable initialized to zero, and each step sets that variable to the result of evaluating a factorial function on one of two fixed inputs. The recursive factorial operator must be properly declared using a RECURSIVE keyword to avoid issues with coverage and cost analysis in tools. The specification should define an initial condition, a next-state relation composed of two possible transitions, and a temporal specification combining the initial condition with a always-enabled next-state relation. The module serves primarily as a demonstration that recursive operator definitions work correctly in the context of model checking, particularly verifying that tools handle recursive calls without infinite loops during coverage or cost instrumentation. No explicit safety or liveness properties beyond the basic temporal specification need to be checked.
