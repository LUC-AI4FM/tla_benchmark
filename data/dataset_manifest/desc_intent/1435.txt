Write a small TLA+ module that demonstrates the minimal viable specification structure: a single variable that is initialized to a fixed value and never changes. The specification should consist of an initial condition setting the variable to zero and a next-state relation that constrains the variable to remain unchanged forever. No meaningful safety or liveness properties beyond what is implicit in the stuttering-closed behavior need to be verified; the purpose is simply to illustrate the smallest possible well-formed TLA+ specification with a SPECIFICATION declaration in the configuration file.
