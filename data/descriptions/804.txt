This module specifies a binary search algorithm over a sorted sequence `seq` of integer values from a constant set `Values`, searching for a target value `val`. The translated algorithm maintains variables `low`, `high`, and `result`, repeatedly checking the middle element and narrowing the search range until either a matching index is found or the search terminates with `result = 0`. The specification includes a temporal behavior `Spec` with weak fairness on `Next`, a termination property stating that eventually `pc = "Done"`, and a TLAPS proof that the safety property `resultCorrect` is invariant under the behavior.
