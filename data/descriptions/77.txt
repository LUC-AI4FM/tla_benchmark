This specification is a minimal working example intended to demonstrate a tooling issue: that constraints supplied through ConstInit do not propagate as expected. It models no dynamic algorithm beyond a trivial state machine whose Init and Next predicates are both TRUE, so the only meaningful property is a constraint relating the constants t_min and t_max. The file assumes both constants are integers, asserts an assumption t_min <= t_max, and defines an invariant Inv that repeats the same ordering condition.
