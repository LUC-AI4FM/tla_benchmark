This module provides a TLAPS proof of the safety properties of a readers-writers specification. The main properties proved are that the system maintains type correctness (TypeOK) and a safety property (Safety) throughout all behaviors, as asserted by the temporal formulas Spec => []TypeOK and Spec => []Safety. The proof is inductive, relying on the fact that the head of the waiting sequence is always a 2-tuple with the first component being either "read" or "write", and that the set of writers never contains more than one element. The proof uses explicit assumptions about the finiteness of actors and leverages lemmas about sequences. The design is modular, with most system details inherited from the ReadersWriters module, and the proof is structured hierarchically using TLAPS constructs.
