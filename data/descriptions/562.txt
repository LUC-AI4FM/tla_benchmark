This specification models the transaction commit protocol (TCommit) for a set of resource managers (RMs). Each RM can be in one of several states: working, prepared, committed, or aborted. The protocol allows RMs to prepare, commit, or abort a transaction, with actions defined for each transition. The specification checks that all RMs can only commit if all are prepared, and that abort is only possible if no RM has committed. The temporal property TCSpec asserts that the system starts in the initial state and all steps are valid transitions, using stuttering steps as needed. No explicit fairness or liveness properties are specified beyond the basic temporal structure.
