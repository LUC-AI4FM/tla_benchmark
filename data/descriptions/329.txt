This module is a small TLC-oriented regression test that checks equality between different syntactic representations of the same sets. It defines an invariant-like operator that uses a sequence of IF-THEN-ELSE checks together with TLC's Assert and Print operators to confirm that set enumeration, set comprehension, SUBSET, UNION, union, intersection, set difference, ranges, and DOMAIN all behave as expected. The modeled state is trivial, with a single variable x initialized to 1 and unchanged forever, so the substantive content of the specification is the collection of set-theoretic test expressions rather than a transition algorithm.
