This module specifies Safra's distributed termination detection algorithm on a ring, following EWD 998. Nodes communicate asynchronously, can be active or inactive, maintain local counters for sent minus received messages, and a circulating token records position, accumulated counter information, and color to determine whether global termination has been detected. The specification includes a type invariant, an inductive invariant, a safety property stating that a detected white-token condition implies actual termination, a liveness property asserting eventual detection after termination, a fairness condition on the system token actions, and a TLC state constraint to bound the otherwise infinite state space.
