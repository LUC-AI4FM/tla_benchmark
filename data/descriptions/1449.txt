This specification models a very small randomized state machine with two variables, x and y. Initially, x is chosen from RandomSubset(10, 1..1000) and y is set to 0; each Next step chooses a new x from the same random-subset expression and increments y by 1. The temporal specification is Spec == Init /\ [][Next]_<<x,y>>, and the file also defines a simple state invariant Inv asserting that y < 10.
