This module specifies a tutorial version of binary search over an input sequence of integers, searching for a given key using machine-style integer bounds and returning either a matching index or a negative insertion-point encoding. The state consists of the current low and high bounds, a termination flag, and the returned value, with Init setting up the initial search interval and Next modeling one search step or stuttering after termination. The spec also defines a postcondition stating that once the algorithm has terminated, the return value is correct in the sense that it is nonnegative exactly when the key is found; the comments note this property is derived from the Java Arrays.binarySearch behavior.
