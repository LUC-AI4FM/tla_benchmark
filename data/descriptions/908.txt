This specification models a simple two-phase handshake communication channel using a single variable 'chan' that is a record with fields 'val', 'rdy', and 'ack'. The channel transmits values from the set 'Data' using a protocol where the sender updates the value and toggles the ready bit, and the receiver acknowledges by toggling the ack bit. The system ensures that the channel variable always satisfies the type invariant, and the main temporal property asserts that this invariant is always maintained throughout execution. The model is basic, with no explicit fault model or fairness conditions, and verifies safety via a single theorem.
