This module defines operators for choosing pseudo-random subsets of a set, primarily for inductive invariance checking where the operators appear only in the initial predicate. The comments explain TLC-specific behavior: in breadth-first search, pseudo-random choices for a particular state are determined by the first state of the step so runs are reproducible enough to generate error traces, while in simulation mode the choices are independent of the state. The module defines a random k-element subset operator, a random set of subsets operator constrained by cardinality, and a testing operator that returns a function on 1..5 whose values are the cardinality of repeated executions of the random set-of-subsets operator. Except for TestRandomSetOfSubsets, the definitions are overridden by TLC's Java implementation.
