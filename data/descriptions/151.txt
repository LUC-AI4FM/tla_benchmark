This specification models a very small two-variable state machine in which integer variables x and y range over a bounded nonnegative interval and swap values on every step. The initial condition requires both variables to lie in the set Range and to have different values, so the system starts from two distinct bounded integers. The spec defines two temporal properties: one liveness property asserting that whenever x is 0, eventually x becomes nonzero while y becomes 0, and a second intentionally false-looking liveness property asserting that whenever x is 0, eventually both x and y are 0; because Next only swaps the two distinct values, the second property is not expected to hold.
