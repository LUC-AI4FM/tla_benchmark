This module is a tutorial TLA+ specification of a binary search procedure over an input sequence and key. It models the search interval with variables low and high, tracks termination with isTerminated, and stores the algorithm's return value in returnValue. The current version leaves the main loop body unimplemented and specifies the expected postcondition instead: once terminated, the return value should be nonnegative exactly when the key is found, accounting for TLA+ sequences being 1-based while the intended Java-style return value is 0-based.
