This module specifies Bloemen et al.'s multi-core on-the-fly strongly connected components decomposition algorithm on a directed graph whose nodes and edges are given as constants. The file contains a commented PlusCal algorithm and its generated TLA+ translation, modeling shared union-find state, per-thread search state, and a work-stealing style exploration in which multiple threads cooperatively discover and merge SCC candidates while marking sets dead when fully explored. The specification defines the operational behavior with Init, Next, and Spec, adds weak fairness for both the main thread process action and the unite procedure, asserts a termination property as an eventuality that all program counters become Done, and defines a safety/correctness condition stating that upon termination the SCC partition computed by the algorithm matches the mathematical SCC decomposition by reachability.
