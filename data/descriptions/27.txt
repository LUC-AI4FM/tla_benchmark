This specification models a simple traffic light controller with two state variables: whether the light is green and whether a request to turn green is pending. The system starts with the light red and no pending request, allows a request for green only when the light is red and no request is already pending, allows switching to red whenever the light is green, and allows switching to green when the light is red and a request is pending. It also states a temporal liveness property asserting that every pending green request will eventually be fulfilled, and defines a stuttering-closed next-state relation using [Next]_vars.
