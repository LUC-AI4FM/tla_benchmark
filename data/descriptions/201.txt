This specification is a regression test for recursive operators declared in an instantiated module. The outer module defines a variable f and initializes it to the result of calling the recursive operator A from the inner module instance I, using two alternative initial predicates Init and Init2. The recursive operator A computes a simple countdown-based arithmetic result, and the file also defines a stuttering Next action and a state invariant Inv asserting that f = 2. There are no temporal properties, fairness conditions, proofs, or PlusCal constructs in this file.
