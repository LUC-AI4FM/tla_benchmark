This specification models a load-balancing agent moving around a ring of N nodes. Each node stores a natural-number load, the agent remembers the last load it observed, can carry at most one task, and alternates between moving and inspecting the current node to pick up or drop a task based on the difference between the current and previous loads. The environment can nondeterministically create additional tasks at a node while creation is enabled, and the spec defines an initial condition, a next-state relation, a fairness-constrained behavior specification, and several temporal properties including a liveness-style claim about task creation stopping and safety-style formulas about balanced loads and the agent carrying no task.
