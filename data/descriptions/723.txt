This module is a test specification for relational-property operators provided by the Relation module, instantiated over the concrete finite set S = {0, 1, 2, 3}. It uses a series of ASSUME statements to check whether equality, less-than, and less-than-or-equal satisfy standard relation properties such as reflexivity, irreflexivity, symmetry, antisymmetry, asymmetry, transitivity, and various partial and total order notions on S. The file also constructs explicit relation-valued functions in LET blocks to demonstrate counterexamples for antisymmetry and transitivity, and it uses TLC printing in an initial ASSUME to announce the test run; there are no state variables, actions, temporal specifications, fairness conditions, proofs, or PlusCal processes.
