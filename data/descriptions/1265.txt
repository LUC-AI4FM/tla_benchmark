This module provides helper operators for TLC trace serialization and replay rather than specifying a distributed algorithm. It serializes TLC counterexample traces to a file, deserializes them, constrains replayed states to match a recorded trace, and defines a view that preserves liveness lassos by mapping levels beyond the dumped prefix to the lasso target. The design relies on Java module overrides for serialization, deserialization, and state access, and it includes logic to support replay when only a subset of variables is shared between the original trace and the current specification.
