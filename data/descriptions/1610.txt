This module specifies a PlusCal model of an in-place quicksort-style algorithm over arrays of length N whose entries range over 1..N. The algorithm maintains a set S of subarray intervals still to be processed, repeatedly chooses an interval, nondeterministically selects a pivot position, and then nondeterministically replaces the current array by a permutation of itself that satisfies the partition ordering constraints around that pivot. The translated TLA+ specification defines the initial state, a single control-location action qs1, the overall next-state relation, a standard temporal specification with weak fairness on Next, and an eventual termination property asserting that the program counter eventually reaches "Done".
