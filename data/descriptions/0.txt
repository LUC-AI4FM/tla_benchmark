This module models the client-visible consistency guarantees of Microsoft Azure Cosmos DB across multiple regions and clients. It abstracts away the internal replication protocol and instead specifies client operations, asynchronous replication among regions, and the resulting histories and database states used to characterize strong, bounded staleness, session, consistent prefix, and eventual consistency. The spec defines an initial state, client and database actions, a temporal specification with weak fairness for both clients and the database replication process, several invariant-style consistency properties selected by the constant Consistency, and a liveness property stating that eventually all regional databases become equal forever.
