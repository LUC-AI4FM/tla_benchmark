This module specifies a recursive factorial algorithm generated from a PlusCal procedure-based program. The algorithm uses a procedure FactProc with an explicit call stack to model recursive calls, multiplying a global result by the current argument until the argument reaches 0, and then returning to the caller. The temporal specification requires initialization, step-wise execution under Next, weak fairness of Next, and it asserts eventual termination with pc = "Done"; it also includes an invariant that result remains a natural number and a TLC-specific operator that inspects possible named states.
