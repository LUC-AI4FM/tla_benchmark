This module defines a very small state machine used to check an Apalache fold over a sequence into a set. It introduces one integer state variable x, with an initial state x = 0 and a stuttering next-state relation that leaves x unchanged. The interesting property is a state predicate Inv that asserts the negation of the invariant that should actually hold: folding the operator A(p, q) == p \union {q} over the sequence <<1,2,3>> starting from the set {4,4} yields something unequal to {1,2,3,4}. The comments indicate this is intended as a satisfiability check of the SMT encoding, expecting the negated invariant to be unsatisfiable if the encoding is properly constrained.
