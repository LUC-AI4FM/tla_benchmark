This specification models a small state machine intended to expose or test an initialization-state related bug. It defines recursive operators for enumerating all subsets of a set and summing the elements of a set, then uses a choice operator to select a subset whose sum is greater than 4. The system has three state variables and transitions in two steps from an initial state, first assigning a large powerset-based value and then assigning the set of all subsets of 1..8; the comments note that one range was increased from 1..8 to 1..20 to test performance.
