This module specifies the Afek et al. shared snapshot algorithm for the unbounded-memory case, as described in the comments and the cited shared snapshot object reference. It models separate reader and writer process sets, shared memory indexed by writers, and the internal two-pass read logic that can either return a consistent double-read result or use a writer-provided snapshot when movement is detected. The specification defines an initial state and a next-state relation over reader and writer actions, and asserts a standard temporal safety-style system specification `Init /\ [][Next]_vars` with internal variables included in `vars` and no explicit fairness or liveness assumptions.
