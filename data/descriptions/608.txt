This module specifies a resolved timestamp mechanism over a set of region keys RM. It models region-local transaction message generation and application, forwarding of messages through a channel to a resolver, and production of resolved timestamps and commit timestamps into output queues. The specification includes transaction steps such as prewrite, commit, rollback, message application, fetch-ts requests, and resolver-side handling, and it verifies safety properties about commit timestamp consistency, resolved timestamp consistency, and overall type correctness; it also defines a liveness-style leads-to property showing that FetchTS messages can eventually produce a resolved timestamp when no region has an outstanding prewrite.
