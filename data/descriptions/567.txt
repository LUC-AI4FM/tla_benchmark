This module is a model-checking wrapper around a Raft-related specification, configuring and restricting the explored state space for a CCF/Raft model. It reads configuration choices from the IO environment, constrains reconfiguration sequences, term growth, client requests, message duplication, and signature generation, and defines debugging and coverage-related predicates for TLC runs. The file also introduces assumptions about configuration and term/request bounds, a symmetry set and view for model checking, and postconditions intended to detect whether certain debug invariants were ever exercised.
