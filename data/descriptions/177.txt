This module defines a collection of recursive utility operators over finite sets, sequences, and functions. It specifies computations for summing a set of numbers, taking the union of a set of sets, filtering a sequence by a predicate, counting how many elements of a set satisfy a predicate, computing the range of a sequence, finding a mode of a sequence, and checking whether a function is injective. The module contains no state variables, no actions, and no temporal behavior; it is a purely functional helper module built around recursive definitions and choice expressions.
