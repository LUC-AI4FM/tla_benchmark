This module is a small test specification for definability of user-declared infix operators and aliases in TLA+, especially operators whose symbols overlap with built-in notation. It declares several custom infix operators, initializes a single variable x, and defines a Next action that currently allows only one enabled transition using the built-in % operator while many alternative tests are commented out because of parser or TLC bugs. The specification is not a full temporal system specification with Spec, invariants, or liveness properties; rather, it is a parser/tool behavior test that uses TLC's Print operator during initialization.
