This specification models a simple finite-set state variable and defines an alternative cardinality computation using a fold over a set. The variable `set` is initialized nondeterministically to some subset of `1..10`, and thereafter the system only stutters because `Next` leaves the variable unchanged. The main property expressed is the invariant `Inv`, which states that the standard `Cardinality(set)` operator agrees with the user-defined `MyCardinality(set)` computed via `ApaFoldSet` and a local increment operator.
