This specification models a single Boolean state variable x that can nondeterministically take any value in BOOLEAN at each step. The main behavior is given by Init and Next, with Spec requiring Init and the standard temporal formula [][Next]_vars; an alternative FairSpec additionally imposes weak fairness WF_x(Next). The file focuses on temporal property checking, especially an AtMostOnce property intended to constrain how x may become false again after becoming true, along with an equivalent reformulation, negation, and leads-to properties. It also includes a TLC-oriented postcondition that inspects a generated counterexample trace and checks its exact structure using TLC extension operators.
