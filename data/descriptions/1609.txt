This module specifies a recursive quicksort algorithm over an array of length ArrayLen, modeled first in commented PlusCal and then as the generated TLA+ translation. The algorithm chooses a pivot nondeterministically within the current subarray and then nondeterministically replaces the array by a permutation that preserves elements outside the subarray and partitions the subarray so that all values at or before the pivot are less than or equal to all values after it. The translated model uses explicit control state pc together with a stack of procedure frames to represent recursive calls to QS. The specification defines Init, Next, and Spec with weak fairness on Next, and it asserts a termination property stating that eventually pc reaches "Done". The final test state checks that the resulting array is a permutation of the initial array and is sorted in nondecreasing order.
