This module specifies a tutorial version of binary search over an input sequence, with constants for the input sequence, the search key, and a fixed machine-integer bit width. It models the algorithm as a small state machine with variables low, high, isTerminated, and returnValue, where Init sets the initial search interval and Next describes one computation step including the midpoint calculation and the three comparison branches. The specification also defines sortedness of the input, a correctness condition relating the return value to whether the key occurs in the sequence, and two postconditions, one unconditional and one weakened to account for possibly unsorted inputs; there is no explicit fault model or temporal Spec operator in this file.
