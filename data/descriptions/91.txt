This module is a minimal regression-test specification for commented Apalache type annotations attached to constants. It declares two constants, v and y, and includes structured type comments describing v as a set of records with an integer field x and y as a record with fields x and y, where the latter field is a sequence of integers. The file does not define any behavior, state variables, actions, temporal specification, or properties; it is purely a syntactic test of comment-handling in type annotations.
