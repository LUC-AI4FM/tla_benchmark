This specification models a small state space over the fixed set S = {"n1", "n2"} with two variables x and y. The predicate Direct constrains x to be a function from S to {"a"} and y to be a function from S to S, and it requires that for every s in S, if x[s] = "a" then y[s] = s. Indirect is defined as Direct, and InIndirect wraps Indirect through a LET-bound alias zz == xx; the initial condition requires InIndirect(x, y), and the temporal specification asserts Init together with the box-action formula [][InIndirect(x', y')]_vars.
