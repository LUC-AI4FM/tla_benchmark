This module is a small TLAPS-oriented test specification intended to check proof-language syntax restrictions, specifically that USE and HIDE commands cannot take arbitrary expressions as facts. It declares simple theorems, including one theorem that is just the tuple <<1, 2>> and another theorem built as an ASSUME TRUE PROVE FALSE proof. The file is focused on proof structure and proof command validation rather than modeling a transition system, and it contains no variables, actions, temporal specification, or PlusCal algorithm.
