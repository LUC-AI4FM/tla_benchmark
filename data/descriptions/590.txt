This specification models a concurrent variant of the Percolator transaction protocol over a set of keys and clients. Each client executes a transaction with a primary key and secondary keys, using start and commit timestamps, prewrite locks, cleanup of stale locks, and commit of the primary key before secondaries are considered committed or recoverable. The model checks safety-style properties including typing invariants, write and lock consistency, committed and aborted transaction consistency, and an auxiliary snapshot isolation condition tracked by instrumentation variables.
