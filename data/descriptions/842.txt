This module is a model-checking wrapper for a Paxos specification. It extends the Paxos module and TLC, introduces model values for three acceptors and two values, defines a quorum family consisting of all 2-of-3 acceptor subsets, and constrains a ballot-related parameter to the range 0..MaxBallot. The file itself does not define the Paxos algorithm; instead, it supplies concrete constants and a property alias referring to V!Spec from an extended module for verification.
