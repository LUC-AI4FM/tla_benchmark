This module specifies an abstract lock mechanism using a simple two-process mutual exclusion protocol. The system models two processes that repeatedly attempt to enter and exit a critical section, using a shared lock variable to ensure mutual exclusion. The specification includes both the PlusCal algorithm and its TLA+ translation, with explicit state variables and actions for each process step. The module verifies mutual exclusion via an invariant and includes a temporal property stating that if a process is waiting to enter the critical section, it will eventually succeed. The fault model is idealized (no faults), and the design is intentionally simple to focus on the correctness of the locking protocol.
