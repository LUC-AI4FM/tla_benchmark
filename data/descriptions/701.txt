This module defines a library of sequence-related operators that extend the standard Sequences module with conversions, search operations, prefix/suffix relations, folds, zipping/interleaving, and subsequence replacement utilities. It models no transition system and introduces no state variables; instead, it provides pure mathematical operators over sequences, sets, bags, and functions. The file includes helper constructions for converting between sets and sequences, computing common prefixes, flattening nested sequences, and performing first/all subsequence replacement, with comments emphasizing TLC and TLAPS compatibility decisions.
