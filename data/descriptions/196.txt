This module specifies the N-queens problem and an iterative algorithm that computes all solutions by progressively extending partial queen placements. Placements are represented as sequences or equivalently as functions from rows 1..N to columns 1..N, and the spec uses Apalache's FunAsSeq operator to convert functions into sequences when defining the full set of mathematical solutions. The algorithm maintains a set of partial placements in todo and a set of complete solutions in sols, repeatedly chooses a partial placement, extends it with all safe next-column choices, and moves complete extensions into sols. The specification includes an initial condition, a next-state action with weak fairness, a type invariant, a safety-style invariant relating sols and Solutions, and a liveness property asserting eventual termination when todo becomes empty.
