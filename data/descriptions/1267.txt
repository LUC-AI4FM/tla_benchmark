This specification models an open-addressing fingerprint set with bounded probing, concurrent writer processes, and an eviction procedure that moves fingerprints from the in-memory hash table to external storage when the table is full. The PlusCal algorithm describes concurrent insertion threads, an eviction phase that sorts table contents and flushes selected entries to an external sorted sequence, and uses auxiliary variables such as history to state correctness properties. The file checks safety-style invariants about containment, duplicates, sortedness, and consistency between table and external storage, and it also specifies liveness properties such as termination and eventual completion under weak fairness for writer and eviction actions.
