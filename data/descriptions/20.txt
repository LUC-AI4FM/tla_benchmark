This specification models a simple message-set system in which a set variable `msgs` stores messages of two possible record shapes: integer messages tagged with type `"int"` and string messages tagged with type `"str"`. The system can add either kind of message to the set, remove and inspect an integer message to update `found3`, or remove and inspect a string message to update `foundC`. The spec includes an initial state predicate, several state-transition actions, a combined `Next` action, and a type-correctness invariant `TypeOk`, but it does not include a temporal `Spec`, fairness conditions, fault model, or proofs.
