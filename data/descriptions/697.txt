This module defines basic predicates and constructions for binary relations represented as Boolean-valued functions over a set S. It provides checks for standard relational properties such as reflexivity, irreflexivity, symmetry, asymmetry, transitivity, and connectedness, and it defines both transitive closure and reflexive transitive closure. The specification is purely functional and state-free: it declares no variables, no actions, and no temporal behavior, and it relies on Naturals and FiniteSets for natural-number indexing and finite-set cardinality.
