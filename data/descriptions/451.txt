This module is a small test specification for parametrized INSTANCE usage. It declares a single variable y, defines one instantiated module without substitutions and another instantiated module with an explicit substitution x <- y, and refers to the instantiated module's Spec operator. The specification also defines a simple state invariant requiring y to lie in the natural-number range 0..4, and the comments indicate the file is intended to test handling of JSpec versus ISpec rather than model a full algorithm.
