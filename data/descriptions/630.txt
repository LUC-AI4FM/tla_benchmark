This module is a shallow wrapper around another module instance for a light client detector scenario with three nodes and one faulty validator ratio encoded as <<2, 3>>. It declares concrete configuration values such as the node set, trusted and target heights, clock drift bounds, correctness flags for primary and secondary peers, and the detector state variables. The file itself does not define the transition relation or temporal properties directly; instead, it provides parameterization and state-variable declarations for an instantiated detector module.
