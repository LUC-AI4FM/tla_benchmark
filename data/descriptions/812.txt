This module specifies Boyer and Moore's majority vote algorithm over an input sequence of values. The algorithm scans the sequence in one pass, maintaining an index i, a current candidate cand, and a counter cnt, and it guarantees that when the scan is complete, any value with an absolute majority must equal cand. The specification includes a temporal behavior Spec with initialization, a next-state action, and weak fairness for Next, and it also defines correctness and an inductive invariant used for reasoning about the algorithm.
