This module is a test specification that compares behavior of the Apalache module against TLC on a collection of small sequence, set, and function-manipulation examples. It defines a trivial one-variable state machine with Init and stuttering Next so TLC can run, but the substantive content is a suite of state-level test predicates covering folding over sequences and sets, sequence construction, subsequences, selection by predicate, converting functions to sequences, and nondeterministic guessing from sets. The spec also explores implementation-sensitive set representations such as duplicate elements and ghost cells, and aggregates the individual checks into an AllTests conjunction rather than asserting temporal correctness properties beyond the basic Init/Next structure.
