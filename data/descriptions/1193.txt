This module is a test specification for handling primed expressions in TLA+ actions and related constructs. It models a tiny state space with two variables, x and y, initialized to 1, and then checks many different syntactic contexts in which x' appears, including function definitions, set expressions, CHOOSE, function override, CASE, quantifiers, implication, and operator calls. The specification is designed as a regression-style test using TLC's Print and Assert operators, with the intended successful behavior being that the primed expressions evaluate consistently during the next-state relation and that only two distinct states are explored.
