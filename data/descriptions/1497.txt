This module specifies a very small state machine with a single variable x over the natural numbers. The initial state sets x to 0 and additionally requires a helper predicate Op1 over the range 1..17, where Op1 states that every subset of the given set has nonnegative cardinality. The next-state relation allows either action A(10) \/ B(3), each of which updates x to a value chosen by Op2 as the maximum element of the interval 1..n via a CHOOSE expression. The specification contains state predicates and actions but no temporal Spec operator, no fairness conditions, and no proof constructs.
