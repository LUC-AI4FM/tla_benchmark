This module is a TLC model-checking wrapper module for another specification, rather than the primary algorithm specification itself. It extends the modules ghostferry, TLC, and stats, introduces model values r0, r1, and r2, and defines concrete constant values and model-checking bindings such as a record set, a maximum primary key, an initial table, and a maximum binlog size. It also binds the checked behavior to Spec, the action constraint to BinlogSizeActionConstraint, the invariant to SourceTargetEquality, and the temporal property to Termination, but it does not define those underlying operators in this file because they come from extended modules.
