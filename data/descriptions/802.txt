This module defines utility operators for finite zero-indexed sequences represented as functions with domain 0..(n-1). It provides constructors and conversions between ordinary one-indexed TLA+ sequences and this zero-indexed representation, along with derived operators for length, valid indices, rotations, and a lexicographic order. The module is a pure mathematical helper library with no state variables, no transition system, no fault model, and no temporal verification properties; its notable design choice is to represent zero-indexed sequences explicitly as functions rather than using the built-in Sequences indexing convention.
