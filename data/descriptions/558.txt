This module specifies the classic Die Hard water-jug problem using two buckets of capacities 5 and 3. The commented PlusCal algorithm models a single process that repeatedly nondeterministically chooses among filling, emptying, and pouring actions between the buckets, and the translated TLA+ action FixWater captures those state transitions over the variables bigBucket, smallBucket, action, and water_to_pour. The specification defines an initial state and a temporal specification Spec as Init /\ [][Next]_vars, and it includes an invariant Inv asserting that bigBucket is never equal to 4.
