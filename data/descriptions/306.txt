This specification models a tutorial version of binary search over an input sequence, including bounded machine-integer arithmetic for midpoint computation. It tracks the search interval with variables low and high, records termination and returnValue, and counts the number of executed steps in nSteps. The spec defines initialization, a single-step transition relation for the search loop, a sortedness predicate on the input sequence, a correctness condition for the returned value, and state/action properties related to postcondition, termination, and progress. It does not define a full temporal Spec operator.
