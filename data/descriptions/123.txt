This specification models a small state machine with a single integer variable x and defines helper operators over functions from strings to integers. The operator A updates a function at one string key to value 1, and f is a constant function over the finite domain {"x", "y", "z"} initialized to 0. The temporal structure consists of an initial condition Init, a stuttering next-state action Next that leaves x unchanged, and an invariant Inv asserting that folding A over the domain of f with ApaFoldSet yields the function mapping every element of DOMAIN f to 1.
