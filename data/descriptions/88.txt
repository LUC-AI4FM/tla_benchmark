This specification models a typed one-place communication channel with a sender and receiver synchronized by ready and acknowledgment bits. The channel state is stored in a single record variable `chan` containing a data value `val` and two control bits `rdy` and `ack`; sending updates the value and toggles `rdy`, while receiving toggles `ack`. The specification defines an initial condition, a next-state relation allowing either a send of some datum from `Data` or a receive, and a temporal specification `Spec == Init /\ [][Next]_chan`; it proves that the type invariant is always preserved.
