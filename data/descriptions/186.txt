This specification models a simple distributed pizza ordering system with a fixed set of clients, a server, and a network of messages. Clients nondeterministically send order requests, the server receives request messages from the network and appends them to an outstanding order queue while sending acknowledgments, and the server later delivers orders by moving the head of the outstanding queue into the delivered history for the corresponding client. The spec defines initialization, the next-state relation, and a safety property asserting that no client's delivered order sequence contains the same order twice; it does not include an overall temporal Spec operator or fairness assumptions.
