This module specifies a bounded blocking queue with multiple producers and multiple consumers that use poison pills to achieve global termination. Producers enqueue either ordinary data or the distinguished constant Poison, and consumers dequeue items; the state also tracks a wait set for blocked threads plus counters telling how many poison-related actions each producer and consumer still owes before termination. The specification verifies type correctness, absence of deadlock, queue emptiness after global termination, and a leads-to termination property; it also studies a stronger fairness variant under which all producers eventually terminate, and includes a concrete counterexample value in PostCondition.
