This module specifies the Paxos Commit algorithm, modeling resource managers, acceptors, leaders, and the set of all messages ever sent. It focuses only on safety, not liveness: messages are represented by membership in a global message set rather than explicit receipt events, leader selection is left abstract, and resource managers may spontaneously prepare or abort. The specification defines the protocol state, the actions of resource managers, leaders, and acceptors, a next-state relation and full temporal specification, and proves type correctness as well as that the protocol implements the transaction-commit specification imported from module TCommit.
