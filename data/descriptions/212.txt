This module specifies a very small state machine for a circulating token represented as a record with fields pos, q, and color. The token is constrained by a type invariant: pos ranges over the node identifiers 0..N-1 where N = 3, q is an integer, and color is either "white" or "black". The initial state fixes the token to pos 0, q 0, and color black, and the only next-state action is stuttering via UNCHANGED token, so the system never changes state after initialization.
