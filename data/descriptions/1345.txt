This specification models a minimal one-variable TLA+ system with state variable x. The initial state sets x to 1, and the behavior specification requires that x initially equals 1 and thereafter all steps satisfy the action A up to stuttering via [][A]_x. The file also defines a state invariant asserting x \in Nat, a theorem claiming that Spec implies []Inv, and a separate temporal property Prop asserting that eventually x = 42; a comment notes that action A is intended to be replaced by an external evaluation in Java.
