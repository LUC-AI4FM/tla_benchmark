This file contains a top-level module Test1254 that also includes a nested module base, used as a regression test for an Apalache issue about instance-referenced operator behavior. The inner module base defines a single integer variable x, a trivial boolean-valued function FF, a higher-order operator Check that applies a function argument to its argument, and a simple incrementing Next action that advances x when Check(x, FF) holds; it also defines Init and a GOAL predicate x < 3. The outer module Test1254 redeclares x, defines its own predicate CheckOrig, instantiates the base module as BASE, redefines Next to call BASE!Check(x, CheckOrig), reuses BASE!Init as Init, and defines its own GOAL predicate x < 5; there are no temporal formulas, fairness constraints, proofs, or PlusCal processes.
