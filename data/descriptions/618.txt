This module is a model-checking wrapper for an instantiated Tendermint accountability specification. It declares the state variables used by the underlying Tendermint model, introduces a constant proposer function, and instantiates another module with concrete process sets, fault sets, value sets, and a maximum round bound. The only top-level property defined in this file is a constant initialization constraint requiring Proposer to be a function from rounds to all processes; the detailed algorithm, actions, and temporal properties are not defined in this file itself but are delegated to the instantiated module.
