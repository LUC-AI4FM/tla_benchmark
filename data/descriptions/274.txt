This module is a small functional test specification for variant-related operators. It models a trivial one-variable state machine with an initial state x = 0 and a stuttering next-state relation, while the substantive content consists of state predicates that test construction, membership, filtering, tag inspection, unsafe extraction, and defaulted extraction of variants. The file is intended as operator-level validation rather than a protocol model, and it does not include temporal correctness properties beyond the basic Init/Next structure.
