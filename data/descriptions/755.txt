This module is an Apalache-compatible wrapper around another specification, DieHardest, for model checking only the interleaved-composition part of the system described as Section 4. The comments explain that the original DieHardest specification uses TLC-specific operators in Sections 1-3, so this wrapper avoids those and instead provides constant initialization and capacity functions in a form acceptable to Apalache. The module declares constants for capacities and goal, variables for two capacity maps and two scalar states, instantiates the DieHardest module, and defines helper operators that set up a specific model-checking scenario with two candidate capacity configurations and a fixed goal value.
