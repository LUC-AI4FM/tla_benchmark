This module provides dummy definitions for operators that would be defined in a true Reals module, intended for use in TLA+ specifications that mention real numbers. It is not a real implementation: the operators here are placeholders, and any tool that supports real numbers is expected to provide its own correct implementation. The module defines a set Real (as the string "Reals"), a division operator a / b using CHOOSE, and an Infinity value as a CHOOSE of an element not in Real and greater than all elements of Real. The comments clarify that TLC does not support real numbers and will error if these operators are evaluated. The module extends Integers, but does not inherit any of its definitions directly.
