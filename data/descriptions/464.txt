This module is a small test specification for arithmetic and range behavior from the standard numeric modules, especially natural-number-related operators such as subtraction, multiplication, comparisons, division, modulus, and interval expressions. It models a trivial one-variable system in which the only variable x is initialized to 0 and never changes, while the invariant Inv performs a sequence of runtime checks using IF-THEN-ELSE expressions together with TLC's Print and Assert operators. The design is intentionally simple: the temporal behavior is just stuttering, and the main purpose of the file is to validate expected arithmetic identities and edge cases such as 2 - 3 \notin Nat and 3 .. 2 = {}.
