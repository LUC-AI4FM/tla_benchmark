This specification models a very small two-variable state machine with integer variables x and y. The initial state sets x = 0 and y = 1, and the single transition swaps the values by assigning x' = y and y' = x. The file is intended to test behavior with superfluous nested box operators in temporal formulas, and it defines one liveness property asserting that eventually x = 1 under repeated nested [] operators, along with a false liveness variant asserting eventually x = 2.
