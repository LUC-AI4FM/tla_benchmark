This file contains two TLA+ modules and a configuration section. The main module `UndeclaredRecursion` extends `Base` and `Integers` and defines `DefIsOdd(n)` as `IF n = 0 THEN FALSE ELSE IsEven(n-1)`. The embedded module `Base` extends `Naturals`, declares the operator-valued constant `IsOdd(_)`, defines `IsEven(n)` as `IF n = 0 THEN TRUE ELSE IsOdd(n-1)`, and contains the assumption `IsEven(2)`. The configuration section overrides `IsOdd` with `DefIsOdd`, but configuration entries are not top-level module operator definitions.
