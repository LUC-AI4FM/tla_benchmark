This specification is a small test module that checks that the Snowcat type checker accepts several uses of TLC printing operators over differently typed values. It models six state variables of types string, boolean, integer, set of strings, sequence of strings, and a record with string fields, initializes them to concrete values, and then defines a Next action that invokes Print and PrintT on those values. The behavior is intentionally simple: Next leaves all variables unchanged, and the temporal specification asserts that the system starts in Init and thereafter always takes stuttering-compatible Next steps.
