This specification models a very small two-variable transition system with integer state variables x and y and explicitly notes in a comment that it tests behavior when the system does not have loops. The initial state constrains both variables to lie in a bounded nonnegative integer range from 0 to 50 and requires them to be distinct. The next-state relation swaps the variables' roles while incrementing each by 1, and the module defines two temporal properties: one liveness-style property asserting that always, if x exceeds 50 then eventually y stays above 50 forever, and another property asserting that if x eventually exceeds 52 then y is always above 100.
