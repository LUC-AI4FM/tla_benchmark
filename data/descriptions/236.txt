This specification is a small regression test for issue #1305 concerning TLC support for --view on functions. It models a single state variable `fun`, intended by comment to be a function from integers to integers, initialized to the identity function on the domain `1..2`. The next-state relation either stutters or updates `fun` by rebuilding it over its current domain with each value incremented by its argument, and it defines a simple invariant `Inv` requiring `fun[1] /= 2` together with a view operator `View == fun`.
