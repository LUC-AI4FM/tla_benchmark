This module specifies a small two-variable transition system with integer variable x and boolean variable y. Action A toggles y and increments x while x < 4, and action B toggles y and resets x from 4 back to 1, yielding a cyclic behavior under Next == A \/ B. The specification defines both an unfaired behavior Spec and a weakly fair behavior FairSpec, checks an invariant Inv asserting x < 4, and a temporal property Prop asserting eventual x > 4, which is intentionally violated. The module also defines an Alias operator used by TLC to present reordered and augmented state views, plus postconditions that validate the exact counterexample traces produced by TLC in simulation, lasso, and stuttering scenarios.
