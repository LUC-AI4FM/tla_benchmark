This specification models a joint-action memory system by composing two hidden internal components: an environment component and a memory component. The environment tracks a readiness map and can either send memory requests or receive replies, while the memory component accepts requests into per-process buffers, updates control state, and delegates additional behavior to imported operators such as Do and Rsp from an extended module. The top-level specification existentially hides the internal variables of both components and asserts the conjunction of their temporal behaviors, with each component described by an initialization predicate and a stuttering-closed next-state formula.
