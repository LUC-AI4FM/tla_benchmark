This module defines constants and state variables for a model of a light-client detector interacting with a reference blockchain and fetched light blocks. It models a four-node setting with a designated faulty-validator ratio, trusted and target heights, clock drift assumptions, and booleans describing whether primary and secondary components are correct. The file is only a thin wrapper module that instantiates another module and declares the state vocabulary, but it contains no initialization, next-state relation, temporal specification, or proofs of its own.
