This specification models the Paxos consensus algorithm, focusing on its safety properties and omitting explicit leader and learner processes. The model uses a message-passing abstraction, where the set of all messages ever sent is tracked, rather than modeling messages in transit or message loss. The algorithm is parameterized by sets of values, acceptors, and quorums, and models the core Paxos phases (1a, 1b, 2a, 2b) as actions, with state variables representing the highest ballot seen, the highest ballot voted for, and the value voted for by each acceptor. The specification includes a type invariant, an initial state, and a refinement mapping to a Voting module, as well as an inductive invariant for proof purposes. Liveness is only partially addressed, with the main focus on safety.
