This module specifies Dijkstra's first published mutual exclusion algorithm, presented as a PlusCal algorithm together with its generated TLA+ translation. It models an arbitrary set Proc of processes that compete to enter a critical section using shared boolean arrays b and c and a shared process-valued variable k, with weak fairness assumptions for process steps in the main specification. The file defines the initial condition, per-control-location actions, the overall next-state relation and specification, and then states safety and liveness properties including mutual exclusion, deadlock freedom, starvation freedom, and a stronger deadlock-freedom property under a modified fairness interpretation.
