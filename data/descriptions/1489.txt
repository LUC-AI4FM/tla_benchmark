This file models a small TLA+ example about the semantics of action composition and module instantiation, specifically demonstrating that instantiation does not distribute over the action composition operator `\cdot` because of the interaction with primed and unprimed variables. The top module defines a system with variables `x`, `y`, and `z`, instantiates a helper module `HL` with both `x` and `y` mapped to `z`, and compares two temporal formulas: one using `HL!Next` under instantiation and another using `(HL!A \cdot HL!B)` under instantiation. The extensive comments explain the classic counterexample from the TLA+ semantics in Specifying Systems, showing how renaming of internal variables in `B \cdot C` affects substitution and why the two specs differ; the file verifies temporal behaviors using boxed action formulas rather than fairness or proof obligations.
