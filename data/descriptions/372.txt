This module is a SANY2 parser and proof-scope test rather than a distributed algorithm or transition-system model. It checks the scope rules for NEW declarations and DEFINE statements inside hierarchical TLAPS proofs, especially that NEW declarations are restricted to the statement's proof except for SUFFICES, whose assumptions remain visible in the rest of the current proof. The file contains a simple theorem with nested proof steps, top-level operator definitions, and an ASSUME statement using TLC's PrintT operator; it does not define state variables, actions, temporal behavior, or fault-tolerance properties.
