This module defines an SVG-based animation layer for Dijkstra's EWD998 distributed termination detection algorithm, specifically for a ring of nodes that exchange messages and circulate a colored token with an accumulated queue count. It is not the base algorithm itself; instead, it extends an existing channel-based specification and visualizes current and next-state information such as node activity, node color, message counters, token position and color, in-flight versus arriving messages, and global status such as running, terminated, or termination detected. The design emphasizes deterministic rendering, modular visual components, debugger watch support, and TLC alias support for frame-by-frame animation generation.
