This module specifies a parameterized one-round asynchronous reliable broadcast algorithm in the presence of Byzantine faults, based on the Srikanth-Toueg algorithm. The model represents correct and faulty processes, the local control state of each process, the set of ECHO messages sent by correct processes, and the messages received by each process; Byzantine behavior is abstracted via arbitrary Byzantine ECHO messages from faulty processes. The specification defines initialization, receive and step actions, a temporal specification with weak fairness for liveness checking, and several correctness properties including correctness, relay, unforgeability, and an inductive invariant used in a TLAPS proof of unforgeability when no correct process initially broadcasts.
