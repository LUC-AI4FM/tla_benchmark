This module is a TLC model-checking wrapper around a specification imported from EWD840. It defines additional checking expressions, including a derived specification that requires Spec, ENABLED Next, and an ENABLED expression involving SelectSeq over a sequence built from 1..N+1 and a lambda comparing nodes to tpos. It also defines a tautological StateConstraint and an ActionConstraint intended to trigger evaluation of a Java module override that accesses state, plus helper operators Stop and Alias for inspection of the imported state.
