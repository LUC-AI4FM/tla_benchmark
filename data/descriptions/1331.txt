This TLA+ specification models Shmuel Safra's distributed termination detection algorithm on a ring topology, as described in EWD 998. Unlike the original, this variant represents message channels as sequences, allowing for explicit modeling of message ordering and delivery. The system consists of N nodes, each with a color, activity status, counter, and an inbox for messages, including a circulating token. The algorithm ensures that termination is detected only when all nodes are passive and the token returns to the initiator in a specific state. The specification includes a refinement mapping to a simpler set-based model (EWD998), type invariants, and state constraints to bound the state space for model checking. Temporal properties are specified to ensure correct system evolution, and the spec is designed for TLC model checking with explicit fairness and state/action constraints.
