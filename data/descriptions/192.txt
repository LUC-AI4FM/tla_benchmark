This module defines a small TLA+ specification centered on the operator `PolyOper`, which uses the Apalache-specific operator `ApaFoldSet`. Inside `PolyOper`, a LET-bound local operator `Add(f,e)` is defined as `[ x \in DOMAIN f \union {e} |-> 0 ]`. The fold starts from the empty function `[x \in {} |-> 0]`. The top-level operators are `Init == TRUE`, `Next == TRUE`, and `Inv == PolyOper({1}) = [x \in {1} |-> 0]`.
