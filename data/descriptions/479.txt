This TLA+ specification models Dijkstra's distributed termination detection algorithm for a ring of N nodes, as described in EWD 840. The system consists of nodes that can be active or passive, each with a color (white or black), and a circulating token with a position and color. The algorithm detects global termination by passing a token around the ring and using color changes to track activity. The specification defines the possible actions: initiating a probe, passing the token, sending messages (which may activate other nodes and change colors), and deactivating nodes. The temporal property ensures that the system starts in a type-correct initial state with a black token, and that all steps follow the defined next-state relation, with weak fairness for the system actions. The model assumes N is a positive natural number and does not explicitly model faults.
