This specification models Lamport's distributed mutual exclusion algorithm from "Time, Clocks and the Ordering of Events in a Distributed System" using typed variables and explicit message queues between processes. It represents processes, logical clocks, request timestamps, acknowledgements, the current critical-section occupants, and a pairwise FIFO network carrying request, acknowledgement, and release messages. The specification defines the initial state, the next-state relation for requesting, entering, exiting, and receiving each message type, and states safety-oriented properties including type correctness, a bounded-network condition useful for finite-state checking, and the mutual exclusion invariant; it also includes a clock bound intended as a TLC state constraint for finite-state model checking.
