This module defines alternative versions of several finite-set utility operators intended to be automatically rewired by the Apalache importer in place of the corresponding community-module definitions. It provides folds, set aggregation operators such as sum and product, derived set operators such as symmetric difference, k-subset enumeration, extremum selection, Cartesian-style choice over a set of sets, and unique choice under a predicate. The file is purely definitional: it declares no state variables, no transition actions, and no temporal properties, and its notable design choice is to adapt behavior and add type annotations for Apalache compatibility while relying on local instances of supporting modules.
