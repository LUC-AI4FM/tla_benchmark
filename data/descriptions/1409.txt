This specification models a very small state machine with two variables, x and y. The initial state sets x to the string value "foo" and y to 0, and the next-state relation allows either keeping x as "foo" while incrementing y by 1, or setting x to TRUE while incrementing y by 2. The temporal specification requires that execution start in Init and thereafter always follow Next modulo stuttering, and it also defines a simple state invariant Inv asserting that y remains less than 5; no fault model, fairness, PlusCal algorithm, or proofs are present.
