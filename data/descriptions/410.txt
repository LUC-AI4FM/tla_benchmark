This specification is a small test module for TLC model values. It declares three constants a, b, and c, one variable x, initializes x to 1, and defines only stuttering behavior by leaving x unchanged in Next. The main property-like operator Inv checks that the model value a is not treated as a string, not equal to the concrete set {1, 2}, not a member of a numeric set comprehension, and not a member of the explicitly enumerated set {b, c}; each check uses Assert on failure and Print on success.
