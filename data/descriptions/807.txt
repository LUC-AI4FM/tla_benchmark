This module specifies an abstract version of the Quicksort algorithm over finite nonempty sequences of integers drawn from a constant set Values. The partition step is modeled nondeterministically by choosing any sequence in Partitions(I, p, seq), so the spec abstracts away from any concrete in-place partition implementation while preserving the required ordering relation around the pivot. The specification includes a temporal behavior with initialization, a next-state relation, weak fairness of Next, and a termination property stating that eventually pc = "Done". It also contains a substantial TLAPS proof of partial correctness, proving that every terminating execution yields a sorted permutation of the initial sequence.
