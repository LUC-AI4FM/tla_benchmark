This module defines helper operators for bounded sequences and directed graphs, and then specifies a tiny state system with two variables ranging over the edge set of a constant graph. It uses TLC-specific evaluation through TLCEval and RandomElement to force evaluation of expressions in a particular context, and comments explain that caching behavior matters for correctness of the invariant. The file includes an assumption about the cardinality of a nested bounded-sequence construction and defines an invariant asserting both type membership of the variables and membership in a derived test graph, together with a fixed TLCEval-computed cardinality check.
