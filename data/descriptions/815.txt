This module defines two helper operators related to a parameterized reachability setting imported from the ParReach module. It chooses a successor function from Nodes to subsets of Nodes such that every node has exactly two successors, and it defines a set of bounded-length sequences over a set S by taking the union over all sequence lengths from 0 up to the cardinality of Nodes. The module itself contains no variables, no transition actions, and no temporal properties; it is purely a structural extension that adds state-independent mathematical definitions.
