This module is a test specification for TLA+ labels and subexpression selectors rather than a distributed algorithm or transition system. It exercises how labels, selector syntax, operator-valued arguments, LET-IN bindings, CHOOSE, quantifiers, sets, tuples, records, function constructors, EXCEPT, temporal subscript syntax, fairness syntax, and INSTANCE references interact with subexpression selection. The file verifies these behaviors through many ASSUME statements and two simple theorems, without introducing state variables, a Next action, fairness conditions in a system specification, or a temporal transition system.
