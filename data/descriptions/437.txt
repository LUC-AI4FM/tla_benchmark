This module is a test specification for passing TLA+ prefix and postfix operators as operator arguments and for defining custom prefix and postfix operators. It checks that operators such as `[]`, `<>`, `ENABLED`, `UNCHANGED`, `SUBSET`, `UNION`, `DOMAIN`, and the prime operator can be supplied to higher-order operator definitions and used syntactically in definitions and assumptions. The spec also includes a tiny two-variable state machine over sets, defines a standard `Spec` and a derived temporal `Property`, and uses an ASSUME block with TLC `Print` calls to validate expected parsing and evaluation behavior.
