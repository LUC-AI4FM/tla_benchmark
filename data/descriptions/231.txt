This specification models a single variable `things` that maps string keys to record values with a single integer field `cnt`. The initial state constructs two finite maps `F` and `G` inside a `LET` block and merges them so that `things` initially contains entries for keys such as "A", "B", and "C", with the later override determining the value for overlapping keys. The next-state relation either stutters or decrements the `cnt` field of `things["B"]` using a helper operator `NonNegative` so the count never becomes negative, and the invariant asserts that `things["B"].cnt` is always at least 0.
