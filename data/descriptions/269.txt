This specification models a simple request/acknowledgment interaction over a set of message variants and an event log. The state consists of an integer balance, a set of messages, and a sequence log; requests can be sent for amounts in 1..10, and requests are later processed by either withdrawing the requested amount if sufficient balance exists or recording a lacking event otherwise. The spec is a test for the Variants module, using tagged variant values such as Req, Ack, Withdraw, and Lacking, and it defines only initial-state and next-state behavior without any temporal property, fairness condition, or fault model.
