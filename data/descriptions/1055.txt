This module specifies the Dijkstra-Scholten distributed termination detection algorithm for a diffusing computation initiated by a distinguished root node. The system maintains a dynamic spanning tree of active nodes, with nodes sending base messages, receiving acknowledgments, detaching from the tree when inactive and childless, and the initiator declaring termination when it becomes inactive and has no remaining children. The specification includes a PlusCal algorithm and its TLA+ translation, models bounded message counts for state-space exploration, assumes a finite node set with an initiator in that set, and verifies both a safety property that termination implies quiescence and a liveness property that quiescence leads to eventual termination under weak fairness of each process action.
