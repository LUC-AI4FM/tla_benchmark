This specification models a small transition system over three set-valued variables S, T, and R, together with an integer control variable state. Initially S contains 1, T contains 4, and R is defined as the union of S and T; in each Next step either S grows according to a 1->2->3->1 pattern or T grows according to a 4->5->6->1 pattern, while state also evolves according to a separate finite-state transition relation over values 0 through 4. The file defines an invariant Inv asserting that S and T are unequal, but it does not define a full temporal Spec operator or any fairness assumptions.
