This module specifies an abstract behavioral specification for what the Alternating Bit protocol is intended to accomplish. It models three processes: A updates the current sent message from a queue of pending data values, B copies A's value when the alternating bit changes, and E nondeterministically appends new data values from the constant set Data into the queue. The specification includes an initial condition, a next-state relation over the variables AVar, BVar, and NewValQueue, and a temporal specification requiring all behaviors to start in Init, evolve according to [][Next]_vars, and satisfy weak fairness for actions A and B.
