This specification models a write-through cache system layered over an internal memory interface, with the original module instantiation expanded manually because the TLC version targeted by the file could not handle INSTANCE. The system has per-processor control state, request buffers, a per-processor cache, and a memory request queue that serializes cache misses and writes to memory. It specifies initialization, state-transition actions for requests, reads, writes, queue processing, and eviction, and it asserts temporal safety properties that the type invariant and cache coherence hold under the main specification.
