This module specifies the Paxos Commit algorithm, focusing exclusively on safety properties and not liveness. The model simplifies the protocol by letting the variable msgs be the set of all messages ever sent, and does not explicitly model message receipt; instead, actions are enabled based on the presence of messages in msgs. Leader selection is not modeled, and actions that a leader may perform are defined without specifying which process acts as leader. The resource managers (RMs) can spontaneously issue Prepared messages, and Prepare messages are ignored. The specification defines the types and initial states of resource managers, acceptors, and messages, and models the protocol's actions for RMs, leaders, and acceptors. The main temporal property asserts that the protocol maintains type correctness, and the module also asserts that Paxos Commit implements the transaction commit protocol of another module (TCommit) via an INSTANCE statement.
