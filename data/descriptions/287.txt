This module specifies a very small one-variable transition system over an integer variable x. The initial state sets x to 0, and the next-state relation allows incrementing x by 1, decrementing x by 1, or stuttering by leaving x unchanged. The file also defines a simple state invariant Inv asserting x = 0, and a view operator View1 that maps the current state to a two-boolean tuple indicating whether x is negative or positive.
