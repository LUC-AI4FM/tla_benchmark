This module defines basic relational properties and operations for relations represented as binary Boolean functions over a set S. It provides predicates to check if a relation is reflexive, irreflexive, symmetric, asymmetric, transitive, and connected over a set. It also defines operators to compute the transitive closure and reflexive transitive closure of a relation, using recursive LET-bound operators and function constructors. The module is intended as a reusable library for reasoning about relations, and does not specify a particular algorithm or system, nor does it include temporal properties or proofs.
