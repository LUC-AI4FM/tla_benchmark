This specification models a trivial state machine with one variable x and one constant C over integers. The initial condition sets the constant to 1 and initializes x to C, while the next-state relation allows only stuttering by leaving x unchanged. It defines an invariant-like state predicate asserting the existence of an integer y in the range (C + 1) .. 4 such that y = 3, and it uses no explicit temporal specification, fairness, fault model, or proofs.
