This module specifies and model checks an implementation of Booth's algorithm for finding the lexicographically least circular substring, i.e. the least rotation of a sequence. The file contains a PlusCal algorithm and its generated TLA+ translation, with state variables tracking the input sequence, its length, the failure-function array, loop indices, and the program counter. It verifies a type invariant over the translated state and states a partial-correctness property asserting that when the program counter reaches "Done", the computed shift k yields a lexicographically minimal rotation, with ties broken by the smallest shift.
