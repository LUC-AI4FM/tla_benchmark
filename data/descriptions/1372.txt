This specification defines a simple static model of partitions over a fixed set of node identifiers. A vertex is represented as a record with a nonempty subset of Nodes, a successor chosen from Nodes \cup {null}, and a dead flag in BOOLEAN; Partitions is the set of collections of such vertices satisfying pairwise disjointness of node sets and a successor-well-formedness condition. The system has a single variable partition, starts with the empty set, and only permits stuttering steps via Next == UNCHANGED partition, so the file defines state structure and typing rather than a dynamic protocol or fault-tolerant algorithm.
