This module defines a bounded model-checking wrapper for a MultiNode specification by restricting part of the behavior with an explicit bound on the number of view changes. It extends existing modules and adds a constant ViewLimit, then defines bounded action variants that guard inherited actions with checks on the lengths of ledgerBranches and history. The module defines a combined next-state action and a temporal specification MCSpecMultiNode == Init /\ [][MCNextMultiNodeAction]_vars, but it does not introduce its own fairness, proofs, or PlusCal algorithm.
