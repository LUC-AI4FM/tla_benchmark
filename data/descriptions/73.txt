This module is a small test specification used to reproduce or validate the resolution of Apalache issue 593, as noted in the file comments. It models a system with a single state variable, `record`, whose initial value is a record containing one field `type` set to the string "B". The next-state relation introduces a LET-bound name `result` equal to `Dummy`, but the action itself leaves the state unchanged, so the behavior consists entirely of stuttering steps from the initialized state.
