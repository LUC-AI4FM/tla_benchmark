This specification demonstrates the use of parametrized INSTANCE in TLA+. It defines two instances of the module test61a: one with a parameter x set to the variable y, and one without substitution. The spec shows how to reference operators from these instances, and includes an invariant that restricts y to the range 0 to 4. The file is intended as a test for handling parametrized INSTANCE and WITH substitution, and does not specify a full algorithm or temporal property.
