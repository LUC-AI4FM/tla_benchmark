This specification models the asynchronous Byzantine agreement (ABA) protocol as described in Bracha and Toueg's 1985 paper. The system consists of N processes, up to F of which may be Byzantine faulty, and T is a threshold parameter. The model abstracts message passing by counting the number of ECHO and READY messages sent and received, and tracks the state of each process via a program counter (pc) that can be in states such as V0, V1, EC, RD, AC, or BYZ. The protocol allows processes to become Byzantine, send and receive messages, and decide on a value. The specification includes several initial state predicates (Init, Init0, Init1), the main next-state relation (Next), and a temporal specification (Spec) that includes weak fairness for liveness. It also defines type invariants and several temporal properties such as agreement, validity, and unforgeability. The model is parameterized by constants and includes a state constraint for model checking. Notable design decisions include the use of message counting abstraction and explicit modeling of Byzantine process transitions.
