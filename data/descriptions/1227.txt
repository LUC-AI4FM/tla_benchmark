This module is a parser-oriented test specification for handling infix operator symbols in TLA+. It defines many otherwise undefined infix operators as simple set-producing operators and then checks, via a large ASSUME formula using TLC's Print and Assert, that these operators can be passed as operator arguments and parsed correctly. It also tests selected built-in boolean, set, TLC, temporal, and action-related infix symbols, but it does not model a transition system with variables, actions over state, or temporal correctness properties of an algorithm.
