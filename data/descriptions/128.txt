This specification models a simple state machine with a single integer variable x and a helper operator A that inserts an integer q into a set p using set union. The initial state sets x to 0, and the next-state relation permits only stuttering steps by leaving x unchanged. The interesting property checked by the module is a state invariant using the Apalache operator ApaFoldSet, asserting that folding A over the set {1,1,2,2,3,3} starting from {4,4} yields the set {1,2,3,4}; because sets eliminate duplicates, this demonstrates set-fold behavior rather than a nontrivial transition system property.
