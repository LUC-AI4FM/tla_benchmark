This module specifies a voucher transfer protocol modeled as a simplified Two-Phase Commit system. A Voucher Transaction Provider coordinates source holders and destination holders for transferring vouchers, with communication represented by a monotonically growing set of messages and with some protocol messages omitted for simplicity, as explained in the comments. The specification defines initialization, participant and coordinator actions, an invariant asserting type correctness and consistency between source and destination outcomes, and temporal properties stating that the overall protocol preserves those invariants and implements an imported voucher life-cycle specification.
