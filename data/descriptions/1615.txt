This module specifies a small PlusCal algorithm with one process family foob running over the set {1,2}. The algorithm demonstrates nested macro expansion: bar assigns x and invokes foo, and foo invokes ff to assign the process-local variable z and then assigns y. The translated TLA+ model initializes global variables x and y, a per-process function variable z, and a program counter pc; it defines process actions l1 and l2, a Next relation, a standard safety-style Spec with weak fairness for each process action, and a termination property asserting that eventually all processes reach "Done".
