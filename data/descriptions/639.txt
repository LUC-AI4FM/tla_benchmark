This module specifies a Tendermint-style light client as a state machine that attempts to verify a target block height starting from a socially trusted header. It models both the light-client local state and an instantiated blockchain environment, including time progression, validator sets, fetched light blocks, verification status, and whether the primary full node is correct or faulty. The specification defines the verification logic, scheduling strategy, store updates, and a single-step system transition, and checks a collection of safety-style invariants and conditional correctness properties about successful verification, faulty primaries, trusting-period expiration, and probe complexity.
