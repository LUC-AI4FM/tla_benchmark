This module defines the standard finite-set operators `IsFiniteSet` and `Cardinality`. It characterizes finiteness by the existence of a finite sequence whose elements cover the set, and it defines cardinality recursively over subsets by removing one chosen element at a time until the empty set is reached. The file contains no state variables, no actions, and no temporal specification; it is a pure mathematical utility module with comments explaining that TLC overrides these operators in Java.
