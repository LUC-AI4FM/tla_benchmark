This specification models a simple state machine with four variables: node activity status, node colors, a token position, and a token color. It defines type constraints over a small node set and a two-color domain, initializes the state nondeterministically subject to some constraints, and defines a next-state relation that similarly chooses a successor state subject to constraints. The temporal property asserted is a standard behavior specification requiring that behaviors start in Init and thereafter satisfy the stuttering-closed next-state formula [][Next]_vars; there are no fairness conditions, fault assumptions, or proof obligations in this file.
