This module defines utility operators for reasoning about functions, including restriction by domain or value predicate, checking whether one function is a restriction of another, computing a function's range, pointwise combination, inversion, and properties such as injectivity, surjectivity, and bijectivity. It also defines existence predicates for injections, surjections, and bijections between sets, and provides folding operators over functions by relying on a locally instantiated Folds module. The file is a pure library-style module with no state variables, no actions, and no temporal behavior; it specifies mathematical operators only and includes explanatory comments and examples illustrating intended use.
