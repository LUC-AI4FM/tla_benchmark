This module is a model-checking instance for an ERC20 specification intended to be checked with Apalache. It fixes the address universe to three uninterpreted string values, uses all integers as the amount domain, and defines an initial balance function that assigns 100 to every address. The module declares state variables for balances, allowances, pending transactions, the last executed transaction, and the next transaction id, then instantiates the ERC20 module; this file itself contains only the instance setup and no transition actions, temporal specification, fairness, or proofs.
