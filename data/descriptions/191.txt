This module defines a small functional TLA+ example intended to illustrate exponential blowup in let-polymorphism during type inference. It introduces a simple pairing operator and then defines an operator Exp through a deeply nested sequence of LET-bound function definitions over the empty set, where each level applies the previous function to itself. The comments explain that the example is a classical complexity benchmark inspired by Mairson's result on ML typability and that type inference for the final operator may consume substantial time and memory. The module does not model a transition system, has no variables or actions, and contains no temporal or fault-tolerance properties.
