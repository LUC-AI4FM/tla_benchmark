This specification models the Car Talk puzzle from the 22 October 2011 program, in which a farmer must break a 40-pound stone into 4 pieces so that any integer weight from 1 to 40 pounds can be measured using a balance scale and those pieces. The spec generalizes the problem to breaking an N-pound stone into P pieces, with N and P as constants. It defines the set of all possible breaks (ways to partition the stone), checks which breaks allow all weights to be measured (solutions), and provides a way to enumerate all such solutions. The design uses recursive summation, set and function constructs, and quantification to capture the combinatorial structure of the problem. The spec is intended for use with TLC, which can compute the set of all solutions for given N and P.
