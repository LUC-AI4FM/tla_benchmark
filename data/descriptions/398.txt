This specification is a small test module that exercises the semantics of the TLA+ UNCHANGED construct over variables and compound expressions. It defines a state with a function variable x over the range 1..3 and a scalar variable y, and the Next action is a disjunction of test cases that check whether various expressions are correctly considered unchanged, including tuples, function elements, records, quantified expressions, CHOOSE expressions, set comprehensions, and DOMAIN expressions. The module uses TLC's Print and Assert operators to validate these cases during model checking, and the only invariant stated is the trivial invariant TRUE.
