This module is a small regression-style TLA+ specification designed to expose a TLC behavior difference between functions and tuples viewed as functions. It defines a function over the domain 1..3 and a tuple with the same elements, then states assumptions showing that they are equal and that function override syntax behaves as expected on the explicit function value. It also includes assumptions documenting problematic TLC behavior when the same override-style expressions are applied to the tuple, including one case reported as evaluating to FALSE and another as producing a TLC error.
