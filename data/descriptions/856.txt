This module is an Apalache-oriented wrapper around another TLA+ specification named Prisoner, providing type annotations and a concrete constant value definition used by configuration. It models the constants and variables relevant to a prisoner problem, including a prisoner set, a light state, a count, an announced flag, a per-prisoner signalling function, and a set of prisoners who have visited. The module itself does not define the system dynamics, actions, or temporal properties; instead, it instantiates the Prisoner module and adds a concrete set of prisoner string values for use by APPrisoner.cfg.
