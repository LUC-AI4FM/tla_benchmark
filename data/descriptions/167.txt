This module specifies a very small state machine intended to expose a model-value typing failure. It declares two constants of different annotated types, initializes three variables, and performs a single next-state step that assigns a singleton set containing C to x, empties z, and changes s from "init" to "next". The invariant deliberately compares the two differently typed model values C and G for equality, and the comment indicates that this comparison should fail because the model values belong to different types.
