This module, APChannel, provides Apalache type annotations for the FIFO/Channel.tla specification. It is designed to be used as a wrapper that applies type information via INSTANCE, so that the original Channel module remains free of tool-specific details. The module introduces a constant Data, a variable chan with a record type, and instantiates the Channel module. It also defines a concrete value DataVal for the Data constant, likely for use in model checking configurations. No temporal properties or algorithmic behaviors are specified directly in this file; it serves as a typed interface for the underlying Channel specification.
