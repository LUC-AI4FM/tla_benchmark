This module specifies Lamport's Paxos consensus algorithm in the style of "Paxos Made Simple", modeling leaders by ballot number and acceptors as separate processes. It uses a message-history style model in which the variable msgs contains all messages ever sent, rather than explicitly modeling channels, message loss, or delivery; safety is expressed over what may be received from that history. The specification defines the translated PlusCal state machine, a type invariant, predicates describing when a value is chosen, and a correctness property asserting agreement-like uniqueness of chosen values; it also includes a theorem claiming that correctness is always true, with comments noting that the theorem is actually false for the current spec and should be checked with TLC.
