This module is a fixed-instance wrapper around the TwoPhaseUFO specification intended to be checked with Apalache or TLC. It declares concrete state variables for a two-phase commit style system with a transaction manager, a set of three resource managers, and predicates representing prepared, commit, and abort messages. The file itself does not define transitions or temporal properties; instead, it instantiates the TwoPhaseUFO module and provides a finite set of resource-manager values for that instance.
