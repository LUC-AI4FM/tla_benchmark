This specification models an outer module that instantiates an inner module with explicit variable substitutions that intentionally alias inner variables to outer variables. The outer system has only stuttering behavior, but it imports a fairness condition and an ENABLED-based predicate from the inner module through the INSTANCE, and the comments explain that the spec is designed to expose a TLC soundness bug involving INSTANCE substitution context and SelectSeq/LAMBDA evaluation. The file checks both a liveness property and a safety-style invariant: the liveness formula is <> (b = 1), the invariant uses IF Svc!StepEnabled THEN TRUE ELSE b /= 0, and the comments explain that both can be incorrectly reported as satisfied because of the bug. A leads-to tautology is also defined. A notable design point is that the inner module uses a recursive-style function definition over a range with LET and a LAMBDA argument to define a pure TLA+ replacement for SelectSeq, contrasting that with the TLC override behavior.
