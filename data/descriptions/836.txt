This module specifies the N-queens problem and an iterative algorithm that computes all valid queen placements on an N x N chessboard. A placement is represented as a sequence or function from rows to columns, and the specification defines when two queens attack each other, what it means for a partial or full placement to be a solution, and the full set of solutions. The file contains a PlusCal algorithm and its TLA+ translation, with variables tracking partial solutions still to explore and full solutions already found, and it verifies safety properties such as type correctness and solution inclusion as well as temporal properties including termination and weak fairness-based progress.
