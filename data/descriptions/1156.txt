This module is a TLC model wrapper for a Raft-related specification imported from the extended module RaftMongo. It declares concrete model values for the Value and Server constants, defines a symmetry set over the servers, adds a state constraint bounding the global current term and log lengths, and maps the model's specification and invariant to names from the imported module. The temporal behavior itself is not defined in this file; instead, the file syntactically references Spec and NeverRollbackCommitted from the extended specification while providing model-specific constants and TLC configuration operators.
