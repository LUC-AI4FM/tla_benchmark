This module is a test specification for TLA+ record constructs, record typing, nested records, function-valued record fields, EXCEPT updates on records, and membership in record-set type constructors. It uses a single boolean variable x with a trivial state machine: Init sets x to TRUE and Next leaves x unchanged. The main property Inv is a large state predicate built with LET-bound records, functions, and record-set types, and it checks many record-related identities using TLC's Assert and Print operators, including nested field access, string-key access, subset relationships between record-set types, and cardinalities of record sets.
