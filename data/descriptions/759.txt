This specification models the generalized Die Hard water-jug problem with an arbitrary set of jugs, a capacity function assigning each jug a positive integer capacity, and a target amount of water called Goal. The state consists of a single variable contents mapping each jug to its current water amount, and the system evolves by filling a jug, emptying a jug, or pouring from one jug into another by the maximum amount possible. The spec assumes only well-formed capacities and a natural-number goal, uses a standard stuttering-inclusive temporal specification Spec == Init /\ [][Next]_contents, and defines NotSolved as the safety property that no jug currently contains the goal amount; the comments explain that TLC can search for a counterexample to this invariant to produce a solution trace.
