This module is a functional test specification for TLA+ operators over records, especially newer record forms such as record constructors, record-set constructors, field access, field update with EXCEPT, and DOMAIN. It models only a trivial state machine with Init == TRUE and Next == TRUE; the substantive content is a collection of state-level test predicates combined into AllTests. The tests check record construction, equality between a record-set constructor and explicit set enumeration, polymorphic field access and update via LET-defined helpers, domain equality across differently typed records, and existence of records in a record type.
