This specification models a very small one-variable transition system over the variable x. The initial state sets x to TRUE, and the next-state action flips x by assigning x' =~x, so the system alternates the Boolean value of x on each step. The temporal specification requires Init and then always [][Next]_x, meaning every step is either a Next step or a stuttering step on x. The file also includes an embedded TLC configuration selecting Spec as the specification and overriding the constant C with the operator val.
