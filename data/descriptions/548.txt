This specification models the N-process Peterson mutual exclusion algorithm as a PlusCal algorithm translated into TLA+. Each process repeatedly cycles through noncritical section, entry protocol, critical section, and exit, using the shared arrays level and last_to_enter to coordinate access to the critical section. The file defines the initial state, one action per translated control location, a combined Next action over all processes, and a simple temporal specification Spec == Init /\ [][Next]_vars; it does not include explicit fairness, liveness, or proof obligations.
