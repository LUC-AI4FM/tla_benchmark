This module specifies a PlusCal algorithm that computes factorials using two mutually recursive procedures, FactProc and FactProc2, executed by three processes. Two Main processes with self in 1..2 and one Minor process with self = 3 each call the factorial procedure on input 5 and then assert that the resulting value is 120. The translated TLA+ model represents procedure calls explicitly with program counters, procedure-local variables, and a stack for return continuations, and it verifies safety via embedded assertions, an invariant that result is a natural number, and liveness via weak fairness assumptions together with a termination property stating that eventually all processes reach Done.
