This module specifies a minimal one-variable state machine with a constant parameter C. The single variable b is initially FALSE and the only next-state action sets b' to TRUE; the temporal specification requires Init and then always allows Next or stuttering via [][Next]_b. The module also defines a constant-level invariant asserting that C is a subset of Nat, and the appended configuration instantiates C as {1, 2, 3} and checks that invariant.
