This module is a small test specification for Leibniz checking in TLA+ module instantiation and substitution. It defines several operators, some of which are Leibniz and some of which are non-Leibniz because they reference primed variables or ENABLED expressions, and then instantiates other modules with those operators as substitutions. The comments explicitly distinguish legal and illegal INSTANCE substitutions to test the rule that a non-Leibniz operator cannot be substituted for a constant operator; the module does not define an execution specification, transition system, or temporal correctness property.
