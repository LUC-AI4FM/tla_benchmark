This specification models a spanning-tree construction algorithm over an arbitrary graph whose node set is fixed by the constant Nodes and whose edge set is chosen nondeterministically as an initial value of the variable Edges. Each node maintains a parent pointer mom and an estimated distance dist from the distinguished root Root; nodes repeatedly update their parent and distance when they discover a neighbor with a shorter path, choosing any improved distance strictly between the neighbor's distance plus one and the node's current distance minus one. The spec checks type correctness, defines a temporal specification with weak fairness on Next, and states safety and liveness properties including a postcondition characterizing rooted, unreachable, and reachable nodes as well as an additional property AllDistancesOne.
