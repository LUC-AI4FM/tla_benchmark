Write a small TLA+ module that demonstrates TLC's state generation and Print-based diagnostic output. The system starts with two variables both initialized to 1, and in each step either leaves both variables unchanged or nondeterministically assigns the first variable a value from the set {1, 2, 3} while keeping the second variable fixed at 1. Each transition should print diagnostic messages so that a user running TLC can observe exactly which states are being generated. The expected observable behavior is that TLC explores exactly 3 distinct reachable states (corresponding to the three possible values of the first variable). The only invariant required is the trivially true condition, meaning the specification is purely a demonstration of how TLC enumerates states and reports them via print statements rather than a model of any real system with meaningful correctness properties.
