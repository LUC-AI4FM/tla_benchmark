Write a TLA+ specification that demonstrates a simple one-variable state machine where the variable starts at zero and evolves according to several possible transition rules. The variable ranges over natural numbers. The system begins with the variable equal to zero, and each step may set it to a fixed constant, assign it a value within a small bounded range, set it to a specific out-of-range value, or perform one of two very specific value-to-value mappings. The key point of the specification is to define an invariant asserting that the variable stays within a small bounded type and remains at its initial value of zero, then package the invariant together with a stuttering-closed next-state relation as the overall specification. The intent is to demonstrate how an invariant that is immediately violated by any non-stuttering step can be used as the specification itself, effectively constraining the system to do nothing. The correctness property to check is that this combined specification is consistent — that is, the initial condition and the invariant hold together with the closed next-state relation.
