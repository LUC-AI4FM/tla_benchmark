Write a TLA+ specification for a distributed spanning-tree algorithm running on a randomly generated undirected graph. The graph is constructed over a fixed set of nodes with a designated root, where edges are chosen randomly so that different model-checking runs exercise different topologies. Each node maintains a distance estimate and a parent pointer. Initially the root has distance zero and all other nodes have distance equal to some large upper bound (at least the number of nodes), with every node pointing to itself as its own parent. At each step, some node may improve its distance by adopting a neighbor as its parent, provided that neighbor's current distance is strictly less than the node's current distance minus one, and the new distance falls strictly between the neighbor's distance plus one and the node's current distance. The algorithm terminates when no such improvement is possible. The key correctness properties are: safety, meaning that whenever the algorithm is quiescent the result is a valid spanning tree or correctly identifies unreachable nodes; and liveness, meaning the algorithm eventually reaches that quiescent state. Reachable nodes must end up with a distance equal to their parent's distance plus one, while nodes with no path to the root retain the maximum-cardinality distance with no reachable neighbors.
