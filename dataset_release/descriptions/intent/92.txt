Write a TLA+ specification that demonstrates how typed constants of various kinds — an integer, a string, a set of integers, and model values — can be declared, configured, and checked by a model checker such as Apalache. The system is a trivial, static one: a set of variables is initialized to the values of the corresponding constants and then never changes. The point of the module is to verify that the model checker correctly handles a configuration file that supplies concrete values for each constant, including two distinct model values. The invariant to be checked asserts that after initialization the integer variable equals 42, the string variable equals "hello", the set variable equals {1, 2, 3}, and the first model-value variable retains its configured value while being distinct from the second model value. No liveness properties are required; the sole correctness requirement is that this conjunction of equality and distinctness conditions holds as a safety invariant throughout all (trivially unchanging) behaviors.
