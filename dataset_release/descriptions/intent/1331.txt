Specify a TLA+ model of Safra's distributed termination detection algorithm on a ring of N nodes, where message channels are modeled explicitly as FIFO sequences rather than sets. The system consists of N nodes arranged in a ring, each of which can be active or inactive, send payload messages to other nodes, receive payload messages (which reactivate the receiver), and spontaneously deactivate. A single token circulates around the ring carrying a cumulative message count and a color. Node 0 initiates a new probe whenever the token returns to it with evidence that termination has not occurred (wrong color or nonzero in-flight message count). Each node passes the token only when inactive, accumulating its local counter into the token and blackening it if the node is black. The key safety property is the termination detection invariant inherited from the abstract EWD998 specification: the algorithm must never falsely announce termination when messages are still in flight or nodes are still active. The channel-based model must refine the abstract EWD998 specification via a refinement mapping. Liveness is ensured by weak fairness of the token-passing system actions, guaranteeing that the token continues to circulate and termination is eventually detected once the computation has truly finished.
