Write a small TLA+ module that demonstrates how conjunctive initial-state predicates are evaluated together as a simultaneous constraint rather than sequentially. The specification has two variables, x and y, whose initial values are determined by three conjuncts: y equals zero, x equals zero, and y equals x. All three must be satisfied simultaneously in the initial state. After initialization, both variables remain unchanged forever. The key point being illustrated is that the order in which the conjuncts appear does not matter — the system finds values satisfying all constraints at once. The only reachable state is x = 0 and y = 0, and the system stays there. The specification should be checkable with a model checker to confirm that this single initial state is valid and that the stuttering-closed safety property of doing nothing holds thereafter.
