Write a TLA+ specification that demonstrates a minimal stub or scaffolding module for the Dijkstra–Scholten token-based termination detection algorithm over a small fixed set of nodes. The system should model nodes that can be either active or passive, each carrying a color (white or black), along with a circulating token that has a position and its own color. The module need not implement the full algorithm logic — it serves as a starting skeleton where both the initial state and all transitions are unconstrained (any combination of node activity, node colors, and token position is permitted), with the token color fixed to black throughout. The type invariant should capture that node activity is a boolean assignment over the node range, node colors are drawn from the two-element color set, the token position is a valid node, and the token color is a member of the color set. The specification should be checkable as written, with the type invariant as the primary correctness property of interest.
