Write a TLA+ specification that demonstrates how TLC handles `\subseteq` constraints in next-state relations and evaluates the `ENABLED` predicate for such constraints. The system has two variables: one that ranges over subsets of a small finite set and one that remains constant. The initial condition constrains the first variable to be any subset of a two-element set while the second is fixed to the full three-element set. The next-state relation keeps the second variable unchanged and allows the first variable to be any subset of the (unchanged) second variable. The specification should verify two invariants: that the first variable always stays within the three-element universe, and that the `ENABLED` predicate correctly recognizes that a transition constraining the first variable to subsets of a singleton is always possible. Additionally, the specification should use TLC's `_POSSIBLE` feature to track how many distinct states satisfy two state predicates — one checking whether the first variable equals the full set, and one checking whether a specific element is newly gained — and a postcondition should assert the exact expected counts for each predicate based on TLC's enumeration of all reachable next-state pairs.
