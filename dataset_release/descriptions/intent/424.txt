Write a TLA+ specification for a small test model of a multiprocessor request-ordering system, intended to verify correct handling of a request queue and ordering relation. Each processor maintains a sequence of pending requests, where each request carries an address, a value, and an operation type (read or write). Processors may issue new requests, appending them to their queue and updating a global partial order over request identifiers (each identified by processor and queue index). The ordering relation must remain a strict partial order — irreflexive and transitive — and must respect per-processor program order, meaning earlier-issued requests from the same processor always precede later ones. When new requests are issued, the ordering relation may grow but must never lose existing order pairs. The type invariant requires the queue map and order relation to have the appropriate types at all times. Use small finite constants (two processors, one register, one address, two values) and bound queue length to keep the state space tractable. The key correctness property to check is the type invariant.
