Write a small TLA+ module that demonstrates recursive function definitions and their use in invariants. The module should define a recursive function over a small finite domain of integers that computes a simple sequence, and a trivial system whose state variable is initialized to a value within that domain and never changes. The correctness property to verify is that the state variable always equals some value produced by the recursive function, meaning the variable's initial value is reachable within the function's range. The specification should confirm that this invariant holds under the stuttering-tolerant next-state relation.
