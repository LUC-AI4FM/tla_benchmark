Write a TLA+ specification for the translation phase of the PlusCal-to-TLA+ compiler. The module receives a PlusCal algorithm's abstract syntax tree (AST) and a fairness annotation as external inputs and computes the corresponding TLA+ specification as a sequence of string tokens.

The system must validate that the AST represents a syntactically legal algorithm (either uniprocess or multiprocess), covering all statement types: assignments, conditionals, while loops, either-or branches, with-do blocks, procedure calls, returns, combined call-returns, goto, when, print, assert, and skip. It must check that labels within each context are unique and that every goto target refers to an existing label.

The translation itself must produce correct TLA+ output including: variable declarations, the Init predicate, labeled-action definitions for each step, the Next next-state relation, the complete Spec formula, and a Termination formula. For multiprocess algorithms the translation must add appropriate self-subscripts to local variables, define ProcSet, and handle the procedure call stack correctly, including saving and restoring procedure parameters and local variables. The Spec formula must incorporate the specified fairness condition (none, weak fairness of all actions, weak fairness of Next, or strong fairness of all actions). The module should signal descriptive errors if the algorithm is malformed, if labels are inconsistent, or if assignments violate scope or multi-assignment rules.
