Write a TLA+ specification for a classic bounded producer-consumer buffer system with multiple concurrent producers and consumers. There is a fixed-capacity shared buffer, a set of producer processes that append items to the buffer, and a set of consumer processes that remove items from the buffer. Producers that attempt to add to a full buffer are suspended in a waiting set, and consumers that attempt to remove from an empty buffer are similarly suspended. When a producer successfully adds an item it may wake a waiting consumer, and when a consumer successfully removes an item it may wake a waiting producer. The sets of producers and consumers must be disjoint and non-empty, and the buffer capacity must be at least one. The key safety property to verify is that the system never reaches a state of complete deadlock in which every producer is waiting and every consumer is simultaneously waiting — that is, it is always the case that not all producers and all consumers are blocked at the same time.
