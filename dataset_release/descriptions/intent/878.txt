Specify a spanning-tree algorithm for an undirected graph. Given a fixed set of nodes, a set of undirected edges (each edge represented as a two-element set of distinct nodes), a distinguished root node, and an upper bound on the number of nodes, the algorithm must compute a parent function that encodes a rooted spanning tree. Each node tracks its distance from the root, initialized to zero for the root and to the given upper bound (standing in for infinity) for all other nodes. Repeatedly, any node whose current distance exceeds one more than some neighbor's distance may lower its distance to any value strictly between that neighbor's distance plus one and its own current distance, and record that neighbor as its parent. The algorithm terminates when no such improvement is possible.

The key safety property is that upon termination the parent function correctly reflects a valid spanning tree: the root has distance zero and is its own parent; nodes unreachable from the root retain distance equal to the upper bound, are their own parents, and have no neighbors with smaller distance; and every other node's distance equals its parent's distance plus one, with the parent being an actual neighbor. The liveness property is that the algorithm must eventually terminate.
