Write a TLA+ specification that demonstrates the use of TLC's `RandomElement` operator to show that simulation-based model checking can miss invariant violations. The system tracks two independent variables, each of which is randomly assigned a value from the set {0, 1} on every step. The invariant to check asserts that the two variables are always equal. Because each variable is chosen independently and randomly, a counterexample where they differ exists but may not be found deterministically — illustrating that `RandomElement` causes TLC to explore only a sampled subset of behaviors rather than exhaustively verifying all states. The specification should start both variables at zero and transition by independently re-assigning each variable on every step, with the invariant checked throughout. This module serves as a small pedagogical demonstration of how randomized simulation in TLC differs from exhaustive verification.
