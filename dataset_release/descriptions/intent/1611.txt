Specify a TLA+ model of the merge sort algorithm, as transcribed from Sedgewick's "Algorithms" (2nd edition, page 166), operating on integer arrays of length up to some configurable maximum. The algorithm sorts an array by recursively splitting it into halves, copying elements into a temporary buffer array in a specific mirrored pattern, and then merging back from the buffer into the original array. The input array is nondeterministically chosen at startup from all arrays of any length between zero and the configured maximum, where both indices and values range over natural numbers up to that length.

The specification must guarantee two correctness properties. First, a safety invariant: upon termination, the array must be sorted in non-decreasing order — that is, for every pair of indices x and y in the array's domain, x less than y implies the element at x is no greater than the element at y. Second, a liveness property: the algorithm must always eventually terminate. The model should be parameterized by a maximum array length constant and should be validated with that constant set to 2, confirming the exact number of states satisfying the "sorted" termination condition and the number of merge-step transitions observed during model checking.
