Write a TLA+ specification that demonstrates how a CASE expression with an OTHER clause can be used to conditionally update a record (or function). The system maintains an integer variable chosen from a small fixed set and a function mapping that same set to integer values, all initially zero. On each step, the function is updated according to a rule: if the integer variable equals a specific value, one particular entry in the function is set to a designated constant; otherwise the function is left unchanged. The integer variable never changes. No explicit safety or liveness properties need to be checked beyond the specification itself — this is a small illustrative module showing how TLA+ CASE with OTHER behaves when applied to a record-update operator within a next-state relation.
