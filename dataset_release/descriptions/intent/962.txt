Write a TLA+ specification for an abstract correctness model of the Alternating Bit Protocol. The system involves a sender and receiver exchanging data values, tracked through control bits and acknowledgment bits rather than explicit message channels. The sender holds a current data value and a send bit; when its acknowledgment bit matches its send bit, it may choose a new data value and toggle the send bit to indicate a pending transmission. The receiver copies the sent value and flips its own bit to match the sender's bit when it detects a discrepancy. The sender advances its acknowledgment bit to track the receiver's bit, again when they differ. The specification should maintain a type invariant asserting all bits are boolean (0 or 1) and both data variables are drawn from the given Data constant. Liveness is enforced by requiring that the receive and acknowledge actions are weakly fair, ensuring that if the receiver can copy a message or the sender can update its acknowledgment, these actions will eventually occur. The overall specification combines the initial condition, the stuttering-tolerant next-state relation, and these fairness conditions.
