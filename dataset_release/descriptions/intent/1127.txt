Specify a simple single-phase atomic commit protocol for a fixed set of resource managers. Each resource manager begins in a working state and may independently prepare (signaling readiness to commit) or abort at any time before a final decision is reached. A prepared resource manager may commit only once all resource managers have reached at least the prepared state. The system must satisfy two key safety invariants: type correctness (every resource manager is always in one of the four states: working, prepared, committed, or aborted), and consistency (no two resource managers ever reach conflicting decisions, meaning it is impossible for one to have committed while another has aborted). There is no liveness requirement; deadlock freedom need not be checked. The protocol should be verified with three concrete resource managers.
