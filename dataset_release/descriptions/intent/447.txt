Write a TLA+ specification that demonstrates the use of `INSTANCE` inside a `LET` expression within an action definition. The system models a single variable cycling through the values 0 to 4. On each step, the variable is updated by invoking an operator from a locally instantiated module — the instantiation and any auxiliary definitions appear inside a `LET` block rather than at the top level of the module. The instantiated module provides a "value plus one" operation, and the result is reduced modulo 5 to keep the variable in range. The initial state sets the variable to 0. The specification must satisfy weak fairness so that progress is guaranteed. The safety invariant requires that the variable always remains in the range 0 through 4. The liveness property requires that the value 4 is reached infinitely often.
