Write a TLA+ specification that demonstrates basic PlusCal variable manipulation as a simple introductory example. The model should initialize a set variable containing two string elements and a sequence variable containing three integers. It should then perform two sequential updates: adding a new string element to the set, and replacing the second element of the sequence with a different integer value. Each updated value should be printed after modification. The specification should guarantee that execution eventually terminates, meaning the program reaches a done state in finite steps. This is a tutorial or session demonstration module intended to illustrate how PlusCal handles set union operations and sequence element updates, along with TLC's print functionality, rather than modeling any real-world concurrent system or algorithm.
