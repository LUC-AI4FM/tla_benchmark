Write a TLA+ specification demonstrating Euclid's algorithm for computing the greatest common divisor of 24 and some nondeterministically chosen second value. The second input should be chosen from the range 1 to N, where N is a model constant. The algorithm repeatedly subtracts the smaller value from the larger until one of the values reaches zero, at which point the other holds the GCD. When the algorithm finishes, it should print the result alongside the original second input for verification. Define a mathematical GCD operator and use it to confirm correctness. The specification must guarantee termination: no matter which starting value is chosen from the allowed range, the algorithm always completes in finite steps. Use weak fairness to ensure progress is not indefinitely blocked. The model should be checked with N set to a small value such as 3, and the termination property must be verified by the model checker.
