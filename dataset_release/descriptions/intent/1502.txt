Write a TLA+ demonstration module that shows how a higher-order constant operator can be passed in via a configuration file and used to drive state transitions. The module should declare a single variable initialized to zero, and define a transition relation where the variable's next value is drawn from the set produced by applying the configured operator to the current value. The module should also illustrate how an operator defined locally — one that ignores its argument and returns the powerset of some fixed finite set — can be substituted for the higher-order constant through the model configuration. The key point to demonstrate is that TLA+ allows operators to be passed as constants and overridden in the configuration, enabling flexible parameterization of a spec's behavior without changing the spec itself. No particular safety or liveness properties need to be verified; the purpose is purely to illustrate the operator-substitution mechanism.
