Specify Dijkstra's token-ring mutual exclusion algorithm for N processes arranged in a ring, using K distinct counter values (where K > N > 0). There is one special process (process 0) and N−1 ordinary processes numbered 1 through N−1. Each process holds an integer value in the range 0 to K−1. Process 0 may act when its value equals its neighbor's value (the last process in the ring), and when it does, it increments its value modulo K. Each other process i may act when its value differs from the value of process i−1, and when it does, it copies that neighbor's value. A process "holds the token" if it is currently enabled to act: process 0 holds it when its value equals process N−1's value, and any other process holds it when its value differs from its predecessor's value. The specification must guarantee two correctness properties: safety, meaning at least one process always holds the token, and liveness, meaning that eventually exactly one process holds the token and that condition persists. All processes must be scheduled fairly.
