This specification models a tiny state machine over three variables x, z, and s, together with two model-value-style constants C and G. The initial state sets x to the empty set, z to the singleton set containing G, and s to the string "init"; the single next-state action updates x to the singleton {C}, z to the empty set, and s to the string "next". The module also defines a simple invariant stating that either G is a member of z or C is a member of x, and it includes a helper predicate CInit constraining the constants to specific string values.
