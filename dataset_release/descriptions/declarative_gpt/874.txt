This module provides Apalache-oriented type annotations and concrete constant values for an instantiated spanning-tree specification. It declares the constants Nodes, Edges, Root, and MaxCardinality, and the variables mom and dist, then instantiates the module SpanTree rather than redefining its behavior locally. The file itself does not define the spanning-tree algorithm, actions, or temporal properties; instead, it supplies typed context and concrete example values for a small three-node graph used by APSpanTree.cfg.
