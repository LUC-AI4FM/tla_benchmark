This specification defines a CRDT-related module that builds on an imported CRDT module and introduces a reduction step for counters. It constrains the state so that every node's self-counter entry stays at most 3, defines a Reduction action that subtracts the global minimum counter value from every counter entry, and composes that reduction with imported Increment and Gossip actions. The file also includes an assumption that TLC's experimental support for action composition \cdot is enabled, and defines a next-step relation that nondeterministically chooses either a plain imported action or its composition with Reduction.
