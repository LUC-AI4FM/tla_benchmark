This module specifies a simplified Tendermint consensus protocol extended with explicit time, local clocks, a global real-time clock, and proposer-based timestamps. It models correct and Byzantine processes, proposal/prevote/precommit message exchange across rounds, and checks safety-style invariants about agreement on decided values and timestamps, as well as validity relations between decisions and timing bounds. The design includes bounded message delay, clock precision and accuracy assumptions, optional clock drift, explicit bookkeeping for received timely proposals, and liveness-related predicates such as bounded delay and eventual timely proposal reception, but it does not define a temporal Spec formula in this file.
