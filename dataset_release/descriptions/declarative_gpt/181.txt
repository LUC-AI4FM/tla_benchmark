This specification is a small regression-test model for sets of function sets. It declares a variable `witness` that is constrained initially to belong to a singleton set whose only element is a function-set constructor `[{TRUE} -> {222521218, 0}]`, and a Boolean variable `found` that is initialized to range over `BOOLEAN`. The behavior is trivial after initialization: `Next` allows only stuttering by leaving both variables unchanged, and `NotFound` is a simple state predicate expressing that `found` is false via negation.
