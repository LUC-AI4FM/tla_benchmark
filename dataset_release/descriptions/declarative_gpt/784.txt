This specification models Conway's Game of Life on an N by N finite grid. The state consists of a single variable grid mapping each position in the set of board coordinates to a Boolean value indicating whether the cell is alive or dead, and the next-state relation computes the standard Life update rule from neighbor counts. The spec defines helper operators for summing values over a finite set, handling boundary cells outside the board as dead, and counting live neighbors; it verifies behavior through an initial condition and a temporal specification of repeated Next steps with stuttering allowed. There is no fault model, fairness condition, proof structure, or PlusCal algorithm in this file.
