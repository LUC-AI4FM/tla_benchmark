This module specifies and proves properties of a voting protocol in which acceptors maintain a set of votes and a maximum ballot seen. The spec includes the TLA+ translation of a PlusCal algorithm where each acceptor can either increase its maximum ballot or cast a vote for a value at a ballot, subject to a recursively defined safety condition SafeAt. The module proves inductive invariants and agreement-style properties, connects the voting spec to an instantiated Consensus specification, and adds an explicit liveness assumption based on weak fairness for fixed ballot actions together with a stability condition excluding higher ballots.
