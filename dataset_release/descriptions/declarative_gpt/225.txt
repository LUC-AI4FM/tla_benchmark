This specification models a very small transition system used for testing slicing of symbolic transitions. It has a single state variable, initialized to the string "Init", and two possible next-state actions: one sets the state to "A" directly, and the other existentially chooses a value from the set {1, 2, 3} while setting the state to "B". The spec also defines a simple invariant asserting that the state is not equal to "B", but it does not define a full temporal specification, fairness condition, PlusCal algorithm, or proof.
