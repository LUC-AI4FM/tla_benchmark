This module proves auxiliary lemmas about the graph reachability operator ReachableFrom defined in the imported module Reachability. The lemmas characterize basic properties of reachability from a set of nodes, including that every node in a starting set is reachable, that adding successors of a node already in the set does not change the reachable set, and that the reachable set from the empty set is empty. The file is proof-oriented rather than algorithmic: it contains TLAPS-checked hierarchical proofs, uses induction over natural numbers via NaturalsInduction, and establishes facts used in the correctness proof of the algorithm in module Reachable.
