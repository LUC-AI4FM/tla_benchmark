This specification models a very small state machine with two state variables, a and b. It defines an initial state where both variables are 0, and a next-state relation in which a' is chosen from the constant set A while b' is fixed to 1, subject to additional disjunctive conditions relating the current and next values of a. The temporal property Spec asserts that executions start in Init and then always satisfy the stuttering-closed next-state specification [][Next]_<< a,b >>; no explicit fault model, fairness assumptions, or proofs are present.
