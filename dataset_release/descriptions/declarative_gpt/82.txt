This specification models a very small callback-style pattern in which a higher-order operator Pick is parameterized by an operator argument Cb and succeeds by choosing some integer i in the range 1..10 for which Cb(i) holds. The initial condition defines a local callback Cb(i) as the state predicate x = i, and the next-state relation defines a local callback Cb(i) as the action x' = i, so Init requires x to be one of 1 through 10 and Next nondeterministically assigns x a value in that same range. The specification also defines a simple invariant Inv asserting that x > 0; there is no temporal Spec operator, no fairness condition, and no fault model in this file.
