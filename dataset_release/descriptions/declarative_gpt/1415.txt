This specification models a small state machine over two variables x and y, with a fixed set S = {"n1", "n2"}. The main behavioral constraint is expressed through the operators Direct, Indirect, and InIndirect: a next-state pair of values must satisfy type-like conditions requiring xx to be a function from S to {"a"}, yy to be a function from S to S, and for every s in S, if xx[s] = "a" then yy[s] = s. The temporal property Spec consists only of Init and the standard boxed next-state formula [][Next]_vars, with no explicit fairness assumptions, fault model, or liveness properties.
