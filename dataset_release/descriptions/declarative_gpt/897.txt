This module is a TLC model-checking companion module for the InternalMemory specification. It defines concrete replacement operators for the constant operators Send, Reply, and InitMemInt so TLC can evaluate the internal-memory interface used by the underlying specification. The design choice documented in the comments is to model both send and reply by assigning the next internal-memory value to the tuple <<p, d>>, and to define the initial memory-interface values as a singleton set containing <<p, NoVal>> for an arbitrary chosen processor p; this module itself contains no temporal properties or proofs.
