This specification is a small regression test for Apalache issue 476 involving existential quantification over a tuple. It models a two-variable system with integer state variables x and y, initialized to 0, and a next-state relation that nondeterministically assigns x and y from a tuple <<i, j>> drawn from the Cartesian product (1..2) \X (3..4). The file contains only the initialization and transition relation and does not define a temporal specification, fairness condition, theorem, or proof.
