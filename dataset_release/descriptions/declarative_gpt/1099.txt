This module defines a refinement-oriented extension of a lock specification by adding two auxiliary variables: a history variable h_turn and a stuttering variable s. The purpose is to make the lock specification mimic the finer-grained entry behavior of Peterson's algorithm so that the resulting specification can be related to an instantiated Peterson specification. The module defines initialization, process actions, a next-state relation, a temporal specification, and invariants stating typing and consistency properties of the added auxiliary state, including how stuttering encodes intermediate Peterson control states.
