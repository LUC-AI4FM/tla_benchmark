This specification models a simple resource allocator for a finite set of clients and resources. Each client may request a set of resources only when it has no outstanding unsatisfied request and currently holds no allocated resources; requests may then be satisfied incrementally, and clients may return held resources even before their full request has been completely satisfied. The module defines two high-level temporal specifications with different fairness assumptions, and states and proves properties about type correctness, mutual exclusion of resource ownership, eventual return of resources, eventual acquisition of requested resources, and repeated satisfaction of requests. It also includes a TLC symmetry expression and a concrete counterexample value structure near the end of the file.
