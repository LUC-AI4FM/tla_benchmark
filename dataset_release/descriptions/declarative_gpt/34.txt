This module defines a small library of helper operators for representing and manipulating tagged variants in TLA+. It models variants as records whose single field name is the tag and whose field value is the wrapped payload, and it provides operators to construct a variant, filter a set of variants by tag, recover a variant's tag, safely get a tagged value with a default, and unsafely project a tagged value directly. The file does not model a transition system or fault-tolerant algorithm, declares no variables, and contains no temporal properties; it is purely a collection of state-level value operators with comments explaining their intended typed interpretation and an untyped default implementation.
