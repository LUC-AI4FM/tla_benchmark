This specification models a simple terminating loop generated from a PlusCal algorithm that computes the greatest common divisor by repeated subtraction and swapping. The algorithm initializes u to 24, chooses v from the range 1 .. 50, repeatedly swaps u and v when u < v, then subtracts v from u until u = 0, at which point it terminates with v holding the gcd. The translated TLA+ spec represents control flow with the program counter pc, defines Init, step actions for each label, a Next relation including an explicit stuttering disjunct in the Done state to avoid deadlock, and specifies behavior with the temporal formula Spec == /\ Init /\ [][Next]_vars.
