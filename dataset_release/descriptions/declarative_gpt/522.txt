This module specifies an alternating-bit style communication protocol with two endpoints, A and B, and lossy channels in both directions. A repeatedly sends a message record containing data and a control bit to B, while B sends acknowledgments carrying only the bit back to A; A changes its message only when it receives a matching acknowledgment bit, and B updates its stored message when it receives a message whose bit differs from its current one. The model includes explicit message loss through a separate process that can remove arbitrary elements from either channel sequence, and the temporal specification requires initialization, all behavior to follow the translated Next action with stuttering, and fairness conditions for the sender and receiver actions generated from the PlusCal algorithm.
