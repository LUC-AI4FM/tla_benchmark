This specification models a simple parameterized state machine over an array-like function x and a selector variable y. Initially, x maps every element of a non-contiguous domain Dom to 0, and y is chosen from 1..C, yielding C possible initial states that form isomorphic disjunct subgraphs as noted in the comments. Each next-state step leaves y unchanged, chooses an index i in Dom, increments x[i] modulo K, and additionally requires the existence of a subset s of 1..L whose cardinality is L; the comments explain that this construction is intentionally expensive because TLC must explore SUBSET (1..L) and compute cardinalities, making a single next-state evaluation asymptotically proportional to 2^L while the total state space is K^N.
