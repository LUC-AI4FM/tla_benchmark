This module specifies the single-value consensus problem at a very abstract level by modeling only the act of choosing a value, not proposal or learning by clients. The system has one variable, chosen, initially the empty set, and a single state-changing action that can change it once from {} to {v} for some nondeterministically selected v in Values; after that, no further choice is enabled, so the safety specification permits stuttering forever as well. The module proves a safety property that at most one value is ever chosen via an invariant-style theorem, and then defines a stronger liveness specification by adding weak fairness on Next to prove that eventually some value is chosen.
