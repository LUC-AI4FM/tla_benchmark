This module specifies Euclid's algorithm for computing the greatest common divisor of two positive integers between 1 and MaxNum. The file includes a PlusCal algorithm and its generated TLA+ translation, with state variables for the program counter and the algorithm variables u_ini, v_ini, u, and v. The specification checks termination under weak fairness of Next, asserts correctness of the final result using a mathematically defined GCD operator, and also includes TLC-based counting expectations for named properties.
