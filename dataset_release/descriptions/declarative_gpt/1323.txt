This TLA+ specification models Dijkstra's token-based termination detection algorithm (EWD840) for a distributed system. The system consists of N nodes arranged in a ring, each of which can be active or inactive and colored white or black. A token circulates among the nodes, carrying a color and position, and is used to detect global termination. The algorithm tracks node activity and color changes to ensure that termination is detected only when all nodes are inactive and no messages are in transit. The specification defines the system's state, actions (such as passing the token, sending messages, and deactivating nodes), and temporal properties including liveness and safety. Fairness is enforced on the System action, and several invariants and liveness properties are specified to verify correct termination detection.
