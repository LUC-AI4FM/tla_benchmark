This file contains a PlusCal algorithm named trade that models a simple trading system over a fixed set of people and items. The variable owner_of records a function from Items to People, and up to three process instances of giveitem can attempt to transfer ownership of an item to some person. A trade is performed only when origin_of_trade equals the current owner, so the modeled rule is that only the current owner may give an item away. The file contains no explicit temporal property definitions, fairness conditions, assumptions, or proofs; it is just the PlusCal algorithm embedded in comments.
