This module provides Apalache-oriented type annotations and concrete helper definitions for a multi-producer multi-consumer Disruptor specification. It introduces typed constants and variables describing a ring buffer, writer and reader thread sets, sequence numbers, publication status, per-thread program counters, and consumed sequences, then instantiates the underlying Disruptor_MPMC module. The file also defines a typed monomorphic version of Range to support uses on specific functions and gives concrete writer and reader value sets for configuration, but it does not itself define initialization, next-state actions, or temporal correctness properties.
