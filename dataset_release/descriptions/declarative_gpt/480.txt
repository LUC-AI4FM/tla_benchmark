This module specifies a message-passing version of the Paxos consensus algorithm without explicit leaders or learners. It models acceptors, ballots, quorums, and the accumulation of all sent messages in a single set variable, focusing primarily on safety rather than realistic message transport behavior such as loss, duplication, or delivery. The specification defines the phase 1a, phase 1b, phase 2a, and phase 2b actions, gives a standard temporal specification `Spec == Init /\ [][Next]_vars`, and includes copied helper predicates from a Voting-style abstraction plus an inductive invariant candidate relating acceptor vote state to the recorded vote messages.
