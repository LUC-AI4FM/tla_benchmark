This specification models a simple state machine with two variables, x and y. Initially, x is assigned an arbitrary element chosen by TLC's RandomElement from the range 1..1000, and y is initialized to 0; on each next-state step, x either changes to another RandomElement from the same range or stutters, while y increments by 1. The spec defines a standard temporal behavior Spec using Init and the stuttering-closed action [][Next]_<<x,y>>, and it also defines a state invariant Inv asserting that y remains less than 10, though that invariant is not enforced by the transition relation and is instead a property one could check.
