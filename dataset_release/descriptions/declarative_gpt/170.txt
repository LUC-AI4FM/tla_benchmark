This specification models a simple transformation of a finite input set of integers into a sequence. It starts with the variable Left equal to the constant input set InSet and the variable OutSeq equal to the empty sequence, then repeatedly chooses an element from Left, appends it to OutSeq, and removes it from Left until Left is empty. The spec includes an initialization predicate, a next-state relation, a constant initialization constraint fixing InSet to 1..4, and an invariant stating that the original input set is always equal to the union of the remaining elements in Left and the elements already placed into OutSeq.
