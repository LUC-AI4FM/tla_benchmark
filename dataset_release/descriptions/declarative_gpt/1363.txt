This specification is a small TLC-focused test that models nested function values over a non-reducible domain in order to exercise function-domain handling. It defines a set of functions S, builds an initial function I over that set, then constructs x and y using EXCEPT updates where the keys are themselves function values. The spec checks an invariant involving DOMAIN y and S, using PrintT for debugging output, and it has no fault model, fairness, liveness, PlusCal algorithm, or proofs.
