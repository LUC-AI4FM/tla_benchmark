This specification models a simple bag (multiset) over a finite integer base set. The single state variable `bag` is initialized to the empty bag and can evolve by either adding one occurrence of an element from `Base` or removing one occurrence of an element from `Base`, using bag addition and subtraction. The module is a basic state-machine skeleton with `Init` and `Next`; it does not include an explicit temporal `Spec`, fairness conditions, proofs, or fault model.
