This module is a thin wrapper around the HourClock specification, intended to add Apalache type annotations while keeping the original HourClock module unchanged. It declares a single state variable hr with an integer type annotation comment and instantiates the HourClock module, but it does not define any new behavior, actions, temporal specification, or properties of its own. The file serves as a duplicate companion module for chapter examples so sibling modules can refer to HourClock-related content without modifying the original source.
