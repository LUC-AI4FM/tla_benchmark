This module is a small TLA+ test specification about using the Repeat operator with a locally defined operator inside a LET expression. It defines a local operator Op(a, i) == a + 1 and then existentially quantifies over x in the singleton set {5} to assert that Repeat(Op, x, 0) = 5. The spec also includes trivial Init and Next definitions equal to TRUE, and it does not contain temporal properties, fairness conditions, proofs, or PlusCal code.
