This module is a model-checking wrapper for the InnerSerial specification. It introduces a bounded natural-number set MCNat and a state constraint that limits the length of each process operation queue to MaxQLen, in order to keep the TLC state space finite. It also defines an arbitrary initial memory function MCInitMem for the constant parameter InitMem, and states a liveness property AlwaysResponds asserting that non-free register operations eventually become free again and that operation identifiers in opId eventually correspond to completed operations.
