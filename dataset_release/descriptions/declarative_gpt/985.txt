This module specifies the Yo-Yo leader election algorithm on arbitrary strongly connected undirected graphs without self-loops, where nodes are identified by integers and the node with the smallest identifier is the eventual leader. The algorithm maintains an orientation of graph edges via incoming and outgoing neighbor sets and alternates between a down phase, where minimum identifiers are propagated toward sinks, and an up phase, where yes/no replies propagate back and edges receiving a "no" are reversed. The specification models asynchronous node steps as a state machine, assumes a strongly connected undirected input graph, and verifies type correctness, structural neighbor consistency, absence of newly created sources, and eventual stabilization to a state where only the minimum node remains the unique source and all up messages are "yes".
