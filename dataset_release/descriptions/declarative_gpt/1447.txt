This specification models a simple two-variable state machine in which variables x and y are both initialized to 0, and on each next-state step each variable is assigned independently to a randomly chosen element of the set 0..1 using TLC's RandomElement operator. The temporal specification consists of the standard initial condition conjoined with the boxed next-state relation over the tuple <<x,y>>, allowing stuttering through the usual TLA+ action subscript semantics. The file also defines an invariant candidate asserting that x = y, which is notable because the next-state assignments are chosen independently and therefore do not enforce equality after initialization.
