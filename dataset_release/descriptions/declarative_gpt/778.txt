This module defines a generic operator MapThenFoldSet that, given a binary operator 'op', a base value, a mapping function 'f', a choice function 'choose', and a set S, applies 'f' to each element of S and then folds the results using 'op', starting from 'base'. The folding order is determined by the 'choose' function, which selects an element from a set; if 'choose' is not deterministic, the result may depend on the order unless 'op' is associative and commutative. The module comments explain the intended use and provide an example, and reference simpler versions of fold for sets, functions, and sequences in other modules. No temporal properties or state variables are present; this is a pure functional operator definition.
