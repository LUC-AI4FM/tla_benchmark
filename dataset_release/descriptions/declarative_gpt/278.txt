This module specifies a typed version of the classic two-phase commit protocol. It models a transaction manager and a set of resource managers, with state variables for each RM's local state, the TM state, the set of prepared RMs known to the TM, and the set of messages that have been sent. The specification defines initialization, the TM and RM actions, a next-state relation, the overall temporal specification TPSpec, and a consistency property TCConsistent stating that no two resource managers can end in conflicting committed and aborted decisions.
