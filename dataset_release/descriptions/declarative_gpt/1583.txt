This module specifies a small PlusCal algorithm named Either that demonstrates nondeterministic choice using two either/or constructs. The system has four variables: control state pc and data variables x, y, and z; it first chooses between updating x or y, then performs a second choice guarded by the value of x, and finally checks two assertions about the resulting values. The translated TLA+ specification defines the initial state, step actions, a stuttering termination action to avoid deadlock after completion, the temporal specification Spec with weak fairness on Next, and a liveness property Termination asserting that control eventually reaches "Done".
