This module contains TLAPS proofs for the safety and liveness properties of Dijkstra's termination detection algorithm in a ring. It proves type correctness and the main invariant as inductive invariants, derives the safety property that termination is only detected when global termination holds, and then proves liveness using a fairness assumption on the system action together with a three-round argument about token circulation. The module also proves that the concrete algorithm refines a higher-level termination-detection specification, and it is written as a proof module extending another module that contains the actual algorithm definitions.
