This module specifies and proves properties of a voting protocol related to consensus, using acceptors, ballots, and quorums. It models acceptors maintaining a set of votes and a maximum ballot seen, defines a recursive safety predicate SafeAt, and proves state invariants ensuring vote consistency and safety. The file also contains TLAPS proofs showing inductive invariance, uniqueness of chosen values, refinement toward an instantiated Consensus specification, and a liveness assumption requiring weak fairness for some ballot actions while ruling out higher-ballot actions forever.
