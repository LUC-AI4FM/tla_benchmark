This specification models a simple 12-hour clock. The state variable 'hr' represents the current hour, which ranges from 1 to 12. The initial predicate HCini ensures that the hour starts within this range, and the next-state action HCnxt increments the hour by 1 unless it is 12, in which case it wraps around to 1. The temporal property HC asserts that the system starts in a valid state and always follows the hour update rule. The theorem verifies that the invariant HCini is always maintained.
