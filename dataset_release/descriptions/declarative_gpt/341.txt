This specification is a very small test module intended to check that TLC distinguishes the tuple <<x>> from the scalar value x when they appear in function expressions. It defines a set S by set comprehension over singleton tuples built from the numbers 1 through 4, and then states an assumption about equality of two identical function applications. The module has no state variables, no transition system, no temporal specification, and no fault model; it is purely a static expression-level test.
