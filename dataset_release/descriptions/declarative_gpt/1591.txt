This module specifies a PlusCal algorithm named EvenOdd that determines whether a natural number N is even or odd by mutual recursion between procedures Even and Odd. The translated TLA+ model represents procedure calls explicitly with a program counter pc, a stack of activation records, procedure-local variables xEven and xOdd, and a boolean result variable, and it allows infinite stuttering after reaching termination to avoid deadlock. The specification defines the initial state, the step relation for each control location, a temporal specification with weak fairness on Next, and an eventual termination property asserting that execution eventually reaches pc = "Done".
