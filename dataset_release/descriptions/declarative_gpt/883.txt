This specification models an inner serial memory/register interface that tracks per-process sequences of issued operations, their responses, and a partial order over operation identifiers. It distinguishes read and write requests, records the source write that supplies a read value, and constrains the evolving order relation so that the completed history is serializable by extension to some total order consistent with program order and read-from constraints. The spec initializes empty operation queues, allows issuing requests, responding to reads and writes, and internal steps that only extend the order relation, and it verifies the system with a temporal specification using weak fairness for response actions and for internal ordering steps that eventually compare distinct operations.
