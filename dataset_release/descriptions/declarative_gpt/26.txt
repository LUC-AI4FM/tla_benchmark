This module specifies the two-phase commit protocol for a set RM of participating resource managers. Each resource manager begins in the "working" state, may move to "prepared", and can then decide either "committed" if all resource managers are prepared or committed, or "aborted" if no resource manager has yet committed. The specification defines the initial state, the next-state relation as a disjunction of per-resource-manager actions, and proves that the protocol preserves type correctness and consistency, meaning no two resource managers reach conflicting commit and abort decisions.
