This module, Pcal, specifies the translation from the abstract syntax tree (AST) of a +CAL algorithm to its TLA+ description. It provides a detailed grammar for the AST of a +CAL algorithm and defines an operator, Translation, that produces a TLA+ specification from a given AST and fairness option. The module includes a complete state machine for checking the well-formedness of the AST, as well as the translation logic for generating TLA+ code, including handling of variables, procedures, processes, and control flow constructs. The specification is executable by TLC and is intended as a partial specification for a +CAL-to-TLA+ translator, with extensive comments on known limitations, error handling, and formatting issues. It does not cover macro expansion, name collision resolution, or output formatting, and assumes all labels and variable names are distinct.
