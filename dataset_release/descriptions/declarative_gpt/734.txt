This specification models Lamport's Bakery algorithm for mutual exclusion among N processes. The algorithm is specified using a PlusCal algorithm block, which is then translated into TLA+ actions and temporal properties. The model includes the lexicographic ordering relation for ticket numbers, and defines the state variables, process actions, and the main temporal specification. The specification verifies mutual exclusion, type correctness, and includes a detailed inductive invariant (Inv) with a full TLAPS proof of mutual exclusion. The model assumes a crash-free, asynchronous system with no faults, and is designed for both model checking and deductive verification.
