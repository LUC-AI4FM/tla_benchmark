This specification models a trivial one-variable system with state variable a. The initial condition sets a to 0, and the only next-state action is stuttering, expressed as UNCHANGED a, so the value of a never changes. It also defines an invariant-like operator Inv that tests ENABLED of an expression using a LET binding to the primed variable a', making the file primarily about syntactic treatment of primed variables, LET/IN, and ENABLED rather than a substantive distributed algorithm or fault model.
