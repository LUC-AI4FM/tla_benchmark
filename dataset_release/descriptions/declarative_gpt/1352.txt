This specification defines a minimal one-variable TLA+ system in which the variable x is initialized to the constant C and then remains unchanged forever. It also defines a top-level operator C2 == x, with a comment noting that because it references the variable x, it is not a constant expression. The file additionally includes an embedded TLC configuration section that overrides the constant C with C2 and sets Init and Next as the initialization and next-state predicates; no temporal theorem or fairness condition is stated.
