This specification models a very small state machine with two state variables, x and y. The initial condition constrains both variables to start at 0, and the temporal behavior is given by a boxed action subscript that permits either the action x' = x + 1 or stuttering with respect to <<x, y>>. The spec is intentionally incomplete in the sense that the temporal action mentions only x' and leaves y unconstrained in the underlying action, relying on the subscripted box form to define behavior over the tuple of variables.
