This specification models a set of processes, each with an integer-valued logical clock and a derived drift value for every ordered pair of processes. It compares two ways of updating these state components when all clocks advance uniformly by a positive natural-number delta: a direct function-construction style and an explicit fold-based iterative style using Apalache's ApaFoldSet. The spec initializes clocks as natural-valued functions over Proc, defines drift from pairwise clock differences, and includes an invariant-style operator asserting that pairwise drift should remain unchanged across a step because all clocks advance by the same amount.
