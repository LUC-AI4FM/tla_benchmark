This module is a regression-style test specification for handling expressions that contain primed variables in actions. It models a tiny two-variable state machine with variables x and y, initializes both to 1, and then defines an action TNext that sets x' and checks many different syntactic contexts where x' appears, including quantifiers, CHOOSE, set expressions, function definitions, EXCEPT updates, function-set constructors, implication, CASE, DOMAIN, and operator application. The specification uses TLC operators such as Print and Assert to validate that primed expressions are interpreted correctly, and Next allows either TNext or stuttering via UNCHANGED <<x, y>>; it does not include temporal correctness properties beyond these action definitions.
