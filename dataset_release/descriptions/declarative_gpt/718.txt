This module is a test specification for a graph utility library. It consists entirely of ASSUME statements that check expected behavior of imported graph operators such as SimplePath, AreConnectedIn, GraphUnion, IsBipartiteWithPartitions, IsDag, Successors, Predecessors, Ancestors, Descendants, Roots, and Leaves on a variety of small graphs. The file has no state variables, no actions, and no temporal behavior; instead it serves as a collection of static assertions over graph values and boolean results, with one INSTANCE of TLC used inside a LET expression to print a test banner.
