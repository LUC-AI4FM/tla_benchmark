This specification is a minimal test module intended to check parsing and typing behavior for UNCHANGED expressions over tuple syntax. It models a system with two integer-annotated variables, x and y, initialized to 1 and 2, and a Next action that leaves state unchanged through UNCHANGED applied both to <<x>> and <<x, y>>. The file does not model faults, fairness, liveness, or refinement; its notable design purpose is to ensure that <<x, ..., z>> inside UNCHANGED is treated as a tuple.
