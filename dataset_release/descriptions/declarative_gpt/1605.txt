This module specifies a small PlusCal algorithm with a single variable x initialized nondeterministically from the range 1..4 and a control-state variable pc introduced by the PlusCal translation. The algorithm contains a nested labeled if statement: from label a it branches on whether x < 3, then further branches on whether x equals 1 or 3, leading to labels b, c, d, or e where assertions check that the chosen branch matches the value of x. After any successful assertion, control moves to f, prints a message, and then terminates in a Done state; the temporal specification uses standard stuttering steps after termination and a weak fairness condition WF_vars(Next), and it also defines a liveness property asserting eventual termination.
