This module is a test specification for bag and extended bag operators, especially the BagsExt module and its Java overrides as used by TLC. It checks algebraic behavior of operations such as BagAdd, BagRemove, BagRemoveAll, FoldBag, MapThenFoldBag, SumBag, and ProductBag on concrete example bags, including bags represented with multiplicities and bags whose elements are sets or strings. It also includes error-behavior tests via AssertError and defines a TLA+ version of FoldBag, TLAFoldBag, to compare the built-in or overridden FoldBag implementation against a specification-level formulation; there are no temporal properties beyond the config header naming Init and Next, and no fault model is involved.
