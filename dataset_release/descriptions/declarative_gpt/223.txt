This specification defines a very small TLA+ module that introduces a higher-order operator L, which applies an operator argument F to an input n. The system behavior itself is trivial: both Init and Next are defined as TRUE, so the state space is unconstrained and no meaningful transition structure or fault model is modeled. The main property expressed in the file is Inv, which checks that applying L to the identity lambda and the value 3 yields 3, demonstrating use of a LAMBDA expression and operator application.
