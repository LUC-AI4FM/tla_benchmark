This specification models a very small transition system over a single variable x, designed to exercise TLC's handling of Next-state generation and duplicate successor states. The comments explain how different syntactic arrangements of disjuncts and assignments in action formulas affect whether TLC generates duplicate next states, including cases where a branch is obviously true, obviously false, or wrapped in double negation to change evaluation behavior. The spec defines an initial state x = 42, several candidate next-state actions assigning specific values to x, an invariant restricting reachable values, a predicate identifying the state x = 5, a predicate for leaving the initial state, and a TLC-introspection operator that checks the reported number of possible states for selected predicates.
