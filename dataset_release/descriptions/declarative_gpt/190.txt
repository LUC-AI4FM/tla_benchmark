This module defines a small TLA+ specification for constructing and combining integer-valued functions using Apalache. It defines a singleton function constructor MkFun, an infix operator (+) on functions that unions their domains and sums values with default 0 outside each domain, and a BigPlus operator that folds this addition over a set of functions. TestBigPlus checks that folding over two singleton functions yields the expected function on {1,2}. Init and Next are both TRUE, and Inv is defined as TestBigPlus.
