This specification models a simple transformation of a finite input set into a sequence by repeatedly choosing an element from the remaining set and appending it to an output sequence. The state consists of `Left`, the set of elements not yet emitted, and `OutSeq`, the sequence built so far; initialization sets `Left` to `InSet` and `OutSeq` to the empty sequence. The spec includes a constant initialization constraint fixing `InSet` to `1..4`, a next-state action that either stutters when no elements remain or nondeterministically removes one remaining element and appends it to the sequence, and an invariant asserting that the original input set is exactly the union of the remaining elements and the elements already present in the output sequence.
