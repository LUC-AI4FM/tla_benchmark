This module models a small TLC-driven benchmarking harness that runs a fixed collection of TLA+ specifications sequentially with different worker counts and classifies the outcome of each run by the external process exit code. The state records the selected run number, worker count, benchmark spec name, and an IO process record, and the main action either launches TLC through an IOUtils environment-execution primitive or observes one of several terminal outcome classes: done, safety violation, liveness violation, or other violation. The file is not a protocol or fault-tolerant algorithm specification itself; instead it is an orchestration specification for executing model-checking jobs, using TLC and IO utilities, with deadlock checking disabled in the embedded TLC config block.
