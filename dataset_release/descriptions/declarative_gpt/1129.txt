This specification models the Two-Phase Commit protocol, where a transaction manager (TM) coordinates a set of resource managers (RMs) to implement atomic transaction commit. The protocol is simplified: RMs spontaneously issue 'Prepared' messages, and 'Prepare' messages from the TM to RMs are ignored. Additionally, 'Abort' messages from RMs to the TM are omitted; instead, the TM may spontaneously decide to abort. The model focuses exclusively on safety properties, specifying what is allowed to happen, and omits liveness properties. Communication is modeled by a set of sent messages, with no message loss or removal, and the protocol's type correctness and implementation of a higher-level transaction commit specification are verified.
