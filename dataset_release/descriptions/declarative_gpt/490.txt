This specification models a simple system with two variables, a and b, both initialized to 0. The Next action describes possible transitions: either both variables swap their values, or b' is set to 2, with the additional constraint that a' is always set to 1. The IsTwo operator is a helper predicate to check if a value is 2. The temporal property Spec asserts that all behaviors start from the initial state and every step is either a Next step or a stuttering step. There are no fairness constraints or liveness properties, and the model is purely safety-oriented.
