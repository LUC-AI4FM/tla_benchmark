This module defines a grammar for TLA+ configuration files using operators from the BNFGrammars module. It characterizes lexical classes such as letters, digits, identifiers, keywords, strings, and numbers, and then builds a grammar for configuration statements like SPECIFICATION, INIT, NEXT, VIEW, SYMMETRY, constraints, properties, constant replacements, and constant assignments. The specification is purely structural and declarative: it introduces no state variables, no transition actions, and no temporal correctness properties, but instead defines the accepted syntax of config files via grammar combinators and a LET-local grammar parameterized operator.
