This specification models a very small state machine over a single integer variable n. It defines a helper operator Foo using a non-nullary LET-bound local operator r(x), where r always returns TRUE and Foo evaluates it at 1. The system initializes with n = 0 and has a single next-state action that requires Foo and updates n to 1; there are no temporal properties, fairness conditions, fault assumptions, or proofs in the file.
