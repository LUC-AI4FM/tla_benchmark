This specification models a single-variable counter system where the state variable x starts at 0 and is incremented modulo 5 on each step. It also uses TLC-specific stateful operators TLCSet and TLCGet to maintain an auxiliary tool-level counter under key 42, incrementing that value on every Next step and checking it in postconditions. The temporal specification requires Init, repeated Next steps with stuttering allowed, and weak fairness of Next; it defines a liveness property requiring that x equals 1 infinitely often, along with two state-level postcondition predicates about the TLC-managed value.
