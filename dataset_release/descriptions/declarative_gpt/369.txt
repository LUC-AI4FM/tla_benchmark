This module is a parser and notation test for instantiated operators imported from module test204 via an INSTANCE binding named F. It checks that a wide variety of infix and prefix operator symbols, including ASCII and LaTeX-style forms, can be referenced as instantiated operators using the F!Op(...) notation and that synonymous spellings are parsed equivalently. The file contains no state variables, no actions, no temporal specification, and no proofs; it consists entirely of one instance declaration and many ASSUME clauses asserting equalities between instantiated operator applications and tuple values.
