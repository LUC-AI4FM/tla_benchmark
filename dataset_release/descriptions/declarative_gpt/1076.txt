This module contains TLAPS proofs for the EWD998PCal specification, which is a PlusCal translation of Dijkstra's EWD998 token ring algorithm. In this version, the per-node 'pending' counter and the global 'token' are replaced by a single 'network' variable holding a per-node bag of messages (either payload 'pl' messages or the unique 'tok' message). The refinement mapping recovers the original EWD998 variables from 'network'. The module proves the safety part of the refinement, specifically that the PCal spec refines the original EWD998 spec (Spec => EWD998Spec), focusing on type correctness and the preservation of the unique token property. The proofs include inductive invariants, bag-level reasoning, and per-disjunct case analysis for each possible node action, but the full step-refinement theorem is left as a stub (OMITTED) due to the complexity of the required bag-level lemmas.
