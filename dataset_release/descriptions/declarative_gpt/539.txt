This module is a model-checking companion module for a specification imported from Session6func. It defines several state predicates and invariants about a simple computation that fills an array or function x with squares of indices from 0 through n, with control state pc ranging over "a", "b", and "Done". The file asserts a postcondition for correctness when pc = "Done", a typing invariant for n, x, i, and pc, and a stronger reachable-state invariant that characterizes what must hold in each control location.
