This module specifies Safra's distributed termination detection algorithm on a ring of N nodes, based on EWD 998. The PlusCal algorithm models a bag-based message network carrying payload messages and a circulating token with fields q and color; nodes can send payloads, receive payloads, become inactive, pass the token, and the initiator can restart the token circulation depending on token state and local state. The translated TLA+ specification defines the global transition relation, a weak fairness condition for every process action, an instance-based refinement-style comparison to another module EWD998, and a state constraint bounding counters for model checking.
