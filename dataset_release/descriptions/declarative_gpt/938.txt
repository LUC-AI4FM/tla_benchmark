This module augments the InternalMemory specification with liveness requirements for the internal memory system. It defines the tuple of variables used for temporal subscripting, introduces two alternative liveness formulas based on weak fairness of processor actions, and then defines LISpec as the original safety specification ISpec conjoined with one of those liveness conditions. The module also states a liveness property saying that whenever a processor's control state is busy, it eventually reaches the ready state, and includes a theorem asserting that LISpec implies this leads-to property.
