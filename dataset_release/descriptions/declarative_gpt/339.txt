This module is a small test specification intended to exercise TLC's error reporting behavior when computing the Cardinality of a very large set. It compares the cardinalities of two function-set expressions, [0..2 -> 1..2000] and [2..4 -> 1..2000], which should have equal size because both domains have three elements and the codomain is the same. The only top-level assertion is an ASSUME block using an IF expression that prints a success message if the cardinalities match and otherwise calls Assert with a failure message; there are no state variables, actions, temporal behaviors, or fault model.
