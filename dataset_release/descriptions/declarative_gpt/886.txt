This module defines the interface-level data types and type invariant for a register file. It models read requests, write requests, and free register values as record-shaped values over the constant sets Adr, Val, Proc, and Reg, and then combines them into larger sets used to constrain the state variable regFile. The specification does not define an initial condition, transition relation, or temporal behavior; instead, it provides structural type definitions and a state invariant asserting that regFile maps each process to a mapping from registers to register-interface values.
