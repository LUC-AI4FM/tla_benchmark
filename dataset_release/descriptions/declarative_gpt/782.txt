This module is a model-checking wrapper around a replicated log specification imported from another module. It adds a state constraint that bounds the log length and the distance between the log length and each node's executed index, and it defines reduction steps that compact the log by shifting executed counters and taking a suffix of the log. The module also defines composed actions that perform either a write or execute step followed by reduction, and a combined next-step relation that allows ordinary or reduced versions of those actions. The file includes an assumption requiring TLC support for the experimental action composition operator.
