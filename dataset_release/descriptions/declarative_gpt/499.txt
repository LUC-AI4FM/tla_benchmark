This module is a model-checking companion to a MultiPaxos specification and adds TLC-oriented helper definitions plus two top-level correctness theorems. It defines symmetry-related permutation helpers and a constant ballot bound, then states a type-correctness invariant over messages, replica node states, pending and observed sequences, and request/acknowledgment cardinalities. It also defines a linearizability condition over observed client events by extracting request and acknowledgment positions, computing results and write order constraints, and asserting that once the system has terminated there exists a command order consistent with both sequential semantics and real-time ordering.
