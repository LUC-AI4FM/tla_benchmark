This module specifies a state-machine model of a light client that verifies blockchain light blocks between a socially trusted height and a target height, while interacting with an instantiated blockchain environment. The model tracks fetched light blocks, their verification status, the latest verified block, the next height to probe, and a probe counter used for complexity reasoning; it also distinguishes the cases where the primary node is correct versus faulty. The specification defines initialization, a main verification loop, store-update helpers, validity and trust predicates, and a collection of safety-style invariants and implication properties about correctness, trust chains, failure conditions, and worst-case complexity.
