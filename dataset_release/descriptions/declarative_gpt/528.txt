This specification models a very small PlusCal algorithm translated into TLA+. The algorithm initializes a set variable x to {"a", "b"}, a sequence-like tuple variable y to <<1, 2, 3>>, then performs one step that adds "c" to x, updates the second element of y to 4, prints both values using PrintT, and moves the control variable pc to "Done". The temporal behavior is given by Spec == Init /\ [][Next]_vars, and the spec also defines a termination property asserting that eventually pc reaches "Done"; termination is modeled with an explicit Terminating stuttering action to avoid deadlock after completion.
