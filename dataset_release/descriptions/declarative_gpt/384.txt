This module is a negative test specification that checks syntactic and level constraints on temporal operators in TLA+, rather than modeling a concrete distributed algorithm or transition system. It declares a single variable x and defines a collection of formulas using leads-to, guarantees, always, eventually, temporal action subscript syntax, and quantified temporal expressions, with comments marking several intentionally illegal uses involving primed variables in state or temporal contexts. The file is designed to exercise parser or semantic checks for raw TLA restrictions, especially the prohibition of certain combinations such as primed expressions under temporal operators or inside quantifier bounds.
