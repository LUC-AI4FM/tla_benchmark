This module contains a PlusCal algorithm named BatchInstall that models batched installation synchronization across a set of devices. Each device has an application scope value and an installation flag; devices that need syncing add themselves to a shared batch pool, and a procedure ChangeAppScope acquires a lock, filters the pool to devices whose scope is 0, increments their scope, removes them from the pool, and releases the lock. The algorithm uses fair processes for per-device synchronization and a fair TimeLoop process that repeatedly waits for a nonempty pool and invokes the same batch-processing procedure; the file does not contain explicit TLA+ temporal theorems, but the fairness annotations are part of the PlusCal model.
