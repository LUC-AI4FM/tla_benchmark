This module specifies an eventually perfect failure detector in a partially synchronous distributed system. Each process maintains a local clock, a suspicion set, timeout values for other processes, and counters for how long it has been since it last heard from them; processes periodically send "alive" messages, receive incoming messages supplied by the environment, and periodically predict failures based on timeout expiration. The specification models adaptive timeouts by increasing a timeout when a previously suspected process is heard from again, and it includes a type invariant but no full temporal specification such as Spec, fairness, or liveness properties.
