This module is a small test specification focused on the semantics of priming in TLA+ expressions and on avoiding confusion between variables, operator applications, and LET-bound names. It defines simple helper operators and a Next action that exercises priming on direct variable references, operator calls, LET expressions, and conditional branches, using TLC's Print and Assert to check expected behavior. The specification does not model faults or a distributed algorithm; instead, it serves as a semantic regression-style test over state transitions with a trivial invariant Inv == TRUE.
