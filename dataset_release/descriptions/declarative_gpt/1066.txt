This module contains TLAPS proofs for the synchronous termination detection specification defined in the imported module SyncTerminationDetection. It proves safety properties such as type correctness, correctness of termination detection, and quiescence, and also proves a liveness property showing that once the system is terminated and detection has not yet occurred, the DetectTermination action can lead to terminationDetected becoming true. The file is proof-oriented rather than algorithm-defining: it extends the base specification and TLAPS, uses invariance and temporal proof rules, and introduces one lemma characterizing the enabledness of the DetectTermination action.
