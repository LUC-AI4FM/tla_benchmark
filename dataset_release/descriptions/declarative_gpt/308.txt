This module specifies a tutorial version of binary search over an input sequence, with bounded-width integer arithmetic modeled explicitly via helper operators for machine-style addition and wrapping. The state tracks the current search interval, termination flag, return value, and step count, and the main action models one computation step of the search including the terminal case when the interval becomes empty. The specification also defines assumptions about sorted input, a correctness condition for the return value, a postcondition that is weakened when the input is not sorted, a termination bound based on integer width, a progress property about interval contraction, and an in-bounds safety property ensuring sequence accesses stay within DOMAIN INPUT_SEQ.
