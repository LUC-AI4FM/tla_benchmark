This module collects several intentionally inefficient specification patterns, described as antipatterns for Apalache model checking, in order to measure their performance impact. It defines trivial behavior with Init and Next both equal to TRUE, and focuses instead on helper operators that rebuild sets, incrementally modify functions, incrementally build functions, and construct sequences from functions using Apalache folding operators. The main property checked is an invariant asserting that these incremental constructions are extensionally equivalent to their more direct TLA+ formulations over the range 1..N, where N is an integer constant and several constant initializers constrain N to specific sizes.
