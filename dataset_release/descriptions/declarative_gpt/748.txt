This module is a model-checking wrapper around a checkpoint coordination specification. It constrains the explored state space with bounded natural-number and log-index ranges, adds a state constraint requiring there to be at least one open index, and defines a node symmetry set using permutations of Node. It also defines an intentionally incorrect optimization predicate for lease replacement that either delegates to the instantiated CheckpointCoordination module's predicate or allows replacement whenever the lease is held by the current leader, as indicated by the comment describing it as a bad optimization.
