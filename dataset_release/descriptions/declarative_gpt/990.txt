This module specifies a non-blocking atomic commitment protocol variant in which reliable broadcast is used to obtain the non-blocking property. It extends a base module for atomic commitment and adds participant forwarding state so that when a participant receives a decision, it forwards that decision to all other participants before locally delivering it. The specification defines participant-side actions for forwarding, pre-deciding from forwarded or coordinator messages, deciding after forwarding is complete, and aborting on simulated timeout conditions, then combines them into a temporal specification with weak fairness assumptions and includes some invalid liveness-style properties such as all-commit, all-abort, and a yes-votes leads-to commit condition.
