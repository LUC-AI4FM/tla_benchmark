This specification models a very small state machine with a single variable x. The initial condition allows x to be any integer in the range 1..10, and the only next-state action sets x' to 0. The temporal specification requires Init to hold initially and then constrains behavior with [][Next]_vars. It also defines a state predicate NotNine asserting that x is not equal to 9, with a comment noting that this property is violated by one of the initial states.
