This specification extends an existing SingleNode specification to model read-only transactions on a single-node system. It adds one action for submitting a read-only transaction request and another action for producing a response that observes the contents of some ledger branch, assuming read-only transactions are always forwarded and that the read and response occur in one atomic step. The temporal property defines the system behavior as starting from Init and then repeatedly taking NextSingleNodeReadsAction steps with stuttering allowed over vars.
