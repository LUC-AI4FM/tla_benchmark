This module specifies Dijkstra's EWD 840 distributed termination detection algorithm on a ring of N nodes. The system state tracks whether each node is active, each node's color, the token position, and the token color; the termination detector controls token-passing actions while the environment models application-level message sending and deactivation. The specification checks safety and liveness properties of termination detection, includes Dijkstra's inductive invariant, and also contains auxiliary non-properties and a stronger-fairness variant used for validation and experimentation with TLC.
