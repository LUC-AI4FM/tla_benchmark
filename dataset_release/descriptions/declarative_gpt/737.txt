This module is a small wrapper around an underlying Boulanger specification. It introduces a constant bound MaxNat, assumes that MaxNat is a natural number, defines a bounded natural range NatOverride as 0 .. MaxNat, and adds a state constraint requiring each process in Procs to have num[process] < MaxNat. The file itself does not define the underlying algorithm, actions, or temporal properties; it only contributes a bounding assumption and constraint on top of the imported module.
