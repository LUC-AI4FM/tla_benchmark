This module gives a high-level TLA+ model of a Tendermint-style blockchain intended specifically for reasoning about a light client. It models a bounded blockchain up to an ultimate height, block headers with timestamps, validator sets, next validator sets, and commit sets, together with a global time and a set of faulty validators. The fault model assumes a non-decreasing set of faulty nodes and encodes the Tendermint-style assumption that for blocks still within the trusting period, the correct validators have more than two-thirds of the voting power; it also defines when the system is in a faulty zone where that assumption no longer holds. The specification includes initialization of a complete blockchain structure, a time-advancement action, and an action where one more node becomes faulty, but it does not define a full temporal Spec operator in this file.
