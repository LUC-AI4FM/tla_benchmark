This module specifies a very small temporal system over a single variable s. The predicate F(var) holds when its argument is an integer in the range 0..9 and is even, and the specification requires that initially s = 0 and that every step satisfies the boxed subscript formula [][F(s')]_s. There is no explicit next-state action definition beyond the use of F applied to the primed state value, no fault model, and no proofs; the file mainly illustrates a temporal specification using a state predicate over a primed argument inside a stuttering-step box.
