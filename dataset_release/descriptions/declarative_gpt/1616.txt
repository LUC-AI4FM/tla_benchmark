This specification models a small PlusCal algorithm named NoLoop2 that executes a fixed sequence of labeled steps without looping. It initializes variables x and y, assigns x through a local WITH-bound value, nondeterministically chooses y from the set {1, 2}, then conditionally updates x based on whether y = 1, and finally prints x before terminating. The translated TLA+ spec checks the temporal behavior of this simple terminating control-flow graph, includes stuttering after termination to avoid deadlock, and asserts both a standard safety-style behavior through Spec and a liveness property Termination stating that the control location eventually reaches "Done".
