This module defines utility operators for input/output, serialization, environment access, external process execution, and a helper for zero-padding numbers. Most operators are abstract TLA+ stubs intended to be overridden by Java implementations during TLC execution, so they typically return TRUE or a value selected with CHOOSE while comments explain the intended side effects. The module also includes pure helper operators such as atoi, which chooses an integer whose string form matches the input, and zeroPadN, which pads the string form of a natural number with leading zeros using a sequence fold.
