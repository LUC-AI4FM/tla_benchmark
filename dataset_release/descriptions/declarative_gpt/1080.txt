This module defines an options and measurement wrapper around the underlying EWD998 termination-detection specification. It introduces feature flags for several algorithm variants, constrains the randomized initial states and environment behavior for TLC generation mode, and defines an alternative system/environment composition used for simulation and data collection. It also records statistics at termination and when termination is detected, using TLC, CSV, and IO utilities, while assuming probabilistic generation mode and disabling deadlock checking because the modeled algorithm is assumed to terminate.
