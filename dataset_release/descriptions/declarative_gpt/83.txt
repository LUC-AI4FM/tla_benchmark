This module specifies a typed version of the Car Talk balance-scale puzzle: how to break an N-pound stone into P integer-weight pieces so that any integer weight from 1 through N can be balanced on a scale using the pieces on either side. It defines the set of all admissible breaks, a representation relation for balancing a target weight, the predicate characterizing when a break is a solution, the set of all such solutions, and an operator that expands each solution into explicit weighing instructions. The specification is purely declarative and intended for evaluating constant expressions rather than describing a transition system.
