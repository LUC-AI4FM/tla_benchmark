This module is a small test specification for the TLA+ ENABLED operator. It defines two variables x and y, a simple initialization, a parameterized action Step, and a helper operator Foo that applies ENABLED to a formula containing primed variables. The main purpose of the spec is to exercise different syntactic uses of ENABLED, including on actions, state predicates, quantified formulas, subscripted actions, conjunctions with Next, and calls through operator parameters and LET-bound names; it also uses TLC's Print and Assert operators to encode expected pass/fail outcomes.
