This specification models a very small counter system with a single variable x ranging over natural-number values and initialized to 0. The only state-transition action increments x by 1 while x < 2, so execution can move from 0 to 1 to 2 and then stop stuttering. The file defines both an ordinary safety-style specification with a next-state relation and a fairness-strengthened specification using WF_x(Next), and it also states several temporal properties about eventually reaching values and a leads-to tautology.
