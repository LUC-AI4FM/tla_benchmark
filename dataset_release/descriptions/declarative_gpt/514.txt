This module specifies an abstract behavioral version of the Alternating Bit protocol, describing what the protocol is intended to accomplish rather than modeling message transmission details. It uses a constant set Data of payload values and represents messages as records with fields data and bit, where the bit alternates between 0 and 1. The specification defines initialization, two process actions A and B, a next-state relation, and a temporal specification asserting that all behaviors start in Init and thereafter evolve by repeated Next steps with stuttering allowed.
