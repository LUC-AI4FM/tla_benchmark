This specification is a small test module intended to check TLC's handling of replacing a constant with a nonconstant operator. It defines a single state variable x, a helper operator Foo that returns the current state's x value, an initial predicate that prints diagnostic messages and initializes x to 2, and a next-state action that assigns x' to the constant C. It also defines a simple invariant Inv asserting that x = 2. The module does not include a temporal Spec operator, fairness, proofs, or PlusCal; it is primarily a minimal regression-style test around constant replacement behavior.
