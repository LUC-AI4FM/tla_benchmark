This module defines a small higher-order TLA+ specification over a single variable x. It introduces a helper operator Foo that checks whether an operator argument holds for every element of a set, and Bar instantiates Foo with a lambda that tests membership in Nat. The specification states that x initially equals the result of applying Bar to the set {1,2,3}, and that thereafter x never changes, expressed as a temporal box formula over UNCHANGED x. There is no fault model, no refinement structure, and no proof content.
