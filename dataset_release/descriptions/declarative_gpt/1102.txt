This module defines reusable TLA+ operators for adding an auxiliary stuttering variable `s` to an existing specification, as described in the paper "Auxiliary Variables in TLA+". It provides action transformers that wrap an existing subaction `A` with optional pre-stuttering or post-stuttering behavior, using a record-valued control variable `s` whose fields identify the action, its execution context, and a countdown value. The module also defines conditions ensuring that the decrement function driving stuttering eventually reaches a bottom element, including an alternative version intended to be easier for TLC to evaluate on finite models. The file contains no complete system spec of its own; rather, it is a library module meant to be instantiated by another specification, and it includes comments describing a modification that strengthens context checking during stuttering steps.
