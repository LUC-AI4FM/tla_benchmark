This module specifies a tutorial version of binary search over an input sequence, using bounded-width machine-integer arithmetic modeled explicitly with a wrapped addition operator. The state tracks the search interval, termination flag, returned value, and a step counter, and the Next action models the algorithm's branching behavior for shrinking the interval or returning a found or insertion-point result. The specification also defines sortedness of the input, correctness of the return value, a postcondition that depends on sortedness, a termination bound based on integer width, a progress property about interval contraction, and an in-bounds safety condition for sequence access.
