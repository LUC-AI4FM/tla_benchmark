This module is a small test specification for the folding utilities provided by the extended Folds module. It defines a concrete sequence `<< 1,2,3,4 >>` and uses a series of ASSUME statements to check that `MapThenFoldSet` produces expected results for addition, multiplication, and subtraction when combined with different set-selection operators such as `Max` and `Min` over `DOMAIN seq`. It also includes a negative test using `AssertError` to confirm that calling `MapThenFoldSet` with a non-enumerable domain value `42` produces the expected error; there are no state variables, actions, temporal properties, or fairness conditions in this file.
