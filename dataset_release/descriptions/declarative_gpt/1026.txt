This module specifies a one-step Byzantine consensus protocol, modeling only the core one-communication-step algorithm rather than the full underlying consensus procedure. It tracks how correct and faulty processes propose values, how messages are received, how processes decide or remain undecided, and how Byzantine faults can corrupt participating processes up to a bound F under the assumption N > 3 * T and T >= F >= 0. The specification defines both safety-style properties about decisions when all processes initially propose the same value and a liveness-oriented specification with weak fairness for non-faulty operational steps.
