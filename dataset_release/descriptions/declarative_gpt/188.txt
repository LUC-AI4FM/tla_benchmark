This module defines a small helper operator over sets, using a fold to build a function from elements to integers. The main operator PolyOper takes a set S and folds a locally defined Add operator over it, starting from the empty-domain function [x \in {} |-> 0]. The specification itself is trivial, with Init and Next both equal to TRUE, and it states an invariant Inv asserting that applying PolyOper to {1} yields the function [x \in {1} |-> 0].
