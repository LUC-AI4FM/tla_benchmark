This module provides Apalache type annotations and concrete constant values for a parallel reachability specification by instantiating the separate module ParReach. It declares the constants and variables expected by that underlying specification, and supplies an INSTANCE of ParReach with direct substitutions from the annotated names in this module. The file itself does not define the transition system, actions, or temporal properties of the algorithm; instead, it serves as a typed wrapper plus a few concrete value definitions for nodes, successors, root, and processes.
