This module defines a simulation-oriented wrapper around an existing ccfraft specification, adding randomized guards to selected actions, custom initialization choices, a redefined fairness condition, periodic TLC statistics serialization, and a postcondition module for counterexample shortening. The fault model is not introduced independently here; instead, the module reuses the underlying ccfraft behavior and constrains simulation scheduling through RandomElement-based throttling and IO-environment parameters. The specification also includes utilities for stopping TLC after a time budget, serializing runtime data, and a postcondition that records the depth of a discovered counterexample so TLC can be rerun in simulation mode with progressively smaller bounds.
