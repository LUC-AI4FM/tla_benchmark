This module is a model-checking wrapper around an existing specification, refining implementation-level variables into the abstract variables expected by another module instance. It constrains the communication channels AtoB and BtoA to bounded sequence lengths, defines a type-correctness predicate for the refined implementation state, and maps tuple-based variables AVar2 and BVar2 into record-shaped abstract variables using data and bit fields. The module then instantiates Session11a with these substitutions and exposes the instantiated abstract specification property ABSpec!Spec for checking; no local temporal behavior, fairness, or proofs are defined directly in this file.
