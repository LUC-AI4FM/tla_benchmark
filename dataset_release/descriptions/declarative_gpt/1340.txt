This specification models a trivial one-variable system with a single boolean state variable b. The initial condition requires b = TRUE, and the next-state action assigns b' to the truth value of the set-theoretic statement (SUBSET (1..3)) \subseteq (1..4). The spec defines the standard temporal behavior Spec == Init /\ [][Next]_<<b>> and includes a simple invariant Inv asserting that b remains TRUE.
