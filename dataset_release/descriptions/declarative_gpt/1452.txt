This module defines a small collection of set- and function-valued operators over finite sets and integers. It defines the range of a function, a minimum operator on integers, and an operator LP that constructs a set of functions from T into the p-element subsets of S subject to a maximal-distinct-range cardinality condition. The module contains a single unnamed ASSUME that calls TLC's PrintT on an instance of LP, so it is oriented toward evaluating and inspecting the constructed value rather than stating a temporal system specification or verifying safety/liveness properties.
