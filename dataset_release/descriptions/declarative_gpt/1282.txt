This module models token-finding logic for a TLA+ editor feature that identifies an operator or identifier near the cursor in a line of module text. It defines helper operators for treating TLA+ sequences as Java-style zero-based arrays, and includes a PlusCal algorithm translated to TLA+ that scans left and right, recognizes operators, identifiers, TeX symbols, step names like <n>m, and selector chains involving ! and parenthesized expressions. The translated spec contains an initial predicate, a next-state relation, and a liveness property asserting termination at pc = "Done".
