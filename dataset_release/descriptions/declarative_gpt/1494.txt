This specification models a tiny action system over two state variables, x and S. The initial state sets x to 0 and S to the set {1,2}, and the main action Next constrains execution to states with x = 0, leaves S unchanged at first, and existentially chooses an n from S while using action definitions A and B together with the action-composition operator \cdot. The temporal specification Spec asserts Init /\ [][Next]_<<S,x>>, Prop repeats the same box-subscript formula, and Prop2 states the negation of ENABLED Next.
