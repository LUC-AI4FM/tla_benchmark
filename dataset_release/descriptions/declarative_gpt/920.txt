This module specifies a simple one-place handshake channel with a data field and two control bits, rdy and ack. The sender may send a value d only when chan.rdy = chan.ack, and doing so stores d in chan.val and flips the ready bit; the receiver may receive only when chan.rdy # chan.ack, and doing so flips the acknowledge bit. The specification defines initialization, the next-state relation, and a temporal behavior Spec asserting Init and always Next over chan, and it proves that the type invariant is always maintained.
