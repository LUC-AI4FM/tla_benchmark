This module is a small test specification for the standard FiniteSets module. It declares a single variable x, initializes it to 0, and defines a stuttering Next action that keeps x unchanged. The main operator Inv is a state-level conjunction of four IF-THEN-ELSE checks that test IsFiniteSet and Cardinality on the empty set and on the finite set {"a", "b"}, using TLC's Print and Assert operators to report success or failure.
