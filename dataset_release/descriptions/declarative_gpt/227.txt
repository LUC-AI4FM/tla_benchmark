This specification models a tiny symbolic transition system used for testing slicing of symbolic transitions. It has a single state variable, initialized to the string "Init", and two possible next-state actions: one that sets the state to "A" and another that existentially quantifies over finite sets and sets the state to "B". The file also defines a simple invariant asserting that the state is not equal to "B", but it does not include a temporal specification such as Spec, fairness conditions, or proofs.
