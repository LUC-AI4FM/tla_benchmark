This module defines helper operators for deriving ShiViz-compatible metadata from a TLC execution trace, specifically identifying which process changed program counter values between consecutive states and computing a vector clock over the trace. It uses the special Toolbox trace variables `_TETrace` and `_TEPosition`, together with JSON conversion utilities, to expose a current host and clock value for visualization. The module is not a transition-system specification with variables, actions, or temporal properties; instead, it is a trace-analysis utility module built from operator definitions and comments about Toolbox override behavior.
