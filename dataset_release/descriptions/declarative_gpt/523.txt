This model-checking module augments an underlying alternating-bit style session specification by extending the module Session11projimpl and adding concrete constants, a state constraint, and auxiliary predicates. It constrains the lengths of the message queues AtoB, BtoA, and NewValQueue, defines a type-correctness predicate for the implementation state, and states an invariant relating A and B when B has an acknowledgment matching AVar.bit. The comments explain that the invariant may fail when the environment proposes values too quickly, and the module also defines a helper predicate TwoValsSeq over sequences plus an instantiated specification property imported from Session11projspec.
