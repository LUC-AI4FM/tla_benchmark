This specification models an outer module that instantiates an inner module with renamed variables. The inner module defines a single action that changes a result variable from 0 to 1 and updates a sequence by filtering out elements equal to the new result value using SelectSeq and a LAMBDA predicate. The outer specification initializes the instantiated variables, allows either the instantiated step or stuttering when that step is disabled, adds weak fairness for the instantiated step, and asserts a temporal liveness property that execution eventually reaches a state after which the instantiated step remains disabled forever.
