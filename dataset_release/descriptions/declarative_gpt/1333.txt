This TLA+ specification models Safra's distributed termination detection algorithm on a ring topology, as described in EWD 998. The system consists of N nodes arranged in a ring, each of which can be active or passive, and a token that circulates to detect global termination. The algorithm tracks the number of messages sent and received, node colors (white/black), and uses a token with position, color, and a counter to aggregate information as it traverses the ring. The specification defines the system's state transitions, including message sending, receiving, token passing, and node deactivation, and verifies both safety (termination detection correctness) and liveness (termination is eventually detected) properties. The model includes state and action constraints to bound the state space for model checking, and an inductive invariant capturing Safra's correctness argument.
