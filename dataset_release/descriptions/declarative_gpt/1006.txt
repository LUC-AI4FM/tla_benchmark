This TLA+ specification models the reliable broadcast algorithm by message diffusion, as described in Chandra and Toueg's 1996 paper on unreliable failure detectors. The model is parameterized by the number of processes (N), a threshold T, and the maximum number of allowed crashes F. It explicitly encodes process states, message sending and receiving, and crashed processes, and models only ECHO messages. The system allows processes to crash up to F times, and includes both the standard and a 'no broadcast' initialization. The specification checks type correctness, safety (unforgeability), and liveness properties, including that if a correct process broadcasts, all correct processes eventually accept, and that messages sent by correct processes are eventually received by all correct processes. Weak fairness is added to ensure liveness, and the model is designed for parameterized verification of fault-tolerant distributed algorithms under crash failures.
