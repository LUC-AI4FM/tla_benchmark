This specification models a distributed breadth-first spanning tree construction over a fixed undirected graph rooted at root. The graph is defined by a constant node set and edge set, with recursive operators for reachability and distance, and then a PlusCal algorithm translated into TLA+ where each node process updates message queues, parent pointers, depths, and acknowledgment state. The temporal specification requires initialization, next-state evolution, and weak fairness for each node process, and it checks type correctness, a conditional correctness property relating computed depths and parents to graph distance from the root, and eventual termination when all message queues are empty.
