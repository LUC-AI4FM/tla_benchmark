This module specifies a small state machine over variables n and f that uses a recursively characterized function Fact to represent factorial values on the finite domain 1..5. Instead of using a RECURSIVE declaration, the specification defines Fact with a CHOOSE over functions from 1..5 to Int, constrained so that values satisfy the factorial recurrence with base case fun[k] = 1 when k <= 1 and recursive case fun[k] = k * fun[k - 1] otherwise. The system initializes n to 0 and f to Fact[n], then advances by incrementing n and updating f to Fact[n'], modeling iteration through factorial values without any explicit temporal property or fairness condition.
