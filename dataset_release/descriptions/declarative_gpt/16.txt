This specification models Safra's distributed termination-detection algorithm on a ring, following EWD 998. Nodes maintain activity status, colors, counters for sent-minus-received messages, pending in-flight messages, and a circulating token carrying position, accumulated quantity, and color; the spec also includes auxiliary loop and formula-tracking variables used to encode and check temporal properties. It verifies a safety-style termination-detection condition, an invariant inspired by Safra's inductive argument, and a liveness-style temporal property that termination is eventually detected under weak fairness of the system token actions, with an explicit state constraint used to bound TLC exploration.
