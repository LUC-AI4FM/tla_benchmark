This specification is a small test module that checks replacement or overriding of operators, including infix operators and overridden standard-looking operators. It uses an initialization predicate that sets x to 1 and then evaluates a sequence of IF-THEN-ELSE tests involving constant operators P, _++_, Plus, and PLen, as well as locally defined operators and names that shadow familiar library names such as Seq and \o. The behavior being verified is essentially that these operator interpretations produce the expected values during initialization, after which the system only stutters with Next == UNCHANGED x and the invariant is simply TRUE.
