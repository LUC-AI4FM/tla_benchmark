This specification models a simple round-robin mutual exclusion style protocol generated from a PlusCal algorithm named Alternate. A single shared variable turn determines which process may leave its waiting location and enter the critical section, and each process cycles through noncritical, enter, critical, and exit control states recorded in pc. The spec assumes a positive number of processes indexed by Procs = 0..(N-1), defines the initial state and next-state relation, and verifies behavior with a basic temporal specification Spec == Init /\ [][Next]_vars without explicit fairness or separate safety/liveness theorems.
