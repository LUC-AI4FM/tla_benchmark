This specification defines a small single-variable TLA+ model over the variable v and a helper expression over subsets of the set {1,2,3,4}. It computes a set-valued operator Max(s) of maximal elements of a set and then defines sillyExpr as the collection of subsets s for which every element either equals Max(s) or has its successor also in s. The behavior initializes v to 0 and has a single next-state action that leaves v unchanged while asserting that PrintT(sillyExpr) = FALSE; there are no temporal correctness properties, fairness conditions, PlusCal processes, or proofs.
