This module defines a real-time wrapper around an existing write-through cache specification. It extends the underlying cache model with an additional variable lastP and a scheduling discipline that uses a computed position order to control which process may take certain expensive actions, specifically read misses and writes, while preserving other cache and memory queue actions. The specification assumes real-time parameters Delta, Epsilon, and Rho are positive reals satisfying a timing bound, and it asserts a real-time temporal specification RTSpec that combines initialization, a next-state relation, bounded-response timing constraints via RTBound, and the RTnow clocking condition; it finally states a theorem that this real-time specification implies the instantiated RTMemory real-time specification.
