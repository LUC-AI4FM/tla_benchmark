This module specifies a simple event-counting component with a single state variable nEvents. It models a counter that starts at zero and may be incremented by the CountEvent action when a finite maximum is being enforced; if maxEvents is -1, the specification treats that as an unlimited mode and leaves the counter unchanged to avoid introducing an infinite-state model. The file defines the initialization predicate and one action, but it does not define a full temporal specification such as Spec, nor does it include fairness conditions, proofs, or PlusCal code.
