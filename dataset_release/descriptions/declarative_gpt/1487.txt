This module defines the built-in TLAPS support module containing backend prover pragmas and a library of theorem statements used in mechanical proofs. It models no concrete algorithm or transition system; instead, it provides boolean operators whose only purpose is to carry prover annotations, together with temporal-logic proof rules such as invariance, simulation, weak fairness, strong fairness, and leads-to rules. The file also includes compatibility aliases for older prover pragmas, a set extensionality theorem, a theorem asserting that no set contains every element, and several temporal proof principles, some with omitted proofs.
