This module is a small test specification for a parser or importer corner case involving LOCAL operator definitions and LET-bound identifiers. It models no distributed algorithm or transition system; instead, it defines simple operators to check that a LOCAL operator with an internal LET binding does not clash with similarly named LET-bound variables at call sites or across multiple instantiations. The file contains no state variables, no actions, and no temporal properties, and its main design point is scope hygiene for names introduced by LET expressions.
