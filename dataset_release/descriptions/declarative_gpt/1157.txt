This specification models a simplified Raft-style consensus protocol for MongoDB, focusing on server roles, term numbers, and replication or rollback of per-server oplogs. The model represents each server's state and log, allows a server to become primary by a quorum-based up-to-date check, allows leaders to append client values, and allows followers to append or roll back log entries to match another server. The specification verifies the system through an initial-state predicate and a temporal next-state specification, and it also defines helper safety predicates about committed entries never being rolled back, though those verification predicates are not included in the top-level temporal specification.
