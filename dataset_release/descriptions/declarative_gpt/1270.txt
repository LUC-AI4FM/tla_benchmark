This module specifies a small state machine that repeatedly chooses elements from the integer range 1..c until all have been chosen, then resets. The constant c is assumed to be a nonzero natural number, and the distinguished value R is defined as -42 to represent the reset value of x when no current choice is active. The variables satisfy a type condition in which x is either one of the numbers 1 through c or the reset marker R, and z is a subset of 1..c tracking which numbers have already been chosen; the temporal specification starts from the reset state and evolves by repeatedly taking ASChoose or ASRest steps.
