This module is an Apalache-oriented wrapper around an existing InnerFIFO specification, applied via INSTANCE so that the original specification remains unchanged by tool-specific annotations. It introduces a concrete finite set of message values and states channel-level type invariants for the input and output channel records, while intentionally avoiding an invariant of the form q \in Seq(Message) because that would denote an unbounded set that Apalache cannot enumerate. The module therefore models a FIFO-related state structure with variables in, out, and q, but in this file itself it only defines typed constants and a helper invariant over instantiated channel invariants rather than the transition system or temporal correctness properties.
