This module defines typed inductive invariants for a two-phase commit specification imported from the extended module `TwoPhaseTyped`. It does not introduce the protocol itself; instead, it states an invariant `IndInv` relating the transaction manager state, the set of prepared resource managers, resource-manager local states, and the presence of commit/abort/prepared messages. The module also defines `InitInv`, asserting that the base typing invariant holds initially together with the inductive invariant, and is intended for invariant reasoning rather than temporal liveness or fairness properties.
