This specification is a small regression test for a desugaring issue involving grouped-variable UNCHANGED expressions. It defines four state variables, groups them into two tuple-valued helper operators, and then nests those helpers inside a larger tuple operator vars. The system has a single initial state assigning concrete values to all variables, and a Next action that leaves the entire grouped state unchanged via UNCHANGED vars. The temporal property Spec asserts Init and then requires that every step satisfy [][Next]_vars, so the behavior is purely stuttering after initialization.
