This specification defines a very small TLA+ model with a single integer variable x and a helper operator A that inserts an element into a set using union with a singleton. The behavior itself is trivial: the initial state sets x to 0 and the next-state relation leaves x unchanged, so all steps are stuttering on x. The interesting property in the file is a state invariant asserting that Apalache's sequence-fold operator ApaFoldSeqLeft, applied to A, the initial set {4,4}, and the sequence <<1,2,3>>, yields the set {1,2,3,4}; there is no fault model, fairness condition, or proof content.
