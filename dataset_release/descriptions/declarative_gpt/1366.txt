This specification defines a very small TLA+ model over a single variable v and a helper set expression over subsets of {1,2,3,4}. It introduces an operator Max(s) that returns the set of maximal elements of a set s, and a derived operator sillyExpr that filters subsets according to a quantified condition involving an IF expression and membership of x+1 in the subset. The temporal behavior is trivial: Init prints sillyExpr and initializes v to 0, while Next is an impossible action because it is conjoined with FALSE, so the system has no enabled state transitions.
