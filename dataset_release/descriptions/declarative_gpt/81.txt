This module is a regression test for an unsound Skolemization bug involving a LET-IN expression. It models a tiny state machine with a set variable S and a Boolean variable tx_fail, where the next-state action computes a local Boolean fail from an existential query over S and assigns it to tx_fail'. The specification is focused on a state invariant stating that tx_fail remains true; the comments explain that this should hold because S is initialized to { 1, 2 } and the existential condition x /= 1 is satisfiable.
