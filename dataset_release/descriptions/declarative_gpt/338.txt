This module is a small test specification for TLC error reporting on large finite-set cardinality computations. It compares the cardinalities of two function sets, [0..2 -> 1..2000] and [2..4 -> 1..2000], which have equal domain sizes and therefore equal numbers of functions. The only property asserted is an ASSUME containing an IF-THEN-ELSE expression that prints a success message when the cardinalities match and otherwise triggers an assertion failure with an error string.
