This specification models a very small state machine over two variables, a and b. The initial state sets both variables to 0. The next-state relation allows either a simultaneous swap-style constraint on the primed values a' and b' or an existential choice of b' from the set { 1, 2 }, while also requiring a' = 1 and universally constraining a' over the singleton set { 1 }. The temporal specification is [][Next]_<< a,b >>.
