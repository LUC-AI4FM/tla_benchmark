This module defines and reasons about color predicates over a finite set of states. A color predicate is represented as a record with a type field indicating either "every" or "some" and a set field containing a subset of State; satisfaction means either all states in a given state set belong to the predicate set or at least one does, depending on the type. The module proves two theorems: one characterizing satisfaction over unions of state sets, and another showing how to compute satisfaction using bit-vector encodings of state sets based on a finite enumeration of State.
