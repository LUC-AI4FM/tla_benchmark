This module is a TLC scripting specification that orchestrates multiple nested TLC runs of another specification, EWD998_opts.tla, in order to collect statistics and write results to a CSV file. It defines a finite set of feature flags and node values, constructs a CSV filename using the current Java time, writes CSV headers, builds a command line for invoking TLC recursively, and then assumes successful execution of nested runs over all subsets of features and all chosen node values. The specification is not modeling the protocol itself directly; instead, it models an experiment driver that uses IO utilities and TLC-side effects to execute simulations and classify outcomes such as assumption, safety, and liveness violations.
