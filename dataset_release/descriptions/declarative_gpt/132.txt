This specification models two function-valued state variables, fun1 and fun2, each mapping nodes to sets of nodes. The initial state assigns every node in Node to the empty set, and the single next-state action updates both functions by adding "3_OF_N" to the set stored at key "2_OF_N". The property Sanity asserts that the values of fun1 and fun2 agree at key "1_OF_N"; the spec contains no temporal specification operator, no fairness conditions, and no fault model.
