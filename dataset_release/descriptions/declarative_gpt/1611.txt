This module specifies and model checks a recursive mergesort algorithm translated from a PlusCal procedure into TLA+. It models sorting arrays of values in 1..N for all lengths up to ArrayLen, using an auxiliary buffer b and an explicit call stack to represent recursive procedure calls. The specification checks termination under weak fairness of Next and asserts a safety property that when the program counter reaches "Done", the array is sorted in nondecreasing order.
