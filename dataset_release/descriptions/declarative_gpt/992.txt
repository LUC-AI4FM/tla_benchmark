This module specifies an atomic commitment protocol with one coordinator and a set of participants, using a simple broadcast mechanism in an asynchronous setting. The comments explain that synchronous communication has been replaced by implicit asynchronous communication and that failures are detected magically rather than via timeouts; because broadcast is modeled as a sequence of individual sends that can be interrupted by failure, the protocol is non-terminating and the usual termination property AC5 does not hold. The specification defines typed initial states, participant and coordinator actions, a next-state relation with weak fairness on non-death progress actions, and then states safety, liveness, stronger auxiliary properties, and explicitly invalid properties for the protocol.
