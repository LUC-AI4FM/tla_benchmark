This specification models a single-variable system over the variable x. The initial state sets x to 0, and the next-state relation is defined by an IF expression whose condition checks whether the singleton set {1} is a member of SUBSET(1..31); if so, the next value of x is assigned SUBSET(SUBSET(1..32)), otherwise x is assigned 2. The temporal specification asserts that the system starts in Init and then always evolves according to Next with stuttering allowed via the standard box-subscript form [][Next]_x. There is no fault model, no fairness condition, and no proof content.
