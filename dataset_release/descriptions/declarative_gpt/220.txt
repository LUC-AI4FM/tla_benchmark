This specification models a simple transition system over three integer-like state variables x, y, and z. The initial state fixes x = 0, y = 1, and z = 2, and the Next action constrains the primed values of the variables using nested conjunctions and disjunctions of membership tests over singleton sets. The module does not include an explicit temporal specification such as Spec, no fairness conditions, no fault model, and no stated safety or liveness theorem; it is essentially a small action-level example illustrating selections among possible next-state assignments.
