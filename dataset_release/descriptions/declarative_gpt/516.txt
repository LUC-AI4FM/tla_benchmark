This module specifies the Alternating Bit protocol at an abstract behavioral level, describing what the protocol is supposed to accomplish rather than the concrete message-passing mechanism. It models two fair processes, A and B, over message records containing a data value from the constant set Data and a bit in {0,1}; process A chooses new data and flips the bit when the bits match, while process B copies A's value when the bits differ. The temporal specification requires initialization, all steps to satisfy the translated Next action up to stuttering, and weak fairness for both A and B so that each enabled process is eventually scheduled.
