This specification models a trivial one-variable state machine with a single variable x. The initial state sets x = 0, and the only next-state action is a stuttering step that leaves x unchanged forever, so the behavior is constant after initialization. The temporal specification is Spec == Init /\ [][Next]_x, and the property Prop asserts a leads-to formula x \notin Nat ~> x = "abc"; the comments note that the consequent of leads-to must be state-level and discuss a related indexing example.
