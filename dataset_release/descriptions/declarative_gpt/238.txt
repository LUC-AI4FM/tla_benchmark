This specification models a small state machine over a fixed set of processes indexed by the integers 1 through 4. The state consists of a function `unchecked` from process identifiers to sets of integers and a function `nxt` from process identifiers to integers; the initial state sets every `unchecked[p]` to the empty set and every `nxt[p]` to 1. The transition relation either chooses a process `self` and a value `i` from `unchecked[self]` to update `nxt[self]`, while leaving `unchecked` unchanged, or performs a stuttering step; no explicit temporal properties, fairness constraints, or fault model are specified.
