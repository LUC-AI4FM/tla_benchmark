This module specifies a high-level voting algorithm that abstracts the core idea of Paxos consensus without modeling explicit message passing. A set of acceptors casts votes for values in numbered ballots, with quorum intersection assumed so that any two quorums share at least one acceptor; this is the key structural assumption used to ensure agreement. The specification defines when a value is chosen, characterizes safety via SafeAt and related predicates, gives actions for raising an acceptor's maximum ballot and for voting, and proves both an inductive invariant and that the algorithm implements an imported Consensus specification.
