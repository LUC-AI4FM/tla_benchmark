This module specifies the Two-Phase Commit (2PC) protocol with a transaction manager and a set of resource managers. The state tracks each resource manager's local state, the transaction manager's state, the set of participants from which the transaction manager has received prepared messages, and the set of messages that have been sent. The specification proves a safety property: committed and aborted resource-manager states never coexist, by defining an inductive invariant and using TLAPS lemmas and a final theorem to derive []Consistency from Spec.
