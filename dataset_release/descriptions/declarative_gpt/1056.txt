This module defines an animation and visualization layer for the EWD687a specification, rendering states of a process network as SVG graphics and exporting frames to files. It models graph layout, node and edge rendering, overlay information such as active and neutral processes, message and acknowledgment counts, and a legend describing the current TLC action and level. It also adds simulation-oriented predicates such as an interesting behavior condition and a constraint disallowing superfluous idle stuttering steps, while relying on the underlying EWD687a module for the actual protocol state and dynamics.
