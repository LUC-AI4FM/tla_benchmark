This module adapts an underlying Nano specification to make it amenable to TLC model checking. It introduces a model-level hash function state and a helper implementation of hash calculation so that hash assignment can be represented with finite state, and it adds a stuttering action to stop progress gracefully once available hashes are exhausted. The specification verifies safety-related properties by asserting that the overall behavior satisfies both a type invariant and the underlying Nano safety invariant, while using a view that ignores hashFunction and lastHash when hashing states for model checking.
