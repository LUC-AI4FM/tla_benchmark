This module defines real-time specification helpers for TLA+ by introducing a real-valued clock variable `now` and two top-level operators, `RTBound` and `RTnow`. `RTBound(A, v, D, E)` expresses that an action `A` over state tuple `v` must occur within a maximum elapsed time `E` and not before a minimum elapsed time `D`, using an existentially quantified timer variable `t` whose evolution is defined by a nested action. `RTnow(v)` constrains `now` to increase over the reals with weak fairness, providing the real-time clock assumptions needed by bounded-time specifications; the module comments explicitly note that this style of specification cannot be handled by TLC.
