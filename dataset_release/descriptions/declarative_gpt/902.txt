This specification models a write-through cache layered over an internal memory interface. It describes per-processor cache behavior, request and response handling, read misses, writes that update both cache state and a memory queue, queued memory processing, and eviction. The spec verifies a type invariant and a cache coherence property stating that if two cached values for the same address are both valid, then they are equal; it also proves refinement or conformance to an instantiated Memory specification.
