This module specifies reachability in a directed graph represented by a set of nodes and a successor function Succ mapping each node to the set of its outgoing neighbors. It defines what it means for a sequence to be a path from one node to another, uses existential quantification over sequences of nodes to define when a path exists, and then defines the set of nodes reachable from a given set S. The module includes a typing assumption that Succ is a function from Nodes to subsets of Nodes, and it contains no state variables, actions, temporal behavior, fairness conditions, or proofs beyond the commented note about TLAPS modules.
