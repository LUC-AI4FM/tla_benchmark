This TLA+ specification models Shmuel Safra's distributed termination detection algorithm on a ring, as described in EWD 998, with the notable difference that message channels are modeled as sequences rather than sets. The system consists of N nodes arranged in a ring, each of which can be active or inactive, and can send or receive messages (including a special token) via their inboxes. The algorithm uses a colored token and counters to detect global termination, ensuring that the token circulates and collects information about the system's state. The specification defines the system's state, actions for sending and receiving messages, passing the token, and environmental actions, as well as the main temporal property Spec, which asserts that the system starts in Init, always follows Next, and that System is weakly fair. Additional constraints are imposed to bound the state space for model checking, and the spec includes a refinement mapping to a set-based version of the algorithm. The file also contains a theorem stating that the sequence-based model refines the set-based one, and an eventuality property about inboxes.
