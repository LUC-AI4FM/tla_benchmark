This module contains TLAPS proofs for Lamport's distributed mutual-exclusion algorithm, building on a separate LamportMutex specification imported via EXTENDS. It proves type correctness, two inductive invariants about network-message structure and clock relationships, and finally derives the mutual-exclusion safety property. The proof is structured as a hierarchy of lemmas and theorems over the imported state machine, with no PlusCal algorithm in this file and no new system dynamics defined here beyond auxiliary predicates used in the proofs.
