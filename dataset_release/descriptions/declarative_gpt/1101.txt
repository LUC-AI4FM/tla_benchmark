This module specifies Peterson's mutual exclusion algorithm for two processes, including a PlusCal algorithm in comments and its translated TLA+ form. The system state consists of per-process control locations pc, intent flags c, and a shared turn variable; the specification defines the initial state and the step relation over labeled control points a0 through a4 and cs. The module proves an inductive invariant capturing typing, the relation between flags and control locations, and mutual exclusion, and it also defines a refinement mapping to an abstract lock specification via an INSTANCE of Lock. In addition, it states a liveness property asserting that a process waiting at label a3 eventually reaches the critical section cs.
