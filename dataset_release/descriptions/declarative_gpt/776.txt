This specification models a state-based CRDT counter replicated across a finite set of nodes. Each node stores a vector-like map of counts for every node, local increments update only the originating node's own component, and gossip merges copy pointwise maxima from one node's view into another node's view. The spec assumes Node is finite, defines safety and monotonicity properties over the replicated counter state, and introduces a fairness/liveness package asserting weak fairness for gossip and that eventually only gossip steps occur; it also states a convergence property that all node views are repeatedly eventually equal.
