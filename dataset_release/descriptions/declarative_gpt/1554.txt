This specification models the asynchronous termination detection problem in a ring network. Each node can be active or inactive and may have pending messages; the system tracks whether global termination has been detected. The model allows for asynchronous communication, with nodes sending and receiving messages independently, and includes the possibility of detecting termination as soon as all nodes are inactive and have no pending messages. The specification defines safety and liveness properties, including that termination is only detected when it has actually occurred, and that once the system is terminated, it remains so. The model is parameterized by the number of nodes N (assumed positive), and includes constraints to restrict the state space for model checking. The spec is designed for both TLC and Apalache model checkers, with some constructs (like NextOrUnchanged) included for Apalache compatibility.
