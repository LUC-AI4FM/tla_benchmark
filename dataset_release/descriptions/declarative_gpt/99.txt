This specification models a very simple counter with a single state variable x. The initial state sets x to 0, and the next-state action increments x by 1 on every step. The spec defines a standard temporal behavior formula using Init and [][Next]_x, and it also defines a state constraint and invariant requiring x < UpperBound; the file includes an ASSUME block that uses a LET-bound INSTANCE of TLC only for printing, not as part of the modeled algorithm.
