This specification models a high-level abstraction of the Paxos consensus algorithm, focusing on the cooperative selection of a value by a set of processes called acceptors. The model abstracts away message-passing details and instead describes the protocol in terms of acceptors, ballots, votes, and quorums. The fault model is not explicitly stated, but the Quorum assumption ensures intersection between quorums, which is essential for consensus safety. The specification defines the types and invariants necessary for correctness, including the key safety property that at most one value can be chosen per ballot and that only safe values are voted for. The spec includes temporal properties, inductive invariants, and proofs that the algorithm implements the Consensus specification via an INSTANCE substitution. Notable design decisions include the use of set and function constructs to represent votes and ballots, and the use of theorems and invariants to structure the correctness argument.
