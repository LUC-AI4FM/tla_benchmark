This module specifies the issuance of vouchers between voucher issuers and voucher holders, coordinated by a voucher transaction provider using a simplified Two-Phase Commit style protocol. The model represents communication with a monotonically growing set of messages, omits explicit Prepare messages from the coordinator, and also omits explicit abort messages from holders and issuers, instead allowing the coordinator to abort spontaneously. It verifies type correctness and a consistency invariant stating that a holder and an issuer do not reach conflicting outcomes, and it also states that the protocol-level specification implements an imported voucher life cycle specification.
