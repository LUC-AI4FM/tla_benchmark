This module specifies the Paxos consensus algorithm, including the two-phase message exchange between leaders and acceptors and the state maintained by acceptors about ballots and accepted values. The model assumes a quorum system over the set of acceptors, with the key fault-tolerance design captured by the assumption that any two quorums intersect. The specification defines when a value is considered chosen from the accumulated 2b messages, proves an inductive invariant and the consistency property with TLAPS, and finally proves that the Paxos specification refines an instantiated consensus specification.
