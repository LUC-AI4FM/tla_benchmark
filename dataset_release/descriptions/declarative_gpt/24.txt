This module models a sequential bounded model checking procedure similar to the one implemented in Apalache 0.5.x. It represents symbolic exploration of executions up to a maximum depth, where Next is conceptually partitioned into symbolic transitions and the checker incrementally tests which transition subsets are enabled and whether they can lead to an invariant violation. The spec abstracts SMT solving by checking whether the current set of transition prefixes can generate one of a designated set of bad executions, and it tracks whether the search is still working, has found an error, has finished without error at the bound, or has deadlocked.
