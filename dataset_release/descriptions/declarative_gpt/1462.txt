This specification models a very small two-variable transition system with state variables x and y. The system initializes x to 0 and y to FALSE, and then repeatedly takes either an Increment step, which increases x and toggles y, or a Decrement step, which requires x > 0 and decreases x while also toggling y. The file defines a safety condition requiring x /= Limit, a liveness condition requiring that eventually x = Limit, a basic temporal specification using [][Next]_<<x, y>>, and a stronger live specification that adds weak fairness for Increment. It also includes several record constructors as aliases over the current state.
