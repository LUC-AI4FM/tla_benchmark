This module is a small model-checking helper module for the HDiskSynod specification. It defines a concrete ballot-allocation operator that maps each process p to a contiguous range of ballot numbers of size BallotCountPerProcess, starting at p * BallotCountPerProcess. It also defines a concrete majority predicate stating that a set s is a majority exactly when Cardinality(s) * 2 > N; the module itself contains no temporal specification, actions, or proofs.
