This module is a typed model-checking companion module for a two-phase commit specification. It introduces a fixed set of three resource managers, instantiates the underlying TwoPhaseTyped module, and defines view abstractions and example-seeking predicates over the imported state variables rmState, tmState, tmPrepared, and msgs. The file focuses on symmetry-reduced observation functions and simple state predicates that characterize executions where the transaction manager or all resource managers have not yet reached committed or aborted outcomes; it contains no temporal specification, no actions, and no proofs.
