This specification models a typed sliding-block puzzle configuration, specifically the Klotski puzzle on a 4 by 5 board. The state consists of a single variable, board, where each board is a set of pieces and each piece is a set of grid positions. The specification defines board dimensions, the position space, a piece type, the initial Klotski arrangement, a goal predicate, a chooser operator, a type invariant, and helper operators for computing directions, translated pieces, board updates, the initial predicate, and the next-state action. It does not include assumptions, temporal properties, fairness conditions, proofs, or PlusCal code.
