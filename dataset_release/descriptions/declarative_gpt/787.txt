This module specifies client-centric isolation levels for transactional databases, following definitions from Crooks et al. It models database states as total functions from keys to values, operations as read/write records, transactions as sequences of operations, and executions as sequences pairing each transaction with its parent state. The spec defines helper predicates for read states, completeness, write sets, conflicts, transaction effects, and all possible executions, and then formalizes commit tests for Serializability, Snapshot Isolation, Strict Serializability, Read Committed, and Read Uncommitted, along with simple type predicates and a debug helper.
