This module specifies a lower-level worker-node implementation for SwarmKit that refines a higher-level worker specification by explicitly modelling container state in addition to task state. It models worker and environment actions such as task creation and updates, manager synchronisation, container shutdown and exit, node connectivity changes, orphaning tasks when a node stays down, and worker reboot. The spec verifies that the implementation implies the higher-level worker behavior and includes temporal properties with weak fairness on agent progress actions; it also contains a theorem explaining why proving the implementation and system properties in two stages is sufficient.
