This module specifies a tutorial version of binary search over an input sequence, with explicit state variables for the search bounds, termination flag, return value, and step counter. It models fixed-width integer arithmetic via a helper operator that wraps results into a signed machine-integer range determined by INT_WIDTH, and it checks both functional correctness and termination/progress-related properties. The spec includes assumptions about sorted input through a state predicate, defines loop, exit, and stuttering steps, and states postcondition, sorted-postcondition, termination, progress, and bounds-safety properties.
