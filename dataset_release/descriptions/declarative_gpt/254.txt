This module is a functional test specification for community-module operators over functions. It models a trivial state machine with Init and Next both equal to TRUE, and expresses the actual tests as state predicates combined into a single conjunction AllTests. The file checks properties of function restriction, range, injectivity, anti-functions/inverses, folds over functions, and the existence or membership of injections, surjections, and bijections, using finite integer and string-valued examples as well as quantified equivalence tests.
