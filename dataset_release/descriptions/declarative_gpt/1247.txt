This module, FiniteSets, provides definitions for two standard operators: IsFiniteSet and Cardinality. IsFiniteSet determines whether a set S is finite by checking if there exists a finite sequence containing all its elements. Cardinality computes the size of a finite set S recursively, using a LET-bound helper operator CS that counts elements by removing them one by one. The module is intended for use with TLC, which overrides these definitions in Java for efficiency, but the TLA+ definitions are mathematically precise and suitable for proof. The module imports Naturals and Sequences locally, so their definitions are not exported.
