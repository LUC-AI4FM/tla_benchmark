This module specifies a simple bubble-sort style system over an integer sequence. It models the state with a variable sequence `my_list` and a Boolean flag `finished`, initializes the list from a fixed input sequence, and repeatedly either swaps an out-of-order adjacent pair or marks the computation finished when the list is sorted. The specification includes a sortedness invariant and a stronger invariant about preservation of elements up to a reordering, and it uses Apalache-specific type annotations in comments and string-tagged definitions rather than temporal specification operators like `Spec`.
