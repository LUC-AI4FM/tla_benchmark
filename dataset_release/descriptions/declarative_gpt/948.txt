This specification defines a real-time memory-related wrapper around an internal memory specification. The top-level module introduces a positive real-time bound constant Rho, defines an inner module in which a response action forces a process control state to become "rdy", and requires that every process satisfy a real-time bound RTBound on that response action together with the imported internal-memory specification ISpec. The top-level property RTSpec existentially quantifies the internal state variables mem, ctl, and buf and states that there exists an instance of the inner real-time internal-memory specification satisfying RTISpec; the file uses imported real-time operators but does not itself define transition-system variables or proofs.
