This module models a tutorial version of binary search over an input sequence and a search key, using machine-integer bounds as auxiliary definitions. The current version contains only initialization and a single-step control structure for termination, with the actual search-update case for low <= high left unimplemented as stuttering. It specifies the initial values of the search interval and termination flag, and in the base case where the interval is empty it terminates by setting returnValue to -(low + 1); there are no temporal properties, fairness conditions, proofs, assumptions, or PlusCal processes in this file.
