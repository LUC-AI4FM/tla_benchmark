This specification models a simple state machine with a single integer variable x that is initialized to 0 and then remains unchanged forever. It also defines a helper operator A that updates a string-indexed function at a given key to value 1, and a concrete function f over the strings {"x", "y", "z"} initialized to 0. The main invariant asserts that folding the update operator A from the left over the sequence <<"z","y","x">> starting from f yields the function that maps every element of DOMAIN f to 1; the spec uses Apalache-specific typing comments and does not include fairness or liveness properties.
