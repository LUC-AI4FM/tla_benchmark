This module tests definitions and operations for bags (multisets) as constructed using TLA+ set and function primitives. It defines a variety of bag operations such as bag union, difference, subset, cardinality, and conversion between sets and bags. The module includes both general definitions and TLC-friendly variants, and provides a comprehensive suite of test expressions in the Inv operator to validate the correctness of these bag operations. The specification is not a distributed algorithm but rather a mathematical and implementation-level test of bag-related operators, with extensive use of LET and CASE constructs, and includes both functional and set-theoretic reasoning.
