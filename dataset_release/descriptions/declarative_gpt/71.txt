This module models a very small state machine for a collection of chains, where each chain stores a client-id counter and a function mapping client ids to client heights. The specification fixes concrete constants for two chain identifiers and small numeric bounds, then initializes every chain to an empty chain record whose clients all have height 0 and whose counter is 0. The only transition is stuttering, so the behavior is static; the spec mainly serves as a typed data-structure example and checks a simple type invariant over the variable state.
