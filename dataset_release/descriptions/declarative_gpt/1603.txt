This module is a regression test for a PlusCal translation issue involving a top-level comma inside an INSTANCE ... WITH clause located in a PlusCal define block. The translated specification models a trivial one-step algorithm with a program counter pc and a variable x, where the single step assigns x to Inner!Sum from an instantiated module and then moves pc to "Done". The temporal behavior is captured by an initial condition, a Next action consisting of the Step action or terminating stuttering, a standard safety-style specification [][Next]_vars, and a liveness property asserting eventual termination.
