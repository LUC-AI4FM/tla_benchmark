This specification models an iterative computation of factorial values alongside a recursive reference definition of factorial over a finite domain. The variable n is incremented step by step, factSpec is updated from the recursive function Fact at the new value of n, and factComp is updated multiplicatively to match the expected factorial progression. The file appears intended to support invariant checking that the computed factorial factComp always equals the specification value factSpec, with the notable design choice that the recursive function Fact is defined only on the finite range 1..20 because the tools require finite domains.
