This module defines a utility predicate for reasoning about finite functional graphs represented by a relation or function r over a set S. The main operator, IsSimpleCycle, characterizes when repeatedly following r from a chosen start node visits exactly the elements of S, using a finite sequence built over 1..Cardinality(S). The module is a helper-style specification with no variables, actions, temporal behavior, fairness, or proofs; it relies on imported modules for integers, sequences, finite-set cardinality, and function-domain/range operators.
