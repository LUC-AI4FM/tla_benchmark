This module specifies the Paxos Commit algorithm, modeling resource managers, acceptors, and leaders using a safety-only TLA+ specification. The model simplifies communication by representing msgs as the set of all messages ever sent, not explicitly modeling message receipt, and not modeling leader selection, so any process may act as leader. It defines the protocol actions for resource managers, leaders, and acceptors, gives an initial-state predicate and next-state relation, and proves that the resulting specification preserves a type-correctness invariant and implements the transaction commit specification from module TCommit.
