This specification models a tiny two-variable state machine over variables a and b. The initial state sets both variables to 0. The Next action either swaps the next-state values of a and b or nondeterministically assigns b' from the set { 1, 2 }, while also constraining a' to equal 1 and to equal every q in the singleton set { 1 }. Spec is the temporal formula [][Next]_<< a,b >>.
