This specification models Safra's distributed termination detection algorithm on a ring, based on EWD 998. The system consists of nodes with activation state, color, local counters, pending messages, and a circulating token that carries a position, a quantity, and a color; the environment may send messages, receive messages, and deactivate nodes asynchronously. The spec defines safety properties about correct termination detection, an inductive invariant attributed to Safra, a liveness property stating that termination is eventually detected under weak fairness of the system actions, and a bounded state constraint for model checking.
