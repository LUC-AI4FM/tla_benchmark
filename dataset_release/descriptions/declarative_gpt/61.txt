This specification models a minimal fragment of a two-phase commit style protocol, reduced to a small example that exposed a bug. It uses variant-style message constructors for Commit, Abort, and Prepared messages, tracks the state of two resource managers, the set of prepared managers known to the transaction manager, and the set of sent messages. The spec defines an initial state, a transaction-manager commit action, a resource-manager prepare action, a next-state relation that allows either committing or preparing one specific manager, and an invariant asserting that a commit message is not in the current message set.
