This module specifies and checks an algorithm for removing redundant matched parentheses from a well-formed token sequence representing an expression. It defines a recursive mathematical reference function Result(seq) that repeatedly removes an inner matching parenthesis pair when that pair is immediately enclosed by another matching pair, and then gives a PlusCal algorithm together with its translated TLA+ actions to compute the same result operationally. The specification uses no fault model; instead, it verifies functional correctness by asserting at termination that the algorithm's output out equals Result(in), and it also states the temporal property that the algorithm eventually reaches the control state "Done".
