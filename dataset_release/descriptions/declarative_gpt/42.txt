This module provides an alternative, Apalache-oriented version of the community module SequencesExt. It defines a collection of sequence, prefix/suffix, subsequence, folding, conversion, and replacement operators, often with explicit type annotations in comments and with some operators delegated to Apalache-specific helpers. Several operators are marked unsupported by the model checker, reflecting a design choice to keep compatibility with Apalache rather than fully reproduce TLC behavior; the module contains no state variables, actions, temporal specification, or fault model, and it serves as a pure library of state-level operators.
