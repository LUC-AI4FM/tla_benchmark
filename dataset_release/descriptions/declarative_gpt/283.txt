This module is a small regression-test specification for the TLA+ construct UNCHANGED e, specifically targeting a reported issue involving UNCHANGED applied to a tuple that includes variables, a function application, and a constant. The specification initializes a function variable f to map 1..3 to doubled values and initializes the variable i to 2. It defines a Next action consisting solely of UNCHANGED <<f, i, f[i], N>>, so the modeled behavior is a stuttering step over those expressions; there are no temporal properties, fairness conditions, fault model, or proofs in the file.
