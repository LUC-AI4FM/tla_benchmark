This specification is a minimal reproduction of an Apalache issue involving record updates and record type annotations. It models a single variable m that is initialized to a record with one field foo, and then allows either stuttering by leaving m unchanged or an update of the foo field using an EXCEPT expression. The comments explain that the bug concerns a mismatch between the number of record fields declared in a type annotation and the number of fields assigned in a next-state expression, and that with row-type checking the specification is considered ill-typed.
