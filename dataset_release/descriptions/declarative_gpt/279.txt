This module specifies a two-phase commit protocol in an uninterpreted first-order logic style derived from Lamport's TwoPhase specification. It models a transaction manager and a set of resource managers, representing resource-manager states, transaction-manager state, and message presence with uninterpreted functions and Boolean predicates rather than richer TLA+ data structures. The specification defines initialization, transaction-manager and resource-manager actions, a next-state relation, a temporal safety-style system specification TPSpec, and a consistency predicate asserting that no two resource managers can end in conflicting committed and aborted states.
