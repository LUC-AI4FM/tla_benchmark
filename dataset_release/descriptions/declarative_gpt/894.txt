This module demonstrates how to use TLC's Print operator inside assumptions to calculate and display the values of TLA+ expressions during model checking. It defines a helper operator PrintVal that prints an identifier together with an expression value, and then uses a single conjunctive ASSUME block so TLC prints the selected values in a desired order. The spec is not a transition-system algorithm with variables or temporal behavior; it is a small utility-style module focused on expression evaluation, records, record update with EXCEPT, arithmetic, and TLC output.
