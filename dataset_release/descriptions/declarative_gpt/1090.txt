This module is a TLAPS proof module for the safety properties of the specification in the extended module clean. It proves that the imported specification Spec implies the invariants []TypeOK, []primerPositive, and []preservationInvariant, and adds an explicit assumption that the unconstrained constants DNA and PRIMER are natural numbers so arithmetic facts can be used in the proofs. The file is proof-oriented rather than algorithm-defining: it contains assumptions, one helper lemma about natMin, and three main theorems with structured proofs over the imported actions heat, cool, anneal, extend, and stuttering via UNCHANGED vars.
