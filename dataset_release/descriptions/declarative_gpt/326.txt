This specification models the partial link reversal algorithm on a directed graph, following the Gafni and Bertsekas routing approach for networks with changing topology. The state is represented by outgoing neighbors, incoming neighbors, and a per-node set of links marked for reversal; in each step, an arbitrary subset of current sinks except the destination may reverse selected incident links. The spec includes an initial graph, defines when a graph is a DAG via existence of a partial order embedding the directed edges, and provides state-transition operators for updating the graph structure, but it does not include an explicit temporal specification such as Spec, fairness, or liveness properties.
