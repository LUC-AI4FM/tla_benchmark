This specification models a reconfigurable Paxos-style consensus algorithm with acceptors casting votes across instances and ballots, and with reconfiguration commands that change the active configuration. The state consists of per-acceptor votes `avote` and a set `learned` of learned instance-command pairs; the spec defines when votes are cast, when an acceptor abstains, when a value is learned, and how configurations are derived from learned reconfiguration commands. The file proves safety properties only, not liveness: it states the standard temporal specification `Spec == Init /\ [][Next]_<<avote, learned>>`, proves type correctness and a safety invariant, and then develops a substantial TLAPS proof showing an inductive invariant for reconfiguration safety.
