This module is a small regression test for Cartesian product semantics and related tuple/function behavior in TLA+. It models a trivial one-variable system where x is always 1 and the interesting content is an invariant Inv that performs a sequence of runtime checks using IF, Assert, and Print. The checks validate products built with \X, tuple membership in Cartesian products, function constructors over tuple domains, intersections involving function sets, and subset membership of explicit tuple sets; there is no fault model, no temporal liveness property, and no fairness condition.
