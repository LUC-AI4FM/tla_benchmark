This module is a small test specification for let polymorphism and parametric typing in a TLA+ type-checking context. It models two function variables, one from strings to integers and one from integers to strings, and defines a generic helper operator Extend that adds a key-value mapping to an existing function by extending its domain. The specification consists of an initialization assigning both functions to empty-domain functions and a next-state action that updates each variable using the same polymorphic Extend operator instantiated at different types; there are no temporal properties, fairness conditions, proofs, or fault assumptions in the file.
