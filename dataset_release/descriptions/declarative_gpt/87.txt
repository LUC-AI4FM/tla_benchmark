This module specifies a typed version of the Chang-Roberts leader election algorithm on a unidirectional ring. Nodes are arranged in a ring, each has a unique natural-number identifier given by the constant function Id over the node set 1..N, and any subset of nodes may initiate the election. The specification models message passing through per-node message sets, verifies type correctness and a safety property stating that any winner must be the initiating node with the smallest identifier while all others are lost, and includes liveness properties with weak fairness for each process action.
