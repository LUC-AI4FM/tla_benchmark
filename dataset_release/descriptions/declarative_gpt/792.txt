This module is a small wrapper around another specification, KVsnap, and adds TLC-specific helper definitions for model checking. It defines a symmetry operator over transaction identifiers using Permutations and a debugging invariant that queries TLC's execution level and, above a threshold, checks that no two distinct keys in the store hold distinct non-NoVal values. The module does not define its own transition system, variables, or temporal specification; instead, it contributes derived operators intended for symmetry reduction and debugging during analysis.
