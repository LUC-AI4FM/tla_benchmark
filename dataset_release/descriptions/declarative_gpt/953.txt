This module defines a standard TLA+ representation of bags (multisets) as functions from elements to positive natural numbers, where the domain contains exactly the elements present in the bag and the function value gives the multiplicity. It provides operators for recognizing bags, converting between sets and bags, bag membership, empty bags, bag union and difference, subbag comparison, the set of all subbags, image construction over bags, cardinality, and counting copies of an element. The module is a pure mathematical library module rather than a transition-system specification: it has no variables, actions, or temporal properties, and its comments note that most operators are overridden by TLC except for SubBag.
