This module specifies a small PlusCal algorithm with an either-or branch. Starting from x = 0, y = 0, and control at label a, the algorithm nondeterministically chooses either the x branch, which sets x to 1 and then increments it, or the y branch, which sets y to 1 and then increments it. The translated TLA+ specification defines the corresponding control-state variable pc, the actions for each program label, a terminating stuttering action, a temporal specification with weak fairness on Next, an eventual termination property, and helper predicates that inspect TLC named-action coverage counts via TLCGet.
