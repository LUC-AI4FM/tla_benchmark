This module specifies the alternating bit protocol as a simple sender-receiver communication system with separate message and acknowledgment queues. The sender keeps a data value and a control bit, retransmits when an acknowledgment has not yet matched the current bit, and the receiver records the last received bit and data value while sending acknowledgments back. The environment may nondeterministically lose one element from either queue, and the specification checks a type invariant over the protocol state under a temporal specification with weak fairness for retransmission and acknowledgment sending and strong fairness for message and acknowledgment receipt.
