This specification models a simple state machine over a set of records and a Boolean flag. The system starts with ok = TRUE and an empty set of records, then in each step recomputes ok' from the current records and either inserts a fixed record, increments the age field of an existing record via a record EXCEPT update, or stutters on recs. The invariant asserts that every record currently in recs has age < 15, and the next-state relation is written to maintain and observe that age-related condition.
