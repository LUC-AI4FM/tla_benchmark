This module specifies a simple message multiset abstraction for a distributed system network. It models the network state as a function from message records to natural-number multiplicities, with helpers to add or remove a message occurrence and actions to send, discard, reply, duplicate, or drop messages. The specification does not include temporal properties or fairness; it focuses on state initialization and message-update actions, and it uses a function-based bag encoding because the Bags module is not used.
