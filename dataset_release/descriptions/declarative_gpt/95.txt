This module is a small configuration-testing specification used to check whether configuration file settings and command-line overrides are parsed and applied correctly. It models a single integer state variable x with multiple alternative initial predicates and next-state relations, along with several alternative specifications combining safety and fairness. The file defines default and overridden initial conditions, default and overridden transition relations, simple invariants over x, and one liveness property asserting that eventually x becomes greater than 10.
