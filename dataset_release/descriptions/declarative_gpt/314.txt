This module is a model-checking wrapper around an instance of BinSearch6 with the integer width fixed to 8 bits. It does not define the binary-search algorithm itself here; instead, it fixes INT_WIDTH and leaves INPUT_SEQ and INPUT_KEY unconstrained except for initialization through ConstInit using Apalache's Gen operator. The file introduces the state variables expected by BinSearch6, instantiates that module, and defines an initial constraint for arbitrary well-typed constants, but it does not itself define transition actions, temporal specifications, fairness, or proofs.
