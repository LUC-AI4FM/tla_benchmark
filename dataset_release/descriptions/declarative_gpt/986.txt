This specification models the Yo-Yo leader-election algorithm on a strongly connected undirected graph, extended with pruning so that the algorithm terminates. Nodes alternate between down and up phases, exchange structured messages through mailboxes, reverse or prune edges based on replies, and eventually eliminate all but one source so that the smallest node becomes an isolated leader. The spec assumes a connected undirected graph, uses weak fairness for the main next-state action, and states both safety-style properties about graph consistency and termination-style temporal properties such as eventual termination and equivalence between deadlock and the terminated condition.
