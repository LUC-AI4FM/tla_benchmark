This module, APHourClock, provides Apalache type annotations for the Liveness/HourClock.tla specification. It is an exact duplicate of SpecifyingSystems/HourClock/HourClock.tla, but is kept separate so that other modules (such as those in the Specifying-Systems chapter on Liveness) can EXTEND HourClock from a sibling module. The module introduces a single variable 'hr' with an Apalache type annotation indicating it is an integer. No operators, actions, or temporal properties are defined directly in this file; instead, the module relies on the imported HourClock module for its behavior and properties.
