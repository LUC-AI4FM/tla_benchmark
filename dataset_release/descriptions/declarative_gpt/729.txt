This module is a test specification for vector clock causality utilities imported from the VectorClocks module. It asserts a series of assumptions over small example traces and over a log loaded from an NDJSON file, checking whether IsCausalOrder classifies traces as causal or non-causal under various vector-clock and node projections. The specification uses helper operators to extract vector clocks and node identifiers from deserialized log entries, and it documents a JSON deserialization design issue where numeric object keys become record fields with string domains, requiring ToString conversion.
