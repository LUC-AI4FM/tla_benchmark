This specification models a very small two-variable transition system with state variables x and b. The system starts with x in the range 0..3 and b as a Boolean value, and then evolves by either action A, which toggles b while leaving x unchanged when x < 5 and b is TRUE, or action B, which toggles b while incrementing x when b is FALSE. The temporal specification requires the initial condition, permits stuttering through [][Next]_<<x, b>>, adds weak fairness for Next, and also defines a leads-to property Xshrinks asserting that whenever x = 2 holds, eventually x = 1 holds.
