This module constrains executions of an existing Tendermint accountability specification so that only a prescribed trace of action names is replayed. It introduces a trace constant and a local replay variable, initializes the replay buffer from the constant trace, and on each next-state step removes the head of the remaining trace while forcing the action name variable to match the expected action. The module is intended for counterexample replay and debugging with Apalache: once the supplied trace is fully replayed, the restricted system deadlocks because no further replay steps are enabled.
