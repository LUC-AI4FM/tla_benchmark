The module specifies a tutorial model of binary search over a fixed-width integer machine, closely following the Java `Arrays.binarySearch` implementation. It is parameterized by three constants: `INPUT_SEQ` (the sequence to search), `INPUT_KEY` (the value sought), and `INT_WIDTH` (the bit-width of machine integers), from which signed and unsigned integer bounds are derived. The five variables track the current search interval endpoints (`low` and `high`), a termination flag (`isTerminated`), the result (`returnValue`), and a step counter (`nSteps`).

Initialization sets `low` to 0 and `high` to the last index of the sequence. The next-state relation has three actions: `LoopIteration` performs one search step by computing a midpoint via bounded integer addition (`IAdd`), then either advances `low`, retreats `high`, or records a found index and terminates; `LoopExit` fires when the interval is empty, sets `returnValue` to a negative encoding of the insertion point, and terminates; `StutterOnTermination` allows the system to stutter once terminated. Several properties are defined: `PostconditionSorted` asserts that on termination, if the input is sorted, the return value is non-negative exactly when the key is present; `Termination` asserts the algorithm finishes within `INT_WIDTH` steps; `Progress` asserts the interval strictly contracts each non-terminated step; and `InBounds` asserts array accesses stay within sequence bounds throughout execution.
