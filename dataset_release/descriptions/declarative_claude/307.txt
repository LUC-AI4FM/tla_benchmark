The module specifies a tutorial binary search algorithm modeled after Java's `Arrays.binarySearch`, progressing through iterative refinements culminating in version 8, which checks array-access boundary safety.

The system has three constants: `INPUT_SEQ` (the sorted integer sequence to search), `INPUT_KEY` (the search target), and `INT_WIDTH` (the bit-width of machine integers). Variables track the current search interval endpoints `low` and `high`, a termination flag `isTerminated`, the `returnValue`, and a step counter `nSteps`. The operator `IAdd` models fixed-width signed integer addition with wrap-around behavior. `Init` sets `low` to 0, `high` to `Len(INPUT_SEQ) - 1`, and clears termination. Each `Next` step either computes the midpoint using `IAdd` and narrows the interval (or returns the found index), terminates with a negative insertion-point encoding when the interval is exhausted, or stutters once terminated.

Several properties are defined. `Postcondition` asserts that on termination the return value is non-negative if and only if the key is found, and `PostconditionSorted` restricts that guarantee to sorted inputs. `Termination` states that after `INT_WIDTH` steps the algorithm must have halted. `Progress` is an action property asserting that if the algorithm has not terminated, the interval strictly contracts. `InBounds` is a safety invariant asserting that every midpoint index computed while the algorithm is running falls within the domain of `INPUT_SEQ`, guarding against out-of-bounds access caused by integer overflow in the midpoint calculation.
