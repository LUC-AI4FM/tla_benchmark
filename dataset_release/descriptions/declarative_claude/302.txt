The module specifies a tutorial model of binary search (modeled after Java's `Arrays.binarySearch`), developed incrementally across versions. It is parameterized by three constants: `INPUT_SEQ` (the integer sequence being searched), `INPUT_KEY` (the target value), and `INT_WIDTH` (the machine integer bit-width, used to define `MAX_UINT`, `MAX_INT`, and `MIN_INT`).

The state consists of four variables: `low` and `high` (the current inclusive search interval boundaries), `isTerminated` (a flag indicating algorithm completion), and `returnValue` (the result upon termination). `Init` sets `low` to 0, `high` to the last index of the sequence, `isTerminated` to false, and `returnValue` to 0. The `Next` action handles three cases: if not yet terminated and `low <= high`, the loop body is a stub that leaves all variables unchanged (marked as not yet implemented); if not terminated and `low > high`, the algorithm terminates with `returnValue` set to `-(low + 1)`, reflecting the Java convention for a not-found result; if already terminated, all variables remain unchanged.

The module defines `ReturnValueIsCorrect`, which checks that upon termination the return value is a valid 1-based index into `INPUT_SEQ` if the key is present, or is negative if the key is absent. The invariant `Postcondition` asserts that whenever `isTerminated` holds, `ReturnValueIsCorrect` must hold. This serves as the expected postcondition for the completed binary search algorithm.
