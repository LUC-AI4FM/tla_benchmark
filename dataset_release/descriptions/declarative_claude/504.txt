The module specifies single-decree Paxos with a fixed (implicit) leader and no leader-election component. The system is parameterized by four constants: `Acceptors` (a finite set of at least three acceptors), `Quorums` (a collection of subsets of acceptors satisfying the quorum-intersection property), `Values` (a finite set of at least two non-zero candidate values), and `Ballots` (a finite subset of the natural numbers).

The four variables track the global message history (`msgs`) and, per acceptor, the highest ballot seen in a Phase 1a message (`maxPrepared`), the highest ballot for which the acceptor has cast a Phase 2b vote (`maxAccepted`), and the value associated with that vote (`valAccepted`). Initially all acceptor bookkeeping is set to −1 or 0 and the message set is empty. The four actions implement the standard two-phase Paxos protocol: `Phase1a` lets the leader broadcast a prepare message for a fresh ballot; `Phase1b` lets an acceptor promise to ignore lower ballots and report its highest prior vote; `Phase2a` lets the leader, upon collecting a quorum of promises, propose the value constrained by the highest previously accepted ballot in those promises (or any value if none exists); and `Phase2b` lets an acceptor accept the proposed value unless it has already promised a higher ballot. The temporal specification `Spec` is a safety-only formula (`Init /\ [][Next]_vars`) with no fairness or liveness conditions, and the module states no explicit invariants or properties beyond the structural assumptions.
