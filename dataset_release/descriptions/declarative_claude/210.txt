The module Rec8 models an iterative computation of the factorial function and verifies it against a recursive specification, using three integer variables: `n` (the current index), `factSpec` (the factorial value given by a recursive function definition), and `factComp` (an incrementally computed factorial value).

The recursive function `Fact` is defined on the finite domain `1..20`, computing the standard factorial: `Fact[1] = 1` and `Fact[k] = k * Fact[k-1]` for `k > 1`. In the initial state, `n` is set to 1, `factSpec` to `Fact[1]`, and `factComp` to 1. Each step of the `Next` relation advances `n` by one, updates `factSpec` to `Fact[n']`, and updates `factComp` by multiplying the previous value by `n'`, thereby computing the factorial iteratively. The invariant `Inv` asserts that at every reachable state the iteratively computed value `factComp` equals the recursively specified value `factSpec`, confirming that the step-by-step multiplication correctly tracks the factorial function across all steps. No temporal specification or fairness conditions are defined; the module is intended primarily for invariant checking by model checkers such as TLC or Apalache.
