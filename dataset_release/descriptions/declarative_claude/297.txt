The module specifies a Byzantine reliable broadcast protocol for a system of N processes, of which F may be faulty (Byzantine) and the remaining N−F are correct. The parameters satisfy N > 3T ≥ 3F ≥ 0, reflecting standard Byzantine fault-tolerance assumptions. Each correct process holds a program counter (pc) drawn from {"V0", "V1", "SE", "AC"}, where V0 and V1 represent initial states (not broadcasting or broadcasting), SE means an ECHO message has been sent, and AC means the process has accepted. The shared variable sent tracks all ECHO messages broadcast by correct processes, while rcvd records what each correct process has received, including messages that faulty processes may inject arbitrarily.

In each step, a correct process first nondeterministically receives a subset of sent messages plus any ECHOs from faulty processes, then fires one of four guarded transitions: UponV1 sends an ECHO immediately from state V1; UponNonFaulty sends an ECHO upon receiving between T+1 and N−T−1 ECHOs without yet having sent one; UponAcceptNotSent accepts and sends an ECHO upon receiving N−T or more ECHOs from an initial state; and UponAccept moves to AC from SE upon receiving N−T or more ECHOs. The safety invariant Unforg asserts no correct process reaches AC when all started in V0 (no broadcast initiated). The temporal properties UnforgLtl, CorrLtl, and RelayLtl express unforgeability, eventual acceptance when all started in V1, and relay (if any correct process accepts, eventually all do), respectively.
