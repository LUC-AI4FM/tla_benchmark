The module specifies the **partial link reversal** algorithm on directed graphs, based on the 1981 Gafni–Bertsekas paper on loop-free routing in networks with changing topology. The system models a fixed set of nodes (`Nodes = 1..N`, with `N = 4`) and a designated destination node (`dest = 1`).

The state is captured by three variables: `out`, mapping each node to its set of outgoing neighbors; `in`, the corresponding incoming-neighbor sets (derived as the transpose of `out`); and `to_rev`, tracking which incoming edges each node has already had reversed by prior steps. The initial graph is a fixed directed acyclic graph encoded in `InitOut`, with `in` computed from it and `to_rev` empty everywhere.

At each step, the `Next` action selects a nonempty subset of current **sinks** — nodes with no outgoing edges other than the destination — as the `Active` set. For each active sink, the algorithm computes which incoming edges to reverse via `Reversed`: if not all incoming edges have been previously reversed, only the unreversed ones are flipped; otherwise all incoming edges are reversed. The three update actions then simultaneously rewrite `out`, `in`, and `to_rev` to reflect those reversals. Non-active nodes lose outgoing edges toward active sinks and gain incoming edges from them, while active sinks swap their incoming edges into outgoing ones and reset their `to_rev`.

The module defines `IsDag` as a partial-order embedding condition, intended as a safety invariant asserting that the evolving directed graph remains acyclic throughout execution. No explicit temporal specification or fairness conditions are stated.
