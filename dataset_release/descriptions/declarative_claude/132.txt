The module FunExcept2 is a small test or utility specification demonstrating the use of TLA+'s `EXCEPT` construct on functions, rather than modeling a real system. It defines a fixed set `Node` of three string-named elements and declares two variables, `fun1` and `fun2`, each typed as a function from nodes to sets of nodes. Both are initialized to the function mapping every node to the empty set. The single `Next` action updates both functions identically: the entry at key `"2_OF_N"` is extended by adding `"3_OF_N"` to its current set value, while all other entries remain unchanged. Because the same `EXCEPT` expression is applied symmetrically to both `fun1` and `fun2`, the two functions remain equal throughout all reachable states. The invariant `Sanity` asserts that the sets associated with `"1_OF_N"` are equal across the two functions, which holds trivially since neither function's `"1_OF_N"` entry is ever modified. The module has no fairness conditions and no temporal liveness properties; it appears intended purely to check or demonstrate that equivalent `EXCEPT` updates on two separate function variables produce consistent results.
