The module specifies Conway's Game of Life on an N×N toroidal-bounded grid, as a typed variant of an existing TLA+ example. The single constant N (a natural number) defines the grid dimensions, and the single variable `grid` maps every position (a pair of integers in 1..N × 1..N) to a Boolean indicating whether the cell is alive.

The initial state `Init` allows `grid` to be any function from positions to Booleans, representing an arbitrary starting configuration. The `Next` action advances the grid by one generation: each cell's new state is determined by the standard Game of Life rules — a live cell survives if it has exactly 2 or 3 live neighbors, a dead cell becomes alive if it has exactly 3 live neighbors, and all other cells become (or remain) dead. Neighbor counts are computed by the `score` function, which sums the `sc` helper over the eight surrounding positions; `sc` treats out-of-bounds positions (outside 1..N) as dead, effectively implementing a fixed boundary condition. The temporal specification `Spec` is `Init` conjoined with the always-enabled stuttering next-state relation `[][Next]_vars`, with no fairness conditions. The only invariant stated is `TypeOK`, asserting that `grid` is a function from `Pos` to `BOOLEAN`.
