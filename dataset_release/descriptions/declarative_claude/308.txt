The module specifies a tutorial model of binary search, closely following the Java `Arrays.binarySearch` implementation, across a series of refinement versions culminating in a version that fixes an integer-overflow access bug.

The system is parameterized by three constants: `INPUT_SEQ` (the sequence to search), `INPUT_KEY` (the search target), and `INT_WIDTH` (the machine integer bit-width). Derived constants define the signed and unsigned integer ranges, and the helper `IAdd` models fixed-width signed addition with wrap-around. The state is tracked by five variables: `low` and `high` (the current search interval bounds), `isTerminated` and `returnValue` (termination flag and result), and `nSteps` (a step counter).

`Init` sets up the full sequence index range and clears termination state. `Next` implements one iteration of the binary search loop: if not terminated and `low ≤ high`, it computes `mid` using overflow-safe arithmetic, reads `INPUT_SEQ[mid+1]`, and narrows the interval or records a found index; if `low > high`, it sets a negative return value encoding the insertion point; once terminated, all variables stutter. The spec checks several properties: `PostconditionSorted` asserts correctness of the return value when the input is sorted; `Termination` asserts the algorithm halts within `INT_WIDTH` steps; `Progress` asserts the search interval strictly contracts each non-terminating step; and `InBounds` asserts that array accesses always fall within the domain of `INPUT_SEQ`.
