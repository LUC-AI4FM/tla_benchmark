The module TwoPhaseUFO is a reformulation of Leslie Lamport's classic Two-Phase Commit (2PC) protocol rewritten in Uninterpreted First-Order Logic (UFOL), a fragment of TLA+. Its purpose is to represent the same protocol using only uninterpreted sorts and predicates rather than concrete set-theoretic constructs, making it amenable to first-order logic reasoning and model checking tools that operate on that fragment.

The constant `Values_RM` represents the set of resource managers (of sort `SORT_RM`). The variables track each RM's state (`rmState`, a function from RMs to an uninterpreted state sort), the transaction manager's state (`tmState`), the set of RMs from which the TM has received Prepared messages (`tmPrepared`, a Boolean-valued predicate over RMs), and three message-presence flags: `msgsPrepared` (per-RM Boolean), `msgsCommit` (global Boolean), and `msgsAbort` (global Boolean). State values such as "working," "prepared," "committed," and "aborted" are represented as distinguished uninterpreted constants suffixed with `_OF_SORT_STATE`.

Initially all RMs are working, the TM is in its init state, and all message flags are false. Actions include the TM receiving a Prepared message from a specific RM, the TM committing (once all RMs are prepared), and the TM aborting spontaneously. RM actions allow each RM to prepare, choose to abort unilaterally, receive a Commit message, or receive an Abort message. The temporal specification `TPSpec` is a safety specification (no fairness conditions). The invariant `TCConsistent` asserts that no RM has committed while another has aborted, enforcing the fundamental consistency requirement of atomic commitment.
