The module specifies Shmuel Safra's distributed termination detection algorithm on a ring of N nodes, as described in Dijkstra's EWD 998. The system models N nodes arranged in a ring, where nodes can be active or inactive, exchange messages, and pass a token around the ring to detect when all computation has ceased.

The state consists of each node's activation status, color (white or black), a message counter tracking sent-minus-received messages, a pending message count per node, and a token carrying a position, cumulative counter, and color. Initially, counters and pending counts are zero, and the token starts at node 0 as black. The environment actions allow active nodes to send messages to any other node, any node to receive a pending message (which reactivates it and blackens it), and active nodes to deactivate. The system actions are `InitiateProbe`, where node 0 restarts a token pass when the previous round was inconclusive, and `PassToken`, where an inactive node forwards the token toward node 0, accumulating counters and propagating black coloring.

The temporal specification is `Init /\ [][Next]_vars` with weak fairness on system actions. The config sets N=3, applies state constraints bounding counters and pending counts to 3, and checks the invariants `TypeOK` and `Inv`. `Inv` encodes Safra's inductive invariant relating total in-flight message counts to node counters and token state across four disjunctive clauses. The safety property `TerminationDetection` asserts that whenever termination is declared (white token at node 0 with consistent zero-sum accounting), the system has truly terminated. The liveness property `Liveness` asserts that actual termination is eventually detected. An alias provides TLC instrumentation tracking token passes, node activations, and token field statistics.
