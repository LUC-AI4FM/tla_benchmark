This module is a test specification for verifying the correctness of SafeMath arithmetic operations modeled after OpenZeppelin's Solidity SafeMath library, which provides overflow-safe integer arithmetic for 256-bit unsigned integers.

The module defines five variables: `opcode` (the current operation being tested), `arg1` and `arg2` (the two operands), `res` (the result), and `is_error` (a flag indicating whether the operation detected an overflow or invalid condition). The system starts in a `NOP` state with all values zeroed. In a single `Next` step, the system non-deterministically selects two 256-bit unsigned integers and applies either `TryAdd` or `TrySub` (multiplication, division, and modulo are commented out as too expensive for Z3), then transitions to a terminal stuttering state where variables remain unchanged. The `TryAdd` and `TrySub` functions mimic SafeMath's overflow detection logic: addition fails when the modular result wraps below either operand, and subtraction fails when the subtrahend exceeds the minuend.

The invariants `InvAdd`, `InvSub`, `InvMul`, `InvDiv`, and `InvMod` assert that `is_error` is set exactly when the mathematically precise integer result would overflow or involve division by zero. The spec is explicitly expected to deadlock (after one operation step) without violating any invariant. A separate `FalseInv` property, intended to be falsified, asserts that the sum of the two arguments never reaches `MAX_UNSIGNED`, serving as a demonstration that overflows can be witnessed.
