The module specifies Dijkstra's self-stabilizing token-ring algorithm (his first mutual-exclusion solution based on a K-state machine) for a ring of N processes with K possible token values, where K > N > 0.

The system has N processes arranged in a logical ring, indexed 0 through N−1, sharing a global array M mapping each process to a value in 0..K−1. Process 0 (the "bottom" process) holds a token when its value equals that of its neighbor N−1, and responds by incrementing its value modulo K. Each other process i holds a token when its value differs from its left neighbor i−1, and responds by copying that neighbor's value. The specification is translated from PlusCal; the pc array tracks each process's program counter between its guard-check and assignment steps. The temporal specification Spec includes weak fairness for all processes, ensuring every enabled process eventually takes a step.

A token is defined as the condition enabling a process to act: process 0 when M[0] = M[N−1], or process i > 0 when M[i] ≠ M[i−1]. The invariant SomeoneHoldsToken asserts at least one process always holds a token. The liveness property EventuallyJustOneHoldsToken asserts that eventually exactly one process holds the token forever, capturing the self-stabilization guarantee. The configuration checks these properties with N=4 and K=5, and a postcondition validates specific state-space counts for SingleToken and TokenPasses across all reachable states.
