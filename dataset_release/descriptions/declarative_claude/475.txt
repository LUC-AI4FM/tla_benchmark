The module specifies a parameterized model of reliable broadcast by message diffusion with crash failures, based on the algorithm of Chandra and Toueg (1996). It models N processes (indexed 1..N), up to F of which may crash, with a fault-tolerance threshold T. The only message type is "ECHO".

The state is tracked via `pc` (each process's program counter, taking values V0, V1, AC, or CR), `rcvd` (messages received per process), `sent` (the global set of sent messages), `nCrashed` (count of crashed processes), and `Corr` (the current set of correct processes). Initially, no messages are sent or received, no process has crashed, and each process is nondeterministically in V0 (no INIT received) or V1 (INIT received), except in `InitNoBcast` where all start at V0.

In each step, a correct process first nondeterministically receives any superset of its current received messages that is a subset of `sent`, then either: transitions from V1 to AC and broadcasts ECHO (`UponV1`); transitions from V0 or V1 to AC and broadcasts ECHO upon receiving at least one message (`UponAccept`); crashes if the crash budget allows (`UponCrash`); or does nothing. The temporal specification `Spec` adds weak fairness over the non-crash actions to support liveness reasoning. A `SpecNoBcast` variant uses the no-broadcast initial condition.

The module defines a state-type invariant `sTypeOK`, and four properties: `Unforg`/`UnforgLtl` (if no process started with INIT, no correct process ever accepts), `CorrLtl` (if all correct processes hold V1, some eventually accepts), `RelayLtl` (once any correct process accepts, all correct processes eventually accept), and `ReliableChan` (any sent ECHO is eventually permanently received by all correct processes).
