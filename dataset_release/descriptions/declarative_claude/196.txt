The module QueensTyped is a typed variant of the classic N-Queens specification, adapted for use with the Apalache model checker, which requires explicit type annotations. It models both the problem definition and an iterative algorithm for finding all placements of N non-attacking queens on an N×N chessboard.

The single constant `N` specifies the board size. Queens are represented as sequences of column indices, where position `i` in the sequence gives the column of the queen in row `i`. The predicate `Attacks` checks whether two queens share a column or diagonal, and `IsSolution` checks that no two queens in a (possibly partial) sequence attack each other. The set `Solutions` collects all complete, conflict-free placements, using the Apalache operator `FunAsSeq` to convert functions to sequences.

The algorithm's state is held in two variables: `todo`, a set of partial solutions (sequences shorter than N), and `sols`, the set of complete solutions found so far. The initial state places the empty sequence in `todo` and leaves `sols` empty. The single action `PlaceQueen` picks a partial solution from `todo`, computes all valid column extensions for the next queen, and either moves completed N-length sequences into `sols` or replaces the partial solution with its valid extensions in `todo`. The temporal specification includes weak fairness on `PlaceQueen`, ensuring the algorithm always makes progress. The module checks a `TypeInvariant` on the shapes of `todo` and `sols`, a two-part safety and convergence `Invariant` asserting that `sols` contains only valid solutions and eventually all solutions, and a liveness property `Termination` asserting `todo` eventually empties.
