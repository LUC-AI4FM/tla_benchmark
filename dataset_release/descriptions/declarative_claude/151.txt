The module models a simple two-variable integer swap system used to test model-checking behavior when counterexample traces require loops of more than one state.

The system has two integer variables, `x` and `y`, each initialized to a distinct value drawn from the range 0 through 50 inclusive. The sole transition `Next` unconditionally swaps the values of `x` and `y` on every step, so the system oscillates indefinitely between two states. Two liveness properties are declared: `Liveness` asserts that whenever `x` equals 0, it is eventually the case that `x` is nonzero and `y` equals 0 — which holds because the swap will bring `y` to 0 while making `x` nonzero. `FalseLiveness` asserts that whenever `x` equals 0, it is eventually the case that both `x` and `y` equal 0 simultaneously — which is false, since the swap never puts 0 in both variables at once given the initialization constraint `x ≠ y`. The module serves as a test fixture to exercise liveness checking in scenarios where the witnessing loop in the counterexample trace necessarily spans more than a single state.
