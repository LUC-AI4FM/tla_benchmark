The module `ManyDiamonds` is a small test specification designed to exercise model-checking behavior when a temporal formula contains redundant (nested) diamond (`<>`) operators.

The system has two integer variables, `x` and `y`, initialized to 0 and 1 respectively. Each step, `x` is updated to 10 if `y` exceeds 5, otherwise to `y + 1`, and symmetrically `y` is updated to 10 if `x` exceeds 5, otherwise to `x + 1`. This produces a deterministic evolution where the two variables increment in an interleaved fashion until one crosses 5, at which point both quickly reach 10 and the system halts (no stuttering-free successor exists beyond that fixed point).

Two liveness properties are stated, each using five nested diamond operators (which are semantically equivalent to a single `<>`). `Liveness` asserts that `x > 2` is eventually true, which holds since `x` will reach values above 2 in normal execution. `FalseLiveness` asserts that `x = 11` is eventually true, which is false because `x` can only reach 10 at most. The module's primary purpose is to verify that a model checker correctly handles and reduces superfluous nested diamonds in temporal formulas.
