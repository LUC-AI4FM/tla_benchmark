The Messages module is a reusable utility library that provides a multiset (bag) abstraction for modeling an unreliable network message channel in TLA+ specifications. Rather than specifying a standalone system, it defines shared variables and operators intended to be extended or instantiated by other modules.

The single variable `messages` is initialized as a function from an empty domain to natural numbers, representing a bag where each distinct message record maps to its current multiplicity in transit. The module defines `WithMessage` and `WithoutMessage` as internal helpers that add or subtract one occurrence of a message from a bag, extending the domain if necessary. Built on these helpers, `Send` adds a message to the bag, `Discard` removes one occurrence, and `Reply` atomically sends a response while discarding a request in a single step. Two additional actions model network faults: `DuplicateMessage` increments the count of a message already present exactly once, and `DropMessage` removes one occurrence of any in-flight message. The module contains no temporal specification, fairness conditions, or invariants of its own; it exists solely to supply message-passing primitives and a `Nil` constant placeholder for use by consuming specifications.
