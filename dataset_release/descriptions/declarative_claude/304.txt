The module specifies a tutorial model of binary search, closely mirroring the Java `Arrays.binarySearch` implementation. It is parameterized by three constants: `INPUT_SEQ` (the sequence being searched), `INPUT_KEY` (the value to find), and `INT_WIDTH` (the bit-width of machine integers, used to define signed/unsigned integer bounds).

Four variables track execution state: `low` and `high` delimit the current search interval (inclusive), `isTerminated` signals whether the algorithm has halted, and `returnValue` holds the result. `Init` sets `low` to 0, `high` to the last index, and `isTerminated` to false. Each `Next` step either narrows the interval by adjusting `low` or `high` based on a midpoint comparison, sets `returnValue` to the zero-based midpoint index and terminates on a match, or terminates with a negative insertion-point encoding when the interval is exhausted. Once terminated, the state stutters.

The module defines two postcondition invariants. `Postcondition` asserts unconditionally that upon termination the return value is non-negative exactly when the key is present (and points to a matching index). `PostconditionSorted` weakens this to hold only when `INPUT_SEQ` is sorted, matching the algorithm's actual precondition. The `InputIsSorted` predicate checks adjacent-element ordering efficiently. The spec is intended for use with the Apalache model checker to verify correctness across all inputs for a fixed integer bit-width.
