The module specifies a tutorial model of binary search, closely following the Java `Arrays.binarySearch` implementation. It is parameterized by three constants: `INPUT_SEQ` (the sequence to search), `INPUT_KEY` (the value to find), and `INT_WIDTH` (the bit-width of machine integers, used to derive `MAX_INT`, `MIN_INT`, and `MAX_UINT`).

The five variables track the inclusive search interval endpoints `low` and `high`, a termination flag `isTerminated`, the return value `returnValue`, and a step counter `nSteps`. Initialization sets `low = 0`, `high = Len(INPUT_SEQ) - 1`, and `isTerminated = FALSE`. Each `Next` step either narrows the interval by updating `low` or `high` based on a midpoint comparison, sets `returnValue` to the zero-based index on a match, or sets `returnValue` to a negative sentinel when the interval is exhausted, after which the state stutters. The spec uses integer division for midpoint calculation.

Several properties are defined and checked. `PostconditionSorted` asserts that upon termination, if the input is sorted, the return value is non-negative exactly when the key is present and correctly indexes a match. `Termination` asserts that after `INT_WIDTH` steps the algorithm must have terminated. `Progress` is a next-state safety property asserting that while not yet terminated, either `low` strictly increases or `high` strictly decreases, demonstrating interval contraction and implicitly guaranteeing termination.
