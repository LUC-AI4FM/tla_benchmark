The module `Slicer1` is a minimal test specification used to exercise symbolic transition slicing in a model-checking context. It models a trivial system with a single string-typed variable `state`, which is initialized to `"Init"` by the `Init` predicate. The next-state relation `Next` is the disjunction of two actions: action `A`, which sets `state` to `"A"`, and action `B`, which sets `state` to `"B"`. No fairness conditions are specified. The module defines a safety invariant `Inv` asserting that `state` is never equal to `"B"`, which is immediately violated by action `B`. The specification therefore describes a system whose invariant is straightforwardly falsifiable in a single step, serving as a straightforward test case for verifying that a model checker or slicing tool can correctly identify and handle the transition that leads to the violation.
