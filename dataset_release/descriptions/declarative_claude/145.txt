The module specifies Lamport's distributed mutual-exclusion algorithm, originally published in his 1978 CACM paper on logical clocks. It models N processes communicating over pairwise FIFO channels to coordinate exclusive access to a critical section.

The state consists of five variables: `clock` (each process's local Lamport clock), `req` (the clock value associated with the most recently received request from each peer, as seen by each process), `ack` (the set of processes that have acknowledged a given process's request), `crit` (the set of processes currently in the critical section), and `network` (per-process, per-peer FIFO queues of typed messages). Messages are records carrying a type field (`"req"`, `"ack"`, or `"rel"`) and an optional clock value. The algorithm proceeds through six actions: `Request` (a process broadcasts a timestamped request and records its own acknowledgement), `ReceiveRequest` (a process records the requester's clock, advances its own clock, and sends an ack), `ReceiveAck` (a process collects an acknowledgement), `Enter` (a process enters the critical section once it has all acks and holds the highest-priority request by Lamport's tie-breaking order), `Exit` (a process leaves the critical section, broadcasts a release, and resets its request state), and `ReceiveRelease` (a process clears the recorded request from the releasing peer). The temporal specification is `Init /\ [][Next]_vars` with no fairness conditions. The module defines `TypeOK` as a type invariant, `Mutex` (at most one process in the critical section at a time) as the main safety property, and `ClockConstraint` and `BoundedNetwork` as auxiliary state constraints for finite-state model checking.
