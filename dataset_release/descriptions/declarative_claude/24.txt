The module SeqBMC is an abstract, self-referential model of the sequential bounded model checking algorithm implemented in the Apalache symbolic model checker (version 0.5.x), written by Igor Konnov. It does not describe a user-level system but rather formalizes the search procedure of the checker itself.

The two constants are `NTRANS`, the number of symbolic transitions extracted from the `Next` relation, and `MAX_DEPTH`, the exploration bound. The three variables track `prefixes`, a sequence of sets of enabled transitions accumulated so far; `depth`, the current exploration depth; and `state`, which records whether the checker is still `"working"`, has found an `"error"`, concluded `"noerror"`, or hit a `"deadlock"`. A `BadExes` constant encodes a fixed set of transition-index sequences that represent invariant-violating executions. The helper `PrefixesToExes` converts the sequence of enabled-transition sets into the set of all concrete execution sequences it represents, and `SMT` models SMT-solver queries by checking whether any bad execution falls within that set.

In `Init`, the checker starts with a single initializing transition (index 0) and immediately checks whether the invariant is already violated. The `NextStep` action nondeterministically selects a non-empty subset of enabled transitions, invokes the SMT abstraction to test for invariant violations, and either records a counterexample or advances the depth, stopping with `"noerror"` once `MAX_DEPTH` is reached. The safety properties `NeverError` and `NeverDeadlock` assert that the checker never finds a counterexample and never reaches a deadlock state, respectively.
