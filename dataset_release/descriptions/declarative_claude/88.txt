This module is a typed variant of the classic single-channel handshake protocol from Lamport's *Specifying Systems*. It models a one-place communication channel that transfers values of an unspecified data type between a sender and a receiver using a ready/acknowledge bit-flip handshake.

The single constant `Data` is the set of values that can be transmitted. The single variable `chan` is a record with three fields: `val` (the current data value), `rdy` (the sender's ready bit), and `ack` (the receiver's acknowledge bit), both bits drawn from `{0, 1}`. The `TypeInvariant` asserts that `chan` always belongs to the product type `[val : Data, rdy : {0,1}, ack : {0,1}]`. Initialization requires the type invariant to hold and the channel to be idle, meaning `ack` equals `rdy`. The `Send(d)` action fires when the channel is idle (`rdy = ack`), placing datum `d` into `val` and flipping `rdy` to signal a pending message. The `Rcv` action fires when a message is pending (`rdy ≠ ack`), flipping `ack` to acknowledge receipt and restore the idle state. The temporal specification `Spec` is the conjunction of `Init` and the stuttering-closed next-state relation `[][Next]_chan`, with no fairness constraints. The module states the theorem that `Spec` implies `[]TypeInvariant`, confirming the type invariant is an inductive safety property of all behaviors.
