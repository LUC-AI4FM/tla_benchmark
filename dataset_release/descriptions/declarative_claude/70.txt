The module Bug3158 is a regression-test or bug-reproduction specification for the Apalache model checker, specifically targeting a defect (Bug 3158) where function generators produced counterexamples containing spurious "junk" values despite the underlying SMT representation being correct.

The module declares a single variable `fun`, typed as a function from integers to integers. The initial state uses Apalache's `Gen(4)` operator to non-deterministically generate a function with up to four domain elements. The next-state relation holds `fun` unchanged, so the system is effectively static after initialization. The invariant `Inv` asserts that the domain of `fun` is non-empty. Apalache is expected to find a counterexample violating this invariant—namely, a generated function with an empty domain—and the bug under test concerned whether that counterexample was reported cleanly or contained extraneous junk in the function's representation. The specification has no fairness conditions and no liveness properties; it exists solely to exercise and verify correct counterexample generation behavior in Apalache's handling of symbolic function values.
