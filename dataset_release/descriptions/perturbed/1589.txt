This module specifies Yodacz's algorithm for computing the greatest common divisor of two positive integers between 1 and Aqphcv. The file includes a PlusCal algorithm and its generated TLA+ translation, with state variables for the program counter and the algorithm variables Bnivz, Bfiej, u, and v. The specification checks termination under weak fairness of Roct, asserts correctness of the final result using a mathematically defined Haa operator, and also includes TLC-based counting expectations for named properties.
