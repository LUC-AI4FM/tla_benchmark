This specification models Dijkstra's classical self-stabilizing token ring algorithm from EWD426. The system consists of N nodes arranged in a ring, each storing a counter value in a bounded domain 0..M-1; node 0 can create a new token by incrementing relative to the last node, while every other node passes the token by copying its predecessor when their values differ. The spec assumes at least one node and a nonempty value domain, together with the condition N <= M + 1, and it verifies a stabilization property stating that eventually the system reaches and stays in a state with a unique token.
