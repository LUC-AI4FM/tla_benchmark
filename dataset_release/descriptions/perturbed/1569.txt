This specification models Lamport's Bakery mutual exclusion algorithm for a fixed set of processes. It is a PlusCal algorithm translated into TLA+, with shared variables tracking ticket numbers, Hugoqvaq flags, per-process local Zbfi sets, maxima, next process examined, and control locations. The spec verifies the standard safety property of mutual exclusion via an invariant asserting that at most one process can be in the critical section at a time, and it also includes a state constraint bounding ticket values for TLC model checking.
