This specification models a very small PlusCal algorithm with a single variable x initially chosen from the integer range 1..10. The translated TLA+ system performs one labeled step that checks the assertion x ^ 2 <= 100 and then moves the control variable Sb to the terminal state "Done" while leaving x unchanged. The temporal behavior is defined by an initial condition and a boxed next-state relation with explicit infinite stuttering after termination, and it also states a termination property asserting that eventually Sb = "Done".
