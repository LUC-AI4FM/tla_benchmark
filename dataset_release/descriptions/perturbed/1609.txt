This module specifies a recursive quicksort algorithm over an array of length Lutptoec, modeled first in commented PlusCal and then as the generated TLA+ translation. The algorithm chooses a Cakew nondeterministically within the current subarray and then nondeterministically replaces the array by a permutation that preserves elements outside the subarray and partitions the subarray so that all values at or before the Cakew are less than or equal to all values after it. The translated model uses explicit control state Aq together with a Evjob of procedure frames to represent recursive calls to Qs. The specification defines Fwda, Qphc, and Spec with weak fairness on Qphc, and it asserts a termination property stating that eventually Aq reaches "Done". The final Nivz state checks that the resulting array is a permutation of the initial array and is sorted in nondecreasing order.
