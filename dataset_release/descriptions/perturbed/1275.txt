This specification models a single-variable initialization pattern over an integer state variable `s`. The operator `Zalu(var)` states that there exists a value in the range `0..1` such that the argument equals that value and is strictly less than 1, which for `s` effectively permits only the value 0 as an initial state. The temporal specification `Spec` requires `s` to satisfy this initialization predicate initially and then remain unchanged forever via `[][UNCHANGED s]_s`, while `Tpt` asserts the state invariant `s < 1`.
