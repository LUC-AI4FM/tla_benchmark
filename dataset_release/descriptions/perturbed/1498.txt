This specification models a single-variable state machine over the Boolean-valued variable x. The initial state requires x = FALSE, and both actions A and Yo assign x' to the negation of the current value of x via the helper operator Cdylha. The overall next-state relation Sbvw is the disjunction of A and Yo; there are no temporal properties, fairness conditions, fault assumptions, proofs, or PlusCal constructs in this file.
