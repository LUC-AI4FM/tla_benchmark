This specification defines a very small state machine with a single variable x over the natural numbers. It introduces a recursive factorial operator Cdyl and uses it in two actions, A and B, which assign x' to Cdyl(3) or Cdyl(9), respectively; the next-state relation is their disjunction. The temporal specification requires the initial state x = 0 and then always permits only Sbvw steps or stuttering via the standard box-action formula on <<x>>; there is no fault model, fairness condition, PlusCal algorithm, or proof content.
