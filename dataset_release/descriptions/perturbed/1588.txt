This specification models Euclid's algorithm, starting from a fixed value 24 and a second value chosen from the range 1..N, to compute their greatest common divisor by repeated subtraction and swapping. The file contains a PlusCal algorithm and its generated TLA+ translation, with control-state variable Qs and state variables u, v, and Bircu. The temporal specification requires initialization, repeated Haaz steps with stuttering allowed, and weak fairness of Haaz; it also defines a termination property asserting that the control eventually reaches the "Done" state.
