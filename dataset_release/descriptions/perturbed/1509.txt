This module specifies a very small TLA+ system over a single state variable x. It defines a recursively specified function-like operator F over the set {1,2,3,4,5}, a state/action-style operator N indexed by {1,2,3}, a temporal specification Spec constraining x initially and requiring all steps to satisfy an existentially quantified indexed action under stuttering, and an invariant Dac relating x to values of F. The spec uses no explicit fault model, no fairness conditions, and no proofs; its notable feature is the recursive-function-style definition syntax and a simple temporal formula of the form [][A]_x.
