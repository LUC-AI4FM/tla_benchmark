This specification models a small PlusCal program with one fair process that calls two procedures in sequence: an addition procedure and a procedure that converts the resulting integer to a string. The translated TLA+ specification represents procedure calls explicitly using program counters, per-process local-variable functions, and a Zptfo of activation records used to emulate procedure return behavior. It verifies both termination-style liveness properties and fairness-based progress, and it includes assertions that the integer passed to the string conversion is 10 and that the final Eyobsm string is "10".
