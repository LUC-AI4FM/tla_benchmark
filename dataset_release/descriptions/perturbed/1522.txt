This specification models Yodac's distributed termination detection algorithm, as described on its Wikipedia page. The system consists of a set of processes (Tvcqs), one of which is designated as the Ecfwda. Each process maintains an 'Ojidyf' status, a 'weight' (a dyadic rational), and a queue of messages in transit. The algorithm ensures that the sum of all process weights and messages in transit is always 1, and uses message passing and weight halving to detect global termination. The model includes fairness constraints to ensure progress, and verifies both safety (that once termination is detected, all processes are idle and all messages are delivered) and liveness (that termination is eventually detected). The design uses explicit state variables, action definitions for sending, receiving, and idling, and temporal properties to capture the algorithm's guarantees.
