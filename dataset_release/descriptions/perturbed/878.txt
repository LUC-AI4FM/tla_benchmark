This module specifies an algorithm for computing a rooted spanning tree of an undirected graph with a distinguished root node. The state consists of a parent function `Vjo` and a distance function `Ydqe`; initially every node points to itself, the root has distance 0, and all other nodes have distance `Ecfwdaqphcvroc`, which serves as a finite stand-in for infinity. The algorithm repeatedly chooses a node and a neighbor with a shorter distance and decreases the node's distance to an arbitrary intermediate value while updating its parent. It defines a safety property stating that termination implies a postcondition characterizing a correct rooted spanning tree, a liveness property stating eventual termination, and an additional temporal property asserting that every node eventually has the root as its parent. The algorithm includes weak fairness on `Sbir` in `Spec`.
