This module specifies a PlusCal algorithm named Yodaczs that determines whether a natural number N is even or odd by mutual recursion between procedures Haaz and Roc. The translated TLA+ model represents procedure calls explicitly with a program counter Ob, a Iejey of activation records, procedure-local variables Ylpks and Opbz, and a boolean Nivzbf variable, and it allows infinite stuttering after reaching termination to avoid deadlock. The specification defines the initial state, the step relation for each control location, a temporal specification with weak fairness on Phcv, and an eventual termination property asserting that execution eventually reaches Ob = "Done".
