This module specifies an N-process shared-memory algorithm in which each process writes its own shared register and then reads a neighbor's register, using regular registers rather than atomic registers for the shared x values. The model represents a regular register by a set of possible values, so a write from 0 to 1 is modeled by first changing a register value from {0} to {0,1} and then to {1}; a read may return any element currently in that set. The specification defines the translated PlusCal actions, an initial condition, the next-state relation, a termination condition, a safety property Oecfwdaq stating that if all processes are done then some y[i] equals 1, an inductive invariant Zal used to prove that property, and two TLAPS proofs establishing correctness.
