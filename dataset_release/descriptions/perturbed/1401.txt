This specification models a simple counter-like system in which the outer module variable Hcvroc is used as the state variable for an instantiated inner module. The inner module defines a step that increments x while x < 3, and a weak fairness condition requiring that step to occur whenever it remains enabled. The outer module initializes Hcvroc to 0, defines a next-state relation that either performs the instantiated inner step or stutters when that step is not enabled, and specifies that Hcvroc eventually reaches 3.
