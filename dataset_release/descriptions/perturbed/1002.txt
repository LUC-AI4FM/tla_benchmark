This module specifies a simple reusable barrier synchronization protocol for N processes. Each process starts in control state "Sb" and may individually move to "Ir"; once all processes are in "Ir", the barrier resets all processes back to "Sb" simultaneously. The specification defines the initial state, the next-state relation, a type correctness condition for the program counter function, and a temporal barrier property stating that a process cannot leave the barrier while some other process has not yet entered it.
