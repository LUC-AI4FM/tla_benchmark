This module specifies a simplified version of Leslie Lamport's Fast Paxos consensus protocol. The specification assumes a unique coordinator, omits explicit modeling of failures (since agents restore state from stable storage), and allows all agents to communicate directly. The protocol models both fast and classic rounds, with special handling for quorum intersection and value selection in the presence of collisions. The specification defines the main protocol actions, type invariants, and a non-triviality safety property, and it verifies that consensus is achieved only on values that have been proposed.
