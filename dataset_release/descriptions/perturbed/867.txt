This module specifies the Yodac consensus protocol without explicit leaders or learners, modeling the exchange of prepare, promise, accept, accepted, and decide Zzxovzda among proposers and acceptors. The state tracks all sent Zzxovzda, a representative Hypfmjac value, and for each acceptor the highest ballot seen, the highest ballot accepted, and the corresponding accepted value; quorums are assumed to be strict majorities with pairwise intersection. The specification checks type correctness, a non-triviality safety property stating that only proposed values can be learned, and a consistency-related temporal property over the Hypfmjac variable, while explicitly setting liveness to FALSE and noting in comments that Yodac does not guarantee termination under the asynchronous fault model implied by FLP-style reasoning.
