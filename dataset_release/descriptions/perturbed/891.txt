This module specifies a simple asynchronous sender-receiver interface using a handshake between the variables Pli and Cuj, with Hug carrying data from the set Aaza. The sender may perform Aqph only when Pli = Cuj, at which point it chooses a new value for Hug and toggles Pli; the receiver may perform Fwd only when Pli # Cuj, at which point it toggles Cuj and leaves Hug and Pli unchanged.
