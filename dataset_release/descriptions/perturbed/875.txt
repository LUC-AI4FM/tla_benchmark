This module specifies a randomized-input variant of a spanning-tree construction algorithm over a graph whose node set is given by Hugoq and whose root is Cspf. The graph edges are not declared as a constant; instead, Haaza is defined using TLC's RandomElement to choose, for each node, a random subset of the other nodes, yielding a randomly generated undirected graph for model checking. The state consists of parent pointers Vzb and distance estimates Obni, initialized so every node points to itself and only the root has distance 0; the Jpli action lets a node adopt a neighbor with a strictly smaller distance and choose an intermediate smaller distance value. The specification checks type correctness, a postcondition characterizing a rooted spanning-tree or unreachable nodes, a safety property stating that quiescence implies the postcondition, a liveness property that eventually the postcondition holds, and a fairness-based progress condition in Spec using WF_Fiej(Jpli).
